1. AI가 잘하는 것 ✅

① 패턴 학습

수많은 데이터에서 반복되는 패턴을 빠르게 찾아요. 번역, 요약, 분류가 여기에 속해요.

② 형식 변환

"이 문장을 표로 만들어줘", "JSON을 CSV로 변환해줘" 같은 포맷 변경 작업은 거의 실수가 없어요.

③ 초안 작성

"이메일 초안", "보고서 뼈대", "코드 스켈레톤" — 0에서 시작하기 힘든 일을 70% 지점까지 끌어줘요.

④ 브레인스토밍

"이 주제로 50가지 아이디어 내줘" 같은 요청에 지치지 않고 답해요. 사람 혼자보다 빠르고 다양.

⑤ 코드 생성/설명

잘 알려진 패턴(CRUD, API 호출, 정렬)은 거의 완벽하게 만들어요. 모르는 코드를 설명받기도 좋아요.

⑥ 언어 번역

구글 번역보다 자연스러운 문맥 번역 가능. 한국어 ↔ 영어는 거의 사람 수준.

⑦ 요약

긴 글을 핵심만 뽑아내는 데 탁월. 뉴스, 논문, 회의록 등에 유용.

⑧ 문법 교정

영어 문법 체크는 진짜 강점. 영어 작문 보조로 쓰면 실력이 빨리 늘어요.

⑨ 코드 디버깅 보조

에러 메시지를 붙여넣고 "이게 뭐야?"라고 물으면 원인 추정과 해결 방법 제시.

⑩ 24/7 대답

새벽 2시에도 답해요. 선생님/친구에게 물어보기 민망한 초보 질문도 편하게 할 수 있어요.

2. AI가 못하는 것 ❌

① 정확한 수학 계산

놀라겠지만 AI는 큰 숫자 곱셈도 틀려요. 12345 × 67890 같은 건 계산기가 정답. AI는 "추측"이라 틀릴 수 있어요.

② 최신 정보

학습 시점 이후의 사건은 몰라요. "어제 뉴스", "지금 주가" 같은 실시간 정보는 검색 도구 병행 필수.

③ 개인 기억

일반 ChatGPT는 이전 대화를 기억하지 않아요 (Claude Projects 등 별도 기능은 있음). 매번 맥락을 다시 알려줘야 해요.

④ 출처 검증

"이 출처 믿을만해?"에 답 못 해요. 공식 문서와 가짜 블로그를 구분 못 해요.

⑤ 물리 세계 상호작용

AI는 화면 안에만 살아요. 로봇/IoT와 연결 없으면 물리 세계에선 아무것도 못 해요.

⑥ 감정과 의도 파악

텍스트에서 "기분 좋음" vs "빈정댐"을 구분 못 할 때 많아요. 사람의 미묘한 감정 읽기 어려워요.

⑦ 창의성의 진짜 도약

기존 패턴을 섞어서 "새로워 보이는" 건 잘 만들어요. 하지만 패러다임을 바꾸는 혁신은 못 해요.

⑧ 긴 논리 체인

10단계 이상의 복잡한 추론은 중간에서 틀려요. 수학 증명 긴 거는 종종 실패.

⑨ 니가 아는 걸 AI가 모를 때 알아차리기

AI는 "내가 모르는 게 있을 수 있다"는 메타 인지가 약해요. 자기 한계를 모름.

⑩ 도덕적 판단

윤리 딜레마(트롤리 문제 등)에 대해 "정답"을 줄 수 없어요. 여러 시각을 나열할 뿐.

4. "AI 우선" 전략

새로운 일을 시작할 때 다음 순서로 생각해봐요.

  1. 이 작업을 AI가 할 수 있는가?
  2. (가능하면) AI에게 초안을 받는다
  3. 초안을 내가 검토하고 수정한다
  4. 사실 확인이 필요한 부분은 검증한다
  5. 최종 결과물에 내 판단을 더한다

🤔 "AI가 다 해주니까 사람은 필요없다"는 착각. 실제로는 "AI 잘 쓰는 사람"과 "못 쓰는 사람"의 격차가 더 벌어져요. AI는 증폭기예요.
