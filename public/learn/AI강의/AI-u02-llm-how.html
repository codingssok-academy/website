AI LITERACY · UNIT 02

LLM은 어떻게 말할까

확률 기반 다음 단어 예측의 비밀

이 단원에서 배울 것

  • 토큰(token) — AI가 글을 쪼개는 단위
  • 다음 단어를 "확률"로 고르는 방식
  • Temperature — 창의성 조절 다이얼
  • 왜 같은 질문에 매번 답이 조금씩 다른가

1. AI는 이해하지 않는다

충격적일 수 있지만, ChatGPT나 Claude는 "이해"하지 않아요. 다음에 올 단어를 확률로 예측하는 기계일 뿐이에요.

💡 "저는 오늘 학교에..." → 다음 단어로 뭐가 올 확률이 높을까?

  • "갔어요" — 45% 확률
  • "가요" — 30% 확률
  • "갑니다" — 15% 확률
  • "안 가요" — 5% 확률
  • "...(기타)" — 5% 확률

AI는 이 확률 분포에서 한 단어를 뽑아요. 그리고 그 단어를 포함해서 다시 "다음 단어 확률"을 계산해요. 이걸 문장이 끝날 때까지 반복.

토큰 (Token)

AI가 다루는 최소 단위는 "단어"가 아니라 "토큰"이에요. 영어로 apple은 1토큰이지만, 한국어로 안녕하세요는 약 3-5토큰이에요 (모델마다 다름).

GPT-4는 영어 1단어 ≈ 1.3토큰, 한국어 1글자 ≈ 1-2토큰으로 잡아요.

2. Temperature — 창의성 다이얼

AI가 확률 분포에서 단어를 뽑을 때, "가장 확률 높은 것만 뽑을지", "랜덤하게 다양하게 뽑을지"를 조절하는 값이 Temperature예요.

Temperature동작결과
0항상 최고 확률 단어 선택같은 답변 반복, 딱딱함
0.3거의 확정적일관된 답, 사실 답변에 적합
0.7적당한 랜덤일반 대화 기본값
1.0원본 확률 그대로창의적, 예측 불가
1.5+의도적 왜곡시·소설 등 창작용

⚠️ Temperature가 높을수록 "창의적"이지만 "환각(거짓말)"도 늘어요. 코드 생성이나 사실 질문엔 0.2~0.5가 적당해요.

3. 왜 매번 답이 다를까?

Temperature가 0이 아니면 랜덤이 섞여요. 같은 질문에 같은 확률 분포가 나와도, 뽑히는 단어가 달라질 수 있어요.

# 같은 프롬프트, 다른 결과
질문: "오늘 기분이 어때?"
답1: "오늘은 꽤 좋은 하루예요!"
답2: "좋아요, 오늘 하루가 순조로워요."
답3: "기분이 괜찮네요, 감사합니다."

의미는 비슷하지만 단어 선택이 매번 달라요. 확률이 비슷한 여러 단어 중 랜덤으로 뽑히기 때문이에요.

4. Context Window — 기억의 한계

AI는 한 번에 기억할 수 있는 토큰 수가 정해져 있어요. 이걸 Context Window라고 해요.

모델Context Window비고
GPT-3.516K 토큰약 12,000 단어
GPT-4128K 토큰소설 한 권
Claude 3.5200K 토큰논문 수십 편
Claude 4.6 (1M)1,000K 토큰책 수백 권

🤔 Context Window를 넘어가면 AI는 앞부분을 "잊어요". 긴 대화를 하다가 AI가 초반 내용을 까먹는 이유예요.

5. 핵심 정리

  • ✅ LLM은 "이해"가 아니라 "다음 단어 확률 예측"
  • ✅ 토큰 단위로 처리 (단어 ≠ 토큰)
  • ✅ Temperature로 창의성 vs 정확성 조절
  • ✅ Context Window 넘으면 앞 내용 잊음
