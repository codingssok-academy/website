  3. ③표시 형식에서 yyyy는 4자리 연도를 나타낸다
  4. ④사용자 지정 형식에서 @는 숫자를 표시하는 기호이다
36다음 중 수학/통계 함수의 결과 값으로 옳지 않은 것은? 매회
  1. ①SUM 함수는 범위 내 숫자의 합계를 구한다
  2. ②AVERAGE 함수는 범위 내 숫자의 평균을 구한다
  3. ③ROUND(3.456, 2)의 결과는 3.46이다
  4. ④COUNT 함수는 빈 셀의 개수를 구한다
37다음 중 수식 오류 메시지에 대한 설명으로 옳지 않은 것은? 매회
  1. ①#DIV/0!은 0으로 나누었을 때 발생한다
  2. ②#VALUE!는 잘못된 데이터 형식을 사용했을 때 발생한다
  3. ③#NAME?은 함수 이름이 잘못되었을 때 발생한다
  4. ④#REF!는 숫자가 셀 너비보다 클 때 발생한다
38다음 중 피벗 테이블 보고서에 대한 설명으로 옳지 않은 것은? 매회
  1. ①피벗 테이블에서 그룹화 기능으로 날짜를 월/분기별로 묶을 수 있다
  2. ②피벗 테이블 필드 목록에서 드래그로 필드를 배치한다
  3. ③슬라이서를 사용하면 피벗 테이블 데이터를 쉽게 필터링할 수 있다
  4. ④피벗 테이블은 원본 데이터와 같은 시트에만 만들 수 있다
39다음 중 인쇄 설정에 대한 설명으로 옳지 않은 것은? 자주
  1. ①인쇄 영역을 설정하여 원하는 범위만 인쇄할 수 있다
  2. ②페이지 나누기 미리 보기에서 인쇄 범위를 조정할 수 있다
  3. ③머리글/바닥글에 페이지 번호, 날짜 등을 삽입할 수 있다
  4. ④인쇄 제목 설정으로 반복할 행은 설정할 수 있지만, 열은 반복할 수 없다
40다음 중 셀 표시 오류에 대한 설명으로 옳지 않은 것은? 매회
  1. ①#N/A는 찾는 값이 없을 때 발생한다
  2. ②#NUM!은 잘못된 숫자 값을 사용했을 때 발생한다
  3. ③#NULL!은 두 영역의 교차 부분이 없을 때 발생한다
  4. ④######은 수식에 오류가 있을 때 발생한다
