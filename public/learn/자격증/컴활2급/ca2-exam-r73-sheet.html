  3. ③MID("EXCEL", 2, 3)의 결과는 "XCE"이다
  4. ④LEN("EXCEL")의 결과는 6이다
36다음 중 날짜/시간 함수의 결과 값으로 옳지 않은 것은? 자주
  1. ①TODAY()는 현재 날짜를 반환한다
  2. ②NOW()는 현재 날짜와 시간을 반환한다
  3. ③YEAR("2024-03-15")의 결과는 2024이다
  4. ④MONTH("2024-03-15")의 결과는 15이다
37다음 중 셀 서식에 대한 설명으로 옳지 않은 것은? 매회
  1. ①셀 서식에서 숫자, 맞춤, 글꼴, 테두리, 채우기 등을 설정할 수 있다
  2. ②사용자 지정 형식에서 #은 유효한 숫자만 표시한다
  3. ③사용자 지정 형식에서 0은 자릿수가 부족하면 0으로 채운다
  4. ④조건부 서식은 셀의 내용을 직접 변경한다
38다음 중 차트 종류에 대한 설명으로 옳지 않은 것은? 매회
  1. ①원형 차트는 전체에 대한 각 항목의 비율을 표시한다
  2. ②꺾은선 차트는 시간에 따른 데이터 변화를 표시한다
  3. ③막대 차트는 항목 간 크기 비교에 적합하다
  4. ④원형 차트는 여러 데이터 계열을 동시에 비교할 때 적합하다
39다음 중 수식 오류 메시지에 대한 설명으로 옳지 않은 것은? 매회
  1. ①#DIV/0!은 0으로 나누었을 때 발생한다
  2. ②#VALUE!는 잘못된 데이터 형식을 사용했을 때 발생한다
  3. ③#NAME?은 함수 이름이 잘못되었을 때 발생한다
  4. ④#REF!는 숫자가 셀 너비보다 클 때 발생한다
