  3. ③[Ctrl]을 누르고 시트 탭을 드래그하면 시트가 복사된다
  4. ④시트 보호를 설정하면 보호된 셀의 서식도 자유롭게 변경할 수 있다
37다음 중 수학/통계 함수의 결과 값으로 옳지 않은 것은? 매회
  1. ①SUM 함수는 범위 내 숫자의 합계를 구한다
  2. ②AVERAGE 함수는 범위 내 숫자의 평균을 구한다
  3. ③ROUND(3.456, 2)의 결과는 3.46이다
  4. ④COUNT 함수는 빈 셀의 개수를 구한다
38다음 중 날짜 함수에 대한 설명으로 옳지 않은 것은? 자주
  1. ①DATE(2024,1,1)은 2024년 1월 1일을 반환한다
  2. ②WEEKDAY 함수는 요일을 숫자로 반환한다
  3. ③HOUR 함수는 시간 값에서 시(時)를 추출한다
  4. ④DATEDIF 함수는 두 날짜 사이의 합계를 구한다
39다음 중 논리 함수에 대한 설명으로 옳지 않은 것은? 매회
  1. ①IF 함수는 조건에 따라 다른 값을 반환한다
  2. ②IFERROR 함수는 수식 오류 시 대체 값을 반환한다
  3. ③AND는 모든 조건이 TRUE일 때 TRUE를 반환한다
  4. ④OR는 모든 조건이 TRUE일 때만 TRUE를 반환한다
40다음 중 날짜/시간 함수의 결과 값으로 옳지 않은 것은? 자주
  1. ①TODAY()는 현재 날짜를 반환한다
  2. ②NOW()는 현재 날짜와 시간을 반환한다
  3. ③YEAR("2024-03-15")의 결과는 2024이다
  4. ④MONTH("2024-03-15")의 결과는 15이다
