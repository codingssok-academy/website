  4. ④피벗 테이블은 원본 데이터가 변경되면 자동으로 업데이트된다
36다음 중 매크로에 대한 설명으로 옳지 않은 것은? 자주
  1. ①매크로는 반복 작업을 자동화하는 기능이다
  2. ②매크로 기록은 사용자의 작업을 VBA 코드로 저장한다
  3. ③매크로 단축키는 [Ctrl]+알파벳으로 지정할 수 있다
  4. ④매크로가 포함된 파일은 .xlsx 형식으로 저장한다
37다음 중 텍스트 변환 함수에 대한 설명으로 옳지 않은 것은? 자주
  1. ①UPPER는 소문자를 대문자로 변환한다
  2. ②LOWER는 대문자를 소문자로 변환한다
  3. ③TRIM은 문자열 양쪽의 공백을 제거한다
  4. ④REPLACE는 문자열에서 특정 문자를 찾아 바꾼다
38다음 중 데이터 통합에 대한 설명으로 옳지 않은 것은? 자주
  1. ①통합 기능으로 여러 시트의 데이터를 하나로 합칠 수 있다
  2. ②위치별 통합과 범주별 통합이 있다
  3. ③합계, 평균, 개수 등의 함수를 사용할 수 있다
  4. ④통합은 반드시 같은 통합 문서 내의 시트끼리만 가능하다
39다음 중 매크로 관리에 대한 설명으로 옳지 않은 것은? 자주
  1. ①매크로 바이러스는 VBA를 이용한 악성코드이다
  2. ②매크로 실행 단축키로 [Alt]+[F8]을 사용한다
  3. ③Visual Basic Editor는 [Alt]+[F11]로 실행한다
  4. ④매크로는 한 번 기록하면 수정할 수 없다
40다음 중 데이터베이스 함수에 대한 설명으로 옳지 않은 것은? 자주
  1. ①DSUM은 조건에 맞는 데이터의 합계를 구한다
  2. ②DAVERAGE는 조건에 맞는 데이터의 평균을 구한다
  3. ③DCOUNT는 조건에 맞는 숫자 셀의 개수를 구한다
  4. ④데이터베이스 함수는 조건 범위(Criteria)가 필요 없다
