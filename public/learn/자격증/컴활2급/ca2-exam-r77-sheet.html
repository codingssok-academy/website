  4. ④VLOOKUP의 마지막 인수 TRUE는 정확히 일치하는 값만 찾는다
35다음 중 워크시트 관리에 대한 설명으로 옳지 않은 것은? 자주
  1. ①시트 탭을 더블클릭하여 이름을 변경할 수 있다
  2. ②시트를 드래그하여 순서를 변경할 수 있다
  3. ③[Ctrl]을 누르고 시트 탭을 드래그하면 시트가 복사된다
  4. ④시트 보호를 설정하면 보호된 셀의 서식도 자유롭게 변경할 수 있다
36다음 중 인쇄 설정에 대한 설명으로 옳지 않은 것은? 자주
  1. ①인쇄 영역을 설정하여 원하는 범위만 인쇄할 수 있다
  2. ②페이지 나누기 미리 보기에서 인쇄 범위를 조정할 수 있다
  3. ③머리글/바닥글에 페이지 번호, 날짜 등을 삽입할 수 있다
  4. ④인쇄 제목 설정으로 반복할 행은 설정할 수 있지만, 열은 반복할 수 없다
37조건부 함수에 대한 설명으로 옳지 않은 것은? 매회
  1. ①SUMIF는 조건에 맞는 셀의 합계를 구한다
  2. ②COUNTIF는 조건에 맞는 셀의 개수를 구한다
  3. ③AVERAGEIF는 조건에 맞는 셀의 평균을 구한다
  4. ④MAX 함수는 범위 내 최솟값을 구한다
38다음 중 데이터 통합에 대한 설명으로 옳지 않은 것은? 자주
  1. ①통합 기능으로 여러 시트의 데이터를 하나로 합칠 수 있다
  2. ②위치별 통합과 범주별 통합이 있다
  3. ③합계, 평균, 개수 등의 함수를 사용할 수 있다
  4. ④통합은 반드시 같은 통합 문서 내의 시트끼리만 가능하다
39다음 중 고급 필터에 대한 설명으로 옳지 않은 것은? 매회
  1. ①자동 필터는 드롭다운 화살표로 조건을 선택한다
  2. ②필터를 적용하면 조건에 맞지 않는 행은 숨겨진다
  3. ③고급 필터의 조건 범위에서 같은 행은 AND, 다른 행은 OR 조건이다
  4. ④정렬 기준은 최대 3개까지만 설정할 수 있다
40다음 중 이름 정의에 대한 설명으로 옳지 않은 것은? 자주
  1. ①셀이나 범위에 이름을 부여하여 수식에서 사용할 수 있다
  2. ②이름 상자에 직접 입력하여 이름을 정의할 수 있다
  3. ③이름은 공백을 포함할 수 없으며 밑줄(_)은 사용 가능하다
  4. ④이름의 첫 글자에 숫자를 사용할 수 있다
