  3. ③슬라이서를 사용하면 피벗 테이블 데이터를 쉽게 필터링할 수 있다
  4. ④피벗 테이블은 원본 데이터와 같은 시트에만 만들 수 있다
35다음 중 날짜 함수에 대한 설명으로 옳지 않은 것은? 자주
  1. ①DATE(2024,1,1)은 2024년 1월 1일을 반환한다
  2. ②WEEKDAY 함수는 요일을 숫자로 반환한다
  3. ③HOUR 함수는 시간 값에서 시(時)를 추출한다
  4. ④DATEDIF 함수는 두 날짜 사이의 합계를 구한다
36다음 중 피벗 테이블에 대한 설명으로 옳지 않은 것은? 매회
  1. ①피벗 테이블은 대량의 데이터를 요약, 분석하는 도구이다
  2. ②행, 열, 값, 필터 영역으로 구성된다
  3. ③값 영역에는 합계, 평균, 개수 등의 요약 함수를 적용할 수 있다
  4. ④피벗 테이블은 원본 데이터가 변경되면 자동으로 업데이트된다
37다음 중 수학/통계 함수의 결과 값으로 옳지 않은 것은? 매회
  1. ①SUM 함수는 범위 내 숫자의 합계를 구한다
  2. ②AVERAGE 함수는 범위 내 숫자의 평균을 구한다
  3. ③ROUND(3.456, 2)의 결과는 3.46이다
  4. ④COUNT 함수는 빈 셀의 개수를 구한다
38다음 중 데이터 통합에 대한 설명으로 옳지 않은 것은? 자주
  1. ①통합 기능으로 여러 시트의 데이터를 하나로 합칠 수 있다
  2. ②위치별 통합과 범주별 통합이 있다
  3. ③합계, 평균, 개수 등의 함수를 사용할 수 있다
  4. ④통합은 반드시 같은 통합 문서 내의 시트끼리만 가능하다
39다음 중 데이터 정렬에 대한 설명으로 옳지 않은 것은? 매회
  1. ①정렬은 오름차순, 내림차순으로 설정할 수 있다
  2. ②자동 필터는 조건에 맞는 데이터만 표시한다
  3. ③고급 필터는 복잡한 조건으로 데이터를 추출할 수 있다
  4. ④정렬을 수행하면 원본 데이터의 순서가 영구적으로 변경되어 복원할 수 없다
40다음 중 매크로 관리에 대한 설명으로 옳지 않은 것은? 자주
  1. ①매크로 바이러스는 VBA를 이용한 악성코드이다
  2. ②매크로 실행 단축키로 [Alt]+[F8]을 사용한다
  3. ③Visual Basic Editor는 [Alt]+[F11]로 실행한다
  4. ④매크로는 한 번 기록하면 수정할 수 없다
