  1. ①항상 고정된 서버가 할당된다
  2. ②서버 관리를 클라우드 제공자가 담당하고, 사용한 만큼만 과금된다
  3. ③서버가 전혀 존재하지 않는다
  4. ④로컬 컴퓨터에서 실행된다
59디지털 트윈(Digital Twin)에 대한 설명으로 올바른 것은? 자주
  1. ①실제 물리적 객체를 디지털로 복제하여 시뮬레이션하는 기술
  2. ②두 대의 컴퓨터를 연결하는 기술
  3. ③암호화폐를 채굴하는 기술
  4. ④화면을 미러링하는 기술
60다음 중 HTTP 상태 코드 404의 의미는? 매회
  1. ①서버 내부 오류
  2. ②요청한 페이지를 찾을 수 없음
  3. ③접근 권한 없음
  4. ④요청 성공
