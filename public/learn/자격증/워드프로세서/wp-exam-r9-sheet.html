1워드프로세싱 일반Q1 – Q20
1다음 중 교정부호(원고 수정 시 사용하는 약속 기호)에 대한 설명으로 옳지 않은 것은? 자주
  1. ①교정부호는 원고와 구별되도록 다른 색(보통 빨간색)으로 표시한다
  2. ②줄 바꿈 없이 이어 쓸 때는 줄 끝과 다음 줄 시작을 곡선으로 연결한다
  3. ③삽입 부호는 넣을 위치에 'V' 모양을 그리고 위에 삽입할 내용을 쓴다
  4. ④교정 작업이 완료되면 교정부호를 지우지 않고 원고와 함께 보관해야 한다
2다음 중 공문서(관공서에서 작성하는 공식 문서)의 항목 번호 체계로 올바른 순서는? 자주
  1. ①1. → 가. → 1) → 가) → (1) → (가)
  2. ②Ⅰ. → 1. → 가. → 1) → 가) → (1)
  3. ③1. → 1) → 가. → 가) → (1) → (가)
  4. ④가. → 1. → 가) → 1) → (가) → (1)
3다음 중 전결(대리 결재)과 대결(임시 대리 결재)에 대한 설명으로 옳지 않은 것은? 자주
  1. ①전결은 결재권자가 위임한 사항에 대해 하위자가 결재하는 것이다
  2. ②대결은 결재권자가 출장·휴가 등으로 부재 시 직근 하위자가 대신 결재하는 것이다
  3. ③대결한 문서는 결재권자가 복귀한 후에도 다시 결재받을 필요가 없다
  4. ④전결 시에는 '전결' 표시를 하고, 전결하는 사람이 서명한다
4다음 중 트루타입 글꼴(TrueType Font, 윤곽선 기반 글꼴)에 대한 설명으로 옳은 것은? 자주
  1. ①비트맵 글꼴처럼 점(픽셀)으로 구성되어 확대하면 계단 현상이 발생한다
  2. ②화면에 표시되는 모양과 프린터 출력 결과가 동일하다
  3. ③확장자가 .bmp이며 이미지 파일 형식으로 저장된다
  4. ④크기를 변경할 수 없어 고정 크기로만 사용 가능하다
5다음 중 유니코드(Unicode, 국제 문자 코드 표준)에 대한 설명으로 옳지 않은 것은? 자주
  1. ①전 세계 모든 문자를 하나의 코드 체계로 표현하기 위해 만들어졌다
  2. ②한글은 완성형과 조합형을 모두 지원한다
  3. ③ASCII 코드와 호환되지 않아 영문 처리에 별도 변환이 필요하다
  4. ④2바이트 이상을 사용하여 65,536개 이상의 문자를 표현할 수 있다
6다음 중 OLE(Object Linking and Embedding, 개체 연결 및 삽입)에 대한 설명으로 옳은 것은? 자주
  1. ①연결(Linking)은 원본 파일의 경로 정보를 저장하여 원본 변경 시 자동 반영된다
  2. ②삽입(Embedding)은 원본 파일이 삭제되면 삽입된 개체도 함께 사라진다
  3. ③연결(Linking)은 원본 파일이 변경되어도 삽입된 문서에는 영향을 주지 않는다
  4. ④OLE는 같은 프로그램 내에서만 사용할 수 있다
7다음 중 매크로(Macro, 반복 작업 자동 실행 기능)에 대한 설명으로 옳지 않은 것은? 자주
  1. ①자주 반복되는 작업을 기록하여 한 번에 실행할 수 있다
  2. ②매크로는 키보드 조작만 기록할 수 있으며 마우스 동작은 기록되지 않는다
  3. ③매크로 바이러스는 문서 파일에 포함되어 전파될 수 있다
  4. ④매크로에 단축키를 지정하여 빠르게 실행할 수 있다
8다음 중 메일 머지(Mail Merge, 편지 병합)에 대한 설명으로 옳은 것은? 자주
  1. ①주소록 등의 데이터 파일과 본문 서식 파일을 병합하여 여러 문서를 자동 생성한다
  2. ②본문 내용이 수신자마다 서로 다르게 작성되어야 한다
  3. ③이메일 전송에만 사용할 수 있으며 인쇄용으로는 활용할 수 없다
  4. ④데이터 파일 없이 본문 서식만으로도 병합이 가능하다
9다음 중 각주(Footnote)와 미주(Endnote)에 대한 설명으로 옳지 않은 것은? 자주
  1. ①각주는 해당 페이지 하단에, 미주는 문서 끝에 표시된다
  2. ②각주와 미주 모두 본문의 특정 단어에 참조 번호를 부여한다
  3. ③각주는 한 페이지에 하나만 넣을 수 있으며, 여러 개를 넣으면 자동으로 미주로 변환된다
  4. ④각주와 미주는 서로 변환이 가능하다
10다음 중 색인(Index, 찾아보기)과 목차(Table of Contents)에 대한 설명으로 옳은 것은? 자주
  1. ①색인은 문서의 장·절·항 제목을 순서대로 나열한 것이다
  2. ②목차는 특정 용어가 나오는 페이지 번호를 가나다순으로 정리한 것이다
  3. ③목차는 문서의 구조(장·절·항)를 보여주고, 색인은 특정 용어의 위치를 안내한다
  4. ④색인과 목차는 동일한 기능이며, 위치만 다르다
11다음 중 프린터 관련 용어에 대한 설명으로 옳지 않은 것은? 자주
  1. ①DPI(Dots Per Inch)는 1인치당 찍히는 점의 수로, 값이 클수록 선명하다
  2. ②PPM(Pages Per Minute)은 1분당 인쇄 가능한 페이지 수이다
  3. ③스풀링(Spooling)은 인쇄 데이터를 메모리에 저장한 후 순서대로 출력하는 방식이다
  4. ④DPI 값이 높을수록 인쇄 속도가 빨라진다
12다음 중 디더링(Dithering)에 대한 설명으로 옳은 것은? 자주
  1. ①이미지의 해상도를 높이는 기술이다
  2. ②제한된 색상을 조합하여 더 많은 색상을 표현하는 기법이다
  3. ③이미지를 흑백으로 변환하는 기술이다
  4. ④이미지 파일의 용량을 줄이는 압축 기술이다
13다음 중 자간, 장평, 행간에 대한 설명으로 옳지 않은 것은? 자주
  1. ①자간(字間)은 글자와 글자 사이의 간격이다
  2. ②장평(長平)은 글자의 가로 대 세로 비율이다
  3. ③행간(行間)은 줄과 줄 사이의 간격이다
  4. ④커닝(Kerning)은 모든 글자 사이의 간격을 균일하게 맞추는 기능이다
14다음 중 DRM(Digital Rights Management, 디지털 저작권 관리)에 대한 설명으로 옳지 않은 것은? 자주
  1. ①DRM은 오프라인 환경에서는 적용할 수 없으며 인터넷 연결이 필수적이다
  2. ②문서의 열람, 편집, 인쇄 등의 권한을 제한할 수 있다
  3. ③DRM이 적용된 문서는 허가된 사용자만 접근할 수 있다
  4. ④디지털 콘텐츠의 불법 복제와 유통을 방지하기 위한 기술이다
15다음 중 WYSIWYG(위지위그, What You See Is What You Get)에 대한 설명으로 옳은 것은? 자주
  1. ①문서를 코드 형태로 편집하는 방식이다
  2. ②화면에 보이는 그대로 인쇄 결과물이 나오는 편집 방식이다
  3. ③문서를 텍스트 파일로만 저장하는 방식이다
  4. ④프린터에서 출력된 결과를 스캔하여 화면에 표시하는 방식이다
16다음 중 전자문서의 법적 효력에 대한 설명으로 옳지 않은 것은? 자주
  1. ①전자문서는 반드시 특정 파일 형식(PDF)으로만 저장해야 법적 효력이 인정된다
  2. ②전자서명이 포함된 전자문서는 서명 또는 기명날인한 문서로 인정된다
  3. ③전자문서는 작성자의 의사표시가 포함되어야 효력이 있다
  4. ④전자문서는 다른 법률에 특별한 규정이 없는 한 종이 문서와 동일한 효력을 갖는다
17다음 중 워드프로세서의 찾기(검색) 기능에 대한 설명으로 옳지 않은 것은? 자주
  1. ①특정 단어를 찾아 다른 단어로 바꾸는 '찾아 바꾸기' 기능을 제공한다
  2. ②대소문자를 구분하여 검색할 수 있다
  3. ③와일드카드(특수 기호)를 사용하여 패턴 검색이 가능하다
  4. ④찾기 기능은 문서의 본문만 검색하며 머리말·꼬리말은 검색할 수 없다
18다음 중 워드랩(Word Wrap, 자동 줄 바꿈)과 금칙 처리에 대한 설명으로 옳은 것은? 자주
  1. ①워드랩은 문단의 끝에서 사용자가 직접 줄 바꿈을 해야 하는 기능이다
  2. ②금칙 처리는 줄의 맨 앞이나 맨 뒤에 오면 안 되는 문자를 자동으로 처리하는 기능이다
  3. ③금칙 처리의 대상에는 마침표(.)와 쉼표(,)가 포함되지 않는다
  4. ④워드랩과 금칙 처리는 동일한 기능이다
19다음 중 워드프로세서의 스타일(Style) 기능에 대한 설명으로 옳지 않은 것은? 자주
  1. ①글꼴, 크기, 색상, 정렬 등 여러 서식을 하나로 묶어 이름을 붙인 것이다
  2. ②스타일을 수정하면 해당 스타일이 적용된 모든 텍스트에 변경이 반영된다
  3. ③문단 스타일과 글자 스타일을 구분하여 사용할 수 있다
  4. ④스타일은 현재 문서에서만 사용할 수 있으며 다른 문서로 복사할 수 없다
20다음 중 공문서의 날짜 및 금액 표기 방법으로 옳은 것은? 자주
  1. ①날짜는 '2024년 3월 5일'처럼 연·월·일을 온점(.)으로 구분하여 표기한다
  2. ②금액은 한글로 표기하고 괄호 안에 아라비아 숫자를 병기한다
  3. ③날짜는 숫자로 표기하되, 연·월·일의 글자는 생략하고 마침표(.)로 구분한다
  4. ④금액에서 천 단위 구분을 위해 콤마(,) 대신 공백을 사용한다
2PC 운영체제Q21 – Q40
21다음 중 Windows의 휴지통(Recycle Bin)에 대한 설명으로 옳지 않은 것은? 자주
  1. ①휴지통에서 파일을 복원하면 원래 위치로 되돌아간다
  2. ②휴지통의 크기는 드라이브별로 설정할 수 있다
  3. ③네트워크 드라이브에서 삭제한 파일도 휴지통에 보관된다
  4. ④Shift + Delete로 삭제하면 휴지통을 거치지 않고 바로 삭제된다
22다음 중 Windows의 에어로(Aero) 기능에 대한 설명으로 옳은 것은? 자주
  1. ①에어로 피크(Aero Peek)는 작업 표시줄의 미리보기를 통해 열린 창을 확인하는 기능이다
  2. ②에어로 스냅(Aero Snap)은 창을 투명하게 만드는 기능이다
  3. ③에어로 셰이크(Aero Shake)는 창의 크기를 자동으로 조절하는 기능이다
  4. ④에어로 기능은 그래픽 카드와 무관하게 모든 환경에서 작동한다
23다음 중 Windows의 작업 표시줄(Taskbar)에 대한 설명으로 옳지 않은 것은? 자주
  1. ①작업 표시줄에는 최대 10개의 프로그램만 고정할 수 있다
  2. ②알림 영역(시스템 트레이)에는 시계, 볼륨, 네트워크 아이콘 등이 표시된다
  3. ③작업 표시줄을 자동으로 숨기기 설정을 할 수 있다
  4. ④작업 표시줄의 위치를 화면의 상·하·좌·우로 변경할 수 있다
24다음 중 Windows의 단축키에 대한 설명으로 옳은 것은? 자주
  1. ①Ctrl + Z는 실행 취소(Undo), Ctrl + Y는 다시 실행(Redo)이다
  2. ②Alt + F4는 현재 창을 최소화하는 단축키이다
  3. ③Ctrl + A는 현재 선택한 항목을 복사하는 단축키이다
  4. ④Windows + E는 제어판을 여는 단축키이다
25다음 중 FAT32와 NTFS 파일 시스템에 대한 설명으로 옳지 않은 것은? 자주
  1. ①NTFS는 파일 및 폴더에 대한 접근 권한(보안) 설정이 가능하다
  2. ②FAT32는 최대 4GB 이상의 단일 파일을 저장할 수 없다
  3. ③NTFS는 파일 암호화와 압축 기능을 지원한다
  4. ④FAT32는 NTFS보다 보안성이 우수하여 서버용으로 주로 사용된다
26다음 중 Windows의 안전 모드(Safe Mode)에 대한 설명으로 옳은 것은? 자주
  1. ①안전 모드에서는 모든 드라이버와 프로그램이 정상적으로 로드된다
  2. ②안전 모드는 시스템에 문제가 있을 때 최소한의 드라이버와 서비스만으로 부팅하는 방식이다
  3. ③안전 모드에서 네트워크는 항상 사용할 수 있다
  4. ④안전 모드는 BIOS 설정 화면과 동일하다
27다음 중 Windows의 절전 모드와 최대 절전 모드에 대한 설명으로 옳지 않은 것은? 자주
  1. ①절전 모드에서는 전원이 완전히 차단되므로 정전 시에도 데이터가 보존된다
  2. ②최대 절전 모드는 현재 작업 상태를 하드디스크에 저장한다
  3. ③절전 모드는 최대 절전 모드보다 복귀 속도가 빠르다
  4. ④절전 모드는 현재 작업 상태를 RAM(메모리)에 저장한다
28다음 중 Windows의 시스템 복원(System Restore)에 대한 설명으로 옳은 것은? 자주
  1. ①시스템 복원을 실행하면 개인 파일(문서, 사진 등)도 이전 상태로 되돌아간다
  2. ②시스템 복원은 Windows 시스템 파일과 설정을 이전 시점으로 되돌리는 기능이다
  3. ③시스템 복원 지점은 사용자가 수동으로만 만들 수 있다
  4. ④시스템 복원을 실행하면 바이러스에 감염된 파일도 자동으로 치료된다
29다음 중 Windows의 레지스트리(Registry)에 대한 설명으로 옳지 않은 것은? 자주
  1. ①레지스트리는 하드웨어, 소프트웨어, 사용자 설정 등의 정보를 저장하는 데이터베이스이다
  2. ②레지스트리 편집기(regedit)를 통해 레지스트리를 직접 수정할 수 있다
  3. ③레지스트리를 잘못 수정하면 시스템이 불안정해지거나 부팅이 안 될 수 있다
  4. ④레지스트리는 텍스트 파일로 저장되어 메모장에서 직접 편집할 수 있다
30다음 중 UAC(User Account Control, 사용자 계정 컨트롤)에 대한 설명으로 옳은 것은? 자주
  1. ①UAC는 바이러스를 자동으로 제거하는 보안 프로그램이다
  2. ②UAC는 시스템 설정 변경이나 프로그램 설치 시 사용자에게 확인을 요청하는 보안 기능이다
  3. ③UAC를 비활성화하면 컴퓨터 성능이 향상된다
  4. ④UAC는 관리자 계정에서는 작동하지 않는다
31다음 중 디스크 조각 모음(Disk Defragmentation)에 대한 설명으로 옳지 않은 것은? 자주
  1. ①파일이 디스크 여러 곳에 흩어져 저장된 것을 연속된 공간으로 모아주는 작업이다
  2. ②디스크 조각 모음을 수행하면 파일 읽기 속도가 향상될 수 있다
  3. ③SSD(Solid State Drive)에서도 디스크 조각 모음을 반드시 실행해야 성능이 향상된다
  4. ④조각 모음은 예약을 통해 자동으로 실행되도록 설정할 수 있다
32다음 중 Windows의 메모장(Notepad)에 대한 설명으로 옳은 것은? 자주
  1. ①메모장은 서식(글꼴 크기, 색상 등)을 지정하여 저장할 수 있다
  2. ②메모장은 표와 이미지를 삽입할 수 있다
  3. ③메모장은 순수 텍스트(Plain Text)만 편집할 수 있는 프로그램이다
  4. ④메모장으로 저장한 파일의 기본 확장자는 .doc이다

  1. ①폴더를 공유하면 네트워크에 연결된 다른 컴퓨터에서 해당 폴더에 접근할 수 있다
  2. ②공유 폴더에 대해 읽기 전용, 읽기/쓰기 등 접근 권한을 설정할 수 있다
  3. ③공유 이름 끝에 $를 붙이면 숨김 공유가 되어 네트워크 탐색에 표시되지 않는다
  4. ④파일을 공유하면 해당 파일이 자동으로 클라우드에 업로드된다
34다음 중 DHCP(Dynamic Host Configuration Protocol)에 대한 설명으로 옳은 것은? 자주
  1. ①DHCP는 도메인 이름을 IP 주소로 변환하는 프로토콜이다
  2. ②DHCP는 네트워크에 연결된 컴퓨터에 자동으로 IP 주소를 할당하는 프로토콜이다
  3. ③DHCP를 사용하면 모든 컴퓨터가 동일한 IP 주소를 받는다
  4. ④DHCP는 파일을 전송하기 위한 프로토콜이다

  1. ①외부 네트워크로부터의 무단 접근을 차단하는 보안 기능이다

  4. ④방화벽을 켜면 바이러스와 악성코드가 자동으로 치료된다

  1. ①표준 사용자 계정은 다른 사용자 계정을 생성하거나 삭제할 수 있다
  2. ②관리자 계정은 시스템 설정 변경, 프로그램 설치, 사용자 관리 등 모든 작업이 가능하다

  3. ③운영체제가 먼저 로드된 후에 BIOS가 하드웨어를 검사한다
  4. ④BIOS는 부팅 장치(하드디스크, USB 등)의 순서를 설정할 수 있다

  4. ④CU는 데이터를 직접 연산하며, ALU는 명령어를 해석하는 역할을 한다

44다음 중 RAM과 ROM에 대한 설명으로 옳지 않은 것은? 자주
  1. ①ROM은 사용자가 자유롭게 데이터를 읽고 쓸 수 있는 메모리이다
  2. ②ROM은 전원이 꺼져도 데이터가 유지되는 비휘발성 메모리이다
  3. ③RAM의 용량이 클수록 여러 프로그램을 동시에 실행하기에 유리하다
  4. ④RAM은 전원이 꺼지면 저장된 데이터가 사라지는 휘발성 메모리이다
45다음 중 데이터 단위의 크기가 작은 것부터 큰 순서로 올바르게 나열된 것은? 자주

  2. ②바이트(Byte) → 비트(Bit) → 킬로바이트(KB) → 기가바이트(GB) → 메가바이트(MB) → 테라바이트(TB)
  3. ③비트(Bit) → 바이트(Byte) → 메가바이트(MB) → 킬로바이트(KB) → 기가바이트(GB) → 테라바이트(TB)
  4. ④비트(Bit) → 킬로바이트(KB) → 바이트(Byte) → 메가바이트(MB) → 기가바이트(GB) → 테라바이트(TB)

  1. ①프리웨어는 소스 코드가 반드시 공개되므로 오픈소스와 동일하다
  2. ②프리웨어(Freeware)는 무료로 사용할 수 있지만 소스 코드가 공개되지 않을 수 있다
  3. ③오픈소스(Open Source) 소프트웨어는 소스 코드가 공개되어 자유롭게 수정·배포할 수 있다
  4. ④셰어웨어(Shareware)는 일정 기간 무료 사용 후 구매해야 하는 소프트웨어이다
47다음 중 이미지 파일 형식에 대한 설명으로 옳은 것은? 자주
  1. ①JPEG는 비손실 압축을 사용하므로 원본 화질이 완벽하게 보존된다
  2. ②GIF는 최대 1,677만 색상을 표현할 수 있어 사진에 적합하다
  3. ③PNG는 투명 배경을 지원하며 비손실 압축을 사용한다
  4. ④BMP는 압축률이 높아 웹에서 가장 많이 사용되는 형식이다
48다음 중 네트워크 장비에 대한 설명으로 옳지 않은 것은? 자주
  1. ①게이트웨이(Gateway)는 같은 프로토콜을 사용하는 네트워크 간에만 연결이 가능하다
  2. ②스위치(Switch)는 MAC 주소를 기반으로 목적지 포트에만 데이터를 전송한다
  3. ③라우터(Router)는 서로 다른 네트워크를 연결하고 최적 경로를 찾아 데이터를 전달한다
  4. ④허브(Hub)는 연결된 모든 포트에 데이터를 전송하는 장비이다

50다음 중 오류 검출(Error Detection) 방법에 대한 설명으로 옳지 않은 것은? 자주
  1. ①패리티 비트는 2비트 이상의 오류도 검출할 수 있다
  2. ②해밍 코드(Hamming Code)는 오류를 검출하고 수정까지 가능한 방법이다
  3. ③CRC(순환 중복 검사)는 다항식을 이용하여 오류를 검출하는 방법이다
  4. ④패리티 비트(Parity Bit)는 데이터에 1비트를 추가하여 오류를 검출하는 방법이다
51다음 중 암호화(Encryption) 방식에 대한 설명으로 옳은 것은? 자주
  1. ①대칭키 암호화는 암호화와 복호화에 서로 다른 키를 사용한다
  2. ②공개키(비대칭키) 암호화는 하나의 키로 암호화와 복호화를 모두 수행한다
  3. ③대칭키 암호화는 속도가 빠르지만 키 분배 문제가 있다
  4. ④공개키 암호화에서 공개키와 개인키는 동일한 키이다
52다음 중 IPv4와 IPv6에 대한 설명으로 옳지 않은 것은? 자주
  1. ①IPv4는 32비트 주소 체계로 약 43억 개의 주소를 표현할 수 있다
  2. ②IPv6는 128비트 주소 체계로 사실상 무한에 가까운 주소를 표현할 수 있다
  3. ③IPv6는 보안 기능(IPSec)이 기본 내장되어 있다
  4. ④IPv4는 16진수로 표기하고 IPv6는 10진수로 표기한다
53다음 중 DNS(Domain Name System)에 대한 설명으로 옳은 것은? 자주
  1. ①DNS는 IP 주소를 MAC 주소로 변환하는 프로토콜이다
  2. ②DNS는 파일을 전송하기 위한 프로토콜이다
  3. ③DNS는 도메인 이름(예: www.example.com)을 IP 주소로 변환하는 시스템이다
  4. ④DNS는 이메일을 전송하기 위한 프로토콜이다
54다음 중 악성코드(Malware)에 대한 설명으로 옳지 않은 것은? 자주
  1. ①웜(Worm)은 스스로 복제하여 네트워크를 통해 전파되는 악성코드이다
  2. ②바이러스(Virus)는 숙주 프로그램 없이 독립적으로 실행되는 악성코드이다
  3. ③랜섬웨어(Ransomware)는 파일을 암호화한 후 복호화 대가로 금전을 요구한다
  4. ④트로이 목마(Trojan Horse)는 정상 프로그램으로 위장하여 설치되는 악성코드이다
55다음 중 TCP와 UDP에 대한 설명으로 옳은 것은? 자주
  1. ①UDP는 연결 지향형 프로토콜로 신뢰성 있는 데이터 전송을 보장한다
  2. ②TCP는 비연결형 프로토콜로 속도가 빠르지만 데이터 손실이 발생할 수 있다
  3. ③TCP와 UDP는 동일한 전송 방식을 사용한다
  4. ④TCP는 연결 지향형으로 3-way handshake를 통해 연결을 설정한다
56다음 중 클라우드 컴퓨팅(Cloud Computing)의 서비스 유형에 대한 설명으로 옳지 않은 것은? 자주
  1. ①IaaS(Infrastructure as a Service)는 서버, 스토리지 등 인프라를 제공하는 서비스이다
  2. ②SaaS는 사용자가 서버를 직접 관리하고 운영해야 하는 서비스이다
  3. ③SaaS(Software as a Service)는 완성된 소프트웨어를 인터넷으로 제공하는 서비스이다
  4. ④PaaS(Platform as a Service)는 개발 환경(플랫폼)을 제공하는 서비스이다
57다음 중 빅데이터(Big Data)의 3V 특성에 해당하지 않는 것은? 자주
  1. ①Volume(규모) — 데이터의 양이 매우 크다
  2. ②Velocity(속도) — 데이터가 빠르게 생성되고 처리된다
  3. ③Variety(다양성) — 정형, 비정형 등 다양한 형태의 데이터이다
  4. ④Visibility(가시성) — 데이터가 항상 눈에 보이는 형태로 존재한다
58다음 중 저작권에 대한 설명으로 옳지 않은 것은? 자주
  1. ①저작권은 저작물을 창작한 시점에 자동으로 발생한다
  2. ②저작인격권은 공표권, 성명표시권, 동일성유지권으로 구성된다
  3. ③저작재산권은 타인에게 양도하거나 상속할 수 있다
  4. ④저작권을 보호받으려면 반드시 저작권청에 등록해야 한다
59다음 중 데이터 전송 방식에 대한 설명으로 옳은 것은? 자주
  1. ①단방향(Simplex) 통신은 양쪽에서 동시에 데이터를 주고받을 수 있다
  2. ②반이중(Half-Duplex) 통신은 한 번에 한 방향으로만 데이터를 전송할 수 있다
  3. ③전이중(Full-Duplex) 통신은 한 방향으로만 데이터를 전송할 수 있다
  4. ④반이중 통신은 TV 방송과 같은 방식이다
60다음 중 가상 메모리(Virtual Memory)에 대한 설명으로 옳지 않은 것은? 자주
  1. ①하드디스크의 일부를 RAM처럼 사용하여 메모리 용량을 확장하는 기술이다
  2. ②가상 메모리는 RAM보다 속도가 빠르므로 RAM을 대체할 수 있다
  3. ③가상 메모리에서 RAM과 하드디스크 간 데이터 교환을 스왑(Swap)이라 한다
  4. ④가상 메모리를 사용하면 실제 RAM 용량보다 큰 프로그램도 실행할 수 있다
