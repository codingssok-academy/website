1다음 중 전결과 대결의 비교로 옳지 않은 것은? 매회
  1. ①전결은 상사가 부재 시 미리 위임받은 사항을 결재하는 것이다
  2. ②대결은 상사가 출장 등으로 부재 시 차상위자가 대신 결재하는 것이다
  3. ③전결은 결재 후 상사에게 보고할 의무가 없다
  4. ④대결은 상사가 복귀하면 후결을 받아야 한다
2다음 중 관인과 직인의 비교로 옳은 것은? 자주
  1. ①관인은 개인 직위를 나타내는 도장이다
  2. ②직인은 기관의 명의로 발신하는 문서에 사용한다
  3. ③관인은 기관장의 직위를 나타내는 인장이다
  4. ④직인은 관인에 포함되지 않는 별도의 인장이다
3다음 중 공문서와 사문서의 비교로 옳지 않은 것은? 매회
  1. ①공문서는 공공기관에서 작성한 문서이다
  2. ②사문서는 개인이나 민간단체가 작성한 문서이다
  3. ③공문서는 별도 증명 없이도 진정성이 추정된다
  4. ④사문서도 공문서와 동일한 법적 증명력을 갖는다
4다음 중 공문서의 연결과 포함의 비교로 옳은 것은? 매회
  1. ①연결은 다른 문서의 내용을 본문에 직접 삽입하는 것이다
  2. ②포함은 이전에 보낸 문서를 참고하도록 안내하는 것이다
  3. ③연결은 이미 시행한 문서를 인용할 때 사용한다
  4. ④포함과 연결 모두 별첨과 동일한 의미이다
5다음 중 각주(脚註)와 미주(尾註)의 비교로 옳지 않은 것은? 매회
  1. ①각주는 해당 페이지의 하단에 표시된다
  2. ②미주는 문서의 맨 끝에 모아서 표시된다
  3. ③각주와 미주 모두 본문의 내용을 보충 설명하는 기능이다
  4. ④각주는 문서 끝에, 미주는 페이지 하단에 표시된다
6다음 중 색인(Index)과 목차(Table of Contents)의 비교로 옳은 것은? 자주
  1. ①색인은 문서의 처음에, 목차는 문서의 끝에 배치된다
  2. ②목차는 특정 용어를 가나다순으로 정리한 것이다
  3. ③색인은 특정 용어나 키워드를 가나다순(알파벳순)으로 정리하여 해당 페이지를 표시한 것이다
  4. ④색인과 목차는 동일한 기능이다
7다음 중 머리글(Header)과 꼬리글(Footer)의 비교로 옳지 않은 것은? 자주
  1. ①머리글은 용지 상단 여백에 반복 표시된다
  2. ②꼬리글은 용지 하단 여백에 반복 표시된다
  3. ③머리글과 꼬리글에는 쪽 번호, 날짜 등을 삽입할 수 있다
  4. ④머리글은 첫 페이지에만 표시되고 꼬리글은 모든 페이지에 표시된다
8다음 중 자간과 장평의 비교로 옳은 것은? 매회
  1. ①자간은 글자 자체의 가로 폭을 조절한다
  2. ②장평은 글자와 글자 사이의 간격을 조절한다
  3. ③자간을 넓히면 글자 사이 간격이 벌어진다
  4. ④장평을 넓히면 글자 사이 간격이 벌어진다
9다음 중 행간(行間)과 자간(字間)의 비교로 옳지 않은 것은? 자주
  1. ①행간은 줄과 줄 사이의 간격이다
  2. ②자간은 글자와 글자 사이의 간격이다
  3. ③행간을 넓히면 세로 방향 간격이 넓어진다
  4. ④자간을 넓히면 세로 방향 간격이 넓어진다
10다음 중 문단 모양과 글자 모양의 비교로 옳지 않은 것은? 매회
  1. ①문단 모양에서는 정렬 방식을 설정할 수 있다
  2. ②글자 모양에서는 글꼴과 크기를 설정할 수 있다
  3. ③문단 모양에서는 들여쓰기와 내어쓰기를 설정할 수 있다
  4. ④글자 모양에서 행간(줄 간격)을 설정한다
11다음 중 기안문과 시행문의 비교로 옳은 것은? 매회
  1. ①기안문은 외부로 발송하는 문서이다
  2. ②시행문은 내부 결재를 위한 문서이다
  3. ③기안문은 내부 결재용이고 시행문은 대외 발송용이다
  4. ④기안문과 시행문은 동일한 문서이다
12다음 중 공고문과 통지문의 비교로 옳지 않은 것은? 자주
  1. ①공고문은 불특정 다수에게 알리는 문서이다
  2. ②통지문은 특정 대상에게 알리는 문서이다
  3. ③공고문은 게시판, 관보 등에 게시한다
  4. ④통지문은 반드시 관보에 게재해야 한다
13다음 중 감열식 프린터와 잉크젯 프린터의 비교로 옳은 것은? 자주
  1. ①감열식은 잉크를 분사하여 인쇄한다
  2. ②잉크젯은 열에 반응하는 특수 용지에 인쇄한다
  3. ③감열식은 열을 가해 특수 용지에 인쇄하고, 잉크젯은 잉크를 분사하여 인쇄한다
  4. ④두 방식 모두 레이저를 사용한다
14다음 중 일반문서와 비밀문서의 비교로 옳지 않은 것은? 자주
  1. ①비밀문서는 비밀 등급에 따라 I급, II급, III급으로 분류한다
  2. ②일반문서는 누구나 열람할 수 있다
  3. ③비밀문서는 비밀취급 인가를 받은 사람만 열람할 수 있다
  4. ④비밀문서의 원본은 발간등록대장에 등록하지 않는다
15다음 중 워드프로세서에서 용지 방향 세로(Portrait)와 가로(Landscape)의 비교로 옳은 것은? 자주
  1. ①세로 방향은 용지의 긴 변이 가로로 놓인다
  2. ②가로 방향은 용지의 긴 변이 세로로 놓인다
  3. ③가로 방향은 용지의 긴 변이 가로로 놓여 넓은 표나 그림 삽입에 유리하다
  4. ④세로와 가로 방향은 인쇄 결과에 차이가 없다
16다음 중 바닥글(Footer)과 각주(Footnote)의 비교로 옳지 않은 것은? 자주
  1. ①바닥글은 모든 페이지 하단에 반복 표시된다
  2. ②각주는 해당 내용이 있는 페이지 하단에만 표시된다
  3. ③바닥글에는 페이지 번호, 문서 제목 등을 넣는다
  4. ④바닥글과 각주는 동일한 기능이므로 혼용 가능하다
17다음 중 복사(Copy)와 잘라내기(Cut)의 비교로 옳지 않은 것은? 매회
  1. ①복사(Ctrl+C)는 원본을 유지한 채 클립보드에 저장한다
  2. ②잘라내기(Ctrl+X)는 원본을 삭제하고 클립보드에 저장한다
  3. ③복사와 잘라내기 모두 붙여넣기(Ctrl+V)로 삽입한다
  4. ④복사(Ctrl+C)는 원본을 삭제하고 클립보드에 저장한다
18다음 중 블록 설정과 전체 선택(Ctrl+A)의 비교로 옳은 것은? 자주
  1. ①전체 선택은 문서의 일부분만 선택한다
  2. ②블록 설정은 항상 문서 전체를 선택한다
  3. ③블록 설정은 원하는 범위를 지정하고, 전체 선택은 문서 전체를 한 번에 선택한다
  4. ④블록 설정과 전체 선택은 동일한 기능이다
19다음 중 저장(Ctrl+S)과 다른 이름으로 저장의 비교로 옳지 않은 것은? 매회
  1. ①저장은 현재 파일명으로 덮어쓰기 저장한다
  2. ②다른 이름으로 저장은 새로운 파일명이나 위치를 지정하여 저장한다
  3. ③처음 저장할 때는 저장(Ctrl+S)을 눌러도 다른 이름으로 저장 대화상자가 나타난다
  4. ④다른 이름으로 저장하면 원본 파일은 자동으로 삭제된다
20다음 중 찾기(Ctrl+F)와 찾아 바꾸기(Ctrl+H)의 비교로 옳은 것은? 매회
  1. ①찾기는 특정 텍스트를 검색하고 다른 텍스트로 대체할 수 있다
  2. ②찾아 바꾸기는 검색만 가능하고 대체는 불가능하다
  3. ③찾기는 검색만 가능하고, 찾아 바꾸기는 검색과 대체를 모두 수행할 수 있다
  4. ④찾기와 찾아 바꾸기의 단축키는 동일하다

21다음 중 RAM과 ROM의 비교로 옳지 않은 것은? 매회
  1. ①RAM은 전원이 꺼지면 데이터가 사라지는 휘발성 메모리이다
  2. ②ROM은 전원이 꺼져도 데이터가 유지되는 비휘발성 메모리이다
  3. ③RAM은 읽기와 쓰기가 모두 가능하다
  4. ④ROM은 읽기와 쓰기가 모두 자유롭다
22다음 중 SRAM과 DRAM의 비교로 옳은 것은? 매회
  1. ①DRAM은 재충전(Refresh)이 필요 없다
  2. ②SRAM은 재충전(Refresh)이 필요하다
  3. ③SRAM은 속도가 빠르고 캐시 메모리에 사용되며, DRAM은 주기적 재충전이 필요하고 주기억장치에 사용된다
  4. ④SRAM은 DRAM보다 가격이 저렴하다
23다음 중 FAT과 NTFS 파일 시스템의 비교로 옳지 않은 것은? 매회
  1. ①NTFS는 파일/폴더 단위의 보안 권한 설정이 가능하다
  2. ②FAT은 대용량 디스크 지원에 한계가 있다
  3. ③NTFS는 파일 암호화와 압축을 지원한다
  4. ④FAT은 NTFS보다 보안 기능이 우수하다
24다음 중 절전 모드(Sleep)와 최대 절전 모드(Hibernate)의 비교로 옳은 것은? 매회
  1. ①절전 모드는 작업 상태를 하드디스크에 저장한다
  2. ②최대 절전 모드는 작업 상태를 RAM에 유지한다
  3. ③절전 모드는 RAM에 상태를 유지하고, 최대 절전 모드는 하드디스크에 저장한다
  4. ④두 모드 모두 전원이 완전히 차단된다
25다음 중 컴퓨터 바이러스와 웜(Worm)의 비교로 옳지 않은 것은? 매회
  1. ①바이러스는 다른 프로그램에 기생하여 감염된다
  2. ②웜은 독자적으로 실행되며 네트워크를 통해 전파된다
  3. ③바이러스는 숙주 프로그램 없이도 독자 실행이 가능하다
  4. ④웜은 자가 복제하여 네트워크 성능을 저하시킨다
26다음 중 TCP와 UDP의 비교로 옳은 것은? 매회
  1. ①UDP는 연결 지향형 프로토콜이다
  2. ②TCP는 비연결형 프로토콜이다
  3. ③TCP는 신뢰성 있는 연결 지향형이고, UDP는 빠르지만 비연결형이다
  4. ④TCP와 UDP 모두 데이터 순서를 보장한다
27다음 중 대칭키 암호화와 공개키(비대칭키) 암호화의 비교로 옳지 않은 것은? 매회
  1. ①대칭키는 암호화와 복호화에 같은 키를 사용한다
  2. ②공개키는 암호화와 복호화에 서로 다른 키를 사용한다
  3. ③대칭키 방식이 공개키 방식보다 속도가 빠르다
  4. ④대칭키 방식은 키 분배 문제가 없어 더 안전하다
28다음 중 IPv4와 IPv6의 비교로 옳은 것은? 매회
  1. ①IPv4는 128비트 주소 체계를 사용한다
  2. ②IPv6는 32비트 주소 체계를 사용한다
  3. ③IPv4는 32비트, IPv6는 128비트 주소 체계를 사용한다
  4. ④IPv4와 IPv6의 주소 길이는 동일하다
29다음 중 피싱(Phishing)과 파밍(Pharming)의 비교로 옳지 않은 것은? 매회
  1. ①피싱은 가짜 이메일이나 사이트로 개인정보를 유출시킨다
  2. ②파밍은 DNS를 변조하여 정상 주소를 입력해도 가짜 사이트로 이동시킨다
  3. ③피싱은 사용자의 부주의를 이용하고, 파밍은 시스템을 공격한다
  4. ④파밍은 사용자가 주의하면 완전히 예방할 수 있다
30다음 중 컴파일러(Compiler)와 인터프리터(Interpreter)의 비교로 옳은 것은? 매회
  1. ①컴파일러는 소스 코드를 한 줄씩 번역하여 실행한다
  2. ②인터프리터는 소스 코드 전체를 한 번에 번역한 후 실행한다
  3. ③컴파일러는 전체를 한 번에 번역하고, 인터프리터는 한 줄씩 번역하여 실행한다
  4. ④컴파일러와 인터프리터 모두 목적 프로그램을 생성한다
31다음 중 POP3와 IMAP의 비교로 옳지 않은 것은? 자주
  1. ①POP3는 이메일을 다운로드한 후 서버에서 삭제하는 것이 기본이다
  2. ②IMAP은 이메일을 서버에 보관하면서 열람한다
  3. ③IMAP은 여러 기기에서 동일한 메일함을 동기화할 수 있다
  4. ④POP3는 여러 기기 간 메일 동기화에 유리하다
32다음 중 페이징(Paging)과 세그먼테이션(Segmentation)의 비교로 옳은 것은? 자주
  1. ①페이징은 가변 크기로 메모리를 분할한다
  2. ②세그먼테이션은 고정 크기로 메모리를 분할한다
  3. ③페이징은 고정 크기, 세그먼테이션은 가변 크기로 메모리를 분할한다
  4. ④페이징과 세그먼테이션 모두 내부 단편화가 발생한다
33다음 중 직렬 포트(Serial)와 병렬 포트(Parallel)의 비교로 옳지 않은 것은? 자주
  1. ①직렬 포트는 데이터를 한 비트씩 순서대로 전송한다
  2. ②병렬 포트는 여러 비트를 동시에 전송한다
  3. ③직렬 포트는 장거리 전송에 유리하다
  4. ④병렬 포트는 직렬 포트보다 항상 전송 속도가 빠르다
34다음 중 SSD와 HDD의 비교로 옳은 것은? 매회
  1. ①HDD는 반도체 기반으로 기계적 부품이 없다
  2. ②SSD는 자기 디스크를 회전시켜 데이터를 저장한다
  3. ③SSD는 반도체(플래시 메모리) 기반으로 HDD보다 속도가 빠르고 소음이 없다
  4. ④HDD가 SSD보다 내구성과 속도가 모두 우수하다
35다음 중 스풀링(Spooling)과 버퍼링(Buffering)의 비교로 옳지 않은 것은? 자주
  1. ①스풀링은 디스크를 중간 버퍼로 사용한다
  2. ②버퍼링은 주기억장치(RAM)를 중간 버퍼로 사용한다
  3. ③스풀링의 대표적인 예는 인쇄 대기열이다
  4. ④스풀링과 버퍼링 모두 주기억장치만 사용한다
36다음 중 유니코드(Unicode)와 ASCII의 비교로 옳은 것은? 자주
  1. ①ASCII는 전 세계 모든 문자를 표현할 수 있다
  2. ②유니코드는 영문만 표현 가능하다
  3. ③ASCII는 7비트(128자)로 영문 중심이고, 유니코드는 다국어를 지원한다
  4. ④유니코드는 ASCII보다 적은 문자를 표현한다
37다음 중 스택(Stack)과 큐(Queue)의 비교로 옳지 않은 것은? 자주
  1. ①스택은 후입선출(LIFO) 방식이다
  2. ②큐는 선입선출(FIFO) 방식이다
  3. ③스택의 예로는 프린터 출력 대기가 있다
  4. ④큐의 예로는 은행 번호표 대기가 있다
38다음 중 클라우드 컴퓨팅과 온프레미스(On-Premise)의 비교로 옳지 않은 것은? 자주
  1. ①클라우드는 인터넷을 통해 IT 자원을 빌려 쓰는 방식이다
  2. ②온프레미스는 자체 서버를 구축하여 운영하는 방식이다
  3. ③클라우드는 초기 비용이 적고 확장이 유연하다
  4. ④클라우드는 인터넷 없이도 항상 사용 가능하다
39다음 중 LAN과 WAN의 비교로 옳은 것은? 매회
  1. ①LAN은 광범위한 지역을 연결하는 네트워크이다
  2. ②WAN은 건물 내부의 소규모 네트워크이다
  3. ③LAN은 근거리 통신망이고 WAN은 광역 통신망이다
  4. ④LAN이 WAN보다 전송 거리가 더 길다
40다음 중 방화벽(Firewall)과 백신(Antivirus)의 비교로 옳지 않은 것은? 자주
  1. ①방화벽은 네트워크 트래픽을 감시하고 차단한다
  2. ②백신은 악성코드를 탐지하고 제거한다
  3. ③방화벽은 외부 침입을 차단하는 1차 방어선이다
  4. ④방화벽이 있으면 백신은 설치할 필요가 없다

41다음 중 비트맵(Bitmap) 방식과 벡터(Vector) 방식의 비교로 옳지 않은 것은? 매회
  1. ①비트맵은 픽셀(점)로 이미지를 표현한다
  2. ②벡터는 수학적 계산(점, 선, 곡선)으로 이미지를 표현한다
  3. ③비트맵은 확대하면 이미지가 깨진다(계단 현상)
  4. ④벡터는 확대하면 이미지가 깨진다(계단 현상)
42다음 중 JPG(JPEG)와 PNG 이미지 형식의 비교로 옳은 것은? 매회
  1. ①JPG는 투명 배경을 지원한다
  2. ②PNG는 손실 압축 방식을 사용한다
  3. ③JPG는 손실 압축이고 PNG는 비손실 압축이며 투명 배경을 지원한다
  4. ④JPG와 PNG 모두 애니메이션을 지원한다
43다음 중 GIF와 PNG의 비교로 옳지 않은 것은? 자주
  1. ①GIF는 최대 256색을 지원한다
  2. ②PNG는 트루컬러(약 1,677만 색)를 지원한다
  3. ③GIF는 애니메이션(움짤)을 지원한다
  4. ④PNG도 GIF처럼 애니메이션을 기본 지원한다
44다음 중 디더링(Dithering)과 안티앨리어싱(Anti-aliasing)의 비교로 옳은 것은? 자주
  1. ①디더링은 곡선의 계단 현상을 부드럽게 처리하는 기법이다
  2. ②안티앨리어싱은 적은 색으로 많은 색을 표현하는 기법이다
  3. ③디더링은 제한된 색상으로 중간색을 표현하고, 안티앨리어싱은 계단 현상을 부드럽게 한다
  4. ④두 기법 모두 동일한 목적과 원리로 작동한다
45다음 중 MPEG와 AVI의 비교로 옳지 않은 것은? 자주
  1. ①MPEG는 동영상 압축 표준이다
  2. ②AVI는 Microsoft에서 개발한 동영상 파일 형식이다
  3. ③MPEG는 높은 압축률로 파일 크기가 작다
  4. ④AVI는 MPEG보다 항상 압축률이 높다
46다음 중 MP3와 WAV의 비교로 옳은 것은? 매회
  1. ①MP3는 비압축 형식이라 파일 크기가 크다
  2. ②WAV는 손실 압축 형식이라 파일 크기가 작다
  3. ③MP3는 손실 압축으로 크기가 작고, WAV는 비압축으로 원음에 가깝다
  4. ④MP3와 WAV 모두 손실 압축 방식이다
47다음 중 MIDI와 WAV의 비교로 옳지 않은 것은? 자주
  1. ①MIDI는 음의 높낮이, 길이 등 연주 정보를 저장한다
  2. ②WAV는 실제 소리의 파형을 디지털로 저장한다
  3. ③MIDI 파일은 WAV보다 용량이 매우 작다
  4. ④MIDI는 사람의 목소리를 그대로 녹음할 수 있다
48다음 중 HTML과 XML의 비교로 옳은 것은? 자주
  1. ①HTML은 데이터 저장과 전송을 위한 언어이다
  2. ②XML은 웹 페이지의 화면 표시를 위한 언어이다
  3. ③HTML은 웹 페이지 표시용이고, XML은 데이터 저장·전송용이다
  4. ④HTML과 XML은 동일한 목적의 언어이다
49다음 중 HTTP와 HTTPS의 비교로 옳지 않은 것은? 매회
  1. ①HTTPS는 SSL/TLS로 데이터를 암호화하여 전송한다
  2. ②HTTP는 데이터를 평문(암호화 없이)으로 전송한다
  3. ③HTTPS는 보안이 강화된 HTTP이다
  4. ④HTTP와 HTTPS는 보안 수준이 동일하다
50다음 중 FTP와 SFTP의 비교로 옳은 것은? 자주
  1. ①FTP는 암호화된 파일 전송 프로토콜이다
  2. ②SFTP는 암호화 없이 파일을 전송한다
  3. ③FTP는 암호화 없이, SFTP는 SSH 기반 암호화로 파일을 전송한다
  4. ④FTP와 SFTP는 동일한 보안 수준이다
51다음 중 트루타입(TrueType)과 오픈타입(OpenType) 글꼴의 비교로 옳지 않은 것은? 자주
  1. ①트루타입은 Apple과 Microsoft가 공동 개발했다
  2. ②오픈타입은 Microsoft와 Adobe가 공동 개발했다
  3. ③오픈타입은 트루타입과 포스트스크립트를 모두 지원한다
  4. ④트루타입이 오픈타입보다 더 많은 글리프(문자)를 지원한다
52다음 중 아날로그 신호의 디지털 변환 과정에서 표본화(Sampling)와 양자화(Quantization)의 비교로 옳은 것은? 자주
  1. ①표본화는 신호의 크기를 이산적 값으로 변환하는 과정이다
  2. ②양자화는 일정 시간 간격으로 신호를 추출하는 과정이다
  3. ③표본화는 시간 축에서 신호를 추출하고, 양자화는 진폭을 이산 값으로 변환한다
  4. ④표본화와 양자화는 동일한 과정이다
53다음 중 인트라넷(Intranet)과 엑스트라넷(Extranet)의 비교로 옳지 않은 것은? 자주
  1. ①인트라넷은 조직 내부에서만 사용하는 네트워크이다
  2. ②엑스트라넷은 인트라넷을 외부 협력업체까지 확장한 것이다
  3. ③인트라넷과 엑스트라넷 모두 인터넷 기술을 기반으로 한다
  4. ④엑스트라넷은 누구나 접근할 수 있는 공개 네트워크이다
54다음 중 OCR과 OMR의 비교로 옳은 것은? 매회
  1. ①OCR은 마크(표시)를 인식하는 장치이다
  2. ②OMR은 인쇄된 문자를 인식하는 장치이다
  3. ③OCR은 인쇄 문자를 인식하고, OMR은 마크(표시)를 인식한다
  4. ④OCR과 OMR은 동일한 기능이다
55다음 중 SMTP와 POP3의 비교로 옳지 않은 것은? 매회
  1. ①SMTP는 이메일을 보내는(발신) 프로토콜이다
  2. ②POP3는 이메일을 받는(수신) 프로토콜이다
  3. ③SMTP의 포트 번호는 25이다
  4. ④SMTP와 POP3 모두 이메일 수신용 프로토콜이다
56다음 중 도메인(Domain)과 IP 주소의 비교로 옳은 것은? 매회
  1. ①도메인은 숫자로 구성된 컴퓨터 주소이다
  2. ②IP 주소는 문자로 된 주소로 사람이 기억하기 쉽다
  3. ③도메인은 문자 형태의 주소이고, IP 주소는 숫자 형태의 주소이며, DNS가 이를 변환한다
  4. ④도메인과 IP 주소는 동일한 형식이다
57다음 중 절대경로와 상대경로의 비교로 옳지 않은 것은? 자주
  1. ①절대경로는 최상위(루트) 디렉토리부터 전체 경로를 표시한다
  2. ②상대경로는 현재 위치를 기준으로 경로를 표시한다
  3. ③절대경로 예시: C:\Users\Documents\file.txt
  4. ④상대경로는 항상 드라이브 문자(C:\)로 시작한다
58다음 중 하이퍼링크와 북마크(책갈피)의 비교로 옳은 것은? 자주
  1. ①하이퍼링크는 문서 내 특정 위치를 표시하는 기능이다
  2. ②북마크는 다른 문서나 웹 페이지로 이동하는 기능이다
  3. ③하이퍼링크는 클릭 시 다른 위치로 이동하고, 북마크는 문서 내 특정 위치를 표시(지정)하는 기능이다
  4. ④하이퍼링크와 북마크는 동일한 기능이다
59다음 중 매크로(Macro)와 스타일(Style)의 비교로 옳지 않은 것은? 자주
  1. ①매크로는 반복 작업을 자동화하기 위해 일련의 명령을 기록하는 기능이다
  2. ②스타일은 글꼴, 크기, 색상 등 서식을 미리 정의하여 일괄 적용하는 기능이다
  3. ③매크로는 서식뿐 아니라 다양한 작업(찾기, 바꾸기 등)을 자동화할 수 있다
  4. ④스타일은 매크로와 동일하게 명령어를 기록하여 실행하는 기능이다
60다음 중 상용구와 자동 고침의 비교로 옳은 것은? 자주
  1. ①상용구는 맞춤법 오류를 자동으로 수정하는 기능이다
  2. ②자동 고침은 자주 사용하는 긴 문장을 저장하는 기능이다
  3. ③상용구는 자주 사용하는 문구를 등록하여 빠르게 삽입하고, 자동 고침은 입력 오류를 자동으로 수정한다
  4. ④상용구와 자동 고침은 동일한 기능이다
