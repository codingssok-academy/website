11과목: 워드프로세싱 용어 및 기능Q1 – Q20
1다음 중 WYSIWYG의 의미로 올바른 것은? 매회
  1. ①화면에 표시되는 내용 그대로 인쇄 결과에 반영되는 방식이다
  2. ②문서를 암호화하여 보안을 강화하는 기능이다
  3. ③문서의 글꼴을 자동으로 변환해 주는 기능이다
  4. ④원격지에서 문서를 공동 편집하는 기능이다
2다음 중 OLE(Object Linking and Embedding)에 대한 설명으로 옳은 것은? 매회
  1. ①다른 응용 프로그램에서 작성한 개체를 연결하거나 삽입하는 기술이다
  2. ②문서 파일의 크기를 압축하는 기술이다
  3. ③네트워크를 통해 문서를 전송하는 프로토콜이다
  4. ④프린터 드라이버를 자동으로 설치하는 기능이다
3다음 중 커닝(Kerning)의 의미로 올바른 것은? 자주
  1. ①글자의 크기를 일괄적으로 변경하는 것이다
  2. ②문단의 첫 줄을 들여쓰기하는 것이다
  3. ③특정 글자 쌍 사이의 간격을 조절하는 것이다
  4. ④줄 간격을 자동으로 조정하는 것이다
4다음 중 들여쓰기(Indent)에 대한 설명으로 옳지 않은 것은? 매회
  1. ①문단의 왼쪽·오른쪽 여백을 조절할 수 있다
  2. ②첫 줄만 들여쓰기를 설정할 수 있다
  3. ③내어쓰기(Outdent)와 반대 개념이다
  4. ④들여쓰기를 설정하면 해당 글자의 크기가 자동으로 줄어든다
5다음 중 매크로(Macro)에 대한 설명으로 옳은 것은? 매회
  1. ①문서의 맞춤법을 자동으로 검사하는 기능이다
  2. ②문서에 비밀번호를 설정하는 보안 기능이다
  3. ③반복적인 작업을 기록하여 자동으로 실행하는 기능이다
  4. ④여러 문서를 하나로 합치는 기능이다
6다음 중 워터마크(Watermark)에 대한 설명으로 옳은 것은? 자주
  1. ①문서 본문 뒤에 희미하게 표시되는 텍스트나 이미지이다
  2. ②문서의 특정 부분을 형광색으로 강조하는 기능이다
  3. ③인쇄 시 용지의 방향을 자동으로 설정하는 기능이다
  4. ④문서의 여백에 주석을 추가하는 기능이다
7다음 중 스타일(Style)에 대한 설명으로 옳지 않은 것은? 매회
  1. ①글꼴, 크기, 정렬 등 서식을 묶어서 저장한 것이다
  2. ②문서의 일관된 형식을 유지하는 데 유용하다
  3. ③한 번 적용하면 수정이 불가능하다
  4. ④제목, 본문 등 용도별로 여러 스타일을 만들 수 있다
8다음 중 상용구에 대한 설명으로 옳은 것은? 자주
  1. ①자주 사용하는 문구를 등록해 두고 필요할 때 불러오는 기능이다
  2. ②문서의 오타를 자동으로 수정하는 기능이다
  3. ③여러 문서를 동시에 인쇄하는 기능이다
  4. ④문서의 글자 수를 세는 기능이다
9다음 중 금칙 처리에 대한 설명으로 옳은 것은? 매회
  1. ①특정 문자가 줄의 처음이나 끝에 오지 못하도록 제어하는 기능이다
  2. ②문서에 입력할 수 없는 특수 문자를 차단하는 기능이다
  3. ③비밀번호를 설정하여 문서 열람을 제한하는 기능이다
  4. ④지정된 시간이 지나면 문서가 자동 삭제되는 기능이다
10다음 중 개요(Outline) 기능에 대한 설명으로 옳은 것은? 자주
  1. ①문서의 오류를 자동으로 검출하는 기능이다
  2. ②인쇄 시 페이지 경계를 미리 보여주는 기능이다
  3. ③문서의 제목 구조를 계층적으로 표시하고 관리하는 기능이다
  4. ④문서에 사용된 글꼴 목록을 보여주는 기능이다
11다음 중 조판부호에 대한 설명으로 옳은 것은? 매회
  1. ①인쇄 시 용지에 그대로 출력되는 특수 기호이다
  2. ②문서의 저작권을 보호하기 위한 디지털 서명이다
  3. ③문서 편집 시 공백·탭·문단 구분 등을 화면에 표시하는 기호이다
  4. ④표 안의 셀 주소를 나타내는 기호이다
12다음 중 하이퍼링크(Hyperlink)에 대한 설명으로 옳지 않은 것은? 자주
  1. ①문서 내 특정 위치로 이동할 수 있다
  2. ②웹 페이지 주소(URL)를 연결할 수 있다
  3. ③하이퍼링크를 설정하면 해당 텍스트가 자동으로 삭제된다
  4. ④다른 파일을 열 수 있도록 경로를 연결할 수 있다
13다음 중 차트(Chart)에 대한 설명으로 옳은 것은? 자주
  1. ①차트는 표의 데이터를 시각적 그래프로 변환한 것이다
  2. ②차트는 한 번 생성하면 원본 데이터를 수정해도 변하지 않는다
  3. ③차트는 텍스트 문서에서는 사용할 수 없다
  4. ④차트 종류에는 원형만 존재한다
14다음 중 각주(Footnote)와 미주(Endnote)에 대한 설명으로 옳은 것은? 매회
  1. ①각주는 문서 끝에, 미주는 해당 페이지 아래에 표시된다
  2. ②각주와 미주는 동일한 위치에 표시된다
  3. ③각주는 해당 페이지 아래에, 미주는 문서 또는 구역 끝에 표시된다
  4. ④각주와 미주는 인쇄되지 않는 메모이다
15다음 중 텍스트 상자에 대한 설명으로 옳지 않은 것은? 자주
  1. ①문서 내 원하는 위치에 자유롭게 배치할 수 있다
  2. ②텍스트 상자 안에 그림을 삽입할 수 있다
  3. ③텍스트 상자의 크기는 고정되어 변경할 수 없다
  4. ④텍스트 상자에 테두리와 채우기 색을 설정할 수 있다
16다음 중 블록 설정 후 수행할 수 없는 작업은? 매회
  1. ①블록 영역의 글꼴을 변경한다
  2. ②블록 영역을 복사하여 다른 위치에 붙인다
  3. ③블록 영역의 전원을 종료한다
  4. ④블록 영역에 밑줄 서식을 적용한다
17다음 중 단(Column) 나누기에 대한 설명으로 옳은 것은? 매회
  1. ①한 페이지를 여러 단으로 나누어 신문처럼 편집하는 기능이다
  2. ②문서의 행 수를 제한하는 기능이다
  3. ③페이지 번호를 자동으로 매기는 기능이다
  4. ④문서를 여러 파일로 분리 저장하는 기능이다
18다음 중 메일 머지(Mail Merge)에 대한 설명으로 옳은 것은? 매회
  1. ①받는 사람마다 다른 내용을 자동으로 채워 넣어 문서를 대량 생성하는 기능이다
  2. ②이메일의 첨부 파일을 자동으로 압축하는 기능이다
  3. ③여러 사람이 동시에 같은 문서를 편집하는 기능이다
  4. ④문서의 변경 이력을 추적하는 기능이다
19다음 중 탭(Tab)에 대한 설명으로 옳지 않은 것은? 자주
  1. ①왼쪽 정렬 탭, 오른쪽 정렬 탭, 가운데 정렬 탭 등이 있다
  2. ②소수점 탭은 소수점을 기준으로 숫자를 정렬한다
  3. ③탭은 일정 간격만큼 커서를 이동시키는 기능이다
  4. ④탭을 설정하면 문서 전체의 글꼴이 변경된다
20다음 중 공문서의 '결문'에 해당하는 항목으로 옳은 것은? 매회
  1. ①수신자

  4. ④경유
22과목: PC 운영체제Q21 – Q40
21다음 중 운영체제(OS)의 주요 기능으로 옳지 않은 것은? 매회
  1. ①하드웨어 자원을 효율적으로 관리한다
  2. ②사용자와 컴퓨터 사이의 인터페이스를 제공한다
  3. ③응용 프로그램의 소스 코드를 직접 작성한다
  4. ④파일 및 디스크를 관리한다
22다음 중 GUI(Graphical User Interface)의 특징으로 옳은 것은? 매회
  1. ①명령어를 직접 타이핑하여 컴퓨터를 조작한다
  2. ②텍스트 기반으로만 동작한다
  3. ③아이콘, 메뉴, 창 등을 마우스로 조작하여 사용한다
  4. ④네트워크 연결 없이는 사용할 수 없다
23다음 중 Windows에서 작업 관리자를 여는 단축키로 옳은 것은? 매회
  1. ①Ctrl + Alt + Delete
  2. ②Ctrl + Shift + A
  3. ③Alt + F4
  4. ④Windows + E
24다음 중 레지스트리(Registry)에 대한 설명으로 옳은 것은? 매회
  1. ①Windows에서 하드웨어·소프트웨어 설정 정보를 저장하는 데이터베이스이다
  2. ②인터넷 검색 기록을 저장하는 공간이다
  3. ③프린터에서 인쇄 대기 문서를 저장하는 영역이다
  4. ④USB 장치의 드라이버를 자동으로 설치하는 프로그램이다
25다음 중 가상 메모리(Virtual Memory)에 대한 설명으로 옳은 것은? 매회
  1. ①RAM의 물리적 용량을 늘리는 하드웨어 부품이다
  2. ②모니터의 해상도를 조절하는 기능이다
  3. ③CPU의 처리 속도를 높이는 기술이다
  4. ④하드디스크 일부를 RAM처럼 사용하여 메모리 부족을 해결하는 기법이다
26다음 중 스풀링(Spooling)에 대한 설명으로 옳은 것은? 매회
  1. ①프린터 출력 데이터를 디스크에 임시 저장하여 CPU가 다른 작업을 계속할 수 있게 하는 기법이다
  2. ②메모리의 데이터를 압축하는 기법이다
  3. ③네트워크 속도를 높이는 기술이다
  4. ④모니터 화면을 캡처하는 기능이다
27다음 중 드라이버(Driver)에 대한 설명으로 옳은 것은? 매회
  1. ①CPU의 연산 속도를 결정하는 부품이다
  2. ②인터넷에 접속하기 위한 통신 프로토콜이다
  3. ③문서를 PDF로 변환하는 프로그램이다
  4. ④하드웨어 장치를 운영체제가 인식하고 제어할 수 있도록 해 주는 소프트웨어이다
28다음 중 Windows의 제어판에서 할 수 없는 작업은? 자주
  1. ①프린터 추가 및 설정
  2. ②프로그램 추가/제거
  3. ③하드웨어의 물리적 교체
  4. ④화면 해상도 변경
29다음 중 PnP(Plug and Play)에 대한 설명으로 옳은 것은? 매회
  1. ①컴퓨터의 전원을 자동으로 관리하는 기능이다
  2. ②프로그램의 오류를 자동으로 복구하는 기능이다
  3. ③네트워크에 자동으로 접속하는 기능이다
  4. ④새 하드웨어를 연결하면 자동으로 인식·설치되는 기능이다
30다음 중 클립보드(Clipboard)에 대한 설명으로 옳은 것은? 매회
  1. ①파일을 영구적으로 저장하는 보조기억장치이다
  2. ②인터넷에서 다운로드한 파일을 저장하는 폴더이다
  3. ③삭제된 파일을 보관하는 휴지통이다
  4. ④복사·잘라내기한 데이터를 임시로 저장하는 메모리 영역이다
31다음 중 바로 가기 아이콘에 대한 설명으로 옳은 것은? 매회
  1. ①바로 가기를 삭제하면 원본 파일도 함께 삭제된다
  2. ②바로 가기 아이콘은 폴더에만 만들 수 있다
  3. ③바로 가기 아이콘은 원본 파일과 크기가 동일하다
  4. ④원본 파일의 위치를 가리키는 연결 아이콘이다
32다음 중 안전 모드(Safe Mode)에 대한 설명으로 옳은 것은? 매회
  1. ①컴퓨터의 성능을 최대로 높여주는 모드이다
  2. ②바이러스를 자동으로 치료하는 모드이다
  3. ③네트워크 속도를 최적화하는 모드이다
  4. ④최소한의 드라이버와 서비스만으로 부팅하여 문제를 진단하는 모드이다
33다음 중 NTFS 파일 시스템의 특징으로 옳지 않은 것은? 매회
  1. ①파일 및 폴더에 대한 접근 권한을 설정할 수 있다
  2. ②4GB 이상의 대용량 파일을 저장할 수 있다
  3. ③파일 압축 및 암호화 기능을 지원한다
  4. ④Windows 95에서 처음 도입된 파일 시스템이다
34다음 중 폴더(Folder)에 대한 설명으로 옳지 않은 것은? 자주
  1. ①파일과 하위 폴더를 포함할 수 있다
  2. ②DOS에서는 디렉토리(Directory)라 불렸다
  3. ③트리(Tree) 구조로 계층적으로 관리된다
  4. ④폴더 안에 같은 이름의 파일을 여러 개 저장할 수 있다
35다음 중 휴지통에 대한 설명으로 옳은 것은? 매회
  1. ①휴지통에서 삭제하면 복구할 수 없다
  2. ②네트워크 드라이브에서 삭제한 파일도 휴지통에 저장된다
  3. ③Shift+Delete로 삭제하면 휴지통을 거치지 않고 영구 삭제된다
  4. ④휴지통의 용량은 변경할 수 없다
36다음 중 DLL(Dynamic Link Library)에 대한 설명으로 옳은 것은? 자주
  1. ①프로그램 실행 시 필요한 기능을 동적으로 연결하여 사용하는 라이브러리 파일이다
  2. ②인터넷 주소를 저장하는 파일이다

  3. ③Ctrl+A를 누르면 모든 파일을 선택할 수 있다

  4. ④CPU 내부에 있는 초고속 저장 장치이다

  3. ③다양한 주변기기를 연결할 수 있는 범용 인터페이스이다
  4. ④USB 포트에는 최대 1개의 장치만 연결할 수 있다

  3. ③기계적 구동부가 없어 소음이 적다
  4. ④자기 디스크에 데이터를 기록한다

  3. ③웹 페이지의 이름을 나타내는 도메인이다
  4. ④하드디스크의 물리적 위치를 나타내는 주소이다
