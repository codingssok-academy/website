1다음 중 공문서의 '끝' 표시에 대한 설명으로 옳은 것은? 매회
  1. ①본문 마지막 글자 다음에 한 칸 띄고 '끝'을 표시한다
  2. ②본문이 끝나면 줄을 바꿔 '끝'을 표시한다
  3. ③첨부물이 있으면 첨부 목록 아래에 '끝'을 표시한다
  4. ④표 아래에는 '끝' 표시를 생략한다
2다음 중 결재의 종류에 대한 설명으로 옳지 않은 것은? 매회
  1. ①협조 — 관련 부서의 동의를 구하는 절차로 결재의 한 종류이다
  2. ②대결 — 결재권자 부재 시 차상위자가 대신 결재하며 후결이 필요하다
  3. ③후결 — 긴급할 때 먼저 시행하고 나중에 결재를 받는다
  4. ④전결 — 위임받은 사항을 최종 결재권자 대신 결재한다
3다음 중 각주와 미주에 대한 설명으로 옳은 것은? 매회
  1. ①각주는 해당 페이지 하단, 미주는 문서 끝에 표시한다
  2. ②미주는 해당 페이지 하단에 표시한다
  3. ③각주와 미주는 동일한 위치에 표시된다
  4. ④각주는 문서 끝에 모아서 표시한다
4다음 중 DTP(전자출판)에 대한 설명으로 옳은 것은? 매회
  1. ①인쇄된 문자를 읽어 디지털로 변환하는 장치이다
  2. ②마크시트의 표시를 광학적으로 판독하는 장치이다
  3. ③문서를 네트워크로 전송하는 프로토콜이다
  4. ④컴퓨터를 이용하여 편집·조판·인쇄를 처리하는 출판 방식이다
5다음 중 매크로(Macro)에 대한 설명으로 옳지 않은 것은? 매회
  1. ①매크로 실행 시 원본 문서가 자동으로 백업된다
  2. ②키보드·마우스 동작을 기록하여 재실행할 수 있다
  3. ③복잡한 작업을 단축키 하나로 실행할 수 있다
  4. ④반복적인 작업을 자동화하는 기능이다
6다음 중 문서의 비밀 등급 분류가 올바른 것은? 매회
  1. ①1급 비밀 — 2급 비밀 — 3급 비밀 — 대외비
  2. ②극비 — 비밀 — 대외비 — 일반
  3. ③A급 비밀 — B급 비밀 — C급 비밀
  4. ④1급 비밀 — 2급 비밀 — 3급 비밀
7다음 중 RTF(Rich Text Format)에 대한 설명으로 옳은 것은? 매회
  1. ①서로 다른 워드프로세서 간 호환이 가능한 서식 있는 텍스트 형식이다
  2. ②이미지 파일 형식의 하나이다
  3. ③서식 정보 없이 순수 텍스트만 저장한다
  4. ④한글(한컴) 전용 문서 형식이다
8다음 중 교정 부호와 그 의미가 올바르게 연결된 것은? 매회
  1. ①∧ — 글자를 삽입한다
  2. ②∨ — 글자를 삭제한다
  3. ③○ — 띄어쓰기를 한다
  4. ④⌒ — 줄을 바꾼다
9다음 중 머리글/꼬리글에 대한 설명으로 옳은 것은? 매회
  1. ①머리글과 꼬리글은 매 페이지에 반복 인쇄되는 영역이다
  2. ②꼬리글은 본문의 보충 설명을 해당 페이지 하단에 표시하는 기능이다
  3. ③꼬리글에는 페이지 번호를 삽입할 수 없다
  4. ④머리글은 문서 첫 페이지에만 표시된다
10다음 중 문자 입력 방식에 대한 설명으로 옳은 것은? 자주
  1. ①삽입 모드에서는 기존 문자가 새 문자로 대체된다
  2. ②수정 모드에서는 기존 문자가 뒤로 밀린다
  3. ③삽입 모드와 수정 모드는 동일하게 동작한다
  4. ④Insert 키로 삽입 모드와 수정 모드를 전환할 수 있다
11다음 중 공문서의 날짜 표기로 옳은 것은? 매회
  1. ①2024. 3. 15.
  2. ②2024년 3월 15일
  3. ③24/03/15
  4. ④2024-03-15
12다음 중 공문서에서 숫자 표기에 대한 설명으로 옳은 것은? 매회
  1. ①금액은 아라비아 숫자로 쓰고 괄호 안에 한글로 기재한다
  2. ②숫자는 아라비아 숫자로 표기하되, 금액은 '#' 기호로 마감한다
  3. ③숫자를 아라비아 숫자로 쓰고 괄호 안에 한글 병기는 불필요하다
  4. ④금액은 한글로 표기한다
13다음 중 문서의 수발신 관련 용어에 대한 설명으로 옳은 것은? 매회
  1. ①시행문은 내부 검토용 문서이다
  2. ②접수란 발신 기관에서 문서를 보내는 것이다
  3. ③발신은 문서를 받아 등록하는 절차이다
  4. ④기안은 문서를 처음으로 작성하는 것을 말한다
14다음 중 글꼴(폰트)에 대한 설명으로 옳지 않은 것은? 자주
  1. ①트루타입 글꼴은 래스터 방식으로 저장된다
  2. ②비트맵 글꼴은 확대하면 계단 현상이 발생한다
  3. ③포스트스크립트(PostScript) 글꼴은 인쇄 품질이 우수하다
  4. ④트루타입(TrueType) 글꼴은 확대·축소 시 깨지지 않는다
15다음 중 치환(찾아 바꾸기) 기능에 대한 설명으로 옳은 것은? 자주
  1. ①서식(글꼴, 크기 등)도 바꾸기 대상에 포함할 수 있다
  2. ②한 번에 하나의 문자열만 바꿀 수 있다
  3. ③특수 문자는 바꾸기 대상에서 제외된다
  4. ④영문은 대소문자를 구분하지 못한다
16다음 중 문서 보관 기한에 대한 설명으로 옳은 것은? 자주
  1. ①보관 기한은 영구, 준영구, 30년, 10년, 5년, 3년, 1년으로 구분한다
  2. ②모든 문서는 5년간 보관 후 폐기한다
  3. ③보관 기한이 끝나면 자동으로 폐기된다
  4. ④보관 기한은 접수일부터 기산한다
17다음 중 OCR·OMR·MICR·BCR에 대한 설명으로 옳은 것은? 매회
  1. ①BCR은 바코드를 읽는 장치이다
  2. ②OCR은 마크시트의 표시를 읽는 장치이다
  3. ③MICR은 바코드를 읽는 장치이다
  4. ④OMR은 인쇄된 문자를 광학적으로 읽는 장치이다
18다음 중 공문서의 항목 번호 순서로 올바른 것은? 매회
  1. ①1. → 가. → 1) → 가) → (1) → (가)
  2. ②1. → 가. → (1) → (가) → 1) → 가)
  3. ③가. → 1. → 가) → 1) → (가) → (1)
  4. ④Ⅰ. → 1. → 가. → 1) → 가) → (1)
19다음 중 워드프로세서 편집 기능에 대한 설명으로 옳지 않은 것은? 자주
  1. ①블록 설정 후 이동(Move)하면 원본이 삭제된다
  2. ②블록 설정 후 복사(Copy)하면 원본이 유지된다
  3. ③되돌리기(Undo)는 직전 작업을 취소한다
  4. ④다시 실행(Redo)은 마지막으로 저장된 상태로 복원한다
20다음 중 프린터 종류에 대한 설명으로 옳은 것은? 매회
  1. ①레이저 프린터는 토너와 열을 이용하여 인쇄한다
  2. ②잉크젯 프린터는 충격식(Impact) 프린터이다
  3. ③도트 매트릭스 프린터는 비충격식(Non-Impact) 프린터이다
  4. ④열전사 프린터는 리본에 핀으로 충격을 주어 인쇄한다

21다음 중 Windows 바로 가기 키에 대한 설명으로 옳지 않은 것은? 매회
  1. ①Ctrl+C — 복사하기
  2. ②Ctrl+V — 붙여넣기
  3. ③Ctrl+Z — 되돌리기(실행 취소)
  4. ④Ctrl+S — 전체 선택
22다음 중 Windows 휴지통에 대한 설명으로 옳은 것은? 매회
  1. ①Shift+Delete로 삭제하면 휴지통에 보관된다
  2. ②휴지통에서 복원하면 원래 위치로 돌아간다
  3. ③휴지통의 최대 크기는 변경할 수 없다
  4. ④네트워크 드라이브의 파일도 휴지통에 보관된다
23다음 중 Windows 작업 관리자로 할 수 있는 작업이 아닌 것은? 자주
  1. ①실행 중인 프로세스 확인
  2. ②응답 없는 프로그램 강제 종료
  3. ③CPU 및 메모리 사용량 모니터링
  4. ④하드디스크 파티션 생성
24다음 중 Windows 파일 시스템에 대한 설명으로 옳은 것은? 매회
  1. ①FAT32는 4GB 이상의 단일 파일을 저장할 수 있다
  2. ②NTFS는 파일 암호화 및 압축 기능을 지원한다
  3. ③FAT32는 NTFS보다 보안 기능이 우수하다
  4. ④NTFS에서 FAT32로 변환 시 데이터 손실이 없다
25다음 중 레지스트리(Registry)에 대한 설명으로 옳지 않은 것은? 자주
  1. ①Windows 시스템의 모든 설정 정보를 저장하는 데이터베이스이다
  2. ②regedit 명령으로 레지스트리 편집기를 실행할 수 있다
  3. ③잘못 수정하면 시스템이 부팅되지 않을 수 있다
  4. ④레지스트리는 텍스트 파일 형태로 저장된다
26다음 중 Windows 제어판에서 설정할 수 없는 것은? 자주
  1. ①프로그램 추가/제거
  2. ②네트워크 및 인터넷 설정
  3. ③디스플레이 해상도 변경
  4. ④BIOS 설정 변경
27다음 중 Windows 바로 가기 아이콘에 대한 설명으로 옳은 것은? 매회
  1. ①바로 가기를 삭제하면 원본 파일도 삭제된다
  2. ②바로 가기 아이콘의 확장자는 .exe이다
  3. ③바로 가기는 원본과 같은 폴더에만 만들 수 있다
  4. ④바로 가기 아이콘에는 화살표 표시가 있다
28다음 중 클립보드(Clipboard)에 대한 설명으로 옳지 않은 것은? 자주
  1. ①복사하거나 잘라낸 데이터가 임시로 저장되는 메모리 영역이다
  2. ②컴퓨터를 재부팅하면 클립보드 내용이 유지된다
  3. ③새로운 데이터를 복사하면 이전 클립보드 내용이 대체된다
  4. ④여러 응용 프로그램 간에 데이터를 전달할 수 있다
29다음 중 Windows 멀티태스킹에 대한 설명으로 옳은 것은? 매회
  1. ①한 번에 하나의 프로그램만 실행할 수 있는 방식이다
  2. ②여러 프로그램을 동시에 실행할 수 있는 방식이다
  3. ③하나의 프로그램을 여러 컴퓨터에서 실행하는 방식이다
  4. ④여러 사용자가 하나의 프로그램을 공유하는 방식이다
30다음 중 Windows 폴더 옵션에서 설정할 수 있는 것으로 옳은 것은? 자주
  1. ①CPU 클럭 속도 변경
  2. ②숨김 파일 및 폴더 표시 여부
  3. ③IP 주소 설정
  4. ④프린터 드라이버 설치
31다음 중 Windows에서 파일 확장자와 프로그램의 연결이 올바르지 않은 것은? 매회

  2. ②.xlsx — Excel
  3. ③.hwp — 한글
  4. ④.mp3 — 그림판
32다음 중 Windows 안전 모드에 대한 설명으로 옳은 것은? 자주
  1. ①모든 드라이버와 서비스가 정상적으로 로드된다
  2. ②네트워크에 자동으로 연결된다
  3. ③시스템 진단 및 문제 해결을 위해 최소한의 드라이버로 부팅한다
  4. ④안전 모드에서는 프로그램을 설치할 수 없다
33다음 중 디스크 조각 모음에 대한 설명으로 옳은 것은? 매회
  1. ①파일을 삭제하여 디스크 공간을 확보한다
  2. ②흩어진 파일 조각을 연속된 공간으로 재배치하여 성능을 향상시킨다
  3. ③SSD에서도 반드시 주기적으로 실행해야 한다
  4. ④디스크 조각 모음 시 파일이 손상될 수 있다
34다음 중 드라이버(Driver)에 대한 설명으로 옳은 것은? 매회
  1. ①응용 프로그램의 일종으로 사용자가 직접 실행한다
  2. ②하드웨어 장치를 운영체제가 인식하고 제어하도록 하는 소프트웨어이다
  3. ③드라이버 없이도 모든 하드웨어를 사용할 수 있다
  4. ④드라이버는 한 번 설치하면 업데이트가 필요 없다
35다음 중 Windows 시스템 복원에 대한 설명으로 옳지 않은 것은? 자주
  1. ①복원 지점을 만들어 이전 상태로 되돌릴 수 있다
  2. ②시스템 파일과 설정을 복원하지만 개인 파일은 영향받지 않는다
  3. ③사용자가 수동으로 복원 지점을 생성할 수 있다
  4. ④시스템 복원 시 모든 개인 문서도 해당 시점으로 복원된다
36다음 중 Windows 명령 프롬프트(CMD) 명령어와 기능이 올바르게 연결된 것은? 매회
  1. ①dir — 파일 삭제
  2. ②cd — 디렉터리(폴더) 변경
  3. ③copy — 파일 이동
  4. ④del — 파일 복사
37다음 중 와일드카드 문자에 대한 설명으로 옳은 것은? 매회
  1. ①* 는 임의의 한 문자를 대체한다
  2. ②? 는 임의의 여러 문자를 대체한다
  3. ③* 는 임의의 여러 문자(0개 이상), ? 는 임의의 한 문자를 대체한다
