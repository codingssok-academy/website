1다음 중 교정부호에 대한 설명으로 올바른 것은? 매회
  1. ①∧ 부호는 글자와 글자 사이를 벌리라는 뜻이다.
  2. ②∨ 부호는 글자를 삽입(끼워 넣기)하라는 뜻이다.
  3. ③⌒ 부호는 줄을 바꾸라는 의미이다.
  4. ④≠ 부호는 앞뒤 글자의 자리를 서로 바꾸라는 뜻이다.
2공문서(관공서에서 쓰는 공식 문서) 작성 시 날짜, 금액, 시간 표시 방법으로 올바른 것은? 매회
  1. ①날짜는 '2026. 3. 19.'처럼 온점(마침표)으로 구분하고, 금액은 '금123,000원(금일이삼만원)'처럼 숫자와 한글을 함께 쓴다.
  2. ②날짜는 '2026-03-19'처럼 하이픈(빼기표)으로 구분한다.
  3. ③금액은 숫자로만 쓰고 한글 표기는 생략해도 된다.
  4. ④시간은 오전/오후 방식(AM/PM)으로 쓰는 것이 원칙이다.
3공문서에서 본문 내용이 끝났을 때 '끝' 표시에 대한 설명으로 올바른 것은? 매회
  1. ①본문 내용이 표(테이블)로 끝나면 표 아래 왼쪽 끝에 '끝'을 쓴다.
  2. ②첨부물이 있으면 첨부 표시 다음 줄 왼쪽 끝에 '끝'을 쓴다.
  3. ③본문의 마지막 글자에서 한 칸 띄고 '끝'을 쓴다.
  4. ④본문이 표로 끝나더라도 항상 본문 마지막 글자 뒤에 '끝'을 쓴다.
4공문서에서 후결(나중에 결재받기)에 대한 설명으로 올바른 것은? 자주
  1. ①결재권자가 없을 때 직근 하위자가 대신 결재하는 것이다.
  2. ②두 개 이상의 부서가 함께 의논하여 결정하는 것이다.
  3. ③결재권자가 미리 위임한 사항에 대해 하위자가 결재하는 것이다.
  4. ④긴급한 일을 먼저 처리한 뒤, 나중에 결재권자에게 승인받는 것이다.
5업무 실명제에 대한 설명으로 틀린 것은? 자주
  1. ①주요 업무를 처리한 담당자의 실명(진짜 이름)을 기록하는 제도이다.
  2. ②업무 처리의 투명성(누가 했는지 알 수 있게)을 높이는 것이 목적이다.
  3. ③모든 업무에 실명을 기록해야 하므로 사소한 메모에도 적용된다.
  4. ④업무 책임을 분명히 하여 부정·비리를 예방하는 효과가 있다.
6다음 중 오픈타입(OpenType) 글꼴에 대한 설명으로 올바른 것은? 매회
  1. ①Adobe와 Microsoft가 공동 개발한 글꼴 형식으로, 하나의 파일로 Windows와 Mac 모두에서 사용할 수 있다.
  2. ②Apple과 Microsoft가 공동 개발한 글꼴 형식이다.
  3. ③Adobe가 단독 개발한 프린터 전용 글꼴이다.
  4. ④트루타입의 이전 버전으로, 화면 표시 전용 글꼴이다.
7유니코드(Unicode)에 대한 설명으로 틀린 것은? 매회
  1. ①전 세계 문자를 하나의 코드 체계로 통일한 국제 표준이다.
  2. ②UTF-8 인코딩은 항상 2바이트 고정 길이로 문자를 표현한다.
  3. ③한글, 영어, 일본어, 아랍어 등 다양한 언어를 지원한다.
  4. ④인터넷 웹 페이지에서 가장 많이 사용되는 문자 코드이다.
8한글 코드 체계에서 완성형과 조합형에 대한 설명으로 올바른 것은? 자주
  1. ①완성형은 초성·중성·종성을 조합하여 모든 한글을 표현할 수 있다.
  2. ②조합형은 KS X 1001에서 정한 2,350자만 표현할 수 있다.
  3. ③완성형은 모든 한글 11,172자를 표현할 수 있어 뷁, 쓩 같은 글자도 가능하다.
  4. ④조합형은 초성·중성·종성 각각에 코드를 부여하여 모든 한글을 조합할 수 있다.
9워드프로세서에서 OLE(개체 연결 및 포함)의 '연결'과 '포함'에 대한 설명으로 틀린 것은? 매회
  1. ①연결(링크)은 원본 파일이 수정되면 문서의 개체도 자동으로 바뀐다.
  2. ②포함(임베드)은 원본 파일을 문서 안에 통째로 넣는 것이다.
  3. ③포함 방식은 연결 방식보다 문서 파일 크기가 더 커진다.
  4. ④연결은 원본 파일을 삭제해도 문서에는 아무 영향이 없다.
10워드프로세서의 매크로(Macro, 자동 반복 기능)에 대한 설명으로 틀린 것은? 자주
  1. ①반복되는 작업을 한 번 기록해두면 버튼 하나로 자동 실행할 수 있다.
  2. ②매크로로 기록한 작업 순서를 나중에 수정(편집)할 수 있다.
  3. ③매크로에 바이러스가 포함될 수 있어 주의가 필요하다.
  4. ④매크로는 RAM(임시 메모리)에만 존재하며 파일로 저장할 수 없다.
11메일머지(Mail Merge, 편지 병합)에 대한 설명으로 올바른 것은? 자주
  1. ①메일머지는 양식 파일(본문 틀)과 데이터 파일(이름·주소 등)을 합쳐서 여러 장의 문서를 자동으로 만드는 기능이다.
  2. ②메일머지는 이메일을 자동으로 보내주는 기능이다.
  3. ③메일머지의 데이터 파일에는 그림과 동영상만 넣을 수 있다.
  4. ④메일머지를 사용하면 문서마다 내용을 전부 직접 수정해야 한다.
12워드프로세서의 머리말/꼬리말과 각주/미주에 대한 설명으로 틀린 것은? 매회
  1. ①머리말은 페이지 위쪽에 반복 표시되는 내용이다.
  2. ②머리말에는 텍스트만 넣을 수 있고, 표나 그림은 넣을 수 없다.
  3. ③각주는 해당 페이지 아래에, 미주는 문서 맨 끝에 표시된다.
  4. ④머리말/꼬리말을 짝수 페이지와 홀수 페이지에 다르게 설정할 수 있다.
13워드프로세서의 스타일(Style) 기능에 대한 설명으로 올바른 것은? 매회
  1. ①스타일을 수정하면 해당 스타일이 적용된 모든 부분을 일일이 다시 지정해야 한다.
  2. ②스타일에는 글자 크기만 저장할 수 있고, 색상이나 줄 간격은 저장할 수 없다.
  3. ③스타일을 수정하면 해당 스타일이 적용된 모든 부분이 한꺼번에 자동으로 변경된다.
  4. ④스타일은 한 번 만들면 삭제하거나 새로 추가할 수 없다.
14템플릿(Template, 서식 파일)에 대한 설명으로 틀린 것은? 자주
  1. ①자주 사용하는 문서의 형식(틀)을 미리 만들어 저장해둔 것이다.
  2. ②템플릿을 열면 원본이 열리는 것이 아니라 복사본이 새로 만들어진다.
  3. ③편지, 이력서, 보고서 등 반복 사용하는 문서에 활용된다.
  4. ④템플릿은 한 번 만들면 내용을 수정하거나 변경할 수 없다.
15다음 중 프린터 종류와 특징의 연결이 올바른 것은? 매회
  1. ①잉크젯 프린터 — 잉크를 미세한 노즐로 분사(뿌리기)하여 인쇄한다.
  2. ②레이저 프린터 — 바늘(핀)로 리본을 때려서 점을 찍어 인쇄한다.
  3. ③도트 매트릭스 프린터 — 레이저 빛으로 토너(가루)를 녹여 인쇄한다.
  4. ④플로터 — 잉크를 가열하여 종이에 뿌리는 가정용 프린터이다.
16스풀링(Spooling, 인쇄 대기열 관리)에 대한 설명으로 틀린 것은? 매회
  1. ①인쇄할 데이터를 하드디스크에 임시 저장한 뒤 순서대로 인쇄한다.
  2. ②스풀링을 사용하면 인쇄 속도 자체가 빨라진다.
  3. ③스풀링 덕분에 인쇄 중에도 컴퓨터로 다른 작업을 할 수 있다.
  4. ④스풀링은 하드디스크 공간을 사용하므로 디스크 여유 공간이 필요하다.
17워드프로세서에서 커닝(Kerning)과 트래킹(Tracking)에 대한 설명으로 올바른 것은? 매회
  1. ①커닝은 문단과 문단 사이의 간격을 조절하는 기능이다.
  2. ②트래킹은 특정 두 글자 사이의 간격만 조절하는 기능이다.
  3. ③커닝은 특정 글자 쌍(예: AV) 사이의 간격을 조절하고, 트래킹은 글자 전체의 간격을 일괄 조절한다.
  4. ④커닝과 트래킹은 줄(행) 간격을 조절하는 동일한 기능이다.
18워드랩(Word Wrap, 자동 줄 바꿈)에 대한 설명으로 틀린 것은? 자주
  1. ①문장이 오른쪽 끝에 닿으면 자동으로 다음 줄로 넘어가는 기능이다.
  2. ②영문에서 단어 중간이 아닌 단어 단위로 줄을 바꿔준다.
  3. ③사용자가 엔터(Enter)를 누르지 않아도 자동으로 작동한다.
  4. ④워드랩은 글자 하나하나를 기준으로 줄을 바꾸기 때문에 단어가 잘릴 수 있다.
19하이퍼텍스트(Hypertext)에 대한 설명으로 올바른 것은? 매회
  1. ①하이퍼텍스트는 문서를 처음부터 끝까지 순서대로만 읽을 수 있는 선형 구조이다.
  2. ②하이퍼텍스트는 동영상이나 소리를 포함할 수 없는 텍스트 전용 기술이다.
  3. ③하이퍼텍스트는 TCP/IP 프로토콜로만 전송할 수 있다.
  4. ④하이퍼텍스트는 링크를 통해 비선형적(순서 상관없이)으로 문서 간 이동이 가능하다.
20전자문서(컴퓨터로 만든 공식 문서)의 법적 효력 발생 시점으로 올바른 것은? 매회
  1. ①발신자가 '보내기' 버튼을 누른 순간 효력이 발생한다.
  2. ②수신자가 지정한 정보처리시스템(컴퓨터/서버)에 입력된 때 효력이 발생한다.
  3. ③수신자가 문서를 열어서 내용을 확인한 때 효력이 발생한다.
  4. ④발신자와 수신자가 전화로 확인한 때 효력이 발생한다.
2PC 운영체제Q21 – Q40
21Windows 탐색기(파일 찾는 프로그램)에서 파일의 크기, 수정 날짜, 종류까지 한눈에 볼 수 있는 보기 방식은? 자주
  1. ①자세히 — 이름, 크기, 날짜, 종류를 표처럼 보여준다
  2. ②큰 아이콘 — 사진처럼 크게 보여준다
  3. ③목록 — 파일 이름만 쭉 나열한다
  4. ④타일 — 아이콘 옆에 파일 종류만 보여준다
22파일을 원래 위치에 그대로 두고 다른 폴더에도 똑같은 파일을 만들려면 어떤 단축키 조합을 써야 하는가? 자주
  1. ①Ctrl+X → Ctrl+V (잘라내기 → 붙여넣기)
  2. ②Ctrl+C → Ctrl+V (복사 → 붙여넣기)
  3. ③Ctrl+Z → Ctrl+V (실행취소 → 붙여넣기)
  4. ④Ctrl+A → Ctrl+V (전체선택 → 붙여넣기)
23USB 메모리에 있는 파일을 Delete 키로 삭제하면 어떻게 되는가? 매회
  1. ①휴지통으로 이동하므로 나중에 복원할 수 있다
  2. ②바탕화면에 백업 파일이 자동 생성된다
  3. ③삭제 전 자동으로 하드디스크에 복사된다
  4. ④바로 완전 삭제되어 복원할 수 없다
24하드디스크에 있는 파일을 휴지통을 거치지 않고 바로 완전 삭제하려면 어떤 키를 눌러야 하는가? 매회
  1. ①Ctrl+Delete
  2. ②Alt+Delete
  3. ③Shift+Delete
  4. ④Tab+Delete
25Windows에서 파일 확장자(파일 이름 뒤의 .txt, .jpg 등)가 보이지 않을 때, 이를 표시하려면 어디에서 설정해야 하는가? 자주
  1. ①탐색기 → 보기 탭 → '파일 이름 확장명' 체크
  2. ②바탕화면 → 마우스 오른쪽 → 화면 해상도
  3. ③제어판 → 프로그램 제거
  4. ④작업 관리자 → 프로세스 탭
26제어판(컴퓨터 설정 모음)의 키보드 설정에서 조절할 수 있는 항목으로 올바른 것은? 자주
  1. ①마우스 포인터의 이동 속도
  2. ②화면 밝기와 해상도
  3. ③스피커 볼륨 크기
  4. ④키를 눌렀을 때 반복되는 속도(재입력 시간)
27Windows에서 창(윈도우)을 화면 왼쪽 끝으로 드래그하면 어떤 기능이 작동하는가? 매회
  1. ①에어로 셰이크 — 다른 창이 모두 최소화된다
  2. ②에어로 스냅 — 화면 왼쪽 절반에 딱 맞게 정렬된다
  3. ③에어로 피크 — 모든 창이 투명해져서 바탕화면이 보인다
  4. ④에어로 플립 — 3D 효과로 창이 회전한다
28작업 표시줄에서 열려 있는 프로그램 아이콘 위에 마우스를 올리면 나타나는 작은 미리보기 화면을 제공하는 기능은? 매회
  1. ①에어로 스냅(Aero Snap)
  2. ②에어로 셰이크(Aero Shake)
  3. ③가상 데스크톱(Virtual Desktop)
  4. ④라이브 썸네일(에어로 피크, Aero Peek)

  2. ②DDoS의 D는 Distributed(분산)로, 여러 곳에서 동시에 공격하는 것을 의미한다
  3. ③DDoS 공격을 받으면 정상 사용자도 서버에 접속할 수 없게 된다
  4. ④DDoS는 서버에 직접 악성코드를 설치하여 데이터를 삭제하는 공격이다

  2. ②이메일을 보내기 위한 메일 전송 프로토콜이다
  3. ③웹 통신을 암호화하여 안전하게 보호하는 보안 프로토콜로, HTTPS의 기반이다
  4. ④IP 주소를 도메인 이름으로 바꿔주는 변환 서비스이다

  1. ①매번 서비스를 이용할 때마다 각각 다른 아이디로 로그인해야 하는 방식이다
  2. ②한 번의 로그인으로 연결된 여러 서비스를 추가 로그인 없이 이용할 수 있는 방식이다
  3. ③비밀번호 대신 지문이나 얼굴만으로 로그인하는 생체 인증 방식이다
  4. ④일회용 비밀번호(OTP)를 매번 발급받아 로그인하는 방식이다

  4. ④저작권법은 아이디어 자체도 보호하므로, 비슷한 생각만 해도 저작권 침해이다
