  1. ①시스템 설정 정보를 저장하는 계층형 데이터베이스이다.
  2. ②편집은 regedit(레지스트리 편집기)를 사용한다.
  3. ③메모장(Notepad)으로 직접 열어서 수정하는 것이 가장 안전하다.
  4. ④잘못 수정하면 시스템이 정상 작동하지 않을 수 있다.
39다음 중 Windows UAC(사용자 계정 컨트롤)에 대한 설명으로 옳은 것은? 매회
  1. ①UAC를 끄면 보안이 강화되어 바이러스 감염 위험이 줄어든다.
  2. ②UAC는 화면 해상도를 자동으로 조절하는 기능이다.
  3. ③UAC는 파일을 자동으로 백업하는 기능이다.
  4. ④UAC는 프로그램 설치 등 시스템 변경 시 사용자에게 확인을 요청하여 보안을 강화한다.
40다음 중 디스크 조각 모음에 대한 설명으로 옳지 않은 것은? 매회
  1. ①하드디스크에 흩어진 파일 조각을 연속된 공간으로 모아 재배치한다.
  2. ②조각 모음을 하면 불필요한 파일이 삭제되어 디스크 공간이 늘어난다.
  3. ③조각 모음을 하면 파일 읽기 속도가 향상될 수 있다.
  4. ④SSD에서는 조각 모음이 불필요하며 오히려 수명을 단축시킬 수 있다.

41다음 중 CPU의 구성 요소에 대한 설명으로 옳은 것은? 매회
  1. ①ALU(산술논리연산장치)는 산술·논리·비교 연산을 담당한다.
  2. ②CU(제어장치)는 덧셈, 뺄셈 등 산술 연산을 직접 수행한다.
  3. ③ALU(산술논리연산장치)는 명령어를 해독하고 각 장치에 제어 신호를 보낸다.
  4. ④레지스터는 보조기억장치의 일종으로 하드디스크에 위치한다.
42다음 중 레지스터에 대한 설명으로 옳지 않은 것은? 자주
  1. ①PC(프로그램 카운터)는 현재 실행 중인 명령어의 결과값을 저장한다.
  2. ②IR(명령어 레지스터)는 현재 실행 중인 명령어를 저장한다.
  3. ③AC(누산기)는 연산 결과를 임시로 저장하는 레지스터이다.
  4. ④MAR(메모리 주소 레지스터)는 접근할 메모리의 주소를 저장한다.
43다음 중 이메일 프로토콜에 대한 설명으로 옳지 않은 것은? 매회
  1. ①SMTP는 이메일을 보낼 때 사용하는 프로토콜이다.
  2. ②POP3는 이메일을 보낼 때 사용하는 프로토콜이다.
  3. ③IMAP은 서버에 메일을 남겨두고 여러 기기에서 확인할 수 있다.
  4. ④POP3는 메일을 다운로드한 후 서버에서 삭제하는 것이 기본이다.
44다음 중 HTTP와 HTTPS에 대한 설명으로 옳은 것은? 매회
  1. ①HTTP는 포트 443번을 사용하고 암호화를 지원한다.
  2. ②HTTPS는 포트 80번을 사용하며 보안이 취약하다.
  3. ③HTTP와 HTTPS는 동일한 포트 번호를 사용한다.
  4. ④HTTP는 포트 80번, HTTPS는 포트 443번을 사용한다.
45다음 중 컴퓨터 세대별 소자의 연결이 올바른 것은? 매회
  1. ①1세대 — 진공관, 2세대 — 트랜지스터, 3세대 — IC(집적회로)
  2. ②1세대 — 트랜지스터, 2세대 — 진공관
  3. ③1세대 — 진공관, 2세대 — IC(집적회로)
  4. ④2세대 — IC(집적회로), 3세대 — LSI
46다음 중 주기억장치에 대한 설명으로 옳지 않은 것은? 매회
  1. ①RAM은 읽기와 쓰기가 모두 가능한 메모리이다.
  2. ②ROM은 전원이 꺼져도 내용이 유지되는 비휘발성 메모리이다.
  3. ③ROM은 전원이 꺼지면 내용이 사라지는 휘발성 메모리이다.
  4. ④RAM은 전원이 꺼지면 저장 내용이 사라진다.
47다음 중 캐시 메모리에 대한 설명으로 옳지 않은 것은? 매회
  1. ①CPU와 주기억장치(RAM) 사이의 속도 차이를 줄이기 위해 사용한다.
  2. ②SRAM(정적 RAM)으로 구성되어 있다.
  3. ③보조기억장치(HDD/SSD)와 주기억장치(RAM) 사이에 위치한다.
  4. ④CPU에 가까울수록 용량이 작고 속도가 빠르다.
48다음 중 데이터 단위에 대한 설명으로 옳은 것은? 매회
  1. ①1바이트(Byte)는 4비트로 구성된다.
  2. ②1KB는 1,024Byte이다.
  3. ③1KB는 1,000Byte이다.
  4. ④니블(Nibble)은 8비트이다.
49다음 중 SSD와 HDD를 비교한 설명으로 옳지 않은 것은? 자주
  1. ①HDD는 SSD보다 읽기/쓰기 속도가 빠르다.
  2. ②HDD는 회전하는 디스크에 자기적으로 데이터를 기록한다.
  3. ③SSD는 반도체(플래시 메모리) 기반이라 충격에 강하다.
  4. ④SSD는 소음이 없고 발열이 적다.
50다음 중 소프트웨어 분류에 대한 설명으로 옳은 것은? 자주
  1. ①프리웨어(Freeware)는 무료이고 소스코드도 공개된다.
  2. ②셰어웨어(Shareware)는 일정 기간 무료 사용 후 구매가 필요하다.
  3. ③오픈소스 소프트웨어는 소스코드가 비공개이다.
  4. ④번들웨어(Bundleware)는 인터넷에서 무료로 다운로드하는 소프트웨어이다.
51다음 중 언어 번역 프로그램에 대한 설명으로 옳지 않은 것은? 자주
  1. ①컴파일러는 소스코드 전체를 한 번에 번역한 후 실행한다.
  2. ②인터프리터는 소스코드를 한 줄씩 번역하면서 실행한다.
  3. ③컴파일러는 번역 후 실행 속도가 빠르다.
  4. ④인터프리터는 전체를 번역한 후 한꺼번에 실행하므로 속도가 빠르다.
52다음 중 이미지 파일 형식에 대한 설명으로 옳지 않은 것은? 매회
  1. ①JPG(JPEG)는 손실 압축 방식으로 사진 저장에 많이 쓰인다.
  2. ②GIF는 최대 1,677만 색을 표현하며 애니메이션을 지원하지 않는다.
  3. ③PNG는 비손실 압축으로 투명 배경(알파 채널)을 지원한다.
  4. ④BMP는 비압축 방식으로 파일 크기가 크다.
53다음 중 MIDI에 대한 설명으로 옳은 것은? 자주
  1. ①실제 악기 소리를 녹음한 오디오 파일이다.
  2. ②사람의 목소리를 디지털로 변환한 파일이다.
  3. ③악기의 연주 정보(음높이, 길이, 세기 등)를 저장한 데이터이다.
  4. ④동영상과 음성을 함께 저장하는 멀티미디어 형식이다.
54다음 중 네트워크 장비에 대한 설명으로 옳지 않은 것은? 매회
  1. ①허브(Hub)는 OSI 1계층에서 동작하며 받은 데이터를 모든 포트에 전송한다.
  2. ②스위치(Switch)는 OSI 2계층에서 MAC 주소를 기반으로 선택 전달한다.
  3. ③라우터(Router)는 OSI 3계층에서 IP 주소를 기반으로 최적 경로를 결정한다.
  4. ④허브(Hub)는 MAC 주소를 분석하여 특정 장치에만 데이터를 전달한다.
55다음 중 TCP와 UDP에 대한 설명으로 옳은 것은? 자주
  1. ①TCP는 연결형 프로토콜로 신뢰성을 보장하며, UDP는 비연결형으로 속도가 빠르다.
  2. ②UDP는 연결형 프로토콜로 데이터 전송의 신뢰성을 보장한다.
  3. ③TCP는 비연결형 프로토콜로 속도가 빠르다.
  4. ④TCP와 UDP 모두 데이터 도착 순서와 완전성을 보장한다.
56다음 중 악성코드의 종류에 대한 설명으로 옳은 것은? 매회
  1. ①웜(Worm)은 정상 파일에 기생하며 반드시 숙주 파일이 필요하다.
  2. ②트로이목마는 스스로 복제하여 네트워크를 통해 전파된다.
  3. ③바이러스는 숙주 파일 없이 독립적으로 전파되는 악성코드이다.
  4. ④랜섬웨어는 파일을 암호화한 뒤 복호화 대가로 금전을 요구한다.
57다음 중 사이버 공격에 대한 설명으로 옳지 않은 것은? 자주
  1. ①피싱(Phishing)은 가짜 이메일이나 사이트로 유인하여 개인정보를 탈취한다.
  2. ②파밍(Pharming)은 DNS를 조작하여 정상 주소를 입력해도 가짜 사이트로 이동시킨다.
  3. ③스니핑(Sniffing)은 가짜 사이트를 만들어 사용자를 유인하는 공격이다.
  4. ④스미싱(Smishing)은 문자 메시지(SMS)를 이용한 피싱 공격이다.
58다음 중 암호화 방식에 대한 설명으로 옳지 않은 것은? 매회
  1. ①대칭키 방식은 암호화와 복호화에 동일한 키를 사용한다.
  2. ②공개키(비대칭키) 방식은 공개키와 개인키 한 쌍을 사용한다.
  3. ③대칭키 방식은 키 배포가 안전하여 인터넷 통신에서 단독으로 사용된다.
  4. ④RSA는 대표적인 공개키(비대칭키) 암호화 알고리즘이다.
59다음 중 IP 주소와 DNS에 대한 설명으로 옳지 않은 것은? 매회
  1. ①IPv4는 32비트 주소 체계로, 약 43억 개의 주소를 사용할 수 있다.
  2. ②IPv6는 32비트 주소 체계로 IPv4보다 주소 공간이 적다.
  3. ③DNS는 도메인 이름(예: www.naver.com)을 IP 주소로 변환하는 시스템이다.
  4. ④IPv6는 128비트 주소 체계로, IPv4의 주소 부족 문제를 해결한다.
60다음 중 최신 IT 기술에 대한 설명으로 옳지 않은 것은? 자주
  1. ①IaaS는 서버·네트워크·스토리지 같은 인프라를 서비스로 제공한다.
  2. ②빅데이터의 3V는 Volume(대용량), Velocity(고속), Variety(다양성)이다.
  3. ③블록체인은 중앙 서버 없이 분산 원장(장부)으로 데이터 위변조를 방지한다.
  4. ④IoT(사물인터넷)는 사람이 직접 모든 기기를 수동으로 조작하는 기술이다.
