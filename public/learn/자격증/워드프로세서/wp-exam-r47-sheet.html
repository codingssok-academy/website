11과목: 워드프로세싱 용어 및 기능Q1 – Q20
1다음 중 전자출판(DTP)에 대한 설명으로 옳지 않은 것은? 매회
  1. ①대량 인쇄 시 오프셋 인쇄보다 단가가 저렴하다
  2. ②원고 작성부터 편집·인쇄까지 컴퓨터로 처리한다
  3. ③소량 다품종 제작에 적합하다
  4. ④편집·수정이 용이하여 작업 시간이 단축된다
2다음 중 공문서의 본문에 해당하는 항목으로 옳은 것은? 매회
  1. ①수신자
  2. ②발신명의
  3. ③제목
  4. ④발신기관명
3다음 중 대결에 대한 설명으로 옳은 것은? 매회
  1. ①결재권자가 미리 권한을 위임하여 최종 결재하게 하는 것이다
  2. ②결재권자가 부재 시 차상위자가 대신 결재하는 것이다
  3. ③긴급한 경우 먼저 시행하고 나중에 결재받는 것이다
  4. ④여러 부서가 공동으로 결재하는 것이다
4다음 중 매크로(Macro)에 대한 설명으로 옳지 않은 것은? 자주
  1. ①반복 작업을 자동화할 수 있다
  2. ②사용자가 키보드와 마우스 동작을 기록할 수 있다
  3. ③매크로 실행 후에는 실행 취소(Undo)가 불가능하다
  4. ④매크로에 단축키를 지정하여 실행할 수 있다
5다음 중 꼬리말(Footer)에 대한 설명으로 옳은 것은? 매회
  1. ①꼬리말은 인쇄 시에만 나타나며 화면에서는 볼 수 없다
  2. ②꼬리말은 첫 페이지에만 설정할 수 있다
  3. ③꼬리말에는 그림을 삽입할 수 없다
  4. ④꼬리말에 페이지 번호를 자동 삽입할 수 있다
6다음 중 WYSIWYG의 의미로 가장 옳은 것은? 매회
  1. ①화면에 표시된 내용과 인쇄 결과가 동일하다
  2. ②문서를 암호화하여 보안을 강화하는 기능이다
  3. ③여러 사용자가 동시에 편집할 수 있는 기능이다
  4. ④문서 파일을 압축하여 저장하는 기능이다
7다음 중 상용구(AutoText)에 대한 설명으로 옳은 것은? 자주
  1. ①자주 사용하는 문구를 미리 등록해 놓고 빠르게 입력할 수 있다
  2. ②맞춤법 검사를 자동으로 수행하는 기능이다
  3. ③문서의 글꼴을 일괄 변경하는 기능이다
  4. ④문서를 자동으로 저장하는 기능이다
8다음 중 탭(Tab) 설정에 대한 설명으로 옳지 않은 것은? 자주
  1. ①왼쪽 탭, 오른쪽 탭, 가운데 탭, 소수점 탭이 있다
  2. ②탭은 문단 내에서 일정 위치로 커서를 이동시킨다
  3. ③탭 간격은 사용자가 변경할 수 없다
  4. ④탭 채움선을 설정할 수 있다
9다음 중 교정 부호에서 '삽입'을 나타내는 부호로 옳은 것은? 매회
  1. ①∧(갈매기) 모양
  2. ②○ 모양으로 글자를 감싼다
  3. ③── 모양의 밑줄
  4. ④⌐ 모양
10다음 중 블록 설정 후 수행할 수 없는 작업은? 자주
  1. ①글자 모양(글꼴, 크기) 변경
  2. ②복사 및 이동
  3. ③새 문서 만들기
  4. ④정렬(왼쪽, 가운데, 오른쪽) 변경
11다음 중 차트(그래프)의 종류와 설명이 옳지 않은 것은? 자주
  1. ①원형 차트 — 전체 대비 각 항목의 비율을 나타낸다
  2. ②꺾은선 차트 — 시간에 따른 변화 추이를 나타낸다
  3. ③막대 차트 — 항목 간 크기를 비교한다
  4. ④방사형 차트 — 두 변수 간의 상관관계를 점으로 나타낸다
12다음 중 글자 겹침 현상이 발생하는 원인으로 가장 적절한 것은? 자주
  1. ①프린터 드라이버가 올바르게 설치되지 않았다
  2. ②장평이나 자간이 잘못 설정되었다
  3. ③용지 방향이 잘못되었다
  4. ④페이지 번호가 중복되었다
13다음 중 서식 파일(스타일 시트)에 대한 설명으로 옳은 것은? 자주
  1. ①서식 파일은 한 번 설정하면 수정할 수 없다
  2. ②서식 파일에는 글꼴, 문단 형식 등을 미리 저장해 둘 수 있다
  3. ③서식 파일은 한글(HWP)에서만 사용할 수 있다
  4. ④서식 파일은 문서의 내용만 저장하고 서식은 저장하지 않는다
14다음 중 각주(Footnote)에 대한 설명으로 옳은 것은? 매회
  1. ①각주는 문서의 마지막 페이지에만 표시된다
  2. ②각주는 해당 페이지 하단에 표시된다
  3. ③각주는 본문 내에 괄호로 표시된다
  4. ④각주 번호는 사용자가 수동으로만 지정해야 한다
15다음 중 개요(Outline) 기능에 대한 설명으로 옳지 않은 것은? 자주
  1. ①문서의 구조를 계층적으로 파악할 수 있다
  2. ②제목 수준에 따라 접기·펼치기가 가능하다
  3. ③개요 보기에서는 글자 서식을 변경할 수 없다
  4. ④문단의 수준을 올리거나 내릴 수 있다
16다음 중 우편 병합(Mail Merge)에 대한 설명으로 옳은 것은? 매회
  1. ①우편 병합은 이메일 전송에만 사용할 수 있다
  2. ②우편 병합은 같은 내용의 문서만 만들 수 있다
  3. ③데이터 파일의 각 레코드별로 서로 다른 내용의 문서를 생성할 수 있다
  4. ④우편 병합은 본문 파일 없이 데이터 파일만으로 실행할 수 있다
17다음 중 워드프로세서의 입력 방식에서 '삽입 모드'와 '수정(겹쳐쓰기) 모드'에 대한 설명으로 옳은 것은? 자주
  1. ①삽입 모드에서는 기존 글자가 지워지면서 새 글자가 입력된다
  2. ②수정 모드에서는 커서 위치에 글자가 끼워 넣어진다
  3. ③삽입 모드에서는 기존 글자를 밀어내면서 새 글자가 끼워 넣어진다
  4. ④두 모드는 전환할 수 없다
18다음 중 공문서에서 금액을 기재하는 방법으로 옳은 것은? 매회
  1. ①금50,000원
  2. ②금 오만원정
  3. ③금50,000원정
  4. ④\50,000
19다음 중 OLE(Object Linking and Embedding)에 대한 설명으로 옳지 않은 것은? 매회
  1. ①다른 응용 프로그램에서 작성한 개체를 문서에 삽입할 수 있다
  2. ②연결(Linking)은 원본 파일이 수정되면 삽입된 개체도 자동 갱신된다
  3. ③포함(Embedding)된 개체는 원본 파일과 독립적이다
  4. ④OLE는 텍스트만 삽입할 수 있다
20다음 중 조판 부호에 대한 설명으로 옳은 것은? 자주
  1. ①조판 부호는 항상 인쇄된다
  2. ②조판 부호는 삭제할 수 없다
  3. ③조판 부호를 표시하면 탭, 띄어쓰기 등 편집 기호를 확인할 수 있다
  4. ④조판 부호는 워드프로세서에서 지원하지 않는 기능이다
22과목: PC 운영체제Q21 – Q40
21다음 중 Windows의 바로 가기 아이콘에 대한 설명으로 옳은 것은? 매회
  1. ①바로 가기 아이콘을 삭제하면 원본 파일도 삭제된다
  2. ②바로 가기 아이콘은 원본 파일의 위치 정보를 가지고 있다
  3. ③바로 가기 아이콘의 확장자는 .exe이다
  4. ④바로 가기 아이콘은 바탕화면에서만 만들 수 있다
22다음 중 Windows 작업 관리자에서 할 수 없는 것은? 자주
  1. ①응답 없는 프로그램 강제 종료
  2. ②CPU 및 메모리 사용량 확인
  3. ③하드디스크 포맷
  4. ④실행 중인 프로세스 목록 확인
23다음 중 클립보드(Clipboard)에 대한 설명으로 옳지 않은 것은? 자주
  1. ①복사나 잘라내기를 하면 데이터가 클립보드에 저장된다
  2. ②클립보드의 내용은 컴퓨터를 끄면 사라진다
  3. ③클립보드에는 한 번에 하나의 데이터만 저장할 수 있다
  4. ④클립보드의 내용은 여러 번 붙여넣기 할 수 있다
24다음 중 Windows의 [제어판]에서 설정할 수 없는 항목은? 자주
  1. ①프린터 추가 및 제거
  2. ②프로그램 소스코드 편집
  3. ③사용자 계정 관리
  4. ④날짜 및 시간 설정
25다음 중 Windows의 휴지통에 대한 설명으로 옳지 않은 것은? 매회
  1. ①삭제한 파일을 복원할 수 있다
  2. ②휴지통의 크기는 사용자가 변경할 수 있다
  3. ③Shift + Delete로 삭제한 파일은 휴지통을 거치지 않는다
  4. ④USB 드라이브에서 삭제한 파일도 휴지통에 저장된다
26다음 중 Windows 탐색기에서 파일을 선택하는 방법으로 옳지 않은 것은? 자주
  1. ①Ctrl 키를 누른 채 클릭하면 비연속 파일을 선택할 수 있다
  2. ②Shift 키를 누른 채 클릭하면 연속된 파일을 범위 선택할 수 있다
  3. ③Ctrl + A를 누르면 모든 파일을 선택할 수 있다
  4. ④Alt 키를 누른 채 클릭하면 파일을 하나씩 추가 선택할 수 있다
27다음 중 Windows의 멀티태스킹에 대한 설명으로 옳은 것은? 매회
  1. ①여러 프로그램을 동시에 실행할 수 있다
  2. ②한 프로그램만 실행할 수 있다
  3. ③프로그램 전환이 불가능하다
  4. ④멀티태스킹은 DOS에서 처음 지원된 기능이다
28다음 중 Windows에서 [시스템 복원]에 대한 설명으로 옳은 것은? 자주
  1. ①삭제된 개인 파일(문서, 사진)을 복원할 수 있다
  2. ②시스템 복원 시 설치된 프로그램이 제거될 수 있다
  3. ③시스템 복원은 하드디스크를 포맷한 후에도 사용할 수 있다
  4. ④시스템 복원 지점은 자동으로 생성되지 않는다
29다음 중 드라이버(Driver)에 대한 설명으로 옳은 것은? 매회
  1. ①하드웨어를 운영체제가 인식하고 제어할 수 있도록 하는 소프트웨어이다
  2. ②드라이버는 하드웨어 장치 자체를 의미한다
  3. ③드라이버 없이도 모든 하드웨어를 사용할 수 있다
  4. ④드라이버는 한 번 설치하면 업데이트가 불필요하다
30다음 중 Windows의 레지스트리(Registry)에 대한 설명으로 옳지 않은 것은? 매회
  1. ①시스템 구성 정보를 저장하는 데이터베이스이다
  2. ②regedit 명령으로 편집할 수 있다
  3. ③잘못 수정하면 시스템에 심각한 오류가 발생할 수 있다
  4. ④레지스트리는 텍스트 파일 형태로 저장된다
31다음 중 디스크 조각 모음에 대한 설명으로 옳은 것은? 매회
  1. ①디스크의 바이러스를 제거하는 기능이다
  2. ②디스크 조각 모음을 하면 파일이 삭제될 수 있다
  3. ③분산 저장된 파일 조각을 연속된 공간으로 재배치하여 읽기 속도를 향상시킨다
  4. ④SSD에서 조각 모음을 자주 실행하면 수명이 늘어난다
32다음 중 FAT32와 NTFS 파일 시스템에 대한 설명으로 옳은 것은? 매회
  1. ①FAT32는 4GB 이상의 단일 파일을 저장할 수 있다
  2. ②NTFS는 파일 및 폴더에 대한 보안 권한 설정이 가능하다
  3. ③FAT32가 NTFS보다 보안 기능이 우수하다
  4. ④NTFS는 Windows에서만 읽을 수 있고 다른 OS에서는 사용 불가하다
33다음 중 안전 모드(Safe Mode)에 대한 설명으로 옳은 것은? 매회
  1. ①안전 모드에서는 네트워크에 접속할 수 없다
  2. ②안전 모드는 최소한의 드라이버와 서비스만으로 Windows를 시작한다
  3. ③안전 모드에서는 모든 프로그램을 정상적으로 사용할 수 있다
  4. ④안전 모드는 정상 부팅보다 성능이 우수하다
34다음 중 Windows의 가상 메모리에 대한 설명으로 옳은 것은? 매회
  1. ①하드디스크의 일부를 RAM처럼 사용하는 기술이다
  2. ②가상 메모리는 실제 RAM보다 속도가 빠르다
  3. ③가상 메모리를 사용하면 RAM이 필요 없다
  4. ④가상 메모리는 크기를 변경할 수 없다
35다음 중 Windows 방화벽에 대한 설명으로 옳은 것은? 자주
  1. ①바이러스를 검사하고 치료하는 프로그램이다
  2. ②네트워크를 통한 무단 접근을 차단하는 보안 기능이다
  3. ③파일을 암호화하여 보호하는 기능이다
  4. ④디스크 조각 모음을 자동으로 수행하는 기능이다
36다음 중 Windows 바탕화면의 작업 표시줄에 대한 설명으로 옳지 않은 것은? 자주
  1. ①실행 중인 프로그램의 아이콘이 표시된다
  2. ②작업 표시줄의 위치는 변경할 수 없다
  3. ③알림 영역(시스템 트레이)에서 시간, 네트워크 상태 등을 확인할 수 있다
