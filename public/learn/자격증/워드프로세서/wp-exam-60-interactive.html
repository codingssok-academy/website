  4. ④후결은 결재 과정을 거치지 않고 바로 발송하는 것이다.

  1. ①확대할 경우 계단 현상(깨짐)이 발생한다.
  2. ②Apple과 Microsoft가 공동으로 개발하였다.

  1. ①연결(Linking)은 원본 수정 시 삽입된 개체에 자동 반영된다.
  2. ②포함(Embedding) 시 원본이 수정되면 문서에도 반영된다.
  3. ③다른 프로그램에서 만든 개체를 문서에 삽입할 수 있다.
  4. ④연결 시 원본 파일이 삭제되면 개체를 볼 수 없다.
6다음 중 공문서의 작성에 관한 설명으로 옳지 않은 것은? 매회
  1. ①한글 맞춤법에 따라 가로로 작성한다.
  2. ②쉽고 간결하게 뜻이 정확히 전달되도록 작성한다.
  3. ③문서는 정보통신망을 이용하여 발신함이 원칙이다.
  4. ④한글 맞춤법에 따라 세로로 작성한다.
7다음 중 유니코드(Unicode)에 대한 설명으로 옳은 것은? 매회
  1. ①모든 문자를 2바이트(16비트)로 고정 표현한다.
  2. ②완성형 한글 11,172자를 표현할 수 있다.
  3. ③현대 한글만 표현 가능하고 옛한글은 지원하지 않는다.
  4. ④미국에서 영문 전용으로 개발된 코드이다.
8다음 중 한글 입력 방식에 대한 설명으로 옳은 것은? 자주
  1. ①3벌식이 현재 한국 표준 입력 방식이다.
  2. ②2벌식은 초성, 중성, 종성을 구분하여 입력한다.
  3. ③2벌식은 자음 14개와 모음 10개, 총 24개 키를 사용한다.
  4. ④2벌식은 공병우 박사가 개발하였다.
9다음 중 워드프로세서의 찾기 기능에 대한 설명으로 옳지 않은 것은? 자주
  1. ①와일드카드 문자(*, ?)를 사용할 수 있다.
  2. ②블록 지정하여 특정 영역만 검색할 수 있다.
  3. ③교정 부호나 메모의 내용을 지정하여 검색할 수 있다.
  4. ④글자 모양이나 스타일을 지정하여 검색할 수 있다.
10다음 중 각주와 미주에 대한 설명으로 옳지 않은 것은? 매회
  1. ①각주는 해당 페이지 하단에 설명을 표시한다.
  2. ②미주는 문서의 마지막 페이지에 모아서 표시한다.
  3. ③머리말에는 표를 입력할 수 없다.
  4. ④머리말/꼬리말은 짝수쪽·홀수쪽을 다르게 설정할 수 있다.
11다음 중 색인(Index)에 대한 설명으로 옳은 것은? 자주
  1. ①문서의 맨 앞에 위치한다.
  2. ②중요 용어를 내림차순으로 정리한다.
  3. ③중요 용어와 해당 쪽 번호를 오름차순으로 정리한다.
  4. ④장·절 제목과 쪽 번호를 정리한 것이다.
12다음 중 매크로(Macro)에 대한 설명으로 옳지 않은 것은? 자주
  1. ①반복 작업을 자동화하는 데 효과적이다.
  2. ②작성한 매크로는 별도 파일로 저장할 수 있다.
  3. ③마우스 동작을 포함한 모든 동작을 기억하는 것을 '키 매크로'라고 한다.
  4. ④매크로는 편집이 가능하다.
13다음 중 메일머지(Mail Merge)에 대한 설명으로 옳은 것은? 자주
  1. ①단일 문서를 한 사람에게만 발송하는 기능이다.
  2. ②데이터 파일 없이 서식 파일만으로 수행할 수 있다.
  3. ③데이터 파일과 서식 파일을 결합하여 개인화된 문서를 대량 생성한다.
  4. ④메일머지로 생성된 문서는 편집할 수 없다.
14다음 중 프린터 관련 용어에 대한 설명으로 옳지 않은 것은? 자주
  1. ①DPI는 1인치당 찍히는 점의 수로 해상도를 나타낸다.
  2. ②PPM은 1분당 출력 페이지 수로 인쇄 속도를 나타낸다.
  3. ③PPM은 해상도 단위이다.
  4. ④스풀링 사용 시 인쇄 중에도 다른 작업이 가능하다.
15다음 중 전자출판 용어에 대한 설명으로 옳지 않은 것은? 매회
  1. ①커닝(Kerning)은 글자와 글자 사이의 간격을 미세하게 조정하는 작업이다.
  2. ②디더링(Dithering)은 제한된 색상을 조합하여 새로운 색을 만드는 기법이다.
  3. ③필터링(Filtering)은 제한된 색상을 조합하여 중간색을 표현하는 작업이다.
  4. ④WYSIWYG는 화면 표시와 인쇄 결과가 동일한 것을 의미한다.
16다음 중 텍스트 표시 기능에 대한 설명으로 옳지 않은 것은? 자주
  1. ①자간은 글자와 글자 사이의 가로 간격이다.
  2. ②행간은 줄과 줄 사이의 세로 간격이다.
  3. ③장평은 글자의 세로 높이 비율이다.
  4. ④1포인트는 1/72인치이다.
17다음 중 DRM(Digital Rights Management)에 대한 설명으로 옳은 것은? 자주
  1. ①디지털 문서의 빠른 검색을 돕는 기술이다.
  2. ②디지털 콘텐츠의 불법 복제를 방지하고 사용 권한을 통제하는 기술이다.
  3. ③문서를 가운데로 정렬하는 기능이다.
  4. ④하이퍼텍스트를 관리하는 시스템이다.
18다음 중 파일링(Filing) 시스템의 도입 효과로 옳지 않은 것은? 자주
  1. ①문서 관리의 명확화
  2. ②정보 전달의 원활화
  3. ③사무 공간의 효율적 활용
  4. ④기록 활용 비용 증가
19다음 중 전자문서에 대한 설명으로 옳지 않은 것은? 자주
  1. ①컴퓨터로 전자적 형태로 작성·송수신·저장된 문서이다.
  2. ②전자문서의 효력은 수신자의 전자시스템에 입력되었을 때 발생한다.
  3. ③전자문서는 공람 기록을 수동으로 표시해야 한다.
  4. ④기안은 전자문서로 하는 것이 원칙이다.
20다음 중 문서의 논리 전개 방식에 대한 설명으로 옳지 않은 것은? 자주
  1. ①두괄식은 결론을 처음에 제시한다.
  2. ②미괄식은 결론을 끝에 제시한다.
  3. ③양괄식은 처음과 끝 모두에 결론을 제시한다.
  4. ④두괄식은 결론을 마지막에 제시한다.

  3. ③네트워크 드라이브의 파일을 삭제하면 휴지통으로 이동한다.
  4. ④휴지통에서 특정 파일만 선택하여 삭제할 수 있다.
22다음 중 Windows 고급 부팅 옵션에 대한 설명으로 옳은 것은? 자주
  1. ①안전 모드는 네트워크 서비스를 포함하여 부팅한다.
  2. ②부팅 로깅은 부팅 과정을 ntbtlog.txt에 기록하는 모드이다.
  3. ③저해상도 비디오 모드는 1024×768로 부팅한다.
  4. ④최대 절전 모드는 RAM에 현재 상태를 저장한다.
23다음 중 Windows 에어로(Aero) 기능에 대한 설명으로 옳지 않은 것은? 매회
  1. ①에어로 스냅은 창을 화면 가장자리로 드래그 시 크기가 자동 조정된다.
  2. ②에어로 피크는 작업표시줄 아이콘을 가리키면 썸네일 미리보기를 제공한다.
  3. ③에어로 셰이크는 창을 흔들면 다른 모든 창이 최소화된다.
  4. ④에어로 전환 3D는 점프 목록과 프로그램 단추 고정 기능이다.
24다음 중 Windows 작업 표시줄에 대한 설명으로 옳지 않은 것은? 자주
  1. ①현재 실행 중인 프로그램 단추가 표시된다.
  2. ②위치를 화면의 위/아래/왼쪽/오른쪽으로 변경할 수 있다.
  3. ③크기는 화면의 1/4까지만 늘릴 수 있다.
  4. ④잠금 설정 시 크기와 위치 변경이 불가하다.
25다음 중 파일 시스템에 대한 설명으로 옳지 않은 것은? 매회
  1. ①FAT32의 최대 단일 파일 크기는 4GB이다.
  2. ②NTFS는 파일별 접근 권한 설정이 가능하다.
  3. ③FAT32에서 파일별 접근 권한을 설정할 수 있다.
  4. ④NTFS는 파일 암호화(EFS)를 지원한다.
26다음 중 Windows 시스템 복원에 대한 설명으로 옳지 않은 것은? 자주
  1. ①시스템을 과거 복원 지점 상태로 되돌린다.
  2. ②시스템 파일, 레지스트리, 드라이버가 복원된다.
  3. ③개인 파일(문서·사진·음악)도 함께 삭제된다.
  4. ④복원 지점은 자동 또는 수동으로 생성할 수 있다.
27다음 중 Windows 레지스트리에 대한 설명으로 옳지 않은 것은? 자주
  1. ①시스템 설정을 저장하는 계층형 데이터베이스이다.
  2. ②편집 도구는 regedit(레지스트리 편집기)이다.
  3. ③잘못 수정 시 시스템 불안정이 발생할 수 있다.
  4. ④텍스트 편집기(메모장)로 수정한다.
28다음 중 UAC(사용자 계정 컨트롤)에 대한 설명으로 옳지 않은 것은? 자주
  1. ①프로그램 설치나 시스템 변경 시 관리자 권한을 확인한다.
  2. ②악성 소프트웨어의 자동 실행을 방지한다.
  3. ③UAC를 끄면 보안이 강화된다.
  4. ④관리자 권한 확인 팝업이 표시된다.
29다음 중 디스크 관리에 대한 설명으로 옳지 않은 것은? 자주
  1. ①디스크 조각 모음은 파일 조각을 한 곳에 모아 읽기 속도를 향상시킨다.
  2. ②디스크 정리는 임시 파일 등 불필요한 파일을 삭제한다.
  3. ③디스크 조각 모음은 파일을 삭제하는 기능이다.
  4. ④chkdsk는 파일 시스템 오류를 검사하고 복구한다.
30다음 중 Windows 메모장(Notepad)에 대한 설명으로 옳지 않은 것은? 자주
  1. ①순수 텍스트(.txt) 파일을 편집한다.
  2. ②저장 시 글꼴 색상과 크기가 유지된다.
  3. ③글자 수 제한이 없다.
  4. ④인코딩(UTF-8, ANSI 등)을 선택하여 저장할 수 있다.
31다음 중 Windows 파일 공유에 대한 설명으로 옳지 않은 것은? 자주
  1. ①공유 폴더는 읽기 전용 또는 읽기·쓰기 권한을 설정할 수 있다.
  2. ②공유 이름은 폴더 이름과 다르게 설정할 수 있다.
  3. ③공유 이름 끝에 $를 붙이면 숨김 공유가 된다.
  4. ④공유 폴더는 읽기만 가능하다.
32다음 중 네트워크 설정에 대한 설명으로 옳은 것은? 자주
  1. ①ipconfig는 연결 테스트 명령어이다.
  2. ②ping은 IP 주소를 확인하는 명령어이다.
  3. ③DHCP는 라우터가 자동으로 IP를 할당하는 방식이다.
  4. ④tracert는 IP 주소를 확인하는 명령어이다.
33다음 중 Windows 방화벽에 대한 설명으로 옳지 않은 것은? 자주
  1. ①외부 네트워크 침입을 차단한다.
  2. ②특정 포트나 프로그램에 대한 예외 설정이 가능하다.
  3. ③방화벽을 켜면 모든 인터넷 연결이 차단된다.
  4. ④켜면 보안이 강화되고, 끄면 위험해진다.
34다음 중 Windows 바탕화면 우클릭 메뉴에서 할 수 없는 것은? 자주
  1. ①새 폴더를 만들 수 있다.
  2. ②아이콘을 표시하거나 숨길 수 있다.
