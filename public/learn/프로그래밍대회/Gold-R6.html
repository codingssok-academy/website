문제 설명
N개의 정점과 M개의 간선이 주어집니다.
간선에는 가중치가 있습니다.
다음 세 가지 연산을 처리합니다:
1) link u v w : 정점 u와 v를 가중치 w인 간선으로 연결합니다.
2) cut u v : 정점 u와 v 사이의 간선을 제거합니다.
3) query u v : 정점 u에서 v까지 경로 상 간선 가중치의 최댓값을 출력합니다.
간선의 동적 추가/삭제가 있으므로 Link-Cut 트리를 사용합니다.

Link-Cut 트리 핵심 원리
Link-Cut 트리는 Splay 트리들의 포레스트입니다.
각 preferred path를 하나의 Splay 트리로 관리합니다.
access(v): 루트에서 v까지의 경로를 하나의 preferred path로 만듭니다.
makeRoot(v): v를 전체 트리의 루트로 만듭니다 (Splay 뒤집기 활용).
link(u, v): makeRoot(u) 후 u의 부모를 v로 설정합니다.
cut(u, v): makeRoot(u), access(v) 후 연결을 끊습니다.
간선 가중치를 다루기 위해 간선을 가상 노드로 변환합니다.

문제 설명
길이 N인 배열 A가 주어집니다.
다음 연산을 처리합니다:
1) chmin l r v : A[i] = min(A[i], v) for i in [l, r]
2) sum l r : 구간 [l, r]의 합을 출력합니다.
일반 Lazy Propagation으로는 chmin을 처리할 수 없습니다.
Ji Driver Segment Tree (Segment Beats)를 사용합니다.

핵심 아이디어 (Segment Beats)
각 노드에 다음 정보를 유지합니다:
• mx: 구간 최댓값
• cnt: 최댓값의 등장 횟수
• mx2: 두 번째 최댓값 (strictly less than mx)
• sum: 구간 합

chmin(v) 갱신 시 세 가지 경우:
1) v ≥ mx → 아무 변화 없음, 종료
2) mx2 < v < mx → sum에서 (mx - v) × cnt를 빼고, mx = v로 갱신

웨이블릿 트리 실전 — 구간 rank, select, K번째
Wavelet Tree구간 rank구간 K번째GOLD

개념 설명
웨이블릿 트리(Wavelet Tree)는 문자열/수열에 대한 다양한 쿼리를 O(log σ) 시간에 처리하는 자료구조입니다.
σ는 알파벳(값의 범위) 크기입니다.
각 내부 노드는 값의 범위를 이분합니다.
왼쪽 자식: 값이 mid 이하인 원소들
오른쪽 자식: 값이 mid 초과인 원소들
각 노드에서 비트 벡터를 유지하여 원소가 왼쪽/오른쪽 중 어디로 갔는지 기록합니다.

지원하는 연산
• rank(l, r, v): 구간 [l, r]에서 값 v의 등장 횟수
• select(l, r, v, k): 구간 [l, r]에서 값 v의 k번째 등장 위치
• kth(l, r, k): 구간 [l, r]에서 k번째로 작은 값
• count(l, r, a, b): 구간 [l, r]에서 값이 [a, b]인 원소의 개수
모든 연산이 O(log σ)입니다.

#include <stdio.h> #include <string.h> #define MAXN 200005 #define MAXLOG 20 int n, q; int a[MAXN]; /* 각 레벨에서의 비트 벡터와 매핑 */ int bv[MAXLOG][MAXN]; /* bv[d][i] = i번째 원소가 왼쪽(0)인지 오른쪽(1)인지 */ int pref[MAXLOG][MAXN]; /* 접두사 합: 왼쪽으로 간 개수 */ int arr[MAXLOG][MAXN]; /* 각 레벨의 배열 */ int lo_range[MAXLOG], hi_range[MAXLOG]; /* 각 노드의 값 범위 */ void buildWT(int d, int lo, int hi, int from, int to) { if (lo == hi || from >= to) return; int mid = (lo + hi) / 2; int leftArr[MAXN], rightArr[MAXN]; int lCnt = 0, rCnt = 0; int cumLeft = 0; for (int i = from; i < to; i++) { if (arr[d][i] <= mid) { bv[d][i] = 0; leftArr[lCnt++] = arr[d][i]; cumLeft++; } else { bv[d][i] = 1; rightArr[rCnt++] = arr[d][i]; } pref[d][i+1] = cumLeft; /* pref[d][i+1] = 구간 [from, i]에서 왼쪽 개수 */ } for (int i = 0; i < lCnt; i++) arr[d+1][from + i] = leftArr[i]; for (int i = 0; i < rCnt; i++) arr[d+1][from + lCnt + i] = rightArr[i]; buildWT(d+1, lo, mid, from, from + lCnt); buildWT(d+1, mid+1, hi, from + lCnt, to); } /* 구간 [l, r)에서 k번째 (1-indexed) 작은 수 */ int kthSmallest(int d, int lo, int hi, int from, int to, int l, int r, int k) { if (lo == hi) return lo; int mid = (lo + hi) / 2; int lb = pref[d][l] - pref[d][from]; /* [from, l)에서 왼쪽 간 수 */ int leftInRange = pref[d][r] - pref[d][l]; /* [l, r)에서 왼쪽 간 수 */ int lCnt = pref[d][to] - pref[d][from]; /* 전체에서 왼쪽 간 수 */ if (k <= leftInRange) return kthSmallest(d+1, lo, mid, from, from + lCnt, from + lb, from + lb + leftInRange, k); else return kthSmallest(d+1, mid+1, hi, from + lCnt, to, from + lCnt + (l - from - lb), from + lCnt + (r - from - (pref[d][r] - pref[d][from])), k - leftInRange); } int main(void) { scanf("%d %d", &n, &q); for (int i = 0; i < n; i++) { scanf("%d", &a[i]); arr[0][i] = a[i]; } memset(pref, 0, sizeof(pref)); buildWT(0, 0, n - 1, 0, n); while (q--) { int l, r, k; scanf("%d %d %d", &l, &r, &k); l--; /* 0-indexed */ printf("%d\n", kthSmallest(0, 0, n - 1, 0, n, l, r, k)); } return 0; }

동적 볼록 껍질 — Li Chao 트리와 시간 분할
Li Chao TreeConvex Hull Trick시간 분할GOLD

개념 설명
볼록 껍질 트릭(CHT)은 직선 y = ax + b를 삽입하고,
주어진 x에서 최솟값(또는 최댓값)을 구하는 자료구조입니다.
Li Chao 트리는 세그먼트 트리 기반으로 이를 구현합니다.
삽입: O(log C), 쿼리: O(log C) (C = x 좌표 범위)

문제: Li Chao 트리는 삭제를 지원하지 않습니다.
삭제가 필요하면 "시간 분할 정복 (Segment Tree on Time)" 기법을 사용합니다.
각 직선이 활성인 시간 구간 [t_add, t_del)을 세그먼트 트리에 매핑합니다.

Li Chao 트리 구현 원리
• 각 노드는 하나의 직선을 "우세한 직선"으로 저장합니다.
• 새 직선 삽입 시 현재 노드의 구간 중점에서 비교합니다.
• 중점에서 더 좋은 직선이 현재 노드에 남고,
• 밀려난 직선은 자식 중 유리한 쪽으로 재귀적으로 내려갑니다.
• 쿼리 시 루트에서 리프까지 내려가며 최적값을 갱신합니다.

Kinetic Heaps — 시간에 따라 변하는 우선순위
Kinetic Heap이벤트 기반우선순위 큐GOLD

개념 설명
Kinetic Heap은 각 원소의 우선순위(값)가 시간 t의 함수 f_i(t) = a_i · t + b_i로 변할 때,
최댓값(또는 최솟값)을 효율적으로 추적하는 자료구조입니다.
일반 힙에서는 값이 변하면 전체를 재구성해야 하지만,
Kinetic Heap은 "인접한 원소의 순서가 바뀌는 시점"을 이벤트로 예약합니다.

동작 원리
1) 초기에 현재 시간 t=0에서의 값으로 힙을 구성합니다.
2) 힙에서 부모-자식 쌍 (i, j)에 대해, f_i(t) < f_j(t)가 되는 시점을 계산합니다.
3) 이 "역전 시점"을 이벤트 큐(priority queue)에 넣습니다.
4) 시간이 흐르면 가장 이른 이벤트를 꺼내, 해당 쌍을 swap하고,
5) 새로운 인접 쌍에 대해 이벤트를 다시 계산합니다.

이벤트 수: O(n^2)개 (worst case)지만,
각 이벤트 처리: O(log n)
실제로는 역전 횟수가 훨씬 적어 효율적입니다.

NP-Hard 문제는 다항 시간에 최적해를 구할 수 없지만(P ≠ NP 가정),
근사 알고리즘으로 최적해에 가까운 해를 보장할 수 있습니다.
근사 비율(approximation ratio) α: 알고리즘 해 / 최적해 ≤ α

1. MAX-SAT 근사
• 문제: m개의 절(clause)을 가진 CNF에서 만족되는 절의 수를 최대화
• 랜덤 할당: 각 변수를 독립적으로 1/2 확률로 True/False
• 기대 만족 절 수 ≥ m/2 (각 절이 최소 하나의 리터럴 포함)
• k개 리터럴인 절이 만족될 확률: 1 - (1/2)^k ≥ 1/2
• 따라서 2-근사 알고리즘

2. Set Cover 로그 근사
• 문제: 전체집합 U를 부분집합들의 합집합으로 덮되, 선택 수 최소화
• 그리디: 매번 가장 많은 미커버 원소를 덮는 집합 선택
• 근사 비율: H(n) = ln(n) + 1 (조화급수)
• 이것이 최선: ln(n) 미만 근사는 P ≠ NP 하에서 불가능

3. k-Center 2-근사
• 문제: n개 점에서 k개 센터를 선택, 최대 거리 최소화
• 그리디: 가장 먼 점을 순서대로 센터로 선택
• 근사 비율: 2
• 2 미만 근사는 P ≠ NP 하에서 불가능

개요
스트리밍 알고리즘은 데이터를 한 번(또는 소수 번) 순회하며,
제한된 메모리로 통계를 추정하는 알고리즘입니다.
정확한 답 대신 확률적 근사값을 제공합니다.

1. Count-Min Sketch
• 목적: 원소의 빈도(frequency) 추정
• 구조: d개의 해시 함수, 각각 w개의 카운터 배열 (d × w 행렬)
• 삽입(x): 각 해시 함수 h_i(x)에 해당하는 카운터를 +1
• 쿼리(x): min(counter[i][h_i(x)]) for all i
• 특성: 빈도를 과대추정할 수 있지만, 과소추정은 절대 없음
• 오차: εN 이내 (확률 1 - δ), w = e/ε, d = ln(1/δ)

• 목적: 고유 원소 수(cardinality) 추정

I/O 복잡도 모델
외부 메모리 모델에서는 메인 메모리 크기 M과 블록 크기 B가 주어집니다.
디스크에서 블록 단위로 읽고 쓰며, I/O 횟수를 최소화합니다.
• N개 원소 스캔: O(N/B) I/O
• N개 원소 정렬: O((N/B) log_{M/B} (N/B)) I/O
• N개 원소 탐색(B-트리): O(log_B N) I/O

B-트리
각 노드가 최대 B개의 키를 저장합니다.
높이 O(log_B N)이므로 탐색 시 O(log_B N) I/O면 충분합니다.
내부 노드의 분기 수(branching factor)가 B이므로 디스크 접근이 최소화됩니다.
삽입/삭제도 O(log_B N) I/O입니다.

외부 정렬 (External Merge Sort)
1) 메모리에 M개씩 읽어 정렬 → N/M개의 정렬된 런(run) 생성
2) M/B-way merge: 한 번에 M/B개의 런을 합병
3) 총 패스 수: O(log_{M/B} (N/M))
4) 총 I/O: O((N/B) log_{M/B} (N/M))

병렬 알고리즘 개념 — PRAM과 Work/Span

PRAM 모델
Parallel Random Access Machine: p개의 프로세서가 공유 메모리에 동시 접근합니다.
• EREW (Exclusive Read Exclusive Write): 동시 접근 불허
• CREW (Concurrent Read Exclusive Write): 동시 읽기 허용
• CRCW (Concurrent Read Concurrent Write): 동시 읽기/쓰기 허용

Work/Span 분석
• Work W(n): 총 연산 수 (순차 실행 시간과 같음)
• Span S(n): 최장 의존 경로 (무한 프로세서 가정 시 실행 시간)
• 병렬도(parallelism): W(n) / S(n)
• p개 프로세서에서의 시간: T_p = O(W/p + S)

병렬 접두사 합 (Parallel Prefix Sum)
순차: O(n). 병렬: Work = O(n), Span = O(log n)
두 단계로 구성됩니다:
1) Up-sweep (reduce): 트리 형태로 부분합 계산
2) Down-sweep: 루트에서 리프로 전파하며 접두사 합 완성

#include <stdio.h> #define MAXN 16 /* 병렬 접두사 합 시뮬레이션 (순차로 구현) */ void parallelPrefixSum(int *a, int n) { /* Up-sweep */ for (int stride = 1; stride < n; stride *= 2) { for (int i = 2 * stride - 1; i < n; i += 2 * stride) { a[i] += a[i - stride]; } } /* a[n-1]에 전체 합이 저장됨 */ /* Down-sweep */ a[n - 1] = 0; /* exclusive prefix sum */ for (int stride = n / 2; stride >= 1; stride /= 2) { for (int i = 2 * stride - 1; i < n; i += 2 * stride) { int t = a[i - stride]; a[i - stride] = a[i]; a[i] += t; } } } int main(void) { int a[8] = {3, 1, 7, 0, 4, 1, 6, 3}; int n = 8; printf("Input: "); for (int i = 0; i < n; i++) printf("%d ", a[i]); printf("\n"); parallelPrefixSum(a, n); printf("Prefix: "); for (int i = 0; i < n; i++) printf("%d ", a[i]); printf("\n"); return 0; }

양자 알고리즘 개념 — Shor & Grover

양자 컴퓨팅 기초
• 큐비트(qubit): 0과 1의 중첩(superposition) 상태
• 양자 게이트: 유니터리 변환으로 큐비트 상태를 변화
• 측정: 확률적으로 0 또는 1이 관측됨
• 양자 병렬성: n 큐비트로 2^n 상태를 동시에 연산

Shor's Algorithm (소인수분해)
• 고전 최선: O(exp(n^{1/3})) (수체 체로)
• Shor: O(n^2 log n log log n) — 다항 시간!
• 핵심: 양자 푸리에 변환(QFT)으로 주기(order) 찾기
• RSA 암호 체계에 위협 → 포스트 양자 암호 연구 동기

Grover's Algorithm (비정렬 탐색)
• 고전: O(N) (선형 탐색)
• Grover: O(√N)
• 핵심: 진폭 증폭(amplitude amplification)
• 오라클: f(x)=1인 x를 찾는 블랙박스
• 반복: √N번의 Grover 반복으로 성공 확률 극대화
• 하한: 양자 컴퓨터에서도 Ω(√N) 쿼리 필요 (BBBV 정리)

선형 계획법 (Linear Programming)
선형 목적함수를 선형 부등식 제약 하에 최대화(또는 최소화)하는 문제입니다.
표준형: maximize c^T x, subject to Ax ≤ b, x ≥ 0
• 다항 시간 알고리즘: 타원체법(Ellipsoid), 내점법(Interior Point)
• 실용적 알고리즘: 심플렉스법 (최악 지수이나 평균적으로 매우 빠름)

심플렉스법 개요
1) 가능해(feasible solution)에서 시작합니다.
2) 인접한 꼭짓점 중 목적함수가 개선되는 쪽으로 이동합니다.
3) 더 이상 개선 불가능하면 최적해입니다.
피벗 선택: Bland's rule로 순환(cycling)을 방지합니다.

LP 쌍대성 (Duality)
모든 LP에는 쌍대 문제(dual problem)가 있습니다.
원문제(primal): max c^T x, Ax ≤ b, x ≥ 0
쌍대문제(dual): min b^T y, A^T y ≥ c, y ≥ 0

강쌍대성 정리: 원문제 최적값 = 쌍대문제 최적값
대회 활용: LP 쌍대로 최소 컷 = 최대 플로우 증명, 그리디 정당성 논증

마트로이드 정의
마트로이드 M = (E, I)는 유한 집합 E와 독립 집합의 모임 I로 구성됩니다.
세 가지 공리를 만족합니다:
1) 공집합은 독립: ∅ ∈ I
2) 유전성(hereditary): A ∈ I이고 B ⊆ A이면 B ∈ I
3) 교환 공리(exchange): A, B ∈ I이고 |A| < |B|이면,
∃ x ∈ B \ A such that A ∪ {x} ∈ I

마트로이드의 예
• 균일 마트로이드: I = {S ⊆ E : |S| ≤ k}
• 그래프 마트로이드: E = 간선 집합, I = 포레스트(순환 없는 부분그래프)
• 선형 마트로이드: E = 벡터 집합, I = 선형 독립 부분집합
• 분할 마트로이드: 원소들이 그룹으로 나뉘고, 각 그룹에서 최대 1개 선택

그리디 최적성 정리
가중 마트로이드에서 최대(최소) 가중 독립 집합을 구하는 그리디 알고리즘은 항상 최적입니다.
이것이 Kruskal's MST 알고리즘의 정당성을 보장합니다.
(그래프 마트로이드에서 최소 가중 극대 독립 집합 = MST)

가중 마트로이드 교차 (Matroid Intersection)
두 마트로이드의 교차에서 최대 독립 집합을 구하는 문제입니다.
다항 시간에 풀 수 있습니다 (O(r^2 n) 또는 더 빠른 알고리즘).
