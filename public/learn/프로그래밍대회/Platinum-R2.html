SECTION 828Platinum | 고급 문자열
Palindromic Tree — Eertree 입문
EertreePalindromeString DSPLATINUM

왜 필요한가
회문 부분 문자열을 모두 다루는 문제에서는 Manacher 하나로 끝나지 않는 경우가 많습니다.
Eertree는 각 서로 다른 회문 부분 문자열을 상태로 관리하며, 등장 횟수와 전이 구조를 함께 다룹니다.

노드 의미설명

TIP문제가 "서로 다른 회문"을 묻거나 회문 빈도 통계를 요구하면 Eertree 가능성을 먼저 봐야 합니다.

SECTION 829Platinum | 고급 문자열
Rolling Hash 심화 — LCP와 구간 비교
HashLCPSubstring ComparePLATINUM

활용 포인트
해시는 단순 동일성 확인뿐 아니라, 이분 탐색과 결합해 두 부분 문자열의 LCP를 구하거나 사전순 비교를 가속하는 데 사용됩니다.
Platinum에서는 세그먼트 트리, 이진 검색과 결합된 해시가 자주 등장합니다.

Chash_lcp.c
int lcp(int a, int b, int limit) { int lo = 0, hi = limit; while (lo < hi) { int mid = (lo + hi + 1) >> 1; if (get_hash(a, a + mid - 1) == get_hash(b, b + mid - 1)) lo = mid; else hi = mid - 1; } return lo; }
주의충돌 확률을 낮추기 위해 보통 64비트 또는 이중 모듈러를 씁니다. 동적 문자열에서는 역방향 해시도 함께 준비해야 합니다.

SECTION 838Platinum | 고급 수학·기하
NTT 실전 — 다항식 곱셈 구현
NTTPolynomialConvolutionPLATINUM

Platinum 관점
Gold에서는 NTT의 쓰임새를 이해하는 수준이었다면, 이제는 실제 구현과 bit reversal, primitive root 관리까지 다뤄야 합니다.
길이를 2의 거듭제곱으로 맞추고, 전방/역방 변환을 정확히 구현하는 것이 핵심입니다.

Cntt_core.c
for (int len = 2; len <= n; len <<= 1) { long long wlen = mod_pow(ROOT, (MOD - 1) / len); if (invert) wlen = mod_inv(wlen); for (int i = 0; i < n; i += len) { long long w = 1; for (int j = 0; j < len / 2; j++) { long long u = a[i + j], v = a[i + j + len / 2] * w % MOD; a[i + j] = (u + v) % MOD; a[i + j + len / 2] = (u - v + MOD) % MOD; w = w * wlen % MOD; } } }
