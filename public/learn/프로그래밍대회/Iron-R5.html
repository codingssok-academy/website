SECTION 101Iron | 동적 메모리
malloc — 실행 중에 메모리 할당
mallocstdlib.hheapIron

malloc(size)은 힙(heap) 메모리에서 size 바이트를 할당하고 시작 주소를 반환합니다. 배열 크기를 실행 중에 결정할 수 있습니다.

C개념 코드
#include <stdlib.h> int n; scanf("%d", &n); // n개짜리 int 배열을 동적 할당 int *arr = (int*)malloc(n * sizeof(int)); if (arr == NULL) { printf("Memory allocation failed!\n"); return 1; } // 사용 for (int i = 0; i < n; i++) arr[i] = i * 10; // 반드시 해제! free(arr);
구분스택(지역 변수)힙(malloc)
크기 결정컴파일 시실행 시
해제함수 끝나면 자동free() 직접 호출
크기 제한작음 (~1MB)큼 (수 GB)
free 필수!malloc으로 할당한 메모리는 free로 반환해야 합니다. 안 하면 메모리 누수(memory leak)가 발생합니다.

SECTION 102Iron | 동적 메모리
calloc — 0으로 초기화된 할당
calloc초기화Iron

calloc(count, size)은 count개의 원소를 size 바이트씩 할당하고 모두 0으로 초기화합니다. malloc과 달리 쓰레기 값이 없습니다.

C개념 코드
// malloc: 초기화 안 됨 int *a = (int*)malloc(n * sizeof(int)); // calloc: 0으로 초기화됨 int *b = (int*)calloc(n, sizeof(int)); // b[0] == b[1] == ... == 0 보장
대회에서의 활용빈도 배열, 카운팅 배열 등 0으로 시작해야 하는 경우 calloc이 편리합니다.

등장한 수만 출력한다.

SECTION 103Iron | 동적 메모리
realloc — 크기 변경
realloc확장Iron

realloc(ptr, new_size)은 이미 할당된 메모리의 크기를 변경합니다. 기존 데이터는 보존됩니다.

C개념 코드
int *arr = (int*)malloc(3 * sizeof(int)); arr[0] = 10; arr[1] = 20; arr[2] = 30; // 5개로 확장 (기존 10,20,30 보존) arr = (int*)realloc(arr, 5 * sizeof(int)); arr[3] = 40; arr[4] = 50; free(arr);
realloc 주의realloc이 실패하면 NULL을 반환하고 원본은 유지됩니다. arr = realloc(arr, ...)처럼 직접 대입하면 원본 주소를 잃을 수 있으니, 임시 변수로 받는 것이 안전합니다.

SECTION 105Iron | 동적 메모리
동적 2차원 배열
malloc2D array이중 포인터Iron

2차원 배열도 동적으로 할당할 수 있습니다. 포인터의 배열(이중 포인터)을 사용합니다.

C개념 코드
// R x C 동적 2차원 배열 int **mat = (int**)malloc(R * sizeof(int*)); for (int i = 0; i < R; i++) mat[i] = (int*)calloc(C, sizeof(int)); // 사용: mat[i][j] 로 접근 mat[0][1] = 42; // 해제: 역순으로! for (int i = 0; i < R; i++) free(mat[i]); free(mat);
해제 순서각 행(mat[i])을 먼저 해제하고, 마지막에 행 포인터 배열(mat)을 해제해야 합니다. 순서가 반대면 행 주소를 잃어 메모리 누수가 됩니다.

fgetcfputcEOFIron

// 파일 복사 (문자 단위) FILE *src = fopen("in.txt", "r"); FILE *dst = fopen("out.txt", "w"); int ch; while ((ch = fgetc(src)) != EOF) fputc(ch, dst); fclose(src); fclose(dst);
int로 받기fgetc의 반환형은 int입니다. char로 받으면 EOF와 일반 문자를 구분할 수 없습니다.
