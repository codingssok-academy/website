그래프 표현 — 인접 행렬 vs 리스트
graphadjacency기초Bronze

그래프는 정점(V)과 간선(E)의 집합입니다. 두 가지 표현 방법이 있습니다.

C인접 행렬
int adj[1001][1001]; // O(V²) 공간 // 간선 (u, v) 추가 adj[u][v] = 1; adj[v][u] = 1; // 무방향
C인접 리스트 (배열)
#define MAXV 100001 #define MAXE 200002 int head[MAXV], to[MAXE], nxt[MAXE], ecnt = 0; void add_edge(int u, int v) { to[ecnt] = v; nxt[ecnt] = head[u]; head[u] = ecnt++; to[ecnt] = u; nxt[ecnt] = head[v]; head[v] = ecnt++; } // head[u] 초기값 = -1 // 순회: for(int e=head[u]; e!=-1; e=nxt[e]) { int v=to[e]; }

V ≤ 100000: 반드시 인접 리스트 (행렬은 메모리 초과)
