SECTION 26Iron | 제어문
switch-case 기초 — 메뉴 선택
switchcasebreakIron

switch문은 하나의 값에 따라 여러 갈래로 분기할 때 사용합니다. if-else if 체인보다 깔끔합니다.

C개념 코드
switch (menu) { case 1: printf("Start\n"); break; case 2: printf("Load\n"); break; case 3: printf("Exit\n"); break; default: printf("Invalid\n"); }
break를 빼먹으면?break가 없으면 다음 case로 "떨어집니다"(fall-through). 의도하지 않은 경우 반드시 break를 넣으세요.

SECTION 34Iron | 배열
1차원 배열 — 선언과 순회
배열for인덱스Iron

배열은 같은 타입의 데이터를 연속으로 저장하는 자료구조입니다. 인덱스는 0부터 시작합니다.

C개념 코드

SECTION 43Iron | 문자열

char[]널 종단strlenIron

C에서 문자열은 char 배열에 저장되며, 끝에 '\0'(널 문자)이 자동으로 붙습니다.

C개념 코드

scanf %s의 한계%s는 공백에서 끊깁니다. "Hello World"를 입력하면 "Hello"만 들어갑니다. 공백 포함 입력은 나중에 fgets를 배웁니다.
