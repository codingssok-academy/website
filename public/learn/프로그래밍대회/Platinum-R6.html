Parallel Binary Search

적용 신호

Persistent Trie
PersistentTrieXOR QueryPLATINUM

대표 용도
배열 prefix마다 버전을 만들면 구간 [l, r]에 대한 XOR 최대값, k번째 수, 개수 질의 등을 두 버전 차이로 처리할 수 있습니다.

struct Node { int child[2]; int cnt; };
주의버전 차이 질의에서는 항상 root[r] - root[l-1]의 의미를 유지해야 합니다. 카운트 비교 방향이 뒤바뀌면 최대 XOR과 k번째 값이 동시에 틀립니다.

SECTION 938Platinum | 고급 그래프 2
Johnson Reweighting
Shortest PathJohnsonPotentialPLATINUM

핵심 아이디어
음수 간선은 있지만 음수 사이클은 없을 때, 잠재치 h(v)를 이용해 모든 간선 가중치를 음수 아닌 값으로 다시 쓸 수 있습니다.
이후 여러 시작점 최단거리는 다익스트라로 처리하고, 마지막에 잠재치를 되돌려 원래 거리를 복원합니다.

TEXTformula
w'(u, v) = w(u, v) + h(u) - h(v) dist_original(s, t) = dist_prime(s, t) - h(s) + h(t)
직관잠재치는 간선마다 같은 값을 더하는 것이 아니라, 경로 전체 순서를 보존하도록 “출발 정점 보너스, 도착 정점 패널티”를 배분하는 장치입니다.

SECTION 941Platinum | 고급 그래프 2
Minimum Cycle Basis 개요
Cycle BasisLinear AlgebraGraphPLATINUM

개념 연결
그래프의 cycle space를 GF(2) 위 벡터 공간으로 보면, 각 사이클은 간선 집합의 XOR로 해석됩니다.
Minimum cycle basis는 이 공간을 생성하는 독립 사이클들 중 총 가중치가 최소인 집합을 찾는 문제로, 그래프와 선형대수가 직접 만나는 대표 주제입니다.

학습 목표이 라운드에서는 구현 자체보다 “사이클 독립성”을 선형 독립성으로 보는 관점을 익히는 데 목적이 있습니다.

대회 구현보다는 고급 그래프 이론 문제에서 “원본 전체를 다 보지 않고도 중요한 절단 구조를 보존할 수 있다”는 사고를 익히는 데 의미가 있습니다.

학습 포인트이 주제는 완전 구현형보다 아이디어 판별형 문제에 더 자주 나타납니다. “정확 계산이 아니라 구조 보존”이라는 문장이 보이면 이 계열을 떠올리면 됩니다.
