SECTION 526Silver | 대회 실전 I — KOI 본선급
[KOI] 보석 도둑 — 그리디 + 멀티셋
그리디멀티셋정렬Silver

[문제] N개의 보석이 있고, 각 보석은 무게 Mi와 가치 Vi를 갖습니다.
K개의 가방이 있고, 각 가방은 최대 용량 Cj만큼 담을 수 있습니다.
각 가방에는 보석을 최대 1개만 넣을 수 있습니다.
가방에 넣은 보석 가치의 합을 최대화하세요.

[핵심 아이디어]
1) 보석을 가치 내림차순으로 정렬합니다.
2) 가방 용량을 멀티셋에 넣습니다.
3) 가치가 높은 보석부터, 해당 보석을 넣을 수 있는 가방 중 가장 작은 것을 선택합니다.
→ lower_bound(M_i)로 찾으면 됩니다.
4) 찾은 가방을 멀티셋에서 제거합니다.

[시간 복잡도] O(N log N + K log K + N log K)
보석 정렬 + 가방 멀티셋 구성 + 각 보석마다 이분 탐색 및 삭제

[KOI] 공장 — 교차하지 않는 최대 연결 (LIS)

[문제] 두 줄의 공장이 있습니다.
위쪽 공장에 번호 A[1..N], 아래쪽 공장에 번호 B[1..N]이 배치되어 있습니다.
같은 번호끼리 연결선을 긋되, 연결선끼리 교차하지 않도록 최대한 많이 연결하세요.
이 문제는 LIS (최장 증가 부분 수열)로 변환됩니다.

[LIS 변환 원리]
위쪽 공장 A를 기준으로 정렬하면, 아래쪽 공장 B의 대응 위치가 나옵니다.
교차하지 않으려면 B의 위치가 증가해야 합니다.
따라서 B 위치 배열에서 LIS를 구하면 됩니다.
O(N log N) LIS: 이분 탐색으로 구현합니다.

#include <stdio.h> #include <stdlib.h> #define MAXN 100001 typedef struct { int a, b; } Pair; Pair pairs[MAXN]; int dp[MAXN]; /* LIS 끝값 배열 */ int n, lis_len; int cmp_pair(const void *a, const void *b) { return ((Pair*)a)->a - ((Pair*)b)->a; } /* dp[0..lis_len-1]에서 val 이상인 첫 위치 */ int lower_bound(int val) { int lo = 0, hi = lis_len; while (lo < hi) { int mid = (lo + hi) / 2; if (dp[mid] < val) lo = mid + 1; else hi = mid; } return lo; } int main(void) { scanf("%d", &n); for (int i = 0; i < n; i++) scanf("%d", &pairs[i].a); for (int i = 0; i < n; i++) scanf("%d", &pairs[i].b); qsort(pairs, n, sizeof(Pair), cmp_pair); lis_len = 0; for (int i = 0; i < n; i++) { int pos = lower_bound(pairs[i].b); dp[pos] = pairs[i].b; if (pos == lis_len) lis_len++; } printf("%d\n", lis_len); return 0; }

SECTION 528Silver | 대회 실전 I — KOI 본선급
[KOI] 소풍 — 비트마스크 DP로 짝짓기
비트마스크 DP조합론Silver

[문제] N명의 학생(N은 짝수)이 소풍을 갑니다.
서로 친구인 쌍만 짝을 이룰 수 있습니다.
모든 학생을 2명씩 짝지을 수 있는 경우의 수를 구하세요.

[비트마스크 DP 접근]
상태: dp[mask] = mask에 해당하는 학생들이 모두 짝지어진 경우의 수
기저: dp[0] = 1 (아무도 안 남음 → 1가지)
전이: mask에서 가장 작은 번호 학생 i를 찾고, i와 짝 가능한 j를 모두 시도
→ dp[mask] += dp[mask ^ (1<<i) ^ (1<<j)]
중복 방지: 항상 가장 작은 미배정 학생부터 처리합니다.

[시간 복잡도] O(2N × N)
N ≤ 20이면 약 2천만으로 충분합니다.

Cpicnic_bitmask.c
#include <stdio.h> #include <string.h> #define MAXN 20 int n, m; int fri[MAXN][MAXN]; /* 친구 관계 */ long long dp[1 << MAXN]; int main(void) { scanf("%d %d", &n, &m); for (int i = 0; i < m; i++) { int a, b; scanf("%d %d", &a, &b); fri[a][b] = fri[b][a] = 1; } int full = (1 << n) - 1; dp[0] = 1; for (int mask = 0; mask <= full; mask++) { if (dp[mask] == 0) continue; /* 가장 작은 0-bit 찾기 (미배정 학생) */ int i; for (i = 0; i < n; i++) if (!(mask & (1 << i))) break; for (int j = i + 1; j < n; j++) { if ((mask & (1 << j)) || !fri[i][j]) continue; dp[mask | (1 << i) | (1 << j)] += dp[mask]; } } printf("%lld\n", dp[full]); return 0; }

SECTION 530Silver | 대회 실전 I — KOI 본선급
[KOI] 저울 — 무게추 DP
DP배낭양팔 저울Silver

[문제] N개의 무게추가 주어집니다.
양팔 저울을 사용하여 잴 수 있는 무게를 모두 구하세요.
무게추는 왼쪽(물건 쪽), 오른쪽(반대 쪽), 또는 사용하지 않을 수 있습니다.

[DP 정의]
dp[w] = 무게 w를 잴 수 있는지 (boolean)
초기: dp[0] = true
전이: 각 추 c에 대해
  1) 오른쪽에 놓기: dp[w + c] = true (if dp[w])
  2) 왼쪽에 놓기: dp[|w - c|] = true (if dp[w])
  3) 안 놓기: 그대로 유지

[주의] 추를 왼쪽(물건 쪽)에 놓으면 잴 수 있는 무게가 줄어들 수 있습니다.
예: 추 1, 5가 있으면 5-1=4도 잴 수 있습니다.

[핵심 아이디어]

SECTION 547Silver | 대회 실전 III — Codeforces/AtCoder
[CF] DP on Tree — Rerooting 기법
트리 DPRerootingDFSSilver

[문제] N개의 노드로 이루어진 트리가 있습니다.
각 간선에 비용이 있습니다.
각 노드 v에 대해, v를 루트로 삼았을 때 모든 노드까지의 거리 합을 구하세요.

[Rerooting DP]
1단계: 노드 1을 루트로 DFS → 각 서브트리의 크기 sz[v]와 dist_sum[v] 계산
2단계: 루트를 "옮기면서" 답을 갱신
루트를 u에서 자식 v로 옮기면:
  ans[v] = ans[u] + (N - 2 * sz[v]) * w(u,v)
v쪽 sz[v]개 노드는 w만큼 가까워지고, 나머지 N-sz[v]개 노드는 w만큼 멀어집니다.

Crerooting.c
#include <stdio.h> #include <string.h> #define MAXN 200001 #define MAXE 400002 int to[MAXE], wt[MAXE], nx[MAXE], hd[MAXN], ec; int sz[MAXN], n; long long ds[MAXN]; /* dist_sum from root */ long long ans[MAXN]; void add(int u, int v, int w) { to[ec]=v; wt[ec]=w; nx[ec]=hd[u]; hd[u]=ec++; } /* 1단계: 루트=1 기준 서브트리 크기와 거리 합 */ void dfs1(int u, int p) { sz[u] = 1; ds[u] = 0; for (int e = hd[u]; e != -1; e = nx[e]) { int v = to[e]; if (v == p) continue; dfs1(v, u); sz[u] += sz[v]; ds[u] += ds[v] + (long long)sz[v] * wt[e]; } } /* 2단계: rerooting */ void dfs2(int u, int p) { for (int e = hd[u]; e != -1; e = nx[e]) { int v = to[e]; if (v == p) continue; ans[v] = ans[u] + (long long)(n - 2 * sz[v]) * wt[e]; dfs2(v, u); } } int main(void) { memset(hd, -1, sizeof(hd)); scanf("%d", &n); for (int i = 0; i < n - 1; i++) { int u, v, w; scanf("%d %d %d", &u, &v, &w); add(u, v, w); add(v, u, w); } dfs1(1, 0); ans[1] = ds[1]; dfs2(1, 0); for (int i = 1; i <= n; i++) printf("%lld\n", ans[i]); return 0; }

4 1 2 1 1 3 2 3 4 3
OUTPUT
8 10 6 12
루트거리합
노드11 → 2: 1, 1 → 3: 2, 1 → 4: 58
노드22 → 1: 1, 2 → 3: 3, 2 → 4: 610

TIP — Rerooting 핵심 공식 ans[v] = ans[u] + (N - 2*sz[v]) * w
이 공식은 간선 가중치가 1인 경우에도 동일하게 적용됩니다 (w=1).
Codeforces에서 매우 자주 출제되는 패턴입니다.

[문제] 확률 p/q가 주어질 때, 이를 mod M = 109+7로 표현하세요.

[모듈러 역원]
M이 소수일 때, 페르마 소정리에 의해:
  qM-1 ≡ 1 (mod M)
  q-1 ≡ qM-2 (mod M)
따라서 p/q mod M = p × qM-2 mod M

[거듭제곱 계산]
qM-2는 빠른 거듭제곱(반복 제곱법)으로 O(log M)에 계산합니다.

#include <stdio.h> #define MOD 1000000007LL long long power(long long base, long long exp, long long mod) { long long result = 1; base %= mod; while (exp > 0) { if (exp & 1) result = result * base % mod; base = base * base % mod; exp >>= 1; } return result; } long long mod_inv(long long q, long long mod) { return power(q, mod - 2, mod); } int main(void) { long long p, q; scanf("%lld %lld", &p, &q); long long ans = p % MOD * mod_inv(q, MOD) % MOD; printf("%lld\n", ans); return 0; } /* === 응용: 기댓값 계산 예제 === */ /* * 동전을 던져 앞면이 나올 확률이 1/2일 때, * 첫 앞면까지 기대 횟수 = 2. * mod 10^9+7로 표현: * 2/1 mod M = 2 * * 주사위 눈의 기대값 = 7/2 * 7 * inv(2) mod M = 7 * 500000004 mod M = 500000007 */
