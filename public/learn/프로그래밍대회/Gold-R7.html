SECTION 751Gold | 고급 최적화
WQS Binary Search — Aliens Trick
WQSLagrangianDPGOLD

핵심 아이디어
원래 목표가 비용 최소화 + 구간 수 정확히 K개처럼 개수 제약을 포함하면 직접 DP가 무거워집니다.
각 선택에 벌점 λ를 더한 보조 문제를 풀고, 최적해가 선택한 개수의 변화를 이용해 λ를 이분 탐색합니다.

판단 기준
λ가 커질수록 선택 개수는 줄어드는 방향으로 단조성이 생겨야 합니다.
보조 DP가 비용뿐 아니라 선택 개수까지 함께 저장해야 마지막에 벌점을 정확히 되돌릴 수 있습니다.

Cwqs_dp.c
typedef struct { long long cost; int cnt; } State; State better(State a, State b) { if (a.cost != b.cost) return (a.cost < b.cost ? a : b); return (a.cnt < b.cnt ? a : b); } State solve_with_penalty(long long lambda) { dp[0] = (State){0, 0}; for (int i = 1; i <= n; i++) { dp[i] = dp[i - 1]; for (int j = 0; j < i; j++) { State cand = dp[j]; cand.cost += cost(j + 1, i) + lambda; cand.cnt += 1; dp[i] = better(dp[i], cand); } } return dp[n]; }
λ보조 문제 비용선택 개수판단
101328K보다 많음
251785목표 K와 근접
402093K보다 적음
복원 공식보조 문제의 결과가 (cost', cnt)이면 원래 비용은 보통 cost' - lambda * K 또는 cost' - lambda * cnt 형태로 복원합니다.

SECTION 752Gold | 고급 최적화
Monge 성질과 Divide and Conquer DP
MongeD&C DPopt monotoneGOLD

문제 형태
dp[i] = min(dp_prev[k] + C(k + 1, i)) 꼴에서 최적 분할점 opt[i]가 단조 증가하면 각 행을 O(N log N)에 계산할 수 있습니다.

Monge와 단조성
비용 함수가 Monge 성질 또는 quadrangle inequality를 만족하면 opt[i]의 단조성이 생기는 경우가 많습니다.
하지만 모든 Monge 비용에서 자동으로 쓸 수 있는 것은 아니며, 전이 경계를 정확히 맞춰야 합니다.

Cdivide_conquer_dp.c
long long dp_prev[MAXN], dp_cur[MAXN]; void compute(int l, int r, int optL, int optR) { if (l > r) return; int mid = (l + r) >> 1; long long best = INF64; int bestK = -1; for (int k = optL; k <= optR && k < mid; k++) { long long cand = dp_prev[k] + cost(k + 1, mid); if (cand < best) best = cand, bestK = k; } dp_cur[mid] = best; compute(l, mid - 1, optL, bestK); compute(mid + 1, r, bestK, optR); }
조건의미실전 체크
opt[i] ≤ opt[i+1]최적 분할점 단조작은 N에서 직접 출력
구간 비용 O(1) 또는 O(log N)전이 자체가 빨라야 함누적 합/전처리 확인
전이 범위 정확성k < mid 같은 경계 중요자기 자신 허용 여부 점검
주의단조성을 추측만 하고 적용하면 틀리기 쉽습니다. 작은 입력에서 opt[i]를 실제로 찍어 확인하는 습관이 중요합니다.

적용 문제
구간 DP에서 dp[i][j] = min(dp[i][k] + dp[k][j] + w(i, j)) 꼴이 자주 등장합니다.
opt[i][j-1] ≤ opt[i][j] ≤ opt[i+1][j]가 성립하면 O(N^3)에서 O(N^2)로 줄일 수 있습니다.

Cknuth_opt.c
for (int i = 0; i < n; i++) { dp[i][i] = 0; opt[i][i] = i; } for (int len = 2; len <= n; len++) { for (int i = 0; i + len - 1 < n; i++) { int j = i + len - 1; dp[i][j] = INF64; int L = opt[i][j - 1]; int R = opt[i + 1][j]; for (int k = L; k <= R; k++) { long long cand = dp[i][k] + dp[k + 1][j] + w(i, j); if (cand < dp[i][j]) dp[i][j] = cand, opt[i][j] = k; } } }
적용 대표 예시파일 합치기, 최적 이진 탐색 트리, 일부 구간 병합 비용 문제에서 자주 등장합니다. 하지만 비용 함수가 아무 구간 합 형태라고 해서 자동으로 Knuth가 되는 것은 아닙니다.

Cbitset_shift.c
void shift_or(unsigned long long *a, int words, int s) { int ws = s >> 6, bs = s & 63; for (int i = words - 1; i >= 0; i--) { unsigned long long v = 0; if (i - ws >= 0) v |= a[i - ws] << bs; if (bs && i - ws - 1 >= 0) v |= a[i - ws - 1] >> (64 - bs); a[i] |= v; } }

SECTION 755Gold | 고급 최적화
SOS DP — 부분집합/상위집합 합 전처리
SOS DPBitmaskSubset TransformGOLD

정의
f[mask]가 주어졌을 때 모든 부분집합 또는 상위집합에 대한 합을 빠르게 구하는 기법입니다.
나이브하게는 각 마스크마다 모든 부분집합을 돌면 O(3^N)이지만, SOS DP는 O(N 2^N)에 계산합니다.

Csos_dp.c
for (int bit = 0; bit < B; bit++) { for (int mask = 0; mask < (1 << B); mask++) { if (mask & (1 << bit)) f[mask] += f[mask ^ (1 << bit)]; } }
목표전이 방향조건
부분집합 합mask → mask ^ bit비트가 켜진 상태에서 이전 부분집합을 더함
상위집합 합mask → mask | bit비트가 꺼진 상태에서 상위집합 정보를 받음
실전 사용처집합 포함 관계가 들어가는 DP, 비트마스크 기반 카운팅, 특정 조건을 만족하는 부분집합 수 계산, AND/OR/XOR 기반 변환 문제에서 자주 등장합니다.

SECTION 756Gold | 고급 최적화
FWT — XOR Convolution
FWTXORConvolutionGOLD

언제 필요한가
두 배열 A, B에 대해 C[k] = Σ A[i]B[j] where i xor j = k 를 빠르게 구하고 싶을 때 사용합니다.
FFT가 덧셈 인덱스를 처리한다면, FWT는 XOR/AND/OR 형태의 인덱스를 처리합니다.

Cfwt_xor.c
void fwt(long long *a, int n, int inv) { for (int len = 1; len < n; len <<= 1) { for (int i = 0; i < n; i += len << 1) { for (int j = 0; j < len; j++) { long long x = a[i + j], y = a[i + j + len]; a[i + j] = x + y; a[i + j + len] = x - y; } } } if (inv == -1) for (int i = 0; i < n; i++) a[i] /= n; }
INPUT
A = [1, 2, 3, 4] B = [0, 1, 0, 1]
OUTPUT
C = [6, 4, 6, 4]
주의역변환에서 n으로 나누는 단계를 빠뜨리면 값이 모두 n배 커집니다. 모듈러 연산에서는 역원을 곱해야 합니다.

SECTION 763Gold | 고급 모델링

핵심
모든 제약을 둘 중 하나는 참 꼴의 절로 바꾸고, 이를 함의 그래프로 변환합니다.
변수 x에 대해 노드 x와 not x를 만들고, 절 (a or b)는 not a → b, not b → a로 바뀝니다.

문장 패턴절 형태
A와 B가 동시에 참이면 안 됨(not A or not B)
A가 참이면 B도 참(not A or B)
