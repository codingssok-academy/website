SECTION 151Iron | 스택
배열로 스택 구현
stackLIFO배열Iron

스택(Stack)은 후입선출(LIFO) 자료구조입니다. 마지막에 넣은 것을 먼저 꺼냅니다. 배열과 top 인덱스로 간단히 구현합니다.

C개념 코드
#define MAXN 10001 int stk[MAXN], top = -1; void push(int x) { stk[++top] = x; } int pop(void) { return stk[top--]; } int peek(void) { return stk[top]; } int empty(void){ return top == -1; }
연산스택 상태top
push(3)[3]0
push(7)[3, 7]1
push(1)[3, 7, 1]2
pop() → 1[3, 7]1
peek() → 7[3, 7]1

[문제] N개의 명령을 처리하시오.
• push X: X를 넣기
• pop: 꺼내서 출력 (비어있으면 -1)
• size: 크기 출력
• empty: 비어있으면 1, 아니면 0
• top: 꼭대기 출력 (비어있으면 -1)

입력
7 push 1 push 2 top size empty pop pop
출력
2 2 0 2 1
풀이 작성
2
SECTION 152Iron | 스택
괄호 검사 — 스택의 대표 응용
stack괄호대회 필수Iron

여는 괄호는 push, 닫는 괄호는 pop하며 짝이 맞는지 확인합니다. 끝났을 때 스택이 비어있어야 올바릅니다.

C개념 코드
int check(const char *s) { int top = -1; char stk[10001]; for (int i = 0; s[i]; i++) { if (s[i] == '(' || s[i] == '[' || s[i] == '{') stk[++top] = s[i]; else { if (top == -1) return 0; char o = stk[top--]; if (s[i]==')' && o!='(') return 0; if (s[i]==']' && o!='[') return 0; if (s[i]=='}' && o!='{') return 0; } } return top == -1; }

SECTION 153Iron | 스택
후위 표기식(Postfix) 계산
stackpostfixIron

후위 표기식(RPN)은 연산자가 피연산자 뒤에 옵니다. 스택으로 계산: 숫자는 push, 연산자는 두 개 pop하여 계산 후 push.

C개념 코드
// "3 4 + 2 *" = (3+4)*2 = 14 // 토큰이 숫자면 push // 토큰이 연산자면: int b = pop(); // 먼저 pop한 것이 b! int a = pop(); if (op == '+') push(a + b); if (op == '-') push(a - b); // 순서 주의!
순서 주의뺄셈과 나눗셈은 순서가 중요합니다. 먼저 pop한 것이 오른쪽 피연산자(b), 나중이 왼쪽(a)입니다.

[문제] 공백으로 구분된 후위 표기식을 입력받아 계산 결과를 출력하시오. (한 자리 숫자, +, -, *, / 연산)

입력

#define MAXN 10001 int que[MAXN], front = 0, rear = 0; void enqueue(int x) { que[rear++] = x; } int dequeue(void) { return que[front++]; } int q_empty(void){ return front == rear; } int q_size(void) { return rear - front; }

원형 큐 (Circular Queue)
circular queue모듈러Iron

C개념 코드
#define CAP 100 int cq[CAP], cf = 0, cr = 0, csz = 0; void cq_push(int x) { cq[cr] = x; cr = (cr+1) % CAP; csz++; } int cq_pop(void) { int v = cq[cf]; cf = (cf+1) % CAP; csz--; return v; }
