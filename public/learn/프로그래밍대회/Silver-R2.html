단절점 (Articulation Point) — DFS 트리 기반 탐색
단절점DFS 트리그래프 연결성Silver

[개념] 단절점(Articulation Point)이란 해당 정점을 제거했을 때 그래프가 둘 이상의 연결 요소로 분리되는 정점입니다.
네트워크에서 단일 장애점(Single Point of Failure)을 찾는 데 핵심적으로 사용됩니다.
DFS 트리에서 두 가지 배열 disc[]와 low[]를 활용하여 O(V+E)에 모든 단절점을 찾을 수 있습니다.

핵심 정의:
disc[u] = 정점 u를 DFS로 처음 방문한 시점 (발견 순서)
low[u] = u에서 DFS 트리의 서브트리를 통해 도달 가능한 최소 disc 값
역방향 간선(back edge)을 통해 조상으로 올라갈 수 있으므로 low 값이 disc보다 작아질 수 있습니다.

단절점 판별 조건:
1) u가 루트가 아닌 경우: DFS 트리에서 u의 자식 v에 대해 low[v] ≥ disc[u]이면 u는 단절점
   (v의 서브트리가 u를 거치지 않고는 u의 조상에 도달할 수 없음)
2) u가 루트인 경우: DFS 트리에서 자식이 2개 이상이면 u는 단절점
   (루트를 제거하면 각 자식의 서브트리가 분리됨)

low[u] 갱신 규칙:
초기값: low[u] = disc[u]
트리 간선 (u → v): low[u] = min(low[u], low[v])
역방향 간선 (u → w, w는 이미 방문한 조상): low[u] = min(low[u], disc[w])

Carticulation_point.c
#include <stdio.h> #include <string.h> #define MAXN 100001 #define MAXM 200001 int head[MAXN], to[MAXM * 2], nxt[MAXM * 2], ecnt; int disc[MAXN], low[MAXN], timer_val; int is_ap[MAXN]; /* 단절점 여부 */ int N, M; void addEdge(int u, int v) { to[ecnt] = v; nxt[ecnt] = head[u]; head[u] = ecnt++; to[ecnt] = u; nxt[ecnt] = head[v]; head[v] = ecnt++; } void dfs(int u, int parent) { disc[u] = low[u] = ++timer_val; int children = 0; for (int e = head[u]; e != -1; e = nxt[e]) { int v = to[e]; if (!disc[v]) { children++; dfs(v, u); if (low[v] < low[u]) low[u] = low[v]; /* 루트가 아닌 경우: low[v] >= disc[u] */ if (parent != -1 && low[v] >= disc[u]) is_ap[u] = 1; } else if (v != parent) { /* 역방향 간선: disc[v]로 갱신 */ if (disc[v] < low[u]) low[u] = disc[v]; } } /* 루트이고 자식이 2개 이상이면 단절점 */ if (parent == -1 && children >= 2) is_ap[u] = 1; } int main(void) { memset(head, -1, sizeof(head)); scanf("%d %d", &N, &M); for (int i = 0; i < M; i++) { int u, v; scanf("%d %d", &u, &v); addEdge(u, v); } for (int i = 1; i <= N; i++) if (!disc[i]) dfs(i, -1); printf("단절점: "); for (int i = 1; i <= N; i++) if (is_ap[i]) printf("%d ", i); printf("\n"); return 0; }

단절선 (Bridge) — low[v] > disc[u] 조건
단절선브릿지DFS 트리Silver

[개념] 단절선(Bridge)이란 해당 간선을 제거했을 때 그래프가 둘 이상의 연결 요소로 분리되는 간선입니다.
단절점과 마찬가지로 DFS 트리에서 disc[]와 low[]를 사용하여 O(V+E)에 찾습니다.

단절점과의 차이:
단절점: low[v] ≥ disc[u] (같거나 크면)
단절선: low[v] > disc[u] (엄격히 크면)
등호의 차이가 핵심입니다!
low[v] == disc[u]이면 v의 서브트리에서 u까지는 올라올 수 있으므로 간선 (u,v)를 제거해도 u를 통해 연결됩니다.
하지만 low[v] > disc[u]이면 v의 서브트리가 u에조차 도달할 수 없으므로 간선 (u,v)는 브릿지입니다.

다중 간선(multi-edge) 처리:
같은 두 정점 사이에 간선이 2개 이상이면 하나를 제거해도 다른 간선이 남으므로 브릿지가 아닙니다.
이를 처리하려면 parent 정점이 아니라 parent 간선 번호를 추적해야 합니다.

Cbridge.c
#include <stdio.h> #include <string.h> #define MAXN 100001 #define MAXM 200001 int head[MAXN], to[MAXM * 2], nxt[MAXM * 2], ecnt; int disc[MAXN], low[MAXN], timer_val; int N, M; int br_u[MAXM], br_v[MAXM], br_cnt; /* 브릿지 저장 */ void addEdge(int u, int v) { to[ecnt] = v; nxt[ecnt] = head[u]; head[u] = ecnt++; to[ecnt] = u; nxt[ecnt] = head[v]; head[v] = ecnt++; } void dfs(int u, int parentEdge) { disc[u] = low[u] = ++timer_val; for (int e = head[u]; e != -1; e = nxt[e]) { int v = to[e]; if ((e ^ 1) == parentEdge) continue; /* 역방향 간선 번호 건너뛰기 */ if (!disc[v]) { dfs(v, e); if (low[v] < low[u]) low[u] = low[v]; /* 브릿지 조건: low[v] > disc[u] (엄격 부등호) */ if (low[v] > disc[u]) { br_u[br_cnt] = u; br_v[br_cnt] = v; br_cnt++; } } else { if (disc[v] < low[u]) low[u] = disc[v]; } } } int main(void) { memset(head, -1, sizeof(head)); scanf("%d %d", &N, &M); for (int i = 0; i < M; i++) { int u, v; scanf("%d %d", &u, &v); addEdge(u, v); } for (int i = 1; i <= N; i++) if (!disc[i]) dfs(i, -1); printf("브릿지 수: %d\n", br_cnt); for (int i = 0; i < br_cnt; i++) printf("%d - %d\n", br_u[i], br_v[i]); return 0; }

블록-컷 트리 (BCC) — 이중 연결 요소 분해
BCC이중 연결 요소블록-컷 트리Silver

[개념] 이중 연결 요소(Biconnected Component, BCC)란 단절점이 없는 극대 부분 그래프입니다.
즉, BCC 내의 어떤 정점 하나를 제거해도 나머지가 여전히 연결되어 있습니다.
임의의 두 정점 사이에 정점이 겹치지 않는 경로가 2개 이상 존재합니다.

블록-컷 트리:
그래프를 BCC들과 단절점들로 분해한 뒤, 트리 구조로 표현한 것입니다.
블록(block) 노드 = 각 BCC를 대표하는 노드
컷(cut) 노드 = 각 단절점을 대표하는 노드
단절점이 어떤 BCC에 속하면 컷 노드와 블록 노드 사이에 간선을 연결합니다.
결과적으로 항상 트리가 됩니다.

구현 방법:
DFS를 수행하면서 방문하는 간선을 스택에 push합니다.
단절점 조건(low[v] ≥ disc[u])이 만족되면 스택에서 간선 (u,v)까지 pop하여 하나의 BCC를 구성합니다.
루트의 경우에도 각 자식 서브트리마다 BCC를 하나씩 추출합니다.

2-SAT 개념 — 함의 그래프와 만족 가능성
2-SAT함의 그래프SCCSilver

[개념] 2-SAT은 불리언 변수 x1, x2, ..., xn에 대해
각 절(clause)이 정확히 2개의 리터럴의 OR로 이루어진 CNF 식의 만족 가능성을 판별하는 문제입니다.
예: (x1 ∨ ¬x2) ∧ (¬x1 ∨ x3) ∧ (x2 ∨ x3)

함의 그래프(Implication Graph) 구성:
각 절 (a ∨ b)를 두 개의 함의(implication)로 변환합니다:
¬a → b (a가 거짓이면 b는 반드시 참)
¬b → a (b가 거짓이면 a는 반드시 참)
이 두 함의를 방향 간선으로 표현하면 함의 그래프가 됩니다.

변수 인코딩:
변수 xi를 정점 2i로, ¬xi를 정점 2i+1로 표현합니다.
NEG(x) = x ^ 1로 부정을 간단히 구할 수 있습니다.
예: x0 = 정점 0, ¬x0 = 정점 1, x1 = 정점 2, ¬x1 = 정점 3

절 (a ∨ b) 추가:
간선 NEG(a) → b 추가
간선 NEG(b) → a 추가
총 2M개의 간선이 생깁니다 (M = 절의 수).

절함의 1함의 2의미
(x0 ∨ x1)¬x0 → x1¬x1 → x0둘 중 하나는 참
(x0 ∨ ¬x1)¬x0 → ¬x1x1 → x0x0 거짓이면 x1도 거짓
(¬x0 ∨ x1)x0 → x1¬x1 → ¬x0x0 참이면 x1도 참
(¬x0 ∨ ¬x1)x0 → ¬x1x1 → ¬x0둘 다 참은 불가

만족 가능성 판별:
함의 그래프에서 SCC(강한 연결 요소)를 구합니다.
만약 어떤 변수 xi와 ¬xi가 같은 SCC에 속하면 → 불가능(UNSATISFIABLE)
(x → ¬x → ... → x 순환이 존재하면 모순)
그렇지 않으면 → 만족 가능(SATISFIABLE)

TIP — 해 구성 방법 SCC를 위상 정렬 역순으로 번호를 매긴 후,
scc[x_i] > scc[¬x_i]이면 xi = TRUE
scc[x_i] < scc[¬x_i]이면 xi = FALSE
Tarjan의 SCC 알고리즘은 역위상 정렬 순으로 SCC를 생성하므로
scc 번호가 작을수록 위상 정렬에서 뒤에 옵니다.
WARNING — 함의 방향 주의 절 (a ∨ b)에서 함의는 ¬a → b, ¬b → a입니다.
a → b, b → a로 잘못 넣으면 완전히 다른 의미가 됩니다!
"a가 거짓이면 b가 참이어야 한다"는 논리를 정확히 따르세요.

핵심 기법은 "Union-Find with Rollback"입니다.

일반 Union-Find와의 차이:
일반 Union-Find는 경로 압축(path compression)을 사용하여 되돌리기(rollback)가 불가능합니다.
Rollback을 지원하려면 경로 압축 대신 union by rank만 사용합니다.
union 연산 시 변경된 내용을 스택에 기록하고, 필요할 때 역순으로 복원합니다.

시간 복잡도:
union by rank만 사용 시 find는 O(log N)입니다.
경로 압축 없이도 rank 기반 합치기로 트리 높이가 O(log N)으로 보장됩니다.
rollback은 스택에서 pop하므로 O(1)입니다.

이중 연결 요소와 브릿지 트리 — 2-edge-connected 축약
브릿지 트리2-edge-connected축약Silver

[개념] 2-edge-connected component(이중 간선 연결 요소)란
어떤 간선 하나를 제거해도 연결이 유지되는 극대 부분 그래프입니다.
즉, 브릿지가 하나도 없는 최대 연결 부분 그래프입니다.

BCC(biconnected, 이중 정점 연결)와의 차이:
BCC: 정점 하나를 제거해도 연결 유지 (단절점 기준 분해)
2-edge-connected: 간선 하나를 제거해도 연결 유지 (브릿지 기준 분해)
2-edge-connected 요소가 더 크거나 같습니다.

브릿지 트리 구성:
1) 모든 브릿지를 찾습니다 (Section 427 참조).
2) 브릿지를 제거하면 남는 각 연결 요소가 2-edge-connected component입니다.
3) 각 컴포넌트를 하나의 노드로 축약합니다.
4) 브릿지를 이 축약된 노드들 사이의 간선으로 연결하면 트리가 됩니다.
이것이 브릿지 트리(Bridge Tree)입니다.

브릿지 트리의 성질:
원래 그래프의 두 정점 u, v 사이에서 반드시 지나야 하는 브릿지의 수
= 브릿지 트리에서 u가 속한 노드와 v가 속한 노드 사이의 거리입니다.
이를 통해 "경로상 필수 간선" 문제를 트리 쿼리로 변환할 수 있습니다.

퍼시스턴트 세그트리버전 관리K번째 수Silver

[개념] 퍼시스턴트(Persistent) 세그먼트 트리는 세그먼트 트리의 모든 과거 버전을 보존하는 자료구조입니다.
일반 세그먼트 트리는 업데이트하면 이전 상태가 사라지지만,
퍼시스턴트 버전은 매 업데이트마다 새로운 "버전"을 만들어 이전 상태를 유지합니다.

핵심 아이디어: 노드 복사 (Path Copying)
업데이트할 때 변경되는 노드만 새로 만들고, 나머지는 이전 버전의 노드를 공유합니다.
세그먼트 트리에서 업데이트 경로는 루트에서 리프까지 O(log N)개의 노드입니다.
따라서 각 업데이트마다 O(log N)개의 노드만 새로 생성합니다.

구조:
일반 세그먼트 트리: 배열 기반 (tree[4*N])
퍼시스턴트 세그먼트 트리: 동적 노드 할당
  각 노드: { 왼쪽 자식 인덱스, 오른쪽 자식 인덱스, 값 }
  roots[]: 각 버전의 루트 노드 인덱스

메모리 분석:
초기 트리: O(N) 노드 (또는 4N)
각 업데이트: O(log N) 새 노드
Q번 업데이트 후 총 노드: O(N + Q log N)
보통 20~25 * N 정도로 노드 풀을 잡습니다.

대표 응용: 구간 K번째 수 (온라인)

version[r] - version[l-1]의 세그트리 차이가 구간 [l, r]의 값 분포입니다.
여기서 K번째 작은 수를 O(log N)에 찾을 수 있습니다.

TIP — 일반 세그트리와의 비교 일반 세그트리: 공간 O(N), 업데이트 O(log N), 과거 접근 불가
퍼시스턴트: 공간 O(N + Q log N), 업데이트 O(log N), 모든 과거 접근 가능

퍼시스턴트 세그트리는 O(log N)이고 온라인 가능합니다.

#include <stdio.h> #define MAXN 100001 #define MAXNODES 5000000 /* 충분히 크게 */ int ls[MAXNODES], rs[MAXNODES]; /* 왼쪽/오른쪽 자식 */ int val[MAXNODES]; /* 노드 값 (개수) */ int ncnt; /* 노드 풀 카운터 */ int roots[MAXN]; /* 각 버전의 루트 */ /* 새 노드 생성 (기존 노드 복사) */ int newNode(int src) { int nd = ++ncnt; ls[nd] = ls[src]; rs[nd] = rs[src]; val[nd] = val[src]; return nd; } /* 빌드: 빈 세그트리 (값 범위 [lo, hi]) */ int build(int lo, int hi) { int nd = ++ncnt; val[nd] = 0; if (lo == hi) { ls[nd] = rs[nd] = 0; return nd; } int mid = (lo + hi) / 2; ls[nd] = build(lo, mid); rs[nd] = build(mid + 1, hi); return nd; } /* 업데이트: pos 위치에 +1 (이전 버전 prev 기반) */ int update(int prev, int lo, int hi, int pos) { int nd = newNode(prev); /* 노드 복사! */ val[nd]++; if (lo == hi) return nd; int mid = (lo + hi) / 2; if (pos <= mid) ls[nd] = update(ls[prev], lo, mid, pos); else rs[nd] = update(rs[prev], mid + 1, hi, pos); return nd; } /* 쿼리: 두 버전의 차이로 K번째 수 찾기 */ int query(int vl, int vr, int lo, int hi, int k) { if (lo == hi) return lo; int mid = (lo + hi) / 2; int cnt = val[ls[vr]] - val[ls[vl]]; /* 왼쪽 구간 개수 */ if (k <= cnt) return query(ls[vl], ls[vr], lo, mid, k); else return query(rs[vl], rs[vr], mid + 1, hi, k - cnt); } int arr[MAXN], sorted[MAXN], N, Q; int lower_bound(int v, int n) { int lo = 0, hi = n - 1, ans = 0; while (lo <= hi) { int mid = (lo + hi) / 2; if (sorted[mid] <= v) { ans = mid; lo = mid + 1; } else hi = mid - 1; } return ans; } int main(void) { scanf("%d %d", &N, &Q); for (int i = 1; i <= N; i++) { scanf("%d", &arr[i]); sorted[i - 1] = arr[i]; } /* 좌표 압축 (간략화: 정렬 + 중복 제거) */ /* ... 정렬 및 중복 제거 코드 생략 ... */ int sz = N; /* 고유 값 개수 */ roots[0] = build(0, sz - 1); for (int i = 1; i <= N; i++) { int pos = lower_bound(arr[i], sz); roots[i] = update(roots[i - 1], 0, sz - 1, pos); } for (int q = 0; q < Q; q++) { int l, r, k; scanf("%d %d %d", &l, &r, &k); int idx = query(roots[l - 1], roots[r], 0, sz - 1, k); printf("%d\n", sorted[idx]); } return 0; }

링크-컷 트리 개념 — Splay 기반 동적 트리
링크-컷 트리Splay Tree동적 트리Silver

[개념] 링크-컷 트리(Link-Cut Tree)는 포레스트(트리들의 집합)를 관리하는 자료구조로,
동적으로 트리의 간선을 추가(link)하거나 제거(cut)하면서
경로 쿼리(경로 합, 경로 최대 등)를 O(log N) 분할 상환 시간에 처리합니다.

왜 필요한가?
HLD(Heavy-Light Decomposition)는 정적 트리에서만 동작합니다.
간선이 동적으로 변하면 HLD를 매번 재구성해야 하므로 비효율적입니다.
링크-컷 트리는 간선 변경을 O(log N)에 처리합니다.

구성 요소:
1) Preferred Path: 각 노드에서 자식 하나를 "선호 자식"으로 지정하여 만든 경로
2) Auxiliary Tree: 각 preferred path를 Splay 트리로 관리
   Splay 트리의 키는 트리에서의 깊이 순서
3) Path-Parent Edge: auxiliary tree의 루트가 원래 트리의 부모를 가리키는 간선

핵심 연산:
access(u): u에서 루트까지의 경로를 하나의 preferred path로 만듦
   모든 다른 연산의 기초
makeRoot(u): u를 트리의 루트로 설정 (Splay 트리 뒤집기)
link(u, v): 서로 다른 트리의 u와 v를 간선으로 연결
cut(u, v): u-v 간선을 제거하여 트리를 분리
findRoot(u): u가 속한 트리의 루트를 찾음

연산시간 복잡도용도
access(u)O(log N) amortized루트~u 경로를 preferred path로
makeRoot(u)O(log N) amortizedu를 루트로 설정
link(u, v)O(log N) amortized간선 추가
cut(u, v)O(log N) amortized간선 제거
findRoot(u)O(log N) amortized연결성 확인
pathQuery(u, v)O(log N) amortized경로 집약 쿼리
TIP — access 연산의 핵심 access(u) 수행 시:
1) u를 Splay 트리의 루트로 splay
2) u의 오른쪽 자식을 끊음 (u 아래의 preferred path 해제)
3) path-parent를 따라 위로 올라가며 반복
최종적으로 u에서 원래 트리 루트까지가 하나의 Splay 트리가 됩니다.
WARNING — Euler Tour Tree와의 차이 ETT(Euler Tour Tree)도 동적 트리를 지원하지만 서브트리 쿼리에 특화됩니다.
링크-컷 트리는 경로 쿼리에 특화됩니다.
경로 집약(합, 최대) → 링크-컷 트리
서브트리 집약(합, 크기) → ETT

리-밸런싱 트리 (Treap) — 랜덤 우선순위 BST
TreapBSTsplit/mergeSilver

[개념] Treap은 Tree + Heap의 합성어로,
BST 성질(키 기준)과 Heap 성질(우선순위 기준)을 동시에 만족하는 자료구조입니다.
우선순위를 랜덤으로 부여하면 기댓값 O(log N) 높이의 균형 트리가 됩니다.

핵심 연산:
split(t, key): 트리 t를 key 기준으로 두 트리 (left, right)로 분할
   left: key 이하의 모든 노드
   right: key 초과의 모든 노드
merge(l, r): 두 트리 l, r을 합침 (l의 모든 키 < r의 모든 키 전제)
   우선순위가 높은 쪽이 루트가 됨

삽입: split으로 분할 → 새 노드 끼워 넣기 → merge로 합치기
삭제: split으로 해당 키 분리 → 버리기 → merge로 합치기
K번째 원소: 서브트리 크기(size)를 관리하면 O(log N)에 가능

#include <stdio.h> #include <stdlib.h> #define MAXN 200001 int key[MAXN], pri[MAXN], sz[MAXN]; int lc[MAXN], rc[MAXN]; int ncnt, root; int newNode(int k) { int nd = ++ncnt; key[nd] = k; pri[nd] = rand(); sz[nd] = 1; lc[nd] = rc[nd] = 0; return nd; } void update(int t) { if (t) sz[t] = sz[lc[t]] + sz[rc[t]] + 1; } /* split: key 이하 → l, key 초과 → r */ void split(int t, int k, int *l, int *r) { if (!t) { *l = *r = 0; return; } if (key[t] <= k) { *l = t; split(rc[t], k, &rc[t], r); } else { *r = t; split(lc[t], k, l, &lc[t]); } update(t); } /* merge: l의 모든 키 < r의 모든 키 */ int merge(int l, int r) { if (!l || !r) return l ? l : r; if (pri[l] > pri[r]) { rc[l] = merge(rc[l], r); update(l); return l; } else { lc[r] = merge(l, lc[r]); update(r); return r; } } void insert(int k) { int l, r; split(root, k, &l, &r); root = merge(merge(l, newNode(k)), r); } void erase(int k) { int l, m, r; split(root, k, &l, &r); split(l, k - 1, &l, &m); /* m에는 key==k인 노드들 — 하나만 제거 */ m = merge(lc[m], rc[m]); root = merge(merge(l, m), r); } int kth(int t, int k) { int left_sz = sz[lc[t]]; if (k <= left_sz) return kth(lc[t], k); if (k == left_sz + 1) return key[t]; return kth(rc[t], k - left_sz - 1); } int main(void) { srand(42); insert(5); insert(3); insert(7); insert(1); insert(4); printf("크기: %d\n", sz[root]); printf("3번째 원소: %d\n", kth(root, 3)); erase(3); printf("삭제 후 2번째: %d\n", kth(root, 2)); return 0; }

[개념] 암시적 키(Implicit Key) Treap은 키를 명시적으로 저장하지 않고,
서브트리 크기(size)로부터 "몇 번째 원소인가"를 암시적으로 결정하는 Treap입니다.
이를 통해 배열의 구간 연산(삽입, 삭제, 뒤집기)을 O(log N)에 처리할 수 있습니다.

핵심 차이 (일반 Treap vs 암시적 Treap):
일반 Treap: key로 split/merge → 집합(set) 역할
암시적 Treap: 위치(인덱스)로 split/merge → 배열(array) 역할
split(t, k): 앞에서 k개 → left, 나머지 → right

구간 뒤집기 (Reverse):
구간 [l, r]을 뒤집으려면:
1) split(root, l-1) → left, rest
2) split(rest, r-l+1) → mid, right
3) mid의 루트에 reverse lazy tag 적용
4) merge(left, mid, right)로 합치기

Cimplicit_treap.c
#include <stdio.h> #include <stdlib.h> #define MAXN 300001 int val[MAXN], pri[MAXN], sz[MAXN]; int lc[MAXN], rc[MAXN], rev[MAXN]; int ncnt, root; int newNode(int v) { int nd = ++ncnt; val[nd] = v; pri[nd] = rand(); sz[nd] = 1; lc[nd] = rc[nd] = rev[nd] = 0; return nd; } void push(int t) { if (t && rev[t]) { int tmp = lc[t]; lc[t] = rc[t]; rc[t] = tmp; if (lc[t]) rev[lc[t]] ^= 1; if (rc[t]) rev[rc[t]] ^= 1; rev[t] = 0; } } void upd(int t) { if (t) sz[t] = sz[lc[t]] + sz[rc[t]] + 1; } /* 앞에서 k개 → l, 나머지 → r */ void split(int t, int k, int *l, int *r) { if (!t) { *l = *r = 0; return; } push(t); if (sz[lc[t]] < k) { *l = t; split(rc[t], k - sz[lc[t]] - 1, &rc[t], r); } else { *r = t; split(lc[t], k, l, &lc[t]); } upd(t); } int merge(int l, int r) { push(l); push(r); if (!l || !r) return l ? l : r; if (pri[l] > pri[r]) { rc[l] = merge(rc[l], r); upd(l); return l; } else { lc[r] = merge(l, lc[r]); upd(r); return r; } } void reverse(int l, int r) { /* 1-indexed [l, r] */ int a, b, c; split(root, l - 1, &a, &b); split(b, r - l + 1, &b, &c); rev[b] ^= 1; root = merge(merge(a, b), c); } void printArr(int t) { if (!t) return; push(t); printArr(lc[t]); printf("%d ", val[t]); printArr(rc[t]); } int main(void) { srand(42); int a[] = {1,2,3,4,5,6,7}; for (int i = 0; i < 7; i++) root = merge(root, newNode(a[i])); printf("원본: "); printArr(root); printf("\n"); reverse(2, 5); /* [2,5] 뒤집기 */ printf("뒤집기 후: "); printArr(root); printf("\n"); return 0; }

웨이블릿 트리 개념 — 비트별 분할로 구간 쿼리
웨이블릿 트리구간 K번째rank/selectSilver

[개념] 웨이블릿 트리(Wavelet Tree)는 정수 배열에 대해
구간 K번째 수, 구간 rank, 구간 select 등을 O(log σ) 시간에 처리하는 자료구조입니다.
여기서 σ는 값의 범위(알파벳 크기)입니다.

구성 원리:
값의 범위 [lo, hi]를 이진 분할합니다.
mid = (lo + hi) / 2로 놓고:
  값 ≤ mid인 원소 → 왼쪽 자식으로
  값 > mid인 원소 → 오른쪽 자식으로
각 노드에서는 원소가 왼쪽/오른쪽 중 어디로 갔는지를 비트맵으로 기록합니다.
lo == hi가 될 때까지 재귀합니다.

핵심 쿼리:
rank(l, r, v): 구간 [l, r]에서 v 이하인 원소의 개수
kth(l, r, k): 구간 [l, r]에서 k번째 작은 수
select(l, r, v, k): 구간 [l, r]에서 값 v의 k번째 출현 위치

kth(l, r, k) 동작:
현재 노드의 비트맵에서 구간 [l, r] 중 왼쪽으로 간 원소 수 = cnt
k ≤ cnt이면 → 왼쪽 자식에서 찾기 (l, r을 왼쪽 구간으로 매핑)
k > cnt이면 → 오른쪽 자식에서 k - cnt 번째 찾기

연산시간 복잡도설명
buildO(N log σ)비트별 분할 트리 구성
kth(l, r, k)O(log σ)구간 K번째 수
rank(l, r, v)O(log σ)v 이하 개수
count(l, r, lo, hi)O(log σ)값이 [lo, hi]인 원소 수

퍼시스턴트 세그트리와의 비교:
퍼시스턴트 세그트리: 구간 K번째 O(log N), 공간 O(N log N)
웨이블릿 트리: 구간 K번째 O(log σ), 공간 O(N log σ)
웨이블릿 트리는 rank/select 등 추가 쿼리도 자연스럽게 지원합니다.
값의 범위가 크면 좌표 압축이 필요합니다.

NOTE — 구현 팁 비트맵 대신 prefix sum 배열을 사용하면 rank를 O(1)에 계산할 수 있습니다.
각 노드의 배열에서 "왼쪽으로 간 원소의 prefix sum"을 관리합니다.
구현이 다소 복잡하지만, 상수가 작아 실전에서 빠릅니다.
WARNING — 값 범위 확인 웨이블릿 트리의 높이는 log σ입니다.
값이 109이면 약 30층이 되어 메모리가 O(30N)이 됩니다.
좌표 압축으로 σ를 N 이하로 줄이면 O(N log N)으로 동일해집니다.

Skip List — 확률적 다층 연결 리스트

[개념] Skip List는 정렬된 연결 리스트에 여러 층(level)의 "빠른 링크"를 추가하여
검색, 삽입, 삭제를 O(log N) 기대 시간에 수행하는 확률적 자료구조입니다.
Red-Black Tree와 같은 기능을 훨씬 단순한 구현으로 제공합니다.

구조:
Level 0: 모든 원소가 연결된 정렬 리스트
Level 1: 확률 1/2로 선택된 원소들의 리스트
Level 2: 확률 1/4로 선택된 원소들의 리스트
...
Level k: 확률 1/2k로 선택된 원소들의 리스트
최대 레벨: O(log N)

검색:
가장 높은 레벨부터 시작하여 오른쪽으로 이동합니다.
다음 노드의 값이 목표보다 크면 한 레벨 아래로 내려갑니다.

평균 비교 횟수: O(log N)

SECTION 446Silver | 수학 심화
FFT 개념 — 다항식 곱셈 O(N log N)
FFTDFT다항식 곱셈Silver

[개념] FFT(Fast Fourier Transform, 고속 푸리에 변환)는
두 다항식의 곱셈을 O(N log N) 시간에 수행하는 알고리즘입니다.
나이브하게 곱하면 O(N²)이지만, FFT를 사용하면 획기적으로 빨라집니다.

핵심 아이디어:
다항식을 계수 표현(coefficient representation)과 점-값 표현(point-value representation) 사이에서 변환합니다.
1) 계수 표현 → 점-값 표현: DFT (O(N log N))
2) 점-값에서 원소별 곱셈: O(N)
3) 점-값 표현 → 계수 표현: IDFT (O(N log N))
총 시간: O(N log N)

DFT (이산 푸리에 변환):
N개의 계수 [a0, a1, ..., aN-1]에 대해
N번째 단위근 ω = e2πi/N의 거듭제곱에서 다항식 값을 평가합니다.
A(ωk) = ∑ aj · ωjk, (k = 0, 1, ..., N-1)

재귀 분할 (Cooley-Tukey):
짝수 인덱스와 홀수 인덱스로 분할합니다.
A(x) = Aeven(x²) + x · Aodd(x²)
T(N) = 2T(N/2) + O(N) = O(N log N)

단위근의 성질:
ωN = 1 (N번째 단위근)
ωN/2 = -1 (반주기 성질)
ωk+N/2 = -ωk (대칭 성질, "나비 연산"의 핵심)

단계연산시간설명
1DFT(A), DFT(B)O(N log N)두 다항식을 점-값 표현으로
2C[k] = A[k] × B[k]O(N)점별 곱셈
3IDFT(C)O(N log N)결과를 계수 표현으로

IDFT:
DFT와 거의 동일하지만 ω 대신 ω-1을 사용하고, 결과를 N으로 나눕니다.
IDFT[k] = (1/N) ∑ A[j] · ω-jk

NOTE — N은 2의 거듭제곱 FFT는 N이 2의 거듭제곱일 때 동작합니다.
다항식의 차수가 2의 거듭제곱이 아니면 0으로 패딩합니다.
결과 다항식의 차수가 deg(A) + deg(B)이므로
N ≥ deg(A) + deg(B) + 1인 최소 2의 거듭제곱을 사용합니다.
WARNING — 실수 오차 복소수 FFT는 부동소수점 연산을 사용하므로 오차가 발생합니다.
결과 계수를 정수로 반올림할 때 주의하세요 (round 사용).
정확한 정수 결과가 필요하면 NTT(Section 448)를 사용합니다.

FFT 구현 — 비재귀(Iterative) FFT
FFT비재귀비트 반전Silver

[구현] 재귀 FFT는 직관적이지만 함수 호출 오버헤드가 있습니다.
실전에서는 비재귀(iterative) FFT가 더 빠르며, 비트 반전 순열(bit-reversal permutation)을 활용합니다.

비트 반전 순열:
재귀 분할 시 짝수/홀수 인덱스로 나누는 것을 반복하면,
최종적으로 원소가 인덱스의 비트를 반전시킨 위치에 놓입니다.
예: N=8일 때 0(000)→0, 1(001)→4(100), 2(010)→2(010), 3(011)→6(110), ...

Cfft.c
#include <stdio.h> #include <math.h> #define MAXN (1 << 20) #define PI 3.14159265358979323846 typedef struct { double re, im; } Complex; Complex cmul(Complex a, Complex b) { return (Complex){ a.re*b.re - a.im*b.im, a.re*b.im + a.im*b.re }; } Complex cadd(Complex a, Complex b) { return (Complex){ a.re + b.re, a.im + b.im }; } Complex csub(Complex a, Complex b) { return (Complex){ a.re - b.re, a.im - b.im }; } Complex A[MAXN], B[MAXN]; void fft(Complex *a, int n, int inv) { /* 비트 반전 순열 */ for (int i = 1, j = 0; i < n; i++) { int bit = n >> 1; for (; j & bit; bit >>= 1) j ^= bit; j ^= bit; if (i < j) { Complex t = a[i]; a[i] = a[j]; a[j] = t; } } /* 나비 연산 */ for (int len = 2; len <= n; len <<= 1) { double ang = 2 * PI / len * (inv ? -1 : 1); Complex wlen = { cos(ang), sin(ang) }; for (int i = 0; i < n; i += len) { Complex w = { 1, 0 }; for (int j = 0; j < len / 2; j++) { Complex u = a[i + j]; Complex v = cmul(a[i + j + len/2], w); a[i + j] = cadd(u, v); a[i + j + len/2] = csub(u, v); w = cmul(w, wlen); } } } if (inv) { for (int i = 0; i < n; i++) { a[i].re /= n; a[i].im /= n; } } } /* 다항식 곱셈: 결과를 res에 저장 */ void multiply(int *a, int na, int *b, int nb, long long *res) { int n = 1; while (n < na + nb) n <<= 1; for (int i = 0; i < n; i++) { A[i].re = (i < na) ? a[i] : 0; A[i].im = 0; B[i].re = (i < nb) ? b[i] : 0; B[i].im = 0; } fft(A, n, 0); fft(B, n, 0); for (int i = 0; i < n; i++) A[i] = cmul(A[i], B[i]); fft(A, n, 1); for (int i = 0; i < na + nb - 1; i++) res[i] = (long long)(A[i].re + 0.5); } int main(void) { int a[] = {1, 2, 3}; /* 1 + 2x + 3x² */ int b[] = {4, 5}; /* 4 + 5x */ long long res[5]; multiply(a, 3, b, 2, res); printf("결과: "); for (int i = 0; i < 4; i++) printf("%lld ", res[i]); printf("\n"); return 0; }

NTT (Number Theoretic Transform) — 모듈러 FFT
NTT원시근모듈러 산술Silver

[개념] NTT는 복소수 대신 모듈러 산술을 사용하는 FFT입니다.
부동소수점 오차가 없으며, 결과를 특정 소수 MOD로 나눈 나머지로 정확히 구합니다.

단위근 대체:
복소수 FFT: ω = e2πi/N (N번째 복소 단위근)
NTT: ω = g(MOD-1)/N mod MOD (원시근 g의 거듭제곱)
여기서 MOD는 MOD-1이 2의 큰 거듭제곱을 인수로 가지는 소수여야 합니다.

자주 사용하는 MOD:
998244353 = 119 × 223 + 1 (원시근 g = 3)
N ≤ 223 = 8388608까지 가능
이 소수는 대회에서 가장 널리 사용됩니다.

#include <stdio.h> #define MAXN (1 << 20) #define MOD 998244353LL #define G 3LL long long A[MAXN], B[MAXN]; long long power(long long base, long long exp, long long mod) { long long res = 1; base %= mod; while (exp > 0) { if (exp & 1) res = res * base % mod; base = base * base % mod; exp >>= 1; } return res; } void ntt(long long *a, int n, int inv) { /* 비트 반전 순열 */ for (int i = 1, j = 0; i < n; i++) { int bit = n >> 1; for (; j & bit; bit >>= 1) j ^= bit; j ^= bit; if (i < j) { long long t = a[i]; a[i] = a[j]; a[j] = t; } } for (int len = 2; len <= n; len <<= 1) { long long w = inv ? power(power(G, (MOD - 1) / len, MOD), MOD - 2, MOD) : power(G, (MOD - 1) / len, MOD); for (int i = 0; i < n; i += len) { long long wn = 1; for (int j = 0; j < len / 2; j++) { long long u = a[i + j]; long long v = a[i + j + len/2] * wn % MOD; a[i + j] = (u + v) % MOD; a[i + j + len/2] = (u - v + MOD) % MOD; wn = wn * w % MOD; } } } if (inv) { long long n_inv = power(n, MOD - 2, MOD); for (int i = 0; i < n; i++) a[i] = a[i] * n_inv % MOD; } } int main(void) { int na, nb; scanf("%d %d", &na, &nb); na++; nb++; for (int i = 0; i < na; i++) scanf("%lld", &A[i]); for (int i = 0; i < nb; i++) scanf("%lld", &B[i]); int n = 1; while (n < na + nb) n <<= 1; for (int i = na; i < n; i++) A[i] = 0; for (int i = nb; i < n; i++) B[i] = 0; ntt(A, n, 0); ntt(B, n, 0); for (int i = 0; i < n; i++) A[i] = A[i] * B[i] % MOD; ntt(A, n, 1); for (int i = 0; i < na + nb - 1; i++) printf("%lld ", A[i]); printf("\n"); return 0; }

[개념] 선형 점화식(linear recurrence)을 행렬 곱셈으로 표현하면,
행렬 거듭제곱을 통해 N번째 항을 O(k³ log N)에 구할 수 있습니다.
k는 점화식의 차수입니다.

예제 1: 피보나치 수열
F(n) = F(n-1) + F(n-2)
행렬 표현: [F(n+1), F(n)]T = [[1,1],[1,0]] × [F(n), F(n-1)]T
따라서 [F(n+1), F(n)]T = [[1,1],[1,0]]n × [F(1), F(0)]T

예제 2: 2×N 타일링
f(n) = f(n-1) + f(n-2) (피보나치와 같은 구조)
2×1과 1×2 타일로 2×N 직사각형을 채우는 방법의 수
행렬 거듭제곱으로 O(log N)에 계산 가능

예제 3: 그래프 경로 수
인접 행렬 A에서 Ak[i][j]는 정점 i에서 j로 가는 길이 k인 경로의 수입니다.
