문제 설명
N개의 정점으로 이루어진 루트 트리가 주어집니다.
각 정점에 가중치가 있습니다.
다음 두 종류의 쿼리를 처리해야 합니다:
1) 경로 쿼리: 정점 u에서 v까지의 경로 상 모든 정점 가중치에 val을 더합니다.
2) 서브트리 쿼리: 정점 u의 서브트리에 속한 모든 정점 가중치의 합을 출력합니다.
경로 갱신에는 HLD를, 서브트리 쿼리에는 오일러 투어 순서를 활용합니다.
핵심은 HLD 순서와 오일러 투어 순서가 동일한 세그먼트 트리를 공유할 수 있다는 점입니다.

HLD + 오일러 투어 통합 원리
HLD의 DFS 순서는 오일러 투어의 in-time과 동일합니다.
따라서 하나의 세그먼트 트리로 경로 쿼리와 서브트리 쿼리를 모두 처리합니다.
경로 업데이트: HLD 체인을 따라 구간 갱신 (Lazy Propagation)
서브트리 합: in[u] ~ out[u] 구간 합 쿼리
두 연산이 같은 배열 위에서 동작하므로 갱신과 쿼리가 상호 반영됩니다.

센트로이드 분할FFT다항식 곱GOLD

문제 설명
N개의 정점으로 이루어진 트리가 주어집니다.
거리가 정확히 k인 정점 쌍의 수를 모든 k (1 ≤ k ≤ N-1)에 대해 구하세요.
나이브하게 풀면 O(N²)이지만, 센트로이드 분할 + FFT로 O(N log² N)에 해결합니다.

핵심 아이디어
센트로이드 분할: 트리를 센트로이드 기준으로 재귀 분할합니다.
각 센트로이드에서 서브트리별 깊이 분포를 다항식으로 표현합니다.
cnt[d] = 깊이 d인 정점 수 → 다항식 A(x) = ∑ cnt[d] · x^d
두 서브트리의 다항식을 FFT로 곱하면 거리별 쌍의 수를 얻습니다.
중복 카운팅 방지를 위해 전체 서브트리 곱에서 각 자식 서브트리 곱을 뺍니다.

다항식 곱의 의미
A(x) · B(x)의 k차 계수 = ∑ A[i] · B[k-i]
이는 한쪽에서 깊이 i, 다른쪽에서 깊이 k-i인 정점 쌍의 수입니다.
센트로이드를 경유하므로 실제 거리는 i + (k-i) = k가 됩니다.

Splay 트리 + 구간 연산
Splay 트리구간 뒤집기LazyGOLD

문제 설명
길이 N의 문자열이 주어집니다.
다음 연산을 Q번 수행합니다:
1) Reverse(l, r): 구간 [l, r]의 문자를 뒤집습니다.
2) Move(l, r, k): 구간 [l, r]을 잘라내어 위치 k 뒤에 삽입합니다.
3) Print(l, r): 구간 [l, r]의 문자열을 출력합니다.
배열로는 O(NQ)이지만 Splay 트리를 사용하면 각 연산이 amortized O(log N)입니다.

Splay 트리의 구간 연산 원리
Splay 트리에서 구간 [l, r]을 추출하는 방법:
1) l-1번째 원소를 루트로 splay합니다.
2) r+1번째 원소를 루트의 오른쪽 자식으로 splay합니다.
3) 그러면 r+1의 왼쪽 서브트리가 정확히 [l, r] 구간입니다.
이 서브트리에 lazy 태그를 달아 뒤집기를 O(1)에 처리합니다.
Move 연산: 구간을 잘라내고(split) 원하는 위치에 붙입니다(merge).

Lazy Propagation in Splay
rev 플래그: 해당 서브트리 전체를 뒤집어야 함을 표시합니다.
push 시 왼쪽/오른쪽 자식을 교환하고 자식에 플래그를 전파합니다.
splay, find_kth 등 노드를 방문할 때마다 push를 먼저 호출합니다.

상태 전이 행렬 구축
S × S 행렬 A를 만듭니다.
A[i][j] = 상태 i에서 상태 j로의 전이 가능 여부 (또는 경로 수).
N턴 후 전이: A^N을 계산합니다.

행렬 거듭제곱 (Matrix Exponentiation)
A^N = A^(N/2) * A^(N/2) (N 짝수)
A^N = A^(N-1) * A (N 홀수)
분할 정복으로 O(S³ log N)에 계산합니다.

SECTION 709Gold | 극한 실전 I
볼록 껍질 트릭 (CHT) + Li Chao 트리
CHTLi Chao 트리DP 최적화GOLD

문제 설명
N개의 작업이 있으며, i번째 작업의 비용은 a[i] * t + b[i]입니다 (t는 시작 시간).
작업을 순서대로 처리하며, dp[i] = min(dp[j] + a[i] * t[j] + b[i])로 전이합니다.
나이브 O(N²)을 CHT로 O(N log N)에 최적화합니다.

볼록 껍질 트릭 (Convex Hull Trick)
dp[j] + a[i]*t[j]에서, j마다 직선 y = t[j]*x + dp[j]를 유지합니다.
쿼리 x = a[i]에서 최솟값을 구합니다.
직선들의 하부 볼록 껍질을 관리하면 됩니다.
기울기 또는 쿼리가 단조적이면 O(N), 아니면 O(N log N)입니다.

Li Chao 트리
세그먼트 트리와 유사한 구조로, 각 노드에 직선 하나를 저장합니다.
삽입: 구간의 중점에서 기존 직선과 새 직선을 비교하여 교체/재귀합니다.
쿼리: 루트에서 리프까지 경로의 직선 중 최솟값을 취합니다.
기울기 순서에 무관하게 O(log X)에 삽입/쿼리합니다 (X = 좌표 범위).

문제 설명 (AtCoder 스타일)
N개의 원소를 K개의 연속 구간으로 분할합니다.
각 구간 [i, j]의 비용은 cost(i, j)이며, 총 비용을 최소화하세요.
dp[k][j] = 처음 j개 원소를 k개 구간으로 나눈 최소 비용.
dp[k][j] = min(dp[k-1][i] + cost(i+1, j)) for i < j.

Knuth 최적화 (Knuth's Optimization)
cost 함수가 사각 부등식(quadrangle inequality)을 만족하면 적용 가능합니다.
opt[k][j] = dp[k][j]를 최소화하는 i라 하면, opt[k][j-1] ≤ opt[k][j] ≤ opt[k+1][j].
이를 통해 O(N³) → O(N²)로 줄어듭니다.

CHT와의 결합
cost 함수가 특정 형태면 dp[k-1][i] + cost(i+1, j)를 직선 형태로 변환할 수 있습니다.
예: cost(i+1, j) = f(j) - f(i) - g(i)*h(j) 형태이면 CHT 적용 가능.
Knuth로 탐색 범위를 좁히고, CHT로 전이를 가속합니다.
