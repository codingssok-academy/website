인터랙티브 문제 개요
인터랙티브fflush통신 프로토콜GOLD

인터랙티브 문제란?
일반적인 프로그래밍 문제는 입력을 한 번에 받고 출력을 한 번에 내보냅니다.
인터랙티브 문제는 프로그램이 채점기(judge)와 질의-응답을 반복합니다.
프로그램이 질문을 출력하면 채점기가 답을 돌려주고, 이를 바탕으로 최종 답을 결정합니다.
핵심은 제한된 질의 횟수 안에 정답을 찾아내는 전략입니다.

fflush(stdout)의 중요성
C 표준 출력은 버퍼링됩니다.
printf로 질의를 출력한 뒤 fflush(stdout)를 호출하지 않으면 채점기가 질의를 받지 못합니다.
결과적으로 프로그램은 채점기의 응답을 영원히 기다리며 TLE(시간 초과)가 됩니다.
모든 질의 출력 직후 반드시 fflush(stdout)를 호출해야 합니다.

적응형 vs 비적응형
비적응형(Non-Adaptive): 채점기가 미리 답을 고정합니다. 프로그램의 질의에 관계없이 답이 바뀌지 않습니다.
적응형(Adaptive): 채점기가 프로그램의 질의를 보고 답을 동적으로 조정할 수 있습니다. 이전 응답과 모순되지 않는 한 최악의 경우를 만들어냅니다.
적응형 문제는 결정론적(deterministic) 전략이 필요합니다.

통신 프로토콜 패턴
1. 프로그램이 질의 타입과 파라미터를 출력합니다 (예: ? x)
2. fflush(stdout)를 호출합니다
3. scanf로 채점기의 응답을 읽습니다
4. 응답을 분석하여 다음 질의를 결정합니다
5. 최종 답을 찾으면 ! answer 형식으로 출력합니다

이분 탐색인터랙티브log₂N 질의GOLD

문제 유형
채점기가 1~N 사이의 숫자 하나를 골랐습니다.
프로그램은 매 질의에서 숫자 하나를 제시하고, 채점기는 "더 크다/작다/맞다"를 알려줍니다.
최대 ⌈log₂N⌉번의 질의로 숫자를 맞춰야 합니다.
이진 탐색의 가장 직접적인 응용입니다.

핵심 전략
매 질의마다 남은 범위를 정확히 절반으로 나눕니다.
mid = (lo + hi) / 2를 질의합니다.
응답에 따라 lo 또는 hi를 갱신합니다.
lo == hi가 되면 답을 확정합니다.

질의 수 분석
N = 2^k일 때 정확히 k번의 질의가 필요합니다.
일반적으로 ⌈log₂N⌉번이면 충분합니다.
N = 10^9이면 최대 30번의 질의로 답을 찾을 수 있습니다.
N = 10^18이면 최대 60번입니다.

Cbinary_search_interactive.c
#include <stdio.h> /* * 채점기 프로토콜: * 입력: N (범위 상한) * 질의: "? x" → 응답: -1 (답<x), 0 (정답), 1 (답>x) * 출력: "! answer" * 질의 제한: ceil(log2(N)) */ int main(void) { int n; scanf("%d", &n); int lo = 1, hi = n; while (lo < hi) { int mid = lo + (hi - lo) / 2; printf("? %d\n", mid); fflush(stdout); int res; scanf("%d", &res); if (res == 0) { // 정답을 맞춤 printf("! %d\n", mid); fflush(stdout); return 0; } else if (res == 1) { // 답이 mid보다 큼 lo = mid + 1; } else { // 답이 mid보다 작음 hi = mid - 1; } } printf("! %d\n", lo); fflush(stdout); return 0; }

문제 개요
N개의 정점으로 이루어진 미지의 그래프가 있습니다.
프로그램은 질의 ? u를 통해 정점 u의 인접 정점 목록을 얻을 수 있습니다.
제한된 질의 횟수 내에 특정 조건(예: 정점 1에서 정점 N까지의 최단 경로)을 찾아야 합니다.
핵심은 불필요한 정점을 탐색하지 않는 전략입니다.

BFS 기반 전략
시작 정점에서 BFS를 수행합니다.
큐에서 정점을 꺼낼 때마다 해당 정점의 인접 정보를 질의합니다.
이미 방문한 정점은 다시 질의하지 않습니다.
최단 경로를 찾으면 즉시 종료합니다.

DFS 기반 전략
목표가 연결 성분 파악이나 사이클 탐지인 경우 DFS가 유리합니다.
스택을 사용하여 깊이 우선 탐색을 수행합니다.
백트래킹 시 추가 질의가 필요 없으므로 질의 수가 절약됩니다.

Cgraph_interactive_bfs.c
#include <stdio.h> #include <string.h> #define MAXN 1005 int visited[MAXN], parent[MAXN]; int queue[MAXN], front, rear; /* 질의: 정점 u의 인접 정보를 얻는다 * 프로토콜: "? u" → 응답: k v1 v2 ... vk */ int adj[MAXN], adj_count; void query(int u) { printf("? %d\n", u); fflush(stdout); scanf("%d", &adj_count); for (int i = 0; i < adj_count; i++) scanf("%d", &adj[i]); } int main(void) { int n, target; scanf("%d %d", &n, &target); memset(visited, 0, sizeof(visited)); memset(parent, -1, sizeof(parent)); front = rear = 0; // BFS 시작: 정점 1 visited[1] = 1; queue[rear++] = 1; while (front < rear) { int u = queue[front++]; query(u); // 인접 정보 질의 for (int i = 0; i < adj_count; i++) { int v = adj[i]; if (!visited[v]) { visited[v] = 1; parent[v] = u; queue[rear++] = v; if (v == target) { // 경로 역추적 후 출력 int path[MAXN], plen = 0; for (int x = target; x != -1; x = parent[x]) path[plen++] = x; printf("! %d", plen); for (int j = plen - 1; j >= 0; j--) printf(" %d", path[j]); printf("\n"); fflush(stdout); return 0; } } } } printf("! -1\n"); // 도달 불가 fflush(stdout); return 0; }

SECTION 679Gold | 인터랙티브 문제
비교 기반 인터랙티브
비교 정렬머지소트인터랙티브GOLD

문제 개요
N개의 원소가 있으며, 각 원소의 값은 알 수 없습니다.
질의 ? i j로 원소 i와 j를 비교하면, 채점기가 어느 쪽이 더 큰지 알려줍니다.
제한된 비교 횟수 내에 원소들을 정렬하거나 k번째 원소를 찾아야 합니다.
비교 횟수의 하한은 정보 이론에 의해 결정됩니다.

정렬의 비교 횟수 하한
N개 원소의 순열은 N!가지입니다.
각 비교는 2가지 결과를 줍니다.
따라서 최소 ⌈log₂(N!)⌉번의 비교가 필요합니다.
스털링 근사: log₂(N!) ≈ N log₂N - N/ln2
머지소트는 약 N log₂N번의 비교를 사용하므로 거의 최적입니다.

머지소트 기반 전략
머지소트를 그대로 구현하되, 원소 비교를 인터랙티브 질의로 대체합니다.
N=1000일 때 약 10,000번의 비교로 정렬 가능합니다.
대부분의 인터랙티브 정렬 문제는 이 정도 질의 제한을 줍니다.

Ccompare_interactive.c
#include <stdio.h> #define MAXN 1005 int arr[MAXN], tmp[MAXN]; /* 비교 질의: i와 j 중 어느 것이 큰지 묻는다 * 응답: 1 (arr[i] < arr[j]), 2 (arr[i] > arr[j]) */ int ask(int i, int j) { printf("? %d %d\n", i, j); fflush(stdout); int res; scanf("%d", &res); return res; } void merge_sort(int *a, int l, int r) { if (l >= r) return; int mid = (l + r) / 2; merge_sort(a, l, mid); merge_sort(a, mid + 1, r); int i = l, j = mid + 1, k = l; while (i <= mid && j <= r) { if (ask(a[i], a[j]) == 1) // a[i] < a[j] tmp[k++] = a[i++]; else tmp[k++] = a[j++]; } while (i <= mid) tmp[k++] = a[i++]; while (j <= r) tmp[k++] = a[j++]; for (int x = l; x <= r; x++) a[x] = tmp[x]; } int main(void) { int n; scanf("%d", &n); for (int i = 0; i < n; i++) arr[i] = i + 1; merge_sort(arr, 0, n - 1); printf("!"); for (int i = 0; i < n; i++) printf(" %d", arr[i]); printf("\n"); fflush(stdout); return 0; }

SECTION 680Gold | 인터랙티브 문제
적응형(Adaptive) 인터랙티브
적응형결정론적 전략인터랙티브GOLD

적응형 채점기란?
비적응형 채점기는 게임 시작 전에 답을 고정합니다.
적응형 채점기는 프로그램의 질의를 보면서 답을 바꿀 수 있습니다.
단, 이전에 준 모든 응답과 모순되지 않아야 합니다.
채점기는 항상 최악의 경우를 만들려고 합니다.

왜 결정론적 전략이 필요한가?
난수 기반 전략은 적응형 채점기에게 취약합니다.
채점기가 프로그램의 난수 시드를 모르더라도, 프로그램의 출력을 관찰하고 대응할 수 있습니다.
따라서 최악의 경우에도 보장되는 결정론적 전략을 세워야 합니다.

예제: 적응형 숫자 맞추기
범위 [1, N]에서 숫자를 맞추되, 채점기가 적응형입니다.
채점기는 남은 가능한 답의 집합(candidate set)이 항상 비어있지 않도록 응답합니다.
이분 탐색 전략: 매번 candidate set을 정확히 절반으로 나누는 질의를 합니다.
어떤 응답이 오든 candidate set이 절반 이하로 줄어듭니다.
따라서 ⌈log₂N⌉번이면 충분합니다.

적응형에서 흔한 실수
1. 이전 응답과 일관성 없는 상태 관리
2. candidate set 갱신을 빠뜨림
3. 질의 결과를 가정하고 다음 질의를 미리 결정 (파이프라이닝 불가)

Cadaptive_example.c
#include <stdio.h> /* * 적응형 숫자 맞추기 * 채점기는 응답을 동적으로 바꿀 수 있음 * 전략: 항상 candidate set의 중앙값을 질의 * 보장: ceil(log2(N)) 질의 이내에 반드시 답을 찾음 */ int main(void) { int n; scanf("%d", &n); // candidate set: [lo, hi] int lo = 1, hi = n; while (lo < hi) { int mid = lo + (hi - lo) / 2; // 질의: "답이 mid 이하인가?" printf("? %d\n", mid); fflush(stdout); int res; scanf("%d", &res); if (res == 1) { // 채점기 답: "답 ≤ mid" hi = mid; } else { // 채점기 답: "답 > mid" lo = mid + 1; } // 어떤 응답이든 candidate set은 절반 이하 } printf("! %d\n", lo); fflush(stdout); return 0; }

문제 개요
N개의 정점으로 이루어진 미지의 트리가 있습니다.
질의를 통해 트리의 구조를 복원해야 합니다.
질의 유형은 문제마다 다르지만 대표적으로:
• ? u v: 정점 u와 v 사이의 거리 반환
• ? u v: 정점 u와 v의 LCA 반환
제한된 질의 횟수 내에 N-1개의 간선을 모두 찾아야 합니다.

거리 질의 기반 복원
정점 1을 루트로 잡고, 모든 정점까지의 거리를 질의합니다 (N-1번).
거리 순으로 정렬합니다.
각 정점 v의 부모를 찾기 위해 dist(v)-1 거리인 정점 중 LCA를 확인합니다.
총 질의 수: O(N) ~ O(N log N)

LCA 질의 기반 복원
정점을 하나씩 추가하면서 트리를 구성합니다.
새 정점 v를 추가할 때, 기존 정점들과의 LCA를 질의합니다.
LCA 정보를 통해 v의 정확한 위치를 결정합니다.
이진 탐색을 활용하면 O(N log N) 질의로 가능합니다.

Prüfer 수열 활용
Prüfer 수열은 N-2 길이의 수열로 레이블 트리를 유일하게 표현합니다.
질의로 Prüfer 수열의 각 원소를 결정할 수 있으면 트리를 복원할 수 있습니다.
리프 노드를 먼저 식별하고, 해당 리프의 유일한 이웃을 찾는 방식입니다.

문제 개요
채점기가 N차 다항식 f(x) = a₀ + a₁x + a₂x² + ... + aₙxⁿ을 숨겼습니다.
질의 ? x로 f(x)의 값을 얻을 수 있습니다.
N+1번의 질의로 다항식의 모든 계수를 복원해야 합니다.
N+1개의 점이 주어지면 N차 다항식은 유일하게 결정됩니다.

라그랑주 보간법
N+1개의 점 (x₀, y₀), (x₁, y₁), ..., (xₙ, yₙ)이 주어지면:
f(x) = ∑ yₖ · ∏(x - xⱼ) / (xₖ - xⱼ) (j ≠ k)
각 기저 다항식 Lₖ(x) = ∏(x - xⱼ) / (xₖ - xⱼ)는 xₖ에서 1, 나머지에서 0입니다.
계수를 직접 추출하려면 다항식 곱셈을 수행해야 합니다.

전략: 연속 정수 대입
x = 0, 1, 2, ..., N을 질의하면 가장 간단합니다.
이산 차분(finite difference)을 사용하면 계수를 O(N²)에 구할 수 있습니다.
Δ⁰f = f(0), Δ¹f = f(1)-f(0), Δ²f = f(2)-2f(1)+f(0), ...
aₖ = Δᵏf(0) / k!

문제 개요
간선이 추가되고 삭제되는 그래프에서 연결성 쿼리를 처리해야 합니다.
온라인으로 처리하려면 Link-Cut Tree가 필요하지만 구현이 매우 복잡합니다.
모든 쿼리를 미리 알 수 있다면(오프라인), 더 간단한 방법이 있습니다.

간선의 존재 시간 구간
각 간선은 추가된 시점 t₁과 삭제된 시점 t₂가 있습니다.
따라서 간선 e는 시간 구간 [t₁, t₂)에만 존재합니다.
이 구간을 시간축 세그먼트 트리에 삽입합니다.
세그먼트 트리의 각 노드에는 해당 시간 범위에 완전히 포함되는 간선들의 리스트가 저장됩니다.

분할 정복 + Undo Union-Find
세그먼트 트리를 DFS로 순회합니다.
각 노드에 진입할 때 해당 간선들을 Union-Find에 추가합니다.
리프 노드에 도달하면 해당 시점의 연결성 쿼리에 답합니다.
노드에서 빠져나올 때 Union-Find를 롤백(Undo)합니다.
롤백을 위해 경로 압축은 사용하지 않고, union by rank만 사용합니다.

Coffline_dynamic_connectivity.c
#include <stdio.h> #include <string.h> #define MAXN 200005 #define MAXQ 200005 #define MAXT 800020 /* Undo Union-Find (경로 압축 없음, union by rank) */ int par[MAXN], rnk[MAXN]; int stk_a[MAXQ], stk_b[MAXQ], stk_top; // undo 스택 void uf_init(int n) { for (int i = 0; i <= n; i++) { par[i] = i; rnk[i] = 0; } stk_top = 0; } int find(int x) { while (par[x] != x) x = par[x]; return x; } int unite(int a, int b) { a = find(a); b = find(b); if (a == b) return 0; if (rnk[a] < rnk[b]) { int t = a; a = b; b = t; } stk_a[stk_top] = b; stk_b[stk_top] = rnk[a]; stk_top++; par[b] = a; if (rnk[a] == rnk[b]) rnk[a]++; return 1; } void undo(int save) { while (stk_top > save) { stk_top--; int b = stk_a[stk_top]; int old_rnk = stk_b[stk_top]; int a = par[b]; par[b] = b; rnk[a] = old_rnk; } } /* 세그먼트 트리 노드에 간선 저장 */ int seg_edges[MAXT][20]; // 간선 인덱스 int seg_cnt[MAXT]; int eu[MAXQ], ev[MAXQ]; // 간선 u, v void seg_add(int node, int s, int e, int l, int r, int eid) { if (l > e || r < s) return; if (l <= s && e <= r) { seg_edges[node][seg_cnt[node]++] = eid; return; } int mid = (s + e) / 2; seg_add(node*2, s, mid, l, r, eid); seg_add(node*2+1, mid+1, e, l, r, eid); } int ans[MAXQ], qry_u[MAXQ], qry_v[MAXQ], qry_t[MAXQ]; int qcnt; void solve(int node, int s, int e) { int save = stk_top; for (int i = 0; i < seg_cnt[node]; i++) unite(eu[seg_edges[node][i]], ev[seg_edges[node][i]]); if (s == e) { // 리프: 시점 s의 쿼리에 답 if (qry_t[s] >= 0) ans[s] = (find(qry_u[s]) == find(qry_v[s])); } else { int mid = (s + e) / 2; solve(node*2, s, mid); solve(node*2+1, mid+1, e); } undo(save); // 롤백 } int main(void) { int n, q; scanf("%d %d", &n, &q); uf_init(n); memset(seg_cnt, 0, sizeof(seg_cnt)); memset(qry_t, -1, sizeof(qry_t)); // 쿼리 파싱 및 간선 구간 등록은 문제에 맞게 구현 // solve(1, 0, q-1) 호출 후 ans[] 출력 solve(1, 0, q - 1); for (int i = 0; i < q; i++) if (qry_t[i] >= 0) printf("%s\n", ans[i] ? "YES" : "NO"); return 0; }

find 연산은 O(log N)이지만 전체 시간 복잡도는 O(Q log Q log N)으로 충분합니다.

시간 분할 (Sqrt Decomposition on Time)
Sqrt Decomposition시간축삽입/삭제GOLD

개념
쿼리를 시간 순으로 √Q개씩 묶어 블록으로 나눕니다.
각 블록의 시작 시점에 전체 자료구조를 재구성합니다.
블록 내부에서는 변경 사항을 별도로 관리합니다.
블록이 끝나면 변경 사항을 병합하고 다음 블록으로 넘어갑니다.

삽입/삭제 균형
삽입만 있는 문제는 간단하지만, 삭제가 섞이면 복잡해집니다.
시간 분할을 사용하면 삭제를 "블록 경계에서의 재구성"으로 대체할 수 있습니다.
블록 크기 B = √Q로 설정하면:
• 재구성 횟수: Q/B = √Q
• 각 재구성 비용: O(N) 또는 O(N log N)
• 블록 내 쿼리 처리: 각 O(B) = O(√Q)

응용 예시: 집합에 원소 추가/삭제 + 쿼리
집합에 원소를 추가하거나 삭제하면서, 특정 조건을 만족하는 원소 수를 묻는 쿼리가 있습니다.
매 블록 시작 시 현재 집합 상태를 정렬된 배열로 유지합니다.
블록 내의 추가/삭제는 작은 보조 배열에 기록합니다.

롤백이란?
자료구조의 상태를 이전 시점으로 되돌리는 연산입니다.
분할 정복, 세그먼트 트리 DFS 등에서 "진입 시 추가, 퇴장 시 복원" 패턴에 필수입니다.
스택에 변경 이력을 기록하고, 되돌릴 때 역순으로 복원합니다.

Union-Find Rollback
Union by rank를 사용합니다 (경로 압축 불가).
unite(a, b) 시 변경된 정보를 스택에 push합니다:
• 어떤 노드의 parent가 바뀌었는지
• 어떤 노드의 rank가 바뀌었는지
rollback(save_point) 시 스택을 save_point까지 pop하며 원상 복구합니다.

Persistent 대안
Persistent 자료구조는 모든 버전을 동시에 유지합니다.
공간 O(N log N), 각 연산 O(log N)입니다.
Rollback은 공간 O(N)이지만 특정 순서로만 되돌릴 수 있습니다 (LIFO).
분할 정복 패턴에서는 LIFO 롤백으로 충분합니다.

개념
트리의 각 정점에 대해 서브트리 내의 정보를 집계해야 하는 문제입니다.
예: 각 서브트리에서 가장 많이 등장하는 색은 무엇인가?

핵심 아이디어
각 정점에 "집합"을 유지합니다.
자식들의 집합을 합칠 때, 항상 작은 집합을 큰 집합에 병합합니다.
이렇게 하면 각 원소가 병합되는 횟수가 O(log N)번입니다.
이유: 원소가 병합될 때마다 속한 집합의 크기가 최소 2배가 됩니다.

DSU on tree (Euler Tour 기반)
Heavy child의 결과를 재활용하고, light child의 결과만 다시 계산합니다.
1. 각 정점의 heavy child를 결정합니다 (서브트리 크기가 가장 큰 자식)
2. DFS 순서: light children 먼저 처리 (결과 버림) → heavy child 처리 (결과 유지)
3. 현재 정점과 light children의 원소를 heavy child의 결과에 추가

문제 유형

모든 쿼리를 동시에 이분 탐색하면 O((T + Q) · log T)로 줄일 수 있습니다.

알고리즘
1. 각 쿼리 i에 대해 lo[i] = 0, hi[i] = T를 초기화합니다.
2. 반복 (최대 log T번):
  a. 각 쿼리의 mid[i] = (lo[i] + hi[i]) / 2를 계산합니다.
  b. 시간 0부터 T까지 이벤트를 순서대로 처리합니다.
  c. 시간 t를 처리한 후, mid[i] == t인 모든 쿼리 i의 조건을 검사합니다.
  d. 조건 만족 시 hi[i] = mid[i], 아니면 lo[i] = mid[i] + 1
3. lo[i]가 최종 답입니다.

문제 유형
"정확히 K개를 선택하여 비용을 최소화하라"와 같은 제약 최적화 문제입니다.
K를 고정하면 풀기 어렵지만, K에 대한 페널티를 부과하면 제약 없이 풀 수 있는 경우가 있습니다.
이때 최적의 페널티 값을 이분 탐색으로 찾는 기법입니다.

WQS Binary Search (WBBS)
비용 함수 f(k)가 볼록(convex)하다고 가정합니다.
g(λ) = min_k { f(k) + λ · k }를 정의합니다.
λ를 고정하면 K 제약 없이 최적화할 수 있습니다.
g(λ)는 λ에 대해 오목(concave)하므로, 최적 λ를 이분 탐색합니다.
f(K) = g(λ*) - λ* · K입니다.

Aliens 트릭
IOI 2016 "Aliens" 문제에서 유래한 이름입니다.
WQS Binary Search와 본질적으로 같은 기법입니다.
DP 전이에서 "선택 횟수"에 비례하는 페널티를 추가합니다.

Suffix Array + LCP 활용
Suffix Array(SA)를 구축합니다.
인접한 접미사 사이의 LCP(Longest Common Prefix)를 계산합니다.
서로 다른 부분 문자열 수 = ∑(N - SA[i] - LCP[i])
= N(N+1)/2 - ∑LCP[i]

왜 이 공식이 성립하는가?
SA 순서로 접미사를 나열하면 사전순으로 정렬됩니다.
i번째 접미사의 길이는 N - SA[i]이고, 이것이 가진 부분 문자열(접두사)의 수는 N - SA[i]개입니다.
이 중 LCP[i]개는 이전 접미사와 겹칩니다.
따라서 새로운 부분 문자열 수는 (N - SA[i]) - LCP[i]개입니다.

오일러 투어 (Euler Tour Linearization, ETL)
DFS 순서로 트리를 1차원 배열로 펼칩니다.
각 정점 v의 진입 시각 tin[v]와 퇴장 시각 tout[v]를 기록합니다.
v의 서브트리 = 배열의 구간 [tin[v], tout[v]]
서브트리 쿼리가 구간 쿼리로 변환됩니다.

BIT (Binary Indexed Tree) 활용
점 업데이트 + 구간 합 쿼리 → BIT가 최적입니다.
업데이트: BIT의 tin[v] 위치에 x를 더합니다.
서브트리 합: BIT에서 구간 [tin[v], tout[v]]의 합을 구합니다.
시간 복잡도: 각 연산 O(log N)
