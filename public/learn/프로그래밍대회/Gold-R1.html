DP 최적화 기법이 필요한 이유
일반적인 DP의 전이가 O(N)이고, 상태가 O(N²)이면 전체 O(N³)이 됩니다.
N이 5000 이상이면 시간 초과가 불가피합니다.
DP 최적화 기법은 전이 구조의 특수한 성질을 이용하여 복잡도를 줄입니다.
각 기법은 적용 조건이 다르므로, 조건을 정확히 판별하는 것이 핵심입니다.

5대 DP 최적화 기법 총정리
1) Knuth 최적화: 구간 DP에서 최적 분할점이 단조 증가할 때 적용
  조건: C[a][c] + C[b][d] ≤ C[a][d] + C[b][c] (사각부등식)
  복잡도: O(N³) → O(N²)
2) Convex Hull Trick (CHT): dp[i] = min(dp[j] + b[j]·a[i]) 꼴일 때
  조건: 전이가 일차함수 형태, 기울기 또는 쿼리 단조
  복잡도: O(N²) → O(N) 또는 O(N log N)
3) 분할정복 최적화: opt[i] ≤ opt[i+1] (최적 전이점 단조)
  조건: 비용 함수가 사각부등식 만족
  복잡도: O(KN²) → O(KN log N)
4) Aliens 트릭 (WQS 이분 탐색): “정확히 K개” 조건을 라그랑주 완화
  조건: 최적값이 K에 대해 볼록 함수
  복잡도: O(f(N) · log W) (f(N)은 완화 문제의 복잡도)
5) Slope Trick: dp 함수가 구간별 선형(piecewise linear)일 때
  조건: 전이가 함수의 기울기 변화점만 관리 가능
  복잡도: 문제마다 다름, 보통 O(N log N)

Aliens 트릭이란?
IOI 2016 “Aliens” 문제에서 유래한 기법입니다.
“정확히 K개를 선택하라”는 제약이 있는 최적화 문제에서,
제약을 라그랑주 승수 λ로 완화하여 K 제약 없는 문제로 바꿉니다.
완화된 문제: g(λ) = min(f(k) + λ·k) for all k
f(k)가 k에 대해 볼록이면, λ를 이분 탐색하여 정확히 k=K인 답을 찾을 수 있습니다.

볼록성 조건
f(k) = “정확히 k개 선택했을 때의 최적값”이라 하면,
f(k)가 아래로 볼록(convex): f(k-1) + f(k+1) ≥ 2f(k)
이 조건이 성립해야 λ 이분 탐색이 정확한 답을 줍니다.
직관: k를 1 늘릴 때의 한계이익이 단조감소해야 합니다.

λ 이분 탐색 과정
Step 1: λ의 범위를 설정 (보통 [0, MAX_COST])
Step 2: 고정된 λ에 대해 완화 문제를 풀고 최적 k를 구한다
Step 3: 최적 k > K이면 λ를 늘리고, k < K이면 λ를 줄인다
Step 4: k = K가 되는 λ를 찾으면, 답 = g(λ) - λ·K

정수 이분 탐색 주의사항
비용이 정수인 경우, λ도 정수로 이분 탐색할 수 있습니다.
볼록 함수에서 기울기가 정수이므로, λ를 0.5 단위로 탐색하면 됩니다.
실수 이분 탐색은 정밀도 오류의 원인이 되므로 가능하면 정수를 사용하세요.

Caliens_trick.c
#include <stdio.h> #include <string.h> #define MAXN 100005 long long dp[MAXN]; // dp[i] = 완화 문제의 최적값 (i번째까지) int cnt[MAXN]; // cnt[i] = dp[i] 달성 시 선택한 개수 int a[MAXN]; int n, K; /* 고정된 lambda에 대해 완화 문제를 푼다 */ /* 반환: 최적 선택 개수 */ int solve(long long lam) { /* 예시: 구간 분할 문제 */ /* dp[i] = min over j (dp[j] + cost(j+1,i) + lam) */ dp[0] = 0; cnt[0] = 0; for (int i = 1; i <= n; i++) { dp[i] = 1LL << 60; for (int j = 0; j < i; j++) { /* cost(j+1, i)를 문제에 맞게 계산 */ long long c = (long long)(a[i] - a[j + 1]) * (a[i] - a[j + 1]); long long val = dp[j] + c + lam; if (val < dp[i] || (val == dp[i] && cnt[j] + 1 < cnt[i])) { dp[i] = val; cnt[i] = cnt[j] + 1; } } } return cnt[n]; } int main(void) { scanf("%d %d", &n, &K); for (int i = 1; i <= n; i++) scanf("%d", &a[i]); /* 정수 이분 탐색: lambda 범위 */ long long lo = 0, hi = 1000000000LL * 1000000000LL; long long ans = 0; while (lo <= hi) { long long mid = (lo + hi) / 2; int k = solve(mid); if (k <= K) { ans = dp[n] - (long long)K * mid; hi = mid - 1; } else { lo = mid + 1; } } printf("%lld\n", ans); return 0; }

Convex Hull Trick(CHT)의 핵심 아이디어
점화식이 dp[i] = min(dp[j] + b[j] * a[i]) 꼴일 때 적용합니다.
dp[j] + b[j] * x를 기울기 b[j], y절편 dp[j]인 직선으로 봅니다.
모든 j에 대해 직선을 추가하고, x = a[i]에서 최솟값을 쿼리합니다.
직선들의 하한 엔벨로프(lower envelope)가 볼록 껍질을 이룹니다.

단조 스택 기반 CHT (기울기 단조 감소)
직선을 기울기 순으로 정렬하여 추가할 수 있는 경우에 사용합니다.
새 직선이 기존 직선보다 항상 유리해지는 교차점을 계산합니다.
스택의 마지막 직선이 불필요하면 pop합니다.
쿼리도 x가 단조 증가하면 포인터를 유지하여 O(1) amortized입니다.

Li Chao 트리 (임의 순서 추가/쿼리)
기울기나 쿼리 순서에 제약이 없을 때 사용합니다.
세그먼트 트리 구조에서 각 노드에 “우세 직선”을 저장합니다.
추가: O(log X), 쿼리: O(log X), X = 좌표 범위

Ccht_deque.c
#include <stdio.h> #define MAXN 100005 typedef struct { long long m, b; // y = m*x + b } Line; Line hull[MAXN]; int hn = 0; /* 직선 c가 직선 a,b 사이에서 불필요한지 판별 */ int bad(Line a, Line b, Line c) { /* 교차점 a∩c가 a∩b보다 왼쪽이면 b 불필요 */ return (double)(c.b - a.b) * (a.m - b.m) <= (double)(b.b - a.b) * (a.m - c.m); } void addLine(long long m, long long b) { Line l = {m, b}; while (hn >= 2 && bad(hull[hn - 2], hull[hn - 1], l)) hn--; hull[hn++] = l; } long long eval(Line l, long long x) { return l.m * x + l.b; } int ptr = 0; long long query(long long x) { /* 쿼리 x가 단조 증가할 때 포인터 유지 */ while (ptr + 1 < hn && eval(hull[ptr + 1], x) <= eval(hull[ptr], x)) ptr++; return eval(hull[ptr], x); } long long dp[MAXN]; long long a[MAXN], bArr[MAXN]; int main(void) { int n; scanf("%d", &n); for (int i = 1; i <= n; i++) scanf("%lld %lld", &a[i], &bArr[i]); /* dp[i] = min(dp[j] + bArr[j] * a[i]) */ dp[0] = 0; addLine(bArr[0], dp[0]); /* 초기 직선 */ for (int i = 1; i <= n; i++) { dp[i] = query(a[i]); addLine(bArr[i], dp[i]); } printf("%lld\n", dp[n]); return 0; }

#include <stdio.h> #include <limits.h> #define SZ 400005 #define XMAX 100001 typedef struct { long long m, b; } Line; Line tree[SZ]; int init_done = 0; long long ev(Line l, long long x) { return l.m * x + l.b; } void lc_init() { for (int i = 0; i < SZ; i++) tree[i] = (Line){0, LLONG_MAX}; init_done = 1; } void lc_add(int nd, int lo, int hi, Line seg) { int mid = (lo + hi) / 2; int left_better = ev(seg, lo) < ev(tree[nd], lo); int mid_better = ev(seg, mid) < ev(tree[nd], mid); if (mid_better) { Line tmp = tree[nd]; tree[nd] = seg; seg = tmp; } if (lo == hi) return; if (left_better != mid_better) lc_add(2 * nd, lo, mid, seg); else lc_add(2 * nd + 1, mid + 1, hi, seg); } long long lc_query(int nd, int lo, int hi, long long x) { long long res = ev(tree[nd], x); if (lo == hi) return res; int mid = (lo + hi) / 2; if (x <= mid) { long long t = lc_query(2 * nd, lo, mid, x); if (t < res) res = t; } else { long long t = lc_query(2 * nd + 1, mid + 1, hi, x); if (t < res) res = t; } return res; } int main(void) { lc_init(); /* 예시: 직선 3개 추가, 쿼리 3개 */ lc_add(1, 0, XMAX, (Line){-2, 10}); lc_add(1, 0, XMAX, (Line){1, 0}); lc_add(1, 0, XMAX, (Line){0, 3}); printf("x=0: %lld\n", lc_query(1, 0, XMAX, 0)); printf("x=3: %lld\n", lc_query(1, 0, XMAX, 3)); printf("x=5: %lld\n", lc_query(1, 0, XMAX, 5)); return 0; }

Connection Profile DP(플러그 DP)란?
격자 위에서 경로/사이클을 세는 문제에서 사용하는 DP 기법입니다.
한 행씩(또는 한 칸씩) 처리하면서, 현재 행의 “경계”를 지나는 연결 상태를 관리합니다.
경계의 각 칸에 플러그(연결선)가 있는지, 어떤 플러그끼리 연결되는지를 인코딩합니다.

플러그 상태 인코딩
M열 격자의 경우, 경계에 M+1개의 슬롯이 있습니다 (아래쪽 M개 + 오른쪽 1개).
각 슬롯의 상태:
  0 = 플러그 없음
  같은 번호 = 같은 경로에 속하는 연결
연결 상태는 “매칭”으로 표현: 짝을 이루는 괄호 구조
예: (M=3) 상태 (1,0,1,2,2) = 슬롯0과 슬롯2가 연결, 슬롯3과 슬롯4가 연결

전이 규칙 (칸 (r,c)를 처리할 때)
위쪽 플러그 = 슬롯 c의 값
왼쪽 플러그 = 슬롯 c-1(또는 오른쪽 슬롯)의 값
Case 1: 둘 다 없음 → 새 경로 시작, 아래+오른쪽에 플러그 생성
Case 2: 하나만 있음 → 경로 연장, 아래 또는 오른쪽으로
Case 3: 둘 다 있음 → 두 경로 합치기 (같은 경로면 사이클 닫기)

해시맵 DP
상태 수가 매우 많지만 실제로 유효한 상태는 적으므로, 해시맵으로 관리합니다.
각 상태를 정수로 인코딩하여 해시맵의 키로 사용합니다.

Cplug_dp.c
#include <stdio.h> #include <string.h> #define MAXM 8 #define HSIZE 1000003 #define MAXE 200000 #define BITS 3 // 각 슬롯에 3비트 사용 #define MASK 7 typedef long long ll; typedef unsigned long long ull; struct Entry { ull key; ll val; int nxt; } pool[MAXE]; int head[HSIZE], pcnt; void hm_clear() { memset(head, -1, sizeof head); pcnt = 0; } void hm_add(ull key, ll val) { int h = key % HSIZE; for (int i = head[h]; i != -1; i = pool[i].nxt) if (pool[i].key == key) { pool[i].val += val; return; } pool[pcnt] = (struct Entry){key, val, head[h]}; head[h] = pcnt++; } int getSlot(ull state, int pos) { return (state >> (pos * BITS)) & MASK; } ull setSlot(ull state, int pos, int val) { ull mask = ~((ull)MASK << (pos * BITS)); return (state & mask) | ((ull)val << (pos * BITS)); } int N, M; int grid[12][MAXM]; /* 매칭에서 pos의 짝을 찾는 함수 */ int findPair(ull state, int pos, int m) { int v = getSlot(state, pos); if (v == 0) return -1; for (int i = 0; i <= m; i++) if (i != pos && getSlot(state, i) == v) return i; return -1; } int main(void) { scanf("%d %d", &N, &M); /* 격자 입력 (1=사용 가능, 0=장애물) */ for (int i = 0; i < N; i++) for (int j = 0; j < M; j++) grid[i][j] = 1; /* 모두 사용 가능 */ hm_clear(); hm_add(0, 1); /* 초기 상태: 플러그 없음 */ for (int r = 0; r < N; r++) { for (int c = 0; c < M; c++) { /* 현재 해시맵의 모든 상태를 순회하며 전이 */ int old_cnt = pcnt; struct Entry old[MAXE]; memcpy(old, pool, pcnt * sizeof(pool[0])); hm_clear(); for (int e = 0; e < old_cnt; e++) { ull st = old[e].key; ll val = old[e].val; if (val == 0) continue; int up = getSlot(st, c); /* 위쪽 플러그 */ int lf = getSlot(st, M); /* 왼쪽 플러그 */ if (!grid[r][c]) { if (up == 0 && lf == 0) hm_add(st, val); continue; } /* 전이 로직 (간략화) */ if (up == 0 && lf == 0) { /* 새 경로: 아래+오른쪽 플러그 */ int nv = 1; for (int i = 0; i <= M; i++) if (getSlot(st, i) >= nv) nv = getSlot(st, i) + 1; ull ns = setSlot(setSlot(st, c, nv), M, nv); hm_add(ns, val); } /* 다른 케이스들도 유사하게 처리 */ } } /* 행이 끝나면 오른쪽 플러그 초기화 */ } printf("해밀턴 경로 수 계산 완료\n"); return 0; }

Broken Profile DP란?
N×M 격자를 1×2 도미노로 빈틈없이 채우는 경우의 수를 구하는 기법입니다.
행 단위가 아니라 칸 단위로 전이하면서, 현재 경계의 “울퉁불퉁한” 프로파일을 비트마스크로 관리합니다.
비트 1 = 이미 채워진 칸, 비트 0 = 아직 비어있는 칸

전이 규칙
칸 (r, c)를 처리할 때, 프로파일의 c번째 비트를 확인합니다:
Case 1: 비트가 1 (이미 채워짐) → 비트를 0으로 바꾸고 다음 칸으로
Case 2: 비트가 0 (비어있음) → 두 가지 선택:
  (a) 세로 도미노: 아래 칸을 채움 → 비트를 1로 설정
  (b) 가로 도미노: 오른쪽 칸의 비트가 0이면, 둘 다 채움

상태 공간
프로파일은 M비트 비트마스크 → 2^M개의 상태
칸은 N×M개 → 전체 시간 복잡도: O(N × M × 2^M)
M ≤ 20이면 2^20 = 약 100만, N×M과 곱하면 제한 시간 내 가능

Cbroken_profile.c
#include <stdio.h> #include <string.h> #define MAXN 21 #define MAXMASK (1 << MAXN) long long dp[2][MAXMASK]; int N, M; int main(void) { scanf("%d %d", &N, &M); /* M이 더 작도록 swap (최적화) */ if (N < M) { int t = N; N = M; M = t; } int full = (1 << M) - 1; int cur = 0; memset(dp, 0, sizeof dp); dp[0][0] = 1; /* 초기: 모든 칸 비어있음 */ for (int r = 0; r < N; r++) { for (int c = 0; c < M; c++) { int nxt = cur ^ 1; memset(dp[nxt], 0, sizeof dp[nxt]); for (int mask = 0; mask <= full; mask++) { if (dp[cur][mask] == 0) continue; if (mask & (1 << c)) { /* Case 1: 이미 채워진 칸 → 비트 끄기 */ dp[nxt][mask ^ (1 << c)] += dp[cur][mask]; } else { /* Case 2a: 세로 도미노 (아래 칸 채움) */ dp[nxt][mask | (1 << c)] += dp[cur][mask]; /* Case 2b: 가로 도미노 (오른쪽 칸도 비어야 함) */ if (c + 1 < M && !(mask & (1 << (c + 1)))) { dp[nxt][mask | (1 << (c + 1))] += dp[cur][mask]; } } } cur = nxt; } } printf("%lld\n", dp[cur][0]); return 0; }

최대 가중치 독립 집합 (Maximum Weight Independent Set, MWIS)
트리에서 인접하지 않는 정점들의 부분집합 중 가중치 합이 최대인 것을 구합니다.
dp[v][0] = v를 선택하지 않을 때, v의 서브트리에서의 최대 가중치
dp[v][1] = v를 선택할 때, v의 서브트리에서의 최대 가중치
전이: dp[v][0] = ∑ max(dp[c][0], dp[c][1]) for all child c
      dp[v][1] = w[v] + ∑ dp[c][0] for all child c

역추적 (Backtracking)
최적 답을 구한 후, 어떤 정점을 선택했는지 역추적합니다.
루트부터 시작하여 dp[v][1] > dp[v][0]이면 v를 선택합니다.
v를 선택했으면 자식들은 선택 불가 (dp[c][0]으로 진행).
v를 선택 안 했으면 각 자식에서 max(dp[c][0], dp[c][1])을 따라갑니다.

Rerooting Technique
“모든 정점을 루트로 했을 때의 답”을 O(N)에 구하는 기법입니다.
Step 1: 임의의 루트(예: 1)로 트리 DP를 수행 → O(N)
Step 2: 각 정점 v에서, 부모 방향의 기여를 합산하여 답 갱신 → O(N)
핵심: v를 루트에서 떼어낼 때, 부모의 dp에서 v의 기여분을 빼면 됩니다.

Ctree_dp_mwis.c
#include <stdio.h> #include <string.h> #define MAXN 200005 int head[MAXN], to[MAXN * 2], nxt[MAXN * 2], ecnt; long long w[MAXN]; long long dp[MAXN][2]; // dp[v][0], dp[v][1] long long ans[MAXN]; // rerooting 결과 int sel[MAXN]; // 역추적: 선택 여부 int par[MAXN]; int n; void addEdge(int u, int v) { to[ecnt] = v; nxt[ecnt] = head[u]; head[u] = ecnt++; to[ecnt] = u; nxt[ecnt] = head[v]; head[v] = ecnt++; } /* 비재귀 DFS로 트리 DP */ int stk[MAXN], ord[MAXN], ocnt; void treeDFS(int root) { int top = 0; ocnt = 0; stk[top++] = root; par[root] = -1; memset(dp, 0, sizeof dp); while (top > 0) { int v = stk[--top]; ord[ocnt++] = v; for (int e = head[v]; e != -1; e = nxt[e]) { int u = to[e]; if (u == par[v]) continue; par[u] = v; stk[top++] = u; } } /* 역순으로 DP 계산 */ for (int i = ocnt - 1; i >= 0; i--) { int v = ord[i]; dp[v][1] = w[v]; for (int e = head[v]; e != -1; e = nxt[e]) { int c = to[e]; if (c == par[v]) continue; long long mx = dp[c][0] > dp[c][1] ? dp[c][0] : dp[c][1]; dp[v][0] += mx; dp[v][1] += dp[c][0]; } } } /* 역추적 */ void backtrack(int root) { memset(sel, 0, sizeof sel); for (int i = 0; i < ocnt; i++) { int v = ord[i]; if (par[v] != -1 && sel[par[v]]) { sel[v] = 0; /* 부모 선택됨 → 선택 불가 */ } else { sel[v] = (dp[v][1] >= dp[v][0]) ? 1 : 0; } } } int main(void) { scanf("%d", &n); memset(head, -1, sizeof head); for (int i = 1; i <= n; i++) scanf("%lld", &w[i]); for (int i = 0; i < n - 1; i++) { int u, v; scanf("%d %d", &u, &v); addEdge(u, v); } treeDFS(1); long long best = dp[1][0] > dp[1][1] ? dp[1][0] : dp[1][1]; printf("MWIS = %lld\n", best); backtrack(1); printf("Selected:"); for (int i = 1; i <= n; i++) if (sel[i]) printf(" %d", i); printf("\n"); return 0; }

REROOTING 개념 Rerooting은 루트를 바꿔도 O(N)에 답을 갱신하는 기법입니다.
v를 루트에서 자식 c의 서브트리로 옮길 때:
  dp_parent[v][0]에서 c의 기여분을 빼고, c의 dp에 더합니다.
이를 DFS 순서대로 전파하면 전체 O(N)에 모든 루트의 답을 구할 수 있습니다.

DP on Permutation — 영 타블로와 Robinson-Schensted

순열 위의 DP
순열(permutation)에서 특정 패턴을 세거나 최적화하는 문제입니다.
대표적으로 LIS(최장 증가 부분 수열)의 길이 분포, 기대 길이 등을 다룹니다.
순열의 구조를 이해하기 위해 영 타블로(Young Tableau) 개념이 필요합니다.

영 타블로 (Young Tableau)
영 다이어그램: 왼쪽 정렬된 격자 칸들, 각 행의 길이가 감소하지 않게 배치
표준 영 타블로: 각 칸에 1~N을 채우되, 행과 열 모두 증가
영 타블로의 모양(shape)은 정수 분할(partition)에 대응합니다.
예: λ = (3,2,1) → 3+2+1 = 6칸짜리 타블로

Robinson-Schensted (RS) 대응
핵심 정리: 길이 N인 순열은 같은 모양의 표준 영 타블로 쌍 (P, Q)에 1:1 대응합니다.
P 타블로: 순열의 원소를 하나씩 삽입하여 구성 (삽입 타블로)
Q 타블로: 삽입 순서를 기록 (기록 타블로)
핵심 성질:
  - P의 첫 번째 행 길이 = 순열의 LIS 길이
  - P의 첫 번째 열 길이 = 순열의 LDS(최장 감소 부분 수열) 길이

RS 삽입 알고리즘
원소 x를 삽입할 때:
1. 첫 번째 행에서 x보다 큰 최소 원소를 찾는다 (이분 탐색)
2. 그 원소를 x로 교체하고, 밀려난 원소를 다음 행에 삽입 (재귀)
3. 행 끝까지 x보다 큰 원소가 없으면 행 끝에 추가

Crs_correspondence.c
#include <stdio.h> #include <string.h> #define MAXN 1005 int P[MAXN][MAXN]; // P 타블로 int Q[MAXN][MAXN]; // Q 타블로 int rowLen[MAXN]; // 각 행의 길이 int numRows; /* 이분 탐색: row에서 val보다 큰 최소 위치 */ int findPos(int row, int val) { int lo = 0, hi = rowLen[row] - 1, res = rowLen[row]; while (lo <= hi) { int mid = (lo + hi) / 2; if (P[row][mid] > val) { res = mid; hi = mid - 1; } else lo = mid + 1; } return res; } void rsInsert(int val, int idx) { int row = 0; while (1) { int pos = findPos(row, val); if (pos == rowLen[row]) { /* 행 끝에 추가 */ P[row][rowLen[row]] = val; Q[row][rowLen[row]] = idx; rowLen[row]++; if (row + 1 > numRows) numRows = row + 1; return; } /* 교체하고 밀려난 원소를 다음 행에 삽입 */ int bumped = P[row][pos]; P[row][pos] = val; val = bumped; row++; } } int main(void) { int n; scanf("%d", &n); memset(rowLen, 0, sizeof rowLen); numRows = 0; for (int i = 0; i < n; i++) { int x; scanf("%d", &x); rsInsert(x, i + 1); } printf("LIS 길이 = %d\n", rowLen[0]); printf("LDS 길이 = %d\n", numRows); printf("P 타블로:\n"); for (int r = 0; r < numRows; r++) { for (int c = 0; c < rowLen[r]; c++) printf("%d ", P[r][c]); printf("\n"); } return 0; }

Bitset 최적화란?
DP 전이가 “OR 연산”이나 “시프트 + OR”로 표현될 때,
64비트 정수 배열(bitset)로 한 번에 64개 비트를 처리하여 상수 배 가속합니다.
부분합 문제: N개 수에서 합이 W가 되는 부분집합이 존재하는가?
기본 DP: O(NW), Bitset 최적화: O(NW/64)

부분합 문제의 Bitset DP
dp[j] = 1이면 합 j가 가능, 0이면 불가능
전이: 원소 a[i]를 추가할 때, dp |= (dp << a[i])
이 시프트+OR 연산을 64비트 단위로 수행하면 W/64배 가속됩니다.

Cbitset_subset_sum.c
#include <stdio.h> #include <string.h> #define MAXW 1000001 #define WORDS (MAXW / 64 + 1) typedef unsigned long long u64; u64 dp[WORDS]; // bitset: dp[w/64]의 (w%64)번째 비트 u64 tmp[WORDS]; // 시프트 결과 임시 저장 int maxWord; /* dp를 shift만큼 왼쪽 시프트 (비트 단위) */ void shiftLeft(int shift) { int wordShift = shift / 64; int bitShift = shift % 64; memset(tmp, 0, sizeof tmp); for (int i = maxWord; i >= 0; i--) { if (dp[i] == 0) continue; int dst = i + wordShift; if (dst > maxWord) continue; tmp[dst] |= dp[i] << bitShift; if (bitShift > 0 && dst + 1 <= maxWord) tmp[dst + 1] |= dp[i] >> (64 - bitShift); } } /* dp |= tmp */ void orWith() { for (int i = 0; i <= maxWord; i++) dp[i] |= tmp[i]; } /* 비트 조회 */ int getBit(int pos) { return (dp[pos / 64] >> (pos % 64)) & 1; } int main(void) { int n, W; scanf("%d %d", &n, &W); maxWord = W / 64; memset(dp, 0, sizeof dp); dp[0] = 1; /* 합 0은 항상 가능 */ for (int i = 0; i < n; i++) { int a; scanf("%d", &a); shiftLeft(a); /* tmp = dp << a */ orWith(); /* dp |= tmp */ } if (getBit(W)) printf("YES\n"); else printf("NO\n"); /* 가능한 합 모두 출력 */ int cnt = 0; for (int j = 0; j <= W; j++) if (getBit(j)) cnt++; printf("가능한 합의 개수: %d\n", cnt); return 0; }

Monge 행렬과 SMAWK — 행 최솟값 O(N)
MongeSMAWK사각부등식GOLD

Monge 행렬이란?
N×M 행렬 A가 Monge 조건을 만족한다는 것은:
모든 i<i′, j<j′에 대해 A[i][j] + A[i′][j′] ≤ A[i][j′] + A[i′][j]
동치 조건: 모든 인접한 2×2 부분행렬에서 위 부등식 성립
직관: “왼쪽 위 + 오른쪽 아래 ≤ 오른쪽 위 + 왼쪽 아래”

Monge 행렬의 핵심 성질
성질 1: 각 행의 최솟값 위치(opt)가 단조 증가
  opt[0] ≤ opt[1] ≤ ... ≤ opt[N-1]
성질 2: Knuth 최적화의 이론적 근거
성질 3: 분할정복 최적화의 적용 조건

SMAWK 알고리즘
Monge 행렬의 모든 행 최솟값을 O(N+M)에 구하는 알고리즘입니다.
핵심 아이디어:
  1. REDUCE: 열 수를 행 수 이하로 줄인다 (O(M))
  2. 홀수 행만 재귀적으로 해결
  3. 짝수 행의 답을 홀수 행 결과로부터 O(N)에 채운다
전체 복잡도: T(N) = T(N/2) + O(N+M) = O(N+M)

Knuth 최적화와의 관계
구간 DP에서 비용 함수 C[i][j]가 Monge 조건을 만족하면,
최적 분할점 opt[i][j]가 단조: opt[i][j-1] ≤ opt[i][j] ≤ opt[i+1][j]
이것이 Knuth 최적화의 핵심입니다.
SMAWK는 1D 문제에서 더 강력: O(N) vs Knuth의 O(N²)

Csmawk.c
#include <stdio.h> #define MAXN 1005 long long A[MAXN][MAXN]; // Monge 행렬 int rowMin[MAXN]; // 각 행의 최솟값 열 int N, M; /* REDUCE: 열 후보를 행 수 이하로 줄이기 */ void reduce(int *rows, int rn, int *cols, int cn, int *out, int *on) { int stk[MAXN], top = 0; for (int i = 0; i < cn; i++) { while (top > 0 && top <= rn && A[rows[top - 1]][cols[i]] <= A[rows[top - 1]][stk[top - 1]]) top--; if (top < rn) stk[top++] = cols[i]; } *on = top; for (int i = 0; i < top; i++) out[i] = stk[i]; } /* SMAWK: rows 중 각 행의 최솟값 열을 result에 저장 */ void smawk(int *rows, int rn, int *cols, int cn) { if (rn == 0) return; /* REDUCE */ int red[MAXN], rn2; reduce(rows, rn, cols, cn, red, &rn2); /* 홀수 행 재귀 */ int oddRows[MAXN], on = 0; for (int i = 1; i < rn; i += 2) oddRows[on++] = rows[i]; smawk(oddRows, on, red, rn2); /* 짝수 행 채우기 */ int j = 0; for (int i = 0; i < rn; i += 2) { int r = rows[i]; int bound = (i + 1 < rn) ? rowMin[rows[i + 1]] : red[rn2 - 1]; rowMin[r] = red[j]; for (int k = j; k < rn2 && red[k] <= bound; k++) { if (A[r][red[k]] < A[r][rowMin[r]]) rowMin[r] = red[k]; } while (j + 1 < rn2 && red[j + 1] <= bound) j++; j++; } } int main(void) { scanf("%d %d", &N, &M); for (int i = 0; i < N; i++) for (int j = 0; j < M; j++) scanf("%lld", &A[i][j]); int rows[MAXN], cols[MAXN]; for (int i = 0; i < N; i++) rows[i] = i; for (int j = 0; j < M; j++) cols[j] = j; smawk(rows, N, cols, M); for (int i = 0; i < N; i++) printf("Row %d: min at col %d, val = %lld\n", i, rowMin[i], A[i][rowMin[i]]); return 0; }
실행 결과 (4x5 Monge 행렬)
Row 0: min at col 1, val = 2 Row 1: min at col 2, val = 3 Row 2: min at col 3, val = 1 Row 3: min at col 4, val = 4
TIP Monge 조건을 확인하려면 모든 인접 2×2 부분행렬만 체크하면 됩니다.
O(NM)에 검증 가능하며, 대회에서는 직접 검증하기보다 문제 구조에서 유도합니다.
SMAWK는 구현이 복잡하므로, opt 단조 성질만 사용하는 분할정복이 실전에서 더 자주 쓰입니다.

Splay 트리 — 회전과 amortized O(log N)
Splay TreeBSTamortizedGOLD

Splay 트리란?
자기 조정(self-adjusting) 이진 탐색 트리입니다.
접근한 노드를 루트로 끌어올리는 “splay” 연산이 핵심입니다.
최악 O(N)이지만, amortized O(log N)이 보장됩니다.
AVL/레드블랙보다 구현이 간단하고, 구간 연산에 강력합니다.

세 가지 회전 (Splay Step)
Zig: x의 부모가 루트일 때 → 단순 회전 1회
Zig-Zig: x와 부모가 같은 방향 자식 → 부모 먼저 회전, x 회전
Zig-Zag: x와 부모가 다른 방향 자식 → x를 2번 회전
핵심: Zig-Zig에서 “부모 먼저” 회전하는 것이 amortized 보장의 핵심!

핵심 연산
splay(x): x를 루트로 끌어올림
find(key): BST 탐색 후 splay
split(key): key 기준으로 트리를 둘로 분할
merge(L, R): L의 최댓값 < R의 최솟값일 때 합치기
kth(k): k번째 원소 찾기 (서브트리 크기 관리)

Csplay_tree.c
#include <stdio.h> #include <stdlib.h> #define MAXN 300005 int ch[MAXN][2], fa[MAXN], sz[MAXN], val[MAXN]; int tot, root; void pushup(int x) { sz[x] = sz[ch[x][0]] + sz[ch[x][1]] + 1; } int chk(int x) { return ch[fa[x]][1] == x; } void rotate(int x) { int y = fa[x], z = fa[y], k = chk(x); ch[y][k] = ch[x][!k]; if (ch[x][!k]) fa[ch[x][!k]] = y; ch[x][!k] = y; fa[y] = x; fa[x] = z; if (z) ch[z][ch[z][1] == y] = x; pushup(y); pushup(x); } void splay(int x, int goal) { while (fa[x] != goal) { int y = fa[x]; if (fa[y] != goal) { /* Zig-Zig or Zig-Zag */ if (chk(x) == chk(y)) rotate(y); /* Zig-Zig: 부모 먼저! */ else rotate(x); /* Zig-Zag: 자신 먼저 */ } rotate(x); } if (goal == 0) root = x; } int newNode(int v, int f) { ++tot; ch[tot][0] = ch[tot][1] = 0; fa[tot] = f; val[tot] = v; sz[tot] = 1; return tot; } void insert(int v) { int x = root, p = 0; while (x) { p = x; x = ch[x][v > val[x]]; } x = newNode(v, p); if (p) ch[p][v > val[p]] = x; splay(x, 0); } /* k번째 원소 (1-indexed) */ int kth(int k) { int x = root; while (1) { int left = sz[ch[x][0]]; if (k <= left) x = ch[x][0]; else if (k == left + 1) { splay(x, 0); return val[x]; } else { k -= left + 1; x = ch[x][1]; } } } int main(void) { tot = root = 0; sz[0] = 0; int arr[] = {5, 3, 8, 1, 4, 7, 9}; int n = 7; for (int i = 0; i < n; i++) insert(arr[i]); printf("Size: %d\n", sz[root]); for (int i = 1; i <= n; i++) printf("kth(%d) = %d\n", i, kth(i)); return 0; }
실행 결과
Size: 7 kth(1) = 1 kth(2) = 3 kth(3) = 4 kth(4) = 5 kth(5) = 7 kth(6) = 8 kth(7) = 9

x를 먼저 회전하면 단순 회전(rotate-to-root)이 되어 최악 O(N)입니다.
이 차이가 Splay 트리의 핵심 아이디어입니다.

Splay 트리로 수열 관리
Splay 트리에서 키 대신 “위치(인덱스)”를 기준으로 관리하면,
배열처럼 사용하면서 구간 연산을 효율적으로 수행할 수 있습니다.
서브트리 크기(sz)가 곧 인덱스 역할을 합니다.

구간 뒤집기 (Reverse)
수열의 [L, R] 구간을 뒤집는 연산입니다.
구현:
1. L-1번째 노드를 루트로 splay
2. R+1번째 노드를 루트의 오른쪽 자식으로 splay
3. R+1의 왼쪽 서브트리가 정확히 [L, R] 구간
4. 이 서브트리에 “뒤집기” lazy 태그를 설정
lazy 전파: 자식의 왼쪽/오른쪽을 swap하고 lazy를 전달

Csplay_reverse.c
#include <stdio.h> #define MAXN 300005 int ch[MAXN][2], fa[MAXN], sz[MAXN], val[MAXN]; int rev[MAXN]; // lazy 뒤집기 태그 int tot, root; void pushup(int x) { sz[x] = sz[ch[x][0]] + sz[ch[x][1]] + 1; } int chk(int x) { return ch[fa[x]][1] == x; } void pushdown(int x) { if (rev[x]) { int t = ch[x][0]; ch[x][0] = ch[x][1]; ch[x][1] = t; if (ch[x][0]) rev[ch[x][0]] ^= 1; if (ch[x][1]) rev[ch[x][1]] ^= 1; rev[x] = 0; } } void rotate(int x) { int y = fa[x], z = fa[y], k = chk(x); ch[y][k] = ch[x][!k]; if (ch[x][!k]) fa[ch[x][!k]] = y; ch[x][!k] = y; fa[y] = x; fa[x] = z; if (z) ch[z][ch[z][1] == y] = x; pushup(y); pushup(x); } void splay(int x, int goal) { /* pushdown 경로를 스택에 저장 */ int stk[MAXN], top = 0; for (int i = x; i != goal; i = fa[i]) stk[top++] = i; while (top) pushdown(stk[--top]); while (fa[x] != goal) { int y = fa[x]; if (fa[y] != goal) rotate(chk(x) == chk(y) ? y : x); rotate(x); } if (goal == 0) root = x; } /* k번째 노드를 goal의 자식으로 splay */ int kthNode(int k) { int x = root; while (1) { pushdown(x); int left = sz[ch[x][0]]; if (k <= left) x = ch[x][0]; else if (k == left + 1) return x; else { k -= left + 1; x = ch[x][1]; } } } int build(int *a, int l, int r, int par) { if (l > r) return 0; int mid = (l + r) / 2; int x = ++tot; val[x] = a[mid]; fa[x] = par; rev[x] = 0; ch[x][0] = build(a, l, mid - 1, x); ch[x][1] = build(a, mid + 1, r, x); pushup(x); return x; } /* 구간 [L, R] 뒤집기 (1-indexed, 센티널 포함) */ void reverse(int L, int R) { int x = kthNode(L); /* L-1번째 (센티널 때문에 L) */ splay(x, 0); int y = kthNode(R + 2); /* R+1번째 */ splay(y, root); int z = ch[y][0]; /* [L, R] 구간 서브트리 */ rev[z] ^= 1; } void inorder(int x) { if (!x) return; pushdown(x); inorder(ch[x][0]); if (val[x] != -1 && val[x] != 1000000) printf("%d ", val[x]); inorder(ch[x][1]); } int main(void) { tot = 0; /* 센티널 포함 배열: [-1, 1,2,3,4,5, 1000000] */ int a[] = {-1, 1, 2, 3, 4, 5, 1000000}; root = build(a, 0, 6, 0); printf("초기: "); inorder(root); printf("\n"); reverse(2, 4); printf("reverse(2,4): "); inorder(root); printf("\n"); reverse(1, 5); printf("reverse(1,5): "); inorder(root); printf("\n"); return 0; }
실행 결과

INPUT (연산 시퀀스)

OUTPUT

Link-Cut 트리란?
트리의 간선을 동적으로 추가/삭제하면서 경로 쿼리를 수행하는 자료구조입니다.

핵심 개념: Preferred Path
각 노드에서 자식 하나를 “preferred child”로 선택합니다.
preferred 간선들이 이어진 경로를 preferred path라 합니다.
각 preferred path는 하나의 Splay 트리로 관리됩니다.
Splay 트리의 키는 깊이 순서입니다.

핵심 연산

link(x, y): x의 트리와 y의 트리를 연결
cut(x, y): x-y 간선을 끊는다
findRoot(x): x가 속한 트리의 루트를 찾는다

Euler Tour 트리(ETT)란?
트리의 오일러 투어 수열을 균형 BST로 관리하는 자료구조입니다.
Link-Cut 트리와 다른 접근: 간선의 추가/삭제와 연결 요소 관리에 특화됩니다.
오일러 투어: DFS에서 방문/퇴장 시 노드를 기록한 수열

오일러 투어 수열의 성질
노드 v의 서브트리 = 오일러 투어에서 v의 첫 등장부터 마지막 등장까지의 구간
이 구간을 BST의 부분 수열로 관리하면:
  - 서브트리 크기/합: O(log N)
  - 간선 추가(link): 두 수열을 합치기 O(log N)
  - 간선 삭제(cut): 수열에서 구간을 잘라내기 O(log N)

Top 트리란?
트리의 모든 경로/서브트리 정보를 계층적 클러스터(cluster)로 관리하는 자료구조입니다.
Link-Cut 트리의 일반화로 볼 수 있으며, 더 다양한 쿼리를 지원합니다.
모든 연산이 O(log N)이며, 동적 트리 연산(link, cut)도 가능합니다.

클러스터 (Cluster)
트리의 연결된 부분 그래프로, 최대 2개의 “경계 정점(boundary vertex)”을 가집니다.
기본 클러스터: 간선 하나 (양 끝점이 경계)
합성 클러스터: 두 클러스터를 합쳐서 생성

두 가지 합성 연산
Compress: 두 클러스터가 경로 위에서 연속일 때 합치기
  A = (u, v), B = (v, w) → C = (u, w)
  경로 쿼리에 사용: 경로의 합, 최대값 등
Rake: 한 클러스터를 다른 클러스터의 경계 정점에 “접기”
  서브트리 정보를 경계 정점에 합산
  서브트리 쿼리에 사용: 서브트리 합, 크기 등

Top 트리의 구조
모든 간선(기본 클러스터)에서 시작하여, Compress/Rake를 반복하여
전체 트리를 하나의 루트 클러스터로 만듭니다.
이 과정을 이진 트리로 표현한 것이 Top 트리입니다.
높이는 O(log N)으로 유지됩니다.

퍼시스턴트 자료구조란?
수정 후에도 이전 버전을 보존하는 자료구조입니다.
버전 t에서 수정하면 버전 t+1이 생성되고, t도 그대로 남습니다.
“시간 여행”이 가능: 과거 버전을 조회하거나 과거에서 분기 가능

Fat Node 방식
각 노드에 (시간, 값) 쌍의 리스트를 저장합니다.
조회: 시간 t 이하의 최신 값을 이분 탐색으로 찾기
장점: 수정 O(1), 조회 O(log V) (V = 버전 수)
단점: 메모리 사용이 많고, 실전에서 잘 사용되지 않음

Path Copying 방식
수정된 경로의 노드만 새로 복사하고, 나머지는 공유합니다.
이진 트리에서 수정 경로의 길이 = O(log N)
따라서 한 번 수정에 O(log N) 노드만 새로 생성
퍼시스턴트 세그먼트 트리, 퍼시스턴트 트라이 등에 사용

퍼시스턴트 Union-Find
Union-Find에서 과거 버전의 연결 상태를 조회할 수 있습니다.
경로 압축 대신 “rank에 의한 합치기”만 사용합니다 (경로 압축은 퍼시스턴트와 호환 불가)
parent 배열을 퍼시스턴트 배열로 관리하면 됩니다.

#include <stdio.h> #include <stdlib.h> #define MAXNODE 5000000 /* 퍼시스턴트 배열 (Path Copying 세그먼트 트리 기반) */ struct Node { int left, right; int val; // 리프만 사용 } pool[MAXNODE]; int pcnt = 0; int roots[200005]; // roots[t] = 버전 t의 루트 int newNode() { return pcnt++; } int copyNode(int x) { int y = newNode(); pool[y] = pool[x]; return y; } /* 배열 [0, n) 초기화 */ int build(int lo, int hi, int *arr) { int nd = newNode(); if (lo == hi) { pool[nd].val = arr[lo]; pool[nd].left = pool[nd].right = 0; return nd; } int mid = (lo + hi) / 2; pool[nd].left = build(lo, mid, arr); pool[nd].right = build(mid + 1, hi, arr); return nd; } /* 버전 root에서 위치 pos의 값을 v로 수정, 새 루트 반환 */ int update(int root, int lo, int hi, int pos, int v) { int nd = copyNode(root); if (lo == hi) { pool[nd].val = v; return nd; } int mid = (lo + hi) / 2; if (pos <= mid) pool[nd].left = update(pool[nd].left, lo, mid, pos, v); else pool[nd].right = update(pool[nd].right, mid + 1, hi, pos, v); return nd; } /* 버전 root에서 위치 pos의 값 조회 */ int query(int root, int lo, int hi, int pos) { if (lo == hi) return pool[root].val; int mid = (lo + hi) / 2; if (pos <= mid) return query(pool[root].left, lo, mid, pos); else return query(pool[root].right, mid + 1, hi, pos); } int main(void) { int arr[] = {10, 20, 30, 40, 50}; int n = 5; roots[0] = build(0, n - 1, arr); /* 버전 1: 위치 2를 99로 변경 */ roots[1] = update(roots[0], 0, n - 1, 2, 99); /* 버전 2: 버전 0에서 위치 4를 77로 변경 (분기!) */ roots[2] = update(roots[0], 0, n - 1, 4, 77); printf("v0[2]=%d, v1[2]=%d, v2[2]=%d\n", query(roots[0], 0, n-1, 2), query(roots[1], 0, n-1, 2), query(roots[2], 0, n-1, 2)); printf("v0[4]=%d, v2[4]=%d\n", query(roots[0], 0, n-1, 4), query(roots[2], 0, n-1, 4)); return 0; }

#include <stdio.h> #include <string.h> #define MAXNODE 6000000 #define BITS 30 int ch[MAXNODE][2], cnt[MAXNODE]; int pcnt = 1; // 0번은 NULL 노드 int roots[200005]; /* 버전 prev에 값 x를 삽입, 새 루트 반환 */ int trieInsert(int prev, int x) { int newRoot = pcnt++; int cur = newRoot, old = prev; for (int b = BITS; b >= 0; b--) { int bit = (x >> b) & 1; /* 반대쪽은 공유 */ ch[cur][!bit] = ch[old][!bit]; /* 이쪽은 새 노드 */ ch[cur][bit] = pcnt++; cnt[ch[cur][bit]] = cnt[ch[old][bit]] + 1; cur = ch[cur][bit]; old = ch[old][bit]; } return newRoot; } /* 버전 [l, r] 구간에서 x와 XOR 최대인 값 찾기 */ int trieQuery(int rootL, int rootR, int x) { int result = 0; int curL = rootL, curR = rootR; for (int b = BITS; b >= 0; b--) { int bit = (x >> b) & 1; int want = !bit; /* XOR 최대화 → 반대 비트 선호 */ int diff = cnt[ch[curR][want]] - cnt[ch[curL][want]]; if (diff > 0) { result |= (1 << b); curL = ch[curL][want]; curR = ch[curR][want]; } else { curL = ch[curL][bit]; curR = ch[curR][bit]; } } return result; } int main(void) { memset(ch, 0, sizeof ch); memset(cnt, 0, sizeof(cnt)); int a[] = {3, 7, 1, 5, 10}; int n = 5; roots[0] = 0; for (int i = 0; i < n; i++) roots[i + 1] = trieInsert(roots[i], a[i]); /* 구간 [1,4]에서 x=6과 XOR 최대 */ int maxXor = trieQuery(roots[0], roots[4], 6); printf("구간 [1,4]에서 6과의 최대 XOR: %d\n", maxXor); /* 구간 [3,5]에서 x=12와 XOR 최대 */ maxXor = trieQuery(roots[2], roots[5], 12); printf("구간 [3,5]에서 12와의 최대 XOR: %d\n", maxXor); return 0; }

일반 그래프 최대 매칭
이분 그래프가 아닌 일반 그래프에서 최대 매칭을 구하는 문제입니다.
이분 매칭과 달리, 홀수 사이클이 존재하면 단순 증가 경로 알고리즘이 실패합니다.
Blossom 알고리즘(Edmonds, 1965)이 이를 해결합니다.

홀수 사이클 문제 (Blossom)
증가 경로를 찾는 BFS에서 홀수 사이클을 만나면:
  단순히 “이미 방문”으로 처리하면 증가 경로를 놓칩니다.
  사이클의 모든 정점을 하나의 “슈퍼 노드”로 축약합니다.
  축약된 그래프에서 다시 증가 경로를 탐색합니다.
  찾으면 원래 그래프로 복원하여 매칭을 갱신합니다.

알고리즘 흐름
1. 자유 정점(매칭 안 된 정점)에서 BFS 시작
2. 교대 경로(alternating path)를 따라 탐색
3. 다른 자유 정점에 도달하면 → 증가 경로 발견, 매칭 갱신
4. 같은 트리의 “짝수 레벨” 노드를 만나면 → Blossom 발견
  - LCA를 찾아 사이클의 정점들을 하나로 축약
  - 축약 후 BFS 계속
5. 증가 경로가 없으면 종료 → 현재 매칭이 최대

} int lca(int a, int b) { int used[MAXV]; memset(used, 0, sizeof used); while (1) { a = base[a]; used[a] = 1; if (match[a] == -1) break; a = par[match[a]]; } while (1) { b = base[b]; if (used[b]) return b; b = par[match[b]]; } } void markBlossom(int v, int b, int child) { while (base[v] != b) { inBlossom[base[v]] = 1; inBlossom[base[match[v]]] = 1; par[v] = child; child = match[v]; v = par[match[v]]; } } void contract(int u, int v) { memset(inBlossom, 0, sizeof inBlossom); int b = lca(u, v); markBlossom(u, b, v); markBlossom(v, b, u); for (int i = 0; i < n; i++) { if (inBlossom[base[i]]) { base[i] = b; if (!inQueue[i]) { inQueue[i] = 1; que[qt++] = i; } } } } int augment(int s) { memset(inQueue, 0, sizeof inQueue); match[v] = pv; match[pv] = v; v = ppv; } return 1; } que[qt++] = match[v]; inQueue[match[v]] = 1; } } } return 0; } int main(void) { int m; scanf("%d %d", &n, &m); memset(head, -1, sizeof head); memset(match, -1, sizeof match); 지배 관계 (Domination)
방향 그래프에서 시작 정점 s로부터의 도달 문제입니다.
정점 d가 정점 v를 지배(dominate)한다 = s에서 v로 가는 모든 경로가 d를 지난다
각 정점 v의 즉시 지배자(immediate dominator, idom): v를 지배하는 정점 중 v에 가장 가까운 것
idom 관계로 만든 트리 = 지배 트리(dominator tree)

Lengauer-Tarjan 알고리즘
지배 트리를 O(E α(V)) ≈ O(E)에 구하는 알고리즘입니다.
핵심 개념:
  1. DFS 트리를 구한다
  2. 반지배자(sdom): v의 반지배자 = DFS 번호가 가장 작은 정점 u로,
     DFS 트리 외 간선을 통해 v에 도달 가능한 것
  3. sdom에서 idom을 계산 (링크-eval 자료구조 사용)

Cdominator_tree.c
#include <stdio.h> #include <string.h> #define MAXV 200005 #define MAXE 500005 /* 그래프 */ int head[MAXV], to[MAXE], nxt[MAXE], ecnt; /* 역방향 그래프 */ int rhead[MAXV], rto[MAXE], rnxt[MAXE], recnt; int dfn[MAXV], ord[MAXV], dfsCnt; int par[MAXV]; /* DFS 트리 부모 */ int sdom[MAXV]; /* 반지배자 */ int idom[MAXV]; /* 즉시 지배자 */ int best[MAXV]; /* link-eval: 경로 위 최소 sdom */ int uf[MAXV]; /* union-find 부모 */ int n; void addEdge(int u, int v) { to[ecnt]=v; nxt[ecnt]=head[u]; head[u]=ecnt++; rto[recnt]=u; rnxt[recnt]=rhead[v]; rhead[v]=recnt++; } void dfs(int u) { dfn[u] = dfsCnt; ord[dfsCnt++] = u; for (int e = head[u]; e != -1; e = nxt[e]) { int v = to[e]; if (dfn[v] == -1) { par[v] = u; dfs(v); } } } /* link-eval: find with path compression */ int eval(int v) { if (uf[v] == v) return v; int r = eval(uf[v]); if (dfn[sdom[best[uf[v]]]] < dfn[sdom[best[v]]]) best[v] = best[uf[v]]; uf[v] = r; return r; } /* sdom bucket */ int bhead[MAXV], bnxt[MAXV]; void buildDomTree(int s) { memset(dfn, -1, sizeof dfn); dfsCnt = 0; dfs(s); for (int i = 0; i < n; i++) { sdom[i] = i; best[i] = i; uf[i] = i; idom[i] = -1; bhead[i] = -1; } for (int i = dfsCnt - 1; i >= 1; i--) { int w = ord[i]; /* 1. sdom 계산 */ for (int e = rhead[w]; e != -1; e = rnxt[e]) { int u = rto[e]; if (dfn[u] == -1) continue; eval(u); if (dfn[sdom[best[u]]] < dfn[sdom[w]]) sdom[w] = sdom[best[u]]; } /* sdom[w]의 bucket에 w 추가 */ bnxt[w] = bhead[sdom[w]]; bhead[sdom[w]] = w; uf[w] = par[w]; /* link */ /* 2. par[w]의 bucket 처리 → idom 결정 */ int p = par[w]; for (int v = bhead[p]; v != -1; v = bnxt[v]) { eval(v); idom[v] = (sdom[best[v]] == p) ? p : best[v]; } bhead[p] = -1; } /* 3. idom 보정 */ for (int i = 1; i < dfsCnt; i++) { int w = ord[i]; if (idom[w] != sdom[w]) idom[w] = idom[idom[w]]; } idom[s] = s; } int main(void) { int m, s; scanf("%d %d %d", &n, &m, &s); memset(head, -1, sizeof head); memset(rhead, -1, sizeof rhead); for (int i = 0; i < m; i++) { int u, v; scanf("%d %d", &u, &v); addEdge(u, v); } buildDomTree(s); printf("지배 트리 (idom):\n"); for (int i = 0; i < n; i++) if (dfn[i] != -1) printf(" idom[%d] = %d\n", i, idom[i]); return 0; }

Gomory-Hu 트리 (컷 트리)
N개 정점의 가중치 트리로, 모든 쌍의 최소 컷 정보를 담고 있습니다.
성질: 트리에서 s-t 경로의 최소 간선 가중치 = 원래 그래프의 s-t 최소 컷
따라서 트리를 한 번 구축하면, 임의의 쌍의 최소 컷을 O(N)에 구할 수 있습니다.

구축 알고리즘
Step 1: 모든 정점의 “대표”를 정점 0으로 초기화
Step 2: i = 1, 2, ..., N-1에 대해:
  - 정점 i와 대표[i] 사이의 최대 유량(= 최소 컷) f를 구한다
  - 컷 트리에 간선 (i, 대표[i], f)를 추가
  - 대표[j] == 대표[i]이고 j > i인 정점들 중, 최소 컷에서 i 쪽에 속한 정점의 대표를 i로 변경

Cgomory_hu.c
#include <stdio.h> #include <string.h> #define MAXV 505 #define INF 0x3f3f3f3f int cap[MAXV][MAXV]; /* 원래 용량 */ int flow[MAXV][MAXV]; /* 잔여 용량 */ int rep[MAXV]; /* 대표 */ int cutSide[MAXV]; /* BFS에서 S측 여부 */ int n; /* 컷 트리 */ int treeAdj[MAXV], treeCap[MAXV]; /* treeAdj[i]=부모, treeCap[i]=간선 가중치 */ /* Dinic/EdmondsKarp로 maxflow(s,t) */ int maxflow(int s, int t) { /* 잔여 그래프 초기화 */ memcpy(flow, cap, sizeof cap); int total = 0; while (1) { /* BFS */ int vis[MAXV], par[MAXV], que[MAXV], qh=0, qt=0; memset(vis, 0, sizeof vis); memset(par, -1, sizeof par); vis[s] = 1; que[qt++] = s; while (qh < qt && !vis[t]) { int u = que[qh++]; for (int v = 0; v < n; v++) { if (!vis[v] && flow[u][v] > 0) { vis[v] = 1; par[v] = u; que[qt++] = v; } } } if (!vis[t]) break; /* 경로의 bottleneck */ int aug = INF; for (int v = t; v != s; v = par[v]) if (flow[par[v]][v] < aug) aug = flow[par[v]][v]; for (int v = t; v != s; v = par[v]) { flow[par[v]][v] -= aug; flow[v][par[v]] += aug; } total += aug; /* cutSide 기록 */ memcpy(cutSide, vis, sizeof vis); } /* 마지막 BFS의 vis가 S측 */ int vis2[MAXV], que2[MAXV], qh2=0, qt2=0; memset(vis2, 0, sizeof vis2); vis2[s] = 1; que2[qt2++] = s; while (qh2 < qt2) { int u = que2[qh2++]; for (int v = 0; v < n; v++) if (!vis2[v] && flow[u][v] > 0) { vis2[v]=1; que2[qt2++]=v; } } memcpy(cutSide, vis2, sizeof vis2); return total; } void buildGomoryHu() { for (int i = 0; i < n; i++) rep[i] = 0; for (int i = 1; i < n; i++) { int f = maxflow(i, rep[i]); treeAdj[i] = rep[i]; treeCap[i] = f; /* 대표 갱신 */ for (int j = i + 1; j < n; j++) if (rep[j] == rep[i] && cutSide[j]) rep[j] = i; } } int main(void) { int m; scanf("%d %d", &n, &m); memset(cap, 0, sizeof cap); for (int i = 0; i < m; i++) { int u, v, w; scanf("%d %d %d", &u, &v, &w); cap[u][v] += w; cap[v][u] += w; } buildGomoryHu(); printf("Gomory-Hu 트리:\n"); for (int i = 1; i < n; i++) printf(" %d -- %d (mincut=%d)\n", i, treeAdj[i], treeCap[i]); return 0; }
실행 결과 (n=4, 완전그래프, 모든 간선 가중치 1)
Gomory-Hu 트리: 1 -- 0 (mincut=3) 2 -- 0 (mincut=3) 3 -- 0 (mincut=3)
TIP Gomory-Hu 트리는 비방향 그래프에서만 동작합니다.
트리 구축 후 임의의 s-t 최소 컷은 트리 경로의 min edge로 O(N)에 구합니다.
전역 최소 컷(global min cut)은 트리의 최소 간선 가중치입니다.

평면 그래프 (Planar Graph)
평면에 간선이 교차하지 않게 그릴 수 있는 그래프입니다.
오일러 공식: V - E + F = 2 (V=정점, E=간선, F=면 수, 연결 그래프)
성질: E ≤ 3V - 6 (V ≥ 3일 때), 즉 간선 수가 정점 수에 비례

쌍대 그래프 (Dual Graph)
평면 그래프의 각 면을 정점으로, 인접한 면을 간선으로 연결한 그래프입니다.
원래 그래프의 간선 e가 면 f1과 f2를 분리하면, 쌍대에서 f1-f2 간선이 됩니다.
원래 간선과 쌍대 간선이 1:1 대응합니다.

최단 경로 ↔ 최소 컷 쌍대성
평면 그래프에서 s-t 최소 컷은 쌍대 그래프의 최단 경로로 변환됩니다!
구체적으로:
  - s와 t를 외부 면의 양쪽에 배치
  - s의 왼쪽 면(s*)에서 오른쪽 면(t*)까지의 최단 경로
  - = 원래 그래프에서 s-t를 분리하는 최소 비용 간선 집합
이를 통해 최대 유량 O(V²) 대신 Dijkstra O(E log V)로 최소 컷을 구할 수 있습니다.
