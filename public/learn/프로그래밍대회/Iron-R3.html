SECTION 57Iron | 함수
지역 변수 vs 전역 변수
scope지역변수전역변수Iron

지역 변수는 함수 안에서 선언되어 그 함수 안에서만 사용할 수 있습니다. 전역 변수는 함수 바깥에서 선언되어 모든 함수에서 접근 가능합니다.

C개념 코드
#include <stdio.h> int count = 0; // 전역 변수 void increment(void) { count++; // 전역 변수 접근 가능 } int main(void) { int x = 10; // 지역 변수 (main 안에서만) increment(); increment(); printf("count=%d, x=%d\n", count, x); return 0; }
실행 결과
count=2, x=10
전역 변수 남용 금지전역 변수는 편리하지만 어디서든 바뀔 수 있어 버그 원인이 됩니다. 대회에서 큰 배열은 전역으로 선언하되, 단순 변수는 지역으로 두는 것이 좋습니다.
