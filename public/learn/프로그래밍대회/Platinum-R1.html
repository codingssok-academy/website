Heavy-Light Decomposition 심화 — 경로 업데이트와 질의
HLDTree PathSegment TreePLATINUM

Gold와의 차이
Gold에서는 경로 합이나 최댓값 질의가 중심이었다면, Platinum에서는 경로 구간에 lazy propagation을 얹어 업데이트와 질의를 동시에 처리하는 경우가 많습니다.
이때 경로를 여러 체인으로 분해한 뒤 세그먼트 트리 구간 연산을 조합합니다.

Chld_lazy.c
void update_path(int u, int v, long long val) { while (head[u] != head[v]) { if (depth[head[u]] < depth[head[v]]) swap(&u, &v); seg_update(pos[head[u]], pos[u], val); u = parent[head[u]]; } if (depth[u] > depth[v]) swap(&u, &v); seg_update(pos[u], pos[v], val); }

트리 경로 여러 번HLD간선 값/정점 값 구분
경로 갱신 + 질의HLD + Lazy Segtree마지막 구간 포함 범위

SECTION 802Platinum | 고급 트리·자료구조
Centroid Decomposition 실전 — 최근접 질의
CentroidDistance QueryTree DividePLATINUM

전형 문제
정점을 빨간색으로 칠하거나 해제하고, 임의 정점에서 가장 가까운 빨간 정점까지 거리를 묻는 문제는 centroid decomposition의 대표 예시입니다.
각 정점이 centroid 조상까지의 거리를 미리 저장해 두면 갱신과 질의를 모두 O(log N)에 처리할 수 있습니다.

연산처리
정점 v 활성화centroid 조상 c마다 best[c] = min(best[c], dist(v,c))
정점 u 질의centroid 조상 c마다 best[c] + dist(u,c)의 최솟값
비활성화도 필요multiset 또는 카운팅 구조 추가
TIPPlatinum에서는 decomposition 자체보다, 조상 체인에 어떤 정보를 저장해야 문제 답으로 연결되는지가 더 중요합니다.

DSU on Tree — Sack Technique
DSU on TreeSubtree QuerySmall to LargePLATINUM

문제 구조
모든 정점에 대해 자기 서브트리 내 색 개수, 최빈값, 특정 조건을 만족하는 정점 수를 구하는 문제가 전형입니다.
heavy child는 유지하고, light child는 계산 후 버리는 방식으로 전체 복잡도를 줄입니다.

Cdsu_on_tree.c
void dfs(int v, int p, int keep) { for (int u : light_child[v]) dfs(u, v, 0); if (heavy[v] != -1) dfs(heavy[v], v, 1); for (int u : light_child[v]) add_subtree(u, v, +1); add_vertex(v, +1); answer[v] = current_answer(); if (!keep) add_subtree(v, p, -1); }
주의배열을 언제 초기화하고 무엇을 유지하는지 흐리면 바로 틀립니다. heavy subtree를 유지하고 나머지를 합친다는 흐름을 먼저 손으로 추적해 보세요.

SECTION 806Platinum | 고급 트리·자료구조
Implicit Treap — 수열 편집 자료구조
TreapSequenceSplit/MergePLATINUM

용도
배열처럼 보이지만 중간 삽입, 삭제, 구간 뒤집기, 구간 합 질의를 모두 빠르게 처리해야 할 때 implicit treap이 유용합니다.

Cimplicit_treap.c
void split(Node *t, int k, Node **a, Node **b) { if (!t) { *a = *b = NULL; return; } push(t); if (size(t->l) >= k) { split(t->l, k, a, &t->l); *b = pull(t); } else { split(t->r, k - size(t->l) - 1, &t->r, b); *a = pull(t); } }
