님 게임 (Nim) — XOR 전략으로 필승/필패 판별
NimXOR게임 이론Silver

[개념] 님 게임(Nim)은 가장 기본적인 조합 게임(combinatorial game)입니다.
N개의 돌 더미가 있고, 두 플레이어가 번갈아 하나의 더미에서 1개 이상의 돌을 가져갑니다.
마지막 돌을 가져가는 사람이 이기는 정상(normal play) 규칙을 따릅니다.
핵심 정리: 모든 더미 크기의 XOR(nim-sum)이 0이면 후수 필승, 0이 아니면 선수 필승입니다.

왜 XOR인가?
XOR = 0인 상태에서는 어떤 수를 빼도 XOR ≠ 0이 됩니다.
XOR ≠ 0인 상태에서는 항상 XOR = 0으로 만드는 수가 존재합니다.
따라서 XOR = 0 → 현재 움직여야 하는 플레이어가 불리 (필패 상태, P-position)
XOR ≠ 0 → 현재 플레이어가 유리 (필승 상태, N-position)

필승 전략 구체적 방법:
1) 전체 nim-sum S = a[0] ^ a[1] ^ ... ^ a[n-1] 계산
2) S ≠ 0이면, a[i] ^ S < a[i]인 더미 i를 찾음
3) 더미 i에서 a[i] - (a[i] ^ S)개를 제거하면 전체 XOR이 0이 됨

Cnim_game.c
#include <stdio.h> int main(void) { int n; scanf("%d", &n); int a[100]; int xor_sum = 0; for (int i = 0; i < n; i++) { scanf("%d", &a[i]); xor_sum ^= a[i]; } if (xor_sum == 0) { printf("Second player wins (P-position)\n"); } else { printf("First player wins (N-position)\n"); /* 필승 전략: XOR을 0으로 만드는 수 찾기 */ for (int i = 0; i < n; i++) { int target = a[i] ^ xor_sum; if (target < a[i]) { printf("Pile %d: remove %d stones (%d -> %d)\n", i, a[i] - target, a[i], target); break; } } } return 0; }

TIP XOR 연산의 성질을 기억하세요:
• a ^ a = 0 (자기 자신과 XOR하면 0)
• a ^ 0 = a (0과 XOR하면 자기 자신)
• 교환법칙, 결합법칙 성립

스프라그-그런디 정리 — 모든 공정 게임의 통합 이론
Sprague-GrundymexGrundy NumberSilver

[개념] 스프라그-그런디(Sprague-Grundy) 정리는 모든 공정(impartial) 게임을 님 게임으로 환원합니다.
공정 게임이란: 양쪽 플레이어가 동일한 수를 둘 수 있는 게임 (체스는 공정하지 않음, 님은 공정함)
모든 게임 상태에는 Grundy number (= nim-value, SG값)가 부여됩니다.

mex 함수 (minimum excludant):
mex(S) = 집합 S에 포함되지 않는 가장 작은 음이 아닌 정수
예) mex({0, 1, 3}) = 2
예) mex({1, 2}) = 0
예) mex({}) = 0 (빈 집합)

Grundy number 정의:
G(x) = mex({ G(y) | y는 x에서 한 수로 도달 가능한 상태 })
종료 상태(더 이상 움직일 수 없는 상태)의 Grundy number = 0
G(x) = 0이면 P-position (필패), G(x) ≠ 0이면 N-position (필승)

정리의 핵심:
1) 단일 게임: G(x)가 곧 그 게임의 "님 더미 크기"
2) 복합 게임: 독립적인 게임들의 Grundy number를 XOR하면 전체 게임의 Grundy number
G(game1 + game2) = G(game1) ^ G(game2)

증명 개요:
1) G(x) = 0인 상태에서는 G(y) ≠ 0인 상태로만 이동 가능 (mex 정의에 의해)
2) G(x) = k > 0인 상태에서는 G(y) = 0, 1, ..., k-1인 상태로 모두 이동 가능
이는 크기 k인 님 더미와 정확히 같은 구조입니다.

상태 x이동 가능한 상태들Grundy values of successorsG(x) = mex
종료 상태없음{}0
돌 1개종료{0}1
돌 2개종료, 돌1개{0, 1}2
돌 3개종료, 돌1, 돌2{0, 1, 2}3
NOTE 일반 님 게임에서 크기 n인 더미의 Grundy number는 n 자체입니다.
하지만 게임 규칙이 변형되면 Grundy number는 달라집니다.
예) "최대 3개까지만 가져갈 수 있는 님" → G(n) = n mod 4
TIP SG 정리의 강력함: 아무리 복잡한 공정 게임이라도
1) 각 독립 부분의 Grundy number를 구하고
2) 전부 XOR하면 전체 게임의 승패를 판별할 수 있습니다.

그런디 수 계산 — DP로 mex 구하기
GrundyDPmexSilver

[개념] 실제 문제에서 Grundy number를 계산하는 핵심은 DP(동적 프로그래밍)입니다.
작은 상태부터 bottom-up으로 G값을 채워 나갑니다.
mex를 구할 때는 boolean 배열을 활용하면 효율적입니다.

문제 설정:
돌 n개가 있고, 한 번에 가져갈 수 있는 개수가 집합 S = {s1, s2, ..., sk}로 제한됩니다.
예) S = {1, 3, 4} → 한 번에 1개, 3개, 또는 4개만 가져갈 수 있음
G(n) = mex({ G(n - si) | si ∈ S, n - si ≥ 0 })

#include <stdio.h> #include <string.h> #define MAXN 1001 #define MAXK 20 int grundy[MAXN]; /* mex: 집합에 없는 최소 비음수 정수 */ int mex(int *vals, int cnt) { int used[MAXN]; memset(used, 0, sizeof(used)); for (int i = 0; i < cnt; i++) if (vals[i] < MAXN) used[vals[i]] = 1; for (int i = 0; ; i++) if (!used[i]) return i; } int main(void) { int n, k; int s[MAXK]; /* 가져갈 수 있는 개수 집합 */ scanf("%d %d", &n, &k); for (int i = 0; i < k; i++) scanf("%d", &s[i]); grundy[0] = 0; /* 종료 상태 */ for (int i = 1; i <= n; i++) { int reachable[MAXK], cnt = 0; for (int j = 0; j < k; j++) if (i - s[j] >= 0) reachable[cnt++] = grundy[i - s[j]]; grundy[i] = mex(reachable, cnt); } printf("Grundy numbers: "); for (int i = 0; i <= n; i++) printf("G(%d)=%d ", i, grundy[i]); printf("\n"); if (grundy[n] != 0) printf("First player wins\n"); else printf("Second player wins\n"); return 0; }

SECTION 454Silver | 게임 이론
복합 게임 — 독립 게임의 XOR 결합
복합 게임XORSprague-GrundySilver

[개념] 여러 개의 독립적인 게임이 동시에 진행될 때, 전체 게임의 Grundy number는 각 부분 게임의 Grundy number를 XOR한 것입니다.
이것이 스프라그-그런디 정리의 핵심 결과입니다.
플레이어는 한 턴에 정확히 하나의 부분 게임에서만 수를 둡니다.

복합 게임의 예:
게임판 3개가 동시에 진행됨
게임 A: 돌 5개 (가져갈 수 있는 수 {1,2,3}) → G(A) = ?
게임 B: 돌 3개 (가져갈 수 있는 수 {1,2}) → G(B) = ?
게임 C: 돌 4개 (가져갈 수 있는 수 {1,3}) → G(C) = ?
전체: G = G(A) ^ G(B) ^ G(C)

Ccomposite_game.c
#include <stdio.h> #include <string.h> #define MAXN 1001 int compute_grundy(int n, int *moves, int mcnt) { int g[MAXN]; g[0] = 0; for (int i = 1; i <= n; i++) { int used[MAXN]; memset(used, 0, sizeof(used)); for (int j = 0; j < mcnt; j++) if (i - moves[j] >= 0 && g[i - moves[j]] < MAXN) used[g[i - moves[j]]] = 1; for (g[i] = 0; used[g[i]]; g[i]++); } return g[n]; } int main(void) { int num_games; scanf("%d", &num_games); int total_xor = 0; for (int g = 0; g < num_games; g++) { int n, k; scanf("%d %d", &n, &k); int moves[20]; for (int i = 0; i < k; i++) scanf("%d", &moves[i]); int gv = compute_grundy(n, moves, k); printf("Game %d: stones=%d, G=%d\n", g+1, n, gv); total_xor ^= gv; } printf("Total XOR = %d\n", total_xor); if (total_xor) printf("First player wins\n"); else printf("Second player wins\n"); return 0; }
INPUT
3 5 3 1 2 3 3 2 1 2 4 2 1 3
OUTPUT
Game 1: stones=5, G=1 Game 2: stones=3, G=0 Game 3: stones=4, G=2 Total XOR = 3 First player wins
TIP 복합 게임에서 XOR 대신 합(+)을 사용하는 것은 매우 흔한 실수입니다.
반드시 XOR(^)를 사용하세요. 이것이 님 게임의 수학적 구조입니다.
PRACTICE — 독립 게임 3개의 G값이 각각 3, 5, 6일 때 전체 승패와 필승 전략을 구하시오

SECTION 455Silver | 게임 이론
Green Hackenbush — 그래프 위의 게임
Hackenbush그래프 게임GrundySilver

[개념] Green Hackenbush는 그래프의 간선을 제거하는 게임입니다.
"ground"(지면)에 연결된 그래프에서, 플레이어는 번갈아 간선 하나를 제거합니다.
간선 제거 후 지면과 연결되지 않는 부분은 사라집니다.
더 이상 간선을 제거할 수 없으면 패배합니다.

트리에서의 Hackenbush:
트리(tree)의 경우 분석이 단순해집니다.
각 간선의 "높이"(지면으로부터의 거리)를 기준으로 생각하면:
• 경로(path) 하나의 Grundy number = 경로 길이 (간선 수)
• 여러 경로가 한 점에서 만나면: 각 서브트리의 Grundy number를 XOR

Colon Principle (콜론 원리):
트리의 한 정점에 여러 서브트리가 붙어 있으면,
각 서브트리의 Grundy number를 XOR한 값을 가진 단일 간선으로 대체 가능합니다.
이를 반복하면 복잡한 트리도 단일 경로로 축소됩니다.

트리 구조서브트리 G값XOR 결합최종 G값
A — B — C (경로)길이 = 2—2
A에서 B, C 분기 (높이 각 1)G(B)=1, G(C)=11 ^ 1 = 00 (+ A-root 간선 1) = 1
root에서 길이 3, 2 분기G=3, G=23 ^ 2 = 11
NOTE Green Hackenbush에서 "green"은 양쪽 모두 같은 간선을 자를 수 있다는 뜻입니다 (공정 게임).
Blue-Red Hackenbush는 편파적(partisan) 게임으로, 훨씬 복잡합니다.
대회에서는 주로 Green Hackenbush (트리 위)가 출제됩니다.
TIP 트리 Hackenbush의 풀이 흐름:
1) 리프에서 루트 방향으로 올라가며 각 서브트리의 G값을 XOR
2) 최종 루트의 G값이 0이면 후수 승, 아니면 선수 승
PRACTICE — 루트에서 길이 4, 3, 2인 세 경로가 뻗어나간 트리의 Hackenbush G값을 구하시오

동전 뒤집기 게임 — 격자 위 님-값 분석
Coin TurningNim-value격자 게임Silver

[개념] 1차원 동전 뒤집기 게임: n개의 동전이 일렬로 놓여 있고, 각각 앞면(H) 또는 뒷면(T)입니다.
플레이어는 앞면인 동전 하나를 선택하여 뒤집고(H→T),
선택한 동전보다 왼쪽에 있는 동전 중 하나를 추가로 뒤집을 수 있습니다 (선택 사항).
모든 동전이 뒷면이 되면 더 이상 움직일 수 없어 패배합니다.

님-값 분석:
각 앞면 동전의 위치를 님 더미로 생각합니다.
위치 i에 앞면 동전이 있으면, 이것은 크기 i인 님 더미와 동치입니다.
전체 게임의 Grundy number = 모든 앞면 동전 위치의 XOR

예제:
동전 배열: T H T H T H (인덱스 0~5)
앞면 위치: 1, 3, 5
G = 1 ^ 3 ^ 5 = 7 ≠ 0 → 선수 필승

Ccoin_flip_game.c
#include <stdio.h> #include <string.h> int main(void) { int n; char coins[101]; /* 'H' or 'T' */ scanf("%d", &n); for (int i = 0; i < n; i++) scanf(" %c", &coins[i]); int xor_sum = 0; printf("Heads at positions: "); for (int i = 0; i < n; i++) { if (coins[i] == 'H') { printf("%d ", i); xor_sum ^= i; } } printf("\n"); printf("XOR = %d\n", xor_sum); if (xor_sum != 0) printf("First player wins\n"); else printf("Second player wins\n"); return 0; }

OUTPUT
Heads at positions: 1 3 5 XOR = 7 First player wins

이 패턴을 기억하면 2D 변형도 쉽게 풀 수 있습니다.

SECTION 457Silver | 게임 이론
미세로 게임 (Misère Nim) — 마지막 돌 가져가면 지는 변형
Misere NimXOR특수 처리Silver

[개념] 미세로 님(Misère Nim)은 마지막 돌을 가져가는 사람이 지는 변형입니다.
일반 님과 거의 같지만, 끝 처리가 다릅니다.
핵심 차이: "모든 더미의 크기가 1 이하"인 경우만 특별히 처리합니다.

미세로 님 전략:
경우 1: 모든 더미의 크기 ≤ 1
  → 더미 수가 홀수이면 후수 승 (선수가 마지막을 가져감)
  → 더미 수가 짝수이면 선수 승
경우 2: 크기 > 1인 더미가 존재
  → XOR ≠ 0이면 선수 승 (일반 님과 동일)
  → XOR = 0이면 후수 승 (일반 님과 동일)

왜 이렇게 되는가?

기댓값 기초 — E[X]의 정의와 선형성
기댓값선형성확률Silver

[개념] 확률변수 X의 기댓값(Expected Value) E[X]는 X가 취할 수 있는 모든 값에 대해 "값 × 확률"의 합입니다.
E[X] = Σ x · P(X = x)
직관적으로 "평균적으로 기대되는 값"을 의미합니다.

기댓값의 선형성 (Linearity of Expectation):
E[X + Y] = E[X] + E[Y]
이 성질은 X와 Y가 독립이든 아니든 항상 성립합니다.
이것이 기댓값 문제를 풀 때 가장 강력한 도구입니다.

예제 1: 주사위 기댓값
공정한 6면 주사위: E[X] = (1+2+3+4+5+6)/6 = 3.5

예제 2: 동전 던지기
공정한 동전을 10번 던질 때 앞면 횟수의 기댓값:
X = X1 + X2 + ... + X10 (Xi = i번째가 앞면이면 1, 아니면 0)
E[X] = E[X1] + E[X2] + ... + E[X10] = 10 × 0.5 = 5

예제 3: 선형성의 위력
n명이 모자를 벗어 무작위로 섞은 후 다시 쓸 때, 자기 모자를 쓴 사람 수의 기댓값:
Xi = i번째 사람이 자기 모자를 쓰면 1
E[Xi] = 1/n
E[X] = n × (1/n) = 1 (n에 관계없이 항상 1!)

상황확률변수기댓값 계산결과
주사위 1회X = 눈(1+2+3+4+5+6)/63.5
동전 10회X = 앞면 수10 × 0.55
모자 문제 (n=100)X = 맞는 모자 수100 × (1/100)1
주사위 2개 합X = 합3.5 + 3.57
TIP 기댓값의 선형성을 사용하면, 복잡한 확률 계산 없이도 기댓값을 구할 수 있습니다.

도달 확률:
dp[i] = 위치 i에서 시작하여 위치 N에 도달할 확률
dp[0] = 0, dp[N] = 1
dp[i] = 0.5 × dp[i-1] + 0.5 × dp[i+1]
해: dp[i] = i/N (대칭 랜덤 워크)

E[i] = 위치 i에서 흡수될 때까지의 기대 걸음 수
E[0] = 0, E[N] = 0
E[i] = 1 + 0.5 × E[i-1] + 0.5 × E[i+1]
해: E[i] = i × (N - i)

[개념] 조건부 확률 P(A|B)는 B가 일어났을 때 A가 일어날 확률입니다.
P(A|B) = P(A ∩ B) / P(B)
베이즈 정리: P(A|B) = P(B|A) × P(A) / P(B)

베이즈 정리의 확장 (전체 확률의 법칙):
P(B) = Σ P(B|Ai) × P(Ai) (Ai가 전체를 분할할 때)
따라서: P(Ai|B) = P(B|Ai) × P(Ai) / Σ P(B|Aj) × P(Aj)

예제: 질병 검사
유병률: P(병) = 0.01
검사 민감도: P(양성|병) = 0.99
검사 특이도: P(음성|건강) = 0.95, 즉 P(양성|건강) = 0.05
양성일 때 실제 병일 확률: P(병|양성) = ?
P(양성) = 0.99 × 0.01 + 0.05 × 0.99 = 0.0099 + 0.0495 = 0.0594
P(병|양성) = 0.0099 / 0.0594 ≈ 0.1667 (약 16.7%!)

#include <stdio.h> #include <stdlib.h> #define MAXY 100001 int bit[MAXY]; void bit_update(int i, int val) { for (; i < MAXY; i += i & (-i)) bit[i] += val; } int bit_query(int i) { int s = 0; for (; i > 0; i -= i & (-i)) s += bit[i]; return s; } int bit_range(int l, int r) { return bit_query(r) - bit_query(l - 1); } typedef struct { int x, y1, y2, type; /* type: 0=START, 1=QUERY, 2=END */ } Event; int cmp_event(const void *a, const void *b) { Event *ea = (Event*)a, *eb = (Event*)b; if (ea->x != eb->x) return ea->x - eb->x; return ea->type - eb->type; } int main(void) { int h, v; /* 수평, 수직 선분 수 */ scanf("%d %d", &h, &v); Event events[30001]; int ecnt = 0; for (int i = 0; i < h; i++) { int x1, x2, y; scanf("%d %d %d", &x1, &x2, &y); if (x1 > x2) { int t = x1; x1 = x2; x2 = t; } events[ecnt++] = (Event){x1, y, y, 0}; events[ecnt++] = (Event){x2, y, y, 2}; } for (int i = 0; i < v; i++) { int x, y1, y2; scanf("%d %d %d", &x, &y1, &y2); if (y1 > y2) { int t = y1; y1 = y2; y2 = t; } events[ecnt++] = (Event){x, y1, y2, 1}; } qsort(events, ecnt, sizeof(Event), cmp_event); int total = 0; for (int i = 0; i < ecnt; i++) { if (events[i].type == 0) bit_update(events[i].y1, 1); else if (events[i].type == 2) bit_update(events[i].y1, -1); else total += bit_range(events[i].y1, events[i].y2); } printf("Intersections: %d\n", total); return 0; }

오프라인 알고리즘 — Mo's Algorithm
Mo's Algorithmsqrt 분할오프라인Silver

[개념] Mo's Algorithm은 구간 쿼리를 오프라인으로 처리하는 기법입니다.
쿼리를 적절히 정렬하여 구간의 양 끝을 최소한으로 이동시킵니다.
시간 복잡도: O((N + Q) × √N)

정렬 기준:
1) l을 √N 크기의 블록 번호로 나눔
2) 같은 블록이면 r 기준 오름차순
이렇게 하면 l은 블록 내에서 O(√N)만 이동하고,
r은 각 블록에서 전체 O(N) 이동 → 총 O(N√N)

Cmos_algorithm.c
#include <stdio.h> #include <stdlib.h> #include <math.h> #define MAXN 100001 #define MAXQ 100001 #define MAXVAL 1000001 int a[MAXN], ans[MAXQ]; int cnt[MAXVAL]; /* 값의 출현 횟수 */ int distinct; /* 구간 내 서로 다른 값의 수 */ int block_size; typedef struct { int l, r, idx; } Query; Query queries[MAXQ]; int cmp_query(const void *a, const void *b) { Query *qa = (Query*)a, *qb = (Query*)b; int ba = qa->l / block_size, bb = qb->l / block_size; if (ba != bb) return ba - bb; return (ba & 1) ? qb->r - qa->r : qa->r - qb->r; } void add(int idx) { if (cnt[a[idx]]++ == 0) distinct++; } void remove_val(int idx) { if (--cnt[a[idx]] == 0) distinct--; } int main(void) { int n, q; scanf("%d %d", &n, &q); block_size = (int)sqrt(n) + 1; for (int i = 0; i < n; i++) scanf("%d", &a[i]); for (int i = 0; i < q; i++) { scanf("%d %d", &queries[i].l, &queries[i].r); queries[i].l--; /* 0-indexed */ queries[i].r--; queries[i].idx = i; } qsort(queries, q, sizeof(Query), cmp_query); int cl = 0, cr = -1; distinct = 0; for (int i = 0; i < q; i++) { int l = queries[i].l, r = queries[i].r; while (cr < r) add(++cr); while (cl > l) add(--cl); while (cr > r) remove_val(cr--); while (cl < l) remove_val(cl++); ans[queries[i].idx] = distinct; } for (int i = 0; i < q; i++) printf("%d\n", ans[i]); return 0; }

OUTPUT
3 2 4
쿼리 (정렬 후)cl, cr 이동distinct답
[0,4] (원래 쿼리1)cl:0→0, cr:-1→4{1,2,3} = 33
[1,3] (원래 쿼리2)cl:0→1, cr:4→3{2,1,3} → remove a[4]=2, a[0]=1 → 22
[2,6] (원래 쿼리3)cl:1→2, cr:3→6{1,3,2,1,4} = 44
TIP Mo's Algorithm의 정렬에서 짝수 블록은 r 오름차순, 홀수 블록은 r 내림차순으로 하면
(지그재그 정렬) 상수를 약 30% 줄일 수 있습니다.
WARNING Mo's Algorithm은 오프라인이므로 쿼리를 모두 읽은 후 처리합니다.
온라인 강제 문제(이전 답에 따라 다음 쿼리가 결정)에는 사용할 수 없습니다.

온라인 vs 오프라인 — 강제 온라인과 퍼시스턴트 자료구조
온라인오프라인퍼시스턴트Silver

[개념] 오프라인 알고리즘은 모든 쿼리를 미리 알고 재배열하여 처리합니다.
온라인 알고리즘은 각 쿼리를 즉시 처리하고, 이전 답이 다음 쿼리에 영향을 줄 수 있습니다.
강제 온라인: 문제에서 이전 답으로 다음 쿼리를 XOR하는 트릭을 사용하여 오프라인을 방지합니다.

오프라인이 가능할 때:
• Mo's Algorithm: 구간 쿼리 재배열
• CDQ 분할정복: 시간순 분할
• 쿼리 정렬 후 스위핑
장점: 구현이 쉽고 상수가 작음

강제 온라인일 때 필요한 도구:
• 퍼시스턴트 세그먼트 트리: 버전 관리 가능한 세그트리
• 퍼시스턴트 배열/트라이
• 링크-컷 트리: 동적 트리 쿼리
• 각 쿼리를 O(log N)에 독립 처리 가능해야 함

비교 항목오프라인온라인
쿼리 순서재배열 가능고정 (순서대로)

대표 기법Mo's, CDQ, 쿼리 정렬퍼시스턴트, 세그트리
공간 복잡도보통 O(N)퍼시스턴트: O(N log N)
구현 난이도보통높음
NOTE 강제 온라인 문제의 전형적 패턴:
실제 쿼리 = 주어진 값 XOR 이전 답

비트 병렬 처리 — bitset으로 N/64 최적화
Bitset비트 병렬N/64Silver

[개념] 비트 병렬(bit parallelism)은 64비트 정수 하나로 64개의 불리언 값을 동시에 처리하는 기법입니다.
N개의 원소에 대한 집합 연산을 N/64로 가속할 수 있습니다.
C에서는 unsigned long long 배열로 bitset을 구현합니다.

주요 응용:
1) 전이적 폐포 (Transitive Closure): adj[i] |= adj[j] (행 OR 연산)
2) 도달 가능성: 그래프에서 i에서 j로 갈 수 있는지
3) 집합 교집합/합집합 빠르게 계산
4) 부분합 문제의 가속

Cbitset_transitive.c
#include <stdio.h> #include <string.h> #define MAXN 1000 #define WORDS (MAXN / 64 + 1) unsigned long long reach[MAXN][WORDS]; /* i번째 비트 설정 */ void set_bit(unsigned long long *bs, int i) { bs[i / 64] |= 1ULL << (i % 64); } /* i번째 비트 확인 */ int get_bit(unsigned long long *bs, int i) { return (bs[i / 64] >> (i % 64)) & 1; } /* bs1 |= bs2 (OR 연산) */ void or_bs(unsigned long long *dst, unsigned long long *src, int w) { for (int i = 0; i < w; i++) dst[i] |= src[i]; } int main(void) { int n, m; scanf("%d %d", &n, &m); int w = n / 64 + 1; memset(reach, 0, sizeof(reach)); /* 자기 자신은 도달 가능 */ for (int i = 0; i < n; i++) set_bit(reach[i], i); /* 간선 입력 */ for (int i = 0; i < m; i++) { int u, v; scanf("%d %d", &u, &v); set_bit(reach[u], v); } /* Floyd-Warshall with bitset: O(N^3 / 64) */ for (int k = 0; k < n; k++) for (int i = 0; i < n; i++) if (get_bit(reach[i], k)) or_bs(reach[i], reach[k], w); /* 도달 가능한 쌍의 수 */ int cnt = 0; for (int i = 0; i < n; i++) for (int j = 0; j < w; j++) cnt += __builtin_popcountll(reach[i][j]); printf("Reachable pairs: %d\n", cnt); return 0; }

[개념] 메모리 제한이 엄격한 문제에서는 DP 테이블을 압축해야 합니다.
핵심 기법 두 가지:
1) 슬라이딩 DP: 이전 행만 유지 (2행 교대 사용)
2) 비트마스크 DP: 불리언 배열을 정수의 비트로 압축

슬라이딩 DP 예제: LCS (Longest Common Subsequence)
일반 LCS: dp[i][j] = 문자열 A의 i번째, B의 j번째까지 고려한 LCS 길이
공간: O(N×M) → 슬라이딩으로 O(M)으로 줄임
dp[j]만 유지하고, 이전 행 값을 prev에 백업

Csliding_lcs.c
#include <stdio.h> #include <string.h> #define MAXLEN 100001 int dp[2][MAXLEN]; int main(void) { char a[MAXLEN], b[MAXLEN]; scanf("%s %s", a, b); int n = strlen(a), m = strlen(b); memset(dp, 0, sizeof(dp)); for (int i = 1; i <= n; i++) { int cur = i & 1, prev = 1 - cur; for (int j = 1; j <= m; j++) { if (a[i-1] == b[j-1]) dp[cur][j] = dp[prev][j-1] + 1; else dp[cur][j] = dp[prev][j] > dp[cur][j-1] ? dp[prev][j] : dp[cur][j-1]; } } printf("LCS length: %d\n", dp[n & 1][m]); return 0; }
