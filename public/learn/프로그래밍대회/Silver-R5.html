Suffix Array 응용 — LCP 배열로 서로 다른 부분 문자열 수
Suffix ArrayLCP문자열Silver

[개념] 길이 N인 문자열의 모든 부분 문자열(substring) 수는 N(N+1)/2이지만, 중복을 제거하면 몇 개일까요?
Suffix Array(SA)와 LCP(Longest Common Prefix) 배열을 사용하면 O(N) 시간에 답을 구할 수 있습니다.
핵심 공식: 서로 다른 부분 문자열 수 = Σ(N - SA[i] - LCP[i]) (i = 0 ~ N-1)

왜 이 공식이 성립하는가?
SA[i]번째 접미사의 길이는 N - SA[i]이고, 이 접미사가 가진 접두사(= 부분 문자열)는 N - SA[i]개입니다.
그런데 LCP[i]개는 이전 접미사(SA[i-1])와 공유하는 접두사이므로 중복입니다.
따라서 SA[i]번째 접미사가 새로 기여하는 부분 문자열 수는 (N - SA[i]) - LCP[i]입니다.
이를 모든 i에 대해 합하면 전체 서로 다른 부분 문자열 수가 됩니다.
(LCP[0] = 0으로 정의)

Suffix Array 구축은 O(N log N) 또는 O(N)에 가능합니다.
여기서는 O(N log²N)의 간결한 구현을 사용합니다.
LCP 배열은 Kasai 알고리즘으로 O(N)에 구합니다.

#include <stdio.h> #include <string.h> #include <stdlib.h> #define MAXN 100005 char s[MAXN]; int sa[MAXN], rnk[MAXN], tmp[MAXN], lcp[MAXN]; int n; /* O(N log^2 N) Suffix Array 구축 */ int cmp(const void *a, const void *b) { int i = *(int*)a, j = *(int*)b; if (rnk[i] != rnk[j]) return rnk[i] - rnk[j]; int ri = (i + (n/2) < n) ? rnk[i + n/2] : -1; int rj = (j + (n/2) < n) ? rnk[j + n/2] : -1; return ri - rj; } void build_sa() { int i, k; for (i = 0; i < n; i++) { sa[i] = i; rnk[i] = s[i]; } for (k = 1; k < n; k *= 2) { qsort(sa, n, sizeof(int), cmp); tmp[sa[0]] = 0; for (i = 1; i < n; i++) { tmp[sa[i]] = tmp[sa[i-1]]; int pi = sa[i-1], ci = sa[i]; int rpi = (pi+k < n) ? rnk[pi+k] : -1; int rci = (ci+k < n) ? rnk[ci+k] : -1; if (rnk[pi] != rnk[ci] || rpi != rci) tmp[sa[i]]++; } for (i = 0; i < n; i++) rnk[i] = tmp[i]; } } /* Kasai 알고리즘: O(N) LCP 배열 */ void build_lcp() { int i, k = 0; int inv[MAXN]; for (i = 0; i < n; i++) inv[sa[i]] = i; for (i = 0; i < n; i++) { if (inv[i] == 0) { k = 0; continue; } int j = sa[inv[i] - 1]; while (i + k < n && j + k < n && s[i+k] == s[j+k]) k++; lcp[inv[i]] = k; if (k) k--; } } int main() { scanf("%s", s); n = strlen(s); build_sa(); build_lcp(); long long total = 0; for (int i = 0; i < n; i++) total += (n - sa[i]) - lcp[i]; printf("서로 다른 부분 문자열 수: %lld\n", total); /* SA와 LCP 출력 */ printf("i\tSA[i]\tLCP[i]\tSuffix\n"); for (int i = 0; i < n; i++) printf("%d\t%d\t%d\t%s\n", i, sa[i], lcp[i], s + sa[i]); return 0; }

Suffix Array + LCP로 최장 반복 부분 문자열
Suffix ArrayLCP최장 반복Silver

[개념] 최장 반복 부분 문자열(Longest Repeated Substring)은 문자열 안에서 2번 이상 등장하는 가장 긴 부분 문자열입니다.
LCP 배열의 최댓값이 곧 최장 반복 부분 문자열의 길이입니다.
이유: LCP[i]는 사전순 인접한 두 접미사의 공통 접두사 길이이며, 공통 접두사는 원래 문자열에서 2번 이상 등장합니다.

2개 이상 문자열에서 최장 공통 부분 문자열(LCS):
문자열 A와 B를 구분자(원래 문자열에 없는 문자, 예: '#')로 연결합니다.
연결된 문자열 "A#B"에 대해 SA와 LCP를 구합니다.
LCP[i]가 최대인 것 중, SA[i]와 SA[i-1]이 서로 다른 문자열에 속하는 경우를 찾습니다.
그 LCP 값이 최장 공통 부분 문자열의 길이입니다.

회문 트리 (Eertree) — 고유 팰린드롬 부분 문자열 관리
EertreePalindrome문자열Silver

[개념] 회문 트리(Palindrome Tree, Eertree)는 문자열의 모든 고유 팰린드롬 부분 문자열을 관리하는 자료구조입니다.
길이 N인 문자열에서 고유 팰린드롬 부분 문자열은 최대 N+1개이며, Eertree는 이를 O(N) 시간에 구축합니다.
각 노드가 하나의 고유 팰린드롬을 나타냅니다.

노드 구조:
• len: 이 노드가 나타내는 팰린드롬의 길이
• link: suffix link — 이 팰린드롬의 가장 긴 진접미사(proper suffix)이면서 팰린드롬인 것을 가리킴
• to[c]: 문자 c를 양쪽에 추가하여 만든 더 긴 팰린드롬
• cnt: 등장 횟수 (나중에 suffix link를 따라 전파)

초기 상태:
• 노드 0: "홀수 루트" (len = -1). 모든 길이 1 팰린드롬의 부모
• 노드 1: "짝수 루트" (len = 0). 빈 문자열을 나타냄
• 둘 다 suffix link는 노드 0을 가리킴

삽입 알고리즘 (문자 s[i] 추가):
1) 현재 노드(last)에서 suffix link를 따라가며 s[i-1-len] == s[i]인 노드 p를 찾음
2) p에서 문자 s[i]로의 간선이 없으면 새 노드를 생성
3) 새 노드의 suffix link: p의 suffix link에서 같은 과정을 반복하여 찾음
4) last를 새 노드(또는 기존 노드)로 갱신

#include <stdio.h> #include <string.h> #define MAXN 100005 #define ALPHA 26 struct Node { int len, link, cnt; int to[ALPHA]; } tree[MAXN]; int sz, last; char s[MAXN]; int n; void init() { /* 노드 0: 홀수 루트 (len=-1) */ tree[0].len = -1; tree[0].link = 0; memset(tree[0].to, -1, sizeof(tree[0].to)); /* 노드 1: 짝수 루트 (len=0) */ tree[1].len = 0; tree[1].link = 0; memset(tree[1].to, -1, sizeof(tree[1].to)); sz = 2; last = 1; } int get_link(int v, int i) { while (i - tree[v].len - 1 < 0 || s[i - tree[v].len - 1] != s[i]) v = tree[v].link; return v; } void add_char(int i) { int c = s[i] - 'a'; int p = get_link(last, i); if (tree[p].to[c] == -1) { int cur = sz++; tree[cur].len = tree[p].len + 2; memset(tree[cur].to, -1, sizeof(tree[cur].to)); tree[cur].cnt = 0; int q = get_link(tree[p].link, i); tree[cur].link = (tree[q].to[c] != -1) ? tree[q].to[c] : 1; tree[p].to[c] = cur; } last = tree[p].to[c]; tree[last].cnt++; } int main() { scanf("%s", s); n = strlen(s); init(); for (int i = 0; i < n; i++) add_char(i); /* suffix link를 따라 cnt 전파 */ for (int i = sz - 1; i >= 2; i--) tree[tree[i].link].cnt += tree[i].cnt; printf("고유 팰린드롬 수: %d\n", sz - 2); for (int i = 2; i < sz; i++) printf(" 노드 %d: len=%d, cnt=%d\n", i, tree[i].len, tree[i].cnt); return 0; }

Lyndon 분해 — Duval 알고리즘과 최소 회전
LyndonDuval최소 회전Silver

[개념] Lyndon word란 자기 자신이 모든 회전(rotation) 중 사전순으로 가장 작은 문자열입니다.
예: "abc"는 Lyndon word (abc < bca < cab)
예: "aab"는 Lyndon word (aab < aba < baa)
예: "abab"는 Lyndon word가 아님 (abab > abab... 자기 자신의 접미사보다 큰 접두사 존재)

Lyndon 분해: 모든 문자열 S는 s1 s2 ... sk로 분해할 수 있으며, 각 si는 Lyndon word이고 s1 ≥ s2 ≥ ... ≥ sk (사전순)입니다.
이 분해는 유일합니다.

Duval 알고리즘 (O(N)):
세 포인터 i, j, k를 사용합니다.
• i: 현재 Lyndon 분해의 시작 위치
• j: 비교 기준 위치 (주기의 시작)
• k: 현재 비교 위치
s[k] == s[j]이면 k++, j++
s[k] > s[j]이면 k++, j = i (새로운 Lyndon word 후보)
s[k] < s[j]이면 Lyndon word 하나가 결정됨, i 전진

최소 회전 문자열과의 관계:
문자열 S를 두 번 이어붙인 SS에 대해 Lyndon 분해를 하면, 최소 회전의 시작 위치를 찾을 수 있습니다.
SS의 Lyndon 분해에서 첫 번째 인자 길이가 N 이상이면 그 시작이 최소 회전입니다.

Clyndon_decomp.c
#include <stdio.h> #include <string.h> #define MAXN 100005 char s[MAXN]; /* Duval 알고리즘: Lyndon 분해 O(N) */ void lyndon_decomp(char *s, int n) { int i = 0; printf("Lyndon 분해: "); while (i < n) { int j = i, k = i + 1; while (k < n && s[j] <= s[k]) { if (s[j] < s[k]) j = i; else j++; k++; } int len = k - j; /* Lyndon word의 주기 */ while (i <= j) { printf("["); for (int t = 0; t < len; t++) putchar(s[i + t]); printf("] "); i += len; } } printf("\n"); } /* 최소 회전: Booth 알고리즘 O(N) */ int min_rotation(char *s, int n) { char ss[MAXN * 2]; for (int i = 0; i < n; i++) { ss[i] = s[i]; ss[i + n] = s[i]; } int f[MAXN * 2]; memset(f, -1, sizeof(f)); int best = 0; for (int j = 1; j < 2 * n; j++) { int i = f[j - 1 - best]; while (i != -1 && ss[j] != ss[best + i + 1]) { if (ss[j] < ss[best + i + 1]) best = j - i - 1; i = f[i]; } if (i == -1 && ss[j] != ss[best]) { if (ss[j] < ss[best]) best = j; f[j - best] = -1; } else { f[j - best] = i + 1; } } return best; } int main() { scanf("%s", s); int n = strlen(s); lyndon_decomp(s, n); int pos = min_rotation(s, n); printf("최소 회전 시작: %d\n", pos); printf("최소 회전: "); for (int i = 0; i < n; i++) putchar(s[(pos + i) % n]); printf("\n"); return 0; }

Suffix Automaton 응용 — 부분 문자열 등장 횟수와 LCS
Suffix AutomatonSAM문자열Silver

[개념] Suffix Automaton(SAM)은 문자열의 모든 부분 문자열을 인식하는 최소 DFA입니다.
길이 N인 문자열에서 SAM의 상태 수는 최대 2N-1, 전이 수는 최대 3N-4입니다.
O(N) 시간에 구축할 수 있습니다.

SAM의 핵심 개념:
• endpos: 부분 문자열 t가 원문에서 끝나는 모든 위치의 집합
• 같은 endpos를 가진 부분 문자열들은 같은 상태에 속함
• suffix link: 한 상태에서 endpos가 진(strictly) 확장되는 가장 긴 접미사 상태를 가리킴
• suffix link들은 트리를 이루며, 이 트리를 parent tree라고 함

부분 문자열 등장 횟수:
각 상태의 cnt를 1로 초기화 (clone된 상태는 0)
suffix link 트리에서 역순으로 cnt를 전파하면, 각 상태의 cnt가 해당 부분 문자열의 등장 횟수가 됩니다.

두 문자열의 최장 공통 부분 문자열 (LCS):
문자열 A의 SAM을 구축한 뒤, 문자열 B를 SAM 위에서 매칭합니다.
현재 상태와 매칭 길이를 유지하며, 전이가 없으면 suffix link를 따라감
매칭 길이의 최댓값이 LCS 길이입니다.

#include <stdio.h> #include <string.h> #define MAXN 200005 #define ALPHA 26 struct State { int len, link; int to[ALPHA]; long long cnt; int is_clone; } st[MAXN * 2]; int sz, last; void sa_init() { st[0].len = 0; st[0].link = -1; memset(st[0].to, -1, sizeof(st[0].to)); st[0].cnt = 0; st[0].is_clone = 0; sz = 1; last = 0; } void sa_extend(int c) { int cur = sz++; st[cur].len = st[last].len + 1; st[cur].cnt = 1; st[cur].is_clone = 0; memset(st[cur].to, -1, sizeof(st[cur].to)); int p = last; while (p != -1 && st[p].to[c] == -1) { st[p].to[c] = cur; p = st[p].link; } if (p == -1) { st[cur].link = 0; } else { int q = st[p].to[c]; if (st[p].len + 1 == st[q].len) { st[cur].link = q; } else { int clone = sz++; st[clone] = st[q]; st[clone].len = st[p].len + 1; st[clone].cnt = 0; st[clone].is_clone = 1; while (p != -1 && st[p].to[c] == q) { st[p].to[c] = clone; p = st[p].link; } st[q].link = clone; st[cur].link = clone; } } last = cur; } /* cnt 전파: 위상 정렬 (len 내림차순) */ int order[MAXN * 2], bucket[MAXN]; void propagate_cnt() { int maxlen = 0; for (int i = 0; i < sz; i++) { if (st[i].len > maxlen) maxlen = st[i].len; } memset(bucket, 0, sizeof(int) * (maxlen + 1)); for (int i = 0; i < sz; i++) bucket[st[i].len]++; for (int i = 1; i <= maxlen; i++) bucket[i] += bucket[i-1]; for (int i = sz - 1; i >= 0; i--) order[--bucket[st[i].len]] = i; for (int i = sz - 1; i >= 1; i--) st[st[order[i]].link].cnt += st[order[i]].cnt; } int main() { char a[MAXN], b[MAXN]; scanf("%s %s", a, b); /* A의 SAM 구축 */ sa_init(); for (int i = 0; a[i]; i++) sa_extend(a[i] - 'a'); propagate_cnt(); printf("SAM 상태 수: %d\n", sz); /* B와의 LCS */ int cur = 0, matched = 0, best = 0; for (int i = 0; b[i]; i++) { int c = b[i] - 'a'; while (cur != 0 && st[cur].to[c] == -1) { cur = st[cur].link; matched = st[cur].len; } if (st[cur].to[c] != -1) { cur = st[cur].to[c]; matched++; } if (matched > best) best = matched; } printf("LCS 길이: %d\n", best); return 0; }

아호-코라식 심화 — 다중 패턴 등장 횟수와 fail 트리 DP
Aho-Corasickfail 트리DPSilver

[개념] 아호-코라식(Aho-Corasick) 알고리즘은 여러 패턴을 동시에 텍스트에서 찾는 알고리즘입니다.
기본 아호-코라식은 "어떤 패턴이 어디서 등장하는가"를 찾지만, 심화에서는 각 패턴의 등장 횟수를 구합니다.

fail 트리(failure tree):
각 노드의 failure link를 부모로 생각하면 트리가 됩니다.
노드 v를 방문할 때마다 v에서 루트까지의 경로에 있는 모든 패턴 끝 노드에 +1 기여합니다.
이를 나이브하게 하면 O(텍스트길이 × 최대패턴길이)이지만, fail 트리 위 DP로 O(N+M)에 가능합니다.

효율적 방법:
1) 텍스트를 오토마톤 위에서 순회하며, 방문한 노드에 cnt[v]++
2) BFS 역순(잎 → 루트)으로 cnt[v]를 failure link 부모에 전파
3) 패턴 끝 노드의 cnt 값이 해당 패턴의 등장 횟수

Caho_corasick_count.c
#include <stdio.h> #include <string.h> #define MAXN 500005 #define ALPHA 26 int to[MAXN][ALPHA], fail[MAXN], sz; int pat_end[MAXN]; /* 패턴 i의 끝 노드 */ long long cnt[MAXN]; int q[MAXN], head, tail; void init() { memset(to[0], -1, sizeof(to[0])); sz = 1; } void insert(char *s, int id) { int cur = 0; for (int i = 0; s[i]; i++) { int c = s[i] - 'a'; if (to[cur][c] == -1) { memset(to[sz], -1, sizeof(to[sz])); to[cur][c] = sz++; } cur = to[cur][c]; } pat_end[id] = cur; } void build() { head = tail = 0; fail[0] = 0; for (int c = 0; c < ALPHA; c++) { if (to[0][c] == -1) to[0][c] = 0; else { fail[to[0][c]] = 0; q[tail++] = to[0][c]; } } while (head < tail) { int u = q[head++]; for (int c = 0; c < ALPHA; c++) { if (to[u][c] == -1) { to[u][c] = to[fail[u]][c]; } else { fail[to[u][c]] = to[fail[u]][c]; q[tail++] = to[u][c]; } } } } void search(char *text, int npat) { memset(cnt, 0, sizeof(long long) * sz); int cur = 0; for (int i = 0; text[i]; i++) { cur = to[cur][text[i] - 'a']; cnt[cur]++; } /* BFS 역순으로 fail link 전파 */ for (int i = tail - 1; i >= 0; i--) cnt[fail[q[i]]] += cnt[q[i]]; for (int i = 0; i < npat; i++) printf("패턴 %d: %lld회\n", i, cnt[pat_end[i]]); } int main() { int npat; char text[MAXN], pat[MAXN]; scanf("%d", &npat); init(); for (int i = 0; i < npat; i++) { scanf("%s", pat); insert(pat, i); } build(); scanf("%s", text); search(text, npat); return 0; }

Run-Length Encoding + Lempel-Ziv — 문자열 압축 알고리즘

[개념] 문자열 압축 알고리즘은 대회에서 직접 출제되기보다는 배경 지식으로 자주 등장합니다.
여기서는 세 가지 기본 압축 방식을 다룹니다.

1. Run-Length Encoding (RLE):
연속된 같은 문자를 (문자, 반복횟수) 쌍으로 압축합니다.
예: "aaabbbcc" → "a3b3c2"
구현이 매우 단순하고, 같은 문자가 많이 반복되는 경우 효과적입니다.
최악의 경우(모두 다른 문자) 오히려 길이가 늘어날 수 있습니다.

2. LZ77 (슬라이딩 윈도우):
이미 처리한 부분(윈도우)에서 현재 위치와 일치하는 가장 긴 부분을 찾습니다.
(거리, 길이, 다음 문자) 트리플로 인코딩합니다.
예: "aabaabaab" → (0,0,a)(0,1,b)(3,3,b)(3,3,END)
gzip, deflate의 기반 알고리즘입니다.

3. LZ78 (사전 기반):
사전(dictionary)에 새로운 부분 문자열을 등록하면서 압축합니다.
(사전 인덱스, 다음 문자) 쌍으로 인코딩합니다.
예: "aabaabaab" → (0,a)(1,b)(1,a)(3,a)(2,END)

Aliens 트릭 (WQS Binary Search) — 개념
AliensWQS이분탐색볼록함수Silver

[개념] Aliens 트릭(WQS Binary Search, Lagrangian Relaxation)은 "정확히 K개를 선택"하는 제약이 있는 최적화 문제를 풀 때 사용합니다.
원래 DP가 O(N²) 또는 O(NK)일 때, 이를 O(N log N · f(N))으로 줄일 수 있습니다.
IOI 2016 "Aliens" 문제에서 유명해졌습니다.

핵심 아이디어:
g(K) = "정확히 K개를 선택했을 때의 최적값"이라 하면, g(K)가 볼록 함수일 때 적용 가능합니다.
K개 선택이라는 제약 대신, 선택할 때마다 패널티 λ를 부과합니다.
h(λ) = min_K { g(K) + λ·K } 를 구하면, 이는 K에 대한 제약 없는 문제입니다.

알고리즘 흐름:
1) λ에 대해 이분 탐색을 수행합니다.
2) 주어진 λ에 대해, "선택할 때마다 λ만큼 비용 추가"하는 DP를 풀어 최적값과 선택 개수를 구합니다.
3) 선택 개수가 K보다 크면 λ를 키우고, 작으면 λ를 줄입니다.
4) 선택 개수가 정확히 K가 되는 λ를 찾으면, 답 = h(λ) - λ·K

왜 볼록 함수여야 하는가?
g(K)가 볼록이면 h(λ)는 g에 대한 르장드르 변환이며, 정보 손실 없이 복원 가능합니다.
볼록이 아니면 접선으로 복원할 수 없는 구간이 존재합니다.

단계λ최적값 h(λ)선택 수동작
101008K=5보다 많음 → λ 증가
2101303K=5보다 적음 → λ 감소
351155K=5 → 답 = 115 - 5×5 = 90
NOTE — 볼록성 확인 g(K+1) - g(K) ≥ g(K) - g(K-1) (증가율이 증가)이면 아래로 볼록입니다.
g(K+1) - g(K) ≤ g(K) - g(K-1) (증가율이 감소)이면 위로 볼록입니다.
두 경우 모두 Aliens 트릭 적용 가능합니다 (이분 탐색 방향만 다름).
WARNING — 정수 문제에서의 주의 λ가 실수이면 eps 처리가 필요합니다.
정수 문제에서는 λ를 정수나 0.5 단위로 이분 탐색하는 기법이 있습니다.
선택 개수가 K와 정확히 같지 않을 수 있으므로, "K개 이하"일 때의 처리가 중요합니다.
TIP — 적용 가능한 문제 패턴 "N개 중 정확히 K개를 선택하여 비용 최소화" 형태
K를 고정하지 않으면 O(N) DP로 풀 수 있는 경우
g(K)의 볼록성을 직관적으로 확인할 수 있는 경우

[문제] N개의 구간이 주어지고, 정확히 K개의 구간을 선택하여 합집합의 커버 비용을 최소화해야 합니다.
겹치는 부분은 한 번만 계산됩니다.
DP로 풀면 O(NK)이지만, Aliens 트릭으로 O(N log N)에 풀 수 있습니다.

구현 핵심:
1) λ에 대해 이분 탐색 (lo=0, hi=최대가능비용)
2) 각 λ에서 DP를 풀되, 구간을 선택할 때마다 비용에 λ를 추가
3) DP 결과에서 실제 선택 개수를 추적
4) 선택 개수 ≥ K이면 λ를 올리고, < K이면 내림

#include <stdio.h> #include <stdlib.h> #define MAXN 100005 typedef long long ll; int n, K; int L[MAXN], R[MAXN]; /* 구간 [L[i], R[i]) */ /* lambda를 고정한 DP: 선택 시 lambda 추가 비용 */ /* dp[i] = i번째 구간까지 고려했을 때 최소 비용 */ ll dp[MAXN]; int cnt[MAXN]; /* 선택한 구간 수 */ int cmpInterval(const void *a, const void *b) { int i = *(int*)a, j = *(int*)b; if (L[i] != L[j]) return L[i] - L[j]; return R[j] - R[i]; } int idx[MAXN], m; /* 전처리 후 유효 구간 */ void preprocess() { int ord[MAXN]; for (int i = 0; i < n; i++) ord[i] = i; qsort(ord, n, sizeof(int), cmpInterval); m = 0; int maxR = -1; for (int i = 0; i < n; i++) { if (R[ord[i]] > maxR) { idx[m++] = ord[i]; maxR = R[ord[i]]; } } } /* 주어진 lambda로 DP 수행, 선택 개수 반환 */ int solve(ll lam, ll *cost) { dp[0] = 0; cnt[0] = 0; for (int i = 0; i < m; i++) { /* 선택하지 않는 경우 */ dp[i+1] = dp[i]; cnt[i+1] = cnt[i]; /* 선택하는 경우: 이전에 선택한 구간과 겹침 계산 */ for (int j = i; j >= 0; j--) { ll overlap = 0; if (j > 0 && R[idx[j-1]] > L[idx[i]]) overlap = R[idx[j-1]] - L[idx[i]]; ll val = dp[j] + (R[idx[i]] - L[idx[i]]) - overlap + lam; if (val < dp[i+1] || (val == dp[i+1] && cnt[j]+1 < cnt[i+1])) { dp[i+1] = val; cnt[i+1] = cnt[j] + 1; } if (overlap <= 0) break; } } *cost = dp[m]; return cnt[m]; } int main() { scanf("%d %d", &n, &K); for (int i = 0; i < n; i++) scanf("%d %d", &L[i], &R[i]); preprocess(); ll lo = 0, hi = 2000000000LL, ans = 0; while (lo <= hi) { ll mid = (lo + hi) / 2; ll cost; int c = solve(mid, &cost); if (c <= K) { ans = cost - mid * K; hi = mid - 1; } else { lo = mid + 1; } } printf("%lld\n", ans); return 0; }

라그랑주 보간법 — N+1개 점으로 다항식 복원
Lagrange보간법다항식Silver

[개념] N차 다항식은 N+1개의 서로 다른 점 (x₀,y₀), (x₁,y₁), ..., (xₙ,yₙ)으로 유일하게 결정됩니다.
라그랑주 보간 공식:

P(x) = Σᵢ yᵢ · Π(j≠i) (x - xⱼ) / (xᵢ - xⱼ)

시간복잡도:
• 일반적인 경우: O(N²) — 각 점에 대해 분모와 분자를 계산
• 등차 x 좌표 (x₀, x₀+1, ...): O(N) — 전처리로 prefix/suffix 곱 계산

대회에서의 활용:
• DP 값이 K에 대한 다항식임을 알면, 작은 K에서 값을 구하고 보간으로 큰 K의 값을 복원
• 예: 합 공식 Σk³ = [n(n+1)/2]² 는 4차 다항식 → 5개 점이면 복원 가능
• 모듈러 연산과 함께 사용할 때는 분모의 모듈러 역원이 필요

#include <stdio.h> #define MAXN 1005 typedef long long ll; const ll MOD = 998244353; ll power(ll a, ll b, ll mod) { ll r = 1; a %= mod; while (b > 0) { if (b & 1) r = r * a % mod; a = a * a % mod; b >>= 1; } return r; } ll modinv(ll a, ll mod) { return power((a % mod + mod) % mod, mod - 2, mod); } /* 일반 라그랑주 보간 O(N^2) */ ll lagrange(ll *xs, ll *ys, int n, ll t) { ll result = 0; for (int i = 0; i <= n; i++) { ll num = ys[i], den = 1; for (int j = 0; j <= n; j++) { if (i == j) continue; num = num % MOD * ((t - xs[j]) % MOD + MOD) % MOD; den = den % MOD * ((xs[i] - xs[j]) % MOD + MOD) % MOD; } result = (result + num % MOD * modinv(den, MOD)) % MOD; } return result; } /* 등차 x좌표 (0,1,...,n) 전용 O(N) 보간 */ ll pre[MAXN], suf[MAXN], fac[MAXN], ifac[MAXN]; void init_fac(int n) { fac[0] = 1; for (int i = 1; i <= n; i++) fac[i] = fac[i-1] * i % MOD; ifac[n] = modinv(fac[n], MOD); for (int i = n-1; i >= 0; i--) ifac[i] = ifac[i+1] * (i+1) % MOD; } ll lagrange_consecutive(ll *ys, int n, ll t) { init_fac(n); pre[0] = (t % MOD + MOD) % MOD; for (int i = 1; i <= n; i++) pre[i] = pre[i-1] % MOD * ((t - i) % MOD + MOD) % MOD; suf[n] = (t - n) % MOD; suf[n] = (suf[n] + MOD) % MOD; for (int i = n-1; i >= 0; i--) suf[i] = suf[i+1] % MOD * ((t - i) % MOD + MOD) % MOD; ll result = 0; for (int i = 0; i <= n; i++) { ll num = ys[i]; if (i > 0) num = num * pre[i-1] % MOD; if (i < n) num = num % MOD * suf[i+1] % MOD; ll den = ifac[i] % MOD * ifac[n-i] % MOD; if ((n - i) & 1) den = (MOD - den) % MOD; result = (result + num % MOD * den) % MOD; } return result; } int main() { int n; ll t; scanf("%d %lld", &n, &t); ll xs[MAXN], ys[MAXN]; for (int i = 0; i <= n; i++) { xs[i] = i; scanf("%lld", &ys[i]); } printf("일반 보간: %lld\n", lagrange(xs, ys, n, t)); printf("등차 보간: %lld\n", lagrange_consecutive(ys, n, t)); return 0; }

Connection Profile DP — 플러그 DP (격자 해밀턴 경로)
Profile DP플러그 DP해밀턴Silver

[개념] Connection Profile DP(플러그 DP, Broken Profile DP)는 격자 위에서 특정 조건을 만족하는 경로나 타일링의 수를 세는 기법입니다.
M×N 격자를 한 칸씩 순서대로 채우면서, 현재 윤곽선(profile)의 연결 정보를 상태로 관리합니다.

핵심 아이디어:
• 격자를 왼쪽 위부터 오른쪽 아래로 한 칸씩 처리
• 현재 칸의 위와 왼쪽에서 오는 "플러그"(간선 연결)가 있는지 추적
• 상태: 윤곽선 위 M+1개 플러그의 연결 정보
• 연결 정보는 "같은 경로에 속하는 플러그"를 묶어서 표현

상태 인코딩:
• 각 플러그에 번호를 부여하고, 같은 경로에 속하면 같은 번호
• 이를 비트마스크나 해시맵으로 저장
• 카탈란 수 C(M+1)개의 유효 상태만 존재

전이 규칙 (한 칸 처리):
현재 칸에 위 플러그(top)와 왼쪽 플러그(left)가 올 수 있습니다.

topleft전이
없음없음새 경로 시작: 오른쪽+아래 플러그 생성 (같은 번호)
있음없음위에서 온 경로를 오른쪽 또는 아래로 보냄
없음있음왼쪽에서 온 경로를 오른쪽 또는 아래로 보냄
있음있음두 경로를 연결 (같은 번호면 사이클 닫기)

해밀턴 경로/사이클:
모든 칸을 정확히 한 번 방문하는 경로/사이클의 수를 셉니다.
마지막 칸에서 모든 플러그가 닫혀야 유효한 해입니다.
사이클의 경우 마지막에 정확히 하나의 사이클이 남아야 합니다.

NOTE — 시간복잡도 상태 수: 카탈란 수 C(M) ≈ 4^M / M^1.5
전체: O(N · M · C(M))
M ≤ 7~8 정도까지 실용적입니다.
해시맵을 사용하면 유효 상태만 관리하여 상수를 줄일 수 있습니다.
WARNING — 구현 난이도 플러그 DP는 개념은 명확하지만 구현이 매우 까다롭습니다.
상태 인코딩, 전이 규칙의 모든 경우 처리, 해시맵 관리 등이 필요합니다.
대회에서는 미리 템플릿을 준비해두는 것이 좋습니다.
TIP — 대회 출제 빈도 플러그 DP는 ICPC 지역 본선, IOI에서 가끔 출제됩니다.
격자 크기가 작고 (M ≤ 8) "경로 수를 세라" 형태이면 의심하세요.
도미노 타일링도 플러그 DP의 일종입니다.

Slope Trick — 볼록 함수의 꺾이는 점 관리
Slope TrickPriority Queue볼록Silver

[개념] Slope Trick은 DP 함수가 구간별 선형(piecewise linear)이고 볼록일 때, 함수 전체를 저장하는 대신 기울기가 변하는 점(꺾이는 점)만 관리하는 기법입니다.
우선순위 큐(max-heap, min-heap)로 꺾이는 점을 관리합니다.

핵심 관찰:
• 볼록 구간별 선형 함수는 기울기가 단조 증가
• 기울기 변화 = 꺾이는 점에서 +1 (또는 -1)
• 꺾이는 점의 위치만 알면 함수 전체를 복원 가능
• 꺾이는 점 추가/삭제/이동을 힙으로 O(log N)

대표 연산:
• 점 추가 f(x) += |x - a|: 꺾이는 점 a를 L-heap과 R-heap 양쪽에 추가
• 슬라이딩 f(x) → min_{|y-x|≤d} f(y): L-heap 모든 원소에서 d 빼기, R-heap 모든 원소에 d 더하기
• 최솟값 조회: 별도 변수로 관리

LIS 변형 (원소 변경 최소화):
배열을 비감소로 만들기 위한 최소 변경 비용도 Slope Trick으로 O(N log N)에 풀 수 있습니다.

#include <stdio.h> #include <stdlib.h> #define MAXN 200005 typedef long long ll; /* Max-heap (왼쪽 기울기 변화점) */ ll Lheap[MAXN]; int Lsz; void Lpush(ll x) { Lheap[++Lsz] = x; int i = Lsz; while (i > 1 && Lheap[i] > Lheap[i/2]) { ll t = Lheap[i]; Lheap[i] = Lheap[i/2]; Lheap[i/2] = t; i /= 2; } } ll Lpop() { ll top = Lheap[1]; Lheap[1] = Lheap[Lsz--]; int i = 1; while (2*i <= Lsz) { int c = 2*i; if (c+1 <= Lsz && Lheap[c+1] > Lheap[c]) c++; if (Lheap[i] >= Lheap[c]) break; ll t = Lheap[i]; Lheap[i] = Lheap[c]; Lheap[c] = t; i = c; } return top; } ll Ltop() { return Lheap[1]; } /* 배열을 비감소로 만드는 최소 비용 (각 원소 변경 비용 |a[i]-b[i]|) */ int main() { int n; scanf("%d", &n); ll ans = 0; Lsz = 0; for (int i = 0; i < n; i++) { ll a; scanf("%lld", &a); Lpush(a); Lpush(a); /* |x - a|: 꺾이는 점 a를 2번 추가 */ ll top = Lpop(); /* 오른쪽 힙으로 넘겨야 할 것 중 최대 제거 */ ans += top - a; /* top을 오른쪽 힙에 넣는 대신, 최솟값에 반영 */ } printf("최소 비용: %lld\n", ans); return 0; }

Hirschberg 알고리즘 — O(N) 메모리 편집 거리
Hirschberg편집거리분할정복Silver

[개념] 일반적인 편집 거리(Edit Distance) DP는 O(NM) 시간과 O(NM) 메모리를 사용합니다.
Hirschberg 알고리즘은 분할 정복 + DP를 결합하여 O(NM) 시간에 O(min(N,M)) 메모리로 편집 거리와 실제 편집 순서까지 복원합니다.

핵심 아이디어:
1) 편집 거리 DP의 마지막 행만 구하면 O(N) 메모리로 가능 (값만 필요할 때)
2) 실제 편집 순서를 복원하려면: 문자열 A를 반으로 나눔
3) A의 전반부에서 정방향 DP, 후반부에서 역방향 DP를 수행
4) 두 DP의 마지막 행을 합산하여 최적 분할점을 찾음
5) 재귀적으로 각 반에 대해 반복

시간복잡도: T(N,M) = O(NM) + T(N/2, k) + T(N/2, M-k)
합산하면 O(NM) (각 재귀 레벨에서 전체 작업량이 절반씩 줄어듦)

메모리: DP에 O(M), 재귀 스택에 O(log N), 총 O(M + log N)

DP on DAG 최적화 — 위상 정렬 순서 DP
DAG위상정렬DP경로Silver

[개념] DAG(방향 비순환 그래프) 위에서의 DP는 위상 정렬 순서를 이용하여 최장/최단 경로, 경로 수 등을 효율적으로 구합니다.
위상 정렬 순서로 노드를 처리하면, 현재 노드를 처리할 때 모든 선행 노드가 이미 처리되어 있음이 보장됩니다.

대표 문제:
• 최장 경로: dp[v] = max(dp[u] + w(u,v)) for all u → v
• 최단 경로: dp[v] = min(dp[u] + w(u,v)) for all u → v
• 경로 수: dp[v] = Σ dp[u] for all u → v
• 복합 문제: 최장 경로의 수, K번째 최장 경로 등

위상 정렬 + DP의 강점:
다익스트라는 음수 가중치를 처리할 수 없지만, DAG DP는 가능합니다.
시간복잡도: O(V + E)로 다익스트라보다 빠릅니다.
경로 수까지 동시에 구할 수 있습니다.

[개념] Li Chao 트리는 직선(y = ax + b)을 삽입하고, 특정 x에서 최솟값(또는 최댓값)을 쿼리하는 자료구조입니다.

삽입과 쿼리 모두 O(log N)입니다.

핵심 아이디어:
• 각 노드는 자신의 x 구간에서 "가장 좋은 직선 후보"를 저장
• 새 직선을 삽입할 때, 구간 중앙(mid)에서 기존 직선과 비교
• mid에서 더 좋은 직선을 현재 노드에 저장
• 나머지 직선은 한쪽 자식으로만 재귀 (항상 한쪽만!)
• 쿼리: 루트부터 리프까지 경로의 모든 직선 중 최적 선택

CHT(Convex Hull Trick) 대비 장점:
• 직선 삽입 순서에 제약이 없음 (온라인 가능)
• 구현이 간결함
• 선분(구간 제한)도 삽입 가능

Li Chao 트리 응용 — DP 최적화
Li Chao TreeDP최적화Silver

[개념] dp[i] = min(dp[j] + b[j]·x[i] + c[i]) 형태의 DP를 Li Chao 트리로 최적화합니다.
이 형태에서 j를 고정하면 y = b[j]·x + dp[j]는 x에 대한 직선입니다.
따라서 각 j에 대해 직선 (기울기=b[j], 절편=dp[j])을 Li Chao 트리에 삽입하고,
i를 처리할 때 x=x[i]에서 쿼리하면 O(log N)에 dp[i]를 구할 수 있습니다.

적용 가능한 형태:
dp[i] = min_{j<i} { dp[j] + f(j)·g(i) + h(i) }
여기서 f(j)는 j에만 의존, g(i)는 i에만 의존하면 됩니다.
직선 y = f(j)·x + dp[j]를 삽입하고, x = g(i)에서 쿼리 → dp[i] = query + h(i)

CHT 대신 Li Chao를 선택하는 경우:
• 기울기 f(j)가 단조가 아닐 때 (CHT는 기울기 정렬 필요)
• 쿼리 x 좌표가 단조가 아닐 때
• 두 가지 모두 비단조이면 Li Chao가 유일한 선택

세그먼트 비츠 (Segment Beats) — 구간 chmin/chmax 연산
Segment BeatsJi Driver세그먼트 트리Silver

[개념] 세그먼트 비츠(Segment Beats, Ji Driver Segment Tree)는 구간에 대해 chmin(x) 또는 chmax(x) 연산을 효율적으로 처리합니다.
chmin(l, r, x): 구간 [l,r]의 모든 원소를 min(a[i], x)로 갱신
chmax(l, r, x): 구간 [l,r]의 모든 원소를 max(a[i], x)로 갱신
동시에 구간 합, 구간 최댓값 등의 쿼리도 지원합니다.

핵심 아이디어 (chmin 기준):
각 세그먼트 트리 노드에 다음을 저장합니다:
• mx: 구간 최댓값
• mx2: 구간 두 번째 최댓값 (mx보다 작은 값 중 최대)
• cnt_mx: 최댓값과 같은 원소 수
• sum: 구간 합

chmin(x) 연산의 분기:
• x ≥ mx: 아무 변화 없음 → 바로 리턴
• mx2 < x < mx: 최댓값만 x로 변경. sum += (x - mx) × cnt_mx
• x ≤ mx2: 자식으로 재귀 (이 경우만 추가 탐색)

시간복잡도: O(N log²N) amortized
각 원소의 값이 감소할 때마다 비용이 발생하며, 총 감소 횟수가 제한됩니다.

암시적 Treap의 핵심:
• 키를 명시적으로 저장하지 않고, 서브트리 크기로 인덱스를 결정
• 우선순위(priority)는 랜덤값으로 트리의 균형을 유지

• merge(l, r): 두 트리를 순서대로 합침
• 구간 [l,r] 연산: split으로 3조각으로 분할 → 가운데에 연산 → merge로 합침

구간 뒤집기:
lazy 태그로 "이 서브트리가 뒤집혀야 함"을 표시합니다.
