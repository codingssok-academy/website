가중 그래프 표현 — 인접 행렬 & 인접 리스트
가중 그래프인접 행렬인접 리스트Bronze

가중 그래프(Weighted Graph)는 간선에 가중치(비용, 거리 등)가 부여된 그래프입니다. 최단 경로, 최소 신장 트리 등의 알고리즘을 적용하려면 가중치를 함께 저장해야 합니다.

인접 행렬: adj[i][j] = w로 간선의 가중치를 저장합니다. 간선이 없으면 INF(매우 큰 값)를 넣습니다. O(V²) 공간이 필요하므로 정점 수가 적을 때 적합합니다.

인접 리스트: 구조체 Edge{int to, w;}를 사용하여 각 정점에 연결된 간선 목록을 저장합니다. O(V+E) 공간으로 희소 그래프에 효율적입니다.

C가중 그래프 — 인접 행렬
#include <stdio.h> #include <string.h> #define MAXV 101 #define INF 1000000000 int adj[MAXV][MAXV]; int V, E; void initGraph() { for (int i = 0; i < MAXV; i++) for (int j = 0; j < MAXV; j++) adj[i][j] = (i == j) ? 0 : INF; } int main() { scanf("%d %d", &V, &E); initGraph(); for (int i = 0; i < E; i++) { int u, v, w; scanf("%d %d %d", &u, &v, &w); adj[u][v] = w; adj[v][u] = w; // 무방향 그래프 } printf("1->3 가중치: %d\n", adj[1][3]); return 0; }

다익스트라 (배열 방식) — O(V²) 최단 경로
다익스트라최단 경로그리디Bronze

다익스트라(Dijkstra) 알고리즘은 하나의 출발점에서 다른 모든 정점까지의 최단 거리를 구합니다. 음이 아닌 가중치를 가진 그래프에서만 동작합니다.

핵심 아이디어: 매 단계에서 아직 방문하지 않은 정점 중 dist[]가 가장 작은 정점을 선택하고, 그 정점을 경유하여 인접 정점의 거리를 갱신(relaxation)합니다.

배열 방식은 최솟값을 O(V) 선형 탐색으로 찾으므로 전체 시간복잡도는 O(V²)입니다. 정점 수가 적을 때(V ≤ 1000) 간단하게 사용할 수 있습니다.

C다익스트라 — 배열 방식 O(V²)
#include <stdio.h> #include <string.h> #define MAXV 101 #define INF 1000000000 int adj[MAXV][MAXV]; int dist[MAXV]; int visited[MAXV]; int V, E; void dijkstra(int src) { for (int i = 1; i <= V; i++) { dist[i] = INF; visited[i] = 0; } dist[src] = 0; // 출발점 거리 = 0 for (int step = 0; step < V; step++) { // 미방문 중 dist 최솟값 정점 선택 int u = -1, minD = INF; for (int v = 1; v <= V; v++) { if (!visited[v] && dist[v] < minD) { minD = dist[v]; u = v; } } if (u == -1) break; // 연결 안 된 정점 visited[u] = 1; // u를 경유하여 인접 정점 거리 갱신 for (int v = 1; v <= V; v++) { if (adj[u][v] != INF && dist[u] + adj[u][v] < dist[v]) { dist[v] = dist[u] + adj[u][v]; } } } } int main() { scanf("%d %d", &V, &E); // 초기화 for (int i = 1; i <= V; i++) for (int j = 1; j <= V; j++) adj[i][j] = (i == j) ? 0 : INF; for (int i = 0; i < E; i++) { int u, v, w; scanf("%d %d %d", &u, &v, &w); adj[u][v] = w; adj[v][u] = w; } dijkstra(1); for (int i = 1; i <= V; i++) printf("dist[%d] = %d\n", i, dist[i]); return 0; }

다익스트라 (우선순위 큐) — O(E log V)
다익스트라최소힙경로 역추적Bronze

배열 방식 다익스트라는 매 단계 O(V)로 최솟값을 찾습니다. 최소힙(min-heap)을 사용하면 O(log V)로 줄일 수 있어 전체 시간복잡도가 O(E log V)가 됩니다.

C 언어에는 표준 우선순위 큐가 없으므로 배열 기반 이진 힙을 직접 구현합니다. 힙에 {dist, vertex} 쌍을 넣고, dist가 작은 것이 먼저 나오게 합니다.

경로 역추적: prev[v] 배열에 v의 최단 경로 상 이전 정점을 기록하면, 도착점에서 출발점까지 역추적하여 실제 경로를 복원할 수 있습니다.

C다익스트라 — 최소힙 + 경로 역추적
#include <stdio.h> #include <string.h> #define MAXV 10001 #define MAXE 200001 #define INF 1000000000 typedef struct { int to, w; } Edge; typedef struct { int d, v; } Node; Edge graph[MAXV][50]; int deg[MAXV]; int dist[MAXV], prev_node[MAXV]; int V, E; // ── 최소힙 구현 ── Node heap[MAXE]; int hsize = 0; void swap(Node *a, Node *b) { Node t = *a; *a = *b; *b = t; } void push(Node n) { heap[hsize] = n; int i = hsize++; while (i > 0 && heap[i].d < heap[(i-1)/2].d) { swap(&heap[i], &heap[(i-1)/2]); i = (i-1)/2; } } Node pop() { Node top = heap[0]; heap[0] = heap[--hsize]; int i = 0; while (1) { int c = 2*i+1; if (c >= hsize) break; if (c+1 < hsize && heap[c+1].d < heap[c].d) c++; if (heap[i].d <= heap[c].d) break; swap(&heap[i], &heap[c]); i = c; } return top; } void dijkstra(int src) { for (int i = 1; i <= V; i++) { dist[i] = INF; prev_node[i] = -1; } dist[src] = 0; hsize = 0; push((Node){0, src}); while (hsize > 0) { Node cur = pop(); if (cur.d > dist[cur.v]) continue; // 이미 갱신된 정점 for (int k = 0; k < deg[cur.v]; k++) { Edge e = graph[cur.v][k]; if (dist[cur.v] + e.w < dist[e.to]) { dist[e.to] = dist[cur.v] + e.w; prev_node[e.to] = cur.v; push((Node){dist[e.to], e.to}); } } } } void printPath(int t) { if (t == -1) return; printPath(prev_node[t]); printf("%d ", t); } int main() { scanf("%d %d", &V, &E); for (int i = 0; i < E; i++) { int u, v, w; scanf("%d %d %d", &u, &v, &w); graph[u][deg[u]++] = (Edge){v, w}; graph[v][deg[v]++] = (Edge){u, w}; } dijkstra(1); printf("1->5 최단거리: %d\n경로: ", dist[5]); printPath(5); printf("\n"); return 0; }

벨만-포드 — 음수 간선 처리
벨만-포드음수 간선음수 사이클Bronze

벨만-포드(Bellman-Ford) 알고리즘은 음수 가중치 간선이 있는 그래프에서도 최단 경로를 구할 수 있습니다. 다익스트라와 달리 모든 간선을 반복적으로 relaxation합니다.

동작 원리: V-1번 반복하면서 모든 간선 (u, v, w)에 대해 dist[v] = min(dist[v], dist[u] + w)를 수행합니다. 최단 경로는 최대 V-1개의 간선을 포함하므로 V-1번이면 충분합니다.

음수 사이클 감지: V번째 반복에서도 갱신이 발생하면 음수 사이클이 존재합니다. 음수 사이클이 있으면 최단 경로가 정의되지 않습니다(무한히 줄일 수 있으므로).

시간복잡도는 O(VE)로 다익스트라보다 느리지만, 음수 간선을 처리할 수 있는 유일한 단일 출발점 알고리즘입니다.

C벨만-포드 알고리즘
#include <stdio.h> #define MAXV 501 #define MAXE 10001 #define INF 1000000000 typedef struct { int u, v, w; } Edge; Edge edges[MAXE]; int dist[MAXV]; int V, E; // 벨만-포드: 음수 사이클이면 1 반환 int bellmanFord(int src) { for (int i = 1; i <= V; i++) dist[i] = INF; dist[src] = 0; // V-1번 반복: 모든 간선 relaxation for (int i = 0; i < V - 1; i++) { for (int j = 0; j < E; j++) { int u = edges[j].u; int v = edges[j].v; int w = edges[j].w; if (dist[u] != INF && dist[u] + w < dist[v]) { dist[v] = dist[u] + w; } } } // V번째 반복: 음수 사이클 감지 for (int j = 0; j < E; j++) { int u = edges[j].u; int v = edges[j].v; int w = edges[j].w; if (dist[u] != INF && dist[u] + w < dist[v]) { return 1; // 음수 사이클 존재! } } return 0; } int main() { scanf("%d %d", &V, &E); for (int i = 0; i < E; i++) scanf("%d %d %d", &edges[i].u, &edges[i].v, &edges[i].w); if (bellmanFord(1)) { printf("음수 사이클 존재!\n"); } else { for (int i = 1; i <= V; i++) printf("dist[%d] = %d\n", i, dist[i] == INF ? -1 : dist[i]); } return 0; }

플로이드-워셜 — 모든 쌍 최단 경로 O(V³)
플로이드-워셜모든 쌍경유지Bronze

플로이드-워셜(Floyd-Warshall) 알고리즘은 모든 정점 쌍 (i, j) 사이의 최단 거리를 한 번에 구합니다. 시간복잡도는 O(V³)이며, 인접 행렬을 사용합니다.

핵심 점화식: dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j])
정점 k를 경유하여 i에서 j로 가는 것이 더 짧으면 갱신합니다. k 루프가 가장 바깥에 있어야 합니다!

V ≤ 400~500일 때 적합합니다. 음수 간선도 처리 가능하며, 대각선에 음수가 생기면 음수 사이클이 존재합니다.

C플로이드-워셜 알고리즘
#include <stdio.h> #define MAXV 101 #define INF 1000000000 int dist[MAXV][MAXV]; int V, E; void floyd() { // k: 경유 정점 (가장 바깥 루프!) for (int k = 1; k <= V; k++) for (int i = 1; i <= V; i++) for (int j = 1; j <= V; j++) if (dist[i][k] != INF && dist[k][j] != INF && dist[i][k] + dist[k][j] < dist[i][j]) dist[i][j] = dist[i][k] + dist[k][j]; } int main() { scanf("%d %d", &V, &E); // 초기화 for (int i = 1; i <= V; i++) for (int j = 1; j <= V; j++) dist[i][j] = (i == j) ? 0 : INF; for (int i = 0; i < E; i++) { int u, v, w; scanf("%d %d %d", &u, &v, &w); dist[u][v] = w; dist[v][u] = w; // 무방향 } floyd(); // 결과 출력 printf("모든 쌍 최단 거리:\n"); for (int i = 1; i <= V; i++) { for (int j = 1; j <= V; j++) { if (dist[i][j] == INF) printf("INF "); else printf("%3d ", dist[i][j]); } printf("\n"); } return 0; }

최소 신장 트리 (크루스칼) — Union-Find
MST크루스칼Union-FindBronze

최소 신장 트리(MST, Minimum Spanning Tree)는 그래프의 모든 정점을 연결하는 트리 중 간선 가중치 합이 최소인 트리입니다. 정점 V개를 연결하는 데 정확히 V-1개의 간선이 필요합니다.

크루스칼(Kruskal) 알고리즘: 모든 간선을 가중치 순으로 정렬한 뒤, 사이클을 만들지 않는 간선만 선택합니다. 사이클 검사는 Union-Find(서로소 집합)를 사용합니다.

Union-Find 최적화:
• 경로 압축(Path Compression): find() 시 루트까지 가는 모든 노드를 루트에 직접 연결
• 랭크 기반 합치기(Union by Rank): 작은 트리를 큰 트리 아래에 붙임

C크루스칼 알고리즘 (Union-Find)
#include <stdio.h> #include <stdlib.h> #define MAXV 1001 #define MAXE 100001 typedef struct { int u, v, w; } Edge; Edge edges[MAXE]; int parent[MAXV], rnk[MAXV]; int V, E; // Union-Find: 경로 압축 int find(int x) { if (parent[x] != x) parent[x] = find(parent[x]); // 경로 압축 return parent[x]; } // Union-Find: 랭크 기반 합치기 int unite(int a, int b) { a = find(a); b = find(b); if (a == b) return 0; // 이미 같은 집합 if (rnk[a] < rnk[b]) { int t = a; a = b; b = t; } parent[b] = a; if (rnk[a] == rnk[b]) rnk[a]++; return 1; } int cmp(const void *a, const void *b) { return ((Edge*)a)->w - ((Edge*)b)->w; } int main() { scanf("%d %d", &V, &E); for (int i = 0; i < E; i++) scanf("%d %d %d", &edges[i].u, &edges[i].v, &edges[i].w); // 간선 정렬 qsort(edges, E, sizeof(Edge), cmp); // 초기화 for (int i = 1; i <= V; i++) { parent[i] = i; rnk[i] = 0; } int totalW = 0, cnt = 0; printf("선택된 간선:\n"); for (int i = 0; i < E && cnt < V - 1; i++) { if (unite(edges[i].u, edges[i].v)) { printf(" %d-%d (w=%d)\n", edges[i].u, edges[i].v, edges[i].w); totalW += edges[i].w; cnt++; } } printf("MST 총 가중치: %d\n", totalW); return 0; }

최소 신장 트리 (프림) — O(V²) 배열 방식
MST프림그리디Bronze

프림(Prim) 알고리즘은 하나의 정점에서 시작하여 MST를 점진적으로 확장합니다. 현재 MST에 포함된 정점 집합에서 바깥 정점으로 연결된 간선 중 가중치가 최소인 간선을 선택합니다.

배열 방식: key[v] = MST 집합에서 v로 가는 최소 간선 가중치, inMST[v] = MST 포함 여부. 매 단계에서 key[]가 최소인 정점을 선택하여 MST에 추가합니다.

다익스트라와 구조가 매우 유사합니다! 차이점: 다익스트라는 출발점에서의 누적 거리를 최소화하고, 프림은 MST 집합과의 연결 비용을 최소화합니다.

C프림 알고리즘 — 배열 방식 O(V²)
#include <stdio.h> #define MAXV 101 #define INF 1000000000 int adj[MAXV][MAXV]; int key[MAXV]; // MST와의 최소 연결 비용 int inMST[MAXV]; // MST 포함 여부 int parent[MAXV]; // MST 간선의 부모 정점 int V, E; int prim() { for (int i = 1; i <= V; i++) { key[i] = INF; inMST[i] = 0; parent[i] = -1; } key[1] = 0; // 시작 정점 int totalW = 0; for (int step = 0; step < V; step++) { // key가 최소인 미포함 정점 선택 int u = -1, minK = INF; for (int v = 1; v <= V; v++) { if (!inMST[v] && key[v] < minK) { minK = key[v]; u = v; } } if (u == -1) break; inMST[u] = 1; totalW += key[u]; // 인접 정점의 key 갱신 for (int v = 1; v <= V; v++) { if (!inMST[v] && adj[u][v] != INF && adj[u][v] < key[v]) { key[v] = adj[u][v]; parent[v] = u; } } } return totalW; } int main() { scanf("%d %d", &V, &E); for (int i = 1; i <= V; i++) for (int j = 1; j <= V; j++) adj[i][j] = INF; for (int i = 0; i < E; i++) { int u, v, w; scanf("%d %d %d", &u, &v, &w); adj[u][v] = w; adj[v][u] = w; } int result = prim(); printf("MST 간선:\n"); for (int v = 2; v <= V; v++) printf(" %d-%d (w=%d)\n", parent[v], v, adj[parent[v]][v]); printf("MST 총 가중치: %d\n", result); return 0; }

위상 정렬 심화 — DAG 최장 경로와 작업 스케줄링
위상 정렬DAG최장 경로Critical PathBronze

DAG(Directed Acyclic Graph)에서는 위상 정렬 순서대로 DP를 적용하여 최장 경로를 구할 수 있습니다. 일반 그래프에서 최장 경로는 NP-hard이지만, DAG에서는 O(V+E)에 해결됩니다.

작업 스케줄링: 각 작업에 소요 시간이 있고, 선행 관계(방향 간선)가 있을 때, 전체 프로젝트 완료까지 최소 시간은 DAG의 최장 경로(Critical Path)입니다.

점화식: dp[v] = max(dp[u] + cost[v]) (u는 v로 들어오는 모든 간선의 출발 정점). 위상 정렬 순서대로 처리하면 u가 항상 v보다 먼저 계산됩니다.

CDAG 최장 경로 — 위상 정렬 + DP
#include <stdio.h> #include <string.h> #define MAXV 1001 int graph[MAXV][MAXV], deg_out[MAXV]; // 인접 리스트 int indeg[MAXV]; // 진입 차수 int cost[MAXV]; // 작업 소요 시간 int dp[MAXV]; // 최장 경로 int queue[MAXV], front, rear; int V, E; void topSortDP() { front = rear = 0; for (int i = 1; i <= V; i++) { dp[i] = cost[i]; // 자기 자신의 비용으로 초기화 if (indeg[i] == 0) queue[rear++] = i; } while (front < rear) { int u = queue[front++]; for (int k = 0; k < deg_out[u]; k++) { int v = graph[u][k]; if (dp[u] + cost[v] > dp[v]) dp[v] = dp[u] + cost[v]; indeg[v]--; if (indeg[v] == 0) queue[rear++] = v; } } } int main() { scanf("%d %d", &V, &E); for (int i = 1; i <= V; i++) scanf("%d", &cost[i]); for (int i = 0; i < E; i++) { int u, v; scanf("%d %d", &u, &v); graph[u][deg_out[u]++] = v; indeg[v]++; } topSortDP(); int ans = 0; for (int i = 1; i <= V; i++) if (dp[i] > ans) ans = dp[i]; printf("프로젝트 최소 완료 시간: %d\n", ans); for (int i = 1; i <= V; i++) printf(" 작업 %d: 최빨리 끝나는 시각 = %d\n", i, dp[i]); return 0; }

SCC (강한 연결 요소) — 코사라주 알고리즘
SCC코사라주DFSBronze

강한 연결 요소(SCC, Strongly Connected Component)란 방향 그래프에서 모든 정점 쌍 (u, v)에 대해 u→v와 v→u 경로가 모두 존재하는 최대 부분 그래프입니다.

코사라주(Kosaraju) 알고리즘은 두 번의 DFS로 SCC를 찾습니다:
1. 정방향 그래프에서 DFS → 종료 순서(후위 순서) 기록
2. 역방향 그래프에서, 후위 순서의 역순으로 DFS → 각 DFS 트리가 하나의 SCC

시간복잡도는 O(V+E)이며, 타잔(Tarjan) 알고리즘과 동일한 결과를 줍니다.

C코사라주 알고리즘
#include <stdio.h> #include <string.h> #define MAXV 1001 int g[MAXV][MAXV], gd[MAXV]; // 정방향 그래프 int rg[MAXV][MAXV], rgd[MAXV]; // 역방향 그래프 int visited[MAXV]; int order[MAXV], ocnt; // 후위 순서 int comp[MAXV]; // SCC 번호 int V, E; // 1단계: 정방향 DFS (후위 순서 기록) void dfs1(int u) { visited[u] = 1; for (int k = 0; k < gd[u]; k++) if (!visited[g[u][k]]) dfs1(g[u][k]); order[ocnt++] = u; // 후위 기록 } // 2단계: 역방향 DFS (SCC 분류) void dfs2(int u, int c) { comp[u] = c; visited[u] = 1; for (int k = 0; k < rgd[u]; k++) if (!visited[rg[u][k]]) dfs2(rg[u][k], c); } int main() { scanf("%d %d", &V, &E); for (int i = 0; i < E; i++) { int u, v; scanf("%d %d", &u, &v); g[u][gd[u]++] = v; // 정방향 rg[v][rgd[v]++] = u; // 역방향 } // 1단계: 정방향 DFS memset(visited, 0, sizeof(visited)); ocnt = 0; for (int i = 1; i <= V; i++) if (!visited[i]) dfs1(i); // 2단계: 역방향 DFS (후위 역순) memset(visited, 0, sizeof(visited)); int sccCnt = 0; for (int i = ocnt - 1; i >= 0; i--) if (!visited[order[i]]) dfs2(order[i], ++sccCnt); printf("SCC 개수: %d\n", sccCnt); for (int c = 1; c <= sccCnt; c++) { printf("SCC %d: ", c); for (int v = 1; v <= V; v++) if (comp[v] == c) printf("%d ", v); printf("\n"); } return 0; }

KMP(Knuth-Morris-Pratt) 알고리즘은 문자열 매칭을 O(N+M)에 수행합니다.
핵심은 실패 함수 pi[]를 미리 계산하여, 불일치 시 패턴을 최대한 많이 건너뛰는 것입니다.

실패 함수 pi[i]의 정의:
패턴 P[0..i]의 접두사(prefix)이면서 접미사(suffix)인 최대 길이 (자기 자신 제외)
예: P = "ABACABAB"일 때
pi[0]=0, pi[1]=0, pi[2]=1, pi[3]=0, pi[4]=1, pi[5]=2, pi[6]=3, pi[7]=2

pi[] 구축 원리:
1) i=1부터 시작, j=0 (현재 매칭된 접두사 길이)
2) P[i] == P[j]이면 j 증가, pi[i] = j
3) P[i] != P[j]이고 j > 0이면 j = pi[j-1]로 점프
4) P[i] != P[j]이고 j == 0이면 pi[i] = 0

Ckmp.c
#include <stdio.h> #include <string.h> #define MAXN 1000001 int pi[MAXN]; int result[MAXN]; // 실패 함수 구축 void buildPI(char *P, int m) { pi[0] = 0; int j = 0; for (int i = 1; i < m; i++) { while (j > 0 && P[i] != P[j]) j = pi[j - 1]; if (P[i] == P[j]) j++; pi[i] = j; } } // KMP 검색 int kmpSearch(char *T, char *P) { int n = strlen(T); int m = strlen(P); buildPI(P, m); int cnt = 0, j = 0; for (int i = 0; i < n; i++) { while (j > 0 && T[i] != P[j]) j = pi[j - 1]; if (T[i] == P[j]) j++; if (j == m) { result[cnt++] = i - m + 1; j = pi[j - 1]; // 다음 매칭을 위해 } } return cnt; } int main() { char T[MAXN], P[MAXN]; scanf("%s %s", T, P); int cnt = kmpSearch(T, P); printf("%d\n", cnt); for (int i = 0; i < cnt; i++) printf("%d ", result[i] + 1); // 1-indexed printf("\n"); return 0; }

라빈-카프(Rabin-Karp) 알고리즘은 해시(hash)를 이용한 문자열 매칭입니다.
패턴의 해시값과 텍스트의 부분 문자열 해시값을 비교합니다.

롤링 해시 원리:
해시 함수: H(s) = (s[0]×dm-1 + s[1]×dm-2 + ... + s[m-1]) mod q

아호-코라식(Aho-Corasick)은 여러 패턴을 동시에 텍스트에서 찾는 알고리즘입니다.
트라이에 모든 패턴을 삽입한 뒤, KMP의 실패 함수와 유사한 failure link를 구축합니다.
텍스트를 한 번 스캔(O(N))하면서 모든 패턴 매칭을 찾습니다.

구축 과정:
1) 모든 패턴을 트라이에 삽입
2) BFS로 각 노드의 failure link를 계산 (루트의 자식은 루트를 가리킴)
3) 현재 노드에서 불일치 시 failure link를 따라 이동
4) 출력 링크(output link)로 매칭된 패턴을 수집

문자열 해싱 — 다항식 해싱과 부분문자열 비교

다항식 해싱(Polynomial Hashing)은 문자열을 정수로 변환하는 기법입니다.
H(s) = (s[0]×pn-1 + s[1]×pn-2 + ... + s[n-1]) mod M
여기서 p는 소수(보통 31 또는 37), M은 큰 소수(109+7 등)입니다.

접두사 해시로 부분문자열 O(1) 비교:
H[i] = s[0..i-1]의 해시값을 전처리하면
s[l..r]의 해시 = (H[r+1] - H[l] × pr-l+1) mod M

Suffix Array 개념 — 접미사 배열과 LCP

접미사 배열(Suffix Array, SA)은 문자열의 모든 접미사를 사전순으로 정렬한 배열입니다.
문자열 "banana"의 접미사들:
0: banana, 1: anana, 2: nana, 3: ana, 4: na, 5: a
사전순 정렬: a(5), ana(3), anana(1), banana(0), na(4), nana(2)
SA = [5, 3, 1, 0, 4, 2]

O(n log² n) 구축:
1) 초기 순위: 각 문자의 ASCII 값
2) 길이 2k씩 늘려가며 정렬 (비교 키: 현재 순위 + 다음 절반 순위)
3) log n 라운드 반복하면 완성

LCP 배열: SA에서 인접한 두 접미사의 최장 공통 접두사 길이
Kasai 알고리즘으로 O(n)에 구축 가능합니다.

모듈러 연산의 기본 성질:
(a + b) % m = ((a % m) + (b % m)) % m
(a × b) % m = ((a % m) × (b % m)) % m
(a - b) % m = ((a % m) - (b % m) + m) % m
나눗셈은 직접 모듈러를 적용할 수 없으며, 모듈러 역원을 곱해야 합니다.

모듈러 거듭제곱 (빠른 거듭제곱):
an mod m을 O(log n)에 계산합니다.
n이 짝수면: an = (an/2)2
n이 홀수면: an = a × an-1

페르마 소정리:
p가 소수이고 gcd(a, p) = 1이면, ap-1 ≡ 1 (mod p)
따라서 a-1 ≡ ap-2 (mod p)
nCr mod p = n! × (r!)-1 × ((n-r)!)-1 mod p

오일러 피 함수 φ(n)은 1 이상 n 이하의 정수 중 n과 서로소인 수의 개수입니다.
공식: φ(n) = n × ∏(1 - 1/p) (p는 n의 소인수)
예: φ(12) = 12 × (1-1/2) × (1-1/3) = 12 × 1/2 × 2/3 = 4
서로소인 수: {1, 5, 7, 11}

소인수분해 기반 계산:
1) n을 소인수분해: n = p1a1 × p2a2 × ...
2) result = n
3) 각 소인수 p에 대해: result = result / p * (p - 1)
