SECTION 796Gold | Platinum 브릿지
Heavy-Light Decomposition 입문
HLDTree Path QuerySegment TreeGOLD

필요한 이유
트리 경로 쿼리가 많고 단순 LCA만으로는 부족할 때 HLD가 등장합니다.
트리를 heavy path로 분해해 경로를 O(log N)개의 구간으로 바꾸고, 각 구간을 세그먼트 트리로 처리합니다.

Chld_query.c
long long query_path(int u, int v) { long long ans = 0; while (head[u] != head[v]) { if (depth[head[u]] < depth[head[v]]) swap(&u, &v); ans += seg_query(pos[head[u]], pos[u]); u = parent[head[u]]; } if (depth[u] > depth[v]) swap(&u, &v); ans += seg_query(pos[u], pos[v]); return ans; }
브릿지 포인트HLD는 Platinum에서 자주 쓰이지만, Gold 상위권에서도 경로 쿼리 문제의 자연스러운 확장으로 등장합니다.

SECTION 798Gold | Platinum 브릿지
Li Chao Tree 입문
Li Chao TreeCHTOptimizationGOLD

상황
직선 집합에 대해 특정 x에서 최솟값이나 최댓값을 반복 질의하는 문제입니다.
기울기 단조가 없거나 온라인으로 직선이 추가되면 일반적인 Convex Hull Trick 대신 Li Chao Tree가 유리합니다.

Cli_chao.c
void insert(Line nw, int node, long long s, long long e) { long long mid = (s + e) >> 1; int left = f(nw, s) < f(tree[node], s); int middle = f(nw, mid) < f(tree[node], mid); if (middle) swap_line(&tree[node], &nw); if (s == e) return; if (left != middle) insert(nw, node << 1, s, mid); else insert(nw, node << 1 | 1, mid + 1, e); }
주의정의역 x 범위를 미리 알고 있어야 하며, long long 곱셈 오버플로를 특히 조심해야 합니다.
