포인터(pointer)는 메모리 주소를 저장하는 변수입니다. &는 변수의 주소를 얻고, *는 주소가 가리키는 값을 읽거나 씁니다.

C개념 코드
#include <stdio.h> int main(void) { int a = 42; int *p = &a; // p는 a의 주소를 저장 printf("a의 값: %d\n", a); // 42 printf("a의 주소: %p\n", (void*)&a); printf("p가 가리키는 값: %d\n", *p); // 42 *p = 100; // 포인터로 값 변경 printf("a의 값: %d\n", a); // 100 return 0; }
실행 결과
a의 값: 42 a의 주소: 0x7ffd1234abcd p가 가리키는 값: 42 a의 값: 100

&aa의 주소0x7ffd...
*pp가 가리키는 값42
*p = 100p가 가리키는 곳에 값 쓰기a가 100으로 변경

포인터로 swap — 두 변수 교환
pointerswapcall by referenceIron

C에서 함수의 매개변수는 값 복사(call by value)입니다. 포인터를 사용하면 원본 변수를 직접 수정할 수 있습니다.

C개념 코드
// 잘못된 swap (값만 복사됨) void bad_swap(int a, int b) { int tmp = a; a = b; b = tmp; // main의 원본은 안 바뀜! } // 올바른 swap (포인터 사용) void swap(int *a, int *b) { int tmp = *a; *a = *b; *b = tmp; } // 호출: swap(&x, &y);
핵심 차이bad_swap(x, y)는 x, y의 값을 복사해서 함수 안에서만 바꿉니다. swap(&x, &y)는 주소를 전달하므로 원본이 바뀝니다.

qsort비교 함수stdlib.hIron

qsort는 C 표준 라이브러리의 정렬 함수입니다. 비교 함수를 전달하여 정렬 기준을 지정합니다. 대회에서 매우 자주 사용됩니다.

C개념 코드
#include <stdlib.h> int cmp_asc(const void *a, const void *b) { return (*(int*)a) - (*(int*)b); // 오름차순 } int arr[] = {5, 2, 8, 1, 3}; qsort(arr, 5, sizeof(int), cmp_asc); // 결과: 1 2 3 5 8
qsort 매개변수의미
1번째: arr정렬할 배열
2번째: 5원소 개수
3번째: sizeof(int)원소 하나의 크기
4번째: cmp_asc비교 함수 (음수: a가 앞, 양수: b가 앞)
