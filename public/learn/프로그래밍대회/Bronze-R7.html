세그먼트 트리 개념 — 구간 쿼리 O(log N)
세그먼트 트리구간 쿼리분할 정복Bronze

세그먼트 트리(Segment Tree)는 배열의 구간에 대한 질의(합, 최솟값, 최댓값 등)를 O(log N)에 처리하고,
원소 하나를 갱신하는 것도 O(log N)에 처리할 수 있는 자료구조입니다.
단순 반복문으로 구간 합을 구하면 O(N)이 걸리지만,
세그먼트 트리를 사용하면 N이 100,000 이상일 때 극적인 성능 향상을 얻습니다.

핵심 아이디어: 배열을 이진 트리 형태로 분할합니다.
루트 노드는 전체 구간 [0, N-1]을 담당합니다.
왼쪽 자식은 [0, mid], 오른쪽 자식은 [mid+1, N-1]을 담당합니다.
리프 노드는 배열의 개별 원소에 대응합니다.
각 내부 노드는 자식 두 개의 값을 합산(또는 min/max)하여 저장합니다.

배열 기반 구현: 1-indexed 배열 tree[]를 사용합니다.
노드 번호 i의 왼쪽 자식은 2*i, 오른쪽 자식은 2*i+1입니다.
배열 크기가 N일 때, 트리 배열은 최대 4*N 크기가 필요합니다.

세 가지 핵심 연산:

1) build(node, start, end): 재귀적으로 트리를 구성합니다.
start == end이면 리프 노드이므로 tree[node] = arr[start].
그렇지 않으면 왼쪽/오른쪽 자식을 재귀 호출한 뒤 tree[node] = tree[2*node] + tree[2*node+1].

2) query(node, start, end, l, r): 구간 [l, r]의 합을 구합니다.
[start, end]가 [l, r]에 완전히 포함되면 tree[node]를 반환합니다.
겹치지 않으면 0을 반환합니다.
부분적으로 겹치면 왼쪽/오른쪽 자식을 재귀 호출하여 합산합니다.

3) update(node, start, end, idx, val): 인덱스 idx의 값을 val로 변경합니다.
리프 노드에 도달하면 tree[node] = val.
재귀 복귀 시 tree[node] = tree[2*node] + tree[2*node+1]로 갱신합니다.

개념설명시간 복잡도
Build전체 배열로부터 트리 구성O(N)
Query구간 [l, r]의 합/최솟값/최댓값O(log N)
Update단일 원소 값 변경O(log N)
공간트리 배열 크기O(4N)
NOTE — 개념도배열 [1, 3, 5, 7, 9, 11]의 구간 합 세그먼트 트리 구조:

                [36]              ← 전체 합
        [9]           [27]      ← 좌/우 반
    [4]     [5]    [16]   [11]
  [1] [3]   [5]  [7] [9] [11]   ← 리프(원본 배열)
TIP세그먼트 트리의 높이는 약 log₂N이며, 각 연산은 루트에서 리프까지 한 경로만 탐색하므로 O(log N)입니다.
N = 100,000일 때 약 17단계만 거치면 됩니다.
WARNING트리 배열 크기를 2*N으로 잡으면 부족할 수 있습니다. 안전하게 4*N으로 할당하세요.
N이 2의 거듭제곱이 아닐 때 트리가 완전 이진 트리가 되지 않기 때문입니다.

세그먼트 트리구간 합재귀 구현Bronze

구간 합 세그먼트 트리를 C언어로 완전히 구현합니다.
build 함수로 트리를 구축하고, query로 구간 합을 구하고, update로 원소를 갱신합니다.
아래 코드는 1-indexed 배열 기반 세그먼트 트리의 표준적인 구현입니다.

Csegment_tree_sum.c
#include <stdio.h> #define MAXN 100001 int arr[MAXN]; long long tree[4 * MAXN]; int n, q; /* build: 구간 [start, end]에 대한 트리 구축 */ void build(int node, int start, int end) { if (start == end) { tree[node] = arr[start]; /* 리프 노드 */ return; } int mid = (start + end) / 2; build(2 * node, start, mid); build(2 * node + 1, mid + 1, end); tree[node] = tree[2 * node] + tree[2 * node + 1]; } /* query: 구간 [l, r]의 합 */ long long query(int node, int start, int end, int l, int r) { if (r < start || end < l) return 0; if (l <= start && end <= r) return tree[node]; int mid = (start + end) / 2; return query(2 * node, start, mid, l, r) + query(2 * node + 1, mid + 1, end, l, r); } /* update: idx 위치의 값을 val로 변경 */ void update(int node, int start, int end, int idx, int val) { if (start == end) { arr[idx] = val; tree[node] = val; return; } int mid = (start + end) / 2; if (idx <= mid) update(2 * node, start, mid, idx, val); else update(2 * node + 1, mid + 1, end, idx, val); tree[node] = tree[2 * node] + tree[2 * node + 1]; } int main() { scanf("%d %d", &n, &q); for (int i = 1; i <= n; i++) scanf("%d", &arr[i]); build(1, 1, n); for (int i = 0; i < q; i++) { int type, a, b; scanf("%d %d %d", &type, &a, &b); if (type == 1) { update(1, 1, n, a, b); } else { printf("%lld\n", query(1, 1, n, a, b)); } } return 0; }

세그먼트 트리 응용 — RMQ, 최댓값, GCD
RMQ구간 최솟값구간 GCDBronze

세그먼트 트리의 구조는 동일하지만, 노드에 저장하는 값과 병합 함수만 바꾸면
다양한 구간 쿼리를 처리할 수 있습니다.
구간 합 대신 구간 최솟값(RMQ), 구간 최댓값, 구간 GCD 등을 구할 수 있습니다.

구간 최솟값 (Range Minimum Query):
병합: tree[node] = min(tree[2*node], tree[2*node+1])
범위 밖 반환값: INF (매우 큰 값)
리프: tree[node] = arr[start]

Csegment_tree_min.c
#include <stdio.h> #define MAXN 100001 #define INF 2000000000 int arr[MAXN], tree[4 * MAXN]; int n, q; int minVal(int a, int b) { return a < b ? a : b; } void build(int nd, int s, int e) { if (s == e) { tree[nd] = arr[s]; return; } int m = (s + e) / 2; build(2*nd, s, m); build(2*nd+1, m+1, e); tree[nd] = minVal(tree[2*nd], tree[2*nd+1]); } int query(int nd, int s, int e, int l, int r) { if (r < s || e < l) return INF; if (l <= s && e <= r) return tree[nd]; int m = (s + e) / 2; return minVal(query(2*nd, s, m, l, r), query(2*nd+1, m+1, e, l, r)); } void update(int nd, int s, int e, int idx, int val) { if (s == e) { tree[nd] = val; return; } int m = (s + e) / 2; if (idx <= m) update(2*nd, s, m, idx, val); else update(2*nd+1, m+1, e, idx, val); tree[nd] = minVal(tree[2*nd], tree[2*nd+1]); } int main() { scanf("%d %d", &n, &q); for (int i = 1; i <= n; i++) scanf("%d", &arr[i]); build(1, 1, n); while(q--) { int t, a, b; scanf("%d %d %d", &t, &a, &b); if (t == 1) update(1, 1, n, a, b); else printf("%d\n", query(1, 1, n, a, b)); } return 0; }

구간 GCD 변형:
병합 함수만 GCD로 바꾸면 됩니다.
범위 밖 반환값은 0입니다 (gcd(0, x) = x이므로).

CGCD 세그먼트 트리 (변형 부분)
int gcd(int a, int b) { while (b) { int t = b; b = a % b; a = t; } return a; } /* build: tree[nd] = gcd(tree[2*nd], tree[2*nd+1]); */ /* query: 범위 밖 -> return 0; 병합 -> gcd(left, right); */ /* update: tree[nd] = gcd(tree[2*nd], tree[2*nd+1]); */

세그먼트 트리 Lazy Propagation — 구간 업데이트 O(log N)
Lazy Propagation구간 업데이트세그먼트 트리Bronze

문제: 구간 [l, r]의 모든 원소에 동일한 값을 더하는 연산이 필요하다면?
단순 세그먼트 트리로는 하나씩 업데이트해야 하므로 O(N log N)이 걸립니다.
Lazy Propagation을 사용하면 구간 업데이트도 O(log N)에 처리할 수 있습니다.

핵심 아이디어:
lazy[] 배열을 추가로 유지합니다.
구간 업데이트 시, 해당 구간을 완전히 포함하는 노드에 lazy 값을 저장하고 즉시 반환합니다.
나중에 해당 노드를 방문할 때 자식에게 lazy 값을 전파(pushDown)합니다.
이를 "게으른 전파"라고 합니다 — 필요할 때만 전파하므로 효율적입니다.

pushDown 함수:
부모 노드의 lazy 값이 0이 아니면:
1) 왼쪽 자식의 tree 값에 lazy * (왼쪽 구간 크기)를 더합니다.
2) 오른쪽 자식의 tree 값에 lazy * (오른쪽 구간 크기)를 더합니다.
3) 왼쪽/오른쪽 자식의 lazy에 부모의 lazy를 더합니다.
4) 부모의 lazy를 0으로 초기화합니다.

Clazy_propagation.c
#include <stdio.h> #define MAXN 100001 long long tree[4 * MAXN]; long long lazy[4 * MAXN]; int arr[MAXN]; int n, q; void build(int nd, int s, int e) { lazy[nd] = 0; if (s == e) { tree[nd] = arr[s]; return; } int m = (s + e) / 2; build(2*nd, s, m); build(2*nd+1, m+1, e); tree[nd] = tree[2*nd] + tree[2*nd+1]; } void pushDown(int nd, int s, int e) { if (lazy[nd] != 0) { int m = (s + e) / 2; tree[2*nd] += lazy[nd] * (m - s + 1); tree[2*nd+1] += lazy[nd] * (e - m); lazy[2*nd] += lazy[nd]; lazy[2*nd+1] += lazy[nd]; lazy[nd] = 0; } } void updateRange(int nd, int s, int e, int l, int r, long long val) { if (r < s || e < l) return; if (l <= s && e <= r) { tree[nd] += val * (e - s + 1); lazy[nd] += val; return; } pushDown(nd, s, e); int m = (s + e) / 2; updateRange(2*nd, s, m, l, r, val); updateRange(2*nd+1, m+1, e, l, r, val); tree[nd] = tree[2*nd] + tree[2*nd+1]; } long long query(int nd, int s, int e, int l, int r) { if (r < s || e < l) return 0; if (l <= s && e <= r) return tree[nd]; pushDown(nd, s, e); int m = (s + e) / 2; return query(2*nd, s, m, l, r) + query(2*nd+1, m+1, e, l, r); } int main() { scanf("%d %d", &n, &q); for (int i = 1; i <= n; i++) scanf("%d", &arr[i]); build(1, 1, n); while(q--) { int t; scanf("%d", &t); if (t == 1) { int l, r; long long v; scanf("%d %d %lld", &l, &r, &v); updateRange(1, 1, n, l, r, v); } else { int l, r; scanf("%d %d", &l, &r); printf("%lld\n", query(1, 1, n, l, r)); } } return 0; }

펜윅 트리 (BIT) — Binary Indexed Tree
펜윅 트리BIT구간 합Bronze

펜윅 트리(Fenwick Tree), 또는 BIT(Binary Indexed Tree)는
세그먼트 트리와 같은 O(log N) 성능을 제공하면서도 구현이 훨씬 간결한 자료구조입니다.
주로 점 업데이트 + 구간 합 쿼리에 사용됩니다.

핵심 연산 — lowbit:
lowbit(i) = i & (-i)는 i의 이진 표현에서 가장 낮은 비트를 추출합니다.
예: lowbit(6) = lowbit(110₂) = 2
예: lowbit(12) = lowbit(1100₂) = 4

update(idx, delta): idx부터 시작하여 i += lowbit(i)로 올라가며 값을 갱신합니다.
query(idx): idx부터 시작하여 i -= lowbit(i)로 내려가며 합을 구합니다.
구간 합 [l, r] = query(r) - query(l-1)

Cfenwick_tree.c
#include <stdio.h> #include <string.h> #define MAXN 100001 long long bit[MAXN]; int n, q; /* update: idx 위치에 delta를 더함 */ void update(int idx, long long delta) { for (; idx <= n; idx += idx & (-idx)) bit[idx] += delta; } /* query: [1, idx] 구간 합 */ long long query(int idx) { long long sum = 0; for (; idx > 0; idx -= idx & (-idx)) sum += bit[idx]; return sum; } /* rangeQuery: [l, r] 구간 합 */ long long rangeQuery(int l, int r) { return query(r) - query(l - 1); } int main() { scanf("%d %d", &n, &q); memset(bit, 0, sizeof(bit)); for (int i = 1; i <= n; i++) { int x; scanf("%d", &x); update(i, x); } while(q--) { int t, a, b; scanf("%d %d %d", &t, &a, &b); if (t == 1) update(a, b); else printf("%lld\n", rangeQuery(a, b)); } return 0; }

펜윅 트리 응용 — 역순 쌍 개수 (Inversion Count)
Inversion Count좌표 압축BITBronze

역순 쌍(Inversion)이란 i < j인데 arr[i] > arr[j]인 쌍 (i, j)를 말합니다.
역순 쌍의 개수는 배열이 얼마나 "정렬되지 않았는지"를 측정하는 지표입니다.
버블 소트의 교환 횟수와 정확히 같습니다.

BIT를 이용한 O(N log N) 풀이:
배열을 오른쪽에서 왼쪽으로 순회합니다.
현재 원소 arr[i]를 처리할 때:
1) query(arr[i] - 1): arr[i]보다 작은 값이 오른쪽에 몇 개 있는지 = 역순 쌍 수
2) update(arr[i], 1): arr[i] 위치에 1을 추가
값의 범위가 크면 좌표 압축을 먼저 수행합니다.

Cinversion_count.c
#include <stdio.h> #include <stdlib.h> #include <string.h> #define MAXN 200001 int bit[MAXN]; int n, maxVal; void update(int idx, int val) { for (; idx <= maxVal; idx += idx & (-idx)) bit[idx] += val; } int query(int idx) { int s = 0; for (; idx > 0; idx -= idx & (-idx)) s += bit[idx]; return s; } int arr[MAXN], sorted_a[MAXN], rk[MAXN]; int cmp(const void *a, const void *b) { return *(int*)a - *(int*)b; } void compress() { memcpy(sorted_a, arr, sizeof(int) * n); qsort(sorted_a, n, sizeof(int), cmp); int cnt = 1; for (int i = 1; i < n; i++) if (sorted_a[i] != sorted_a[i-1]) sorted_a[cnt++] = sorted_a[i]; maxVal = cnt; for (int i = 0; i < n; i++) { int lo = 0, hi = cnt - 1; while (lo <= hi) { int m = (lo + hi) / 2; if (sorted_a[m] == arr[i]) { rk[i] = m + 1; break; } else if (sorted_a[m] < arr[i]) lo = m + 1; else hi = m - 1; } } } int main() { scanf("%d", &n); for (int i = 0; i < n; i++) scanf("%d", &arr[i]); compress(); memset(bit, 0, sizeof(bit)); long long inv = 0; for (int i = n - 1; i >= 0; i--) { inv += query(rk[i] - 1); update(rk[i], 1); } printf("%lld\n", inv); return 0; }

SECTION 357Bronze | 고급 자료구조
스파스 테이블 — 전처리 O(N log N), 쿼리 O(1)
스파스 테이블RMQ정적 배열Bronze

스파스 테이블(Sparse Table)은 정적 배열(업데이트 없음)에서
구간 최솟값/최댓값 쿼리를 O(1)에 처리하는 자료구조입니다.
전처리에 O(N log N) 시간과 공간이 필요합니다.

구조: sparse[k][i] = 인덱스 i부터 시작하는 길이 2^k 구간의 최솟값
전처리:
sparse[0][i] = arr[i] (길이 1 구간)
sparse[k][i] = min(sparse[k-1][i], sparse[k-1][i + 2^(k-1)])
즉, 길이 2^k 구간을 길이 2^(k-1)인 두 구간으로 분할합니다.

쿼리 O(1): 구간 [l, r]의 최솟값을 구할 때
k = floor(log2(r - l + 1))
답 = min(sparse[k][l], sparse[k][r - 2^k + 1])
두 구간이 겹쳐도 min이므로 정확한 결과를 얻습니다.

Csparse_table.c
#include <stdio.h> #define MAXN 100001 #define LOG 17 int sp[LOG][MAXN]; int lg[MAXN]; int n, q; int minVal(int a, int b) { return a < b ? a : b; } void buildSparse() { lg[1] = 0; for (int i = 2; i <= n; i++) lg[i] = lg[i / 2] + 1; for (int k = 1; k < LOG; k++) for (int i = 1; i + (1 << k) - 1 <= n; i++) sp[k][i] = minVal(sp[k-1][i], sp[k-1][i + (1 << (k - 1))]); } int queryRMQ(int l, int r) { int k = lg[r - l + 1]; return minVal(sp[k][l], sp[k][r - (1 << k) + 1]); } int main() { scanf("%d %d", &n, &q); for (int i = 1; i <= n; i++) scanf("%d", &sp[0][i]); buildSparse(); while (q--) { int l, r; scanf("%d %d", &l, &r); printf("%d\n", queryRMQ(l, r)); } return 0; }

머지 소트 트리 — 구간 K번째 수
머지 소트 트리구간 K번째이분 탐색Bronze

머지 소트 트리(Merge Sort Tree)는 세그먼트 트리의 각 노드에
해당 구간의 원소들을 정렬된 배열로 저장하는 자료구조입니다.
"구간 [l, r]에서 x 이하인 원소가 몇 개인가?"를 O(log² N)에 답할 수 있고,
이를 이분 탐색과 결합하면 "구간 K번째 수"를 O(log³ N)에 구할 수 있습니다.

구조:
각 노드는 해당 구간의 원소를 정렬된 형태로 저장합니다.
리프 노드: 원소 하나만 저장
내부 노드: 왼쪽/오른쪽 자식의 배열을 머지(병합)하여 저장
전체 공간: O(N log N)

countLessOrEqual(l, r, x):
구간 [l, r]에서 x 이하인 원소의 개수를 반환합니다.
각 노드의 정렬된 배열에서 upper_bound를 사용합니다.

Cmerge_sort_tree.c (간략 구현)
#include <stdio.h> #include <stdlib.h> #include <string.h> #define MAXN 100001 #define MAXLOG 18 int arr[MAXN]; int seg[MAXLOG][MAXN]; /* 각 레벨의 정렬된 배열 */ int n; void buildMST(int lv, int s, int e) { if (s == e) { seg[lv][s] = arr[s]; return; } int m = (s + e) / 2; buildMST(lv + 1, s, m); buildMST(lv + 1, m + 1, e); /* merge */ int i = s, j = m + 1, k = s; int tmp[MAXN]; while (i <= m && j <= e) { if (seg[lv+1][i] <= seg[lv+1][j]) tmp[k++] = seg[lv+1][i++]; else tmp[k++] = seg[lv+1][j++]; } while (i <= m) tmp[k++] = seg[lv+1][i++]; while (j <= e) tmp[k++] = seg[lv+1][j++]; for (i = s; i <= e; i++) seg[lv][i] = tmp[i]; } /* countLE: seg[lv][s..e]에서 x 이하인 원소 개수 */ int countLE(int lv, int s, int e, int x) { int lo = s, hi = e, res = s - 1; while (lo <= hi) { int m = (lo + hi) / 2; if (seg[lv][m] <= x) { res = m; lo = m + 1; } else hi = m - 1; } return res - s + 1; } int main() { scanf("%d", &n); for (int i = 0; i < n; i++) scanf("%d", &arr[i]); buildMST(0, 0, n - 1); printf("Sorted: "); for (int i = 0; i < n; i++) printf("%d ", seg[0][i]); printf("\n"); return 0; }

SECTION 359Bronze | 고급 자료구조
sqrt 분할 (Mo's Algorithm) — 오프라인 구간 쿼리
Mo's Algorithmsqrt 분할오프라인 쿼리Bronze

Mo's Algorithm은 오프라인으로 구간 쿼리를 처리하는 기법입니다.
블록 크기를 √N으로 설정하고, 쿼리를 특별한 순서로 정렬하여
총 O((N + Q)√N) 시간에 모든 쿼리를 답합니다.

핵심 아이디어:
현재 구간 [curL, curR]을 유지하면서,
다음 쿼리의 구간 [L, R]로 한 칸씩 이동합니다.
add(idx): 원소를 구간에 추가
remove(idx): 원소를 구간에서 제거
이동 비용을 최소화하기 위해 쿼리를 정렬합니다.

정렬 기준:
1순위: l / √N (블록 번호)
2순위: 같은 블록이면 r 기준 (홀수 블록은 내림차순, 짝수는 오름차순)

Cmos_algorithm.c
#include <stdio.h> #include <stdlib.h> #include <math.h> #define MAXN 100001 #define MAXQ 100001 int arr[MAXN]; int cnt[MAXN]; /* 각 값의 출현 횟수 */ int ans[MAXQ]; int n, q, sqrtN; int curAns; struct Query { int l, r, idx; }; struct Query queries[MAXQ]; int cmpQ(const void *a, const void *b) { struct Query *qa = (struct Query *)a; struct Query *qb = (struct Query *)b; int ba = qa->l / sqrtN, bb = qb->l / sqrtN; if (ba != bb) return ba - bb; return (ba & 1) ? (qb->r - qa->r) : (qa->r - qb->r); } void add(int idx) { cnt[arr[idx]]++; if (cnt[arr[idx]] == 1) curAns++; } void remove_(int idx) { cnt[arr[idx]]--; if (cnt[arr[idx]] == 0) curAns--; } int main() { scanf("%d %d", &n, &q); sqrtN = (int)sqrt((double)n) + 1; for (int i = 0; i < n; i++) scanf("%d", &arr[i]); for (int i = 0; i < q; i++) { scanf("%d %d", &queries[i].l, &queries[i].r); queries[i].l--; queries[i].r--; queries[i].idx = i; } qsort(queries, q, sizeof(struct Query), cmpQ); int curL = 0, curR = -1; curAns = 0; for (int i = 0; i < q; i++) { int L = queries[i].l, R = queries[i].r; while (curR < R) add(++curR); while (curL > L) add(--curL); while (curR > R) remove_(curR--); while (curL < L) remove_(curL++); ans[queries[i].idx] = curAns; } for (int i = 0; i < q; i++) printf("%d\n", ans[i]); return 0; }

네트워크 플로우 개념 — 최대 유량과 최소 컷
네트워크 플로우최대 유량최소 컷Bronze

네트워크 플로우(Network Flow)는 방향 그래프에서
소스(source, S)에서 싱크(sink, T)로 보낼 수 있는 최대 유량을 구하는 문제입니다.
각 간선에는 용량(capacity)이 있으며, 유량은 용량을 초과할 수 없습니다.

핵심 용어:
소스(S): 유량이 시작되는 정점
싱크(T): 유량이 도착하는 정점
용량(capacity): 간선이 허용하는 최대 유량
유량(flow): 실제 흐르는 양. 0 ≤ flow ≤ capacity
잔여 용량(residual): capacity - flow. 추가로 보낼 수 있는 양
잔여 그래프(residual graph): 잔여 용량이 양수인 간선들로 구성된 그래프

최대 유량-최소 컷 정리 (Max-Flow Min-Cut Theorem):
네트워크의 최대 유량 = 최소 컷의 용량
컷(cut): S와 T를 분리하는 간선 집합
최소 컷: 용량 합이 최소인 컷
이 정리는 네트워크 플로우의 근본적인 이론적 기반입니다.

증가 경로(Augmenting Path):
잔여 그래프에서 S에서 T로 가는 경로입니다.
이 경로를 따라 유량을 추가로 보낼 수 있습니다.
경로의 병목(최소 잔여 용량)만큼 유량을 증가시킵니다.
증가 경로가 더 이상 없으면 최대 유량에 도달한 것입니다.

개념설명
유량 보존S, T 외의 모든 정점에서 들어오는 유량 = 나가는 유량
용량 제한모든 간선에서 0 ≤ flow ≤ capacity
역간선유량을 취소할 수 있도록 반대 방향 간선을 잔여 그래프에 추가
증가 경로잔여 그래프에서 S→T 경로. 없으면 최대 유량 달성
NOTE — 예시4개 정점, S=0, T=3
간선: (0,1,cap=10), (0,2,cap=10), (1,2,cap=2), (1,3,cap=4), (2,3,cap=8)
최대 유량: 12 (경로 0→1→3: 4, 경로 0→2→3: 8)
TIP역간선의 의미: 이미 보낸 유량을 '취소'하는 것과 같습니다.
이를 통해 최적이 아닌 경로 선택을 나중에 교정할 수 있습니다.

포드-풀커슨 (DFS) — 증가 경로 탐색
포드-풀커슨DFS최대 유량Bronze

포드-풀커슨(Ford-Fulkerson) 알고리즘은 최대 유량을 구하는 가장 기본적인 방법입니다.
DFS로 잔여 그래프에서 증가 경로를 찾고, 경로의 병목만큼 유량을 갱신합니다.
증가 경로가 없을 때까지 반복합니다.

알고리즘 순서:
1) 잔여 그래프에서 S→T DFS로 증가 경로를 찾는다
2) 경로의 최소 잔여 용량(bottleneck)을 구한다
3) 경로의 각 간선: flow += bottleneck, 역간선: flow -= bottleneck
4) 증가 경로가 없으면 종료

에드몬드-카프 (BFS) — O(VE²) 최대 유량
에드몬드-카프BFS최대 유량Bronze

에드몬드-카프(Edmonds-Karp) 알고리즘은 포드-풀커슨의 개선 버전입니다.
DFS 대신 BFS로 최단(간선 수 기준) 증가 경로를 찾습니다.
이렇게 하면 시간 복잡도가 O(VE²)로 보장됩니다.

구현 핵심:
1) BFS로 S에서 T까지 최단 경로를 찾고, parent[] 배열에 경로를 기록합니다.
2) T에서 parent를 역추적하며 경로의 병목(최소 잔여 용량)을 구합니다.
3) 경로를 다시 역추적하며 flow를 갱신합니다.
4) BFS가 T에 도달하지 못하면 종료합니다.

Cedmonds_karp.c
#include <stdio.h> #include <string.h> #define MAXV 101 #define INF 1000000000 int cap[MAXV][MAXV]; int flow[MAXV][MAXV]; int parent[MAXV]; int V; int minVal(int a, int b) { return a < b ? a : b; } /* BFS로 최단 증가 경로 탐색 */ int bfs(int s, int t) { int queue[MAXV], front = 0, rear = 0; memset(parent, -1, sizeof(parent)); parent[s] = s; queue[rear++] = s; while (front < rear) { int u = queue[front++]; for (int v = 0; v < V; v++) { if (parent[v] == -1 && cap[u][v] - flow[u][v] > 0) { parent[v] = u; if (v == t) return 1; queue[rear++] = v; } } } return 0; } int edmondsKarp(int s, int t) { int maxFlow = 0; while (bfs(s, t)) { int bottleneck = INF; for (int v = t; v != s; v = parent[v]) bottleneck = minVal(bottleneck, cap[parent[v]][v] - flow[parent[v]][v]); for (int v = t; v != s; v = parent[v]) { flow[parent[v]][v] += bottleneck; flow[v][parent[v]] -= bottleneck; } maxFlow += bottleneck; } return maxFlow; } int main() { int E; scanf("%d %d", &V, &E); memset(cap, 0, sizeof(cap)); memset(flow, 0, sizeof(flow)); for (int i = 0; i < E; i++) { int u, v, c; scanf("%d %d %d", &u, &v, &c); cap[u][v] += c; } printf("%d\n", edmondsKarp(0, V - 1)); return 0; }

SECTION 364Bronze | 고급 그래프
이분 매칭 — 헝가리안 알고리즘
이분 매칭헝가리안DFSBronze

이분 매칭(Bipartite Matching)은 이분 그래프에서
최대 매칭(서로 겹치지 않는 간선 집합)을 구하는 문제입니다.
헝가리안 알고리즘은 DFS 기반으로 O(VE)에 최대 매칭을 구합니다.

알고리즘:
왼쪽 정점을 하나씩 순회합니다.
각 왼쪽 정점 u에 대해 DFS로 증가 경로를 찾습니다.
증가 경로를 찾으면 매칭 수를 1 증가시킵니다.
match_r[v]: 오른쪽 정점 v에 매칭된 왼쪽 정점
visited[v]: 현재 DFS에서 방문한 오른쪽 정점

DFS 핵심:
정점 u와 연결된 오른쪽 정점 v를 순회합니다.
v가 아직 매칭되지 않았으면 바로 매칭합니다.
v가 이미 매칭되어 있으면, 기존 매칭 상대를 다른 곳으로 옮길 수 있는지 재귀적으로 시도합니다.

Chungarian.c
#include <stdio.h> #include <string.h> #define MAXN 101 int adj[MAXN][MAXN]; /* adj[i][j]: i에서 j로 연결 가능 */ int match_r[MAXN]; /* match_r[j]: j에 매칭된 왼쪽 정점 */ int visited[MAXN]; int N_left, N_right, E; /* DFS로 증가 경로(augmenting path) 탐색 */ int dfs(int u) { for (int v = 1; v <= N_right; v++) { if (adj[u][v] && !visited[v]) { visited[v] = 1; /* v가 비어있거나, v의 현재 매칭을 옮길 수 있으면 */ if (match_r[v] == 0 || dfs(match_r[v])) { match_r[v] = u; return 1; } } } return 0; } int hungarian() { int result = 0; memset(match_r, 0, sizeof(match_r)); for (int u = 1; u <= N_left; u++) { memset(visited, 0, sizeof(visited)); if (dfs(u)) result++; } return result; } int main() { scanf("%d %d %d", &N_left, &N_right, &E); memset(adj, 0, sizeof(adj)); for (int i = 0; i < E; i++) { int u, v; scanf("%d %d", &u, &v); adj[u][v] = 1; } printf("%d\n", hungarian()); return 0; }

3 3 5 1 1 1 2 2 2 2 3 3 1
OUTPUT
3

u=3: DFS → v=1 이미 매칭(1). dfs(1) → v=2 이미 매칭(2). dfs(2) → v=3 비어있음!

결과: 최대 매칭 = 3

TIPvisited 배열은 각 왼쪽 정점마다 초기화해야 합니다.
같은 DFS 내에서 오른쪽 정점을 중복 방문하면 무한 루프에 빠집니다.

SECTION 365Bronze | 고급 그래프
이분 매칭 응용 — 최소 버텍스 커버, 최대 독립 집합
쾨니그 정리버텍스 커버독립 집합Bronze

쾨니그 정리(König's Theorem):
이분 그래프에서 최소 버텍스 커버의 크기 = 최대 매칭의 크기입니다.

버텍스 커버(Vertex Cover):
모든 간선을 "커버"하는 정점 집합입니다.
즉, 모든 간선의 양 끝 정점 중 적어도 하나가 이 집합에 포함됩니다.
최소 버텍스 커버는 이러한 집합 중 크기가 가장 작은 것입니다.

최대 독립 집합(Maximum Independent Set):
서로 인접하지 않는 정점들의 최대 집합입니다.
이분 그래프에서: 최대 독립 집합 = N - 최대 매칭
(N = 전체 정점 수)

관계 정리:
최소 버텍스 커버 = 최대 매칭 (쾨니그 정리)
최대 독립 집합 = N - 최소 버텍스 커버 = N - 최대 매칭
이 관계는 이분 그래프에서만 성립합니다. 일반 그래프에서는 NP-hard입니다.

개념정의이분 그래프 공식
최대 매칭겹치지 않는 간선 최대 집합헝가리안 알고리즘으로 계산
최소 버텍스 커버모든 간선을 커버하는 최소 정점 집합= 최대 매칭
최대 독립 집합서로 인접하지 않는 최대 정점 집합= N - 최대 매칭
최소 에지 커버모든 정점을 커버하는 최소 간선 집합= N - 최대 매칭
NOTE — 예제왼쪽 {1,2,3}, 오른쪽 {A,B,C}
간선: 1-A, 1-B, 2-B, 2-C, 3-A
최대 매칭 = 3 (1-B, 2-C, 3-A)
최소 버텍스 커버 = 3
최대 독립 집합 = 6 - 3 = 3
TIP실전에서 '최소한의 무언가로 모든 조건을 만족'하는 문제는
최소 버텍스 커버(= 최대 매칭)로 모델링할 수 있는 경우가 많습니다.
WARNING쾨니그 정리는 이분 그래프에서만 성립합니다!
일반 그래프에서는 최소 버텍스 커버 != 최대 매칭입니다.

SECTION 366Bronze | 고급 그래프
LCA (최소 공통 조상) — naive O(N)
LCA최소 공통 조상트리Bronze

LCA(Lowest Common Ancestor, 최소 공통 조상)는
트리에서 두 정점 u, v의 공통 조상 중 가장 깊은(가장 가까운) 정점입니다.

naive 알고리즘 O(N):
1) DFS로 각 정점의 깊이(depth)와 부모(parent)를 계산합니다.
2) LCA(u, v) 쿼리:
  a) u와 v의 깊이를 맞춥니다 (깊은 쪽을 올립니다)
  b) 같은 깊이에서 함께 한 칸씩 올라갑니다
  c) 같은 정점이 되면 그것이 LCA입니다

Clca_naive.c
#include <stdio.h> #include <string.h> #define MAXN 100001 int parent[MAXN], depth[MAXN]; int adj[MAXN][100], deg[MAXN]; int n; void dfs(int u, int par, int d) { parent[u] = par; depth[u] = d; for (int i = 0; i < deg[u]; i++) { int v = adj[u][i]; if (v != par) dfs(v, u, d + 1); } } int lca(int u, int v) { /* 깊이 맞추기 */ while (depth[u] > depth[v]) u = parent[u]; while (depth[v] > depth[u]) v = parent[v]; /* 함께 올라가기 */ while (u != v) { u = parent[u]; v = parent[v]; } return u; } int main() { int q; scanf("%d", &n); memset(deg, 0, sizeof(deg)); for (int i = 0; i < n - 1; i++) { int u, v; scanf("%d %d", &u, &v); adj[u][deg[u]++] = v; adj[v][deg[v]++] = u; } dfs(1, 0, 0); scanf("%d", &q); while (q--) { int u, v; scanf("%d %d", &u, &v); printf("%d\n", lca(u, v)); } return 0; }

OUTPUT

depth[4]=2, depth[6]=2 (같은 깊이)

u=2, v=3: parent[2]=1, parent[3]=1 → u=1, v=1
u == v == 1 → LCA = 1

N, Q ≥ 100,000이면 시간 초과! 희소 배열 LCA를 사용하세요.

SECTION 367Bronze | 고급 그래프
LCA (희소 배열) — O(log N) 쿼리
LCA희소 배열Binary LiftingBronze

희소 배열(Binary Lifting)을 사용하면 LCA 쿼리를 O(log N)에 처리할 수 있습니다.
전처리 O(N log N), 쿼리 O(log N).

구조: par[k][v] = 정점 v의 2^k번째 조상
par[0][v] = v의 직접 부모
par[k][v] = par[k-1][par[k-1][v]] (2^k = 2^(k-1) + 2^(k-1))

LCA(u, v) 알고리즘:
1) 깊이가 더 깊은 쪽을 올려서 깊이를 맞춥니다 (Binary Lifting)
2) 같은 정점이면 바로 반환
3) k를 큰 값부터 줄여가며, par[k][u] != par[k][v]이면 둘 다 올립니다
4) par[0][u]가 LCA입니다

Clca_sparse.c
#include <stdio.h> #include <string.h> #define MAXN 100001 #define LOG 17 int par[LOG][MAXN]; /* par[k][v] = v의 2^k번째 조상 */ int depth[MAXN]; int adj[MAXN][100], deg[MAXN]; int n; void dfs(int u, int p, int d) { par[0][u] = p; depth[u] = d; for (int i = 0; i < deg[u]; i++) { int v = adj[u][i]; if (v != p) dfs(v, u, d + 1); } } void buildLCA() { for (int k = 1; k < LOG; k++) for (int v = 1; v <= n; v++) par[k][v] = par[k-1][par[k-1][v]]; } int lca(int u, int v) { if (depth[u] < depth[v]) { int t = u; u = v; v = t; } int diff = depth[u] - depth[v]; for (int k = 0; k < LOG; k++) if ((diff >> k) & 1) u = par[k][u]; if (u == v) return u; for (int k = LOG - 1; k >= 0; k--) { if (par[k][u] != par[k][v]) { u = par[k][u]; v = par[k][v]; } } return par[0][u]; } int main() { int q; scanf("%d", &n); memset(deg, 0, sizeof(deg)); for (int i = 0; i < n - 1; i++) { int u, v; scanf("%d %d", &u, &v); adj[u][deg[u]++] = v; adj[v][deg[v]++] = u; } dfs(1, 0, 0); buildLCA(); scanf("%d", &q); while (q--) { int u, v; scanf("%d %d", &u, &v); printf("%d\n", lca(u, v)); } return 0; }

LCA 응용 — 트리 위 두 정점 거리, 경로 쿼리

트리 위 두 정점 사이의 거리는 LCA를 이용하여 O(log N)에 구할 수 있습니다.

공식: dist(u, v) = depth[u] + depth[v] - 2 * depth[LCA(u, v)]
u에서 LCA까지의 거리 + v에서 LCA까지의 거리입니다.

가중 트리에서의 경로 쿼리:
각 정점 v에 대해 루트에서 v까지의 가중치 합 dist_w[v]를 DFS로 전처리합니다.
경로 (u, v)의 가중치 합 = dist_w[u] + dist_w[v] - 2 * dist_w[LCA(u, v)]

Clca_distance.c
/* 트리 위 두 정점 거리 */ /* dist(u,v) = depth[u] + depth[v] - 2*depth[LCA(u,v)] */ int treeDist(int u, int v) { int l = lca(u, v); return depth[u] + depth[v] - 2 * depth[l]; } /* 트리 경로 쿼리: u->v 경로의 가중치 합 */ /* 각 정점에 루트까지의 가중치 합 dist[] 저장 */ long long dist_w[MAXN]; /* dist_w[v] = 루트~v 경로 가중치 합 */ long long pathWeight(int u, int v) { int l = lca(u, v); return dist_w[u] + dist_w[v] - 2 * dist_w[l]; }

SECTION 369Bronze | 고급 그래프
오일러 투어 — 서브트리를 구간으로 변환
오일러 투어DFS 순서서브트리 쿼리Bronze

오일러 투어(Euler Tour)는 DFS 순서대로 정점을 나열하는 기법입니다.
각 정점 u에 대해 진입 시간(in_time[u])과 퇴장 시간(out_time[u])을 기록합니다.
이렇게 하면 u의 서브트리가 구간 [in_time[u], out_time[u]]에 대응됩니다!

핵심 성질:
v가 u의 서브트리에 속함 ⇔ in_time[u] ≤ in_time[v] ≤ out_time[u]
서브트리 내의 값 합, 최솟값 등을 세그먼트 트리로 O(log N)에 처리할 수 있습니다.

응용:
서브트리 합 쿼리: 세그먼트 트리에서 구간 [in[u], out[u]]의 합
서브트리 업데이트: in[u] 위치의 값을 변경

CCW (Counter-Clockwise) 외적

BRONZE 기하 외적

세 점 A, B, C가 주어졌을 때, A→B→C로 이동하는 방향이
반시계 방향(CCW)인지, 시계 방향(CW)인지, 일직선인지를 판별하는 것이
기하 알고리즘의 가장 기본적인 연산입니다.

외적(Cross Product) 공식:
벡터 AB = (B.x - A.x, B.y - A.y)
벡터 AC = (C.x - A.x, C.y - A.y)
외적 = AB.x × AC.y - AB.y × AC.x

외적 값방향의미
> 0CCW (반시계)C가 AB의 왼쪽
< 0CW (시계)C가 AB의 오른쪽
= 0일직선A, B, C가 한 직선 위
Cccw.c
#include <stdio.h> typedef struct { long long x, y; } Point; /* ccw: 양수=반시계, 음수=시계, 0=일직선 */ long long ccw(Point A, Point B, Point C) { return (B.x - A.x) * (C.y - A.y) - (B.y - A.y) * (C.x - A.x); } int main(void) { Point p1 = {0, 0}; Point p2 = {4, 0}; Point p3 = {2, 3}; Point p4 = {2, -3}; Point p5 = {8, 0}; long long v1 = ccw(p1, p2, p3); long long v2 = ccw(p1, p2, p4); long long v3 = ccw(p1, p2, p5); printf("(0,0)-(4,0)-(2,3): %lld → %s\n", v1, v1 > 0 ? "CCW" : v1 < 0 ? "CW" : "일직선"); printf("(0,0)-(4,0)-(2,-3): %lld → %s\n", v2, v2 > 0 ? "CCW" : v2 < 0 ? "CW" : "일직선"); printf("(0,0)-(4,0)-(8,0): %lld → %s\n", v3, v3 > 0 ? "CCW" : v3 < 0 ? "CW" : "일직선"); return 0; }

선분 교차 판정

BRONZE 기하 CCW

두 선분 AB와 CD가 교차하는지 판별하는 문제는 기하 알고리즘의 핵심입니다.
CCW를 활용하면 깔끔하게 해결할 수 있습니다.

교차 조건:
1. CCW(A,B,C)와 CCW(A,B,D)의 부호가 다르고 (C와 D가 AB의 양쪽에 있고)
2. CCW(C,D,A)와 CCW(C,D,B)의 부호가 다르면 (A와 B가 CD의 양쪽에 있으면)
두 선분은 교차합니다.

특수 케이스 — 일직선:
네 개의 CCW가 모두 0인 경우, 네 점이 한 직선 위에 있습니다.
이때는 x좌표와 y좌표의 범위가 겹치는지 확인해야 합니다.

볼록 껍질 — Graham Scan

BRONZE 기하 볼록 껍질 스택

볼록 껍질(Convex Hull)은 주어진 점들을 모두 감싸는 가장 작은 볼록 다각형입니다.
마치 점들에 고무줄을 씌운 모양이라고 생각하면 됩니다.

Graham Scan 알고리즘:
1. y좌표가 가장 작은 점(같으면 x가 작은 점)을 기준점으로 선택
2. 나머지 점들을 기준점에서의 각도순으로 정렬
3. 스택을 이용해 CCW가 아닌 점을 제거하며 진행
시간 복잡도: O(N log N) (정렬이 지배적)

Cgraham_scan.c
#include <stdio.h> #include <stdlib.h> typedef struct { long long x, y; } Pt; Pt pivot; long long cross(Pt O, Pt A, Pt B) { return (A.x-O.x)*(B.y-O.y) - (A.y-O.y)*(B.x-O.x); } long long dist2(Pt a, Pt b) { return (a.x-b.x)*(a.x-b.x) + (a.y-b.y)*(a.y-b.y); } int cmp(const void *a, const void *b) { Pt *p = (Pt*)a, *q = (Pt*)b; long long v = cross(pivot, *p, *q); if (v != 0) return v > 0 ? -1 : 1; return dist2(pivot,*p) < dist2(pivot,*q) ? -1 : 1; } int main(void) { int n; scanf("%d", &n); Pt pts[100001]; for (int i = 0; i < n; i++) scanf("%lld %lld", &pts[i].x, &pts[i].y); /* 1. 기준점 찾기 (y 최소, x 최소) */ int mi = 0; for (int i = 1; i < n; i++) { if (pts[i].y < pts[mi].y || (pts[i].y == pts[mi].y && pts[i].x < pts[mi].x)) mi = i; } Pt tmp = pts[0]; pts[0] = pts[mi]; pts[mi] = tmp; pivot = pts[0]; /* 2. 각도순 정렬 */ qsort(pts + 1, n - 1, sizeof(Pt), cmp); /* 3. 스택으로 볼록 껍질 구성 */ Pt stk[100001]; int top = 0; stk[top++] = pts[0]; stk[top++] = pts[1]; for (int i = 2; i < n; i++) { while (top >= 2 && cross(stk[top-2], stk[top-1], pts[i]) <= 0) top--; stk[top++] = pts[i]; } printf("볼록 껍질 점 수: %d\n", top); for (int i = 0; i < top; i++) printf("(%lld, %lld)\n", stk[i].x, stk[i].y); return 0; }

볼록 껍질 점 수: 5 (0, 0) (2, 0) (4, 1) (4, 4) (0, 3)

BRONZE 기하 볼록 껍질 Rotating Calipers

최원점 쌍(Farthest Pair)이란 주어진 점 집합에서 가장 먼 두 점을 찾는 문제입니다.
모든 쌍을 비교하면 O(N²)이지만,
볼록 껍질 + Rotating Calipers를 쓰면 O(N log N)에 해결됩니다.

핵심 아이디어:
최원점 쌍은 반드시 볼록 껍질 위의 점입니다.
볼록 껍질의 한 변에 대해 가장 먼 점(반대편 꼭짓점)은
변이 회전함에 따라 단조 증가합니다. (캘리퍼스가 회전하는 것처럼)

단계설명시간 복잡도
1볼록 껍질 구성 (Graham Scan)O(N log N)
2Rotating Calipers로 최원점 탐색O(M) (M = 껍질 점 수)
전체볼록 껍질이 지배적O(N log N)
