SECTION 856Platinum | 고급 DP·최적화
Steiner Tree DP on Subsets
Steiner TreeSubset DPGraph DPPLATINUM

문제 신호
특정 중요한 정점 집합을 최소 비용으로 모두 연결하라는 질문은 Steiner Tree 가능성을 강하게 시사합니다.
중요 정점 수 K가 작다면 부분집합 DP와 최단 경로 완화를 결합합니다.

Csteiner_dp.c
for (int mask = 1; mask < (1 << K); mask++) { for (int sub = (mask - 1) & mask; sub; sub = (sub - 1) & mask) { dp[mask][v] = min(dp[mask][v], dp[sub][v] + dp[mask ^ sub][v]); } run_dijkstra(mask); }

SECTION 862Platinum | 고급 그래프
Stoer-Wagner Global Min-Cut
Min-CutStoer-WagnerUndirected GraphPLATINUM

문제 구조
source와 sink가 지정되지 않은 전체 그래프의 global min-cut을 구하는 고전 알고리즘입니다.
반복적으로 가장 강하게 연결된 정점을 확장해 마지막 두 정점 사이 절단값을 평가합니다.

비교최소 컷 하나만 필요하면 Stoer-Wagner가 직접적이고, 모든 쌍 컷 정보가 필요하면 Gomory-Hu tree가 더 유용합니다.
