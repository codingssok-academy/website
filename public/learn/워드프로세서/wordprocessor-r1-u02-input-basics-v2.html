Chapter 02

키보드와 한글 입력기 기본

한영 전환, 특수문자, 지우기, 줄 바꾸기처럼 문서 입력의 가장 기초가 되는 도구부터 익혀봐요.

이 유닛에서 배우는 것

  • 한영 전환과 한글 입력기의 기본 상태를 확인할 수 있어요.
  • Enter, Backspace, Delete, Space, Shift의 역할을 구분할 수 있어요.
  • 특수문자 입력과 기본 교정 습관을 익혀요.
  • 입력 속도보다 입력 정확도가 더 중요하다는 점을 이해해요.

UNIT 02 키보드와 한글 입력기 기본

문서는 손보다 먼저 입력 도구가 중요해요

워드프로세서에서 가장 먼저 익혀야 하는 건 화려한 기능이 아니에요. 정확하게 입력하는 습관이에요. 제목을 치다가 영어로 입력하거나, 줄을 바꿔야 할 때 띄어쓰기를 여러 번 넣으면 문서 모양이 금방 무너져요.

시험에서도 입력 실수는 시간을 많이 잡아먹어요. 한 번 잘못 입력한 문장은 고치면서 다시 읽어야 하고, 서식까지 틀리면 더 손해예요. 그래서 오늘은 문서 작업의 가장 바닥부터 잡아요.

[핵심] 오늘 꼭 구분할 6개 키 한/영 — 입력 언어를 바꿔요.
Shift — 대문자, 기호 입력에 써요.
Space — 한 칸 띄워요.
Enter — 줄을 바꿔요.
Backspace — 커서 왼쪽 글자를 지워요.
Delete — 커서 오른쪽 글자를 지워요.

한글 입력기의 기본

1
1단계 상태 표시 보기
작업 표시줄이나 입력기 표시에서 한글 상태인지 영어 상태인지 먼저 확인해요.
2
2단계 한영 전환
한/영 키나 Alt+Shift 같은 전환 키로 입력 언어를 바꿔요.
3
3단계 Shift 활용
영어 대문자나 괄호, 물음표 같은 기호는 Shift와 함께 입력해요.
4
4단계 틀리면 바로 수정
한 단어가 영어로 잘못 들어갔으면 끝까지 두지 말고 바로 Backspace로 지워요.
키언제 쓰나요?문서 작업에서 왜 중요할까요?
Enter다음 줄로 내려갈 때문단과 줄을 분리해요
Space단어와 단어 사이띄어쓰기를 정확히 맞춰요
Backspace방금 입력한 글자를 지울 때오타를 가장 빠르게 수정해요
Delete앞쪽이 아니라 뒤쪽 글자를 지울 때커서 위치를 유지한 채 정리해요
Shift대문자나 기호를 넣을 때문서 부호 입력에 자주 써요
한/영입력 언어를 바꿀 때한글 문서에서 가장 자주 실수하는 부분이에요

자주 하는 입력 실수

[주의] 많이 틀리는 4가지 1. 한글을 쳐야 하는데 영어 상태로 입력해요.
2. 줄을 바꾸려고 스페이스를 여러 번 눌러요.
3. 제목을 강조하려고 글자를 다시 입력해요.
4. 오타를 놔두고 계속 입력해서 나중에 더 크게 고쳐요.
실수잘못된 처리바른 처리
다음 줄로 내려가기스페이스를 여러 번 누름Enter를 한 번 누름
오타 수정문장 끝까지 쓰고 나서 돌아옴바로 Backspace로 수정
물음표 입력한글 상태에서 계속 눌러 봄영문 상태와 Shift 조합 확인
띄어쓰기 맞추기눈대중으로 빈칸 여러 개단어 사이 Space 한 번

특수문자와 기호

문서에는 글자만 들어가지 않아요. 괄호, 쉼표, 마침표, 콜론, 물음표 같은 기호도 자주 써요. 시험에서는 이런 기호 하나가 빠져도 감점 포인트가 될 수 있어요.

용어설명
입력기한글과 영어 같은 입력 언어를 처리하는 도구

핵심 정리
1. 문서 작업의 출발점은 빠른 타자가 아니라 정확한 입력이에요.
2. 한영 전환, 줄 바꾸기, 지우기 키를 구분하면 기본 실수가 크게 줄어요.
3. 기호 하나도 문서의 일부라서 정확하게 입력해야 해요.
[실생활] 어디에 쓰일까요? 과제 제목, 공지문, 신청서, 보고서처럼 거의 모든 문서 작업에서 입력 정확도가 바닥이 돼요. 이 기본이 흔들리면 뒤에서 배우는 표와 서식도 자꾸 꼬여요.
[다음 유닛 미리보기] 다음 유닛에서는 파일과 폴더, 저장과 다른 이름으로 저장을 배워요. 문서를 만들고도 못 찾으면 작업이 끝난 게 아니에요.
