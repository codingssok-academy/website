Q1 교정부호
매회 출제
다음 중 교정 부호의 사용법에 대한 설명으로 옳지 않은 것은?
  1. 1한 번 교정된 부분도 다시 교정할 수 있다.
  2. 2교정 부호를 표시하는 색은 원고의 글자색과 같은 색으로 한다.
  3. 3교정 부호는 여러 개 사용 시 겹치지 않도록 한다.
  4. 4교정 부호로 글자를 삽입, 삭제, 수정할 수 있다.
정답: 2번
!파인만 한 줄
교정부호는 원본 내용이랑 헷갈리면 안 되니까 반드시 다른 색으로 표시한다.
*감정 태깅
선생님이 빨간펜으로 채점하는 이유? 학생이 쓴 검정 글씨랑 구별하려고! 그게 교정부호의 원리야.
!출제자 함정
"같은 색" vs "다른 색" — 딱 한 글자 차이 함정. "혼동되지 않도록"을 기억하면 절대 안 걸린다.
#키워드 공식
교정부호 = 다른 색, 다시 교정 가능, 겹치지 않게
Q2 공문서 작성
매회 출제
다음 중 공문서의 항목 구분 순서로 올바른 것은?
  1. 1가, 나, 다 → 1, 2, 3 → 가), 나), 다) → 1), 2), 3)
  2. 21, 2, 3 → 가, 나, 다 → 1), 2), 3) → 가), 나), 다)
  3. 31), 2), 3) → 가), 나), 다) → 1, 2, 3 → 가, 나, 다
  4. 4(1), (2), (3) → 1, 2, 3 → (가), (나), (다) → 가, 나, 다
정답: 2번
!파인만 한 줄
숫자 → 한글 → 숫자) → 한글) → (숫자) → (한글). 숫자가 먼저, 괄호 붙으면 한 단계 아래!
*감정 태깅
군대 계급처럼: 숫자=대장, 한글=중장, 괄호 붙으면 한 계급 내려간다고 생각해.
!출제자 함정
1단계를 "가, 나, 다"로 시작하는 보기가 함정. 1단계는 반드시 숫자(1, 2, 3)!
v프로테제 테스트
"공문서 항목 구분 6단계를 순서대로 말해봐"
Q3 전결 vs 대결
자주 출제
다음 중 결재의 종류에 대한 설명으로 옳은 것은?
  1. 1전결은 결재권자가 부재 시 대리하는 자가 결재하는 것이다.
  2. 2대결은 결재권자가 하위 직위자에게 결재권을 위임하는 것이다.
  3. 3대결 시 원래 결재권자는 후에 내용을 확인하여야 한다.
  4. 4후결은 결재 과정을 거치지 않고 바로 발송하는 것이다.
정답: 3번
!파인만 한 줄
전결 = 권한 위임. 대결 = 부재 시 대신(사후 확인). 둘을 뒤바꾸는 게 출제자 수법!
=혼동쌍 — 매회 출제!
구분뜻핵심
전결결재권 위임하위자가 최종 결재권자
대결부재 시 대리원 결재권자 사후 확인
후결먼저 시행나중에 결재
협조의견 요청결재가 아닌 참조
v프로테제 테스트
"전결이랑 대결 차이를 한 문장으로 설명해봐"
Q4 글꼴 종류
매회 출제
다음 중 트루타입(TrueType) 폰트에 대한 설명으로 옳지 않은 것은?
  1. 1확대할 경우 계단 현상(깨짐)이 발생한다.
  2. 2Apple과 Microsoft가 공동으로 개발하였다.
  3. 3화면에 표시되는 것과 인쇄 결과가 동일하다.
  4. 4벡터 방식의 외곽선 폰트이다.
정답: 1번
!파인만 한 줄
확대하면 깨지는 건 비트맵! 트루타입은 벡터라서 아무리 확대해도 선명.
*감정 태깅
사진 확대하면 픽셀 보이잖아(비트맵). 일러스트는 아무리 키워도 깨끗해(벡터). 트루타입 = 일러스트 쪽!
=혼동쌍
폰트방식확대 시개발
비트맵점(픽셀)계단현상—
트루타입벡터선명Apple + MS
오픈타입벡터선명Adobe + MS
포스트스크립트PDL선명Adobe
Q5 OLE
자주 출제
다음 중 OLE에 대한 설명으로 옳지 않은 것은?
  1. 1연결(Linking)은 원본 수정 시 삽입된 개체에 자동 반영된다.
  2. 2포함(Embedding) 시 원본이 수정되면 문서에도 반영된다.
  3. 3다른 프로그램에서 만든 개체를 문서에 삽입할 수 있다.
  4. 4연결 시 원본 파일이 삭제되면 개체를 볼 수 없다.
정답: 2번
!파인만 한 줄
연결 = 바로가기(같이 바뀜). 포함 = 복사본(안 바뀜). 2번은 포함을 연결처럼 설명!
*감정 태깅
인스타에 친구 사진 링크하면 친구가 바꾸면 같이 바뀌지. 스크린샷(=포함)은 원본 바꿔도 그대로!
#키워드 공식
연결 = 자동반영 + 원본 필요 / 포함 = 반영 안 됨 + 원본 불필요

Q6 휴지통
매회 출제
다음 중 Windows 휴지통에 대한 설명으로 옳지 않은 것은?
  1. 1휴지통에서 파일을 복원하면 원래 위치로 돌아간다.
  2. 2Shift+Delete로 삭제하면 휴지통을 거치지 않는다.
  3. 3네트워크 드라이브의 파일을 삭제하면 휴지통으로 이동한다.
  4. 4휴지통에서 특정 파일만 선택하여 삭제할 수 있다.
정답: 3번
!파인만 한 줄
네트워크 드라이브와 USB 파일은 휴지통 안 거치고 즉시 삭제!
*감정 태깅
내 방(C드라이브)에서 버리면 쓰레기통에 잠깐 있지. 남의 집(네트워크)이나 캐리어(USB)에서 버리면? 바로 사라져!
~선지별 해부
선지판정이유
1O복원 시 원래 경로로 돌아감
2OShift+Delete = 완전 삭제
3X네트워크 파일은 즉시 완전 삭제!
4O개별 파일 선택 삭제 가능

  2. 2부팅 로깅은 부팅 과정을 ntbtlog.txt에 기록하는 모드이다.
  3. 3저해상도 비디오 모드는 1024x768로 부팅한다.

3X저해상도 = 640x480
4X최대 절전 = 하드디스크, 절전 = RAM

Q8 RAM / ROM / 캐시
매회 출제
다음 중 기억장치에 대한 설명으로 옳지 않은 것은?
  1. 1RAM은 전원이 꺼지면 저장 내용이 사라지는 휘발성 메모리이다.
  2. 2ROM은 읽기만 가능하며, 전원이 꺼져도 내용이 유지된다.
  3. 3캐시 메모리는 보조기억장치와 주기억장치 사이에 위치한다.
  4. 4캐시 메모리는 SRAM으로 구성된다.
정답: 3번
!파인만 한 줄
캐시는 CPU와 RAM 사이! "보조기억장치와 RAM 사이"는 거짓!
*감정 태깅
CPU=셰프, RAM=주방 테이블, 캐시=셰프 옆 조리대, HDD=창고. 조리대는 셰프와 테이블 사이에 있지, 창고와 테이블 사이가 아냐!
#키워드 공식
속도순: 레지스터 > 캐시(SRAM) > RAM(DRAM) > SSD > HDD

  2. 2라우터는 OSI 2계층에서 동작하는 장비이다.
  3. 3스위치는 MAC 주소를 기반으로 선택적으로 데이터를 전달한다.
  4. 4게이트웨이는 신호를 증폭하여 재전송하는 장비이다.
정답: 3번
~선지별 해부

1X허브 = 모든 포트 브로드캐스트
2X라우터 = 3계층, 2계층은 스위치
3O스위치 = 2계층, MAC 기반 선택 전달
4X신호 증폭 = 리피터
=혼동쌍 — 시험 단골!

Q10 악성코드
매회 출제
다음 중 악성코드에 대한 설명으로 옳지 않은 것은?
  1. 1바이러스는 정상 파일에 기생하며, 숙주 파일이 필요하다.
  2. 2웜(Worm)은 반드시 숙주 파일이 있어야 전파된다.
  3. 3랜섬웨어는 파일을 암호화한 후 금전을 요구한다.
  4. 4트로이목마는 정상 프로그램으로 위장하여 백도어를 설치한다.
정답: 2번
!파인만 한 줄
바이러스 = 기생충(숙주 필요). 웜 = 독립 생물(숙주 없이 자동 전파).
*감정 태깅
바이러스=코로나(사람에 붙어서 퍼짐). 웜=지렁이(혼자 기어다니며 퍼짐). 이름이 힌트야!
=혼동쌍
악성코드숙주특징

웜불필요독립 전파, 네트워크 확산
트로이목마불필요정상 프로그램 위장, 백도어
랜섬웨어불필요파일 암호화 + 금전 요구
스파이웨어불필요정보 수집 + 전송
