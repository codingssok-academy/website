Chapter 08

찾기, 바꾸기, 자동 고침

같은 단어나 오타가 여러 번 나오면 손으로 하나씩 고치지 말고, 한 번에 찾고 바꿔야 해요.

이 유닛에서 배우는 것

  • 찾기 기능의 역할을 설명할 수 있어요.
  • 바꾸기 기능으로 반복 수정 작업을 줄일 수 있어요.
  • 자동 고침이 편할 때와 조심해야 할 때를 구분해요.
  • 긴 문서에서 반복 오타를 빠르게 정리하는 루틴을 익혀요.

긴 문서는 눈으로만 찾으면 느려요

짧은 문서라면 오타를 눈으로 찾아도 괜찮아요. 하지만 문장이 길어지고 같은 단어가 여러 번 나오면 하나씩 눈으로 찾는 건 금방 느려져요. 이럴 때 쓰는 기능이 찾기와 바꾸기예요.

[핵심] 두 기능의 역할 찾기는 문서 안에서 원하는 단어나 표현이 어디 있는지 보여줘요.
바꾸기는 찾은 표현을 다른 표현으로 한 번에 고쳐 줘요.

찾기는 위치 확인 도구예요

찾는 대상왜 찾을까요?
특정 단어문서 안에서 몇 번 나오는지 확인해요
오타 표현어디를 고쳐야 하는지 빠르게 찾죠
특정 날짜나 이름수정 누락을 막아요

바꾸기는 반복 수정의 지름길이에요

1
1단계 바꿀 표현 정하기
현재 문서에 들어 있는 잘못된 표현을 먼저 적어요.
2
2단계 바뀔 표현 정하기
어떤 내용으로 고칠지 정확히 정해요.
3
3단계 한 번씩 확인 또는 모두 바꾸기
문맥이 다르면 하나씩 확인하고, 전부 같으면 한 번에 바꿔요.
상황손으로 고치면바꾸기를 쓰면
같은 오타가 5번 나옴5번 찾아서 수정한 번에 정리 가능
이름 표기를 통일해야 함누락이 생기기 쉬움빠르게 점검 가능
날짜 형식을 바꿔야 함여러 줄을 다시 읽어야 함반복 수정 시간을 크게 줄임

자동 고침은 편하지만 확인이 필요해요

자동 고침은 자주 틀리는 입력을 자동으로 바로잡아 주는 기능이에요. 편하지만, 원하지 않는 모양으로 바뀌는 경우도 있어서 결과를 확인하는 습관이 필요해요.

[주의] 모두 바꾸기는 항상 안전하지 않아요 같은 글자라도 문맥마다 뜻이 다를 수 있어요. 그래서 전부 똑같이 바꿔도 되는지 먼저 확인해야 해요. 애매하면 하나씩 확인하면서 바꾸는 쪽이 더 안전해요.

실습 1

문서에 `문서작업`이라는 단어를 세 번, `문서 작업`이라는 단어를 두 번 입력한 뒤, 찾기 기능으로 각각 몇 번 나오는지 확인해 보세요.

실습 2

`2026년`이라는 표현을 문서에 여러 번 넣은 뒤, 한 번은 `2026학년도`로 바꾸어 보세요. 바꾸기 전에 전부 같은 문맥인지 먼저 확인해 보세요.

용어설명
찾기문서 안에서 원하는 단어나 표현의 위치를 찾는 기능
바꾸기찾은 표현을 다른 표현으로 바꾸는 기능
모두 바꾸기문서 안의 같은 표현을 한 번에 전부 바꾸는 기능
자동 고침자주 틀리는 입력을 자동으로 수정해 주는 기능
핵심 정리
1. 긴 문서의 반복 수정은 찾기와 바꾸기로 처리해야 빨라요.
2. 모두 바꾸기를 누르기 전에 문맥이 같은지 먼저 확인해야 해요.
3. 자동 고침은 편리하지만 결과 확인이 꼭 필요해요.
[실생활] 어디에 쓰일까요? 학교 행사 날짜를 여러 줄에서 바꾸거나, 이름 표기를 통일할 때 찾기와 바꾸기 기능이 큰 힘을 발휘해요. 긴 공지문일수록 차이가 커져요.
