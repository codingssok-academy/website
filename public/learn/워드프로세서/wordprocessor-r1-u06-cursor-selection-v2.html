커서 이동과 범위 선택

문서를 고치는 힘은 어디를 정확히 선택하느냐에서 시작돼요. 커서와 블록 선택부터 익혀봐요.

이 유닛에서 배우는 것

  • 커서의 의미를 설명할 수 있어요.
  • 글자, 단어, 줄, 문단 단위로 범위를 선택할 수 있어요.
  • 마우스와 키보드 선택 방식을 구분해요.
  • 수정 전에 먼저 선택하는 습관을 익혀요.

UNIT 06 커서 이동과 범위 선택

편집은 커서 위치에서 시작돼요

문서에서 깜빡이는 세로줄이 바로 커서예요. 지금 입력하거나 지우는 일이 어디에서 일어날지 알려 주는 표시예요. 커서 위치가 틀리면 글자가 엉뚱한 곳에 들어가고, 삭제도 다른 부분에서 일어나요.

편집에서 가장 중요한 기본은 두 가지예요. 첫째, 커서를 정확한 위치로 이동하기. 둘째, 바꿀 범위를 정확히 선택하기. 이 두 개가 되면 복사, 삭제, 서식 적용이 전부 쉬워져요.

[핵심] 오늘의 기본 공식 수정 = 먼저 이동 + 그다음 선택
문서를 고치기 전에, 어디를 바꿀지 정확히 잡는 게 먼저예요.

커서 이동 방법

방법언제 쓰나요?예시
마우스로 클릭원하는 위치를 바로 찍고 싶을 때문장 중간 클릭
방향키한 글자씩 미세하게 움직일 때오타 한 글자 앞으로 이동
Home줄의 맨 앞으로 갈 때줄 첫 글자로 이동
End줄의 맨 끝으로 갈 때줄 끝에 문장 추가
Page Up / Page Down긴 문서에서 위아래로 크게 이동할 때다음 페이지로 이동

범위 선택은 여러 크기로 할 수 있어요

1
글자 선택
마우스로 짧게 끌거나 Shift와 방향키를 이용해요.
2
단어 선택
단어를 빠르게 잡고 싶으면 더블클릭이 편해요.
3
문장 또는 줄 선택
문장 일부가 아니라 줄 전체를 수정할 때 유용해요.
4
문단 선택
정렬이나 줄 간격은 문단 단위로 잡아야 정확해요.
바꾸고 싶은 것선택 단위이유
오타 한 글자글자딱 필요한 곳만 고쳐요
잘못된 단어단어앞뒤 글자를 건드리지 않아요
제목 한 줄줄 또는 문장한 번에 정리하기 좋아요
정렬 바꿀 본문문단문단 서식은 문단째로 적용돼요
[주의] 서식이 이상하게 먹는 이유 문단 정렬이나 줄 간격을 바꾸려는데 이상한 결과가 나오는 경우가 많아요. 대부분은 문단 전체를 선택하지 않고 일부 글자만 잡았기 때문이에요.

선택 전에 확인할 것

확인 항목왜 볼까요?
커서가 원하는 위치에 있는가?엉뚱한 곳에 글자가 들어가는 걸 막아요
선택 범위가 너무 넓지 않은가?필요 없는 부분까지 같이 바뀌는 걸 막아요
문단 전체가 필요한가, 글자 일부만 필요한가?문자 서식과 문단 서식을 구분해요

직접 해보기

실습 1

짧은 문장 세 줄을 입력한 뒤, 둘째 줄 첫 글자 앞에 커서를 놓아 보세요. 마우스 클릭과 방향키 이동을 둘 다 써 보세요.

실습 2

문장에서 단어 하나만 선택하고, 다른 줄에서는 문장 전체를 선택해 보세요. 선택 범위가 어떻게 달라지는지 확인해 보세요.

용어설명
커서현재 입력이나 수정이 일어날 위치를 보여주는 표시
선택수정하거나 서식을 적용할 범위를 지정하는 일
문단Enter로 구분되는 한 덩어리의 글
블록문서에서 선택된 범위를 가리키는 말
핵심 정리
1. 문서를 고치기 전에 커서 위치를 먼저 확인해야 해요.
2. 문자 수정과 문단 수정은 선택 단위가 달라요.
3. 정확한 선택이 되면 복사, 삭제, 서식 적용이 한결 쉬워져요.
[실생활] 어디에 쓰일까요? 과제 제목, 보고서 본문, 신청서 항목처럼 수정할 부분을 정확히 잡는 능력은 모든 문서 작업의 바닥이에요. 선택이 흔들리면 뒤에 오는 기능도 전부 불안해져요.
[다음 유닛 미리보기] 다음 유닛에서는 복사, 잘라내기, 붙여넣기, 되돌리기를 배워요. 선택한 범위를 실제로 움직이는 편집 루틴이 시작돼요.
