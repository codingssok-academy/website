1 다음 중 교정 부호의 사용법에 대한 설명으로 옳지 않은 것은? 매회
  1. ①한 번 교정된 부분도 다시 교정할 수 있다.
  2. ②교정 부호를 표시하는 색은 원고의 글자색과 같은 색으로 한다.
  3. ③교정 부호는 여러 개 사용 시 겹치지 않도록 한다.
  4. ④교정 부호로 글자를 삽입, 삭제, 수정할 수 있다.
2 다음 중 공문서의 항목 구분 순서로 올바른 것은? 매회
  1. ①가, 나, 다 → 1, 2, 3 → 가), 나), 다) → 1), 2), 3)
  2. ②1, 2, 3 → 가, 나, 다 → 1), 2), 3) → 가), 나), 다)
  3. ③1), 2), 3) → 가), 나), 다) → 1, 2, 3 → 가, 나, 다
  4. ④(1), (2), (3) → 1, 2, 3 → (가), (나), (다) → 가, 나, 다
3 다음 중 결재의 종류에 대한 설명으로 옳은 것은? 자주
  1. ①전결은 결재권자가 부재 시 대리하는 자가 결재하는 것이다.
  2. ②대결은 결재권자가 하위 직위자에게 결재권을 위임하는 것이다.
  3. ③대결 시 원래 결재권자는 후에 내용을 확인하여야 한다.
  4. ④후결은 결재 과정을 거치지 않고 바로 발송하는 것이다.
4 다음 중 트루타입(TrueType) 폰트에 대한 설명으로 옳지 않은 것은? 매회
  1. ①확대할 경우 계단 현상(깨짐)이 발생한다.
  2. ②Apple과 Microsoft가 공동으로 개발하였다.
  3. ③화면에 표시되는 것과 인쇄 결과가 동일하다.
  4. ④벡터 방식의 외곽선 폰트이다.
5 다음 중 OLE(Object Linking and Embedding)에 대한 설명으로 옳지 않은 것은? 자주
  1. ①연결(Linking)은 원본 수정 시 삽입된 개체에 자동 반영된다.
  2. ②포함(Embedding) 시 원본이 수정되면 문서에도 반영된다.
  3. ③다른 프로그램에서 만든 개체를 문서에 삽입할 수 있다.
  4. ④연결 시 원본 파일이 삭제되면 개체를 볼 수 없다.

6 다음 중 Windows 휴지통에 대한 설명으로 옳지 않은 것은? 매회
  1. ①휴지통에서 파일을 복원하면 원래 위치로 돌아간다.
  2. ②Shift+Delete로 삭제하면 휴지통을 거치지 않는다.
  3. ③네트워크 드라이브의 파일을 삭제하면 휴지통으로 이동한다.
  4. ④휴지통에서 특정 파일만 선택하여 삭제할 수 있다.
7 다음 중 Windows 고급 부팅 옵션에 대한 설명으로 옳은 것은? 자주
  1. ①안전 모드는 네트워크 서비스를 포함하여 부팅한다.
  2. ②부팅 로깅은 부팅 과정을 ntbtlog.txt에 기록하는 모드이다.
  3. ③저해상도 비디오 모드는 1024×768로 부팅한다.
  4. ④최대 절전 모드는 RAM에 현재 상태를 저장한다.
3컴퓨터와 정보활용 Q8 – Q10
8 다음 중 기억장치에 대한 설명으로 옳지 않은 것은? 매회
  1. ①RAM은 전원이 꺼지면 저장 내용이 사라지는 휘발성 메모리이다.
  2. ②ROM은 읽기만 가능하며, 전원이 꺼져도 내용이 유지된다.
  3. ③캐시 메모리는 보조기억장치와 주기억장치 사이에 위치한다.
  4. ④캐시 메모리는 SRAM으로 구성된다.
9 다음 중 네트워크 장비에 대한 설명으로 옳은 것은? 매회
  1. ①허브는 MAC 주소를 기반으로 특정 포트에만 데이터를 전달한다.
  2. ②라우터는 OSI 2계층에서 동작하는 장비이다.
  3. ③스위치는 MAC 주소를 기반으로 선택적으로 데이터를 전달한다.
  4. ④게이트웨이는 신호를 증폭하여 재전송하는 장비이다.
10 다음 중 악성코드에 대한 설명으로 옳지 않은 것은? 매회
  1. ①바이러스는 정상 파일에 기생하며, 숙주 파일이 필요하다.
  2. ②웜(Worm)은 반드시 숙주 파일이 있어야 전파된다.
  3. ③랜섬웨어는 파일을 암호화한 후 금전을 요구한다.
  4. ④트로이목마는 정상 프로그램으로 위장하여 백도어를 설치한다.
