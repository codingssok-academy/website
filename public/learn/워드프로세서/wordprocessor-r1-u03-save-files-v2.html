Chapter 03

파일과 폴더, 저장과 다른 이름으로 저장

문서를 만들었으면 찾을 수 있어야 하고, 덮어쓰지 않고 안전하게 저장할 수 있어야 해요.

이 유닛에서 배우는 것

  • 파일과 폴더의 역할을 구분할 수 있어요.
  • 저장과 다른 이름으로 저장의 차이를 설명할 수 있어요.
  • 문서 파일 형식 `hwp`, `docx`, `pdf`의 차이를 알아요.
  • 좋은 파일명과 폴더 정리 습관을 익혀요.

UNIT 03 파일과 폴더, 저장과 다른 이름으로 저장

문서를 만들고도 못 찾으면 끝이에요

문서 작업에서 생각보다 많은 시간이 파일 찾기에 쓰여요. 제목은 잘 써 놓고 저장 위치를 잊어버리거나, 파일 이름을 엉뚱하게 붙이면 다시 찾는 데 시간이 오래 걸려요.

실기 시험에서도 저장은 뒤로 미루는 기능이 아니에요. 문서를 열자마자 어디에 저장할지, 어떤 이름으로 저장할지 먼저 생각하는 습관이 필요해요.

[핵심] 파일과 폴더 파일은 실제 문서 내용이에요.
폴더는 파일을 정리해 두는 서랍장이에요.
문서 작업이 늘어나면 파일보다 폴더 정리가 더 중요해져요.

저장과 다른 이름으로 저장

1
1단계 첫 저장
처음 문서를 만들었으면 저장 위치와 파일명을 먼저 정해요.
2
2단계 작업 중간 저장
수정이 생길 때마다 저장해서 작업 손실을 막아요.
3
3단계 다른 이름으로 저장
원본을 남기고 복사본을 만들거나 형식을 바꿀 때 써요.
4
4단계 제출 형식 확인
제출용이면 PDF인지, 수정용이면 문서 원본인지 확인해요.
기능언제 쓰나요?결과
저장기존 문서를 계속 수정할 때같은 파일에 덮어써요
다른 이름으로 저장복사본이나 새 형식이 필요할 때새 파일이 하나 더 생겨요
PDF 저장제출용 모양을 고정하고 싶을 때읽기 중심 파일을 만들어요

파일 형식은 왜 다를까요?

형식주로 쓰는 프로그램언제 쓰면 좋을까요?
hwp한글국내 문서 작업, 실기 연습
docxMS WordWord 중심 작업, 공유 문서
pdf뷰어, 브라우저제출, 배포, 인쇄용
txt메모장서식 없는 순수 텍스트 기록

좋은 파일명 규칙

[팁] 파일명은 짧고 찾기 쉽게 파일명에는 과목, 주제, 날짜나 버전을 넣으면 좋아요. 공백이 많고 뜻이 없는 이름은 나중에 찾기 어려워요.
나쁜 예좋은 예이유
새 문서(12).hwpwp-u03-저장연습.hwp무슨 문서인지 바로 보여요
진짜최종최종.hwp가정통신문-v2.hwp버전이 명확해요
숙제.hwp워드실기-자기소개-20260317.hwp언제 만든 문서인지 알 수 있어요
[주의] 많이 생기는 저장 사고 1. 저장은 했는데 어디에 저장했는지 모름
2. 원본 위에 덮어써서 이전 내용이 사라짐
3. 제출용 PDF를 안 만들고 원본만 제출함
4. 파일명이 비슷해서 잘못 첨부함

직접 해보기

실습 1

새 문서에 자신의 이름을 입력한 뒤 `wp-u03-저장연습`이라는 파일명으로 저장해 보세요. 저장한 폴더 이름도 확인해 보세요.

실습 2

같은 문서를 `다른 이름으로 저장` 기능으로 `wp-u03-저장연습-복사본`이라는 이름으로 한 번 더 저장해 보세요.

용어설명
파일실제 문서 내용이 저장된 단위
폴더파일을 분류해 넣는 묶음 공간
다른 이름으로 저장기존 파일을 유지한 채 새 이름이나 형식으로 저장하는 기능
PDF문서 배포와 제출에 자주 쓰는 고정형 파일 형식
핵심 정리
1. 문서 작업은 저장까지 해야 끝나요.
2. 저장과 다른 이름으로 저장은 결과가 달라요.
3. 파일명과 폴더 정리가 좋으면 문서를 다시 찾는 시간이 크게 줄어요.
[실생활] 어디에 쓰일까요? 학교 과제 제출, 동아리 공지문, 자기소개서, 보고서처럼 이름이 비슷한 문서가 여러 개 생길 때 파일명 규칙과 폴더 정리가 바로 효율 차이를 만들어요.
[다음 유닛 미리보기] 다음 유닛에서는 한글 화면 구성을 배워요. 메뉴, 리본, 눈금자, 상태 표시줄을 알면 필요한 기능을 훨씬 빨리 찾을 수 있어요.
