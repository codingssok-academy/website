  • 문서 파일 형식의 기본 차이를 구분할 수 있어요.
  • 실기 공부 전에 왜 저장 습관이 중요한지 알아요.

UNIT 01 워드프로세서는 뭘 하는 도구일까요?

워드프로세서는 그냥 타자기일까요?

워드프로세서는 문서를 입력하고, 편집하고, 정리하고, 저장하고, 출력하는 프로그램이에요. 학교 과제, 가정통신문, 보고서, 이력서처럼 글이 중심인 문서를 만들 때 가장 많이 써요.

많은 학생이 워드프로세서를 그냥 '타자 치는 프로그램' 정도로 생각해요. 그런데 시험에서는 타자보다 정확한 서식 적용과 작업 순서가 더 중요해요. 잘 쓰는 사람은 빨리 치는 사람이 아니라, 지시문을 보고 필요한 기능을 바로 찾는 사람이에요.

[핵심] 워드프로세서의 5가지 일 1. 입력 — 글자를 문서에 넣어요.
2. 편집 — 고치고, 옮기고, 지워요.
3. 서식 — 글자와 문단을 보기 좋게 다듬어요.
4. 저장 — 나중에 다시 열 수 있게 파일로 남겨요.
5. 출력 — 인쇄하거나 PDF로 내보내요.

문서는 어떤 순서로 만들어질까요?

1
1단계 입력
제목과 본문 내용을 먼저 입력해요.
2
2단계 편집
틀린 글자를 고치고 문장을 정리해요.
3
3단계 서식
글자 크기, 문단 정렬, 줄 간격, 표 같은 모양을 맞춰요.
4
4단계 저장
작업 중간에도 자주 저장해서 실수를 줄여요.
5
5단계 제출
인쇄하거나 PDF로 바꿔서 제출해요.
상황워드프로세서에서 하는 일대표 기능
학교 과제제목과 본문을 보기 좋게 정리글자 모양, 문단 모양
가정통신문공지 문장을 단정하게 배치정렬, 줄 간격, 여백
표가 있는 보고서내용을 표로 정리표 삽입, 셀 병합, 정렬
공식 제출 문서페이지 구조를 맞춤편집 용지, 쪽 번호, 머리말
온라인 제출다른 컴퓨터에서도 같은 모양 유지PDF 저장

파일 형식도 문서마다 달라요

문서는 다 똑같은 파일이 아니에요. 어떤 프로그램으로 만들었는지, 수정 가능한지, 제출용인지에 따라 파일 형식이 달라져요.

형식주로 쓰는 곳특징
hwp한글 문서국내 문서 작업에서 많이 써요
docxMS Word 문서Word에서 기본으로 많이 써요
pdf제출용 문서모양이 잘 안 깨져요
txt메모, 순수 글자서식이 거의 없어요
[주의] 저장을 미루면 바로 손해예요 실기 작업에서는 순서보다 먼저 저장 습관이 중요해요. 작업을 10분 해 놓고 저장을 안 하면, 프로그램이 멈췄을 때 처음부터 다시 해야 해요. 문서를 열자마자 저장 위치와 파일명을 먼저 확인하는 습관을 들여야 해요.
[팁] 워드프로세서 공부의 핵심 기능 이름을 외우는 것보다 지시문을 보고 어떤 기능을 써야 하는지 연결하는 훈련이 더 중요해요. 예를 들어 '가운데 정렬'은 문단 모양, '11포인트 굵게'는 글자 모양 문제예요.

용어설명
워드프로세서문서를 입력, 편집, 저장, 출력하는 프로그램
서식글자나 문단의 모양을 보기 좋게 바꾸는 설정
PDF다른 컴퓨터에서도 문서 모양이 비교적 잘 유지되는 파일 형식

핵심 정리
1. 워드프로세서는 글만 입력하는 프로그램이 아니라 문서를 완성하는 도구예요.
2. 문서 작업의 기본 흐름은 입력 -> 편집 -> 서식 -> 저장 -> 제출이에요.
3. 실기 공부에서는 기능 암기보다 지시문과 기능을 연결하는 습관이 중요해요.
[실생활] 어디에 쓰일까요? 학교 과제, 가정통신문, 안내문, 독후감, 보고서, 이력서 같은 문서는 거의 전부 워드프로세서로 만들어요. 실기 시험용 기능은 실제 문서 작업에서도 그대로 쓰여요.
[다음 유닛 미리보기] 다음 유닛에서는 한글 입력기와 키보드 기본을 다뤄요. 한영 전환, 특수문자, 입력 실수를 먼저 잡아 두면 뒤 유닛이 훨씬 빨라져요.
