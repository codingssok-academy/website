  2. ②레이저 프린터나 전자 식자기로 출력할 수 있다
  3. ③워드프로세서나 편집 소프트웨어가 필요하다
  4. ④컴퓨터를 이용하여 문서를 편집·조판하는 것이다

  2. ②≠ (부등호)
  3. ③∥ (병렬 기호)
  4. ④⊃ (포함 기호)

  4. ④결재권자가 미리 특정 사안의 결재 권한을 하위자에게 넘기는 것이다
