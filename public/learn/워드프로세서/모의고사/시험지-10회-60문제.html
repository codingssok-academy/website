  2. ②결재권자가 부재 시 직근 하위자가 대신 결재하는 것
  3. ③결재권자가 출장에서 돌아온 후 사후에 결재하는 것
  4. ④관련 부서의 장이 동의 의사를 표시하는 것
5다음 중 트루타입(TrueType) 글꼴에 대한 설명으로 틀린 것은? 자주
  1. ①외곽선(윤곽선) 방식의 글꼴이다
  2. ②확대·축소해도 글자가 깨지지 않는다
  3. ③화면 표시와 인쇄 결과가 동일하다
  4. ④비트맵 방식이므로 파일 크기가 매우 작다
6유니코드(Unicode)에 대한 설명으로 옳지 않은 것은? 자주
  1. ①전 세계 모든 문자를 하나의 코드 체계로 통합한 것이다
  2. ②한글, 한자, 영문, 일본어 등 다국어를 지원한다
  3. ③한글은 완성형 방식만 수록되어 있다
  4. ④UTF-8은 유니코드의 대표적인 인코딩 방식이다
7다음 중 2벌식 자판에 대한 설명으로 올바른 것은? 자주
  1. ①초성, 중성, 종성을 각각 별도 영역에 배치한다
  2. ②영문 타자기와 호환이 되지 않는다
  3. ③키 수가 많아 빠른 타이핑에 불리하다
  4. ④자음은 왼쪽, 모음은 오른쪽에 배치한다
8OLE(Object Linking and Embedding)에서 '연결(Linking)'의 특징으로 올바른 것은? 자주
  1. ①원본 파일이 삭제되어도 문서에 포함된 내용은 유지된다
  2. ②원본 파일이 수정되면 해당 문서에도 자동으로 반영된다
  3. ③문서 파일 크기가 크게 증가한다
  4. ④원본 파일의 위치와 무관하게 독립적으로 작동한다
9다음 중 매크로(Macro)에 대한 설명으로 틀린 것은? 자주
  1. ①자주 사용하는 작업을 기록하여 자동 실행할 수 있다
  2. ②매크로 바이러스에 감염될 위험이 있다
  3. ③키매크로는 키보드 입력을 기록하여 반복 실행한다
  4. ④한 번 기록하면 수정이 불가능하다
10메일머지(Mail Merge)에 대한 설명으로 올바른 것은? 자주
  1. ①본문 양식과 데이터 파일을 결합하여 여러 문서를 한꺼번에 만드는 기능이다
  2. ②전자우편을 자동으로 암호화하는 기능이다
  3. ③받은 메일을 자동으로 분류하는 필터 기능이다
  4. ④여러 문서를 하나의 파일로 병합하는 기능이다
11각주(脚註)와 미주(尾註)에 대한 설명으로 올바른 것은? 자주
  1. ①각주는 문서의 맨 끝에, 미주는 해당 페이지 하단에 표시된다
  2. ②각주와 미주는 모두 해당 페이지 상단에 표시된다
  3. ③각주는 해당 페이지 하단에, 미주는 문서의 맨 끝에 표시된다
  4. ④각주와 미주는 기능이 완전히 동일하다
12다음 중 머리말(Header)과 꼬리말(Footer)에 대한 설명으로 틀린 것은? 자주
  1. ①머리말은 페이지 상단, 꼬리말은 페이지 하단에 반복 표시된다
  2. ②페이지 번호, 문서 제목, 날짜 등을 삽입할 수 있다
  3. ③머리말과 꼬리말은 각 페이지마다 별도로 내용을 입력해야 한다
  4. ④짝수·홀수 페이지에 서로 다른 머리말을 설정할 수 있다
13다음 중 스타일(Style)에 대한 설명으로 올바른 것은? 자주
  1. ①문서에 사용할 글꼴, 크기, 정렬 등 서식을 묶어서 이름을 붙인 것이다
  2. ②문서를 다른 형식으로 저장하는 기능이다
  3. ③문서의 맞춤법을 검사하는 기능이다
  4. ④문서에 그림을 삽입하는 기능이다
14다음 중 잉크젯 프린터에 대한 설명으로 올바르지 않은 것은? 자주
  1. ①잉크를 미세한 노즐로 분사하여 인쇄한다
  2. ②레이저 프린터보다 소음이 적다
  3. ③컬러 인쇄가 가능하며 사진 출력에 적합하다
  4. ④충격식(임팩트) 방식으로 복사 용지에도 인쇄된다
15DPI(Dots Per Inch)에 대한 설명으로 올바른 것은? 자주
  1. ①1분당 출력하는 페이지 수를 나타낸다
  2. ②1초당 출력하는 글자 수를 나타낸다
  3. ③1초당 전송하는 데이터의 양을 나타낸다
  4. ④1인치당 찍을 수 있는 점의 수로, 인쇄 해상도를 나타낸다
16다음 중 커닝(Kerning)에 대한 설명으로 올바른 것은? 자주
  1. ①글자 전체의 자간을 균일하게 조절하는 것
  2. ②특정 글자 쌍 사이의 간격을 개별적으로 조절하는 것
  3. ③줄과 줄 사이의 간격을 조절하는 것
  4. ④문단의 들여쓰기를 조절하는 것
17WYSIWYG의 의미로 올바른 것은? 자주
  1. ①여러 사용자가 동시에 문서를 편집하는 기능
  2. ②화면에 보이는 그대로 인쇄되는 것
  3. ③문서를 웹 페이지로 변환하는 기능
  4. ④문서의 버전을 관리하는 기능
18다음 중 전자문서(Electronic Document)에 대한 설명으로 틀린 것은? 자주
  1. ①종이 문서를 디지털화한 것으로, 수정과 배포가 용이하다
  2. ②EDMS(Electronic Document Management System)는 전자문서 관리 시스템이다
  3. ③전자문서는 법적 효력이 인정되지 않는다
  4. ④EDI(Electronic Data Interchange)는 기업 간 전자문서 교환 표준이다
19하이퍼텍스트(Hypertext)에 대한 설명으로 올바른 것은? 자주
  1. ①문서 내용을 암호화하는 기술이다
  2. ②텍스트에 링크를 걸어 비순차적으로 정보를 연결하는 방식이다
  3. ③문서의 글자 크기를 자동으로 조절하는 기능이다
  4. ④텍스트를 음성으로 변환하는 기술이다

22과목: PC 운영체제Q21 – Q40
21Windows에서 파일 탐색기(File Explorer)의 기능으로 올바르지 않은 것은? 자주
  1. ①운영체제의 커널(Kernel)을 직접 수정할 수 있다
  2. ②네트워크 드라이브에 연결할 수 있다
  3. ③파일의 확장자별로 실행 프로그램을 연결할 수 있다
  4. ④파일 및 폴더의 복사, 이동, 삭제를 할 수 있다
22Windows 휴지통(Recycle Bin)에 대한 설명으로 틀린 것은? 자주
  1. ①USB 메모리에서 삭제한 파일도 휴지통에 보관된다
  2. ②Shift+Delete로 삭제하면 휴지통을 거치지 않고 영구 삭제된다
  3. ③휴지통의 최대 크기는 사용자가 설정할 수 있다
  4. ④삭제된 파일을 임시로 보관하며, 복원이 가능하다
23Windows에서 파일의 속성(Attribute)에 해당하지 않는 것은? 자주
  1. ①실행(Execute)
  2. ②숨김(Hidden)
  3. ③보관(Archive)
  4. ④읽기 전용(Read-only)
24Windows 제어판(Control Panel)에서 설정할 수 없는 것은? 자주
  1. ①CPU의 클럭 속도 변경
  2. ②날짜와 시간 변경
  3. ③프로그램 제거
  4. ④프린터 추가 및 제거
25Windows 에어로(Aero) 기능에 해당하지 않는 것은? 자주
  1. ①에어로 피크(Aero Peek) — 열린 창을 투명하게 하여 바탕화면을 미리 보기
  2. ②에어로 스냅(Aero Snap) — 창을 화면 가장자리로 끌어 자동 정렬
  3. ③에어로 블래스트(Aero Blast) — 모든 창을 동시에 최대화
  4. ④에어로 쉐이크(Aero Shake) — 하나의 창을 흔들면 나머지 창이 최소화
26Windows에서 작업 표시줄(Taskbar)에 대한 설명으로 틀린 것은? 자주
  1. ①실행 중인 프로그램을 아이콘으로 표시한다
  2. ②알림 영역(시스템 트레이)에서 시계와 알림을 확인할 수 있다
  3. ③작업 표시줄의 위치를 화면 상·하·좌·우로 변경할 수 있다
  4. ④작업 표시줄에서 프로그램을 직접 설치할 수 있다
27Windows에서 Ctrl+Z 단축키의 기능으로 올바른 것은? 자주
  1. ①선택한 항목을 복사한다
  2. ②마지막 작업을 실행 취소(Undo)한다
  3. ③모든 항목을 선택한다
  4. ④파일을 저장한다
28Windows에서 DHCP(Dynamic Host Configuration Protocol)의 역할로 올바른 것은? 자주
  1. ①도메인 이름을 IP 주소로 변환한다
  2. ②네트워크에 연결된 컴퓨터에 IP 주소를 자동으로 할당한다
  3. ③파일을 암호화하여 전송한다
  4. ④네트워크 트래픽을 감시한다
29Windows 방화벽(Firewall)에 대한 설명으로 올바른 것은? 자주
  1. ①컴퓨터의 온도를 감지하여 과열을 방지한다
  2. ②바이러스를 검사하고 치료하는 프로그램이다
  3. ③외부 네트워크와 내부 네트워크 사이에서 허가되지 않은 접근을 차단한다
  4. ④하드디스크의 불량 섹터를 복구한다
30Windows의 부팅 과정 순서로 올바른 것은? 자주
  1. ①POST → BIOS → 부트로더 → 운영체제 로드
  2. ②운영체제 로드 → BIOS → POST → 부트로더
  3. ③부트로더 → POST → BIOS → 운영체제 로드
  4. ④BIOS → 운영체제 로드 → POST → 부트로더
31Windows의 안전 모드(Safe Mode)에 대한 설명으로 틀린 것은? 자주
  1. ①최소한의 드라이버와 서비스만으로 Windows를 시작한다
  2. ②시스템 문제 해결이나 바이러스 제거에 유용하다
  3. ③안전 모드에서는 네트워크 연결이 항상 지원된다
  4. ④화면 해상도가 낮게 표시되는 것이 일반적이다
32Windows에서 최대 절전 모드(Hibernate)에 대한 설명으로 올바른 것은? 자주
  1. ①메모리의 내용을 유지하면서 전력을 최소한으로 공급한다
  2. ②모니터만 끄고 나머지는 정상 작동한다
  3. ③메모리의 내용을 하드디스크에 저장한 후 전원을 완전히 끈다
  4. ④실행 중인 프로그램을 모두 종료한 후 전원을 끈다
33Windows 작업 관리자(Task Manager)에서 확인할 수 없는 것은? 자주
  1. ①현재 실행 중인 프로세스 목록
  2. ②CPU 및 메모리 사용률
  3. ③네트워크 사용 현황
  4. ④하드디스크의 물리적 회전 속도(RPM)
34NTFS 파일 시스템이 FAT32에 비해 가지는 장점으로 틀린 것은? 자주
  1. ①파일 및 폴더에 개별 보안 권한을 설정할 수 있다
  2. ②파일 압축 및 암호화(EFS)를 지원한다
  3. ③4GB 이상의 파일을 저장할 수 있다
  4. ④모든 운영체제에서 읽기·쓰기가 가능하다
35Windows 시스템 복원(System Restore)에 대한 설명으로 올바른 것은? 자주
  1. ①삭제된 개인 파일(문서, 사진)을 복구할 수 있다
  2. ②복원 지점(Restore Point)을 기준으로 시스템 설정을 이전 상태로 되돌린다
  3. ③하드디스크를 포맷하고 운영체제를 재설치한다
  4. ④바이러스에 감염된 파일을 자동으로 치료한다
36Windows 레지스트리(Registry)에 대한 설명으로 올바른 것은? 자주
  1. ①사용자의 개인 파일을 저장하는 폴더이다
  2. ②운영체제와 프로그램의 설정 정보를 저장하는 데이터베이스이다
  3. ③인터넷 검색 기록을 저장하는 파일이다
  4. ④시스템 업데이트 파일을 보관하는 폴더이다
37Windows의 UAC(User Account Control, 사용자 계정 컨트롤)에 대한 설명으로 올바른 것은? 자주
  1. ①사용자의 파일을 자동으로 백업하는 기능이다
  2. ②시스템에 중요한 변경이 발생할 때 사용자에게 확인을 요청하는 보안 기능이다
