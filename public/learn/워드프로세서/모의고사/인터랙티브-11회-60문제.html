11과목: 워드프로세싱 용어 및 기능Q1 – Q20
1다음 중 공문서의 결재 방식에 대한 설명으로 옳지 않은 것은? 매회
  1. ①협조는 결재권자를 대신하여 최종 결재를 완료하는 것이다
  2. ②대결은 결재권자가 부재 시 그 직무를 대리하는 자가 결재하며, 원 결재권자가 사후 확인한다
  3. ③후결은 급한 문서를 먼저 시행한 후 나중에 결재를 받는 것이다
  4. ④전결은 결재권자가 하위 직위자에게 결재권을 위임하여 처리하는 것이다
2다음 중 공문서 작성 규칙에 대한 설명으로 옳지 않은 것은? 매회
  1. ①공문서는 한글 맞춤법에 따라 가로 방향으로 작성한다
  2. ②표 서식 중간까지만 작성된 경우 마지막 작성 칸 다음 줄에 '끝'을 표시한다
  3. ③날짜는 연·월·일을 온점(.)으로 구분하여 표시한다
  4. ④금액은 숫자와 한글을 병기하여 표시한다
3다음 중 교정부호에 대한 설명으로 옳지 않은 것은? 매회
  1. ①교정부호는 문서 내용과 혼동되지 않도록 다른 색으로 표기한다
  2. ②한번 교정된 부분도 필요하면 다시 교정할 수 있다
  3. ③자리바꿈(전위) 부호는 글자나 단어를 삭제할 때 사용한다
  4. ④여러 교정부호를 사용할 때는 겹치지 않도록 해야 한다
4다음 중 워드프로세서 기본 용어에 대한 설명으로 옳지 않은 것은? 자주
  1. ①색인(Index)은 중요 내용을 문서 맨 뒤에 용어와 쪽번호를 오름차순으로 정리한 것이다
  2. ②목차(TOC)는 문서 맨 앞에 제목과 쪽번호를 정리한 것이다
  3. ③PDF 형식은 기종이나 소프트웨어에 관계없이 호환되는 문서 형식이다
  4. ④한 부씩 찍기(Collate)를 미선택하면 1-2-3, 1-2-3 순서로 인쇄된다
5다음 중 프린터에 대한 설명으로 옳지 않은 것은? 자주
  1. ①도트 매트릭스 프린터는 레이저 프린터보다 인쇄 속도가 빠르고 소음이 적다
  2. ②PPM은 1분당 출력되는 페이지 수를 나타내는 인쇄 속도 단위이다
  3. ③플로터(Plotter)는 도면이나 설계도 등 대형 출력에 적합한 장치이다
  4. ④DPI는 1인치 안에 찍히는 점의 수로 해상도를 나타내는 단위이다
6다음 중 글꼴(폰트)에 대한 설명으로 옳지 않은 것은? 매회
  1. ①비트맵 폰트는 점(픽셀)의 집합으로 글자를 표현하며 확대 시 계단 현상이 발생한다
  2. ②오픈타입 폰트는 Apple과 Microsoft가 공동 개발한 크로스플랫폼 폰트이다
  3. ③트루타입 폰트는 Apple과 Microsoft가 공동 개발한 벡터 방식의 폰트이다
  4. ④포스트스크립트는 Adobe가 개발한 페이지 기술 언어(PDL)이다
7다음 중 한글 코드 체계에 대한 설명으로 옳지 않은 것은? 매회
  1. ①조합형은 초·중·종성 각각에 코드를 부여하여 모든 한글을 표현할 수 있다
  2. ②유니코드는 완성형 한글 11,172자와 한글 자모 240자를 포함한다
  3. ③완성형 코드는 조합형보다 표현 가능한 한글 수가 더 많다
  4. ④완성형(KS X 1001)은 완성된 글자에 코드를 부여하여 2,350자를 지원한다
8다음 중 워드프로세서의 편집 기능에 대한 설명으로 옳지 않은 것은? 자주
  1. ①찾기 기능에서 와일드카드 문자(*, ?)를 사용하여 검색할 수 있다
  2. ②블록을 지정한 후 찾기/바꾸기를 실행하면 해당 영역만 적용된다
  3. ③금칙처리는 줄의 맨 앞이나 맨 끝에 오면 안 되는 문자의 위치를 자동 조정한다
  4. ④교정 부호나 메모의 내용을 지정하여 검색할 수 있다
9다음 중 텍스트 표시 기능에 대한 설명으로 옳지 않은 것은? 자주
  1. ①자간은 글자와 글자 사이의 가로 간격을 의미한다
  2. ②장평은 글자의 세로 높이 비율을 조정하는 기능이다
  3. ③행간은 줄과 줄 사이의 세로 간격을 의미한다
  4. ④커닝은 특정 글자 조합에서 글자 간격을 미세하게 조정하는 기능이다
10다음 중 각주·미주·머리말에 대한 설명으로 옳지 않은 것은? 매회
  1. ①머리말에는 숫자, 문자, 그림은 입력 가능하지만 표는 입력할 수 없다
  2. ②각주는 해당 페이지 하단에 설명을 표시한다
  3. ③미주는 문서의 마지막 페이지에 모아서 표시한다
  4. ④머리말과 꼬리말은 짝수쪽·홀수쪽을 다르게 설정할 수 있다
11다음 중 전자출판(DTP) 관련 용어에 대한 설명으로 옳지 않은 것은? 자주
  1. ①WYSIWYG는 화면에 표시되는 것과 인쇄 결과가 동일한 것을 의미한다
  2. ②OPI는 저해상도 이미지로 편집 후 출력 시 고해상도로 자동 대체하는 기술이다
  3. ③디더링은 이미지의 채도와 명암을 조절하는 작업이다
  4. ④RIP는 벡터나 포스트스크립트 데이터를 비트맵으로 변환하여 출력하는 장치이다
12다음 중 OLE(Object Linking and Embedding)에 대한 설명으로 옳지 않은 것은? 매회
  1. ①연결(Linking)은 원본 파일이 수정되면 문서에도 자동 반영된다
  2. ②포함(Embedding)은 원본 파일의 복사본이 문서에 내장된다
  3. ③다른 프로그램에서 만든 객체를 워드 문서에 삽입하는 기술이다
  4. ④포함(Embedding)으로 삽입한 객체는 원본 파일 수정 시 문서에도 자동 반영된다
13다음 중 매크로에 대한 설명으로 옳지 않은 것은? 자주
  1. ①마우스 동작을 포함한 모든 동작을 기억하는 것을 키 매크로라 한다
  2. ②작성한 매크로는 별도 파일로 저장하거나 편집할 수 있다
  3. ③반복 작업의 자동화에 효과적이다
  4. ④일련의 작업 순서를 기록하여 필요할 때 한 번에 재실행할 수 있다
14다음 중 스타일과 페이지 설정에 대한 설명으로 옳지 않은 것은? 자주
  1. ①스타일을 수정하면 해당 스타일이 적용된 모든 부분이 자동으로 변경된다
  2. ②구역(Section)을 나누면 페이지별로 다른 설정을 적용할 수 있다
  3. ③스타일을 수정하면 해당 스타일 부분만 수동으로 하나씩 변경해야 한다
  4. ④템플릿은 반복 사용하는 문서 형식을 미리 저장한 것이다
15다음 중 하이퍼텍스트와 DRM에 대한 설명으로 옳지 않은 것은? 자주
  1. ①하이퍼텍스트는 링크를 통해 문서 간 비선형적으로 이동하는 기능이다
  2. ②DRM은 디지털 콘텐츠의 빠른 검색과 분류를 돕는 기술이다
  3. ③HTML은 하이퍼텍스트를 기반으로 한 마크업 언어이다
  4. ④하이퍼미디어는 하이퍼텍스트에 이미지, 동영상, 음성 등을 포함한 개념이다
16다음 중 문서관리와 파일링에 대한 설명으로 옳지 않은 것은? 매회
  1. ①문서관리는 문서를 산출한 업무와 연계하여 이루어지는 것이 바람직하다
  2. ②EDI는 기업 간 상거래 서류를 컴퓨터 간 직접 교환하는 시스템이다
  3. ③전자문서의 효력은 수신자가 관리하는 전자시스템에 입력되었을 때 발생한다
  4. ④파일링 시스템 도입 시 기록 활용 비용이 증가한다
17다음 중 논리 전개 방식에 대한 설명으로 옳지 않은 것은? 자주
  1. ①두괄식은 결론을 처음에 제시하고 이후 설명을 전개하는 방식이다
  2. ②미괄식은 서론에서 본론을 거쳐 결론을 끝에 제시하는 방식이다
  3. ③양괄식은 처음과 끝에 모두 결론을 제시하는 방식이다
  4. ④두괄식은 결론을 문서의 마지막에 제시하는 방식이다
18다음 중 보고서 작성에 대한 설명으로 옳지 않은 것은? 매회
  1. ①보고서는 대항목에서 소항목으로 점진적으로 작성하는 것이 올바르다
  2. ②사실과 의견을 명확히 구분하여 기술해야 한다
  3. ③보고서는 소항목에서 대항목 순으로 작성하는 것이 올바르다
  4. ④표와 그림을 활용하여 시각 효과를 높이는 것이 좋다
19다음 중 메일머지(Mail Merge)에 대한 설명으로 옳지 않은 것은? 자주
  1. ①하나의 문서를 한 사람에게만 개별 발송하는 기능이다
  2. ②데이터 파일(주소록)과 폼 파일(편지 양식)을 결합하여 문서를 생성한다
  3. ③동일 내용의 편지를 여러 사람에게 각자 이름과 주소를 맞추어 발송할 수 있다
  4. ④명칭 파일과 양식 파일이 필요하다
20다음 중 문서 저장에 대한 설명으로 옳지 않은 것은? 매회
  1. ①저장 시 암호를 지정하면 타인의 열람을 제한할 수 있다
  2. ②다른 이름으로 저장하면 기존 파일은 삭제된다
  3. ③저장 대화상자에서 새 폴더를 만들거나 삭제할 수 있다
  4. ④파일의 저장 위치, 이름, 형식을 변경할 수 있다
22과목: PC 운영체제Q21 – Q40
21다음 중 Windows 휴지통에 대한 설명으로 옳지 않은 것은? 매회
  1. ①네트워크 드라이브의 파일을 삭제하면 휴지통으로 이동된다
  2. ②삭제된 파일은 휴지통에 임시 보관되며 복원하면 원래 위치로 돌아간다
  3. ③Shift+Delete로 삭제하면 휴지통을 거치지 않고 완전 삭제된다
  4. ④휴지통에서 특정 파일만 선택하여 삭제할 수 있다
22다음 중 파일 관리에 대한 설명으로 옳지 않은 것은? 자주
  1. ①Ctrl+C와 Ctrl+V로 파일을 복사할 수 있다
  2. ②현재 편집 중인 파일이 포함된 폴더도 삭제할 수 있다
  3. ③F2 키로 파일 이름을 바꿀 수 있다
  4. ④읽기 전용 속성은 파일 내용을 변경할 수 없게 한다
23다음 중 Windows 제어판에 대한 설명으로 옳지 않은 것은? 자주
  1. ①프로그램 및 기능에서 프로그램을 설치하거나 제거할 수 있다
  2. ②전원 옵션에서 절전 모드와 최대 절전 설정을 변경할 수 있다
  3. ③디스크 정리에서 다운로드한 프로그램 파일은 삭제할 수 없다
  4. ④장치 및 프린터에서 프린터나 외부 장치를 추가하고 관리할 수 있다
24다음 중 Windows 에어로(Aero) 기능에 대한 설명으로 옳지 않은 것은? 매회
  1. ①에어로 스냅은 창을 화면 가장자리로 드래그하면 크기가 자동 조정되는 기능이다
  2. ②에어로 셰이크는 창을 흔들면 다른 모든 창이 최소화되는 기능이다
  3. ③에어로 피크는 작업표시줄 아이콘에 마우스를 가리키면 썸네일 미리보기가 나타나는 기능이다
  4. ④에어로 전환 3D는 점프 목록과 프로그램 단추 고정을 통해 빠르게 실행하는 기능이다
25다음 중 Windows 바탕화면과 도움말에 대한 설명으로 옳지 않은 것은? 매회
  1. ①바탕화면 우클릭으로 새 폴더를 만들 수 있다
  2. ②바탕화면 우클릭으로 화면 해상도를 변경할 수 있다
  3. ③도움말에서 새로운 기술 내용을 추가하거나 수정할 수 있다
  4. ④도움말은 하이퍼텍스트 기능으로 관련 항목을 탐색할 수 있다
26다음 중 Windows 네트워크 설정에 대한 설명으로 옳지 않은 것은? 자주
  1. ①IP 주소 확인 명령어는 ipconfig이다
  2. ②방화벽을 켜면 모든 인터넷 연결이 완전히 차단된다
  3. ③DHCP 방식은 라우터가 자동으로 IP를 할당하여 설정이 편리하다
  4. ④공유 폴더의 이름은 원래 폴더 이름과 다르게 설정할 수 있다
27다음 중 Windows 부팅 옵션에 대한 설명으로 옳지 않은 것은? 매회
  1. ①안전 모드는 네트워크 서비스를 포함하여 부팅하는 모드이다
  2. ②안전 모드는 최소 드라이버만으로 부팅하며 네트워크 서비스가 포함되지 않는다
  3. ③부팅 로깅은 부팅 과정을 ntbtlog.txt 파일에 기록하는 모드이다
  4. ④저해상도 비디오 모드는 640×480 해상도로 부팅하는 모드이다
28다음 중 Windows 종료 옵션에 대한 설명으로 옳지 않은 것은? 매회
  1. ①절전(Sleep) 모드는 현재 상태를 RAM에 저장하여 빠르게 재개할 수 있다
  2. ②최대 절전(Hibernate) 모드는 하드디스크에 상태를 저장하며 전원이 완전히 차단된다

58다음 중 ICT 신기술에 대한 설명으로 옳지 않은 것은? 매회
  1. ①SaaS는 소프트웨어 앱을 서비스로 제공하는 클라우드 모델이다
  2. ②AR(증강현실)은 현실 위에 디지털 정보를 겹쳐 보여주는 기술이다
  3. ③블록체인은 중앙 서버에 데이터를 집중 저장하여 보안을 강화하는 기술이다
  4. ④VR(가상현실)은 완전히 디지털로 구현된 가상 환경에서 경험하는 기술이다
59다음 중 빅데이터와 저작권에 대한 설명으로 옳지 않은 것은? 자주
  1. ①빅데이터의 3V는 Volume(대용량), Velocity(고속), Variety(다양성)이다
  2. ②저작권 보호 기간은 한국 기준 창작자 사후 70년이다
  3. ③아이디어 자체는 저작권 보호 대상이 아니며 표현된 창작물만 보호된다
  4. ④빅데이터의 3V에는 Veracity(정확성)가 포함된다
60다음 중 BIOS와 CMOS에 대한 설명으로 옳지 않은 것은? 매회
  1. ①BIOS는 ROM에 저장되는 펌웨어로 POST(자가 진단)를 수행한다
  2. ②CMOS는 ROM에 저장되므로 배터리 없이도 영구적으로 설정이 유지된다
  3. ③CMOS는 BIOS 설정값(날짜, 시간, 부팅 순서 등)을 저장하는 메모리 칩이다
  4. ④CMOS는 배터리로 전원을 공급받아 전원이 꺼져도 설정이 유지된다
