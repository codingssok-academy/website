1다음 중 공문서의 '끝' 표시에 대한 설명으로 옳지 않은 것은? 매회
  1. ①본문 내용의 마지막 글자 다음에 한 칸 띄고 '끝'을 표시한다
  2. ②첨부물이 있는 경우 붙임 표시 다음 줄에 '끝'을 표시한다
  3. ③본문이 표로 끝나면 표 아래 왼쪽에 '끝'을 표시한다
  4. ④본문이 오른쪽 한계선에 닿으면 다음 줄 오른쪽 끝에 '끝'을 표시한다
2다음 중 전자출판(DTP)에 대한 설명으로 옳은 것은? 자주
  1. ①DTP는 Desktop Transfer Protocol의 약자이다
  2. ②전문 인쇄소 없이도 고품질 인쇄물 제작이 가능하다
  3. ③비트맵 이미지는 사용할 수 없고 벡터만 지원한다
  4. ④출판물의 배포만 담당하며 편집 기능은 없다
3다음 중 교정부호에 대한 설명으로 옳지 않은 것은? 매회
  1. ①∨ 기호는 한 글자만큼 띄우라는 표시이다
  2. ②○ 안에 숫자를 쓰면 그만큼 띄우라는 뜻이다
  3. ③ℓ 기호는 줄을 바꾸라는 표시이다
  4. ④⌒ 기호는 글자를 삭제하라는 표시이다
4다음 중 머리글과 꼬리글에 대한 설명으로 옳은 것은? 매회
  1. ①머리글은 페이지 하단에, 꼬리글은 페이지 상단에 표시된다
  2. ②머리글과 꼬리글은 첫 페이지에만 삽입할 수 있다
  3. ③머리글과 꼬리글에는 페이지 번호를 삽입할 수 있다
  4. ④머리글을 설정하면 꼬리글은 자동으로 비활성화된다
5다음 중 문서 보안 등급에 대한 설명으로 옳지 않은 것은? 자주
  1. ①4급 비밀은 일반 행정 문서에 부여하는 등급이다
  2. ②대외비는 비밀에 해당하지 않으나 외부 유출을 금지한다
  3. ③1급 비밀이 가장 높은 보안 등급이다
  4. ④비밀 등급은 1급, 2급, 3급으로 분류된다
6다음 중 매크로(Macro)에 대한 설명으로 옳은 것은? 매회
  1. ①매크로는 한 번 기록하면 수정할 수 없다
  2. ②매크로 바이러스는 실행 파일에만 감염된다
  3. ③반복 작업을 자동화하여 업무 효율을 높인다
  4. ④매크로는 운영체제 수준에서만 동작한다
7다음 중 각주(脚註)와 미주(尾註)에 대한 설명으로 옳지 않은 것은? 매회
  1. ①각주는 해당 페이지 하단에 표시된다
  2. ②미주는 문서의 맨 끝에 모아서 표시된다
  3. ③각주와 미주 모두 본문의 보충 설명에 사용된다
  4. ④각주 번호는 문서 전체에서 페이지마다 1번부터 다시 시작해야 한다
8다음 중 글꼴(Font)에 대한 설명으로 옳은 것은? 자주
  1. ①트루타입 글꼴은 화면용으로만 사용되며 인쇄할 수 없다
  2. ②비트맵 글꼴은 확대해도 깨지지 않는 장점이 있다
  3. ③오픈타입 글꼴은 트루타입과 포스트스크립트의 장점을 결합한 형식이다
  4. ④포스트스크립트 글꼴은 무료로만 배포된다
9다음 중 WYSIWYG에 대한 설명으로 옳지 않은 것은? 자주
  1. ①WYSIWYG 환경에서는 별도의 인쇄 미리보기가 필요 없으므로 해당 기능이 제공되지 않는다
  2. ②화면에 보이는 대로 인쇄 결과가 출력된다
  3. ③대부분의 현대 워드프로세서가 지원하는 기능이다
  4. ④What You See Is What You Get의 약자이다
10다음 중 전자문서의 장점으로 옳지 않은 것은? 자주
  1. ①전자문서는 위·변조가 불가능하다
  2. ②검색과 수정이 용이하다
  3. ③네트워크를 통한 공유가 가능하다
  4. ④보관 공간이 절약된다
11다음 중 공문서의 기안에 대한 설명으로 옳은 것은? 매회
  1. ①기안문에는 반드시 발신명의를 표시해야 한다
  2. ②기안은 업무를 처리하기 위해 문서를 작성하는 행위이다
  3. ③기안문의 본문은 한자로만 작성해야 한다
  4. ④기안자는 결재 권한이 없으므로 서명할 필요가 없다
12다음 중 탭(Tab) 기능에 대한 설명으로 옳지 않은 것은? 자주
  1. ①왼쪽 탭은 탭 위치에서 오른쪽으로 텍스트가 정렬된다
  2. ②오른쪽 탭은 탭 위치에서 왼쪽으로 텍스트가 정렬된다
  3. ③가운데 탭은 탭 위치를 중심으로 텍스트가 정렬된다
  4. ④소수점 탭은 문자열의 첫 글자를 기준으로 정렬한다
13다음 중 인쇄 관련 용어에 대한 설명으로 옳은 것은? 자주
  1. ①래스터 이미지는 확대해도 품질이 저하되지 않는다
  2. ②해상도(DPI)는 1인치당 점의 수를 나타낸다
  3. ③벡터 이미지는 사진 표현에 가장 적합하다
  4. ④포인트(pt)는 글꼴 크기가 아니라 용지 크기의 단위이다
14다음 중 워드프로세서의 편집 기능에 대한 설명으로 옳지 않은 것은? 매회
  1. ①찾기/바꾸기 기능으로 특정 문자열을 일괄 변경할 수 있다
  2. ②실행 취소(Undo)는 직전 작업을 되돌리는 기능이다
  3. ③블록 지정 후 Delete 키를 누르면 블록이 삭제된다
  4. ④상용구 기능은 자주 쓰는 문장을 등록하여 단축키로 입력하는 기능이나, 한 번 등록하면 수정이 불가능하다
15다음 중 전결과 대결에 대한 설명으로 옳은 것은? 매회
  1. ①전결은 상사 부재 시 차상위자가 대신 결재하는 것이다
  2. ②대결 후에는 후결을 받을 필요가 없다
  3. ③전결은 사전에 위임된 사항에 대해 하위자가 결재하는 것이다
  4. ④전결과 대결 모두 결재 후 상사에게 보고할 의무가 없다
16다음 중 문서에 그림을 삽입하는 방식에 대한 설명으로 옳지 않은 것은? 자주
  1. ①배경으로 삽입하면 그림이 본문 텍스트를 완전히 대체한다
  2. ②어울림 배치는 텍스트가 그림을 감싸는 형태로 배치된다
  3. ③글 앞으로 배치하면 그림이 텍스트 위에 겹쳐 표시된다
  4. ④문자열 취급 방식은 그림이 글자처럼 본문 흐름을 따른다
17다음 중 문서 파일 형식에 대한 설명으로 옳은 것은? 매회
  1. ①HWP는 마이크로소프트에서 만든 문서 형식이다
  2. ②PDF는 운영체제나 장치에 관계없이 동일하게 표시되는 형식이다
  3. ③RTF는 특정 프로그램에서만 열 수 있는 독점 형식이다
  4. ④TXT 파일은 서식 정보와 그림을 모두 포함할 수 있다
18다음 중 메일 머지(Mail Merge)에 대한 설명으로 옳지 않은 것은? 자주
  1. ①하나의 본문 양식에 여러 데이터를 결합하여 문서를 생성한다
  2. ②초대장, 안내문 등을 대량으로 작성할 때 유용하다
  3. ③데이터 파일에는 이름, 주소 등의 정보가 포함된다
  4. ④메일 머지는 전자우편 전송만 가능하며 인쇄 출력은 불가능하다
19다음 중 표(Table) 편집에 대한 설명으로 옳은 것은? 매회
  1. ①셀 병합은 두 개 이상의 셀을 하나로 합치는 기능이다
  2. ②표의 행 높이는 변경할 수 있으나 열 너비는 고정이다
  3. ③표 안에 다른 표를 삽입하는 것은 불가능하다
  4. ④표의 테두리 선 종류는 실선만 지원된다
20다음 중 공문서 작성 원칙에 대한 설명으로 옳지 않은 것은? 매회
  1. ①공문서의 본문은 한글로 작성함을 원칙으로 한다
  2. ②날짜 표기는 숫자로 하되 연·월·일을 마침표로 구분한다
  3. ③금액은 한글로 적고 괄호 안에 아라비아 숫자를 함께 표기할 수 있다
  4. ④수정할 때는 수정액을 사용하여 원래 내용을 완전히 지운다
22과목: PC 운영체제Q21 – Q40
21다음 중 운영체제(OS)에 대한 설명으로 옳지 않은 것은? 매회
  1. ①운영체제는 응용 프로그램의 한 종류이다
  2. ②사용자와 컴퓨터 하드웨어 간의 인터페이스 역할을 한다
  3. ③프로세스 관리, 메모리 관리, 파일 관리 등의 기능을 수행한다
  4. ④하드웨어와 소프트웨어 자원을 관리한다
22다음 중 Windows의 바로 가기 키에 대한 설명으로 옳은 것은? 매회
  1. ①Ctrl + C는 선택한 항목을 잘라내기 한다
  2. ②Ctrl + V는 클립보드의 내용을 붙여넣기 한다
  3. ③Ctrl + Z는 다시 실행(Redo) 기능이다
  4. ④Ctrl + A는 현재 파일을 저장한다
23다음 중 파일 시스템에 대한 설명으로 옳지 않은 것은? 매회
  1. ①FAT32는 NTFS보다 더 큰 단일 파일을 저장할 수 있다
  2. ②NTFS는 파일 암호화와 압축 기능을 지원한다
  3. ③NTFS는 FAT32보다 보안 기능이 우수하다
  4. ④FAT32는 최대 4GB까지의 단일 파일을 지원한다
24다음 중 Windows 제어판의 기능에 대한 설명으로 옳은 것은? 자주
  1. ①프로그램 추가/제거를 통해 소프트웨어를 설치하거나 제거할 수 있다
  2. ②제어판에서는 하드디스크를 물리적으로 교체할 수 있다
  3. ③제어판의 디스플레이 설정은 모니터 하드웨어를 직접 변경한다
  4. ④제어판에서만 네트워크 설정이 가능하며 설정 앱에서는 불가능하다
25다음 중 Windows 레지스트리에 대한 설명으로 옳지 않은 것은? 자주
  1. ①레지스트리는 텍스트 파일 형태로 저장되므로 메모장으로 편집하는 것이 권장된다
  2. ②regedit 명령으로 레지스트리 편집기를 실행할 수 있다
  3. ③레지스트리를 잘못 수정하면 시스템이 불안정해질 수 있다
  4. ④시스템 구성 정보, 사용자 설정 등을 저장하는 데이터베이스이다
26다음 중 Windows 작업 관리자에 대한 설명으로 옳은 것은? 매회
  1. ①Ctrl + Shift + Esc 키로 직접 실행할 수 있다
  2. ②실행 중인 프로세스를 확인할 수 있으나 종료는 불가능하다
  3. ③CPU 사용률은 확인할 수 있으나 메모리 사용률은 표시되지 않는다
  4. ④작업 관리자는 관리자 권한이 없으면 실행할 수 없다
27다음 중 디스크 관리에 대한 설명으로 옳지 않은 것은? 자주
  1. ①디스크 조각 모음은 분산된 파일 조각을 연속 배치하여 성능을 향상시킨다
  2. ②SSD에서는 디스크 조각 모음을 자주 실행해야 성능이 향상된다
  3. ③포맷은 디스크에 파일 시스템을 생성하는 작업이다
  4. ④파티션은 하나의 물리적 디스크를 논리적으로 분할하는 것이다
28다음 중 IP 주소에 대한 설명으로 옳은 것은? 매회
  1. ①IPv4 주소는 128비트로 구성된다
  2. ②IPv6는 IPv4의 주소 부족 문제를 해결하기 위해 개발되었다
  3. ③동일 네트워크에서 같은 IP 주소를 여러 장치가 사용할 수 있다
  4. ④IP 주소는 물리적 주소(MAC 주소)와 동일한 개념이다
29다음 중 Windows의 폴더 옵션에 대한 설명으로 옳지 않은 것은? 자주
  1. ①폴더 옵션에서 파일의 내용을 직접 편집할 수 있다
  2. ②알려진 파일 형식의 확장명을 표시하거나 숨길 수 있다
  3. ③폴더를 열 때 새 창으로 열지 같은 창에서 열지 설정할 수 있다
  4. ④숨김 파일 및 폴더를 표시하거나 숨길 수 있다
30다음 중 Windows의 바로 가기 아이콘에 대한 설명으로 옳은 것은? 매회
  1. ①바로 가기를 삭제하면 원본 파일도 함께 삭제된다
  2. ②바로 가기 아이콘에는 왼쪽 아래에 화살표 표시가 있다
  3. ③바로 가기는 원본 파일과 동일한 크기의 저장 공간을 차지한다
  4. ④바로 가기는 폴더에만 만들 수 있으며 파일에는 만들 수 없다
31다음 중 Windows 방화벽에 대한 설명으로 옳지 않은 것은? 자주
  1. ①외부에서 들어오는 네트워크 연결을 차단할 수 있다
  2. ②특정 프로그램의 네트워크 접근을 허용하거나 차단할 수 있다
  3. ③인바운드 규칙과 아웃바운드 규칙을 설정할 수 있다
  4. ④방화벽을 설정하면 바이러스가 완전히 제거된다
32다음 중 멀티태스킹(Multitasking)에 대한 설명으로 옳은 것은? 매회
  1. ①하나의 CPU가 여러 작업을 동시에 처리하는 것처럼 보이게 하는 기능이다
