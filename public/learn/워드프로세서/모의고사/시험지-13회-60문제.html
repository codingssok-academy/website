  3. ③교정부호는 반드시 연필로만 작성해야 한다
  4. ④교정부호는 원고와 같은 색의 필기구로 작성해야 한다
2다음 중 공문서의 용지 사용 방향에 대한 설명으로 옳은 것은? 매회
  1. ①공문서는 가로로 작성하는 것이 원칙이다
  2. ②공문서는 세로로 작성하는 것이 원칙이다
  3. ③공문서는 용지 방향에 제한이 없다
  4. ④공문서는 세로 작성이 원칙이며, 특별한 사유가 있을 때만 가로 사용이 가능하다
3다음 중 전결과 대결에 대한 설명으로 올바른 것은? 매회
  1. ①전결은 결재권자가 출장 중일 때 그 직무를 대신 처리하는 것이다
  2. ②대결은 결재권자가 위임전결규정에 따라 하위자에게 결재 권한을 넘기는 것이다
  3. ③전결은 결재권자가 위임전결규정에 따라 결재 권한을 하위자에게 위임하는 것이다
  4. ④전결과 대결은 완전히 동일한 개념이다

  1. ①화면에서는 매끄럽지만 인쇄 시 계단 현상이 발생한다
  2. ②비트맵 글꼴의 일종으로 확대하면 깨진다
  3. ③윤곽선(외곽선) 글꼴의 일종으로 확대해도 계단 현상이 없다
  4. ④프린터 전용 글꼴로 화면에서는 표시되지 않는다
5다음 중 OLE에서 '연결(Linking)'의 특징으로 옳은 것은? 매회
  1. ①원본 파일이 삭제되어도 삽입된 객체는 유지된다
  2. ②문서 파일의 크기가 크게 증가한다
  3. ③원본 파일과 완전히 독립적으로 동작한다
  4. ④원본 파일을 수정하면 삽입된 문서의 객체도 자동 갱신된다
6다음 중 유니코드(Unicode)에 대한 설명으로 올바른 것은? 매회
  1. ①한글 전용 문자 코드 체계이다
  2. ②각 문자를 1바이트로 표현하여 256자까지 지원한다
  3. ③각 문자를 2바이트(16비트)로 표현하여 전 세계 문자를 통합 지원한다
  4. ④ASCII 코드와 동일한 체계이다
7다음 중 완성형 코드에 대한 설명으로 옳은 것은? 매회
  1. ①완성된 글자 하나하나에 코드를 부여하므로 표현 불가능한 글자가 있을 수 있다
  2. ②한글의 자음과 모음을 조합하여 모든 한글을 표현할 수 있다
  3. ③조합형보다 더 많은 한글을 표현할 수 있다
  4. ④유니코드와 완전히 동일한 방식이다
8다음 중 키 매크로에 대한 설명으로 올바른 것은? 매회
  1. ①키 매크로는 키보드 입력과 마우스 동작 모두를 기록할 수 있다
  2. ②매크로는 운영체제에서만 사용할 수 있는 기능이다
  3. ③매크로는 한 번 실행하면 수정할 수 없다
  4. ④키 매크로는 키보드 입력만 기록하며, 마우스 동작은 기록하지 않는다
9다음 중 색인(Index)에 대한 설명으로 올바른 것은? 매회
  1. ①색인은 특정 용어가 등장하는 페이지 번호를 모아놓은 것으로, 문서의 맨 뒤에 삽입된다
  2. ②색인은 문서의 맨 앞부분에 삽입된다
  3. ③색인과 목차는 완전히 동일한 기능이다
  4. ④색인은 문서의 중간에만 삽입할 수 있다
10다음 중 장평에 대한 설명으로 올바른 것은? 매회
  1. ①장평은 글자의 세로 비율을 조절하는 기능이다
  2. ②장평은 글자 간의 간격을 조절하는 기능이다
  3. ③장평은 글자의 가로 비율을 조절하는 기능이다
  4. ④장평은 줄과 줄 사이의 간격을 조절하는 기능이다
11다음 중 전자문서의 발신 시점으로 올바른 것은? 매회
  1. ①수신자의 컴퓨터에 도달한 때
  2. ②작성자가 전송 버튼을 누른 때
  3. ③수신자가 문서를 열람한 때
  4. ④송신자의 컴퓨터를 떠난 때

  3. ③이미지에서 특정 색상만 추출하는 기법이다
  4. ④제한된 색상으로 중간색을 표현하기 위해 서로 다른 색의 점을 혼합 배치하는 기법이다

  1. ①프린터의 해상도를 나타내는 단위이다

  3. ③머리말은 페이지 상단, 꼬리말은 페이지 하단에 반복 출력된다
  4. ④머리말과 꼬리말은 화면에서만 보이고 인쇄되지 않는다
15다음 중 WYSIWYG의 의미로 올바른 것은? 자주
  1. ①문서를 인터넷으로 전송하는 기술이다
  2. ②화면에 보이는 대로 인쇄되는 기능이다
  3. ③문서를 암호화하여 보안을 유지하는 기능이다
  4. ④여러 사용자가 동시에 문서를 편집하는 기능이다

18다음 중 각주(Footnote)에 대한 설명으로 올바른 것은? 자주

  4. ④각주와 미주는 동일한 위치에 표시된다
19다음 중 들여쓰기에 대한 설명으로 올바른 것은? 자주
  1. ①들여쓰기는 문단의 왼쪽 시작 위치를 안쪽으로 이동시키는 것이다

  4. ④들여쓰기는 오른쪽 여백에만 적용된다

  1. ①문서를 순차적으로만 읽을 수 있는 형태이다
  2. ②특정 단어를 클릭하면 관련 문서로 이동할 수 있는 비순차적 구조이다
  3. ③문서를 암호화하여 저장하는 기술이다
  4. ④문서의 인쇄 품질을 높이는 기술이다
22과목: PC 운영체제Q21 – Q40
21다음 중 Windows에서 휴지통에 대한 설명으로 올바른 것은? 매회
  1. ①네트워크 드라이브에서 삭제한 파일도 휴지통에 저장된다
  2. ②USB 메모리에서 삭제한 파일은 휴지통에 저장된다
  3. ③CD-ROM에서 삭제한 파일도 휴지통에 저장된다
  4. ④로컬 하드디스크에서 삭제한 파일만 휴지통에 저장된다
22다음 중 Windows의 작업 표시줄에 대한 설명으로 올바른 것은? 매회
  1. ①작업 표시줄은 화면의 최대 1/2까지 크기 조절 가능하다
  2. ②작업 표시줄은 크기를 조절할 수 없다
  3. ③작업 표시줄은 화면의 최대 1/4까지 크기 조절 가능하다
  4. ④작업 표시줄은 상하좌우 배치 가능하며, 최대 1/2까지 조절 가능하다
23다음 중 안전 모드(Safe Mode)에 대한 설명으로 올바른 것은? 매회
  1. ①안전 모드에서는 네트워크 연결을 절대 사용할 수 없다
  2. ②안전 모드에서는 모든 프로그램이 정상 실행된다
  3. ③안전 모드는 일반 모드보다 더 많은 기능을 제공한다
  4. ④최소한의 드라이버만 로드하며, '네트워크 사용 안전 모드'도 있다
24다음 중 최대 절전 모드(Hibernate)에 대한 설명으로 올바른 것은? 매회
  1. ①현재 작업 상태를 하드디스크에 저장한 후 전원을 완전히 차단한다
  2. ②현재 작업 상태를 RAM에 유지하면서 최소 전력으로 동작한다
  3. ③컴퓨터를 재부팅하는 것과 동일하다
  4. ④최대 절전 모드에서는 데이터가 모두 삭제된다
25다음 중 FAT32에 대한 설명으로 올바른 것은? 매회
  1. ①파일/폴더에 대한 접근 권한 설정이 가능하다
  2. ②최대 4GB 이상의 단일 파일을 저장할 수 있다
  3. ③Windows에서만 사용할 수 있다
  4. ④파일/폴더에 대한 접근 권한 설정 기능이 없다
26다음 중 시스템 복원에 대한 설명으로 올바른 것은? 매회
  1. ①시스템 파일과 설정만 이전 상태로 되돌리며, 개인 파일에는 영향이 없다
  2. ②시스템 복원을 하면 개인 파일도 삭제된다
  3. ③시스템 복원은 하드디스크를 포맷하는 기능이다
  4. ④시스템 복원 후에는 되돌릴 수 없다

  4. ④레지스트리를 삭제해도 시스템에 영향이 없다

  1. ①디스크의 저장 용량을 늘려준다

  4. ④디스크를 포맷하는 기능이다
