1워드프로세싱 일반Q1 – Q20
1다음 중 교정부호(원고를 고칠 때 쓰는 약속 기호)와 공문서(관공서 공식 문서) 작성을 모두 고려한 설명으로 옳은 것은? 자주
  1. ①교정부호로 수정한 공문서는 원본(처음 문서)으로 인정되므로 재작성할 필요가 없다
  2. ②공문서에 교정부호를 사용할 때는 원고와 같은 색 펜으로 표시해야 공식적이다
  3. ③공문서의 본문을 교정할 때는 교정부호를 사용하고, 교정한 곳에 날인(도장)해야 한다
  4. ④교정부호는 사적 문서에서만 쓸 수 있고, 공문서에는 적용할 수 없다
2글꼴(폰트, 글자 모양)과 DTP(Desktop Publishing, 탁상 출판)에 대한 설명을 모두 고려할 때, 옳은 것은? 자주
  1. ①DTP에서는 비트맵 글꼴(점으로 만든 글꼴)만 사용할 수 있다
  2. ②트루타입(TrueType) 글꼴은 화면과 프린터 출력이 동일하여 DTP에 적합하다
  3. ③DTP 작업에서는 글꼴 크기를 변경할 수 없다
  4. ④벡터 글꼴(선으로 만든 글꼴)은 확대하면 깨지므로 DTP에 부적합하다
3코드 체계(컴퓨터가 문자를 숫자로 바꾸는 규칙)와 입력 방식(키보드로 글자를 넣는 방법)에 대한 설명으로 옳은 것은? 자주
  1. ①유니코드(Unicode)는 전 세계 문자를 하나의 코드로 통일한 체계이며, 2바이트 이상을 사용한다
  2. ②ASCII 코드는 한글 입력을 위해 만들어진 한국 전용 코드 체계이다
  3. ③2벌식 자판에서는 자음과 모음이 각각 별도의 키보드에 배치된다
  4. ④완성형 코드는 자음과 모음을 조합하여 글자를 만드는 방식이다
4OLE(Object Linking and Embedding, 개체 연결·삽입)와 표/셀(표의 각 칸) 기능을 모두 사용할 때의 설명으로 옳은 것은? 자주
  1. ①OLE로 삽입한 엑셀 표는 원본 파일을 수정해도 문서 안의 표는 변하지 않는다(포함 방식일 때)
  2. ②OLE 연결(Linking) 방식은 원본 파일이 삭제되어도 문서에 영향이 없다
  3. ③워드프로세서의 표에서 셀 합치기를 하면 OLE 개체가 자동으로 생성된다
  4. ④OLE는 같은 프로그램 안에서만 사용 가능하며 다른 프로그램 간에는 작동하지 않는다
5워드프로세서의 찾기(특정 내용 검색)와 바꾸기(찾은 내용을 다른 내용으로 교체) 기능에 대한 설명으로 옳지 않은 것은? 자주
  1. ①찾기 기능에서 와일드카드(*, ? 등의 특수 기호)를 사용하면 비슷한 패턴의 문자를 한 번에 검색할 수 있다
  2. ②바꾸기 기능으로 특정 서식(글꼴, 크기 등)을 다른 서식으로 일괄 변경할 수 있다
  3. ③바꾸기에서 '바꿀 내용'을 비워두면 찾은 문자를 일괄 삭제하는 효과가 있다
  4. ④찾기 기능은 영문 대·소문자를 구분할 수 없으며, 항상 대소문자를 동일하게 취급한다
6각주(脚注, 페이지 아래에 다는 설명)와 머리말(Header, 모든 페이지 위에 반복되는 내용)을 함께 사용할 때의 설명으로 옳은 것은? 자주
  1. ①머리말을 설정하면 해당 페이지의 각주는 자동으로 삭제된다
  2. ②각주는 페이지 하단, 머리말은 페이지 상단에 위치하며 서로 독립적으로 작동한다
  3. ③각주 번호는 머리말 영역 안에 표시된다
  4. ④미주(문서 끝 주석)와 머리말은 같은 영역에 배치된다
7매크로(Macro, 반복 작업을 자동으로 실행하는 기능)와 메일 머지(Mail Merge, 편지 병합)를 함께 활용할 때의 설명으로 옳지 않은 것은? 자주
  1. ①매크로는 키보드·마우스 조작을 녹화하여 반복 실행할 수 있다
  2. ②메일 머지는 본문(양식)과 데이터 파일(이름·주소 목록)을 합쳐서 여러 문서를 만든다
  3. ③메일 머지의 데이터 파일로 엑셀, CSV 등 다양한 형식을 사용할 수 있다
  4. ④매크로를 실행하면 메일 머지의 데이터 파일이 자동으로 생성된다
8색인(Index, 주요 용어의 위치를 모은 목록), 목차(Table of Contents, 제목과 페이지 목록), 스타일(Style, 서식 묶음)의 관계에 대한 설명으로 옳은 것은? 자주
  1. ①색인과 목차는 동일한 기능이므로 하나만 사용하면 된다
  2. ②목차를 자동 생성하려면 제목에 '제목 스타일(Heading Style)'을 적용해야 한다
  3. ③스타일을 적용하면 색인이 자동으로 생성된다
  4. ④색인은 문서의 맨 앞에, 목차는 문서의 맨 뒤에 배치하는 것이 원칙이다
9프린터의 종류와 해상도(Resolution, 인쇄 선명도)에 대한 복합 설명으로 옳은 것은? 자주
  1. ①잉크젯 프린터는 레이저 프린터보다 항상 해상도가 높다
  2. ②해상도의 단위 DPI(Dots Per Inch)는 1인치 안에 찍을 수 있는 점의 수를 의미한다
  3. ③도트 프린터(Dot Matrix)는 레이저 프린터보다 해상도가 높아 사진 인쇄에 적합하다
  4. ④해상도가 높을수록 인쇄 속도가 빨라진다
10전자문서(Electronic Document), EDI(Electronic Data Interchange, 전자 데이터 교환), EDMS(Electronic Document Management System, 전자문서 관리 시스템)에 대한 설명으로 옳지 않은 것은? 자주
  1. ①전자문서는 컴퓨터로 작성·저장·전송할 수 있는 디지털 형태의 문서이다
  2. ②EDI는 기업 간 거래 서류(주문서, 송장 등)를 표준 양식으로 전자 교환하는 시스템이다
  3. ③EDMS는 전자문서의 생성·보관·검색·폐기 등 전체 생명주기를 관리한다
  4. ④EDI는 개인 간 이메일 전송을 위해 만들어진 시스템이며, 기업 간 거래에는 사용하지 않는다
11인쇄 품질과 관련된 디더링(Dithering, 점 혼합), 필터링(Filtering, 걸러내기), 트래핑(Trapping, 겹침 보정)에 대한 설명으로 옳은 것은? 자주
  1. ①디더링은 제한된 색상으로 더 많은 색을 표현하기 위해 점들을 혼합 배치하는 기법이다
  2. ②트래핑은 이미지의 잡음(노이즈)을 제거하는 기법이다
  3. ③필터링은 인쇄 시 색상이 겹치는 부분의 틈(빈 공간)을 메우는 기법이다
  4. ④디더링을 적용하면 이미지의 해상도가 2배로 증가한다
12문서 편집에서 자간(글자 사이 간격), 장평(글자의 가로 폭 비율), 행간(줄과 줄 사이 간격), 커닝(Kerning, 특정 글자 쌍의 간격 조정)에 대한 설명으로 옳지 않은 것은? 자주
  1. ①자간을 줄이면 글자들이 더 가까이 붙어서 좁은 공간에 많은 글을 넣을 수 있다
  2. ②장평 100%는 원래 비율이며, 200%로 하면 글자가 가로로 2배 넓어진다
  3. ③커닝은 모든 글자 사이를 동일하게 조정하는 기능으로 자간과 같은 개념이다
  4. ④행간을 넓히면 줄 사이 공간이 커져 문서의 가독성(읽기 쉬움)이 높아질 수 있다
13워드랩(Word Wrap, 자동 줄 바꿈)과 금칙 처리(禁則處理, 줄의 시작·끝에 올 수 없는 문자 규칙)에 대한 설명으로 옳은 것은? 자주
  1. ①워드랩은 사용자가 직접 Enter 키를 눌러야만 작동하는 수동 줄 바꿈 기능이다
  2. ②금칙 처리에서 마침표(.)는 줄의 맨 앞에 올 수 있다
  3. ③워드랩은 단어가 줄 끝을 넘으면 자동으로 다음 줄로 내리고, 금칙 처리는 특정 문자의 줄 위치를 제한한다
  4. ④금칙 처리와 워드랩은 완전히 동일한 기능의 다른 이름이다
14하이퍼텍스트(Hypertext, 클릭하면 다른 문서로 이동하는 텍스트)와 전자책(e-Book)에 대한 설명으로 옳지 않은 것은? 자주
  1. ①하이퍼텍스트는 비순차적(순서 없이) 정보 접근이 가능하여 전자책에서 활용된다
  2. ②전자책은 종이책을 디지털화한 것으로, 멀티미디어(소리·동영상)를 포함할 수 있다
  3. ③전자책의 대표 형식으로 EPUB, PDF 등이 있다
  4. ④하이퍼텍스트는 한 방향으로만 이동 가능하며, 이전 문서로 되돌아갈 수 없다
15DRM(Digital Rights Management, 디지털 저작권 관리)과 저작권에 대한 설명으로 옳은 것은? 자주
  1. ①DRM은 디지털 콘텐츠의 불법 복제·배포를 방지하기 위한 기술적 보호 조치이다
  2. ②저작권은 등록해야만 발생하며, 작품을 만든 것만으로는 보호받지 못한다
  3. ③DRM이 적용된 파일은 어떤 방법으로도 열어볼 수 없다
  4. ④저작권은 저작자 사후 10년까지만 보호된다
16WYSIWYG(What You See Is What You Get, 보이는 대로 출력)와 포스트스크립트(PostScript, 페이지 기술 언어)에 대한 설명으로 옳은 것은? 자주
  1. ①WYSIWYG는 화면에 보이는 내용과 인쇄 결과가 다르게 나오는 방식이다
  2. ②포스트스크립트는 키보드 입력 방식의 한 종류이다
  3. ③포스트스크립트는 프린터에 인쇄 내용을 전달하는 페이지 기술 언어로, WYSIWYG 구현에 기여한다
  4. ④WYSIWYG 방식에서는 프린터 종류에 관계없이 항상 동일한 결과가 나온다
17보고서 작성 시 '사실과 의견의 구분'과 '항목 번호 체계'를 모두 고려한 설명으로 옳은 것은? 자주
  1. ①보고서에서 사실과 의견은 같은 항목 번호 아래 구분 없이 작성한다
  2. ②항목이 하나뿐인 보고서에서는 'Ⅰ.'을 반드시 붙이고, 의견만 서술한다
  3. ③보고서의 항목 번호 순서는 작성자가 자유롭게 정하며, 사실 확인은 불필요하다
  4. ④보고서의 항목 번호는 Ⅰ → 1 → 가 → (1) → (가) → ① 순서이며, 사실과 의견을 구분하여 작성해야 한다
18공문서에서 날짜, 금액, 시간을 표기하는 방법으로 옳은 것은? 자주
  1. ①날짜는 '2024년 3월 15일'로, 금액은 '금 1,234,567원'으로, 시간은 24시간제(14:00)로 쓴다
  2. ②날짜는 '2024.3.15.'로 쓰고, 금액은 한글로만 '일백이십삼만사천오백육십칠원'으로 쓴다
  3. ③날짜는 '24/03/15'로, 금액은 '$1,234,567'로, 시간은 12시간제(오후 2시)로 쓴다
  4. ④날짜·금액·시간 모두 작성자가 편한 형식을 자유롭게 선택할 수 있다
19공문서에서 본문이 끝났음을 나타내는 끝 표시 규칙과 붙임(첨부 파일) 표기에 대한 설명으로 옳은 것은? 자주
  1. ①본문 내용이 끝나면 다음 줄 왼쪽 끝에 '이상'이라고 쓴다
  2. ②본문이 표(도표)로 끝나면 표 아래 오른쪽에 '끝.'이라고 쓴다
  3. ③첨부 파일이 있으면 본문 끝 표시 없이 바로 '붙임'을 쓴다
  4. ④본문의 끝 표시는 생략해도 무방하다
20업무실명제(업무 처리자의 이름을 공개하는 제도)와 전자결재(Electronic Approval, 컴퓨터로 결재하는 시스템)에 대한 설명으로 옳은 것은? 자주
  1. ①업무실명제는 담당자의 이름을 문서에 기재하지 않는 제도이다
  2. ②전자결재는 종이 문서에 직접 서명하는 것을 말한다
  3. ③업무실명제는 업무 투명성과 책임성을 높이며, 전자결재 시스템에서 결재자 정보가 자동 기록된다
  4. ④전자결재에서는 결재 순서를 정할 수 없으며, 모든 결재자가 동시에 처리한다
2PC 운영체제Q21 – Q40
21Windows 탐색기(Explorer)에서 파일의 속성(Properties)을 확인하려고 한다. 다음 중 탐색기와 파일 속성에 대한 설명으로 옳은 것은? 자주
  1. ①탐색기의 '자세히' 보기에서는 파일 크기를 확인할 수 있지만, 숨김(Hidden) 속성 여부는 표시되지 않는다.
  2. ②파일을 마우스 오른쪽 클릭 → 속성에서 '읽기 전용(Read-only)'과 '숨김(Hidden)' 속성을 동시에 설정할 수 있다.
  3. ③탐색기 주소 표시줄에 폴더 경로를 직접 입력하면 해당 폴더의 속성 창이 자동으로 열린다.
  4. ④파일의 '보관(Archive)' 속성은 사용자가 속성 창의 일반 탭에서 직접 해제할 수 있다.
22휴지통(Recycle Bin)과 바로 가기(Shortcut)에 대한 설명으로 옳은 것은? 자주
  1. ①바로 가기 아이콘을 휴지통에 넣어 삭제해도 원본 파일은 그대로 남아 있으며, 바로 가기의 확장자는 .lnk이다.
  2. ②휴지통에서 '복원(Restore)'하면 파일이 바탕화면으로 이동한다.
  3. ③Shift + Delete로 삭제한 파일도 휴지통 속성에서 '최대 크기'를 늘리면 복원할 수 있다.
  4. ④바로 가기를 삭제하면 원본 파일도 함께 삭제되므로 주의해야 한다.
23Windows 제어판(Control Panel)과 디스플레이(Display) 설정에 대한 설명으로 옳지 않은 것은? 자주
  1. ①제어판의 '프로그램 및 기능'에서 디스플레이 해상도를 변경할 수 있다.
  2. ②다중 모니터 환경에서 '디스플레이 확장(Extend)'을 선택하면 각 모니터에 서로 다른 해상도를 설정할 수 있다.
  3. ③제어판은 Windows 11에서도 여전히 존재하며, 실행(Win+R) → control로 접근 가능하다.
  4. ④디스플레이 설정에서 주 모니터를 변경하면 작업 표시줄과 시작 메뉴의 기본 위치가 이동한다.
24Windows 에어로(Aero) 기능과 작업 표시줄(Taskbar)에 대한 설명으로 옳지 않은 것은? 자주
  1. ①에어로 피크(Aero Peek)는 작업 표시줄 오른쪽 끝에 마우스를 올리면 열린 창을 투명하게 만들어 바탕화면을 미리 볼 수 있다.
  2. ②에어로 스냅(Aero Snap)은 창을 화면 가장자리로 끌면 자동으로 화면의 절반 또는 전체 크기로 정렬해 준다.
  3. ③작업 표시줄의 점프 목록(Jump List)은 마우스 오른쪽 클릭으로 최근 파일이나 자주 쓰는 기능에 빠르게 접근하는 기능이다.
  4. ④에어로 셰이크(Aero Shake)로 최소화된 창들은 다시 셰이크해도 복원되지 않으므로 하나씩 수동으로 복원해야 한다.
25Windows 단축키와 작업 관리자(Task Manager)에 대한 설명으로 옳은 것은? 자주
  1. ①Ctrl + Shift + Esc를 누르면 작업 관리자가 바로 실행되며, '프로세스' 탭에서 CPU·메모리 사용량을 함께 확인할 수 있다.
  2. ②Ctrl + Alt + Delete를 누르면 작업 관리자가 곧바로 열리며 다른 메뉴는 표시되지 않는다.
  3. ③작업 관리자의 '성능' 탭에서는 실행 중인 프로그램을 강제 종료할 수 있다.
  4. ④Alt + F4는 현재 활성 창을 닫는 단축키이며, 바탕화면에서 누르면 컴퓨터가 즉시 종료된다.
26Windows 안전 모드(Safe Mode)와 부팅 과정(Boot Process)에 대한 설명으로 옳지 않은 것은? 자주
  1. ①부팅 순서는 POST → 부트로더(Boot Loader) → 커널(Kernel) 로드 → 로그인 화면 순이다.
  2. ②안전 모드에서는 최소한의 드라이버와 서비스만 로드하여 문제를 진단할 수 있다.
  3. ③안전 모드(네트워킹 사용)를 선택하면 네트워크 드라이버도 함께 로드되어 인터넷 사용이 가능하다.
  4. ④안전 모드에서는 모든 하드웨어 장치가 정상적으로 인식되므로 드라이버 충돌 테스트에는 적합하지 않다.
27절전(Sleep), 최대 절전(Hibernate), 로그아웃(Sign Out)에 대한 설명으로 옳지 않은 것은? 자주
  1. ①절전(Sleep)은 작업 상태를 RAM에 유지하므로 복귀 속도가 빠르지만, 전원이 꺼지면 데이터가 손실된다.
  2. ②절전과 최대 절전 모두 복귀 시 로그인 화면 없이 바로 바탕화면이 나타나므로 보안 걱정이 없다.
  3. ③최대 절전(Hibernate)은 작업 상태를 하드디스크(hiberfil.sys)에 저장하므로 전원이 꺼져도 데이터가 유지된다.
  4. ④로그아웃을 하면 현재 사용자의 프로그램은 모두 종료되지만, 다른 사용자 계정의 실행 중인 프로그램에는 영향을 주지 않는다.
28FAT32, NTFS 파일 시스템과 포맷(Format)에 대한 설명으로 옳지 않은 것은? 자주
  1. ①FAT32는 개별 파일 크기가 최대 4GB로 제한되어 대용량 영상 파일을 저장하기 어렵다.
  2. ②NTFS는 파일·폴더 단위의 접근 권한(ACL) 설정과 파일 암호화(EFS)를 지원한다.
  3. ③빠른 포맷(Quick Format)은 데이터 영역까지 완전히 초기화하므로 일반 포맷보다 보안성이 높다.
  4. ④포맷 시 할당 단위 크기(클러스터 크기)를 크게 설정하면 작은 파일이 많을 때 디스크 낭비가 발생할 수 있다.
29Windows 시스템 복원(System Restore)과 복원 지점(Restore Point)에 대한 설명으로 옳은 것은? 자주
  1. ①시스템 복원을 실행하면 운영체제 설정뿐 아니라 사용자가 저장한 문서 파일도 이전 상태로 되돌아간다.
  2. ②시스템 복원은 복원 지점을 수동으로만 만들 수 있으며, Windows Update 시 자동 생성되지 않는다.
  3. ③복원 지점에는 레지스트리, 시스템 파일, 설치된 프로그램 정보 등이 포함되어 시스템 문제 해결에 활용된다.
  4. ④시스템 복원을 수행한 후에는 다시 되돌릴(실행 취소) 수 없으므로 신중하게 사용해야 한다.
30Windows 레지스트리(Registry)와 사용자 계정 컨트롤(UAC)에 대한 설명으로 옳지 않은 것은? 자주
  1. ①레지스트리는 운영체제와 프로그램의 설정 정보를 계층적(트리 구조)으로 저장하는 데이터베이스이다.
  2. ②레지스트리 편집기(regedit)에서 잘못된 값을 수정하면 시스템이 부팅되지 않을 수 있다.
  3. ③UAC는 관리자 권한이 필요한 작업 시 확인 대화 상자를 표시하여 악성 프로그램의 무단 설치를 방지한다.
  4. ④UAC 알림 수준을 '알리지 않음'으로 설정하면 레지스트리 변경도 자동으로 차단되어 보안이 강화된다.
31Windows 디스크 관리 도구인 조각 모음(Defragment), 디스크 정리(Disk Cleanup), chkdsk에 대한 설명으로 옳은 것은? 자주
  1. ①SSD에서도 조각 모음을 자주 실행하면 읽기/쓰기 속도가 크게 향상된다.
  2. ②디스크 정리는 임시 파일, 휴지통 내용, 시스템 캐시 등을 삭제하여 저장 공간을 확보하며, chkdsk는 디스크 오류를 검사·복구한다.
  3. ③chkdsk 명령은 GUI(그래픽) 환경에서만 실행할 수 있으며, 명령 프롬프트에서는 사용할 수 없다.
  4. ④조각 모음은 파일을 삭제하여 공간을 확보하는 기능이고, 디스크 정리는 파일을 연속 배치하는 기능이다.
32Windows 기본 프로그램인 메모장(Notepad)과 워드패드(WordPad)에 대한 설명으로 옳지 않은 것은? 자주
  1. ①메모장은 서식 없는 순수 텍스트(.txt)만 편집할 수 있고, 글꼴 색상이나 크기 변경이 파일에 저장되지 않는다.
  2. ②워드패드는 서식 있는 문서(.rtf)를 지원하여 굵게, 기울임, 글꼴 크기 등을 적용하고 저장할 수 있다.
  3. ③메모장에서 .html 파일을 열면 태그가 그대로 텍스트로 보이고, 워드패드에서 열면 웹페이지처럼 렌더링된다.
  4. ④메모장은 시스템 설정 파일(.ini, .cfg)이나 소스 코드 편집에 자주 사용된다.
33Windows 그림판(Paint)과 이미지 파일 형식에 대한 설명으로 옳은 것은? 자주
  1. ①그림판에서 저장할 때 PNG 형식을 선택하면 투명 배경을 유지할 수 있으며, JPEG는 투명 배경을 지원하지 않는다.
  2. ②BMP 형식은 압축률이 가장 높아 파일 크기가 작으므로 웹에서 주로 사용된다.
  3. ③GIF 형식은 최대 1,677만 색상을 표현할 수 있어 사진 편집에 가장 적합하다.
  4. ④JPEG 형식은 무손실 압축 방식이므로 여러 번 저장해도 화질이 전혀 저하되지 않는다.
34Windows 네트워크, 방화벽(Firewall), 파일 공유(File Sharing)에 대한 설명으로 옳지 않은 것은? 자주
  1. ①Windows 방화벽은 인바운드(외부→내부)와 아웃바운드(내부→외부) 트래픽을 모두 제어할 수 있다.
  2. ②파일 공유 시 '읽기(Read)' 권한만 부여하면 상대방이 파일을 열어볼 수는 있지만 수정·삭제는 할 수 없다.
  3. ③네트워크 프로필을 '공용(Public)'으로 설정하면 파일 공유와 네트워크 검색이 기본적으로 활성화되어 편리하다.
  4. ④방화벽에서 특정 프로그램에 대해 예외 규칙을 추가하면 해당 프로그램의 네트워크 통신이 허용된다.
35DHCP와 IP 설정에 대한 설명으로 옳은 것은? 자주
  1. ①DHCP 서버가 없는 네트워크에서는 컴퓨터가 자동으로 공인 IP(Public IP)를 생성하여 인터넷에 접속한다.
  2. ②고정 IP 설정 시 IP 주소, 서브넷 마스크(Subnet Mask), 기본 게이트웨이(Default Gateway)를 모두 올바르게 입력해야 정상 통신이 가능하다.
  3. ③DHCP(Dynamic Host Configuration Protocol)는 IP 주소만 자동 할당하며, DNS 서버 주소는 수동으로 설정해야 한다.
  4. ④같은 네트워크에서 두 컴퓨터에 동일한 IP 주소를 수동 설정해도 충돌 없이 정상 작동한다.
36Windows 사용자 계정(User Account)과 권한(Permission)에 대한 설명으로 옳지 않은 것은? 자주
  1. ①관리자(Administrator) 계정은 소프트웨어 설치, 시스템 설정 변경, 다른 사용자 계정 관리 등 모든 작업을 수행할 수 있다.
  2. ②표준 사용자(Standard User) 계정은 프로그램 실행과 개인 설정 변경은 가능하지만, 시스템 전체에 영향을 주는 변경은 관리자 승인이 필요하다.
  3. ③게스트(Guest) 계정은 임시 사용자를 위한 것으로, 소프트웨어 설치와 시스템 설정 변경이 제한된다.
  4. ④표준 사용자 계정으로도 다른 사용자의 개인 폴더(문서, 사진 등)에 자유롭게 접근하여 파일을 삭제할 수 있다.
37Windows 암호화 기능인 BitLocker와 EFS(Encrypting File System)에 대한 설명으로 옳은 것은? 자주
  1. ①EFS는 NTFS 파일 시스템에서만 사용할 수 있으며, 개별 파일이나 폴더 단위로 암호화할 수 있다.
  2. ②BitLocker는 개별 파일만 암호화하고, EFS는 드라이브 전체를 암호화하는 기능이다.
  3. ③BitLocker와 EFS 모두 Windows Home 에디션에서 기본 제공된다.
  4. ④BitLocker로 암호화된 드라이브는 복구 키(Recovery Key) 없이도 다른 컴퓨터에서 자유롭게 읽을 수 있다.
38Windows 보안(Windows Defender)과 Windows Update에 대한 설명으로 옳지 않은 것은? 자주
  1. ①Windows Defender는 실시간 보호 기능으로 바이러스, 스파이웨어, 맬웨어를 자동으로 탐지하고 차단한다.
  2. ②Windows Update는 보안 패치, 기능 업데이트, 드라이버 업데이트 등을 제공하여 시스템을 최신 상태로 유지한다.
  3. ③Windows Defender의 '빠른 검사'는 시스템의 모든 파일과 레지스트리를 완전히 검사하므로 시간이 오래 걸린다.
  4. ④Windows Update 후 문제가 발생하면 '업데이트 기록'에서 특정 업데이트를 제거(롤백)할 수 있다.
39Windows 바탕화면(Desktop)과 개인 설정(Personalization)에 대한 설명으로 옳은 것은? 자주
  1. ①바탕화면의 아이콘 정렬 방식을 '자동 정렬'로 설정하면 아이콘을 자유로운 위치에 배치할 수 있다.
  2. ②개인 설정에서 테마(Theme)를 변경하면 바탕화면 배경, 색상, 소리, 마우스 커서가 한꺼번에 적용된다.
  3. ③바탕화면 배경은 반드시 그림 파일만 설정할 수 있으며, 단색(Solid Color)이나 슬라이드 쇼는 지원하지 않는다.
  4. ④개인 설정에서 변경한 내용은 모든 사용자 계정에 동시에 적용되어 개별 설정이 불가능하다.
40Windows 접근성(Accessibility)과 전원 옵션(Power Options)에 대한 설명으로 옳지 않은 것은? 자주
  1. ①접근성의 '돋보기(Magnifier)'는 화면을 확대하여 보여주고, '내레이터(Narrator)'는 화면 내용을 음성으로 읽어준다.
  2. ②전원 옵션에서 '균형 조정(Balanced)' 모드는 성능과 전력 소비의 균형을 맞추는 기본 전원 관리 방식이다.
  3. ③접근성의 '고대비(High Contrast)' 테마는 시각 장애인을 위해 색상 대비를 높여 화면 가독성을 향상시킨다.
  4. ④전원 옵션의 '고성능(High Performance)' 모드를 선택하면 CPU 성능이 올라가면서 배터리 소모는 오히려 줄어든다.

41CPU의 구성 요소와 레지스터에 대한 설명으로 옳지 않은 것은? 자주
  1. ①메모리 주소 레지스터(MAR)는 메모리에서 읽어온 데이터 자체를 저장하는 역할을 한다
  2. ②ALU(산술논리연산장치)는 덧셈, 뺄셈 등 연산을 수행하고, 누산기(Accumulator)는 연산 결과를 임시 저장한다
  3. ③프로그램 카운터(PC)는 다음에 실행할 명령어의 메모리 주소를 저장한다
  4. ④명령어 레지스터(IR)는 현재 실행 중인 명령어를 저장하며, 제어장치(CU)가 이를 해독한다
42인터넷 프로토콜과 포트 번호의 조합으로 올바른 것은? 자주
  1. ①FTP는 데이터 전송에 포트 20, 제어에 포트 25를 사용한다
  2. ②HTTP는 포트 80, HTTPS는 포트 443을 기본으로 사용한다
  3. ③SMTP는 포트 110을 사용하여 이메일을 발신한다
  4. ④DNS는 포트 23을 사용하여 도메인 이름을 IP 주소로 변환한다
43컴퓨터 세대별 특징과 처리 능력에 따른 분류를 연결한 설명으로 옳은 것은? 자주
  1. ①1세대 컴퓨터는 진공관을 사용했으며, 오늘날의 슈퍼컴퓨터보다 빠른 연산 속도를 가졌다
  2. ②3세대 컴퓨터는 LSI(대규모 집적회로)를 사용했으며, 개인용 컴퓨터(PC)가 이때 보급되었다
  3. ③2세대 컴퓨터는 트랜지스터를 사용했고, 이 시기에 운영체제(OS)와 고급 언어가 등장하기 시작했다
  4. ④4세대 컴퓨터는 IC(집적회로)를 사용했고, 마이크로프로세서가 등장했다
44RAM, ROM, 캐시 메모리에 대한 설명으로 옳지 않은 것은? 자주
  1. ①SRAM은 DRAM보다 속도가 빠르고 가격이 비싸서 캐시 메모리에 주로 사용된다
  2. ②ROM의 종류 중 EEPROM은 전기적으로 내용을 지우고 다시 기록할 수 있다
  3. ③캐시 메모리는 CPU와 주기억장치 사이에서 속도 차이를 줄여주는 역할을 한다
  4. ④DRAM은 전원이 꺼져도 데이터가 유지되므로 주기억장치(메인 메모리)로 사용된다
45한글 2글자와 영문 3글자로 구성된 데이터를 UTF-8로 저장할 때 필요한 최소 바이트 수는? 자주
  1. ①9바이트
  2. ②7바이트
  3. ③10바이트
  4. ④12바이트
46소프트웨어 분류와 라이선스 유형에 대한 설명으로 옳은 것은? 자주
  1. ①프리웨어(Freeware)는 소스 코드가 공개되어 있어 누구나 수정·배포할 수 있는 소프트웨어이다
  2. ②셰어웨어(Shareware)는 일정 기간 무료 사용 후 계속 쓰려면 비용을 지불해야 하는 소프트웨어이다
  3. ③오픈소스 소프트웨어는 무조건 무료이며, 어떤 형태의 상업적 이용도 금지된다
  4. ④시스템 소프트웨어에는 워드프로세서, 스프레드시트, 데이터베이스 관리 프로그램이 포함된다
47컴파일러, 인터프리터, 어셈블러에 대한 설명으로 옳지 않은 것은? 자주
  1. ①컴파일러는 고급 언어 전체를 한꺼번에 기계어로 번역하여 목적 프로그램(Object Program)을 생성한다
  2. ②인터프리터는 소스 코드를 한 줄씩 번역·실행하므로 별도의 목적 프로그램을 생성하지 않는다
  3. ③어셈블러는 어셈블리어(저급 언어)를 기계어로 변환하며, 이 과정을 컴파일이라 한다
  4. ④인터프리터 방식은 오류를 즉시 발견할 수 있어 디버깅에 유리하지만, 실행 속도는 컴파일러보다 느리다
48멀티미디어 파일 형식에 대한 설명으로 옳은 것은? 자주
  1. ①JPEG는 비손실 압축 방식의 이미지 포맷으로, 투명 배경을 지원한다
  2. ②GIF는 최대 1,677만 색상을 표현할 수 있어 사진 저장에 가장 적합하다
  3. ③AVI는 오디오 전용 파일 형식이며, WAV는 동영상 전용 파일 형식이다
  4. ④MP3는 오디오 파일의 손실 압축 형식이고, MIDI는 악기의 연주 정보를 디지털 신호로 저장하는 형식이다
49네트워크 장비와 해당 장비가 동작하는 OSI 7계층의 연결로 옳지 않은 것은? 자주
  1. ①허브(Hub) — 전송 계층(4계층): 포트 번호를 기반으로 데이터를 분배한다
  2. ②리피터(Repeater) — 물리 계층(1계층): 약해진 신호를 증폭·재생한다
  3. ③브리지(Bridge) — 데이터 링크 계층(2계층): MAC 주소를 기반으로 프레임을 전달한다
  4. ④라우터(Router) — 네트워크 계층(3계층): IP 주소를 기반으로 최적 경로를 설정한다
5010진수 29를 2진수로 변환한 후, 다시 8진수와 16진수로 표현한 것으로 올바른 것은? 자주
  1. ①2진수: 11011, 8진수: 33, 16진수: 1B
  2. ②2진수: 11101, 8진수: 34, 16진수: 1E
  3. ③2진수: 11101, 8진수: 35, 16진수: 1D
  4. ④2진수: 11100, 8진수: 34, 16진수: 1C
51보수(Complement)와 오류 검출에 대한 설명으로 옳지 않은 것은? 자주
  1. ①CRC(순환 중복 검사)는 다항식을 이용한 오류 검출 방법으로, 블록 단위 전송에서 널리 사용된다
  2. ②패리티 비트(Parity Bit)는 오류를 검출할 수 있을 뿐만 아니라 오류 수정까지 가능하다
  3. ③2진수 1010의 1의 보수는 0101이고, 2의 보수는 0110이다
  4. ④해밍 코드(Hamming Code)는 오류 검출과 1비트 오류 수정이 가능하다
52암호화 방식과 보안 프로토콜에 대한 설명으로 옳지 않은 것은? 자주
  1. ①대칭키 암호화는 암호화와 복호화에 같은 키를 사용하며, DES와 AES가 대표적이다
  2. ②공개키(비대칭키) 암호화는 공개키로 암호화하고 개인키로 복호화하며, RSA가 대표적이다
  3. ③공개키 암호화는 대칭키 암호화보다 처리 속도가 빠르므로 대용량 데이터 암호화에 적합하다
  4. ④SSL/TLS는 웹 통신을 암호화하는 프로토콜로, HTTPS에 사용된다
53IP 주소, DNS, 도메인 이름에 대한 설명으로 옳은 것은? 자주
  1. ①IPv4 주소는 128비트로 구성되며, 8개의 그룹으로 나뉜다
  2. ②DNS(Domain Name System)는 도메인 이름을 IP 주소로 변환해주는 시스템이다
  3. ③도메인의 최상위 도메인(TLD)은 www와 같은 호스트 이름을 말한다
  4. ④IPv6는 32비트로 구성되어 IPv4보다 적은 수의 주소를 제공한다
54악성코드와 네트워크 공격 유형의 연결로 옳지 않은 것은? 자주
  1. ①피싱(Phishing)은 시스템의 보안 취약점을 이용해 관리자 권한을 탈취하는 악성코드이다
  2. ②웜(Worm)은 자기 복제를 통해 네트워크를 통해 스스로 전파되며, 숙주 프로그램이 필요 없다
  3. ③트로이 목마(Trojan Horse)는 정상 프로그램으로 위장하여 시스템에 침투하며, 자기 복제 기능은 없다
  4. ④DDoS(분산 서비스 거부) 공격은 여러 대의 컴퓨터로 동시에 대량의 트래픽을 보내 서버를 마비시킨다
55데이터 전송 방식과 전송 속도 단위에 대한 설명으로 옳은 것은? 자주
  1. ①직렬 전송은 여러 비트를 동시에 전송하므로 병렬 전송보다 속도가 빠르다
  2. ②bps(bits per second)는 1초에 전송하는 바이트(Byte) 수를 의미한다
  3. ③동기식 전송은 데이터 블록 단위로 전송하며, 비동기식보다 전송 효율이 높다
  4. ④반이중(Half-Duplex) 통신은 송신과 수신을 동시에 할 수 있는 방식이다
56운영체제 처리 방식과 BIOS/CMOS에 대한 설명으로 옳지 않은 것은? 자주
  1. ①시분할 처리(Time Sharing)는 CPU 시간을 여러 사용자에게 번갈아 배분하여 동시에 사용하는 것처럼 느끼게 한다
  2. ②다중 프로그래밍(Multiprogramming)은 메모리에 여러 프로그램을 올려 CPU 활용률을 높이는 방식이다
  3. ③BIOS(기본 입출력 시스템)는 컴퓨터 부팅 시 하드웨어를 점검(POST)하고 운영체제를 로드하는 펌웨어이다
  4. ④CMOS는 부팅 프로그램 자체를 저장하며, 배터리 없이도 설정 정보가 영구 보존된다
57데이터베이스, SQL, DBMS에 대한 설명으로 옳은 것은? 자주
  1. ①DDL(데이터 정의어)에는 SELECT, INSERT, UPDATE, DELETE가 포함된다
  2. ②DBMS(데이터베이스 관리 시스템)는 데이터의 중복을 최소화하고 일관성을 유지하기 위한 소프트웨어이다
  3. ③DML(데이터 조작어)에는 CREATE, ALTER, DROP이 포함된다
  4. ④스키마(Schema)는 데이터베이스에 실제로 저장된 데이터 값 자체를 의미한다
58가상 기억장치, 페이징, 폰 노이만 구조에 대한 설명으로 옳지 않은 것은? 자주
  1. ①가상 기억장치는 보조기억장치의 일부를 주기억장치처럼 사용하여 메모리 부족을 해결하는 기법이다
  2. ②페이징(Paging)은 프로그램을 고정 크기의 페이지로 나누어 메모리에 적재하는 방식이다
  3. ③폰 노이만 구조는 프로그램과 데이터를 주기억장치에 저장하고 순차적으로 실행하는 방식이다
  4. ④세그먼테이션(Segmentation)은 프로그램을 고정 크기로 나누며, 내부 단편화가 발생한다
59클라우드 컴퓨팅, IoT, 빅데이터에 대한 설명으로 옳은 것은? 자주
  1. ①IoT(사물인터넷)는 사물에 센서를 부착하여 인터넷으로 데이터를 주고받는 기술이며, 빅데이터의 주요 수집원이 된다
  2. ②IaaS(Infrastructure as a Service)는 완성된 소프트웨어를 서비스로 제공하며, Gmail이 대표적이다
  3. ③SaaS(Software as a Service)는 서버, 스토리지 등 하드웨어 인프라만 제공하는 서비스이다
  4. ④빅데이터의 3V는 Volume(크기), Velocity(속도), Visibility(가시성)를 의미한다
60저작권, CCL(크리에이티브 커먼즈 라이선스), 정보 윤리에 대한 설명으로 옳지 않은 것은? 자주
  1. ①저작권은 저작물을 창작한 순간 자동으로 발생하며, 별도의 등록 절차가 필요 없다
  2. ②CCL의 BY(저작자 표시)는 모든 CCL 조건에 기본으로 포함되는 필수 요소이다
  3. ③CCL의 SA(동일조건변경허락)는 원저작물과 동일한 라이선스 조건으로만 2차 저작물을 배포할 수 있게 한다
  4. ④공개 소프트웨어(Open Source)는 저작권이 소멸된 퍼블릭 도메인(Public Domain)과 동일한 개념이다
