1다음 중 교정 부호에서 '삽입'을 나타내는 부호의 형태로 옳은 것은? 매회
  1. ①∨ 모양으로 표시하고 삽입할 내용을 기입한다
  2. ②○ 모양으로 해당 글자를 감싼다
  3. ③≡ 모양으로 밑줄을 긋는다
  4. ④× 모양으로 해당 글자 위에 표시한다
2다음 중 전자출판(DTP)에 대한 설명으로 옳지 않은 것은? 매회
  1. ①대량 인쇄 시 오프셋 인쇄보다 비용이 저렴하다
  2. ②소량 다품종 출판에 적합하다
  3. ③출판 소요 시간을 단축할 수 있다
  4. ④원고 작성부터 편집·인쇄까지 컴퓨터로 처리한다
3다음 중 공문서의 본문에 해당하지 않는 구성 요소는? 매회
  1. ①수신자
  2. ②내용
  3. ③붙임
  4. ④제목
4다음 중 결재에 대한 설명으로 옳은 것은? 매회
  1. ①대결은 결재권자가 직접 위임한 사항에 대해 최종 결재하는 것이다
  2. ②전결은 결재권자 부재 시 차상위자가 임시로 대신 결재하는 것이다
  3. ③후결은 긴급 시 먼저 시행하고 나중에 결재를 받는 것이다
  4. ④결재와 결제는 동일한 의미로 사용된다
5다음 중 꼬리말(Footer)에 대한 설명으로 옳지 않은 것은? 매회
  1. ①페이지 하단에 반복 출력되는 영역이다
  2. ②꼬리말은 인쇄 미리보기에서만 확인 가능하고 편집 화면에는 표시되지 않는다
  3. ③한 번 설정하면 전체 페이지에 동일하게 적용된다
  4. ④페이지 번호, 날짜 등을 자동으로 삽입할 수 있다
6다음 중 매크로(Macro)에 대한 설명으로 옳지 않은 것은? 매회
  1. ①반복적인 작업을 자동화할 수 있다
  2. ②매크로는 다른 문서 파일로 복사할 수 없다
  3. ③기록된 매크로는 편집·수정이 가능하다
  4. ④매크로 바이러스에 감염될 위험이 있다
7다음 중 문서의 보안 등급이 높은 순서부터 바르게 나열한 것은? 자주
  1. ①비밀 → 대외비 → 일반
  2. ②대외비 → 비밀 → 일반
  3. ③일반 → 대외비 → 비밀
  4. ④비밀 → 일반 → 대외비
8다음 중 차트(그래프)의 종류와 용도가 바르게 연결된 것은? 매회
  1. ①원형 차트 — 시간에 따른 데이터 변화 추이를 나타낸다
  2. ②꺾은선 차트 — 전체 대비 각 항목의 구성 비율을 나타낸다
  3. ③막대 차트 — 항목별 수량의 크기를 비교한다
  4. ④방사형 차트 — 두 변수 간의 상관관계를 나타낸다
9다음 중 글꼴(Font)에 대한 설명으로 옳은 것은? 자주
  1. ①트루타입(TrueType) 글꼴은 화면 표시 전용으로 인쇄할 수 없다
  2. ②비트맵 글꼴은 확대해도 깨지지 않는다
  3. ③오픈타입(OpenType) 글꼴은 Windows와 Mac에서 모두 사용 가능하다
  4. ④포스트스크립트 글꼴은 웹 전용 글꼴이다
10다음 중 문단 정렬 방식에 대한 설명으로 옳지 않은 것은? 매회
  1. ①왼쪽 정렬은 문단의 왼쪽 끝을 일정하게 맞춘다
  2. ②오른쪽 정렬은 문단의 오른쪽 끝을 일정하게 맞춘다
  3. ③가운데 정렬은 각 줄의 중앙을 기준으로 정렬한다
  4. ④양쪽 정렬은 왼쪽만 맞추고 오른쪽은 자연스럽게 놔둔다
11다음 중 탭(Tab) 기능에 대한 설명으로 옳은 것은? 자주
  1. ①탭 간격은 변경할 수 없다
  2. ②탭은 문서 전체에 동일하게만 적용된다
  3. ③탭 위치에 점선이나 밑줄 등의 채움선을 설정할 수 있다
  4. ④탭 키를 누르면 항상 8칸씩 이동한다
12다음 중 스타일(Style) 기능에 대한 설명으로 옳은 것은? 자주
  1. ①글꼴, 크기, 색상 등 서식을 묶어서 한 번에 적용할 수 있다
  2. ②스타일은 한 번 만들면 수정할 수 없다
  3. ③스타일은 문자 서식만 저장할 수 있고 문단 서식은 불가능하다
  4. ④스타일을 적용하면 원본 서식이 완전히 삭제된다
13다음 중 메일 머지(Mail Merge)에 대한 설명으로 옳은 것은? 매회
  1. ①여러 사람에게 이메일을 동시에 보내는 기능이다
  2. ②본문 양식과 데이터 파일을 결합하여 개별 문서를 자동 생성한다
  3. ③두 개의 문서를 하나로 합치는 기능이다
  4. ④문서의 맞춤법을 자동으로 교정하는 기능이다
14다음 중 워드프로세서의 입력 방식에서 '삽입 모드'에 대한 설명으로 옳은 것은? 자주
  1. ①커서 위치에 새 문자를 삽입하고 기존 문자는 뒤로 밀린다
  2. ②커서 위치의 기존 문자를 새 문자로 대체한다
  3. ③입력한 문자가 자동으로 삭제된다
  4. ④삽입 모드에서는 한글 입력이 불가능하다
15다음 중 개인정보 보호법상 전자문서에 포함된 개인정보 처리에 대한 설명으로 옳은 것은? 매회
  1. ①개인정보 처리 시 정보주체의 동의를 받아야 한다
  2. ②개인정보는 수집 목적 외 용도로 자유롭게 활용할 수 있다
  3. ③개인정보는 보유기간에 관계없이 영구 저장해야 한다
  4. ④공개된 개인정보는 동의 없이 마음대로 수집할 수 있다
16다음 중 워드프로세서에서 표(Table) 편집 기능으로 옳지 않은 것은? 매회
  1. ①셀 병합과 분할이 가능하다
  2. ②표 안에 다른 표를 삽입할 수 있다
  3. ③셀 안에서 텍스트 정렬을 개별적으로 설정할 수 있다
  4. ④표의 행·열 수는 생성 후 변경할 수 없다
17다음 중 문서 저장 형식에 대한 설명으로 옳은 것은? 매회
  1. ①HWP는 마이크로소프트에서 개발한 문서 형식이다
  2. ②PDF는 운영체제와 관계없이 동일한 형태로 문서를 볼 수 있다
  3. ③TXT 파일은 글꼴·색상 등의 서식 정보를 포함한다
  4. ④DOC 형식은 한글 전용 문서 형식이다
18다음 중 각주와 미주에 대한 설명으로 옳은 것은? 매회
  1. ①각주는 문서의 맨 끝에 모아서 표시한다
  2. ②미주는 해당 페이지의 하단에 표시한다
  3. ③각주는 해당 페이지 하단에, 미주는 문서 끝에 표시한다
  4. ④각주와 미주는 동일한 위치에 표시된다
19다음 중 문서 작성 시 단축키에 대한 설명으로 옳지 않은 것은? 매회
  1. ①Ctrl+C는 선택한 내용을 복사한다
  2. ②Ctrl+V는 클립보드 내용을 붙여넣기 한다
  3. ③Ctrl+Z는 마지막 작업을 취소(되돌리기)한다
  4. ④Ctrl+S는 문서를 인쇄한다
20다음 중 프린터의 종류에 대한 설명으로 옳은 것은? 매회
  1. ①잉크젯 프린터는 열을 가해 토너를 종이에 정착시킨다
  2. ②레이저 프린터는 잉크를 분사하여 인쇄한다
  3. ③도트 매트릭스 프린터는 핀이 리본을 때려 인쇄하는 충격식이다
  4. ④3D 프린터는 2차원 평면 인쇄 전용이다
22과목: PC 운영체제Q21 – Q40
21다음 중 Windows 운영체제의 특징으로 옳지 않은 것은? 매회
  1. ①GUI(그래픽 사용자 인터페이스)를 제공한다
  2. ②멀티태스킹을 지원한다
  3. ③선점형 멀티태스킹 방식을 사용한다
  4. ④단일 사용자만 지원하며 네트워크 기능이 없다
22다음 중 바로 가기 아이콘에 대한 설명으로 옳지 않은 것은? 매회
  1. ①바로 가기 아이콘을 삭제하면 원본 파일도 함께 삭제된다
  2. ②바로 가기 아이콘에는 화살표 표시가 있다
  3. ③바로 가기 아이콘의 확장자는 .lnk이다
  4. ④하나의 파일에 여러 개의 바로 가기를 만들 수 있다
23다음 중 휴지통에 대한 설명으로 옳은 것은? 매회
  1. ①휴지통에서 파일을 복원하면 원래 위치로 되돌아간다
  2. ②USB 드라이브에서 삭제한 파일도 휴지통에 저장된다
  3. ③Shift+Delete로 삭제한 파일도 휴지통에 보관된다
  4. ④휴지통의 크기는 변경할 수 없다
24다음 중 Windows 작업 관리자에서 할 수 없는 것은? 자주
  1. ①현재 실행 중인 프로세스 목록을 확인한다
  2. ②응답하지 않는 프로그램을 강제 종료한다
  3. ③CPU 및 메모리 사용률을 모니터링한다
  4. ④하드디스크를 포맷한다
25다음 중 레지스트리(Registry)에 대한 설명으로 옳지 않은 것은? 자주
  1. ①Windows의 하드웨어·소프트웨어 설정 정보를 저장하는 데이터베이스이다
  2. ②레지스트리 편집기(regedit)로 직접 수정할 수 있다
  3. ③잘못 수정하면 시스템에 심각한 문제가 발생할 수 있다
  4. ④레지스트리는 텍스트 파일로 저장되어 메모장으로 편집한다
26다음 중 Windows의 제어판에서 설정할 수 없는 것은? 매회
  1. ①프린터 및 장치 추가
  2. ②프로그램 추가/제거
  3. ③디스플레이 해상도 변경
  4. ④BIOS 설정 변경
27다음 중 Windows 탐색기에 대한 설명으로 옳은 것은? 매회
  1. ①인터넷 웹 페이지를 탐색하는 프로그램이다
  2. ②파일과 폴더를 관리할 수 있는 파일 관리자이다
  3. ③탐색기에서는 파일 이름 변경이 불가능하다
  4. ④탐색기는 명령 프롬프트로만 실행할 수 있다
28다음 중 파일 확장자와 프로그램의 연결이 옳지 않은 것은? 매회
  1. ①.xlsx — 스프레드시트(Excel)
  2. ②.pptx — 프레젠테이션(PowerPoint)
  3. ③.docx — 워드 프로세서(Word)
  4. ④.hwp — 웹 브라우저(Chrome)
29다음 중 디스크 조각 모음에 대한 설명으로 옳은 것은? 매회
  1. ①흩어진 파일 조각을 연속된 공간에 재배치하여 성능을 향상시킨다
  2. ②디스크의 물리적 불량 섹터를 복구한다
  3. ③디스크의 데이터를 모두 삭제하는 포맷 작업이다
  4. ④SSD에서 반드시 정기적으로 수행해야 한다
30다음 중 안전 모드(Safe Mode)에 대한 설명으로 옳은 것은? 매회
  1. ①최소한의 드라이버와 서비스만으로 Windows를 시작한다
  2. ②모든 드라이버와 프로그램이 정상적으로 로드된다
  3. ③안전 모드에서는 인터넷 사용이 절대 불가능하다
  4. ④안전 모드는 Windows 설치 시에만 진입할 수 있다
31다음 중 가상 메모리(Virtual Memory)에 대한 설명으로 옳은 것은? 매회
  1. ①RAM을 증설하는 하드웨어적 방법이다
  2. ②캐시 메모리와 동일한 개념이다
  3. ③하드디스크의 일부를 RAM처럼 사용하여 메모리 부족을 해결한다
  4. ④가상 메모리는 RAM보다 속도가 빠르다
32다음 중 Windows의 사용자 계정 유형에 대한 설명으로 옳은 것은? 자주
  1. ①표준 사용자 계정은 시스템 설정을 자유롭게 변경할 수 있다
  2. ②관리자 계정은 소프트웨어 설치·삭제 및 시스템 설정 변경이 가능하다
  3. ③게스트 계정은 관리자 계정과 동일한 권한을 갖는다
  4. ④모든 사용자 계정은 동일한 권한을 가진다
33다음 중 클립보드(Clipboard)에 대한 설명으로 옳지 않은 것은? 자주
  1. ①복사(Ctrl+C)하거나 잘라내기(Ctrl+X)한 데이터가 임시로 저장된다
  2. ②붙여넣기(Ctrl+V)를 실행하면 클립보드의 내용이 삽입된다
  3. ③컴퓨터를 재시작해도 클립보드 내용은 영구 보존된다
  4. ④새로운 내용을 복사하면 이전 클립보드 내용은 대체된다
34다음 중 Windows 방화벽에 대한 설명으로 옳은 것은? 매회
  1. ①바이러스를 검사하고 치료하는 프로그램이다
  2. ②파일을 압축하여 저장 공간을 절약하는 도구이다
  3. ③네트워크를 통한 무단 접근을 차단하는 보안 소프트웨어이다
  4. ④운영체제를 업데이트하는 기능이다
35다음 중 드라이버(Driver)에 대한 설명으로 옳은 것은? 매회
  1. ①하드웨어를 물리적으로 연결하는 케이블이다
  2. ②운영체제와 하드웨어 장치 간의 통신을 담당하는 소프트웨어이다
  3. ③파일을 저장하는 보조 기억 장치이다
  4. ④프린터의 잉크를 교체하는 도구이다
36다음 중 PnP(Plug and Play)에 대한 설명으로 옳은 것은? 매회
  1. ①새 하드웨어를 연결하면 자동으로 인식하고 드라이버를 설치한다
  2. ②PnP는 소프트웨어 자동 업데이트 기능이다
  3. ③PnP는 네트워크 공유 기능을 의미한다
  4. ④PnP 기능은 Windows 95 이전부터 지원되었다
37다음 중 명령 프롬프트(CMD) 명령어의 기능이 옳은 것은? 매회
  1. ①dir — 현재 디렉터리의 파일과 폴더 목록을 표시한다
  2. ②format — 파일을 복사한다
  3. ③copy — 디스크를 포맷한다
  4. ④del — 디렉터리를 생성한다
38다음 중 파일 시스템에 대한 설명으로 옳지 않은 것은? 매회
  1. ①FAT32는 최대 4GB 파일 크기를 지원한다
  2. ②NTFS는 파일 단위의 접근 권한 설정이 가능하다
  3. ③NTFS는 파일 압축·암호화 기능을 지원한다
  4. ④FAT32는 NTFS보다 보안 기능이 우수하다
39다음 중 시스템 복원에 대한 설명으로 옳은 것은? 매회
  1. ①삭제한 개인 파일(문서, 사진)을 복구할 수 있다
  2. ②복원 지점을 기준으로 시스템 설정을 이전 상태로 되돌린다
  3. ③시스템 복원은 하드디스크를 포맷하는 것이다
  4. ④시스템 복원은 Windows 재설치와 동일하다
40다음 중 멀티부팅(Multi-Booting)에 대한 설명으로 옳은 것은? 자주
  1. ①하나의 컴퓨터에 두 개 이상의 운영체제를 설치하여 선택 부팅할 수 있다
  2. ②여러 프로그램을 동시에 실행하는 것이다
  3. ③하나의 CPU로 여러 작업을 처리하는 것이다
  4. ④여러 대의 컴퓨터를 하나로 연결하는 것이다

42다음 중 RAM과 ROM에 대한 설명으로 옳은 것은? 매회
  1. ①RAM은 전원이 꺼져도 데이터가 유지된다
  2. ②ROM은 읽기·쓰기가 자유롭다
  3. ③RAM은 휘발성 메모리이고 ROM은 비휘발성 메모리이다
  4. ④ROM은 용량이 크기 때문에 주기억장치로 주로 사용된다

44다음 중 논리 게이트(Logic Gate)에 대한 설명으로 옳은 것은? 매회
  1. ①AND 게이트는 입력 중 하나만 1이면 출력이 1이다
  2. ②OR 게이트는 모든 입력이 1이어야 출력이 1이다
  3. ③NOT 게이트는 입력 신호를 반전시킨다
  4. ④XOR 게이트는 입력이 같으면 출력이 1이다

  1. ①물리적 전기 신호로 데이터를 전송한다
  2. ②데이터의 경로를 설정하고 전달한다
  3. ③종단 간 신뢰성 있는 데이터 전송을 담당한다
  4. ④사용자 인터페이스를 제공한다
46다음 중 IPv4 주소에 대한 설명으로 옳은 것은? 매회

  2. ②32비트로 구성되어 있으며 약 43억 개의 주소를 제공한다
  3. ③영문자와 숫자를 혼합하여 표현한다
  4. ④IPv4는 IPv6보다 주소 공간이 넓다

  4. ④3행만 고정하고 열은 변하는 혼합 참조이다

  2. ②전 세계 모든 문자를 하나의 코드 체계로 통일한 국제 표준이다

  4. ④통신 에러 검출을 위한 코드이다
50다음 중 소프트웨어 분류에서 프리웨어(Freeware)에 대한 설명으로 옳은 것은? 자주

  2. ②소스 코드가 공개되어 자유롭게 수정·배포할 수 있는 소프트웨어이다

  4. ④반드시 구매해야 사용할 수 있는 상용 소프트웨어이다
51다음 중 RAID(Redundant Array of Independent Disks)에 대한 설명으로 옳은 것은? 자주
  1. ①하나의 디스크를 여러 파티션으로 나누는 기술이다
  2. ②여러 개의 디스크를 하나처럼 묶어 성능 향상이나 데이터 안전성을 높이는 기술이다
  3. ③디스크를 압축하여 저장 공간을 늘리는 기술이다
  4. ④CD-ROM 드라이브의 읽기 속도를 향상시키는 기술이다
52다음 중 TCP/IP 프로토콜에 대한 설명으로 옳은 것은? 매회
  1. ①파일을 압축하는 프로토콜이다
  2. ②인터넷에서 데이터 통신을 위한 표준 프로토콜이다
  3. ③전화 통신 전용 프로토콜이다
  4. ④하드웨어를 제어하는 프로토콜이다

56다음 중 USB(Universal Serial Bus)에 대한 설명으로 옳지 않은 것은? 매회
  1. ①직렬(Serial) 방식으로 데이터를 전송한다

  4. ④USB는 병렬 포트보다 전송 속도가 느리다

  3. ③MP3는 손실 압축 방식의 오디오 형식이다
  4. ④BMP는 압축률이 높아 파일 크기가 매우 작다
