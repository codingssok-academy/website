1다음 중 각주(Footnote)와 미주(Endnote)의 차이점으로 옳은 것은? 매회
  1. ①각주는 문서 끝에, 미주는 해당 페이지 하단에 표시된다
  2. ②각주와 미주는 모두 문서 끝에 표시된다
  3. ③각주는 해당 페이지 하단에, 미주는 문서 끝에 표시된다
  4. ④각주와 미주는 표시 위치가 동일하다
2다음 중 전결과 대결의 차이로 옳은 것은? 매회
  1. ①전결은 부재 시 대리 결재, 대결은 권한 위임 결재이다
  2. ②전결과 대결은 동일한 개념이다
  3. ③전결은 권한을 위임받아 최종 결재, 대결은 부재 시 대리 결재이다
  4. ④전결은 결재를 거부하는 것, 대결은 결재를 승인하는 것이다
3다음 중 복사(Copy)와 이동(Move)의 차이로 옳은 것은? 매회
  1. ①복사와 이동은 동일한 기능이다
  2. ②복사는 원본이 삭제되고, 이동은 원본이 유지된다
  3. ③복사는 원본이 남고 사본이 생기며, 이동은 원본이 사라지고 새 위치로 옮겨진다
  4. ④복사는 서식만, 이동은 내용만 적용된다
4다음 중 연결(Linking)과 삽입(Embedding)의 차이로 옳은 것은? 매회
  1. ①연결과 삽입은 차이가 없다
  2. ②연결은 원본과 독립적이고, 삽입은 원본 수정 시 반영된다
  3. ③연결은 원본 수정 시 반영되고, 삽입은 원본과 독립적이다
  4. ④연결은 텍스트만, 삽입은 이미지만 가능하다
5다음 중 머리말(Header)과 꼬리말(Footer)의 비교로 옳은 것은? 매회
  1. ①머리말에는 페이지 번호를 넣을 수 없다
  2. ②머리말만 인쇄되고 꼬리말은 인쇄되지 않는다
  3. ③머리말은 페이지 상단, 꼬리말은 페이지 하단에 표시된다
  4. ④꼬리말은 첫 페이지에만 표시된다
6다음 중 가로쓰기와 세로쓰기의 비교로 옳지 않은 것은? 자주
  1. ①가로쓰기는 왼쪽에서 오른쪽으로 글자를 나열한다
  2. ②세로쓰기는 위에서 아래로 글자를 나열한다
  3. ③세로쓰기에서 줄 번호는 오른쪽에서 왼쪽으로 매겨진다
  4. ④가로쓰기 문서는 세로쓰기로 변환할 수 없다
7다음 중 문단 정렬 방식의 비교로 옳은 것은? 매회
  1. ①양쪽 정렬은 왼쪽만 맞추고 오른쪽은 들쭉날쭉하다
  2. ②왼쪽 정렬은 양쪽 끝을 모두 맞춘다
  3. ③가운데 정렬은 문단의 각 줄이 가운데를 기준으로 정렬된다
  4. ④오른쪽 정렬은 글자 크기를 자동으로 조절한다
8다음 중 한 페이지 인쇄와 모아 찍기의 차이로 옳은 것은? 자주
  1. ①한 페이지 인쇄와 모아 찍기는 동일한 기능이다
  2. ②모아 찍기는 양면 인쇄를 의미한다
  3. ③한 페이지 인쇄는 한 장에 1페이지, 모아 찍기는 한 장에 여러 페이지를 축소 배치한다
  4. ④모아 찍기는 컬러 인쇄 전용 기능이다
9다음 중 글꼴(Font)에서 세리프(Serif)와 산세리프(Sans-Serif)의 차이로 옳은 것은? 자주
  1. ①세리프와 산세리프는 글자 크기의 차이이다
  2. ②산세리프는 글자 끝에 장식이 있고, 세리프는 장식이 없다
  3. ③세리프는 글자 끝에 장식(삐침)이 있고, 산세리프는 장식이 없다
  4. ④세리프는 영문 전용, 산세리프는 한글 전용이다
10다음 중 래스터(Raster) 이미지와 벡터(Vector) 이미지의 비교로 옳은 것은? 매회
  1. ①래스터는 확대해도 깨지지 않고, 벡터는 확대하면 깨진다
  2. ②래스터와 벡터는 동일한 방식이다
  3. ③래스터는 픽셀로 구성되어 확대 시 깨지고, 벡터는 수학 공식 기반이라 확대해도 깨지지 않는다
  4. ④벡터 이미지는 사진 촬영에 주로 사용된다
11다음 중 찾기(Find)와 바꾸기(Replace)의 비교로 옳지 않은 것은? 자주
  1. ①찾기는 특정 텍스트의 위치를 검색한다
  2. ②바꾸기는 찾은 텍스트를 다른 텍스트로 교체한다
  3. ③바꾸기에서 '모두 바꾸기'를 선택하면 일괄 교체된다
  4. ④찾기 기능에서는 서식 조건을 지정할 수 없다
12다음 중 도트 프린터와 레이저 프린터의 비교로 옳은 것은? 매회
  1. ①도트 프린터는 비충격식, 레이저 프린터는 충격식이다
  2. ②도트 프린터와 레이저 프린터는 동일한 인쇄 방식이다
  3. ③도트 프린터는 충격식으로 소음이 크고, 레이저 프린터는 비충격식으로 소음이 작다
  4. ④레이저 프린터는 복사 용지를 사용할 수 없다
13다음 중 상대 경로와 절대 경로의 차이로 옳은 것은? 자주
  1. ①절대 경로는 현재 위치를 기준으로 한다
  2. ②상대 경로는 루트(최상위)부터의 전체 경로이다
  3. ③절대 경로는 루트부터의 전체 경로, 상대 경로는 현재 위치 기준이다
  4. ④상대 경로와 절대 경로는 동일하다
14다음 중 들여쓰기와 내어쓰기의 비교로 옳은 것은? 매회
  1. ①들여쓰기는 첫 줄을 안쪽으로, 내어쓰기는 첫 줄을 바깥쪽으로 배치한다
  2. ②들여쓰기와 내어쓰기는 동일한 기능이다
  3. ③내어쓰기는 글자 크기를 줄이는 기능이다
  4. ④들여쓰기는 줄 간격을 넓히는 기능이다
15다음 중 공문서의 두문·본문·결문 구성이 올바르게 연결된 것은? 매회
  1. ①두문: 제목, 본문: 수신자, 결문: 붙임
  2. ②두문: 발신명의, 본문: 제목, 결문: 수신자
  3. ③두문: 수신자·경유, 본문: 제목·내용, 결문: 발신명의
  4. ④두문: 붙임, 본문: 발신명의, 결문: 수신자
16다음 중 교정 부호에서 '삽입'과 '삭제' 부호의 비교로 옳은 것은? 매회
  1. ①삽입 부호는 ∨(삽입 위치 표시), 삭제 부호는 해당 글자에 가로줄을 긋는다
  2. ②삽입 부호와 삭제 부호는 동일한 표시이다
  3. ③삭제 부호는 ∨ 모양이다
  4. ④삽입 부호는 해당 글자에 가로줄을 긋는다
17다음 중 한글 완성형과 조합형 코드의 차이로 옳은 것은? 자주
  1. ①완성형은 초성·중성·종성을 조합, 조합형은 완성된 글자에 코드 부여이다
  2. ②완성형과 조합형은 동일한 코드 체계이다
  3. ③완성형은 완성된 글자에 코드를 부여하고, 조합형은 초성·중성·종성 각각에 코드를 부여한다
  4. ④조합형만 유니코드에 포함된다
18다음 중 페이지 나누기와 구역 나누기의 차이로 옳은 것은? 자주
  1. ①페이지 나누기와 구역 나누기는 동일한 기능이다
  2. ②페이지 나누기는 인쇄 시 적용되지 않는다
  3. ③구역 나누기는 페이지 번호만 변경한다
  4. ④페이지 나누기는 새 페이지를 시작하고, 구역 나누기는 용지 크기·방향 등을 달리 설정할 수 있다
19다음 중 자동 저장과 수동 저장의 비교로 옳은 것은? 자주
  1. ①자동 저장은 사용자가 지정한 시간 간격으로 자동 저장되고, 수동 저장은 사용자가 직접 저장한다
  2. ②자동 저장은 수동 저장보다 안전하므로 수동 저장이 필요 없다
  3. ③수동 저장은 자동으로 백업본을 생성한다
  4. ④자동 저장은 최종 저장을 완전히 대체한다
20다음 중 글꼴(Font)에서 포인트(pt)와 급의 관계로 옳은 것은? 자주
  1. ①1포인트는 1급과 동일하다
  2. ②포인트와 급은 무게를 나타내는 단위이다
  3. ③급이 포인트보다 항상 크다
  4. ④1포인트는 약 0.3528mm이고, 1급은 0.25mm이다
22과목: PC 운영체제Q21 – Q40
21다음 중 FAT32와 NTFS 파일 시스템의 비교로 옳은 것은? 매회
  1. ①FAT32는 4GB 이상의 파일을 저장할 수 있고, NTFS는 4GB 미만만 가능하다
  2. ②FAT32는 파일 암호화를 지원하고 NTFS는 지원하지 않는다
  3. ③FAT32는 최대 파일 크기가 4GB이고, NTFS는 그 이상을 지원한다
  4. ④FAT32와 NTFS의 기능은 동일하다
22다음 중 CLI(Command Line Interface)와 GUI(Graphical User Interface)의 비교로 옳은 것은? 매회
  1. ①CLI는 아이콘 기반, GUI는 명령어 기반이다
  2. ②CLI와 GUI는 동일한 인터페이스이다
  3. ③GUI는 초보자에게 어렵고, CLI는 초보자에게 쉽다
  4. ④CLI는 명령어 입력 방식이고, GUI는 아이콘·메뉴 클릭 방식이다
23다음 중 단축키 Alt+F4와 Ctrl+W의 차이로 옳은 것은? 자주
  1. ①Alt+F4는 현재 문서(탭)를 닫고, Ctrl+W는 프로그램을 종료한다
  2. ②Alt+F4는 새 창을 여는 단축키이다
  3. ③두 단축키는 동일한 기능이다
  4. ④Alt+F4는 프로그램 자체를 종료하고, Ctrl+W는 현재 문서(탭)를 닫는다
24다음 중 절전 모드(Sleep)와 최대 절전 모드(Hibernate)의 차이로 옳은 것은? 매회
  1. ①절전 모드는 RAM에, 최대 절전 모드는 하드디스크에 현재 상태를 저장한다
  2. ②절전 모드는 하드디스크에, 최대 절전 모드는 RAM에 저장한다
  3. ③두 모드는 전력 소모가 동일하다
  4. ④최대 절전 모드는 전원을 끄지 않는다
25다음 중 포맷(Format)과 조각 모음(Defragmentation)의 차이로 옳은 것은? 매회
  1. ①포맷은 데이터를 정리하고, 조각 모음은 데이터를 삭제한다
  2. ②조각 모음을 하면 디스크의 데이터가 삭제된다
  3. ③포맷과 조각 모음은 동일한 기능이다
  4. ④포맷은 디스크의 모든 데이터를 삭제하고, 조각 모음은 흩어진 데이터를 재배치한다
26다음 중 복사(Copy)와 백업(Backup)의 비교로 옳은 것은? 자주
  1. ①복사와 백업은 동일한 개념이다
  2. ②복사는 데이터 보호 목적으로만 사용된다
  3. ③백업은 원본을 삭제하는 것이다
  4. ④복사는 파일을 다른 위치에 그대로 복제하는 것이고, 백업은 데이터 손실에 대비한 예비 보관이다
27다음 중 빠른 포맷과 일반 포맷의 차이로 옳은 것은? 자주
  1. ①빠른 포맷은 디스크 오류도 검사하고, 일반 포맷은 파일만 삭제한다
  2. ②일반 포맷이 빠른 포맷보다 속도가 빠르다
  3. ③두 포맷은 소요 시간이 동일하다
  4. ④빠른 포맷은 파일 시스템 정보만 초기화하고, 일반 포맷은 불량 섹터 검사도 수행한다
28다음 중 32비트 운영체제와 64비트 운영체제의 비교로 옳은 것은? 매회
  1. ①32비트는 최대 4GB RAM을 인식하고, 64비트는 그 이상을 인식할 수 있다
  2. ②64비트 OS에서 32비트 프로그램은 실행할 수 없다
  3. ③32비트와 64비트는 처리 속도가 동일하다
  4. ④32비트 OS가 64비트보다 더 많은 RAM을 인식한다
29다음 중 바이러스와 웜(Worm)의 차이로 옳은 것은? 매회
  1. ①바이러스는 독립 실행이 가능하고, 웜은 숙주 파일이 필요하다
  2. ②웜은 자기 복제 기능이 없다
  3. ③바이러스와 웜은 동일한 개념이다
  4. ④바이러스는 숙주 파일에 기생하고, 웜은 독립적으로 실행·전파된다
30다음 중 시스템 복원과 초기화(리셋)의 차이로 옳은 것은? 매회
  1. ①시스템 복원은 특정 시점으로 되돌리고, 초기화는 공장 출하 상태로 만든다
  2. ②시스템 복원과 초기화는 동일한 기능이다
  3. ③초기화는 개인 파일이 유지되고, 시스템 복원은 모든 파일이 삭제된다
  4. ④시스템 복원은 하드웨어를 교체하는 것이다
31다음 중 공유 폴더와 로컬 폴더의 비교로 옳은 것은? 자주
  1. ①공유 폴더는 네트워크 상 다른 컴퓨터에서 접근할 수 있고, 로컬 폴더는 해당 PC에서만 접근 가능하다
  2. ②로컬 폴더도 자동으로 네트워크에 공유된다
  3. ③공유 폴더는 인터넷에서만 접근 가능하다
  4. ④공유 폴더와 로컬 폴더는 차이가 없다
32다음 중 관리자(Administrator) 계정과 표준 사용자 계정의 차이로 옳은 것은? 매회
  1. ①표준 사용자도 시스템 설정을 자유롭게 변경할 수 있다
  2. ②표준 사용자 계정으로만 프로그램을 설치할 수 있다
  3. ③관리자 계정과 표준 사용자 계정의 권한은 동일하다
  4. ④관리자 계정은 프로그램 설치·시스템 설정 변경 등 모든 권한을 갖고, 표준 사용자는 제한된 권한을 가진다
33다음 중 압축 풀기와 압축하기의 비교로 옳은 것은? 자주
  1. ①압축하기는 파일 크기를 줄이고, 압축 풀기는 원래 크기로 복원한다
  2. ②압축하기와 압축 풀기는 동일한 작업이다
  3. ③압축 풀기를 하면 파일이 삭제된다
  4. ④압축하기는 파일 크기를 늘린다
34다음 중 선점형 멀티태스킹과 비선점형 멀티태스킹의 차이로 옳은 것은? 자주
  1. ①선점형은 프로그램이 자발적으로 CPU를 양보하고, 비선점형은 OS가 강제로 전환한다
  2. ②비선점형이 현대 OS에서 주로 사용된다
  3. ③두 방식은 차이가 없다
  4. ④선점형은 OS가 CPU 할당을 강제로 전환하고, 비선점형은 프로그램이 자발적으로 양보한다
35다음 중 장치 관리자와 작업 관리자의 비교로 옳은 것은? 매회
  1. ①장치 관리자는 하드웨어 장치를 관리하고, 작업 관리자는 실행 중인 프로그램과 프로세스를 관리한다
  2. ②작업 관리자는 하드웨어 장치를 관리한다
  3. ③장치 관리자는 프로그램의 CPU 사용률을 확인한다
  4. ④두 관리자는 동일한 기능이다
36다음 중 로컬 프린터와 네트워크 프린터의 차이로 옳은 것은? 자주
  1. ①로컬 프린터는 해당 PC에 직접 연결되고, 네트워크 프린터는 네트워크를 통해 공유된다
  2. ②네트워크 프린터는 USB로만 연결된다
  3. ③로컬 프린터와 네트워크 프린터는 동일하다
  4. ④로컬 프린터는 여러 PC에서 동시에 사용할 수 있다
37다음 중 Windows 바탕 화면 아이콘 보기 방식의 비교로 옳은 것은? 자주
  1. ①큰 아이콘, 보통 아이콘, 작은 아이콘 중 선택할 수 있다
  2. ②아이콘 크기는 변경할 수 없다
  3. ③바탕 화면에서는 목록 보기만 가능하다
  4. ④아이콘 보기 방식은 운영체제 재설치 후에만 변경할 수 있다
38다음 중 로그온(Log on)과 로그오프(Log off)의 비교로 옳은 것은? 자주
  1. ①로그온은 시스템에 사용자 인증 후 접속하는 것이고, 로그오프는 접속을 해제하는 것이다
  2. ②로그온과 로그오프는 동일한 개념이다
  3. ③로그오프를 하면 컴퓨터 전원이 꺼진다
  4. ④로그온은 프로그램 설치를 의미한다
39다음 중 프로그램 설치와 프로그램 제거의 비교로 옳은 것은? 자주
  1. ①프로그램 제거 시 관련 레지스트리 정보도 함께 삭제된다
  2. ②프로그램 제거는 파일만 삭제하고 레지스트리는 남긴다
  3. ③프로그램을 제거하려면 반드시 안전 모드에서 해야 한다
  4. ④프로그램 설치와 제거는 제어판에서 관리할 수 없다
40다음 중 확장자 .exe와 .dll의 비교로 옳은 것은? 자주
  1. ①.exe는 실행 파일이고, .dll은 여러 프로그램이 공유하는 라이브러리 파일이다
  2. ②.exe와 .dll은 동일한 기능의 파일이다
  3. ③.dll은 직접 더블 클릭으로 실행된다
  4. ④.exe는 라이브러리 파일이다

41다음 중 RAM과 ROM의 비교로 옳은 것은? 매회
  1. ①RAM은 비휘발성이고, ROM은 휘발성이다
  2. ②ROM은 읽기·쓰기 모두 자유롭다
  3. ③RAM과 ROM은 동일한 메모리이다
  4. ④RAM은 휘발성(전원 OFF 시 삭제)이고, ROM은 비휘발성(전원 OFF에도 유지)이다
42다음 중 HDD와 SSD의 비교로 옳은 것은? 매회
  1. ①HDD는 반도체 기반이고, SSD는 자기 디스크 기반이다
  2. ②SSD는 소음과 진동이 HDD보다 크다
  3. ③HDD가 SSD보다 읽기 속도가 빠르다
  4. ④HDD는 자기 디스크(플래터)에, SSD는 반도체(플래시 메모리)에 데이터를 저장한다
43다음 중 직렬(Serial) 전송과 병렬(Parallel) 전송의 비교로 옳은 것은? 매회
  1. ①직렬은 여러 비트를 동시에, 병렬은 한 비트씩 전송한다
  2. ②병렬 전송은 원거리 통신에 적합하다
  3. ③직렬 전송은 항상 병렬보다 빠르다
  4. ④직렬은 한 비트씩 순서대로, 병렬은 여러 비트를 동시에 전송한다
44다음 중 IPv4와 IPv6의 비교로 옳은 것은? 매회
  1. ①IPv4는 128비트, IPv6는 32비트 주소 체계이다
  2. ②IPv4는 32비트(약 43억 개), IPv6는 128비트(사실상 무한)의 주소 체계이다
  3. ③IPv4와 IPv6는 주소 크기가 동일하다
  4. ④IPv6는 IPv4보다 주소 수가 적다
45다음 중 유선 네트워크(LAN)와 무선 네트워크(Wi-Fi)의 비교로 옳은 것은? 매회
  1. ①유선은 케이블로 연결하여 안정적이고, 무선은 전파로 연결하여 이동성이 좋다
  2. ②무선이 유선보다 항상 빠르다
  3. ③유선은 보안이 약하고 무선은 보안이 강하다
  4. ④유선과 무선의 속도는 항상 동일하다
46다음 중 주기억장치와 보조기억장치의 비교로 옳은 것은? 매회
  1. ①주기억장치는 속도가 느리고, 보조기억장치는 속도가 빠르다
  2. ②주기억장치(RAM)는 속도가 빠르고 휘발성이며, 보조기억장치(HDD/SSD)는 느리지만 비휘발성이다
  3. ③주기억장치와 보조기억장치의 용량은 동일하다
  4. ④보조기억장치는 CPU가 직접 접근한다
47다음 중 입력장치와 출력장치의 분류로 옳은 것은? 매회
  1. ①프린터는 입력장치, 키보드는 출력장치이다
  2. ②모니터와 스피커는 입력장치이다
  3. ③키보드와 마우스는 입력장치, 프린터와 모니터는 출력장치이다
  4. ④스캐너는 출력장치이다
48다음 중 인트라넷(Intranet)과 인터넷(Internet)의 차이로 옳은 것은? 자주
  1. ①인트라넷은 전 세계 개방 네트워크, 인터넷은 조직 내부 네트워크이다
  2. ②인트라넷은 조직 내부 전용 네트워크, 인터넷은 전 세계 개방 네트워크이다
  3. ③인트라넷과 인터넷은 동일한 개념이다
  4. ④인터넷은 사내에서만 접속 가능하다
49다음 중 SMTP와 POP3의 비교로 옳은 것은? 매회
  1. ①SMTP는 메일 수신, POP3는 메일 발신 프로토콜이다
  2. ②SMTP는 메일 발신(보내기), POP3는 메일 수신(받기) 프로토콜이다
  3. ③SMTP와 POP3는 동일한 프로토콜이다
  4. ④POP3는 웹 페이지를 전송하는 프로토콜이다
50다음 중 TCP와 UDP의 비교로 옳은 것은? 매회
  1. ①TCP는 비연결형이고, UDP는 연결형이다
  2. ②TCP는 연결형으로 신뢰성이 높고, UDP는 비연결형으로 속도가 빠르다
  3. ③TCP와 UDP는 동일한 프로토콜이다
  4. ④UDP는 데이터 재전송 기능이 있다
51다음 중 BMP와 JPG 이미지 파일의 비교로 옳은 것은? 매회
  1. ①BMP는 압축 파일이고, JPG는 비압축 파일이다
  2. ②BMP는 비압축(무손실)으로 파일 크기가 크고, JPG는 손실 압축으로 파일 크기가 작다
  3. ③BMP와 JPG는 동일한 파일 형식이다
  4. ④JPG는 비트맵 형식이 아니다
52다음 중 허브(Hub)와 스위치(Switch)의 비교로 옳은 것은? 매회
  1. ①허브는 목적지를 식별하여 전송하고, 스위치는 모든 포트에 데이터를 전송한다
  2. ②허브는 모든 포트에 데이터를 전송(브로드캐스트)하고, 스위치는 목적지 포트만 식별하여 전송한다
  3. ③허브와 스위치는 동일한 장비이다
  4. ④스위치는 네트워크에 연결할 수 없다
53다음 중 스파이웨어(Spyware)와 애드웨어(Adware)의 차이로 옳은 것은? 자주
  1. ①스파이웨어는 광고를 표시하고, 애드웨어는 정보를 몰래 수집한다
  2. ②스파이웨어는 사용자 정보를 몰래 수집하고, 애드웨어는 광고를 강제로 표시한다
  3. ③스파이웨어와 애드웨어는 동일하다
  4. ④애드웨어는 바이러스의 한 종류이다
54다음 중 공개키 암호화와 대칭키(비밀키) 암호화의 비교로 옳은 것은? 자주
  1. ①공개키는 암호화·복호화에 같은 키를 사용하고, 대칭키는 서로 다른 키를 사용한다
  2. ②공개키는 암호화·복호화에 서로 다른 키를 사용하고, 대칭키는 같은 키를 사용한다
  3. ③공개키와 대칭키 암호화는 동일한 방식이다
  4. ④대칭키 방식이 공개키보다 키 관리가 쉽다
55다음 중 캐시 메모리(Cache)와 RAM의 비교로 옳은 것은? 매회
  1. ①캐시는 RAM보다 느리고 용량이 크다
  2. ②캐시는 RAM보다 빠르고 용량이 작으며, CPU와 RAM 사이의 속도 차를 줄인다
  3. ③캐시와 RAM은 동일한 메모리이다
  4. ④RAM이 캐시보다 CPU에 더 가깝다
56다음 중 컴파일러(Compiler)와 인터프리터(Interpreter)의 비교로 옳은 것은? 매회
  1. ①컴파일러는 한 줄씩 해석하고, 인터프리터는 전체를 한 번에 번역한다
  2. ②컴파일러는 소스 전체를 한 번에 기계어로 번역하고, 인터프리터는 한 줄씩 해석하여 실행한다
  3. ③컴파일러와 인터프리터는 동일한 방식이다
  4. ④인터프리터는 실행 파일을 생성한다
57다음 중 트로이 목마(Trojan Horse)와 랜섬웨어(Ransomware)의 차이로 옳은 것은? 매회
  1. ①트로이 목마는 데이터를 암호화하고 몸값을 요구한다
  2. ②트로이 목마는 정상 프로그램으로 위장하여 침투하고, 랜섬웨어는 데이터를 암호화한 뒤 돈을 요구한다
  3. ③트로이 목마와 랜섬웨어는 동일한 악성코드이다
  4. ④랜섬웨어는 자기 복제 기능이 핵심이다
58다음 중 LAN(Local Area Network)과 WAN(Wide Area Network)의 비교로 옳은 것은? 매회
  1. ①LAN은 광범위 지역, WAN은 좁은 지역 네트워크이다
  2. ②LAN은 건물·학교 등 좁은 지역, WAN은 도시·국가 등 넓은 지역 네트워크이다
  3. ③LAN과 WAN은 동일한 범위이다
  4. ④WAN이 LAN보다 전송 속도가 항상 빠르다
59다음 중 절대 주소와 상대 주소의 비교(스프레드시트 기준)로 옳은 것은? 매회
  1. ①절대 주소는 복사 시 셀 주소가 자동 변경되고, 상대 주소는 고정된다
  2. ②절대 주소($A$1)는 복사해도 고정되고, 상대 주소(A1)는 복사 시 자동 변경된다
  3. ③절대 주소와 상대 주소는 동일하다
  4. ④상대 주소는 $ 기호를 사용한다
60다음 중 라우터(Router)와 게이트웨이(Gateway)의 비교로 옳은 것은? 자주
  1. ①라우터는 서로 다른 프로토콜을 변환하고, 게이트웨이는 같은 프로토콜 내 경로를 설정한다
  2. ②라우터는 최적 경로를 설정하여 패킷을 전달하고, 게이트웨이는 서로 다른 프로토콜의 네트워크를 연결한다
  3. ③라우터와 게이트웨이는 동일한 장비이다
  4. ④게이트웨이는 물리 계층에서만 동작한다
