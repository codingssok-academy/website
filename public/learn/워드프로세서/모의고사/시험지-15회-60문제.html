1다음 중 머리말/꼬리말에 대한 설명으로 옳은 것은? 매회
  1. ①문서의 본문 첫 줄에 자동으로 삽입되는 제목이다
  2. ②문서의 마지막 페이지에만 표시되는 요약 정보이다
  3. ③각 페이지의 상단(머리말) 또는 하단(꼬리말)에 반복 출력되는 영역이다
  4. ④표의 첫 행과 마지막 행을 가리키는 용어이다
2다음 중 각주(脚註)라는 용어에 대한 설명으로 옳지 않은 것은? 매회
  1. ①본문의 특정 단어나 문장에 대한 보충 설명을 해당 페이지 하단에 표시한다
  2. ②각주와 미주는 동일한 위치에 표시된다
  3. ③각주 번호는 본문에 위 첨자로 자동 삽입된다
  4. ④논문이나 보고서에서 출처를 밝힐 때 주로 사용한다
3다음 중 단(段, Column)에 대한 설명으로 옳은 것은? 매회
  1. ①한 페이지를 세로로 여러 구역으로 나누어 텍스트를 배치하는 기능이다
  2. ②페이지를 가로로 나누어 상·하로 내용을 분리하는 기능이다
  3. ③문서에 표를 삽입할 때만 사용할 수 있는 기능이다
  4. ④인쇄 시 용지를 물리적으로 절단하는 기능이다
4다음 중 서식(Format)이라는 용어의 의미로 가장 적절한 것은? 매회
  1. ①문서 파일을 다른 확장자로 변환하는 작업이다
  2. ②문서 내용을 검색하여 바꾸는 기능이다
  3. ③하드디스크를 초기화하는 작업이다
  4. ④문자·문단·페이지 등의 모양과 배치를 설정하는 것이다
5다음 중 교정부호의 종류와 의미가 옳지 않은 것은? 매회
  1. ①∨ — 빠진 글자를 삽입하라는 표시이다
  2. ②⌒ — 글자나 단어를 삭제하라는 표시이다
  3. ③⌢ — 글자 크기를 키우라는 표시이다
  4. ④↵ — 줄을 바꾸라는 표시이다
6다음 중 블록(Block) 설정에 대한 설명으로 옳은 것은? 매회
  1. ①하드디스크의 저장 단위를 의미한다
  2. ②문서에서 특정 영역을 선택(지정)하여 편집 대상으로 만드는 것이다
  3. ③네트워크 보안에서 접근을 차단하는 것이다
  4. ④프린터에서 용지 걸림을 해제하는 절차이다
7다음 중 매크로(Macro)에 대한 설명으로 옳은 것은? 자주
  1. ①반복적인 작업을 자동으로 실행할 수 있도록 기록해 둔 명령 집합이다
  2. ②문서에 삽입하는 그림 파일의 한 종류이다
  3. ③프린터의 인쇄 품질을 높이는 해상도 설정이다
  4. ④문서 파일을 압축하여 용량을 줄이는 기능이다
8다음 중 텍스트 파일(TXT)에 대한 설명으로 옳지 않은 것은? 자주
  1. ①서식 정보 없이 순수한 문자 데이터만 저장한다
  2. ②어떤 운영체제에서든 열어볼 수 있는 범용 파일 형식이다
  3. ③메모장(Notepad) 등 기본 편집기로 편집 가능하다
  4. ④그림·표·글꼴 정보를 함께 저장할 수 있다
9다음 중 WYSIWYG라는 용어의 의미로 올바른 것은? 매회
  1. ①문서를 암호화하여 보안을 강화하는 기술이다
  2. ②여러 사용자가 동시에 문서를 편집하는 기술이다
  3. ③화면에 보이는 그대로 인쇄 결과물이 출력되는 것을 뜻한다
  4. ④문서를 자동으로 번역해 주는 기능이다
10다음 중 스타일(Style)에 대한 설명으로 옳은 것은? 자주
  1. ①문서에 삽입된 이미지의 해상도를 조절하는 기능이다
  2. ②글꼴·크기·정렬 등 서식 설정을 묶어 이름을 붙여 놓은 것이다
  3. ③맞춤법 검사를 수행하는 도구이다
  4. ④문서의 인쇄 매수를 설정하는 기능이다
11다음 중 메일 머지(Mail Merge)에 대한 설명으로 옳은 것은? 매회
  1. ①본문 양식에 데이터 파일의 정보를 결합하여 여러 문서를 한꺼번에 만드는 기능이다
  2. ②이메일을 자동으로 분류하여 폴더에 저장하는 기능이다
  3. ③두 개의 문서 파일을 하나로 합치는 기능이다
  4. ④문서에 전자우편 주소를 하이퍼링크로 삽입하는 기능이다
12다음 중 들여쓰기에 대한 설명으로 옳지 않은 것은? 자주
  1. ①문단의 첫 줄 또는 전체를 안쪽으로 밀어 넣어 정렬하는 것이다
  2. ②왼쪽 들여쓰기, 오른쪽 들여쓰기, 첫 줄 들여쓰기 등이 있다
  3. ③문단 시작 위치를 조절하여 가독성을 높이는 편집 기능이다
  4. ④들여쓰기를 하면 글꼴 크기가 자동으로 작아진다
13다음 중 워터마크(Watermark)에 대한 설명으로 옳은 것은? 자주
  1. ①문서 내 하이퍼링크를 자동으로 생성하는 기능이다
  2. ②문서 본문 뒤에 희미하게 표시되는 배경 텍스트나 이미지이다
  3. ③인쇄 시 용지에 물을 뿌려 잉크를 번지게 하는 효과이다
  4. ④문서 저장 시 자동으로 백업 파일을 만드는 기능이다
14다음 중 공문서에 대한 설명으로 옳지 않은 것은? 매회
  1. ①공문서의 날짜는 음력을 기준으로 표기한다
  2. ②행정기관이 공무상 작성하거나 접수한 문서를 말한다
  3. ③두문·본문·결문으로 구성된다
  4. ④수신자는 두문에 기재하며, 발신 명의는 결문에 기재한다
15다음 중 전자출판(DTP)에 대한 설명으로 옳은 것은? 자주
  1. ①전자우편을 통해 문서를 전송하는 기능이다
  2. ②전자칠판에 문서를 띄우는 프레젠테이션 기술이다
  3. ③컴퓨터를 이용하여 원고 작성부터 편집·조판·인쇄까지 처리하는 출판 방식이다
  4. ④문서를 전자서명으로 인증하는 보안 기술이다
16다음 중 OCR(광학 문자 인식)에 대한 설명으로 옳은 것은? 매회
  1. ①모니터 화면의 해상도를 높이는 기술이다
  2. ②문서에 음성 파일을 삽입하는 기능이다
  3. ③프린터의 잉크 잔량을 확인하는 기술이다
  4. ④인쇄된 문서나 이미지 속 문자를 스캔하여 편집 가능한 텍스트로 변환하는 기술이다
17다음 중 하이퍼텍스트(Hypertext)에 대한 설명으로 옳지 않은 것은? 자주
  1. ①순차적으로만 읽어야 하는 선형 구조의 문서이다
  2. ②문서 안에서 다른 문서나 위치로 바로 이동할 수 있는 링크 구조이다
  3. ③HTML은 하이퍼텍스트를 구현하기 위한 대표적 언어이다
  4. ④웹 페이지가 하이퍼텍스트의 대표적인 예이다
18다음 중 개체 삽입(OLE)에 대한 설명으로 옳은 것은? 자주
  1. ①문서에서 맞춤법 오류를 자동으로 수정하는 기능이다
  2. ②다른 프로그램에서 만든 개체(그림·표·차트 등)를 문서에 연결하거나 삽입하는 기능이다
  3. ③문서의 글자 수를 자동으로 세어 주는 기능이다
  4. ④문서를 전자우편으로 발송하는 기능이다
19다음 중 탭(Tab)에 대한 설명으로 옳지 않은 것은? 자주
  1. ①커서를 미리 설정된 위치로 이동시키는 기능이다
  2. ②왼쪽 탭, 가운데 탭, 오른쪽 탭, 소수점 탭 등의 종류가 있다
  3. ③탭 간격은 사용자가 임의로 변경할 수 없다
  4. ④표를 사용하지 않고도 텍스트를 깔끔하게 정렬할 수 있다
20다음 중 상용구에 대한 설명으로 옳은 것은? 자주
  1. ①문서를 인쇄할 때 사용하는 프린터 드라이버이다
  2. ②문서의 배경 색상을 지정하는 기능이다
  3. ③문서 파일을 읽기 전용으로 잠그는 기능이다
  4. ④자주 사용하는 문구나 문장을 미리 등록해 두고 빠르게 입력하는 기능이다
2PC 운영체제Q21 – Q40
21다음 중 운영체제(OS)에 대한 설명으로 옳지 않은 것은? 매회
  1. ①하드웨어와 사용자 사이의 중재 역할을 하는 시스템 소프트웨어이다
  2. ②응용 소프트웨어 없이는 운영체제가 작동하지 않는다
  3. ③프로세스 관리, 메모리 관리, 파일 관리 등의 기능을 수행한다
  4. ④Windows, Linux, macOS 등이 대표적인 운영체제이다
22다음 중 커널(Kernel)에 대한 설명으로 옳은 것은? 매회
  1. ①사용자가 명령어를 입력하는 인터페이스이다
  2. ②응용 프로그램을 설치하는 유틸리티 도구이다
  3. ③운영체제의 핵심 부분으로 하드웨어 자원을 직접 관리하는 프로그램이다
  4. ④네트워크 접속을 위한 프로토콜이다
23다음 중 가상 메모리(Virtual Memory)에 대한 설명으로 옳은 것은? 매회
  1. ①RAM이 부족할 때 하드디스크 일부를 메모리처럼 사용하는 기술이다
  2. ②USB 메모리를 가상으로 인식하는 기술이다
  3. ③클라우드에 데이터를 저장하는 기술이다
  4. ④모니터 화면 해상도를 높이는 기술이다
24다음 중 레지스트리(Registry)에 대한 설명으로 옳은 것은? 매회
  1. ①Windows에서 시스템 설정·프로그램 정보 등을 저장하는 계층형 데이터베이스이다
  2. ②인터넷 브라우저의 즐겨찾기 목록이다
  3. ③하드디스크를 분할하는 유틸리티이다
  4. ④바이러스를 검사하는 보안 프로그램이다
25다음 중 드라이버(Driver)에 대한 설명으로 옳지 않은 것은? 매회
  1. ①하드웨어 장치를 운영체제가 인식하고 제어할 수 있도록 하는 소프트웨어이다
  2. ②프린터, 그래픽카드, 사운드카드 등 각 장치마다 전용 드라이버가 필요하다
  3. ③드라이버가 없으면 해당 하드웨어를 정상적으로 사용할 수 없다
  4. ④드라이버는 응용 프로그램의 한 종류이다
26다음 중 BIOS(Basic Input Output System)에 대한 설명으로 옳은 것은? 매회
  1. ①운영체제 설치 후에만 사용할 수 있는 프로그램이다
  2. ②인터넷 브라우저의 시작 페이지를 설정하는 프로그램이다
  3. ③컴퓨터 전원을 켜면 가장 먼저 실행되어 하드웨어를 초기화하고 운영체제 부팅을 시작하는 펌웨어이다
  4. ④USB 장치를 자동으로 인식하는 응용 프로그램이다
27다음 중 파일 시스템(File System)에 대한 설명으로 옳지 않은 것은? 자주
  1. ①저장 장치에 파일을 저장·관리하는 방식과 구조를 정의한 체계이다
  2. ②파일 시스템은 CPU 속도와 직접 관련이 있다
  3. ③NTFS, FAT32, exFAT 등이 대표적인 파일 시스템이다
  4. ④포맷(Format)을 하면 파일 시스템이 새로 구성된다
28다음 중 안전 모드(Safe Mode)에 대한 설명으로 옳은 것은? 매회
  1. ①게임 실행 시 눈 보호를 위해 밝기를 낮추는 기능이다
  2. ②파일을 암호화하여 안전하게 보관하는 기능이다
  3. ③USB 장치를 안전하게 제거하는 기능이다
  4. ④Windows 시스템에 문제가 생겼을 때 최소한의 드라이버와 서비스만으로 부팅하는 진단 모드이다
29다음 중 플러그 앤 플레이(Plug and Play)에 대한 설명으로 옳은 것은? 매회
  1. ①전원 플러그를 꽂으면 컴퓨터가 자동으로 켜지는 기능이다
  2. ②새 하드웨어를 연결하면 운영체제가 자동으로 인식하고 설정하는 기능이다
  3. ③음악 플레이어를 자동으로 설치하는 기능이다
  4. ④네트워크 케이블을 꽂으면 인터넷 속도가 2배로 빨라지는 기능이다
30다음 중 클립보드(Clipboard)에 대한 설명으로 옳지 않은 것은? 자주
  1. ①클립보드의 내용은 컴퓨터를 재부팅해도 영구적으로 보관된다
  2. ②복사(Ctrl+C)나 잘라내기(Ctrl+X) 시 데이터가 임시 저장되는 메모리 영역이다
  3. ③붙여넣기(Ctrl+V)를 하면 클립보드 내용이 삽입된다
  4. ④Windows 10/11에서는 클립보드 기록(Win+V)을 지원한다
31다음 중 DLL(Dynamic Link Library)에 대한 설명으로 옳은 것은? 자주
  1. ①동영상 파일을 재생하는 미디어 플레이어이다
  2. ②여러 프로그램이 공유하여 사용할 수 있는 함수·자원의 라이브러리 파일이다
  3. ③디스크를 조각 모음하는 유틸리티이다
  4. ④데이터를 암호화하는 보안 프로토콜이다
32다음 중 작업 관리자(Task Manager)에 대한 설명으로 옳지 않은 것은? 매회
  1. ①현재 실행 중인 프로세스와 성능 상태를 확인할 수 있다
  2. ②응답 없는 프로그램을 강제 종료할 수 있다
  3. ③하드디스크의 파티션을 나누는 기능을 제공한다
  4. ④Ctrl+Shift+Esc 또는 Ctrl+Alt+Del로 실행할 수 있다
33다음 중 바로가기(Shortcut)에 대한 설명으로 옳은 것은? 자주
  1. ①원본 파일이나 폴더의 위치를 가리키는 연결 파일로, 삭제해도 원본은 영향받지 않는다
  2. ②원본 파일을 복사하여 다른 위치에 저장한 파일이다
  3. ③바로가기를 삭제하면 원본 파일도 함께 삭제된다
  4. ④바로가기 파일은 원본 파일과 동일한 크기를 차지한다
34다음 중 디스크 조각 모음(Defragmentation)에 대한 설명으로 옳은 것은? 자주
  1. ①하드디스크를 여러 파티션으로 분할하는 작업이다
  2. ②삭제된 파일을 복구하는 작업이다
  3. ③SSD에 반드시 실행해야 하는 필수 유지보수 작업이다
  4. ④흩어져 저장된 파일 조각들을 연속적으로 재배치하여 읽기 속도를 향상시키는 작업이다
35다음 중 멀티태스킹(Multitasking)에 대한 설명으로 옳은 것은? 매회
  1. ①여러 대의 컴퓨터를 네트워크로 연결하는 기술이다
  2. ②하나의 프로그램을 여러 컴퓨터에서 동시에 실행하는 기술이다
  3. ③하나의 컴퓨터에서 여러 작업(프로그램)을 동시에 처리하는 것이다
  4. ④CPU를 여러 개 장착하는 하드웨어 기술이다
36다음 중 제어판(Control Panel)에 대한 설명으로 옳지 않은 것은? 자주
  1. ①제어판에서 하드디스크를 물리적으로 교체할 수 있다
  2. ②Windows 시스템 설정을 변경할 수 있는 관리 도구이다
  3. ③프로그램 추가/제거, 네트워크 설정, 사용자 계정 관리 등을 할 수 있다
  4. ④Windows 10/11에서는 '설정' 앱이 제어판의 많은 기능을 대체하고 있다
37다음 중 시스템 복원(System Restore)에 대한 설명으로 옳은 것은? 매회
  1. ①삭제된 개인 파일(사진, 문서)을 복구하는 기능이다
  2. ②시스템 설정과 프로그램 상태를 이전 시점으로 되돌리는 기능이다
  3. ③하드디스크를 공장 초기화하는 기능이다
  4. ④바이러스에 감염된 파일을 치료하는 기능이다
38다음 중 환경 변수(Environment Variable)에 대한 설명으로 옳은 것은? 자주
  1. ①모니터의 밝기와 색온도를 조절하는 설정이다
  2. ②에어컨의 온도를 원격으로 제어하는 IoT 기능이다
  3. ③운영체제나 프로그램이 참조하는 시스템 경로·설정값을 저장하는 변수이다
  4. ④프린터 용지 크기를 설정하는 값이다
39다음 중 방화벽(Firewall)에 대한 설명으로 옳지 않은 것은? 매회
  1. ①외부 네트워크로부터 내부 시스템을 보호하는 보안 장치 또는 소프트웨어이다
  2. ②허가된 트래픽만 통과시키고 비인가 접근을 차단한다
  3. ③Windows에는 기본으로 Windows 방화벽이 내장되어 있다
  4. ④방화벽만 설치하면 모든 바이러스를 100% 차단할 수 있다
40다음 중 부팅(Booting)에 대한 설명으로 옳은 것은? 매회
  1. ①컴퓨터의 전원을 끄는 과정이다
  2. ②운영체제를 삭제하는 과정이다
  3. ③응용 프로그램을 설치하는 과정이다
  4. ④컴퓨터 전원을 켜고 운영체제를 메모리에 적재하여 사용 가능 상태로 만드는 과정이다

41다음 중 CPU(중앙처리장치)에 대한 설명으로 옳지 않은 것은? 매회
  1. ①컴퓨터의 모든 연산과 제어를 담당하는 핵심 장치이다
  2. ②CPU는 데이터를 영구적으로 저장하는 장치이다
  3. ③제어장치(CU), 연산장치(ALU), 레지스터로 구성된다
  4. ④CPU의 성능은 클럭 속도(GHz)와 코어 수에 영향을 받는다
42다음 중 RAM(주기억장치)에 대한 설명으로 옳은 것은? 매회
  1. ①전원이 꺼져도 데이터가 보존되는 비휘발성 메모리이다
  2. ②하드디스크보다 용량이 크고 속도가 느린 저장장치이다
  3. ③CPU가 현재 처리 중인 데이터와 프로그램을 임시로 저장하는 휘발성 메모리이다
  4. ④읽기만 가능하고 쓰기는 불가능한 메모리이다
43다음 중 SSD(Solid State Drive)에 대한 설명으로 옳지 않은 것은? 매회
  1. ①반도체 플래시 메모리를 이용하여 데이터를 저장하는 보조기억장치이다
  2. ②기계적 회전 부품이 없어 HDD보다 소음이 적고 속도가 빠르다
  3. ③HDD보다 충격에 강하고 전력 소모가 적다
  4. ④HDD보다 동일 용량 대비 가격이 저렴하다
44다음 중 USB(Universal Serial Bus)에 대한 설명으로 옳은 것은? 자주
  1. ①키보드·마우스·프린터 등 다양한 주변 장치를 연결하는 범용 직렬 인터페이스이다
  2. ②컴퓨터 내부 CPU와 메모리를 연결하는 버스이다
  3. ③모니터의 화면 해상도를 결정하는 규격이다
  4. ④무선 통신 전용 인터페이스이다
45다음 중 IP 주소에 대한 설명으로 옳지 않은 것은? 매회
  1. ①인터넷에 연결된 각 장치를 식별하기 위한 고유 주소이다
  2. ②IP 주소는 한 번 할당되면 절대 변경할 수 없다
  3. ③IPv4는 32비트, IPv6는 128비트 주소 체계를 사용한다
  4. ④192.168.x.x 대역은 사설 IP 주소로 사용된다
46다음 중 DNS(Domain Name System)에 대한 설명으로 옳은 것은? 매회
  1. ①데이터를 암호화하여 전송하는 보안 프로토콜이다
  2. ②이메일을 주고받기 위한 프로토콜이다
  3. ③도메인 이름(예: www.google.com)을 IP 주소로 변환해 주는 시스템이다
  4. ④파일을 전송하기 위한 프로토콜이다
47다음 중 프로토콜(Protocol)에 대한 설명으로 옳은 것은? 매회
  1. ①컴퓨터의 CPU 성능을 측정하는 단위이다
  2. ②하드디스크의 저장 용량을 나타내는 단위이다
  3. ③모니터의 화면 크기를 나타내는 단위이다
  4. ④네트워크에서 데이터를 주고받기 위해 정한 통신 규약이다
48다음 중 클라우드 컴퓨팅(Cloud Computing)에 대한 설명으로 옳지 않은 것은? 매회
  1. ①반드시 자체 서버를 구축해야만 이용할 수 있다
  2. ②인터넷을 통해 서버·스토리지·소프트웨어 등 IT 자원을 필요한 만큼 빌려 쓰는 기술이다
  3. ③SaaS, PaaS, IaaS 등의 서비스 모델이 있다
  4. ④구글 드라이브, 네이버 클라우드 등이 대표적인 예이다
49다음 중 스프레드시트(Spreadsheet)에 대한 설명으로 옳은 것은? 자주
  1. ①그림을 그리고 편집하는 그래픽 소프트웨어이다
  2. ②행과 열로 구성된 셀에 데이터를 입력하고 계산·분석하는 소프트웨어이다
  3. ③프레젠테이션 자료를 만드는 소프트웨어이다
  4. ④동영상을 편집하는 멀티미디어 소프트웨어이다
50다음 중 픽셀(Pixel)에 대한 설명으로 옳은 것은? 자주
  1. ①프린터의 인쇄 속도를 나타내는 단위이다
  2. ②하드디스크의 저장 단위이다
  3. ③디지털 이미지를 구성하는 가장 작은 점(화소) 단위이다
  4. ④네트워크 전송 속도를 나타내는 단위이다
51다음 중 랜섬웨어(Ransomware)에 대한 설명으로 옳은 것은? 매회
  1. ①사용자의 파일을 암호화한 뒤 금전(몸값)을 요구하는 악성코드이다
  2. ②컴퓨터 성능을 최적화해 주는 유틸리티 프로그램이다
  3. ③네트워크 속도를 측정하는 도구이다
  4. ④삭제된 파일을 복구해 주는 프로그램이다
52다음 중 QR코드에 대한 설명으로 옳지 않은 것은? 자주
  1. ①2차원 매트릭스 형태의 바코드로 정보를 저장한다
  2. ②기존 1차원 바코드보다 훨씬 많은 정보를 담을 수 있다
  3. ③스마트폰 카메라로 인식하여 URL, 텍스트 등의 정보를 읽을 수 있다
  4. ④QR코드는 흑백으로만 표현해야 하며 색상을 사용할 수 없다
53다음 중 IoT(사물인터넷)에 대한 설명으로 옳은 것은? 매회
  1. ①인터넷 속도를 10배로 높이는 통신 기술이다
  2. ②개인 컴퓨터의 저장 용량을 늘리는 기술이다
  3. ③다양한 사물(가전·센서·차량 등)에 인터넷을 연결하여 정보를 주고받는 기술이다
  4. ④전화선을 이용한 아날로그 통신 방식이다
54다음 중 압축(Compression)에 대한 설명으로 옳지 않은 것은? 자주
  1. ①손실 압축은 원본과 완전히 동일하게 복원할 수 있다
  2. ②파일 크기를 줄여 저장 공간을 절약하고 전송 시간을 단축하는 기술이다
  3. ③ZIP, RAR, 7z 등이 대표적인 압축 파일 형식이다
  4. ④비손실 압축은 원본 데이터를 그대로 보존하면서 크기를 줄인다
55다음 중 해상도(Resolution)에 대한 설명으로 옳은 것은? 자주
  1. ①화면이나 이미지를 구성하는 픽셀 수로 표현되며, 높을수록 선명하다
  2. ②모니터의 물리적 크기(인치)를 나타내는 단위이다
  3. ③프린터가 1분에 출력하는 장수를 나타내는 단위이다
  4. ④하드디스크의 회전 속도를 나타내는 단위이다
56다음 중 쿠키(Cookie)에 대한 설명으로 옳지 않은 것은? 자주
  1. ①웹사이트가 사용자의 컴퓨터에 저장하는 작은 텍스트 파일이다
  2. ②로그인 상태 유지, 장바구니 정보 저장 등에 활용된다
  3. ③브라우저 설정에서 쿠키를 삭제하거나 차단할 수 있다
  4. ④쿠키는 실행 파일이므로 바이러스를 포함할 수 있다
57다음 중 빅데이터(Big Data)에 대한 설명으로 옳은 것은? 자주
  1. ①용량이 큰 동영상 파일을 의미한다
  2. ②기존 도구로는 처리하기 어려운 대규모 데이터를 수집·저장·분석하여 가치를 추출하는 기술이다
  3. ③데이터를 삭제하여 저장 공간을 확보하는 기술이다
  4. ④컴퓨터 화면을 크게 확대하는 기술이다
58다음 중 유니코드(Unicode)에 대한 설명으로 옳은 것은? 자주
  1. ①영어 알파벳만을 표현하기 위한 문자 코드 체계이다
  2. ②이미지 파일의 압축 형식이다
  3. ③프로그래밍 언어의 한 종류이다
  4. ④전 세계 모든 문자를 하나의 코드 체계로 표현하기 위한 국제 표준 문자 코드이다
59다음 중 피싱(Phishing)에 대한 설명으로 옳은 것은? 매회
  1. ①물고기를 잡는 온라인 게임이다
  2. ②신뢰할 수 있는 기관을 사칭하여 개인정보(비밀번호·계좌번호 등)를 탈취하는 사기 수법이다
  3. ③컴퓨터 바이러스를 치료하는 보안 기술이다
  4. ④대용량 파일을 빠르게 전송하는 기술이다
60다음 중 블루투스(Bluetooth)에 대한 설명으로 옳지 않은 것은? 자주
  1. ①근거리 무선 통신 기술로, 주로 10m 이내에서 사용된다
  2. ②이어폰·키보드·마우스 등 주변 장치를 무선으로 연결할 수 있다
  3. ③유선 LAN보다 전송 속도가 빠르고 통신 거리가 길다
  4. ④2.4GHz 주파수 대역을 사용한다
