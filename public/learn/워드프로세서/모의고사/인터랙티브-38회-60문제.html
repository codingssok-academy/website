1다음 중 전자출판(DTP)의 장점으로 옳지 않은 것은? 매회

  2. ②편집·수정이 간편하여 작업 시간이 단축된다
  3. ③소량 다품종 출판물 제작에 적합하다
  4. ④원고 작성에서 편집·인쇄까지 컴퓨터로 처리할 수 있다
2다음 중 교정 부호에서 '줄 바꿈(개행)'을 나타내는 부호로 옳은 것은? 매회

  3. ③○ 모양으로 글자를 감싼다

  1. ①각주는 문서 전체의 맨 마지막 페이지에 모아서 표시된다
  2. ②본문의 특정 내용을 보충 설명할 때 사용한다
  3. ③각주 번호는 자동으로 매겨진다
  4. ④해당 페이지 하단에 참조 내용을 표시한다
7다음 중 문서 보안 방법으로 옳지 않은 것은? 자주
  1. ①읽기 암호를 설정하여 열람을 제한한다
  2. ②쓰기 암호를 설정하여 수정을 제한한다
  3. ③문서를 PDF로 변환하면 수정이 완전히 불가능하다
  4. ④매크로 보안 수준을 설정하여 악성 매크로를 차단한다
8다음 중 매크로(Macro)에 대한 설명으로 옳은 것은? 매회
  1. ①매크로는 한 번 기록하면 수정할 수 없다
  2. ②반복적인 작업을 자동으로 수행하도록 기록하는 기능이다
  3. ③매크로는 문서 인쇄 시에만 실행할 수 있다
  4. ④매크로를 사용하면 파일 크기가 줄어든다
9다음 중 글꼴(Font)에 대한 설명으로 옳은 것은? 자주
  1. ①트루타입(TrueType) 글꼴은 화면과 인쇄 출력이 다르다
  2. ②비트맵 글꼴은 확대해도 깨지지 않는다
  3. ③오픈타입(OpenType) 글꼴은 윈도우와 맥에서 모두 사용할 수 있다
  4. ④포스트스크립트 글꼴은 화면 표시 전용이다
10다음 중 스타일(Style)에 대한 설명으로 옳지 않은 것은? 자주

  2. ②스타일을 변경하면 해당 스타일이 적용된 모든 단락이 한꺼번에 변경된다
  3. ③스타일은 현재 문서에서만 사용 가능하고 다른 문서에 적용할 수 없다
  4. ④문단 스타일과 글자 스타일을 구분하여 사용할 수 있다
11다음 중 차트(Chart) 종류와 용도의 연결이 옳지 않은 것은? 자주
  1. ①원형 차트 — 전체에 대한 각 항목의 비율 표시
  2. ②꺾은선 차트 — 시간에 따른 데이터 변화 추이 표시
  3. ③막대 차트 — 항목 간 크기 비교
  4. ④방사형 차트 — 두 변수 간의 상관관계 표시
12다음 중 메일 머지(Mail Merge)에 대한 설명으로 옳은 것은? 매회
  1. ①메일 머지는 이메일 전송 전용 기능이다
  2. ②하나의 본문에 여러 수신자의 데이터를 자동으로 삽입하여 개별 문서를 만드는 기능이다
  3. ③메일 머지를 사용하면 원본 데이터가 자동으로 삭제된다
  4. ④데이터 파일 없이도 메일 머지를 실행할 수 있다

  1. ①편집 화면과 인쇄 결과가 동일하게 나타나는 방식이다
  2. ②문서를 암호화하여 보안을 강화하는 기술이다
  3. ③문서 파일을 압축하여 저장하는 방식이다
  4. ④여러 사용자가 동시에 문서를 편집하는 기술이다

  1. ①선택 영역의 글꼴·크기 변경

  3. ③선택 영역 삭제
  4. ④선택 영역의 맞춤법 오류 자동 수정

  3. ③삽입 모드와 수정 모드는 동일한 기능이다
  4. ④삽입 모드에서는 글자 입력이 불가능하다

  2. ②시행일자는 문서가 실제로 발송되는 날짜이다

  2. ②CPU 및 메모리 사용률
  3. ③네트워크 사용 현황
  4. ④현재 실행 중인 응용 프로그램 목록
23다음 중 Windows의 휴지통에 대한 설명으로 옳지 않은 것은? 매회
  1. ①삭제된 파일을 임시로 보관하는 공간이다
  2. ②휴지통에서 파일을 복원하면 원래 위치로 되돌아간다
  3. ③Shift + Delete로 삭제하면 휴지통을 거치지 않고 영구 삭제된다
  4. ④USB 드라이브에서 삭제한 파일도 휴지통에 보관된다
24다음 중 Windows의 제어판에서 설정할 수 없는 것은? 매회
  1. ①프린터 추가 및 설정
  2. ②프로그램 추가/제거
  3. ③디스플레이 해상도 변경
  4. ④BIOS 설정 변경
25다음 중 레지스트리(Registry)에 대한 설명으로 옳은 것은? 매회
  1. ①레지스트리는 Windows에서 사용하는 임시 파일 저장소이다
  2. ②레지스트리에는 하드웨어, 소프트웨어, 사용자 설정 정보가 저장된다
  3. ③레지스트리를 삭제해도 시스템에 영향이 없다
  4. ④레지스트리는 텍스트 편집기에서만 수정할 수 있다
26다음 중 Windows의 파일 시스템에 대한 설명으로 옳지 않은 것은? 매회
  1. ①FAT32는 단일 파일 최대 크기가 4GB로 제한된다
  2. ②NTFS는 파일 및 폴더에 대한 보안 권한 설정이 가능하다
  3. ③FAT32는 NTFS보다 보안 기능이 뛰어나다
  4. ④NTFS는 파일 암호화 및 압축 기능을 지원한다
27다음 중 가상 메모리에 대한 설명으로 옳은 것은? 매회
  1. ①RAM과 동일한 속도로 작동한다
  2. ②하드디스크의 일부를 RAM처럼 사용하는 기술이다
  3. ③RAM이 충분하면 가상 메모리는 사용되지 않는다
  4. ④가상 메모리를 늘리면 RAM을 추가하는 것과 동일한 효과가 있다
28다음 중 디스크 조각 모음에 대한 설명으로 옳지 않은 것은? 매회
  1. ①흩어진 파일 조각을 연속된 공간으로 모아 성능을 향상시킨다
  2. ②하드디스크의 물리적 손상을 복구한다
  3. ③파일 읽기 속도를 개선할 수 있다
  4. ④디스크 조각 모음은 HDD에서 효과적이다
29다음 중 Windows에서 파일 확장자와 프로그램 연결이 옳지 않은 것은? 자주
  1. ①.txt — 메모장(Notepad)
  2. ②.xlsx — 엑셀(Excel)
  3. ③.pptx — 파워포인트(PowerPoint)
  4. ④.mp3 — 그림판(Paint)
30다음 중 멀티태스킹(Multitasking)에 대한 설명으로 옳은 것은? 매회
  1. ①한 대의 컴퓨터에서 하나의 프로그램만 실행할 수 있다
  2. ②여러 프로그램을 동시에 실행할 수 있는 운영체제 기능이다
  3. ③멀티태스킹을 위해서는 반드시 여러 개의 CPU가 필요하다
  4. ④DOS는 멀티태스킹 운영체제이다
31다음 중 Windows의 시스템 복원에 대한 설명으로 옳지 않은 것은? 매회
  1. ①복원 지점을 생성하여 시스템을 이전 상태로 되돌릴 수 있다
  2. ②시스템 복원을 하면 개인 문서 파일도 이전 상태로 돌아간다
  3. ③프로그램 설치 전 복원 지점을 만드는 것이 좋다
  4. ④시스템 파일, 레지스트리 등을 복원 지점의 상태로 되돌린다
32다음 중 스풀링(Spooling)에 대한 설명으로 옳은 것은? 매회
  1. ①CPU와 주변장치 간의 속도 차이를 보완하기 위해 디스크에 데이터를 임시 저장하는 기술이다
  2. ②프린터의 물리적 고장을 수리하는 기능이다
  3. ③파일을 압축하여 저장하는 기술이다
  4. ④모니터의 해상도를 자동으로 조절하는 기술이다
33다음 중 Windows에서 폴더 옵션으로 설정할 수 있는 것은? 자주
  1. ①숨김 파일 및 폴더 표시 여부
  2. ②CPU 클럭 속도 변경
  3. ③네트워크 IP 주소 설정
  4. ④사운드 카드 드라이버 업데이트
34다음 중 Windows의 명령 프롬프트(CMD) 명령어와 기능이 옳게 연결된 것은? 자주
  1. ①dir — 현재 디렉토리의 파일 및 폴더 목록 표시
  2. ②dir — 파일 내용을 화면에 출력
  3. ③dir — 디렉토리를 삭제
  4. ④dir — 파일을 복사
35다음 중 클립보드(Clipboard)에 대한 설명으로 옳지 않은 것은? 자주
  1. ①복사하거나 잘라낸 데이터를 임시로 저장하는 메모리 영역이다
  2. ②클립보드의 내용은 새로운 데이터를 복사하면 이전 내용이 대체된다
  3. ③컴퓨터를 재부팅하면 클립보드 내용이 유지된다
  4. ④클립보드의 데이터를 여러 번 붙여넣기할 수 있다
36다음 중 안전 모드(Safe Mode)에 대한 설명으로 옳은 것은? 매회
  1. ①안전 모드에서는 모든 프로그램과 드라이버가 정상 로드된다
  2. ②안전 모드는 시스템 문제 진단을 위해 최소한의 드라이버만 로드하여 부팅하는 모드이다
  3. ③안전 모드에서는 인터넷 접속이 불가능하다
  4. ④안전 모드는 Windows에서 지원하지 않는다

  2. ②PnP는 네트워크 프로토콜의 한 종류이다
  3. ③PnP 기능을 사용하려면 반드시 수동으로 드라이버를 설치해야 한다
  4. ④PnP는 DOS에서 처음 도입된 기능이다
38다음 중 바탕화면 아이콘에 대한 설명으로 옳지 않은 것은? 매회
  1. ①바로 가기 아이콘에는 화살표 표시가 있다
  2. ②바로 가기 아이콘을 삭제해도 원본 파일은 삭제되지 않는다
  3. ③바탕화면의 아이콘은 이름 변경이 가능하다
  4. ④바로 가기 아이콘을 삭제하면 원본 프로그램도 함께 삭제된다
39다음 중 Windows 탐색기에서 파일 선택 방법으로 옳은 것은? 매회
  1. ①연속된 파일 선택: 첫 파일 클릭 → Ctrl 누른 채 마지막 파일 클릭
  2. ②비연속적 파일 선택: 첫 파일 클릭 → Shift 누른 채 원하는 파일 클릭
  3. ③전체 파일 선택: Ctrl + A
  4. ④파일 선택 해제: Ctrl + Z
40다음 중 Windows 업데이트에 대한 설명으로 옳지 않은 것은? 자주

  3. ③드라이버 업데이트도 포함될 수 있다

  2. ②HDD보다 읽기·쓰기 속도가 빠르다
  3. ③물리적인 회전 디스크를 사용한다

  1. ①IPv4 주소는 32비트로 구성된다

  4. ④IPv4 주소는 무한대로 할당할 수 있어 부족 문제가 없다

  2. ②네트워크에서 데이터 통신을 위한 규칙과 약속이다
  3. ③모니터의 해상도를 설정하는 소프트웨어이다
  4. ④하드디스크를 포맷하는 명령어이다

  3. ③이메일을 자동으로 분류하는 시스템이다
  4. ④파일을 압축하는 프로그램이다

  1. ①사용자 모르게 설치되어 개인 정보를 수집·유출하는 악성 프로그램이다
  2. ②하드디스크의 공간을 늘려주는 유틸리티이다
  3. ③네트워크 속도를 향상시키는 프로그램이다
  4. ④파일을 자동으로 백업하는 프로그램이다
50다음 중 클라우드 컴퓨팅에 대한 설명으로 옳지 않은 것은? 매회
  1. ①인터넷을 통해 서버, 스토리지, 소프트웨어 등을 제공받는 서비스이다
  2. ②사용한 만큼 비용을 지불하는 종량제 방식이 일반적이다
  3. ③장소에 구애받지 않고 서비스를 이용할 수 있다

  1. ①바이러스는 스스로 복제할 수 없지만 웜은 자체 복제가 가능하다
  2. ②바이러스는 숙주 파일에 기생하고, 웜은 독립적으로 실행·전파된다
  3. ③웜은 파일을 감염시키고, 바이러스는 네트워크로 전파된다
  4. ④바이러스와 웜은 동일한 방식으로 작동한다
54다음 중 QR 코드에 대한 설명으로 옳지 않은 것은? 자주
  1. ①2차원 매트릭스 형태의 바코드이다

  3. ③스마트폰 카메라로 인식할 수 있다
  4. ④QR 코드는 숫자 정보만 저장할 수 있다

  3. ③웹페이지를 전송하는 프로토콜이다
  4. ④원격 접속 프로토콜이다

  2. ②해상도는 소리의 품질을 나타내는 단위이다
  3. ③해상도가 낮을수록 파일 크기가 커진다
  4. ④모든 모니터의 해상도는 동일하다

  4. ④2.4GHz 주파수 대역을 사용한다

  3. ③네트워크 보안을 강화하는 방화벽 프로그램이다
