1워드프로세싱 일반Q1 – Q20
1다음 중 교정부호(校正符號)의 적용에 대한 설명으로 옳지 않은 것은? 자주
  1. ①교정부호는 원본과 다른 색으로 표시하여 구별한다.
  2. ②줄 바꿈 교정부호는 '∧' 기호를 사용한다.
  3. ③삭제 교정부호는 해당 글자 위에 가로선(─)을 긋는다.
  4. ④글자를 바꿀 때는 해당 글자 아래에 새 글자를 쓴다.
2공문서(公文書)의 구성요소에 대한 설명으로 옳지 않은 것은? 자주
  1. ①두문(頭文)에는 발신기관명, 수신기관명, 경유 등이 포함된다.
  2. ②본문에는 제목, 내용, 붙임(첨부) 등이 포함된다.
  3. ③관인(官印)은 두문(頭文)에 해당하는 구성요소이다.
  4. ④결문(結文)에는 발신명의, 기안자, 검토자, 결재권자, 협조자 등이 포함된다.
3공문서의 항목 구분 기호에 대한 설명으로 옳지 않은 것은? 자주
  1. ①1단계는 로마 숫자 Ⅰ, Ⅱ, Ⅲ을 사용한다.
  2. ②2단계는 아라비아 숫자 1., 2., 3.을 사용한다.
  3. ③4단계는 ①, ②, ③을 사용한다.
  4. ④3단계는 가, 나, 다를 사용한다.
4전결(專決)·대결(代決)·후결(後決)에 대한 설명으로 옳지 않은 것은? 자주
  1. ①전결(專決)은 결재권자가 사전에 위임한 사항에 대해 하급자가 결재하는 것이다.
  2. ②대결 시에는 '대결' 표시 없이 일반 결재와 동일하게 처리한다.
  3. ③후결(後決)은 대결한 내용을 결재권자가 출근 후에 재가(裁可)하는 것이다.
  4. ④대결(代決)은 결재권자가 부재중일 때 그 직무를 대리하는 자가 결재하는 것이다.
5다음 중 글꼴(Font)의 개발사와 특징에 대한 설명으로 옳지 않은 것은? 자주
  1. ①트루타입(TrueType) 글꼴은 Apple과 Microsoft가 공동 개발하였다.
  2. ②포스트스크립트(PostScript) 글꼴은 Adobe가 개발하였다.
  3. ③트루타입 글꼴은 3차 베지어(Bézier) 곡선으로 윤곽을 표현한다.
  4. ④오픈타입(OpenType) 글꼴은 트루타입과 포스트스크립트를 통합한 형식이다.
6유니코드(Unicode)의 인코딩 방식에 대한 설명으로 옳지 않은 것은? 자주
  1. ①UTF-8은 가변 길이 인코딩으로 1~4바이트를 사용한다.
  2. ②UTF-16은 기본 다국어 평면(BMP) 문자를 2바이트로 표현한다.
  3. ③UTF-16은 모든 문자를 고정 2바이트로 표현하므로 처리 속도가 빠르다.
  4. ④UTF-8은 ASCII 문자와 하위 호환성이 있다.
7완성형 한글 코드에 대한 설명으로 옳지 않은 것은? 자주
  1. ①KS X 1001 완성형은 2,350자의 한글을 표현할 수 있다.
  2. ②완성형은 조합형에 비해 코드 체계가 단순하다.
  3. ③완성형은 모든 현대 한글 11,172자를 표현할 수 있다.
  4. ④완성형은 한 글자에 2바이트를 사용한다.
8OLE(Object Linking and Embedding)에 대한 설명으로 옳지 않은 것은? 자주
  1. ①연결(Linking)은 원본 파일이 수정되면 삽입된 문서에도 자동 반영된다.
  2. ②포함(Embedding)은 원본 파일과 독립적으로 개체가 문서에 저장된다.
  3. ③OLE를 사용하면 서로 다른 응용 프로그램 간에 데이터를 공유할 수 있다.
  4. ④연결(Linking)된 개체는 원본 파일이 삭제되어도 정상적으로 표시된다.
9매크로(Macro)에 대한 설명으로 옳지 않은 것은? 자주
  1. ①반복적인 작업을 자동화하기 위해 일련의 명령을 기록하는 기능이다.
  2. ②매크로는 실행 파일(.exe)로 저장되어 독립적으로 실행된다.
  3. ③매크로 바이러스를 방지하기 위해 보안 수준을 설정할 수 있다.
  4. ④매크로는 기록 후 편집하여 수정할 수 있다.
10메일 머지(Mail Merge)에 대한 설명으로 옳지 않은 것은? 자주
  1. ①본문 문서(주 문서)와 데이터 원본(자료 파일)이 필요하다.
  2. ②본문 문서에는 데이터 원본의 데이터가 직접 입력되어 있어야 한다.
  3. ③메일 머지를 실행하면 데이터 원본의 각 레코드마다 별도의 문서가 생성된다.
  4. ④데이터 원본으로 엑셀, 데이터베이스, 텍스트 파일 등을 사용할 수 있다.
11머리말(Header)과 꼬리말(Footer)에 대한 설명으로 옳지 않은 것은? 자주
  1. ①머리말은 문서 위쪽, 꼬리말은 문서 아래쪽에 반복 출력된다.
  2. ②머리말/꼬리말은 화면에서는 보이지 않고 인쇄 시에만 출력된다.
  3. ③머리말/꼬리말에 페이지 번호, 날짜, 파일 이름 등을 삽입할 수 있다.
  4. ④짝수 페이지와 홀수 페이지에 서로 다른 머리말/꼬리말을 설정할 수 있다.
12색인(索引, Index)에 대한 설명으로 옳지 않은 것은? 자주
  1. ①색인은 문서 내 특정 단어나 구문의 위치를 찾기 위한 목록이다.
  2. ②색인은 문서의 첫 페이지에 자동으로 배치된다.
  3. ③색인에는 해당 항목이 위치한 페이지 번호가 표시된다.
  4. ④색인 항목은 오름차순 또는 내림차순으로 정렬할 수 있다.
13프린터의 인쇄 속도 단위에 대한 설명으로 옳지 않은 것은? 자주
  1. ①DPI(Dots Per Inch)는 분당 인쇄 도트 수로, 프린터의 인쇄 속도를 나타낸다.
  2. ②LPM(Lines Per Minute)은 분당 인쇄 줄 수로, 라인 프린터에 사용된다.
  3. ③PPM(Pages Per Minute)은 분당 인쇄 페이지 수로, 레이저/잉크젯 프린터에 사용된다.
  4. ④CPS(Characters Per Second)는 초당 인쇄 문자 수로, 도트 매트릭스 프린터에 사용된다.
14스풀링(Spooling)과 버퍼링(Buffering)에 대한 설명으로 옳지 않은 것은? 자주
  1. ①버퍼링은 하드디스크를 이용하므로 스풀링보다 더 많은 데이터를 저장할 수 있다.
  2. ②버퍼링은 주기억장치(RAM)의 일부를 이용하여 데이터를 임시 저장한다.
  3. ③스풀링은 여러 작업의 출력을 동시에 처리할 수 있다.
  4. ④스풀링은 인쇄 데이터를 하드디스크에 임시 저장하여 CPU가 다른 작업을 할 수 있게 한다.
15커닝(Kerning)과 자간(字間, Letter Spacing)에 대한 설명으로 옳지 않은 것은? 자주
  1. ①커닝과 자간은 동일한 개념으로, 같은 방식으로 작동한다.
  2. ②커닝(Kerning)은 특정 글자 쌍(예: AV, To) 사이의 간격을 시각적으로 보정하는 것이다.
  3. ③커닝은 글자의 모양에 따라 간격을 다르게 적용한다.
  4. ④자간(Letter Spacing)은 모든 글자 사이의 간격을 균일하게 조절하는 것이다.
16포인트(Point)와 파이카(Pica)에 대한 설명으로 옳지 않은 것은? 자주
  1. ①1파이카(Pica)는 1/10인치이다.
  2. ②1파이카(Pica)는 12포인트와 같다.
  3. ③1인치는 72포인트이다.
  4. ④1포인트(Point)는 약 0.3528mm(1/72인치)이다.
17WYSIWYG(위지위그)에 대한 설명으로 옳지 않은 것은? 자주
  1. ①래스터(Raster) 방식의 디스플레이 기술로 구현된다.
  2. ②화면에 표시되는 내용이 인쇄 결과와 동일하게 출력되는 기술이다.
  3. ③What You See Is What You Get의 약자이다.
  4. ④WYSIWYG를 구현하려면 비트맵 디스플레이와 그래픽 사용자 인터페이스(GUI)가 필요하다.
18전자문서(電子文書)의 공람(公覽)에 대한 설명으로 옳지 않은 것은? 자주
  1. ①공람은 결재가 완료된 문서를 관련자에게 돌려보는 것이다.
  2. ②공람 확인은 자동으로 표시될 수 있다.
  3. ③공람은 열람 후 의견을 첨부할 수 있다.
  4. ④공람 대상자는 문서의 결재권을 가진다.
19두괄식(頭括式)과 미괄식(尾括式)에 대한 설명으로 옳지 않은 것은? 자주
  1. ①두괄식(頭括式)은 결론이나 핵심 내용을 글의 처음에 제시하는 방식이다.
  2. ②미괄식(尾括式)은 결론이나 핵심 내용을 글의 끝에 제시하는 방식이다.
  3. ③두(頭)는 '머리', 미(尾)는 '꼬리'를 뜻하는 한자이다.
  4. ④공문서 작성 시에는 미괄식(尾括式)을 원칙으로 한다.
20다음 문서 파일 형식에 대한 설명으로 옳지 않은 것은? 자주
  1. ①RTF(Rich Text Format)는 서로 다른 워드프로세서 간 호환을 위한 문서 형식이다.
  2. ②PDF(Portable Document Format)는 Adobe에서 개발한 전자 문서 형식이다.
  3. ③TXT는 서식 정보 없이 순수 텍스트만 저장하는 형식이다.
  4. ④HWP는 Microsoft에서 개발한 한글 전용 문서 형식이다.

21Windows 탐색기(Explorer)에서 파일 정렬과 그룹화에 대한 설명으로 옳지 않은 것은? 자주
  1. ①파일을 이름, 날짜, 유형, 크기 등으로 정렬할 수 있다.
  2. ②그룹화를 적용하면 특정 기준으로 파일을 묶어서 표시할 수 있다.
  3. ③내림차순 정렬 시 Z→A, 큰 수→작은 수 순서로 표시된다.
  4. ④정렬 기준은 한 가지만 적용할 수 있으며, 보조 정렬은 불가능하다.
22Windows에서 Ctrl+클릭과 Shift+클릭의 파일 선택에 대한 설명으로 옳지 않은 것은? 자주
  1. ①Ctrl+클릭은 떨어져 있는 파일을 개별적으로 선택할 수 있다.
  2. ②Shift+클릭은 처음 선택한 파일부터 마지막 클릭한 파일까지 연속 선택한다.
  3. ③Shift+클릭은 비연속적인 파일을 개별 선택하는 데 사용된다.
  4. ④Ctrl+A는 현재 폴더의 모든 파일과 폴더를 선택한다.
23Windows의 휴지통(Recycle Bin)에 대한 설명으로 옳지 않은 것은? 자주
  1. ①휴지통의 최대 크기는 드라이브별로 설정할 수 있다.
  2. ②Shift+Delete로 삭제하면 휴지통을 거치지 않고 영구 삭제된다.
  3. ③네트워크 드라이브에서 삭제한 파일도 휴지통에 저장된다.
  4. ④휴지통의 파일은 원래 위치로 복원할 수 있다.
24Windows에서 바로 가기(Shortcut) 아이콘에 대한 설명으로 옳지 않은 것은? 자주
  1. ①바로 가기 아이콘의 왼쪽 아래에 화살표 표시가 있다.
  2. ②바로 가기를 삭제하면 원본 파일도 함께 삭제된다.
  3. ③바로 가기의 확장자는 .lnk이다.
  4. ④바로 가기 속성에서 대상 파일의 경로, 시작 위치, 바로 가기 키를 설정할 수 있다.
25Windows에서 숨김 파일 표시 설정 경로로 옳은 것은? 자주
  1. ①설정 → 개인 설정 → 테마 → 숨김 파일 표시
  2. ②제어판 → 시스템 → 고급 시스템 설정 → 숨김 파일
  3. ③탐색기 → 보기 → 옵션 → 폴더 옵션 → 보기 탭 → '숨김 파일 및 폴더 표시'
  4. ④작업 관리자 → 보기 → 숨김 파일 표시
26Windows에서 디스플레이 해상도 변경 경로로 옳지 않은 것은? 자주
  1. ①바탕 화면 우클릭 → 디스플레이 설정 → 해상도
  2. ②설정 → 시스템 → 디스플레이 → 해상도
  3. ③제어판 → 장치 관리자 → 모니터 → 해상도 변경
  4. ④제어판 → 디스플레이 → 해상도 조정
27Windows의 에어로 피크(Aero Peek)에 대한 설명으로 옳지 않은 것은? 자주
  1. ①작업 표시줄의 미리 보기 축소판 위에 마우스를 올리면 해당 창만 표시된다.
  2. ②작업 표시줄 오른쪽 끝의 '바탕 화면 보기' 영역에 마우스를 올리면 모든 창이 투명해진다.
  3. ③에어로 피크를 사용하려면 반드시 에어로 테마를 사용해야 하며, 기본 테마에서는 작동하지 않는다.
  4. ④에어로 피크는 실제로 창을 최소화하는 것이 아니라 일시적으로 투명하게 만든다.
28Windows 작업 표시줄 알림 영역(시스템 트레이)에 대한 설명으로 옳지 않은 것은? 자주
  1. ①시계, 네트워크, 볼륨, 배터리 등의 시스템 아이콘이 표시된다.
  2. ②알림 영역에 표시할 아이콘을 사용자가 선택할 수 있다.
  3. ③백그라운드에서 실행 중인 프로그램의 아이콘이 표시될 수 있다.
  4. ④알림 영역의 아이콘을 클릭하면 해당 프로그램이 새로 설치된다.
29Windows에서 바탕 화면 아이콘 정렬에 대한 설명으로 옳지 않은 것은? 자주
  1. ①바탕 화면 우클릭 → 정렬 기준에서 이름, 크기, 항목 유형, 수정한 날짜로 정렬할 수 있다.
  2. ②바탕 화면 아이콘 정렬은 탐색기 내부 폴더에도 동일하게 적용된다.
  3. ③'아이콘을 격자에 맞춤'을 해제하면 아이콘을 자유 위치에 배치할 수 있다.
  4. ④'아이콘 자동 정렬'을 선택하면 아이콘이 왼쪽 위부터 자동 배치된다.
30Windows에서 Win 키 조합 단축키에 대한 설명으로 옳지 않은 것은? 자주
  1. ①Win+E는 파일 탐색기를 연다.
  2. ②Win+F는 시스템 종료 창을 연다.
  3. ③Win+D는 바탕 화면 보기/복원을 전환한다.
  4. ④Win+L은 컴퓨터를 잠근다.
31Windows의 도움말과 원격 지원에 대한 설명으로 옳지 않은 것은? 자주
  1. ①도움말은 하이퍼텍스트(Hypertext) 형식으로 관련 항목 간 이동이 가능하다.
  2. ②원격 지원은 인터넷 연결 없이 블루투스만으로 사용할 수 있다.
  3. ③원격 지원 시 초대를 받은 사람은 상대방의 화면을 볼 수 있다.
  4. ④원격 지원을 사용하면 네트워크를 통해 다른 사용자의 컴퓨터에 접속할 수 있다.
32ipconfig, ping, tracert 명령어에 대한 설명으로 옳지 않은 것은? 자주
  1. ①ipconfig는 현재 컴퓨터의 IP 주소, 서브넷 마스크, 기본 게이트웨이 정보를 표시한다.
  2. ②ping은 UDP 프로토콜을 사용하여 대상 호스트에 패킷을 전송한다.
  3. ③tracert는 특정 호스트까지의 경로(경유하는 라우터)를 추적한다.
  4. ④ping은 특정 호스트까지의 네트워크 연결 상태와 응답 시간을 확인한다.
33Windows 안전 모드(Safe Mode)의 3가지 종류에 대한 설명으로 옳지 않은 것은? 자주
  1. ①안전 모드에서는 해상도가 자동으로 최고 해상도로 설정된다.
  2. ②안전 모드(네트워킹 사용)은 네트워크 드라이버를 포함하여 시작한다.
  3. ③안전 모드(명령 프롬프트)는 GUI 없이 명령 프롬프트만으로 시작한다.
  4. ④안전 모드는 최소한의 드라이버와 서비스만으로 Windows를 시작한다.
34POST, BIOS, UEFI의 관계에 대한 설명으로 옳지 않은 것은? 자주
  1. ①POST는 운영체제가 부팅된 후에 실행되는 진단 프로그램이다.
  2. ②BIOS(Basic Input/Output System)는 하드웨어와 운영체제 사이의 펌웨어이다.
  3. ③UEFI(Unified Extensible Firmware Interface)는 BIOS의 후속 규격으로, GUI 지원과 대용량 디스크 부팅이 가능하다.
  4. ④POST(Power-On Self-Test)는 컴퓨터 전원 투입 시 하드웨어를 자가 진단하는 과정이다.
35Windows 작업 관리자(Task Manager)에 대한 설명으로 옳지 않은 것은? 자주
  1. ①작업 관리자에서 새로운 하드웨어 드라이버를 설치할 수 있다.
  2. ②성능 탭에서 CPU, 메모리, 디스크, 네트워크 사용률을 모니터링할 수 있다.
  3. ③Ctrl+Shift+Esc 또는 Ctrl+Alt+Delete로 작업 관리자를 열 수 있다.
  4. ④프로세스 탭에서 실행 중인 응용 프로그램과 백그라운드 프로세스를 확인할 수 있다.
36NTFS 파일 시스템에 대한 설명으로 옳지 않은 것은? 자주
  1. ①NTFS는 단일 파일 최대 크기가 2GB로 제한된다.
  2. ②EFS(Encrypting File System)를 통한 파일 암호화를 지원한다.
  3. ③개별 파일이나 폴더에 대한 압축 기능을 제공한다.
  4. ④저널링(Journaling) 기능으로 파일 시스템 오류 복구가 가능하다.
37Windows의 시스템 이미지 백업과 복원 지점에 대한 설명으로 옳지 않은 것은? 자주
  1. ①복원 지점을 사용하면 개인 파일(문서, 사진 등)도 이전 상태로 되돌아간다.
  2. ②복원 지점(시스템 복원)은 시스템 파일과 레지스트리를 이전 상태로 되돌린다.
  3. ③시스템 이미지 백업에는 개인 파일(문서, 사진 등)도 포함된다.
  4. ④시스템 이미지 백업은 드라이브 전체를 이미지로 백업한다.
38Windows 레지스트리(Registry)의 5대 루트 키에 대한 설명으로 옳지 않은 것은? 자주
  1. ①HKEY_CLASSES_ROOT(HKCR)는 파일 확장자 연결과 OLE 정보를 저장한다.
  2. ②HKEY_CURRENT_USER(HKCU)는 현재 로그인한 사용자의 환경 설정을 저장한다.
  3. ③HKEY_LOCAL_MACHINE(HKLM)은 컴퓨터의 하드웨어와 소프트웨어 설정을 저장한다.
  4. ④HKEY_CURRENT_CONFIG(HKCC)는 모든 사용자의 프로필 목록을 저장한다.
39Windows Defender의 실시간 보호에 대한 설명으로 옳지 않은 것은? 자주
  1. ①실시간 보호는 파일을 열거나 다운로드할 때 자동으로 악성코드를 검사한다.
  2. ②정기적인 정의(Definition) 업데이트를 통해 최신 위협에 대응한다.
  3. ③Windows Defender는 Windows에 기본 내장된 백신 프로그램이다.
  4. ④실시간 보호를 끄면 바이러스 검사가 완전히 비활성화된다.
40디스크 저장 구조에서 섹터(Sector), 클러스터(Cluster), 트랙(Track)에 대한 설명으로 옳지 않은 것은? 자주
  1. ①섹터(Sector)는 디스크에서 데이터를 저장하는 최소 물리적 단위이다.
  2. ②클러스터(Cluster)는 하나 이상의 섹터로 구성된 파일 시스템의 최소 할당 단위이다.
  3. ③트랙(Track)은 디스크 표면의 동심원 형태의 기록 영역이다.
  4. ④섹터는 여러 클러스터를 묶어서 구성한 단위이다.

41CPU의 명령어 처리 4단계(기계 사이클)에 대한 설명으로 옳지 않은 것은? 자주
  1. ①인출(Fetch) → 해독(Decode) → 실행(Execute) → 저장(Store) 순서로 진행된다.
  2. ②인출(Fetch) 단계에서 주기억장치의 명령어를 가져온다.
  3. ③해독(Decode) 단계에서 제어장치가 명령어를 분석한다.
  4. ④실행(Execute) 단계에서 명령어를 주기억장치에 다시 기록한다.
42CPU의 5대 레지스터에 대한 설명으로 옳지 않은 것은? 자주
  1. ①AC(누산기, Accumulator)는 연산 결과를 임시 저장하는 레지스터이다.
  2. ②PC(프로그램 카운터, Program Counter)는 다음에 실행할 명령어의 주소를 저장한다.
  3. ③MAR(메모리 주소 레지스터)는 메모리에서 읽어온 데이터를 저장한다.
  4. ④IR(명령어 레지스터, Instruction Register)는 현재 실행 중인 명령어를 저장한다.
43SMTP, POP3, IMAP, FTP, SSH에 대한 설명으로 옳지 않은 것은? 자주
  1. ①SMTP(Simple Mail Transfer Protocol)는 이메일을 보내는 데 사용되는 프로토콜이다.
  2. ②POP3(Post Office Protocol 3)는 이메일을 수신하여 서버에서 삭제하는 방식이 기본이다.
  3. ③FTP(File Transfer Protocol)는 암호화된 파일 전송을 기본으로 제공하는 프로토콜이다.
  4. ④IMAP(Internet Message Access Protocol)은 이메일을 서버에 보관하며 여러 기기에서 동기화할 수 있다.
44HTTP, HTTPS, DNS의 포트 번호에 대한 설명으로 옳지 않은 것은? 자주
  1. ①HTTP의 기본 포트 번호는 80이다.
  2. ②HTTPS의 기본 포트 번호는 8080이다.
  3. ③DNS의 기본 포트 번호는 53이다.
  4. ④HTTPS의 기본 포트 번호는 443이다.
45컴퓨터 세대 구분에 대한 설명으로 옳지 않은 것은? 자주
  1. ①1세대 컴퓨터는 진공관(Vacuum Tube)을 사용하였으며, ENIAC이 대표적이다.
  2. ②2세대 컴퓨터는 트랜지스터(Transistor)를 사용하여 크기와 발열을 줄였다.
  3. ③ENIAC은 트랜지스터 기반의 2세대 컴퓨터이다.
  4. ④3세대 컴퓨터는 집적회로(IC, Integrated Circuit)를 사용하였다.
46DRAM, SRAM, DDR에 대한 설명으로 옳지 않은 것은? 자주
  1. ①DRAM(Dynamic RAM)은 주기적인 재충전(Refresh)이 필요하다.
  2. ②SRAM(Static RAM)은 재충전이 필요 없어 캐시 메모리에 주로 사용된다.
  3. ③SRAM은 DRAM보다 가격이 저렴하고 집적도가 높아 주기억장치로 사용된다.
  4. ④DDR(Double Data Rate) SDRAM은 클록의 상승과 하강 양쪽에서 데이터를 전송한다.
47Mask ROM, PROM, EPROM, EEPROM에 대한 설명으로 옳지 않은 것은? 자주
  1. ①Mask ROM은 제조 시 데이터가 기록되며, 이후 변경이 불가능하다.
  2. ②PROM(Programmable ROM)은 사용자가 1회에 한해 데이터를 기록할 수 있다.
  3. ③EEPROM(Electrically Erasable PROM)은 자외선으로만 데이터를 지울 수 있다.
  4. ④EPROM(Erasable PROM)은 자외선(UV)을 이용하여 데이터를 지우고 다시 기록할 수 있다.
48광 저장매체의 저장 용량에 대한 설명으로 옳지 않은 것은? 자주
  1. ①CD-ROM의 표준 용량은 약 700MB이다.
  2. ②단층 단면 DVD의 표준 용량은 약 4.7GB이다.
  3. ③단층 단면 블루레이 디스크(BD)의 표준 용량은 약 25GB이다.
  4. ④CD-RW의 용량은 DVD보다 크다.
49직렬/병렬 전송과 동기/비동기 전송에 대한 설명으로 옳지 않은 것은? 자주
  1. ①직렬 전송은 한 번에 1비트씩 순차적으로 데이터를 전송한다.
  2. ②동기 전송은 시작 비트와 정지 비트를 매 바이트마다 추가하여 동기화한다.
  3. ③비동기 전송은 시작 비트(Start Bit)와 정지 비트(Stop Bit)로 데이터를 구분한다.
  4. ④병렬 전송은 여러 비트를 동시에 전송하여 속도가 빠르지만 거리 제한이 있다.
50오류 검출 방식인 패리티, 해밍, CRC, 체크섬에 대한 설명으로 옳지 않은 것은? 자주
  1. ①패리티 비트(Parity Bit)는 1비트 오류를 검출할 수 있으나 수정은 불가능하다.
  2. ②체크섬(Checksum)은 오류를 검출하고 자동으로 수정하는 방식이다.
  3. ③CRC(Cyclic Redundancy Check)는 다항식을 이용한 오류 검출 방식이다.
  4. ④해밍 코드(Hamming Code)는 오류를 검출하고 수정(교정)까지 가능하다.
51대칭키 암호화(DES, AES)와 공개키 암호화(RSA)에 대한 설명으로 옳지 않은 것은? 자주
  1. ①대칭키 암호화는 암호화와 복호화에 같은 키를 사용한다.
  2. ②RSA는 암호화와 복호화에 같은 키를 사용하는 대칭키 알고리즘이다.
  3. ③AES(Advanced Encryption Standard)는 DES의 후속으로 128/192/256비트 키를 지원한다.
  4. ④DES(Data Encryption Standard)는 56비트 키를 사용하는 대칭키 알고리즘이다.
52SSL, SSH, VPN, IPSec에 대한 설명으로 옳지 않은 것은? 자주
  1. ①SSL(Secure Sockets Layer)/TLS는 웹 통신 암호화에 주로 사용된다.
  2. ②IPSec은 응용 계층(Application Layer)에서 동작하는 보안 프로토콜이다.
  3. ③VPN(Virtual Private Network)은 공중망에서 전용선과 같은 보안 통신을 제공한다.
  4. ④SSH(Secure Shell)는 원격 접속 시 암호화된 통신 채널을 제공한다.
53IPv4 클래스, 사설 IP, 루프백(Loopback)에 대한 설명으로 옳지 않은 것은? 자주
  1. ①C클래스의 사설 IP 범위는 192.168.0.0 ~ 192.168.255.255이며, 서브넷 마스크는 255.0.0.0이다.
  2. ②B클래스의 사설 IP 범위는 172.16.0.0 ~ 172.31.255.255이다.
  3. ③루프백(Loopback) 주소는 127.0.0.1로, 자기 자신을 가리킨다.
  4. ④A클래스의 IP 범위는 1.0.0.0 ~ 126.255.255.255이다.
54바이러스, 웜, 트로이 목마, 랜섬웨어, 스파이웨어, 키로거에 대한 설명으로 옳지 않은 것은? 자주
  1. ①랜섬웨어(Ransomware)는 키보드 입력을 기록하여 비밀번호를 탈취하는 악성코드이다.
  2. ②웜(Worm)은 독립적으로 실행되며 네트워크를 통해 자가 전파된다.
  3. ③트로이 목마(Trojan Horse)는 정상 프로그램으로 위장하여 악성 행위를 수행한다.
  4. ④바이러스(Virus)는 다른 프로그램에 기생하여 자기 복제를 통해 전파된다.
55피싱, 파밍, 스푸핑, 스니핑, DDoS에 대한 설명으로 옳지 않은 것은? 자주
  1. ①DDoS(Distributed Denial of Service)는 서버의 데이터를 암호화하여 사용 불가능하게 만드는 공격이다.
  2. ②파밍(Pharming)은 DNS를 변조하여 가짜 사이트로 유도하는 공격이다.
  3. ③스니핑(Sniffing)은 네트워크상의 데이터를 도청하는 공격이다.
  4. ④피싱(Phishing)은 가짜 이메일이나 웹사이트로 개인정보를 탈취하는 공격이다.
56운영체제의 처리 방식인 일괄, 실시간, 시분할, 다중, 분산 처리에 대한 설명으로 옳지 않은 것은? 자주
  1. ①분산 처리(Distributed Processing)는 하나의 컴퓨터에서 모든 작업을 집중 처리하는 방식이다.
  2. ②실시간 처리(Real-Time Processing)는 데이터 발생 즉시 처리하는 방식이다.
  3. ③시분할 처리(Time-Sharing)는 CPU 시간을 여러 사용자에게 분배하는 방식이다.
  4. ④일괄 처리(Batch Processing)는 데이터를 모아서 한꺼번에 처리하는 방식이다.
57페이징(Paging)과 세그멘테이션(Segmentation)에 대한 설명으로 옳지 않은 것은? 자주
  1. ①세그멘테이션에서는 내부 단편화(Internal Fragmentation)가 발생한다.
  2. ②페이징에서는 내부 단편화(Internal Fragmentation)가 발생할 수 있다.
  3. ③세그멘테이션은 논리적 단위(세그먼트)로 가변 크기 분할한다.
  4. ④페이징은 프로세스를 고정 크기의 페이지로 나누어 메모리에 적재한다.
58폰 노이만(Von Neumann)의 프로그램 내장 방식에 대한 설명으로 옳지 않은 것은? 자주
  1. ①프로그램과 데이터를 주기억장치에 저장한 후 순차적으로 실행한다.
  2. ②CPU, 기억장치, 입출력장치로 구성되는 구조를 제안하였다.
  3. ③프로그램 내장 방식의 최초 컴퓨터는 EDSAC이다.
  4. ④프로그램을 변경하려면 하드웨어 배선을 다시 연결해야 한다.
59IaaS, PaaS, SaaS, 빅데이터 3V, 블록체인에 대한 설명으로 옳지 않은 것은? 자주
  1. ①IaaS(Infrastructure as a Service)는 서버, 스토리지 등 인프라를 서비스로 제공한다.
  2. ②PaaS(Platform as a Service)는 개발 플랫폼과 환경을 서비스로 제공한다.
  3. ③빅데이터의 3V는 Volume(규모), Velocity(속도), Variety(다양성)이다.
  4. ④블록체인(Blockchain)은 중앙 서버가 모든 거래를 관리하는 중앙집중형 기술이다.
60저작권법과 관련된 설명으로 옳지 않은 것은? 자주
  1. ①저작권은 저작자 사후 70년간 보호된다.
  2. ②아이디어 자체는 저작권으로 보호되지 않으며, 표현만 보호된다.
  3. ③CCL(Creative Commons License)은 저작자가 이용 조건을 미리 표시하는 라이선스이다.
  4. ④저작권은 특허청에 등록해야만 효력이 발생한다.
