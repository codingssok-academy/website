1다음과 같이 문장이 수정되었을 때, 사용된 교정부호(원고를 고칠 때 쓰는 약속된 기호)로 옳은 것은? 변경 전: "컴퓨터는 빠르다" 변경 후: "컴퓨터는 매우 빠르다" 자주
  1. ①삽입(끼워 넣기) 부호
  2. ②삭제(지우기) 부호
  3. ③위치 교환(자리 바꿈) 부호
  4. ④줄 바꿈 부호
2공문서(관공서에서 쓰는 공식 문서)의 보고서 작성 시 유의사항으로 옳은 것은? 자주
  1. ①보고서는 개인의 주관적 의견만으로 작성해도 된다
  2. ②사실(실제 일어난 일)과 의견(내 생각)을 구분하여 작성해야 한다
  3. ③대항목(큰 제목)과 소항목(작은 제목)의 구분 없이 나열한다
  4. ④보고서의 결론(마무리 내용)은 생략해도 무방하다
3공문서(관공서에서 쓰는 공식 문서)의 항목 번호 기재에 대한 설명으로 옳은 것은? 자주
  1. ①항목이 하나뿐이더라도 반드시 번호를 붙여야 한다
  2. ②항목 번호는 아라비아 숫자(1, 2, 3)로만 사용한다
  3. ③항목이 하나뿐일 때는 번호를 기재하지 않는다
  4. ④항목 번호의 순서는 작성자가 자유롭게 정한다
4다음 중 문서의 구성 요소에서 두문(문서의 머리 부분)에 해당하는 것은? 자주
  1. ①제목(문서의 이름)
  2. ②본문 내용(설명하는 글)
  3. ③발신 명의(보내는 사람 서명)
  4. ④수신(받는 사람)과 경유(거쳐 가는 곳)
5워드프로세서에서 "다른 이름으로 저장" 기능에 대한 설명으로 옳은 것은? 자주
  1. ①기존 파일은 그대로 유지되고, 새 이름의 파일이 별도로 만들어진다
  2. ②기존 파일이 삭제되고 새 이름으로 대체된다
  3. ③기존 파일의 이름만 바뀌고 내용은 동일하다
  4. ④새 파일은 만들어지지 않고 기존 파일에 덮어쓰기만 된다
6프린터로 여러 부(copy)를 인쇄할 때 한 부씩 찍기(Collate, 콜레이트)를 설정하면 어떤 순서로 인쇄되는가? (3페이지 문서를 2부 인쇄 시) 자주
  1. ①1-1-2-2-3-3 순서로 같은 페이지를 연속 인쇄
  2. ②1-2-3, 1-2-3 순서로 한 부씩 완성하며 인쇄
  3. ③3-2-1, 3-2-1 순서로 역순 인쇄
  4. ④1-3-2, 1-3-2 순서로 홀수 페이지 우선 인쇄
7어떤 문서의 총 글자 수가 2,400자일 때, 200자 원고지로 환산하면 몇 매인가? 자주

  2. ②11매
  3. ③12매
  4. ④24매
8다음 중 비트맵(래스터) 방식의 그래픽에 대한 설명으로 틀린 것은? 자주
  1. ①픽셀(작은 점)들이 모여서 이미지를 구성한다
  2. ②확대하면 계단 현상(깨짐)이 나타날 수 있다
  3. ③사진과 같은 자연스러운 이미지 표현에 적합하다
  4. ④수학 공식(좌표·곡선)으로 이미지를 저장하므로 파일 크기가 작다
9글자 크기를 나타내는 단위인 포인트(Point)와 파이카(Pica)에 대한 설명으로 옳은 것은? 자주
  1. ①1포인트는 1/72인치이고, 1파이카는 12포인트이다
  2. ②1포인트는 1/96인치이고, 1파이카는 10포인트이다
  3. ③1포인트는 1/48인치이고, 1파이카는 6포인트이다
  4. ④1포인트는 1mm이고, 1파이카는 10mm이다
10ASCII 코드(아스키 코드, 미국 표준 문자 코드)에 대한 설명으로 옳은 것은? 자주
  1. ①16비트를 사용하여 65,536개의 문자를 표현한다
  2. ②7비트를 사용하여 128개의 문자를 표현하며, 확장 ASCII는 8비트로 256개를 표현한다
  3. ③한글, 한자 등 동양 문자를 모두 포함하는 국제 표준이다
  4. ④IBM 메인프레임 전용으로 개발된 문자 코드이다
11EBCDIC(확장 2진화 10진 코드)에 대한 설명으로 옳은 것은? 자주
  1. ①개인용 컴퓨터(PC)에서 가장 널리 사용되는 표준 코드이다
  2. ②7비트를 사용하여 128개의 문자를 표현한다
  3. ③IBM 대형 컴퓨터(메인프레임)에서 사용하는 8비트 코드이다
  4. ④전 세계 모든 언어를 표현할 수 있는 국제 통합 코드이다
12금칙처리(줄의 처음이나 끝에 오면 안 되는 문자 규칙)에 대한 설명으로 옳은 것은? 자주
  1. ①여는 괄호( '(' )는 줄의 처음에 올 수 없다
  2. ②마침표( '.' )는 줄의 처음에 와야 한다
  3. ③닫는 괄호( ')' )는 줄의 끝에 올 수 없다
  4. ④닫는 괄호( ')' ), 마침표( '.' ) 등은 줄의 처음에 올 수 없다
13워드프로세서에서 블록 지정(범위 선택)하는 방법으로 틀린 것은? 자주
  1. ①Ctrl+A를 누르면 문서 전체가 블록 지정된다
  2. ②Shift+방향키를 누르면 한 글자(또는 한 줄)씩 블록 지정된다
  3. ③마우스로 드래그하면 원하는 범위를 블록 지정할 수 있다
  4. ④Alt+F4를 누르면 현재 줄이 블록 지정된다
14워드프로세서에서 도형 그룹화(여러 도형을 하나로 묶기)에 대한 설명으로 옳은 것은? 자주
  1. ①그룹화하면 각 도형의 색상이 자동으로 통일된다
  2. ②그룹화된 도형은 하나의 개체(덩어리)로 취급되어 함께 이동·크기 조절이 된다
  3. ③그룹화된 도형은 해제(풀기)할 수 없다
  4. ④그룹화는 텍스트(글자)에만 적용 가능하다
15워드프로세서의 표(Table) 기능에 대한 설명으로 옳은 것은? 자주
  1. ①셀(Cell, 칸)은 행(가로줄)과 열(세로줄)이 만나는 하나의 칸을 의미한다
  2. ②한번 만든 표의 행(가로줄)과 열(세로줄) 수는 변경할 수 없다
  3. ③셀 합치기(여러 칸을 하나로)와 셀 나누기(한 칸을 여러 개로) 모두 가능하다
  4. ④표 안에는 텍스트(글자)만 넣을 수 있고, 그림은 넣을 수 없다
16워드프로세서에서 다단 설정(페이지를 여러 단으로 나누기)에 대한 설명으로 틀린 것은? 자주
  1. ①한 페이지를 2단, 3단 등 여러 단으로 나눌 수 있다
  2. ②신문이나 잡지처럼 좁은 폭의 글 배치가 가능하다
  3. ③구역(섹션) 나누기를 사용하면 페이지마다 다른 단 수를 설정할 수 있다
  4. ④다단 설정을 하면 페이지의 위쪽 여백(상단 여백)이 자동으로 없어진다
17전자결재(컴퓨터로 하는 결재 시스템)에 대한 설명으로 틀린 것은? 자주
  1. ①결재 진행 현황(어디까지 결재됐는지)을 실시간으로 확인할 수 없다
  2. ②결재선(결재할 사람 순서)을 미리 지정하여 결재 경로를 설정한다
  3. ③결재 시 의견(코멘트)을 첨부할 수 있다
  4. ④종이 문서 없이 온라인으로 결재가 가능하다
18RTF(Rich Text Format, 서식 있는 텍스트 형식)에 대한 설명으로 옳은 것은? 자주
  1. ①그림이나 표를 포함할 수 없는 순수 텍스트 형식이다
  2. ②글꼴, 크기, 색상 등 서식 정보를 포함하며 다양한 워드프로세서 간 호환성이 높다
  3. ③Microsoft Word에서만 열 수 있는 전용 형식이다
  4. ④파일 크기가 가장 작은 문서 형식이다
19EDI(Electronic Data Interchange, 전자문서교환)에 대한 설명으로 옳은 것은? 자주
  1. ①개인이 사적인 메일을 주고받는 시스템이다
  2. ②문서의 형식(포맷)이 자유로워 표준화가 필요 없다
  3. ③기업과 기업 사이에 표준화된 형식으로 전자문서를 교환하는 시스템이다
  4. ④인터넷이 없는 환경에서만 사용할 수 있다
20보고서의 문장 전개 방식에서, 결론을 맨 앞에 제시하고 뒤에 근거를 설명하는 방식은? 자주
  1. ①미괄식(끝에 결론을 배치하는 방식)
  2. ②양괄식(처음과 끝에 결론을 배치하는 방식)
  3. ③열거식(여러 항목을 나열하는 방식)
  4. ④두괄식(처음에 결론을 배치하는 방식)

21Windows 탐색기(파일을 관리하는 프로그램)의 화면 구성에 대한 설명으로 옳은 것은? 자주
  1. ①왼쪽 창에는 파일의 내용이, 오른쪽 창에는 폴더 트리(나무 구조)가 표시된다
  2. ②탐색기에서는 파일의 보기 방식(아이콘 크기 등)을 변경할 수 없다
  3. ③왼쪽 창에는 폴더 트리(나무 구조)가, 오른쪽 창에는 선택한 폴더의 내용이 표시된다
  4. ④탐색기는 파일 검색 기능을 제공하지 않는다
22탐색기에서 떨어져 있는 파일 여러 개를 동시에 선택하려면 어떤 키를 누른 채 클릭해야 하는가? 자주
  1. ①Ctrl 키
  2. ②Alt 키
  3. ③Tab 키
  4. ④Shift 키
23휴지통(삭제한 파일이 임시로 보관되는 곳)에 대한 설명으로 틀린 것은? 자주
  1. ①휴지통을 비우면 파일이 영구적으로 삭제되어 일반적인 방법으로 복원할 수 없다
  2. ②휴지통의 최대 용량은 속성에서 변경할 수 있다
  3. ③Shift+Delete로 삭제하면 휴지통을 거치지 않고 바로 영구 삭제된다
  4. ④휴지통을 비워도 파일은 하드디스크 어딘가에 원본 그대로 남아 있다
24Windows에서 파일 이름을 바꿀 때 사용하는 단축키와, 파일 이름에 사용할 수 없는 문자의 조합으로 옳은 것은? 자주

25바로 가기(프로그램이나 파일로 빠르게 이동하는 아이콘)에 대한 설명으로 옳은 것은? 자주
  1. ①바로 가기를 삭제하면 원본 파일도 함께 삭제된다
  2. ②바로 가기 아이콘에는 화살표 표시가 없어 원본과 구별할 수 없다
  3. ③바로 가기는 원본의 위치 정보만 가지고 있어, 삭제해도 원본은 그대로 유지된다
  4. ④하나의 파일에 대해 바로 가기는 하나만 만들 수 있다
26Windows의 화면 보호기(일정 시간 사용하지 않으면 화면에 움직이는 그림이 나오는 기능)에 대한 설명으로 틀린 것은? 자주
  1. ①대기 시간을 분 단위로 설정할 수 있다
  2. ②개인 설정(또는 디스플레이 설정)에서 화면 보호기를 변경할 수 있다
  3. ③화면 보호기는 반드시 인터넷에서 다운로드해야 사용할 수 있다
  4. ④다시 시작 시 로그온 화면 표시 옵션을 설정할 수 있다
27Windows의 에어로 셰이크(Aero Shake) 기능에 대한 설명으로 옳은 것은? 자주
  1. ①창의 제목 표시줄을 잡고 좌우로 흔들면 다른 모든 창이 최소화된다
  2. ②창을 흔들면 해당 창만 최소화되고 나머지는 그대로 유지된다
  3. ③에어로 셰이크로 최소화한 창은 다시 흔들어도 복원되지 않는다
  4. ④에어로 셰이크는 데스크톱 아이콘을 정렬하는 기능이다
28작업 표시줄 오른쪽에 있는 알림 영역(시스템 트레이)에 기본으로 표시되는 항목으로 거리가 먼 것은? 자주
  1. ①시계(날짜와 시간)
  2. ②네트워크(인터넷 연결 상태) 아이콘
  3. ③파일 탐색기 바로 가기 아이콘
  4. ④볼륨(소리 크기) 아이콘
29운영체제의 멀티태스킹(다중 작업)에 대한 설명으로 옳은 것은? 자주
  1. ①한 번에 하나의 프로그램만 실행할 수 있는 방식이다
  2. ②여러 개의 프로그램을 동시에 실행하고 전환하며 사용할 수 있는 방식이다
  3. ③멀티태스킹을 사용하려면 CPU가 반드시 2개 이상이어야 한다
  4. ④멀티태스킹은 서버 운영체제에서만 지원되는 기능이다
30여러 프로그램을 실행 중일 때 Alt+Tab 키의 기능으로 옳은 것은? 자주
  1. ①현재 실행 중인 프로그램을 강제 종료한다
  2. ②바탕 화면의 아이콘을 정렬한다
  3. ③새 프로그램을 설치하는 창을 연다
