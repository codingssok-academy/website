11과목: 워드프로세싱 용어 및 기능Q1 – Q20
1다음 중 전자출판(DTP)의 장점으로 옳지 않은 것은? 매회
  1. ①전문 인쇄소 없이는 절대 출력할 수 없다
  2. ②다양한 글꼴과 그래픽을 활용할 수 있다
  3. ③인쇄 전 화면으로 미리보기가 가능하다
  4. ④편집과 수정이 용이하여 작업 시간이 단축된다
2다음 중 매크로(Macro) 기능의 장점으로 옳지 않은 것은? 매회
  1. ①복잡한 반복 작업을 자동화할 수 있다
  2. ②매크로 실행 중 수동 개입이 반드시 필요하다
  3. ③한 번 기록하면 여러 번 재사용할 수 있다
  4. ④작업 시간을 크게 단축시킬 수 있다
3다음 중 메일 머지(Mail Merge)의 장점으로 옳지 않은 것은? 매회
  1. ①동일한 양식의 문서를 대량으로 작성할 수 있다
  2. ②수신자별로 개별 내용을 자동 삽입할 수 있다
  3. ③데이터 파일과 본문 파일을 별도로 관리해야 하므로 파일 관리가 복잡해진다
  4. ④반복적인 문서 작성 시간을 절약할 수 있다
4다음 중 RTF(Rich Text Format) 파일 형식의 장점으로 옳지 않은 것은? 매회
  1. ①서로 다른 워드프로세서 간 호환이 가능하다
  2. ②서식 정보를 유지한 채 저장할 수 있다
  3. ③다양한 운영체제에서 열어볼 수 있다
  4. ④파일 용량이 원본보다 항상 작아진다
5다음 중 각주(Footnote) 기능의 장점으로 옳지 않은 것은? 매회
  1. ①문서 전체의 마지막 페이지에 모아서 표시된다
  2. ②해당 페이지에서 바로 보충 설명을 확인할 수 있다
  3. ③본문의 흐름을 끊지 않고 부가 정보를 제공할 수 있다
  4. ④참고 문헌이나 출처를 명시할 때 유용하다
6다음 중 WYSIWYG 방식의 장점으로 옳지 않은 것은? 매회
  1. ①화면에 보이는 그대로 인쇄 결과를 예측할 수 있다
  2. ②시스템 자원을 거의 사용하지 않아 저사양 PC에서도 원활하다
  3. ③별도의 코드 입력 없이 직관적으로 편집할 수 있다
  4. ④편집 결과를 실시간으로 확인할 수 있다
7다음 중 OCR(광학 문자 판독기)의 장점으로 옳지 않은 것은? 매회
  1. ①인쇄물을 스캔하여 편집 가능한 텍스트로 변환할 수 있다
  2. ②대량의 문서를 빠르게 디지털화할 수 있다
  3. ③필기체나 손글씨도 100% 정확하게 인식할 수 있다
  4. ④수동 입력에 비해 시간과 비용을 절감할 수 있다
8다음 중 공문서 전자문서화의 장점으로 옳지 않은 것은? 매회
  1. ①문서의 보관 및 검색이 용이하다
  2. ②종이 사용량을 줄여 비용을 절감할 수 있다
  3. ③네트워크를 통한 신속한 문서 전달이 가능하다
  4. ④전원이 차단되어도 문서 열람에 지장이 없다
9다음 중 TXT(텍스트) 파일 형식의 장점으로 옳지 않은 것은? 매회
  1. ①글꼴, 색상, 표 등 다양한 서식을 저장할 수 있다
  2. ②파일 용량이 매우 작다
  3. ③바이러스 감염 위험이 상대적으로 낮다
  4. ④거의 모든 프로그램에서 열어볼 수 있다
10다음 중 머리글/꼬리글 기능의 장점으로 옳지 않은 것은? 자주
  1. ①페이지 번호를 자동으로 매길 수 있다
  2. ②본문 영역과 겹쳐서 표시되므로 공간을 절약한다
  3. ③한 번 설정하면 모든 페이지에 자동 적용된다
  4. ④문서 제목이나 작성자를 매 페이지에 표시할 수 있다
11다음 중 글자 그림자(Shadow) 효과의 장점으로 옳지 않은 것은? 자주
  1. ①제목이나 강조 문구를 눈에 띄게 표현할 수 있다
  2. ②문서의 시각적 완성도를 높일 수 있다
  3. ③파일 용량의 변화 없이 적용할 수 있다
  4. ④입체감 있는 텍스트를 표현할 수 있다
12다음 중 문서 암호화 기능의 장점으로 옳지 않은 것은? 매회
  1. ①무단 열람으로부터 문서를 보호할 수 있다
  2. ②문서의 수정이나 복사를 제한할 수 있다
  3. ③기밀 정보를 안전하게 관리할 수 있다
  4. ④암호를 분실해도 문서를 쉽게 복구할 수 있다
13다음 중 스타일(Style) 기능의 장점으로 옳지 않은 것은? 자주
  1. ①스타일을 적용하면 해당 텍스트의 개별 서식 변경이 완전히 불가능해진다
  2. ②스타일 변경 시 해당 스타일이 적용된 모든 부분이 자동 변경된다
  3. ③반복적인 서식 지정 작업을 줄여 효율성을 높인다
  4. ④문서 전체의 서식을 일관되게 유지할 수 있다
14다음 중 잉크젯 프린터의 장점으로 옳지 않은 것은? 매회
  1. ①컬러 인쇄 품질이 우수하다
  2. ②인쇄 속도가 레이저 프린터보다 빠르다
  3. ③소음이 적어 사무 환경에 적합하다
  4. ④레이저 프린터에 비해 가격이 저렴하다
15다음 중 레이저 프린터의 장점으로 옳지 않은 것은? 매회
  1. ①인쇄 속도가 빠르다
  2. ②대량 인쇄 시 인쇄 비용이 저렴하다
  3. ③잉크젯에 비해 본체 가격이 저렴하다
  4. ④해상도가 높아 텍스트가 선명하다
16다음 중 찾기/바꾸기 기능의 장점으로 옳지 않은 것은? 자주
  1. ①문서 내 특정 단어를 빠르게 검색할 수 있다
  2. ②일괄 바꾸기로 수정 시간을 대폭 줄일 수 있다
  3. ③대소문자를 구분하여 정확한 검색이 가능하다
  4. ④삭제된 텍스트도 복원하여 검색할 수 있다
17다음 중 표(Table) 기능의 장점으로 옳지 않은 것은? 자주
  1. ①표의 데이터를 실시간으로 외부 데이터베이스와 동기화할 수 있다
  2. ②셀 병합·분할로 다양한 레이아웃을 구성할 수 있다
  3. ③간단한 계산(합계, 평균)을 수행할 수 있다
  4. ④데이터를 정렬하여 보기 쉽게 정리할 수 있다
18다음 중 자동 저장 기능의 장점으로 옳지 않은 것은? 자주
  1. ①정전이나 시스템 오류 시 데이터 손실을 최소화할 수 있다
  2. ②자동 저장이 활성화되면 수동 저장이 비활성화된다
  3. ③복구 시 마지막 자동 저장 시점의 문서를 되살릴 수 있다
  4. ④사용자가 별도로 저장하지 않아도 주기적으로 백업된다
19다음 중 다단(Multi-column) 편집의 장점으로 옳지 않은 것은? 자주
  1. ①신문이나 잡지 형태의 레이아웃을 구현할 수 있다
  2. ②좁은 단으로 나눠 가독성을 높일 수 있다
  3. ③단 수를 변경하면 문서 내용이 자동으로 요약된다
  4. ④한 페이지에 더 많은 내용을 효율적으로 배치할 수 있다
20다음 중 PDF 파일 형식의 장점으로 옳지 않은 것은? 매회
  1. ①어떤 환경에서든 동일한 레이아웃으로 출력된다
  2. ②운영체제에 관계없이 열어볼 수 있다
  3. ③무단 수정을 방지하는 보안 설정이 가능하다
  4. ④내용 편집이 워드프로세서만큼 자유롭다
22과목: PC 운영체제Q21 – Q40
21다음 중 GUI(그래픽 사용자 인터페이스)의 장점으로 옳지 않은 것은? 매회
  1. ①CLI보다 시스템 자원을 적게 사용한다
  2. ②초보자도 쉽게 사용할 수 있다
  3. ③마우스 클릭만으로 대부분의 작업을 수행할 수 있다
  4. ④아이콘과 메뉴로 직관적인 조작이 가능하다
22다음 중 CLI(명령줄 인터페이스)의 장점으로 옳지 않은 것은? 매회
  1. ①시스템 자원을 적게 사용한다
  2. ②별도의 학습 없이 누구나 바로 사용할 수 있다
  3. ③명령어 숙지 시 GUI보다 빠르게 작업할 수 있다
  4. ④반복 작업을 스크립트로 자동화할 수 있다
23다음 중 가상 메모리(Virtual Memory)의 장점으로 옳지 않은 것은? 매회
  1. ①실제 RAM보다 더 큰 프로그램을 실행할 수 있다
  2. ②여러 프로그램을 동시에 실행할 수 있는 환경을 제공한다
  3. ③RAM보다 접근 속도가 빨라 성능이 향상된다
  4. ④물리적 메모리의 한계를 극복할 수 있다
24다음 중 멀티태스킹(Multi-tasking)의 장점으로 옳지 않은 것은? 매회
  1. ①여러 프로그램을 동시에 실행할 수 있다
  2. ②작업 간 전환이 빠르고 편리하다
  3. ③CPU 활용률을 높일 수 있다
  4. ④프로그램 간 충돌이 절대 발생하지 않는다
25다음 중 Windows 바로 가기 아이콘의 장점으로 옳지 않은 것은? 매회
  1. ①바로 가기 아이콘을 삭제하면 원본 프로그램도 함께 제거된다
  2. ②바탕화면에서 더블클릭으로 바로 실행할 수 있다
  3. ③바로 가기를 삭제해도 원본 파일은 삭제되지 않는다
  4. ④자주 사용하는 프로그램에 빠르게 접근할 수 있다
26다음 중 Windows 작업 관리자의 장점으로 옳지 않은 것은? 자주
  1. ①응답 없는 프로그램을 강제 종료할 수 있다
  2. ②삭제된 파일을 복구할 수 있다
  3. ③실행 중인 프로세스 목록을 확인할 수 있다
  4. ④CPU 및 메모리 사용량을 실시간으로 확인할 수 있다
27다음 중 디스크 조각 모음의 장점으로 옳지 않은 것은? 자주
  1. ①파일 읽기/쓰기 속도가 향상된다
  2. ②하드디스크의 수명을 연장하는 데 도움이 된다
  3. ③SSD(솔리드 스테이트 드라이브)에 특히 효과적이다
  4. ④단편화된 파일을 연속된 공간에 재배치한다
28다음 중 휴지통(Recycle Bin)의 장점으로 옳지 않은 것은? 매회
  1. ①실수로 삭제한 파일을 복원할 수 있다
  2. ②삭제 전 파일의 원래 위치와 삭제 날짜를 확인할 수 있다
  3. ③비우기 전까지 파일이 보존된다
  4. ④USB 드라이브에서 삭제한 파일도 휴지통에 보관된다
29다음 중 Windows 레지스트리의 장점으로 옳지 않은 것은? 매회
  1. ①잘못 수정해도 시스템에 영향을 주지 않는다
  2. ②시스템 구성을 세밀하게 제어할 수 있다
  3. ③하드웨어·소프트웨어 정보를 통합 관리한다
  4. ④운영체제와 프로그램의 설정 정보를 중앙에서 관리한다
30다음 중 파일 압축의 장점으로 옳지 않은 것은? 자주
  1. ①파일 크기를 줄여 저장 공간을 절약할 수 있다
  2. ②압축 파일은 별도 프로그램 없이 항상 열 수 있다
  3. ③전송 시간을 단축할 수 있다
  4. ④여러 파일을 하나로 묶어 관리할 수 있다
31다음 중 Windows 방화벽의 장점으로 옳지 않은 것은? 매회
  1. ①외부로부터의 무단 접근을 차단할 수 있다
  2. ②네트워크 트래픽을 모니터링할 수 있다
  3. ③바이러스를 탐지하고 자동으로 치료할 수 있다
  4. ④특정 프로그램의 네트워크 접근을 제어할 수 있다
32다음 중 안전 모드(Safe Mode)의 장점으로 옳지 않은 것은? 자주
  1. ①문제가 있는 드라이버나 프로그램을 진단할 수 있다
  2. ②최소한의 드라이버만 로드하여 부팅한다
  3. ③시스템 오류 시 복구 작업을 수행할 수 있다
  4. ④일반 모드보다 모든 기능이 더 빠르게 동작한다
33다음 중 Windows 시스템 복원의 장점으로 옳지 않은 것은? 자주
  1. ①하드디스크의 물리적 손상도 복구할 수 있다
  2. ②복원 지점을 사용자가 직접 만들 수 있다
  3. ③개인 파일(문서, 사진)에는 영향을 주지 않는다
  4. ④프로그램 설치 후 오류 발생 시 이전 상태로 되돌릴 수 있다
34다음 중 NTFS 파일 시스템의 장점으로 옳지 않은 것은? 매회
  1. ①파일 및 폴더 단위로 접근 권한을 설정할 수 있다
  2. ②모든 운영체제에서 읽기·쓰기가 자유롭다
  3. ③파일 암호화 기능(EFS)을 지원한다
  4. ④4GB 이상의 대용량 파일을 저장할 수 있다
35다음 중 FAT32 파일 시스템의 장점으로 옳지 않은 것은? 매회
  1. ①Windows, macOS, Linux 등 대부분의 운영체제에서 호환된다
  2. ②USB 메모리 등 이동식 저장 장치에 널리 사용된다
  3. ③개별 파일 크기 제한 없이 대용량 파일을 저장할 수 있다
  4. ④구조가 단순하여 처리 속도가 빠르다
36다음 중 Windows 제어판의 장점으로 옳지 않은 것은? 자주
  1. ①하드웨어 및 소프트웨어 설정을 한곳에서 관리할 수 있다

  3. ③네트워크, 디스플레이, 사운드 등 다양한 설정을 변경할 수 있다
  4. ④운영체제의 커널 소스 코드를 직접 수정할 수 있다
37다음 중 클립보드(Clipboard)의 장점으로 옳지 않은 것은? 자주
  1. ①컴퓨터를 종료해도 클립보드 내용이 영구 보존된다
  2. ②프로그램 간에 텍스트나 이미지를 전달할 수 있다
  3. ③복사·잘라내기·붙여넣기 작업이 빠르고 편리하다
  4. ④복사한 내용을 원하는 위치에 여러 번 붙여넣기 할 수 있다
38다음 중 드라이버(Driver) 소프트웨어의 장점으로 옳지 않은 것은? 자주
  1. ①하드웨어와 운영체제 사이의 통신을 가능하게 한다
  2. ②새로운 하드웨어를 운영체제에서 인식하고 사용할 수 있게 한다
  3. ③드라이버 없이도 모든 하드웨어가 자동으로 동작한다
  4. ④드라이버 업데이트로 하드웨어 성능을 개선할 수 있다
39다음 중 Windows 업데이트의 장점으로 옳지 않은 것은? 자주
  1. ①보안 취약점을 패치하여 시스템을 보호한다
  2. ②업데이트 후 이전 버전의 프로그램이 모두 더 빨라진다
  3. ③버그 수정으로 시스템 안정성이 개선된다
  4. ④새로운 기능이 추가되어 사용 편의성이 향상된다
40다음 중 네트워크 공유 폴더의 장점으로 옳지 않은 것은? 자주
  1. ①여러 사용자가 동일 파일에 접근할 수 있다
  2. ②파일을 이메일로 보내지 않아도 공유가 가능하다
  3. ③네트워크 연결 없이도 공유 폴더에 접근할 수 있다
  4. ④접근 권한을 설정하여 보안을 유지할 수 있다

41다음 중 SSD(솔리드 스테이트 드라이브)의 장점으로 옳지 않은 것은? 매회
  1. ①HDD보다 데이터 읽기/쓰기 속도가 빠르다
  2. ②기계적 구동 부분이 없어 충격에 강하다
  3. ③소음이 거의 없고 발열이 적다
  4. ④HDD보다 GB당 가격이 저렴하다
42다음 중 HDD(하드디스크 드라이브)의 장점으로 옳지 않은 것은? 매회
  1. ①기계적 부품이 없어 진동과 충격에 강하다
  2. ②오랜 기간 검증된 안정적인 저장 매체이다
  3. ③대용량 모델이 다양하게 출시되어 있다
  4. ④GB당 가격이 저렴하여 대용량 저장에 유리하다
43다음 중 USB 메모리의 장점으로 옳지 않은 것은? 매회
  1. ①크기가 작고 휴대가 간편하다
  2. ②저장 용량이 무제한이다
  3. ③다양한 운영체제에서 호환된다
  4. ④별도의 전원 없이 USB 포트에 꽂아 바로 사용할 수 있다
44다음 중 광섬유(Optical Fiber) 케이블의 장점으로 옳지 않은 것은? 매회
  1. ①전송 속도가 매우 빠르다
  2. ②전자기 간섭(EMI)에 강하다
  3. ③설치 비용이 구리 케이블보다 저렴하다
  4. ④장거리 전송에 유리하다
45다음 중 클라우드 컴퓨팅의 장점으로 옳지 않은 것은? 매회
  1. ①인터넷만 연결되면 어디서든 데이터에 접근할 수 있다
  2. ②서버 구축 비용을 절감할 수 있다
  3. ③필요에 따라 자원을 유연하게 확장할 수 있다
  4. ④인터넷 연결 없이도 모든 서비스를 이용할 수 있다
46다음 중 오픈소스 소프트웨어의 장점으로 옳지 않은 것은? 자주
  1. ①제조사의 공식 기술 지원이 항상 보장된다
  2. ②무료로 사용할 수 있는 경우가 많다
  3. ③커뮤니티를 통한 빠른 버그 수정이 가능하다
  4. ④소스 코드가 공개되어 자유롭게 수정할 수 있다
47다음 중 무선 LAN(Wi-Fi)의 장점으로 옳지 않은 것은? 매회
  1. ①케이블 없이 자유롭게 이동하며 사용할 수 있다
  2. ②유선 LAN보다 보안이 강하고 속도가 항상 빠르다
  3. ③여러 기기를 동시에 연결할 수 있다
  4. ④설치가 간편하고 배선 비용이 절감된다
48다음 중 스프레드시트(엑셀)의 장점으로 옳지 않은 것은? 자주
  1. ①대량의 데이터를 표 형태로 관리할 수 있다
  2. ②수식과 함수를 이용한 자동 계산이 가능하다
  3. ③동영상 편집 기능이 내장되어 있다
  4. ④차트를 이용하여 데이터를 시각화할 수 있다
49다음 중 멀티미디어 데이터의 장점으로 옳지 않은 것은? 자주
  1. ①텍스트, 이미지, 오디오, 비디오를 통합하여 표현할 수 있다
  2. ②정보 전달력과 이해도를 높일 수 있다
  3. ③교육, 의료, 오락 등 다양한 분야에 활용된다
  4. ④파일 용량이 작아 저장 공간이 거의 필요 없다
50다음 중 벡터(Vector) 그래픽의 장점으로 옳지 않은 것은? 매회
  1. ①사진과 같은 복잡한 이미지 표현에 유리하다
  2. ②파일 용량이 비트맵에 비해 작다
  3. ③로고나 일러스트 제작에 적합하다
  4. ④확대해도 이미지 품질이 저하되지 않는다
51다음 중 비트맵(Bitmap) 그래픽의 장점으로 옳지 않은 것은? 매회
  1. ①사진처럼 색상이 풍부한 이미지를 표현할 수 있다
  2. ②확대해도 이미지 품질이 전혀 떨어지지 않는다
  3. ③세밀한 색상 표현과 그라데이션이 가능하다
  4. ④디지털 카메라로 촬영한 이미지를 자연스럽게 저장한다
52다음 중 IPv6 주소 체계의 장점으로 옳지 않은 것은? 자주
  1. ①IPv4보다 훨씬 많은 주소 공간을 제공한다
  2. ②보안 기능(IPsec)이 기본 내장되어 있다
  3. ③IPv4 기기와 별도 변환 없이 직접 통신할 수 있다
  4. ④주소 자동 설정 기능을 지원한다
53다음 중 JPEG 이미지 형식의 장점으로 옳지 않은 것은? 매회
  1. ①사진 이미지의 파일 크기를 효과적으로 줄일 수 있다
  2. ②약 1,677만 색상(24비트 컬러)을 지원한다
  3. ③웹에서 가장 널리 사용되는 이미지 형식이다
  4. ④압축과 복원을 반복해도 화질 손실이 전혀 없다
54다음 중 데이터베이스 관리 시스템(DBMS)의 장점으로 옳지 않은 것은? 자주
  1. ①시스템 도입 비용과 운영 비용이 들지 않는다
  2. ②다수의 사용자가 동시에 데이터에 접근할 수 있다
  3. ③데이터의 일관성과 무결성을 유지할 수 있다
  4. ④데이터 중복을 최소화할 수 있다
55다음 중 인터프리터(Interpreter) 방식의 장점으로 옳지 않은 것은? 자주
  1. ①프로그램 수정 후 즉시 실행 결과를 확인할 수 있다
  2. ②컴파일러 방식보다 실행 속도가 빠르다
  3. ③별도의 컴파일 과정 없이 바로 실행할 수 있다
  4. ④줄 단위로 번역하므로 오류 위치를 쉽게 파악할 수 있다
56다음 중 컴파일러(Compiler) 방식의 장점으로 옳지 않은 것은? 자주
  1. ①전체 소스를 기계어로 변환하여 실행 속도가 빠르다
  2. ②한 번 컴파일하면 반복 실행 시 재번역이 필요 없다
  3. ③소스 코드를 수정할 때마다 바로 결과를 확인할 수 있다
  4. ④최적화를 통해 효율적인 실행 파일을 생성할 수 있다
57다음 중 유니코드(Unicode)의 장점으로 옳지 않은 것은? 자주
  1. ①전 세계 모든 문자를 하나의 코드 체계로 표현할 수 있다
  2. ②다국어 문서 작성 시 문자 깨짐을 방지할 수 있다
  3. ③이모지(emoji)도 표현할 수 있다
  4. ④ASCII보다 적은 비트를 사용하여 저장 효율이 높다
58다음 중 스타 토폴로지(Star Topology)의 장점으로 옳지 않은 것은? 매회
  1. ①한 노드에 장애가 발생해도 다른 노드에 영향이 적다
  2. ②새로운 노드의 추가·제거가 쉽다
  3. ③장애 발생 시 원인 진단이 용이하다
  4. ④중앙 허브가 고장 나도 네트워크 전체가 정상 작동한다
59다음 중 RAM(주기억장치)의 장점으로 옳지 않은 것은? 매회
  1. ①전원이 꺼져도 데이터가 영구 보존된다
  2. ②읽기와 쓰기가 모두 가능하다
  3. ③프로그램 실행 시 데이터를 임시 저장하여 처리 속도를 높인다
  4. ④CPU가 데이터에 빠르게 접근할 수 있다
60다음 중 ROM(읽기 전용 메모리)의 장점으로 옳지 않은 것은? 매회
  1. ①전원이 꺼져도 데이터가 유지된다
  2. ②사용자가 언제든 자유롭게 내용을 수정할 수 있다
  3. ③데이터 변조의 위험이 적어 보안성이 높다
  4. ④BIOS 등 시스템 기본 프로그램을 안전하게 저장한다
