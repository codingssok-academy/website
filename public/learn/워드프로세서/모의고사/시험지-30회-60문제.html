  2. ②페이지 번호, 작성일, 파일명 등을 삽입할 수 있다
  3. ③머리글과 꼬리글은 각 페이지마다 개별 설정해야 한다
  4. ④인쇄 시 모든 페이지에 동일하게 출력된다

  4. ④매크로 실행 시 원본 파일이 자동 백업된다

  3. ③텍스트만 교환할 수 있는 파일 형식이다
  4. ④문서를 웹 페이지로 변환하는 기능이다

  3. ③각 단의 폭을 서로 다르게 설정할 수 있다
  4. ④단 나누기를 설정하면 페이지 방향이 자동으로 가로로 변경된다

  2. ②문서의 각 페이지에 순서대로 번호를 매긴다
  3. ③특정 텍스트에 하이퍼링크를 설정한다
  4. ④문서를 읽기 전용으로 설정한다
18다음 중 상용구(AutoText)에 대한 설명으로 옳은 것은? 자주
  1. ①자주 사용하는 문구를 등록해두고 간단히 불러오는 기능이다
  2. ②문서의 오타를 자동으로 수정하는 기능이다
  3. ③문서를 다른 언어로 번역하는 기능이다
  4. ④글자 수를 자동으로 세는 기능이다
19다음 중 아스키(ASCII) 코드에 대한 설명으로 옳지 않은 것은? 매회

  2. ②영문 대·소문자, 숫자, 특수문자를 포함한다
  3. ③한글을 포함한 다국어 문자를 지원한다
  4. ④미국 표준 정보 교환 코드이다

  1. ①일정한 순서 없이 텍스트를 작성하는 방식이다
  2. ②음성을 텍스트로 변환하는 기술이다
  3. ③문서 내 특정 단어를 클릭하면 관련 문서로 이동하는 비순차적 정보 연결 방식이다
  4. ④텍스트를 이미지로 변환하는 기술이다

22다음 중 Windows 레지스트리(Registry)에 대한 설명으로 옳은 것은? 매회
  1. ①운영체제 및 프로그램의 설정 정보를 저장하는 데이터베이스이다
  2. ②임시 파일을 저장하는 폴더이다
  3. ③네트워크 드라이버를 관리하는 도구이다
  4. ④디스크 조각 모음을 수행하는 유틸리티이다
23다음 중 FAT32와 NTFS 파일 시스템의 비교로 옳은 것은? 매회
  1. ①FAT32가 NTFS보다 보안 기능이 뛰어나다
  2. ②NTFS는 파일 암호화와 접근 권한 설정을 지원한다
  3. ③FAT32는 4TB 이상의 단일 파일을 저장할 수 있다
  4. ④NTFS는 USB 메모리에만 사용할 수 있다
24다음 중 Windows 작업 관리자에서 확인할 수 없는 것은? 자주
  1. ①현재 실행 중인 프로세스 목록
  2. ②CPU 및 메모리 사용률
  3. ③네트워크 사용 현황
  4. ④하드디스크의 물리적 배드 섹터 위치
25다음 중 Windows 명령 프롬프트에서 디렉터리의 파일 목록을 보는 명령어는? 매회
  1. ①DIR
  2. ②CD
  3. ③COPY
  4. ④DEL
26다음 중 가상 메모리(Virtual Memory)에 대한 설명으로 옳은 것은? 매회
  1. ①하드디스크의 일부를 RAM처럼 사용하여 메모리 부족을 해결하는 기법이다
  2. ②RAM을 물리적으로 확장하는 하드웨어이다
  3. ③캐시 메모리의 다른 이름이다
  4. ④USB 메모리를 RAM으로 변환하는 기능이다
27다음 중 스풀링(Spooling)에 대한 설명으로 옳은 것은? 매회
  1. ①CPU와 입출력 장치 사이의 속도 차이를 해결하기 위해 디스크를 버퍼로 사용한다
  2. ②메모리의 단편화를 해결하는 기법이다
  3. ③네트워크 대역폭을 늘리는 기술이다
  4. ④CPU의 처리 속도를 높이는 오버클럭 기술이다
28다음 중 Windows 휴지통에 대한 설명으로 옳지 않은 것은? 매회
  1. ①삭제된 파일을 임시 보관하여 복원할 수 있다
  2. ②Shift + Delete로 삭제하면 휴지통에 보관되지 않는다
  3. ③네트워크 드라이브에서 삭제한 파일도 휴지통에 보관된다
  4. ④휴지통 크기를 사용자가 설정할 수 있다
29다음 중 멀티태스킹(Multitasking)에 대한 설명으로 옳은 것은? 매회
  1. ①하나의 CPU가 여러 프로그램을 동시에 실행하는 것처럼 처리한다
  2. ②여러 대의 컴퓨터가 하나의 작업을 분담한다
  3. ③여러 사용자가 동시에 하나의 프로그램을 사용한다
  4. ④하나의 프로그램을 여러 CPU가 병렬 처리한다
30다음 중 장치 드라이버(Device Driver)에 대한 설명으로 옳지 않은 것은? 자주
  1. ①운영체제와 하드웨어 장치 사이의 통신을 담당하는 소프트웨어이다
  2. ②프린터, 그래픽 카드 등 주변 장치에 필요하다
  3. ③드라이버가 없어도 모든 하드웨어는 기본 기능을 사용할 수 있다
  4. ④장치 관리자에서 드라이버를 업데이트할 수 있다
31다음 중 클립보드(Clipboard)에 대한 설명으로 옳은 것은? 자주
  1. ①파일을 영구 저장하는 보조 기억 장치이다
  2. ②복사·잘라내기한 데이터를 임시 저장하는 메모리 영역이다
  3. ③인터넷 검색 기록을 저장하는 공간이다
  4. ④삭제된 파일을 복구하는 도구이다
32다음 중 안전 모드(Safe Mode)에 대한 설명으로 옳은 것은? 매회
  1. ①최소한의 드라이버와 서비스만으로 Windows를 시작하는 진단 모드이다
  2. ②바이러스를 자동으로 치료하는 모드이다
  3. ③네트워크 속도를 최대로 올리는 모드이다
  4. ④모든 프로그램을 최신 버전으로 업데이트하는 모드이다
33다음 중 PnP(Plug and Play)에 대한 설명으로 옳은 것은? 매회
  1. ①프로그램을 자동으로 업데이트하는 기능이다
  2. ②하드웨어를 연결하면 드라이버가 자동 설치되어 바로 사용할 수 있는 기능이다
  3. ③네트워크에 자동으로 접속하는 프로토콜이다
  4. ④파일을 자동으로 백업하는 기능이다
34다음 중 Windows 제어판에서 설정할 수 없는 것은? 자주
  1. ①프로그램 추가/제거
  2. ②디스플레이 해상도 변경
  3. ③네트워크 및 인터넷 설정
  4. ④BIOS 부팅 순서 변경
35다음 중 바이러스(Virus)와 웜(Worm)의 차이점으로 옳은 것은? 매회
  1. ①바이러스는 네트워크로 전파되고 웜은 파일에 감염된다
  2. ②바이러스는 숙주 파일이 필요하지만 웜은 스스로 복제·전파할 수 있다
  3. ③웜은 바이러스의 일종으로 기능이 동일하다
  4. ④바이러스는 자가 복제가 불가능하다
36다음 중 디스크 조각 모음(Defragmentation)에 대한 설명으로 옳은 것은? 매회
  1. ①삭제된 파일을 복구하는 기능이다
  2. ②바이러스를 검사하고 치료하는 기능이다
  3. ③흩어진 파일 조각을 연속 배치하여 디스크 성능을 향상시킨다
  4. ④디스크의 저장 용량을 늘리는 기능이다
37다음 중 Windows 파일 속성에 해당하지 않는 것은? 자주
  1. ①읽기 전용(Read-only)
  2. ②숨김(Hidden)
  3. ③보관(Archive)
  4. ④실행 전용(Execute-only)
38다음 중 Windows 바탕화면 아이콘 관리에 대한 설명으로 옳지 않은 것은? 매회
  1. ①바로 가기 아이콘은 원본 파일의 위치를 가리키는 링크이다
  2. ②바로 가기 아이콘을 삭제하면 원본 파일도 삭제된다
  3. ③바로 가기 아이콘에는 화살표 표시가 있다
  4. ④아이콘을 드래그하여 위치를 이동할 수 있다
39다음 중 운영체제의 역할로 옳지 않은 것은? 자주

  1. ①네트워크 케이블의 물리적 규격이다

  3. ③데이터를 암호화하여 전송하는 프로토콜이다
  4. ④하드디스크의 데이터를 백업하는 장치이다

  3. ③최대 127개의 장치를 연결할 수 있다
  4. ④USB 2.0은 USB 3.0보다 전송 속도가 빠르다

  3. ③네트워크 장비를 물리적으로 연결하는 장치이다
