Chapter 10

프로젝트: 공지문 초안 편집하기

선택, 복사, 찾기, 글자 모양을 묶어서 짧은 공지문을 실제로 손봐 보는 첫 편집 프로젝트예요.

이 유닛에서 배우는 것

  • 짧은 공지문 초안을 읽고 수정할 수 있어요.
  • 제목과 본문을 문자 서식으로 구분할 수 있어요.
  • 반복 표현을 찾기/바꾸기로 정리할 수 있어요.
  • 편집 작업을 순서대로 진행하는 프로젝트 루틴을 익혀요.

선수 학습

커서 이동과 선택을 할 수 있다
→
복사, 잘라내기, 붙여넣기, 되돌리기를 사용할 수 있다
→
찾기/바꾸기와 문자 서식의 기본을 안다

초안은 처음부터 완벽하지 않아요

실제 문서 작업은 처음부터 완성된 글을 입력하는 경우보다, 이미 있는 초안을 더 읽기 좋게 다듬는 일이 더 많아요. 이번 프로젝트는 그런 흐름을 연습하는 단계예요.

[핵심] 이번 프로젝트의 목표 1. 제목을 본문과 구분해요.
2. 반복되는 표현을 정리해요.
3. 잘못된 순서나 배치를 바로잡아요.
4. 수정 후 저장까지 끝내요.

초안 예시

줄초안 내용문제점
1학교행사안내제목과 본문 구분이 약해요
2이번주 금요일 학교행사가 있습니다띄어쓰기와 가독성 보완 필요
3준비물 준비물 필통 물반복 표현 정리 필요
4운동장 집합 9시정보 순서를 다듬으면 더 읽기 쉬워요

편집 순서

1
1단계 제목 먼저 정리
첫 줄을 제목으로 보고 크기나 굵게를 조정해요.
2
2단계 반복 표현 정리
찾기/바꾸기나 직접 수정을 이용해 중복 단어를 없애요.
3
3단계 정보 순서 정리
시간, 장소, 준비물처럼 읽기 쉬운 순서로 배열해요.
4
4단계 저장
수정본 파일로 저장해 결과를 남겨요.
[팁] 프로젝트는 위에서 아래로 정리해요 짧은 공지문은 제목 -> 본문 -> 세부 정보 순서로 보면 좋아요. 처음부터 세세한 글자 하나보다 큰 구조를 먼저 잡으면 편해요.
편집 대상쓸 기능목표
제목글자 크기, 굵게첫눈에 제목이 보이게
반복 표현찾기/바꾸기 또는 직접 수정중복 제거
정보 순서선택 후 잘라내기/붙여넣기읽기 쉬운 흐름 만들기
최종 결과저장수정본 파일 남기기
[주의] 프로젝트에서 흔한 실수 1. 제목만 꾸미고 내용은 안 고침
2. 중복 단어를 놓침
3. 순서를 바꾸다 문장을 잃어버림
4. 수정 후 저장을 빼먹음

직접 해보기

실습 1

초안 예시를 직접 문서에 입력한 뒤, 첫 줄 제목을 본문과 다르게 보이도록 수정해 보세요.

실습 2

`준비물 준비물`처럼 반복되는 표현을 찾아 하나만 남기도록 고쳐 보세요.

실습 3

`운동장 집합 9시` 문장을 더 읽기 쉬운 순서로 바꿔 보세요. 필요한 경우 잘라내기와 붙여넣기를 사용해 보세요.

용어설명
초안완성 전에 먼저 적어 둔 문서의 기본 형태
편집문서를 고치고 옮기고 다듬는 작업
반복 표현같은 단어나 문장이 불필요하게 여러 번 나온 상태
수정본원본을 고친 뒤 저장한 결과 문서
핵심 정리
1. 초안 편집은 제목, 반복 표현, 정보 순서부터 보면 쉬워요.
2. 선택, 잘라내기, 붙여넣기, 찾기/바꾸기, 문자 서식이 함께 쓰여요.
3. 프로젝트는 수정 후 저장까지 해야 끝이에요.
[실생활] 어디에 쓰일까요? 학교 행사 공지, 동아리 안내, 반 소식지처럼 짧은 공지문은 실제 생활에서 아주 자주 만들어요. 이번 프로젝트는 그런 문서를 빠르게 정리하는 첫 연습이에요.
[다음 유닛 미리보기] 다음 블록에서는 문단 모양으로 넘어가요. 이제 글자 하나가 아니라 문단 전체를 정렬하고 줄 간격을 다듬는 단계예요.
