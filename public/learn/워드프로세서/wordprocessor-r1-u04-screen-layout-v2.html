한글 화면 구성과 기본 도구 찾기

버튼이 많아 보여도 구역만 알면 길을 잃지 않아요. 화면을 읽는 법부터 잡아봐요.

이 유닛에서 배우는 것

  • 워드프로세서 화면의 주요 구역을 이름으로 부를 수 있어요.
  • 메뉴, 리본, 문서 영역, 눈금자, 상태 표시줄의 역할을 이해해요.
  • 자주 쓰는 기능이 어느 구역에 있는지 큰 방향을 잡을 수 있어요.
  • 기능을 무작정 찾지 않고 화면 구조로 접근하는 습관을 익혀요.

버튼이 많아 보여도 구역만 알면 쉬워요

처음 한글이나 Word를 열면 버튼이 너무 많아 보여요. 그래서 많은 학생이 화면을 무섭게 느껴요. 그런데 실제로는 버튼 하나하나를 외우는 게 아니라 어느 구역에 어떤 기능이 모여 있는지만 알면 훨씬 쉬워져요.

문서 프로그램은 비슷한 성격의 기능끼리 묶여 있어요. 글자 관련 기능, 문단 관련 기능, 삽입 기능, 페이지 관련 기능이 따로 모여 있기 때문에 길만 알면 원하는 도구를 빨리 찾을 수 있어요.

[핵심] 먼저 볼 5개 구역 문서 영역 — 실제 글을 쓰는 곳
메뉴/리본 — 기능을 찾는 곳
눈금자 — 들여쓰기와 폭을 보는 곳
스크롤 막대 — 위아래로 이동하는 곳
상태 표시줄 — 현재 페이지와 입력 상태를 보는 곳

자주 쓰는 기능은 어디에서 찾을까요?

1
글자 모양이 필요할 때
홈 또는 기본 탭에서 글꼴, 크기, 굵게, 색을 먼저 찾아요.
2
문단 정렬이 필요할 때
홈이나 문단 관련 구역에서 정렬과 줄 간격을 찾아요.
3
표와 그림을 넣을 때
삽입 탭이나 개체 관련 메뉴를 먼저 봐요.
4
용지나 여백을 바꿀 때
쪽, 레이아웃, 편집 용지 같은 메뉴 쪽으로 이동해요.
[주의] 버튼을 눈으로만 사냥하지 마세요 기능을 찾을 때 화면 전체를 훑으면서 비슷한 아이콘을 찍는 습관은 시험에서 위험해요. 먼저 어느 구역의 기능인지를 생각한 다음, 그 안에서 찾는 습관을 들여야 해요.

직접 해보기

실습 1

문서 프로그램을 열고 화면 위, 가운데, 아래에서 각각 어떤 구역이 보이는지 직접 말해 보세요. 메뉴, 문서 영역, 상태 표시줄을 찾아보세요.

실습 2

표를 넣고 싶다면 어느 탭이나 메뉴 쪽을 먼저 볼지, 편집 용지를 바꾸고 싶다면 어느 쪽을 먼저 볼지 스스로 적어 보세요.

용어설명
리본기능을 종류별로 묶어 보여주는 상단 도구 영역
문서 영역실제로 글과 표를 입력하는 작업 공간
눈금자여백과 위치를 눈으로 가늠하는 도구
상태 표시줄페이지 번호나 입력 상태처럼 현재 문서 정보를 보여주는 줄
핵심 정리
1. 문서 프로그램은 버튼을 외우는 게 아니라 구역을 먼저 읽어야 쉬워요.
2. 문서 영역, 메뉴, 눈금자, 상태 표시줄의 역할을 구분하면 길을 잃지 않아요.
3. 하고 싶은 작업이 어떤 종류인지 먼저 생각하면 기능을 더 빨리 찾을 수 있어요.
[실생활] 어디에 쓰일까요? 학교 보고서나 안내문을 만들 때도 결국 필요한 기능을 빨리 찾는 사람이 작업을 더 빨리 끝내요. 화면 구성을 아는 건 워드프로세서의 지도 보는 법과 같아요.
[다음 유닛 미리보기] 다음 유닛에서는 첫 프로젝트로 자기소개 문서를 직접 만들고 저장해요. 지금까지 배운 입력, 저장, 화면 읽기를 한 번에 묶어 볼 거예요.
