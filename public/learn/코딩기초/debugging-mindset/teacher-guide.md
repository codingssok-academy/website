# 🎓 교사용 지도안 — 디버깅 탐정 수업

**대상**: 초등학교 3~6학년
**총 소요시간**: 90분
**준비물**: 화이트보드, 마커, 학생용 태블릿/노트북 (선택), `lesson.html` 화면 공유

---

## 🎯 수업 목표

이 수업이 끝나면 학생은:
1. **버그**가 무엇인지 설명할 수 있다
2. **LAF 3단계**(Look-Ask-Fix)로 문제를 찾아낼 수 있다
3. 일상 속 "잘못된 지시"와 코드 오류를 **같은 방식**으로 분석할 수 있다
4. AI에게 **명확한 질문**을 만들 수 있다
5. AI 답변을 **검증하는 습관**을 갖기 시작한다

---

## 📅 타임라인 (90분 기준)

| 시간 | 섹션 | 활동 |
|---|---|---|
| 0~5분 | 훅: 이상한 라면 레시피 | 선생님이 읽어주고, 학생이 "뭐가 빠졌지?" 지적 |
| 5~15분 | 버그 & 디버깅 개념 | 나방 이야기 + 프로그래머는 왜 디버깅이 중요한지 |
| 15~25분 | LAF 3단계 | 칠판에 3글자 크게 쓰고 계산기 예제로 시연 |
| 25~45분 | 일상 디버깅 퀴즈 3개 | 학생이 직접 답하고 토론 |
| 45~65분 | 코드 디버깅 실습 | 파이썬 버그 2개, LAF로 해결 |
| 65~80분 | AI 질문 디버깅 | 나쁜 질문 vs 좋은 질문, 실제 나바쌤 시연 |
| 80~85분 | 오늘 정리 | LAF 복습, 슈퍼파워 선언 |
| 85~90분 | 숙제 안내 | 탐정 미션 3개 공책에 적기 |

## 🔥 섹션별 진행 가이드

### 📍 섹션 1. 훅 (5분) — 집중력 잡기

**목표**: 수업 시작하자마자 학생 뇌를 "문제 찾기 모드"로 전환

**진행법**:
1. 화이트보드에 라면 레시피를 **일부러 빠뜨리고** 크게 쓴다:
   ```
   1. 물 끓이기
   2. 면 넣기
   3. 면 꺼내기
   4. 먹기
   ```
2. "선생님이 알려준 대로 라면 만들면 어떻게 될까?" 질문
3. 학생들이 "수프가 빠졌어요!" "너무 일찍 꺼냈어요!" 등 외침
4. **중요 포인트**: "이렇게 지시가 이상하거나 빠진 걸 **버그**라고 해!"

**❗ 주의**: 답을 미리 말하지 말 것. 학생들이 스스로 찾게 유도.

---

### 📍 섹션 2. 버그 & 디버깅 (10분)

**목표**: 개념을 **이야기**로 머리에 박기

**진행법**:
1. **나방 이야기**: "옛날에 컴퓨터 안에 진짜 나방(Bug)이 들어가서 망가졌대! 그래서 프로그램이 이상할 때 '버그 생겼다'고 말해."
2. **큰 그림**: "프로그래머는 하루의 50%를 디버깅해!"
3. **의미 재정의**: "버그 = 내가 원한 것과 다른 결과 / 디버깅 = 그걸 찾아서 고치기"

**❗ 팁**: "50%"라는 숫자를 강조하면 아이들 눈이 커짐. "진짜요?"

---

### 📍 섹션 3. LAF 3단계 (10분)

**목표**: 평생 쓸 프레임워크 주입

**진행법**:
1. 칠판에 크게:
   ```
   L = Look (잘 봐)
   A = Ask (물어봐)
   F = Fix (고쳐봐)
   ```
2. 계산기 예제 시연:
   - "1+1 했는데 3이 나와!"
   - **L**: "결과가 3이네" (확인)
   - **A**: "원래 2여야 하는데? 왜 3이지?"
   - **F**: "혹시 +를 -로 잘못 눌렀나?" (원인 추정)
3. **반복 학습**: 학생과 함께 "엘! 에이! 에프!" 큰 소리로 외치기

**❗ 주의**: 이 3단계를 **이후 모든 활동**에서 계속 참조. 반복만이 답.

---

### 📍 섹션 4. 일상 디버깅 (20분)

**목표**: 프로그래밍 = 일상의 문제 해결이라는 것 체득

**진행법**:
1. `lesson.html` 화면 공유 (섹션 4)
2. 퀴즈 3개를 **학생이 직접 클릭**하게 함 (원격수업이면 채팅으로 답)
3. **답 맞춘 학생 칭찬 > 틀린 학생 격려**:
   - 정답: "완벽한 탐정이야! 왜 이게 답이야?" (설명 유도)
   - 오답: "재밌는 생각! 근데 LAF로 다시 볼까?"

**❗ 팁**: 마지막 퀴즈(자전거)는 난이도 높음. 시간 주고 토론하게.

---

### 📍 섹션 5. 코드 디버깅 (20분)

**목표**: 실제 코드에서 LAF 적용

**진행법**:
1. 첫 번째 예제 (고양이 vs 강아지) — **선생님이 직접** LAF 시연
2. 두 번째 예제 (range 버그) — **학생이 찾기**
3. 여유되면 나바쌤에게 "이 코드 왜 안 돼?" 물어보고, 답이 맞는지 검증

**💡 선생님 멘트 예시**:
- "range(1, 5)는 사실 1, 2, 3, 4까지야. 5는 포함 안 해! 이게 컴퓨터의 규칙이야. 놀라운 버그지?"

**❗ 주의**: range 개념이 처음이면 숫자 세면서 설명. "0부터 시작"도 언급하면 혼란 가중 → 이번엔 1부터만.

---

### 📍 섹션 6. AI 디버깅 (15분)

**목표**: AI를 "맹목적으로 쓰지 않는" 습관 시작

**진행법**:
1. 나쁜 질문 vs 좋은 질문 비교 설명
2. **시연**: 실제로 나바쌤에게 나쁜 질문 → 이상한 답 → 학생들 반응 관찰
3. 다시 좋은 질문으로 바꿔서 물어봄 → 정확한 답
4. **핵심 강조**: "AI 답이 항상 맞는 건 아니야! 꼭 실행해봐"

**💡 강력한 순간 만들기**:
- 일부러 나바쌤에게 "강아지를 파이썬으로 만들어줘" 같은 애매한 질문
- AI가 이상한 답 하면 학생들 웃음 → 기억에 남음

---

### 📍 섹션 7. 정리 (5분)

**목표**: 오늘 배운 것 한 줄로 요약

**진행법**:
- 학생들에게 "오늘 배운 슈퍼파워 한 단어로?" 질문
- 답: "**디버깅**" 또는 "**LAF**"
- 다 같이 외치기: "왜 안 될까? 찾는다!"

---

### 📍 섹션 8. 숙제 안내 (5분)

**숙제**:
1. 일상 버그 3개 찾기 (LAF 적용)
2. AI에게 물을 좋은 질문 3개 만들기
3. 보너스: 나쁜 질문을 일부러 해보고 왜 이상한지 적기

**❗ 중요**: 숙제는 **공책에 손으로 쓰게** 할 것. AI로 숙제하지 않게!

## 🎨 수업 분위기 만들기 팁

### ✅ 해야 할 것
- "버그 찾았어!" 외치면 박수
- 틀린 답에도 "왜 그렇게 생각했어?" 관심 보이기
- 선생님도 일부러 "아이고 나도 버그 만들었네~" 장난스럽게 실수 인정
- LAF 3글자를 **반복해서** 외치게 하기

### ❌ 피해야 할 것
- "이것도 몰라?" 같은 말
- 정답을 바로 알려주기 (학생이 찾을 시간 주기)
- 모든 학생에게 같은 속도 강요

## 🧰 확장 활동 (시간 남을 때)

### 추가 활동 1: "버그 마스터 대결"
- 학생 2명이 나와서 코드 하나씩 주고 누가 먼저 버그 찾는지 대결
- 발표력 + 디버깅 + 자신감 트레이닝

### 추가 활동 2: "나쁜 선생님 역할극"
- 선생님이 일부러 이상한 지시 줌 ("공책 꺼내고 읽어")
- 학생이 "뭐 읽어요? 뭐 공책이요? 버그입니다!" 하며 지적

### 추가 활동 3: "AI 상담실"
- 학생 각자 나바쌤에게 질문 하나씩
- 답이 이상하면 반에서 공유, 왜 이상한지 토론

## 📊 평가 포인트

수업 끝에 학생이 이 질문에 답할 수 있으면 성공:
1. "디버깅이 뭐야?" → **"왜 안 되는지 찾아서 고치는 것"**
2. "LAF가 뭐야?" → **"Look, Ask, Fix"**
3. "AI한테 잘 물어보는 방법?" → **"뭘 원하는지, 무슨 언어로, 어떤 상황인지 명확히"**
4. "AI 답은 항상 맞아?" → **"아니, 꼭 실행해서 확인해야 해"**

## 💬 자주 나오는 학생 질문 & 대답

**Q: "그런데 선생님, AI가 버그도 고쳐주잖아요?"**
> 맞아! 근데 AI가 고쳐준 게 **정말 맞는지** 누가 확인할까? 네가 LAF로 확인해야 해. 그게 프로그래머의 일이야.

**Q: "왜 컴퓨터는 실수를 할까요?"**
> 사실 컴퓨터는 실수 안 해. **사람이** 명령을 잘못 쓴 거지. 그걸 우리가 고치는 게 디버깅이야.

**Q: "나방이 진짜 컴퓨터에 들어갔어요?"**
> 응! 1947년에 진짜 있었던 일이야. 그때는 컴퓨터가 방만큼 커서 벌레가 들어갈 수 있었거든.

**Q: "디버깅 잘하려면 뭐가 필요해요?"**
> 👀 관찰력, 🤔 궁금증, 🔄 포기 안 하는 마음. 이 세 개만 있으면 돼.
