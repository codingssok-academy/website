MATH THINKING · UNIT 01

참과 거짓

명제란 무엇인가 — 컴퓨터처럼 생각하는 첫걸음

이 단원에서 배울 것

  • 명제의 정의: 참/거짓을 판단할 수 있는 문장
  • 명제와 명제가 아닌 문장 구분하기
  • 일상 문장을 명제로 다듬는 연습
  • 컴퓨터가 명제를 다루는 방식 (Boolean)

1. 명제란 무엇일까?

명제(命題, Proposition)는 참(True)인지 거짓(False)인지 명확하게 판단할 수 있는 문장이에요.

💡 핵심: "그 문장이 맞는지 틀린지 누구나 똑같이 판단할 수 있다면" 명제예요.

명제인 것

  • "3은 홀수다" → 참 ✓
  • "2 + 2 = 5" → 거짓 ✗
  • "서울은 한국의 수도다" → 참 ✓
  • "고래는 물고기다" → 거짓 ✗ (포유류)

명제가 아닌 것

  • "오늘 날씨 좋다!" → 사람마다 기준이 다름 (감상)
  • "x + 3 = 7" → x를 모르면 판단 불가 (변수 포함)
  • "창문 좀 열어줘" → 명령문, 참/거짓 없음
  • "몇 시야?" → 의문문

⚠️ 주의: "x + 3 = 7" 같은 식은 명제가 아니지만, "x = 4일 때 x + 3 = 7이 참이다"처럼 만들면 명제가 됩니다.

2. 컴퓨터는 명제를 어떻게 다룰까?

컴퓨터는 모든 판단을 참(True) 또는 거짓(False) 둘 중 하나로 처리해요. 이걸 Boolean(불리언) 자료형이라고 해요.

나이 = 15
나이 >= 13   # → True (참)
나이 == 20   # → False (거짓)
나이 < 10    # → False (거짓)

위 코드에서 나이 >= 13은 "나이가 13 이상이다"라는 명제예요. 컴퓨터는 이 명제를 보고 True를 돌려줍니다.

🤔 생각해보기: 우리가 컴퓨터에게 "비가 오면 우산을 가져가"라고 시키려면, 먼저 "비가 온다"는 명제를 참/거짓으로 판단할 수 있어야 해요. 컴퓨터는 모든 결정을 명제로 시작합니다.

현실의 명제 → 컴퓨터의 표현

현실 문장컴퓨터 표현결과
점수가 80점 이상이다점수 >= 80True 또는 False
비밀번호가 "1234"다비번 == "1234"True 또는 False
리스트가 비어있다len(목록) == 0True 또는 False

3. 연습 문제

다음 중 명제인 것에 ○, 아닌 것에 ✗ 표시하세요.

1
"5는 짝수다."
2
"피자가 맛있다."
3
"파리는 프랑스의 수도다."
4
"2x = 10"
5
"내일 비가 올까?"
6
"100보다 작은 소수의 개수는 25개다."
정답: 1✓(거짓 명제) / 2✗(주관적) / 3✓(참 명제) / 4✗(변수 포함) / 5✗(의문문) / 6✓(참 명제)

다음 단원에서는 "그리고 / 또는 / 아니다"라는 논리 연산자를 배웁니다. 두 개 이상의 명제를 합쳐서 더 복잡한 판단을 만드는 법이에요.
