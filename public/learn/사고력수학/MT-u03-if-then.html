1. 조건문이란?

"만약 P라면 Q다" 형태의 명제예요. 기호로는 P → Q. "P가 참이면 Q도 참이다"라는 약속이에요.

💡 조건문은 P가 거짓일 땐 결론이 뭐든 항상 참으로 쳐요. (공약속, 텅 빈 약속)

진리표 — "비가 오면(P) 우산을 쓴다(Q)"

P (비)Q (우산)P → Q설명
참참✓ 참비 오고 우산 씀 — 약속 지킴
참거짓✗ 거짓비 오는데 우산 안 씀 — 약속 어김
거짓참✓ 참비 안 오는데 우산 씀 — 약속 무관
거짓거짓✓ 참비도 안 오고 우산도 안 씀 — 약속 무관

⚠️ 3, 4번 행이 헷갈릴 수 있어요. "비가 온다"가 거짓이면 약속은 발동하지 않으므로 전체 명제는 거짓이 아니에요.

2. 역 · 이 · 대우

원래 명제 P → Q를 재배치하면 3가지가 나와요.

이름형태예시 (P=비, Q=우산)
원명제P → Q비가 오면 우산을 쓴다
역Q → P우산을 쓰면 비가 온다 (?)
이¬P → ¬Q비가 안 오면 우산을 안 쓴다 (?)
대우¬Q → ¬P우산을 안 쓰면 비가 안 온다

🤔 핵심: 원명제와 대우는 항상 같은 진리값이에요. 역과 이는 원명제와 상관없이 참/거짓이 달라질 수 있어요.

위 예시에서 "우산을 쓰면 비가 온다"는 거짓일 수 있어요 (햇볕 가리려고 쓸 수 있으니까). 하지만 "우산을 안 쓰면 비가 안 온다"는 원명제("비가 오면 우산을 쓴다")와 논리적으로 같아요.

3. 필요조건 vs 충분조건

P → Q 에서 P는 Q의 충분조건, Q는 P의 필요조건이에요.

  • 충분조건: P만 있으면 Q가 반드시 따라온다
  • 필요조건: Q가 되려면 P가 꼭 필요하다

예시: "고양이다(P) → 동물이다(Q)"

  • 고양이라는 것은 동물이기 위한 충분조건 (고양이면 무조건 동물)
  • 동물이라는 것은 고양이이기 위한 필요조건 (고양이이려면 동물이어야 함)

4. 코드에서의 조건문

점수 = 78

if 점수 >= 90:
    print("A등급")
elif 점수 >= 80:
    print("B등급")
elif 점수 >= 70:
    print("C등급")
else:
    print("D등급 이하")

# 출력: C등급

if는 "만약", elif는 "그렇지 않고 만약", else는 "그 외"예요. 위에서부터 차례로 검사해서 처음 맞는 조건에서 멈춰요.

5. 연습 문제

다음 명제의 대우를 만드세요.

1
"눈이 오면 날씨가 춥다"
2
"짝수면 2로 나눠진다"

다음 코드의 출력은?

x = 15
if x > 20:
    print("A")
elif x > 10:
    print("B")
elif x > 5:
    print("C")
else:
    print("D")
정답:
1. "날씨가 춥지 않으면 눈이 안 온다"
2. "2로 나눠지지 않으면 짝수가 아니다"
3. 코드 출력: B (15 > 10이 먼저 참이 되어서 멈춤)
