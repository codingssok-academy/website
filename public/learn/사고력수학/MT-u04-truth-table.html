1. 진리표란?

진리표(truth table)는 논리식에 들어가는 모든 변수에 참/거짓을 넣어봤을 때 결과가 어떻게 나오는지를 표로 정리한 거예요.

💡 왜 쓰나? 머릿속으로는 케이스가 많아지면 놓치기 쉽지만, 표로 그리면 절대 놓치지 않아요. 컴퓨터가 논리를 계산하는 방식도 이것과 똑같아요.

변수 3개 — 8가지 경우 (2³)

변수 n개면 경우의 수는 2ⁿ이에요. 4개면 16가지, 5개면 32가지.

2. 진리표 만드는 순서

복잡한 식: (P ∧ Q) ∨ ¬R 의 진리표를 만들어볼게요.

Step 1. 변수 컬럼 + 모든 경우 나열

변수가 P, Q, R 3개니까 2³ = 8행. 왼쪽부터 P는 참참참참 거거거거, Q는 참참거거 반복, R은 참거 반복 — 이렇게 규칙적으로 채워요.

Step 2. 부분식부터 채우기

①먼저 P ∧ Q 컬럼 / ②그다음 ¬R 컬럼 / ③마지막에 (P ∧ Q) ∨ ¬R 컬럼

3. 항진명제와 모순명제

항진명제 (Tautology)

모든 경우에 항상 참인 명제. 변수 값이 뭐든 결과가 참.

예: P ∨ ¬P (P이거나 P가 아니거나 — 항상 둘 중 하나니까 참)

P¬PP ∨ ¬P
참거참
거참참

모순명제 (Contradiction)

모든 경우에 항상 거짓인 명제.

예: P ∧ ¬P (P이면서 P가 아니다 — 말이 안 됨)

P¬PP ∧ ¬P
참거거
거참거

🤔 항진명제는 수학 증명, 모순명제는 "귀류법"에 쓰여요. 나중에 논리 증명을 배울 때 이 둘이 결정적인 무기가 될 거예요.
