집합이란?

같은 성질의 것들을 묶는다는 것

이 단원에서 배울 것

  • 집합의 정의 — 분명한 기준으로 묶인 모음
  • 원소(element)와 소속 기호 (∈, ∉)
  • 집합을 표현하는 3가지 방법
  • 원소 개수 세기 (유한집합 vs 무한집합)

1. 집합이 뭘까?

집합(set)은 분명한 기준으로 묶인 서로 다른 것들의 모음이에요.

💡 핵심 조건: (1) 어떤 것이 그 모음에 속하는지 누구나 같게 판단할 수 있어야 함, (2) 같은 것은 한 번만 넣음.

집합인 것

  • "1부터 10까지의 홀수" → {1, 3, 5, 7, 9} ✓
  • "코딩쏙 교실에 있는 컴퓨터" ✓ (개수 셀 수 있음)
  • "한글 자음" → {ㄱ, ㄴ, ㄷ, ...} ✓

집합이 아닌 것

  • "키 큰 사람들" — '큰'의 기준이 사람마다 다름 ✗
  • "재밌는 영화" — 주관적 ✗
  • "맛있는 음식" — 기준 없음 ✗

⚠️ 집합은 "어떤 것이 안에 있는지 확실하게 판단 가능"해야 해요. 모호하면 집합이 아닙니다.

2. 원소와 기호

집합 안에 들어 있는 각각의 것을 원소(element)라고 해요.

A = {1, 2, 3, 4, 5}

1은 A의 원소다  →  1 ∈ A
7은 A의 원소가 아니다  →  7 ∉ A

기호 정리

기호읽기의미
∈"속한다"원소다
∉"속하지 않는다"원소가 아니다
{ }중괄호집합 표시
∅공집합원소 0개인 집합

3. 집합 표현법 — 3가지

① 원소나열법

원소를 직접 중괄호 안에 나열해요.

A = {1, 2, 3, 4, 5}
B = {사과, 바나나, 포도}

② 조건제시법

"어떤 조건을 만족하는 x"라는 식으로 표현.

A = {x | x는 1 이상 10 이하의 자연수}
B = {x | x는 짝수}

③ 그림 (벤다이어그램)

다음 단원에서 자세히 배워요. 동그라미 안에 원소를 그리는 방식이에요.

4. 유한집합 vs 무한집합

유한집합 (Finite Set)

원소의 개수가 셀 수 있을 만큼 유한한 집합. 원소 수를 n(A)라고 써요.

A = {1, 2, 3, 4, 5}
n(A) = 5

무한집합 (Infinite Set)

원소가 무한히 많은 집합.

N = {1, 2, 3, 4, 5, ...}    // 자연수 전체
Z = {..., -2, -1, 0, 1, 2, ...}  // 정수 전체

공집합 (Empty Set)

원소가 하나도 없는 집합. 기호는 ∅ 또는 { }.

A = {x | x는 30보다 큰 한 자리 수}
   = ∅   (말이 안 되니까)

🤔 공집합은 "텅 빈 상자"예요. 상자 자체는 있지만 안에 뭐 없음. 수학에서는 매우 유용한 개념이에요 (나중에 조건 안 맞을 때 "답은 공집합").

5. 컴퓨터의 집합

# 파이썬의 set
A = {1, 2, 3, 4, 5}
B = set([1, 2, 2, 3])  # 중복 자동 제거 → {1, 2, 3}

print(3 in A)   # True
print(7 in A)   # False
print(len(A))   # 5 (= n(A))

파이썬의 set은 수학의 집합과 거의 똑같이 작동해요. 중복 자동 제거 + 순서 무관.
