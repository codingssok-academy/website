1. 복합 명제가 필요한 이유

이전 단원에서 하나의 명제는 참 또는 거짓이 된다는 걸 배웠어요. 그런데 현실에서는 "두 가지 조건을 동시에" 또는 "둘 중 하나라도" 맞아야 하는 상황이 많아요.

💡 예시: "비가 오고 우산이 없으면 젖는다" — 두 명제 모두 참이어야 결론이 참이에요.

세 가지 기본 연산자

연산자한국어영어기호언제 쓰나
AND그리고and∧둘 다 참이어야 참
OR또는or∨하나라도 참이면 참
NOT아니다not¬참을 거짓으로 뒤집음

2. AND — 그리고

두 명제가 모두 참일 때만 전체가 참이에요. 하나라도 거짓이면 거짓.

예시: "숙제를 다 했고 시간이 남았다"

  • 숙제 O + 시간 O → 게임 가능 (참)
  • 숙제 O + 시간 X → 게임 불가 (거짓)
  • 숙제 X + 시간 O → 게임 불가 (거짓)
  • 숙제 X + 시간 X → 게임 불가 (거짓)
# 파이썬 코드
나이 = 15
점수 = 85

if 나이 >= 13 and 점수 >= 80:
    print("입상 대상!")

⚠️ "and" 는 엄격해요. 하나라도 틀리면 전체가 거짓이에요.

3. OR — 또는

둘 중 하나라도 참이면 전체가 참이에요. 둘 다 거짓일 때만 거짓.

예시: "엄마가 허락하거나 아빠가 허락하면"

  • 엄마 O + 아빠 O → 갈 수 있다 (참)
  • 엄마 O + 아빠 X → 갈 수 있다 (참)
  • 엄마 X + 아빠 O → 갈 수 있다 (참)
  • 엄마 X + 아빠 X → 못 감 (거짓)
if 주말 == True or 공휴일 == True:
    print("오늘 쉬는 날!")

4. NOT — 아니다 (부정)

참을 거짓으로, 거짓을 참으로 뒤집는 연산자예요.

원래 명제NOT 적용
"오늘은 월요일이다" (참)"오늘은 월요일이 아니다" (거짓)
"눈이 온다" (거짓)"눈이 안 온다" (참)
배고프다 = True
if not 배고프다:
    print("점심 안 먹어도 됨")
# 배고프다가 True면 not은 False라 실행 안 됨

🤔 NOT을 두 번 쓰면? not(not 참) = 참. 뒤집은 걸 또 뒤집으면 원래대로. 수학의 "-(-5) = 5" 랑 똑같은 원리예요.

5. 복합 사용

# "13살 이상이고, 부모 동의가 있거나 선생님 동의가 있으면"
if 나이 >= 13 and (부모동의 or 선생님동의):
    print("참가 가능!")

and가 or보다 먼저 계산돼요. 순서를 바꾸려면 괄호를 쓰세요.

6. 연습 문제

다음 상황의 결과를 구하세요. (참/거짓)

1
나이 = 15. "나이 > 10 and 나이 < 20"
2
점수 = 55. "점수 >= 90 or 점수 < 60"
3
비가온다 = 거짓. "not 비가온다"
4
A=참, B=거짓. "A and B"
5
A=참, B=거짓. "A or B"
6
"not(참 and 거짓)"
정답: 1.참 / 2.참 (55<60) / 3.참 / 4.거짓 / 5.참 / 6.참 (거짓의 NOT)
