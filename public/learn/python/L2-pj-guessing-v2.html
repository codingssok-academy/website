숫자 맞추기 게임

컴퓨터가 숨긴 숫자를 UP/DOWN 힌트를 받으며 맞추는 게임입니다.

이 프로젝트에서 배우는 것

  • while True로 무한 반복을 만들 수 있습니다.
  • break로 반복문을 탈출할 수 있습니다.
  • 비교 연산자(>, <, ==)로 숫자를 비교합니다.
  • 시도 횟수를 카운터로 셀 수 있습니다.
  • 이진 탐색의 원리를 게임으로 이해합니다.

while True와 break

while True는 조건 없이 영원히 반복합니다. break를 만나면 즉시 반복을 탈출합니다.

# while True + break 기본 패턴 while True: answer = input("숫자를 입력하세요 (0이면 종료): ") if answer == "0": print("종료합니다.") break # 여기서 while 탈출! print(f"{answer} 입력됨")

숫자 맞추기 게임에서는 정답을 맞출 때까지 계속 반복해야 하므로 while True가 적합합니다.

따라해보세요
1
"quit" 입력 시 break로 탈출하는 반복문을 만드세요.
while True: word = input("단어 입력 (quit으로 종료): ") if word == "quit": break print(f"입력한 단어: {word}") print("게임 종료!")
quit 입력 시 게임 종료! 출력되고 탈출합니다
2
숫자를 입력받아 50보다 크면 break, 아니면 계속 반복하세요.
while True: n = int(input("숫자 입력: ")) if n > 50: print("50보다 큰 숫자! 탈출!") break print(f"{n}은 50 이하입니다.")
50 이하면 계속, 51 이상이면 탈출
3
시도 횟수를 세는 카운터와 함께 만들어보세요.
count = 0 while True: n = int(input("숫자: ")) count += 1 if n == 7: print(f"정답! {count}번 만에 맞췄습니다!") break
7을 입력할 때까지 반복, 횟수 표시

완성: 숫자 맞추기 게임

1~100 사이 숫자를 UP/DOWN 힌트로 맞추는 완성 게임입니다.

import random secret = random.randint(1, 100) # 비밀 숫자 tries = 0 print("=== 숫자 맞추기 게임 ===") print("1~100 사이 숫자를 맞춰보세요!") while True: guess = int(input("숫자 입력: ")) tries += 1 if guess == secret: print(f"정답! {tries}번 만에 맞췄습니다!") if tries <= 5: print("대단해요! 천재적인 실력!") elif tries <= 10: print("잘 했어요!") else: print("조금 더 연습해봐요~") break elif guess < secret: print(f"{guess} — UP (더 큰 숫자!)") else: print(f"{guess} — DOWN (더 작은 숫자!)")

핵심 요약

이 유닛에서 배운 것

  • while True는 무한 반복 — 반드시 break로 탈출해야 함
  • break는 반복문을 즉시 탈출한다
  • tries += 1로 반복할 때마다 시도 횟수를 누적한다
  • 비교 연산자: ==(같음), >(큼), <(작음)
  • UP/DOWN 전략: 중간값을 먼저 시도하면 최소 시도로 맞출 수 있다 (이진 탐색)
  • random.randint(1, 100)으로 1~100 사이 비밀 숫자 생성
