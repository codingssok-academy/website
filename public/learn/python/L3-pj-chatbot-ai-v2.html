Step 1 — if/elif로 키워드 감지하기

챗봇의 핵심은 사용자가 입력한 문장에서 키워드를 찾아 알맞은 대답을 내놓는 것입니다. in 연산자로 키워드 존재를 확인하고 if/elif/else로 응답을 분기합니다.

# Step 1: 기본 챗봇 import random responses = { "greeting": ["안녕! 나는 파이봇이야.", "반가워! 뭐 도와줄까?"], "weather": ["날씨? 나는 AI라 모르지만 맑으면 좋겠다!"], "game": ["게임 좋아! 숫자 맞추기 같이 하자."], "bye": ["잘 가! 또 얘기하자.", "바이바이~"], "default": ["흠... 잘 모르겠어!", "좀 더 쉽게 말해줘."], } def get_response(msg): msg = msg.lower() if "안녕" in msg or "hi" in msg: key = "greeting" elif "날씨" in msg or "비" in msg: key = "weather" elif "게임" in msg or "놀자" in msg: key = "game" elif "잘가" in msg or "bye" in msg: key = "bye" else: key = "default" return random.choice(responses[key]) # 테스트 print(get_response("안녕하세요")) # greeting print(get_response("오늘 날씨 어때")) # weather

Step 2 — 감정 분석: 긍정/부정 단어 카운트

사용자의 메시지에서 긍정 단어와 부정 단어의 개수를 세어 감정 점수를 계산합니다. 이를 바탕으로 챗봇이 공감하는 대답을 할 수 있습니다.

# Step 2: 감정 분석 함수 POSITIVE = ["좋아", "행복", "신나", "최고", "사랑", "재미", "감사", "즐거"] NEGATIVE = ["싫어", "힘들", "짜증", "슬퍼", "무서", "걱정", "지쳐", "최악"] def analyze_emotion(msg): score = 0 for word in POSITIVE: if word in msg: score += 1 for word in NEGATIVE: if word in msg: score -= 1 if score >= 2: return "매우 긍정", score elif score == 1: return "긍정", score elif score == 0: return "중립", score elif score == -1: return "부정", score else: return "매우 부정", score # 감정에 따른 공감 응답 def empathy_response(emotion): if "긍정" in emotion: return "오, 기분 좋아 보여! 나도 덩달아 기쁘다." elif "부정" in emotion: return "많이 힘들구나. 내가 들어줄게." return "그렇구나. 계속 얘기해봐."

Step 3 — 대화 기록 파일에 저장하기

챗봇과 나눈 대화를 텍스트 파일로 저장해두면 나중에 다시 읽을 수 있습니다. open(filename, "w")의 쓰기 모드로 파일에 기록합니다.

open()에 "w"(쓰기 모드)를 지정하면 파일을 새로 만들거나 덮어씁니다. with 문을 사용하면 파일이 자동으로 닫혀 안전합니다.

# Step 3: 파일 저장 def save_history(filename="chat_log.txt"): with open(filename, "w", encoding="utf-8") as f: f.write("=== 대화 기록 ===\n") for i, (user_msg, bot_reply) in enumerate(history, 1): f.write(f"[{i}] 나: {user_msg}\n") f.write(f" 봇: {bot_reply}\n") print(f"저장 완료! ({len(history)}개 대화)") # 파일 불러오기 def load_history(filename="chat_log.txt"): try: with open(filename, "r", encoding="utf-8") as f: content = f.read() print(content) except FileNotFoundError: print("저장된 기록이 없습니다.")

msg.split() 결과가 길이 3이고 가운데 원소가 +/-/* 중 하나인지 확인하세요. int() 변환에 try/except를 사용하세요.

정답 보기
def calc_response(msg): parts = msg.split() if len(parts) == 3 and parts[1] in ["+", "-", "*", "/"]: try: a, op, b = int(parts[0]), parts[1], int(parts[2]) if op == "+": return f"계산 결과: {a + b}" if op == "-": return f"계산 결과: {a - b}" if op == "*": return f"계산 결과: {a * b}" if op == "/" and b != 0: return f"계산 결과: {a / b}" except ValueError: pass return None

핵심 요약

  • if/elif/else + in 연산자로 키워드 기반 대화 분기를 구현합니다.
  • 긍정/부정 단어 리스트를 순회하며 감정 점수를 누적해 감정을 분류합니다.
  • 대화 내용은 list.append(tuple)로 기록하고 open()/write()로 파일에 저장합니다.
  • random.choice()로 응답 목록에서 무작위 선택해 자연스러운 대화를 만듭니다.
  • while True 메인 루프와 break 조건으로 챗봇의 대화 흐름을 제어합니다.
