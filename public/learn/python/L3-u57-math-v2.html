math 모듈 — 제곱근, 올림, 내림, 원주율

math는 파이썬 표준 라이브러리에 포함된 모듈로, 수학 계산에 필요한 함수들을 모아 놓았습니다. 먼저 import math로 불러온 뒤 math.함수명() 형태로 씁니다.

import math # 제곱근 — 넓이 25인 정사각형의 한 변 side = math.sqrt(25) print(f"한 변의 길이: {side}") # 5.0 # 올림: 4.1 -> 5, 내림: 4.9 -> 4 print(math.ceil(4.1)) # 5 print(math.floor(4.9)) # 4 # 원주율로 원의 넓이 계산 r = 5 area = math.pi * r ** 2 print(f"넓이: {area:.2f}") # 78.54
한 변의 길이: 5.0 5 4 넓이: 78.54
ceil vs floor vs round
ceil(x)는 항상 크거나 같은 정수로 올림, floor(x)는 항상 작거나 같은 정수로 내림입니다. 파이썬 내장 round()는 반올림 — 이 셋은 서로 다릅니다.

math 모듈 — pow, log, fabs 심화

math.pow(x, y)는 x의 y제곱, math.log(x)는 자연로그, math.log(x, base)는 밑이 base인 로그입니다. math.fabs(x)는 실수 절댓값을 반환합니다.

import math # 거듭제곱 — 2의 10제곱 print(math.pow(2, 10)) # 1024.0 (항상 float) # 자연로그 (밑 e) print(math.log(math.e)) # 1.0 # 상용로그 (밑 10) print(math.log(1000, 10)) # 3.0 # 실수 절댓값 print(math.fabs(-9.5)) # 9.5 # 실전: 복리 계산 (원금 100만, 연이율 5%, 10년) principal = 1_000_000 rate = 0.05 years = 10 result = principal * math.pow(1 + rate, years) print(f"10년 후 원리금: {result:,.0f}원")
1024.0 1.0 3.0 9.5 10년 후 원리금: 1,628,895원
주의: math.pow vs **
math.pow(x, y)는 항상 float을 반환합니다. 정수 결과가 필요하면 ** 연산자 또는 int(math.pow(...))를 사용하세요.

statistics 모듈 — mean, median, stdev

statistics는 리스트 데이터의 통계값을 한 줄로 계산해 주는 모듈입니다. 성적 분석, 설문 결과 요약, 센서 데이터 처리 등에 자주 쓰입니다.

import statistics scores = [60, 70, 80, 90, 95] # 평균 avg = statistics.mean(scores) print(f"평균: {avg}") # 79 # 중앙값 med = statistics.median(scores) print(f"중앙값: {med}") # 80 # 표준편차 (값이 얼마나 퍼져 있나) sd = statistics.stdev(scores) print(f"표준편차: {sd:.2f}") # 14.14
평균: 79 중앙값: 80 표준편차: 14.14
표준편차 해석
표준편차가 작을수록 점수가 평균 근처에 몰려 있고, 클수록 점수 차이가 크다는 뜻입니다. 반 학생 성적 분포를 한눈에 파악할 때 유용합니다.

실전 예제 — math와 statistics 함께 쓰기

학생 성적 리스트를 받아 평균, 중앙값, 표준편차를 출력하고, math.sqrt로 직접 표준편차를 검증하는 예제입니다. 또한 복리 계산을 담당하는 compound 함수를 정의해 math.pow를 활용합니다.

import math import statistics scores = [78, 85, 92, 67, 74, 88, 95, 61] avg = statistics.mean(scores) med = statistics.median(scores) sd = statistics.stdev(scores) hi = max(scores) lo = min(scores) print("=== 성적 분석 보고서 ===") print(f" 평균: {avg:.1f}") print(f" 중앙값: {med}") print(f" 표준편차: {sd:.2f}") print(f" 최고점: {hi}") print(f" 최저점: {lo}")
=== 성적 분석 보고서 === 평균: 80.0 중앙값: 81.5 표준편차: 11.55 최고점: 95 최저점: 61

math.sqrt로 대각선 길이 구하기
쉬움
가로 3, 세로 4인 직사각형의 대각선 길이를 math.sqrt와 피타고라스 정리를 이용해 계산하세요. (대각선 = sqrt(가로²+세로²))
입력a=3, b=4
출력5.0

힌트 보기
math.sqrt(a**2 + b**2) 형태로 계산합니다. 3²+4²=25이므로 sqrt(25)=5.0 이 나옵니다.

import math a, b = 3, 4 print(math.sqrt(a**2 + b**2))
2
statistics.mean으로 과목별 평균 비교
보통
국어 점수 리스트 [72, 85, 91, 68, 79]와 수학 점수 리스트 [88, 74, 95, 62, 83]의 평균을 각각 구하고, 어느 과목의 평균이 더 높은지 출력하세요.
출력 예국어: 79 / 수학: 80.4 / 수학 평균이 더 높습니다
내 답안
힌트 보기
statistics.mean()으로 두 리스트의 평균을 각각 구한 뒤, if 문으로 비교해서 더 높은 과목 이름을 출력합니다.
정답 보기
import statistics korean = [72,85,91,68,79] math_s = [88,74,95,62,83] k_avg = statistics.mean(korean) m_avg = statistics.mean(math_s) print(f"국어: {k_avg} / 수학: {m_avg}") if k_avg > m_avg: print("국어 평균이 더 높습니다") else: print("수학 평균이 더 높습니다")
3
복리 계산기 — math.pow 활용
보통
원금(principal), 연이율(rate), 기간(years)을 변수로 받아 복리 원리금을 계산하는 함수 compound를 작성하세요. 결과는 소수점 없는 원화로 출력합니다.
입력principal=500000, rate=0.03, years=5
출력579,637원
내 답안
힌트 보기
복리 공식: 원금 * math.pow(1 + 연이율, 기간). f-string의 ,:0f 포맷으로 쉼표 포함 정수 출력이 가능합니다.
정답 보기
import math def compound(principal, rate, years): result = principal * math.pow(1 + rate, years) print(f"{result:,.0f}원") compound(500000, 0.03, 5)

핵심 요약

  • import math — 제곱근(sqrt), 올림(ceil), 내림(floor), 원주율(pi), 거듭제곱(pow), 로그(log), 절댓값(fabs)을 제공합니다.
  • math.pow(x, y)는 항상 float을 반환합니다. 정수 결과가 필요하면 ** 연산자를 씁니다.
  • import statistics — mean(평균), median(중앙값), stdev(표준편차)로 데이터 요약이 가능합니다.
  • 이상값이 있는 데이터는 mean보다 median이 더 신뢰할 수 있는 대표값입니다.
  • 두 모듈을 함께 사용하면 성적 분석, 복리 계산, 원 넓이 계산 등 실생활 문제를 간단히 해결할 수 있습니다.
