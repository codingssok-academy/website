텍스트 이모티콘 만들기

딕셔너리로 텍스트 이모티콘을 변환하고, 사용자가 커스텀 이모티콘을 추가할 수 있는 프로그램을 만듭니다.

이 프로젝트에서 배우는 것

  • 딕셔너리로 키-값 쌍의 이모티콘 변환 테이블을 만들 수 있습니다.
  • dict[key]로 값을 조회하고 dict.get(key, 기본값)으로 안전하게 찾을 수 있습니다.
  • dict[key] = value로 새 항목을 추가할 수 있습니다.
  • for key, value in dict.items()로 모든 항목을 순회할 수 있습니다.
  • 문자열 replace()로 여러 이모티콘을 한 번에 변환할 수 있습니다.

이모티콘 딕셔너리 만들기

딕셔너리는 {"키": "값"} 형태로 만듭니다. 이모티콘 텍스트를 키로, 한글 설명을 값으로 저장합니다.

# 이모티콘 변환 딕셔너리 emoticons = { ":)": "웃는얼굴", ":D": "활짝웃음", ":(": "슬픔", ":P": "혀내밀기", ";>_<": "화남", ":O": "놀람", "^^": "기쁨", "T_T": "펑펑울음", } # 키로 값 조회 code = ":)" name = emoticons.get(code, "알 수 없는 이모티콘") print(f"{code} = {name}") # :) = 웃는얼굴

문장에서 이모티콘 변환하기

입력 문장에서 이모티콘을 찾아 한글로 바꿔주는 함수를 만듭니다. 문자열 replace()와 딕셔너리를 함께 활용합니다.

def convert_emoticons(text): """문장 속 이모티콘을 한글로 변환""" result = text for code, name in emoticons.items(): result = result.replace(code, name) return result # 테스트 sentence = "오늘 기분 좋다 :) 날씨도 좋고 ^^" converted = convert_emoticons(sentence) print(f"원본: {sentence}") print(f"변환: {converted}")

완성: 이모티콘 메이커 프로그램

변환, 목록 보기, 커스텀 추가 기능을 갖춘 완전한 이모티콘 메이커를 만듭니다.

emoticons = { ":)": "웃는얼굴", ":D": "활짝웃음", ":(": "슬픔", ":P": "혀내밀기", ":O": "놀람", "^^": "기쁨", "T_T": "펑펑울음", } def convert(text): result = text for code, name in emoticons.items(): result = result.replace(code, name) return result while True: print("\n1.변환 2.목록 3.추가 4.종료") choice = input("선택: ") if choice == "1": text = input("문장 입력: ") print(f"변환: {convert(text)}") elif choice == "2": print("\n--- 이모티콘 목록 ---") for code, name in emoticons.items(): print(f" {code} → {name}") elif choice == "3": code = input("이모티콘 코드 (예: :3): ") name = input("이름 (예: 고양이): ") emoticons[code] = name print(f"{code} → {name} 추가 완료!") elif choice == "4": print("종료!"); break

sentences = ["오늘 :) 좋다", ":) 날씨도 :D", "T_T 힘들어", ":) ^^"] freq = {code: 0 for code in emoticons} for s in sentences: for code in emoticons: if code in s: freq[code] += 1 best = max(freq, key=freq.get) print(f"최다 사용: {best} ({freq[best]}회)")

핵심 요약

이 유닛에서 배운 것

  • {"키": "값"} 형태로 딕셔너리를 만든다
  • dict[키]: 값 조회 (없으면 KeyError), dict.get(키, 기본값): 안전 조회
  • dict[키] = 값: 새 항목 추가 또는 기존 값 수정
  • for k, v in dict.items():로 모든 키-값 쌍을 순회한다
  • 문자열.replace(찾을것, 바꿀것)으로 문자열 안의 텍스트를 교체한다
  • 딕셔너리는 데이터를 이름으로 저장하고 빠르게 찾을 때 사용한다
