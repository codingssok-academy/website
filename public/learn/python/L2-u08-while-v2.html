Chapter 08

while 반복문

조건이 참인 동안 코드를 반복 실행하는 while 반복문을 배웁니다.

이 유닛에서 배우는 것

  • while 반복문의 기본 구조를 이해하고 사용할 수 있습니다.
  • 조건 변수를 갱신하여 무한루프를 방지할 수 있습니다.
  • while True + break 패턴으로 입력 검증을 할 수 있습니다.
  • for와 while의 차이를 설명하고 적절히 선택할 수 있습니다.
  • 카운터, 누적, 센티넬 패턴을 구현할 수 있습니다.

while 반복문이란?

while은 조건이 True인 동안 계속 반복합니다. "~하는 동안 반복해라"라는 뜻입니다.

count = 0 while count < 5: print(count) count += 1 # 반드시 갱신!
따라해보세요 - 기본 while
1
"반복 중!" 을 3번 출력하세요.
count = 0 while count < 3: print("반복 중!") count += 1
반복 중! 이 3줄 출력됩니다
2
10부터 1까지 카운트다운하세요.
n = 10 while n > 0: print(n) n -= 1 print("발사!")
10, 9, 8, ... 1, 발사!
3
2의 거듭제곱을 1000 이하까지 출력하세요.
n = 1 while n <= 1000: print(n) n *= 2
1, 2, 4, 8, 16, 32, 64, 128, 256, 512

무한루프 주의!

조건이 영원히 True이면 프로그램이 멈추지 않습니다. 반드시 조건 변수를 갱신하세요.

while True + break 패턴

while True로 무한루프를 만들고, 특정 조건에서 break로 탈출합니다. 입력 검증에 많이 씁니다.

while True: text = input("입력 (q=종료): ") if text == "q": print("종료합니다.") break print(f"입력: {text}")
따라해보세요 - while True
1
양수만 입력받는 프로그램을 만드세요.
while True: n = int(input("양수 입력: ")) if n > 0: break print("양수가 아닙니다!") print(f"입력한 양수: {n}")
양수를 입력할 때까지 반복됩니다
2
비밀번호를 맞출 때까지 반복하세요.
password = "python" while True: guess = input("비밀번호: ") if guess == password: print("정답!") break print("틀렸습니다. 다시!")
"python" 입력 시 정답! 출력 후 종료
3
숫자를 계속 입력받아 합계를 구하세요. 0 입력 시 종료.
total = 0 while True: n = int(input("숫자 (0=종료): ")) if n == 0: break total += n print("합계:", total)
0을 입력하면 그때까지의 합계 출력

for vs while 비교

횟수가 정해졌으면 for, 조건으로 끝을 결정하면 while을 씁니다.

카운터 패턴

while문에서 횟수를 세는 카운터 변수를 함께 관리합니다.

count = 0 while count < 3: print(f"{count + 1}번째 반복") count += 1 print("종료!")

센티넬(보초) 패턴

특정 값(보초값)이 입력되면 반복을 종료하는 패턴입니다. 위의 "0 입력 시 종료" 예제가 대표적입니다.

실전: 숫자 맞추기 (간단 버전)

컴퓨터가 생각한 숫자를 맞출 때까지 반복하는 프로그램을 만들어봅시다.

answer = 7 # 정답 while True: guess = int(input("1~10 숫자 입력: ")) if guess == answer: print("정답!") break elif guess < answer: print("UP! 더 큰 수를 입력하세요") else: print("DOWN! 더 작은 수를 입력하세요")
따라해보세요 - 실전 while
1
위 숫자 맞추기 코드를 실행해보세요.
answer = 7 while True: guess = int(input("숫자: ")) if guess == answer: print("정답!") break print("틀렸어요!")
7을 입력하면 정답! 출력
2
시도 횟수를 세는 기능을 추가하세요.
answer = 7 tries = 0 while True: guess = int(input("숫자: ")) tries += 1 if guess == answer: print(f"{tries}번 만에 정답!") break print("틀렸어요!")
몇 번 만에 맞췄는지 알려줍니다
3
"quit" 입력 시 포기하는 메뉴를 추가하세요.
while True: cmd = input("메뉴(play/quit): ") if cmd == "quit": print("종료!") break elif cmd == "play": print("게임 시작!") else: print("play 또는 quit을 입력하세요")
play/quit 메뉴가 동작합니다

핵심 요약

이 유닛에서 배운 것

  • while 조건:은 조건이 True인 동안 반복한다
  • 반드시 조건 변수를 갱신해야 무한루프를 방지한다
  • while True: ... break 패턴으로 입력 검증을 한다
  • 카운터 패턴: 횟수를 세는 변수를 함께 관리한다
  • 센티넬 패턴: 특정 값(보초값)이 오면 반복을 종료한다
  • for는 횟수가 정해질 때, while은 조건으로 끝을 결정할 때 사용한다
