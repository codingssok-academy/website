1. 4대 자료구조 비교 — 한눈에 보기

파이썬에는 데이터를 담는 대표 자료구조가 네 가지입니다. 각각의 특징을 비교하면 선택 기준이 명확해집니다.

특성 list tuple dict set
선언 방법 [ ] ( ) { k:v } { } / set()
순서 유지 O O O (3.7+) X
수정 가능 O X O O
중복 허용 O O 키 X / 값 O X
인덱스 접근 O O 키로 접근 X
주요 용도 일반 데이터 목록 변하면 안 되는 값 이름표 달린 데이터 중복 제거

표를 외울 필요는 없습니다. "내 데이터에 뭐가 필요한가?"를 물어보면 자연스럽게 선택이 됩니다. 다음 섹션에서 상황별로 정리합니다.

2. 상황별 선택 가이드 — 흐름도

다음 질문에 순서대로 답하면 어떤 자료구조를 써야 할지 결정할 수 있습니다.

상황별 요약

순서가 필요하고 값이 바뀜 → list

학생 점수 목록, 쇼핑카트, 할 일 목록처럼 항목을 추가·삭제·수정해야 할 때. append(), remove() 등이 자유롭게 쓰입니다.

이름표가 달린 데이터 → dict

이름, 나이, 점수처럼 각 데이터에 의미 있는 이름이 필요할 때. student["name"]처럼 키로 바로 접근합니다.

중복을 없애야 함 → set

방문자 목록에서 중복 ID 제거, 두 반의 공통 수강생 찾기 등. 교집합(&), 합집합(|) 연산이 강력합니다.

데이터가 바뀌면 안 됨 → tuple

RGB 색상 값, 좌표, 설정 상수처럼 실수로 바꾸면 안 되는 데이터. 수정 시도 시 오류가 발생해 안전합니다.

3. 리스트와 튜플 — 같은 듯 다른 둘

리스트와 튜플은 둘 다 순서가 있고 중복을 허용합니다. 핵심 차이는 수정 가능 여부입니다.

# 리스트: 수정 가능 students = ["홍길동", "김철수", "박영희"] students.append("이민준") # 추가 OK students[0] = "홍길동2" # 수정 OK print(students) # ['홍길동2', '김철수', '박영희', '이민준'] # 튜플: 수정 불가 rgb_red = (255, 0, 0) print(rgb_red[0]) # 255 — 읽기는 OK # rgb_red[0] = 200 # TypeError! 수정 불가 # 튜플의 장점: 함수에서 여러 값 반환 def min_max(nums): return min(nums), max(nums) # 튜플로 반환 low, high = min_max([3, 1, 7, 2]) print(f"최솟값: {low}, 최댓값: {high}") # 최솟값: 1, 최댓값: 7

4. 딕셔너리 — 이름표 달린 데이터

딕셔너리는 "이름표(키)"와 "내용(값)"을 하나의 쌍으로 관리합니다. 리스트의 숫자 인덱스 대신 의미 있는 이름으로 접근합니다.

# 딕셔너리 기본 사용 student = { "name": "홍길동", "score": 95, "grade": "A" } # 키로 접근 print(student["name"]) # 홍길동 print(student.get("score", 0)) # 95 (키 없으면 0 반환) # 값 추가/수정 student["teacher"] = "김선생" # 새 키 추가 student["score"] = 98 # 값 수정 # 반복 for key, value in student.items(): print(f"{key}: {value}")
name: 홍길동 score: 98 grade: A teacher: 김선생

딕셔너리 실전 패턴 — 빈도 세기

텍스트에서 단어 등장 횟수를 세는 전형적인 패턴입니다.

# 단어 빈도 세기 words = ["python", "is", "fun", "python", "is", "great"] freq = {} for word in words: freq[word] = freq.get(word, 0) + 1 print(freq) # {'python': 2, 'is': 2, 'fun': 1, 'great': 1} # 가장 많이 등장한 단어 most_common = max(freq, key=freq.get) print(f"최다 등장: {most_common} ({freq[most_common]}회)")

5. 세트 — 중복 없이 깔끔하게

세트는 수학의 집합과 같습니다. 같은 값을 여러 번 넣어도 한 번만 저장됩니다. 순서도 없습니다.

# 세트 기본 nums = {1, 2, 3, 2, 1} # 중복 자동 제거 print(nums) # {1, 2, 3} # 집합 연산 a = {1, 2, 3, 4} b = {3, 4, 5, 6} print(a | b) # 합집합: {1,2,3,4,5,6} print(a & b) # 교집합: {3,4} print(a - b) # 차집합: {1,2} print(a ^ b) # 대칭차: {1,2,5,6}

세트의 핵심 활용 — 중복 제거

# 리스트에서 중복 제거 visitors = ["김철수", "홍길동", "김철수", "박영희", "홍길동"] unique = list(set(visitors)) # set으로 중복 제거 후 list로 변환 print(f"방문자 수: {len(unique)}명") print(f"방문자 목록: {unique}") # 두 반의 공통 수강생 찾기 class_a = {"홍길동", "김철수", "이영희"} class_b = {"박민준", "홍길동", "최수진"} common = class_a & class_b print(f"양쪽 모두 수강: {common}") # {'홍길동'}
따라해보세요 — 세트

6. 자료구조 간 변환

실전에서는 자료구조를 바꿔가며 사용하는 경우가 많습니다. 각 변환 함수의 역할을 이해합니다.

# 1. list -> set: 중복 제거 data = [1, 2, 2, 3, 3, 3] unique = set(data) # {1, 2, 3} # 2. set -> list: 다시 리스트로 (정렬 후 순서 확보) back_to_list = sorted(unique) # [1, 2, 3] # 3. dict.keys() / .values() / .items() -> list scores = {"홍": 90, "김": 85, "박": 92} names = list(scores.keys()) # ['홍', '김', '박'] vals = list(scores.values()) # [90, 85, 92] # 4. 두 리스트 -> dict (zip 활용) keys = ["name", "age", "city"] values = ["홍길동", 15, "서울"] person = dict(zip(keys, values)) print(person) # {'name': '홍길동', 'age': 15, 'city': '서울'}
{'name': '홍길동', 'age': 15, 'city': '서울'}

7. 실전 시나리오 — 자료구조 선택

실제 프로그램을 만들 때 어떤 자료구조를 써야 할지 판단하는 연습입니다. 문제를 읽고 최적의 자료구조를 고르세요.

1
학생 성적 관리 시스템
중간

학생 이름과 점수를 저장하고, 이름으로 점수를 바로 찾아야 합니다. 또한 새 학생을 추가하거나 점수를 수정할 수 있어야 합니다. 어떤 자료구조를 사용하고, 어떻게 코드를 작성하면 될까요?

입력 이름: "홍길동", 점수: 95
출력 scores["홍길동"] -> 95
내 답안
힌트 보기 / 정답 보기

힌트: 이름(키)으로 점수(값)를 찾는다 = 딕셔너리. 수정도 가능해야 하므로 dict가 최적입니다.

scores = {"홍길동": 95, "김철수": 88} scores["박영희"] = 92 # 추가 scores["홍길동"] = 98 # 수정 print(scores["홍길동"]) # 98

visits = ["김", "홍", "김", "박", "홍", "이"] unique = set(visits) print(f"고유 방문자: {len(unique)}명") # 4명

A ["파이썬", "축구", "영화", "독서"]

8. 종합 실습 — 학생 관리 미니 시스템

네 가지 자료구조를 모두 활용해 학생 정보를 관리하는 미니 시스템을 만들어봅니다.

# 종합 실습: 학생 관리 미니 시스템 SUBJECTS = ("수학", "영어", "과학") # tuple: 과목명은 불변 students = [ # list: 학생 목록 {"name": "홍길동", "score": 95}, # dict: 학생 1명 {"name": "김철수", "score": 72}, {"name": "박영희", "score": 88}, {"name": "이민준", "score": 95}, ] # 등급 계산 추가 for s in students: s["grade"] = "A" if s["score"] >= 90 else "B" if s["score"] >= 80 else "C" grades_used = {s["grade"] for s in students} # set: 중복 없는 등급 목록 print(f"사용된 등급: {sorted(grades_used)}") # ['A', 'B', 'C'] print(f"개설 과목: {SUBJECTS}") # ('수학', '영어', '과학') for s in students: print(f"{s['name']:6} {s['score']}점 → {s['grade']}")
사용된 등급: ['A', 'B', 'C'] 개설 과목: ('수학', '영어', '과학') 홍길동 95점 -> A 김철수 72점 -> C 박영희 88점 -> B 이민준 95점 -> A

핵심 요약

  • list: 순서 O, 중복 O, 수정 O — 일반 목록에 기본 선택
  • tuple: 순서 O, 중복 O, 수정 X — 변하면 안 되는 값 (좌표, 상수)
  • dict: 키:값 쌍, 수정 O — 이름표로 찾아야 할 때
  • set: 중복 X, 순서 X, 수정 O — 중복 제거, 집합 연산
  • 변환 패턴: list -> set (중복 제거), set -> list (순서 확보), zip -> dict (쌍 생성)
  • 선택 기준: 키:값 필요 → dict, 중복 제거 → set, 불변 → tuple, 나머지 → list
