프로젝트:
닉네임 생성기

형용사와 동물을 무작위로 조합해 닉네임을 만들고, 중복 검사와 글자 수 제한으로 커스텀 규칙을 적용합니다.

이 프로젝트에서 만드는 것

  • random.choice()로 형용사와 동물을 무작위 조합해 닉네임을 만들 수 있습니다.
  • set으로 이미 사용된 닉네임을 추적해 중복을 막을 수 있습니다.
  • len()으로 글자 수를 검사해 커스텀 규칙을 적용할 수 있습니다.
  • while 반복문으로 조건을 만족할 때까지 닉네임을 계속 생성할 수 있습니다.

핵심 개념 — 조합과 중복 체크

형용사 + 동물 조합 패턴

두 리스트에서 각각 random.choice()로 하나씩 뽑아 문자열을 합칩니다. 5개 형용사 x 5개 동물 = 25가지 조합이 가능합니다.

set으로 중복 방지

set은 같은 값을 두 번 저장하지 않습니다. in 연산자로 이미 사용된 닉네임인지 바로 확인할 수 있습니다.

Step 1
기본 닉네임 생성 함수

형용사 리스트와 동물 리스트를 합쳐서 닉네임을 반환하는 함수를 만듭니다.

import random adjectives = ["용감한", "빠른", "신비한", "강한", "날쌘"] animals = ["늑대", "여우", "독수리", "호랑이", "사자"] def make_nickname(): adj = random.choice(adjectives) animal = random.choice(animals) return adj + animal # 닉네임 5개 출력 for i in range(5): nick = make_nickname() print(f"닉네임 {i+1}: {nick}")
닉네임 1: 신비한독수리 닉네임 2: 빠른여우 닉네임 3: 용감한호랑이 닉네임 4: 신비한독수리 ← 중복 발생! 닉네임 5: 날쌘사자

Step 2 — set으로 중복 없는 닉네임 생성

이미 사용된 닉네임을 set에 저장하고, while 반복문으로 새 닉네임이 나올 때까지 계속 시도합니다.

def make_unique_nickname(used_set): while True: nick = make_nickname() if nick not in used_set: used_set.add(nick) return nick used = set() for i in range(5): nick = make_unique_nickname(used) print(f"닉네임 {i+1}: {nick}") print(f"사용된 닉네임: {used}")

Step 3 — 글자 수 제한 규칙

len(nickname)으로 닉네임 길이를 검사합니다. 너무 짧거나 긴 닉네임은 걸러냅니다.

def make_valid_nickname(used_set, min_len=4, max_len=7): while True: nick = make_nickname() if nick in used_set: continue # 중복이면 다시 if not (min_len <= len(nick) <= max_len): continue # 글자수 벗어나면 다시 used_set.add(nick) return nick used = set() print("--- 4~7글자 닉네임 5개 ---") for i in range(5): nick = make_valid_nickname(used) print(f" {i+1}. {nick} ({len(nick)}글자)")

최종 완성본 — nickname_gen.py

import random adjectives = ["용감한", "빠른", "신비한", "강한", "날쌘"] animals = ["늑대", "여우", "독수리", "호랑이", "사자"] def make_nickname(): return random.choice(adjectives) + random.choice(animals) def make_valid_nickname(used_set, min_len=4, max_len=7): while True: nick = make_nickname() if nick in used_set: continue if not (min_len <= len(nick) <= max_len): continue used_set.add(nick) return nick max_count = len(adjectives) * len(animals) n = int(input("닉네임 몇 개 생성할까요? ")) if n > max_count: print(f"최대 {max_count}개까지 가능합니다.") n = max_count used = set() for i in range(n): nick = make_valid_nickname(used) print(f" {i+1}. {nick} ({len(nick)}글자)")

핵심 요약

  • random.choice(list) — 리스트에서 무작위로 1개 선택해 문자열 조합
  • set() — 중복 없는 컬렉션, in으로 빠른 포함 검사
  • set.add(값) — set에 원소 추가 (이미 있으면 무시)
  • len(문자열) — 글자 수 반환, 조건으로 길이 제한 구현
  • while True + continue — 조건을 만족할 때까지 반복 시도
  • min_len <= len(nick) <= max_len — 범위 검사를 한 줄로 표현
