프로젝트:
문장 뒤집기 도구

문자열을 다양한 방법으로 변환하는 도구를 만듭니다. 글자 뒤집기, 단어 순서 뒤집기, 대소문자 변환을 구현합니다.

이 프로젝트에서 배우는 것

  • text[::-1] 슬라이싱으로 문자열을 뒤집습니다.
  • text.split()으로 단어 리스트를 만들고 순서를 바꿉니다.
  • text.upper(), text.lower()로 대소문자를 변환합니다.
  • text.swapcase()로 대소문자를 뒤바꿉니다.
  • 여러 기능을 함수로 분리해 도구 모음을 만듭니다.

Step 1 — 슬라이싱으로 문자열 뒤집기

파이썬의 슬라이싱 text[start:stop:step]에서 step을 -1로 하면 문자열이 역순으로 복사됩니다. text[::-1]은 "처음부터 끝까지 역순으로"를 의미합니다.

# 문자열 뒤집기 text = "Hello World" # 방법 1: 슬라이싱 (가장 간단) reversed_text = text[::-1] print(reversed_text) # dlroW olleH # 방법 2: reversed() + join reversed_text2 = "".join(reversed(text)) print(reversed_text2) # dlroW olleH

단어 순서 뒤집기

split()으로 단어 리스트를 만든 뒤 [::-1]로 순서를 뒤집고, join()으로 다시 문자열로 합칩니다.

# 단어 순서 뒤집기 sentence = "I love Python programming" words = sentence.split() # 단어 리스트로 분리 words_reversed = words[::-1] # 리스트 뒤집기 result = " ".join(words_reversed) # 다시 문자열로 print(result) # programming Python love I # 한 줄로도 가능 print(" ".join(sentence.split()[::-1]))

Step 2 — 대소문자 변환 & 완성

파이썬 문자열에는 대소문자를 변환하는 내장 메서드가 여러 개 있습니다. upper(), lower(), title(), swapcase()를 익힙니다.

# 완성된 뒤집기 도구 def reverse_chars(text): return text[::-1] def reverse_words(text): return " ".join(text.split()[::-1]) def toggle_case(text): return text.swapcase() def is_palindrome(text): clean = text.lower().replace(" ", "") return clean == clean[::-1] text = input("문장 입력: ") print("글자 뒤집기:", reverse_chars(text)) print("단어 뒤집기:", reverse_words(text)) print("대소문자 변환:", toggle_case(text)) print("팰린드롬?", is_palindrome(text))
Q1
각 단어를 뒤집기
쉬움
문장의 단어 순서는 유지하되, 각 단어의 글자를 뒤집으세요.
입력"Hello World"
출력"olleH dlroW"
힌트 / 정답 보기
힌트: [w[::-1] for w in text.split()]
text = "Hello World" result = " ".join(w[::-1] for w in text.split()) print(result)
Q2
팰린드롬 검사기
보통
입력한 단어가 팰린드롬(앞뒤로 읽어도 같은 단어)인지 확인하세요. "racecar", "level", "noon"을 테스트해보세요.
입력racecar
출력팰린드롬입니다!
힌트 / 정답 보기
힌트: word == word[::-1]
word = input("단어 입력: ").lower() if word == word[::-1]: print("팰린드롬입니다!") else: print("팰린드롬이 아닙니다.")
Q3
암호 메시지 만들기
어려움
각 단어를 뒤집고 대소문자도 바꾸는 암호 변환기를 만드세요.
입력"Hello World"
출력"OLLEh DLROw"
힌트 / 정답 보기
힌트: 각 단어를 뒤집은 뒤 swapcase() 적용
text = "Hello World" result = " ".join(w[::-1].swapcase() for w in text.split()) print(result)

핵심 요약

  • text[::-1] — 문자열 전체를 거꾸로 뒤집기
  • " ".join(list) — 리스트를 공백으로 연결해 문자열로
  • text.upper() / text.lower() — 대문자 / 소문자 변환
  • text.swapcase() — 대소문자 뒤바꾸기
  • text.title() — 각 단어의 첫 글자를 대문자로
