프로젝트:
별 패턴 만들기

for 문과 문자열 곱셈을 사용해 직각삼각형, 피라미드, 다이아몬드 등 다양한 별 패턴을 출력합니다. 반복문의 원리를 시각적으로 체험합니다.

이 프로젝트에서 배우는 것

  • "*" * n 문자열 곱셈으로 반복 패턴을 만듭니다.
  • for i in range(n)으로 줄 수를 제어합니다.
  • " " * (n-i)으로 앞에 공백을 넣어 가운데 정렬합니다.
  • 위쪽(증가)과 아래쪽(감소)을 합쳐 다이아몬드를 만듭니다.
  • 중첩 for 문으로 숫자 삼각형을 출력합니다.

Step 1 — 직각삼각형과 피라미드

직각삼각형은 "*" * i만으로 만듭니다. 피라미드는 앞에 공백을 추가해서 가운데로 맞춥니다. i번째 줄의 공백은 size-i개입니다.

# 직각삼각형 def right_triangle(size): for i in range(1, size + 1): print("*" * i) # 피라미드 (가운데 정렬) def pyramid(size): for i in range(1, size + 1): spaces = " " * (size - i) stars = "*" * (2 * i - 1) print(spaces + stars) right_triangle(5) print() pyramid(5)

range(size, 0, -1)로 i를 size에서 1까지 내려가게 하면 뒤집힌 모양이 나옵니다.

Step 2 — 다이아몬드와 숫자 패턴

다이아몬드는 위쪽 피라미드와 아래쪽 역피라미드를 이어 붙입니다. 두 개의 for 문을 연달아 씁니다.

# 다이아몬드 def diamond(size): # 위쪽 (증가) for i in range(1, size + 1): print(" " * (size - i) + "*" * (2 * i - 1)) # 아래쪽 (감소) for i in range(size - 1, 0, -1): print(" " * (size - i) + "*" * (2 * i - 1)) # 숫자 삼각형 (중첩 for 문) def number_triangle(size): for i in range(1, size + 1): for j in range(1, i + 1): print(j, end=" ") print() # 줄 바꿈 diamond(4) print() number_triangle(4)

def hollow_rect(w, h): for i in range(h): if i == 0 or i == h - 1: print("*" * w) else: print("*" + " " * (w-2) + "*") hollow_rect(5, 4)

def x_shape(size): for i in range(size): row = "" for j in range(size): if j == i or j == size - 1 - i: row += "*" else: row += " " print(row) x_shape(5)

핵심 요약

  • "*" * n — n개의 별을 하나의 문자열로 만듦
  • " " * (size-i) — i가 커질수록 공백이 줄어 가운데 정렬됨
  • 다이아몬드 = 위쪽 for (증가) + 아래쪽 for (감소)
  • 중첩 for 문: 바깥 for = 줄, 안쪽 for = 칸
  • print(x, end=" ") — 줄 바꿈 없이 같은 줄에 출력
