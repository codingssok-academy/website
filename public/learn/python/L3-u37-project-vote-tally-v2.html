프로젝트:
투표 집계 시스템

L3c에서 배운 딕셔너리 활용, sorted+lambda, f-string, JSON 저장을 총동원해 실용적인 투표 집계 프로그램을 완성합니다.

이 유닛에서 만드는 것

  • 딕셔너리 get()으로 후보자별 득표수를 안전하게 집계할 수 있습니다.
  • sorted(dict.items(), key=lambda x: x[1])로 득표 순위를 정렬할 수 있습니다.
  • max()와 딕셔너리로 최다 득표자를 한 줄에 찾을 수 있습니다.
  • f-string 포맷팅으로 투표 결과표를 깔끔하게 출력할 수 있습니다.
  • 투표율(총 유권자 수 대비 참여율)을 계산하고 백분율로 표시할 수 있습니다.
  • json 모듈로 집계 결과를 파일에 저장하고 다시 불러올 수 있습니다.

프로젝트 준비 — L3c 핵심 기법 복습

이 프로젝트는 L3c에서 배운 딕셔너리 기법을 집중적으로 활용합니다. 사용할 기법을 빠르게 정리합니다.

Step 1 — 딕셔너리로 투표 집계

투표 집계의 핵심은 후보자 이름을 키, 득표수를 값으로 쓰는 딕셔너리입니다. get(이름, 0) + 1 패턴으로 처음 투표든 두 번째 투표든 안전하게 집계합니다.

# Step 1: 딕셔너리로 투표 집계 def tally_votes(vote_list): """투표 목록을 받아 후보자별 득표수 딕셔너리 반환""" votes = {} for candidate in vote_list: votes[candidate] = votes.get(candidate, 0) + 1 return votes # 테스트 투표 데이터 ballot = [ "김민준", "이서연", "김민준", "박지호", "이서연", "김민준", "이서연", "최수아", "박지호", "이서연" ] result = tally_votes(ballot) print(result)
{'김민준': 3, '이서연': 4, '박지호': 2, '최수아': 1}

get(candidate, 0)은 해당 후보자 키가 없을 때 0을 반환합니다. 이 덕분에 처음 나온 후보자도 KeyError 없이 0 + 1 = 1로 집계됩니다.

Step 2 — 최다 득표자 찾기

딕셔너리에서 가장 큰 값을 가진 키를 찾는 가장 파이썬다운 방법은 max(dict, key=dict.get)입니다. 람다 없이 단 한 줄로 최다 득표자를 구할 수 있습니다.

# Step 2: 최다 득표자 찾기 def find_winner(votes): """최다 득표자와 득표수 반환""" if not votes: return None, 0 winner = max(votes, key=votes.get) return winner, votes[winner] winner, count = find_winner(result) print(f"최다 득표자: {winner} ({count}표)")

Step 3 — 결과 정렬 (sorted + items + lambda)

투표 결과를 득표수 내림차순으로 정렬해 순위표를 만듭니다. dict.items()로 (키, 값) 쌍을 얻고, lambda x: x[1]로 값 기준 정렬을 합니다.

# Step 3: 결과 정렬 def sort_results(votes): """득표수 내림차순으로 정렬된 리스트 반환""" return sorted(votes.items(), key=lambda x: x[1], reverse=True) ranked = sort_results(result) for rank, (name, cnt) in enumerate(ranked, start=1): print(f"{rank}위 {name:6} {cnt}표")

Step 4 — 투표율 계산

투표율은 전체 유권자 수 대비 실제 투표에 참여한 수의 비율입니다. 소수점 출력에는 f-string의 :.1f 포맷을 씁니다.

# Step 4: 투표율 계산 def calc_turnout(votes, total_voters): """투표율(%) 반환""" total_votes = sum(votes.values()) if total_voters == 0: return 0.0 turnout = (total_votes / total_voters) * 100 return round(turnout, 1) TOTAL_VOTERS = 15 # 총 유권자 수 rate = calc_turnout(result, TOTAL_VOTERS) print(f"투표율: {rate:.1f}%")
투표율: 66.7%

Step 6 — JSON으로 결과 저장

투표 결과를 파일로 저장하면 나중에 다시 불러오거나 다른 프로그램과 공유할 수 있습니다. Python의 json 모듈은 딕셔너리를 JSON 텍스트로 쉽게 변환합니다.

# Step 6: JSON으로 결과 저장 import json def save_results(votes, total_voters, filename="result.json"): """투표 결과를 JSON 파일로 저장""" winner, top_cnt = find_winner(votes) rate = calc_turnout(votes, total_voters) data = { "votes": votes, "winner": winner, "top_count": top_cnt, "turnout": rate, "total_voters": total_voters } with open(filename, "w", encoding="utf-8") as f: json.dump(data, f, ensure_ascii=False, indent=2) print(f"저장 완료: {filename}") save_results(result, 15)

완성: vote_tally.py 전체 코드

지금까지 만든 5개 함수를 하나의 파일로 통합합니다. 각 단계를 순서대로 호출하면 완전한 투표 집계 시스템이 됩니다.

# vote_tally.py — 완성 코드 import json def tally_votes(vote_list): votes = {} for candidate in vote_list: votes[candidate] = votes.get(candidate, 0) + 1 return votes def find_winner(votes): if not votes: return None, 0 winner = max(votes, key=votes.get) return winner, votes[winner] def sort_results(votes): return sorted(votes.items(), key=lambda x: x[1], reverse=True) def calc_turnout(votes, total_voters): total = sum(votes.values()) return round((total / total_voters) * 100, 1) if total_voters else 0.0 def save_results(votes, total_voters, filename="result.json"): winner, top_cnt = find_winner(votes) data = {"votes": votes, "winner": winner, "top_count": top_cnt, "turnout": calc_turnout(votes, total_voters), "total_voters": total_voters} with open(filename, "w", encoding="utf-8") as f: json.dump(data, f, ensure_ascii=False, indent=2) # 메인 실행 ballot = ["김민준","이서연","김민준","박지호", "이서연","김민준","이서연","최수아", "박지호","이서연"] TOTAL_VOTERS = 15 votes = tally_votes(ballot) ranked = sort_results(votes) winner, cnt = find_winner(votes) rate = calc_turnout(votes, TOTAL_VOTERS) print("=" * 30) for rank, (name, c) in enumerate(ranked, 1): print(f"{rank:>2}위 {name:<6} {c:>3}표 {'*'*c}") print(f"당선자: {winner} ({cnt}표) | 투표율: {rate:.1f}%") save_results(votes, TOTAL_VOTERS)

확장 기능 — 실전 투표 시스템 개선

완성한 기본 시스템에 두 가지 실용적인 기능을 추가합니다. 무효표 처리와 후보자 사전 등록 기능입니다.

# 확장 1: 후보자 명단 등록 + 무효표 처리 def tally_with_candidates(vote_list, candidates): """사전 등록된 후보자만 집계, 무효표 별도 카운트""" # 후보자 모두 0표로 초기화 votes = {c: 0 for c in candidates} invalid = 0 for v in vote_list: if v in votes: votes[v] += 1 else: invalid += 1 # 등록되지 않은 후보 = 무효 return votes, invalid # 테스트 candidates = ["김민준", "이서연", "박지호", "최수아"] ballot2 = ["김민준", "이서연", "홍길동", "김민준", "무효"] v2, inv = tally_with_candidates(ballot2, candidates) print(v2) print(f"무효표: {inv}표")
{'김민준': 2, '이서연': 1, '박지호': 0, '최수아': 0} 무효표: 2표

딕셔너리 컴프리헨션으로 초기화

{c: 0 for c in candidates}는 딕셔너리 컴프리헨션입니다. 리스트의 모든 항목을 키로, 0을 값으로 하는 딕셔너리를 한 줄에 만듭니다.

핵심 요약

  • 딕셔너리 컴프리헨션 {k: v for k in list}로 초기값이 있는 딕셔너리를 한 줄에 생성
  • 후보자 등록 기반 집계는 if v in votes로 무효표를 구분
  • 0표 후보도 결과에 포함되어 공정한 순위표 출력 가능
  • json.dump(ensure_ascii=False)는 한글 JSON 저장의 필수 옵션
  • 투표 시스템 = 집계 + 정렬 + 투표율 + 저장 4단계의 조합
기법 사용 목적 핵심 문법
딕셔너리 집계 후보자별 득표수 카운트 d.get(k, 0) + 1
최다 득표자 탐색 최댓값 키 추출 max(d, key=d.get)
결과 정렬 득표 순위표 생성 sorted(d.items(), key=lambda x: x[1])
투표율 계산 참여율 백분율 표시 sum(d.values()) / total * 100
JSON 저장 결과 파일로 보존 json.dump(data, f, ensure_ascii=False)
