turtle —
그림 그리기
프로그래밍

파이썬 내장 모듈 turtle로 거북이를 움직여 선, 도형, 별, 나선, 집을 그립니다. 반복문과 결합하면 복잡한 그래픽도 단 몇 줄로 완성됩니다.

이 유닛에서 배우는 것

  • import turtle로 모듈을 불러오고 화면을 설정할 수 있습니다.
  • forward, backward, left, right로 거북이를 움직일 수 있습니다.
  • penup, pendown으로 선을 그리거나 이동만 할 수 있습니다.
  • color, fillcolor, begin_fill, end_fill로 색을 채울 수 있습니다.
  • circle(r)으로 원과 호를 그릴 수 있습니다.
  • for문과 결합해 별, 나선, 집 등 실용 도형을 그릴 수 있습니다.

1 — turtle 모듈 시작하기

turtle은 파이썬에 기본 내장된 모듈입니다. 별도 설치 없이 import turtle만으로 바로 사용할 수 있습니다. 실행하면 별도 창(윈도우)이 열리고, 가운데서 거북이가 출발합니다.

기본 이동 명령어

명령어단축형설명
forward(d)fd(d)현재 방향으로 d픽셀 전진
backward(d)bk(d)현재 방향의 반대로 d픽셀 후진
left(a)lt(a)현재 방향에서 왼쪽(반시계)으로 a도 회전
right(a)rt(a)현재 방향에서 오른쪽(시계)으로 a도 회전
goto(x, y)setpos(x, y)좌표 (x, y)로 바로 이동 (선이 그려짐)
home()—원점 (0,0)으로 돌아가고 방향도 초기화

첫 번째 코드: 정사각형 그리기

import turtle t = turtle.Turtle() # 거북이 객체 생성 for i in range(4): # 4번 반복 t.forward(100) # 100픽셀 전진 t.left(90) # 왼쪽으로 90도 회전 turtle.done() # 창 유지 (없으면 즉시 닫힘)
turtle.done()은 항상 마지막에 써야 합니다. 없으면 그림이 그려지자마자 창이 닫혀버립니다. IDLE에서 실행할 때는 없어도 되지만, 터미널에서 직접 실행할 때는 필수입니다.

2 — 펜 제어와 색상

penup / pendown

거북이가 이동할 때 항상 선이 그려지지는 않습니다. penup()을 호출하면 이동해도 선을 그리지 않고, pendown()을 호출하면 다시 선을 그립니다.

import turtle t = turtle.Turtle() t.forward(80) # 선 그리며 이동 t.penup() # 펜 올림 — 이동해도 선 없음 t.forward(40) # 이동만 (선 없음) t.pendown() # 펜 내림 — 다시 선 그림 t.forward(80) # 선 그리며 이동 turtle.done()

색상 설정

color(선색) 또는 color(선색, 채우기색)으로 색을 지정합니다. 색 이름 문자열("red", "blue") 또는 HEX 코드("#ff6600")를 모두 사용할 수 있습니다.

import turtle t = turtle.Turtle() t.color("red") # 선 색만 빨강 t.color("blue", "yellow") # 선=파랑, 채우기=노랑 t.pensize(3) # 선 굵기 3픽셀 t.begin_fill() # 채우기 시작 for _ in range(4): t.forward(100) t.left(90) t.end_fill() # 채우기 끝 — 노란 정사각형 완성 turtle.done()

circle — 원과 호 그리기

circle(r)은 반지름 r인 원을 그립니다. circle(r, extent)는 extent도만큼의 호를 그립니다.

명령어설명예시
circle(50)반지름 50의 원 (360도)완전한 원
circle(50, 180)반지름 50의 반원 (180도)반원 호
circle(50, 90)반지름 50의 1/4 원 (90도)모서리 곡선
circle(-50)오른쪽 방향으로 원 (음수 반지름)반대 방향 원

3 — for문으로 도형과 별 그리기

for문과 이동 명령어를 결합하면 정다각형을 간단하게 그릴 수 있습니다. n각형의 외각은 항상 360/n도입니다.

import turtle t = turtle.Turtle() # n각형 그리기 — n과 side만 바꾸면 어떤 정다각형도 OK n = 6 # 육각형 side = 80 # 한 변의 길이 angle = 360 / n # 외각 계산 for _ in range(n): t.forward(side) t.left(angle) turtle.done()

별(Star) 그리기

별은 5번 반복하며 144도씩 회전합니다. 한 꼭짓점에서 출발해 두 칸씩 건너뛰며 연결하면 별 모양이 됩니다.

import turtle t = turtle.Turtle() t.color("gold", "yellow") t.pensize(2) t.begin_fill() for _ in range(5): # 5번 반복 t.forward(100) # 100픽셀 전진 t.left(144) # 144도 회전 (두 칸 건너뜀) t.end_fill() turtle.done()

4 — 나선(Spiral)과 집(House) 그리기

나선형(Spiral) 그리기

나선은 매 반복마다 전진 거리를 조금씩 늘리면 됩니다. for문의 range를 거리로 활용하거나, 변수를 누적해서 늘릴 수 있습니다.

import turtle t = turtle.Turtle() t.speed(0) # 최고 속도 (0=fastest, 1=slowest, 10=fast) colors = ["red", "blue", "green", "orange"] for i in range(10, 110, 10): # 10,20,30,...,100 t.color(colors[i // 10 % len(colors)]) t.forward(i) t.left(90) turtle.done()

집(House) 그리기

집 = 정사각형(본체) + 삼각형(지붕)의 조합입니다. 정사각형을 그린 뒤 방향을 조정하고 삼각형을 연이어 그립니다.

import turtle t = turtle.Turtle() t.speed(3) # 본체: 정사각형 t.color("navy", "lightblue") t.begin_fill() for _ in range(4): t.forward(100) t.left(90) t.end_fill() # 지붕: 삼각형 (왼쪽 아랫모서리에서 시작) t.color("darkred", "salmon") t.left(30) # 방향 조정으로 지붕 각도 맞춤 t.begin_fill() for _ in range(3): t.forward(115) # 대각선 길이 (100 / cos30 ≈ 115) t.left(120) # 삼각형 외각 360/3 = 120 t.end_fill() turtle.done()

심화: turtle.Screen() 설정

화면 크기, 배경색, 타이틀을 설정하려면 turtle.Screen()을 사용합니다.

import turtle screen = turtle.Screen() screen.title("나의 turtle 그림") # 창 제목 screen.bgcolor("black") # 배경색 screen.setup(600, 600) # 창 크기 (width, height) t = turtle.Turtle() t.color("white") t.speed(0) for i in range(36): # 36개 별 방향 t.forward(100) t.backward(100) t.right(10) # 10도씩 회전 → 방사형 turtle.done()
심화 보충: hideturtle()과 tracer()

t.hideturtle(): 거북이 아이콘을 숨깁니다. 완성된 그림만 보여줄 때 사용합니다.

turtle.tracer(0) + turtle.update(): 애니메이션을 끄고 한번에 완성 그림을 보여줍니다. 복잡한 그림일 때 속도가 훨씬 빠릅니다.

import turtle turtle.tracer(0) # 애니메이션 끔 t = turtle.Turtle() t.hideturtle() # 거북이 아이콘 숨김 # ... 복잡한 그리기 코드 ... turtle.update() # 한번에 화면 갱신 turtle.done()
심화 보충: write()로 텍스트 출력

t.write(텍스트, font=(폰트, 크기, 스타일))으로 거북이 위치에 텍스트를 출력할 수 있습니다.

import turtle t = turtle.Turtle() t.penup() t.goto(-80, 0) t.write("Hello, turtle!", font=("Arial", 20, "bold")) turtle.done()
