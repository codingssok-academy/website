Chapter 02

input() — 사용자 입력 받기

키보드로 값을 입력받아 프로그램에서 사용하는 방법을 배웁니다.

이 유닛에서 배우는 것

  • input() 함수로 키보드 입력을 받을 수 있습니다.
  • 입력받은 값을 변수에 저장할 수 있습니다.
  • int()로 문자열을 숫자로 변환할 수 있습니다.
  • 여러 개의 입력을 받아 계산할 수 있습니다.
  • 입력을 활용한 간단한 프로그램을 만들 수 있습니다.

input() 함수

input()은 키보드로 값을 입력받는 함수입니다. 괄호 안에 질문 메시지를 넣을 수 있습니다.

name = input("이름을 입력하세요: ") print("안녕,", name)
따라해보세요
1
이름을 물어보고 인사하세요.
name = input("이름이 뭐야? ") print("반가워,", name, "!")
이름을 입력하면 인사 메시지가 출력됩니다
2
좋아하는 음식을 물어보세요.
food = input("좋아하는 음식: ") print(food, "맛있겠다!")
피자를 입력하면 "피자 맛있겠다!" 출력
3
두 개를 연속으로 입력받아보세요.
color = input("좋아하는 색: ") animal = input("좋아하는 동물: ") print(color, animal, "캐릭터를 만들자!")
파랑 고양이 캐릭터를 만들자!

int() — 숫자로 변환하기

input()은 항상 문자열을 돌려줍니다. 숫자로 계산하려면 int()로 변환해야 합니다.

age_str = input("나이를 입력하세요: ") # 문자열 "14" age = int(age_str) # 숫자 14 print("내년 나이:", age + 1)

한 줄로 줄이면 더 깔끔합니다.

age = int(input("나이: ")) print("내년 나이:", age + 1)
따라해보세요
1
나이를 입력받아 내년 나이를 출력하세요.
age = int(input("나이: ")) print("내년 나이:", age + 1)
14를 입력하면 "내년 나이: 15" 출력
2
두 수를 입력받아 합을 구하세요.
a = int(input("첫째 수: ")) b = int(input("둘째 수: ")) print("합:", a + b)
10과 25를 입력하면 "합: 35" 출력
3
용돈과 지출을 입력받아 잔액을 구하세요.
money = int(input("용돈: ")) spend = int(input("지출: ")) print("잔액:", money - spend, "원")
10000, 3500 입력하면 "잔액: 6500 원"

여러 입력 활용하기

여러 번 input()을 사용하면 다양한 정보를 입력받을 수 있습니다.

name = input("이름: ") age = int(input("나이: ")) school = input("학교: ") print(name, "님은", age, "살,", school, "학생입니다.")

float()를 사용하면 소수점이 있는 숫자도 입력받을 수 있습니다.

따라해보세요
1
자기 소개 프로그램을 만드세요.
name = input("이름: ") hobby = input("취미: ") print(name, "의 취미는", hobby, "입니다.")
민수, 게임 입력시 "민수 의 취미는 게임 입니다."
2
태어난 해를 입력받아 나이를 계산하세요.
birth = int(input("태어난 해: ")) age = 2026 - birth print("나이:", age, "살")
2012 입력하면 "나이: 14 살"
3
세 과목 점수를 입력받아 평균을 구하세요.
kor = int(input("국어: ")) eng = int(input("영어: ")) mat = int(input("수학: ")) avg = (kor + eng + mat) / 3 print("평균:", avg)
90, 85, 95 입력하면 "평균: 90.0"

Q3
사탕 나누기
보통
사탕 개수와 친구 수를 input()으로 입력받아, 한 명당 몇 개를 받는지와 남는 사탕 수를 출력하세요.

내 답안

정답 확인
candy = int(input("사탕 개수: ")) friends = int(input("친구 수: ")) each = candy // friends left = candy % friends print("한 명당:", each, "개, 남은 사탕:", left, "개")

핵심 요약

이 유닛에서 배운 것

  • input("질문")으로 키보드 입력을 받아 변수에 저장한다
  • input()의 결과는 항상 문자열이다
  • 숫자 계산을 하려면 int() 또는 float()로 변환한다
  • int(input("질문"))으로 한 줄에 숫자를 입력받을 수 있다
  • 여러 번 input()을 사용하면 여러 값을 입력받을 수 있다
