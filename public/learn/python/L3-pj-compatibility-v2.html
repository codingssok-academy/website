프로젝트:
이름 궁합 테스트

두 이름의 자음과 모음을 분석해 점수를 계산하고, f-string으로 A~F 등급의 결과를 출력합니다.

이 프로젝트에서 만드는 것

  • 한글 유니코드 원리를 이해하고 자음/모음을 추출하는 알고리즘을 구현합니다.
  • 두 이름의 자음/모음 일치 비율로 궁합 점수를 계산합니다.
  • 점수 범위에 따라 A~F 등급을 부여하는 조건문을 작성합니다.
  • f-string으로 이름, 점수, 등급, 메시지를 깔끔하게 포맷합니다.

핵심 개념 — 한글 유니코드 분해

한글 글자 하나는 초성(자음) + 중성(모음) + 종성(자음)으로 이루어집니다. 유니코드 계산으로 이를 분리할 수 있습니다.

간단한 접근법 — 자모 카운팅

정확한 분해 대신, 두 이름에서 같은 글자가 몇 개나 겹치는지 세는 방식으로도 궁합 점수를 만들 수 있습니다. 더 간단하고 직관적입니다.

Step 1
이름 점수 계산 함수

두 이름의 공통 글자 수와 자음/모음 기반 점수를 합산합니다.

def name_score(name): # 이름 각 글자의 ord() 값을 합산해 점수 생성 total = sum(ord(c) for c in name) return total % 100 def common_chars(name1, name2): # 두 이름에서 공통 글자 수 계산 s1 = set(name1) s2 = set(name2) return len(s1 & s2) # 교집합 크기 # 테스트 print(name_score("김민준")) # 예: 72 print(common_chars("김민준", "김서현")) # 1

Step 2 — 궁합 점수 및 등급 계산

두 이름의 name_score 차이와 common_chars를 합산해 최종 궁합 점수를 만들고, 점수 범위에 따라 A~F 등급을 부여합니다.

def get_grade(score): if score >= 90: return "A", "완벽한 궁합! 천생연분이에요." elif score >= 75: return "B", "좋은 궁합! 잘 맞는 편이에요." elif score >= 60: return "C", "보통 궁합. 노력하면 잘 맞을 거예요." elif score >= 45: return "D", "조금 어려워요. 서로를 이해하는 시간이 필요해요." elif score >= 30: return "E", "많이 다른 편이에요. 차이를 인정하면 좋아질 거예요." else: return "F", "지금은 시기가 아닌 것 같아요." def compatibility(name1, name2): s1 = name_score(name1) s2 = name_score(name2) common = common_chars(name1, name2) diff = abs(s1 - s2) score = 100 - diff + common * 5 score = max(0, min(100, score)) grade, msg = get_grade(score) return score, grade, msg

f-string으로 결과 출력

f-string의 형식 지정자로 점수를 소수점 없이, 등급을 강조해서 출력합니다.

name1 = input("첫 번째 이름: ") name2 = input("두 번째 이름: ") score, grade, msg = compatibility(name1, name2) print(f"{'='*30}") print(f" {name1} X {name2} 궁합 결과") print(f"{'='*30}") print(f" 점수: {score:3d}점 등급: {grade}") print(f" {msg}")

names = ["김민준", "이서연", "박지민", "최수호"] best_score = -1 best_pair = None for i in range(len(names)): for j in range(i+1, len(names)): score, grade, _ = compatibility(names[i], names[j]) if score > best_score: best_score = score best_pair = (names[i], names[j], grade) print(f"최고 궁합: {best_pair[0]} X {best_pair[1]} ({best_pair[2]}등급, {best_score}점)")

핵심 요약 — 이름 궁합 테스트 완성

핵심 요약

  • ord(c) — 문자를 유니코드 정수로 변환, 이름 기반 점수 생성에 활용
  • set(이름) — 문자열의 각 글자를 원소로 갖는 집합 생성
  • set1 & set2 — 두 set의 교집합, 공통 글자 찾기
  • abs(a - b) — 두 점수 차이의 절댓값
  • max(0, min(100, score)) — 값을 0~100 범위로 clamp
  • f-string {n:.1f} — 소수점 자리수 지정 출력
  • 다중 반환값 — return a, b, c로 여러 값을 한 번에 반환
