프로젝트:
비밀 일기장

비밀번호 잠금, 시저 암호(Caesar Cipher)로 내용 암호화, 파일 저장, 날짜별 관리까지 구현합니다. 문자열 처리, ord()/chr() 함수, 파일 입출력을 실전에 활용합니다.

이 유닛에서 만드는 것

  • 비밀번호를 입력받아 틀리면 접근을 막는 잠금 기능을 만들 수 있습니다.
  • ord()/chr()로 문자를 숫자로 변환해 시저 암호를 구현할 수 있습니다.
  • open()으로 파일을 만들고 일기 내용을 저장할 수 있습니다.
  • datetime 모듈로 오늘 날짜를 자동으로 파일명에 붙일 수 있습니다.
  • 암호화된 파일을 다시 읽어 복호화하는 기능을 만들 수 있습니다.

Step 1 — 비밀번호 잠금 시스템

일기장을 열려면 비밀번호를 입력해야 합니다. 최대 3번까지 시도할 수 있으며, 3번 실패하면 프로그램을 종료합니다. while 루프와 카운터 변수를 사용합니다.

# secret_diary.py — Step 1: 비밀번호 잠금 import sys PASSWORD = "1234" # 실제로는 해시 사용 권장 MAX_TRIES = 3 def check_password(): """비밀번호 확인, 통과하면 True 반환""" tries = 0 while tries < MAX_TRIES: pw = input(f"비밀번호 입력 ({MAX_TRIES - tries}회 남음): ") if pw == PASSWORD: print("잠금 해제! 일기장을 엽니다.") return True tries += 1 print("틀렸습니다.") print("접근 거부. 종료합니다.") sys.exit(0)

Step 2 — 시저 암호 구현

시저 암호(Caesar Cipher)는 알파벳 각 글자를 일정한 수(shift)만큼 밀어서 암호화합니다. ord()는 문자를 아스키 코드(숫자)로, chr()는 숫자를 문자로 변환합니다.

c = "A" shifted = chr(ord(c) + 3) print(shifted)

print(chr(ord("Z") + 3))

% 연산으로 알파벳 범위 내에서 순환하는 공식을 적용하세요.
c = "Z" shifted = chr((ord(c) - 65 + 3) % 26 + 65) print(shifted)
C — Z에서 3칸 이동하면 C(순환)

Step 3 — 시저 암호화/복호화 함수

암호화 공식 (ord(c) - 65 + shift) % 26 + 65는 알파벳을 0~25 범위로 변환하고 shift를 더한 뒤 다시 알파벳으로 돌립니다. 한글이나 숫자는 변환 없이 그대로 둡니다.

# Step 3a: 암호화/복호화 함수 def caesar_encrypt(text, shift=3): """텍스트를 시저 암호로 암호화""" result = "" for c in text: if c.isalpha() and c.isupper(): result += chr((ord(c) - 65 + shift) % 26 + 65) elif c.isalpha() and c.islower(): result += chr((ord(c) - 97 + shift) % 26 + 97) else: result += c # 알파벳 외 문자는 그대로 return result def caesar_decrypt(text, shift=3): """복호화는 반대 방향으로 shift""" return caesar_encrypt(text, -shift) # 테스트 msg = "Hello World" enc = caesar_encrypt(msg) dec = caesar_decrypt(enc) print(f"원문: {msg}") print(f"암호: {enc}") print(f"복호: {dec}")
원문: Hello World 암호: Khoor Zruog 복호: Hello World

Step 4 — 파일에 저장하기

파이썬의 open() 함수로 파일을 만들고 일기 내용을 저장합니다. datetime.today()로 오늘 날짜를 가져와 파일명으로 씁니다. "w" 모드는 새 파일 생성, "a" 모드는 기존 파일에 내용 추가입니다.

# Step 4: 파일 저장 from datetime import datetime def save_entry(content, shift=3): """일기를 암호화해서 날짜 파일에 저장""" today = datetime.today().strftime("%Y-%m-%d") filename = f"diary_{today}.txt" encrypted = caesar_encrypt(content, shift) with open(filename, "a", encoding="utf-8") as f: f.write(f"[{today}]\n") f.write(encrypted + "\n---\n") print(f"{filename}에 저장됨")

Step 5 — 파일 읽고 복호화하기

저장된 일기 파일을 "r" 모드로 열어 읽은 뒤, caesar_decrypt()로 원문을 복원합니다. with open() 구문은 파일을 열고 자동으로 닫아줍니다.

# Step 5: 파일 읽고 복호화 def read_diary(date=None, shift=3): """날짜 미입력 시 오늘 일기 읽기""" if date is None: date = datetime.today().strftime("%Y-%m-%d") filename = f"diary_{date}.txt" try: with open(filename, "r", encoding="utf-8") as f: content = f.read() # 헤더 [날짜] 줄은 그대로, 암호문만 복호화 lines = content.split("\n") for line in lines: if line.startswith("[") or line == "---": print(line) else: print(caesar_decrypt(line, shift)) except FileNotFoundError: print(f"{date} 일기를 찾을 수 없습니다.")

핵심 요약

  • ord(c)는 문자를 아스키 숫자로, chr(n)은 숫자를 문자로 변환합니다.
  • % 26 나머지 연산으로 알파벳을 순환시킵니다.
  • with open(파일, 모드, encoding="utf-8")로 파일을 안전하게 열고 자동으로 닫습니다.
  • "w" 모드는 새 파일, "a" 모드는 내용 추가, "r" 모드는 읽기입니다.
  • datetime.today().strftime()으로 날짜를 원하는 형식의 문자열로 만듭니다.
