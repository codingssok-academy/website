프로젝트:
시간표 관리

datetime 모듈로 날짜와 시간을 다루고, 수업 일정을 딕셔너리로 관리합니다. JSON 저장으로 데이터를 영속화하는 시간표 관리 시스템을 만듭니다.

이 프로젝트에서 만드는 것

  • datetime.now()와 strftime/strptime으로 날짜 파싱
  • timedelta로 날짜 연산 (D-day 계산)
  • 요일별 딕셔너리로 시간표 데이터 구조 설계
  • 수업 추가, 삭제, 조회, 오늘 시간표 출력
  • JSON 저장/불러오기로 영속적 시간표 관리

핵심 개념 — datetime과 날짜 연산

datetime 모듈은 날짜와 시간을 다루는 파이썬 내장 모듈입니다. datetime.now()로 현재 시각을 가져오고, strftime()으로 원하는 형식의 문자열로 변환합니다. strptime()은 반대로 문자열을 datetime 객체로 변환합니다. weekday()는 월요일=0, 일요일=6으로 반환합니다.

# datetime 기본 사용법 from datetime import datetime, timedelta now = datetime.now() print(now.strftime("%Y년 %m월 %d일 %H:%M")) # 2025년 03월 21일 09:30 dt = datetime.strptime("2025-06-20", "%Y-%m-%d") diff = (dt - now).days print(f"D-{diff}") # 기말고사까지 남은 일수 delta = timedelta(days=7) print((now + delta).strftime("%Y-%m-%d")) # 1주일 뒤

Step 1 — 시간표 데이터 구조와 수업 추가

요일을 키로, 수업 목록을 값으로 갖는 딕셔너리로 시간표를 설계합니다. weekday()는 0~6(월~일)을 반환하므로 DAYS 리스트와 매핑합니다. add_class는 요일과 시간을 입력받아 schedule에 추가합니다.

# Step 1: 시간표 데이터 구조 from datetime import datetime, timedelta DAYS = ["월", "화", "수", "목", "금", "토", "일"] schedule = {day: [] for day in DAYS} # 딕셔너리 컴프리헨션 def add_class(day, subject, time_str): """time_str 형식: '09:30'""" schedule[day].append({"subject": subject, "time": time_str}) schedule[day].sort(key=lambda x: x["time"]) print(f"[추가] {day}요일 {time_str} {subject}") def show_today(): today = datetime.now() day = DAYS[today.weekday()] print(f"오늘({today.strftime('%Y-%m-%d')}) {day}요일 시간표:") classes = schedule.get(day, []) if not classes: print(" 수업 없음") else: for c in classes: print(f" {c['time']} {c['subject']}")

Step 2 — 주간 조회 + JSON 저장

show_week()는 schedule 딕셔너리의 모든 요일을 순회하고, delete_class()는 특정 요일에서 subject 이름이 일치하는 항목을 제거합니다. JSON 저장 시 datetime 객체는 직렬화 불가하므로 시간을 문자열로만 관리합니다.

# Step 2: 주간 조회 + 삭제 + JSON import json def show_week(): print("=== 주간 시간표 ===") for day in DAYS[:5]: # 월~금만 classes = schedule[day] if classes: print(f"{day}: {', '.join(f\"{c['time']}{c['subject']}\" for c in classes)}") def delete_class(day, subject): before = len(schedule[day]) schedule[day] = [c for c in schedule[day] if c["subject"] != subject] if len(schedule[day]) < before: print(f"[삭제] {day} {subject}") def save_schedule(path="schedule.json"): with open(path, "w", encoding="utf-8") as f: json.dump(schedule, f, ensure_ascii=False, indent=2) def load_schedule(path="schedule.json"): global schedule try: with open(path, encoding="utf-8") as f: schedule = json.load(f) print("시간표 불러오기 완료") except FileNotFoundError: print("저장 파일 없음") def dday(date_str): """date_str: 'YYYY-MM-DD'""" target = datetime.strptime(date_str, "%Y-%m-%d") diff = (target - datetime.now().replace(hour=0, minute=0)).days print(f"D-{diff}" if diff > 0 else f"D+{abs(diff)}")

연습 문제

Q1
다음 수업 조회
Easy
오늘 현재 시각 이후 가장 가까운 수업을 출력하는 next_class() 함수를 작성하세요. 오늘 남은 수업이 없으면 "오늘 수업 없음"을 출력합니다. datetime.now()와 strptime으로 시간을 비교합니다.
호출
next_class()
출력
다음 수업: 14:00 과학
힌트 보기
오늘 요일의 수업 중 datetime.strptime(c["time"], "%H:%M").time()이 현재 시간보다 큰 것 중 가장 이른 것을 찾습니다.
정답 보기
def next_class(): now = datetime.now() day = DAYS[now.weekday()] current_time = now.time() upcoming = [c for c in schedule[day] if datetime.strptime(c["time"], "%H:%M").time() > current_time] if upcoming: c = upcoming[0] print(f"다음 수업: {c['time']} {c['subject']}") else: print("오늘 수업 없음")
Q2
수업 시간 수정
Medium
update_class(day, subject, new_time) 함수를 작성하세요. 해당 요일에서 subject를 찾아 시간을 수정하고, 수정 후 시간 순으로 재정렬합니다. 없는 과목이면 오류 메시지를 출력합니다.
호출
update_class("월", "수학", "10:00")
출력
[수정] 월 수학 10:00
힌트 보기
리스트 순회 중 c["subject"] == subject인 항목을 찾아 c["time"] = new_time으로 수정합니다. 수정 후 sort(key=...)를 다시 호출합니다.
정답 보기
def update_class(day, subject, new_time): for c in schedule[day]: if c["subject"] == subject: c["time"] = new_time schedule[day].sort(key=lambda x: x["time"]) print(f"[수정] {day} {subject} {new_time}") return print(f"[오류] {day} {subject} 없음")
Q3
시간 충돌 검사
Hard
같은 요일에 동일한 시간대(시간이 같은 경우)의 수업이 이미 존재하면 추가를 막는 safe_add(day, subject, time_str)를 작성하세요. strptime으로 시간을 파싱해 timedelta로 30분 이내 충돌을 감지합니다.
충돌
safe_add("월", "체육", "09:20") → 충돌!
정상
safe_add("월", "체육", "11:00") → 추가됨
힌트 보기
abs((t1 - t2).seconds) < 1800로 30분 이내 충돌을 판단합니다. datetime.strptime으로 두 시간을 datetime 객체로 변환해 뺄셈합니다.
정답 보기
def safe_add(day, subject, time_str): new_t = datetime.strptime(time_str, "%H:%M") for c in schedule[day]: exist_t = datetime.strptime(c["time"], "%H:%M") if abs((new_t - exist_t).seconds) < 1800: print(f"[충돌] {c['time']} {c['subject']}와 30분 이내") return add_class(day, subject, time_str)

핵심 요약

  • datetime.now() — 현재 날짜/시간 반환, .weekday()로 요일 인덱스(0=월)
  • strftime / strptime — datetime <--> 문자열 양방향 변환, %Y %m %d %H %M
  • timedelta — 날짜 연산, (target - today).days로 D-day 계산
  • 딕셔너리 컴프리헨션 — {day: [] for day in DAYS}로 요일별 리스트 초기화
  • JSON 저장 — 문자열 기반 시간 데이터는 직렬화 가능, datetime 객체는 불가
