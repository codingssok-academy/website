Chapter 06

주석 -- 코드에 메모 남기기

코드에 설명을 달아 읽기 쉽게 만드는 방법을 배웁니다.

이 유닛에서 배우는 것

  • #으로 한 줄 주석을 작성할 수 있습니다.
  • 따옴표 3개로 여러 줄 주석을 작성할 수 있습니다.
  • 주석이 프로그램 실행에 영향을 주지 않음을 이해합니다.
  • 좋은 주석과 나쁜 주석의 차이를 설명할 수 있습니다.
  • 코드를 임시로 비활성화하는 데 주석을 사용할 수 있습니다.

한 줄 주석 -- # 기호

# 뒤에 쓴 내용은 파이썬이 무시합니다. 코드에 메모를 남기는 가장 기본적인 방법입니다.

주석은 코드 옆에 쓸 수도 있고, 코드 위에 따로 한 줄을 차지할 수도 있습니다.

따라해보세요
1
주석이 있는 코드를 실행해보세요. 주석은 출력에 영향을 주지 않습니다.
# 내 첫 번째 주석 print("안녕하세요") # 인사 출력
안녕하세요 만 출력됩니다 (주석은 무시)
2
코드 앞에 #을 붙여서 실행을 막아보세요.
# print("이 줄은 실행 안 됨") print("이 줄만 실행됨")
이 줄만 실행됨 -- 첫 줄은 주석 처리되어 무시
3
변수 옆에 설명 주석을 달아보세요.
name = "자현" # 사용자 이름 age = 15 # 나이 print(name, age)
자현 15 가 출력됩니다

여러 줄 주석 -- 따옴표 3개

긴 설명이 필요할 때는 작은따옴표 3개(''')로 감싸서 여러 줄 주석을 만들 수 있습니다. 큰따옴표 3개(""")도 동일하게 동작합니다.

따라해보세요
1
여러 줄 주석을 작성하고 실행해보세요.
""" 이름: 자현 목적: 파이썬 학습 """ print("시작!")
시작! 만 출력됩니다 (주석 내용은 무시)
2
작은따옴표 3개로도 같은 결과인지 확인하세요.
''' 여러 줄 주석 테스트 작은따옴표 3개도 동일 ''' print("확인 완료")
확인 완료 가 출력됩니다
3
한 줄 주석 여러 개로 같은 효과를 낼 수도 있습니다.
# 이름: 자현 # 목적: 파이썬 학습 # 날짜: 2026-03-19 print("완료")
완료 가 출력됩니다

좋은 주석 vs 나쁜 주석

주석은 코드를 읽는 사람(미래의 나 포함)을 위한 것입니다. 하지만 아무 주석이나 다는 것보다, 필요한 곳에 정확한 주석을 다는 것이 중요합니다.

정리하면, 주석은 "무엇(What)"보다 "왜(Why)"를 설명해야 합니다. 코드가 무엇을 하는지는 코드 자체로 알 수 있지만, 왜 그렇게 했는지는 주석 없이는 알기 어렵습니다.

직접 풀어보세요

Q1
한 줄 주석 달기
쉬움
# 주석으로 각 줄의 역할을 설명하세요.
코드name = "Python"
print(name)
내 답안
힌트 보기
각 줄 뒤에 # 설명 형태로 주석을 달면 됩니다.
정답 확인
name = "Python" # 언어 이름 저장 print(name) # 이름 출력
Q2
여러 줄 주석 작성
쉬움
따옴표 3개를 사용하여 자기 이름, 학년, 좋아하는 과목을 여러 줄 주석으로 작성한 뒤, print("완료")를 실행하세요.
출력완료
내 답안
힌트 보기
따옴표 3개로 시작하고 따옴표 3개로 닫으세요. 그 안에 자유롭게 작성합니다.
정답 확인
""" 이름: 구자현 학년: 중학교 1학년 좋아하는 과목: 수학, 과학, 코딩 """ print("완료")
Q3
주석으로 코드 비활성화
보통
아래 코드에서 두 번째 print()만 주석 처리하여, A와 C만 출력되게 하세요.
코드print("A")
print("B")
print("C")
출력A
C
내 답안
힌트 보기
비활성화하고 싶은 줄 앞에 #을 붙이면 됩니다.
정답 확인
print("A") # print("B") print("C")

핵심 요약

이 유닛에서 배운 것

  • # 뒤의 내용은 한 줄 주석 -- 파이썬이 무시한다
  • 따옴표 3개(""" 또는 ''')로 여러 줄 주석을 작성한다
  • 주석은 실행에 영향을 주지 않는다 -- 메모 용도
  • 좋은 주석은 "왜(Why)"를 설명하고, 나쁜 주석은 코드를 반복한다
  • 코드를 임시로 비활성화할 때도 # 주석을 활용한다
