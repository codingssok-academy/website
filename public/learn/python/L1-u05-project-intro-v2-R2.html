프로젝트: 자기소개 프로그램

print()로 배운 모든 기법을 활용하여 자기소개 프로그램을 완성합니다.

이 유닛에서 배우는 것

  • print()의 다양한 기능을 종합적으로 활용할 수 있습니다.
  • 출력 결과를 먼저 설계하고 코드로 구현할 수 있습니다.
  • sep, end, 이스케이프 문자, 삼중 따옴표를 적재적소에 사용할 수 있습니다.
  • ASCII 아트를 코드로 표현할 수 있습니다.
  • 완성된 프로그램을 단계적으로 개선할 수 있습니다.
왜 이걸 배울까? 지금까지 배운 print()의 다양한 기능들을 하나의 프로그램으로 합쳐봅니다. 개별 기능을 아는 것과 그것을 조합해서 완성품을 만드는 것은 완전히 다릅니다. 이 프로젝트가 "코드로 무언가를 만드는" 첫 경험이 됩니다.

자주 하는 실수
  • 설계 없이 바로 코드를 작성하는 것 — 먼저 "출력 결과가 어떻게 보여야 하는지" 종이에 그려보세요.
  • 문자열 안에 따옴표를 넣을 때 이스케이프를 잊는 것: print("He said "Hi"")는 에러 — "를 사용하거나 바깥 따옴표를 바꾸세요.
  • * 연산자로 문자열 반복할 때 숫자 위치를 헷갈리는 것 — "*" * 10이 맞고, 10 * "*"도 됩니다.
확인해봅시다 print("=" * 20)의 출력 결과를 적어보십시오. 문자열 반복 연산자(*)가 어떤 일을 하는지 설명할 수 있습니까?

프로젝트 소개

이번 유닛에서는 지금까지 배운 print() 기능을 총동원하여 자기소개 프로그램을 만듭니다. 단순히 글자를 나열하는 것이 아니라, 테두리, 정렬, ASCII 아트까지 포함된 완성도 있는 프로그램을 목표로 합니다.

프로젝트는 4단계로 진행됩니다. 각 단계를 완성한 뒤 실행해 보고, 다음 단계로 넘어갑니다.

1
1단계: 기본 자기소개
이름, 나이, 학교 등 기본 정보를 출력합니다.
2
2단계: 테두리 추가
출력에 테두리를 넣어 명함처럼 꾸밉니다.
3
3단계: ASCII 아트 추가
문자로 만든 그림을 프로그램에 추가합니다.
4
4단계: 종합 완성
sep, end, 이스케이프 문자를 활용하여 최종 버전을 완성합니다.

새로운 도구 — 문자열 반복(*)

프로젝트를 시작하기 전에, 테두리를 만들 때 유용한 도구를 하나 배웁니다. 문자열에 * 연산자를 사용하면 해당 문자열을 반복할 수 있습니다.

Pythonrepeat.py
1print("=" * 30)
2print("-" * 20)
3print("Ha" * 5)
4print("*" * 10)
실행 결과
============================== -------------------- HaHaHaHaHa **********
줄코드역할
1"=" * 30=를 30번 반복합니다. 구분선을 만들 때 유용합니다.
3"Ha" * 5여러 글자도 반복됩니다. HaHaHaHaHa가 출력됩니다.
TIP
테두리 만들기 패턴
print("+" + "-" * 20 + "+")처럼 +와 -를 조합하면 깔끔한 테두리를 만들 수 있습니다. 숫자를 바꾸면 테두리 길이가 달라집니다.

TIP
테두리 정렬하기
오른쪽 | 기호가 깔끔하게 맞으려면 각 줄의 글자 수를 동일하게 맞춰야 합니다. 공백으로 채우면 됩니다. 나중에 .ljust() 같은 메서드를 배우면 자동으로 맞출 수 있지만, 지금은 직접 공백을 넣어 봅니다.

3단계: ASCII 아트 추가

ASCII 아트는 문자만으로 그림을 표현하는 기법입니다. 자기소개 프로그램에 개성 있는 그림을 추가해 봅시다.

Pythonascii_face.py
1print(""" _____
2 / \\
3 | ^ ^ |
4 | (>) |
5 \\_____/
6""")
7print("안녕하세요! 김코딩입니다.")
실행 결과

ASCII 아트와 역슬래시
