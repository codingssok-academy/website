구구단 게임

random 모듈로 문제를 출제하고, 정답을 체크하며 연속 정답 카운트를 관리하는 게임을 만듭니다.

이 프로젝트에서 배우는 것

  • random.randint()로 무작위 문제를 만들 수 있습니다.
  • 정답 비교로 맞춤/틀림을 판정할 수 있습니다.
  • 카운터 변수로 연속 정답 수를 관리할 수 있습니다.
  • while 루프로 반복 게임 구조를 만들 수 있습니다.
  • 최고 기록 변수로 최댓값을 추적할 수 있습니다.

랜덤 문제 만들기

random.randint(2, 9)로 2~9 사이 숫자 두 개를 뽑아 곱셈 문제를 만들고, 사용자 답과 비교해 정오를 판정합니다.

import random # 문제 하나 만들기 a = random.randint(2, 9) b = random.randint(2, 9) answer = a * b # 정답 print(f"{a} x {b} = ?") user_answer = int(input("정답: ")) if user_answer == answer: print("정답입니다!") else: print(f"틀렸습니다. 정답은 {answer}입니다.")

연속 정답 카운트하기

연속으로 맞춘 횟수를 streak 변수로 관리합니다. 정답이면 +1, 틀리면 0으로 초기화합니다. best_streak로 최고 연속 기록도 추적합니다.

import random score = 0 streak = 0 # 현재 연속 정답 best_streak = 0 # 최고 연속 기록 total = 10 # 총 문제 수 for i in range(total): a = random.randint(2, 9) b = random.randint(2, 9) print(f"\n문제 {i+1}: {a} x {b} = ?") answer = int(input("정답: ")) if answer == a * b: print("정답!") score += 10 streak += 1 if streak > best_streak: best_streak = streak else: print(f"틀림! 정답: {a * b}") streak = 0 print(f"\n최종 점수: {score}/{total*10}") print(f"최고 연속: {best_streak}개")

완성: 구구단 게임 전체 코드

import random print("=== 구구단 게임 ===") total = int(input("문제 수 (1~20): ")) score = correct = streak = best_streak = 0 for i in range(total): a = random.randint(2, 9) b = random.randint(2, 9) try: user = int(input(f"Q{i+1}) {a} x {b} = ")) except ValueError: print("숫자 입력 필요! 오답 처리") user = -1 if user == a * b: streak += 1 best_streak = max(best_streak, streak) correct += 1 score += 10 bonus = " 콤보!" if streak >= 3 else "" print(f"정답! (연속 {streak}){bonus}") else: print(f"틀림! 정답: {a * b}") streak = 0 print(f"\n=== 결과 ===") print(f"점수: {score}점 ({correct}/{total} 정답)") print(f"최고 연속: {best_streak}개") print(f"정답률: {correct/total*100:.0f}%")

import random ranges = {"1":(2,5), "2":(2,9), "3":(2,19)} level = input("난이도 선택 (1/2/3): ") lo, hi = ranges.get(level, (2,9)) for i in range(5): a = random.randint(lo, hi) b = random.randint(lo, hi) ans = int(input(f"Q{i+1}) {a} x {b} = ")) if ans == a*b: print("정답!") else: print(f"틀림! {a*b}")

핵심 요약

이 유닛에서 배운 것

  • random.randint(a, b): a 이상 b 이하의 랜덤 정수 반환
  • 카운터 변수: 정답 시 streak += 1, 틀리면 streak = 0
  • best = max(best, streak): if 없이 최댓값 한 줄로 갱신
  • for i in range(n):으로 n번 반복해 문제를 출제한다
  • 조건부 표현식: "콤보!" if streak >= 3 else ""
  • try/except와 게임 루프를 결합해 견고한 프로그램을 만든다
