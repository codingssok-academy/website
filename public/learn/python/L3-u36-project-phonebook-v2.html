프로젝트 준비 — 데이터 구조 설계

전화번호부를 만들기 전에 어떤 자료구조를 쓸지 결정해야 합니다. L3c에서 배운 딕셔너리와 중첩 구조를 활용합니다.

이 프로젝트에서는 중첩 딕셔너리를 사용합니다. 이름을 키로, 세부 정보(전화번호, 그룹)를 값으로 저장합니다.

# 전화번호부 데이터 구조 phonebook = { "홍길동": {"phone": "010-1234-5678", "group": "친구"}, "김철수": {"phone": "010-9876-5432", "group": "가족"}, "이영희": {"phone": "010-5555-1234", "group": "직장"}, } # 접근 방법 print(phonebook["홍길동"]["phone"]) # "010-1234-5678" print(phonebook["김철수"]["group"]) # "가족"

Step 1 — 추가 기능 구현

새 연락처를 전화번호부에 추가합니다. 먼저 이름이 이미 있는지 확인하고, 없으면 새로 추가합니다.

# Step 1: 연락처 추가 def add_contact(phonebook, name, phone, group="기타"): """전화번호부에 새 연락처 추가""" if name in phonebook: print(f"[오류] '{name}'은 이미 존재합니다.") return False phonebook[name] = {"phone": phone, "group": group} print(f"[추가] '{name}' 저장 완료.") return True # 테스트 phonebook = {} add_contact(phonebook, "홍길동", "010-1234-5678", "친구") add_contact(phonebook, "홍길동", "010-0000-0000") # 중복

Step 2 — 검색 기능 / Step 3 — 수정 기능

Step 2 — 연락처 검색

이름으로 검색하거나, 이름의 일부분으로 검색하는 두 가지 방식을 구현합니다.

# Step 2: 검색 기능 def search_contact(phonebook, keyword): """이름에 keyword가 포함된 연락처 모두 반환""" results = {} for name, info in phonebook.items(): if keyword in name: results[name] = info return results # 테스트 found = search_contact(phonebook, "길") if found: for name, info in found.items(): print(f"이름: {name} | 번호: {info['phone']} | 그룹: {info['group']}") else: print("검색 결과가 없습니다.")
이름: 홍길동 | 번호: 010-1234-5678 | 그룹: 친구

Step 3 — 수정 기능

이름을 기준으로 연락처를 찾아 전화번호 또는 그룹을 수정합니다. get() 메서드로 현재 값을 확인한 뒤 새 값으로 업데이트합니다.

# Step 3: 수정 기능 def update_contact(phonebook, name, field, new_value): """field: 'phone' 또는 'group'""" if name not in phonebook: print(f"[오류] '{name}'을 찾을 수 없습니다.") return False if field not in ("phone", "group"): print("[오류] phone 또는 group만 수정 가능합니다.") return False old_value = phonebook[name][field] phonebook[name][field] = new_value print(f"[수정] {name} / {field}: {old_value} -> {new_value}") return True # 테스트 update_contact(phonebook, "홍길동", "phone", "010-9999-0000")
[수정] 홍길동 / phone: 010-1234-5678 -> 010-9999-0000

Step 4 — 삭제와 전체 목록

# Step 4-1: 삭제 def delete_contact(phonebook, name): if name not in phonebook: print(f"[오류] '{name}'을 찾을 수 없습니다.") return False del phonebook[name] print(f"[삭제] '{name}' 삭제 완료.") return True # Step 4-2: 전체 목록 def list_all(phonebook): if not phonebook: print("전화번호부가 비어 있습니다.") return print(f"\n[ 전화번호부 — 총 {len(phonebook)}명 ]") print("-" * 45) for i, (name, info) in enumerate(phonebook.items(), 1): print(f"{i:2}. {name:<10} {info['phone']:<16} [{info['group']}]") print("-" * 45)

Step 5 — JSON 저장 / 불러오기

json 모듈의 dump()로 파일에 저장하고, load()로 불러옵니다. 파일이 없을 때는 빈 딕셔너리를 반환하도록 예외 처리를 합니다.

import json # Step 5: JSON 저장 / 불러오기 FILENAME = "phonebook.json" def save_phonebook(phonebook): with open(FILENAME, "w", encoding="utf-8") as f: json.dump(phonebook, f, ensure_ascii=False, indent=2) print(f"[저장] {FILENAME}에 {len(phonebook)}건 저장 완료.") def load_phonebook(): try: with open(FILENAME, "r", encoding="utf-8") as f: return json.load(f) except FileNotFoundError: print("[안내] 파일이 없습니다. 새 전화번호부를 시작합니다.") return {} # 테스트 save_phonebook(phonebook) loaded = load_phonebook() print(f"불러온 연락처 수: {len(loaded)}")

Step 6 — 메뉴 기반 CLI 완성

while True 루프 안에 메뉴를 출력하고, 사용자 입력에 따라 각 기능 함수를 호출합니다. 프로그램을 종료하기 전에 JSON 파일에 자동 저장합니다.

# Step 6: 메뉴 기반 CLI def show_menu(): print("\n====== 전화번호부 ======") print("1. 연락처 추가") print("2. 연락처 검색") print("3. 연락처 수정") print("4. 연락처 삭제") print("5. 전체 목록") print("6. 저장 후 종료") print("========================") def run(): phonebook = load_phonebook() while True: show_menu() choice = input("선택 (1-6): ").strip() if choice == "1": name = input("이름: ").strip() phone = input("번호: ").strip() group = input("그룹 (기본값 기타): ").strip() or "기타" add_contact(phonebook, name, phone, group) elif choice == "2": keyword = input("검색어: ").strip() found = search_contact(phonebook, keyword) for n, info in found.items(): print(f" {n}: {info['phone']} [{info['group']}]") elif choice == "3": name = input("이름: ").strip() field = input("수정 필드 (phone/group): ").strip() value = input("새 값: ").strip() update_contact(phonebook, name, field, value) elif choice == "4": name = input("삭제할 이름: ").strip() delete_contact(phonebook, name) elif choice == "5": list_all(phonebook) elif choice == "6": save_phonebook(phonebook) print("프로그램을 종료합니다.") break else: print("1-6 중에서 선택하세요.") if __name__ == "__main__": run()

심화 기능 — 그룹별 목록 출력

딕셔너리 컴프리헨션과 items()를 조합하면 특정 그룹의 연락처만 필터링할 수 있습니다.

# 심화: 그룹별 연락처 필터링 def list_by_group(phonebook, group): """특정 그룹의 연락처만 반환""" filtered = { name: info for name, info in phonebook.items() if info["group"] == group } print(f"\n[ {group} 그룹 — {len(filtered)}명 ]") for name, info in filtered.items(): print(f" {name}: {info['phone']}") # 테스트 list_by_group(phonebook, "친구")
[ 친구 그룹 — 2명 ] 홍길동: 010-1234-5678 이영희: 010-5555-1234
심화 도전 — 정렬된 전체 목록

전체 목록을 이름 가나다 순으로 정렬해 출력하려면 sorted(phonebook.items())를 사용합니다. 기본 정렬 기준이 키(이름)이므로 별도 key가 필요 없습니다.

for name, info in sorted(phonebook.items()): print(f"{name}: {info['phone']}")
심화 도전 — 전체 그룹 통계

각 그룹에 몇 명씩 있는지 딕셔너리로 집계합니다. setdefault() 또는 get()을 활용합니다.

stats = {} for info in phonebook.values(): g = info["group"] stats[g] = stats.get(g, 0) + 1 print(stats) # {"친구": 2, "가족": 1, ...}

핵심 요약

핵심 요약

  • 중첩 딕셔너리: phonebook[name] = {"phone": ..., "group": ...} 구조로 여러 정보를 하나의 값에 저장합니다.
  • 키 존재 확인: if name in phonebook으로 중복 추가나 없는 키 접근을 방지합니다.
  • items() 순회: for name, info in phonebook.items()로 키와 값을 동시에 꺼냅니다.
  • json.dump(): ensure_ascii=False로 한글을 깨지지 않게 JSON 파일에 저장합니다.
  • json.load(): JSON 파일을 파이썬 딕셔너리로 복원합니다. 파일이 없으면 FileNotFoundError 예외 처리합니다.
  • 메뉴 CLI: while True + input() + if/elif/else로 사용자 선택 기반 루프를 구현합니다.
  • 딕셔너리 컴프리헨션: {k:v for k,v in items() if 조건}으로 그룹 필터링 등 조건부 생성을 합니다.
