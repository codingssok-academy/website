L3 — Unit 29

2차원 리스트:
표와 격자

리스트 안에 리스트를 넣어 행과 열로 이루어진 2차원 데이터를 다룹니다.

이 유닛에서 배우는 것

  • 2차원 리스트를 생성하고 matrix[행][열]로 접근할 수 있습니다.
  • 이중 for문으로 모든 원소를 순회할 수 있습니다.
  • 성적표, 좌석 배치도, 틱택토 보드를 2차원 리스트로 표현할 수 있습니다.
  • 행 합계와 열 합계를 계산하는 코드를 작성할 수 있습니다.

2차원 리스트란?

파이썬에서 리스트 안에 또 다른 리스트를 넣으면 2차원 리스트가 됩니다. 행(가로줄)과 열(세로줄)로 이루어진 표나 격자 구조를 표현하는 데 사용합니다.

기본 생성 문법

# 3행 3열 행렬 matrix = [[1, 2, 3], [4, 5, 6], [7, 8, 9]] print(matrix) # [[1, 2, 3], [4, 5, 6], [7, 8, 9]] print(matrix[0]) # [1, 2, 3] → 첫 번째 행 전체 print(matrix[1][2]) # 6 → 1행 2열의 값

리스트의 각 원소가 다시 리스트이기 때문에 matrix[행]으로 한 행 전체를, matrix[행][열]으로 개별 값을 꺼냅니다.

값 변경

matrix[0][0] = 99 # 0행 0열을 99로 변경 print(matrix[0]) # [99, 2, 3]
따라해보세요 1 — 2차원 리스트 만들기
STEP 1
3x3 행렬을 만들고 각 위치의 값을 출력합니다.
grid = [[1, 2, 3], [4, 5, 6], [7, 8, 9]] print("0행 1열:", grid[0][1]) # 2 print("2행 0열:", grid[2][0]) # 7 print("1행 전체:", grid[1]) # [4, 5, 6]
0행 1열: 2 / 2행 0열: 7 / 1행 전체: [4, 5, 6]
STEP 2
중앙값(1행 1열)을 0으로 바꾸고 확인합니다.
grid[1][1] = 0 print(grid[1]) # [4, 0, 6]
출력: [4, 0, 6]

인덱스 [행][열] 매핑과 이중 for문

이중 for문으로 전체 순회

2차원 리스트의 모든 원소를 방문하려면 for문 안에 또 다른 for문을 씁니다. 바깥 루프는 행, 안쪽 루프는 열을 담당합니다.

matrix = [[1, 2, 3], [4, 5, 6]] for row in matrix: # row = 각 행 리스트 for value in row: # value = 개별 원소 print(value, end=" ") print() # 행 끝에서 줄바꿈
1 2 3
4 5 6

range()를 사용한 인덱스 기반 이중 for문도 자주 씁니다.

for i in range(len(matrix)): # i = 행 인덱스 for j in range(len(matrix[i])): # j = 열 인덱스 print(f"[{i}][{j}]=", matrix[i][j], end=" ") print()
[0][0]= 1 [0][1]= 2 [0][2]= 3
[1][0]= 4 [1][1]= 5 [1][2]= 6

실용 예 1 — 성적표

2차원 리스트로 학생별 과목 성적을 저장합니다. 행은 학생, 열은 과목입니다.

scores = [ [85, 92, 78], # 지수 [76, 88, 95], # 민준 [90, 84, 91], # 서아 ] names = ["지수", "민준", "서아"] subjects = ["국어", "수학", "영어"] for i, name in enumerate(names): avg = sum(scores[i]) / len(scores[i]) print(f"{name} 평균: {avg:.1f}")
지수 평균: 85.0
민준 평균: 86.3
서아 평균: 88.3
따라해보세요 2 — 성적표 출력
STEP 1
각 학생의 과목별 점수를 표 형식으로 출력합니다.
print(f"{'이름':4s} | 국어 | 수학 | 영어") print("-" * 26) for i in range(len(names)): row = scores[i] print(f"{names[i]:4s} | {row[0]:4d} | {row[1]:4d} | {row[2]:4d}")
이름 | 국어 | 수학 | 영어 (표 형식 출력)

실용 예 2 — 좌석 배치도와 틱택토 보드

좌석 배치도

seats = [ ["지수", "민준", "서아", "준호", "하은"], ["태양", "유나", "재원", "소연", "도현"], ["보미", "성우", "지아", "민서", "현준"], ] print("1행 3번 자리:", seats[0][2]) # 서아 print("3행 5번 자리:", seats[2][4]) # 현준

틱택토 보드

board = [ ["X", "O", "_"], ["_", "X", "O"], ["_", "_", "X"], ] # 보드 출력 함수 def print_board(b): for row in b: print(" | ".join(row)) print("-" * 9) print_board(board)
X | O | _
---------
_ | X | O
---------
_ | _ | X
---------
따라해보세요 3 — 좌석 배치도 출력
STEP 1
이중 for문으로 좌석 배치도를 행마다 출력합니다.
for i, row in enumerate(seats): print(f"{i+1}행:", " ".join(row))
1행: 지수 민준 서아 준호 하은 / 2행: ... / 3행: ...

행 합계와 열 합계 구하기

2차원 리스트에서 각 행의 합계(가로 합)와 각 열의 합계(세로 합)를 구하는 것은 성적 처리, 통계 등에서 자주 사용합니다.

행 합계 (가로 합)

scores = [ [85, 92, 78], # 지수 [76, 88, 95], # 민준 [90, 84, 91], # 서아 ] names = ["지수", "민준", "서아"] # 행 합계: 각 학생의 총점 for i, row in enumerate(scores): total = sum(row) print(f"{names[i]} 총점: {total}")
지수 총점: 255
민준 총점: 259
서아 총점: 265

열 합계 (세로 합)

# 열 합계: 각 과목의 총점 subjects = ["국어", "수학", "영어"] cols = len(scores[0]) for j in range(cols): col_sum = 0 for i in range(len(scores)): col_sum += scores[i][j] print(f"{subjects[j]} 총점: {col_sum}")
국어 총점: 251
수학 총점: 264
영어 총점: 264

연습 문제

Q1
2차원 리스트 접근
Easy
아래 2차원 리스트 data가 있습니다. data[2][1]의 값을 출력하고, data[0][0]을 99로 바꾼 뒤 data[0]을 출력하는 코드를 완성하세요.
data = [ [10, 20, 30], [40, 50, 60], [70, 80, 90], ] print(data[___][___]) # 80 data[___][___] = 99 print(data[___]) # [99, 20, 30]
출력 1 80
출력 2 [99, 20, 30]
내 답안
힌트 보기
data[행][열] — 행은 0부터 시작합니다. 2행 1열이면 data[2][1].
정답 보기
print(data[2][1]) # 80 data[0][0] = 99 print(data[0]) # [99, 20, 30]
Q2
이중 for문으로 곱셈표 만들기
Medium
이중 for문을 사용해 3x3 곱셈표를 2차원 리스트로 만들고, 각 행을 출력하세요. 예: table[i][j] = (i+1) * (j+1)
출력 [1, 2, 3] / [2, 4, 6] / [3, 6, 9]
내 답안
힌트 보기
빈 리스트 table = []에 각 행을 append합니다. 행을 만들 때도 빈 리스트에 append하면 됩니다.
정답 보기
table = [] for i in range(3): row = [] for j in range(3): row.append((i+1) * (j+1)) table.append(row) for row in table: print(row)
Q3
가장 높은 점수 학생 찾기
Hard
아래 성적 데이터에서 각 학생의 평균을 구하고, 평균이 가장 높은 학생의 이름과 평균을 출력하세요.
scores = [[85, 92, 78], [76, 88, 95], [90, 84, 91]] names = ["지수", "민준", "서아"]
출력 최고 평균: 서아 (88.3)
내 답안
힌트 보기
최대 평균을 저장할 변수를 -1로 초기화하고, 각 학생의 평균과 비교해 갱신합니다.
정답 보기
best_name = "" best_avg = -1 for i in range(len(scores)): avg = sum(scores[i]) / len(scores[i]) if avg > best_avg: best_avg = avg best_name = names[i] print(f"최고 평균: {best_name} ({best_avg:.1f})")

핵심 정리

항목 문법 설명
생성 matrix = [[1,2],[3,4]] 리스트 안에 리스트를 넣음
행 접근 matrix[i] i번째 행 전체를 리스트로 반환
원소 접근 matrix[i][j] i행 j열의 값
값 변경 matrix[i][j] = 값 해당 위치 값을 변경
전체 순회 for row in matrix: for v in row: 이중 for문으로 모든 원소 방문
행 합계 sum(matrix[i]) i번째 행의 원소 합
열 합계 sum(matrix[i][j] for i in range(...)) j번째 열의 원소 합

이 유닛에서 배운 것

  • 2차원 리스트는 리스트 안의 리스트로 행과 열이 있는 표 구조를 만듭니다.
  • matrix[행][열]으로 원소에 접근하고 값을 변경할 수 있습니다.
  • 이중 for문으로 모든 원소를 행 순서대로 순회합니다.
  • 성적표, 좌석 배치도, 틱택토 보드 등 실생활 표 구조를 코드로 표현할 수 있습니다.
  • sum(row)으로 행 합계, 인덱스 기반 이중 for문으로 열 합계를 구합니다.
