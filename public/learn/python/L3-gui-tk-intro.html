1. tkinter가 뭐야?

tkinter는 파이썬에 기본 내장된 GUI(Graphical User Interface) 라이브러리예요. 별도 설치 없이 바로 쓸 수 있어요.

💡 GUI = 마우스로 클릭하고 창으로 보는 프로그램. 우리가 매일 쓰는 카카오톡, 크롬, 메모장 — 모두 GUI 앱이에요.

지금까지의 파이썬 vs GUI 파이썬

구분지금까지 (콘솔)GUI (tkinter)
입력input()입력칸 (Entry)
출력print()라벨 (Label)
실행터미널 검은 화면독립 윈도우 창
배포.py 파일 + 파이썬 설치 필요.exe 파일 더블클릭

2. 첫 윈도우 창 만들기

아래 5줄이면 진짜 윈도우 창이 뜹니다.

import tkinter as tk

window = tk.Tk()           # 창 만들기
window.title("내 첫 앱")   # 창 제목
window.geometry("400x300") # 창 크기 (가로x세로)
window.mainloop()          # 창 띄우기 (계속 실행)

줄별로 뜯어보기

1줄 — tkinter를 tk라는 짧은 이름으로 가져와요.

3줄 — tk.Tk()는 창 객체를 만들어요. window는 우리가 붙인 이름.

4줄 — title()로 창 위쪽 제목줄 텍스트를 정해요.

5줄 — geometry("400x300")로 창 크기를 픽셀 단위로 지정. 가로 400, 세로 300.

6줄 — mainloop()는 "창을 계속 띄워두고 사용자 동작을 기다려라"는 뜻이에요. 이게 없으면 창이 떴다가 즉시 닫혀요.

⚠️ mainloop()는 항상 맨 마지막에 호출! 이 줄 아래 있는 코드는 창이 닫혀야 실행돼요.

3. 창 꾸미기

창 배경색과 아이콘도 바꿀 수 있어요.

import tkinter as tk

window = tk.Tk()
window.title("코딩쏙 첫 앱 🦋")
window.geometry("500x400")
window.configure(bg="#3b82f6")  # 배경색 (파란색)
window.resizable(False, False)  # 크기 조절 잠금

window.mainloop()

주요 옵션

코드역할
configure(bg="색")배경색 (예: "white", "#ff0000")
geometry("WxH+x+y")크기 + 화면상 위치 (예: "400x300+100+50")
resizable(가로, 세로)크기 조절 가능 여부 (True/False)
iconbitmap("파일.ico")창 아이콘 변경

🎨 색상은 영어 이름("red", "blue") 또는 헥스코드("#3b82f6") 둘 다 사용 가능해요. 헥스코드는 더 정확한 색을 표현할 수 있어요.

4. 미션

아래 조건을 모두 만족하는 창을 만드세요.

2
크기: 가로 600 × 세로 400
3

크기 조절 불가능하게

import tkinter as tk

window = tk.Tk()

window.mainloop()
