Chapter 07

들여쓰기 -- Python의 문법 규칙

파이썬에서 들여쓰기가 왜 중요한지, 어떻게 사용하는지 배웁니다.

이 유닛에서 배우는 것

  • 파이썬에서 들여쓰기가 문법의 일부임을 이해합니다.
  • 4칸 공백이 파이썬 표준 들여쓰기임을 알 수 있습니다.
  • IndentationError가 발생하는 원인을 파악할 수 있습니다.
  • 탭과 공백의 차이를 이해하고 일관되게 사용합니다.
  • if 문에서 들여쓰기를 올바르게 작성할 수 있습니다.

들여쓰기란?

파이썬에서 들여쓰기(indentation)는 코드 블록을 구분하는 문법 규칙입니다. 다른 언어에서는 중괄호 {}를 사용하지만, 파이썬은 들여쓰기로 코드의 구조를 나타냅니다.

파이썬 공식 스타일 가이드(PEP 8)에서는 공백 4칸을 들여쓰기 표준으로 권장합니다.

따라해보세요
1
if 문과 들여쓰기를 처음 사용해보세요. if True:는 항상 실행됩니다.
if True: print("들여쓰기 성공!")
들여쓰기 성공! 이 출력되면 OK
2
들여쓰기된 줄을 여러 개 작성해보세요.
if True: print("첫째 줄") print("둘째 줄") print("셋째 줄")
3줄 모두 출력됩니다 (같은 블록)
3
들여쓰기 바깥의 코드는 if와 관계없이 항상 실행됩니다. if False:로 확인해보세요.
if False: print("실행 안 됨") print("항상 실행됨")
항상 실행됨 만 출력 (if False이므로 블록 건너뜀)

IndentationError -- 들여쓰기 오류

파이썬에서 들여쓰기를 잘못하면 IndentationError가 발생합니다. 가장 흔한 실수를 직접 체험해봅시다.

따라해보세요
1
일부러 들여쓰기를 빼고 에러를 확인하세요.
if True: print("에러 발생!") # 들여쓰기 없음
IndentationError: expected an indented block 발생
2
같은 블록에서 들여쓰기 칸 수를 다르게 해보세요.
if True: print("4칸") print("6칸") # 칸 수 불일치
IndentationError: unexpected indent 발생
3
올바르게 수정하여 정상 실행되게 만들어보세요.
if True: print("4칸") print("4칸") # 같은 칸 수로 통일!
4칸 / 4칸 이 정상 출력됩니다

탭 vs 공백

키보드의 Tab 키를 누르면 탭 문자가 입력됩니다. 스페이스바를 4번 누르면 공백 4개가 입력됩니다. 둘은 화면에서 비슷해 보이지만, 파이썬은 이 둘을 다른 것으로 인식합니다.

대부분의 코드 에디터(VS Code 등)는 Tab 키를 누르면 자동으로 공백 4칸으로 변환해줍니다. 이 설정을 사용하면 혼용 문제를 예방할 수 있습니다.

출력Hello

if True: print("Hello")

코드if True:
print("A")
출력A
내 답안
힌트 보기
print("A") 앞에 들여쓰기(공백 4칸)가 필요합니다.
정답 확인

Q3
블록 안팎 구분
보통
if False: 블록 안에 print("안녕")을, 블록 바깥에 print("끝")을 작성하여 끝만 출력되게 하세요.
출력끝
내 답안
힌트 보기
if False:의 블록(들여쓰기)은 실행되지 않고, 들여쓰기 없는 줄은 항상 실행됩니다.
정답 확인
if False: print("안녕") print("끝")

핵심 요약

이 유닛에서 배운 것

  • 파이썬에서 들여쓰기는 코드 블록을 구분하는 문법 규칙이다
  • 공백 4칸이 파이썬 표준 들여쓰기이다 (PEP 8)
  • 같은 블록의 코드는 반드시 같은 칸 수로 들여쓰기해야 한다
  • 들여쓰기가 잘못되면 IndentationError가 발생한다
  • 탭과 공백을 섞어 쓰면 안 된다 -- 공백 4칸으로 통일
