Hello, World!

print() 함수로 화면에 원하는 내용을 출력하는 방법을 배웁니다.

이 유닛에서 배우는 것

  • print() 함수로 문자열을 출력할 수 있습니다.
  • 작은따옴표와 큰따옴표의 차이를 설명할 수 있습니다.
  • 여러 값을 쉼표(,)로 구분하여 출력할 수 있습니다.
  • sep와 end 매개변수를 사용할 수 있습니다.
  • 이스케이프 문자(\n, \t, \\)를 사용할 수 있습니다.

print() 함수

print()는 화면에 글자를 출력하는 함수입니다. 괄호 안에 따옴표로 감싼 텍스트를 넣으세요.

따라해보세요
1
아래 코드를 그대로 입력하고 실행하세요.
print("Hello, Python!")
Hello, Python! 이 출력되면 성공
2
따옴표 안의 내용을 바꿔보세요.
print("나는 파이썬을 배우고 있어요")
따옴표 안 내용이 그대로 출력됩니다
3
쉼표로 여러 값을 출력해보세요.
print("안녕", "세상", 2026)
안녕 세상 2026 — 쉼표 사이에 자동 공백

파이썬에서 문자열은 큰따옴표와 작은따옴표 둘 다 사용할 수 있습니다.

이스케이프 문자

\n은 줄바꿈, \t는 탭입니다. 하나의 print()로 여러 줄을 출력할 수 있습니다.

따라해보세요
1
\n으로 줄바꿈을 만들어보세요.
print("첫째 줄\n둘째 줄\n셋째 줄")
3줄로 나눠서 출력됩니다
2
\t로 칸을 맞춰보세요.
print("이름\t점수") print("민수\t95") print("서연\t88")
탭으로 깔끔하게 정렬됩니다
3
따옴표 안에 따옴표를 넣어보세요.
print("파이썬이 말했다: \"안녕!\"")
\" 로 따옴표를 출력할 수 있습니다

sep과 end — 출력 방식 바꾸기

sep은 값 사이의 구분자를 바꿉니다. 기본값은 공백입니다.

end는 출력 끝의 문자를 바꿉니다. 기본값은 줄바꿈(\n)입니다.

따라해보세요
1
sep으로 구분자를 바꿔보세요.
print("2025", "03", "19", sep="-")
2025-03-19 — 공백 대신 하이픈
2
end로 줄바꿈을 없애보세요.
print("Hello", end=" ") print("World")
Hello World — 두 print가 한 줄에
3
둘 다 같이 써보세요.
print("A", "B", "C", sep="/", end="!\n")
A/B/C! — 슬래시 구분 + 느낌표 끝

핵심 요약

이 유닛에서 배운 것

  • print("내용")으로 화면에 출력한다
  • 큰따옴표(" ")와 작은따옴표(' ') 모두 사용 가능
  • 쉼표(,)로 여러 값을 구분하면 공백이 자동 삽입됨
  • sep으로 구분자 변경, end로 줄바꿈 변경
  • \n(줄바꿈), \t(탭), \\(역슬래시) 이스케이프 문자
