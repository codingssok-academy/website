Chapter 05

프로젝트: 자기소개 프로그램

print()와 문자열 반복(*)을 활용하여 나만의 자기소개 프로그램을 만듭니다.

이 유닛에서 배우는 것

  • 문자열 반복 연산자(*)를 사용하여 패턴을 만들 수 있습니다.
  • IPO(입력-처리-출력) 모델로 프로그램을 설계할 수 있습니다.
  • ASCII 아트를 활용한 텍스트 그림을 만들 수 있습니다.
  • 줄 구분선, 빈 줄 등 꾸미기 기법을 적용할 수 있습니다.
  • print()만으로 완성도 있는 자기소개 프로그램을 만들 수 있습니다.

문자열 반복 — * 연산자

문자열에 *를 사용하면 같은 텍스트를 여러 번 반복할 수 있습니다. 구분선이나 패턴을 만들 때 매우 유용합니다.

따라해보세요
1
별표로 구분선을 만들어보세요.
print("*" * 30)
****************************** 이 출력됩니다
2
두 글자 패턴을 반복해보세요.
print("=-" * 15)
=-=-=-=-=-=-=-=-=-=-=-=-=-=-=- 물결 패턴 완성
3
반복과 일반 문자열을 합쳐보세요.
print("+" * 20) print(" 나의 자기소개") print("+" * 20)
구분선 사이에 제목이 표시됩니다

자기소개 설계 — IPO 모델

프로그램을 만들기 전에 먼저 설계합니다. IPO 모델은 입력(Input), 처리(Process), 출력(Output)의 3단계로 프로그램을 정리하는 방법입니다.

따라해보세요
1
가장 기본적인 자기소개를 만들어보세요.
print("이름: 홍길동") print("나이: 14살") print("취미: 코딩")
3줄로 기본 정보가 출력됩니다
2
구분선을 추가해보세요.
print("=" * 20) print(" 이름: 홍길동") print(" 나이: 14살") print("=" * 20)
구분선 안에 정보가 깔끔하게 들어갑니다
3
제목과 인사말도 추가해보세요.
print("=" * 24) print(" [ 자기소개 카드 ]") print("=" * 24) print(" 이름: 홍길동") print(" 나이: 14살") print(" 취미: 코딩") print(" 꿈: 프로그래머") print("=" * 24) print("반갑습니다!")
제목 + 정보 + 인사가 포함된 완성형 자기소개

ASCII 아트

키보드 문자만으로 그림을 만드는 것을 ASCII 아트라고 합니다. 자기소개에 넣으면 개성이 살아납니다.

따라해보세요
1
고양이 얼굴을 출력해보세요.
print(" /\\_/\\") print("( o.o )") print(" > ^ <")
고양이 얼굴이 3줄로 출력됩니다
2
별 모양 삼각형을 만들어보세요.
print(" *") print(" ***") print("*****")
위에서 아래로 점점 넓어지는 삼각형
3
이름표를 ASCII 아트로 만들어보세요.
print("+----------+") print("| 홍길동 |") print("+----------+")
상자 안에 이름이 들어간 이름표 완성

꾸미기 기법

구분선, 빈 줄, 들여쓰기를 조합하면 출력이 훨씬 보기 좋아집니다. 아래 기법들을 자기소개에 적용해보세요.

따라해보세요
1
빈 줄로 섹션을 나눠보세요.
print("이름: 홍길동") print() print("취미: 코딩")
이름과 취미 사이에 빈 줄이 생깁니다
2
두 종류의 구분선을 사용해보세요.
print("=" * 24) print(" [ 자기소개 카드 ]") print("-" * 24) print(" 이름: 홍길동") print("=" * 24)
=는 바깥선, -는 안쪽 구분선으로 사용
3
ASCII 아트 + 꾸미기로 완성형 자기소개를 만들어보세요.
print("=" * 26) print(" [ 나를 소개합니다 ]") print("=" * 26) print(" 이름: 홍길동") print(" 나이: 14살") print(" 취미: 코딩") print(" 꿈 : 프로그래머") print("-" * 26) print(" /\\_/\\") print(" ( o.o ) 반갑습니다!") print(" > ^ <") print("=" * 26)
구분선 + 정보 + ASCII 아트가 결합된 자기소개

핵심 요약

이 유닛에서 배운 것

  • "문자" * n으로 문자열을 원하는 횟수만큼 반복할 수 있다
  • IPO 모델(입력-처리-출력)로 프로그램을 미리 설계한다
  • 키보드 특수문자로 ASCII 아트를 만들 수 있다
  • 구분선("=" * n), 빈 줄(print()), 들여쓰기로 출력을 꾸민다
  • print()만으로 완성도 있는 자기소개 프로그램을 만들 수 있다
