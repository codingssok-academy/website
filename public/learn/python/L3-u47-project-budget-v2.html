Step 1 — try/except로 안전한 입력 받기

가계부에서 금액을 입력받을 때, 사용자가 숫자 대신 문자를 입력하면 프로그램이 멈춥니다. try/except로 이를 막아야 합니다.

# Step 1: 안전한 금액 입력 함수 def get_amount(): """금액을 정수로 입력받는다. 실패하면 None 반환.""" try: text = input("금액(원): ") amount = int(text) # 문자면 ValueError 발생 if amount <= 0: print("0보다 큰 금액을 입력하세요.") return None return amount except ValueError: print("숫자만 입력할 수 있습니다.") return None # 안전한 분류 입력 (수입/지출) def get_category(): """'수입' 또는 '지출'만 허용.""" valid = ["수입", "지출"] text = input("분류 (수입/지출): ").strip() if text not in valid: print(f"'{text}'은 올바른 분류가 아닙니다. 수입 또는 지출을 입력하세요.") return None return text

try 블록 안에서 오류가 생기면 즉시 except로 이동합니다. ValueError는 "숫자여야 하는데 문자가 왔을 때" 발생하는 오류입니다.

Step 2 — with문으로 CSV 파일에 저장하기

with open()은 파일을 열고 작업이 끝나면 자동으로 닫습니다. csv.writer를 함께 사용하면 쉼표로 구분된 파일을 쉽게 만들 수 있습니다.

import csv # Step 2: CSV에 거래 저장 def save_record(filename, record): """record = [날짜, 분류, 설명, 금액] 리스트.""" # mode='a' → 이어쓰기, newline='' → 빈 줄 방지 with open(filename, mode='a', newline='', encoding='utf-8') as f: writer = csv.writer(f) writer.writerow(record) # 한 줄 쓰기 # 헤더 생성 (처음 한 번만) def init_file(filename): """CSV 헤더 행 생성.""" with open(filename, mode='w', newline='', encoding='utf-8') as f: writer = csv.writer(f) writer.writerow(["날짜", "분류", "설명", "금액"]) # 사용 예시 init_file("budget.csv") save_record("budget.csv", ["2024-03", "수입", "용돈", 50000]) save_record("budget.csv", ["2024-03", "지출", "점심식비", 8000])

mode='a'는 파일 끝에 이어서 씁니다(append). 파일이 없으면 자동으로 만들어집니다. newline=''은 Windows에서 빈 줄이 생기는 현상을 막습니다.

모드의미파일 없을 때기존 내용
'w'쓰기(덮어쓰기)새로 생성삭제
'a'이어쓰기(append)새로 생성유지
'r'읽기오류 발생유지

Step 3 — CSV 불러오기와 월별 합계

csv.reader로 저장된 파일을 읽고, 딕셔너리를 이용해 월별 수입·지출 합계를 계산합니다.

import csv # Step 3: CSV 읽어서 월별 합계 계산 def load_records(filename): """CSV에서 모든 거래 내역 읽기.""" records = [] try: with open(filename, encoding='utf-8') as f: reader = csv.reader(f) next(reader) # 헤더 행 건너뛰기 for row in reader: if len(row) == 4: # 열이 4개인 행만 records.append(row) except FileNotFoundError: print("저장된 가계부가 없습니다.") return records def monthly_summary(records): """월별 수입/지출 합계를 딕셔너리로 반환.""" summary = {} # {"2024-03": {"수입": 0, "지출": 0}} for row in records: month, category, _, amount_str = row amount = int(amount_str) if month not in summary: summary[month] = {"수입": 0, "지출": 0} summary[month][category] += amount return summary # 결과 출력 records = load_records("budget.csv") summary = monthly_summary(records) for month, data in sorted(summary.items()): income = data["수입"] expense = data["지출"] balance = income - expense print(f"{month} 수입:{income:,} 지출:{expense:,} 잔액:{balance:,}")
2024-03 수입:50,000 지출:8,000 잔액:42,000 2024-04 수입:50,000 지출:32,000 잔액:18,000

next(reader)는 헤더 행을 한 번 읽어서 건너뜁니다. FileNotFoundError는 파일이 없을 때 발생하는 예외입니다.

def top_expense_month(records): expense_by_month = {} for row in records: month, category, _, amount_str = row if category == "지출": expense_by_month[month] = expense_by_month.get(month, 0) + int(amount_str) if not expense_by_month: print("지출 데이터 없음") return top = max(expense_by_month, key=expense_by_month.get) print(f"지출 최다: {top} ({expense_by_month[top]:,}원)")

핵심 요약

try/except 예외처리

  • try 블록 안에서 오류가 발생하면 즉시 except로 이동한다.
  • ValueError: 잘못된 형식(문자 → 정수 변환 실패 등).
  • FileNotFoundError: 존재하지 않는 파일을 열려 할 때 발생.
  • 오류가 없으면 except 블록은 실행되지 않는다.

with문으로 파일 관리

  • with open(filename, mode, newline, encoding) as f: — 블록이 끝나면 자동으로 파일 닫힘.
  • mode='w': 덮어쓰기 / 'a': 이어쓰기 / 'r': 읽기.
  • Windows에서 CSV 저장 시 newline='' 필수 (빈 줄 방지).

csv 모듈

  • csv.writer(f).writerow(list): 리스트를 쉼표 구분 한 줄로 저장.
  • csv.reader(f): 각 행을 리스트로 읽음.
  • next(reader): 헤더 행 건너뛰기.

월별 집계 패턴

  • 딕셔너리 키에 월을 저장하고 값에 금액을 누적한다.
  • d.get(key, 0): 키가 없을 때 0을 기본값으로 사용.
  • max(d, key=d.get): 딕셔너리에서 최댓값을 가진 키 반환.
