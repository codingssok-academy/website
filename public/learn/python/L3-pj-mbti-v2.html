프로젝트:
MBTI 테스트 만들기

딕셔너리, 리스트, 조건문, 함수를 조합해 실제 MBTI 테스트처럼 작동하는 파이썬 프로그램을 만듭니다. 질문에 답하면 E/I, S/N, T/F, J/P를 자동으로 계산해 16가지 유형 중 하나를 출력합니다.

이 유닛에서 만드는 것

  • 질문 리스트와 딕셔너리로 MBTI 질문 데이터를 구조화할 수 있습니다.
  • input()으로 사용자 답변을 받아 E/I, S/N, T/F, J/P 점수를 누적할 수 있습니다.
  • 조건문으로 4개 축의 최종 유형 문자를 결정할 수 있습니다.
  • 문자열 결합으로 16가지 MBTI 코드를 만들 수 있습니다.
  • 딕셔너리로 16가지 유형별 설명을 저장하고 조회할 수 있습니다.
  • 함수로 각 단계를 분리해 mbti_test.py를 완성할 수 있습니다.

Step 1 — 질문 데이터 설계

MBTI 테스트의 핵심은 질문 데이터를 어떻게 저장하느냐입니다. 각 질문은 어떤 축(E/I, S/N, T/F, J/P)을 측정하는지, 어떤 답변이 어떤 유형을 가리키는지를 함께 저장해야 합니다.

# mbti_test.py — Step 1: 질문 데이터 정의 questions = [ { "text": "파티에서 에너지가 충전된다 vs 혼자 있을 때 충전된다", "axis": "EI", "a_type": "E", "b_type": "I" }, { "text": "사실과 경험을 믿는다 vs 가능성과 상상을 믿는다", "axis": "SN", "a_type": "S", "b_type": "N" }, { "text": "논리적으로 판단한다 vs 감정으로 판단한다", "axis": "TF", "a_type": "T", "b_type": "F" }, { "text": "계획을 세우는 게 편하다 vs 즉흥적인 게 편하다", "axis": "JP", "a_type": "J", "b_type": "P" }, ] print(f"총 {len(questions)}개 질문 로드됨")

점수 딕셔너리 초기화

4개 축 각각에서 두 유형 중 어느 쪽이 더 많이 나왔는지 세기 위해 딕셔너리로 카운터를 만듭니다.

# 점수 카운터 초기화 scores = { "E": 0, "I": 0, "S": 0, "N": 0, "T": 0, "F": 0, "J": 0, "P": 0 }
따라해보세요 — Step 1
1
questions 리스트를 입력하고 첫 번째 질문의 "text"를 출력하세요.
print(questions[0]["text"])
파티에서 에너지가 충전된다 vs 혼자 있을 때 충전된다
2
for 문으로 모든 질문의 axis 값만 출력하세요.
for q in questions: print(q["axis"])
EI / SN / TF / JP 순서로 출력
3
scores 딕셔너리에서 "E" 키의 값을 1 증가시키고 출력하세요.
scores["E"] += 1 print(scores["E"])
1

Step 2 — 질문 루프와 점수 누적

for 문으로 모든 질문을 순서대로 출력하고, 사용자가 a 또는 b를 입력하면 해당 유형의 점수를 1씩 올립니다.

# Step 2: 질문 루프 print("=== MBTI 테스트 시작 ===") print("a 또는 b를 입력하세요\n") for i, q in enumerate(questions, 1): print(f"Q{i}. {q['text']}") print(" a) 첫 번째 b) 두 번째") answer = input("선택 (a/b): ").strip().lower() if answer == "a": chosen = q["a_type"] else: chosen = q["b_type"] scores[chosen] += 1 print(f" → {chosen} +1\n")

Step 3 — 4개 축별 유형 결정

각 축에서 점수가 높은 쪽이 그 축의 유형이 됩니다. 점수가 같으면 첫 번째 문자(예: E)를 기본으로 선택합니다. 파이썬의 조건 표현식 a if 조건 else b를 쓰면 if/else를 한 줄로 쓸 수 있습니다.

# Step 3: 4개 축 유형 결정 def get_type(a, b): """점수 비교 후 유형 문자 반환""" return a if scores[a] >= scores[b] else b ei = get_type("E", "I") sn = get_type("S", "N") tf = get_type("T", "F") jp = get_type("J", "P") result = ei + sn + tf + jp print(f"\n당신의 MBTI: {result}")
Q1. 파티에서 에너지가 충전된다 vs 혼자 있을 때 충전된다 a) 첫 번째 b) 두 번째 선택 (a/b): a → E +1 당신의 MBTI: ENTP

Step 4 — 16가지 유형 설명 딕셔너리

딕셔너리 키를 MBTI 코드(문자열)로, 값을 유형 설명으로 저장하면 결과를 바로 조회할 수 있습니다.

# Step 4: 유형별 설명 딕셔너리 (16가지) descriptions = { "INTJ": "전략가 — 논리적이고 계획적인 완벽주의자.", "INTP": "논리술사 — 지식 탐구를 즐기는 이론가.", "ENTJ": "통솔자 — 타고난 리더십으로 목표를 달성합니다.", "ENTP": "변론가 — 논리적이고 창의적인 아이디어뱅크.", "INFJ": "옹호자 — 조용하고 신비롭지만 강한 원칙을 가짐.", "INFP": "중재자 — 이상주의적이고 공감 능력이 뛰어납니다.", "ENFJ": "주인공 — 카리스마 있는 사람 중심의 리더.", "ENFP": "활동가 — 열정적이고 창의적인 자유로운 영혼.", "ISTJ": "현실주의자 — 신뢰할 수 있고 철저한 사실주의자.", "ISFJ": "수호자 — 헌신적이고 따뜻한 보호자.", "ESTJ": "관리자 — 사실에 근거한 강력한 행정가.", "ESFJ": "집정관 — 사교적이고 배려심 깊은 협력자.", "ISTP": "장인 — 대담하고 실용적인 실험가.", "ISFP": "모험가 — 유연하고 매력적인 예술가.", "ESTP": "사업가 — 영리하고 에너지 넘치는 행동파.", "ESFP": "연예인 — 자발적이고 활기차며 끼가 넘칩니다.", } # 최종 출력 print(f"\n===== 결과 =====") print(f"당신의 MBTI: {result}") print(f"유형: {descriptions[result]}")
===== 결과 ===== 당신의 MBTI: ENTP 유형: 변론가 — 논리적이고 창의적인 아이디어뱅크.
Q1
questions 리스트에서 axis가 "TF"인 질문의 index를 찾으세요.
보통
for 문과 enumerate()를 사용해 questions 리스트를 순회하면서 axis가 "TF"인 항목의 인덱스를 출력하세요.
출력 index 2: 논리적으로 판단한다 vs 감정으로 판단한다
힌트 보기
enumerate(questions, 0)으로 인덱스와 함께 순회하고, q["axis"] == "TF" 조건으로 필터링하세요.
정답 보기
for i, q in enumerate(questions): if q["axis"] == "TF": print(f"index {i}: {q['text']}")

연습 문제

Q2
get_type() 함수를 수정해 동점이면 "?" 반환
보통
현재 get_type()는 동점이면 첫 번째 유형을 반환합니다. 동점인 경우 "?"를 반환하도록 수정하세요. 예: scores["T"]==2, scores["F"]==2 이면 "?" 반환.
입력 scores["T"]=2, scores["F"]=2
출력 TF축: ?
힌트 보기
scores[a] == scores[b] 조건을 먼저 체크하고 "?"를 반환하세요.
정답 보기
def get_type(a, b): if scores[a] == scores[b]: return "?" return a if scores[a] > scores[b] else b
Q3
MBTI 결과와 점수를 함께 포맷팅 출력
심화
f-string을 사용해 아래 형식으로 최종 결과를 출력하는 print_result() 함수를 만드세요. scores 딕셔너리와 result 변수를 활용합니다. 배운 조건 표현식을 활용하면 한 줄로 분기할 수 있습니다.
출력 ENTP | E:3 I:1 | S:1 N:3 | T:2 F:2 | J:0 P:4
힌트 보기
f-string 안에 scores["E"], scores["I"] 등을 직접 넣어서 조합하세요.
정답 보기
def print_result(): s = scores print(f"{result} | E:{s['E']} I:{s['I']} | S:{s['S']} N:{s['N']} | T:{s['T']} F:{s['F']} | J:{s['J']} P:{s['P']}")

핵심 요약

  • 딕셔너리 안에 딕셔너리를 넣어 복잡한 데이터를 구조화할 수 있습니다.
  • enumerate()로 인덱스와 값을 동시에 순회할 수 있습니다.
  • 조건 연산자 a if 조건 else b로 한 줄 분기가 가능합니다.
  • 문자열 결합 ei + sn + tf + jp로 MBTI 코드를 만들 수 있습니다.
  • 딕셔너리 키로 문자열을 사용하면 유형 설명을 O(1)로 조회할 수 있습니다.
