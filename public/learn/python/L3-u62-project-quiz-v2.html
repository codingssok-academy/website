Step 2 — CSV 파일 로드 + 랜덤 출제

CSV 형식은 스프레드시트(엑셀 등)에서 편집하기 좋습니다. csv.DictReader를 쓰면 첫 줄 헤더를 키로 자동 매핑해 딕셔너리 리스트로 읽을 수 있습니다.

CSV 로드 함수

import csv def load_questions_csv(filepath): """CSV 파일에서 문제 리스트를 읽어 반환""" questions = [] with open(filepath, "r", encoding="utf-8") as f: reader = csv.DictReader(f) for row in reader: questions.append(dict(row)) return questions

랜덤 출제 — random.shuffle

random.shuffle(list)는 리스트를 제자리에서(in-place) 무작위로 섞습니다. 원본 리스트가 바뀌므로, 원본을 보존하려면 copy()로 복사 후 섞어야 합니다.

import random def get_random_questions(questions, count=5): """문제를 랜덤하게 섞어 count개 반환""" pool = questions.copy() # 원본 보존 random.shuffle(pool) return pool[:count] # 앞에서 count개 # 5문제 랜덤 추출 quiz = get_random_questions(questions, 5) print(f"출제 문제 수: {len(quiz)}")

Step 3 — 정답 체크 + 점수 기록

사용자 입력을 정답과 비교할 때, 대소문자 차이와 공백을 무시하도록 .strip().lower()로 정규화합니다. 점수와 시간은 딕셔너리에 담아 JSON으로 저장합니다.

정답 체크 함수

def check_answer(user_input, correct_answer): """대소문자·공백 무시하고 정답 비교""" user = user_input.strip().lower() correct = correct_answer.strip().lower() return user == correct

점수 기록 + JSON 저장

import json from datetime import datetime def save_score(name, score, total, filepath="scores.json"): """점수 기록을 scores.json에 추가 저장""" # 기존 데이터 읽기 (없으면 빈 리스트) try: with open(filepath, "r", encoding="utf-8") as f: records = json.load(f) except FileNotFoundError: records = [] # 새 기록 추가 records.append({ "name": name, "score": score, "total": total, "percent": round(score / total * 100, 1), "date": datetime.now().strftime("%Y-%m-%d %H:%M") }) # 저장 with open(filepath, "w", encoding="utf-8") as f: json.dump(records, f, ensure_ascii=False, indent=2) print(f"점수 저장 완료: {score}/{total}")

def save_wrong_note(question_dict, user_answer, filepath="wrong_notes.json"): """틀린 문제를 오답 노트 파일에 추가""" try: with open(filepath, "r", encoding="utf-8") as f: notes = json.load(f) except FileNotFoundError: notes = [] notes.append({ "question": question_dict["question"], "correct": question_dict["answer"], "my_answer": user_answer, "level": question_dict["level"] }) with open(filepath, "w", encoding="utf-8") as f: json.dump(notes, f, ensure_ascii=False, indent=2)

난이도 필터링

리스트 컴프리헨션으로 level 키가 일치하는 문제만 걸러냅니다. level 값이 없는 문항은 get()으로 안전하게 처리합니다.

def filter_by_level(questions, level): """난이도(level)로 문제 필터링. level이 없으면 전체 반환""" if level is None: return questions return [q for q in questions if q.get("level") == level] # 사용 예 easy_qs = filter_by_level(questions, "easy") hard_qs = filter_by_level(questions, "hard") all_qs = filter_by_level(questions, None) print(f"쉬움: {len(easy_qs)}개, 어려움: {len(hard_qs)}개")

핵심 요약

  • json.load(f) — 파일 객체를 받아 Python 객체(리스트/딕셔너리)로 변환
  • json.dump(data, f, ensure_ascii=False, indent=2) — Python 객체를 JSON 파일로 저장
  • csv.DictReader(f) — CSV 첫 줄을 헤더로 쓰고, 각 행을 딕셔너리로 변환
  • random.shuffle(lst) — 리스트를 제자리에서 섞음 (반환값 없음)
  • str.strip().lower() — 공백 제거 + 소문자 변환으로 입력 정규화
  • 파일 읽기 시 try/except FileNotFoundError로 파일 없음 예외를 처리
  • 리스트 컴프리헨션 [q for q in qs if q.get("level") == lv]로 난이도 필터링
  • 오답 노트: 틀린 문제를 JSON에 누적 저장해 복습 시 재활용 가능
