프로젝트:
일기장 프로그램

파일 입출력과 예외 처리를 활용하여 날짜별 일기를 작성하고 검색하는 CLI 일기장을 완성합니다. append 모드로 데이터를 누적하고, try/except로 안전하게 처리합니다.

이 유닛에서 만드는 것

  • 파일을 append 모드로 열어 기존 내용을 지우지 않고 일기를 추가할 수 있습니다.
  • 날짜를 기준으로 특정 일기를 검색하고 출력할 수 있습니다.
  • 키워드가 포함된 일기를 전부 찾아 출력하는 검색 기능을 구현할 수 있습니다.
  • 전체 일기 목록(날짜 목록)을 출력할 수 있습니다.
  • try/except FileNotFoundError로 파일이 없을 때 안전하게 처리할 수 있습니다.
  • 메뉴 루프로 사용자가 원하는 기능을 반복 선택할 수 있습니다.

Step 1 — 파일 구조 설계와 append 모드

일기장 데이터는 diary.txt 파일 한 개에 모두 저장합니다. 날짜와 내용을 구분자로 나누어 한 줄씩 기록합니다.

구분자로 |를 사용하면 line.split("|", 1)으로 날짜와 내용을 쉽게 분리할 수 있습니다. maxsplit=1을 주면 내용 안에 |가 있어도 안전합니다.

일기 쓰기 함수

def write_diary(date, content, filename="diary.txt"): """날짜와 내용을 파일에 append로 저장""" with open(filename, "a", encoding="utf-8") as f: f.write(f"{date}|{content}\n") print(f"[{date}] 일기가 저장되었습니다.") # 테스트 write_diary("2025-03-01", "파이썬 파일 입출력을 배웠다.") write_diary("2025-03-02", "학교 발표를 잘 마쳤다.")
[2025-03-01] 일기가 저장되었습니다. [2025-03-02] 일기가 저장되었습니다.

with 문을 사용하면 파일을 자동으로 닫아줍니다. f.write()에 \n을 붙여야 줄이 분리됩니다.

Step 2 — 날짜별 일기 읽기와 try/except

파일을 읽을 때는 "r" 모드를 사용합니다. 파일이 없는 경우 FileNotFoundError가 발생하므로 try/except로 처리합니다.

날짜로 특정 일기 읽기

def read_by_date(target_date, filename="diary.txt"): """특정 날짜의 일기를 출력""" try: with open(filename, "r", encoding="utf-8") as f: lines = f.readlines() except FileNotFoundError: print("아직 일기가 없습니다.") return found = False for line in lines: line = line.strip() if "|" not in line: continue date, content = line.split("|", 1) if date == target_date: print(f"[{date}] {content}") found = True if not found: print(f"{target_date}에 해당하는 일기가 없습니다.")
read_by_date("2025-03-12") [2025-03-12] 비가 많이 왔다. read_by_date("2025-01-01") 2025-01-01에 해당하는 일기가 없습니다.

Step 3 — 키워드 검색과 목록 보기

키워드가 내용(content)에 포함된 일기를 모두 찾습니다. in 연산자로 문자열 포함 여부를 확인합니다.

키워드 검색 함수

def search_diary(keyword, filename="diary.txt"): """키워드가 포함된 일기를 모두 검색""" try: with open(filename, "r", encoding="utf-8") as f: lines = f.readlines() except FileNotFoundError: print("아직 일기가 없습니다.") return results = [] for line in lines: line = line.strip() if "|" not in line: continue date, content = line.split("|", 1) if keyword in content: results.append((date, content)) if results: print(f"'{keyword}' 검색 결과 ({len(results)}건):") for date, content in results: print(f" [{date}] {content}") else: print(f"'{keyword}'이(가) 포함된 일기가 없습니다.")
search_diary("코딩") '코딩' 검색 결과 (1건): [2025-03-13] 코딩 공부를 3시간 했다.

전체 목록 보기 함수

def list_diary(filename="diary.txt"): """저장된 모든 일기의 날짜와 앞 20자를 목록으로 출력""" try: with open(filename, "r", encoding="utf-8") as f: lines = f.readlines() except FileNotFoundError: print("아직 일기가 없습니다.") return entries = [l.strip() for l in lines if "|" in l] print(f"총 {len(entries)}개의 일기가 있습니다.") for i, line in enumerate(entries, 1): date, content = line.split("|", 1) preview = content[:20] + ("..." if len(content) > 20 else "") print(f" {i:2}. [{date}] {preview}")
총 4개의 일기가 있습니다. 1. [2025-03-11] 새로 시작! 2. [2025-03-12] 비가 많이 왔다. 3. [2025-03-13] 코딩 공부를 3시간 했다. 4. [2025-03-14] 친구와 밥을 먹었다.

Step 4 — 메뉴 통합과 최종 완성

앞서 만든 함수들을 while True 루프와 메뉴로 연결하면 완전한 CLI 일기장이 됩니다.

def main(): print("=== 나의 일기장 ===") while True: print("\n1. 일기 쓰기 2. 날짜 조회 3. 키워드 검색 4. 목록 보기 q. 종료") choice = input("선택: ").strip() if choice == "1": date = input("날짜 (YYYY-MM-DD): ").strip() content = input("내용: ").strip() write_diary(date, content) elif choice == "2": date = input("날짜 (YYYY-MM-DD): ").strip() read_by_date(date) elif choice == "3": keyword = input("검색어: ").strip() search_diary(keyword) elif choice == "4": list_diary() elif choice == "q": print("일기장을 닫습니다.") break else: print("잘못된 입력입니다.") main()
=== 나의 일기장 === 1. 일기 쓰기 2. 날짜 조회 3. 키워드 검색 4. 목록 보기 q. 종료 선택: 1 날짜 (YYYY-MM-DD): 2025-03-15 내용: 드디어 일기장을 완성했다! [2025-03-15] 일기가 저장되었습니다.

핵심 요약

  • open(파일, "a") — append 모드: 기존 내용 유지, 끝에 추가
  • open(파일, "r") — read 모드: 파일이 없으면 FileNotFoundError
  • try: ... except FileNotFoundError: — 파일 없을 때 안전하게 처리
  • f.readlines() — 파일의 모든 줄을 리스트로 반환
  • line.split("|", 1) — 첫 번째 |만 분리, 내용 안 |는 보존
  • keyword in content — 문자열 포함 여부를 True/False로 반환
  • with open(...) as f: — 블록이 끝나면 자동으로 파일 닫힘
  • 구분자를 통일하면 split으로 날짜와 내용을 항상 정확히 분리 가능
