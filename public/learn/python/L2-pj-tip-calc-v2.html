팁 계산기

식당 금액과 인원수를 입력받아 팁 포함 1인당 금액을 계산합니다.

이 프로젝트에서 배우는 것

  • 퍼센트(%) 계산을 파이썬으로 구현할 수 있습니다.
  • 여러 입력값을 조합해 최종 금액을 계산할 수 있습니다.
  • round()로 정수 단위로 반올림할 수 있습니다.
  • f-string 포맷팅으로 보기 좋은 출력을 만들 수 있습니다.
  • 실제 생활에서 쓰이는 금액 계산 프로그램을 만들 수 있습니다.

팁 계산 방법

팁은 음식값의 일정 퍼센트입니다. 예를 들어 10% 팁이라면 음식값에 0.1을 곱합니다.

파이썬에서는 퍼센트를 직접 입력받아 100으로 나누면 소수로 변환할 수 있습니다.

# 팁 계산 기본 bill = float(input("음식 금액(원): ")) tip_percent = float(input("팁 퍼센트(%): ")) tip = bill * (tip_percent / 100) total = bill + tip print(f"팁: {tip:,.0f}원") print(f"총 금액: {total:,.0f}원")
따라해보세요
1
음식값 30000원, 팁 10%로 팁 금액을 계산하세요.
bill = 30000 tip_percent = 10 tip = bill * (tip_percent / 100) print(f"팁: {tip:,.0f}원")
팁: 3,000원
2
input()으로 금액과 팁 퍼센트를 받아서 총 금액을 출력하세요.
bill = float(input("금액: ")) pct = float(input("팁%: ")) total = bill + bill * (pct / 100) print(f"총 금액: {total:,.0f}원")
50000, 10 입력 시 총 금액: 55,000원
3
팁 5%, 10%, 15%, 20% 각각의 금액을 한 번에 출력하세요.
bill = float(input("금액: ")) print(f"5%: {bill * 1.05:,.0f}원") print(f"10%: {bill * 1.1:,.0f}원") print(f"15%: {bill * 1.15:,.0f}원") print(f"20%: {bill * 1.2:,.0f}원")
50000 입력 시 네 가지 팁 옵션이 출력됩니다

인원수로 나누기

총 금액을 인원수로 나누어 1인당 금액을 계산합니다. round()로 원 단위로 깔끔하게 맞춥니다.

# 팁 계산기 + 인원 분할 bill = float(input("음식 금액(원): ")) tip_percent = float(input("팁 퍼센트(%): ")) people = int(input("인원수: ")) tip = bill * (tip_percent / 100) total = bill + tip per_person = total / people print(f"--- 계산 결과 ---") print(f"음식값: {bill:,.0f}원") print(f"팁({tip_percent}%): {tip:,.0f}원") print(f"합계: {total:,.0f}원") print(f"1인당: {round(per_person):,}원")
따라해보세요
1
75000원을 5명이 10% 팁을 포함해서 나눠 내세요.
bill = 75000 tip = bill * 0.10 total = bill + tip per = round(total / 5) print(f"1인당: {per:,}원")
1인당: 16,500원
2
input()을 활용해서 금액, 팁%, 인원을 모두 입력받아 1인당 금액을 출력하세요.
bill = float(input("금액: ")) pct = float(input("팁%: ")) n = int(input("인원: ")) total = bill * (1 + pct / 100) print(f"1인당: {round(total / n):,}원")
각자 낼 금액이 출력됩니다
3
팁 없을 때와 10% 팁 있을 때 차이를 함께 출력하세요.
bill = float(input("금액: ")) n = int(input("인원: ")) no_tip = round(bill / n) with_tip = round(bill * 1.1 / n) print(f"팁 없음: {no_tip:,}원 / 10% 팁: {with_tip:,}원")
팁 유무에 따른 차이를 한 눈에 볼 수 있습니다

핵심 요약

이 유닛에서 배운 것

  • 퍼센트 계산: bill * (percent / 100)
  • 팁 포함 금액: bill * (1 + percent / 100) 로 한 번에 계산
  • round()로 소수점 없이 정수로 반올림
  • f"{값:,.0f}"으로 천 단위 쉼표 + 소수점 없이 출력
  • int(input())으로 인원수처럼 정수가 필요한 값을 입력받는다
  • float(input())으로 금액처럼 소수점이 생길 수 있는 값을 입력받는다
