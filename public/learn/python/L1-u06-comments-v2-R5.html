주석

주석(#)으로 코드를 설명하고, 불필요한 코드를 임시로 비활성화하는 방법을 배웁니다.

이 유닛에서 배우는 것

  • #으로 한 줄 주석을 작성할 수 있습니다.
  • 코드 옆에 인라인 주석을 달 수 있습니다.
  • 주석으로 코드를 임시 비활성화(주석 처리)할 수 있습니다.
  • 좋은 주석과 나쁜 주석의 차이를 설명할 수 있습니다.
  • VS Code에서 주석 단축키를 사용할 수 있습니다.
왜 이걸 배울까? 코드는 컴퓨터뿐 아니라 사람도 읽습니다. 한 달 뒤에 자신이 쓴 코드를 다시 보면, "이게 무슨 의미였지?"라고 당황하게 됩니다. 주석은 미래의 나를 위한 메모장입니다. 팀으로 일할 때는 동료를 위한 안내판이기도 합니다.

주석이란?

주석(comment)은 코드에 남기는 메모입니다. Python은 # 뒤의 글자를 무시하고 실행하지 않습니다. 주석은 사람을 위한 것이지, 컴퓨터를 위한 것이 아닙니다.

Pythoncomment.py
1# 이것은 주석입니다. 실행되지 않습니다.
2print("Hello") # 이 부분도 주석입니다.
실행 결과
Hello
줄코드역할
1#으로 시작하는 줄 전체가 주석입니다. Python은 이 줄을 완전히 무시합니다.
2#코드 뒤에 을 쓰면 그 뒤만 주석이 됩니다. print("Hello")는 실행됩니다.

주석의 3가지 용도

1
1. 코드 설명
이 코드가 무엇을 하는지, 왜 이렇게 작성했는지 메모합니다. 다른 사람(또는 미래의 나)이 코드를 이해하는 데 도움을 줍니다.
2
2. 코드 비활성화
코드 앞에 #을 붙이면 실행되지 않습니다. 삭제하지 않고 잠시 끄고 싶을 때 사용합니다. 이것을 '주석 처리'라고 합니다.
3
3. TODO / 할 일 메모
아직 완성하지 않은 부분에 # TODO: 나중에 추가처럼 메모를 남깁니다.

용도 1 — 코드 설명

Pythonexplain_comment.py
1# 사용자 정보 출력
2print("이름: 김코딩")
3print("나이: 15")
4
5# 구분선
6print("-" * 30)
7
8# 성적 출력
9print("국어: 95")
10print("수학: 100")
TIP
# 뒤에 공백 한 칸
#주석 보다 # 주석처럼 # 뒤에 공백을 한 칸 넣는 것이 PEP 8 권장 스타일입니다.

용도 2 — 코드 비활성화 (주석 처리)

코드가 에러를 발생시키거나, 잠시 실행하고 싶지 않을 때 # 을 붙여서 비활성화합니다.

Pythoncomment_out.py
1print("1단계 완료")
2# print("2단계 완료") # 아직 미완성
3print("3단계 완료")
실행 결과
1단계 완료 3단계 완료
줄코드역할
22번 줄은 #으로 시작하므로 실행되지 않습니다. "2단계 완료"는 출력되지 않습니다.
KEY
주석 처리 vs 삭제
코드를 삭제하면 복구하기 어렵습니다. 주석 처리하면 나중에 # 만 지우면 다시 실행할 수 있습니다. 디버깅할 때 특히 유용합니다.

용도 3 — TODO 메모

Pythontodo.py
1print("=" * 30)
2print("자기소개 프로그램")
3print("=" * 30)
4
5print("이름: 김코딩")
6# TODO: 나이, 학교 추가
7# TODO: ASCII 아트 추가
8# TODO: 테두리 디자인 개선
TIP
VS Code의 TODO 강조
VS Code에서 TODO라고 적으면 일부 확장 기능이 자동으로 강조해 줍니다. 할 일을 놓치지 않는 데 유용합니다.

인라인 주석

코드 뒤에 주석을 다는 것을 인라인 주석(inline comment)이라고 합니다. 코드와 주석 사이에 공백을 최소 2칸 넣는 것이 PEP 8 규칙입니다.

Pythoninline.py
1print("Hello") # 인사말 출력
2print(3 + 4) # 계산 결과 출력
3print("=" * 20) # 구분선
좋은 인라인 주석
Python
1price = 1500 # 단가 (원)
2tax = 0.1 # 부가세 10%
나쁜 인라인 주석
Python
1price = 1500 # price에 1500 대입
2tax = 0.1 # tax에 0.1 대입

주석은 '왜(why)'를 설명해야 합니다. 코드를 그대로 번역한 주석은 불필요합니다. price = 1500은 누구나 읽을 수 있으므로, '단가'라는 의미를 적는 것이 좋은 주석입니다.

좋은 주석 vs 나쁜 주석

주석을 잘 다는 것도 실력입니다. 좋은 주석은 코드를 이해하기 쉽게 만들지만, 나쁜 주석은 오히려 방해가 됩니다.

구분예시이유
좋은 주석# 부가세 포함 가격 계산코드의 의도(왜)를 설명
좋은 주석# TODO: 예외 처리 추가할 일을 명확히 기록
좋은 주석# 주의: 0으로 나누면 에러 발생함정이나 주의사항 경고
나쁜 주석# print 함수 호출코드를 그대로 번역 (불필요)
나쁜 주석# 변수 x에 10 대입누구나 읽을 수 있는 내용 반복
나쁜 주석# 여기서부터 코드 시작의미 없는 주석
KEY
주석의 원칙
좋은 코드는 주석 없이도 읽힙니다. 주석은 코드가 '무엇(what)'을 하는지가 아니라 '왜(why)' 그렇게 했는지를 적습니다.

여러 줄 주석

Python에는 공식적인 여러 줄 주석 문법이 없습니다. 대신 두 가지 방법을 사용합니다.

방법 1: # 을 여러 줄에 사용

Pythonmulti_comment1.py
1# 이 프로그램은 자기소개를 출력합니다.
2# 작성자: 김코딩
3# 작성일: 2025-03-15
4# 버전: 1.0
5
6print("자기소개 프로그램")

방법 2: 삼중 따옴표 (docstring)

Pythonmulti_comment2.py
1"""
2이 프로그램은 자기소개를 출력합니다.
3작성자: 김코딩
4작성일: 2025-03-15
5버전: 1.0
6"""
7
8print("자기소개 프로그램")
WARNING
삼중 따옴표는 엄밀히 주석이 아닙니다
삼중 따옴표(""")는 실제로는 문자열입니다. 변수에 저장하지 않으면 무시되기 때문에 주석처럼 사용할 수 있을 뿐입니다. 함수나 클래스 바로 아래에 적으면 docstring(문서화 문자열)이라는 특별한 역할을 합니다. 이것은 Layer 10(함수)에서 자세히 배웁니다.

커서가 있는 줄에서 Ctrl + / 를 누르면 주석이 추가됩니다. 이미 주석인 줄에서 다시 누르면 주석이 해제됩니다. 여러 줄을 선택한 상태에서 누르면 한꺼번에 주석 처리됩니다.

에러 체험 — 주석 관련 실수

주석은 단순해 보이지만 실수할 여지가 있습니다.

실수 1: 문자열 안의 #

Pythonhash_in_string.py
1print("C# 프로그래밍")
2print("트위터 #Python")
실행 결과
C# 프로그래밍 트위터 #Python
KEY
따옴표 안의 #은 주석이 아닙니다
문자열 안에 있는 #은 그냥 글자입니다. 주석은 코드 영역에서 #이 나타날 때만 적용됩니다.

실수 2: 주석 처리 위치 실수

의도: 2번 줄만 주석 처리
Python
1print("A")
2# print("B")
3print("C")
4
5# 출력: A, C
실수: # 위치가 잘못됨
Python
1print("A")
2print(#"B")
3print("C")
4
5# SyntaxError 발생!

#은 반드시 주석으로 만들 코드의 맨 앞에 놓아야 합니다. 코드 중간에 넣으면 문법이 깨집니다.

실수 3: 오래된 주석

Pythonstale_comment.py
1# 인사말 2개 출력
2print("Hello")
3print("World")
4print("Python")
WARNING
거짓말하는 주석
주석에는 "인사말 2개 출력"이라고 적혀 있지만, 실제로는 3개를 출력합니다. 코드를 수정했으면 주석도 함께 수정해야 합니다. 틀린 주석은 주석이 없는 것보다 나쁩니다.
