프로젝트:
펫 시뮬레이터

Pet 클래스(이름, 배고픔, 행복, 에너지)를 설계하고, 먹기/놀기/자기 메서드와 시간 경과 시스템을 구현합니다. 속성과 메서드, 상태 변화 흐름을 실전에서 완성합니다.

이 유닛에서 만드는 것

  • Pet 클래스에 이름, 배고픔, 행복, 에너지 속성을 정의할 수 있습니다.
  • eat() 메서드로 배고픔을 줄이고 에너지를 회복할 수 있습니다.
  • play() 메서드로 행복을 높이되 에너지와 배고픔이 변하는 관계를 구현합니다.
  • sleep() 메서드로 에너지를 완전히 회복하고 배고픔이 증가하는 구조를 만듭니다.
  • tick()으로 시간 경과에 따른 상태 자동 변화를 구현합니다.
  • status()로 현재 펫 상태를 요약 출력합니다.

Step 1 — Pet 클래스 기본 설계

Pet 클래스는 이름(name), 배고픔(hunger), 행복(happy), 에너지(energy) 네 가지 속성을 가집니다. 숫자는 모두 0~100 범위를 유지합니다.

# Step 1: Pet 클래스 — 속성 초기화 class Pet: def __init__(self, name): self.name = name self.hunger = 20 # 0=배부름, 100=매우 배고픔 self.happy = 70 # 0=슬픔, 100=최고 행복 self.energy = 80 # 0=지침, 100=활발 def _clamp(self, v): """값을 0~100 범위로 제한""" return max(0, min(100, v)) def status(self): """현재 상태 출력""" print(f"[{self.name}] hunger={self.hunger} happy={self.happy} energy={self.energy}") # 테스트 pet = Pet("뽀삐") pet.status()
[뽀삐] hunger=20 happy=70 energy=80

Step 2 — eat / play / sleep 메서드

펫의 행동 메서드 세 가지를 구현합니다. 각 메서드는 속성을 변화시키고, 항상 _clamp()로 범위를 보정합니다.

# Step 2: 행동 메서드 3개 def eat(self, amount=20): """밥 먹기: 배고픔 감소, 에너지 소폭 회복""" self.hunger = self._clamp(self.hunger - amount) self.energy = self._clamp(self.energy + 10) print(f"{self.name}이(가) 밥을 먹었습니다. 배고픔: {self.hunger}") def play(self, mins=30): """놀기: 행복 상승, 에너지 감소, 배고픔 소폭 증가""" self.happy = self._clamp(self.happy + mins // 2) self.energy = self._clamp(self.energy - mins // 3) self.hunger = self._clamp(self.hunger + 5) print(f"{self.name}이(가) 놀았습니다. 행복: {self.happy} 에너지: {self.energy}") def sleep(self, hrs=8): """자기: 에너지 완전 회복, 배고픔 증가""" self.energy = self._clamp(self.energy + hrs * 10) self.hunger = self._clamp(self.hunger + hrs * 3) print(f"{self.name}이(가) 잠을 잤습니다. 에너지: {self.energy}") # 테스트 pet = Pet("뽀삐") pet.eat() pet.play(60) pet.sleep(4) pet.status()

Step 3 — tick() 시간 경과 시스템

tick()은 시간 한 단위가 지남을 의미합니다. 호출할 때마다 hunger가 증가하고, happy와 energy가 감소합니다. 방치하면 펫 상태가 악화됩니다.

# Step 3: tick() — 시간 경과 + 위험 알림 def tick(self, steps=1): """시간 경과: hunger 증가, happy/energy 감소""" for _ in range(steps): self.hunger = self._clamp(self.hunger + 5) self.happy = self._clamp(self.happy - 3) self.energy = self._clamp(self.energy - 2) self._warn() def _warn(self): """위험 상태 경고""" if self.hunger >= 80: print(f" [경고] {self.name}이(가) 매우 배고픕니다!") if self.happy <= 20: print(f" [경고] {self.name}이(가) 매우 슬픕니다!") if self.energy <= 10: print(f" [경고] {self.name}이(가) 지쳐있습니다!") # 시뮬레이션: 20 tick 경과 pet = Pet("뽀삐") pet.tick(10) pet.status() pet.tick(10) pet.status()

Step 4 — 완성 펫 시뮬레이터

하루 루틴(아침-낮-저녁-밤)을 시뮬레이트합니다. 각 시간대마다 tick()과 행동 메서드를 조합해 펫이 최적 상태를 유지하도록 합니다.

# Step 4: 하루 루틴 시뮬레이터 def simulate_day(pet, day): print(f"\n--- {day}일차 ---") # 아침: 밥 먹기 + 2시간 경과 pet.eat(30) pet.tick(2) # 낮: 놀기 + 4시간 경과 pet.play(60) pet.tick(4) # 저녁: 밥 먹기 + 3시간 경과 pet.eat(25) pet.tick(3) # 밤: 자기 pet.sleep(8) print(f"하루 끝 상태:") pet.status() # 3일 시뮬레이션 my_pet = Pet("뽀삐") for day in range(1, 4): simulate_day(my_pet, day)

완성 코드 — pet_simulator.py

Pet 클래스 전체를 하나로 통합합니다. 모든 메서드가 _clamp()를 통해 속성 범위를 보장합니다.

# pet_simulator.py — 완성 코드 class Pet: def __init__(self, name): self.name=name; self.hunger=20; self.happy=70; self.energy=80 def _clamp(self, v): return max(0, min(100, v)) def status(self): print(f"[{self.name}] hunger={self.hunger} happy={self.happy} energy={self.energy}") def eat(self, amount=20): self.hunger=self._clamp(self.hunger-amount) self.energy=self._clamp(self.energy+10) def play(self, mins=30): self.happy=self._clamp(self.happy+mins//2) self.energy=self._clamp(self.energy-mins//3) self.hunger=self._clamp(self.hunger+5) def sleep(self, hrs=8): self.energy=self._clamp(self.energy+hrs*10) self.hunger=self._clamp(self.hunger+hrs*3) def tick(self, steps=1): for _ in range(steps): self.hunger=self._clamp(self.hunger+5) self.happy=self._clamp(self.happy-3) self.energy=self._clamp(self.energy-2)

핵심 요약

이 유닛에서 배운 것

  • __init__ 메서드로 객체 속성 초기화 — hunger, happy, energy를 초기값으로 설정합니다.
  • _clamp(v) — max(0, min(100, v))로 속성값이 범위를 벗어나지 않도록 보장합니다.
  • eat() — 배고픔 감소, 에너지 소폭 회복. 속성 간 연동 관계의 핵심 예시입니다.
  • play() — 행복 상승, 에너지 소모, 배고픔 증가. 트레이드오프(trade-off) 관계를 구현합니다.
  • sleep() — 에너지 대폭 회복, 배고픔 증가. 자원 회복 패턴의 전형입니다.
  • tick(steps) — 시간 단위 경과 시스템. 게임/시뮬레이션의 기본 패턴입니다.
  • 상태 판정 로직 — 조건문으로 "건강/주의/위험" 판정. 객체 속성 기반 의사결정의 예시입니다.
