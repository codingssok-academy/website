프로젝트:
단어장 프로그램

영어-한국어 딕셔너리를 딕셔너리로 구현합니다. 단어 추가/삭제/검색은 물론, 퀴즈 모드와 JSON 저장/불러오기까지 완성합니다.

이 유닛에서 만드는 것

  • 딕셔너리로 영어-한국어 단어 쌍을 저장하고 관리할 수 있습니다.
  • dict[key] = value로 단어를 추가하고 del dict[key]로 삭제할 수 있습니다.
  • dict.get()과 in 연산자로 단어를 안전하게 검색할 수 있습니다.
  • random.choice(list(dict.keys()))로 퀴즈 단어를 무작위 선택할 수 있습니다.
  • json.dump()와 json.load()로 단어장을 파일에 저장하고 불러올 수 있습니다.
  • 반복 퀴즈로 맞은 개수와 정답률을 계산해 출력할 수 있습니다.

Step 1 — 딕셔너리로 단어장 기본 구조 만들기

단어장의 핵심은 영어 단어를 키, 한국어 뜻을 값으로 저장하는 딕셔너리입니다. 단어 추가와 삭제 함수를 먼저 만듭니다.

# vocab.py — Step 1: 기본 구조 import json import random # 기본 단어장 (딕셔너리) vocabulary = { "apple": "사과", "book": "책", "cat": "고양이", "dog": "개", "house": "집" } def add_word(english, korean): """단어 추가""" vocabulary[english] = korean print(f"추가됨: {english} = {korean}") def delete_word(english): """단어 삭제""" if english in vocabulary: del vocabulary[english] print(f"삭제됨: {english}") else: print(f"없는 단어: {english}")

Step 2 — 단어 검색 기능

단어가 딕셔너리에 있는지 확인하려면 in 연산자나 get()을 씁니다. get()은 없는 단어일 때 None 대신 기본 메시지를 반환합니다.

def search_word(english): """단어 검색 — get()으로 안전하게""" result = vocabulary.get(english, None) if result: print(f"{english} = {result}") else: print(f"'{english}'은(는) 단어장에 없습니다.") def show_all(): """전체 단어 출력""" print(f"\n--- 전체 단어 ({len(vocabulary)}개) ---") for eng, kor in sorted(vocabulary.items()): print(f" {eng:<12} {kor}")

Step 3 — 퀴즈 모드 구현

퀴즈 모드는 딕셔너리에서 무작위로 단어를 골라 뜻을 맞히는 기능입니다. random.choice(list(vocabulary.keys()))로 무작위 키를 선택합니다.

def quiz_mode(rounds=5): """퀴즈 모드 — rounds번 문제 출제""" print(f"\n--- 단어 퀴즈 ({rounds}문제) ---") correct = 0 for i in range(rounds): word = random.choice(list(vocabulary.keys())) answer = input(f"Q{i+1}. '{word}'의 뜻은? ") if answer == vocabulary[word]: print("정답!") correct += 1 else: print(f"오답. 정답: {vocabulary[word]}") rate = correct / rounds * 100 print(f"\n결과: {correct}/{rounds}개 정답 ({rate:.1f}%)")

Step 4 — JSON 저장과 불러오기

json.dump()로 단어장 딕셔너리를 파일에 저장하고, json.load()로 프로그램 시작 시 이전 단어장을 불러옵니다.

def save_vocab(filename="vocab.json"): """단어장을 JSON 파일로 저장""" with open(filename, "w", encoding="utf-8") as f: json.dump(vocabulary, f, ensure_ascii=False, indent=2) print(f"저장 완료: {filename}") def load_vocab(filename="vocab.json"): """JSON 파일에서 단어장 불러오기""" global vocabulary try: with open(filename, "r", encoding="utf-8") as f: vocabulary = json.load(f) print(f"불러오기 완료: {len(vocabulary)}개 단어") except FileNotFoundError: print("저장된 단어장이 없습니다. 기본 단어장으로 시작합니다.")

def main(): load_vocab() # 시작 시 저장된 단어장 불러오기 while True: print("\n1.단어추가 2.단어검색 3.퀴즈 4.전체보기 5.저장 6.종료") choice = input("선택: ") if choice == "1": eng = input("영어: ") kor = input("한국어: ") add_word(eng, kor) elif choice == "2": eng = input("검색할 단어: ") search_word(eng) elif choice == "3": quiz_mode(5) elif choice == "4": show_all() elif choice == "5": save_vocab() elif choice == "6": save_vocab() # 종료 시 자동 저장 print("단어장을 저장하고 종료합니다.") break main()

핵심 요약

단어장 프로그램 핵심 기법

  • 단어 추가: dict[key] = value — 키가 없으면 새로 추가, 있으면 덮어쓰기
  • 단어 삭제: del dict[key] — 삭제 전 in으로 존재 확인 필수
  • 안전 검색: dict.get(key, 기본값) — KeyError 없이 안전하게 조회
  • 무작위 선택: random.choice(list(dict.keys())) — 퀴즈 단어 선택
  • JSON 저장: json.dump(dict, f, ensure_ascii=False, indent=2)
  • JSON 불러오기: json.load(f) — try/except로 파일 없을 때 처리
  • 역방향 검색: items() 순회로 값이 일치하는 키 찾기
