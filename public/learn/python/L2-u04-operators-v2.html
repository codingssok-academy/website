Chapter 04

연산자 — 계산과 비교

파이썬으로 덧셈, 뺄셈부터 비교, 논리 판단까지 — 연산자를 완전 정복합니다.

이 유닛에서 배우는 것

  • 산술 연산자 7가지(+, -, *, /, //, %, **)를 사용할 수 있습니다.
  • 연산자 우선순위와 괄호의 역할을 설명할 수 있습니다.
  • 비교 연산자(==, !=, >, <, >=, <=)로 참/거짓을 판별할 수 있습니다.
  • 논리 연산자(and, or, not)로 조건을 결합할 수 있습니다.
  • 복합 대입 연산자(+=, -= 등)를 사용할 수 있습니다.

산술 연산자 — 기본 사칙연산

파이썬은 계산기처럼 쓸 수 있습니다. +, -, *, / 네 가지가 기본입니다.

/ 나누기는 항상 소수점 결과를 돌려줍니다. 10 / 3의 결과는 3.3333...입니다.

따라해보세요
1
사칙연산을 모두 해보세요.
print(15 + 7) # 더하기 print(15 - 7) # 빼기 print(15 * 7) # 곱하기 print(15 / 7) # 나누기
22, 8, 105, 2.142857... 순서대로 출력
2
변수에 저장한 뒤 계산해보세요.
a = 20 b = 6 print(a + b) print(a * b)
26과 120이 출력되면 성공
3
문자열 더하기도 해보세요.
print("Hello" + " " + "Python")
Hello Python — 문자열끼리 +는 이어붙이기

산술 연산자 — //, %, **

나누기에는 3가지 변형이 있습니다. //는 몫, %는 나머지, **는 거듭제곱입니다.

따라해보세요
1
몫과 나머지를 구해보세요.
print(17 // 5) # 몫 print(17 % 5) # 나머지
3과 2가 출력됩니다
2
거듭제곱을 계산해보세요.
print(2 ** 10) # 2의 10승 print(3 ** 3) # 3의 3승
1024와 27이 출력됩니다
3
짝수/홀수 판별에 %를 활용해보세요.
print(10 % 2) # 0이면 짝수 print(7 % 2) # 1이면 홀수
0과 1 — 나머지로 짝홀수를 판별합니다

연산자 우선순위

수학과 마찬가지로, 파이썬도 곱셈/나눗셈을 먼저 계산합니다. 순서를 바꾸려면 () 괄호를 사용합니다.

따라해보세요
1
괄호 유무에 따른 결과 차이를 확인하세요.
print(2 + 3 * 4) # 14 print((2 + 3) * 4) # 20
14와 20 — 괄호가 우선순위를 바꿉니다
2
거듭제곱이 곱셈보다 먼저 계산되는지 확인하세요.
print(2 * 3 ** 2) # 18 (3**2=9 먼저) print((2 * 3) ** 2) # 36 (2*3=6 먼저)
18과 36 — **가 *보다 높은 우선순위
3
복잡한 식도 괄호로 제어해보세요.
print((10 + 5) * 2 - 8 / 4)
28.0 — 15*2=30, 8/4=2.0, 30-2.0=28.0

비교 연산자

두 값을 비교하면 결과는 True(참) 또는 False(거짓)입니다. 이 결과를 불(bool)이라고 합니다.

주의: =는 대입(변수에 값 저장)이고, ==는 비교(같은지 확인)입니다. 헷갈리지 마세요!

따라해보세요
1
비교 연산자의 결과를 확인하세요.
print(10 == 10) # True print(10 != 5) # True print(3 > 7) # False
True, True, False 출력
2
변수로 비교해보세요.
score = 85 print(score >= 90) # False print(score >= 80) # True
False, True — 85는 90 미만, 80 이상
3
문자열도 비교할 수 있습니다.
print("apple" == "apple") # True print("apple" == "Apple") # False
True, False — 대소문자가 다르면 다른 문자열

논리 연산자 — and, or, not

여러 조건을 결합하거나 뒤집을 때 and, or, not을 사용합니다.

따라해보세요
1
and와 or를 비교해보세요.
print(5 > 3 and 10 > 7) # True print(5 > 3 and 10 < 7) # False print(5 > 3 or 10 < 7) # True
True, False, True 순서로 출력
2
not으로 결과를 뒤집어보세요.
print(not True) # False print(not 3 > 5) # True (3>5는 False, 뒤집으면 True)
False, True
3
실전: 점수가 60~100 사이인지 확인하세요.
score = 85 print(score >= 60 and score <= 100)
True — 85는 60 이상이고 100 이하

복합 대입 연산자

변수의 값을 바꿀 때, a = a + 5 대신 a += 5로 줄여 쓸 수 있습니다.

a = 10 a += 5 # a는 이제 15 print(a) a *= 2 # a는 이제 30 print(a) a -= 10 # a는 이제 20 print(a)

핵심 요약

이 유닛에서 배운 것

  • 산술 연산자 7가지: + - * / //(몫) %(나머지) **(거듭제곱)
  • / 나누기는 항상 소수점(float) 결과를 반환한다
  • 연산자 우선순위: ** > * / // % > + - — 괄호()로 변경 가능
  • 비교 연산자 6가지: == != > < >= <= — 결과는 True 또는 False
  • 논리 연산자: and(둘 다 참), or(하나라도 참), not(뒤집기)
  • 복합 대입 연산자: += -= *= //= 등으로 짧게 쓸 수 있다
