프로젝트:
주사위 시뮬레이터

random 모듈로 주사위를 던지고 결과를 수집합니다. math 모듈로 평균과 표준편차를 계산하고, 텍스트 히스토그램으로 분포를 시각화하는 통계 시뮬레이터를 만듭니다.

이 프로젝트에서 만드는 것

  • random.randint(1,6)으로 주사위 던지기 시뮬레이션
  • math.sqrt()와 분산 공식으로 표준편차 계산
  • collections.Counter로 빈도 분석과 최빈값 추출
  • 텍스트 히스토그램으로 분포 시각화
  • 연속 같은 수 기록(streak) 통계 집계

핵심 개념 — random, math, Counter

random 모듈은 무작위 수를 생성하고, random.seed()로 재현 가능한 결과를 만들 수 있습니다. math 모듈의 sqrt()로 제곱근을 계산해 표준편차를 구합니다. collections.Counter는 리스트의 각 요소 빈도를 자동으로 집계하는 딕셔너리 서브클래스입니다.

# random / math / Counter 기본 사용 import random, math from collections import Counter random.seed(42) # 재현 가능한 난수 results = [random.randint(1, 6) for _ in range(100)] counter = Counter(results) mean = sum(results) / len(results) variance = sum((x - mean) ** 2 for x in results) / len(results) std = math.sqrt(variance) print(f"평균: {mean:.2f}, 표준편차: {std:.2f}") print(f"최빈값: {counter.most_common(1)[0][0]}")

Step 1 — 주사위 던지기와 히스토그램

roll(n) 함수는 주사위를 n번 던진 결과를 리스트로 반환합니다. histogram()은 Counter로 빈도를 집계한 뒤 "*" * count로 막대 길이를 표현합니다. scale 파라미터로 막대 너비를 조정합니다.

# Step 1: 기본 주사위와 히스토그램 import random, math from collections import Counter def roll(n=1, sides=6): return [random.randint(1, sides) for _ in range(n)] def histogram(results, scale=1): counter = Counter(results) print(f"=== 히스토그램 (총 {len(results)}회) ===") for face in sorted(counter): cnt = counter[face] bar = "*" * (cnt // scale) print(f"{face}: {bar} {cnt}") def stats(results): mean = sum(results) / len(results) var = sum((x - mean) ** 2 for x in results) / len(results) std = math.sqrt(var) print(f"평균: {mean:.2f} 표준편차: {std:.2f}")

Step 2 — 다중 주사위 + 연속 기록

multi_roll(dice, n)은 여러 개의 주사위를 n번 굴려 합계 분포를 분석합니다. streak(n, target)은 target 숫자가 연속으로 나오는 최장 기록을 찾습니다. compare_dice()는 두 플레이어의 주사위 결과를 비교합니다.

# Step 2: 다중 주사위 + 연속 기록 def multi_roll(dice=2, n=100): """dice개 주사위를 n번 굴려 합계 히스토그램""" sums = [] for _ in range(n): total = sum(roll(1)[0] for _ in range(dice)) sums.append(total) histogram(sums, scale=max(1, n // 50)) return sums def streak(n=100, target=6): """target이 연속으로 나온 최장 횟수""" results = roll(n) max_s = cur = 0 for r in results: if r == target: cur += 1 max_s = max(max_s, cur) else: cur = 0 print(f"{target} 최장 연속: {max_s}회") return max_s def compare_dice(rounds=10): """두 플레이어 주사위 승부""" p1 = roll(rounds); p2 = roll(rounds) w1 = sum(a > b for a, b in zip(p1, p2)) w2 = sum(a < b for a, b in zip(p1, p2)) print(f"P1승: {w1} P2승: {w2} 무: {rounds-w1-w2}")

연습 문제

Q1
목표 합계 달성 확률
Easy
주사위 2개를 n번 굴려 합이 target 이상인 비율을 계산하는 prob_reach(target, n=1000)을 작성하세요. Counter와 누적 합산으로 확률을 계산합니다.
호출
prob_reach(10, 1000)
출력
합계 10이상: 16.8% (168/1000)
힌트 보기
sum(1 for s in sums if s >= target)로 조건을 만족하는 횟수를 세고 n으로 나눕니다.
정답 보기
def prob_reach(target, n=1000): sums = multi_roll(2, n) count = sum(1 for s in sums if s >= target) print(f"합계 {target}이상: {count/n*100:.1f}% ({count}/{n})")
Q2
퍼센타일 계산
Medium
결과 리스트를 정렬해 p 퍼센타일 값을 반환하는 percentile(results, p)를 작성하세요. p=50이면 중앙값, p=75면 상위 25% 임계값입니다. 인덱스 계산에 math.ceil()을 활용합니다.
호출
percentile(roll(100), 75)
출력
75퍼센타일: 5
힌트 보기
정렬된 리스트에서 인덱스 = math.ceil(p/100 * len(results)) - 1로 퍼센타일 위치를 찾습니다.
정답 보기
def percentile(results, p): sorted_r = sorted(results) idx = math.ceil(p / 100 * len(sorted_r)) - 1 value = sorted_r[idx] print(f"{p}퍼센타일: {value}") return value
Q3
몬테카를로 방법으로 pi 추정
Hard
random.random()으로 단위 원 안에 점이 떨어지는 비율로 pi를 추정하는 estimate_pi(n)을 작성하세요. x,y를 0~1 사이 난수로 생성해 x**2 + y**2 < 1인 점의 비율 * 4가 pi입니다.
호출
estimate_pi(100000)
출력
pi 추정값: 3.1416 (오차: 0.02%)
힌트 보기
inside = sum(1 for _ in range(n) if random.random()**2 + random.random()**2 < 1)로 원 내부 점을 세고 4 * inside / n이 pi 추정값입니다.
정답 보기
def estimate_pi(n=10000): inside = sum(1 for _ in range(n) if random.random()**2 + random.random()**2 < 1) pi_est = 4 * inside / n error = abs(pi_est - math.pi) / math.pi * 100 print(f"pi 추정값: {pi_est:.4f} (오차: {error:.2f}%)")

핵심 요약

  • random.randint(a, b) — a이상 b이하 정수 난수, seed()로 재현 가능
  • Counter(list) — 빈도 자동 집계, .most_common(n)으로 최빈값 추출
  • 표준편차 — math.sqrt(sum((x-mean)**2 for x in data) / len(data))
  • 텍스트 히스토그램 — "*" * count로 막대 길이 표현
  • 몬테카를로 — 무작위 시뮬레이션으로 수학적 상수 근사
