프로젝트:
행렬 계산기

2차원 리스트로 행렬을 표현하고, 덧셈·뺄셈·전치를 구현합니다. f-string으로 결과를 정렬된 표 형식으로 출력하며, 중첩 리스트 컴프리헨션도 활용합니다.

이 프로젝트에서 만드는 것

  • 2차원 리스트 lst[i][j]로 행렬의 원소에 접근할 수 있습니다.
  • 중첩 for 반복문으로 행렬 덧셈과 뺄셈을 구현할 수 있습니다.
  • 중첩 리스트 컴프리헨션으로 행렬 전치를 한 줄로 표현할 수 있습니다.
  • f-string과 :4d 포맷으로 정렬된 행렬 출력 함수를 만들 수 있습니다.
  • 행렬 크기가 다를 때 예외 처리를 추가할 수 있습니다.

핵심 개념 — 2차원 리스트와 행렬 표현

행렬(matrix)은 숫자를 행과 열로 배열한 표입니다. 파이썬에서는 리스트 안에 리스트를 넣는 2차원 리스트로 표현합니다.

Step 1 — 행렬 출력 함수 (f-string 포맷)

행렬을 보기 좋게 출력하는 함수를 먼저 만듭니다. f-string의 :4d는 숫자를 4칸 너비로 오른쪽 정렬합니다.

# Step 1: 행렬 출력 함수 def print_matrix(mat, label=""): """2차원 리스트를 정렬된 행렬 형식으로 출력""" if label: print(f"{label}:") for row in mat: # f-string :4d — 정수를 4칸 너비로 오른쪽 정렬 row_str = " ".join([f"{val:4d}" for val in row]) print(f" [{row_str} ]") # 테스트 A = [[1, 2, 3], [4, 5, 6], [7, 8, 9]] print_matrix(A, "행렬 A")
행렬 A: [ 1 2 3 ] [ 4 5 6 ] [ 7 8 9 ]

Step 2 — 행렬 덧셈과 뺄셈

행렬 덧셈은 같은 위치의 원소끼리 더하는 연산입니다. 두 행렬의 크기(행 수, 열 수)가 같아야 가능합니다.

# Step 2: 행렬 덧셈과 뺄셈 def add_matrix(A, B): """두 행렬의 덧셈 — 같은 위치 원소끼리 더하기""" rows = len(A) cols = len(A[0]) result = [[A[i][j] + B[i][j] for j in range(cols)] for i in range(rows)] return result def sub_matrix(A, B): """두 행렬의 뺄셈""" rows = len(A) cols = len(A[0]) result = [[A[i][j] - B[i][j] for j in range(cols)] for i in range(rows)] return result A = [[1, 2], [3, 4]] B = [[5, 6], [7, 8]] print_matrix(add_matrix(A, B), "A + B") print_matrix(sub_matrix(A, B), "A - B")
A + B: [ 6 8 ] [ 10 12 ] A - B: [ -4 -4 ] [ -4 -4 ]

Step 3 — 행렬 전치 (Transpose)

전치는 행과 열을 바꾸는 연산입니다. 원래 [i][j] 위치의 원소가 전치 행렬에서는 [j][i] 위치에 놓입니다.

# Step 3: 행렬 전치 — 중첩 리스트 컴프리헨션 def transpose(A): """행과 열을 바꾸는 전치 연산""" rows = len(A) cols = len(A[0]) # [열][행] 순서로 새 행렬 생성 return [[A[i][j] for i in range(rows)] for j in range(cols)] A = [[1, 2, 3], [4, 5, 6]] AT = transpose(A) print_matrix(A, "원본 A (2x3)") print_matrix(AT, "전치 AT (3x2)")
원본 A (2x3): [ 1 2 3 ] [ 4 5 6 ] 전치 AT (3x2): [ 1 4 ] [ 2 5 ] [ 3 6 ]

Step 4 — 완성 프로그램 통합

모든 함수를 matrix_calc.py로 통합합니다. 크기 불일치 예외 처리도 추가합니다.

# matrix_calc.py — 완성 프로그램 def print_matrix(mat, label=""): if label: print(f"{label}:") for row in mat: print(" [" + " ".join([f"{v:4d}" for v in row]) + " ]") def _check_size(A, B): if len(A) != len(B) or len(A[0]) != len(B[0]): raise ValueError("크기가 다른 행렬은 연산 불가") def add_matrix(A, B): _check_size(A, B) return [[A[i][j]+B[i][j] for j in range(len(A[0]))] for i in range(len(A))] def sub_matrix(A, B): _check_size(A, B) return [[A[i][j]-B[i][j] for j in range(len(A[0]))] for i in range(len(A))] def transpose(A): return [[A[i][j] for i in range(len(A))] for j in range(len(A[0]))] A = [[1,2,3],[4,5,6],[7,8,9]] B = [[9,8,7],[6,5,4],[3,2,1]] print_matrix(add_matrix(A,B), "A+B") print_matrix(transpose(A), "A 전치")
A+B: [ 10 10 10 ] [ 10 10 10 ] [ 10 10 10 ] A 전치: [ 1 4 7 ] [ 2 5 8 ] [ 3 6 9 ]

Q1. 행렬 대각합(trace) 구하기
쉬움
정사각 행렬의 대각합(trace)은 대각선 원소(lst[i][i])를 모두 더한 값입니다. trace(A) 함수를 작성하세요.
입력[[1,2,3],[4,5,6],[7,8,9]]
출력15 (1+5+9)
힌트 보기
sum([A[i][i] for i in range(len(A))])로 대각 원소를 합산할 수 있습니다. 리스트 컴프리헨션과 sum()을 함께 사용하세요.
정답 보기
def trace(A): return sum([A[i][i] for i in range(len(A))]) A = [[1,2,3],[4,5,6],[7,8,9]] print(trace(A)) # 15

Q2. 단위 행렬 생성
보통
크기 n을 받아 n×n 단위 행렬(대각선은 1, 나머지는 0)을 반환하는 identity(n)을 작성하세요. 중첩 리스트 컴프리헨션과 삼항 연산자를 활용합니다.
입력n = 3
출력[[1,0,0],[0,1,0],[0,0,1]]
힌트 보기
[1 if i == j else 0 for j in range(n)]는 행 i의 원소를 만듭니다. 이것을 for i in range(n)으로 감싸면 전체 행렬이 됩니다.
정답 보기
def identity(n): return [[1 if i == j else 0 for j in range(n)] for i in range(n)] print_matrix(identity(3), "3x3 단위행렬")

Q3. 행렬 스칼라 곱
어려움
행렬의 모든 원소에 상수 k를 곱하는 scalar_mul(A, k)를 작성하세요. 그리고 sub_matrix(A, B)가 add_matrix(A, scalar_mul(B, -1))과 같은 결과인지 검증하세요.
입력A=[[1,2],[3,4]], k=3
출력[[3,6],[9,12]]
힌트 보기
중첩 리스트 컴프리헨션에서 A[i][j] * k로 각 원소에 k를 곱합니다. 검증은 두 결과 리스트를 ==로 비교하세요.
정답 보기
def scalar_mul(A, k): return [[A[i][j] * k for j in range(len(A[0]))] for i in range(len(A))] A = [[1,2],[3,4]] B = [[5,6],[7,8]] r1 = sub_matrix(A, B) r2 = add_matrix(A, scalar_mul(B, -1)) print(r1 == r2) # True

핵심 요약 — 행렬 계산기 완성

핵심 요약

  • lst[i][j] — 2차원 리스트의 i행 j열 원소 접근. i는 행 인덱스, j는 열 인덱스.
  • 행렬 덧셈 — 같은 위치 원소끼리 더함. 두 행렬의 크기(행×열)가 같아야 함.
  • 행렬 전치 — [A[i][j] for i in range(rows)] for j in range(cols)로 행/열 교환.
  • f"{val:4d}" — 정수를 4칸 너비 오른쪽 정렬로 출력. 숫자 크기에 맞게 조절.
  • 중첩 리스트 컴프리헨션 — [[식 for j in range(cols)] for i in range(rows)] 패턴으로 2차원 리스트 생성.
  • len(A) — 행의 수(행렬의 높이). len(A[0]) — 첫 행의 열 수(너비).
  • raise ValueError("메시지") — 크기 불일치 등 잘못된 입력에 예외를 발생시킴.
