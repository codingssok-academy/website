Chapter 30 — L3

문자열 메서드
총정리

split, join, replace를 중심으로 문자열을 자유자재로 다루는 7가지 메서드 그룹을 완전 정복합니다.

이 유닛에서 배우는 것

  • split()으로 문자열을 기준 문자로 쪼개어 리스트로 만들 수 있습니다.
  • join()으로 리스트 항목을 하나의 문자열로 이어 붙일 수 있습니다.
  • replace()로 문자열 안의 특정 부분을 다른 내용으로 바꿀 수 있습니다.
  • strip()으로 앞뒤 공백을 제거하고, startswith/endswith로 패턴을 확인할 수 있습니다.
  • find(), count(), upper(), lower(), title()의 기본 사용법을 익힙니다.

split() — 문자열 쪼개기

split(구분자)는 문자열을 구분자 기준으로 나눠서 리스트로 반환합니다. 구분자를 생략하면 공백(스페이스, 탭, 줄바꿈)을 기준으로 나눕니다.

# 기본 사용법 s = "사과,배,딸기" result = s.split(",") print(result) # ['사과', '배', '딸기'] # 공백 기준 분리 (기본값) sentence = "파이썬 문자열 메서드" words = sentence.split() print(words) # ['파이썬', '문자열', '메서드'] # maxsplit: 최대 몇 번 나눌지 제한 data = "a:b:c:d" print(data.split(":", 2)) # ['a', 'b', 'c:d']

subjects = "국어,수학,영어,과학" lst = subjects.split(",") print(lst) print(len(lst), "개 과목")

row = "홍길동,17,서울" fields = row.split(",") name = fields[0] print("이름:", name)
이름: 홍길동

split() 핵심 정리

  • s.split(sep) — sep 기준으로 나눈 리스트 반환
  • s.split() — 공백 기준 분리 (연속 공백도 하나로 처리)
  • s.split(sep, n) — 최대 n번만 나눔, 나머지는 마지막 요소에 포함
  • 결과 타입은 항상 list — 인덱스로 접근 가능

join() — 리스트 합치기

구분자.join(리스트)는 리스트의 문자열 항목들을 구분자로 연결해서 하나의 문자열로 만듭니다. split()의 역방향 연산입니다.

# join: 리스트를 하나의 문자열로 fruits = ["사과", "배", "딸기"] result = ",".join(fruits) print(result) # 사과,배,딸기 # 구분자 없이 연결 chars = ["P", "y", "t", "h", "o", "n"] print("".join(chars)) # Python # 줄바꿈으로 연결 (파일 출력 등에 유용) lines = ["1번 줄", "2번 줄", "3번 줄"] print("\n".join(lines))

주의: join()은 리스트 안에 문자열만 있을 때 작동합니다. 정수가 섞여 있으면 TypeError가 발생하므로 str()로 변환해야 합니다.

# 숫자가 섞인 경우 — str()로 변환 필요 numbers = [1, 2, 3] result = "-".join(str(n) for n in numbers) print(result) # 1-2-3

True

join() 핵심 정리

  • "구분자".join(리스트) — 리스트 항목을 구분자로 연결
  • split()과 반대 방향 — 리스트 → 문자열
  • 리스트 원소는 모두 str 타입이어야 함
  • 구분자가 ""이면 공백 없이 붙임

replace() — 치환

s.replace(old, new)는 문자열 안의 old를 모두 new로 바꾼 새 문자열을 반환합니다. 원본은 바뀌지 않습니다.

# 기본 치환 s = "Hello World" result = s.replace("World", "Python") print(result) # Hello Python print(s) # Hello World (원본 불변) # 여러 곳 동시 치환 text = "나는 사과를 사과나무에서 땄다" print(text.replace("사과", "배")) # 나는 배를 배나무에서 땄다 # 특정 횟수만 치환 (count 인수) data = "aaa" print(data.replace("a", "b", 2)) # bba

strip() / lstrip() / rstrip() — 공백 제거

사용자 입력이나 파일 데이터에는 앞뒤에 공백이 끼기 쉽습니다. strip 계열 메서드로 깔끔하게 정리합니다.

s = " 파이썬 " print(s.strip()) # "파이썬" print(s.lstrip()) # "파이썬 " print(s.rstrip()) # " 파이썬" # 특정 문자 제거 (문자 집합으로 동작) url = "https://example.com/" print(url.strip("/")) # "https://example.com"

startswith() / endswith() — 시작/끝 확인

문자열이 특정 문자열로 시작하거나 끝나는지 True / False로 반환합니다. 파일 확장자 확인이나 URL 분류에 자주 쓰입니다.

filename = "report.pdf" print(filename.endswith(".pdf")) # True print(filename.startswith("rep")) # True # 튜플로 여러 접미사 동시 확인 print(filename.endswith((".pdf", ".docx", ".txt"))) # True # 조건문과 함께 사용 url = "https://example.com" if url.startswith("https"): print("보안 연결")

find() / count() — 찾기와 세기

find(sub)는 처음 발견된 위치(인덱스)를 반환하고, 없으면 -1을 반환합니다. count(sub)는 등장 횟수를 셉니다.

s = "Python Programming" print(s.find("o")) # 4 (처음 등장 위치) print(s.find("xyz")) # -1 (없으면 -1) print(s.count("o")) # 2 (총 등장 횟수) print(s.count("P")) # 2 (대소문자 구분) # 시작/끝 범위 지정 print(s.find("o", 5)) # 10 (5번 인덱스 이후에서 탐색)

탐색 메서드 비교

  • find(sub) — 첫 등장 인덱스, 없으면 -1 (에러 없음)
  • index(sub) — find와 같으나 없으면 ValueError 발생
  • count(sub) — 등장 횟수 (겹치는 구간은 미포함)
  • in 연산자 — 포함 여부만 확인할 때 더 간결: "o" in s

upper() / lower() / title() — 대소문자 변환

영문 처리 시 대소문자를 통일하면 비교 오류를 방지할 수 있습니다. 특히 사용자 입력을 처리할 때 자주 쓰입니다.

s = "Hello World" print(s.upper()) # HELLO WORLD print(s.lower()) # hello world print(s.title()) # Hello World (각 단어 첫 글자 대문자) # 대소문자 무시 비교 (casefold) user_input = "PYTHON" if user_input.lower() == "python": print("정답입니다!")

대소문자는 구분하지 않습니다 (입력을 lower()로 통일 후 처리).

단원 요약 — 문자열 메서드 총정리

핵심 요약 — 핵심 포인트 7가지

  • split(sep) — 구분자로 나눠 리스트 반환 (없으면 공백 기준)
  • "sep".join(lst) — 리스트를 하나의 문자열로 연결 (원소는 str이어야 함)
  • replace(old, new) — old를 new로 치환, 원본 불변
  • strip() — 앞뒤 공백/지정 문자 제거 (lstrip/rstrip으로 한쪽만 가능)
  • startswith() / endswith() — True/False 반환, 튜플로 복수 확인 가능
  • find(sub) — 위치 인덱스 반환, 없으면 -1 / count(sub) — 등장 횟수
  • upper() / lower() / title() — 대소문자 변환 (원본 불변)

이해도 체크리스트

확인 항목관련 메서드
"a,b,c"를 쪼개서 리스트로 만들 수 있다split(",")
["a","b","c"]를 "a-b-c"로 이어붙일 수 있다"-".join(lst)
문자열 안의 특정 단어를 다른 단어로 바꿀 수 있다replace(old, new)
사용자 입력의 앞뒤 공백을 제거할 수 있다strip()
파일 확장자를 확인할 수 있다endswith(".pdf")
문자열 안에서 특정 단어의 위치를 찾을 수 있다find(sub)
대소문자를 무시하고 문자열을 비교할 수 있다lower() 후 비교
