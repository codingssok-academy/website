세트
중복 없는 집합

같은 값을 자동으로 제거하는 세트와 집합 연산을 배웁니다.

이 유닛에서 배우는 것

  • 세트를 만들고 중복이 제거되는 원리를 이해합니다.
  • add(), remove(), discard()로 값을 관리합니다.
  • 합집합, 교집합, 차집합 연산을 수행합니다.
  • 리스트의 중복을 세트로 제거할 수 있습니다.
  • 출석체크 중복 제거 프로그램을 만듭니다.

세트 만들기

세트는 {} 중괄호로 만들지만, 딕셔너리와 달리 값만 넣습니다. 같은 값은 자동으로 1개만 남습니다.

# 세트 만들기 fruits = {"사과", "바나나", "사과", "포도"} print(fruits) # {'사과', '바나나', '포도'} — 중복 제거! # 리스트에서 세트로 변환 nums = [1, 2, 2, 3, 3, 3] unique = set(nums) print(unique) # {1, 2, 3} # 빈 세트 — {}는 딕셔너리! empty = set() print(type(empty)) # <class 'set'>
따라해보세요
1
중복이 있는 리스트를 세트로 바꿔보세요.
colors = ["빨강", "파랑", "빨강", "초록", "파랑"] unique_colors = set(colors) print(unique_colors)
{'빨강', '파랑', '초록'} — 중복 제거됨
2
세트에 값을 추가하고 삭제하세요.
s = {1, 2, 3} s.add(4) s.remove(1) print(s)
{2, 3, 4}
3
discard()는 없는 값도 에러 없이 무시합니다.
s.discard(99) # 에러 안 남! print(s)
{2, 3, 4} — 그대로

집합 연산

세트는 수학의 집합과 같습니다. 합집합, 교집합, 차집합 연산을 할 수 있습니다.

a = {1, 2, 3} b = {2, 3, 4} # 합집합 — 둘 다 합치기 print(a | b) # {1, 2, 3, 4} print(a.union(b)) # 같은 결과 # 교집합 — 공통만 print(a & b) # {2, 3} print(a.intersection(b)) # 같은 결과 # 차집합 — A에만 있는 것 print(a - b) # {1} print(a.difference(b)) # 같은 결과
따라해보세요
1
월요일 출석과 화요일 출석의 교집합(둘 다 온 학생)을 구하세요.
mon = {"민수", "서연", "지호"} tue = {"서연", "지호", "하늘"} print(mon & tue)
{'서연', '지호'}
2
화요일에만 온 학생을 구하세요.
print(tue - mon)
{'하늘'}
3
이틀 중 한 번이라도 온 학생 전체를 구하세요.
print(mon | tue)
{'민수', '서연', '지호', '하늘'}

출석체크 중복 제거

출석부에 이름이 중복으로 들어갈 때가 있습니다. 세트를 이용해서 깔끔하게 정리합시다.

# 출석체크 — 중복 제거 attendance = ["민수", "서연", "민수", "지호", "서연", "하늘", "민수"] # 세트로 중복 제거 unique = set(attendance) print(f"출석 인원: {len(unique)}명") print(f"명단: {sorted(unique)}") # 전체 학생 vs 출석 학생 → 결석 학생 all_students = {"민수", "서연", "지호", "하늘", "예은"} present = set(attendance) absent = all_students - present print(f"결석: {absent}") # {'예은'}
따라해보세요
1
숫자 리스트의 중복을 제거한 뒤 정렬해서 리스트로 되돌리세요.
nums = [5, 3, 5, 1, 3, 2, 1] result = sorted(set(nums)) print(result)
[1, 2, 3, 5]
2
두 반의 공통 과목을 구하세요.
class_a = {"수학", "영어", "과학"} class_b = {"영어", "과학", "음악"} print(class_a & class_b)
{'영어', '과학'}
3
A반에만 있는 과목을 구하세요.
print(class_a - class_b)
{'수학'}

핵심 요약

이 유닛에서 배운 것

  • 세트는 {값1, 값2}로 만들고, 중복을 자동 제거한다
  • 빈 세트는 set()으로 만든다 ({}는 딕셔너리)
  • add(), remove(), discard()로 값을 관리한다
  • | 합집합, & 교집합, - 차집합 연산을 한다
  • set(리스트)로 중복을 쉽게 제거할 수 있다
