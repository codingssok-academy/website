프로젝트:
행맨 게임

랜덤으로 단어를 뽑아 한 글자씩 맞추는 행맨 게임을 만듭니다. ASCII 아트로 행맨을 그리고, 남은 목숨을 표시하며, 게임 전체 흐름을 함수로 구현합니다.

이 프로젝트에서 만드는 것

  • random.choice()로 단어 리스트에서 랜덤 단어를 선택할 수 있습니다.
  • 리스트 컴프리헨션으로 맞춘 글자와 _를 조합해 현재 상태를 표시할 수 있습니다.
  • ASCII 아트 리스트로 목숨 단계(6개)에 따라 행맨 그림을 출력할 수 있습니다.
  • set으로 이미 입력한 글자를 추적하고 중복 입력을 방지할 수 있습니다.
  • 게임 루프(while)로 승리/패배 조건을 판별할 수 있습니다.
  • 전체 게임을 함수로 분리해 깔끔한 코드 구조를 만들 수 있습니다.

Step 1 — 단어 목록과 ASCII 아트 준비

행맨 게임에는 두 가지 핵심 데이터가 필요합니다. 첫째, 랜덤으로 뽑을 단어 리스트, 둘째, 목숨 단계에 따라 표시할 ASCII 아트 리스트입니다.

import random # 단어 목록 (영어 단어 — 중학생 수준) WORDS = [ "python", "computer", "keyboard", "monitor", "internet", "program", "function", "variable", "student", "school" ] # ASCII 아트 — 목숨 6 → 0 순서 (인덱스 0이 완성된 행맨) HANGMAN = [ """ +---+ | | O | /|\\ | / \\ | | ========""", """ +---+ | | O | /|\\ | / | | ========""", """ +---+ | | O | /|\\ | | | ========""", """ +---+ | | O | /| | | | ========""", """ +---+ | | O | | | | | ========""", """ +---+ | | O | | | | ========""", """ +---+ | | | | | | ========""" ] # 테스트: 단어 뽑기 word = random.choice(WORDS) print(f"뽑힌 단어: {word} (길이: {len(word)})") print(HANGMAN[6]) # 목숨 6 = 빈 교수대
뽑힌 단어: program (길이: 7) +---+ | | | | | | ========

Step 2 — 게임 핵심 로직

게임의 핵심은 세 가지 함수입니다. get_display()로 현재 상태를 _ p _ t h _ n 형태로 표시하고, check_win()으로 승리를 판별하며, 메인 루프에서 입력을 받아 처리합니다.

def get_display(word, guessed): """맞춘 글자는 표시, 나머지는 _ 로 반환""" return " ".join(c if c in guessed else "_" for c in word) def check_win(word, guessed): """단어의 모든 글자를 맞췄으면 True""" return all(c in guessed for c in word) # 테스트 word = "python" guessed = {"p", "t", "h"} print(get_display(word, guessed)) print(check_win(word, guessed)) guessed = {"p", "y", "t", "h", "o", "n"} print(check_win(word, guessed))
p _ t h _ n False True

메인 게임 루프

def play_hangman(): word = random.choice(WORDS) guessed = set() # 입력한 글자 집합 lives = 6 # 남은 목숨 wrong = set() # 틀린 글자 집합 print("=== 행맨 게임 시작! ===") while lives > 0: print(HANGMAN[lives]) print(f"단어: {get_display(word, guessed)}") print(f"남은 목숨: {lives} 틀린 글자: {', '.join(sorted(wrong))}") if check_win(word, guessed): print(f"축하! '{word}' 완성!") return guess = input("글자 입력: ").lower().strip() if len(guess) != 1 or not guess.isalpha(): print("알파벳 한 글자만 입력하세요.") continue if guess in guessed: print("이미 입력한 글자입니다.") continue guessed.add(guess) if guess in word: print(f"'{guess}' 맞았어요!") else: wrong.add(guess) lives -= 1 print(f"'{guess}' 틀렸어요. 목숨 -{lives}") print(HANGMAN[0]) print(f"게임 오버. 정답은 '{word}'") play_hangman()

입력hint
출력힌트: 'y'가 단어에 있습니다! (힌트 1/2 사용)
내 답안
힌트 보기
아직 맞추지 않은 글자 목록: [c for c in word if c not in guessed]. random.choice로 하나 선택하세요.
정답 보기
hint_count = 0 # 함수 시작 부분에 추가 # 입력 처리 부분에 추가: if guess == "hint": if hint_count >= 2: print("힌트를 모두 사용했습니다.") else: remaining = [c for c in word if c not in guessed] if remaining: h = random.choice(remaining) hint_count += 1 print(f"힌트: '{h}'가 단어에 있습니다! (힌트 {hint_count}/2 사용)") continue

핵심 요약

  • random.choice(리스트) — 리스트에서 무작위로 하나 선택
  • set — 중복 없는 집합. 글자 추적에 최적 (in 검색 O(1))
  • 리스트 컴프리헨션 + 조건식 — c if c in guessed else "_"
  • all(조건 for x in iterable) — 모두 True이면 True
  • ASCII 아트는 삼중 따옴표 문자열로 작성, 리스트에 저장
  • 게임 루프: while lives > 0 + 승리 조건으로 종료
