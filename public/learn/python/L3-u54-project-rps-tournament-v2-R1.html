프로젝트:
숫자 야구 게임

random으로 3자리 비밀 숫자를 생성하고, 스트라이크/볼 판정 알고리즘으로 힌트를 제공해 사용자가 정답을 맞히는 과정을 시도 횟수와 함께 기록합니다.

이 유닛에서 만드는 것

  • random.sample()로 중복 없는 3자리 숫자를 생성할 수 있습니다.
  • 스트라이크(위치+값 일치)와 볼(값만 일치) 판정 알고리즘을 구현할 수 있습니다.
  • 사용자 입력을 검증하고 유효하지 않은 입력을 걸러낼 수 있습니다.
  • 시도 횟수를 누적 기록하고 게임 종료 시 통계를 출력할 수 있습니다.
  • 게임을 반복 실행하는 메인 루프를 구성할 수 있습니다.

Step 1 — 비밀번호 생성과 입력 검증

숫자 야구에서 비밀번호는 1~9까지 중복 없이 3자리입니다. random.sample()은 리스트에서 중복 없이 원하는 개수만큼 뽑아줍니다.

import random def generate_secret() -> list: """1~9에서 중복 없이 3자리 비밀번호 생성""" return random.sample(range(1, 10), 3) def validate_input(user_input: str) -> list | None: """입력 검증 — 3자리 숫자, 중복 없음, 0 없음. 유효하면 list 반환""" if len(user_input) != 3: return None if not user_input.isdigit(): return None digits = [int(c) for c in user_input] if 0 in digits: return None if len(set(digits)) != 3: # 중복 체크 return None return digits

게임 루프 — 입력 받기

def get_guess() -> list: """유효한 추측을 받을 때까지 반복 입력""" while True: raw = input("추측 (3자리, 예: 472): ").strip() digits = validate_input(raw) if digits is not None: return digits print(" 잘못된 입력입니다. 1~9에서 중복 없이 3자리를 입력하세요.")

Step 2 — 스트라이크/볼 판정 알고리즘

숫자 야구의 핵심은 스트라이크(위치와 값 모두 일치)와 볼(값은 맞지만 위치가 다름) 판정입니다.

판정 함수 구현

def judge(secret: list, guess: list) -> tuple: """(strikes, balls) 반환""" strikes = 0 balls = 0 for i in range(3): if guess[i] == secret[i]: strikes += 1 # 위치, 값 모두 일치 elif guess[i] in secret: balls += 1 # 값만 일치 (위치 다름) return strikes, balls

시도 횟수 기록

attempts 카운터를 게임 루프 밖에서 초기화하고, 매 시도마다 1씩 증가합니다. 게임 종료 시 기록 리스트에 추가해 이전 기록과 비교합니다.

history = [] # 이전 게임 기록 저장 def play_game(): secret = generate_secret() attempts = 0 print("숫자 야구 시작! (1~9, 중복없는 3자리)") while True: guess = get_guess() attempts += 1 s, b = judge(secret, guess) print(f" → {s}S {b}B") if s == 3: print(f"정답! {attempts}번 만에 맞혔습니다.") history.append(attempts) break print(f"기록 목록: {history}") print(f"최소 시도: {min(history)}번")

Step 3 — 완성 코드와 통계 출력

모든 함수를 조합해 완전한 숫자 야구 게임을 완성합니다. 여러 판을 플레이한 후 최솟값, 최댓값, 평균을 출력합니다.

def print_stats(history: list): """게임 기록 통계 출력""" if not history: print("기록 없음") return print(f"\n--- 전체 기록 ({len(history)}판) ---") print(f"최소: {min(history)}번") print(f"최대: {max(history)}번") print(f"평균: {sum(history)/len(history):.1f}번") def main(): history = [] while True: play_game(history) again = input("한 판 더? (y/n): ") if again.lower() != "y": break print_stats(history) if __name__ == "__main__": main()

힌트 모드 확장

스트라이크/볼 결과만으로는 어렵다고 느끼는 사용자를 위해 힌트 모드를 추가할 수 있습니다. hint_mode=True이면 볼의 실제 숫자를 알려줍니다.

def judge_with_hint(secret, guess, hint_mode=False): s, b = judge(secret, guess) print(f" → {s}S {b}B") if hint_mode and b > 0: balls = [guess[i] for i in range(3) if guess[i] != secret[i] and guess[i] in secret] print(f" 힌트: {balls} 는 볼입니다.") return s, b

Step 4 — 4자리 모드와 난이도 선택

기본 3자리 모드에서 4자리 모드로 확장하면 난이도가 크게 올라갑니다. digit_count 매개변수로 자릿수를 조절하면 하나의 함수로 두 모드를 지원할 수 있습니다.

1
아웃(Out) 횟수 판정 추가
쉬움

judge() 함수를 수정해 스트라이크도 볼도 아닌 숫자의 개수(아웃 수)도 함께 반환하도록 고치세요. 반환값을 (strikes, balls, outs)로 바꿉니다.

예) secret=[4,7,2], guess=[4,9,2] → (2, 0, 1)
힌트 보기
outs = 3 - strikes - balls 로 계산하면 별도 루프 없이 간단히 구할 수 있습니다.
정답 보기
def judge(secret, guess): strikes = balls = 0 for i in range(3): if guess[i] == secret[i]: strikes += 1 elif guess[i] in secret: balls += 1 outs = 3 - strikes - balls return strikes, balls, outs
2
최고 기록 경신 알림
보통

play_game(history)에서 게임이 끝난 후, 이번 시도 횟수가 history의 최솟값보다 적으면 "신기록!"을 출력하도록 수정하세요. history가 비어 있으면 항상 신기록입니다.

예) history=[7,5], 이번=3 → "신기록! 이전 최고: 5번"
힌트 보기
not history 로 빈 리스트 체크, min(history) 로 이전 최고 기록을 가져옵니다. attempts < min(history) 이면 신기록입니다.
정답 보기
if not history or attempts < min(history): prev = min(history) if history else "-" print(f"신기록! 이전 최고: {prev}번")

4자리 모드 지원
어려움

generate_secret(digit_count=3)와 judge(secret, guess)를 자릿수에 무관하게 동작하도록 수정하세요. digit_count 매개변수를 두 함수에 추가하고, validate_input()도 길이 체크를 digit_count에 맞게 바꾸세요.

예) generate_secret(4) → 4개짜리 리스트 반환
힌트 보기
random.sample(range(1,10), digit_count) 로 자릿수를 파라미터로 받으면 됩니다. judge()의 range(3)도 range(digit_count)로 바꾸세요.
정답 보기
def generate_secret(digit_count=3): return random.sample(range(1,10), digit_count) def judge(secret, guess): s = b = 0 n = len(secret) for i in range(n): if guess[i] == secret[i]: s += 1 elif guess[i] in secret: b += 1 return s, b

핵심 요약

  • random.sample(population, k): population에서 중복 없이 k개 무작위 선택 — 비밀번호 생성 핵심
  • 스트라이크 판정: guess[i] == secret[i] — 위치와 값이 모두 일치할 때
  • 볼 판정: elif guess[i] in secret — 스트라이크가 아닌 경우에만 체크 (elif 필수)
  • set(digits)으로 중복 체크: 길이가 달라지면 중복 있음
  • 시도 횟수 기록: 게임 루프 밖 리스트에 추가, min()/max()/sum()으로 통계
  • 매개변수화: digit_count를 파라미터로 넘겨 3자리/4자리 모드 분리
