프로젝트:
D-Day 카운터

datetime 모듈로 날짜를 다루고, 여러 이벤트의 남은/지난 일수를 자동 계산해 깔끔하게 출력하는 프로그램을 만듭니다.

이 유닛에서 만드는 것

  • datetime 모듈로 오늘 날짜를 가져오고 날짜끼리 뺄셈을 할 수 있습니다.
  • timedelta.days로 남은 일수와 지난 일수를 계산할 수 있습니다.
  • 딕셔너리 리스트로 여러 이벤트를 관리할 수 있습니다.
  • 지난 이벤트와 다가올 이벤트를 자동으로 분리해서 출력할 수 있습니다.
  • f-string으로 날짜와 숫자를 깔끔하게 포맷팅할 수 있습니다.

Step 1 — datetime 모듈 기초

datetime은 날짜와 시간을 다루는 파이썬 표준 모듈입니다. 오늘 날짜를 가져오거나, 두 날짜의 차이를 계산하거나, 원하는 형식으로 출력할 때 사용합니다.

오늘 날짜 가져오기

from datetime import datetime # 오늘 날짜와 시간 today = datetime.today() print(today) # 2026-03-21 14:30:00.123456 # 날짜 부분만 보기 print(today.date()) # 2026-03-21 # 각 부분 따로 접근 print(today.year) # 2026 print(today.month) # 3 print(today.day) # 21
2026-03-21 14:30:00.123456 2026-03-21 2026 3 21

특정 날짜 만들기

datetime(년, 월, 일)로 원하는 날짜를 직접 만들 수 있습니다. 이 날짜와 오늘 날짜를 빼면 시간 차이를 계산할 수 있습니다.

from datetime import datetime # 특정 날짜 직접 만들기 birthday = datetime(2026, 7, 15) # 7월 15일 생일 today = datetime.today() # 날짜 차이 계산 (timedelta 반환) diff = birthday - today print(type(diff)) # <class 'datetime.timedelta'> print(diff.days) # 116 (양수 = 미래)

Step 2 — 남은 일수 계산과 이벤트 분리

D-Day 카운터의 핵심은 timedelta.days의 부호를 보고 이벤트가 미래(양수)인지 과거(음수)인지 자동으로 판단하는 것입니다.

이벤트 데이터 구조 설계

여러 이벤트를 관리하려면 딕셔너리 리스트를 사용합니다. 각 이벤트는 이름과 날짜를 가집니다.

from datetime import datetime # 이벤트 목록 — 딕셔너리 리스트 events = [ {"name": "신정", "date": datetime(2026, 1, 1)}, {"name": "코딩쏙 개강", "date": datetime(2026, 3, 2)}, {"name": "여름방학", "date": datetime(2026, 7, 20)}, {"name": "크리스마스", "date": datetime(2026, 12,25)}, ] today = datetime.today() # 각 이벤트의 남은/지난 일수 계산 for event in events: diff = event["date"] - today days = diff.days print(f"{event['name']}: {days}일")
신정: -79일 코딩쏙 개강: -19일 여름방학: 121일 크리스마스: 279일

지난 이벤트 / 다가올 이벤트 자동 분리

# 두 리스트로 분리 past = [] upcoming = [] for event in events: diff = event["date"] - today event["days"] = diff.days # days 필드 추가 if diff.days < 0: past.append(event) else: upcoming.append(event) print(f"지난 이벤트: {len(past)}개") print(f"다가올 이벤트: {len(upcoming)}개")
지난 이벤트: 2개 다가올 이벤트: 2개

Step 3 — f-string 포맷팅으로 출력 꾸미기

f-string은 문자열 안에 변수를 직접 넣는 방법입니다. f"..." 앞에 f를 붙이고 {변수}로 값을 삽입합니다. 폭·정렬·소수점까지 지정할 수 있어 깔끔한 출력에 매우 유용합니다.

D-Day 형식으로 출력하기

def format_dday(days): """days 값을 D-N / D-Day / D+N 형식으로 변환""" if days == 0: return "D-Day" elif days > 0: return f"D-{days}" # 미래: D-116 else: return f"D+{abs(days)}" # 과거: D+79 # 테스트 print(format_dday(116)) # D-116 print(format_dday(0)) # D-Day print(format_dday(-79)) # D+79
D-116 D-Day D+79

날짜 포맷팅 — strftime

strftime(형식문자열)로 날짜를 원하는 형태의 문자열로 변환할 수 있습니다. %Y는 4자리 년도, %m은 월, %d는 일입니다.

from datetime import datetime event_date = datetime(2026, 7, 20) # 다양한 포맷 출력 print(event_date.strftime("%Y-%m-%d")) # 2026-07-20 print(event_date.strftime("%Y년 %m월 %d일")) # 2026년 07월 20일 print(event_date.strftime("%m/%d")) # 07/20
2026-07-20 2026년 07월 20일 07/20

Step 4 — 완성: D-Day 카운터 전체 코드

지금까지 배운 datetime, 이벤트 분리, f-string을 모두 합쳐서 여러 이벤트를 지난 것/다가올 것으로 나눠 출력하는 완성 프로그램을 만들겠습니다.

from datetime import datetime # ── 1) 이벤트 목록 ───────────────────────────── events = [ {"name": "신정", "date": datetime(2026, 1, 1)}, {"name": "코딩쏙 개강", "date": datetime(2026, 3, 2)}, {"name": "여름방학", "date": datetime(2026, 7, 20)}, {"name": "크리스마스", "date": datetime(2026, 12,25)}, {"name": "해가 바뀌는 날", "date": datetime(2027, 1, 1)}, ] # ── 2) D-Day 형식 함수 ───────────────────────── def format_dday(days): if days == 0: return "D-Day" elif days > 0: return f"D-{days}" else: return f"D+{abs(days)}" # ── 3) 오늘 기준 계산 + 분리 ─────────────────── today = datetime.today() past, upcoming = [], [] for event in events: diff = event["date"] - today event["days"] = diff.days (past if diff.days < 0 else upcoming).append(event) # ── 4) 출력 ──────────────────────────────────── print(f"오늘: {today.strftime('%Y년 %m월 %d일')}\n") print("[지난 이벤트]") for e in sorted(past, key=lambda x: x["days"], reverse=True): dday = format_dday(e["days"]) date_str = e["date"].strftime("%m/%d") print(f" {e['name']:<12} {date_str} {dday}") print("\n[다가올 이벤트]") for e in sorted(upcoming, key=lambda x: x["days"]): dday = format_dday(e["days"]) date_str = e["date"].strftime("%m/%d") print(f" {e['name']:<12} {date_str} {dday}")
오늘: 2026년 03월 21일 [지난 이벤트] 코딩쏙 개강 03/02 D+19 신정 01/01 D+79 [다가올 이벤트] 여름방학 07/20 D-121 크리스마스 12/25 D-279 해가 바뀌는 날 01/01 D-286

Step 5 — 심화: 가장 가까운 이벤트 찾기

min()과 key 파라미터를 사용하면 다가올 이벤트 중 오늘과 가장 가까운 것을 한 줄로 찾을 수 있습니다.

from datetime import datetime events = [ {"name": "어린이날", "date": datetime(2026, 5, 5)}, {"name": "광복절", "date": datetime(2026, 8, 15)}, {"name": "크리스마스","date": datetime(2026, 12,25)}, ] today = datetime.today() # 미래 이벤트만 필터링 future = [e for e in events if (e["date"] - today).days >= 0] # 가장 가까운 이벤트 nearest = min(future, key=lambda e: (e["date"] - today).days) days_left = (nearest["date"] - today).days print(f"가장 가까운 이벤트: {nearest['name']}") print(f"날짜: {nearest['date'].strftime('%Y-%m-%d')}") print(f"D-{days_left}")
가장 가까운 이벤트: 어린이날 날짜: 2026-05-05 D-45

from datetime import datetime today = datetime.today() events = [ {"name": "신정", "date": datetime(2026, 1, 1)}, {"name": "코딩쏙 개강", "date": datetime(2026, 3, 2)}, {"name": "여름방학", "date": datetime(2026, 7, 20)}, {"name": "해가 바뀌는 날", "date": datetime(2027, 1, 1)}, ] def get_days(e): return (e["date"] - today).days future = [e for e in events if get_days(e) >= 0] past = [e for e in events if get_days(e) < 0] far = max(future, key=get_days) oldest = min(past, key=get_days) print(f"가장 먼 미래: {far['name']} (D-{get_days(far)})") print(f"가장 오래된 과거: {oldest['name']} (D+{abs(get_days(oldest))})")

핵심 요약

핵심 요약

  • from datetime import datetime으로 모듈을 가져온다.
  • datetime.today()는 오늘 날짜와 시간을 반환한다.
  • datetime(년, 월, 일)로 특정 날짜 객체를 만든다.
  • 두 datetime을 빼면 timedelta 객체가 되고, .days로 정수 일수를 얻는다.
  • days > 0이면 미래(D-N), days < 0이면 과거(D+N), days == 0이면 D-Day.
  • strftime("%Y-%m-%d")로 날짜를 원하는 문자열 형식으로 출력한다.
  • 딕셔너리 리스트로 여러 이벤트를 관리하고 리스트 컴프리헨션으로 분리한다.
  • f-string의 {변수:<N}으로 왼쪽 정렬, {변수:>N}으로 오른쪽 정렬한다.

이 유닛에서 배운 것

  • datetime 활용: datetime.today(), datetime(y, m, d)로 날짜 생성 및 계산
  • 남은 일수 계산: 날짜 뺄셈 → timedelta → .days로 정수 획득
  • 여러 이벤트 관리: 딕셔너리 리스트 + for문으로 일괄 처리
  • 지난/다가올 분리: days 부호로 if/else 분류 + 리스트 컴프리헨션
  • f-string 포맷팅: :<N, :>N, strftime으로 깔끔한 출력
