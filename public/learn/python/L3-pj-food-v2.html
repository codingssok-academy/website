이 유닛에서 만드는 것

  • 카테고리를 키로, 음식 리스트를 값으로 갖는 중첩 딕셔너리를 만들 수 있습니다.
  • random.choice()로 리스트에서 무작위 항목을 뽑을 수 있습니다.
  • 리스트 컴프리헨션으로 조건에 맞는 음식만 필터링할 수 있습니다.

  • 함수로 각 기능을 분리해 재사용 가능한 코드를 만들 수 있습니다.

Step 1 — 음식 딕셔너리 설계

음식 데이터를 카테고리 → 음식 이름 → 칼로리 구조의 중첩 딕셔너리로 저장합니다. 이렇게 하면 카테고리별로 음식을 관리하고 칼로리도 함께 조회할 수 있습니다.

# food_recommender.py — Step 1: 음식 딕셔너리 menu = { "한식": {"김치찌개": 450, "비빔밥": 550, "삼겹살": 800}, "중식": {"짜장면": 600, "탕수육": 720, "짬뽕": 580}, "양식": {"파스타": 650, "피자": 900, "스테이크": 750}, "분식": {"떡볶이": 400, "순대": 350, "튀김": 500}, } # 특정 음식 칼로리 조회 print(menu["한식"]["비빔밥"]) # 550 print(list(menu.keys())) # 카테고리 목록

random 모듈로 랜덤 추천

random.choice()는 리스트에서 임의의 항목 하나를 골라 반환합니다. random.choice(list(menu.keys()))처럼 딕셔너리 키를 리스트로 변환해서 사용합니다.

Step 2 — 선호도 필터

사용자가 먹고 싶은 카테고리를 선택하면 해당 카테고리의 음식만 보여줍니다. 리스트 컴프리헨션으로 조건에 맞는 음식을 필터링합니다. in 연산자로 딕셔너리 키 존재 여부를 확인할 수 있습니다.

# Step 2: 선호도 필터 함수 def filter_by_category(category): """카테고리가 menu에 있으면 해당 음식 목록 반환""" if category not in menu: print(f"'{category}' 카테고리를 찾을 수 없습니다.") return [] items = menu[category] result = [[name, cal] for name, cal in items.items()] return result # 테스트 foods = filter_by_category("한식") for name, cal in foods: print(f" {name}: {cal}kcal")
김치찌개: 450kcal 비빔밥: 550kcal 삼겹살: 800kcal

Step 3 — 칼로리 합산과 평균

선택한 음식들의 칼로리를 sum()으로 합산하고, 리스트 컴프리헨션으로 칼로리 값만 추출합니다.

# Step 3: 칼로리 계산 함수 def calc_calories(foods): """[이름, 칼로리] 2D 리스트에서 총 칼로리와 평균 반환""" if not foods: return 0, 0 cals = [item[1] for item in foods] total = sum(cals) avg = total // len(cals) return total, avg # 한식 칼로리 계산 foods = filter_by_category("한식") total, avg = calc_calories(foods) print(f"총 칼로리: {total}kcal") print(f"평균 칼로리: {avg}kcal")
총 칼로리: 1800kcal 평균 칼로리: 600kcal

Step 4 — 완전한 추천 함수 만들기

카테고리 입력 → 필터 → 랜덤 선택 → 칼로리 출력을 하나의 함수로 통합합니다. 함수 파라미터에 기본값 category=None을 지정하면 인수 없이 호출했을 때 자동으로 전체 랜덤 모드가 됩니다.

# Step 4: 통합 추천 함수 import random def recommend(category=None): """카테고리 미입력 시 전체 중 랜덤 선택""" if category is None: category = random.choice(list(menu.keys())) print(f"카테고리: {category} (랜덤 선택)") foods = filter_by_category(category) if not foods: return pick = random.choice(foods) print(f"추천 메뉴: {pick[0]}") print(f"칼로리: {pick[1]}kcal") print(f"카테고리 평균: {calc_calories(foods)[1]}kcal") # 실행 recommend("분식") recommend() # 전체 랜덤
추천 메뉴: 떡볶이 칼로리: 400kcal 카테고리 평균: 416kcal 카테고리: 양식 (랜덤 선택) 추천 메뉴: 파스타 칼로리: 650kcal 카테고리 평균: 766kcal

Q2
가장 칼로리가 낮은 음식 찾기
보통
전체 menu에서 칼로리가 가장 낮은 음식 이름과 칼로리를 출력하세요. 모든 음식을 하나의 리스트로 만든 후 min() 함수의 key 파라미터를 활용하세요.
출력 최저 칼로리: 순대 (350kcal)
힌트 보기
all_foods = [(name, cal) for items in menu.values() for name, cal in items.items()] 로 전체 리스트를 만들고 min(all_foods, key=lambda x: x[1]) 로 최솟값을 찾으세요.
정답 보기
all_foods = [(name, cal) for items in menu.values() for name, cal in items.items()] cheapest = min(all_foods, key=lambda x: x[1]) print(f"최저 칼로리: {cheapest[0]} ({cheapest[1]}kcal)")
Q3
새 카테고리와 음식 추가 기능 만들기
심화
menu 딕셔너리에 새 카테고리와 음식을 추가하는 add_food() 함수를 작성하세요. 카테고리가 없으면 새로 만들고, 이미 있으면 기존 카테고리에 추가합니다. 딕셔너리의 setdefault() 메서드를 활용하세요.
호출 add_food("일식", "라멘", 620)
출력 일식 카테고리에 라멘(620kcal) 추가됨
힌트 보기
menu.setdefault(category, {}) 로 카테고리가 없을 때 빈 딕셔너리를 만들고, menu[category][food_name] = calories 로 음식을 추가하세요.
정답 보기
def add_food(category, food_name, calories): menu.setdefault(category, {}) menu[category][food_name] = calories print(f"{category} 카테고리에 {food_name}({calories}kcal) 추가됨") add_food("일식", "라멘", 620)

핵심 요약

  • 중첩 딕셔너리 menu["카테고리"]["음식"]으로 2단계 데이터를 저장합니다.
  • random.choice(리스트)로 무작위 항목을 선택합니다.
  • 딕셔너리에서 키 존재 여부는 in 또는 not in으로 확인합니다.
  • sum([x[1] for x in 리스트])로 특정 열의 합산을 구합니다.
  • dict.setdefault(키, 기본값)으로 키가 없을 때 자동 생성합니다.
