for와 range()

for 반복문과 range() 함수를 사용하여 코드를 원하는 횟수만큼 반복하는 방법을 배웁니다.

이 유닛에서 배우는 것

  • for 반복문의 기본 구조를 이해하고 사용할 수 있습니다.
  • range() 함수의 매개변수(start, stop, step)를 활용할 수 있습니다.
  • 문자열과 리스트를 for문으로 순회할 수 있습니다.
  • 중첩 for문으로 2차원 패턴을 출력할 수 있습니다.
  • break와 continue로 반복을 제어할 수 있습니다.

for 반복문이란?

같은 코드를 여러 번 실행할 때 for 반복문을 사용합니다. "이 목록의 각 항목에 대해 실행해라"라는 뜻입니다.

for i in range(5): print(i)
따라해보세요 - 기본 for문
1
"안녕"을 5번 출력하세요.
for i in range(5): print("안녕")
안녕이 5줄 출력됩니다
2
0부터 4까지 숫자를 출력하세요.
for i in range(5): print(i)
0, 1, 2, 3, 4가 한 줄씩 출력됩니다
3
1부터 5까지 출력하세요. (i + 1 활용)
for i in range(5): print(i + 1)
1, 2, 3, 4, 5가 한 줄씩 출력됩니다

range() 함수 완전 정복

range()는 숫자 시퀀스를 만듭니다. 매개변수를 1개, 2개, 3개로 사용할 수 있습니다.

따라해보세요 - range() 활용
1
1부터 10까지 출력하세요.
for i in range(1, 11): print(i)
1부터 10까지 출력 (11은 포함 안 됨)
2
짝수만 출력하세요 (2, 4, 6, 8, 10).
for i in range(2, 11, 2): print(i)
2, 4, 6, 8, 10 출력
3
10에서 1까지 역순으로 출력하세요.
for i in range(10, 0, -1): print(i)
10, 9, 8, ..., 1 역순 출력 (step=-1)

range()에서 step에 음수를 넣으면 거꾸로 셉니다. range(10, 0, -1)은 10에서 시작해 1씩 줄이면서 1까지 갑니다.

for문으로 문자열 순회

for는 문자열의 각 글자를 하나씩 꺼내서 반복할 수 있습니다.

for ch in "Python": print(ch)

누적 합계 패턴

for문에서 변수에 값을 누적하면 합계를 구할 수 있습니다.

total = 0 for i in range(1, 6): total = total + i print("합계:", total)
따라해보세요 - 순회와 누적
1
자기 이름을 한 글자씩 출력하세요.
for ch in "홍길동": print(ch)
홍, 길, 동이 한 줄씩 출력됩니다
2
1부터 100까지의 합을 구하세요.
total = 0 for i in range(1, 101): total += i print("합:", total)
합: 5050
3
구구단 3단을 출력하세요.
for i in range(1, 10): print(f"3 x {i} = {3 * i}")
3 x 1 = 3 부터 3 x 9 = 27까지

break와 continue

break는 반복을 즉시 종료합니다. continue는 현재 회차를 건너뛰고 다음으로 넘어갑니다.

# break: 5를 찾으면 멈춤 for i in range(1, 11): if i == 5: break print(i) # 1, 2, 3, 4
# continue: 홀수만 건너뜀 for i in range(1, 11): if i % 2 == 1: continue print(i) # 2, 4, 6, 8, 10

중첩 for문

for문 안에 for문을 넣으면 2차원 반복이 됩니다. 구구단 전체를 출력할 때 많이 씁니다.

for dan in range(2, 10): print(f"--- {dan}단 ---") for gop in range(1, 10): print(f"{dan} x {gop} = {dan * gop}")

별 패턴 출력

중첩 for문으로 직각삼각형 별 패턴을 만들어봅시다.

for i in range(1, 6): print("* " * i)
따라해보세요 - 패턴과 응용
1
역삼각형 별 패턴을 만드세요 (5줄 -> 1줄).
for i in range(5, 0, -1): print("* " * i)
5개부터 1개까지 줄어드는 역삼각형
2
1부터 10까지 짝수의 합을 구하세요.
total = 0 for i in range(2, 11, 2): total += i print("짝수 합:", total)
짝수 합: 30
3
입력받은 단의 구구단을 출력하세요.
dan = int(input("몇 단? ")) for i in range(1, 10): print(f"{dan} x {i} = {dan * i}")
입력한 단의 구구단이 출력됩니다

핵심 요약

이 유닛에서 배운 것

  • for i in range(n)으로 n번 반복한다 (0부터 n-1까지)
  • range(start, stop, step)으로 시작, 끝, 간격을 지정한다
  • for ch in "문자열"로 글자를 하나씩 순회한다
  • 누적 패턴: 변수를 0으로 초기화하고 for문 안에서 +=로 누적한다
  • break는 즉시 종료, continue는 다음 회차로 건너뛴다
  • 중첩 for문으로 구구단, 별 패턴 같은 2차원 출력을 만든다
