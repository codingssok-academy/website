미니 SNS

User 클래스(이름, 게시물 리스트, 팔로우 목록)와 Post 클래스를 설계합니다. 팔로우 기반 타임라인 출력 시스템으로 실전 OOP 다중 클래스 연동을 완성합니다.

이 유닛에서 만드는 것

  • Post 클래스에 작성자(author), 내용(content), 좋아요(likes) 속성을 정의합니다.
  • User 클래스에 이름, 게시물 리스트(posts), 팔로우 목록(following)을 정의합니다.
  • post(content) 메서드로 새 게시물을 작성해 posts 리스트에 추가합니다.
  • follow(user) 메서드로 다른 유저를 following 목록에 추가합니다.
  • timeline()으로 팔로잉 유저들의 게시물을 모아 출력합니다.
  • Post.like()로 좋아요 수를 증가시킵니다.

Step 1 — Post 클래스 설계

Post는 작성자(author), 내용(content), 좋아요 수(likes)를 가집니다. like()로 좋아요를 누르고, __str__()으로 게시물을 보기 좋게 출력합니다.

# Step 1: Post 클래스 class Post: def __init__(self, author, content): self.author = author # User 객체 self.content = content # 게시물 내용 self.likes = 0 # 좋아요 수 def like(self): """좋아요 1 증가""" self.likes += 1 def __str__(self): return f"[@{self.author.name}] {self.content} (좋아요: {self.likes})" # 임시 테스트 (User 없이) class _TempUser: name = "테스터" p = Post(_TempUser(), "안녕하세요 첫 게시물입니다.") print(p) p.like() p.like() print(p)

Step 2 — User 클래스 설계

User 클래스는 이름(name), 게시물 리스트(posts), 팔로우 목록(following)을 가집니다. post()로 게시물을 작성하고, follow()로 다른 유저를 구독합니다.

# Step 2: User 클래스 class User: def __init__(self, name): self.name = name self.posts = [] # 내가 작성한 Post 리스트 self.following = [] # 내가 팔로우한 User 리스트 def post(self, content): """새 게시물 작성""" p = Post(self, content) # author = self self.posts.append(p) print(f"[@{self.name}] 게시물 작성: {content[:20]}...") return p def follow(self, user): """다른 유저 팔로우 (중복 방지)""" if user in self.following: print(f"이미 @{user.name}을 팔로우 중입니다.") elif user is self: print("자기 자신은 팔로우할 수 없습니다.") else: self.following.append(user) print(f"@{self.name}이(가) @{user.name}을 팔로우했습니다.") def __str__(self): return f"@{self.name} (게시물: {len(self.posts)}, 팔로잉: {len(self.following)})" # 테스트 alice = User("alice") bob = User("bob") alice.post("오늘 날씨가 좋네요.") alice.follow(bob) alice.follow(alice) # 자기 자신 팔로우 차단 print(alice)

Step 3 — timeline() 타임라인 구현

timeline()은 내가 팔로우하는 모든 유저의 게시물을 수집해 한 번에 출력합니다. 리스트 컴프리헨션으로 모든 팔로잉 유저의 posts를 하나의 리스트로 합칩니다.

# Step 3: timeline() 메서드 def timeline(self): """팔로잉 유저들의 게시물 모아 출력""" print(f"\n=== @{self.name}의 타임라인 ===") if not self.following: print(" 팔로우하는 유저가 없습니다.") return # 팔로잉 유저의 모든 posts 수집 all_posts = [ p for user in self.following for p in user.posts ] if not all_posts: print(" 팔로잉 유저들의 게시물이 없습니다.") return for i, post in enumerate(all_posts, 1): print(f"{i:2}. {post}") # 테스트 alice = User("alice") bob = User("bob") carol = User("carol") bob.post("파이썬 재밌다") bob.post("오늘 코딩 3시간") carol.post("클래스 이해했어요") alice.follow(bob) alice.follow(carol) alice.timeline()

완성 코드 — mini_sns.py

Post와 User 클래스를 하나의 파일로 통합합니다. Post는 User를 참조하고, User는 Post 리스트와 User 리스트를 보유합니다.

# mini_sns.py — 완성 코드 class Post: def __init__(self, author, content): self.author=author; self.content=content; self.likes=0 def like(self): self.likes+=1 def __str__(self): return f"[@{self.author.name}] {self.content} (좋아요: {self.likes})" class User: def __init__(self, name): self.name=name; self.posts=[]; self.following=[] def post(self, content): p=Post(self,content); self.posts.append(p); return p def follow(self, user): if user not in self.following and user is not self: self.following.append(user) def timeline(self): all_posts=[p for u in self.following for p in u.posts] for i,p in enumerate(all_posts,1): print(f"{i}. {p}")

핵심 요약

이 유닛에서 배운 것

  • Post(author, content) — author로 User 객체를 받습니다. 객체가 다른 객체를 속성으로 가지는 패턴입니다.
  • Post.like() — likes += 1로 상태를 변경하는 단순한 메서드. 누적형 카운터의 전형입니다.
  • User.post(content) — Post 객체를 생성해 self.posts에 추가하고 반환합니다.
  • User.follow(user) — if user in self.following으로 중복을 방지합니다. is not self로 자기 팔로우를 차단합니다.
  • User.timeline() — 중첩 리스트 컴프리헨션: [p for u in following for p in u.posts]로 팔로잉 게시물 수집.
  • 다중 클래스 연동 — Post는 User를 참조, User는 Post 리스트와 User 리스트를 보유. 클래스 간 의존 관계 설계의 핵심 패턴.
