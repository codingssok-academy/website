Chapter 09

나만의 챗봇 만들기

너만의 챗봇을 만들어보자! print()와 input()으로 대화형 프로그램을 만듭니다.

이 유닛에서 배우는 것

  • input() 함수로 사용자의 입력을 받을 수 있습니다.
  • 입력받은 값을 변수에 저장하고 활용할 수 있습니다.
  • 인사하는 챗봇을 만들 수 있습니다.
  • 점심 추천 챗봇을 만들 수 있습니다.
  • 운세 챗봇을 만들 수 있습니다.

input() 맛보기 - 키보드로 입력받기

input()은 사용자가 키보드로 입력한 값을 받아오는 함수입니다. L2에서 자세히 배우지만, 여기서 맛만 봅시다!

따라해보세요
1
이름을 입력받아보세요.
name = input("이름: ") print(name)
키보드로 입력한 이름이 출력됩니다
2
좋아하는 색을 물어보세요.
color = input("좋아하는 색: ") print("와!", color, "좋은 색이다!")
와! 파란색 좋은 색이다! (입력한 값에 따라 다름)
3
나이를 물어보세요.
age = input("나이: ") print("너는", age, "살이구나!")
너는 13 살이구나!

버전1: 인사하는 챗봇

이름을 물어보고 인사하는 간단한 챗봇을 만들어봅시다!

# 인사하는 챗봇 print("=== 인사 챗봇 ===") print("안녕! 나는 인사봇이야.") print() name = input("이름이 뭐야? : ") print() print("반가워,", name + "!") print("좋은 하루 보내!") print("=== 대화 끝 ===")
따라해보세요
1
위의 인사 챗봇 코드를 그대로 입력하고 실행하세요.
print("=== 인사 챗봇 ===") name = input("이름이 뭐야? : ") print("반가워,", name + "!")
이름을 입력하면 인사해줍니다
2
인사말을 바꿔보세요.
name = input("이름: ") print(name + "님, 환영합니다!")
민수님, 환영합니다!
3
두 가지를 물어보는 챗봇을 만들어보세요.
name = input("이름: ") hobby = input("취미: ") print(name + "의 취미는 " + hobby + "이구나!")
민수의 취미는 게임이구나!

버전2: 점심 추천 챗봇

좋아하는 음식을 물어보고 점심 메뉴를 추천하는 챗봇입니다!

# 점심 추천 챗봇 print("=== 점심 추천 챗봇 ===") print("안녕! 나는 점심봇이야.") print() food = input("좋아하는 음식이 뭐야? : ") print() print("오!", food, "좋아하는구나!") print("그러면 오늘 점심은", food, "어때?") print(food, "맛집을 검색해볼게!") print("=== 추천 끝 ===")
따라해보세요
1
점심 추천 챗봇을 실행하세요.
print("=== 점심 추천 챗봇 ===") food = input("좋아하는 음식: ") print("오늘 점심은", food, "어때?")
오늘 점심은 피자 어때?
2
이름도 물어보는 버전을 만들어보세요.
name = input("이름: ") food = input("좋아하는 음식: ") print(name + "아, 오늘 " + food + " 먹자!")
민수아, 오늘 치킨 먹자!
3
음료도 추천하는 버전을 만들어보세요.
food = input("음식: ") drink = input("음료: ") print(food + " + " + drink + " = 완벽한 점심!")
피자 + 콜라 = 완벽한 점심!

버전3: 운세 챗봇

이름을 입력하면 운세를 알려주는 챗봇입니다. 아직 랜덤은 못 쓰지만, 재미있는 메시지를 만들어봅시다!

# 운세 챗봇 print("=== 오늘의 운세 챗봇 ===") print("안녕! 나는 운세봇이야.") print() name = input("이름을 알려줘: ") print() print("[ " + name + "의 오늘의 운세 ]") print() print("오늘의 행운 점수: 95점!") print("오늘은 좋은 일이 생길 거야.") print(name + "아, 자신감을 가져!") print() print("행운의 색: 파란색") print("행운의 숫자: 7") print("=== 운세 끝 ===")
따라해보세요
1
운세 챗봇을 실행하세요.
name = input("이름: ") print("[", name, "의 운세 ]") print("오늘의 행운 점수: 95점!")
[ 민수 의 운세 ] 오늘의 행운 점수: 95점!
2
행운의 색도 물어보는 버전을 만드세요.
name = input("이름: ") color = input("좋아하는 색: ") print(name + "의 행운의 색은 " + color + "!")
민수의 행운의 색은 빨간색!
3
행운의 숫자도 입력받아보세요.
name = input("이름: ") num = input("좋아하는 숫자: ") print(name + "의 행운의 숫자는 " + num + "!") print("오늘 " + num + "번 웃으면 좋은 일이 생겨!")
민수의 행운의 숫자는 7! 오늘 7번 웃으면 좋은 일이 생겨!

핵심 요약

이 유닛에서 배운 것

  • input("질문")으로 사용자의 입력을 받을 수 있다
  • 입력받은 값은 변수에 저장한다: name = input("이름: ")
  • input()의 결과는 항상 문자열(str)이다
  • 문자열 연결(+)과 쉼표(,)로 입력값을 활용한다
  • 챗봇 구조: 인사 - 질문(input) - 응답(print)
