Chapter 10

문자열

문자열을 자르고, 합치고, 바꾸고, 검색하는 모든 기술을 배웁니다.

이 유닛에서 배우는 것

  • 문자열 인덱싱과 슬라이싱으로 원하는 글자를 꺼낼 수 있습니다.
  • upper(), lower(), replace() 등 문자열 메서드를 사용할 수 있습니다.
  • f-string으로 변수 값을 문자열에 삽입할 수 있습니다.
  • split()과 join()으로 문자열을 분리하고 합칠 수 있습니다.
  • in 연산자로 문자열 포함 여부를 판별할 수 있습니다.

문자열 인덱싱

문자열은 글자가 순서대로 나열된 것입니다. 각 글자에는 0부터 시작하는 인덱스 번호가 있습니다.

s = "Python" print(s[0]) # P print(s[5]) # n print(s[-1]) # n (뒤에서 첫 번째)
따라해보세요
1
인덱싱으로 글자를 꺼내보세요.
s = "Hello" print(s[0]) # H print(s[4]) # o print(s[-1]) # o
H, o, o 가 각각 출력되면 성공
2
len()으로 문자열 길이를 구해보세요.
name = "파이썬" print(len(name)) # 3
3이 출력됩니다
3
문자열을 합쳐보세요.
a = "Hello" b = " World" print(a + b) # Hello World print(a * 3) # HelloHelloHello
+ 는 이어붙이기, * 는 반복

문자열 슬라이싱

s[시작:끝]으로 문자열의 일부를 잘라낼 수 있습니다. 시작은 포함, 끝은 미포함입니다.

s = "Python" print(s[0:3]) # Pyt (0,1,2번) print(s[:3]) # Pyt (처음부터) print(s[3:]) # hon (3번부터 끝) print(s[::2]) # Pto (2칸씩 건너뛰기) print(s[::-1]) # nohtyP (뒤집기)
따라해보세요
1
슬라이싱으로 부분 문자열을 꺼내보세요.
msg = "Hello, World!" print(msg[7:12]) # World print(msg[-6:-1]) # World
두 방법 모두 World가 출력됩니다
2
문자열을 뒤집어보세요.
word = "level" print(word[::-1]) # level (회문!)
거꾸로 해도 같으면 회문(palindrome)입니다
3
step을 활용해보세요.
nums = "0123456789" print(nums[::3]) # 0369
3칸씩 건너뛰어 출력됩니다

문자열 메서드

문자열에는 다양한 메서드가 있습니다. 메서드는 문자열 뒤에 .메서드()로 호출합니다.

s = "hello python" print(s.upper()) # HELLO PYTHON print(s.lower()) # hello python print(s.title()) # Hello Python print(s.replace("hello", "bye")) # bye python print(s.count("l")) # 2 print(s.find("python")) # 6
따라해보세요
1
대소문자를 바꿔보세요.
name = "alice" print(name.upper()) # ALICE print(name.title()) # Alice
upper()는 전부 대문자, title()은 첫 글자만
2
문자열을 교체해보세요.
msg = "I like Java" print(msg.replace("Java", "Python"))
I like Python
3
공백을 제거해보세요.
raw = " hello " print(raw.strip()) # "hello" print(raw.lstrip()) # "hello " print(raw.rstrip()) # " hello"
strip은 양쪽, lstrip은 왼쪽, rstrip은 오른쪽

f-string으로 변수 삽입

f"" 안에 {변수}를 넣으면 변수 값이 문자열에 자동 삽입됩니다.

name = "자현" age = 15 print(f"이름: {name}, 나이: {age}") # 이름: 자현, 나이: 15 # 중괄호 안에서 계산도 가능 print(f"내년 나이: {age + 1}") # 내년 나이: 16
따라해보세요
1
f-string으로 자기소개를 만드세요.
name = "자현" school = "코딩쏙" print(f"안녕! 나는 {name}이고 {school}에서 배워")
변수 값이 자동으로 들어갑니다
2
계산 결과를 포맷팅해보세요.
price = 12500 print(f"가격: {price:,}원") # 가격: 12,500원
:, 로 천 단위 쉼표가 붙습니다
3
소수점 자릿수를 지정해보세요.
pi = 3.141592 print(f"원주율: {pi:.2f}") # 원주율: 3.14
.2f는 소수점 2자리까지

split()과 join()

split()은 문자열을 나눠서 리스트로, join()은 리스트를 합쳐서 문자열로 만듭니다.

text = "사과-바나나-포도" fruits = text.split("-") print(fruits) # ['사과', '바나나', '포도'] result = " + ".join(fruits) print(result) # 사과 + 바나나 + 포도

in 연산자

in으로 문자열 안에 특정 글자가 있는지 확인할 수 있습니다.

email = "user@codingssok.com" print("@" in email) # True print("gmail" in email) # False print("gmail" not in email) # True

직접 풀어보세요

Q1
이메일 아이디 추출
쉬움
split()을 사용하여 이메일 주소에서 @ 앞의 아이디 부분만 출력하세요.
입력email = "student@codingssok.com"
출력student
내 답안
힌트 보기
split("@")으로 나눈 뒤 첫 번째 요소를 가져오세요.
정답 확인
email = "student@codingssok.com" user_id = email.split("@")[0] print(user_id)
Q2
비밀번호 마스킹
보통
비밀번호의 앞 2글자만 보여주고 나머지는 *로 바꿔 출력하세요.
입력pw = "secret123"
출력se*******
내 답안
힌트 보기
앞 2글자 pw[:2]와 나머지 길이만큼 "*"를 곱하세요.
정답 확인
pw = "secret123" masked = pw[:2] + "*" * (len(pw) - 2) print(masked)
Q3
문장 뒤집기
보통
문장의 단어 순서를 뒤집어 출력하세요. (글자가 아니라 단어 순서)
입력s = "I love Python"
출력Python love I
내 답안
힌트 보기
split()으로 나누고, 리스트를 [::-1]로 뒤집은 뒤 join()하세요.
정답 확인
s = "I love Python" words = s.split() result = " ".join(words[::-1]) print(result)

핵심 요약

이 유닛에서 배운 것

  • s[0] 인덱싱, s[1:4] 슬라이싱으로 글자를 꺼낸다
  • 음수 인덱스 s[-1]은 뒤에서부터, s[::-1]은 뒤집기
  • upper(), lower(), replace(), strip() 등 문자열 메서드
  • f"이름: {name}" f-string으로 변수 삽입, 포맷 지정
  • split()으로 나누고 join()으로 합친다
  • in 연산자로 문자열 포함 여부 확인
