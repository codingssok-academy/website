매개변수 심화
기본값과 키워드 인자

함수를 더 유연하게 쓰는 두 가지 강력한 기능을 배웁니다.

이 유닛에서 배우는 것

  • 기본값 매개변수로 선택적 인자를 만들 수 있습니다.
  • 키워드 인자로 순서에 상관없이 값을 전달할 수 있습니다.
  • 위치 인자와 키워드 인자의 차이를 설명할 수 있습니다.
  • 기본값 매개변수는 오른쪽부터 써야 하는 규칙을 이해합니다.
  • 여러 기본값을 조합해서 유연한 함수를 만들 수 있습니다.

기본값 매개변수

매개변수에 =로 기본값을 설정하면, 인자를 생략했을 때 기본값이 자동으로 사용됩니다. 호출할 때 선택적으로 값을 전달할 수 있어서 함수가 훨씬 유연해집니다.

# 기본값 매개변수 def greet(name, greeting="안녕"): print(f"{greeting}, {name}!") greet("민수") # 안녕, 민수! greet("서연", "하이") # 하이, 서연! greet("지호", "반가워") # 반가워, 지호!

키워드 인자 — 이름으로 전달하기

함수를 호출할 때 매개변수이름=값 형식으로 전달하면 순서에 상관없이 원하는 매개변수에 값을 넣을 수 있습니다. 이것을 키워드 인자라고 합니다.

def greet(name, greeting="안녕"): print(f"{greeting}, {name}!") # 위치 인자 (순서대로) greet("철수", "하이") # 하이, 철수! # 키워드 인자 (이름으로 — 순서 바꿔도 됨) greet(greeting="하이", name="철수") # 하이, 철수! # 섞어 쓰기 (위치 먼저, 키워드 나중) greet("민수", greeting="좋은 아침") # 좋은 아침, 민수!

기본값 순서 규칙

기본값 매개변수는 반드시 오른쪽(뒤쪽)부터 배치해야 합니다. 기본값이 없는 매개변수가 기본값 있는 매개변수 뒤에 오면 Python이 오류를 냅니다.

# 올바른 배치 — 기본값은 오른쪽부터 def func(a, b, c=0): # OK return a + b + c def func2(a, b=1, c=2): # OK — 기본값 두 개 return a + b + c # 잘못된 배치 # def func3(a, b=1, c): # SyntaxError! # 기본값 뒤에 기본값 없는 매개변수 불가
주의 — 기본값으로 변경 가능한 객체(리스트 등) 사용 금지

기본값에 []나 {}를 쓰면 모든 호출이 같은 객체를 공유하는 버그가 생깁니다. 기본값은 None으로 하고 함수 안에서 새로 만드세요.

종합 예제 — 기본값과 키워드 인자 함께 쓰기

실제 프로그램에서는 기본값 매개변수와 키워드 인자를 함께 씁니다. 아래 영수증 출력 함수를 통해 어떻게 조합하는지 살펴봅니다.

def receipt(name, items, tax=False, title="영수증"): total = sum(items) if tax: total = int(total * 1.1) print(f"[{title}] {name}님 합계: {total}원") receipt("민수", [3000, 5000]) receipt("서연", [8000], tax=True) receipt("지호", [2000, 3000], title="간이영수증") receipt("철수", [10000], tax=True, title="세금계산서")
정리 — 언제 어떤 인자를 쓸까?

꼭 전달해야 하는 값은 위치 인자로, 자주 쓰이는 기본 값이 있으면 기본값 매개변수로, 가독성이 중요하거나 여러 선택지 중 일부만 바꿀 때는 키워드 인자로 호출합니다. 예를 들어 send_email(to, subject="안녕하세요", urgent=False)처럼 이메일 전송 함수나 show_info(name, level=1, job="전사", hp=100)처럼 게임 캐릭터 정보를 출력하는 함수를 만들면 필요한 값만 선택적으로 지정할 수 있습니다.

보통
캐릭터 스탯을 출력하는 함수 show_info를 만드세요. 매개변수: name(필수), level(기본값 1), job(기본값 "전사"), hp(기본값 100). 아래 세 가지 방식으로 모두 호출하세요.
호출1 show_info("민수")
호출2 show_info("서연", job="마법사", level=5)
호출3 show_info("지호", 10, hp=250)
힌트 보기

정답 보기
def show_info(name, level=1, job="전사", hp=100): print(f"{name} | Lv.{level} {job} | HP:{hp}") show_info("민수") # 민수 | Lv.1 전사 | HP:100 show_info("서연", job="마법사", level=5) # 서연 | Lv.5 마법사 | HP:100 show_info("지호", 10, hp=250) # 지호 | Lv.10 전사 | HP:250

핵심 요약

핵심 요약 — 매개변수 심화

  • 기본값 매개변수: def f(a, b="기본값") — 인자 생략 시 기본값 자동 사용
  • 키워드 인자: f(b="값", a="값") — 이름으로 지정, 순서 무관
  • 위치 인자: 순서대로 전달, 첫 번째가 첫 매개변수에 매칭
  • 순서 규칙: 기본값 있는 매개변수는 반드시 오른쪽(뒤)에 배치
  • 섞어쓰기: 위치 인자 먼저, 그 다음에 키워드 인자
  • 중간 생략: 중간 기본값만 바꾸려면 키워드 인자를 사용
  • 실용 패턴: None 기본값으로 빈 컨테이너 안전하게 초기화

자주 나오는 패턴

  • 선택적 설정이 필요할 때 → 기본값 매개변수
  • 매개변수가 많아서 헷갈릴 때 → 키워드 인자로 명확하게
  • 일부 기본값만 바꿀 때 → 키워드 인자로 해당 것만 지정
  • Python 내장 함수 대부분이 이 패턴 사용: print(end="\n"), range(start, stop, step=1)

다음 유닛에서는 *args와 **kwargs로 개수가 정해지지 않은 인자를 받는 방법을 배웁니다.
