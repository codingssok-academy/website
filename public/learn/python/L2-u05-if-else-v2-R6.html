R6 — 종합 정리

조건문 완벽 치트시트

패턴코드 예시설명
단순 if if 조건: 실행 조건이 참일 때만 실행
if-else if 조건: A else: B 참이면 A, 거짓이면 B
if-elif-else if 조건1: A elif 조건2: B else: C 여러 조건 순서대로 검사
논리 연산 A and B  A or B  not A 조건 조합
범위 검사 1 <= x <= 10 파이썬 전용 연속 비교
포함 검사 x in [1,2,3]  x not in [...] 여러 값 중 하나인지 확인
삼항 연산자 A if 조건 else B 한 줄 if-else

핵심 규칙 3가지

1
조건 뒤에는 반드시 콜론(:). 빠뜨리면 SyntaxError
2
실행할 코드는 4칸 들여쓰기. 탭과 스페이스 섞으면 IndentationError
3
elif는 여러 개 쓸 수 있고, else는 맨 마지막에 딱 한 번만

다음 코드의 출력 결과를 맞혀보세요
Q1. 다음 코드의 출력은?
x = 5 if x > 3 and x < 10: print("A") elif x > 0: print("B") else: print("C")
A B A와 B 모두 C
정답 확인
A
x=5는 3보다 크고 10보다 작으므로 첫 번째 if가 참. elif는 검사하지 않고 건너뜀.
Q2. 다음 코드의 출력은?
result = "합격" if 75 >= 80 else "불합격" print(result)
합격 불합격 오류 발생
정답 확인
불합격
75 >= 80은 False이므로 else 부분인 "불합격"이 result에 저장됩니다.
Q3. 다음 코드의 출력은?
day = "수" if day in ["토", "일"]: print("주말") else: print("평일")
주말 평일 오류 발생
정답 확인
평일
"수"는 ["토", "일"] 리스트에 포함되지 않으므로 in 연산의 결과가 False → else 실행
Q4. 다음 코드의 출력은?
a = 10 b = 5 print("크다" if a > b else "작다" if a < b else "같다")
크다 작다 같다 오류
정답 확인
크다
a=10 > b=5이므로 첫 번째 조건(a > b)이 True → "크다" 출력. 삼항 연산자는 중첩도 가능하지만 가독성이 떨어지므로 주의.
