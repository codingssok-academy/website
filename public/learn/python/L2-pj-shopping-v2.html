프로젝트:
장보기 목록

리스트에 물건을 추가하고 삭제하며, 총 개수를 확인하는 장보기 앱을 만듭니다. while 메뉴로 사용자가 원하는 기능을 선택할 수 있게 합니다.

이 프로젝트에서 배우는 것

  • list.append()와 list.remove()로 항목을 추가/삭제합니다.
  • while True + 메뉴 번호로 사용자 인터페이스를 만듭니다.
  • in 연산자로 리스트에 항목이 있는지 확인합니다.
  • len()으로 목록 개수를 출력합니다.
  • 함수로 기능을 나눠 코드를 정리합니다.

Step 1 — 리스트에 추가하고 삭제하기

리스트에 항목을 추가할 때는 append(), 삭제할 때는 remove()를 씁니다. remove()는 값으로 삭제하는데, 없는 값을 삭제하려 하면 오류가 납니다.

# 장보기 목록 기본 조작 cart = [] # 추가 cart.append("사과") cart.append("우유") cart.append("달걀") print(cart) # ['사과', '우유', '달걀'] # 삭제 전에 있는지 확인 if "우유" in cart: cart.remove("우유") print("우유 삭제됨") else: print("우유가 목록에 없습니다") print(cart) # ['사과', '달걀']

목록 보기 함수

for 문으로 모든 항목을 번호와 함께 출력합니다. 총 개수는 len()으로 표시합니다. x in list를 사용하면 항목이 있는지 확인한 뒤 안전하게 삭제할 수 있습니다.

def show_cart(cart): print("\n[ 장보기 목록 ]") if not cart: print("목록이 비어있습니다.") return for i, item in enumerate(cart, 1): print(f" {i}. {item}") print(f"총 {len(cart)}개")

Step 2 — while 메뉴로 앱 완성하기

while True 루프 안에서 input으로 메뉴 번호를 받고, if/elif로 기능을 실행합니다. 4번을 선택하면 break로 종료합니다.

# 완성된 장보기 앱 cart = [] def show_menu(): print("\n1.추가 2.삭제 3.목록보기 4.종료") while True: show_menu() choice = input("선택: ") if choice == "1": item = input("추가할 물건: ") cart.append(item) print(f"{item} 추가됨") elif choice == "2": item = input("삭제할 물건: ") if item in cart: cart.remove(item) print(f"{item} 삭제됨") else: print("목록에 없습니다") elif choice == "3": for i, item in enumerate(cart, 1): print(f" {i}. {item}") print(f"총 {len(cart)}개") elif choice == "4": print("장보기 완료!") break

n = int(input("몇 번 삭제? ")) if 1 <= n <= len(cart): removed = cart.pop(n - 1) print(f"{n}번 '{removed}' 삭제됨") else: print("없는 번호입니다")

핵심 요약

  • list.append(x) — 끝에 추가 / list.remove(x) — 값으로 삭제
  • list.pop(i) — 인덱스로 삭제하고 값 반환
  • list.clear() — 전체 비우기
  • x in list — 리스트에 x가 있는지 확인 (True/False)
  • while True + if/elif + break — 메뉴 패턴
