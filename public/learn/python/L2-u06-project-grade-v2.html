성적 관리

input, 변수, 조건문을 종합하여 성적 관리 프로그램을 완성합니다.

게임 랭크처럼, 점수에 따라 등급을 매긴다

이 프로젝트에서 만드는 것

  • 세 과목 점수를 입력받아 평균을 계산합니다.
  • if-elif-else로 등급(A~F)을 판정합니다.
  • 합격/불합격을 판정하고 결과를 출력합니다.
  • 보너스: 게임 랭크 판정기를 만듭니다.

Step 1 — 점수 입력과 평균 계산

세 과목(국어, 영어, 수학) 점수를 입력받고, 합계와 평균을 계산합니다.

# Step 1: 점수 입력 kor = int(input("국어 점수: ")) eng = int(input("영어 점수: ")) math = int(input("수학 점수: ")) # Step 2: 합계와 평균 total = kor + eng + math avg = total / 3 print("합계:", total) print("평균:", avg)
따라해보세요
1
위 코드를 입력하고 85, 92, 78을 넣어보세요.
# 실행 결과 확인 # 합계: 255 # 평균: 85.0
합계 255, 평균 85.0이 나오면 성공
2
평균을 소수점 첫째 자리까지 깔끔하게 출력하세요.
print(f"평균: {avg:.1f}점")
평균: 85.0점 — f-string으로 포맷팅
3
탭으로 성적표를 깔끔하게 출력하세요.
print("=== 성적표 ===") print("국어\t영어\t수학") print(f"{kor}\t{eng}\t{math}") print(f"합계: {total} / 평균: {avg:.1f}")
깔끔한 성적표가 출력됩니다

Step 2 — 등급 판정

평균 점수에 따라 A, B, C, D, F 등급을 매깁니다.

# Step 3: 등급 판정 if avg >= 90: grade = "A" elif avg >= 80: grade = "B" elif avg >= 70: grade = "C" elif avg >= 60: grade = "D" else: grade = "F" print(f"등급: {grade}")
따라해보세요
1
Step 1과 Step 2를 합쳐서 전체 코드를 완성하세요.
kor = int(input("국어: ")) eng = int(input("영어: ")) math = int(input("수학: ")) total = kor + eng + math avg = total / 3 if avg >= 90: grade = "A" elif avg >= 80: grade = "B" elif avg >= 70: grade = "C" elif avg >= 60: grade = "D" else: grade = "F" print(f"평균: {avg:.1f} / 등급: {grade}")
85, 92, 78 → 평균: 85.0 / 등급: B
2
합격/불합격 판정을 추가하세요 (평균 60 이상이면 합격).
if avg >= 60: print("합격입니다!") else: print("불합격입니다...")
평균 60 이상이면 "합격입니다!" 출력
3
최고/최저 과목을 찾아 출력하세요.
if kor >= eng and kor >= math: best = "국어" elif eng >= kor and eng >= math: best = "영어" else: best = "수학" print(f"최고 과목: {best}")
85, 92, 78 → "최고 과목: 영어"

Step 3 — 성적 관리 프로그램 완성

모든 단계를 합쳐 하나의 완성된 프로그램을 만듭니다.

# === 성적 관리 프로그램 === print("=== 성적 관리 프로그램 ===") # 1. 입력 kor = int(input("국어 점수: ")) eng = int(input("영어 점수: ")) math = int(input("수학 점수: ")) # 2. 계산 total = kor + eng + math avg = total / 3 # 3. 등급 판정 if avg >= 90: grade = "A" elif avg >= 80: grade = "B" elif avg >= 70: grade = "C" elif avg >= 60: grade = "D" else: grade = "F" # 4. 합격 여부 if avg >= 60: result = "합격" else: result = "불합격" # 5. 결과 출력 print("====================") print(f"국어: {kor} / 영어: {eng} / 수학: {math}") print(f"합계: {total} / 평균: {avg:.1f}") print(f"등급: {grade} / 결과: {result}") print("====================")

보너스 프로젝트 — 게임 랭크 판정기

게임 점수를 입력받아 랭크를 매기는 프로그램을 만듭니다. 학교 성적과 같은 구조지만, 더 재미있는 주제입니다!

# === 게임 랭크 판정기 === print("=== 게임 랭크 판정기 ===") name = input("닉네임: ") score = int(input("점수: ")) if score >= 1000: rank = "Master" msg = "전설의 플레이어!" elif score >= 800: rank = "Diamond" msg = "최상위권입니다!" elif score >= 600: rank = "Gold" msg = "실력이 좋아요!" elif score >= 400: rank = "Silver" msg = "꾸준히 성장 중!" else: rank = "Bronze" msg = "시작이 반이다!" print(f"플레이어: {name}") print(f"점수: {score} → 랭크: {rank}") print(msg)
따라해보세요
1
게임 랭크 판정기를 입력하고 자기 닉네임과 점수를 넣어보세요.
# 직접 실행해보세요! # 1200점 → Master # 850점 → Diamond # 350점 → Bronze
다양한 점수를 넣어 랭크가 바뀌는지 확인
2
다음 랭크까지 남은 점수를 알려주세요.
if rank == "Master": print("이미 최고 랭크!") elif rank == "Diamond": print(f"Master까지 {1000 - score}점 남음") elif rank == "Gold": print(f"Diamond까지 {800 - score}점 남음") elif rank == "Silver": print(f"Gold까지 {600 - score}점 남음") else: print(f"Silver까지 {400 - score}점 남음")
750점 → "Diamond까지 50점 남음"
3
상위 몇 %인지 출력하세요 (최고 1500점 기준).
percent = (score / 1500) * 100 print(f"상위 {100 - percent:.1f}%")
750점 → "상위 50.0%"

응용 — 입력값 검증하기

사용자가 잘못된 값을 입력할 수 있습니다. 0~100 범위를 벗어나면 경고를 출력합니다.

print("=== 성적 관리 (검증 포함) ===") kor = int(input("국어: ")) eng = int(input("영어: ")) math = int(input("수학: ")) # 입력 검증 if 0 <= kor <= 100 and 0 <= eng <= 100 and 0 <= math <= 100: total = kor + eng + math avg = total / 3 if avg >= 90: grade = "A" elif avg >= 80: grade = "B" elif avg >= 70: grade = "C" elif avg >= 60: grade = "D" else: grade = "F" print(f"평균: {avg:.1f} / 등급: {grade}") else: print("오류: 0~100 사이의 점수만 입력하세요!")

보통

힘 >= 80: 전사 / 지능 >= 80: 마법사 / 둘 다 60 이상: 기사 / 그 외: 모험가
입력45 / 90

Q3
시험 결과 분석기
보통
세 과목 점수를 입력받아 다음을 모두 출력하세요.
1) 합계, 평균 (소수점 1자리)
2) 등급 (A/B/C/D/F)
3) 가장 높은 과목 이름
4) 모든 과목 60점 이상이면 "전과목 합격", 아니면 "재시험 필요"
입력90 / 55 / 80
출력합계:225 평균:75.0 등급:C 최고:국어 재시험 필요
내 답안
힌트 보기
등급 판정과 최고 과목 찾기를 각각 if-elif-else로 작성하세요. 전과목 합격은 and로 세 과목 모두 검사하세요.
정답 확인
kor = int(input("국어: ")) eng = int(input("영어: ")) math = int(input("수학: ")) total = kor + eng + math avg = total / 3 if avg >= 90: grade = "A" elif avg >= 80: grade = "B" elif avg >= 70: grade = "C" elif avg >= 60: grade = "D" else: grade = "F" if kor >= eng and kor >= math: best = "국어" elif eng >= kor and eng >= math: best = "영어" else: best = "수학" print(f"합계:{total} 평균:{avg:.1f} 등급:{grade} 최고:{best}") if kor >= 60 and eng >= 60 and math >= 60: print("전과목 합격") else: print("재시험 필요")

핵심 요약

이 프로젝트에서 배운 것

  • input()으로 여러 값을 입력받아 변수에 저장한다
  • 산술 연산으로 합계와 평균을 계산한다
  • if-elif-else로 등급을 판정한다
  • f"..." (f-string)으로 변수 값을 문자열에 삽입한다
  • {avg:.1f}로 소수점 자릿수를 지정한다
  • 입력값 검증으로 잘못된 데이터를 걸러낸다
  • and로 여러 조건을 동시에 검사한다
