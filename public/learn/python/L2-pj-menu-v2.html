프로젝트:
분식집 메뉴판

딕셔너리로 메뉴와 가격을 저장하고, 주문을 받아 총 금액을 계산하는 분식집 포스(POS) 시스템을 만듭니다.

이 프로젝트에서 배우는 것

  • {"키": 값} 딕셔너리로 메뉴와 가격을 짝지어 저장합니다.
  • dict[key]로 특정 메뉴의 가격을 가져옵니다.
  • for key in dict로 전체 메뉴를 출력합니다.
  • dict.get(key)로 없는 키를 안전하게 조회합니다.
  • 주문 수량과 가격을 곱해 총액을 계산합니다.

Step 1 — 딕셔너리로 메뉴 만들기

딕셔너리는 키(key): 값(value) 쌍으로 데이터를 저장합니다. 메뉴 이름을 키, 가격을 값으로 저장하면 이름으로 가격을 바로 찾을 수 있습니다.

# 분식집 메뉴 딕셔너리 menu = { "떡볶이": 3000, "순대": 2500, "라면": 3500, "김밥": 2000, "튀김": 1000 } # 가격 조회 print(menu["떡볶이"]) # 3000 print(menu.get("치킨")) # None (없는 키, 오류 없음) # 전체 메뉴 출력 print("=== 메뉴판 ===") for name, price in menu.items(): print(f" {name}: {price:,}원")
=== 메뉴판 === 떡볶이: 3,000원 순대: 2,500원 라면: 3,500원 김밥: 2,000원 튀김: 1,000원

Step 2 — 주문 받고 총액 계산하기

while 루프로 주문을 계속 받고, 딕셔너리로 메뉴 유무를 확인하며, 수량 * 가격으로 총 금액을 계산합니다.

# 분식집 주문 시스템 menu = {"떡볶이":3000, "순대":2500, "라면":3500, "김밥":2000} order = {} total = 0 while True: item = input("주문 (종료: quit): ") if item == "quit": break if item not in menu: print("메뉴에 없습니다.") continue qty = int(input(f"{item} 수량: ")) order[item] = order.get(item, 0) + qty total += menu[item] * qty print(f"소계: {menu[item] * qty:,}원") print("\n===== 영수증 =====") for name, qty in order.items(): print(f" {name} x{qty}: {menu[name]*qty:,}원") print(f"합계: {total:,}원")

출력가장 비싼 메뉴: 라면 (3,500원)
힌트 / 정답 보기

most = max(menu, key=menu.get) print(f"가장 비싼 메뉴: {most} ({menu[most]:,}원)")

if item == "사장": act = input("추가(a)/삭제(d): ") if act == "a": name = input("메뉴명: ") price = int(input("가격: ")) menu[name] = price print(f"{name}({price:,}원) 추가됨") elif act == "d": name = input("삭제할 메뉴: ") if name in menu: del menu[name] print(f"{name} 삭제됨")
# 메뉴 순회 패턴 요약 for name in menu: # 키만 순회 print(name) for price in menu.values(): # 값만 순회 print(price) for n, p in menu.items(): # 키+값 동시 순회 print(f"{n}: {p}원")

핵심 요약

  • {"key": value} — 딕셔너리 생성. 키로 값을 빠르게 조회
  • dict[key] — 값 조회 (없으면 KeyError) / dict.get(key) — 없으면 None
  • for k, v in dict.items() — 키와 값을 동시에 순회
  • dict[key] = val — 추가 또는 수정 / del dict[key] — 삭제
  • key in dict — 키 존재 여부 확인
