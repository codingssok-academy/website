얼굴 인식
Haar Cascade

사진이나 웹캠에서 사람 얼굴을 자동으로 찾아내는 Haar Cascade 알고리즘을 배웁니다. 얼굴 위에 사각형을 그리고 실시간 인식까지 구현해봅니다.

이 유닛에서 배우는 것

  • Haar Cascade가 무엇인지, 어떤 원리로 얼굴을 찾는지 이해합니다.
  • cv2.CascadeClassifier()로 학습된 모델을 불러옵니다.
  • detectMultiScale()로 이미지에서 얼굴 좌표를 추출합니다.
  • 감지된 얼굴 위에 사각형을 그려 결과를 시각화합니다.
  • 웹캠으로 실시간 얼굴 인식 프로그램을 만들어봅니다.

Haar Cascade란?

Haar Cascade는 2001년 Viola-Jones가 개발한 얼굴 감지 알고리즘입니다. 수천 장의 얼굴 사진으로 학습된 분류기(Classifier)로, 이미지에서 얼굴처럼 생긴 패턴을 빠르게 찾아냅니다.

학습된 모델 파일 위치

OpenCV를 설치하면 학습된 Haar Cascade XML 파일들이 함께 설치됩니다.

import cv2 import os # OpenCV의 haarcascades 폴더 위치 확인 cascade_path = cv2.data.haarcascades print(cascade_path) # C:/Python/lib/site-packages/cv2/data/ # 얼굴 검출용 파일 face_xml = cascade_path + "haarcascade_frontalface_default.xml" print("파일 존재?", os.path.exists(face_xml)) # True
import cv2 # Cascade 분류기 불러오기 cascade_path = cv2.data.haarcascades face_cascade = cv2.CascadeClassifier( cascade_path + "haarcascade_frontalface_default.xml" ) print("모델 로드 완료")

얼굴 검출 — detectMultiScale()

detectMultiScale()은 이미지에서 얼굴을 찾아 각 얼굴의 (x, y, w, h) 좌표를 반환합니다. x, y는 왼쪽 위 모서리, w는 너비, h는 높이입니다.

import cv2 cascade_path = cv2.data.haarcascades face_cascade = cv2.CascadeClassifier( cascade_path + "haarcascade_frontalface_default.xml" ) img = cv2.imread("group.jpg") gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY) # detectMultiScale(흑백이미지, scaleFactor, minNeighbors) faces = face_cascade.detectMultiScale( gray, scaleFactor=1.1, # 이미지 축소 비율 (1.1 = 10%씩) minNeighbors=5, # 최소 이웃 사각형 수 (높을수록 엄격) minSize=(30, 30) # 최소 얼굴 크기 ) print(f"감지된 얼굴 수: {len(faces)}개")

감지된 얼굴에 사각형 그리기

# 각 얼굴에 초록 사각형 그리기 for (x, y, w, h) in faces: cv2.rectangle(img, (x, y), (x+w, y+h), (0, 255, 0), 3) # 얼굴 번호도 표시 cv2.putText(img, "Face", (x, y-10), cv2.FONT_HERSHEY_SIMPLEX, 0.7, (0, 255, 0), 2) cv2.imwrite("result.jpg", img) print("저장 완료")

웹캠 실시간 얼굴 인식

cv2.VideoCapture(0)으로 웹캠을 열어 실시간으로 프레임을 읽고, 매 프레임마다 얼굴을 감지합니다.

import cv2 cascade_path = cv2.data.haarcascades face_cascade = cv2.CascadeClassifier( cascade_path + "haarcascade_frontalface_default.xml" ) # 웹캠 열기 (0 = 기본 카메라) cap = cv2.VideoCapture(0) while True: ret, frame = cap.read() # 프레임 읽기 if not ret: break gray = cv2.cvtColor(frame, cv2.COLOR_BGR2GRAY) faces = face_cascade.detectMultiScale(gray, 1.1, 5) for (x, y, w, h) in faces: cv2.rectangle(frame, (x,y), (x+w, y+h), (0,255,0), 3) cv2.imshow("Face Detection", frame) if cv2.waitKey(1) == ord('q'): # q 누르면 종료 break cap.release() cv2.destroyAllWindows()

핵심 요약

  • Haar Cascade — 수천 장 학습된 XML 파일 기반 얼굴 검출 알고리즘
  • cv2.data.haarcascades — OpenCV 내장 XML 파일 경로
  • cv2.CascadeClassifier(xml_path) — 분류기 로드
  • detectMultiScale(gray, scaleFactor, minNeighbors) — 얼굴 좌표 반환
  • 반환값 [x, y, w, h] — 왼쪽 위 좌표 + 너비 + 높이
  • cv2.VideoCapture(0) — 웹캠 열기, cap.read()로 프레임 읽기
  • 종료 시 cap.release(), cv2.destroyAllWindows() 호출 필수
