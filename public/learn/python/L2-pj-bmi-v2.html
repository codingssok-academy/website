BMI 계산기

키와 몸무게를 입력받아 BMI를 계산하고 체중 상태를 판정하는 프로그램을 만듭니다.

이 프로젝트에서 배우는 것

  • float()로 소수점 숫자를 입력받을 수 있습니다.
  • BMI 공식(몸무게 / 키^2)을 코드로 구현할 수 있습니다.
  • if/elif/else로 조건에 따라 다른 메시지를 출력할 수 있습니다.
  • f-string으로 소수점 자릿수를 조절할 수 있습니다.
  • 실생활 데이터를 활용한 프로그램을 만들 수 있습니다.

BMI란 무엇인가?

BMI(Body Mass Index)는 키와 몸무게로 체중 상태를 파악하는 지수입니다. 공식은 간단합니다.

예를 들어 키 170cm, 몸무게 65kg이면: BMI = 65 / (1.7 × 1.7) = 65 / 2.89 = 22.49

파이썬에서 키를 m 단위로 바꾸는 것이 핵심입니다. cm를 100으로 나누면 m로 변환됩니다.

# 키 단위 변환 height_cm = float(input("키를 입력하세요(cm): ")) height_m = height_cm / 100 # cm → m 변환 print(f"키: {height_cm}cm = {height_m}m")
따라해보세요
1
키를 cm로 입력받아 m로 변환해서 출력하세요.
height_cm = float(input("키(cm): ")) height_m = height_cm / 100 print(f"키: {height_m}m")
170 입력 시 키: 1.7m 출력
2
몸무게도 함께 입력받고, BMI를 계산해보세요.
height_cm = float(input("키(cm): ")) weight = float(input("몸무게(kg): ")) height_m = height_cm / 100 bmi = weight / (height_m * height_m) print(f"BMI: {bmi}")
170cm, 65kg 입력 시 BMI: 22.49...가 나옵니다
3
BMI를 소수점 2자리로 반올림해서 출력하세요.
height_cm = float(input("키(cm): ")) weight = float(input("몸무게(kg): ")) height_m = height_cm / 100 bmi = weight / (height_m * height_m) print(f"BMI: {bmi:.2f}")
BMI: 22.49처럼 깔끔하게 출력됩니다

if/elif로 체중 판정하기

BMI 값에 따라 if, elif, else로 다른 판정 메시지를 출력합니다.

# BMI 판정 (if/elif/else) if bmi < 18.5: result = "저체중" elif bmi < 25: result = "정상" elif bmi < 30: result = "과체중" else: result = "비만" print(f"판정: {result}")
따라해보세요
1
if/elif/else로 판정 메시지를 출력하는 코드를 만들고, BMI 22를 테스트하세요.
bmi = float(input("BMI 값: ")) if bmi < 18.5: print("저체중") elif bmi < 25: print("정상") else: print("과체중 이상")
22 입력 시 "정상" 출력
2
BMI 17, 27, 35를 각각 입력해서 판정이 맞는지 확인하세요.
bmi = float(input("BMI: ")) if bmi < 18.5: result = "저체중" elif bmi < 25: result = "정상" elif bmi < 30: result = "과체중" else: result = "비만" print(result)
17→저체중, 27→과체중, 35→비만
3
판정 결과에 따라 다른 조언 메시지도 출력해보세요.
bmi = 22.5 if bmi < 18.5: msg = "더 많이 드세요!" elif bmi < 25: msg = "건강한 체중입니다!" else: msg = "운동을 시작해보세요!" print(msg)
건강한 체중입니다! 출력

완성: BMI 계산기 전체 코드

지금까지 배운 내용을 합쳐서 완전한 BMI 계산기를 만듭니다.

# BMI 계산기 — 완성 버전 print("=== BMI 계산기 ===") height_cm = float(input("키를 입력하세요(cm): ")) weight = float(input("몸무게를 입력하세요(kg): ")) height_m = height_cm / 100 bmi = weight / (height_m * height_m) if bmi < 18.5: result = "저체중" advice = "영양 섭취를 늘려보세요." elif bmi < 25: result = "정상" advice = "건강한 체중입니다!" elif bmi < 30: result = "과체중" advice = "운동을 시작해보세요." else: result = "비만" advice = "전문가 상담을 추천합니다." print(f"\n--- 결과 ---") print(f"키: {height_cm}cm / 몸무게: {weight}kg") print(f"BMI: {bmi:.2f}") print(f"판정: {result}") print(f"조언: {advice}")

핵심 요약

이 유닛에서 배운 것

  • float(input())으로 소수점 숫자를 입력받는다
  • cm 단위를 / 100으로 m 단위로 변환한다
  • BMI 공식: 몸무게(kg) / (키(m) * 키(m))
  • if / elif / else로 조건에 따라 다른 결과를 출력한다
  • f"{bmi:.2f}"로 소수점 2자리까지 출력한다
  • 변수에 판정 결과 문자열을 저장한 뒤 한 번에 출력하면 코드가 깔끔해진다
