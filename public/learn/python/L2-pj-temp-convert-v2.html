온도 변환기

함수로 섭씨↔화씨를 변환하고, 메뉴로 방향을 선택하는 프로그램을 만듭니다.

이 프로젝트에서 배우는 것

  • def 키워드로 함수를 정의하고 return으로 값을 반환할 수 있습니다.
  • 매개변수를 받아 계산 결과를 돌려주는 순수 함수를 만들 수 있습니다.
  • input()으로 메뉴를 선택하고 if/elif로 분기처리를 할 수 있습니다.
  • while True 루프로 계속 실행되는 프로그램을 만들 수 있습니다.
  • 함수를 호출해 실제 계산을 수행하는 방법을 이해합니다.

변환 함수 만들기

def로 함수를 정의하면 같은 계산을 여러 번 재사용할 수 있습니다. 온도 변환 공식을 함수로 만들어봅니다.

# 섭씨 → 화씨 변환 함수 def celsius_to_fahrenheit(c): f = c * 9 / 5 + 32 return f # 화씨 → 섭씨 변환 함수 def fahrenheit_to_celsius(f): c = (f - 32) * 5 / 9 return c

함수를 만들었으면 함수이름(값)으로 호출할 수 있습니다.

# 함수 호출 예시 result = celsius_to_fahrenheit(100) print(result) # 212.0 출력 result2 = fahrenheit_to_celsius(32) print(result2) # 0.0 출력

섭씨 0도를 화씨로 변환하는 함수를 만들고 결과를 출력하세요.
def c_to_f(c): return c * 9 / 5 + 32 print(c_to_f(0)) # 32.0 print(c_to_f(100)) # 212.0

화씨 98.6을 섭씨로 변환하는 함수를 만들고 체온을 확인하세요.
def f_to_c(f): return (f - 32) * 5 / 9 print(f_to_c(98.6)) # 37.0
98.6°F → 37.0°C (정상 체온)
3
변환 결과를 소수점 1자리로 출력하는 함수를 만드세요.
def c_to_f(c): f = c * 9 / 5 + 32 return round(f, 1) print(c_to_f(37)) # 98.6
37°C → 98.6°F

메뉴로 방향 선택하기

사용자가 원하는 변환 방향을 선택할 수 있도록 메뉴를 만들어봅니다. while True로 계속 반복하다가 '3'을 입력하면 종료합니다.

# 메뉴 반복 루프 while True: print("\n=== 온도 변환기 ===") print("1. 섭씨 → 화씨") print("2. 화씨 → 섭씨") print("3. 종료") choice = input("선택: ") if choice == "1": c = float(input("섭씨: ")) print(f"→ 화씨: {celsius_to_fahrenheit(c):.1f}°F") elif choice == "2": f = float(input("화씨: ")) print(f"→ 섭씨: {fahrenheit_to_celsius(f):.1f}°C") elif choice == "3": print("프로그램 종료!") break else: print("1, 2, 3 중에 선택하세요!")

완성: 온도 변환기 전체 코드

함수 정의와 메뉴 루프를 합쳐 완전한 프로그램을 만듭니다.

# 온도 변환기 — 완성 버전 def celsius_to_fahrenheit(c): """섭씨를 화씨로 변환""" return c * 9 / 5 + 32 def fahrenheit_to_celsius(f): """화씨를 섭씨로 변환""" return (f - 32) * 5 / 9 while True: print("\n=== 온도 변환기 ===") print("1. 섭씨(°C) → 화씨(°F)") print("2. 화씨(°F) → 섭씨(°C)") print("3. 종료") choice = input("원하는 기능을 선택하세요: ") if choice == "1": c = float(input("섭씨 온도를 입력하세요: ")) f = celsius_to_fahrenheit(c) print(f"{c}°C = {f:.1f}°F") elif choice == "2": f = float(input("화씨 온도를 입력하세요: ")) c = fahrenheit_to_celsius(f) print(f"{f}°F = {c:.1f}°C") elif choice == "3": print("프로그램을 종료합니다!") break else: print("잘못된 선택입니다. 1, 2, 3 중에 입력하세요.")

핵심 요약

이 유닛에서 배운 것

  • def 함수이름(매개변수): 로 함수를 정의한다
  • return 값 으로 계산 결과를 돌려준다
  • 함수를 만들면 같은 계산을 여러 번 재사용할 수 있다
  • while True: + break 로 메뉴 반복 루프를 만든다
  • 섭씨→화씨: c * 9/5 + 32, 화씨→섭씨: (f-32) * 5/9
  • 함수 이름은 역할을 잘 설명하는 이름으로 짓는다
