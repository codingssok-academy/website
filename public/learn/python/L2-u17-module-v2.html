Chapter 17

모듈과 패키지

코드를 파일로 나누고, 남이 만든 코드를 가져다 쓰는 방법을 배웁니다.

이 유닛에서 배우는 것

  • import로 표준 모듈을 불러올 수 있습니다.
  • from ... import로 특정 함수만 가져올 수 있습니다.
  • as를 이용해 모듈에 별칭을 붙일 수 있습니다.
  • 직접 모듈 파일(.py)을 만들어서 사용할 수 있습니다.
  • __name__과 if __name__ == "__main__"의 의미를 이해합니다.

import — 모듈 불러오기

import는 다른 파일에 있는 코드를 가져오는 명령입니다. 파이썬에는 미리 만들어둔 표준 모듈이 수백 개 있습니다.

import random num = random.randint(1, 6) print("주사위:", num)
따라해보세요
1
random 모듈로 주사위를 굴려보세요.
import random print(random.randint(1, 6))
1~6 사이의 랜덤 숫자가 출력됩니다
2
math 모듈로 제곱근을 구해보세요.
import math print(math.sqrt(144))
12.0 이 출력됩니다
3
datetime으로 오늘 날짜를 출력해보세요.
import datetime today = datetime.date.today() print("오늘:", today)
오늘: 2026-03-21 형태로 출력됩니다

from ... import — 골라서 가져오기

from 모듈 import 함수를 쓰면 모듈 이름 없이 바로 함수를 사용할 수 있습니다.

from random import randint, choice print(randint(1, 100)) # random. 없이 바로 fruits = ["사과", "바나나", "포도"] print(choice(fruits)) # 하나를 랜덤 선택

as — 별칭 붙이기

모듈 이름이 길 때 as로 짧은 이름을 붙여 편하게 씁니다.

import datetime as dt today = dt.date.today() print("오늘:", today)
따라해보세요
1
from으로 math.pi를 직접 가져와보세요.
from math import pi, sqrt print("원주율:", pi) print("루트9:", sqrt(9))
원주율: 3.141592... 와 루트9: 3.0
2
as로 별칭을 지어보세요.
import random as rd print(rd.randint(1, 100))
rd라는 짧은 이름으로 사용 가능
3
from ... import *를 써보고, 왜 위험한지 생각해보세요.
from math import * print(ceil(3.2)) # 4 print(floor(3.8)) # 3
편하지만 이름 충돌 위험 — 실무에서는 피함

내 모듈 만들기

파이썬 파일(.py) 하나가 곧 모듈입니다. 함수를 모아둔 파일을 만들면 다른 파일에서 import할 수 있습니다.

mytools.py (도구 모듈)

def greet(name): return f"안녕, {name}!" def add(a, b): return a + b def square(n): return n ** 2

main.py (실행 파일)

import mytools print(mytools.greet("자현")) # 안녕, 자현! print(mytools.add(3, 5)) # 8 print(mytools.square(4)) # 16

__name__ 이해하기

파일을 직접 실행하면 __name__은 "__main__"이 됩니다. 다른 파일에서 import하면 모듈 이름이 됩니다.

# mytools.py 끝에 추가 if __name__ == "__main__": # 직접 실행할 때만 동작 (import 시 무시) print(greet("테스트")) print(add(10, 20))

import time for i in range(3, 0, -1): print(i) time.sleep(1) print("출발!")
3, 2, 1, 출발! 이 1초 간격으로 출력

from random import choice menus = ["피자", "치킨", "햄버거", "떡볶이"] print("오늘의 메뉴:", choice(menus))

import os print("현재 위치:", os.getcwd()) print("파일 목록:", os.listdir("."))
현재 디렉토리 경로와 파일 목록 출력

Q1
로또 번호 생성기
쉬움
random 모듈을 사용해서 1~45 사이의 서로 다른 숫자 6개를 출력하세요.
출력[3, 12, 18, 27, 33, 41] (매번 다름)
내 답안
힌트 보기
random.sample(range(1, 46), 6)을 사용해보세요.
정답 확인
import random numbers = random.sample(range(1, 46), 6) numbers.sort() print(numbers)
Q2
나만의 계산기 모듈
보통
calc.py 파일에 add, sub, mul, div 함수를 만들고, main.py에서 import하여 사용하세요.
출력add(10, 3) = 13 / div(10, 3) = 3.33...
내 답안
힌트 보기
각 함수는 return으로 결과를 돌려줘야 합니다.
정답 확인
# calc.py def add(a, b): return a + b def sub(a, b): return a - b def mul(a, b): return a * b def div(a, b): return a / b # main.py from calc import add, sub, mul, div print(add(10, 3)) # 13 print(div(10, 3)) # 3.333...
Q3
비밀번호 생성기
보통
random과 string 모듈을 사용해서 영문+숫자 8자리 랜덤 비밀번호를 생성하세요.
출력비밀번호: aB3xK9mQ (매번 다름)
내 답안
힌트 보기
string.ascii_letters + string.digits로 문자 풀을 만들고 random.choices()를 사용하세요.
정답 확인
import random import string chars = string.ascii_letters + string.digits pw = "".join(random.choices(chars, k=8)) print("비밀번호:", pw)

핵심 요약

이 유닛에서 배운 것

  • import 모듈로 표준 모듈을 불러온다
  • from 모듈 import 함수로 특정 함수만 가져온다
  • import 모듈 as 별칭으로 짧은 이름을 붙인다
  • .py 파일 하나가 곧 모듈이다 — 직접 만들어서 import 가능
  • if __name__ == "__main__":으로 직접 실행 시에만 동작하는 코드를 작성한다
