OpenCV 종합 프로젝트

지금까지 배운 모든 기술을 하나로 합칩니다. 흑백/블러/엣지/모자이크 필터 메뉴, 얼굴 자동 모자이크, 결과 저장까지 — 진짜 앱을 만들어봅니다.

이 프로젝트에서 만드는 것

  • 사용자가 1~5 중 필터를 선택하는 메뉴 인터페이스를 만듭니다.
  • 흑백, 블러, 엣지, 모자이크 필터를 함수로 구현합니다.
  • 얼굴을 자동 감지해서 해당 영역만 모자이크 처리합니다.
  • 선택한 필터를 적용한 결과를 파일로 저장합니다.
  • 한 파일에 모든 기능을 깔끔하게 통합하는 설계를 배웁니다.

프로젝트 설계 — 함수 분리

큰 프로그램은 기능별로 함수를 나눠서 만들어야 유지보수하기 쉽습니다. 이 프로젝트는 5개의 필터 함수 + 1개의 메인 함수로 구성합니다.

모자이크 필터 구현

모자이크는 이미지를 작게 줄였다가 다시 크게 늘리면 픽셀이 뭉개져서 만들어집니다. cv2.resize()를 활용합니다.

import cv2 def apply_mosaic(img, scale=10): """이미지를 모자이크 처리합니다.""" h, w = img.shape[:2] # 1. 작게 축소 (픽셀 수 줄이기) small = cv2.resize(img, (w // scale, h // scale), interpolation=cv2.INTER_LINEAR) # 2. 원래 크기로 확대 (픽셀 뭉개짐) mosaic = cv2.resize(small, (w, h), interpolation=cv2.INTER_NEAREST) return mosaic

얼굴 자동 모자이크

얼굴을 감지한 뒤 해당 영역 ROI(Region of Interest)만 잘라서 모자이크를 적용하고, 원본 이미지에 다시 붙여넣습니다.

def apply_face_mosaic(img): """얼굴 영역만 자동으로 모자이크 처리합니다.""" result = img.copy() gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY) cascade_path = cv2.data.haarcascades face_cascade = cv2.CascadeClassifier( cascade_path + "haarcascade_frontalface_default.xml" ) faces = face_cascade.detectMultiScale(gray, 1.1, 5) for (x, y, w, h) in faces: # ROI 추출 (얼굴 영역만 잘라내기) roi = result[y:y+h, x:x+w] # ROI에 모자이크 적용 small = cv2.resize(roi, (w//10, h//10)) mosaiced = cv2.resize(small, (w, h), interpolation=cv2.INTER_NEAREST) # 원본에 붙이기 result[y:y+h, x:x+w] = mosaiced print(f"{len(faces)}개 얼굴에 모자이크 적용") return result
NumPy 슬라이싱으로 ROI 접근

img[y:y+h, x:x+w]는 NumPy 2D 슬라이싱입니다. 이미지의 특정 영역(ROI)을 잘라내거나 수정할 때 사용합니다.

필터 앱에 세피아 필터 추가
어려움
세피아(Sepia) 필터는 흑백으로 변환 후 따뜻한 갈색 톤으로 컬러 채널을 조절합니다. apply_sepia 함수를 완성하고 메뉴에 추가하세요. (힌트: B*0.272 + G*0.534 + R*0.131 방식)
내 답안
힌트 보기
cv2.transform()과 변환 행렬을 사용하거나, numpy를 이용해 각 채널 값을 직접 계산할 수 있습니다. np.clip()으로 255를 초과하는 값을 잘라냅니다.
정답 보기
import cv2 import numpy as np def apply_sepia(img): img_float = img.astype(np.float64) sepia = np.zeros_like(img_float) # BGR 순서로 변환 행렬 적용 sepia[:,:,0] = np.clip( img_float[:,:,0]*0.272 + img_float[:,:,1]*0.534 + img_float[:,:,2]*0.131, 0, 255) sepia[:,:,1] = np.clip( img_float[:,:,0]*0.349 + img_float[:,:,1]*0.686 + img_float[:,:,2]*0.168, 0, 255) sepia[:,:,2] = np.clip( img_float[:,:,0]*0.393 + img_float[:,:,1]*0.769 + img_float[:,:,2]*0.189, 0, 255) return sepia.astype(np.uint8)

핵심 요약

  • 모자이크 = resize(img, small_size) -> resize(small, original_size, INTER_NEAREST)
  • ROI (Region of Interest) = img[y:y+h, x:x+w] NumPy 슬라이싱
  • 얼굴 모자이크 = 감지 -> ROI 추출 -> 모자이크 적용 -> 원본에 붙이기
  • 함수 분리 설계: 각 필터를 독립 함수로 만들면 유지보수 쉬움
  • 딕셔너리 메뉴: {"1": func1, "2": func2}[choice](img)
  • 컨버전 주의: Canny/흑백 결과는 1채널 -> 저장 전 3채널로 변환
