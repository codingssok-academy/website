Chapter 11

리스트

여러 데이터를 하나로 묶어 저장하고, 추가/삭제/정렬하는 방법을 배웁니다.

이 유닛에서 배우는 것

  • 리스트를 만들고 인덱싱/슬라이싱으로 요소를 꺼낼 수 있습니다.
  • append(), insert(), remove(), pop()으로 요소를 추가/삭제할 수 있습니다.
  • sort()와 sorted()로 리스트를 정렬할 수 있습니다.
  • for문으로 리스트를 순회할 수 있습니다.
  • 리스트 컴프리헨션으로 간결하게 리스트를 생성할 수 있습니다.

리스트 만들기

리스트는 여러 값을 대괄호 [] 안에 쉼표로 구분하여 저장합니다. 어떤 타입이든 넣을 수 있습니다.

fruits = ["사과", "바나나", "포도"] numbers = [10, 20, 30, 40, 50] mixed = ["이름", 15, True] empty = [] # 빈 리스트
따라해보세요
1
리스트를 만들고 인덱싱으로 꺼내보세요.
colors = ["빨강", "파랑", "초록"] print(colors[0]) # 빨강 print(colors[-1]) # 초록 print(len(colors)) # 3
인덱스는 문자열과 같은 방식입니다
2
리스트를 슬라이싱해보세요.
nums = [10, 20, 30, 40, 50] print(nums[1:4]) # [20, 30, 40] print(nums[::2]) # [10, 30, 50]
문자열 슬라이싱과 동일한 규칙
3
리스트 요소를 수정해보세요.
colors = ["빨강", "파랑", "초록"] colors[1] = "노랑" print(colors) # ['빨강', '노랑', '초록']
문자열과 달리 리스트는 값을 바꿀 수 있습니다

요소 추가와 삭제

append()는 맨 뒤에 추가, insert()는 원하는 위치에 추가합니다.

nums = [10, 20, 30] nums.append(40) # 맨 뒤에 추가 print(nums) # [10, 20, 30, 40] nums.insert(1, 15) # 1번 위치에 삽입 print(nums) # [10, 15, 20, 30, 40]
fruits = ["사과", "바나나", "포도", "사과"] fruits.remove("사과") # 첫 번째 "사과" 삭제 print(fruits) # ['바나나', '포도', '사과'] last = fruits.pop() # 마지막 요소 꺼내기 print(last) # 사과 print(fruits) # ['바나나', '포도']
따라해보세요
1
리스트에 요소를 추가해보세요.
todo = [] todo.append("숙제") todo.append("운동") todo.append("독서") print(todo) # ['숙제', '운동', '독서']
빈 리스트에 하나씩 추가됩니다
2
원하는 위치에 삽입해보세요.
todo.insert(0, "아침밥") print(todo) # ['아침밥', '숙제', '운동', '독서']
0번 자리에 삽입되고 나머지는 뒤로 밀립니다
3
요소를 삭제해보세요.
done = todo.pop(0) print(f"완료: {done}") # 완료: 아침밥 print(todo) # ['숙제', '운동', '독서']
pop(0)은 첫 번째 요소를 꺼내서 반환합니다

정렬과 검색

sort()는 리스트 자체를 정렬하고, sorted()는 새 리스트를 반환합니다.

nums = [30, 10, 50, 20, 40] nums.sort() print(nums) # [10, 20, 30, 40, 50] nums.sort(reverse=True) print(nums) # [50, 40, 30, 20, 10] # sorted()는 원본 유지 original = [3, 1, 2] new_list = sorted(original) print(original) # [3, 1, 2] (그대로) print(new_list) # [1, 2, 3]
따라해보세요
1
리스트를 정렬해보세요.
scores = [85, 92, 78, 95, 88] scores.sort() print(scores) # [78, 85, 88, 92, 95]
작은 수부터 정렬됩니다
2
검색 기능을 사용해보세요.
fruits = ["사과", "바나나", "포도"] print("사과" in fruits) # True print(fruits.index("포도")) # 2
in은 있는지 확인, index는 위치를 알려줍니다
3
최대, 최소, 합계를 구해보세요.
nums = [10, 20, 30] print(max(nums)) # 30 print(min(nums)) # 10 print(sum(nums)) # 60
max, min, sum은 리스트에 바로 사용 가능

for문으로 리스트 순회

for문은 리스트의 요소를 하나씩 꺼내서 처리할 때 사용합니다.

for fruit in ["사과", "바나나", "포도"]: print(f"나는 {fruit}를 좋아해") # enumerate로 인덱스와 함께 for i, fruit in enumerate(["사과", "바나나", "포도"]): print(f"{i}: {fruit}")

enumerate() 자세히 — 인덱스가 필요할 때

enumerate()는 리스트의 각 요소와 그 위치(인덱스)를 함께 돌려줍니다. 몇 번째 요소인지 알고 싶을 때 필수입니다.

💡 enumerate 없이: for i in range(len(리스트)): print(i, 리스트[i]) — 동작하지만 파이썬답지 않음
enumerate 사용: for i, 값 in enumerate(리스트): print(i, 값) — 훨씬 깔끔

# 시작 번호 바꾸기 (기본 0, 1부터 시작하려면 start=1) for i, name in enumerate(["민수", "영희", "철수"], start=1): print(f"{i}번: {name}") # 1번: 민수 # 2번: 영희 # 3번: 철수

slicing — 리스트의 일부만 꺼내기

리스트[시작:끝]로 범위를 뽑을 수 있어요. 끝 인덱스는 포함하지 않음에 주의.

nums = [10, 20, 30, 40, 50] print(nums[1:4]) # [20, 30, 40] — 1~3번 인덱스 print(nums[:3]) # [10, 20, 30] — 처음부터 2번까지 print(nums[2:]) # [30, 40, 50] — 2번부터 끝까지 print(nums[-2:]) # [40, 50] — 뒤에서 2개 print(nums[::-1]) # [50, 40, 30, 20, 10] — 거꾸로!

⚠️ nums[1:4]는 인덱스 1, 2, 3만 포함. 끝 인덱스 4는 제외돼요. 이걸 "닫힌-열린 구간"이라 부르며 파이썬의 기본 규칙입니다.

zip() — 두 리스트를 나란히 묶기

같은 길이의 리스트 두 개를 쌍으로 묶어서 동시에 순회할 때 씁니다.

names = ["민수", "영희", "철수"] scores = [85, 92, 78] for name, score in zip(names, scores): print(f"{name}: {score}점") # 민수: 85점 # 영희: 92점 # 철수: 78점

리스트 컴프리헨션

한 줄로 새 리스트를 만드는 강력한 문법입니다.

# 1~5의 제곱 squares = [x**2 for x in range(1, 6)] print(squares) # [1, 4, 9, 16, 25] # 짝수만 필터링 evens = [x for x in range(1, 11) if x % 2 == 0] print(evens) # [2, 4, 6, 8, 10]
따라해보세요
1
for문으로 합계를 구해보세요.
scores = [85, 92, 78, 95, 88] total = 0 for s in scores: total += s print(f"합계: {total}, 평균: {total/len(scores)}")
합계: 438, 평균: 87.6
2
리스트 컴프리헨션으로 새 리스트를 만들어보세요.
names = ["alice", "bob", "charlie"] upper_names = [n.upper() for n in names] print(upper_names) # ['ALICE', 'BOB', 'CHARLIE']
각 이름이 대문자로 변환된 새 리스트
3
조건부 컴프리헨션을 써보세요.
scores = [85, 42, 95, 58, 73] passed = [s for s in scores if s >= 60] print(passed) # [85, 95, 73]
60점 이상만 필터링됩니다

리스트 활용 패턴

리스트 복사할 때 주의할 점이 있습니다.

a = [1, 2, 3] b = a # 같은 리스트! b.append(4) print(a) # [1, 2, 3, 4] ← a도 바뀜! c = a[:] # 복사본 생성 c.append(5) print(a) # [1, 2, 3, 4] ← 그대로 print(c) # [1, 2, 3, 4, 5]

핵심 요약

이 유닛에서 배운 것

  • []로 리스트 생성, 인덱싱/슬라이싱은 문자열과 동일
  • append()로 추가, remove()/pop()으로 삭제
  • sort()는 원본 변경, sorted()는 새 리스트 반환
  • for x in 리스트:로 순회, enumerate()로 인덱스 포함
  • [표현식 for x in 리스트 if 조건] 리스트 컴프리헨션
  • 리스트 복사: a[:] 또는 a.copy() (= 은 같은 객체)
