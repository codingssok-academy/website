은행 계좌 시스템

Account 클래스(입금/출금/이체)를 설계하고, SavingsAccount 상속으로 이자 기능을 추가합니다. 거래 내역 리스트로 히스토리를 관리하는 실전 OOP 시스템을 완성합니다.

이 유닛에서 만드는 것

  • Account 클래스에 계좌주, 잔액, 거래 내역 속성을 정의합니다.
  • deposit()으로 입금, withdraw()로 출금을 구현합니다. 잔액 부족 시 오류 처리를 포함합니다.
  • transfer()로 다른 계좌로 이체하는 메서드를 작성합니다.
  • 모든 거래를 history 리스트에 딕셔너리로 기록합니다.
  • SavingsAccount가 Account를 상속하고 이자율(rate)과 add_interest()를 추가합니다.
  • get_history()로 거래 내역을 출력합니다.

Step 1 — Account 클래스 설계

Account 클래스는 계좌주(owner), 잔액(balance), 거래 내역(history) 세 가지 속성을 가집니다. 모든 거래는 history 리스트에 자동으로 기록됩니다.

# Step 1: Account 클래스 class Account: def __init__(self, owner, balance=0): self.owner = owner self.balance = balance self.history = [] # 거래 내역 리스트 def _record(self, type_, amount): """거래 내역 자동 기록""" self.history.append({ "type": type_, "amount": amount, "balance": self.balance }) def __str__(self): return f"[{self.owner}] 잔액: {self.balance:,}원" # 테스트 acc = Account("김철수", 50000) print(acc)
[김철수] 잔액: 50,000원

Step 2 — deposit / withdraw / transfer 메서드

세 가지 핵심 거래 메서드를 구현합니다. withdraw()와 transfer()는 잔액이 부족하면 오류 메시지를 출력하고 거래를 취소합니다.

# Step 2: 거래 메서드 3개 def deposit(self, amount): """입금""" if amount <= 0: print("[오류] 입금액은 0보다 커야 합니다.") return False self.balance += amount self._record("deposit", amount) print(f"입금 완료: {amount:,}원 → 잔액: {self.balance:,}원") return True def withdraw(self, amount): """출금""" if amount > self.balance: print(f"[오류] 잔액 부족. 현재: {self.balance:,}원") return False self.balance -= amount self._record("withdraw", amount) print(f"출금 완료: {amount:,}원 → 잔액: {self.balance:,}원") return True def transfer(self, target, amount): """이체: 출금 성공 시에만 상대 계좌에 입금""" if self.withdraw(amount): target.deposit(amount) print(f"이체 완료: {self.owner} → {target.owner}") # 테스트 a = Account("철수", 50000) b = Account("영희", 10000) a.deposit(20000) a.transfer(b, 15000) print(a) print(b)
입금 완료: 20,000원 → 잔액: 70,000원 출금 완료: 15,000원 → 잔액: 55,000원 입금 완료: 15,000원 → 잔액: 25,000원 이체 완료: 철수 → 영희 [철수] 잔액: 55,000원 [영희] 잔액: 25,000원

Step 3 — get_history() 거래 내역 출력

get_history()는 history 리스트를 순회하며 거래 유형, 금액, 잔액을 출력합니다. 번호를 붙여 시간 순서대로 보여줍니다.

# Step 3: get_history() 메서드 def get_history(self): """거래 내역 출력""" print(f"=== {self.owner} 거래 내역 ===") if not self.history: print(" 거래 내역 없음") return for i, tx in enumerate(self.history, 1): sign = "+" if tx["type"] == "deposit" else "-" label = "입금" if tx["type"] == "deposit" else "출금" print(f"{i:2}. {label} {sign}{tx['amount']:,}원 잔액: {tx['balance']:,}원")

Step 4 — SavingsAccount 상속

SavingsAccount는 Account를 상속합니다. 이자율(rate) 속성과 add_interest() 메서드를 추가하고, 나머지는 부모 클래스를 그대로 사용합니다.

# Step 4: SavingsAccount — Account 상속 class SavingsAccount(Account): def __init__(self, owner, balance=0, rate=0.02): super().__init__(owner, balance) # 부모 초기화 self.rate = rate # 이자율 (기본 2%) def add_interest(self): """이자 지급: balance * rate를 입금으로 처리""" interest = int(self.balance * self.rate) self.deposit(interest) print(f"이자 {interest:,}원 지급 (이율: {self.rate*100:.1f}%)") def __str__(self): return f"[저축] {super().__str__()} (이율: {self.rate*100:.1f}%)" # 테스트 sav = SavingsAccount("영희", 100000) print(sav) sav.add_interest() print(sav)
[저축] [영희] 잔액: 100,000원 (이율: 2.0%) 이자 2,000원 지급 (이율: 2.0%) [저축] [영희] 잔액: 102,000원 (이율: 2.0%)

핵심 요약

이 유닛에서 배운 것

  • __init__(self, owner, balance=0) — 기본값 매개변수로 초기 잔액을 선택 지정합니다.
  • _record(type_, amount) — 내부 헬퍼 메서드(밑줄 prefix)로 history 리스트에 딕셔너리를 추가합니다.
  • deposit() / withdraw() — 입금/출금 메서드. 성공 시 True, 실패 시 False를 반환해 오류 처리를 구현합니다.
  • transfer(target, amount) — withdraw 성공 시에만 target.deposit()을 호출하는 안전한 이체 패턴입니다.
  • get_history() — enumerate()로 번호를 붙여 딕셔너리 리스트를 순회 출력합니다.
  • class SavingsAccount(Account) — 상속 선언. 부모의 모든 메서드를 그대로 사용합니다.
  • super().__init__() — 자식 클래스 __init__에서 부모 초기화를 명시적으로 호출합니다.
