람다 함수
한 줄 함수

이름 없이 한 줄로 함수를 만드는 lambda 표현식을 배웁니다.

이 유닛에서 배우는 것

  • lambda 기본 문법을 이해하고 간단한 람다 함수를 만들 수 있습니다.
  • def 함수와 lambda의 차이를 비교할 수 있습니다.
  • sorted()의 key 인자에 lambda를 활용할 수 있습니다.
  • map()과 filter()에 lambda를 결합할 수 있습니다.
  • 언제 lambda를 쓰고 언제 def를 써야 하는지 판단할 수 있습니다.

lambda — 이름 없는 한 줄 함수

lambda는 함수를 한 줄로 표현하는 방법입니다. def로 만드는 함수와 똑같이 동작하지만, 이름 없이 즉석에서 만들어 씁니다.

핵심: lambda 뒤에 return을 쓰지 않습니다. 콜론 뒤 표현식이 바로 반환값이 됩니다.
# def 방식 def square(x): return x ** 2 # lambda 방식 — 완전히 동일한 기능 square = lambda x: x ** 2 print(square(5)) # 25 print(square(9)) # 81
따라해보세요
1
숫자를 2배로 만드는 람다 함수를 만들어보세요.
double = lambda x: x * 2 print(double(7)) # 14 print(double(3)) # 6
double(7)은 14를 출력
2
두 수를 더하는 람다 함수를 만들어보세요.
add = lambda x, y: x + y print(add(3, 4)) # 7 print(add(10, 20)) # 30
add(3, 4)는 7을 출력
3
문자열을 대문자로 바꾸는 람다 함수를 만들어보세요.
upper = lambda s: s.upper() print(upper("hello")) # HELLO print(upper("python")) # PYTHON
upper("hello")는 HELLO를 출력

sorted() + key — 정렬 기준 바꾸기

sorted()의 key 인자에 람다를 쓰면 내 마음대로 정렬 기준을 정할 수 있습니다.

names = ["banana", "fig", "apple", "kiwi"] # 기본 정렬 (알파벳 순) print(sorted(names)) # ['apple', 'banana', 'fig', 'kiwi'] # 길이 순으로 정렬 — key에 lambda 사용 print(sorted(names, key=lambda x: len(x))) # ['fig', 'kiwi', 'apple', 'banana']
# 딕셔너리 리스트 — 나이 순으로 정렬 people = [ {"name": "민준", "age": 16}, {"name": "서연", "age": 13}, {"name": "지호", "age": 15}, ] result = sorted(people, key=lambda p: p["age"]) for p in result: print(p["name"], p["age"]) # 서연 13 / 지호 15 / 민준 16
따라해보세요
4
숫자 리스트를 절댓값 기준으로 정렬하세요.
nums = [-5, 3, -1, 4, -2] result = sorted(nums, key=lambda x: abs(x)) print(result) # [-1, -2, 3, 4, -5]
절댓값 순: [-1, -2, 3, 4, -5]
5
단어 리스트를 마지막 글자 기준으로 정렬하세요.
words = ["python", "java", "c", "ruby"] result = sorted(words, key=lambda w: w[-1]) print(result)
마지막 문자: a(java), c(c), n(python), y(ruby)

map() + lambda — 리스트 전체 변환

map(함수, 리스트)는 리스트의 모든 원소에 함수를 적용합니다. lambda와 함께 쓰면 리스트 변환이 한 줄로 끝납니다.

nums = [1, 2, 3, 4, 5] # map() + lambda: 모든 원소를 2배로 doubled = list(map(lambda x: x * 2, nums)) print(doubled) # [2, 4, 6, 8, 10] # 문자열 리스트를 정수로 변환 strings = ["1", "2", "3"] numbers = list(map(lambda s: int(s), strings)) print(numbers) # [1, 2, 3]
# filter() + lambda: 조건을 만족하는 원소만 골라냄 nums = [1, 2, 3, 4, 5, 6] evens = list(filter(lambda x: x % 2 == 0, nums)) print(evens) # [2, 4, 6] # 길이가 4 이상인 단어만 남기기 words = ["hi", "hello", "ok", "world"] long_words = list(filter(lambda w: len(w) >= 4, words)) print(long_words) # ['hello', 'world']
따라해보세요
6
점수 리스트에서 60점 이상만 골라내세요.
scores = [45, 78, 92, 30, 65] passed = list(filter(lambda s: s >= 60, scores)) print(passed) # [78, 92, 65]
60점 이상: [78, 92, 65]
7
섭씨 온도 리스트를 화씨로 변환하세요. (화씨 = 섭씨 × 9/5 + 32)
celsius = [0, 20, 100] fahrenheit = list(map(lambda c: c * 9/5 + 32, celsius)) print(fahrenheit) # [32.0, 68.0, 212.0]
[32.0, 68.0, 212.0] 출력

lambda vs def — 언제 무엇을 쓸까

lambda는 강력하지만 모든 경우에 쓰면 코드가 오히려 읽기 어려워집니다. 올바른 선택 기준을 알아봅니다.

lambda 적합한 경우
  • sorted(), map(), filter()의 인자
  • 한 번만 쓰는 간단한 변환
  • 한 줄 표현식으로 완결되는 경우
def 적합한 경우
  • 여러 곳에서 재사용하는 함수
  • 조건문, 반복문이 필요한 복잡한 로직
  • 이름이 있어야 코드가 읽히는 경우
# 좋은 lambda 사용 예 numbers = [5, 1, 8, 3] sorted(numbers, key=lambda x: -x) # 내림차순 # 나쁜 lambda 사용 예 → def로 대체 # 나쁨: f = lambda x: x**2 if x > 0 else 0 def clamp_square(x): # 좋음: 이름 있고 명확 if x > 0: return x ** 2 return 0

Q3
map + filter 연계
어려움
숫자 리스트에서 홀수만 골라낸 뒤, 각 홀수를 제곱한 리스트를 만드세요. filter()와 map()을 차례로 사용합니다.
입력
[1, 2, 3, 4, 5, 6]
출력
[1, 9, 25]
힌트 보기
먼저 filter(lambda x: x % 2 != 0, nums)로 홀수만 뽑고, 그 결과에 map(lambda x: x**2, ...)을 적용하세요.
정답 보기
nums = [1, 2, 3, 4, 5, 6] odds = filter(lambda x: x % 2 != 0, nums) result = list(map(lambda x: x ** 2, odds)) print(result) # [1, 9, 25]

핵심 요약

  • lambda 문법: lambda 매개변수: 표현식 — return 없이 표현식이 바로 반환값
  • 변수 저장: f = lambda x: x * 2 — def 함수처럼 이름 붙여 재사용 가능
  • sorted key: sorted(list, key=lambda x: ...) — 정렬 기준을 자유롭게 지정
  • map: list(map(lambda x: ..., lst)) — 모든 원소를 변환
  • filter: list(filter(lambda x: ..., lst)) — 조건이 True인 원소만 남김
  • lambda vs def: 한 줄 · 일회성 → lambda, 복잡 · 재사용 → def
