파일 다루기 심화

with문으로 파일을 안전하게 열고 닫는 방법, 파일 모드(r/w/a/r+)의 차이, 여러 파일을 동시에 다루는 패턴, readlines와 writelines로 여러 줄을 한 번에 처리하는 방법을 배웁니다.

이 유닛에서 배우는 것

  • with open() as f: 구문으로 파일을 안전하게 열고 자동으로 닫을 수 있습니다.
  • 파일 모드 r, w, a, r+의 차이를 알고 상황에 맞게 선택할 수 있습니다.
  • readlines()로 파일 전체를 줄 단위 리스트로 읽을 수 있습니다.
  • writelines()로 리스트 데이터를 파일에 한 번에 저장할 수 있습니다.
  • 두 파일을 동시에 열어 데이터를 복사하거나 병합할 수 있습니다.
  • 성적 기록, 일기장 등 실용적인 파일 처리 프로그램을 만들 수 있습니다.

with open() as f: 구문

파일을 열 때 open()만 쓰면 프로그램이 오류로 종료될 때 파일이 닫히지 않아 데이터가 손상될 수 있습니다. with문을 쓰면 블록이 끝날 때 파이썬이 자동으로 close()를 호출합니다.

기본 읽기

# 파일 읽기 — with 사용 with open("note.txt", "r", encoding="utf-8") as f: content = f.read() # 전체를 하나의 문자열로 print(content) # 줄 단위로 읽기 with open("note.txt", "r", encoding="utf-8") as f: for line in f: print(line.strip()) # strip()으로 줄바꿈 제거
따라해보세요 — with open() 읽기
1
먼저 메모장에서 hello.txt를 만들고 "안녕하세요"를 저장하세요. 그 다음 아래 코드로 읽어보세요.
with open("hello.txt", "r", encoding="utf-8") as f: text = f.read() print(text)
안녕하세요 출력, with 블록이 끝나면 f는 자동으로 닫힌다
2
파이썬으로 파일을 직접 만들고 읽어보세요.
# 쓰기 → 읽기 순서 with open("test.txt", "w", encoding="utf-8") as f: f.write("첫 번째 줄\n") f.write("두 번째 줄\n") with open("test.txt", "r", encoding="utf-8") as f: print(f.read())
첫 번째 줄 / 두 번째 줄 순서대로 출력된다
3
for line in f로 줄마다 번호를 붙여 출력하세요.
with open("test.txt", "r", encoding="utf-8") as f: for i, line in enumerate(f, 1): print(f"{i}: {line.strip()}")
1: 첫 번째 줄 / 2: 두 번째 줄

파일 모드 — r / w / a / r+

파일을 열 때 두 번째 인자로 모드를 지정합니다. 모드에 따라 읽기만 되거나 파일을 덮어쓰거나 기존 내용에 이어 쓸 수 있습니다.

모드 이름 동작 파일 없으면?
r 읽기 읽기 전용, 수정 불가 오류 발생
w 쓰기 기존 내용 전부 삭제 후 새로 작성 새로 생성
a 추가 기존 내용 유지, 끝에 이어 쓰기 새로 생성
r+ 읽기+쓰기 읽기와 쓰기 모두 가능 오류 발생

모드별 코드 예시

# w 모드: 새로 쓰기 (기존 내용 사라짐!) with open("score.txt", "w", encoding="utf-8") as f: f.write("홍길동: 95\n") # a 모드: 이어쓰기 (기존 내용 유지) with open("score.txt", "a", encoding="utf-8") as f: f.write("이순신: 88\n") # r 모드: 읽기 전용 with open("score.txt", "r", encoding="utf-8") as f: print(f.read())
홍길동: 95 이순신: 88
주의: 한글 파일은 encoding="utf-8" 필수

윈도우에서 기본 인코딩은 cp949입니다. 한글이 깨지지 않으려면 항상 encoding="utf-8"을 명시하세요. 파이썬 3에서 이 인수를 생략하면 시스템 기본값을 사용합니다.

readlines / writelines

read()는 전체를 하나의 문자열로 읽지만, readlines()는 줄마다 리스트 원소로 분리해서 반환합니다. 반대로 writelines()는 리스트를 받아 파일에 이어 씁니다.

# readlines() — 줄 단위 리스트로 읽기 with open("scores.txt", "r", encoding="utf-8") as f: lines = f.readlines() # ['홍길동 95\n', '이순신 88\n', ...] for line in lines: name, score = line.strip().split() print(f"{name}의 점수: {score}점") # writelines() — 리스트를 파일에 쓰기 students = ["홍길동 95\n", "이순신 88\n", "강감찬 72\n"] with open("output.txt", "w", encoding="utf-8") as f: f.writelines(students) # 리스트 원소를 연속으로 씀
홍길동의 점수: 95점 이순신의 점수: 88점 강감찬의 점수: 72점
따라해보세요 — readlines / writelines
1
과목 리스트를 파일로 저장하고 readlines()로 읽어 몇 줄인지 출력하세요.
subjects = ["수학\n", "영어\n", "과학\n", "국어\n"] with open("subjects.txt", "w", encoding="utf-8") as f: f.writelines(subjects) with open("subjects.txt", "r", encoding="utf-8") as f: lines = f.readlines() print(f"총 {len(lines)}개 과목")
총 4개 과목
2
readlines()로 읽은 줄에서 번호와 내용을 출력하세요.
with open("subjects.txt", "r", encoding="utf-8") as f: lines = f.readlines() for i, line in enumerate(lines, 1): print(f"{i}번: {line.strip()}")
1번: 수학 / 2번: 영어 / 3번: 과학 / 4번: 국어
3
성적 데이터에서 70점 이상인 학생만 골라 새 파일에 저장하세요.
scores = ["홍길동 95\n", "김철수 65\n", "이영희 82\n"] with open("scores.txt", "w", encoding="utf-8") as f: f.writelines(scores) with open("scores.txt", "r", encoding="utf-8") as f: lines = f.readlines() passed = [l for l in lines if int(l.strip().split()[1]) >= 70] with open("passed.txt", "w", encoding="utf-8") as f: f.writelines(passed)
passed.txt에 홍길동 95, 이영희 82만 저장됨

여러 파일 동시에 열기

하나의 with문에 쉼표(,)로 여러 파일을 동시에 열 수 있습니다. 한 파일을 읽으면서 다른 파일에 쓰는 패턴에 자주 쓰입니다.

파일 복사

# 두 파일 동시 열기: 파일 복사 with open("input.txt", "r", encoding="utf-8") as src, \ open("output.txt", "w", encoding="utf-8") as dst: for line in src: dst.write(line) # 한 줄씩 복사 print("복사 완료")

내용 변환하면서 저장

# 원본 읽으면서 대문자로 변환해 저장 with open("names.txt", "r", encoding="utf-8") as src, \ open("names_upper.txt", "w", encoding="utf-8") as dst: for line in src: dst.write(line.upper()) # 대문자 변환 후 저장

두 파일 병합

# kor.txt와 eng.txt를 합쳐 result.txt에 저장 with open("kor.txt", "w", encoding="utf-8") as f: f.write("안녕\n반가워\n") with open("eng.txt", "w", encoding="utf-8") as f: f.write("Hello\nHi\n") with open("kor.txt", "r", encoding="utf-8") as a, \ open("eng.txt", "r", encoding="utf-8") as b, \ open("result.txt", "w", encoding="utf-8") as c: c.writelines(a.readlines()) c.writelines(b.readlines())
result.txt 내용: 안녕 반가워 Hello Hi

실용 예제 — 성적 관리 프로그램

지금까지 배운 내용을 조합해 성적을 저장하고 조회하는 프로그램을 만듭니다. a 모드로 성적을 누적 기록하고, r 모드로 읽어 평균을 계산합니다.

# 성적 저장 함수 def save_grade(name, score): with open("grades.txt", "a", encoding="utf-8") as f: f.write(f"{name} {score}\n") # 평균 계산 함수 def show_average(): with open("grades.txt", "r", encoding="utf-8") as f: lines = f.readlines() scores = [int(l.strip().split()[1]) for l in lines] avg = sum(scores) / len(scores) print(f"평균: {avg:.1f}점") # 사용 save_grade("홍길동", 95) save_grade("이순신", 88) save_grade("강감찬", 72) show_average()
평균: 85.0점

핵심 요약

  • with open(파일, 모드, encoding="utf-8") as f: — 안전한 파일 열기, 자동 close
  • 모드: r 읽기 / w 새로 쓰기 / a 이어 쓰기 / r+ 읽기+쓰기
  • f.read() 전체 문자열 / f.readlines() 줄마다 리스트 원소
  • f.write(str) 문자열 하나 쓰기 / f.writelines(list) 리스트 이어 쓰기
  • 여러 파일 동시: with open(...) as a, open(...) as b:
  • 한글 파일은 반드시 encoding="utf-8" 명시
