프로젝트:
오늘의 운세 뽑기

random.choice로 운세 메시지를 뽑고, 이름 기반 럭키 숫자, 궁합 테스트, 별자리별 운세를 만들어봅니다.

이 프로젝트에서 만드는 것

  • random.choice()로 운세 메시지 목록에서 무작위로 뽑을 수 있습니다.
  • 이름의 각 글자 유니코드 값을 합산해 럭키 숫자를 계산할 수 있습니다.
  • 두 이름의 점수를 비교해 궁합 퍼센트를 출력할 수 있습니다.
  • 딕셔너리로 별자리와 운세를 매핑해 조회할 수 있습니다.
  • f-string으로 결과를 깔끔하게 포맷해 출력할 수 있습니다.

핵심 개념 복습

random 모듈 — 무작위 선택의 핵심

random.choice()는 리스트에서 요소 하나를 무작위로 골라줍니다. 운세, 닉네임, 퀴즈 등 다양한 곳에 씁니다.

함수 설명 예시
random.choice(lst) 리스트에서 1개 무작위 선택 random.choice(["행운","노력","인내"])
random.randint(a, b) a 이상 b 이하 정수 반환 random.randint(1, 45)
random.shuffle(lst) 리스트 순서를 무작위로 섞음 random.shuffle(cards)

이름으로 숫자 만들기 — ord() 활용

문자의 유니코드 값을 얻는 ord() 함수로 이름마다 고유한 숫자를 만들 수 있습니다.

Step 1
오늘의 운세 뽑기 함수 만들기

운세 메시지 리스트를 만들고 random.choice()로 하나를 뽑습니다.

import random # 운세 메시지 목록 messages = [ "오늘은 새로운 친구를 사귀게 될 거야!", "숫자 7이 행운을 가져다 준다.", "오늘 시험 보면 잘 볼 거야. 자신감 UP!", "좋아하는 사람에게 먼저 말을 걸어봐.", "오늘 쉬어도 괜찮아. 충전도 실력이야.", ] def get_fortune(): return random.choice(messages) name = input("이름을 입력하세요: ") fortune = get_fortune() print(f"\n{name}의 오늘 운세: {fortune}")
이름을 입력하세요: 김민준 김민준의 오늘 운세: 숫자 7이 행운을 가져다 준다.

Step 2 — 이름 기반 럭키 숫자

이름 각 글자의 ord() 값을 합산하고 % 9 + 1로 1~9 사이의 럭키 숫자를 만듭니다.

def lucky_number(name): total = sum(ord(c) for c in name) lucky = total % 9 + 1 return lucky name = input("이름을 입력하세요: ") num = lucky_number(name) print(f"{name}의 럭키 숫자는 {num}입니다!")

Step 3 — 궁합 테스트

두 이름의 럭키 숫자 차이로 궁합 퍼센트를 계산합니다. 차이가 작을수록 궁합이 좋습니다.

def compatibility(name1, name2): n1 = lucky_number(name1) n2 = lucky_number(name2) diff = abs(n1 - n2) score = 100 - diff * 10 if score >= 90: grade = "완벽한 궁합!" elif score >= 70: grade = "좋은 궁합!" else: grade = "노력이 필요해요." return score, grade name1 = input("첫 번째 이름: ") name2 = input("두 번째 이름: ") score, grade = compatibility(name1, name2) print(f"\n{name1} X {name2} 궁합: {score}% — {grade}")
첫 번째 이름: 김민준 두 번째 이름: 이서연 김민준 X 이서연 궁합: 90% — 완벽한 궁합!

Step 4 — 별자리별 운세 딕셔너리

딕셔너리에 별자리와 운세를 매핑하고, 입력받은 별자리에 해당하는 운세를 출력합니다. 없는 별자리면 안내 메시지를 보여줍니다.

horoscope = { "양자리": "오늘은 도전하기 좋은 날! 새로운 시도를 해봐.", "황소자리": "꾸준함이 빛을 발하는 날. 포기하지 마!", "쌍둥이자리": "대화가 잘 통하는 날. 친구와 이야기해봐.", "게자리": "감성이 풍부한 날. 일기를 써봐.", "사자자리": "자신감 넘치는 날! 발표가 있으면 최고야.", "처녀자리": "분석력이 높은 날. 공부하기 딱 좋아.", } star = input("별자리를 입력하세요 (예: 사자자리): ") result = horoscope.get(star, "입력한 별자리를 찾을 수 없어요.") print(f"\n[{star}] {result}")

get()의 기본값 — 없는 키도 안전하게

dict.get(key, 기본값)은 키가 없을 때 오류 대신 기본값을 반환합니다. 사용자 입력 처리에 필수입니다.

import random messages = [ "오늘은 새로운 친구를 사귀게 될 거야!", "숫자 7이 행운을 가져다 준다.", "오늘 시험 보면 잘 볼 거야. 자신감 UP!", "좋아하는 사람에게 먼저 말을 걸어봐.", "오늘 쉬어도 괜찮아. 충전도 실력이야.", ] horoscope = { "양자리": "오늘은 도전하기 좋은 날!", "사자자리": "자신감 넘치는 날! 발표가 있으면 최고야.", "게자리": "감성이 풍부한 날. 일기를 써봐.", } def get_fortune(): return random.choice(messages) def lucky_number(name): total = sum(ord(c) for c in name) return total % 9 + 1 def compatibility(name1, name2): diff = abs(lucky_number(name1) - lucky_number(name2)) score = 100 - diff * 10 grade = "완벽!" if score >= 90 else "좋아요" if score >= 70 else "노력해요" return score, grade name = input("이름: ") star = input("별자리: ") name2 = input("궁합 볼 이름: ") score, grade = compatibility(name, name2) print(f"\n[{name}의 운세]") print(f" 운세: {get_fortune()}") print(f" 럭키 숫자: {lucky_number(name)}") print(f" {star} 운세: {horoscope.get(star, '별자리 미등록')}") print(f" {name} X {name2} 궁합: {score}% ({grade})")

핵심 요약

  • random.choice(list) — 리스트에서 무작위로 1개 선택
  • ord(문자) — 문자를 유니코드 정수로 변환, 이름 기반 숫자 생성에 활용
  • sum(ord(c) for c in name) — 제너레이터 표현식으로 이름 합산
  • abs(a - b) — 두 값의 절댓값 차이 계산
  • dict.get(key, default) — 없는 키에도 안전하게 조회
  • f-string — 변수와 문자열을 깔끔하게 합치는 포맷팅
