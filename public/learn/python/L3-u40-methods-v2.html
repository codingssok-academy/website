Chapter 40 — L3

메서드
클래스 안의 함수

클래스가 데이터를 담는 그릇이라면, 메서드는 그 안에서 동작하는 함수입니다. self를 통해 자기 자신의 속성을 읽고 바꾸는 법을 배웁니다.

이 유닛에서 배우는 것

  • 인스턴스 메서드가 무엇인지, self가 왜 필요한지 이해합니다.
  • 메서드 안에서 속성을 읽고 수정하는 법을 익힙니다.
  • 한 메서드가 다른 메서드를 호출하는 패턴을 배웁니다.
  • __str__ 메서드로 객체를 문자열로 표현하는 법을 배웁니다.
  • Counter 클래스와 Pet 클래스를 직접 만들어 봅니다.

인스턴스 메서드와 self

클래스 안에 정의된 함수를 메서드(method)라고 합니다. 메서드의 첫 번째 매개변수는 반드시 self여야 합니다. self는 "이 메서드를 호출한 객체 자신"을 가리킵니다.

class Pet: def __init__(self, name, species): self.name = name # 이름 속성 self.species = species # 종류 속성 self.hungry = True # 배고픔 상태 self.happiness = 50 # 행복도 (0~100) def greet(self): # 첫 번째 매개변수는 항상 self print(f"안녕! 나는 {self.name}이야.") # 두 인스턴스 생성 cat = Pet("나비", "고양이") dog = Pet("초코", "강아지") cat.greet() # 안녕! 나는 나비이야. dog.greet() # 안녕! 나는 초코이야.
self는 자동으로 전달된다

cat.greet()를 호출하면 파이썬이 자동으로 cat 객체를 self에 넣어줍니다. 직접 넣어줄 필요가 없습니다.

메서드 안에서 속성 수정하기

메서드는 self.속성명 = 새값으로 속성 값을 바꿀 수 있습니다.

class Pet: def __init__(self, name, species): self.name = name self.species = species self.hungry = True self.happiness = 50 def eat(self): self.hungry = False # 배고픔 해소 self.happiness += 10 # 행복도 증가 print(f"{self.name}이(가) 밥을 먹었어요!") def status(self): state = "배고픔" if self.hungry else "배부름" print(f"{self.name} | 상태: {state} | 행복도: {self.happiness}") cat = Pet("나비", "고양이") cat.status() # 나비 | 상태: 배고픔 | 행복도: 50 cat.eat() # 나비이(가) 밥을 먹었어요! cat.status() # 나비 | 상태: 배부름 | 행복도: 60

매개변수를 받는 메서드

메서드도 일반 함수처럼 self 이후에 추가 매개변수를 받을 수 있습니다.

class Pet: def __init__(self, name): self.name = name self.happiness = 50 def feed(self, food): # food 매개변수 추가 self.happiness += 10 print(f"{self.name}에게 {food}을(를) 줬어요!") def train(self, skill, reward): # 두 개 매개변수 print(f"{self.name} {skill} 훈련 완료! 보상: {reward}") dog = Pet("초코") dog.feed("사료") # 초코에게 사료을(를) 줬어요! dog.train("앉아", "간식") # 초코 앉아 훈련 완료! 보상: 간식

메서드끼리 호출하기

한 메서드 안에서 같은 클래스의 다른 메서드를 self.메서드명()으로 호출할 수 있습니다. 코드 중복을 줄이고 로직을 분리할 때 매우 유용합니다.

class Pet: def __init__(self, name): self.name = name self.hungry = True self.happiness = 50 def _add_happiness(self, amount): # 내부 헬퍼 메서드 self.happiness = min(100, self.happiness + amount) def eat(self): self.hungry = False self._add_happiness(10) # 다른 메서드 호출 print(f"{self.name}: 냠냠 (행복도 {self.happiness})") def play(self): self.hungry = True self._add_happiness(20) # 동일한 헬퍼 메서드 재활용 print(f"{self.name}: 신나다! (행복도 {self.happiness})") cat = Pet("나비") cat.eat() # 나비: 냠냠 (행복도 60) cat.play() # 나비: 신나다! (행복도 80)

__str__ 맛보기

__str__은 파이썬이 미리 정해 놓은 특별한 메서드입니다. print(객체)를 호출하거나 str(객체)를 할 때 자동으로 실행됩니다.

class Pet: def __init__(self, name, species): self.name = name self.species = species self.happiness = 50 def __str__(self): # print() 시 자동 실행 return f"[{self.species}] {self.name} (행복도: {self.happiness})" cat = Pet("나비", "고양이") print(cat) # [고양이] 나비 (행복도: 50) print(str(cat)) # [고양이] 나비 (행복도: 50) — 동일 결과

실용 예: Counter 클래스

숫자를 세는 Counter 클래스를 만들어봅니다. 간단하지만 메서드끼리 상호작용하는 패턴을 잘 보여주는 예제입니다.

class Counter: def __init__(self, start=0): self.count = start def up(self, n=1): # 기본값 1 self.count += n def down(self, n=1): self.count -= n def reset(self): self.count = 0 def value(self): return self.count def __str__(self): return f"Counter({self.count})" c = Counter() c.up() # count = 1 c.up(3) # count = 4 c.down() # count = 3 print(c.value()) # 3 print(c) # Counter(3) c.reset() print(c) # Counter(0)

def is_zero(self): return self.count == 0 c = Counter() print(c.is_zero()) # True c.up() print(c.is_zero()) # False

Pet 클래스 완성하기

지금까지 배운 내용을 종합해 Pet 클래스를 완성합니다. 먹기, 놀기, 상태 확인, 문자열 표현까지 모두 갖춘 클래스입니다.

class Pet: def __init__(self, name, species): self.name = name self.species = species self.hungry = True self.happiness = 50 self.energy = 100 def _add_happiness(self, amount): self.happiness = min(100, self.happiness + amount) def eat(self): self.hungry = False self.energy = min(100, self.energy + 30) self._add_happiness(10) print(f"{self.name}: 냠냠") def play(self): if self.energy < 20: print(f"{self.name}: 너무 피곤해...") return self.hungry = True self.energy -= 20 self._add_happiness(20) print(f"{self.name}: 신나다!") def status(self): h = "배고픔" if self.hungry else "배부름" print(f"[{self.name}] {h} | 행복: {self.happiness} | 체력: {self.energy}") def __str__(self): return f"Pet({self.species}: {self.name})" cat = Pet("나비", "고양이") cat.eat() cat.play() cat.status() print(cat)

연습 문제

지금까지 배운 메서드 개념을 활용해 BankAccount(은행 계좌) 클래스를 만들어 봅니다. BankAccount는 소유자 이름과 잔액을 속성으로 가지며, 입금과 출금 메서드를 통해 잔액을 관리합니다.

1
BankAccount 클래스 — 입금과 잔액 확인
쉬움
아래 조건에 맞게 BankAccount 클래스를 완성하세요.
- __init__(self, owner): owner 속성과 balance 속성(초기값 0) 설정
- deposit(self, amount): balance에 amount 더하기, "입금: {amount}원" 출력
- get_balance(self): 현재 balance 반환
- __str__(self): "[owner] 잔액: {balance}원" 형태 반환
입력 acc = BankAccount("홍길동") / acc.deposit(5000) / acc.deposit(3000) / print(acc)
출력 입금: 5000원 / 입금: 3000원 / [홍길동] 잔액: 8000원
내 답안
힌트 보기
self.balance += amount 로 잔액을 늘립니다. __str__에서 return f"[{self.owner}] 잔액: {self.balance}원" 형태를 반환하세요.
정답 보기
class BankAccount: def __init__(self, owner): self.owner = owner self.balance = 0 def deposit(self, amount): self.balance += amount print(f"입금: {amount}원") def get_balance(self): return self.balance def __str__(self): return f"[{self.owner}] 잔액: {self.balance}원"
2
BankAccount 클래스 — 출금과 잔액 부족 처리
보통
문제 1의 BankAccount에 withdraw(self, amount) 메서드를 추가하세요.
- 잔액이 충분하면 amount를 빼고 "출금: {amount}원" 출력
- 잔액이 부족하면 "잔액 부족 (현재: {balance}원)" 출력하고 출금하지 않음
입력 acc.deposit(10000) / acc.withdraw(3000) / acc.withdraw(9000)
출력 입금: 10000원 / 출금: 3000원 / 잔액 부족 (현재: 7000원)
내 답안
힌트 보기
if self.balance >= amount: 조건으로 잔액이 충분한지 확인하세요.
정답 보기
def withdraw(self, amount): if self.balance >= amount: self.balance -= amount print(f"출금: {amount}원") else: print(f"잔액 부족 (현재: {self.balance}원)")

Pet 클래스 — sleep() 메서드 추가
도전
완성된 Pet 클래스에 sleep(self) 메서드를 추가하세요.
- energy를 40 회복 (최대 100)

입력 cat = Pet("나비", "고양이") / cat.play() / cat.sleep()
출력 나비: 신나다! / 나비: 잘 잤다! (체력 100) / [나비] 배고픔 | 행복: 70 | 체력: 100

self.energy = min(100, self.energy + 40) 로 에너지를 회복하고, 마지막에 self.status()를 호출하세요.

def sleep(self): self.energy = min(100, self.energy + 40) self.hungry = True print(f"{self.name}: 잘 잤다! (체력 {self.energy})") self.status() # 메서드에서 메서드 호출

핵심 요약

  • 메서드는 클래스 안에 정의된 함수이며, 첫 번째 매개변수는 반드시 self입니다.
  • self는 메서드를 호출한 객체 자신을 가리키며, 호출 시 자동으로 전달됩니다.
  • 메서드 안에서 self.속성명으로 속성을 읽거나 수정할 수 있습니다.
  • self.메서드명()으로 같은 클래스의 다른 메서드를 호출할 수 있습니다.
  • __str__은 print(객체) 시 자동 실행되는 특별 메서드입니다.
  • 인스턴스마다 속성이 독립적으로 저장되어 서로 영향을 주지 않습니다.
