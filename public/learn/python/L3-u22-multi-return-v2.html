여러 값 반환
return과 튜플 언패킹

함수 하나가 결과를 여러 개 돌려주는 방법을 배웁니다. 튜플로 묶어 반환하고, 언패킹으로 받아냅니다.

이 유닛에서 배우는 것

  • return으로 값 하나를 반환하는 방법을 복습합니다.
  • return으로 여러 값을 동시에 반환할 수 있습니다.
  • 여러 값을 반환하면 튜플로 묶여 나옵니다.
  • 언패킹으로 반환값을 변수 여러 개에 나눠 담습니다.
  • 언더스코어(_)로 필요 없는 반환값을 무시합니다.
  • min/max 동시 반환, 몫/나머지 동시 반환 등 실용 예제를 작성합니다.

return 복습 — 값 하나 돌려주기

함수는 return 키워드로 결과를 돌려줍니다. 지금까지는 값을 하나만 반환했습니다.

# 값 하나 반환 — 기본 형태 def square(n): return n * n result = square(4) print(result) # 16

여러 값을 한 번에 반환하기

쉼표로 여러 값을 나열하면 파이썬이 자동으로 튜플로 묶어 반환합니다. 별도의 괄호 없이도 됩니다.

# 여러 값 반환 — 자동으로 튜플이 됨 def min_max(nums): return min(nums), max(nums) result = min_max([45, 3, 97, 22]) print(result) # (3, 97) print(type(result)) # <class 'tuple'>
따라해보세요
1
값 하나를 반환하는 함수를 작성하세요.
def double(n): return n * 2 print(double(7))
14
2
두 값을 반환하는 함수를 작성하고 타입을 확인하세요.
def pair(a, b): return a, b r = pair("안녕", 42) print(r, type(r))
('안녕', 42) <class 'tuple'>
3
숫자 리스트의 최솟값과 최댓값을 동시에 반환하는 함수를 완성하세요.
def min_max(nums): return min(nums), max(nums) print(min_max([10, 5, 99, 3]))
(3, 99)

튜플 언패킹으로 반환값 받기

반환된 튜플을 한 줄에서 바로 여러 변수로 나눠 받을 수 있습니다. 이것이 언패킹입니다.

# 언패킹으로 반환값 받기 def min_max(nums): return min(nums), max(nums) low, high = min_max([45, 3, 97, 22]) print(f"최솟값: {low}, 최댓값: {high}") # 최솟값: 3, 최댓값: 97

세 개 이상도 가능

반환 값의 수가 몇 개든 상관없습니다. 변수 수만 맞추면 됩니다.

# 세 값 반환 def stats(nums): return min(nums), max(nums), sum(nums) // len(nums) lo, hi, avg = stats([10, 20, 30, 40]) print(f"최소={lo}, 최대={hi}, 평균={avg}") # 최소=10, 최대=40, 평균=25

def sum_diff(a, b): return a + b, a - b total, diff = sum_diff(10, 3) print(total, diff)

실용 예제 — 몫과 나머지 동시 반환

나눗셈에서 몫과 나머지를 동시에 구해서 돌려주는 함수는 매우 자주 쓰입니다.

# 몫과 나머지 동시 반환 def divide(a, b): q = a // b # 몫 r = a % b # 나머지 return q, r q, r = divide(17, 5) print(f"17 ÷ 5 = {q} ... {r}") # 17 ÷ 5 = 3 ... 2

실용 예제 — 문자열 분석

문자열의 길이와 대문자 변환을 동시에 반환하면 반복 계산을 줄일 수 있습니다.

def analyze(text): length = len(text) upper = text.upper() return length, upper n, up = analyze("hello") print(f"길이: {n}, 대문자: {up}") # 길이: 5, 대문자: HELLO

_ (언더스코어)로 불필요한 값 무시하기

함수가 여러 값을 반환할 때, 필요 없는 값은 _에 담으면 됩니다. 이는 "이 값은 쓰지 않겠다"는 관례입니다.

# 최댓값만 필요할 때 → _로 최솟값 무시 def min_max(nums): return min(nums), max(nums) _, high = min_max([45, 3, 97, 22]) print(f"최댓값: {high}") # 최댓값: 97 # 최솟값만 필요할 때 low, _ = min_max([45, 3, 97, 22]) print(f"최솟값: {low}") # 최솟값: 3

몫만, 나머지만 필요할 때

def divide(a, b): return a // b, a % b # 나머지만 필요한 경우 (홀수/짝수 판단) _, remainder = divide(17, 2) if remainder == 0: print("짝수") else: print("홀수") # 홀수

나이: 15

def divide(a, b): return a // b, a % b _, r = divide(24, 2) print("짝수" if r == 0 else "홀수")

Q3
BMI 계산기
보통
키(cm)와 몸무게(kg)를 받아 BMI 값(소수점 1자리)과 판정 문자열("저체중", "정상", "과체중")을 동시에 반환하는 함수를 작성하세요. BMI = 몸무게 / (키/100)^2. 18.5 미만 저체중, 25 미만 정상, 25 이상 과체중.
입력키=170, 몸무게=65
출력BMI=22.5, 판정=정상
내 답안
힌트 보기
BMI 계산 후 조건문으로 판정 문자열을 결정하세요. return round(bmi, 1), judgment로 두 값을 반환합니다.
정답 확인
def calc_bmi(height_cm, weight_kg): h = height_cm / 100 bmi = weight_kg / (h ** 2) if bmi < 18.5: judgment = "저체중" elif bmi < 25: judgment = "정상" else: judgment = "과체중" return round(bmi, 1), judgment bmi_val, result = calc_bmi(170, 65) print(f"BMI={bmi_val}, 판정={result}")

핵심 요약

핵심 요약

  • return a, b처럼 쉼표로 나열하면 여러 값을 반환할 수 있다
  • 여러 값을 반환하면 파이썬이 자동으로 tuple로 묶어준다
  • x, y = func()처럼 언패킹하면 변수 여러 개에 한 번에 담는다
  • 변수 수와 반환 값의 수가 반드시 일치해야 한다
  • 필요 없는 반환값은 _에 담아 무시한다 (관례)
  • min/max 동시 반환, 몫/나머지 동시 반환 등에서 자주 쓰인다
