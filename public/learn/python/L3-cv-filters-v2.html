Chapter L3-CV-2 — 컴퓨터 비전

이미지 필터
흑백, 블러, 엣지 검출

SNS 사진 필터처럼 이미지를 변환하는 기법들을 배웁니다. 흑백 변환, 부드럽게 만들기(블러), 윤곽선 찾기(엣지), 밝기와 대비 조절까지.

이 유닛에서 배우는 것

  • cv2.cvtColor()로 컬러 이미지를 흑백(Grayscale)으로 변환합니다.
  • cv2.GaussianBlur()로 이미지를 부드럽게(블러) 처리합니다.
  • cv2.Canny()로 이미지의 윤곽선(엣지)을 검출합니다.
  • convertScaleAbs()로 밝기와 대비를 직접 조절합니다.
  • 여러 필터를 파이프라인처럼 연결하는 방법을 익힙니다.

흑백 변환 — cvtColor(BGR2GRAY)

컬러 이미지(3채널 BGR)를 흑백 이미지(1채널)로 변환합니다. 흑백 이미지는 각 픽셀이 밝기 하나의 값만 가져 처리가 빠릅니다.

import cv2 img = cv2.imread("photo.jpg") # 컬러 -> 흑백 변환 gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY) print("컬러:", img.shape) # (480, 640, 3) print("흑백:", gray.shape) # (480, 640) -- 채널 없음! cv2.imwrite("gray.jpg", gray)

블러 — GaussianBlur()

이미지를 부드럽게 만드는 필터입니다. 주변 픽셀들의 평균값을 계산해 경계가 흐려집니다. 노이즈 제거나 엣지 검출 전처리에 자주 쓰입니다.

import cv2 img = cv2.imread("photo.jpg") # GaussianBlur(이미지, 커널크기, 시그마) blur_light = cv2.GaussianBlur(img, (3, 3), 0) # 약한 블러 blur_medium = cv2.GaussianBlur(img, (5, 5), 0) # 보통 블러 blur_heavy = cv2.GaussianBlur(img, (15, 15), 0) # 강한 블러 cv2.imwrite("blurred.jpg", blur_medium)
커널 크기는 항상 홀수

GaussianBlur의 커널 크기는 반드시 홀수여야 합니다 (3, 5, 7, 9...). 짝수를 넣으면 오류가 발생합니다. 중심 픽셀이 있어야 하기 때문입니다.

엣지 검출 — Canny()

엣지(Edge)는 이미지에서 밝기가 급격히 변하는 경계선입니다. cv2.Canny()는 그림의 윤곽선만 추출하는 강력한 알고리즘입니다.

import cv2 img = cv2.imread("photo.jpg") gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY) # Canny(이미지, 하한 임계값, 상한 임계값) # -- 임계값이 낮을수록 더 많은 엣지 검출 edges = cv2.Canny(gray, 50, 150) print(edges.shape) # (480, 640) -- 흑백 1채널 cv2.imwrite("edges.jpg", edges)

밝기/대비 조절 — convertScaleAbs()

이미지의 밝기(alpha)와 대비(beta)를 수식으로 조절합니다: 새픽셀 = alpha * 픽셀 + beta

import cv2 img = cv2.imread("photo.jpg") # convertScaleAbs(이미지, alpha=대비, beta=밝기) bright = cv2.convertScaleAbs(img, alpha=1.0, beta=50) # 밝게 dark = cv2.convertScaleAbs(img, alpha=1.0, beta=-50) # 어둡게 contrast = cv2.convertScaleAbs(img, alpha=1.5, beta=0) # 대비 강화

필터 파이프라인 실습

지금까지 배운 필터들을 조합해서 다양한 효과를 만들어봅니다.

따라해보세요
실습 1 — 흑백 + 블러 적용
이미지를 흑백으로 변환하고 GaussianBlur를 적용하세요.
import cv2, numpy as np # 테스트용 그라디언트 이미지 생성 img = np.zeros((200, 300, 3), dtype=np.uint8) img[:, :150] = [200, 100, 50] img[:, 150:] = [50, 150, 200] gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY) blurred = cv2.GaussianBlur(gray, (5, 5), 0) print("blurred shape:", blurred.shape)
blurred shape: (200, 300)
실습 2 — 스케치 효과 만들기
흑백 -> 블러 -> Canny를 연결해 스케치 효과를 만드세요.
gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY) blur = cv2.GaussianBlur(gray, (5, 5), 0) sketch = cv2.Canny(blur, 30, 100) cv2.imwrite("sketch.jpg", sketch) print("스케치 저장 완료")
스케치 저장 완료
실습 3 — 밝기 조절 비교
원본 대비 밝게/어둡게 처리한 이미지를 각각 저장하세요.
bright = cv2.convertScaleAbs(img, alpha=1.0, beta=80) dark = cv2.convertScaleAbs(img, alpha=1.0, beta=-80) cv2.imwrite("bright.jpg", bright) cv2.imwrite("dark.jpg", dark) print("밝기 조절 완료")

쉬움
GaussianBlur의 커널 크기로 사용할 수 없는 것을 고르세요.
보기 (1) (3, 3) (2) (4, 4) (3) (5, 5) (4) (15, 15)

힌트 보기
커널 크기는 반드시 홀수여야 합니다. 중심 픽셀이 존재하려면 가로/세로 모두 홀수 크기가 필요합니다.

Canny 엣지 검출 코드 완성
보통
다음 코드의 빈칸을 채워 엣지 이미지를 만드세요. Canny는 반드시 흑백 이미지에 적용해야 합니다.
코드 img = cv2.imread("photo.jpg")
gray = cv2.cvtColor(img, ___________)

Q3
완전한 필터 파이프라인 작성
어려움
이미지를 읽어 ① 흑백 변환 ② (5,5) 블러 ③ Canny(50, 150) 엣지 검출 ④ "result.jpg"로 저장하는 전체 코드를 작성하세요.
내 답안
힌트 보기
imread -> cvtColor -> GaussianBlur -> Canny -> imwrite 순서로 연결하면 됩니다.
정답 보기
import cv2 img = cv2.imread("photo.jpg") gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY) blurred = cv2.GaussianBlur(gray, (5, 5), 0) edges = cv2.Canny(blurred, 50, 150) cv2.imwrite("result.jpg", edges) print("저장 완료")

핵심 요약

  • cv2.cvtColor(img, cv2.COLOR_BGR2GRAY) — 컬러를 흑백(1채널)으로 변환
  • cv2.GaussianBlur(img, (5,5), 0) — 가우시안 블러, 커널은 홀수
  • cv2.Canny(gray, 50, 150) — 윤곽선 검출, 흑백 이미지에 적용
  • cv2.convertScaleAbs(img, alpha=1.5, beta=50) — 대비/밝기 조절
  • 필터 파이프라인: 원본 -> 흑백 -> 블러 -> 엣지 -> 저장
  • 임계값이 낮을수록 더 많은 엣지가 검출됩니다 (노이즈 포함)
