L3 — Unit 33 · L3c 딕셔너리 & 자료구조 활용

중첩 자료구조:
리스트 안의 딕셔너리

리스트와 딕셔너리를 합쳐 현실 데이터를 표현합니다. 학급 명단, 메뉴판처럼 실제로 쓰이는 구조를 만들고 탐색합니다.

이 유닛에서 배우는 것

  • 리스트 안에 딕셔너리를 넣어 표 구조 데이터를 표현할 수 있습니다.
  • 딕셔너리 안에 리스트를 넣어 1:다 관계 데이터를 표현할 수 있습니다.
  • data[0]["name"] 형식으로 중첩 데이터에 접근할 수 있습니다.
  • for 반복문으로 중첩 구조 전체를 순회할 수 있습니다.
  • 학급 명단, 메뉴판 같은 실용 예제를 직접 만들 수 있습니다.

1. 리스트 안에 딕셔너리 넣기

딕셔너리 하나는 한 명의 정보를 담습니다. 여러 명의 정보가 필요하면 딕셔너리를 리스트에 넣으면 됩니다.

# 리스트 안에 딕셔너리 — 학급 명단 students = [ {"name": "철수", "age": 14, "score": 88}, {"name": "영희", "age": 15, "score": 95}, {"name": "민준", "age": 14, "score": 72}, ] # 첫 번째 학생 정보 전체 출력 print(students[0]) # {'name': '철수', 'age': 14, 'score': 88}

인덱스와 키를 함께 사용해 접근

리스트 인덱스로 딕셔너리를 고르고, 그 뒤에 키를 붙여 값을 꺼냅니다.

# 접근 방법: data[인덱스]["키"] print(students[0]["name"]) # 철수 print(students[1]["score"]) # 95 print(students[2]["age"]) # 14
따라해보세요
STEP 1
위의 students 리스트를 그대로 입력하고 print(students[0])를 실행합니다.
{'name': '철수', 'age': 14, 'score': 88}
STEP 2
print(students[1]["name"])를 실행해 두 번째 학생의 이름을 꺼냅니다.
영희
STEP 3
print(students[-1]["score"])로 마지막 학생의 점수를 확인합니다.
72

2. for 반복으로 중첩 구조 탐색

for문으로 리스트를 순회하면 매번 딕셔너리 하나씩 꺼낼 수 있습니다. 반복 변수에 키를 붙여 바로 값에 접근합니다.

# for 반복으로 모든 학생 출력 for student in students: print(student["name"], "점수:", student["score"]) # 출력: # 철수 점수: 88 # 영희 점수: 95 # 민준 점수: 72

조건 필터링 — 특정 조건 학생만 뽑기

반복 중에 if를 써서 조건에 맞는 딕셔너리만 처리할 수 있습니다.

# 점수 90점 이상인 학생만 출력 for student in students: if student["score"] >= 90: print(student["name"], "- 우수") # 출력: 영희 - 우수
따라해보세요
STEP 1
for student in students:로 반복하며 student["name"]만 출력합니다.
철수 / 영희 / 민준 (줄바꿈)
STEP 2
반복 중 if student["age"] == 14:로 14살 학생만 출력합니다.
철수, 민준
STEP 3
f"{student['name']}: {student['score']}점"으로 f-string 출력합니다.
철수: 88점 / 영희: 95점 / 민준: 72점

3. 딕셔너리 안에 리스트 넣기

한 항목에 여러 값이 필요할 때 딕셔너리의 값을 리스트로 만듭니다. 예: 학생 한 명이 여러 과목 점수를 가질 때, 메뉴 카테고리에 여러 음식이 있을 때.

# 딕셔너리 안에 리스트 classroom = { "name": "3학년 2반", "teacher": "김선생님", "students": ["철수", "영희", "민준"], "scores": [88, 95, 72], } # 리스트 값 접근 print(classroom["students"][0]) # 철수 print(classroom["scores"][1]) # 95

반복으로 딕셔너리 내부 리스트 탐색

# 학생 이름과 점수를 함께 출력 names = classroom["students"] scores = classroom["scores"] for i in range(len(names)): print(f"{names[i]}: {scores[i]}점") # 출력: # 철수: 88점 # 영희: 95점 # 민준: 72점
따라해보세요
STEP 1
classroom["students"]를 출력해 리스트 전체를 확인합니다.
['철수', '영희', '민준']
STEP 2
classroom["students"][2]로 세 번째 학생 이름을 꺼냅니다.
민준
STEP 3
for와 range(len(...))로 이름과 점수를 나란히 출력합니다.
철수: 88점 / 영희: 95점 / 민준: 72점

4. 실용 예제 1 — 학급 명단 시스템

리스트 안의 딕셔너리 구조로 학급 명단을 만들고, 평균 점수 계산과 석차 출력까지 구현합니다.

# 학급 명단 + 평균 계산 students = [ {"name": "철수", "age": 14, "score": 88}, {"name": "영희", "age": 15, "score": 95}, {"name": "민준", "age": 14, "score": 72}, {"name": "수진", "age": 15, "score": 81}, ] # 전체 평균 계산 total = 0 for s in students: total += s["score"] average = total / len(students) print(f"반 평균: {average}점") # 반 평균: 84.0점 # 평균 이상 학생 출력 print("--- 평균 이상 ---") for s in students: if s["score"] >= average: print(s["name"], s["score"])
반 평균: 84.0점 --- 평균 이상 --- 철수 88 영희 95

sorted()로 점수 순위 정렬

sorted()의 key 인자에 람다를 써서 딕셔너리 리스트를 특정 키 기준으로 정렬합니다.

# 점수 높은 순으로 정렬 ranked = sorted(students, key=lambda s: s["score"], reverse=True) for rank, s in enumerate(ranked, 1): print(f"{rank}등 {s['name']}: {s['score']}점")
1등 영희: 95점 2등 철수: 88점 3등 수진: 81점 4등 민준: 72점

5. 실용 예제 2 — 음식점 메뉴판

카테고리별 메뉴와 가격을 중첩 자료구조로 표현합니다. 딕셔너리 안에 딕셔너리 리스트를 넣는 패턴입니다.

# 메뉴판 — 딕셔너리 안에 딕셔너리 리스트 menu = { "밥류": [ {"item": "비빔밥", "price": 9000}, {"item": "볶음밥", "price": 8000}, {"item": "김밥", "price": 5000}, ], "면류": [ {"item": "라면", "price": 6000}, {"item": "냉면", "price": 10000}, ], "음료": [ {"item": "아이스티", "price": 3000}, {"item": "식혜", "price": 2500}, ], } # 전체 메뉴 출력 for category, items in menu.items(): print(f"=== {category} ===") for dish in items: print(f" {dish['item']}: {dish['price']}원")
=== 밥류 === 비빔밥: 9000원 볶음밥: 8000원 김밥: 5000원 === 면류 === 라면: 6000원 냉면: 10000원 === 음료 === 아이스티: 3000원 식혜: 2500원
POINT
menu.items()로 키와 값 동시에

for category, items in menu.items(): — 딕셔너리를 반복할 때 키와 값을 동시에 받습니다. category에는 "밥류" 같은 키가, items에는 딕셔너리 리스트가 들어옵니다.

6. 중첩 구조 데이터 수정과 추가

중첩 구조에서도 인덱스와 키를 조합해 값을 수정하거나, append()로 새 항목을 추가할 수 있습니다.

# 특정 학생의 점수 수정 students[0]["score"] = 92 print(students[0]) # {'name': '철수', 'age': 14, 'score': 92} # 새 학생 추가 students.append({"name": "지우", "age": 14, "score": 79}) print("학생 수:", len(students)) # 학생 수: 5 # 특정 조건으로 삭제 (리스트 컴프리헨션) students = [s for s in students if s["score"] >= 80] print("80점 이상:", len(students), "명") # 80점 이상: 3 명

딕셔너리에 새 키 추가

# 모든 학생에게 "grade" 키 추가 for s in students: if s["score"] >= 90: s["grade"] = "A" elif s["score"] >= 80: s["grade"] = "B" else: s["grade"] = "C" for s in students: print(f"{s['name']}: {s['grade']}등급")

핵심 요약

중첩 자료구조 패턴

  • 리스트 안의 딕셔너리: 같은 구조의 여러 항목을 관리할 때 — 학생 명단, 상품 목록, 게시글 목록
  • 딕셔너리 안의 리스트: 하나의 항목에 여러 값이 필요할 때 — 학급(학생 목록), 메뉴 카테고리
  • 접근법: data[인덱스]["키"] 또는 data["키"][인덱스]
  • for 탐색: for item in list:로 딕셔너리 하나씩 꺼내 키로 접근
  • 수정: data[i]["key"] = 새값 — 인덱스 + 키로 바로 수정
  • 추가: data.append({...}) — 새 딕셔너리를 리스트 끝에 추가
  • 삭제: 리스트 컴프리헨션으로 조건 불만족 항목 제거
