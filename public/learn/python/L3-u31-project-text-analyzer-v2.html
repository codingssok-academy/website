Step 1 — 기본 통계: 글자수 / 단어수 / 줄수

텍스트 분석의 첫 단계는 크기를 파악하는 것입니다. len()으로 글자수, split()으로 단어수, splitlines()로 줄수를 셉니다.

# Step 1: 기본 통계 함수 def basic_stats(text): """글자수, 단어수, 줄수를 반환""" char_count = len(text) word_count = len(text.split()) line_count = len(text.splitlines()) return char_count, word_count, line_count # 테스트 sample = """Python은 강력한 언어입니다. 배우기 쉽고 활용도가 높습니다. 텍스트 분석에도 잘 쓰입니다.""" chars, words, lines = basic_stats(sample) print(f"글자수: {chars}") print(f"단어수: {words}") print(f"줄수: {lines}")
글자수: 54 단어수: 12 줄수: 3

split()은 공백과 줄바꿈을 모두 구분자로 쓰므로 split()만으로 단어수를 셀 수 있습니다. len(text)는 공백과 줄바꿈도 글자로 세기 때문에 실제 텍스트 크기를 측정하는 데 적합합니다.

Step 2 — 가장 긴 단어 / 짧은 단어 찾기

텍스트에서 단어를 추출한 뒤 sorted(key=len)으로 길이 순으로 정렬합니다. 정렬 결과의 맨 앞이 가장 짧은 단어, 맨 뒤가 가장 긴 단어입니다.

sorted()는 원본 리스트를 그대로 두고 새 리스트를 반환합니다. key=len을 쓰면 각 요소의 길이를 기준으로 정렬합니다. 결과 리스트에 슬라이싱 [0]과 [-1]을 쓰면 맨 앞과 맨 뒤에 접근할 수 있습니다.

# Step 2: 가장 긴/짧은 단어 찾기 def word_length_stats(text): """단어 길이 기준 최단/최장 단어 반환""" words = text.split() if not words: return None, None sorted_words = sorted(words, key=len) shortest = sorted_words[0] # 가장 짧은 longest = sorted_words[-1] # 가장 긴 return shortest, longest # 테스트 text = "Python is a powerful language for data analysis" short, long_ = word_length_stats(text) print(f"가장 짧은 단어: {short} ({len(short)}자)") print(f"가장 긴 단어: {long_} ({len(long_)}자)")
가장 짧은 단어: a (1자) 가장 긴 단어: analysis (8자)

길이 순으로 상위 N개 단어 보기

슬라이싱 [-n:]을 쓰면 가장 긴 상위 N개 단어를 한 번에 가져올 수 있습니다. [::-1]을 추가하면 내림차순(긴 것부터)으로 뒤집습니다.

# 상위 3개 긴 단어 (내림차순) def top_n_long_words(text, n=3): words = text.split() sorted_words = sorted(words, key=len) return sorted_words[-n:][::-1] # 슬라이싱 활용 print(top_n_long_words(text)) # ['analysis', 'powerful', 'language']

Step 3 — 단어 빈도 분석

특정 단어가 텍스트에 몇 번 등장하는지 세는 것이 빈도 분석의 핵심입니다. 문자열 메서드 count()와 리스트 컴프리헨션을 조합합니다.

lower()로 대소문자를 통일해야 "The"와 "the"를 같은 단어로 셉니다. 그다음 split()으로 단어 목록을 만들고 count()로 특정 단어의 빈도를 구합니다.

# Step 3: 단어 빈도 분석 def word_frequency(text, target): """특정 단어의 빈도수 반환 (대소문자 무시)""" words = text.lower().split() return words.count(target.lower()) def all_unique_words(text): """고유 단어 목록 반환 (컴프리헨션 + set)""" words = text.lower().split() unique = list(set(words)) # 중복 제거 return sorted(unique) # 알파벳 순 정렬 # 테스트 text2 = "The cat sat on the mat. The cat is fat." print(word_frequency(text2, "the")) # 3 print(word_frequency(text2, "cat")) # 2 print(all_unique_words(text2))
3 2 ['cat', 'fat', 'is', 'mat.', 'on', 'sat', 'the']

컴프리헨션으로 여러 단어 빈도 한 번에 조회

조회하고 싶은 단어 목록이 있다면 리스트 컴프리헨션으로 한 번에 모든 빈도를 구할 수 있습니다.

# 여러 단어 빈도 동시 조회 targets = ["the", "cat", "is"] freqs = [word_frequency(text2, w) for w in targets] print(freqs) # [3, 2, 1] # f-string으로 깔끔하게 출력 for w, f in zip(targets, freqs): print(f" {w:10s}: {f}회")
the : 3회 cat : 2회 is : 1회

Step 4 — 단어 빈도 순위표 (2D 리스트)

지금까지 특정 단어의 빈도를 개별적으로 구했습니다. 이번에는 텍스트 안에 등장하는 모든 고유 단어의 빈도를 2D 리스트로 만들고 빈도 순으로 정렬합니다.

# Step 4: 단어 빈도 순위표 만들기 def build_rank_table(text, top_n=10): """2D 리스트 형태의 빈도 순위표 반환""" words = text.lower().split() unique = list(set(words)) # 컴프리헨션으로 [단어, 빈도] 2D 리스트 생성 table = [[w, words.count(w)] for w in unique] # 빈도 내림차순 정렬 (2D 리스트의 [1] 컬럼 기준) table = sorted(table, key=lambda row: row[1], reverse=True) # 순위 컬럼 추가 for i, row in enumerate(table): row.append(i + 1) # [단어, 빈도, 순위] return table[:top_n] # 상위 top_n개만 반환 # 테스트 text2 = "The cat sat on the mat. The cat is fat." table = build_rank_table(text2) for row in table: print(row)
['the', 3, 1] ['cat', 2, 2] ['fat.', 1, 3] ['is', 1, 4] ['mat.', 1, 5] ['on', 1, 6] ['sat', 1, 7]

lambda row: row[1]은 2D 리스트의 각 행에서 인덱스 1(빈도수)을 꺼내 정렬 기준으로 씁니다. reverse=True를 쓰면 빈도가 높은 것부터 내림차순으로 정렬됩니다.

Step 5 — f-string 포맷팅으로 결과 출력

분석 결과를 읽기 좋게 만드는 것도 중요한 기술입니다. f-string의 정렬 포맷(:<, :>, :^)과 너비 지정을 사용합니다.

# Step 5: 결과 포맷팅 함수 def print_report(text): """분석 결과를 보기 좋게 출력""" chars, words, lines = basic_stats(text) short, long_ = word_length_stats(text) table = build_rank_table(text, top_n=5) print("=" * 38) print(f"{'텍스트 분석 보고서':^36}") print("=" * 38) print(f" 글자수 : {chars:>6}") print(f" 단어수 : {words:>6}") print(f" 줄수 : {lines:>6}") print("-" * 38) print(f" 최단 단어: {short} ({len(short)}자)") print(f" 최장 단어: {long_} ({len(long_)}자)") print("-" * 38) print(" 빈도 순위표 (상위 5)") print(f" {'순위':^4} {'단어':<12} {'빈도':>4}") for row in table: ratio = row[1] / words print(f" {row[2]:^4} {row[0]:<12} {row[1]:>4} ({ratio:.1%})") print("=" * 38)
====================================== 텍스트 분석 보고서 ====================================== 글자수 : 40 단어수 : 8 줄수 : 1 -------------------------------------- 최단 단어: a (1자) 최장 단어: analysis (8자) -------------------------------------- 빈도 순위표 (상위 5) 순위 단어 빈도 1 the 2 (25.0%) 2 a 1 (12.5%) 3 analysis 1 (12.5%) 4 for 1 (12.5%) 5 is 1 (12.5%) ======================================

여러 줄로 이루어진 텍스트에서 각 줄의 단어 수를 2D 리스트로 만드세요. 형식은 [줄번호, 단어수, 줄내용]이며 단어수 내림차순으로 정렬해 출력합니다.

Q3
단어 검색기 — 슬라이싱 활용
어려움

특정 문자로 시작하거나 끝나는 단어를 찾는 함수를 만드세요. 슬라이싱 word[0]과 word[-1]을 사용합니다. 결과는 알파벳 순으로 정렬하고 중복을 제거합니다.

입력 text, starts="p", ends="n"
출력 p로 시작: ['python']
n으로 끝: ['python']
내 답안
힌트 1
word[0]은 단어의 첫 글자, word[-1]은 마지막 글자를 가리킵니다. 비교 전에 lower()를 써서 대소문자를 통일하세요.
힌트 2 + 정답
def search_words(text, starts=None, ends=None): words = text.lower().split() result_s, result_e = [], [] if starts: result_s = sorted(set( [w for w in words if w[0] == starts.lower()] )) if ends: result_e = sorted(set( [w for w in words if w[-1] == ends.lower()] )) return result_s, result_e s_text = "Python is powerful. Python programming pays well." s, e = search_words(s_text, starts="p", ends="n") print(f"p로 시작: {s}") print(f"n으로 끝: {e}")

유닛 요약

이 유닛에서 배운 것

  • len(text)은 글자수, len(text.split())은 단어수, len(text.splitlines())은 줄수를 반환합니다.
  • sorted(words, key=len)으로 단어를 길이 순으로 정렬하고 슬라이싱 [0], [-1]으로 최단/최장 단어를 얻습니다.
  • lower().split()으로 대소문자를 통일한 단어 목록을 만들고 list.count()로 빈도를 셉니다.
  • 리스트 컴프리헨션 [[w, words.count(w)] for w in unique]으로 2D 빈도 테이블을 한 줄에 생성합니다.
  • sorted(table, key=lambda row: row[1], reverse=True)로 2D 리스트를 빈도 내림차순으로 정렬합니다.
  • f-string 포맷 {x:<10s}, {n:>6d}, {r:.1%}으로 분석 보고서를 정렬된 형태로 출력합니다.
