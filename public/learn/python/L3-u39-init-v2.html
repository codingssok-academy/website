__init__
생성자로 초기화하기

클래스를 만들 때 객체의 초기 상태를 설정하는 __init__ 메서드를 이해하고, self, 속성 초기화, 기본값, 유효성 검사까지 단계적으로 학습합니다.

이 유닛에서 배우는 것

  • __init__ 메서드가 무엇인지, 언제 자동으로 호출되는지 이해합니다.
  • self 매개변수의 역할과 인스턴스 속성을 설정하는 방법을 익힙니다.
  • 기본값 매개변수를 활용해 유연한 생성자를 작성합니다.
  • __init__ 안에서 유효성 검사를 넣어 안전한 객체를 만듭니다.
  • 실용 예제인 Student와 BankAccount 클래스를 완성합니다.

__init__ 메서드란

파이썬에서 클래스로 객체를 만들 때, 가장 먼저 자동으로 실행되는 특별 메서드가 __init__입니다. 이름 앞뒤로 밑줄 두 개(__)가 붙어 있어 "던더(dunder) 메서드"라고도 부릅니다.

# __init__ 없이 클래스 만들기 (비교용) class Student: pass s = Student() s.name = "김철수" # 속성을 나중에 따로 설정해야 함 — 불편! s.age = 15 # __init__을 사용한 클래스 (권장) class Student: def __init__(self, name, age): self.name = name # 객체가 만들어지는 순간 자동 실행 self.age = age s = Student("김철수", 15) # 생성과 초기화를 한 번에! print(s.name) # 김철수 print(s.age) # 15

self 매개변수

self는 지금 만들어지고 있는 객체(인스턴스) 자신을 가리킵니다. __init__의 첫 번째 매개변수로 반드시 써야 하며, 파이썬이 자동으로 전달하므로 호출할 때는 직접 넣지 않습니다.

왜 self가 필요한가? 같은 클래스에서 여러 객체를 만들면, 각각의 속성을 구분해야 합니다. self는 "내 속성은 나 자신에게 저장"이라는 뜻입니다. s1.name과 s2.name이 서로 다른 값을 가질 수 있는 이유입니다.

속성 초기화와 기본값 매개변수

__init__에서 self.속성명 = 값 형태로 인스턴스 속성을 설정합니다. 매개변수에 기본값을 주면 일부 정보가 없어도 객체를 만들 수 있습니다.

기본값이 있는 __init__

매개변수에 = 값을 붙이면 기본값이 됩니다. 호출할 때 해당 인수를 생략하면 기본값이 자동으로 들어갑니다. 기본값이 없는 매개변수는 반드시 앞에 위치해야 합니다.

class Student: def __init__(self, name, grade=1, score=0): self.name = name # 필수 — 기본값 없음 self.grade = grade # 선택 — 기본값 1학년 self.score = score # 선택 — 기본값 0점 s1 = Student("김민준") # grade=1, score=0 s2 = Student("이서연", 2) # grade=2, score=0 s3 = Student("박지호", 3, 95) # grade=3, score=95 s4 = Student("최수아", score=88) # grade=1, score=88 (키워드 인수) print(s1.name, s1.grade, s1.score) print(s4.name, s4.grade, s4.score)
김민준 1 0 최수아 1 88

__init__에서 유효성 검사

__init__에서 잘못된 값이 들어오면 즉시 ValueError를 발생시킬 수 있습니다. 이렇게 하면 잘못된 상태의 객체가 만들어지는 것을 원천 차단합니다.

class Student: def __init__(self, name, age, score=0): # 이름 유효성 검사 if not name.strip(): raise ValueError("이름은 빈 문자열일 수 없습니다") # 나이 유효성 검사 if age < 0 or age > 150: raise ValueError(f"나이가 잘못되었습니다: {age}") # 점수 유효성 검사 if not (0 <= score <= 100): raise ValueError(f"점수는 0~100 사이여야 합니다: {score}") self.name = name.strip() # 앞뒤 공백 제거 후 저장 self.age = age self.score = score # 정상 생성 s = Student(" 김철수 ", 15, 85) print(s.name) # "김철수" (공백 제거됨) # 오류 발생 테스트 try: bad = Student("홍길동", -1) except ValueError as e: print(f"오류: {e}")
김철수 오류: 나이가 잘못되었습니다: -1
언제 유효성 검사를 넣어야 할까? 숫자 범위가 있을 때(나이, 점수, 금액), 빈 문자열을 막아야 할 때, 특정 선택지만 허용할 때(예: 등급 A~F) 넣으면 됩니다. 검사 코드는 속성 대입 앞에 위치시킵니다.

실용 예 — Student 클래스 완성하기

지금까지 배운 내용을 모두 합쳐 실제로 쓸 수 있는 Student 클래스를 만들어봅니다. __init__에서 속성 초기화, 기본값, 유효성 검사를 함께 사용합니다. 정보 조회 메서드(예: get_balance, average, info)는 속성값을 읽어 반환하거나 출력하는 패턴입니다. 이후 문제에서는 Rectangle(직사각형), Product(상품) 등 다양한 클래스를 직접 설계합니다.

class Student: def __init__(self, name, age, grade=1): if not name.strip(): raise ValueError("이름을 입력하세요") if not (13 <= age <= 20): raise ValueError(f"나이 범위 오류: {age}") if grade not in (1, 2, 3): raise ValueError(f"학년 오류: {grade}") self.name = name.strip() self.age = age self.grade = grade self.scores = [] # 빈 리스트로 초기화 def add_score(self, score): if not (0 <= score <= 100): raise ValueError("점수는 0~100") self.scores.append(score) def average(self): if not self.scores: return 0 return sum(self.scores) / len(self.scores) def info(self): print(f"{self.name} ({self.grade}학년) — 평균: {self.average():.1f}점") # 사용 s = Student("김민준", 15, 2) s.add_score(90) s.add_score(85) s.add_score(92) s.info()
김민준 (2학년) — 평균: 89.0점
주의: 리스트를 기본값으로 쓰지 말 것. def __init__(self, scores=[])처럼 가변 객체(리스트, 딕셔너리)를 기본값에 직접 쓰면 모든 인스턴스가 같은 리스트를 공유합니다. 반드시 self.scores = []로 인스턴스 내부에서 초기화하세요.

실용 예 — BankAccount 클래스

BankAccount는 __init__의 유효성 검사가 왜 중요한지 잘 보여주는 예입니다. 잔액이 음수인 계좌는 처음부터 만들지 못하도록 막습니다. 기본값 매개변수(예: 화폐 단위, 기본값 "원")처럼 선택 속성도 자유롭게 추가할 수 있습니다.

import uuid class BankAccount: def __init__(self, owner, balance=0): if not owner.strip(): raise ValueError("예금주 이름이 필요합니다") if balance < 0: raise ValueError("초기 잔액은 0 이상이어야 합니다") self.owner = owner.strip() self.balance = balance self.account_no = str(uuid.uuid4())[:8].upper() self.transactions = [] def deposit(self, amount): if amount <= 0: raise ValueError("입금액은 양수여야 합니다") self.balance += amount self.transactions.append(f"+{amount}") def withdraw(self, amount): if amount > self.balance: raise ValueError("잔액 부족") self.balance -= amount self.transactions.append(f"-{amount}") def get_balance(self): return f"{self.owner} 잔액: {self.balance:,}원" # 사용 acc = BankAccount("김민준", 50000) acc.deposit(30000) acc.withdraw(10000) print(acc.get_balance()) print(acc.transactions)
김민준 잔액: 70,000원 ['+30000', '-10000']

넓이 = width * height, 둘레 = 2 * (width + height). 유효성 검사는 if width <= 0 or height <= 0으로 처리합니다.

class Rectangle: def __init__(self, width, height): if width <= 0 or height <= 0: raise ValueError("가로, 세로는 양수여야 합니다") self.width = width self.height = height def area(self): return self.width * self.height def perimeter(self): return 2 * (self.width + self.height) r = Rectangle(5, 3) print(f"넓이: {r.area()}, 둘레: {r.perimeter()}")

Product 클래스 — 재고 관리

온라인 쇼핑몰의 Product 클래스를 만드세요.
__init__은 name(필수), price(필수, 양수), stock(기본값 0, 음수 불가)를 받습니다.
buy(quantity) 메서드: 재고가 충분하면 구매 처리, 부족하면 "재고 부족" 출력.

힌트 보기
buy에서 if quantity > self.stock을 확인합니다. restock은 if quantity <= 0을 검사합니다.
정답 보기
class Product: def __init__(self, name, price, stock=0): if price <= 0: raise ValueError("가격은 양수여야 합니다") if stock < 0: raise ValueError("재고는 0 이상이어야 합니다") self.name = name self.price = price self.stock = stock def buy(self, quantity): if quantity > self.stock: print(f"재고 부족. 현재 재고: {self.stock}") else: self.stock -= quantity print(f"구매 완료. 재고: {self.stock}") def restock(self, quantity): if quantity <= 0: raise ValueError("보충량은 양수여야 합니다") self.stock += quantity print(f"재고 추가 완료. 현재 재고: {self.stock}")

핵심 요약

  • __init__은 객체 생성 시 자동으로 호출되는 초기화 메서드입니다.
  • self는 현재 인스턴스를 가리키며, 항상 첫 번째 매개변수로 씁니다.
  • self.속성 = 값으로 인스턴스 속성을 설정합니다.
  • 기본값 매개변수는 필수 매개변수 뒤에 위치해야 합니다.
  • 가변 객체(list, dict)는 기본값이 아닌 self.attr = []로 초기화합니다.
  • __init__에서 raise ValueError로 잘못된 입력을 즉시 막을 수 있습니다.
