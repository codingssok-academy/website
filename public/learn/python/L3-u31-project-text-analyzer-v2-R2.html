프로젝트:
시저 암호

chr와 ord로 알파벳을 숫자로 변환하고, 슬라이싱과 문자열 메서드를 활용해 암호화/복호화 함수를 완성합니다. 역사 속 가장 오래된 암호를 파이썬으로 구현합니다.

이 프로젝트에서 만드는 것

  • ord()로 문자를 아스키 코드(숫자)로 변환할 수 있습니다.
  • chr()로 아스키 코드를 문자로 되돌릴 수 있습니다.
  • % 26 나머지 연산으로 알파벳을 순환(Z 다음 A)할 수 있습니다.
  • 슬라이싱과 문자열 메서드로 암호화 문자열을 조립할 수 있습니다.
  • 암호화 함수와 복호화 함수를 분리해 설계할 수 있습니다.

핵심 개념 — chr, ord, 그리고 아스키 코드

파이썬에서 모든 문자는 내부적으로 숫자로 저장됩니다. ord()는 문자 → 숫자, chr()는 숫자 → 문자 변환을 담당합니다.

Step 1 — 단일 문자 암호화

한 글자를 받아 시저 암호로 변환하는 과정입니다. ord()로 숫자 변환 → shift 더하기 → % 26 순환 → chr()로 복원 순으로 진행합니다.

# Step 1: 단일 문자 암호화 def encrypt_char(c, shift): """알파벳 한 글자를 시저 암호로 변환""" if c.isalpha(): base = ord('A') if c.isupper() else ord('a') shifted = (ord(c) - base + shift) % 26 return chr(base + shifted) return c # 알파벳 아니면 그대로 # 테스트 print(encrypt_char('A', 3)) # D print(encrypt_char('Z', 3)) # C (순환) print(encrypt_char('!', 3)) # ! (비알파벳 유지)
D C !

Step 2 — 문자열 전체 암호화

encrypt_char()를 각 문자에 적용하는 방법은 두 가지입니다. 반복문을 쓰거나 리스트 컴프리헨션을 쓸 수 있습니다.

# Step 2: 문자열 암호화 함수 def encrypt(text, shift): """문자열 전체를 시저 암호로 변환 (리스트 컴프리헨션)""" encrypted = [encrypt_char(c, shift) for c in text] return "".join(encrypted) print(encrypt("Hello, World!", 3)) # Khoor, Zruog! print(encrypt("Python", 13)) # ROT13 print(encrypt("ABCXYZ", 3)) # DEFABC (순환 확인)
Khoor, Zruog! Clguba DEFABC

Step 3 — 복호화 함수

복호화는 암호화의 역과정입니다. shift를 빼면 원문을 복원할 수 있습니다. 수학적으로 -shift는 26 - shift와 같습니다.

# Step 3: 복호화 함수 def decrypt(text, shift): """암호문을 원문으로 복원""" return encrypt(text, 26 - shift) # -shift 와 동일 # 검증: 암호화 후 복호화하면 원문이 나와야 함 original = "Hello, World!" encoded = encrypt(original, 3) decoded = decrypt(encoded, 3) print(f"원문: {original}") print(f"암호화: {encoded}") print(f"복호화: {decoded}") print(f"복원 성공: {original == decoded}")
원문: Hello, World! 암호화: Khoor, Zruog! 복호화: Hello, World! 복원 성공: True

Step 4 — 완성 프로그램 통합

암호화/복호화 함수를 하나의 caesar_cipher.py로 통합합니다. 슬라이싱으로 암호화된 문자열의 일부를 추출하는 기능도 추가합니다.

# caesar_cipher.py — 완성 프로그램 def encrypt_char(c, shift): if c.isalpha(): base = ord('A') if c.isupper() else ord('a') return chr(base + (ord(c) - base + shift) % 26) return c def encrypt(text, shift): return "".join([encrypt_char(c, shift) for c in text]) def decrypt(text, shift): return encrypt(text, 26 - shift) def main(): messages = ["Attack at dawn", "Python 3.12", "Hello, World!"] shift = 7 print(f"=== 시저 암호 (shift={shift}) ===\n") for msg in messages: enc = encrypt(msg, shift) dec = decrypt(enc, shift) # 슬라이싱: 암호문 앞 5글자만 미리보기 preview = enc[:5] print(f"원문: {msg}") print(f"암호화: {enc} (미리보기: {preview}...)") print(f"복호화: {dec}\n") main()
=== 시저 암호 (shift=7) === 원문: Attack at dawn 암호화: Haahje ha khdu (미리보기: Haahj...) 복호화: Attack at dawn 원문: Python 3.12 암호화: Wfaovu 3.12 (미리보기: Wfaov...) 복호화: Python 3.12

Q2. 슬라이싱으로 암호 메시지 조립
보통
두 문자열의 짝수 인덱스와 홀수 인덱스를 각각 다른 shift로 암호화해 합치는 double_encrypt(text, s1, s2)를 작성하세요. 슬라이싱 [::2]와 [1::2]를 활용합니다.
입력"HELLO", s1=3, s2=7
짝수위치HLO (인덱스 0,2,4)
홀수위치EL (인덱스 1,3)
힌트 보기
text[::2]는 짝수 인덱스 문자, text[1::2]는 홀수 인덱스 문자를 추출합니다. 각각 다른 shift로 암호화 후 합치세요.
정답 보기
def double_encrypt(text, s1, s2): evens = encrypt(text[::2], s1) odds = encrypt(text[1::2], s2) return evens + " | " + odds print(double_encrypt("HELLO", 3, 7))

Q3. 단어별 다른 shift 암호화

문장을 단어로 분리한 뒤, 각 단어에 단어 위치 번호를 shift로 적용해 암호화하는 word_cipher(text)를 작성하세요. 첫 번째 단어는 shift 1, 두 번째는 shift 2, ...
입력"Hello World Python"
출력"Ifmmp Yqtnf Sbwkrq"
힌트 보기
enumerate(text.split())로 단어와 인덱스를 함께 꺼낸 뒤 encrypt(word, i+1)를 적용하세요. 결과를 " ".join()으로 합칩니다.
정답 보기
def word_cipher(text): words = text.split() result = [encrypt(w, i+1) for i, w in enumerate(words)] return " ".join(result) print(word_cipher("Hello World Python"))

핵심 요약 — 시저 암호 완성

핵심 요약

  • ord(c) — 문자 c의 아스키 코드(정수)를 반환. ord('A')=65, ord('a')=97.
  • chr(n) — 정수 n에 해당하는 문자를 반환. chr(65)='A'.
  • % 26 — 나머지 연산으로 0~25 범위로 순환. Z 다음이 A가 되도록 함.
  • c.isupper() — 대문자면 True. 대소문자를 구별해 base 값을 선택.
  • c.isalpha() — 알파벳이면 True. 숫자, 공백, 구두점은 그대로 유지.
  • s[::2] — 짝수 인덱스만 추출. s[1::2]는 홀수 인덱스. 슬라이싱 step 활용.
  • "".join(list) — 문자 리스트를 하나의 문자열로 조립.
