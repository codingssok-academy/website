슬라이싱 심화
문자열과 리스트 자르기

start, stop, step으로 원하는 부분만 정밀하게 잘라내는 기술을 배웁니다.

이 유닛에서 배우는 것

  • 슬라이싱의 start, stop, step 세 매개변수를 모두 사용할 수 있습니다.
  • 음수 인덱스로 뒤에서부터 자를 수 있습니다.
  • step을 이용해 문자열/리스트를 건너뛰며 추출할 수 있습니다.
  • step=-1로 문자열/리스트를 뒤집을 수 있습니다.
  • 리스트 슬라이싱으로 일부를 교체하거나 삭제할 수 있습니다.

슬라이싱 문법 — [start:stop:step]

슬라이싱은 [시작:끝:간격] 형식으로 씁니다. 각 값을 생략하면 기본값이 적용됩니다.

# 문자열 슬라이싱 s = "Python" print(s[0:6]) # Python (전체) print(s[2:5]) # tho print(s[:3]) # Pyt (처음부터 3개) print(s[3:]) # hon (3번째부터 끝까지) print(s[::]) # Python (전체 복사) # step 사용 print(s[::2]) # Pto (한 칸씩 건너뛰기) print(s[::-1]) # nohtyP (뒤집기!)

step이 양수면 왼쪽→오른쪽, 음수면 오른쪽→왼쪽으로 이동합니다. [::-1]은 문자열/리스트를 뒤집는 관용 표현이에요.

음수 인덱스와 리스트 슬라이스 수정

음수 인덱스는 뒤에서부터 세는 방법입니다. -1이 마지막, -2가 뒤에서 두 번째예요. 문자열이나 리스트가 길 때 뒤쪽 요소를 쉽게 꺼낼 수 있습니다.

# 음수 인덱스 활용 s = "Hello, World!" print(s[-6:]) # orld! print(s[-6:-1]) # orld print(s[:-7]) # Hello, # 리스트 슬라이스로 수정/삭제 fruits = ["사과", "바나나", "체리", "딸기", "포도"] fruits[1:3] = ["망고", "키위"] # 교체 print(fruits) # ['사과', '망고', '키위', '딸기', '포도'] fruits[2:4] = [] # 삭제 print(fruits) # ['사과', '망고', '포도'] fruits[1:1] = ["레몬", "라임"] # 삽입 print(fruits) # ['사과', '레몬', '라임', '망고', '포도']
슬라이스 수정은 리스트만 가능

문자열은 불변(immutable)이라 슬라이스로 내용을 바꿀 수 없어요. 리스트만 fruits[1:3] = [...] 처럼 수정할 수 있습니다.

실전 활용 — 슬라이싱으로 문제 풀기

슬라이싱은 실무에서도 자주 씁니다. 특히 문자열 파싱, 데이터 전처리, 알고리즘 문제에서 핵심 기술이에요.

# 실전 예시 1: 날짜 파싱 date = "2025-03-21" year = date[:4] # 2025 month = date[5:7] # 03 day = date[8:] # 21 print(f"{year}년 {month}월 {day}일") # 실전 예시 2: 리스트 반반 나누기 data = [1, 2, 3, 4, 5, 6] mid = len(data) // 2 left = data[:mid] # [1, 2, 3] right = data[mid:] # [4, 5, 6] # 실전 예시 3: 마지막 n개 제거 path = "/home/user/documents/file.txt" folder = path[:path.rfind("/")] print(folder) # /home/user/documents

핵심 요약

  • [start:stop:step] — 세 값 모두 생략 가능, 기본값은 처음/끝/1
  • [::-1] — 문자열·리스트 뒤집기의 관용 표현
  • 음수 인덱스: -1=마지막, -n=뒤에서 n번째
  • 리스트는 슬라이스로 교체·삽입·삭제 가능, 문자열은 불가
  • step 양수=정방향, 음수=역방향 이동
