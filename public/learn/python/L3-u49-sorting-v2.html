Step 1 — 왜 정렬이 필요한가

컴퓨터는 데이터를 처리할 때 정렬된 상태를 자주 요구합니다. 정렬이 되어 있으면 원하는 값을 훨씬 빠르게 찾을 수 있기 때문입니다.

정렬은 이진 탐색(binary search)처럼 빠른 검색 알고리즘의 전제 조건이기도 합니다. 정렬된 데이터에서는 중간값을 기준으로 탐색 범위를 절반씩 줄일 수 있습니다.

정렬 알고리즘 종류

대표적인 정렬 알고리즘들을 효율(시간 복잡도) 기준으로 비교하면 다음과 같습니다.

알고리즘방식시간 복잡도특징
버블 정렬인접 쌍 교환O(n²)이해하기 쉬움, 느림
선택 정렬최솟값 선택 후 배치O(n²)교환 횟수 적음
삽입 정렬적절한 위치 삽입O(n²)거의 정렬된 경우 빠름
병합 정렬나누고 합치기O(n log n)안정적, 재귀 사용
퀵 정렬pivot 기준 분할평균 O(n log n)실무에서 자주 사용

이 유닛에서는 버블 정렬과 선택 정렬을 직접 구현합니다. 가장 이해하기 쉬운 O(n²) 알고리즘으로 정렬의 핵심 원리를 익히는 것이 목표입니다.

Step 2 — 버블 정렬 (Bubble Sort)

버블 정렬은 인접한 두 원소를 비교해서 순서가 잘못됐으면 맞바꾸는 방식입니다. 큰 값이 물거품처럼 오른쪽 끝으로 떠오릅니다.

1패스가 끝나면 가장 큰 값(8)이 맨 오른쪽에 확정됩니다. 이 과정을 n-1번 반복하면 모두 정렬됩니다.

swap 구현 — 임시 변수

두 값을 맞바꾸려면 임시 변수가 필요합니다. 직접 대입하면 한쪽 값이 덮어써져 사라지기 때문입니다.

# 잘못된 방법 — a가 사라짐 a = 5 b = 2 a = b # a = 2 (5가 사라짐!) b = a # b = 2 (여전히 2) # 올바른 방법 1 — 임시 변수 사용 a = 5 b = 2 tmp = a # tmp = 5 a = b # a = 2 b = tmp # b = 5 # 올바른 방법 2 — 파이썬 튜플 언팩 (권장) a, b = b, a # 한 줄로 swap 완성

버블 정렬 전체 코드

def bubble_sort(lst): n = len(lst) for i in range(n - 1): # 패스 횟수 for j in range(n - 1 - i): # 비교 범위 (이미 정렬된 끝 제외) if lst[j] > lst[j + 1]: # 앞이 더 크면 swap lst[j], lst[j + 1] = lst[j + 1], lst[j] return lst numbers = [5, 2, 8, 1, 9] print(bubble_sort(numbers))
[1, 2, 5, 8, 9]
이중 for문 구조 이해하기

바깥 for(i)는 패스 횟수를 제어합니다. n=5일 때 4번 패스가 필요합니다.
안쪽 for(j)는 실제 비교 범위입니다. i패스가 끝날 때마다 오른쪽 끝 i개는 이미 정렬됐으므로 범위를 n-1-i로 줄입니다.
총 비교 횟수 = (n-1) + (n-2) + ... + 1 = n(n-1)/2 = O(n²)

최적화 — 이미 정렬됐으면 일찍 끝내기

한 패스에서 교환이 한 번도 없으면 이미 정렬된 상태입니다. swapped 플래그로 조기 종료할 수 있습니다.

def bubble_sort_opt(lst): n = len(lst) for i in range(n - 1): swapped = False for j in range(n - 1 - i): if lst[j] > lst[j + 1]: lst[j], lst[j + 1] = lst[j + 1], lst[j] swapped = True if not swapped: # 교환 없으면 종료 break return lst

Step 3 — 선택 정렬 (Selection Sort)

선택 정렬은 전체에서 가장 작은 값을 찾아 맨 앞 자리와 교환하는 방식입니다. 버블 정렬보다 교환 횟수가 적습니다.

선택 정렬 전체 코드

def selection_sort(lst): n = len(lst) for i in range(n - 1): # i: 확정할 위치 min_idx = i # 현재 위치를 최솟값으로 가정 for j in range(i + 1, n): # i+1부터 끝까지 탐색 if lst[j] < lst[min_idx]: # 더 작은 값 발견 min_idx = j # 최솟값 인덱스 갱신 if min_idx != i: # 위치가 다를 때만 swap lst[i], lst[min_idx] = lst[min_idx], lst[i] return lst numbers = [5, 2, 8, 1, 9] print(selection_sort(numbers))
[1, 2, 5, 8, 9]

min_idx != i 조건을 확인하는 이유: 최솟값이 이미 올바른 위치에 있으면 불필요한 swap을 막아 효율을 높입니다. 생략해도 결과는 같지만 불필요한 교환이 발생합니다.

sorted()와 직접 만든 정렬 비교

파이썬에는 이미 고도로 최적화된 내장 정렬 함수 sorted()와 list.sort()가 있습니다. 그렇다면 왜 직접 만드는 것을 배울까요?

항목sorted() / sort()직접 구현 (버블/선택)

time 모듈을 이용해 버블 정렬과 선택 정렬의 실행 시간을 측정하고 비교하세요. 1000개의 무작위 숫자를 사용합니다.

핵심 요약

정렬이 필요한 이유

  • 데이터를 순서대로 나열하면 검색, 비교, 분석 작업이 훨씬 빠릅니다.
  • 이진 탐색 등 효율적 알고리즘의 전제 조건이 됩니다.
  • 도서관, 게임 랭킹, 쇼핑몰 가격 정렬 등 실생활 곳곳에 사용됩니다.

버블 정렬 핵심

  • 인접한 두 원소를 비교하여 순서가 잘못됐으면 swap합니다.
  • 이중 for문 사용: 바깥 for(패스 횟수), 안쪽 for(비교 범위 n-1-i).
  • 파이썬 swap: a, b = b, a 한 줄로 처리합니다.
  • 시간 복잡도 O(n²), 각 패스마다 가장 큰 값이 오른쪽으로 확정됩니다.

선택 정렬 핵심

  • 전체에서 최솟값 인덱스를 찾아 현재 위치 i와 교환합니다.
  • min_idx = i로 시작하고 더 작은 값이 있으면 min_idx를 갱신합니다.
  • 교환은 각 패스당 최대 1번으로 버블 정렬보다 swap 횟수가 적습니다.
  • 시간 복잡도 O(n²), 비교 횟수는 버블 정렬과 동일합니다.

sorted()와 비교

  • sorted(lst): 원본 유지, 새 리스트 반환 / lst.sort(): 원본 직접 수정
  • 내장 함수는 Timsort (O(n log n)) — 직접 구현 알고리즘보다 훨씬 빠릅니다.
  • 실무에서는 내장 함수를 사용하고, 원리 이해와 코딩 테스트를 위해 직접 구현을 익힙니다.
