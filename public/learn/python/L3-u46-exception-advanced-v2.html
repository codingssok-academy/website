예외 처리 활용:
여러 에러 잡기, finally

여러 except 블록, 튜플로 묶어서 잡기, else와 finally 블록의 역할, 그리고 입력 검증 루프까지 — 실전에서 쓰이는 예외 처리 패턴을 모두 익힙니다.

이 유닛에서 배우는 것

  • 여러 except 블록으로 에러 종류에 따라 다르게 처리할 수 있습니다.
  • except (TypeError, ValueError)처럼 튜플로 묶어 한 번에 잡을 수 있습니다.
  • else 블록이 "에러가 없었을 때만" 실행된다는 것을 이해합니다.
  • finally 블록이 에러 여부와 상관없이 항상 실행된다는 것을 이해합니다.
  • 입력 검증 루프 패턴으로 사용자가 올바른 값을 입력할 때까지 반복할 수 있습니다.

여러 except 블록 — 에러 종류별로 다르게 처리

하나의 try 블록에 except를 여러 개 붙이면, 에러 종류마다 다른 처리를 할 수 있습니다. 파이썬은 위에서 아래로 순서대로 확인하다가 일치하는 첫 번째 except만 실행합니다.

# 여러 except 블록 예시 def safe_divide(a, b): try: result = a / b print(f"결과: {result}") except ZeroDivisionError: print("오류: 0으로 나눌 수 없습니다") except TypeError: print("오류: 숫자만 입력해야 합니다") safe_divide(10, 2) safe_divide(10, 0) safe_divide(10, "두")
결과: 5.0 오류: 0으로 나눌 수 없습니다 오류: 숫자만 입력해야 합니다
핵심 규칙
에러가 발생하면 파이썬은 except 블록을 위에서부터 차례로 확인해 일치하는 첫 번째 블록만 실행합니다. 나머지 except는 건너뜁니다.

튜플로 묶어 잡기 & else 블록

except (TypeError, ValueError) — 한 번에 여러 에러 잡기

같은 방식으로 처리할 에러가 여러 개면 튜플로 묶어서 하나의 except 블록으로 잡을 수 있습니다. 코드가 짧아지고 가독성이 높아집니다.

# 튜플로 여러 에러를 한 번에 잡기 def parse_number(text): try: result = int(text) * 2 print(f"두 배: {result}") except (ValueError, TypeError): print("오류: 정수로 변환할 수 없습니다") parse_number("5") parse_number("abc") parse_number(None)
두 배: 10 오류: 정수로 변환할 수 없습니다 오류: 정수로 변환할 수 없습니다

else 블록 — 에러가 없었을 때만 실행

else 블록은 try 블록이 에러 없이 완료됐을 때만 실행됩니다. "성공 후 처리" 로직을 try 밖으로 분리해 코드를 명확하게 만듭니다.

# else 블록 — 에러 없을 때만 실행 def read_age(text): try: age = int(text) except ValueError: print("숫자를 입력해주세요") else: # try가 성공했을 때만 실행 print(f"나이 {age}세 입력 완료") read_age("20") read_age("스무살")
나이 20세 입력 완료 숫자를 입력해주세요
else vs try 안에 바로 쓰기
성공 처리 코드를 try 안에 쓸 수도 있지만, else로 분리하면 "어디서 에러가 날 수 있는지"가 명확해집니다. 실무 코드에서는 else를 권장합니다.

finally 블록 — 무조건 실행

finally 블록은 try 블록이 성공하든, 에러가 나든, return으로 빠져나가든 무조건 실행됩니다. 파일 닫기, 연결 해제 등 "반드시 해야 하는 정리 작업"에 사용합니다.

# finally 블록 기본 사용 def divide_with_log(a, b): print("--- 계산 시작 ---") try: result = a / b print(f"결과: {result}") except ZeroDivisionError: print("오류: 0으로 나눌 수 없습니다") finally: print("--- 계산 종료 ---") # 항상 실행 divide_with_log(10, 2) print() divide_with_log(10, 0)
--- 계산 시작 --- 결과: 5.0 --- 계산 종료 --- --- 계산 시작 --- 오류: 0으로 나눌 수 없습니다 --- 계산 종료 ---

파일 처리에서의 finally 패턴

파일을 열 때는 예외가 발생해도 반드시 파일을 닫아야 합니다. finally가 이 역할을 보장합니다.

# 파일 처리에서 finally로 반드시 닫기 f = None try: f = open("data.txt", "r") content = f.read() print(content) except FileNotFoundError: print("파일을 찾을 수 없습니다") finally: if f is not None: f.close() print("파일 닫힘")
실무 팁
파일 처리는 대부분 with open(...) as f: 방식으로 쓰며, 이 경우 with 블록이 끝나면 자동으로 파일이 닫힙니다. finally와 동일한 효과를 더 간결하게 제공합니다.

def full_example(x): try: result = 100 / x except ZeroDivisionError: print("0 불가") else: print(f"성공: {result}") finally: print("완료") full_example(5) full_example(0)

실용 패턴 — 입력 검증 루프

사용자가 올바른 값을 입력할 때까지 계속 다시 묻는 패턴입니다. while True로 무한 반복하고, 올바른 입력이 들어오면 break로 루프를 빠져나갑니다.

# 실용 패턴: 올바른 정수 입력 받기 def get_integer(prompt): """올바른 정수를 입력받을 때까지 반복""" while True: text = input(prompt) try: number = int(text) except ValueError: print(f"'{text}'은 정수가 아닙니다. 다시 입력하세요.") else: return number # 성공 시 값 반환하며 루프 종료 age = get_integer("나이를 입력하세요: ") print(f"입력된 나이: {age}")
나이를 입력하세요: 스무살 '스무살'은 정수가 아닙니다. 다시 입력하세요. 나이를 입력하세요: twenty 'twenty'은 정수가 아닙니다. 다시 입력하세요. 나이를 입력하세요: 20 입력된 나이: 20

범위까지 검증하는 확장 패턴

# 범위 검증 포함 입력 루프 def get_score(): """0~100 사이 점수 입력 받기""" while True: try: score = int(input("점수 (0~100): ")) except ValueError: print("숫자를 입력해주세요") continue # 루프 맨 위로 if not (0 <= score <= 100): print("0과 100 사이로 입력해주세요") else: return score

전체 구조 요약 & 종합 예제

종합 예제 — 계산기 (입력 검증 + 여러 except + finally)

# 종합: 계산기 — 입력검증 + 여러 except + finally def calculator(): print("=== 나누기 계산기 ===") while True: try: a = int(input("첫 번째 수: ")) b = int(input("두 번째 수: ")) result = a / b except ValueError: print("정수를 입력하세요. 다시 시도합니다.") continue except ZeroDivisionError: print("0으로 나눌 수 없습니다. 다시 시도합니다.") continue else: print(f"결과: {a} / {b} = {result}") finally: print("--- 시도 완료 ---") break # 성공 시 루프 종료 calculator()
첫 번째 수: abc 정수를 입력하세요. 다시 시도합니다. --- 시도 완료 --- 첫 번째 수: 10 두 번째 수: 0 0으로 나눌 수 없습니다. 다시 시도합니다. --- 시도 완료 --- 첫 번째 수: 10 두 번째 수: 3 결과: 10 / 3 = 3.3333333333333335 --- 시도 완료 ---

핵심 요약

  • 여러 except — 에러 종류마다 다른 처리 블록을 연결할 수 있다
  • except (A, B) — 튜플로 묶어 여러 에러를 같은 블록에서 처리한다
  • else — try가 에러 없이 완료됐을 때만 실행, 성공 로직 분리에 사용
  • finally — 성공/실패 무관하게 무조건 실행, 정리 작업에 사용
  • 입력 검증 루프 — while True + try/except + break 패턴으로 올바른 입력 강제

Q2
else와 finally 순서 이해
보통
아래 코드를 실행하면 어떤 순서로 출력될까요? 실행 결과를 순서대로 쓰세요.
코드
try:
x = int("5")
except ValueError:
print("A")
else:
print("B")
finally:
print("C")
힌트 보기
int("5")는 성공합니다. 에러가 없으니 except는 실행되지 않고, else와 finally는 각각의 조건에 따라 실행됩니다.
정답 보기
B C # int("5") 성공 → except 건너뜀 # else 실행 → B 출력 # finally 무조건 실행 → C 출력
Q3
입력 검증 루프 작성
어려움
1~10 사이의 정수만 받는 함수 get_number()를 작성하세요. 숫자가 아닌 입력이나 범위를 벗어난 숫자 입력 시 각각 다른 오류 메시지를 출력하고 다시 입력받아야 합니다.
입력
abc → "숫자를 입력하세요"
15 → "1~10 사이로 입력하세요"
7 → "입력됨: 7" 출력 후 종료
힌트 보기
while True 안에서 try로 int() 변환을 시도하고 ValueError는 except로 잡습니다. 변환 성공 후 if not (1 <= n <= 10)으로 범위를 별도로 검사합니다.
정답 보기
def get_number(): while True: try: n = int(input("1~10 사이 숫자: ")) except ValueError: print("숫자를 입력하세요") continue if not (1 <= n <= 10): print("1~10 사이로 입력하세요") else: print(f"입력됨: {n}") return n
