Chapter 05

조건문
if, elif, else

조건에 따라 다른 코드를 실행하는 분기 구조를 배웁니다.

신호등처럼, 조건에 따라 다른 행동을 한다

이 유닛에서 배우는 것

  • if 문으로 조건이 참일 때 코드를 실행할 수 있습니다.
  • if-else로 참/거짓에 따라 다른 코드를 실행할 수 있습니다.
  • elif로 여러 조건을 순서대로 검사할 수 있습니다.
  • 비교 연산자(==, !=, >, <, >=, <=)를 조건에 활용할 수 있습니다.
  • 중첩 if 문을 작성할 수 있습니다.

if 문 — 조건이 참이면 실행

if는 조건이 True일 때만 들여쓴 코드를 실행합니다. 콜론(:)과 들여쓰기를 반드시 지켜야 합니다.

if score >= 90: print("합격입니다!")
따라해보세요
1
숫자를 입력받아 양수인지 확인하세요.
num = int(input("숫자: ")) if num > 0: print("양수입니다")
5를 입력하면 "양수입니다" 출력
2
점수가 60 이상이면 "통과"를 출력하세요.
score = int(input("점수: ")) if score >= 60: print("통과!")
75를 입력하면 "통과!" 출력
3
비밀번호가 맞는지 확인하세요.
pw = input("비밀번호: ") if pw == "1234": print("로그인 성공!")
1234를 입력하면 "로그인 성공!" 출력

if-else — 참이면 A, 거짓이면 B

else는 if 조건이 거짓일 때 실행됩니다. 항상 둘 중 하나만 실행됩니다.

age = int(input("나이: ")) if age >= 18: print("성인입니다") else: print("미성년자입니다")
따라해보세요
1
짝수/홀수를 판별하세요.
num = int(input("숫자: ")) if num % 2 == 0: print("짝수") else: print("홀수")
7을 입력하면 "홀수" 출력
2
두 수 중 큰 수를 출력하세요.
a = int(input("첫째: ")) b = int(input("둘째: ")) if a > b: print(a, "이(가) 더 큽니다") else: print(b, "이(가) 더 큽니다")
10, 25 입력하면 "25 이(가) 더 큽니다"
3
합격/불합격을 판정하세요.
score = int(input("점수: ")) if score >= 60: print("합격") else: print("불합격")
45를 입력하면 "불합격" 출력

elif — 여러 조건 순서대로 검사

elif는 "else if"의 줄임말입니다. 위에서부터 순서대로 검사하고, 참인 첫 번째 블록만 실행됩니다.

score = int(input("점수: ")) if score >= 90: print("수") elif score >= 80: print("우") elif score >= 70: print("미") else: print("노력이 필요해요")
따라해보세요
1
위 성적 판정 코드를 입력하고, 85를 넣어보세요.
score = int(input("점수: ")) if score >= 90: print("수") elif score >= 80: print("우") elif score >= 70: print("미") else: print("노력이 필요해요")
85 입력 → "우" 출력
2
온도에 따라 옷차림을 추천하세요.
temp = int(input("기온(도): ")) if temp >= 30: print("반팔 입자!") elif temp >= 20: print("긴팔이면 딱!") elif temp >= 10: print("겉옷 챙기자!") else: print("패딩 필수!")
5를 입력하면 "패딩 필수!" 출력
3
BMI 판정기를 만들어보세요.
bmi = float(input("BMI: ")) if bmi >= 25: print("과체중") elif bmi >= 18.5: print("정상") else: print("저체중")
22.5 입력하면 "정상" 출력

중첩 if와 논리 연산자

if 안에 또 다른 if를 넣을 수 있습니다. and, or, not으로 여러 조건을 조합할 수도 있습니다.

# and: 두 조건 모두 참 age = int(input("나이: ")) score = int(input("점수: ")) if age >= 13 and score >= 80: print("참가 가능!")
따라해보세요
1
and로 두 조건을 동시에 검사하세요.
kor = int(input("국어: ")) math = int(input("수학: ")) if kor >= 70 and math >= 70: print("두 과목 모두 합격!") else: print("재시험 필요")
80, 65 입력 → "재시험 필요"
2
or로 하나라도 만족하면 통과하게 만드세요.
vip = input("VIP인가요? (y/n): ") coupon = input("쿠폰 있나요? (y/n): ") if vip == "y" or coupon == "y": print("할인 적용!") else: print("정가 결제")
n, y 입력 → "할인 적용!"
3
not으로 조건을 뒤집어보세요.
rain = input("비 오나요? (y/n): ") if not rain == "y": print("산책 가자!") else: print("우산 챙겨!")
n 입력 → "산책 가자!"

들여쓰기 규칙과 흔한 실수

파이썬에서 if 블록은 반드시 들여쓰기로 구분합니다. 공백 4칸이 표준입니다.

실전 예제

예제 1: 신호등 판별기

color = input("신호등 색: ") if color == "빨강": print("멈추세요!") elif color == "노랑": print("준비하세요!") elif color == "초록": print("출발하세요!") else: print("잘못된 입력입니다")

예제 2: 계절 판별기

month = int(input("몇 월? ")) if 3 <= month <= 5: print("봄이에요") elif 6 <= month <= 8: print("여름이에요") elif 9 <= month <= 11: print("가을이에요") else: print("겨울이에요")

파이썬에서는 3 <= month <= 5처럼 연속 비교가 가능합니다. 다른 언어에서는 and를 써야 합니다.

핵심 요약

이 유닛에서 배운 것

  • if 조건:으로 조건이 참일 때만 코드를 실행한다
  • else:로 조건이 거짓일 때 실행할 코드를 작성한다
  • elif 조건:으로 여러 조건을 순서대로 검사한다
  • 비교 연산자: ==, !=, >, <, >=, <=
  • 논리 연산자: and(둘 다 참), or(하나라도 참), not(반전)
  • 조건 뒤 콜론(:)과 4칸 들여쓰기는 필수
  • 파이썬에서는 3 <= x <= 5 같은 연속 비교가 가능하다
