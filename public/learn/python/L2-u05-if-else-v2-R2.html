논리 연산자 완전 정복

and, or, not의 동작을 정확히 이해하면 복잡한 조건도 간결하게 쓸 수 있습니다.

진리표 (Truth Table)

ABA and BA or Bnot A
TrueTrueTrueTrueFalse
TrueFalseFalseTrueFalse
FalseTrueFalseTrueTrue
FalseFalseFalseFalseTrue
핵심 암기법 and = "그리고" (둘 다 조건 만족해야 참)  |  or = "또는" (하나만 만족해도 참)  |  not = "아니다" (반전)
# and: 두 조건 모두 참이어야 age = 15 score = 85 if age >= 13 and score >= 80: print("경시대회 참가 가능!") # 출력됨 # or: 하나라도 참이면 has_ticket = False is_vip = True if has_ticket or is_vip: print("입장 가능!") # 출력됨 # not: 조건 반전 is_raining = False if not is_raining: print("자전거 타러 가자!") # 출력됨

나이가 13세 이상이고 키가 150cm 이상일 때 놀이기구 탑승 가능.
age = int(input("나이: ")) height = int(input("키(cm): ")) if age >= 13 and height >= 150: print("탑승 가능!") else: print("탑승 불가")

할인 쿠폰 또는 멤버십 카드가 있으면 할인 적용.
coupon = input("쿠폰 있나요? (y/n): ") member = input("멤버십 있나요? (y/n): ") if coupon == "y" or member == "y": print("20% 할인!") else: print("정가 결제")
n, y → 20% 할인!

복잡한 조건 조합하기

여러 논리 연산자를 한 번에 쓸 수 있습니다. 괄호로 우선순위를 명확하게 표현하는 것이 좋습니다.

# 우선순위 예시 x = 5 print(not x > 3 and x < 10) # not(True) and True → False and True → False print(not (x > 3 and x < 10)) # not(True and True) → not True → False # 괄호로 의도를 명확히! score = 88 grade = "A" if (score >= 80 and score < 90) and grade == "A": print("우수 A등급!")

실전 패턴: 범위 검사

파이썬은 a <= x <= b 연속 비교를 지원합니다. 더 읽기 쉬운 표현입니다.

# 범위 검사 — 3가지 방법 (모두 동일) x = 7 # 방법 1: and 사용 if x >= 1 and x <= 10: print("1~10 사이") # 방법 2: 파이썬 연속 비교 (권장!) if 1 <= x <= 10: print("1~10 사이") # 실전: 중학생(13~15세) 판별 age = int(input("나이: ")) if 13 <= age <= 15: print("중학생이네요!") elif 16 <= age <= 18: print("고등학생이네요!") else: print("초등학생이거나 대학생이에요")

in 연산자 — 여러 값 중 하나인지 검사

# in으로 여러 elif를 줄일 수 있다 # 길고 반복적인 방법 day = input("요일: ") if day == "토" or day == "일": print("주말!") # in으로 더 깔끔하게 (권장!) if day in ["토", "일"]: print("주말!") # not in: 포함되지 않으면 if day not in ["토", "일"]: print("평일이에요")

점수가 70~79점이면 "C등급", 80~89점이면 "B등급"을 연속 비교로.
score = int(input("점수: ")) if 90 <= score <= 100: print("A등급") elif 80 <= score <= 89: print("B등급") elif 70 <= score <= 79: print("C등급") else: print("재시험")

좋아하는 과목이 "수학", "과학", "컴퓨터" 중 하나인지 in으로 확인.
subject = input("좋아하는 과목: ") if subject in ["수학", "과학", "컴퓨터"]: print("이공계 적성이네요!") else: print("문과 적성이에요")
수학 → 이공계 적성이네요!

삼항 연산자 — 한 줄 if

간단한 if-else는 한 줄로 줄일 수 있습니다. 조건부 표현식(conditional expression)이라고 합니다.

# 기존 방법 (4줄) score = 75 if score >= 60: result = "합격" else: result = "불합격" # 삼항 연산자 (1줄!) result = "합격" if score >= 60 else "불합격" print(result) # 합격 # 바로 print에 넣기도 가능 age = int(input("나이: ")) print("성인" if age >= 18 else "미성년자") # 최댓값 구하기 a, b = 10, 25 maximum = a if a > b else b print(f"최댓값: {maximum}") # 최댓값: 25
주의 삼항 연산자는 간단한 조건에만 쓰세요. 복잡한 조건을 한 줄에 쓰면 오히려 읽기 어렵습니다.
따라해보세요
1
숫자가 짝수면 "짝수", 홀수면 "홀수"를 한 줄로 출력하세요.
n = int(input("숫자: ")) print("짝수" if n % 2 == 0 else "홀수")
7 → 홀수
2
두 수 중 작은 값을 삼항 연산자로 구하세요.
a = int(input("a: ")) b = int(input("b: ")) minimum = a if a < b else b print(f"최솟값: {minimum}")
10, 3 → 최솟값: 3
