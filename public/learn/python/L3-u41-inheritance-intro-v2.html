상속 맛보기:
코드를 물려받기

부모 클래스가 만들어 놓은 코드를 자식 클래스가 그대로 물려받아 쓸 수 있습니다. 동물→개/고양이, 탈것→자동차/자전거 비유로 상속의 핵심을 감잡습니다.

이 유닛에서 배울 것

  • 상속이 무엇인지, 왜 쓰는지 설명할 수 있습니다.
  • class Dog(Animal): 문법으로 부모 클래스를 지정할 수 있습니다.
  • super().__init__()으로 부모의 초기화 코드를 불러올 수 있습니다.
  • 자식 클래스에서 새 메서드를 추가하거나 기존 메서드를 바꿀 수 있습니다.
  • 동물, 탈것 비유로 상속 구조를 이해할 수 있습니다.

상속이란? — 코드 물려받기

클래스를 만들다 보면 비슷한 코드를 여러 번 쓰게 됩니다. 예를 들어 Dog 클래스와 Cat 클래스 모두 이름, 소리, 먹는 동작이 있습니다. 이런 공통 코드를 부모 클래스에 한 번만 작성하고, 자식 클래스가 물려받으면 됩니다. 이것이 상속입니다.

기본 문법 — class 자식(부모):

자식 클래스를 만들 때 괄호 안에 부모 클래스 이름을 씁니다. 자식은 부모의 모든 속성과 메서드를 그대로 씁니다.

# 부모 클래스 class Animal: def __init__(self, name): self.name = name def eat(self): print(f"{self.name}이/가 밥을 먹습니다.") # 자식 클래스 — Animal을 상속 class Dog(Animal): # 괄호에 부모 클래스 이름 def bark(self): print(f"{self.name}: 멍멍!") # Dog 인스턴스 생성 d = Dog("바둑이") d.eat() # Animal에서 물려받은 메서드 d.bark() # Dog 자신의 메서드
바둑이이/가 밥을 먹습니다. 바둑이: 멍멍!

Dog에는 eat()를 따로 쓰지 않았지만 부모 Animal에서 물려받아 그대로 씁니다. Dog(Animal)에서 괄호가 "이 클래스의 부모는 Animal"이라는 뜻입니다.

따라해보세요 — 상속 기본
1
Animal과 Dog 클래스를 입력하고, Dog("초코") 인스턴스를 만들어 eat()와 bark()를 실행하세요.
초코이/가 밥을 먹습니다. / 초코: 멍멍!
2
Cat(Animal) 클래스를 추가해 meow() 메서드를 넣고, Cat("나비")로 eat()와 meow()를 불러보세요.
나비이/가 밥을 먹습니다. / 나비: 야옹!

Animal의 eat() 출력 문구를 "~이/가 맛있게 먹습니다."로 바꾸면 Dog와 Cat 모두 바뀌는 것을 확인하세요.
한 곳만 수정해도 자식 클래스 모두 반영됩니다.

super().__init__() — 부모 초기화 호출

자식 클래스에 __init__을 직접 쓸 때가 있습니다. 예를 들어 Dog는 Animal의 name뿐 아니라 품종(breed)도 저장하고 싶습니다. 이때 super().__init__()으로 부모의 초기화 코드를 먼저 실행하고 추가 속성을 붙입니다.

class Animal: def __init__(self, name): self.name = name print(f"Animal 초기화: {self.name}") def eat(self): print(f"{self.name}이/가 밥을 먹습니다.") class Dog(Animal): def __init__(self, name, breed): super().__init__(name) # 부모 초기화 먼저! self.breed = breed # 자식 추가 속성 def bark(self): print(f"{self.name}({self.breed}): 멍멍!") d = Dog("바둑이", "진돗개") d.eat() d.bark()
Animal 초기화: 바둑이 바둑이이/가 밥을 먹습니다. 바둑이(진돗개): 멍멍!
핵심 포인트

super().__init__()을 빠뜨리면 self.name이 설정되지 않아 eat()에서 오류가 납니다. 자식 __init__을 쓸 때는 첫 줄에 super().__init__()을 쓰는 습관을 들이세요.

따라해보세요 — super().__init__()

비유로 이해하기 — 탈것, 동물

상속은 현실 세계의 분류 체계와 똑같습니다. "탈것"에는 자동차도 있고 자전거도 있습니다. 둘 다 바퀴가 있고 이동하는 공통 기능이 있습니다. 이 공통 부분을 Vehicle 부모 클래스에 넣고 Car와 Bicycle이 상속받으면 코드가 깔끔해집니다.

class Vehicle: def __init__(self, name, speed): self.name = name self.speed = speed def move(self): print(f"{self.name} 이동 중 (시속 {self.speed}km)") class Car(Vehicle): def __init__(self, name, speed, fuel): super().__init__(name, speed) self.fuel = fuel def honk(self): print(f"{self.name}: 빵빵! (연료: {self.fuel}L)") class Bicycle(Vehicle): def __init__(self, name, speed, gear): super().__init__(name, speed) self.gear = gear def ring(self): print(f"{self.name}: 따르릉! ({self.gear}단 기어)") car = Car("소나타", 120, 50) bike = Bicycle("삼천리", 25, 7) car.move() car.honk() bike.move() bike.ring()
소나타 이동 중 (시속 120km) 소나타: 빵빵! (연료: 50L) 삼천리 이동 중 (시속 25km) 삼천리: 따르릉! (7단 기어)

Car와 Bicycle 모두 move()를 따로 쓰지 않았습니다. Vehicle에서 물려받아 그대로 씁니다. 각자 고유한 honk()와 ring()만 추가했습니다.

메서드 오버라이딩 맛보기 — 덮어쓰기

부모에서 물려받은 메서드를 자식 클래스에서 같은 이름으로 다시 정의하면, 자식은 자신의 버전을 씁니다. 이것을 오버라이딩(overriding)이라 합니다. 예를 들어 Animal의 speak()를 Dog와 Cat이 각자 덮어쓸 수 있습니다.

class Animal: def __init__(self, name): self.name = name def speak(self): print(f"{self.name}: ...") # 기본 버전 class Dog(Animal): def speak(self): # 오버라이딩! print(f"{self.name}: 멍멍!") class Cat(Animal): def speak(self): # 오버라이딩! print(f"{self.name}: 야옹!") animals = [Animal("동물"), Dog("바둑이"), Cat("나비")] for a in animals: a.speak() # 각자 자신의 버전 실행
동물: ... 바둑이: 멍멍! 나비: 야옹!

같은 speak() 호출이지만 Dog는 "멍멍!", Cat은 "야옹!"을 출력합니다. 각 클래스가 자신의 버전을 쓰기 때문입니다. 이런 특성을 다형성이라 부르는데, 지금은 "오버라이딩으로 각자 다르게 동작할 수 있다"는 것만 기억하면 됩니다.

상속 핵심 개념 정리

개념 설명 예시
부모 클래스 공통 속성/메서드를 가진 기본 클래스 class Animal:
자식 클래스 부모를 상속받아 확장한 클래스 class Dog(Animal):
상속 부모 코드를 자동으로 물려받음 d.eat() — Dog에 없어도 됨
super() 부모 클래스를 가리키는 키워드 super().__init__(name)
오버라이딩 부모 메서드를 자식이 덮어씀 def speak(self): 재정의

자식 클래스는 부모 속성 외에 자신만의 속성을 얼마든지 추가할 수 있습니다. 예를 들어 새(Bird)라면 wing_span(날개폭) 속성을 추가하고, ElectricCar(전기차)라면 battery(배터리 잔량) 속성을 붙이는 식입니다. super().__init__()으로 부모 속성을 먼저 초기화한 뒤 자식 속성을 추가합니다.

정답 보기

Vehicle 상속 — ElectricCar 클래스 추가
보통
Vehicle(name, speed)를 상속받는 ElectricCar를 만드세요.
ElectricCar는 battery(배터리 잔량 %) 속성을 추가하고,
charge() 메서드로 "이름 충전 중... 잔량: battery%"를 출력합니다.
move()는 부모 버전을 그대로 쓰세요.
입력 ElectricCar("테슬라", 200, 80)
출력 테슬라 이동 중 (시속 200km)

내 답안
힌트 보기
super().__init__(name, speed)로 부모 초기화. battery는 자식에서만 쓰므로 super() 이후에 self.battery = battery로 설정하세요.
정답 보기
class Vehicle: def __init__(self, name, speed): self.name = name self.speed = speed def move(self): print(f"{self.name} 이동 중 (시속 {self.speed}km)") class ElectricCar(Vehicle): def __init__(self, name, speed, battery): super().__init__(name, speed) self.battery = battery def charge(self): print(f"{self.name} 충전 중... 잔량: {self.battery}%") ec = ElectricCar("테슬라", 200, 80) ec.move() ec.charge()

핵심 요약

  • 상속: 자식 클래스가 부모 클래스의 속성과 메서드를 물려받는 것
  • 문법: class Dog(Animal): — 괄호 안에 부모 클래스 이름
  • super().__init__(): 자식에서 __init__을 쓸 때 부모 초기화를 먼저 호출
  • 오버라이딩: 부모 메서드를 자식에서 같은 이름으로 다시 정의하면 자식 버전이 실행됨
  • 장점: 코드 중복 제거, 수정이 한 곳에서 반영, 구조가 명확해짐
  • 비유: Animal-Dog/Cat, Vehicle-Car/Bicycle 처럼 "공통 부모 + 고유 자식"
