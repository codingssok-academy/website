함수
코드를 이름으로 묶기

반복되는 코드를 함수로 묶어서 재사용하는 방법을 배웁니다.

이 유닛에서 배우는 것

  • def로 함수를 정의하고 호출할 수 있습니다.
  • 매개변수와 인자의 차이를 이해합니다.
  • return으로 결과값을 돌려줄 수 있습니다.
  • 기본값 매개변수를 사용할 수 있습니다.
  • 자판기 함수를 만들 수 있습니다.

함수 만들기 — def

함수는 def 키워드로 만듭니다. 이름을 붙여서 원할 때 몇 번이든 호출할 수 있습니다.

# 함수 정의 def greet(name): print(f"{name}님 안녕하세요!") # 함수 호출 greet("민수") # 민수님 안녕하세요! greet("서연") # 서연님 안녕하세요! greet("지호") # 지호님 안녕하세요!
따라해보세요

인사 함수를 만들고 3번 호출하세요.
def hello(name): print(f"안녕, {name}!") hello("민수") hello("서연") hello("지호")

def introduce(name, age): print(f"저는 {name}이고 {age}살입니다.") introduce("민수", 15)
저는 민수이고 15살입니다.

return — 결과 돌려주기

return은 함수가 계산한 결과를 돌려줍니다. 돌려받은 값은 변수에 저장하거나 바로 사용할 수 있습니다.

# return으로 값 돌려주기 def add(a, b): return a + b result = add(3, 5) print(result) # 8 # 바로 사용하기 print(add(10, 20)) # 30 # return 없는 함수는 None을 반환 def say_hi(): print("안녕!") x = say_hi() print(x) # None
따라해보세요
1
두 수의 곱을 돌려주는 함수를 만드세요.
def multiply(a, b): return a * b print(multiply(4, 7))
28
2
이름을 받아서 인사말을 만들어 돌려주는 함수를 만드세요.
def make_greeting(name): return f"안녕하세요, {name}님!" msg = make_greeting("자현") print(msg)
안녕하세요, 자현님!
3
짝수인지 판별하는 함수를 만드세요.
def is_even(n): return n % 2 == 0 print(is_even(4)) # True print(is_even(7)) # False
True / False

기본값 매개변수

매개변수에 기본값을 정하면, 호출할 때 생략할 수 있습니다.

def greet(name, msg="안녕"): print(f"{name}, {msg}!") greet("민수") # 민수, 안녕! greet("서연", "반가워") # 서연, 반가워!
# 자판기 함수 def vend(drink, money): menu = {"콜라": 1000, "사이다": 800, "주스": 1200, "커피": 1500} if drink not in menu: return "없는 음료입니다." price = menu[drink] if money < price: return f"{price - money}원이 부족합니다." change = money - price return f"{drink} 나왔습니다! 거스름돈: {change}원" print(vend("콜라", 1500)) print(vend("커피", 1000))
따라해보세요
1
기본값이 있는 인사 함수를 만드세요.
def hi(name, times=1): for _ in range(times): print(f"안녕, {name}!") hi("민수") hi("서연", 3)
민수 1번, 서연 3번 인사
2
자판기에 여러 음료를 주문해보세요.
print(vend("사이다", 1000)) print(vend("주스", 500)) print(vend("물", 500))
사이다(거스름돈 200원) / 주스(700원 부족) / 없는 음료
3
리스트의 평균을 구하는 함수를 만드세요.
def average(numbers): return sum(numbers) / len(numbers) print(average([80, 90, 100]))
90.0

# 여러 값 반환 def get_stats(numbers): return min(numbers), max(numbers), sum(numbers) lo, hi, total = get_stats([3, 7, 1, 9, 5]) print(f"최소: {lo}, 최대: {hi}, 합계: {total}")

자판기 업그레이드
보통

정답 확인
def vend(drink, money): menu = {"콜라": 1000, "사이다": 800, "주스": 1200, "커피": 1500, "물": 500} if drink not in menu: return "없는 음료입니다." price = menu[drink] if money < price: return f"{price - money}원이 부족합니다." change = money - price return f"{drink} 나왔습니다! 거스름돈: {change}원" print(vend("물", 1000))

핵심 요약

이 유닛에서 배운 것

  • def 함수이름(매개변수):로 함수를 정의한다
  • return으로 결과값을 돌려주고 변수에 저장할 수 있다
  • 기본값 매개변수로 호출 시 인자를 생략할 수 있다
  • 함수는 반복되는 코드를 줄이고 재사용성을 높인다
  • 딕셔너리 + 함수를 조합하면 자판기 같은 프로그램을 만든다
