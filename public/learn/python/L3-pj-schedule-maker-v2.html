이 프로젝트에서 만드는 것

  • datetime 모듈로 시험 날짜까지 남은 일수(D-day)를 계산합니다.

  • 학습 완료 시간을 업데이트하며 진행률(%)을 막대로 시각화합니다.
  • 스케줄 데이터를 JSON으로 저장하고 불러와 연속으로 사용합니다.

Step 1 — datetime으로 D-day 계산

datetime 모듈의 date 클래스로 날짜를 다룹니다. 두 날짜를 빼면 timedelta 객체가 나오고, .days 속성으로 남은 일수를 얻습니다.

# Step 1: D-day 계산 + 데이터 구조 from datetime import date, datetime import json # 과목 데이터 구조 schedule = { "수학": {"priority": 5, "hours_needed": 20, "done": 4}, "영어": {"priority": 4, "hours_needed": 15, "done": 8}, "과학": {"priority": 3, "hours_needed": 10, "done": 2}, "국어": {"priority": 4, "hours_needed": 12, "done": 3}, } EXAM_DATE = date(2026, 6, 10) # 시험일 설정 def get_dday(): today = date.today() delta = EXAM_DATE - today if delta.days > 0: return f"D-{delta.days}" elif delta.days == 0: return "D-Day!" else: return f"D+{abs(delta.days)} (시험 종료)" print(get_dday()) # 예: D-81

Step 2 — 우선순위 기반 시간 배분 + 진행률 시각화

과목별 priority를 비율로 환산해 하루 공부 가능 시간을 배분합니다. 각 과목의 진행률은 텍스트 막대(progress bar)로 시각화합니다.

# Step 2: 시간 배분 + 진행률 def allocate_time(daily_hours): total_priority = sum(v["priority"] for v in schedule.values()) result = {} for subject, data in schedule.items(): ratio = data["priority"] / total_priority alloc = round(daily_hours * ratio, 1) result[subject] = alloc return result def progress_bar(done, total, width=20): if total == 0: return "[없음]" pct = done / total fill = int(pct * width) bar = "#" * fill + "-" * (width - fill) return f"[{bar}] {pct*100:.0f}%" def show_schedule(daily_hours=6): alloc = allocate_time(daily_hours) dday = get_dday() print(f"시험까지: {dday} | 오늘 공부 시간: {daily_hours}시간") print("-" * 50) sorted_subjects = sorted(schedule, key=lambda k: schedule[k]["priority"], reverse=True) for sub in sorted_subjects: data = schedule[sub] bar = progress_bar(data["done"], data["hours_needed"]) print(f"{sub:4s}(P{data['priority']}) {alloc[sub]}h/일 {bar}") print(f" {data['done']}/{data['hours_needed']}h 완료")

Step 3 — JSON으로 스케줄 저장/불러오기

스케줄 데이터를 JSON 파일로 저장해두면 프로그램을 다시 실행해도 이어서 공부 기록을 관리할 수 있습니다.

# Step 3: JSON 저장/불러오기 SAVE_FILE = "schedule.json" def save_schedule(): data = { "exam_date": EXAM_DATE.isoformat(), # "2026-06-10" "subjects": schedule, } with open(SAVE_FILE, "w", encoding="utf-8") as f: json.dump(data, f, ensure_ascii=False, indent=2) print("저장 완료!") def load_schedule(): global schedule, EXAM_DATE try: with open(SAVE_FILE, "r", encoding="utf-8") as f: data = json.load(f) EXAM_DATE = date.fromisoformat(data["exam_date"]) schedule = data["subjects"] print("불러오기 완료!") except FileNotFoundError: print("저장 파일 없음 — 기본값 사용")

Q2
남은 공부 시간 계산
보통

시험까지 남은 일수와 과목별 남은 시간(hours_needed - done)을 고려해 하루 필요 공부량(시간)을 계산하는 daily_required() 함수를 만드세요.

내 답안
힌트 보기

남은 시간 합계 = sum(v["hours_needed"] - v["done"] for v in schedule.values()). D-day = (EXAM_DATE - date.today()).days. 하루 필요 = 남은 시간 / D-day

정답 보기
def daily_required(): remaining = sum(v["hours_needed"] - v["done"] for v in schedule.values()) ddays = (EXAM_DATE - date.today()).days if ddays <= 0: return "시험이 이미 지났습니다." per_day = round(remaining / ddays, 1) return f"남은 공부: {remaining}h / {ddays}일 = 하루 {per_day}h"

# 완성 — 스케줄러 앱 def run_scheduler(): load_schedule() while True: print(f"\n{get_dday()} 1.스케줄 2.진행 업데이트 3.필요 시간 4.저장 0.종료") c = input("선택: ") if c == "1": h = float(input("오늘 공부 시간(h): ")) show_schedule(h) elif c == "2": sub = input("과목명: ") hrs = float(input("공부한 시간(h): ")) update_progress(sub, hrs) elif c == "3": print(daily_required()) elif c == "4": save_schedule() elif c == "0": save_schedule() break run_scheduler()
Q3
완료 예상일 계산
어려움

오늘부터 하루 6시간씩 공부한다고 가정할 때, 각 과목의 완료 예상일을 계산하는 estimate_completion() 함수를 만드세요. 우선순위 높은 과목을 먼저 완료합니다.

내 답안
힌트 보기

sorted()로 우선순위 내림차순 정렬 후, 각 과목의 남은 시간을 누적하고 date.today() + timedelta(days=ceil(누적시간/6))로 예상일을 계산하세요.

정답 보기
from math import ceil from datetime import timedelta def estimate_completion(daily_hours=6): today = date.today() cum_hours = 0 order = sorted(schedule, key=lambda k: schedule[k]["priority"], reverse=True) for sub in order: data = schedule[sub] remaining = data["hours_needed"] - data["done"] cum_hours += remaining days_needed = ceil(cum_hours / daily_hours) completion = today + timedelta(days=days_needed) print(f"{sub}: {completion.isoformat()} 완료 예상")

이 프로젝트에서는 하루에 얼마나 공부해야 하는지 자동 계산하는 스케줄러를 만듭니다.

핵심 요약

  • from datetime import date — date.today()와 date(y,m,d)로 날짜 객체를 만들고 뺄셈으로 timedelta를 얻습니다.
  • 우선순위 비율 배분: priority / sum(priorities) * daily_hours 공식 사용.
  • sorted(dict, key=lambda k: dict[k]["field"], reverse=True) — 딕셔너리 키 정렬.
  • 진행률 막대: "#" * fill + "-" * (width-fill)로 텍스트 시각화.
  • date.isoformat()으로 날짜를 문자열로, date.fromisoformat()으로 역변환합니다.
