프로젝트:
미니 검색 엔진

정렬, 이진 탐색, 재귀를 종합하여 단어 목록에서 빠르게 검색하고 결과를 정렬하며 검색 횟수를 카운트하는 미니 검색 엔진을 완성합니다.

이 유닛에서 만드는 것

  • 단어 목록을 sorted()로 정렬하여 이진 탐색의 전제 조건을 충족할 수 있습니다.
  • 이진 탐색 알고리즘으로 선형 탐색보다 빠르게 단어를 찾을 수 있습니다.
  • 재귀 함수로 이진 탐색을 구현하고 동작 원리를 이해할 수 있습니다.
  • 검색 횟수를 딕셔너리로 카운트하고 가장 많이 검색된 단어를 출력할 수 있습니다.
  • 검색 결과를 sorted()로 정렬하여 보기 좋게 출력할 수 있습니다.
  • while True 메뉴 루프로 반복 검색 기능을 완성할 수 있습니다.

L3f 종합 복습 — 정렬 · 탐색 · 재귀

이 프로젝트는 L3f에서 배운 세 가지 개념을 하나로 묶습니다. 각 개념이 어떻게 협력하는지 먼저 확인하세요.

개념 핵심 함수 시간 복잡도 검색 엔진에서 역할
정렬 sorted(), .sort() O(n log n) 이진 탐색 전 정렬, 결과 정렬 출력
선형 탐색 for 루프, in 연산자 O(n) 부분 일치 검색 (접두사 검색)
이진 탐색 binary_search() O(log n) 정렬된 목록에서 정확히 일치하는 단어 검색
재귀 recursive_search() O(log n) 이진 탐색을 재귀로 구현

Step 2 — 이진 탐색 구현

이진 탐색은 정렬된 리스트의 중간 인덱스와 비교해 탐색 범위를 반씩 줄여나갑니다. 20개 단어를 최대 5번의 비교로 찾을 수 있습니다.

def binary_search(sorted_list, target): """정렬된 리스트에서 target을 이진 탐색. 인덱스 반환, 없으면 -1.""" left, right = 0, len(sorted_list) - 1 while left <= right: mid = (left + right) // 2 if sorted_list[mid] == target: return mid # 찾음 elif sorted_list[mid] < target: left = mid + 1 # 오른쪽 절반 else: right = mid - 1 # 왼쪽 절반 return -1 # 없음 # 테스트 idx = binary_search(words_sorted, "search") print(f"'search' 인덱스: {idx}") # 15 idx2 = binary_search(words_sorted, "zebra") print(f"'zebra' 인덱스: {idx2}") # -1
'search' 인덱스: 15 'zebra' 인덱스: -1

Step 3 — 재귀로 이진 탐색 구현

이진 탐색을 재귀 함수로 구현합니다. 반복문 버전과 같은 결과를 내지만, 함수가 자기 자신을 호출해 범위를 좁혀갑니다.

def recursive_search(sorted_list, target, left, right): """재귀로 이진 탐색. left > right면 없는 것 → base case.""" # Base case: 탐색 범위가 없으면 -1 반환 if left > right: return -1 mid = (left + right) // 2 if sorted_list[mid] == target: return mid # 찾음 elif sorted_list[mid] < target: # 재귀: 오른쪽 절반 return recursive_search(sorted_list, target, mid + 1, right) else: # 재귀: 왼쪽 절반 return recursive_search(sorted_list, target, left, mid - 1) # 호출 시 초기 범위 전달 idx = recursive_search(words_sorted, "sort", 0, len(words_sorted) - 1) print(f"'sort' → 인덱스 {idx}") # 16
'sort' → 인덱스 16
재귀 vs 반복 이진 탐색

결과는 동일합니다. 반복문 버전은 메모리를 덜 쓰고 (스택 없음), 재귀 버전은 코드 구조가 더 명확합니다. 실무에서는 반복문 버전이 권장됩니다.

Step 4 — 검색 카운터와 접두사 검색

검색할 때마다 딕셔너리에 횟수를 기록합니다. 접두사(prefix)로 시작하는 단어를 찾는 기능도 추가합니다.

# 검색 카운터 딕셔너리 search_count = {} def search_word(sorted_list, query): """단어 검색 + 카운트 기록""" # 카운트 누적 search_count[query] = search_count.get(query, 0) + 1 idx = binary_search(sorted_list, query) if idx != -1: print(f"[발견] '{query}' — 인덱스 {idx}") else: print(f"[없음] '{query}' 는 목록에 없습니다.") def prefix_search(sorted_list, prefix): """prefix로 시작하는 단어를 모두 찾아 정렬 반환""" results = [w for w in sorted_list if w.startswith(prefix)] return sorted(results) # 테스트 search_word(words_sorted, "sort") search_word(words_sorted, "sort") search_word(words_sorted, "python") search_word(words_sorted, "cloud") hits = prefix_search(words_sorted, "s") print(f"'s'로 시작하는 단어: {hits}")
[발견] 'sort' — 인덱스 16 [발견] 'sort' — 인덱스 16 [발견] 'python' — 인덱스 13 [없음] 'cloud' 는 목록에 없습니다. 's'로 시작하는 단어: ['search', 'sort', 'string']

Step 5 — 메뉴 통합과 최종 완성

앞서 만든 함수들을 while True 메뉴로 연결해 사용자가 반복 검색할 수 있는 미니 검색 엔진을 완성합니다.

def show_stats(): """검색 통계 출력 — 검색 횟수 내림차순 정렬""" if not search_count: print("아직 검색 기록이 없습니다.") return print("\n--- 검색 통계 ---") for word, cnt in sorted(search_count.items(), key=lambda x: -x[1]): print(f" {word}: {cnt}회") def main(): print("=== 미니 검색 엔진 ===") while True: print("\n1. 단어 검색 2. 접두사 검색 3. 검색 통계 q. 종료") choice = input("선택: ").strip() if choice == "1": query = input("검색어: ").strip().lower() search_word(words_sorted, query) elif choice == "2": prefix = input("접두사: ").strip().lower() results = prefix_search(words_sorted, prefix) print(f"'{prefix}'로 시작: {results}") elif choice == "3": show_stats() elif choice == "q": print("검색 엔진을 종료합니다.") break else: print("잘못된 입력입니다.") main()

Q2
이진 탐색 코드 추적
보통
아래 binary_search 함수에서 sorted_list = ["a","b","c","d","e"], target = "d"일 때, 함수가 반환하는 값은?
코드 left=0, right=4
반복1: mid=2 → "c" < "d" → left=3
반복2: mid=3 → "d" == "d" → return 3
힌트 보기
mid = (left + right) // 2 입니다. left=0, right=4이면 mid=2, "c"입니다. "c" < "d"이므로 left = mid+1 = 3이 됩니다.
정답 보기
정답: 3 인덱스 3에 "d"가 있으므로 3을 반환합니다.
Q3
재귀 이진 탐색 빈칸 완성
어려움
아래 재귀 이진 탐색 코드의 빈칸 (A), (B)를 채우세요.
코드 def recursive_search(lst, target, left, right):
  if (A): return -1
  mid = (left + right) // 2
  if lst[mid] == target: return mid
  elif lst[mid] < target:
    return recursive_search(lst, target, (B), right)
  else:
    return recursive_search(lst, target, left, mid-1)
힌트 보기
(A)는 탐색 범위가 더 이상 없을 때의 조건(base case)입니다. (B)는 target이 mid보다 크다면 어느 쪽을 탐색해야 하나요?
정답 보기
(A): left > right → 탐색 범위가 0이 되면 없는 것 → -1 반환 (B): mid + 1 → target이 mid보다 크면 왼쪽 경계를 mid+1로 이동

핵심 요약

  • sorted(list) — 원본을 바꾸지 않고 정렬된 새 리스트 반환, 이진 탐색 전 필수
  • binary_search(lst, target) — 정렬된 리스트를 반으로 나눠 O(log n)으로 탐색
  • mid = (left + right) // 2 — 현재 탐색 범위의 중간 인덱스 계산
  • 이진 탐색 재귀 base case: if left > right: return -1 — 탐색 범위 소진
  • word.startswith(prefix) — 단어가 특정 접두사로 시작하는지 확인 (선형 탐색)
  • search_count.get(word, 0) + 1 — 키가 없으면 0, 있으면 기존 값 + 1
  • sorted(dict.items(), key=lambda x: -x[1]) — 값 내림차순으로 딕셔너리 정렬
  • 선형 탐색 O(n) vs 이진 탐색 O(log n): 1000개 데이터 → 최대 1000번 vs 최대 10번 비교
