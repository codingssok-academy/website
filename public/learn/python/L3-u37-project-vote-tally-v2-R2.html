프로젝트:
도서관 시스템

중첩 딕셔너리로 책 정보를 관리합니다. 대출/반납 처리, 제목/저자 검색, 연체 확인까지 실제 도서관을 모사한 프로그램을 완성합니다.

이 유닛에서 만드는 것

  • 중첩 딕셔너리로 책의 제목, 저자, 대출 상태, 반납 기한을 한 구조로 관리합니다.
  • book["available"]을 True/False로 바꿔 대출/반납 상태를 처리합니다.
  • items() 순회와 in 연산자로 제목·저자 기준 검색을 구현합니다.
  • 오늘 날짜와 반납 기한을 비교해 연체 여부와 연체일수를 계산합니다.
  • 대출 가능 책 목록과 현재 대출 중인 책 목록을 필터링해서 출력합니다.

Step 1 — 중첩 딕셔너리로 도서 데이터 구조 설계

도서관 시스템의 핵심은 각 책을 하나의 딕셔너리로 표현하는 것입니다. 책 ID를 외부 키, 책 정보를 내부 딕셔너리로 구성하는 중첩 딕셔너리 구조를 사용합니다.

# library.py — Step 1: 데이터 구조 from datetime import date, timedelta # 중첩 딕셔너리: 책 ID → 책 정보 library = { "B001": { "title": "파이썬 입문", "author": "홍길동", "available": True, "due_date": None }, "B002": { "title": "자료구조 완전 정복", "author": "김철수", "available": False, "due_date": "2026-03-10" # 대출 중 } } def show_all_books(): """전체 도서 목록 출력""" print(f"\n{'ID':<6} {'제목':<20} {'저자':<12} {'상태'}") print("-" * 50) for book_id, info in library.items(): status = "대출가능" if info["available"] else "대출중" print(f"{book_id:<6} {info['title']:<20} {info['author']:<12} {status}")

Step 2 — 대출과 반납 기능

대출 처리는 book["available"]을 False로, book["due_date"]에 반납 기한을 설정합니다. 반납은 반대로 True로 되돌립니다.

def borrow_book(book_id, days=14): """도서 대출""" if book_id not in library: print("존재하지 않는 도서입니다.") return book = library[book_id] if not book["available"]: print(f"'{book['title']}'은(는) 현재 대출 중입니다.") return book["available"] = False due = date.today() + timedelta(days=days) book["due_date"] = due.isoformat() print(f"대출 완료: {book['title']} (반납기한: {book['due_date']})") def return_book(book_id): """도서 반납""" if book_id in library and not library[book_id]["available"]: library[book_id]["available"] = True library[book_id]["due_date"] = None print(f"반납 완료: {library[book_id]['title']}")

Step 3 — 검색 기능: 제목 / 저자로 찾기

중첩 딕셔너리에서 제목이나 저자로 책을 검색하려면 items()로 전체 순회 후, 내부 딕셔너리의 값에 in 연산자로 부분 일치 검색합니다.

def search_by_title(keyword): """제목으로 검색 — 부분 일치""" results = [] for book_id, info in library.items(): if keyword in info["title"]: results.append((book_id, info)) if results: for bid, info in results: status = "대출가능" if info["available"] else "대출중" print(f"[{bid}] {info['title']} / {info['author']} — {status}") else: print(f"'{keyword}' 검색 결과 없음") def search_by_author(author): """저자로 검색""" results = [(bid, info) for bid, info in library.items() if author in info["author"]] for bid, info in results: print(f"[{bid}] {info['title']}")

Step 4 — 연체 확인 기능

오늘 날짜와 due_date를 비교해 연체 여부를 확인합니다. date.fromisoformat()으로 문자열을 날짜 객체로 변환 후 차이를 계산합니다.

def check_overdue(): """연체 도서 확인""" today = date.today() overdue_found = False print("\n--- 연체 도서 ---") for book_id, info in library.items(): if not info["available"] and info["due_date"]: due = date.fromisoformat(info["due_date"]) days_over = (today - due).days if days_over > 0: print(f"[{book_id}] {info['title']} — {days_over}일 연체") overdue_found = True if not overdue_found: print("연체 도서 없음")

핵심 요약

도서관 시스템 핵심 기법

  • 중첩 딕셔너리: 외부 키(책 ID) → 내부 딕셔너리(책 정보) 구조
  • 상태 관리: book["available"] = True/False로 대출 상태 전환
  • 중첩 접근: library[book_id]["title"] — 두 단계로 접근
  • 부분 일치 검색: keyword in info["title"] — 문자열 포함 여부
  • 날짜 연산: date.fromisoformat()로 문자열 → date 변환 후 빼기
  • 리스트 컴프리헨션 필터: [x for x in items if 조건]
  • values() 집계: sum(1 for info in library.values() if 조건)
