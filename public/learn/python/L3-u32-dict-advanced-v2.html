Chapter 32 — L3

딕셔너리 활용
get, items, 반복

dict.get()으로 안전하게 값을 꺼내고, .items()로 키-값 쌍을 순회하며, update/pop/del로 딕셔너리를 수정합니다.

이 유닛에서 배우는 것

  • dict.get(key, default)로 KeyError 없이 안전하게 값을 가져올 수 있습니다.
  • .keys(), .values(), .items()로 딕셔너리를 순회할 수 있습니다.
  • for key, value in d.items(): 패턴으로 키-값 쌍을 반복 처리합니다.
  • in 연산자로 키 존재 여부를 확인할 수 있습니다.
  • update(), pop(), del로 딕셔너리를 수정하고 삭제합니다.

dict.get() — 안전한 값 접근

딕셔너리에서 없는 키를 d[key]로 접근하면 KeyError가 발생합니다. get()을 사용하면 키가 없을 때 오류 대신 기본값을 반환합니다.

# [] 접근 — 키가 없으면 KeyError student = {"name": "Alice", "grade": 90} print(student["name"]) # Alice (OK) # print(student["age"]) # KeyError: 'age' # get() — 키가 없으면 None (기본값) age = student.get("age") print(age) # None # get() — 두 번째 인자로 기본값 지정 age = student.get("age", 0) print(age) # 0 score = student.get("grade", 0) print(score) # 90 (키가 있으므로 실제 값 반환)
따라해보세요 — dict.get()
STEP 1
학생 정보 딕셔너리에서 없는 키를 get()으로 안전하게 읽어보세요.
student = {"name": "홍길동", "score": 85} name = student.get("name", "무명") email = student.get("email", "없음") print(name) # 홍길동 print(email) # 없음
홍길동 / 없음
STEP 2
get()을 이용해 점수 합계를 구하세요. 없는 과목은 0으로 처리합니다.
scores = {"math": 80, "english": 70} total = scores.get("math", 0) + scores.get("science", 0) print("합계:", total)
합계: 80
STEP 3
get()과 조건문을 조합해서 등급을 출력하세요.
info = {"name": "Bob", "level": "gold"} level = info.get("level", "bronze") if level == "gold": print("골드 회원입니다") else: print("일반 회원입니다")
골드 회원입니다

dict.get() 핵심 요약

  • d.get(key) — 키가 없으면 None 반환 (오류 없음)
  • d.get(key, default) — 키가 없으면 default 반환
  • 키가 있으면 실제 값을 반환하며, default는 무시됨
  • 사용자 입력이나 외부 데이터를 다룰 때 get()을 습관화하면 안전한 코드 작성 가능

.keys() / .values() / .items() — 딕셔너리 조회

딕셔너리의 세 가지 뷰(view) 메서드를 사용하면 키만, 값만, 또는 키-값 쌍을 모두 꺼낼 수 있습니다.

person = {"name": "Alice", "age": 20, "city": "Seoul"} # 키 목록 print(person.keys()) # dict_keys(['name', 'age', 'city']) # 값 목록 print(person.values()) # dict_values(['Alice', 20, 'Seoul']) # 키-값 쌍 목록 print(person.items()) # dict_items([('name','Alice'),('age',20),...]) # 리스트로 변환 key_list = list(person.keys()) print(key_list[0]) # name
메서드 반환 타입 내용 주요 사용처
d.keys() dict_keys 모든 키 키 목록 확인, for 반복
d.values() dict_values 모든 값 합계/평균 계산
d.items() dict_items 키-값 튜플 키-값 동시 처리
따라해보세요 — keys / values / items
STEP 1
values()로 점수 합계와 평균을 계산하세요.
scores = {"math": 80, "english": 90, "science": 70} total = sum(scores.values()) avg = total / len(scores) print("합계:", total, "/ 평균:", avg)
합계: 240 / 평균: 80.0
STEP 2
keys()로 딕셔너리의 항목 수와 첫 번째 키를 출력하세요.
config = {"host": "localhost", "port": 8080, "debug": True} keys = list(config.keys()) print("항목 수:", len(keys)) print("첫 번째 키:", keys[0])
항목 수: 3 / 첫 번째 키: host
STEP 3
items()로 딕셔너리 내용을 보기 좋게 출력하세요.
fruit_price = {"사과": 1200, "배": 2500, "딸기": 3000} for name, price in fruit_price.items(): print(name, ":", price, "원")
사과 : 1200 원 / 배 : 2500 원 / 딸기 : 3000 원

딕셔너리 반복 — for key, value in d.items()

for key, value in d.items(): 패턴은 딕셔너리를 순회할 때 가장 많이 쓰는 관용구입니다. 튜플 언패킹 덕분에 키와 값을 동시에 변수에 받을 수 있습니다.

person = {"name": "Alice", "age": 20, "city": "Seoul"} # 키-값 동시 순회 (가장 많이 쓰는 패턴) for key, value in person.items(): print(key, "→", value) # 출력: # name → Alice # age → 20 # city → Seoul

in 연산자 — 키 존재 확인

key in d는 딕셔너리에 해당 키가 있으면 True, 없으면 False를 반환합니다. 값이 아닌 키를 기준으로 검사합니다.

person = {"name": "Alice", "age": 20} # in 연산자: 키 존재 여부 확인 print("name" in person) # True print("email" in person) # False # 실전 패턴: 키 확인 후 안전하게 접근 if "age" in person: print("나이:", person["age"]) else: print("나이 정보 없음") # not in: 없을 때 처리 if "phone" not in person: print("전화번호가 등록되지 않았습니다")
따라해보세요 — for items() / in 연산자
STEP 1
for-items()로 성적표를 출력하고, 90점 이상인 과목만 따로 표시하세요.
grades = {"수학": 95, "영어": 78, "과학": 92, "국어": 85} for subject, score in grades.items(): mark = " [우수]" if score >= 90 else "" print(subject, score, mark)
수학 95 [우수] / 영어 78 / 과학 92 [우수] / 국어 85
STEP 2
in 연산자로 사용자 권한을 확인하세요.
permissions = {"read": True, "write": True} needed = ["read", "delete"] for perm in needed: status = "OK" if perm in permissions else "없음" print(perm, ":", status)
read : OK / delete : 없음
STEP 3
for-items()로 딕셔너리를 "key=value" 형식으로 변환하세요.
settings = {"width": 800, "height": 600, "fps": 60} parts = [] for k, v in settings.items(): parts.append(str(k) + "=" + str(v)) print(", ".join(parts))
width=800, height=600, fps=60

딕셔너리 수정 — update, pop, del

딕셔너리는 변경 가능(mutable)합니다. update()로 여러 항목을 한 번에 추가/수정하고, pop()이나 del로 키-값을 삭제합니다.

user = {"name": "Alice", "age": 20} # update(): 여러 키-값 추가/수정 user.update({"age": 21, "city": "Busan"}) print(user) # {'name':'Alice','age':21,'city':'Busan'} # pop(): 키 삭제하고 값 반환 city = user.pop("city") print(city) # Busan print(user) # {'name':'Alice','age':21} # pop() 기본값: 없는 키도 안전하게 phone = user.pop("phone", "없음") print(phone) # 없음 # del: 키 삭제 (값 반환 없음) del user["age"] print(user) # {'name': 'Alice'}
따라해보세요 — update / pop / del
STEP 1
update()로 학생 정보를 수정하고 새 항목을 추가하세요.
student = {"name": "Kim", "grade": 2} student.update({"grade": 3, "club": "코딩"}) print(student)
{'name': 'Kim', 'grade': 3, 'club': '코딩'}
STEP 2
pop()으로 장바구니에서 항목을 꺼내고 가격을 출력하세요.
cart = {"apple": 1200, "banana": 800, "milk": 2500} price = cart.pop("banana") print("banana 가격:", price) print("남은 장바구니:", cart)
banana 가격: 800 / 남은 장바구니: {'apple':1200,'milk':2500}
STEP 3
in 확인 후 del로 안전하게 키를 삭제하세요.
data = {"x": 10, "y": 20, "temp": 99} if "temp" in data: del data["temp"] print(data)
{'x': 10, 'y': 20}

실용 예제 — 성적 분석 프로그램

지금까지 배운 get(), items(), for 반복, in, update, pop을 모두 활용해서 간단한 성적 분석 프로그램을 만들어 봅니다.

# 성적 딕셔너리 scores = { "수학": 88, "영어": 92, "과학": 75, "국어": 85, "사회": 90 } # 1. 전체 성적 출력 (items 반복) print("=== 성적표 ===") for subject, score in scores.items(): grade = "A" if score >= 90 else ("B" if score >= 80 else "C") print(f"{subject}: {score}점 ({grade})") # 2. 통계 계산 (values 활용) total = sum(scores.values()) avg = total / len(scores) print(f"총점: {total} / 평균: {avg:.1f}") # 3. 특정 과목 안전하게 조회 (get 활용) art = scores.get("미술", "미응시") print("미술:", art)
# 단어 빈도 카운터 — get() 활용 sentence = "hello world hello python hello" word_count = {} for word in sentence.split(): word_count[word] = word_count.get(word, 0) + 1 print(word_count) # {'hello': 3, 'world': 1, 'python': 1}

핵심 요약 — 딕셔너리 활용

  • d.get(key, default) — 키 없을 때 KeyError 대신 기본값 반환
  • key in d — 키 존재 여부 확인 (True/False)
  • d.keys() / d.values() / d.items() — 키/값/쌍 조회
  • for k, v in d.items(): — 딕셔너리 키-값 동시 순회의 표준 패턴
  • d.update({...}) — 여러 키-값 한 번에 추가/수정 (기존 키는 덮어쓰기)
  • d.pop(key) — 키 삭제 + 삭제된 값 반환 / del d[key] — 키만 삭제
  • 단어 카운터: count[w] = count.get(w, 0) + 1 관용구 암기 필수
