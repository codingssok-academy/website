프로젝트:
카드 게임

클래스(Card, Deck, Player)를 설계하고, random.shuffle로 덱을 섞어 전쟁 카드 게임(War)을 구현합니다. __str__ 메서드와 OOP 개념을 실전에서 완성합니다.

이 유닛에서 만드는 것

  • Card 클래스에 숫자(number)와 무늬(suit) 속성을 정의할 수 있습니다.
  • __str__ 메서드로 AS, KH처럼 카드를 문자열로 출력할 수 있습니다.
  • Deck 클래스에서 4가지 무늬 × 13장 = 52장 덱을 자동 생성할 수 있습니다.
  • random.shuffle로 덱을 섞고 deal()로 카드를 한 장씩 뽑을 수 있습니다.
  • Player 클래스로 이름과 손패(hand)를 관리할 수 있습니다.
  • 높은 숫자가 이기는 War 게임 로직을 완성하고 승자를 출력할 수 있습니다.

Step 1 — Card 클래스 설계

카드 한 장을 표현하는 Card 클래스를 만듭니다. 카드는 숫자(number)와 무늬(suit)로 구성되며, __str__ 메서드로 "AS"처럼 출력합니다.

# Step 1: Card 클래스 class Card: # 숫자 → 이름 매핑 (1=A, 11=J, 12=Q, 13=K) RANKS = {1: "A", 11: "J", 12: "Q", 13: "K"} def __init__(self, number, suit): self.number = number # 정수 1~13 self.suit = suit # "S" "H" "D" "C" def __str__(self): rank = self.RANKS.get(self.number, str(self.number)) return f"{rank}{self.suit}" # 테스트 c1 = Card(1, "S") c2 = Card(13, "H") c3 = Card(7, "D") print(c1, c2, c3) print(c1.number, c2.suit)
AS KH 7D 1 H

__str__는 print()나 f-string에서 객체를 출력할 때 자동으로 호출됩니다. RANKS.get(number, str(number))는 딕셔너리에 없는 숫자(2~10)는 그대로 문자열로 변환합니다.

Step 2 — Deck 클래스 (52장 생성, 셔플, 뽑기)

Deck 클래스는 4가지 무늬 × 13장 = 52장 카드를 자동으로 생성합니다. random.shuffle로 섞고, deal()로 맨 뒤 카드를 한 장씩 뽑습니다.

# Step 2: Deck 클래스 import random class Deck: SUITS = ["S", "H", "D", "C"] def __init__(self): # 4무늬 x 13숫자 = 52장 Card 생성 self.cards = [ Card(n, s) for s in self.SUITS for n in range(1, 14) ] def shuffle(self): """덱을 무작위로 섞기""" random.shuffle(self.cards) def deal(self): """맨 뒤에서 카드 한 장 뽑기""" if not self.cards: return None return self.cards.pop() def __len__(self): return len(self.cards) # 테스트 d = Deck() print(f"덱 카드 수: {len(d)}") d.shuffle() card = d.deal() print(f"뽑은 카드: {card}") print(f"남은 카드: {len(d)}")
덱 카드 수: 52 뽑은 카드: 8D (셔플 결과에 따라 다름) 남은 카드: 51

Step 3 — Player 클래스

Player는 이름(name)과 손패(hand) 리스트를 가집니다. receive(card)로 카드를 받고, play()로 손패에서 카드를 한 장 냅니다.

# Step 3: Player 클래스 class Player: def __init__(self, name): self.name = name self.hand = [] # 손패 리스트 def receive(self, card): """손패에 카드 추가""" self.hand.append(card) def play(self): """손패 맨 앞 카드를 내기""" if not self.hand: return None return self.hand.pop(0) def __str__(self): cards_str = " ".join(str(c) for c in self.hand) return f"{self.name}: [{cards_str}]" # 테스트 p = Player("Alice") p.receive(Card(10, "S")) p.receive(Card(3, "H")) print(p) played = p.play() print(f"낸 카드: {played}")
Alice: [10S 3H] 낸 카드: 10S

Step 4 — War 게임 로직

두 플레이어가 각자 카드를 한 장씩 내고, 숫자가 높은 쪽이 이깁니다. Ace(1)는 가장 약한 카드로 취급합니다. 같은 숫자면 무승부입니다.

# Step 4: War 게임 — 한 라운드 def war_round(p1, p2): """한 라운드: 각자 카드 내고 높은 숫자 승""" c1 = p1.play() c2 = p2.play() if c1 is None or c2 is None: return "게임 종료" print(f"{p1.name}: {c1} vs {p2.name}: {c2}") if c1.number > c2.number: return p1.name elif c2.number > c1.number: return p2.name else: return "무승부"

Step 5 — War 게임 완성

두 플레이어에게 각각 5장을 배분하고, 5라운드 동안 카드를 내며 승패를 집계합니다. 가장 많이 이긴 플레이어가 최종 승자입니다.

# Step 5: 완성 War 게임 def play_war_game(rounds=5): # 덱 준비 deck = Deck() deck.shuffle() # 두 플레이어 p1 = Player("철수") p2 = Player("영희") # 각 플레이어에게 5장 배분 for _ in range(rounds): p1.receive(deck.deal()) p2.receive(deck.deal()) print(f"=== WAR 카드 게임 ({rounds}라운드) ===") print(p1) print(p2) print("-" * 36) # 라운드 진행 + 승패 집계 scores = {p1.name: 0, p2.name: 0} for r in range(1, rounds + 1): print(f"라운드 {r}:", end=" ") winner = war_round(p1, p2) if winner in scores: scores[winner] += 1 print(f" → {winner} 승!") else: print(" → 무승부") # 최종 결과 print("=" * 36) print(f"최종: 철수 {scores['철수']}승 | 영희 {scores['영희']}승") if scores[p1.name] > scores[p2.name]: print(f"우승: {p1.name}") elif scores[p2.name] > scores[p1.name]: print(f"우승: {p2.name}") else: print("무승부 — 재경기 필요") play_war_game()
=== WAR 카드 게임 (5라운드) === 철수: [3S KH 7D 2C 10S] 영희: [JC 4H 9D 6S QC] ------------------------------------ 라운드 1: 철수: 3S vs 영희: JC → 영희 승! 라운드 2: 철수: KH vs 영희: 4H → 철수 승! 라운드 3: 철수: 7D vs 영희: 9D → 영희 승! 라운드 4: 철수: 2C vs 영희: 6S → 영희 승! 라운드 5: 철수: 10S vs 영희: QC → 영희 승! ==================================== 최종: 철수 1승 | 영희 4승 우승: 영희

완성 코드 — card_war.py

세 클래스(Card, Deck, Player)와 게임 함수를 하나의 파일로 통합합니다. 클래스 간 의존 관계를 확인하세요.

# card_war.py — 완성 코드 import random class Card: RANKS = {1:"A", 11:"J", 12:"Q", 13:"K"} def __init__(self, number, suit): self.number = number; self.suit = suit def __str__(self): return f"{self.RANKS.get(self.number, str(self.number))}{self.suit}" class Deck: SUITS = ["S", "H", "D", "C"] def __init__(self): self.cards = [Card(n,s) for s in self.SUITS for n in range(1,14)] def shuffle(self): random.shuffle(self.cards) def deal(self): return self.cards.pop() if self.cards else None def __len__(self): return len(self.cards) class Player: def __init__(self, name): self.name = name; self.hand = [] def receive(self, card): self.hand.append(card) def play(self): return self.hand.pop(0) if self.hand else None def __str__(self): return f"{self.name}: [{' '.join(str(c) for c in self.hand)}]"

확장 기능 — Ace를 가장 강한 카드로

기본 War 게임에서 Ace(1)는 숫자 그대로 1로 비교해 가장 약합니다. 실제 카드 게임처럼 Ace를 14로 취급해 가장 강한 카드로 만들어봅니다.

# 확장: Ace를 14로 취급하는 war_round def card_value(card): """Ace(1)를 14로 변환해 실제 강도 반환""" return 14 if card.number == 1 else card.number def war_round_ace_high(p1, p2): """Ace를 가장 강한 카드로 취급""" c1, c2 = p1.play(), p2.play() if c1 is None or c2 is None: return "게임 종료" v1, v2 = card_value(c1), card_value(c2) print(f"{p1.name}: {c1}({v1}) vs {p2.name}: {c2}({v2})") if v1 > v2: return p1.name elif v2 > v1: return p2.name else: return "무승부" # 테스트 — Ace vs King p1 = Player("철수") p2 = Player("영희") p1.receive(Card(1, "S")) # Ace p2.receive(Card(13, "H")) # King print(war_round_ace_high(p1, p2))
