이 프로젝트에서 배우는 것

  • import random으로 random 모듈을 불러옵니다.
  • random.sample(range(1,46), 6)으로 중복 없이 6개를 뽑습니다.
  • list.sort()로 리스트를 오름차순 정렬합니다.
  • random.randint(1, 45)로 보너스 번호를 뽑습니다.
  • while 루프로 여러 회차의 번호를 반복 생성합니다.

Step 1 — random 모듈 기초

파이썬의 random 모듈에는 무작위 숫자를 생성하는 다양한 함수가 있습니다. 로또에는 중복 없이 뽑는 sample()이 적합합니다.

import random # 1~45 사이에서 중복 없이 6개 추출 numbers = random.sample(range(1, 46), 6) print("추출 (정렬 전):", numbers) # 오름차순 정렬 numbers.sort() print("정렬 후:", numbers) # 보너스 번호 (당첨 번호와 다른 것) while True: bonus = random.randint(1, 45) if bonus not in numbers: break print(f"당첨 번호: {numbers}") print(f"보너스: {bonus}")
추출 (정렬 전): [34, 7, 21, 3, 15, 42] 정렬 후: [3, 7, 15, 21, 34, 42] 당첨 번호: [3, 7, 15, 21, 34, 42] 보너스: 18

sort() vs sorted()

sort()는 리스트 자체를 바꾸고, sorted()는 정렬된 새 리스트를 반환합니다. 원본을 유지하고 싶을 때는 sorted()를 사용합니다.

Step 2 — 완성 코드 & 도전 문제

여러 게임 참가자가 각자 번호를 뽑고, 자신의 번호와 당첨 번호를 비교하는 완성된 로또 프로그램을 만듭니다.

import random def draw_lotto(): numbers = sorted(random.sample(range(1, 46), 6)) while True: bonus = random.randint(1, 45) if bonus not in numbers: break return numbers, bonus def check_match(my_nums, win_nums, bonus): matched = len(set(my_nums) & set(win_nums)) bonus_match = bonus in my_nums print(f"일치: {matched}개", "+ 보너스!" if bonus_match else "") win_nums, bonus = draw_lotto() my_nums = sorted(random.sample(range(1, 46), 6)) print(f"당첨 번호: {win_nums} + [{bonus}]") print(f"내 번호: {my_nums}") check_match(my_nums, win_nums, bonus)

핵심 요약

  • import random — 무작위 기능을 가진 모듈 불러오기
  • random.sample(range(1,46), 6) — 중복 없이 6개 추출
  • random.randint(a, b) — a~b 사이 랜덤 정수 1개
  • list.sort() — 원본 리스트 정렬 / sorted(list) — 새 정렬 리스트 반환
  • set(a) & set(b) — 두 리스트의 교집합 (공통 요소)
