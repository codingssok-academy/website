데이터 분석기

문자열과 리스트를 활용해 성적 데이터를 입력받고 분석하는 프로그램을 만듭니다.

이 프로젝트에서 만드는 것

  • 쉼표로 구분된 성적 데이터를 입력받아 리스트로 변환합니다.
  • 평균, 최고점, 최저점, 통과/불통과 인원을 계산합니다.
  • f-string으로 분석 결과를 보기 좋게 출력합니다.
  • while 반복문으로 여러 번 분석할 수 있게 만듭니다.
  • 문자열 + 리스트 + 조건문 + 반복문 통합 활용.

Step 1. 데이터 입력과 변환

사용자가 쉼표로 구분하여 입력한 점수를 split()으로 나누고 정수 리스트로 변환합니다.

# Step 1: 데이터 입력 raw = input("점수를 쉼표로 구분하여 입력하세요: ") # 예: "85, 92, 78, 95, 88" # Step 2: 문자열 -> 리스트 변환 parts = raw.split(",") scores = [int(s.strip()) for s in parts] print(scores) # [85, 92, 78, 95, 88]
따라해보세요
1
입력 변환 코드를 실행해보세요.
raw = "85, 92, 78, 95, 88" # 테스트용 parts = raw.split(",") print(parts) # ['85', ' 92', ' 78', ' 95', ' 88'] scores = [int(s.strip()) for s in parts] print(scores) # [85, 92, 78, 95, 88]

raw = "85, abc, 78" parts = raw.split(",") scores = [] for s in parts: s = s.strip() if s.isdigit(): scores.append(int(s)) else: print(f"'{s}'은(는) 숫자가 아닙니다. 건너뜁니다.") print(scores) # [85, 78]

빈 문자열 체크는 필수입니다

Step 2. 데이터 분석

리스트에 담긴 점수를 분석하여 평균, 최고점, 최저점, 통과율을 계산합니다.

# 분석 함수 def analyze(scores): count = len(scores) avg = sum(scores) / count high = max(scores) low = min(scores) passed = [s for s in scores if s >= 60] failed = [s for s in scores if s < 60] return { "count": count, "avg": avg, "high": high, "low": low, "passed": len(passed), "failed": len(failed), }
따라해보세요
1
분석 함수를 테스트해보세요.
scores = [85, 92, 78, 95, 88] result = analyze(scores) print(result)
딕셔너리로 결과가 반환됩니다
2
등급 분류를 추가해보세요.
def grade(score): if score >= 90: return "A" elif score >= 80: return "B" elif score >= 70: return "C" elif score >= 60: return "D" else: return "F" grades = [grade(s) for s in scores] print(grades) # ['B', 'A', 'C', 'A', 'B']
각 점수가 등급으로 변환됩니다
3
등급별 인원을 세보세요.
for g in ["A", "B", "C", "D", "F"]: print(f"{g}: {grades.count(g)}명")
A: 2명, B: 2명, C: 1명 ...

Step 3. 결과 출력

f-string과 문자열 메서드를 활용하여 분석 결과를 보기 좋게 출력합니다.

def print_report(result): print("===== 성적 분석 결과 =====") print(f"총 인원: {result['count']}명") print(f"평 균: {result['avg']:.1f}점") print(f"최고점: {result['high']}점") print(f"최저점: {result['low']}점") total = result['count'] p_rate = result['passed'] / total * 100 f_rate = result['failed'] / total * 100 print(f"통 과: {result['passed']}명 ({p_rate:.1f}%)") print(f"불통과: {result['failed']}명 ({f_rate:.1f}%)") print("===========================")
따라해보세요
1
텍스트 막대 그래프를 만들어보세요.
def bar_chart(scores): print("\n[점수 분포]") for i, s in enumerate(scores): bar = "#" * (s // 5) print(f" {i+1}번: {bar} {s}") bar_chart([85, 92, 78, 95, 88])
# 문자로 점수를 시각화합니다
2
등급표도 출력해보세요.
def grade_table(scores): print(f"\n{'번호':>4} {'점수':>6} {'등급':>4}") print("-" * 18) for i, s in enumerate(scores, 1): print(f"{i:>4} {s:>6} {grade(s):>4}")
정렬된 표 형태로 출력됩니다
3
전체를 합쳐서 실행해보세요.
scores = [85, 92, 78, 95, 88] result = analyze(scores) print_report(result) bar_chart(scores) grade_table(scores)

Step 4. 메인 프로그램

while 루프로 여러 번 분석할 수 있게 만들고, 전체 코드를 완성합니다.

# 완성 코드 - 메인 루프 def main(): print("=== 성적 데이터 분석기 ===") while True: raw = input("\n점수 입력 (쉼표 구분): ") if not raw.strip(): print("입력이 없습니다.") continue # 파싱 scores = [] for s in raw.split(","): s = s.strip() if s.isdigit(): scores.append(int(s)) if not scores: print("유효한 점수가 없습니다.") continue # 분석 + 출력 result = analyze(scores) print_report(result) bar_chart(scores) # 계속 여부 again = input("\n다시 분석? (y/n): ") if again.lower() != "y": print("프로그램을 종료합니다.") break main()

확장: 이름+점수 함께 분석

이름과 점수를 함께 입력받아 더 풍부한 분석 결과를 만들어보세요.

def parse_named(raw): """이름:점수 형식을 파싱""" students = [] for item in raw.split(","): item = item.strip() if ":" in item: name, score = item.split(":") students.append((name.strip(), int(score.strip()))) return students # 테스트 data = parse_named("민수:85, 서연:92, 지호:78") print(data) # [('민수', 85), ('서연', 92), ('지호', 78)] # 1등 찾기 best = max(data, key=lambda x: x[1]) print(f"1등: {best[0]} ({best[1]}점)") # 1등: 서연 (92점)

표준편차 계산 추가
보통
analyze() 함수에 표준편차를 추가하세요. 표준편차 = 각 점수와 평균의 차이를 제곱하여 평균을 낸 후 제곱근을 구합니다.
입력[85, 92, 78, 95, 88]
출력표준편차: 5.9
내 답안
힌트 보기
sum((s - avg)**2 for s in scores) / len(scores)를 구한 뒤 ** 0.5로 제곱근을 구하세요.
정답 확인
scores = [85, 92, 78, 95, 88] avg = sum(scores) / len(scores) variance = sum((s - avg)**2 for s in scores) / len(scores) std = variance ** 0.5 print(f"표준편차: {std:.1f}")

점수를 10점 단위 구간(0~9, 10~19, ..., 90~100)으로 나눠 히스토그램을 출력하세요.
입력[85, 92, 78, 95, 88, 72, 91]
출력70~79: ## (2명)
80~89: ## (2명)
90~100: ### (3명)
내 답안
힌트 보기
s // 10으로 구간을 구하고, 각 구간의 개수를 세서 "#"로 표시하세요.
정답 확인
scores = [85, 92, 78, 95, 88, 72, 91] bins = [0] * 11 # 0~10 구간 for s in scores: idx = min(s // 10, 10) bins[idx] += 1 for i in range(11): if bins[i] > 0: lo = i * 10 hi = min(lo + 9, 100) bar = "#" * bins[i] print(f"{lo:>3}~{hi:<3}: {bar} ({bins[i]}명)")

핵심 요약

이 프로젝트에서 배운 것

  • split(",")으로 쉼표 구분 입력을 파싱하고 strip()으로 공백 제거
  • isdigit()으로 유효성 검사, 잘못된 입력 건너뛰기
  • 리스트 컴프리헨션으로 데이터 변환과 필터링
  • sum(), max(), min(), len()으로 통계 계산
  • f-string :.1f, :>4 등으로 정렬된 출력 포맷팅
  • 함수로 기능 분리 (파싱, 분석, 출력, 메인 루프)
