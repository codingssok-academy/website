Chapter 18

파일 입출력

데이터를 파일에 저장하고, 파일에서 읽어오는 방법을 배웁니다.

이 유닛에서 배우는 것

  • open() 함수로 파일을 열고 닫을 수 있습니다.
  • 파일에 텍스트를 쓰고(write), 읽을(read) 수 있습니다.
  • with 문으로 안전하게 파일을 다룰 수 있습니다.
  • 파일 모드(r, w, a)의 차이를 이해합니다.
  • CSV와 JSON 파일을 다룰 수 있습니다.

open() — 파일 열기

open()은 파일을 여는 함수입니다. 두 번째 인자로 모드를 지정합니다.

따라해보세요
1
파일에 글을 써보세요.
f = open("hello.txt", "w") f.write("안녕하세요!\n") f.write("파이썬 파일 입출력입니다.\n") f.close()
hello.txt 파일이 생성됩니다
2
파일을 읽어보세요.
f = open("hello.txt", "r") content = f.read() print(content) f.close()
파일의 전체 내용이 출력됩니다
3
파일에 내용을 추가해보세요.
f = open("hello.txt", "a") f.write("새로운 줄 추가!\n") f.close()
기존 내용 뒤에 새 줄이 추가됩니다

with 문 — 안전한 파일 다루기

with 문을 쓰면 close()를 잊어도 자동으로 파일이 닫힙니다. 실무에서는 항상 with를 사용합니다.

# with 문으로 파일 쓰기 with open("diary.txt", "w") as f: f.write("2026년 3월 21일\n") f.write("오늘 파이썬 공부를 했다!\n") # 여기서 자동으로 f.close() 실행

파일 읽기 — 3가지 방법

# 방법 1: 전체 읽기 with open("diary.txt") as f: all_text = f.read() # 방법 2: 한 줄씩 읽기 with open("diary.txt") as f: line = f.readline() # 방법 3: 줄 리스트로 읽기 with open("diary.txt") as f: lines = f.readlines()
따라해보세요
1
with 문으로 파일을 만들고 읽어보세요.
with open("names.txt", "w") as f: f.write("민수\n서연\n지호\n") with open("names.txt") as f: print(f.read())
민수, 서연, 지호가 줄바꿈으로 출력됩니다
2
readlines()로 리스트를 만들어보세요.
with open("names.txt") as f: names = f.readlines() print(names) # ['민수\n', '서연\n', '지호\n']
각 줄이 리스트 원소가 됩니다 (\\n 포함)
3
for 문으로 줄별 처리를 해보세요.
with open("names.txt") as f: for line in f: name = line.strip() # \n 제거 print(f"이름: {name}")
이름: 민수 / 이름: 서연 / 이름: 지호

실전: 성적 파일 만들기

여러 줄의 데이터를 파일에 쓰고, 다시 읽어서 처리하는 실전 예제입니다.

# 성적 데이터 쓰기 students = [ ("민수", 95), ("서연", 88), ("지호", 72), ("하은", 91) ] with open("scores.txt", "w") as f: for name, score in students: f.write(f"{name},{score}\n") print("저장 완료!")
# 성적 데이터 읽기 + 평균 계산 total = 0 count = 0 with open("scores.txt") as f: for line in f: name, score = line.strip().split(",") print(f"{name}: {score}점") total += int(score) count += 1 print(f"평균: {total / count:.1f}점")

CSV 파일 다루기

CSV(Comma-Separated Values)는 쉼표로 값을 구분하는 파일 형식입니다. 엑셀과 호환됩니다.

import csv # CSV 쓰기 with open("scores.csv", "w", newline="") as f: writer = csv.writer(f) writer.writerow(["이름", "점수"]) writer.writerow(["민수", 95]) writer.writerow(["서연", 88])

JSON 파일 다루기

JSON은 딕셔너리와 리스트를 파일로 저장하는 형식입니다. 웹에서 가장 많이 사용됩니다.

import json # JSON 쓰기 data = {"name": "민수", "age": 15, "scores": [95, 88, 72]} with open("student.json", "w", encoding="utf-8") as f: json.dump(data, f, ensure_ascii=False, indent=2) # JSON 읽기 with open("student.json", encoding="utf-8") as f: loaded = json.load(f) print(loaded["name"], loaded["scores"])
따라해보세요
1
CSV 파일을 읽어서 출력해보세요.
import csv with open("scores.csv", newline="") as f: reader = csv.reader(f) for row in reader: print(row)
['이름', '점수'], ['민수', '95'], ...
2
JSON으로 게임 세이브 데이터를 저장해보세요.
import json save = {"player": "용사", "level": 5, "hp": 100} with open("save.json", "w", encoding="utf-8") as f: json.dump(save, f, ensure_ascii=False, indent=2) print("저장 완료!")
save.json 파일이 생성됩니다
3
JSON 파일을 불러와서 레벨업 시켜보세요.
import json with open("save.json", encoding="utf-8") as f: save = json.load(f) save["level"] += 1 print(f"레벨업! Lv.{save['level']}") with open("save.json", "w", encoding="utf-8") as f: json.dump(save, f, ensure_ascii=False, indent=2)
레벨업! Lv.6 — 파일도 업데이트됨

핵심 요약

이 유닛에서 배운 것

  • open(파일명, 모드)로 파일을 열고 close()로 닫는다
  • 모드: "r" 읽기, "w" 쓰기(덮어쓰기), "a" 추가
  • with open() as f:를 쓰면 자동으로 파일이 닫힌다 (권장)
  • read(), readline(), readlines()로 읽는 방법이 다르다
  • csv 모듈로 표 데이터, json 모듈로 구조화된 데이터를 다룬다
