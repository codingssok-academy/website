Chapter 24 — L3

내장 함수 활용
map, filter, sorted

리스트 전체를 한 번에 변환하고 걸러내고 정렬하는 파이썬의 강력한 도구를 배웁니다.

이 유닛에서 배우는 것

  • map()으로 리스트 전체에 함수를 적용할 수 있습니다.
  • filter()로 조건에 맞는 항목만 골라낼 수 있습니다.
  • sorted()와 key 매개변수로 원하는 기준으로 정렬할 수 있습니다.
  • list()로 map/filter 결과를 리스트로 변환할 수 있습니다.
  • enumerate()와 zip()의 기본 사용법을 알 수 있습니다.

map() — 리스트 전체에 함수 적용

map(함수, 리스트)는 리스트의 모든 항목에 함수를 한 번씩 적용합니다. 결과는 map 객체이므로 list()로 변환해야 합니다.

# 문자열 리스트를 정수로 변환 words = ["1", "2", "3", "4", "5"] result = list(map(int, words)) print(result) # [1, 2, 3, 4, 5] # 모든 이름을 대문자로 names = ["alice", "bob", "charlie"] upper = list(map(str.upper, names)) print(upper) # ['ALICE', 'BOB', 'CHARLIE']
# lambda와 함께: 각 점수에 10점 추가 scores = [70, 85, 60, 95] bonus = list(map(lambda x: x + 10, scores)) print(bonus) # [80, 95, 70, 105]

filter() — 조건에 맞는 것만 골라내기

filter(함수, 리스트)는 함수가 True를 반환하는 항목만 남깁니다. 체(sieve)처럼 원하는 것만 통과시킵니다.

# 양수만 골라내기 nums = [-2, 0, 3, -1, 5] positives = list(filter(lambda x: x > 0, nums)) print(positives) # [3, 5] # 60점 이상 합격자만 scores = [45, 72, 88, 55, 91] passed = list(filter(lambda x: x >= 60, scores)) print(passed) # [72, 88, 91]

sorted() — 정렬하기

sorted(리스트)는 원본을 바꾸지 않고 정렬된 새 리스트를 반환합니다. key 매개변수로 정렬 기준을 지정할 수 있습니다.

# 기본 정렬 (오름차순) nums = [3, 1, 4, 1, 5, 9] asc = sorted(nums) print(asc) # [1, 1, 3, 4, 5, 9] # 내림차순: reverse=True desc = sorted(nums, reverse=True) print(desc) # [9, 5, 4, 3, 1, 1] # key: 이름을 길이 순으로 정렬 words = ["banana", "apple", "fig", "cherry"] by_len = sorted(words, key=len) print(by_len) # ['fig', 'apple', 'banana', 'cherry']
# key=lambda: 마지막 글자 기준 정렬 words = ["banana", "apple", "cherry"] by_last = sorted(words, key=lambda w: w[-1]) print(by_last) # ['banana', 'apple', 'cherry']

실용 예제 — 성적 처리 시스템

map, filter, sorted를 조합하면 실제 성적 데이터를 깔끔하게 처리할 수 있습니다.

# 성적 데이터 처리 파이프라인 raw = ["78", "95", "55", "62", "88", "40"] # 1단계: 문자열 -> 정수 scores = list(map(int, raw)) # 2단계: 60점 이상만 (합격) passed = list(filter(lambda s: s >= 60, scores)) # 3단계: 내림차순 정렬 ranked = sorted(passed, reverse=True) print(ranked) # [95, 88, 78, 62]
# 이름을 알파벳 길이 순으로 정렬 students = ["Charlie", "Alice", "Bob", "David"] by_name_len = sorted(students, key=len) print(by_name_len) # ['Bob', 'Alice', 'David', 'Charlie'] # 대소문자 무시하고 알파벳 정렬 words = ["Banana", "apple", "Cherry"] alpha = sorted(words, key=str.lower) print(alpha) # ['apple', 'Banana', 'Cherry']

enumerate() 와 zip() — 맛보기

이 두 함수도 map, filter처럼 이터레이터를 반환합니다. 반복문에서 자주 쓰이는 강력한 도구입니다.

# enumerate(): 인덱스와 값을 함께 names = ["Alice", "Bob", "Charlie"] for i, name in enumerate(names): print(f"{i+1}번: {name}") # 1번: Alice # 2번: Bob # 3번: Charlie
# zip(): 두 리스트를 묶기 names = ["Alice", "Bob", "Choi"] scores = [85, 92, 78] for name, score in zip(names, scores): print(f"{name}: {score}점") # Alice: 85점 # Bob: 92점 # Choi: 78점 # zip + sorted: 점수 순서로 정렬 pairs = list(zip(names, scores)) ranked = sorted(pairs, key=lambda x: x[1], reverse=True) print(ranked) # [('Bob', 92), ('Alice', 85), ('Choi', 78)]
정리 — list()가 필요한 이유

map(), filter(), zip(), enumerate()는 모두 이터레이터를 반환합니다. 이터레이터는 한 번에 하나씩 꺼내 쓰는 객체라서, 전체 결과를 리스트로 보려면 list()로 변환해야 합니다. for 반복문에서는 변환 없이 바로 사용할 수 있습니다.

핵심 요약

핵심 요약

  • map(함수, 리스트) — 모든 항목에 함수를 적용, 결과 개수 동일
  • filter(함수, 리스트) — True인 항목만 남김, 결과 개수 감소 가능
  • sorted(리스트, key=fn, reverse=True) — 새 리스트 반환, 원본 보존
  • list() — map/filter 결과를 리스트로 변환 (이터레이터 해소)
  • lambda — 간단한 익명 함수, key와 filter에 자주 사용
  • enumerate() — (인덱스, 값) 쌍으로 반복
  • zip() — 두 리스트를 짝지어 반복
