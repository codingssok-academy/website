프로젝트:
회문(팰린드롬)
판별기

슬라이싱 [::-1]로 문자열을 뒤집고, lower()와 replace()로 전처리한 뒤, 리스트 컴프리헨션으로 복수 단어를 한 번에 검사하는 판별기를 완성합니다.

이 프로젝트에서 만드는 것

  • [::-1] 슬라이싱으로 문자열을 역순으로 뒤집을 수 있습니다.
  • lower()와 replace()로 대소문자와 공백을 전처리할 수 있습니다.
  • 전처리된 문자열과 역순을 비교해 회문을 판별할 수 있습니다.
  • 리스트 컴프리헨션으로 여러 단어를 한 번에 검사할 수 있습니다.
  • 문장 단위의 회문(공백 제거 후 판별)도 처리할 수 있습니다.

핵심 개념 — 슬라이싱 역순과 문자열 전처리

s[::-1]은 슬라이싱의 세 번째 인수(step)를 -1로 설정해 문자열을 역순으로 읽습니다. 시작·끝을 생략하면 전체 문자열이 대상입니다. 이 결과가 원본 문자열과 같으면 회문입니다.

Step 1 — 기본 회문 판별 함수

가장 간단한 형태로 시작합니다. 입력을 lower()로 소문자 통일 후 [::-1]와 비교합니다.

# Step 1: 기본 회문 판별 def is_palindrome(word): """단어가 회문이면 True 반환""" cleaned = word.lower() # 소문자 통일 reversed_word = cleaned[::-1] # 역순 슬라이싱 return cleaned == reversed_word # 테스트 print(is_palindrome("radar")) # True print(is_palindrome("Radar")) # True (대소문자 무시) print(is_palindrome("python")) # False
True True False

Step 2 — 문장 단위 회문 (공백/구두점 제거)

문장 회문 판별은 공백과 특수문자를 모두 제거해야 합니다. replace()를 연쇄 호출하거나 리스트 컴프리헨션으로 알파벳만 걸러냅니다.

# Step 2: 문장 회문 — isalpha()로 알파벳만 추출 def is_sentence_palindrome(sentence): """공백/구두점을 무시하고 문장 회문 판별""" # 리스트 컴프리헨션: 소문자 변환 후 알파벳만 추출 chars = [c for c in sentence.lower() if c.isalpha()] cleaned = "".join(chars) # 리스트 → 문자열 return cleaned == cleaned[::-1] print(is_sentence_palindrome("A man a plan a canal Panama")) # True print(is_sentence_palindrome("Was it a car or a cat I saw")) # True print(is_sentence_palindrome("Hello World")) # False
True True False

Step 3 — 리스트 컴프리헨션으로 복수 단어 검사

단어 목록을 받아 회문인 단어만 골라내는 함수를 만듭니다. 리스트 컴프리헨션의 if 조건에 is_palindrome()을 넣으면 한 줄로 해결됩니다.

# Step 3: 목록에서 회문만 골라내기 def find_palindromes(word_list): """리스트 컴프리헨션으로 회문만 필터링""" return [w for w in word_list if is_palindrome(w)] words = ["radar", "python", "level", "code", "civic", "hello", "noon"] palindromes = find_palindromes(words) print(f"전체 단어: {len(words)}개") print(f"회문 단어: {palindromes}") print(f"회문 비율: {len(palindromes)/len(words)*100:.1f}%")
전체 단어: 7개 회문 단어: ['radar', 'level', 'civic', 'noon'] 회문 비율: 57.1%

Step 4 — 완성 프로그램 통합

세 단계를 하나의 palindrome_checker.py로 통합합니다. 사용자가 단어를 입력하면 회문 여부와 역순 문자열을 함께 출력합니다.

# palindrome_checker.py — 완성 프로그램 def is_palindrome(word): cleaned = word.lower() return cleaned == cleaned[::-1] def is_sentence_palindrome(sentence): chars = [c for c in sentence.lower() if c.isalpha()] cleaned = "".join(chars) return cleaned == cleaned[::-1] def find_palindromes(word_list): return [w for w in word_list if is_palindrome(w)] def main(): test_words = ["racecar", "hello", "deified", "world", "noon"] print("=== 회문 판별기 ===") for word in test_words: result = "회문" if is_palindrome(word) else "아님" rev = word[::-1] print(f"{word:<10} 역순: {rev:<10} [{result}]") palindromes = find_palindromes(test_words) print(f"\n회문 단어: {palindromes}") main()

Q3. 가장 긴 회문 찾기
어려움
단어 목록에서 회문 중 가장 긴 단어를 반환하는 longest_palindrome(words)를 작성하세요. 회문이 없으면 빈 문자열을 반환합니다.
입력["radar", "civic", "racecar", "noon", "hello"]
출력racecar
힌트 보기
find_palindromes()로 회문 목록을 먼저 만든 뒤, 그 목록에 max(key=len)을 적용하세요. 목록이 비어있으면 ""을 반환합니다.
정답 보기
def longest_palindrome(words): pals = find_palindromes(words) if not pals: return "" return max(pals, key=len) words = ["radar", "civic", "racecar", "noon", "hello"] print(longest_palindrome(words)) # racecar

핵심 요약 — 회문 판별기 완성

핵심 요약

  • s[::-1] — 슬라이싱 step -1로 문자열 역순 생성. 원본과 같으면 회문.
  • lower() — 대소문자를 통일해 대소문자 구분 없는 회문 판별을 가능하게 함.
  • replace(old, new) — 특정 문자를 다른 문자로 일괄 치환. 공백 제거에 활용.
  • isalpha() — 문자가 알파벳인지 확인. 숫자, 공백, 구두점은 False 반환.
  • 리스트 컴프리헨션 [x for x in lst if 조건] — 조건에 맞는 항목만 새 리스트로 생성.
  • "".join(chars) — 문자 리스트를 하나의 문자열로 합침.
확장 아이디어
더 나아가기
  • 한국어 회문도 판별할 수 있습니다. 예: "기러기", "토마토" — isalpha()는 한글도 True 반환합니다.
  • input()으로 사용자 입력을 받아 실시간 판별기로 만들 수 있습니다.
  • 텍스트 파일에서 가장 긴 회문 단어를 자동으로 찾는 프로그램으로 확장할 수 있습니다.
