숫자 맞추기 게임
(UP/DOWN)

random 모듈, while 반복문, if 조건문을 조합하여 숫자 맞추기 게임을 완성합니다.

이 프로젝트에서 배우는 것

  • random.randint()로 랜덤 숫자를 생성할 수 있습니다.
  • while True + break로 게임 루프를 구현할 수 있습니다.
  • if/elif/else로 UP/DOWN 힌트를 제공할 수 있습니다.
  • 시도 횟수를 카운터 변수로 관리할 수 있습니다.
  • 단계별로 기능을 확장하는 프로그래밍 습관을 익힙니다.

Step 1: random 모듈

import random으로 랜덤 기능을 가져옵니다. random.randint(a, b)는 a부터 b 사이의 정수를 랜덤으로 반환합니다.

import random answer = random.randint(1, 100) print("1~100 중 랜덤 숫자:", answer)

import random dice = random.randint(1, 6) print(f"주사위: {dice}")
1~6 중 하나가 출력됩니다

import random count = 0 for i in range(10): dice = random.randint(1, 6) print(dice, end=" ") if dice == 6: count += 1 print(f"\n6이 {count}번 나왔습니다")
10개 주사위 결과와 6의 횟수

Step 2: 기본 게임 만들기

랜덤 숫자를 생성하고, 사용자가 맞출 때까지 반복합니다. 맞추면 축하 메시지를 출력합니다.

import random answer = random.randint(1, 100) print("=== 숫자 맞추기 게임 ===") print("1~100 사이의 숫자를 맞춰보세요!") while True: guess = int(input("숫자 입력: ")) if guess == answer: print("정답! 축하합니다!") break elif guess < answer: print("UP! 더 큰 수를 입력하세요.") else: print("DOWN! 더 작은 수를 입력하세요.")

Step 3: 시도 횟수 추가

카운터 변수 tries를 추가해서 몇 번 만에 맞췄는지 알려줍니다.

import random answer = random.randint(1, 100) tries = 0 print("=== 숫자 맞추기 게임 ===") print("1~100 사이의 숫자를 맞춰보세요!") while True: guess = int(input("숫자 입력: ")) tries += 1 if guess == answer: print(f"정답! {tries}번 만에 맞췄습니다!") break elif guess < answer: print("UP! 더 큰 수를 입력하세요.") else: print("DOWN! 더 작은 수를 입력하세요.")

Step 4: 범위 힌트 추가

현재 가능한 범위를 표시하면 더 재미있습니다. 변수 low와 high로 범위를 좁혀갑니다.

import random answer = random.randint(1, 100) tries = 0 low = 1 high = 100 print("=== 숫자 맞추기 게임 ===") while True: print(f"범위: {low} ~ {high}") guess = int(input("숫자 입력: ")) tries += 1 if guess == answer: print(f"정답! {tries}번 만에 맞췄습니다!") break elif guess < answer: print("UP!") low = guess + 1 else: print("DOWN!") high = guess - 1

Step 5: 최종 완성 버전

시도 횟수 제한, 등급 평가, 다시하기 기능을 모두 넣은 최종 버전입니다.

import random def get_grade(tries): if tries <= 3: return "S (천재!)" elif tries <= 5: return "A (훌륭!)" elif tries <= 7: return "B (좋아요!)" else: return "C (다음엔 더 잘할 수 있어요)" while True: answer = random.randint(1, 100) tries = 0 max_tries = 10 low, high = 1, 100 print("\n=== 숫자 맞추기 게임 ===") print(f"1~100 사이 숫자를 {max_tries}번 안에 맞춰보세요!") while tries < max_tries: print(f"\n[{tries+1}/{max_tries}] 범위: {low}~{high}") guess = int(input("숫자 입력: ")) tries += 1 if guess == answer: print(f"\n정답! {tries}번 만에 맞췄습니다!") print(f"등급: {get_grade(tries)}") break elif guess < answer: print("UP!") low = guess + 1 else: print("DOWN!") high = guess - 1 else: print(f"\n기회 소진! 정답은 {answer}이었습니다.") again = input("\n다시 하시겠습니까? (y/n): ") if again != "y": print("게임 종료!") break

import random while True: print("\n=== 숫자 맞추기 게임 ===") print("난이도: 1.쉬움(1~10) 2.보통(1~100) 3.어려움(1~1000)") level = int(input("선택: ")) max_num = [10, 100, 1000][level - 1] answer = random.randint(1, max_num) tries = 0 low, high = 1, max_num while True: print(f"범위: {low}~{high}") guess = int(input("숫자: ")) tries += 1 if guess == answer: print(f"정답! {tries}번 만에!") if tries <= 3: print("등급: S") elif tries <= 5: print("등급: A") elif tries <= 7: print("등급: B") else: print("등급: C") break elif guess < answer: print("UP!") low = guess + 1 else: print("DOWN!") high = guess - 1 if input("다시? 핵심 요약

이 프로젝트에서 배운 것

  • import random으로 랜덤 모듈을 가져온다
  • random.randint(a, b)로 a~b 사이 랜덤 정수를 생성한다
  • while True + break로 게임 루프를 만든다
  • if/elif/else로 UP/DOWN 힌트를 제공한다
  • 카운터 변수로 시도 횟수를 추적한다
  • low/high 변수로 가능한 범위를 좁혀간다
  • 단계별로 기능을 추가하며 프로그램을 확장한다
