들여쓰기

Python에서 들여쓰기가 문법인 이유를 이해하고, 올바른 들여쓰기 습관을 익힙니다.

이 유닛에서 배우는 것

  • Python에서 들여쓰기가 문법인 이유를 설명할 수 있습니다.
  • 콜론(:) 뒤에 들여쓰기가 필요한 규칙을 알 수 있습니다.
  • IndentationError 메시지를 읽고 원인을 파악할 수 있습니다.
  • 공백 4칸 들여쓰기 규칙(PEP 8)을 적용할 수 있습니다.
  • 탭과 공백의 차이를 설명할 수 있습니다.
왜 이걸 배울까? 대부분의 프로그래밍 언어에서 들여쓰기는 "보기 좋게"하는 것이지만, Python에서는 문법 그 자체입니다. 들여쓰기를 잘못하면 프로그램이 아예 작동하지 않거나, 작동하더라도 의도와 다르게 동작합니다. 쉽게 말하면, 들여쓰기는 Python의 "문법 부호"입니다.

들여쓰기란?

들여쓰기(indentation)는 코드 줄 앞에 공백을 넣어 안쪽으로 밀어 쓰는 것입니다. 대부분의 프로그래밍 언어에서 들여쓰기는 가독성을 위한 선택사항이지만, Python에서는 문법입니다.

C 언어 — 들여쓰기는 선택
Python
1// 들여쓰기 없어도 동작함
2if (1) {
3printf("A\n");
4printf("B\n");
5}
6// 중괄호 {}가 블록을 결정
Python — 들여쓰기가 문법
Python
1# 들여쓰기가 블록을 결정
2if True:
3 print("A")
4 print("B")
5# 들여쓰기 없으면 에러!

C는 중괄호 {}로 코드 블록을 구분합니다. 들여쓰기를 안 해도 동작합니다. Python은 중괄호가 없습니다. 오직 들여쓰기로 블록을 구분합니다.

콜론(:)과 들여쓰기

Python에서 콜론(:)이 나오면 그 다음 줄부터 들여쓰기해야 합니다. 콜론은 "여기부터 새로운 블록이 시작된다"는 신호입니다.

Pythonblock.py
1if True: # 콜론!
2 print("블록 안") # 들여쓰기 (4칸)
3 print("블록 안") # 들여쓰기 (4칸)
4print("블록 밖") # 들여쓰기 없음
실행 결과
블록 안 블록 안 블록 밖
줄코드역할
1if True:콜론(:)으로 끝나면 다음 줄부터 들여쓰기 블록이 시작됩니다.
2공백 4칸으로 들여쓰기된 줄은 if 블록에 속합니다.
4들여쓰기가 없는 줄은 if 블록 밖입니다. 항상 실행됩니다.
KEY
콜론 → 들여쓰기
if, for, while, def, class 등의 키워드 뒤에 콜론(:)이 오면, 다음 줄은 반드시 들여쓰기해야 합니다. 이 규칙을 어기면 IndentationError가 발생합니다.

공백 4칸 — PEP 8 규칙

들여쓰기 칸 수는 통일하기만 하면 1칸, 2칸, 4칸 어떤 것이든 동작합니다. 하지만 Python 공식 스타일 가이드 PEP 8은 공백 4칸을 권장합니다.

PEP 8 권장 (공백 4칸)
Python
1if True:
2 print("A") # 4칸
3 print("B") # 4칸
동작하지만 비권장 (공백 2칸)
Python
1if True:
2 print("A") # 2칸
3 print("B") # 2칸

둘 다 정상 동작하지만, Python 커뮤니티에서는 4칸이 표준입니다. VS Code는 Tab 키를 누르면 자동으로 공백 4칸을 입력합니다.

TIP
VS Code의 자동 들여쓰기
VS Code에서 콜론(:)을 입력하고 Enter를 누르면 자동으로 공백 4칸이 들어갑니다. Tab 키를 눌러도 공백 4칸이 입력됩니다. VS Code 하단 상태 바에서 'Spaces: 4'로 설정되어 있는지 확인하십시오.

탭 vs 공백

들여쓰기에는 탭(Tab 키)과 공백(Space 키) 두 가지를 사용할 수 있습니다. 하지만 한 파일에서 둘을 섞으면 에러가 발생합니다.

항목탭(Tab)공백(Space)
입력Tab 키 1번Space 키 4번
보이는 모양환경에 따라 4칸 또는 8칸항상 정확히 4칸
PEP 8 권장비권장권장 (공백 4칸)
VS Code 기본Tab → 공백 4칸 자동 변환그대로 입력
섞어 쓰기에러 발생!에러 발생!
WARNING
탭과 공백을 절대 섞지 마십시오
Python 3에서 탭과 공백을 섞으면 TabError: inconsistent use of tabs and spaces in indentation 에러가 발생합니다. VS Code를 사용하면 Tab 키가 자동으로 공백 4칸으로 변환되므로 이 문제가 거의 발생하지 않습니다.

들여쓰기 단계 (중첩)

블록 안에 또 다른 블록이 있으면 들여쓰기가 한 단계 더 깊어집니다. 단계가 깊어질수록 공백이 4칸씩 추가됩니다.

Pythonnested.py
1if True: # 0단계 (공백 0칸)
2 print("1단계") # 1단계 (공백 4칸)
3 if True: # 1단계
4 print("2단계") # 2단계 (공백 8칸)
5 if True: # 2단계
6 print("3단계") # 3단계 (공백 12칸)
7 print("다시 1단계") # 1단계로 돌아옴
8print("0단계")
실행 결과
1단계 2단계 3단계 다시 1단계 0단계
줄코드역할
2공백 4칸 = 1단계. 첫 번째 if 블록에 속합니다.
4공백 8칸 = 2단계. 두 번째 if 블록에 속합니다.
6공백 12칸 = 3단계. 세 번째 if 블록에 속합니다.
7공백 4칸으로 돌아오면 첫 번째 if 블록으로 복귀합니다.
8공백 0칸 = 가장 바깥. 어떤 블록에도 속하지 않습니다.

들여쓰기가 의미를 바꾸는 예

R1의 예측 문제를 확인합니다. 들여쓰기 하나가 프로그램의 동작을 바꿉니다.

코드 A — B가 블록 안
Python
1if True:
2 print("A")
3 print("B")
4
5# 출력:
6# A
7# B
코드 B — B가 블록 밖
Python
1if True:
2 print("A")
3print("B")
4
5# 출력:
6# A
7# B

이 경우 if True:는 항상 실행되므로 결과가 같아 보입니다. 하지만 if False:로 바꾸면 차이가 명확해집니다.

Pythonindent_a.py
1if False:
2 print("A")
3 print("B")
4print("C")
실행 결과
C
Pythonindent_b.py
1if False:
2 print("A")
3print("B")
4print("C")
실행 결과
B C
KEY
들여쓰기 = 소속
들여쓰기된 줄은 윗줄의 블록에 '소속'됩니다. if False: 블록에 소속된 줄은 실행되지 않지만, 소속되지 않은 줄은 항상 실행됩니다. 공백 하나가 프로그램의 동작을 바꿉니다.

들여쓰기가 필요 없는 경우

지금까지 작성한 print() 코드에는 들여쓰기를 하지 않았습니다. 들여쓰기는 콜론(:) 뒤에만 필요합니다.

Pythonno_indent.py
1# 들여쓰기 없음 — 정상
2print("Hello")
3print("World")
4print(1 + 2)
Pythonbad_indent.py
1# 불필요한 들여쓰기 — 에러!
2 print("Hello")
실행 결과
File "bad_indent.py", line 2 print("Hello") IndentationError: unexpected indent
WARNING
불필요한 들여쓰기도 에러
콜론(:) 없이 들여쓰기하면 IndentationError: unexpected indent가 발생합니다. "예상하지 못한 들여쓰기"라는 뜻입니다.

에러 체험 — IndentationError 4가지

들여쓰기 관련 에러는 4가지입니다. 각각의 원인과 해결법을 알아둡니다.

에러 1: expected an indented block

Pythonerr1.py
1if True:
2print("Hello")
실행 결과
File "err1.py", line 2 print("Hello") ^ IndentationError: expected an indented block after 'if' statement on line 1
줄코드역할
2콜론(:) 다음 줄에 들여쓰기가 없습니다. 공백 4칸을 추가하면 해결됩니다.

에러 2: unexpected indent

Pythonerr2.py
1print("A")
2 print("B")
실행 결과
File "err2.py", line 2 print("B") IndentationError: unexpected indent
줄코드역할
2콜론(:) 없이 들여쓰기했습니다. 앞의 공백을 제거하면 해결됩니다.

에러 3: unindent does not match

Pythonerr3.py
1if True:
2 print("A")
3 print("B")
4 print("C")
실행 결과
File "err3.py", line 3 print("B") ^ IndentationError: unexpected indent
줄코드역할
3같은 블록인데 들여쓰기 칸 수가 다릅니다 (4칸과 6칸). 같은 블록은 같은 칸 수여야 합니다.

에러 4: TabError (탭+공백 혼용)

Pythonerr4.py
1if True:
2 print("A") # 공백 4칸
3 print("B") # 탭 1개
실행 결과
File "err4.py", line 3 print("B") ^ TabError: inconsistent use of tabs and spaces in indentation
TIP
보이지 않는 문자 확인
VS Code에서 View → Render Whitespace를 켜면 공백과 탭이 점(·)과 화살표(→)로 표시됩니다. 들여쓰기 문제를 눈으로 확인할 수 있습니다.
