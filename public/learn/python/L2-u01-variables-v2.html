Chapter 01

변수 — 값에 이름 붙이기

변수를 만들어 값을 저장하고, 꺼내 쓰고, 바꾸는 방법을 배웁니다.

이 유닛에서 배우는 것

  • 변수가 무엇인지 설명할 수 있습니다.
  • = 기호로 변수에 값을 저장할 수 있습니다.
  • 올바른 변수명 규칙을 지킬 수 있습니다.
  • 변수의 값을 변경할 수 있습니다.
  • 여러 변수를 이용해 계산할 수 있습니다.

변수란?

변수는 값을 담아두는 상자입니다. 상자에 이름을 붙이고, 그 이름으로 값을 꺼내 쓸 수 있습니다.

= 기호는 "같다"가 아니라 "넣는다"입니다. 오른쪽 값을 왼쪽 이름에 저장합니다.

score = 100 print(score) # 100
따라해보세요
1
게임 점수를 변수에 저장하고 출력하세요.
score = 950 print("내 점수:", score)
내 점수: 950 이 출력되면 성공
2
이름을 변수에 저장하고 출력하세요.
name = "민수" print("안녕,", name)
안녕, 민수 가 출력됩니다
3
숫자와 문자열 변수를 같이 출력하세요.
game = "마인크래프트" level = 27 print(game, "레벨:", level)
마인크래프트 레벨: 27

변수 이름 규칙

변수 이름은 아무렇게나 지을 수 없습니다. 파이썬에는 이름 규칙이 있습니다.

따라해보세요
1
밑줄(_)로 여러 단어를 연결해보세요.
my_age = 14 print("나이:", my_age)
나이: 14 가 출력됩니다
2
대소문자가 다르면 다른 변수인지 확인하세요.
score = 100 Score = 200 print(score, Score)
100 200 — 서로 다른 변수입니다
3
의미 있는 이름으로 용돈 변수를 만드세요.
allowance = 5000 print("이번 달 용돈:", allowance, "원")
이번 달 용돈: 5000 원

값 변경과 계산

변수에 새 값을 넣으면 이전 값은 사라지고 새 값으로 바뀝니다.

score = 100 print(score) # 100 score = 200 print(score) # 200 — 이전 값은 사라짐

변수끼리 더하기, 빼기 등 계산도 할 수 있습니다.

따라해보세요
1
용돈을 계산해보세요.
allowance = 10000 snack = 3500 remaining = allowance - snack print("남은 돈:", remaining, "원")
남은 돈: 6500 원
2
게임 점수를 올려보세요.
score = 0 score = score + 100 print("1단계 클리어:", score) score = score + 250 print("2단계 클리어:", score)
1단계 클리어: 100 / 2단계 클리어: 350
3
세 과목 평균을 구해보세요.
korean = 90 english = 85 math = 95 average = (korean + english + math) / 3 print("평균:", average)
평균: 90.0

f-string — 변수를 문자열에 끼워 넣기

변수에 저장한 값을 문장 속에 자연스럽게 넣고 싶을 때 쓰는 파이썬의 핵심 기능입니다. 문자열 앞에 f를 붙이고, 변수는 중괄호 { }로 감싸요.

💡 f-string은 f-format string의 줄임말. 3가지 방법 중 가장 짧고 읽기 쉬워요.

기본 사용법

name = "자현"
age = 17

# 옛날 방식 1 — 쉼표로 붙이기
print("이름:", name, "나이:", age)
# 이름: 자현 나이: 17

# 옛날 방식 2 — 더하기 (숫자는 str() 필요)
print("이름: " + name + ", 나이: " + str(age))

# f-string 방식 (추천 ✓)
print(f"이름: {name}, 나이: {age}")
# 이름: 자현, 나이: 17

중괄호 안에는 뭐든 넣을 수 있어요

a, b = 7, 3
print(f"{a} + {b} = {a + b}")        # 7 + 3 = 10
print(f"{a}의 3배는 {a * 3}")          # 7의 3배는 21
print(f"이름 길이: {len('자현')}글자") # 이름 길이: 2글자

자주 하는 실수

잘못된 예왜 틀렸나
print("이름: {name}")앞에 f를 안 붙이면 그냥 문자로 출력됨
print(f"이름: (name)")괄호 모양 틀림 — 반드시 중괄호 { }
print(f"값: {undefined_var}")존재하지 않는 변수면 NameError 발생

⚠️ f-string은 Python 3.6 이상에서만 동작해요. 오래된 파이썬(3.5 이하)에서는 안 됨 — 코딩쏙 학습 환경은 3.12라 문제없어요.

숫자 소수점 자리수 조절(:.2f)이나 표 형태 정렬(:10) 같은 고급 기능은 L3-u27 f-string 심화에서 배웁니다. 지금은 변수 값을 문장에 넣는 것만 익숙해지세요.

핵심 요약

이 유닛에서 배운 것

  • 변수는 값을 담아두는 상자이고, =으로 값을 저장한다
  • 변수 이름은 영문자/숫자/밑줄만 가능하고 숫자로 시작할 수 없다
  • 대소문자가 다르면 서로 다른 변수이다
  • 변수에 새 값을 넣으면 이전 값은 사라진다
  • 변수끼리 +, -, *, / 등으로 계산할 수 있다
