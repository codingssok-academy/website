프로젝트:
글자수 세기

문장을 입력하면 전체 글자 수, 단어 수, 띄어쓰기 수, 특수문자 수를 분석하는 텍스트 분석 도구를 만듭니다.

이 프로젝트에서 배우는 것

  • len(text)으로 전체 글자 수를 셉니다.
  • text.split()으로 단어 리스트를 만들고 단어 수를 셉니다.
  • text.count(" ")으로 띄어쓰기 개수를 셉니다.
  • for char in text로 한 글자씩 순회하며 분류합니다.
  • char.isalpha(), char.isdigit() 메서드를 활용합니다.

Step 1 — 기본 글자/단어/띄어쓰기 카운트

len(), split(), count()만으로도 유용한 통계를 뽑을 수 있습니다. 파이썬 문자열의 내장 메서드들을 활용합니다.

# 기본 통계 함수 def basic_count(text): chars = len(text) # 전체 글자 수 (공백 포함) words = len(text.split()) # 단어 수 spaces = text.count(" ") # 띄어쓰기 수 print(f"전체 글자수: {chars}") print(f"단어 수: {words}") print(f"띄어쓰기: {spaces}") text = input("문장을 입력하세요: ") basic_count(text)
문장을 입력하세요: 안녕하세요 저는 파이썬을 배우고 있습니다 전체 글자수: 21 단어 수: 5 띄어쓰기: 4

for 문으로 글자 분류하기

for char in text로 글자를 하나씩 순회하면서 isalpha(), isdigit(), isspace() 메서드로 종류를 분류할 수 있습니다.

def detail_count(text): alpha = digit = space = special = 0 for char in text: if char.isalpha(): alpha += 1 elif char.isdigit(): digit += 1 elif char.isspace(): space += 1 else: special += 1 print(f"문자: {alpha} 숫자: {digit} 공백: {space} 특수: {special}")

Step 2 — 완성 코드 & 도전 문제

기본 카운트와 상세 분류를 합쳐 완전한 텍스트 분석 도구를 완성합니다. 결과를 시각적으로 보기 좋게 정리합니다.

# 완성된 텍스트 분석기 def analyze(text): print("\n===== 텍스트 분석 결과 =====") print(f"입력 문장: {text}") print(f"전체 글자수: {len(text)}") print(f"단어 수: {len(text.split())}") print(f"띄어쓰기: {text.count(' ')}") alpha = digit = space = special = 0 for c in text: if c.isalpha(): alpha += 1 elif c.isdigit(): digit += 1 elif c.isspace(): space += 1 else: special += 1 print(f"문자: {alpha} / 숫자: {digit} / 특수문자: {special}") text = input("문장을 입력하세요: ") analyze(text)

"banana" 문자열에서 가장 많이 등장한 글자를 찾으세요. text.count(char)를 for 문 안에서 사용하면 됩니다.
입력"banana"
출력가장 많은 글자: 'a' (3번)
힌트 / 정답 보기
힌트: max()와 key=text.count 를 활용하세요.
text = "banana" most = max(text, key=text.count) print(f"가장 많은 글자: '{most}' ({text.count(most)}번)")

Q3
단어 길이 통계
어려움
문장의 각 단어 길이를 리스트에 저장하고, 가장 짧은 단어와 긴 단어, 평균 길이를 출력하세요.
입력"I love Python"
출력최단: 1, 최장: 6, 평균: 3.7
힌트 / 정답 보기
힌트: lengths = [len(w) for w in text.split()]
text = "I love Python" lengths = [len(w) for w in text.split()] print(f"최단: {min(lengths)}") print(f"최장: {max(lengths)}") print(f"평균: {sum(lengths)/len(lengths):.1f}")

핵심 요약

  • len(text) — 전체 글자 수 (공백 포함)
  • text.split() — 공백 기준 단어 리스트 반환
  • text.count("x") — "x"가 text에 나오는 횟수
  • char.isalpha() — 문자 여부 / isdigit() — 숫자 여부
  • for c in text — 문자열을 한 글자씩 순회
