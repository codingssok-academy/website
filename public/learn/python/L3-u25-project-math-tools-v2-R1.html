프로젝트:
단위 변환기

기본값 매개변수와 map()을 활용해 km↔mile, kg↔lb, 섭씨↔화씨를 일괄 변환하는 도구를 만듭니다.

이 유닛에서 만드는 것

  • 기본값 매개변수로 소수점 자리를 선택할 수 있는 변환 함수를 작성합니다.
  • km↔mile, kg↔lb, 섭씨↔화씨 양방향 변환 함수를 구현합니다.
  • map()으로 여러 값을 한번에 일괄 변환합니다.
  • 변환 결과를 f-string으로 보기 좋게 출력합니다.
  • 네 기능을 하나의 converter.py로 통합합니다.

Step 1 — 거리 변환: km ↔ mile

1킬로미터는 약 0.621371마일입니다. 기본값 매개변수 decimals=2를 사용하면 소수점 자리를 선택할 수 있어 편리합니다.

# Step 1: 거리 변환 함수 def km_to_mile(km, decimals=2): """킬로미터 → 마일 (기본값: 소수점 2자리)""" result = km * 0.621371 return round(result, decimals) def mile_to_km(mile, decimals=2): """마일 → 킬로미터""" result = mile * 1.60934 return round(result, decimals) # 기본 사용 print(km_to_mile(10)) # 6.21 print(km_to_mile(10, 4)) # 6.2137 print(mile_to_km(5)) # 8.05
6.21 6.2137 8.05

Step 2 — 무게·온도 변환 + map() 일괄 처리

무게 변환은 1kg = 2.20462lb, 온도 변환은 화씨 = 섭씨 × 9/5 + 32 공식을 사용합니다. map()으로 리스트 전체를 한번에 처리합니다.

# Step 2: 무게 + 온도 변환 함수 def kg_to_lb(kg, decimals=2): """킬로그램 → 파운드""" return round(kg * 2.20462, decimals) def lb_to_kg(lb, decimals=2): """파운드 → 킬로그램""" return round(lb / 2.20462, decimals) def celsius_to_f(c, decimals=1): """섭씨 → 화씨""" return round(c * 9 / 5 + 32, decimals) def f_to_celsius(f, decimals=1): """화씨 → 섭씨""" return round((f - 32) * 5 / 9, decimals) # map()으로 일괄 변환 weights_kg = [50, 60, 70, 80] weights_lb = list(map(kg_to_lb, weights_kg)) print(weights_lb) # [110.23, 132.28, 154.32, 176.37] temps_c = [0, 20, 37, 100] temps_f = list(map(celsius_to_f, temps_c)) print(temps_f) # [32.0, 68.0, 98.6, 212.0]
[110.23, 132.28, 154.32, 176.37] [32.0, 68.0, 98.6, 212.0]

Step 3 — 통합 변환기 완성

세 가지 변환 기능을 하나의 함수로 묶어 사용자가 단위 종류를 선택하면 자동으로 변환되도록 만듭니다.

# Step 3: 통합 변환기 def convert(value, unit_type, direction='to'): """통합 변환기 unit_type: 'distance', 'weight', 'temp' direction: 'to' (km→mile / kg→lb / C→F) 또는 'from' (역방향) """ if unit_type == 'distance': return km_to_mile(value) if direction == 'to' else mile_to_km(value) elif unit_type == 'weight': return kg_to_lb(value) if direction == 'to' else lb_to_kg(value) elif unit_type == 'temp': return celsius_to_f(value) if direction == 'to' else f_to_celsius(value) else: raise ValueError(f"알 수 없는 단위: {unit_type}") # 테스트 print(convert(100, 'distance')) # 62.14 mile print(convert(100, 'distance', 'from')) # 160.93 km print(convert(37, 'temp')) # 98.6 °F

정답 보기
def convert_with_label(value, unit_type, direction='to'): labels = { 'distance': ('km', 'mile'), 'weight': ('kg', 'lb'), 'temp': ('C', 'F') } from_l, to_l = labels[unit_type] if direction == 'from': from_l, to_l = to_l, from_l result = convert(value, unit_type, direction) return f"{value}{from_l} → {result}{to_l}" print(convert_with_label(10, 'distance')) # 10km → 6.21mile print(convert_with_label(37, 'temp')) # 37C → 98.6F

핵심 요약

  • 기본값 매개변수 — def f(x, decimals=2):처럼 선언하면 호출 시 생략 가능, 유연성 증가
  • round() — 소수점 자리 지정 반올림: round(6.2137, 2) → 6.21
  • map() — 리스트 전체에 함수 적용, list(map(fn, lst))로 결과 리스트 생성
  • 양방향 변환 — direction 매개변수로 km→mile / mile→km 방향 선택
  • 통합 함수 — 딕셔너리로 라벨 관리 + f-string으로 보기 좋은 출력
