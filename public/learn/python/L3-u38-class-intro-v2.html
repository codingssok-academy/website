클래스란?
데이터와 기능을 하나로

변수와 함수를 하나의 틀로 묶어 더 체계적인 코드를 만드는 방법을 배웁니다.

이 유닛에서 배우는 것

  • 클래스가 왜 필요한지 이해합니다.
  • class 키워드로 클래스를 정의할 수 있습니다.
  • 클래스로 객체(인스턴스)를 만들 수 있습니다.
  • self를 사용해 속성을 저장할 수 있습니다.
  • 메서드를 정의하고 호출할 수 있습니다.

왜 클래스가 필요한가?

학생 여러 명의 정보를 관리해야 할 때, 변수를 따로따로 만들면 코드가 금방 복잡해집니다. 클래스는 관련된 데이터와 기능을 하나의 묶음으로 정리합니다.

붕어빵 틀은 한 번만 만들지만, 그 틀로 붕어빵을 몇 개든 찍어낼 수 있습니다. 마찬가지로 class는 한 번 정의하고, 그 클래스로 객체를 몇 개든 만들 수 있습니다. 메서드로 넓이(area)나 둘레(perimeter) 같은 계산 기능도 추가할 수 있습니다. 가게 이름(shop_name)처럼 실생활 데이터를 속성으로 저장하면 더 다양하게 활용할 수 있습니다.

class 키워드 — 클래스 만들기

class 키워드로 클래스를 정의합니다. __init__은 객체를 만들 때 자동으로 실행되는 특별한 메서드입니다.

class Student: def __init__(self, name, age): self.name = name # 속성 저장 self.age = age # 속성 저장 # 객체(인스턴스) 만들기 s1 = Student("민수", 15) s2 = Student("서연", 14) print(s1.name) # 민수 print(s2.age) # 14

메서드 — 클래스 안의 함수

메서드는 클래스 안에 정의된 함수입니다. 첫 번째 매개변수는 반드시 self여야 하며, 객체.메서드() 형식으로 호출합니다.

class Student: def __init__(self, name, age): self.name = name self.age = age def greet(self): # 메서드 정의 print(f"{self.name}님 안녕하세요!") def info(self): # 또 다른 메서드 print(f"나이: {self.age}살") s1 = Student("민수", 15) s1.greet() # 민수님 안녕하세요! s1.info() # 나이: 15살

Dog 클래스를 만드세요. __init__ 메서드에서 name과 breed 속성을 받아 저장합니다. 인스턴스를 2개 만들어 각각의 name을 출력하세요.

바둑이
뽀삐
힌트 보기
class Dog: 다음 줄에 def __init__(self, name, breed):을 작성합니다. self.name = name 으로 속성을 저장하세요.
정답 보기
class Dog: def __init__(self, name, breed): self.name = name self.breed = breed d1 = Dog("바둑이", "진돗개") d2 = Dog("뽀삐", "푸들") print(d1.name) print(d2.name)
2
메서드 추가하기
보통
Rectangle 클래스를 만드세요. __init__에서 가로(width)와 세로(height)를 받고, area 메서드는 넓이를 반환, perimeter 메서드는 둘레를 반환하도록 만드세요.
입력
width=4, height=6
출력
넓이: 24 / 둘레: 20
힌트 보기
넓이 = width * height, 둘레 = 2 * (width + height). 메서드에서 return 키워드로 값을 돌려주세요.
정답 보기
class Rectangle: def __init__(self, width, height): self.width = width self.height = height def area(self): return self.width * self.height def perimeter(self): return 2 * (self.width + self.height) r = Rectangle(4, 6) print(f"넓이: {r.area()}") print(f"둘레: {r.perimeter()}")

붕어빵 클래스 만들기
어려움
BungeobbangShop 클래스를 만드세요. __init__에서 가게 이름(shop_name)을 받고, sell 메서드는 맛(flavor)과 개수(count)를 받아 주문 내용을 출력합니다. 한 개 가격은 300원으로 고정합니다.
출력
[달콤붕어빵] 팥 붕어빵 3개 = 900원
힌트 보기
sell 메서드 안에서 total = count * 300 으로 총 가격을 계산하세요. self.shop_name으로 가게 이름에 접근합니다.
정답 보기
class BungeobbangShop: def __init__(self, shop_name): self.shop_name = shop_name def sell(self, flavor, count): total = count * 300 print(f"[{self.shop_name}] {flavor} 붕어빵 {count}개 = {total}원") shop = BungeobbangShop("달콤붕어빵") shop.sell("팥", 3)

전체 예제 — 학생 관리 프로그램

지금까지 배운 클래스, 속성, 메서드를 모두 활용해 학생 관리 프로그램을 만들어봅니다.

class Student: def __init__(self, name, score): self.name = name self.score = score def greet(self): print(f"저는 {self.name}입니다!") def grade(self): if self.score >= 90: return "A" elif self.score >= 80: return "B" else: return "C" def study(self, hours): self.score = min(100, self.score + hours) print(f"{self.name} {hours}시간 공부 → 점수: {self.score}") s = Student("민수", 78) s.greet() # 저는 민수입니다! print(s.grade()) # C s.study(5) # 민수 5시간 공부 → 점수: 83 print(s.grade()) # B

핵심 요약

  • class 이름: — 클래스를 정의합니다. 이름은 PascalCase로 씁니다.
  • __init__(self, ...) — 객체를 만들 때 자동 실행되는 생성자 메서드입니다.
  • self.속성 = 값 — 객체의 속성(데이터)을 저장합니다.
  • def 메서드(self): — 클래스 안의 함수. 첫 매개변수는 항상 self입니다.
  • 객체 = 클래스(인자) — 클래스로 인스턴스(객체)를 만듭니다.
  • 클래스 = 붕어빵 틀, 객체 = 붕어빵. 틀 하나로 여러 개를 찍어냅니다.
