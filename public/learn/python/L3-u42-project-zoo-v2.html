Step 1 — Animal 부모 클래스 정의

모든 동물이 공통으로 가져야 할 속성(name, sound, hunger)과 메서드(speak, eat, status)를 부모 클래스에 정의합니다.

# Step 1: Animal 부모 클래스 class Animal: """동물 기본 클래스""" def __init__(self, name, sound): self.name = name # 동물 이름 self.sound = sound # 울음소리 self.hunger = 5 # 배고픔 (0=배부름, 10=매우 배고픔) def speak(self): print(f"{self.name}: {self.sound}!") def eat(self, amount=2): self.hunger -= amount if self.hunger < 0: self.hunger = 0 print(f"{self.name}이(가) 먹이를 먹었습니다. (배고픔: {self.hunger})") def status(self): bar = "#" * self.hunger + "-" * (10 - self.hunger) print(f"[{self.name}] 배고픔: [{bar}] {self.hunger}/10") # 테스트 a = Animal("동물", "...") a.speak() a.status()
동물: ...! [동물] 배고픔: [#####-----] 5/10

Step 2 — 자식 클래스: Lion, Penguin, Monkey

Animal을 상속받아 각 동물만의 고유한 속성과 메서드를 추가합니다. super().__init__()으로 부모 초기화를 재사용하고, 자식만의 메서드를 추가합니다.

# Step 2a: Lion 클래스 (사자) class Lion(Animal): """사자 클래스""" def __init__(self, name): super().__init__(name, "어흥") # 부모 초기화 self.mane = True # 갈기 여부 (사자만) def roar(self): print(f"{self.name}이(가) 크게 포효합니다! 어흥!!") def hunt(self): self.hunger -= 3 if self.hunger < 0: self.hunger = 0 print(f"{self.name}이(가) 사냥에 성공했습니다!") # Step 2b: Penguin 클래스 (펭귄) class Penguin(Animal): """펭귄 클래스""" def __init__(self, name): super().__init__(name, "크왁") self.swim_speed = 25 # 수영 속도 (km/h) def swim(self): print(f"{self.name}이(가) {self.swim_speed}km/h로 수영합니다!") def slide(self): print(f"{self.name}이(가) 배로 미끄러집니다! 슝~") # Step 2c: Monkey 클래스 (원숭이) class Monkey(Animal): """원숭이 클래스""" def __init__(self, name): super().__init__(name, "우키") self.energy = 10 # 활동 에너지 def climb(self): self.energy -= 2 print(f"{self.name}이(가) 나무를 오릅니다! (에너지: {self.energy})") def play(self): print(f"{self.name}이(가) 신나게 놉니다! 우키우키!")

Step 3 — Zoo 클래스: 동물원 관리

Zoo 클래스는 동물 리스트를 내부에 보관하고, 동물을 추가하거나, 전체에게 먹이를 주거나, 현재 상태를 한번에 출력하는 기능을 담당합니다.

# Step 3: Zoo 클래스 class Zoo: """동물원 관리 클래스""" def __init__(self, zoo_name): self.zoo_name = zoo_name self.animals = [] # 동물 리스트 def add_animal(self, animal): self.animals.append(animal) print(f"{animal.name}이(가) {self.zoo_name}에 입소했습니다!") def feed_all(self, amount=2): print(f"\n[{self.zoo_name}] 전체 먹이 주기 시작...") for animal in self.animals: animal.eat(amount) def show_status(self): print(f"\n=== {self.zoo_name} 현황 ===") print(f"총 동물 수: {len(self.animals)}마리") print("-" * 35) for animal in self.animals: animal.status() print("=" * 35) # 동물원 생성 및 동물 추가 zoo = Zoo("서울 코딩 동물원") zoo.add_animal(Lion("심바")) zoo.add_animal(Penguin("뽀로로")) zoo.add_animal(Monkey("마리오")) zoo.show_status()

완성: zoo_simulator.py 전체 코드

지금까지 만든 모든 클래스를 하나의 파일로 통합합니다. Animal 부모와 세 자식 클래스, Zoo 관리 클래스가 함께 동작하는 완전한 동물원 시뮬레이터입니다.

# zoo_simulator.py — 완성 코드 class Animal: def __init__(self, name, sound): self.name = name; self.sound = sound; self.hunger = 5 def speak(self): print(f"{self.name}: {self.sound}!") def eat(self, n=2): self.hunger = max(0, self.hunger - n) print(f"{self.name} 먹이 완료 (배고픔:{self.hunger})") def status(self): bar = "#" * self.hunger + "-" * (10 - self.hunger) print(f"[{self.name}] [{bar}] {self.hunger}/10") class Lion(Animal): def __init__(self, name): super().__init__(name, "어흥"); self.mane = True def speak(self): super().speak(); print(f" ({self.name} 갈기를 흔듭니다)") def roar(self): print(f"{self.name} 포효: 어흥!!") def hunt(self): self.hunger = max(0, self.hunger - 3); print(f"{self.name} 사냥 성공!") class Penguin(Animal): def __init__(self, name): super().__init__(name, "크왁"); self.swim_speed = 25 def speak(self): super().speak(); print(f" ({self.name} 날개 퍼덕)") def swim(self): print(f"{self.name} {self.swim_speed}km/h 수영!") def slide(self): print(f"{self.name} 배로 미끄러집니다 슝~") class Monkey(Animal): def __init__(self, name): super().__init__(name, "우키"); self.energy = 10 def speak(self): super().speak(); print(f" ({self.name} 바나나 먹으며 웃음)") def climb(self): self.energy -= 2; print(f"{self.name} 나무 오르기 (에너지:{self.energy})") def play(self): print(f"{self.name} 신나게 놀기 우키우키!") class Zoo: def __init__(self, name): self.zoo_name = name; self.animals = [] def add_animal(self, a): self.animals.append(a); print(f"{a.name} 입소!") def feed_all(self, n=2): for a in self.animals: a.eat(n) def show_status(self): print(f"\n=== {self.zoo_name} ({len(self.animals)}마리) ===") for a in self.animals: a.status() # 메인 실행 zoo = Zoo("코딩쏙 동물원") zoo.add_animal(Lion("심바")) zoo.add_animal(Penguin("뽀로로")) zoo.add_animal(Monkey("마리오")) zoo.show_status() zoo.feed_all(3) zoo.show_status()

핵심 요약

  • class Animal: — 부모(기반) 클래스. 공통 속성과 메서드를 정의한다.
  • def __init__(self, ...) — 객체 생성 시 자동 실행. self.속성으로 인스턴스 속성을 초기화한다.
  • class Lion(Animal): — 상속. Animal의 모든 기능을 물려받고 새 기능을 추가할 수 있다.
  • super().__init__(...) — 부모 클래스의 __init__을 자식에서 호출. 코드 중복 방지.
  • 메서드 오버라이드 — 자식에서 같은 이름 메서드를 재정의하면 자식 버전이 우선 실행된다.
  • Zoo 클래스 — 다형성 활용. 동물 종류와 무관하게 eat(), status()를 동일하게 호출할 수 있다.
