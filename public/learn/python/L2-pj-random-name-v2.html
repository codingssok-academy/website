랜덤 팀 나누기

이름 리스트를 random.shuffle로 섞고 원하는 팀 수에 맞게 자동으로 배정하는 프로그램을 만듭니다.

이 프로젝트에서 배우는 것

  • import random으로 표준 라이브러리 모듈을 불러올 수 있습니다.
  • random.shuffle()로 리스트를 무작위로 섞을 수 있습니다.
  • 리스트 슬라이싱으로 원하는 부분만 잘라낼 수 있습니다.
  • for 루프와 range()로 팀을 자동으로 나눌 수 있습니다.
  • random.choice()와 random.sample()도 활용할 수 있습니다.

random 모듈 사용하기

import random으로 random 모듈을 불러옵니다. 모듈이란 미리 만들어진 기능 묶음입니다. random.shuffle()은 리스트를 제자리에서 섞습니다.

import random names = ["김민준", "이서연", "박지호", "최유진", "정다은", "황민서", "조현우", "신지민"] # 리스트 섞기 random.shuffle(names) print("섞은 결과:", names) # 무작위로 한 명 뽑기 picked = random.choice(names) print(f"오늘의 발표자: {picked}")

팀 나누기 로직

셔플된 리스트를 슬라이싱으로 잘라 팀을 만듭니다. 8명을 2팀으로 나누면 팀당 4명, 3팀으로 나누면 팀당 약 3명이 됩니다.

import random names = ["김민준", "이서연", "박지호", "최유진", "정다은", "황민서", "조현우", "신지민"] num_teams = int(input("팀 수를 입력하세요: ")) random.shuffle(names) team_size = len(names) // num_teams # 팀당 인원 (몫) for i in range(num_teams): start = i * team_size end = start + team_size team = names[start:end] print(f"팀 {i+1}: {team}") # 나머지 인원 처리 leftover = names[num_teams * team_size:] if leftover: print(f"남은 인원: {leftover}")

완성: 랜덤 팀 나누기 프로그램

import random print("=== 랜덤 팀 나누기 ===") n = int(input("학생 수를 입력하세요: ")) names = [] for i in range(n): name = input(f"{i+1}번째 이름: ") names.append(name) num_teams = int(input("팀 수: ")) random.shuffle(names) team_size = len(names) // num_teams print("\n=== 팀 배정 결과 ===") for i in range(num_teams): start = i * team_size end = start + team_size team = names[start:end] members = " / ".join(team) print(f"[팀 {i+1}] {members}") leftover = names[num_teams * team_size:] if leftover: extra = " / ".join(leftover) print(f"[추가] {extra} (팀 배정 필요)")

핵심 요약

이 유닛에서 배운 것

  • import random으로 랜덤 관련 기능을 불러온다
  • random.shuffle(리스트): 리스트를 무작위로 섞는다 (반환값 없음, 원본 변경)
  • random.choice(리스트): 리스트에서 무작위 1개를 선택해 반환
  • random.sample(리스트, k): 중복 없이 k개를 뽑아 리스트로 반환
  • 리스트[start:end]: 슬라이싱으로 원하는 범위만 추출
  • n // m: 정수 나누기 (나머지 버림)
