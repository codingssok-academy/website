가위바위보 게임

input()으로 내 선택을 입력하고, random으로 컴퓨터가 선택해 승패를 판정합니다.

이 프로젝트에서 배우는 것

  • random.choice()로 리스트에서 무작위 선택을 할 수 있습니다.
  • and 연산자로 두 조건을 동시에 검사할 수 있습니다.
  • 복잡한 if/elif 구조로 승패 9가지 경우를 처리합니다.
  • 비교 연산자(==)로 문자열을 비교할 수 있습니다.
  • 게임 로직을 단계적으로 설계하는 방법을 배웁니다.

가위바위보 로직 설계

가위바위보의 모든 경우의 수는 3 × 3 = 9가지입니다. 이 중 이기는 경우 3가지, 지는 경우 3가지, 비기는 경우 3가지입니다.

import random choices = ["가위", "바위", "보"] user = input("가위, 바위, 보 중 선택: ") computer = random.choice(choices) print(f"나: {user} / 컴퓨터: {computer}") if user == computer: print("비겼습니다!") elif (user == "가위" and computer == "보") or \ (user == "바위" and computer == "가위") or \ (user == "보" and computer == "바위"): print("이겼습니다!") else: print("졌습니다...")

완성: 점수판 있는 가위바위보

여러 판 진행하면서 이긴 횟수를 세는 완성 버전을 만듭니다.

import random choices = ["가위", "바위", "보"] my_score = 0 comp_score = 0 round_num = 1 while round_num <= 3: print(f"\n{round_num}라운드") user = input("선택 (가위/바위/보): ") comp = random.choice(choices) print(f"컴퓨터: {comp}") if user == comp: print("비김") elif (user == "가위" and comp == "보") or \ (user == "바위" and comp == "가위") or \ (user == "보" and comp == "바위"): print("이겼다!") my_score += 1 else: print("졌다...") comp_score += 1 round_num += 1 print(f"\n최종: 나 {my_score} : {comp_score} 컴퓨터") if my_score > comp_score: print("최종 승리!") elif my_score < comp_score: print("최종 패배...") else: print("무승부!")

핵심 요약

이 유닛에서 배운 것

  • random.choice(리스트)로 리스트에서 무작위로 하나를 뽑는다
  • ==으로 문자열을 비교한다 (대소문자 구분 주의!)
  • and로 두 조건이 모두 참일 때만 참이 된다
  • or로 둘 중 하나라도 참이면 참이 된다
  • 복잡한 조건은 여러 개의 elif로 나누어 처리한다
  • 점수 카운터: my_score += 1로 이길 때마다 1씩 추가
