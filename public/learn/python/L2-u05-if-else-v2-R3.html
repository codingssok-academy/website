실전 미니 프로젝트 3개

조건문을 활용한 실제 프로그램을 만들어봅니다. 각 프로젝트를 직접 타이핑해서 실행해보세요.

1
편의점 할인 계산기

구매 금액에 따라 할인율이 달라지는 편의점 계산기를 만듭니다.

# 편의점 할인 계산기 price = int(input("구매 금액: ")) if price >= 50000: discount = 0.15 grade = "골드" elif price >= 30000: discount = 0.10 grade = "실버" elif price >= 10000: discount = 0.05 grade = "브론즈" else: discount = 0 grade = "일반" discount_amount = int(price * discount) final_price = price - discount_amount print(f"--- 영수증 ---") print(f"등급: {grade}") print(f"원래 금액: {price:,}원") print(f"할인 금액: {discount_amount:,}원") print(f"최종 금액: {final_price:,}원")
구매 금액: 35000 --- 영수증 --- 등급: 실버 원래 금액: 35,000원 할인 금액: 3,500원 최종 금액: 31,500원
새로운 개념 {price:,}는 숫자에 천 단위 콤마(,)를 자동으로 넣어줍니다. 예: 35000 → 35,000
2
가위바위보 판정기

사용자와 컴퓨터의 가위바위보 입력을 받아 승패를 판정합니다.

# 가위바위보 판정기 player = input("가위/바위/보: ") computer = input("컴퓨터 선택(가위/바위/보): ") print(f"나: {player} | 컴퓨터: {computer}") if player == computer: print("비겼습니다!") elif (player == "가위" and computer == "보") or \ (player == "바위" and computer == "가위") or \ (player == "보" and computer == "바위"): print("이겼습니다!") else: print("졌습니다...")
가위/바위/보: 가위 컴퓨터 선택(가위/바위/보): 보 나: 가위 | 컴퓨터: 보 이겼습니다!
1
비긴 경우: 두 입력이 같으면 → 비김
2
이긴 경우: 3가지 경우를 or로 연결
3
나머지는 모두 진 경우 → else
줄 이어쓰기 코드가 너무 길 때 \로 다음 줄에 이어 쓸 수 있습니다.
3
미니 키오스크 메뉴

메뉴 번호를 선택하면 가격과 칼로리를 안내하는 키오스크를 만듭니다.

# 미니 키오스크 print("========== 주문 메뉴 ==========") print("1. 불고기버거 5,500원 550kcal") print("2. 치킨버거 6,000원 480kcal") print("3. 콜라 2,000원 140kcal") print("4. 감자튀김 2,500원 320kcal") print("================================") choice = int(input("번호를 선택하세요 (1-4): ")) if choice == 1: name, price, kcal = "불고기버거", 5500, 550 elif choice == 2: name, price, kcal = "치킨버거", 6000, 480 elif choice == 3: name, price, kcal = "콜라", 2000, 140 elif choice == 4: name, price, kcal = "감자튀김", 2500, 320 else: print("잘못된 번호입니다.") name = None if name: print(f"\n주문: {name}") print(f"가격: {price:,}원") print(f"칼로리: {kcal}kcal") print("주문이 완료되었습니다!")
========== 주문 메뉴 ========== 1. 불고기버거 5,500원 550kcal 2. 치킨버거 6,000원 480kcal 3. 콜라 2,000원 140kcal 4. 감자튀김 2,500원 320kcal ================================ 번호를 선택하세요 (1-4): 2 주문: 치킨버거 가격: 6,000원 칼로리: 480kcal 주문이 완료되었습니다!
1
메뉴를 먼저 출력해서 사용자가 선택할 수 있게 함
2
elif로 각 번호에 해당하는 변수에 값 대입
3
잘못된 입력은 else에서 처리, name = None으로 표시
4
if name: → name이 None이 아니면 결과 출력 (None은 False 취급)
