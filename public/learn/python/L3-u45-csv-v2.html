Chapter 45 — L3e

CSV
엑셀처럼 데이터 저장하기

성적표, 주소록, 거래 내역처럼 표 형식의 데이터를 파일로 저장하고 읽는 가장 널리 쓰이는 방법, CSV를 파이썬으로 완전히 익힙니다.

이 유닛에서 배우는 것

  • CSV가 무엇인지, 왜 표 형식 데이터 저장에 가장 많이 쓰이는지 이해합니다.
  • import csv로 csv 모듈을 불러오는 방법을 배웁니다.
  • csv.reader / csv.writer로 CSV 파일을 읽고 씁니다.
  • csv.DictReader / csv.DictWriter로 딕셔너리 형태로 다룹니다.
  • 실용 예시: 성적표 CSV를 만들고, 읽어서 평균을 계산합니다.

CSV란?

CSV(Comma-Separated Values)는 쉼표(,)로 값을 구분하는 텍스트 형식입니다. 엑셀, 구글 스프레드시트에서 CSV 파일을 열 수 있어 데이터 교환의 표준 중 하나로 사용됩니다.

CSV의 특징

  • 각 행(row)은 하나의 데이터 레코드를 나타냅니다.
  • 각 열(column)은 쉼표(,)로 구분됩니다.
  • 첫 번째 행은 보통 헤더(열 이름)로 사용합니다.
  • 일반 텍스트 파일이어서 메모장으로도 열 수 있습니다.
  • 값 안에 쉼표가 있을 때는 큰따옴표로 감쌉니다: "홍길동, 주니어",95

CSV vs JSON 비교

항목 CSV JSON
형태 표 (행/열) 트리 (중첩 가능)
주 사용처 성적표, 주소록, DB 내보내기 API 응답, 설정 파일
엑셀 호환 직접 열기 가능 별도 변환 필요
중첩 데이터 불가 가능

import csv — 모듈 불러오기

파이썬은 CSV를 다루는 기능을 기본 모듈로 제공합니다. 별도 설치 없이 import csv 한 줄로 바로 사용할 수 있습니다.

import csv # 파이썬 기본 내장 모듈, 설치 불필요

csv.reader — CSV 읽기

csv.reader()는 CSV 파일을 한 행씩 읽어 리스트로 반환합니다. 각 행은 쉼표로 나뉜 값들의 리스트가 됩니다.

import csv with open("scores.csv", "r", encoding="utf-8") as f: reader = csv.reader(f) for row in reader: print(row) # ['이름', '국어', '수학', '영어'] # ['홍길동', '95', '88', '92'] # ['이순신', '100', '97', '99']
주의: 모든 값은 문자열

csv.reader로 읽은 숫자도 str 타입입니다. 계산이 필요하면 int(row[1])처럼 형 변환해야 합니다.

따라해보세요
실습 1 — CSV 파일 만들고 읽기
scores.csv 파일을 먼저 만든 뒤, reader로 읽어 출력하세요.
import csv # 먼저 파일 만들기 rows = [['이름','국어','수학'],['홍길동',95,88],['이순신',100,97]] with open("scores.csv","w",newline="",encoding="utf-8") as f: csv.writer(f).writerows(rows) # 읽기 with open("scores.csv","r",encoding="utf-8") as f: for row in csv.reader(f): print(row)
['이름', '국어', '수학'] / ['홍길동', '95', '88'] / ...
실습 2 — 헤더 건너뛰기
next()로 헤더를 건너뛰고 데이터 행만 출력하세요.
with open("scores.csv","r",encoding="utf-8") as f: reader = csv.reader(f) header = next(reader) # 헤더 행 스킵 for row in reader: print(row[0], "국어:", row[1])
홍길동 국어: 95 / 이순신 국어: 100
실습 3 — 국어 점수 합계
국어 점수를 모두 더해 합계를 출력하세요.
with open("scores.csv","r",encoding="utf-8") as f: reader = csv.reader(f) next(reader) total = sum(int(row[1]) for row in reader) print("국어 합계:", total)
국어 합계: 195

csv.writer — CSV 쓰기

csv.writer()는 파이썬 리스트를 CSV 파일에 씁니다. writerow()는 한 행을, writerows()는 여러 행을 한 번에 씁니다.

import csv students = [ ['이름', '국어', '수학', '영어'], # 헤더 ['홍길동', 95, 88, 92], ['이순신', 100, 97, 99], ['강감찬', 82, 90, 78], ] with open("scores.csv", "w", newline="", encoding="utf-8") as f: writer = csv.writer(f) writer.writerow(['이름', '국어', '수학', '영어']) # 헤더 1행 writer.writerows(students[1:]) # 나머지 행 전부
newline="" 필수

Windows에서 newline="" 없이 쓰면 행 사이에 빈 줄이 생깁니다. 항상 open(..., newline="")을 지정하세요.

csv.writer — 구분자 변경

쉼표 대신 탭이나 세미콜론을 구분자로 쓸 때는 delimiter 옵션을 지정합니다.

# 탭으로 구분하는 TSV 파일 만들기 with open("scores.tsv", "w", newline="", encoding="utf-8") as f: writer = csv.writer(f, delimiter="\t") writer.writerow(['이름', '국어', '수학']) writer.writerow(['홍길동', 95, 88])

csv.DictReader — 딕셔너리로 읽기

csv.DictReader()는 각 행을 딕셔너리로 반환합니다. 열 이름을 키로 사용하므로 row[0] 대신 row['이름']처럼 직관적으로 접근할 수 있습니다.

import csv with open("scores.csv", "r", encoding="utf-8") as f: reader = csv.DictReader(f) # 첫 행을 자동으로 헤더로 사용 for row in reader: print(row['이름'], "수학:", row['수학']) # 홍길동 수학: 88 # 이순신 수학: 97 # 강감찬 수학: 90

csv.DictWriter — 딕셔너리로 쓰기

csv.DictWriter()는 딕셔너리 리스트를 CSV 파일에 씁니다. fieldnames로 열 순서를 지정하고, writeheader()로 헤더를 먼저 씁니다.

import csv students = [ {'이름': '홍길동', '국어': 95, '수학': 88}, {'이름': '이순신', '국어': 100, '수학': 97}, ] fields = ['이름', '국어', '수학'] with open("scores.csv", "w", newline="", encoding="utf-8") as f: writer = csv.DictWriter(f, fieldnames=fields) writer.writeheader() # 헤더 행 자동 작성 writer.writerows(students) # 데이터 전부 쓰기

실용 예 — 성적표 CSV 만들기

CSV의 진짜 실력은 실제 데이터를 처리할 때 나타납니다. 성적표를 CSV로 저장하고, 읽어서 평균을 계산해 결과를 새 CSV에 저장하는 흐름을 만들어 봅니다.

import csv # 1. 성적표 CSV 저장 students = [ {'이름': '홍길동', '국어': 95, '수학': 88, '영어': 92}, {'이름': '이순신', '국어': 100, '수학': 97, '영어': 99}, {'이름': '강감찬', '국어': 82, '수학': 90, '영어': 78}, ] fields = ['이름', '국어', '수학', '영어'] with open("scores.csv", "w", newline="", encoding="utf-8") as f: writer = csv.DictWriter(f, fieldnames=fields) writer.writeheader() writer.writerows(students) # 2. 읽어서 평균 계산 후 출력 with open("scores.csv", "r", encoding="utf-8") as f: reader = csv.DictReader(f) for row in reader: scores = [int(row['국어']), int(row['수학']), int(row['영어'])] avg = sum(scores) / len(scores) print(f"{row['이름']}: 평균 {avg:.1f}") # 홍길동: 평균 91.7 # 이순신: 평균 98.7 # 강감찬: 평균 83.3

핵심 요약

CSV 핵심 개념

  • CSV는 쉼표로 열을 구분하는 표 형식의 텍스트 파일입니다.
  • import csv — 기본 내장 모듈, 설치 없이 사용 가능합니다.
  • 파일 쓸 때는 반드시 newline=""을 지정합니다 (Windows 빈 줄 방지).
  • 한글 처리 시 encoding="utf-8"을 지정합니다.
함수/클래스 용도 각 행 타입 특이사항
csv.reader CSV 읽기 list next()로 헤더 스킵
csv.writer CSV 쓰기 list 전달 newline="" 필수
csv.DictReader CSV 읽기 dict 헤더 자동 처리
csv.DictWriter CSV 쓰기 dict 전달 fieldnames + writeheader()

자주 쓰는 패턴

  • 읽기: with open(..., "r", encoding="utf-8") as f: for row in csv.DictReader(f):
  • 쓰기: with open(..., "w", newline="", encoding="utf-8") as f:
  • 숫자 계산 전: int(row['점수']) 또는 float(row['점수'])로 형 변환
  • 헤더만 뽑기: next(reader) 또는 reader.fieldnames (DictReader)
