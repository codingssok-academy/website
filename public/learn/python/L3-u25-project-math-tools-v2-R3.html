프로젝트:
성적 분석 리포트

여러 값 반환, sorted+key, f-string 포맷팅으로 학생 성적 데이터를 분석하고 리포트를 출력합니다.

이 유닛에서 만드는 것

  • 평균, 최고점 과목, 최저점 과목, 석차를 한번에 반환하는 함수를 작성합니다.
  • sorted(dict.items(), key=lambda)로 점수 기준 정렬을 구현합니다.
  • f-string의 포맷 지정자(:.1f, :>10)로 리포트 형식을 맞춥니다.
  • 여러 학생 데이터를 처리해 전체 순위표를 생성합니다.
  • 완성된 리포트를 하나의 grade_report.py로 통합합니다.

Step 1 — 여러 값 반환: 성적 통계 함수

파이썬 함수는 return a, b, c처럼 여러 값을 한번에 반환할 수 있습니다. 반환 값은 튜플로 묶이고, 호출 쪽에서 언패킹해 각 변수에 담습니다.

# Step 1: 여러 값 반환하는 성적 분석 함수 def analyze_scores(scores): """성적 딕셔너리 분석 — 평균, 최고 과목, 최저 과목 반환 scores: {'국어': 85, '수학': 92, '영어': 78} """ values = list(scores.values()) avg = sum(values) / len(values) # key=lambda로 딕셔너리를 값 기준 정렬 sorted_items = sorted(scores.items(), key=lambda x: x[1], reverse=True) top_subject = sorted_items[0][0] # 1위 과목 이름 low_subject = sorted_items[-1][0] # 꼴찌 과목 이름 return avg, top_subject, low_subject # 튜플로 반환 # 언패킹으로 받기 scores = {'국어': 85, '수학': 92, '영어': 78, '과학': 88} avg, top, low = analyze_scores(scores) print(f"평균: {avg:.1f}점") print(f"최고: {top}, 최저: {low}")
평균: 85.8점 최고: 수학, 최저: 영어

Step 2 — f-string 포맷팅으로 리포트 출력

f-string의 포맷 지정자를 사용하면 소수점 자리, 정렬, 자릿수를 세밀하게 조정할 수 있어 깔끔한 리포트를 만들 수 있습니다.

# Step 2: f-string으로 성적 리포트 생성 def print_report(name, scores): """학생 성적 리포트 출력""" avg, top, low = analyze_scores(scores) print(f"{'='*36}") print(f" 학생 성적 리포트 — {name}") print(f"{'='*36}") # 과목별 점수 출력 sorted_scores = sorted(scores.items(), key=lambda x: x[1], reverse=True) for i, (subject, score) in enumerate(sorted_scores, 1): bar = '|' * (score // 5) print(f" {subject:<4} {score:3}점 {bar}") print(f"{'─'*36}") print(f" 평균: {avg:.1f}점 | 최고: {top} | 최저: {low}") print(f"{'='*36}") # 실행 student = {'국어': 85, '수학': 92, '영어': 78, '과학': 88} print_report("홍길동", student)

Step 3 — 여러 학생 순위표 생성

여러 학생의 성적을 분석해 평균 기준으로 순위를 매기고 전체 순위표를 출력합니다. sorted()에 key=lambda를 적용합니다.

# Step 3: 전체 학생 순위표 students = { '홍길동': {'국어': 85, '수학': 92, '영어': 78}, '김철수': {'국어': 72, '수학': 68, '영어': 90}, '이영희': {'국어': 95, '수학': 88, '영어': 91}, } # 각 학생의 평균 계산 avgs = {} for name, scores in students.items(): avg, _, _ = analyze_scores(scores) avgs[name] = avg # 평균 내림차순으로 정렬 ranking = sorted(avgs.items(), key=lambda x: x[1], reverse=True) print(f"{'순위':<4} {'이름':<6} {'평균':>6}") print("─" * 20) for rank, (name, avg) in enumerate(ranking, 1): print(f"{rank}위 {name:<6} {avg:>6.1f}점")

입력평균 85.8점
출력홍길동 | 평균: 85.8점 | 등급: B
내 답안
힌트 보기
평균 계산 후 if avg >= 90: grade = 'A' 순서로 등급을 결정합니다. 마지막으로 f-string으로 출력합니다.
정답 보기
def grade_report(name, scores): avg, top, low = analyze_scores(scores) if avg >= 90: grade = 'A' elif avg >= 80: grade = 'B' elif avg >= 70: grade = 'C' else: grade = 'D' print(f"{name} | 평균: {avg:.1f}점 | 등급: {grade}") print(f" 최고: {top} | 최저: {low}") student = {'국어': 85, '수학': 92, '영어': 78, '과학': 88} grade_report('홍길동', student)

핵심 요약

  • 여러 값 반환 — return a, b, c는 튜플 반환, 호출부에서 x, y, z = fn()으로 언패킹
  • _로 불필요한 값 버리기 — avg, _, _ = fn()처럼 필요 없는 값을 _로 무시
  • sorted(items, key=lambda x: x[1]) — (키, 값) 튜플 리스트를 값 기준 정렬
  • f-string :.1f — 소수점 자리 지정: f"{85.75:.1f}" → "85.8"
  • f-string :<N / :>N — 왼쪽/오른쪽 정렬 N자리: 리포트 열 맞추기에 활용
  • enumerate(list, 1) — 인덱스를 1부터 시작해 순위 번호로 활용
