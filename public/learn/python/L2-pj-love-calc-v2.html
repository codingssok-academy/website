사랑 퍼센트 계산기

두 이름을 입력받아 재미있는 알고리즘으로 궁합 퍼센트를 계산합니다.

이 프로젝트에서 배우는 것

  • 문자열의 len()으로 글자 수를 셀 수 있습니다.
  • ord()로 문자를 숫자(아스키코드)로 변환할 수 있습니다.
  • 반복문 없이 간단한 수식으로 이름 기반 숫자를 만들 수 있습니다.
  • % (모듈로)로 범위를 0~99로 제한할 수 있습니다.
  • 재미있는 프로그램으로 코딩의 즐거움을 경험합니다.

알고리즘 설계하기

이름에서 숫자를 만드는 방법은 여러 가지입니다. 가장 간단한 방법은 이름의 글자 수와 첫 글자의 코드값을 이용하는 것입니다.

이름의 첫 글자를 ord()로 숫자로 바꾸고, 이름 길이를 곱한 뒤 % 100으로 0~99 범위로 만듭니다.

# 이름으로 점수 계산하기 name1 = input("첫 번째 이름: ") name2 = input("두 번째 이름: ") # 이름의 첫 글자 코드 + 길이로 점수 생성 score1 = ord(name1[0]) + len(name1) score2 = ord(name2[0]) + len(name2) love_percent = (score1 + score2) % 100 print(f"사랑 퍼센트: {love_percent}%")

입력이름1: 민준 / 이름2: 지아
출력XX% — 최고의 짝꿍! 또는 그냥 친구
내 답안

n1 = input("이름1: ") n2 = input("이름2: ") pct = (ord(n1[0]) + ord(n2[0])) % 100 msg = "최고의 짝꿍!" if pct >= 80 else "그냥 친구" print(f"{pct}% — {msg}")

n1 = input("이름1: ") n2 = input("이름2: ") pct = (ord(n1[0]) + len(n1) + ord(n2[0]) + len(n2)) % 100 if pct >= 75: msg = "운명적인 만남!" elif pct >= 50: msg = "좋은 궁합이에요" elif pct >= 25: msg = "노력하면 될 수 있어요" else: msg = "인연이 없는 것 같아요" print(f"{pct}% — {msg}")

핵심 요약

이 유닛에서 배운 것

  • ord(글자)로 문자를 유니코드 숫자로 변환할 수 있다
  • len(문자열)로 문자열의 글자 수를 셀 수 있다
  • 이름[0]으로 문자열의 첫 번째 글자를 가져온다
  • % 100으로 어떤 큰 숫자든 0~99 범위로 만들 수 있다
  • 같은 알고리즘도 곱하는 숫자를 바꾸면 다른 결과가 나온다
  • 재미있는 프로그램도 변수, 연산자, if/else로 만들 수 있다
