개념 지도 1 — 기초 문법

L1~L2에서 배운 기초 문법을 한눈에 정리합니다. 각 토픽의 핵심 키워드와 용도를 기억하세요.

조건문 — if / elif / else
조건이 True일 때만 실행.
여러 조건은 elif 체인.
비교: == != > < in
논리: and or not
반복문 — for / while
for: 횟수/시퀀스 순회.
while: 조건이 True인 동안.
break: 즉시 탈출.
continue: 다음 반복으로.
자료구조 비교
list: 순서 있음, 중복 허용, 변경 가능.
tuple: 순서 있음, 변경 불가.
dict: 키-값 쌍, 키는 유일.
set: 중복 없음, 집합 연산.
문자열 핵심 메서드
split(): 분리 → 리스트.
join(): 리스트 → 문자열.
strip(): 앞뒤 공백 제거.
f"{변수}": f-string 포매팅.

핵심 요약 — 기초 문법

  • 변수는 데이터를 저장하는 이름표. 타입(int, str, float, bool)에 따라 연산 방식이 다르다.
  • if/elif/else로 조건 분기, for/while로 반복. 들여쓰기(indent) 4칸 필수.
  • 자료구조 선택 기준: 순서 필요 → list, 키-값 → dict, 중복 제거 → set.

개념 지도 2 — 함수와 클래스

함수는 코드를 묶어 재사용하고, 클래스는 데이터와 함수를 하나의 단위로 묶습니다.

함수 종류

일반 함수 def
이름 있음, 여러 줄 가능.
기본값 매개변수: def f(x=0)
가변 인자: def f(*args)
키워드 인자: def f(**kwargs)
람다 함수 lambda
한 줄짜리 익명 함수.
lambda x: x * 2
sorted(), map(), filter()와 함께 자주 쓰임.

클래스 구조

기본 클래스 class
__init__: 생성자, 속성 초기화.
self: 인스턴스 자신을 가리킴.
메서드: 클래스 안의 함수.
인스턴스: dog = Dog("바둑이")
상속 inheritance
class Cat(Animal):
부모 메서드 재사용.
super().__init__()로 부모 초기화.
오버라이드: 같은 이름으로 재정의.

핵심 요약 — 함수와 클래스

  • 함수: 반복되는 코드를 묶어 이름을 붙인 것. def로 정의, return으로 값 반환.
  • 람다: 한 줄짜리 익명 함수. sorted(data, key=lambda x: x[1]) 패턴이 가장 자주 쓰임.
  • 클래스: 속성(데이터) + 메서드(함수)를 하나로 묶음. __init__에서 self.속성 초기화.

개념 지도 3 — 파일·알고리즘·모듈

알고리즘 3종

정렬 O(n log n)
sorted(): 새 리스트 반환.
list.sort(): 제자리 정렬.
key=lambda x: x[1]: 기준 설정.
reverse=True: 내림차순.
탐색 순차 O(n)
순차 탐색: 처음부터 하나씩.
이진 탐색: 정렬된 리스트, 반씩.
value in list: O(n) 순차.
value in set: O(1) 해시.
재귀 recursion
자기 자신을 호출하는 함수.
반드시 기저 조건(base case) 필요.
팩토리얼, 피보나치, 트리 탐색.
스택 오버플로 주의.

핵심 요약 — 파일·알고리즘·모듈

  • 파일 I/O: with open(파일명, 모드) as f: 패턴 사용. with는 자동으로 파일을 닫아줌.

자주 쓰는 패턴 모음

실제 코딩에서 가장 많이 반복되는 패턴들입니다. 눈에 익혀두면 문제 풀 때 바로 쓸 수 있습니다.

Pattern 01
리스트 컴프리헨션 — 짧고 빠른 리스트 생성
# 일반 for 루프 squares = [] for i in range(1, 6): squares.append(i ** 2) # 리스트 컴프리헨션 (같은 결과, 한 줄) squares = [i ** 2 for i in range(1, 6)] # 조건 필터링 포함 evens = [i for i in range(20) if i % 2 == 0]
Pattern 02
딕셔너리로 빈도 세기 — Counter vs 수동
from collections import Counter words = ["apple", "banana", "apple", "cherry", "banana", "apple"] # 방법 1: Counter (추천) count = Counter(words) print(count.most_common(2)) # [('apple', 3), ('banana', 2)] # 방법 2: dict.get() 수동 count = {} for w in words: count[w] = count.get(w, 0) + 1
Pattern 03
파일 읽기/쓰기 — with 문 필수 패턴
# 쓰기 with open("data.txt", "w", encoding="utf-8") as f: f.write("첫 번째 줄\n") f.write("두 번째 줄\n") # 읽기 (줄 단위) with open("data.txt", "r", encoding="utf-8") as f: for line in f: print(line.strip()) # 개행 제거

Q1 다음 코드의 출력 결과는? 쉬움
아래 코드를 실행하면 무엇이 출력되는가?
data = [3, 1, 4, 1, 5, 9, 2] result = [x for x in data if x > 3] print(sorted(result))
A[4, 5, 9]
B[9, 5, 4]
C[3, 4, 5, 9]
D[4, 5, 9, 2]
정답 확인
정답: A — [4, 5, 9]
리스트 컴프리헨션에서 x > 3 조건으로 4, 5, 9가 선택됩니다. sorted()는 오름차순 정렬이므로 [4, 5, 9]입니다. 3은 조건을 만족하지 않아 제외됩니다.
Q2 딕셔너리 get() vs 직접 접근 — 차이는? 보통
아래 코드에서 (가)와 (나)의 차이로 올바른 것은?
d = {"name": "민지", "age": 15} # (가) val_a = d["score"] # (나) val_b = d.get("score", 0)
A(가)는 None을 반환하고, (나)는 0을 반환한다.
B(가)는 KeyError가 발생하고, (나)는 0을 반환한다.
C(가)와 (나) 모두 0을 반환한다.
D(가)는 KeyError가 발생하고, (나)도 KeyError가 발생한다.
정답 확인
정답: B — (가) KeyError, (나) 0 반환
딕셔너리에 없는 키를 d["key"]로 접근하면 KeyError가 발생합니다. d.get("key", 기본값)은 키가 없을 때 기본값을 반환하므로 안전합니다. 실무에서는 .get()을 선호합니다.
Q3 재귀 함수의 기저 조건 보통
아래 재귀 함수에서 기저 조건(base case)은 어느 부분인가?
def factorial(n): if n == 0: # (가) return 1 # (나) return n * factorial(n - 1) # (다)
A(가)와 (나) 모두 기저 조건이다.
B(다)가 기저 조건이다.
C기저 조건이 없으므로 무한 재귀가 발생한다.
D(다)가 재귀 호출이고 (가)+(나)가 기저 조건이다.
정답 확인
정답: D — (가)+(나)가 기저 조건, (다)가 재귀 호출
기저 조건은 재귀를 멈추는 조건입니다. n == 0일 때 return 1로 재귀가 끝납니다. (다)의 factorial(n-1)은 자기 자신을 호출하는 재귀 호출입니다. 기저 조건이 없으면 RecursionError가 발생합니다.

A바둑이: ...

Q5 set 집합 연산 — 활용 문제 보통
두 반의 출석 명단에서 두 반 모두 참석한 학생만 출력하려면?
a_class = {"민지", "지훈", "수현", "태양"} b_class = {"수현", "태양", "하늘", "미래"} # 두 반 모두 참석한 학생: both = ???
Aa_class + b_class
Ba_class | b_class
Ca_class & b_class
Da_class - b_class
정답 확인
정답: C — a_class & b_class (교집합)
&는 교집합(intersection): 두 집합에 모두 있는 원소. 결과: {'수현', '태양'}. |는 합집합(두 반 중 하나라도 있으면), -는 차집합(a에만 있는 것)입니다.
