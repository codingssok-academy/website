프로젝트:
자판기 시뮬레이터

클래스로 자판기를 설계합니다. 상품 목록, 잔액, 거스름돈 계산, 재고 관리, 매출 통계까지 실제 자판기의 모든 기능을 구현합니다.

이 프로젝트에서 만드는 것

  • __init__에서 상품 딕셔너리(가격, 재고)와 잔액 속성을 초기화합니다.
  • insert_coin()으로 동전을 투입하고 누적 잔액을 관리합니다.
  • select()에서 잔액 확인, 재고 확인, 거스름돈 계산을 모두 처리합니다.
  • 판매 기록을 리스트에 저장하고 show_stats()로 매출 통계를 출력합니다.
  • 재고 부족시 자동으로 경고 메시지를 출력합니다.

Step 1 — VendingMachine 클래스 설계

자판기 클래스의 핵심은 상품 딕셔너리입니다. 상품 이름을 키로, 가격과 재고를 담은 딕셔너리를 값으로 저장합니다. 잔액과 매출도 인스턴스 속성으로 관리합니다.

class VendingMachine: def __init__(self): # 상품: {이름: {"price": 가격, "stock": 재고}} self.items = { "콜라": {"price": 1500, "stock": 10}, "사이다": {"price": 1200, "stock": 8}, "물": {"price": 800, "stock": 15}, "커피": {"price": 2000, "stock": 5}, "주스": {"price": 1800, "stock": 7} } self.balance = 0 # 현재 투입된 금액 self.total_sales = 0 # 총 매출 self.transaction_log = [] # 판매 기록 리스트 def show_menu(self): """현재 판매 중인 상품 목록 출력""" print("\n=== 자판기 메뉴 ===") for name, info in self.items.items(): status = "품절" if info["stock"] == 0 else f"재고:{info['stock']}" print(f" {name:6} {info['price']:5}원 [{status}]") print(f"투입 금액: {self.balance}원") def insert_coin(self, amount): """동전/지폐 투입""" valid = [100, 500, 1000, 5000, 10000] if amount not in valid: print(f"{amount}원은 사용 불가. 100/500/1000/5000/10000원만 가능") return self.balance += amount print(f"{amount}원 투입. 현재 잔액: {self.balance}원") # 테스트 vm = VendingMachine() vm.show_menu() vm.insert_coin(1000) vm.insert_coin(500)
=== 자판기 메뉴 === 콜라 1500원 [재고:10] 사이다 1200원 [재고:8] 물 800원 [재고:15] 커피 2000원 [재고:5] 주스 1800원 [재고:7] 투입 금액: 0원 1000원 투입. 현재 잔액: 1000원 500원 투입. 현재 잔액: 1500원

Step 2 — 상품 구매와 매출 통계

상품을 선택하면 잔액과 재고를 확인하고, 구매 성공 시 잔액에서 가격을 빼고 거스름돈을 계산합니다. 모든 거래는 transaction_log 리스트에 기록됩니다.

def select(self, name): """상품 선택 및 구매 처리""" if name not in self.items: print(f"'{name}'은 없는 상품입니다.") return item = self.items[name] if item["stock"] == 0: print(f"{name} 품절!") return if self.balance < item["price"]: shortage = item["price"] - self.balance print(f"잔액 부족. {shortage}원 더 필요합니다.") return # 구매 처리 self.balance -= item["price"] item["stock"] -= 1 self.total_sales += item["price"] self.transaction_log.append(name) print(f"{name} 구매 완료! 잔액: {self.balance}원") if item["stock"] <= 2: print(f"[경고] {name} 재고 {item['stock']}개 남음!") def refund(self): """잔액 반환""" if self.balance == 0: print("반환할 금액이 없습니다.") else: print(f"{self.balance}원 반환됩니다.") self.balance = 0 def restock(self, name, qty): """재고 추가 (관리자용)""" if name in self.items: self.items[name]["stock"] += qty print(f"{name} 재고 {qty}개 추가. 현재: {self.items[name]['stock']}개") def show_stats(self): """매출 통계 출력""" print("\n=== 매출 통계 ===") print(f"총 매출: {self.total_sales}원") print(f"총 판매: {len(self.transaction_log)}건") if self.transaction_log: # 상품별 판매 횟수 집계 counts = {} for item in self.transaction_log: counts[item] = counts.get(item, 0) + 1 best = max(counts, key=counts.get) print(f"인기 상품: {best} ({counts[best]}회)") # 전체 테스트 vm = VendingMachine() vm.insert_coin(1000) vm.insert_coin(1000) vm.select("콜라") vm.select("물") vm.refund() vm.show_stats()
1000원 투입. 현재 잔액: 1000원 1000원 투입. 현재 잔액: 2000원 콜라 구매 완료! 잔액: 500원 물 구매 완료! 잔액: 0원 (500원 - 800원 = 부족 → 물 800원이므로 잔액 부족) 0원 반환됩니다. === 매출 통계 === 총 매출: 1500원 총 판매: 1건 인기 상품: 콜라 (1회)

def affordable_items(self): buyable = [n for n, info in self.items.items() if info["price"] <= self.balance and info["stock"] > 0] if buyable: print(f"살 수 있는 상품: {', '.join(buyable)}") else: print("현재 잔액으로 살 수 있는 상품이 없습니다.")

핵심 요약

  • 클래스 — 관련 데이터(속성)와 기능(메서드)을 하나로 묶는 설계 단위
  • self.items 딕셔너리로 여러 상품의 가격과 재고를 한 번에 관리
  • self.transaction_log 리스트로 판매 이력을 추적
  • dict.get(key, 기본값) — 키가 없을 때 기본값 반환 (KeyError 방지)
  • 재고 2개 이하 경고, 품절 처리 — 방어적 프로그래밍의 기본
  • max(dict, key=dict.get) — 가장 많이 팔린 상품 찾기
