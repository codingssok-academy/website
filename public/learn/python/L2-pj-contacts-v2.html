프로젝트:
연락처 관리

딕셔너리로 이름과 전화번호를 저장하고, 추가/검색/삭제/전체보기 기능을 갖춘 연락처 앱을 만듭니다.

이 프로젝트에서 배우는 것

  • dict[name] = number로 연락처를 추가합니다.
  • dict.get(name)으로 이름을 검색합니다.
  • del dict[name]으로 연락처를 삭제합니다.
  • for name in dict로 전체 연락처를 출력합니다.
  • 이름 부분 검색: keyword in name으로 포함 여부 확인.

Step 1 — 연락처 추가/조회/삭제

딕셔너리를 이용한 연락처 관리의 핵심은 CRUD(Create, Read, Update, Delete)입니다. 각 동작을 함수로 만들어 정리합니다.

# 연락처 딕셔너리 contacts = {} def add_contact(name, number): contacts[name] = number print(f"{name} 추가됨") def find_contact(name): number = contacts.get(name) if number: print(f"{name}: {number}") else: print("연락처가 없습니다") def delete_contact(name): if name in contacts: del contacts[name] print(f"{name} 삭제됨") else: print("연락처가 없습니다") add_contact("김철수", "010-1234-5678") find_contact("김철수") delete_contact("김철수")
김철수 추가됨 김철수: 010-1234-5678 김철수 삭제됨

Step 2 — 완성 코드 & 도전 문제

while 메뉴로 추가/검색/삭제/전체보기를 선택하는 완전한 연락처 앱을 완성합니다.

# 완성된 연락처 앱 contacts = {} while True: choice = input("\n1.추가 2.검색 3.삭제 4.전체보기 5.종료: ") if choice == "1": name = input("이름: ") num = input("번호: ") contacts[name] = num print(f"{name} 저장됨") elif choice == "2": kw = input("검색할 이름: ") found = [n for n in contacts if kw in n] for name in found: print(f" {name}: {contacts[name]}") if not found: print("검색 결과 없음") elif choice == "3": name = input("삭제할 이름: ") if name in contacts: del contacts[name] print(f"{name} 삭제됨") elif choice == "4": for name, num in sorted(contacts.items()): print(f" {name}: {num}") elif choice == "5": break

핵심 요약

  • dict[key] = value — 추가(없으면 생성, 있으면 수정)
  • dict.get(key) — 안전 조회, 없으면 None 반환
  • del dict[key] — 삭제 (없으면 KeyError 발생)
  • sorted(dict.items()) — 키 기준 정렬 후 순회
  • keyword in name — 부분 문자열 검색
