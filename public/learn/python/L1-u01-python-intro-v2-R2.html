Python의 탄생

1989년 크리스마스 연휴, 네덜란드의 프로그래머 귀도 반 로섬(Guido van Rossum)은 취미로 새 프로그래밍 언어를 만들기 시작했습니다. 당시 그는 네덜란드 국립 수학·컴퓨터과학 연구소(CWI)에서 ABC라는 교육용 언어 프로젝트에 참여하고 있었습니다.

ABC 언어에는 좋은 아이디어가 많았지만, 실용성이 부족했습니다. 귀도는 ABC의 장점(읽기 쉬운 문법, 들여쓰기 기반 구조)은 살리고, 단점(확장성 부족, 운영체제 접근 불가)은 보완한 언어를 직접 설계했습니다.

이 언어의 이름은 뱀이 아닙니다. 귀도가 좋아하던 영국 BBC 코미디 쇼 "Monty Python's Flying Circus"에서 따왔습니다. 재미있고 기억하기 쉬운 이름을 원했기 때문입니다.

1991년 2월, Python 0.9.0이 공개되었습니다. 이후 30년 넘게 발전하며, 2024년 현재 세계에서 가장 인기 있는 프로그래밍 언어 중 하나가 되었습니다.

Python이 사용되는 분야

Python은 범용 프로그래밍 언어입니다. 특정 분야에 국한되지 않고 다양한 곳에서 활용됩니다.

쉽게 말하면, Python은 "사람이 읽기 편한 언어"입니다. 다른 프로그래밍 언어가 컴퓨터에게 맞춰서 복잡한 기호를 사용하는 반면, Python은 영어 문장처럼 자연스럽게 읽힙니다.

1
인공지능 / 머신러닝
TensorFlow, PyTorch, scikit-learn 등의 라이브러리로 AI 모델을 학습시킵니다. ChatGPT도 Python으로 개발되었습니다.
2
데이터 분석 / 과학
pandas, NumPy, matplotlib로 대량의 데이터를 처리하고 시각화합니다. 연구소와 기업에서 가장 많이 사용합니다.
3
웹 개발
Django, Flask, FastAPI로 웹 서비스를 만듭니다. Instagram, Pinterest가 Python으로 만들어졌습니다.
4
자동화 / 스크립트
반복 작업을 자동화합니다. 파일 정리, 엑셀 처리, 이메일 발송 등을 코드 몇 줄로 해결합니다.
5
게임 개발
Pygame으로 2D 게임을 만들 수 있습니다. 간단한 게임 프로토타입 제작에 적합합니다.
6
교육
문법이 간결하여 프로그래밍 입문 언어로 가장 많이 선택됩니다. 전 세계 대학 CS 입문 과목의 80% 이상이 Python을 사용합니다.

Python의 5가지 핵심 특징

1
1. 읽기 쉬운 문법
영어 문장처럼 읽힙니다. 들여쓰기로 코드 블록을 구분하여 누구나 깔끔한 코드를 작성하게 됩니다.
2
2. 인터프리터 언어
코드를 한 줄씩 바로 실행합니다. 컴파일(번역) 단계 없이 결과를 즉시 확인할 수 있습니다.
3
3. 동적 타이핑
변수를 만들 때 자료형을 선언하지 않아도 됩니다. x = 10이라고 쓰면 Python이 알아서 정수로 인식합니다.
4
4. 풍부한 라이브러리
"배터리 포함(Batteries Included)" 철학. 수학, 파일, 네트워크, 데이터 처리 등 수만 개의 라이브러리가 준비되어 있습니다.
5
5. 크로스 플랫폼
Windows, macOS, Linux 어디서든 같은 코드가 동작합니다. 운영체제를 바꿔도 코드를 수정할 필요가 없습니다.
확인해봅시다 Python이 인터프리터 언어라는 것은 어떤 의미입니까? 컴파일 언어와의 차이를 자신의 말로 설명해 보십시오.

인터프리터 vs 컴파일러

프로그래밍 언어는 코드를 실행하는 방식에 따라 크게 두 가지로 나뉩니다.

C는 소스 코드 전체를 먼저 기계어로 번역(컴파일)한 뒤 실행합니다. Python은 코드를 한 줄씩 읽으며 바로 실행합니다. 덕분에 Python은 결과를 즉시 확인할 수 있지만, 실행 속도는 C보다 느립니다.

자주 하는 실수
  • "Python은 뱀 이름에서 따왔다" — 아닙니다! 영국 코미디 쇼 "Monty Python"에서 따왔습니다.
  • "인터프리터 언어는 느리니까 안 좋다" — 느린 것은 사실이지만, 개발 속도가 빠르고 배우기 쉬운 장점이 훨씬 큽니다.
  • "Python 2와 Python 3은 같다" — 호환되지 않습니다. 반드시 Python 3을 사용해야 합니다.

Python 프로그램의 구조

Python 프로그램은 C와 달리 보일러플레이트(boilerplate)가 없습니다. 복잡한 선언 없이 바로 코드를 작성할 수 있습니다.

C 프로그램
Python
1#include <stdio.h>
2
3class="s-type">int main(void) {
4 class="s-type">int a = 10;
5 class="s-type">int b = 20;
6 printf("%d\n", a + b);
7 return 0;
8}
Python 프로그램
Python
1a = 10
2b = 20
3print(a + b)

C는 #include, main 함수, return 0, 세미콜론, 중괄호가 필요합니다. Python은 이 모든 것이 불필요합니다. 하고 싶은 것만 적으면 됩니다.

Python 실행 과정

Python 코드가 실행되기까지 내부적으로 3단계를 거칩니다.

1
1단계: 소스 코드 (.py)
개발자가 작성한 텍스트 파일입니다. hello.py처럼 .py 확장자를 사용합니다.
2
2단계: 바이트코드 (.pyc)
Python 인터프리터(CPython)가 소스 코드를 바이트코드로 변환합니다. __pycache__ 폴더에 .pyc 파일로 저장됩니다.
3
3단계: PVM에서 실행
Python Virtual Machine(PVM)이 바이트코드를 한 줄씩 읽으며 실행합니다. 이 과정이 "인터프리팅"입니다.
TIP
컴파일도 하고 인터프리팅도 한다?
"Python은 인터프리터 언어"라고 하지만, 내부적으로는 바이트코드로 컴파일하는 단계가 있습니다. 다만 이 과정이 자동이라 개발자가 신경 쓸 필요가 없을 뿐입니다. C의 컴파일은 개발자가 직접 gcc 명령을 실행해야 합니다.

느린데 왜 인기가 많을까?
Python은 실행 속도가 C보다 수십 배 느립니다. 그런데도 인기 1위인 이유는 "개발 속도"가 빠르기 때문입니다. 프로그램을 만드는 시간이 짧으면, 사람의 시간을 절약할 수 있습니다. 속도가 중요한 부분만 C로 작성하고, 나머지는 Python으로 작성하는 방식도 널리 사용됩니다.
