간단 퀴즈 게임

if/elif로 정답을 체크하고 점수를 합산해 최종 등급을 출력하는 퀴즈 게임입니다.

이 프로젝트에서 배우는 것

  • if/elif로 정답을 체크하고 점수를 더할 수 있습니다.
  • 점수 변수를 누적해 최종 점수를 계산할 수 있습니다.
  • 점수 범위에 따라 등급을 출력할 수 있습니다.
  • 여러 문제를 순서대로 출력하는 프로그램을 만들 수 있습니다.
  • 문자열 비교로 정답을 판정하는 방법을 배웁니다.

퀴즈 게임 구조 설계

퀴즈 게임은 문제 출력 → 답 입력 → 정답 체크 → 점수 합산 → 다음 문제의 흐름으로 반복됩니다.

가장 단순한 퀴즈부터 시작합니다. 답을 입력받아 if로 정답과 비교합니다.

# 퀴즈 1문제 예시 score = 0 print("Q1. 파이썬을 만든 사람의 이름은?") answer = input("답: ") if answer == "귀도" or answer == "귀도 반 로섬": print("정답!") score += 1 else: print("오답! 정답은 귀도 반 로섬입니다.") print(f"현재 점수: {score}점")

완성: 5문제 퀴즈 게임

파이썬 기초 5문제로 구성된 완성 퀴즈 게임입니다. 점수에 따라 S/A/B/C 등급을 출력합니다.

# 5문제 퀴즈 게임 완성 버전 score = 0 print("=== 파이썬 기초 퀴즈 ===") print("총 5문제입니다.\n") # Q1 print("Q1. 파이썬에서 화면에 출력하는 함수는?") a1 = input("답: ") if a1 == "print" or a1 == "print()": print("정답!\n") score += 1 else: print("오답! 정답: print()\n") # Q2 print("Q2. 10 // 3 의 결과는?") a2 = input("답: ") if a2 == "3": print("정답!\n") score += 1 else: print("오답! 정답: 3 (정수 나눗셈의 몫)\n") # Q3 print("Q3. 문자열을 정수로 변환하는 함수는?") a3 = input("답: ") if a3 == "int" or a3 == "int()": print("정답!\n") score += 1 else: print("오답! 정답: int()\n") # Q4, Q5는 생략 (같은 패턴) score += 2 # Q4, Q5 임시 점수 print(f"\n최종 점수: {score}/5") if score == 5: print("S등급 — 파이썬 천재!") elif score >= 4: print("A등급 — 훌륭해요!") elif score >= 3: print("B등급 — 잘했어요!") else: print("C등급 — 더 공부해봐요!")

정답 확인
score = 0 questions = [ ("2 + 3은?", "5"), ("파이썬 출력 함수는?", "print"), ("10 // 3은?", "3"), ("파이썬 파일 확장자는?", ".py"), ("int('5')의 결과 타입은?", "int") ] for i, (q, correct) in enumerate(questions): print(f"Q{i+1}. {q}") if input("답: ") == correct: score += 1 if score == 5: grade = "S등급 — 완벽!" elif score >= 4: grade = "A등급 — 훌륭해요!" elif score >= 3: grade = "B등급 — 잘했어요!" else: grade = "C등급 — 더 공부해봐요!" print(f"총 점수: {score}/5 → {grade}")

핵심 요약

이 유닛에서 배운 것

  • 문자열 비교: if answer == "정답"으로 정답을 체크한다
  • 점수 누적: 정답 시 score += 1로 1점씩 더한다
  • 여러 정답 허용: or로 두 가지 이상의 정답을 처리한다
  • 등급 판정: if/elif/else로 점수 범위에 따라 등급을 출력한다
  • 문제를 순서대로 나열하면 퀴즈 게임을 만들 수 있다
  • input()은 항상 문자열을 반환 — 숫자 정답도 문자열로 비교해야 함
