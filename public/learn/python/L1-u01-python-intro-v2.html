Python이란?

Python의 탄생 배경, 활용 분야, 핵심 특징, 인터프리터와 컴파일러의 차이를 배웁니다.

  • Python의 핵심 특징 5가지를 설명할 수 있습니다.

Python 탄생 배경

Python은 1991년 네덜란드의 귀도 반 로섬(Guido van Rossum)이 만들었습니다. "누구나 쉽게 읽을 수 있는 코드"를 목표로 설계되었습니다.

이름은 영국 코미디 "Monty Python's Flying Circus"에서 따왔습니다.

따라해보세요
1
Python 공식 사이트(python.org)에 접속해서 현재 최신 버전을 확인하세요.
3.12 이상의 버전 번호가 보이면 성공
2
터미널(명령 프롬프트)에서 Python 버전을 확인하세요.
python --version
Python 3.x.x 형태로 출력되면 성공
3
Python 대화형 모드에 진입해보세요.
python
>>> 프롬프트가 나타나면 성공 (exit()로 종료)

Python 활용 분야

Python은 웹, 데이터 분석, 인공지능, 자동화 등 거의 모든 분야에서 사용됩니다. 배우기 쉬워서 입문자에게 최적입니다.

따라해보세요
1
Python 대화형 모드에서 간단한 계산을 해보세요.
>>> 10 + 20
30이 출력되면 성공
2
문자열을 반복해보세요.
>>> "Python" * 3
'PythonPythonPython'이 출력되면 성공
3
Python으로 첫 출력을 해보세요.
>>> print("Hello, Python!")
Hello, Python! 이 출력되면 성공

Python 핵심 특징 5가지

Python이 전 세계에서 가장 인기 있는 언어가 된 이유입니다. 다섯 가지 핵심 특징을 알아봅니다.

따라해보세요
1
Python이 설치된 경로를 확인해보세요.
>>> import sys >>> print(sys.executable)
Python 설치 경로가 출력되면 성공
2
Python에 내장된 기능 수를 확인해보세요.
>>> print(len(dir(__builtins__)))
150 이상의 숫자가 출력되면 성공
3
Python의 철학(The Zen of Python)을 읽어보세요.
>>> import this
19개의 Python 철학 문장이 출력되면 성공

인터프리터 vs 컴파일러

프로그래밍 언어는 실행 방식에 따라 두 가지로 나뉩니다. Python은 인터프리터 방식을 사용합니다.

인터프리터는 코드를 한 줄씩 실행하고, 컴파일러는 전체를 먼저 번역한 뒤 실행합니다.

따라해보세요
1
일부러 오류를 내서 인터프리터가 어떻게 반응하는지 확인하세요.
>>> print("안녕" # 괄호를 닫지 않으면?
SyntaxError가 나타나면 인터프리터가 오류를 잡은 것
2
두 줄을 연속으로 실행해보세요.
>>> print("첫째 줄") >>> print("둘째 줄")
한 줄씩 즉시 실행되는 것을 확인
3
Python이 인터프리터인지 직접 확인해보세요.
>>> import platform >>> print(platform.python_implementation())
CPython이 출력되면 성공 (C로 만든 인터프리터)

핵심 요약

이 유닛에서 배운 것

  • Python은 1991년 귀도 반 로섬이 만든 프로그래밍 언어다
  • 웹, 데이터, AI, 자동화, 게임, IoT 등 다양한 분야에서 사용된다
  • 쉬운 문법, 무료, 풍부한 라이브러리, 크로스 플랫폼, 큰 커뮤니티가 핵심 특징이다
  • Python은 인터프리터 방식으로 코드를 한 줄씩 번역하고 실행한다
  • 컴파일러는 전체 코드를 먼저 번역한 뒤 실행하는 방식이다
