print() 함수

print()는 화면에 글자를 출력하는 함수입니다. 괄호 안에 따옴표로 감싼 텍스트를 넣으세요.

따라해보세요
1
아래 코드를 그대로 입력하고 실행하세요.
print("Hello, Python!")
Hello, Python! 이 출력되면 성공
2
따옴표 안의 내용을 바꿔보세요.
print("나는 파이썬을 배우고 있어요")
따옴표 안 내용이 그대로 출력됩니다
3
쉼표로 여러 값을 출력해보세요.
print("안녕", "세상", 2026)
안녕 세상 2026 — 쉼표 사이에 자동 공백

Q2

쉬움

이스케이프 문자

\n은 줄바꿈, \t는 탭입니다. 하나의 print()로 여러 줄을 출력할 수 있습니다.

따라해보세요
1
\n으로 줄바꿈을 만들어보세요.
print("첫째 줄\n둘째 줄\n셋째 줄")
3줄로 나눠서 출력됩니다
2
\t로 칸을 맞춰보세요.
print("이름\t점수") print("민수\t95") print("서연\t88")
탭으로 깔끔하게 정렬됩니다
3
따옴표 안에 따옴표를 넣어보세요.
print("파이썬이 말했다: \"안녕!\"")
\" 로 따옴표를 출력할 수 있습니다
