재귀 함수
— 자기 자신을 호출하는 함수

함수가 스스로를 다시 부르는 신기한 구조, 재귀(recursion)를 배웁니다. 팩토리얼과 피보나치 수열로 개념을 익히고, 종료 조건(base case)이 왜 반드시 필요한지 확인합니다.

이 유닛에서 배우는 것

  • 재귀(recursion)가 무엇인지, 어떻게 함수가 자기 자신을 호출하는지 이해합니다.
  • 종료 조건(base case)이 왜 반드시 있어야 하는지 알 수 있습니다.
  • 팩토리얼(n!)을 재귀로 구현하고 호출 흐름을 추적합니다.
  • 피보나치 수열을 재귀로 구현합니다.
  • 재귀와 반복문(for/while)을 비교해 언제 어느 쪽이 나은지 판단합니다.
  • 무한 재귀가 왜 위험한지, RecursionError를 직접 확인합니다.

재귀(Recursion)란?

재귀는 함수가 자기 자신을 다시 호출하는 방법입니다. 큰 문제를 같은 구조의 작은 문제로 쪼개고, 더 이상 쪼갤 수 없을 때 답을 반환합니다.

모든 재귀 함수는 반드시 두 가지를 가집니다.

  • 종료 조건(base case) — 재귀를 멈추는 조건. 없으면 무한 루프처럼 영원히 호출됩니다.
  • 재귀 호출(recursive case) — 문제를 조금 더 작게 만들어 자기 자신을 다시 부릅니다.

가장 간단한 예시 — 카운트다운

def countdown(n): if n == 0: # base case: n이 0이면 멈춤 print("발사!") return print(n) countdown(n - 1) # recursive case: n을 1 줄여서 다시 호출 countdown(3)
3 2 1 발사!

1 2 3 순서로 출력되면 성공

팩토리얼 — n!

팩토리얼은 1부터 n까지 모든 정수를 곱한 값입니다. 수학에서 n!으로 씁니다.

팩토리얼의 핵심은 n! = n × (n-1)! 이라는 것입니다. 즉, 큰 팩토리얼을 작은 팩토리얼로 표현할 수 있어서 재귀와 딱 맞습니다.

def factorial(n): if n == 1: # base case: 1! = 1 return 1 return n * factorial(n - 1) # recursive case print(factorial(4)) # 24 print(factorial(5)) # 120
24 120

재귀 공식 구조

호출 추적 (factorial(4))

실제로 어떤 순서로 실행되는지 표로 확인해봅니다.

호출 순서함수조건반환값
1번째factorial(4)4 != 1 → 재귀4 × factorial(3)
2번째factorial(3)3 != 1 → 재귀3 × factorial(2)
3번째factorial(2)2 != 1 → 재귀2 × factorial(1)
4번째factorial(1)1 == 1 → base case1 (종료)
거슬러 올라가며 계산2×1=2, 3×2=6, 4×6=2424
따라해보세요 — 팩토리얼
1
factorial 함수를 입력하고 factorial(6)과 factorial(10)을 실행하세요.

def factorial(n): if n == 0: return 1 return n * factorial(n - 1)
factorial(0) = 1, factorial(4) = 24 이면 성공

피보나치 수열

피보나치 수열은 앞 두 수를 더해서 다음 수를 만드는 수열입니다. 1, 1, 2, 3, 5, 8, 13, 21 ...

규칙: fib(n) = fib(n-1) + fib(n-2). base case는 n == 1이나 n == 2일 때 1을 반환합니다.

def fib(n): if n <= 2: # base case: 1번째, 2번째는 모두 1 return 1 return fib(n - 1) + fib(n - 2) # recursive case for i in range(1, 9): print(f"fib({i}) = {fib(i)}")
fib(1) = 1 fib(2) = 1 fib(3) = 2 fib(4) = 3 fib(5) = 5 fib(6) = 8 fib(7) = 13 fib(8) = 21

종료 조건(Base Case)이 없으면?

base case가 없으면 함수가 영원히 자기 자신을 호출합니다. Python은 일정 깊이 이상 호출되면 자동으로 RecursionError를 발생시킵니다.

# base case 없는 잘못된 예시 def bad_func(n): print(n) bad_func(n - 1) # 절대 멈추지 않음! bad_func(5) # RecursionError: maximum recursion depth exceeded
무한 재귀 경고

Python의 기본 재귀 한도는 약 1000번입니다. 그 이상 호출되면 RecursionError가 발생합니다. 재귀 함수를 만들 때는 항상 base case가 반드시 도달 가능한지 확인하세요.

재귀 vs 반복문 비교

재귀로 짤 수 있는 것은 대부분 for/while로도 짤 수 있습니다. 어떤 차이가 있는지 팩토리얼로 직접 비교해봅니다.

팩토리얼 — 재귀 버전

def factorial_recursive(n): if n == 1: return 1 return n * factorial_recursive(n - 1)

팩토리얼 — 반복문 버전

def factorial_loop(n): result = 1 for i in range(1, n + 1): result *= i return result
항목재귀반복문
코드 길이 짧고 수학식과 비슷 조금 길지만 명확
속도 함수 호출 비용이 있어 느릴 수 있음 일반적으로 더 빠름
메모리 호출마다 스택 사용 변수 하나로 처리
무한 루프 위험 base case 실수 시 RecursionError 조건 실수 시 무한 루프
가독성 수학적 정의와 1:1 대응 절차가 명확
언제 유리 트리, 폴더 탐색 등 구조가 재귀적일 때 단순 반복, 성능이 중요할 때
언제 재귀를 쓸까?

파일 폴더 안에 또 폴더가 있고, 그 안에 또 폴더가 있는 구조처럼 문제가 스스로 비슷한 구조를 반복할 때 재귀가 자연스럽습니다. 단순히 1부터 n까지 더하는 것은 반복문이 훨씬 낫습니다.

거듭제곱 재귀 — power(base, exp)
쉬움
power(base, exp) 함수를 재귀로 작성하세요. base를 exp번 곱한 값을 반환합니다. base case는 exp == 0일 때 1을 반환하는 것입니다.
입력 power(2, 3)
출력 8
입력 power(3, 4)
출력 81
힌트 보기
2^3 = 2 * 2^2 = 2 * (2 * 2^1) = ... 처럼 exp를 1씩 줄여가면 됩니다. base case는 exp가 0일 때.
정답 보기
def power(base, exp): if exp == 0: return 1 return base * power(base, exp - 1) print(power(2, 3)) # 8 print(power(3, 4)) # 81
2
문자열 뒤집기 재귀 — reverse_str(s)
보통
문자열을 재귀로 뒤집는 reverse_str(s)를 작성하세요. base case는 문자열 길이가 0이나 1일 때 그대로 반환하는 것입니다. 재귀 호출에서는 첫 글자를 맨 뒤로 보냅니다.
입력 reverse_str("hello")
출력 "olleh"
힌트 보기
reverse_str("hello") = reverse_str("ello") + "h" 처럼 나머지를 뒤집고 첫 글자를 맨 뒤에 붙이면 됩니다.
정답 보기
def reverse_str(s): if len(s) <= 1: return s return reverse_str(s[1:]) + s[0] print(reverse_str("hello")) # olleh

리스트 합계 재귀 — sum_list(lst)
보통
리스트의 모든 원소 합을 재귀로 계산하는 sum_list(lst)를 작성하세요. base case는 리스트가 비어 있을 때 0을 반환하는 것입니다.
입력 sum_list([1, 2, 3, 4, 5])
출력 15
힌트 보기
sum_list([1,2,3,4,5]) = 1 + sum_list([2,3,4,5]). 첫 원소 + 나머지 리스트의 합.
정답 보기
def sum_list(lst): if len(lst) == 0: return 0 return lst[0] + sum_list(lst[1:]) print(sum_list([1, 2, 3, 4, 5])) # 15

핵심 요약

  • 재귀는 함수가 자기 자신을 다시 호출하는 방법입니다.
  • base case(종료 조건)는 반드시 있어야 합니다. 없으면 RecursionError가 발생합니다.
  • recursive case는 문제를 더 작게 만들어 자기 자신을 호출합니다.
  • 팩토리얼 : n! = n × (n-1)!, base case는 n == 1이면 1 반환.
  • 피보나치 : fib(n) = fib(n-1) + fib(n-2), base case는 n <= 2이면 1 반환.
  • 재귀는 구조가 반복적인 문제(트리, 폴더)에 자연스럽고, 단순 반복은 반복문이 유리합니다.
