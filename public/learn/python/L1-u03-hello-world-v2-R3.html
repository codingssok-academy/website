print() 함수란?

print()는 괄호 안의 값을 화면에 출력하는 함수입니다. Python에서 가장 먼저, 가장 자주 사용하는 함수입니다.

쉽게 말하면, print()는 "화면에 보여줘!"라는 명령입니다. 괄호 안에 보여주고 싶은 내용을 넣으면 됩니다. 마치 선생님께 "이거 칠판에 써주세요"라고 부탁하는 것과 같습니다.

Pythonhello.py
1print("Hello, World!")
실행 결과
Hello, World!
줄코드역할
1print화면에 출력하는 내장 함수
1(함수에 값을 전달하는 시작 괄호
1"Hello, World!"출력할 문자열 (큰따옴표로 감쌈)
1)함수 호출 끝
확인해봅시다 print("Hello", "World")와 print("Hello" + "World")의 출력 결과가 다른 이유를 설명할 수 있습니까?

문자열 — 따옴표로 감싸기

Python에서 글자(텍스트)를 나타내려면 따옴표로 감싸야 합니다. 이것을 문자열(string)이라고 합니다.

Pythonstring.py
1print("큰따옴표로 감싼 문자열")
2print('작은따옴표로 감싼 문자열')
실행 결과
큰따옴표로 감싼 문자열 작은따옴표로 감싼 문자열
KEY
큰따옴표 vs 작은따옴표
둘 다 문자열을 만듭니다. 결과는 완전히 동일합니다. 다만 문자열 안에 따옴표를 포함해야 할 때 유용합니다.
Pythonquotes.py
1print("It's Python!") # 큰따옴표 안에 작은따옴표
2print('He said "Hi"') # 작은따옴표 안에 큰따옴표
실행 결과
It's Python! He said "Hi"

숫자와 계산 결과 출력

print()는 문자열뿐 아니라 숫자와 계산 결과도 출력할 수 있습니다. 숫자는 따옴표 없이 적습니다.

Pythonnumbers.py
1print(42)
2print(3.14)
3print(10 + 20)
4print(100 - 37)
5print(6 * 7)
실행 결과
42 3.14 30 63 42
TIP
따옴표 유무의 차이
print(10 + 20)은 계산 결과 30을 출력합니다. print("10 + 20")은 글자 그대로 10 + 20을 출력합니다. 따옴표가 있으면 문자열, 없으면 숫자(계산)입니다.

여러 값 출력 — 쉼표와 더하기

print()에 값을 여러 개 전달할 수 있습니다. 쉼표(,)로 구분하면 자동으로 공백이 들어가고, 더하기(+)로 연결하면 공백 없이 붙습니다.

Pythoncomma_vs_plus.py
1print("Hello", "World")
2print("Hello" + "World")
실행 결과
Hello World HelloWorld
줄코드역할
1쉼표로 구분 → 값 사이에 공백 한 칸이 자동으로 삽입됩니다.
2더하기로 연결 → 문자열끼리 그대로 붙습니다 (공백 없음).
WARNING
더하기(+)는 문자열끼리만
print("나이: " + 20)은 오류가 발생합니다. 문자열과 숫자는 +로 연결할 수 없습니다. 쉼표(,)를 사용하면 자동으로 변환되어 문제없이 출력됩니다.
Pythonplus_error.py
1print("나이:", 20) # 쉼표 — 정상
2print("나이: " + class="s-type">str(20)) # str()로 변환 — 정상
3# print("나이: " + 20) # TypeError 발생!
실행 결과
나이: 20 나이: 20

sep와 end — print()의 옵션

print()에는 두 가지 유용한 옵션이 있습니다. sep는 값 사이의 구분자를, end는 출력 끝에 붙는 문자를 지정합니다.

sep — 구분자 바꾸기

Pythonsep.py
1print("2025", "03", "15", sep="-")
2print("서울", "대전", "부산", sep=" → ")
실행 결과
2025-03-15 서울 → 대전 → 부산
줄코드역할
1sep="-"값 사이에 공백 대신 -가 들어갑니다.
2sep=" → "구분자를 여러 글자로 지정할 수도 있습니다.

end — 줄 끝 바꾸기

print()는 기본적으로 출력 후 줄을 바꿉니다. end를 지정하면 줄바꿈 대신 다른 문자를 붙일 수 있습니다.

Pythonend.py
1print("Hello", end=" ")
2print("World")
3print("A", end="")
4print("B", end="")
5print("C")
실행 결과
Hello World ABC
줄코드역할
1end=" "줄바꿈 대신 공백을 붙입니다. 다음 print()가 같은 줄에 이어집니다.
3end=""아무것도 붙이지 않습니다. 바로 이어서 출력됩니다.
5end="\n"end를 지정하지 않으면 기본값 (줄바꿈)이 적용됩니다.

이스케이프 문자

문자열 안에서 특수한 동작을 하는 문자를 이스케이프 문자라고 합니다. 역슬래시(\)로 시작합니다.

Pythonescape.py
1print("첫째 줄\n둘째 줄") # \n — 줄바꿈
2print("이름\t나이\t점수") # \t — 탭
3print("역슬래시: \\") # \\ — 역슬래시 출력
4print("그가 말했다: \"안녕\"") # \" — 큰따옴표 출력
실행 결과
첫째 줄 둘째 줄 이름 나이 점수 역슬래시: \ 그가 말했다: "안녕"
KEY
자주 쓰는 이스케이프 문자
\n — 줄바꿈
\t — 탭 (8칸 간격)
\\ — 역슬래시 자체
\" — 큰따옴표
\' — 작은따옴표

여러 줄 출력 — 3가지 방법

여러 줄을 출력하는 방법은 3가지입니다. 상황에 따라 적절한 방법을 선택합니다.

방법 1: print()를 여러 번 사용

Pythonmulti1.py
1print("첫째 줄")
2print("둘째 줄")
3print("셋째 줄")
실행 결과
첫째 줄 둘째 줄 셋째 줄

방법 2: \n 사용

Pythonmulti2.py
1print("첫째 줄\n둘째 줄\n셋째 줄")
실행 결과
첫째 줄 둘째 줄 셋째 줄

방법 3: 삼중 따옴표(triple quotes)

따옴표 3개로 감싸면 코드에서 줄을 바꾼 그대로 출력됩니다. 여러 줄을 출력할 때 가장 읽기 쉬운 방법입니다.

Pythonmulti3.py
1print("""첫째 줄
2둘째 줄
3셋째 줄""")
실행 결과
첫째 줄 둘째 줄 셋째 줄
방법특징
print() 여러 번각 줄을 개별 제어 가능
\n 사용한 줄 코드로 여러 줄 출력
삼중 따옴표보이는 그대로 출력, 가독성 좋음

빈 줄 출력

print()에 아무 값도 전달하지 않으면 빈 줄이 출력됩니다.

Pythonblank.py
1print("위쪽")
2print()
3print("아래쪽")
실행 결과
위쪽 아래쪽
