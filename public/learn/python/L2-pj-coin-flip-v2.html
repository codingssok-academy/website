동전 던지기 시뮬레이터

random 모듈로 동전 앞/뒤를 시뮬레이션하고 통계를 냅니다.

이 프로젝트에서 배우는 것

  • random 모듈을 import해서 사용할 수 있습니다.
  • random.randint(0, 1)로 0 또는 1을 무작위로 뽑을 수 있습니다.
  • while 반복문으로 N번 반복 실행할 수 있습니다.
  • 카운터 변수로 앞면/뒷면 횟수를 셀 수 있습니다.
  • 시뮬레이션 결과로 확률 통계를 계산할 수 있습니다.

random 모듈 사용하기

파이썬의 random 모듈을 가져오면 난수(무작위 수)를 생성할 수 있습니다. import random 한 줄로 불러옵니다.

import random # 동전 한 번 던지기 result = random.randint(0, 1) if result == 0: print("앞면!") else: print("뒷면!")

실행할 때마다 다른 결과가 나옵니다. 이게 바로 시뮬레이션의 매력입니다.

따라해보세요
1
random을 import하고 동전을 한 번 던져보세요.
import random r = random.randint(0, 1) print("앞면" if r == 0 else "뒷면")
앞면 또는 뒷면이 무작위로 출력됩니다
2
주사위도 만들어보세요. 1~6 사이 숫자를 뽑습니다.
import random dice = random.randint(1, 6) print(f"주사위: {dice}")
1에서 6 사이 숫자가 무작위로 나옵니다
3
random.choice()로 리스트에서 무작위 선택을 해보세요.
import random options = ["가위", "바위", "보"] pick = random.choice(options) print(f"컴퓨터 선택: {pick}")
가위, 바위, 보 중 하나가 무작위로 선택됩니다

while로 N번 던지기

while 반복문으로 동전을 N번 던지고 앞면/뒷면 횟수를 카운터 변수로 셉니다.

import random n = int(input("동전을 몇 번 던질까요? ")) heads = 0 # 앞면 카운터 tails = 0 # 뒷면 카운터 i = 0 while i < n: result = random.randint(0, 1) if result == 0: heads += 1 print(f"던지기 {i+1}: 앞면") else: tails += 1 print(f"던지기 {i+1}: 뒷면") i += 1 print(f"\n결과: 앞면 {heads}회 / 뒷면 {tails}회") print(f"앞면 확률: {heads/n*100:.1f}%")
따라해보세요
1
동전을 10번 던져서 앞면/뒷면 횟수를 세어보세요.
import random heads = tails = 0 i = 0 while i < 10: if random.randint(0, 1) == 0: heads += 1 else: tails += 1 i += 1 print(f"앞:{heads} / 뒤:{tails}")
10번의 결과가 합산됩니다
2
100번 던졌을 때 앞면 비율이 50%에 가까운지 확인하세요.
import random heads = 0 i = 0 while i < 100: if random.randint(0, 1) == 0: heads += 1 i += 1 print(f"앞면 비율: {heads}%")
많이 던질수록 50%에 가까워집니다
3
던진 횟수를 input()으로 받아 결과를 출력하세요.
import random n = int(input("몇 번? ")) heads = tails = 0 i = 0 while i < n: if random.randint(0,1) == 0: heads += 1 else: tails += 1 i += 1 print(f"앞:{heads}회 뒤:{tails}회 ({heads/n*100:.1f}%)")
원하는 횟수만큼 시뮬레이션할 수 있습니다

동전을 20번 던져서 앞면 횟수와 앞면 비율(%)을 출력하세요.

내 답안

while i < 20 반복, heads += 1 카운터, heads/20*100으로 비율 계산

보통
던질 횟수를 input()으로 받아 앞면/뒷면 횟수와 각각의 비율을 출력하는 완성 프로그램을 만드세요.
입력50
출력앞면: 27회(54.0%) / 뒷면: 23회(46.0%)
내 답안
힌트 보기
n = int(input()), while 반복, heads와 tails 두 카운터, n으로 나눠서 비율 계산
정답 확인
import random n = int(input("몇 번 던질까요? ")) heads = tails = 0 i = 0 while i < n: if random.randint(0, 1) == 0: heads += 1 else: tails += 1 i += 1 print(f"앞면: {heads}회({heads/n*100:.1f}%) / 뒷면: {tails}회({tails/n*100:.1f}%)")

핵심 요약

이 유닛에서 배운 것

  • import random으로 random 모듈을 불러온다
  • random.randint(a, b)는 a이상 b이하의 정수를 무작위로 반환한다
  • random.choice(리스트)는 리스트에서 무작위로 하나를 뽑는다
  • while i < n으로 n번 반복하고 반복할 때마다 i += 1
  • 카운터 += 1로 조건에 맞는 횟수를 누적한다
  • 비율 = 앞면 횟수 / 전체 횟수 * 100
