조건문 챌린지

논리적 사고가 필요한 문제입니다. 조건들의 순서와 조합에 집중하세요.

C1
삼각형 종류 판별기
중급
세 변의 길이를 입력받아 삼각형이 만들어지는지 확인하고, 삼각형의 종류를 출력하세요.
조건
삼각형 성립 조건: 두 변의 합 > 나머지 한 변 (모든 조합)
정삼각형: 세 변이 모두 같음
이등변삼각형: 두 변이 같음
직각삼각형: a² + b² = c² (c가 가장 긴 변)
나머지: 일반삼각형
입력3 4 5
출력직각삼각형
입력5 5 5
출력정삼각형
입력1 2 10
출력삼각형이 아닙니다.
생각해봐야 할 것
삼각형 성립 여부를 먼저 검사해야 한다
직각삼각형 검사: 가장 긴 변을 먼저 찾아야 한다
정삼각형 → 이등변삼각형 → 직각삼각형 → 일반 순으로
힌트 보기
1. 세 변을 정렬하여 가장 긴 변을 찾기: sides = sorted([a, b, c])
2. 삼각형 성립: sides[0] + sides[1] > sides[2]
3. 직각: sides[0]**2 + sides[1]**2 == sides[2]**2
정답 확인
정답 코드
a = int(input("변 a: ")) b = int(input("변 b: ")) c = int(input("변 c: ")) # 삼각형 성립 검사 if a + b <= c or a + c <= b or b + c <= a: print("삼각형이 아닙니다.") elif a == b == c: print("정삼각형") elif a == b or b == c or a == c: # 직각 이등변삼각형인지도 확인 sides = sorted([a, b, c]) if sides[0]**2 + sides[1]**2 == sides[2]**2: print("직각이등변삼각형") else: print("이등변삼각형") else: sides = sorted([a, b, c]) if sides[0]**2 + sides[1]**2 == sides[2]**2: print("직각삼각형") else: print("일반삼각형")
C2
장학금 수여 조건 판단기
상급
국어, 영어, 수학 점수를 입력받아 장학금 종류를 결정하세요.
장학금 조건
최우수 장학금: 세 과목 평균 95점 이상 AND 최저 점수 90점 이상
우수 장학금: 세 과목 평균 85점 이상 AND 최저 점수 75점 이상
성적 장학금: 세 과목 평균 75점 이상
해당 없음: 위 조건 모두 불해당
입력97 95 96
출력평균: 96.0점 | 최우수 장학금 수여!
입력90 80 70
출력평균: 80.0점 | 성적 장학금 수여!
접근 방법
평균: (kor + eng + math) / 3
최솟값: if-elif로 직접 찾거나, min(kor, eng, math) 사용
조건이 여러 개일 때는 and로 묶기
힌트 보기
Python의 min() 내장함수를 쓰면 편리합니다: lowest = min(kor, eng, math)
평균은 round((kor+eng+math)/3, 1)로 소수점 1자리까지 표현하세요.
정답 확인
kor = int(input("국어: ")) eng = int(input("영어: ")) math = int(input("수학: ")) avg = round((kor + eng + math) / 3, 1) lowest = min(kor, eng, math) print(f"평균: {avg}점", end=" | ") if avg >= 95 and lowest >= 90: print("최우수 장학금 수여!") elif avg >= 85 and lowest >= 75: print("우수 장학금 수여!") elif avg >= 75: print("성적 장학금 수여!") else: print("해당 장학금 없음")
C3
어드벤처 게임 선택지
최상급
중첩 if를 활용한 텍스트 어드벤처 게임입니다. 선택에 따라 결말이 달라집니다.
# 텍스트 어드벤처: 동굴 탐험 print("=== 동굴 탐험 ===") print("어두운 동굴 입구에 서 있습니다.") print("1. 들어간다 2. 돌아간다") choice1 = int(input("선택: ")) if choice1 == 1: print("\n동굴 안에 두 갈래 길이 있습니다.") print("1. 왼쪽 (불빛 보임) 2. 오른쪽 (물 소리)") choice2 = int(input("선택: ")) if choice2 == 1: print("횃불을 발견! 보물 상자가 보입니다.") choice3 = input("열어보겠습니까? (y/n): ") if choice3 == "y": print("황금을 발견했습니다! 엔딩 A") else: print("현명하게 도망쳤습니다. 엔딩 B") elif choice2 == 2: print("지하 호수를 발견! 보트가 있습니다.") print("탈출에 성공했습니다. 엔딩 C") else: print("잘못된 선택입니다.") elif choice1 == 2: print("안전하게 집으로 돌아갔습니다. 엔딩 D") else: print("잘못된 선택입니다.")

직접 실행해보고, 모든 엔딩(A~D)을 찾아보세요!
