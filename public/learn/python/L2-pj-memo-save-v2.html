메모 저장하기

파일에 메모를 쓰고 읽는 파일 I/O 기능을 배웁니다. append 모드로 기존 내용을 유지하면서 메모를 추가합니다.

이 프로젝트에서 배우는 것

  • open()으로 파일을 열고 write()로 내용을 쓸 수 있습니다.
  • 'a' 모드(append)로 기존 내용을 유지하면서 추가할 수 있습니다.
  • 'r' 모드(read)로 파일 내용을 읽을 수 있습니다.
  • with 문으로 파일을 안전하게 자동 닫을 수 있습니다.
  • readlines()로 줄별로 나눠 읽는 방법을 이해합니다.

파일에 쓰기

open(파일명, 'w')로 파일을 쓰기 모드로 열면 새 파일이 만들어지거나 기존 파일을 덮어씁니다. with 문을 쓰면 작업 후 파일이 자동으로 닫힙니다.

# 파일에 쓰기 — 'w' 모드 (덮어쓰기) with open("memo.txt", "w", encoding="utf-8") as f: f.write("첫 번째 메모\n") f.write("파이썬 공부 중\n") print("memo.txt 파일이 저장되었습니다.") # 파일 읽기 — 'r' 모드 with open("memo.txt", "r", encoding="utf-8") as f: content = f.read() print(content)

메모 저장 앱 만들기

'a' 모드(append)를 쓰면 기존 내용은 그대로 두고 새 내용을 끝에 추가합니다. 메모장처럼 계속 내용을 쌓을 수 있습니다.

def save_memo(text): """메모를 파일에 추가 저장""" with open("memos.txt", "a", encoding="utf-8") as f: f.write(text + "\n") def load_memos(): """저장된 메모 모두 읽기""" with open("memos.txt", "r", encoding="utf-8") as f: lines = f.readlines() for i, line in enumerate(lines, 1): print(f"{i}. {line.strip()}") # 메모 저장 테스트 save_memo("오늘 파이썬 공부 완료!") save_memo("내일은 파일 I/O 복습") load_memos()

완성: 메모 저장 프로그램

메뉴로 쓰기/읽기를 선택하는 완전한 메모 앱을 만듭니다.

import os MEMO_FILE = "memos.txt" def add_memo(text): with open(MEMO_FILE, "a", encoding="utf-8") as f: f.write(text + "\n") print("메모가 저장되었습니다!") def show_memos(): if not os.path.exists(MEMO_FILE): print("저장된 메모가 없습니다.") return with open(MEMO_FILE, "r", encoding="utf-8") as f: lines = f.readlines() print(f"\n--- 메모 목록 ({len(lines)}개) ---") for i, line in enumerate(lines, 1): print(f"{i}. {line.strip()}") while True: print("\n1.메모 추가 2.전체 보기 3.종료") choice = input("선택: ") if choice == "1": text = input("메모: ") add_memo(text) elif choice == "2": show_memos() elif choice == "3": print("종료!"); break

핵심 요약

이 유닛에서 배운 것

  • open(파일명, 모드, encoding="utf-8")로 파일을 연다
  • 'r': 읽기, 'w': 덮어쓰기, 'a': 끝에 추가
  • with open() as f:로 파일을 열면 블록 끝에서 자동으로 닫힌다
  • f.write(텍스트): 파일에 쓰기, f.read(): 전체 읽기
  • f.readlines(): 줄별로 나눈 리스트로 읽기
  • line.strip(): 앞뒤 공백과 줄바꿈 문자 제거
