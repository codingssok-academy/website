탐색 알고리즘:
선형 탐색과 이진 탐색

리스트에서 원하는 값을 찾는 두 가지 방법 — 처음부터 하나씩 확인하는 선형 탐색과, 정렬된 데이터를 반으로 줄여나가는 이진 탐색을 비교하며 배웁니다.

이 유닛에서 배우는 것

  • for문으로 리스트를 처음부터 끝까지 확인하는 선형 탐색을 구현할 수 있습니다.
  • 정렬된 리스트에서 탐색 범위를 반씩 줄이는 이진 탐색 알고리즘을 구현할 수 있습니다.
  • 선형 탐색과 이진 탐색의 시간 복잡도 차이(O(n) vs O(log n))를 설명할 수 있습니다.
  • Python in 연산자가 내부적으로 선형 탐색임을 이해하고 적절히 활용할 수 있습니다.
  • 학생 성적 검색, 단어 사전 조회 등 실제 상황에 탐색 알고리즘을 적용할 수 있습니다.

선형 탐색 (Linear Search)

선형 탐색은 리스트의 첫 번째 원소부터 마지막 원소까지 순서대로 하나씩 비교하여 원하는 값을 찾는 방법입니다. 가장 단순하지만, 모든 유형의 리스트에 사용할 수 있습니다.

선형 탐색 구현

def linear_search(arr, target): """리스트에서 target을 찾아 인덱스를 반환. 없으면 -1.""" for i in range(len(arr)): if arr[i] == target: return i # 찾으면 즉시 인덱스 반환 return -1 # 끝까지 못 찾으면 -1 numbers = [14, 22, 5, 38, 17, 9, 42, 7, 31, 19] result = linear_search(numbers, 9) print(result) # 5
5
핵심 동작 원리
for i in range(len(arr))로 인덱스를 0부터 끝까지 순회합니다. 각 인덱스에서 arr[i] == target이면 즉시 return i로 종료합니다. 리스트 끝까지 도달해도 못 찾으면 -1을 반환합니다.

선형 탐색 — 비교 횟수 추적 버전

실제로 몇 번 비교했는지 확인하는 버전도 만들어볼 수 있습니다.

def linear_search_verbose(arr, target): count = 0 for i in range(len(arr)): count += 1 print(f"비교 {count}회: arr[{i}] = {arr[i]}") if arr[i] == target: print(f"→ 발견! 인덱스 {i}, 총 {count}번 비교") return i print(f"→ 없음. 총 {count}번 비교") return -1

이진 탐색 (Binary Search)

이진 탐색은 정렬된 리스트에서만 사용할 수 있습니다. 탐색 범위의 중간 값을 보고, 목표 값이 더 크면 오른쪽 절반만, 더 작으면 왼쪽 절반만 다시 탐색합니다. 한 번 비교할 때마다 탐색 범위가 절반으로 줄어듭니다.

이진 탐색 구현

이진 탐색은 left와 right 두 포인터로 탐색 범위를 추적합니다. mid = (left + right) // 2로 중간 인덱스를 구합니다.

def binary_search(arr, target): """정렬된 리스트에서 target을 찾아 인덱스 반환. 없으면 -1.""" left = 0 right = len(arr) - 1 while left <= right: mid = (left + right) // 2 # 중간 인덱스 if arr[mid] == target: return mid # 발견 elif arr[mid] < target: left = mid + 1 # 오른쪽 절반으로 else: right = mid - 1 # 왼쪽 절반으로 return -1 # 못 찾음 sorted_nums = [2, 5, 8, 12, 16, 23, 38, 45, 56, 72] print(binary_search(sorted_nums, 23)) # 5 print(binary_search(sorted_nums, 99)) # -1
5 -1
주의: 이진 탐색은 정렬된 리스트에서만 동작
정렬되지 않은 리스트에 이진 탐색을 적용하면 잘못된 결과가 나옵니다. 반드시 sorted()로 정렬하거나, 처음부터 정렬 상태를 유지해야 합니다.

선형 vs 이진 탐색 비교

항목 선형 탐색 이진 탐색
정렬 필요 여부 불필요 (어떤 리스트도 OK) 반드시 정렬 필요
시간 복잡도 O(n) — 원소 수에 비례 O(log n) — 매우 빠름
구현 난이도 단순 (for문 1개) 중간 (while + 포인터 2개)
적합한 경우 소량 데이터, 비정렬 데이터 대량 정렬 데이터
100만 개 데이터 최악 1,000,000번 비교 약 20번 비교

in 연산자와의 관계

Python의 in 연산자는 리스트에서 내부적으로 선형 탐색을 수행합니다. 편리하지만 대량 데이터에서는 느릴 수 있습니다.

# in 연산자 — 내부적으로 선형 탐색 numbers = [14, 22, 5, 38, 9] print(5 in numbers) # True (선형 탐색) print(99 in numbers) # False (끝까지 탐색) # 직접 구현 vs in 연산자 — 결과 동일 print(linear_search(numbers, 5) != -1) # True
팁: 대량 데이터에서 빠른 탐색이 필요하다면
단순히 "존재 여부"만 확인할 때는 리스트 대신 set(집합)을 쓰면 O(1) 해시 탐색이 적용됩니다. 인덱스나 순서가 필요하면 binary_search를 직접 구현하거나, Python 표준 라이브러리 bisect 모듈을 활용하세요.

def binary_search(arr, target): left, right = 0, len(arr) - 1 while left <= right: mid = (left + right) // 2 if arr[mid] == target: return mid elif arr[mid] < target: left = mid + 1 else: right = mid - 1 return -1 print(binary_search([1,3,5,7,9,11,13,15], 7))

실용 예제

예제 1 — 학생 성적 검색 (선형 탐색)

딕셔너리 리스트에서 이름으로 학생을 찾는 실용적인 예입니다. 데이터가 정렬되어 있지 않으므로 선형 탐색이 적합합니다.

# 학생 성적 검색 — 선형 탐색 활용 students = [ {"name": "김민준", "score": 88}, {"name": "이서연", "score": 95}, {"name": "박지훈", "score": 72}, {"name": "최유나", "score": 81}, ] def find_student(students, name): for i, student in enumerate(students): if student["name"] == name: return student return None result = find_student(students, "이서연") if result: print(f"{result['name']}: {result['score']}점") else: print("학생을 찾을 수 없습니다.")
이서연: 95점

예제 2 — 단어 사전 조회 (이진 탐색)

알파벳순으로 정렬된 단어 목록에서 특정 단어를 빠르게 찾는 예입니다. 실제 종이 사전을 찾는 방법과 동일합니다.

# 정렬된 단어 목록에서 이진 탐색 words = ["apple", "banana", "cherry", "date", "grape", "kiwi", "mango", "orange"] def find_word(words, target): left, right = 0, len(words) - 1 while left <= right: mid = (left + right) // 2 if words[mid] == target: return mid elif words[mid] < target: left = mid + 1 else: right = mid - 1 return -1 idx = find_word(words, "mango") print(f"'mango' 위치: {idx}") # 6 print(f"'peach' 위치: {find_word(words, 'peach')}") # -1
'mango' 위치: 6 'peach' 위치: -1

예제 3 — 정렬 후 이진 탐색

정렬되지 않은 리스트를 sorted()로 정렬한 뒤 이진 탐색을 적용하는 패턴입니다.

# 정렬 후 이진 탐색 패턴 raw = [45, 12, 78, 3, 56, 23, 90] sorted_data = sorted(raw) # [3, 12, 23, 45, 56, 78, 90] print(binary_search(sorted_data, 23)) # 2

선형 탐색 — 최솟값 인덱스 찾기
쉬움
선형 탐색 방식을 이용하여 리스트에서 최솟값의 인덱스를 반환하는 함수 find_min_index(arr)를 작성하세요. 리스트가 비어 있으면 -1을 반환합니다.
입력 arr = [42, 13, 7, 28, 5, 19]
출력 4 (arr[4] = 5 가 최솟값)
힌트 보기
min_val = arr[0], min_idx = 0 으로 시작합니다. 순회하면서 현재 원소가 min_val보다 작으면 두 값을 모두 갱신합니다.
정답 보기
def find_min_index(arr): if not arr: return -1 min_idx = 0 for i in range(1, len(arr)): if arr[i] < arr[min_idx]: min_idx = i return min_idx print(find_min_index([42, 13, 7, 28, 5, 19])) # 4

이진 탐색 — 삽입 위치 찾기
보통
정렬된 리스트에 새 값을 삽입할 때 정렬 순서가 유지되는 위치(인덱스)를 반환하는 함수 find_insert_pos(arr, target)를 이진 탐색으로 작성하세요. 이미 존재하면 해당 인덱스를 반환합니다.
입력 arr = [1, 3, 5, 7, 9], target = 6
출력 3 (인덱스 3에 삽입하면 [1,3,5,6,7,9])
힌트 보기
while left <= right 루프가 끝났을 때 left가 삽입 위치입니다. arr[mid] < target이면 left = mid + 1, 그렇지 않으면 right = mid - 1을 적용합니다.
정답 보기
def find_insert_pos(arr, target): left, right = 0, len(arr) - 1 while left <= right: mid = (left + right) // 2 if arr[mid] == target: return mid elif arr[mid] < target: left = mid + 1 else: right = mid - 1 return left # 삽입 위치 print(find_insert_pos([1,3,5,7,9], 6)) # 3

두 탐색 비교 — 비교 횟수 측정
어려움
선형 탐색과 이진 탐색의 비교 횟수를 각각 반환하는 함수를 작성하세요. 두 함수를 이용하여 [1, 2, ..., 100] 리스트에서 73을 찾을 때 각각 몇 번 비교하는지 출력합니다.
출력 선형: 73번 | 이진: 7번
힌트 보기
각 함수 내부에 count 변수를 두고, 비교할 때마다 count += 1을 합니다. 마지막에 (인덱스, count)를 반환합니다.
정답 보기
def linear_count(arr, target): count = 0 for i in range(len(arr)): count += 1 if arr[i] == target: return i, count return -1, count def binary_count(arr, target): left, right, count = 0, len(arr)-1, 0 while left <= right: mid = (left + right) // 2 count += 1 if arr[mid] == target: return mid, count elif arr[mid] < target: left = mid + 1 else: right = mid - 1 return -1, count data = list(range(1, 101)) _, lc = linear_count(data, 73) _, bc = binary_count(data, 73) print(f"선형: {lc}번 | 이진: {bc}번")

핵심 요약

핵심 요약

  • 선형 탐색: for문으로 앞에서부터 하나씩 비교. 정렬 불필요. 시간 복잡도 O(n).
  • 이진 탐색: left/right 포인터와 mid = (left + right) // 2. 반드시 정렬된 리스트에만 사용. 시간 복잡도 O(log n).
  • 이진 탐색의 조건: arr[mid] == target이면 반환, < target이면 left = mid + 1, > target이면 right = mid - 1.
  • Python in 연산자는 리스트에서 내부적으로 선형 탐색(O(n))을 수행한다.
  • 존재 여부만 확인할 때: 리스트 대신 set을 사용하면 O(1) 해시 탐색이 적용된다.
  • 탐색 전에 정렬 비용(O(n log n))이 발생하더라도, 대량 데이터에서 반복 탐색 시 이진 탐색이 유리하다.
알고리즘 선택 가이드
데이터가 비정렬이거나 소량(100개 미만)이면 구현이 단순한 선형 탐색을 사용합니다. 대량 데이터(1,000개 이상)이고 정렬 가능하면 이진 탐색을 사용합니다. Python 내장 bisect 모듈은 이진 탐색을 이미 구현해 두고 있어 바로 가져다 쓸 수 있습니다.
