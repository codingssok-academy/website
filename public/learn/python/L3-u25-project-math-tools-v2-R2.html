프로젝트:
비밀번호 생성기

random, lambda, filter를 조합해 대소문자·숫자·특수문자 조합 비밀번호를 만들고 강도를 검사합니다.

이 유닛에서 만드는 것

  • random.choices()로 무작위 비밀번호를 생성합니다.
  • lambda와 filter()로 문자 종류(대문자/소문자/숫자/특수문자)를 검사합니다.
  • 강도 조건 충족 수를 세어 약함/보통/강함/매우 강함으로 평가합니다.
  • 기본값 매개변수로 비밀번호 길이와 포함할 문자 종류를 선택합니다.
  • 완성된 생성기를 하나의 password_gen.py로 통합합니다.

Step 1 — random과 lambda 복습

random.choices()는 리스트에서 중복을 허용해 k개를 뽑습니다. lambda는 한 줄짜리 익명 함수로 filter나 map의 조건으로 자주 씁니다.

# random.choices 기본 사용 import random import string # string 모듈 — 문자 집합 제공 print(string.ascii_lowercase) # abcdefghijklmnopqrstuvwxyz print(string.ascii_uppercase) # ABCDEFGHIJKLMNOPQRSTUVWXYZ print(string.digits) # 0123456789 print(string.punctuation) # !"#$%&'()*+,-./:;<=>?@[\]^_`{|}~ # choices로 12자리 뽑기 pool = string.ascii_letters + string.digits chars = random.choices(pool, k=12) password = ''.join(chars) print(password) # 예: xK9mB2pQr7Lw (매번 다름)
# lambda + filter로 문자 종류 검사 pw = "xK9m!B2pQ@r" has_upper = len(list(filter(lambda c: c.isupper(), pw))) > 0 has_lower = len(list(filter(lambda c: c.islower(), pw))) > 0 has_digit = len(list(filter(lambda c: c.isdigit(), pw))) > 0 has_special = len(list(filter(lambda c: c in string.punctuation, pw))) > 0 print(has_upper, has_lower, has_digit, has_special) # True True True True

Step 2 — 강도 체크 함수

비밀번호 강도는 네 가지 조건(대문자, 소문자, 숫자, 특수문자 포함 여부)과 길이를 기준으로 판단합니다. 조건을 만족할수록 강도가 높아집니다.

# Step 2: 강도 체크 함수 def check_strength(pw): """비밀번호 강도 평가 — filter + lambda 활용""" conditions = [ len(list(filter(lambda c: c.isupper(), pw))) > 0, # 대문자 len(list(filter(lambda c: c.islower(), pw))) > 0, # 소문자 len(list(filter(lambda c: c.isdigit(), pw))) > 0, # 숫자 len(list(filter(lambda c: c in string.punctuation, pw))) > 0, # 특수 ] score = sum(conditions) # True = 1, False = 0 if score <= 1 or len(pw) < 8: return "약함" elif score == 2: return "보통" elif score == 3: return "강함" else: # score == 4 and len >= 12 return "매우 강함" if len(pw) >= 12 else "강함" # 테스트 print(check_strength("password")) # 약함 print(check_strength("Pass123")) # 보통 print(check_strength("Pass123!")) # 강함 print(check_strength("Pass123!@#xyz")) # 매우 강함
약함 보통 강함 매우 강함

Step 3 — 통합 비밀번호 생성기

기본값 매개변수로 길이와 포함할 문자 종류를 선택할 수 있는 완전한 생성기를 만듭니다.

# Step 3: 통합 비밀번호 생성기 def generate_password( length=12, use_upper=True, use_lower=True, use_digits=True, use_special=True ): """비밀번호 생성기 — 기본값 매개변수로 옵션 선택""" pool = "" if use_upper: pool += string.ascii_uppercase if use_lower: pool += string.ascii_lowercase if use_digits: pool += string.digits if use_special: pool += "!@#$%^&*" if not pool: raise ValueError("최소 하나의 문자 종류를 선택하세요") pw = "".join(random.choices(pool, k=length)) strength = check_strength(pw) return pw, strength # 다양한 옵션으로 생성 pw, s = generate_password() print(f"비밀번호: {pw}") print(f"강도: {s}") pw2, s2 = generate_password(length=8, use_special=False) print(f"숫자 없는 8자리: {pw2} ({s2})")

핵심 요약

  • random.choices(pool, k=n) — 풀에서 n개를 중복 허용해 무작위 선택
  • string 모듈 — ascii_lowercase, digits, punctuation 등 문자 집합 제공
  • lambda c: c.isupper() — 대문자 여부를 한 줄로 표현하는 익명 함수
  • filter(fn, iterable) — fn이 True를 반환하는 원소만 남김, list()로 변환
  • sum(bool_list) — True=1, False=0으로 자동 합산해 조건 충족 수 집계
  • 기본값 매개변수 — 옵션 선택을 간단하게, 미지정 시 기본값 사용
