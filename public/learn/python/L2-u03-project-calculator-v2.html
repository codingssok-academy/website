Chapter 03

나만의 계산기

input()과 int(), float()를 조합해 실용적인 계산기를 만듭니다.

이 유닛에서 배우는 것

  • input()으로 받은 문자열을 int(), float()로 변환할 수 있습니다.
  • 사칙연산(+, -, *, /)을 활용한 계산기를 만들 수 있습니다.
  • f-string으로 결과를 깔끔하게 출력할 수 있습니다.
  • 피자 가격 계산기를 직접 만들 수 있습니다.
  • 용돈 저축 계산기를 직접 만들 수 있습니다.

프로젝트: 계산기를 만들자

지금까지 배운 input(), int(), float(), print()를 합쳐서 진짜 작동하는 계산기를 만들어봅시다.

가장 기본적인 두 수 덧셈 계산기부터 시작합니다.

# 기본 덧셈 계산기 a = int(input("첫 번째 수: ")) b = int(input("두 번째 수: ")) result = a + b print(f"{a} + {b} = {result}")
따라해보세요
1
기본 덧셈 계산기를 만들고, 10과 20을 입력하세요.
a = int(input("첫 번째 수: ")) b = int(input("두 번째 수: ")) print(f"{a} + {b} = {a + b}")
10 + 20 = 30 이 출력되면 성공
2
뺄셈 계산기로 바꿔보세요. +를 -로 변경합니다.
a = int(input("첫 번째 수: ")) b = int(input("두 번째 수: ")) print(f"{a} - {b} = {a - b}")
50 - 30 = 20 이 출력되면 성공
3
사칙연산을 한 번에 다 보여주는 계산기를 만드세요.
a = int(input("첫 번째 수: ")) b = int(input("두 번째 수: ")) print(f"덧셈: {a + b}") print(f"뺄셈: {a - b}") print(f"곱셈: {a * b}") print(f"나눗셈: {a / b}")
네 가지 연산 결과가 한 줄씩 출력됩니다

프로젝트 1: 피자 가격 계산기

피자 1판 가격과 인원수를 입력하면 1인당 얼마를 내야 하는지 계산합니다. float()를 써서 소수점 결과도 처리합니다.

# 피자 가격 계산기 price = int(input("피자 가격(원): ")) topping = int(input("추가 토핑 가격(원): ")) people = int(input("인원수: ")) total = price + topping per_person = total / people print(f"총 가격: {total}원") print(f"1인당: {per_person}원")
따라해보세요
1
피자 가격 계산기를 그대로 입력하고, 피자 25000원 + 토핑 3000원, 3명으로 실행하세요.
price = int(input("피자 가격(원): ")) topping = int(input("추가 토핑 가격(원): ")) people = int(input("인원수: ")) total = price + topping print(f"1인당: {total / people}원")
1인당: 9333.333333333334원 이 나옵니다
2
소수점을 깔끔하게 만들어봅시다. round() 함수를 사용합니다.
price = int(input("피자 가격(원): ")) people = int(input("인원수: ")) per = round(price / people) print(f"1인당: {per}원")
round()로 반올림하면 깔끔한 정수가 됩니다
3
피자 2판을 시킨 경우로 확장해보세요.
price = int(input("피자 1판 가격: ")) count = int(input("피자 수량: ")) people = int(input("인원수: ")) total = price * count print(f"총 가격: {total}원") print(f"1인당: {round(total / people)}원")
수량을 곱해서 총 가격을 계산합니다

프로젝트 2: 용돈 저축 계산기

매주 저축하는 금액과 목표 금액을 입력하면 몇 주가 걸리는지 계산합니다. 정수 나눗셈(//)과 나머지(%)를 활용합니다.

# 용돈 저축 계산기 goal = int(input("목표 금액(원): ")) weekly = int(input("매주 저축 금액(원): ")) weeks = goal // weekly # 몫: 필요한 주 remain = goal % weekly # 나머지: 추가 필요 금액 print(f"목표 금액: {goal}원") print(f"{weeks}주 동안 저축하면 {weeks * weekly}원") if remain > 0: print(f"나머지 {remain}원이 더 필요합니다") else: print("딱 맞게 모을 수 있습니다!")
따라해보세요
1
용돈 저축 계산기를 만들고, 목표 30000원 / 매주 5000원으로 실행하세요.
goal = int(input("목표 금액: ")) weekly = int(input("매주 저축: ")) print(f"{goal // weekly}주 필요") print(f"나머지: {goal % weekly}원")
6주 필요, 나머지: 0원
2
이번에는 목표 50000원, 매주 8000원으로 실행하세요.
goal = int(input("목표 금액: ")) weekly = int(input("매주 저축: ")) weeks = goal // weekly remain = goal % weekly print(f"{weeks}주 + 나머지 {remain}원")
6주 + 나머지 2000원
3
월 저축 계산기로 확장하세요. 한 달을 4주로 계산합니다.
goal = int(input("목표 금액: ")) monthly = int(input("월 저축: ")) months = goal // monthly print(f"{months}개월 필요 (약 {months * 4}주)")
개월 수와 주 수가 함께 출력됩니다

결과를 예쁘게 — f-string 포맷팅

f-string 안에서 : 뒤에 서식 코드를 넣으면 소수점 자릿수나 천 단위 쉼표를 지정할 수 있습니다.

# f-string 포맷팅 예시 price = 28500 people = 3 per = price / people print(f"1인당: {per:,.0f}원") # 9,500원 (소수점 없이, 쉼표 있게) print(f"1인당: {per:.2f}원") # 9500.00원 (소수점 2자리)
따라해보세요
1
큰 숫자에 천 단위 쉼표를 넣어보세요.
print(f"인구: {51000000:,}명")
인구: 51,000,000명
2
소수점 자릿수를 지정해보세요.
pi = 3.141592653589 print(f"원주율: {pi:.4f}")
원주율: 3.1416 (반올림됨)
3
계산기에 포맷을 적용하세요.
price = int(input("가격: ")) people = int(input("인원: ")) print(f"1인당: {price / people:,.0f}원")
25000 / 3 = 1인당: 8,333원

종합: 나만의 만능 계산기

지금까지 배운 것을 모두 합쳐서 피자 주문 종합 계산기를 완성합니다.

# 피자 주문 종합 계산기 print("=== 피자 주문 계산기 ===") pizza = int(input("피자 1판 가격: ")) qty = int(input("피자 수량: ")) topping = int(input("토핑 가격: ")) drink = int(input("음료 가격: ")) people = int(input("인원수: ")) total = pizza * qty + topping + drink per = total / people print(f"\n--- 주문 내역 ---") print(f"피자 {qty}판: {pizza * qty:,}원") print(f"토핑: {topping:,}원") print(f"음료: {drink:,}원") print(f"합계: {total:,}원") print(f"1인당: {per:,.0f}원")

직접 풀어보세요

Q1
간식 가격 계산기
쉬움
과자 가격과 음료 가격을 input()으로 입력받아 합계를 출력하세요. int()로 변환하는 것을 잊지 마세요.
입력과자: 1500 / 음료: 2000
출력합계: 3,500원
내 답안
힌트 보기
int(input())으로 두 값을 받고, f-string의 :, 포맷을 사용하세요.
정답 확인
snack = int(input("과자 가격: ")) drink = int(input("음료 가격: ")) total = snack + drink print(f"합계: {total:,}원")
Q2
거스름돈 계산기
쉬움
물건 가격과 낸 금액을 입력받아 거스름돈을 출력하세요.
입력가격: 3200 / 낸 돈: 5000
출력거스름돈: 1,800원

price = int(input("물건 가격: ")) paid = int(input("낸 금액: ")) change = paid - price print(f"거스름돈: {change:,}원")
Q3
저축 목표 달성 계산기
보통
목표 금액과 매주 저축액을 입력받아 필요한 주 수와 남은 금액을 출력하세요. //와 %를 사용합니다.
입력목표: 35000 / 매주: 8000
출력4주 필요, 나머지 3,000원 추가 저축
내 답안
힌트 보기
//는 몫(주 수), %는 나머지(추가 필요 금액)를 구합니다.
정답 확인
goal = int(input("목표 금액: ")) weekly = int(input("매주 저축: ")) weeks = goal // weekly remain = goal % weekly print(f"{weeks}주 필요, 나머지 {remain:,}원 추가 저축")

핵심 요약

이 유닛에서 배운 것

  • int(input())으로 사용자에게 정수를 입력받는다
  • float(input())으로 소수점 숫자를 입력받는다
  • 사칙연산: + - * / //(몫) %(나머지)
  • round()로 소수점을 반올림한다
  • f"{값:,.0f}"으로 천 단위 쉼표, 소수점 자릿수를 지정한다
  • 입력 - 변환 - 계산 - 출력 4단계로 프로그램을 설계한다
