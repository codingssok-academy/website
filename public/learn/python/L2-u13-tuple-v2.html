Chapter 13

튜플
변하지 않는 묶음

여러 값을 하나로 묶되, 한 번 만들면 바꿀 수 없는 튜플을 배웁니다.

이 유닛에서 배우는 것

  • 튜플을 만들고 값을 읽을 수 있습니다.
  • 튜플과 리스트의 차이를 설명할 수 있습니다.
  • 인덱싱과 슬라이싱으로 원하는 값을 꺼낼 수 있습니다.
  • 언패킹으로 변수에 한 번에 나눠 담을 수 있습니다.
  • 좌표 게임에 튜플을 활용할 수 있습니다.

튜플 만들기

튜플은 소괄호 ()로 만듭니다. 리스트와 비슷하지만, 한 번 만들면 값을 바꿀 수 없습니다.

# 튜플 만들기 fruits = ("사과", "바나나", "포도") print(fruits) # ('사과', '바나나', '포도') print(type(fruits)) # <class 'tuple'> # 값 1개짜리 튜플 — 쉼표 필수! one = ("혼자",) print(type(one)) # <class 'tuple'>
따라해보세요
1
좋아하는 과일 3개로 튜플을 만드세요.
fruits = ("딸기", "수박", "망고") print(fruits)
('딸기', '수박', '망고') 출력
2
값 1개짜리 튜플을 쉼표 없이, 있이 비교하세요.
a = ("하나") b = ("하나",) print(type(a), type(b))
<class 'str'> <class 'tuple'>
3
튜플을 수정하려고 하면 에러가 나는지 확인하세요.
colors = ("빨강", "초록", "파랑") colors[0] = "노랑" # TypeError!
TypeError: 'tuple' object does not support item assignment

인덱싱과 슬라이싱

튜플도 리스트처럼 인덱스로 값을 꺼낼 수 있습니다. 음수 인덱스는 뒤에서부터 셉니다.

cities = ("서울", "부산", "대전", "광주") print(cities[0]) # 서울 print(cities[-1]) # 광주 print(cities[1:3]) # ('부산', '대전')
따라해보세요
1
점수 튜플에서 첫 번째와 마지막 값을 꺼내세요.
scores = (95, 87, 72, 100, 63) print(scores[0], scores[-1])
95 63
2
가운데 3개만 슬라이싱하세요.
print(scores[1:4])
(87, 72, 100)
3
len()과 in을 사용해보세요.
print(len(scores)) # 5 print(100 in scores) # True print(50 in scores) # False
5, True, False

언패킹 — 한 번에 나눠 담기

튜플의 값을 여러 변수에 한꺼번에 넣을 수 있습니다. 이것을 언패킹이라고 합니다.

# 언패킹 info = ("민수", 15, "서울") name, age, city = info print(name, age, city) # 민수 15 서울 # 값 교환 (swap) a, b = 10, 20 a, b = b, a print(a, b) # 20 10
따라해보세요
1
언패킹으로 좌표를 분리하세요.
point = (3, 7) x, y = point print(f"x좌표: {x}, y좌표: {y}")
x좌표: 3, y좌표: 7
2
두 변수의 값을 교환하세요.
left, right = "왼쪽", "오른쪽" left, right = right, left print(left, right)
오른쪽 왼쪽
3
튜플 리스트를 반복하며 출력하세요.
students = [("민수", 90), ("서연", 85), ("지호", 95)] for name, score in students: print(f"{name}: {score}점")
민수: 90점 / 서연: 85점 / 지호: 95점

좌표 게임 만들기

튜플로 좌표를 표현하면 게임에서 위치를 다룰 수 있습니다. 보물찾기 게임을 만들어봅시다.

# 좌표 게임 — 보물찾기 player = (1, 2) treasure = (3, 3) px, py = player tx, ty = treasure distance = abs(px - tx) + abs(py - ty) print(f"보물까지 거리: {distance}칸") if player == treasure: print("보물을 찾았다!") else: print(f"아직 {distance}칸 남았어!")

핵심 요약

이 유닛에서 배운 것

  • 튜플은 ()로 만들고, 한 번 만들면 수정할 수 없다
  • 값 1개짜리 튜플은 ("값",)처럼 쉼표가 필수
  • 인덱싱 [0], 슬라이싱 [1:3]으로 값을 꺼낸다
  • 언패킹 a, b = t로 여러 변수에 한 번에 담는다
  • 좌표 같은 변하지 않는 데이터에 튜플을 사용한다
