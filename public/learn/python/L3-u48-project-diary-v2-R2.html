프로젝트:
CSV 성적 관리

CSV 파일을 읽고 쓰는 방법을 익히며, 학생별 평균 계산, 과목별 통계, 석차 계산, 결과 파일 출력 기능을 구현합니다.

이 유닛에서 만드는 것

  • csv.reader로 CSV 파일을 읽어 학생 성적 데이터를 리스트로 변환할 수 있습니다.
  • 학생별 평균을 계산하고 최고/최저 점수를 파악할 수 있습니다.
  • 과목별 전체 학생의 평균, 최고점, 최저점을 계산할 수 있습니다.
  • sorted와 enumerate로 평균 석차를 계산할 수 있습니다.
  • csv.writer로 분석 결과를 새 CSV 파일로 저장할 수 있습니다.
  • try/except로 파일 없음, 잘못된 형식 오류를 안전하게 처리합니다.

Step 1 — CSV 파일 구조와 읽기

CSV(Comma-Separated Values)는 쉼표로 값을 구분하는 텍스트 형식입니다. 엑셀과 호환되며 파이썬 표준 라이브러리인 csv 모듈로 쉽게 처리할 수 있습니다.

import csv def load_scores(filename="scores.csv"): """CSV 파일에서 성적 데이터 읽기""" students = [] try: with open(filename, "r", encoding="utf-8-sig", newline="") as f: reader = csv.reader(f) header = next(reader) # 첫 줄(헤더) 건너뜀 for row in reader: if len(row) < 5: continue name = row[0] scores = [] for s in row[1:]: try: scores.append(int(s)) except ValueError: scores.append(0) students.append({"name": name, "scores": scores}) except FileNotFoundError: print(f"'{filename}' 파일이 없습니다.") return students, header[1:] if header else []
따라해보세요 — CSV 파일 읽기 테스트
STEP 1
scores.csv를 만들고 3명 이상의 학생 데이터를 입력합니다.
STEP 2
students, subjects = load_scores()를 호출합니다.
students 리스트에 각 학생의 이름과 점수가 딕셔너리로 저장됩니다.
STEP 3
print(students[0])로 첫 번째 학생 데이터를 확인합니다.
{"name": "김민준", "scores": [85, 92, 78, 88]} 형식으로 출력됩니다.

Step 2 — 학생별 평균과 과목별 통계

읽어온 데이터를 활용해 학생별 평균 점수를 계산하고, 각 과목별 전체 통계를 산출합니다.

def student_stats(students): """학생별 평균 계산""" for s in students: scores = s["scores"] s["avg"] = round(sum(scores) / len(scores), 1) if scores else 0 s["best"] = max(scores) if scores else 0 s["worst"] = min(scores) if scores else 0 return students def subject_stats(students, subjects): """과목별 전체 통계 출력""" print("\n--- 과목별 통계 ---") for i, subj in enumerate(subjects): col = [s["scores"][i] for s in students if i < len(s["scores"])] if not col: continue avg = round(sum(col) / len(col), 1) print(f"{subj}: 평균={avg}, 최고={max(col)}, 최저={min(col)}") def calc_rank(students): """평균 기준 석차 계산""" ranked = sorted(students, key=lambda x: x["avg"], reverse=True) for rank, s in enumerate(ranked, 1): s["rank"] = rank return students
따라해보세요 — 통계 계산 실행
STEP 1
student_stats(students)를 호출해 각 학생의 avg, best, worst를 채웁니다.
STEP 2
subject_stats(students, subjects)를 호출해 과목별 통계를 출력합니다.
국어: 평균=82.7, 최고=91, 최저=72 형식으로 출력됩니다.
STEP 3
calc_rank(students)로 석차를 계산하고 print(students)로 확인합니다.
각 학생 딕셔너리에 "rank" 키가 추가됩니다.

Step 3 — 결과 CSV 파일로 저장하기

분석이 완료된 데이터를 csv.writer를 사용해 결과 파일로 저장합니다. 헤더를 먼저 쓰고, 각 학생 데이터를 한 행씩 기록합니다.

def save_result(students, subjects, out="result.csv"): """분석 결과를 CSV 파일로 저장""" header = ["이름"] + subjects + ["평균", "최고", "최저", "석차"] with open(out, "w", encoding="utf-8-sig", newline="") as f: writer = csv.writer(f) writer.writerow(header) for s in students: row = [s["name"]] + s["scores"] + [ s.get("avg", 0), s.get("best", 0), s.get("worst", 0), s.get("rank", "-") ] writer.writerow(row) print(f"[저장됨] {out}") def print_report(students, subjects): """터미널에 성적표 출력""" print(f"\n{'이름':<8}" + " ".join(f"{s:<6}" for s in subjects) + " 평균 석차") print("-" * 55) ranked = sorted(students, key=lambda x: x.get("rank", 99)) for s in ranked: scores_str = " ".join(f"{v:<6}" for v in s["scores"]) print(f"{s['name']:<8}{scores_str} {s['avg']:<6} {s['rank']}")
따라해보세요 — 결과 저장 실행
STEP 1
앞에서 만든 student_stats와 calc_rank를 순서대로 실행합니다.
STEP 2
save_result(students, subjects)를 호출해 result.csv를 생성합니다.
[저장됨] result.csv 메시지가 출력됩니다.
STEP 3
print_report(students, subjects)로 터미널에 성적표를 출력합니다.
석차 순으로 정렬된 성적표가 출력됩니다.

Step 4 — 전체 실행 흐름 완성

지금까지 만든 함수들을 main 함수로 연결해 하나의 프로그램으로 완성합니다.

def main(): print("=== CSV 성적 관리 프로그램 ===") filename = input("성적 파일 이름 (기본: scores.csv): ").strip() if not filename: filename = "scores.csv" students, subjects = load_scores(filename) if not students: print("데이터가 없습니다. 프로그램을 종료합니다.") return print(f"\n학생 {len(students)}명 / 과목: {', '.join(subjects)}") students = student_stats(students) students = calc_rank(students) subject_stats(students, subjects) print_report(students, subjects) save_result(students, subjects) main()

핵심 요약

  • import csv — 파이썬 내장 csv 모듈; 설치 없이 사용 가능
  • csv.reader(f) — 파일 객체를 받아 행마다 문자열 리스트로 반환
  • next(reader) — 헤더 첫 줄을 건너뛸 때 사용하는 이터레이터 패턴
  • csv.writer(f).writerow(row) — 리스트를 한 행으로 CSV에 기록
  • encoding="utf-8-sig" — BOM 포함; 엑셀에서 한글 깨짐 방지
  • sorted(..., key=lambda x: x["avg"], reverse=True) — 평균 내림차순 석차 정렬
