프로젝트:
끝말잇기 게임

컴퓨터와 플레이어가 번갈아 단어를 잇는 게임. set으로 사용 단어를 추적하고, 컴퓨터 AI가 자동으로 대응합니다.

이 프로젝트에서 만드는 것

  • set으로 이미 사용된 단어를 추적해 중복 사용을 막을 수 있습니다.
  • 문자열 인덱싱(word[-1], word[0])으로 끝글자와 첫글자를 비교합니다.
  • 리스트 comprehension으로 컴퓨터의 다음 단어 후보를 필터링합니다.
  • while 게임 루프로 게임 흐름을 제어하고 승패를 판단합니다.

핵심 개념 — 문자열 인덱싱과 set

끝말잇기의 핵심 규칙

이전 단어의 마지막 글자(word[-1])와 새 단어의 첫 글자(next_word[0])가 같아야 합니다.

사용된 단어 추적 — set 활용

이미 사용한 단어를 set에 저장합니다. 새 단어가 set에 있으면 중복 사용으로 패배합니다.

Step 1
끝글자 검사 함수 만들기

이전 단어와 새 단어의 연결이 올바른지, 중복인지 검사하는 함수를 만듭니다.

def is_valid(prev_word, new_word, used): # 중복 검사 if new_word in used: return False, "이미 사용된 단어입니다!" # 끝글자 검사 if prev_word[-1] != new_word[0]: return False, f"{prev_word[-1]}로 시작해야 합니다!" return True, "OK" # 테스트 used = {"사과"} print(is_valid("사과", "과자", used)) # (True, "OK") print(is_valid("사과", "사과", used)) # (False, "이미 사용된...") print(is_valid("사과", "바나나", used)) # (False, "과로 시작해야...")

Step 2 — 컴퓨터 AI 응답 만들기

단어 목록에서 끝글자로 시작하고 아직 사용하지 않은 단어를 골라 컴퓨터가 자동으로 대답합니다.

word_pool = [ "사과", "과자", "자동차", "차선", "선물", "물고기", "기차", "차갑다", "다람쥐", "쥐포", "포도", "도서관", "관람객", "객실", "실내", ] def computer_turn(prev_word, used): last_char = prev_word[-1] candidates = [ w for w in word_pool if w[0] == last_char and w not in used ] if not candidates: return None # 컴퓨터가 이을 단어 없음 → 패배 import random chosen = random.choice(candidates) used.add(chosen) return chosen

Step 3 — 게임 루프

플레이어와 컴퓨터가 번갈아 단어를 입력합니다. 잘못된 단어를 입력하거나 컴퓨터가 대답하지 못하면 게임이 끝납니다.

used = set() current_word = "사과" used.add(current_word) print(f"컴퓨터: {current_word}") while True: # 플레이어 차례 player = input("내 차례: ").strip() ok, msg = is_valid(current_word, player, used) if not ok: print(f"패배! {msg}") break used.add(player) current_word = player # 컴퓨터 차례 computer = computer_turn(current_word, used) if computer is None: print("컴퓨터가 이을 단어를 찾지 못했어요. 승리!") break print(f"컴퓨터: {computer}") current_word = computer

전체 흐름 정리

핵심 요약

  • word[-1] — 문자열의 마지막 글자 (끝말잇기 핵심)
  • word[0] — 문자열의 첫 번째 글자
  • set — 중복 없는 컬렉션, in 검사가 리스트보다 빠름
  • list comprehension — [w for w in pool if 조건] 으로 후보 필터링
  • random.choice(candidates) — 후보 중 무작위 선택으로 컴퓨터 AI 구현
  • while True + break — 게임 루프 패턴, 종료 조건에서 break
