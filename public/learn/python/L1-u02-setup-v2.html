Chapter 02

개발 환경 준비

VS Code와 Python을 설치하고, 첫 코드를 실행하는 환경을 만듭니다.

이 유닛에서 배우는 것

  • Python 공식 사이트에서 설치 파일을 다운로드할 수 있습니다.
  • VS Code를 설치하고 Python 확장을 추가할 수 있습니다.
  • REPL에서 코드를 한 줄씩 실행할 수 있습니다.
  • .py 파일을 만들어 터미널에서 실행할 수 있습니다.
  • 자주 하는 설치 실수를 스스로 해결할 수 있습니다.

Python 설치

python.org에서 최신 버전을 다운로드합니다. 설치할 때 Add Python to PATH 체크박스를 반드시 켜세요.

따라해보세요
1
브라우저에서 python.org에 접속하고 Downloads를 클릭하세요.
노란색 Download Python 3.x.x 버튼이 보이면 성공
2
설치 파일을 실행하고, Add Python to PATH를 반드시 체크한 뒤 Install Now를 클릭하세요.
Setup was successful 메시지가 나오면 완료
3
터미널(명령 프롬프트)을 열고 아래 명령어를 입력하세요.
python --version
Python 3.x.x 버전이 표시되면 설치 성공

VS Code 설치와 확장

VS Code는 코드를 작성하는 편집기입니다. Python 확장을 설치하면 자동 완성과 실행 버튼을 사용할 수 있습니다.

따라해보세요
1
code.visualstudio.com에 접속하여 VS Code를 다운로드하고 설치하세요.
VS Code가 실행되면 성공
2
Ctrl+Shift+X를 눌러 확장 탭을 열고, Python을 검색하여 Install을 클릭하세요.
Microsoft의 Python 확장이 설치되면 완료
3
VS Code에서 Ctrl+`를 눌러 터미널을 열고 python --version을 입력하세요.
버전 번호가 표시되면 VS Code와 Python이 연결된 것

REPL 사용법

REPL은 코드를 한 줄 입력하면 바로 결과를 보여주는 대화형 모드입니다. 터미널에서 python만 입력하면 시작됩니다.

따라해보세요
1
터미널에서 python을 입력하여 REPL을 시작하세요.
python
>>> 프롬프트가 나타나면 REPL 진입 성공
2
>>> 뒤에 아래 코드를 입력하고 Enter를 누르세요.
print("Hello, REPL!")
Hello, REPL! 이 바로 출력됩니다
3
exit()를 입력하여 REPL을 종료하세요.
exit()
일반 터미널 프롬프트로 돌아오면 성공

첫 .py 파일 만들기

REPL은 연습용이고, 실제 프로그램은 .py 파일에 저장합니다. 예를 들어 hello.py나 my_name.py를 만들고, python 파일명.py 또는 python my_name.py처럼 터미널에서 실행합니다.

따라해보세요
1
VS Code에서 Ctrl+N으로 새 파일을 만들고, 아래 코드를 입력하세요.
print("Hello, Python!")
코드가 색깔로 표시되면 Python 확장이 동작하는 것
2
Ctrl+S를 눌러 hello.py로 저장하세요. 확장자는 반드시 .py입니다.
파일 탭에 hello.py가 보이면 성공
3
터미널에서 아래 명령어로 파일을 실행하세요.
python hello.py
Hello, Python! 이 출력되면 첫 프로그램 실행 성공

핵심 요약

이 유닛에서 배운 것

  • python.org에서 Python을 설치하고, Add Python to PATH를 반드시 체크한다
  • VS Code를 설치하고 Python 확장을 추가한다
  • 터미널에서 python을 입력하면 REPL이 시작되고, exit()로 종료한다
  • .py 파일에 코드를 저장하고 python 파일명.py로 실행한다
  • PATH 오류가 나면 Python을 재설치하면서 PATH 옵션을 켠다
