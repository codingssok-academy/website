Step 1 — random.sample로 번호 뽑기

random.sample(population, k)는 시퀀스에서 중복 없이 k개를 무작위로 골라 리스트로 반환합니다. 로또처럼 "한 번 뽑은 건 다시 못 뽑는" 경우에 딱 맞습니다.

기본 번호 생성 함수

import random def generate_lotto(): """1~45 중 6개를 뽑아 정렬된 리스트로 반환""" numbers = sorted(random.sample(range(1, 46), 6)) return numbers # 테스트 ticket = generate_lotto() print("내 번호:", ticket)
내 번호: [3, 12, 19, 27, 33, 41]

보너스 번호 추가

보너스 번호는 이미 뽑힌 6개를 제외한 나머지 중에서 1개를 추가로 뽑습니다. set을 활용하면 간단하게 구현할 수 있습니다.

def generate_lotto_with_bonus(): """6개 번호 + 보너스 번호 반환""" all_numbers = list(range(1, 46)) numbers = sorted(random.sample(all_numbers, 6)) # 뽑힌 6개를 제외한 나머지 중 보너스 1개 remaining = list(set(all_numbers) - set(numbers)) bonus = random.choice(remaining) return numbers, bonus nums, bonus = generate_lotto_with_bonus() print(f"번호: {nums}") print(f"보너스: {bonus}")
번호: [7, 14, 22, 31, 38, 43] 보너스: 19

Step 2 — 여러 게임 생성과 당첨 확인

리스트 컴프리헨션으로 원하는 수만큼 게임을 한 번에 만들 수 있습니다. 당첨 확인은 set 교집합(&)으로 일치 개수를 셉니다.

여러 게임 생성 함수

def generate_games(n=5): """n개의 로또 게임을 생성해 리스트로 반환""" return [generate_lotto() for _ in range(n)] games = generate_games(5) for i, g in enumerate(games, 1): print(f"게임 {i}: {g}")
게임 1: [4, 11, 20, 29, 35, 42] 게임 2: [2, 9, 18, 23, 37, 44] 게임 3: [6, 15, 25, 30, 36, 40] 게임 4: [1, 10, 21, 28, 34, 43] 게임 5: [8, 16, 22, 31, 38, 45]

당첨 확인 함수

실제 당첨 번호 리스트와 내 번호 리스트를 set으로 변환해 교집합 크기를 세면 일치 개수를 바로 알 수 있습니다.

def check_prize(my_numbers, winning_numbers, bonus): """당첨 등수 반환 (미당첨은 0 반환)""" match = len(set(my_numbers) & set(winning_numbers)) bonus_hit = bonus in my_numbers if match == 6: return 1 # 1등 elif match == 5 and bonus_hit: return 2 # 2등 elif match == 5: return 3 # 3등 elif match == 4: return 4 # 4등 elif match == 3: return 5 # 5등 else: return 0 # 낙첨

전체 게임 결과 출력

winning = [7, 14, 19, 31, 38, 42] bonus_num = 25 for i, game in enumerate(games, 1): rank = check_prize(game, winning, bonus_num) result = f"{rank}등" if rank > 0 else "낙첨" print(f"게임 {i}: {game} → {result}")

Step 3 — Counter로 번호 통계 분석

collections.Counter는 요소의 등장 횟수를 자동으로 세는 딕셔너리 서브클래스입니다. 많은 게임을 시뮬레이션하고 가장 자주 나온 번호를 찾는 데 적합합니다.

통계 함수 구현

from collections import Counter def lotto_statistics(num_games=1000, top_n=10): """num_games번 시뮬레이션 후 자주 나온 번호 top_n개 반환""" all_numbers = [] for _ in range(num_games): all_numbers.extend(generate_lotto()) counter = Counter(all_numbers) return counter.most_common(top_n) top10 = lotto_statistics(1000, 10) print("자주 나온 번호 Top 10:") for num, count in top10: bar = "#" * (count // 5) print(f" {num:2d}번: {count:4d}회 {bar}")

Step 4 — 완성 코드 통합

지금까지 만든 함수들을 하나로 모아 메뉴 방식으로 실행하는 완성 프로그램입니다.

import random from collections import Counter def generate_lotto(): return sorted(random.sample(range(1, 46), 6)) def generate_lotto_with_bonus(): all_n = list(range(1, 46)) nums = sorted(random.sample(all_n, 6)) bonus = random.choice(list(set(all_n) - set(nums))) return nums, bonus def generate_games(n=5): return [generate_lotto() for _ in range(n)] def check_prize(my_numbers, winning_numbers, bonus): match = len(set(my_numbers) & set(winning_numbers)) bonus_hit = bonus in my_numbers if match == 6: return 1 if match == 5 and bonus_hit: return 2 if match == 5: return 3 if match == 4: return 4 if match == 3: return 5 return 0 def lotto_statistics(num_games=1000, top_n=10): all_n = [] for _ in range(num_games): all_n.extend(generate_lotto()) return Counter(all_n).most_common(top_n)

핵심 요약

  • random.sample(range(1, 46), 6) — 1~45 중 중복 없이 6개 추출
  • sorted() — 리스트를 오름차순으로 정렬해 새 리스트 반환
  • set(A) & set(B) — 두 리스트의 교집합, 일치 개수를 len()으로 확인
  • list.extend(iterable) — 다른 리스트의 원소를 하나씩 추가 (append는 통째로 추가)
  • Counter(list).most_common(n) — 빈도 상위 n개를 (원소, 횟수) 리스트로 반환
  • 리스트 컴프리헨션 [f() for _ in range(n)]으로 n개 게임을 한 줄에 생성
  • 당첨 등수: 6개 일치=1등, 5개+보너스=2등, 5개=3등, 4개=4등, 3개=5등
함수/메서드 역할 핵심 파라미터
random.sample 중복 없이 k개 추출 population, k
sorted() 정렬된 새 리스트 반환 iterable, reverse=False
set() & 교집합 — 두 집합의 공통 원소 set A & set B
list.extend() 원소를 하나씩 추가 iterable
Counter.most_common(n) 빈도 상위 n개 반환 n (생략 시 전체)
