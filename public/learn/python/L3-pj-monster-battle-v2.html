Monster 클래스를 만들고 이름/HP/공격력/방어력 속성, 속성 상성(불>풀>물>불), 턴제 전투, 레벨업 시스템을 구현합니다. 파이썬 클래스의 핵심을 게임으로 배웁니다.

이 유닛에서 만드는 것

  • class Monster를 정의하고 __init__()으로 속성을 초기화할 수 있습니다.
  • 메서드로 공격, 피해 받기, 상태 출력 기능을 구현할 수 있습니다.
  • 딕셔너리로 속성 상성표를 만들어 데미지를 배율로 적용할 수 있습니다.
  • while 루프로 턴제 전투를 구현하고 승패를 판정할 수 있습니다.
  • 경험치(exp) 누적으로 레벨업 시스템을 만들 수 있습니다.

Step 1 — Monster 클래스 설계

클래스(class)는 같은 종류의 객체를 찍어내는 틀입니다. Monster 클래스를 만들면 불꽃도마뱀, 물고기 등 여러 몬스터를 같은 틀로 쉽게 생성할 수 있습니다. __init__()은 객체 생성 시 자동으로 실행됩니다.

# monster_battle.py — Step 1: Monster 클래스 import random class Monster: def __init__(self, name, hp, attack, defense, element="일반"): self.name = name self.hp = hp self.max_hp = hp self.attack = attack self.defense = defense self.element = element self.level = 1 self.exp = 0 def status(self): """현재 상태 출력""" bar = "#" * (self.hp * 10 // self.max_hp) print(f"[Lv.{self.level}] {self.name} ({self.element})") print(f" HP: [{bar:<10}] {self.hp}/{self.max_hp}")

Step 2 — 속성 상성과 공격 메서드

속성 상성은 딕셔너리로 표현합니다. "불"이 "풀"에게 유리하면 데미지 배율을 1.5배, 불리하면 0.5배로 적용합니다. 공격력에서 방어력을 뺀 값에 배율을 곱해 최종 데미지를 계산합니다.

# Step 2: 속성 상성 딕셔너리 + 공격 메서드 # 클래스 밖에 상성 표 정의 ADVANTAGE = { "불": "풀", # 불이 풀에 유리 "풀": "물", "물": "불", } # Monster 클래스에 메서드 추가 def do_attack(self, target): """target에게 공격. 속성 상성 반영""" multiplier = 1.0 if ADVANTAGE.get(self.element) == target.element: multiplier = 1.5 # 유리 elif ADVANTAGE.get(target.element) == self.element: multiplier = 0.5 # 불리 raw = max(1, self.attack - target.defense) damage = int(raw * multiplier) target.hp = max(0, target.hp - damage) tag = "(효과적!)" if multiplier > 1 else "(효과 없음)" if multiplier < 1 else "" print(f"{self.name}의 공격! {damage} 데미지 {tag}") return damage
불꽃도마뱀의 공격! 22 데미지 (효과적!) 물고기전사의 공격! 6 데미지 (효과 없음)

Step 3 — 턴제 전투 시스템

while 루프로 두 몬스터가 번갈아 공격합니다. 어느 한 쪽의 HP가 0이 되면 전투가 끝납니다. 각 턴마다 두 몬스터의 상태를 출력해 전투 진행을 보여줍니다.

# Step 3: 턴제 전투 def battle(m1, m2): """두 몬스터가 싸워서 승자를 반환""" turn = 1 print(f"=== 배틀 시작: {m1.name} vs {m2.name} ===") while m1.hp > 0 and m2.hp > 0: print(f"\n--- Turn {turn} ---") m1.do_attack(m2) if m2.hp > 0: m2.do_attack(m1) m1.status() m2.status() turn += 1 winner = m1 if m1.hp > 0 else m2 print(f"\n{winner.name} 승리!") winner.gain_exp(30) return winner

Step 4 — 레벨업 시스템

경험치(exp)를 누적하다 일정 기준(level × 50)을 넘으면 레벨이 오릅니다. 레벨업 시 HP, 공격력, 방어력이 모두 상승합니다.

# Step 4: 레벨업 메서드 (Monster 클래스에 추가) def gain_exp(self, amount): """경험치 획득. 조건 충족 시 레벨업""" self.exp += amount print(f"{self.name} +{amount} EXP (총 {self.exp})") if self.exp >= self.level * 50: self.level += 1 self.max_hp += 10 self.hp = self.max_hp # HP 회복 self.attack += 3 self.defense += 2 print(f" 레벨업! {self.name} → Lv.{self.level}")
=== 배틀 시작: 불꽃도마뱀 vs 물고기전사 === --- Turn 1 --- 불꽃도마뱀의 공격! 8 데미지 (효과 없음) 물고기전사의 공격! 24 데미지 (효과적!) ... 물고기전사 승리! 물고기전사 +30 EXP (총 30) 레벨업! 물고기전사 → Lv.2

호출 m1.hp = 40; m1.heal(50)
출력 불꽃도마뱀 HP 50 회복! (80/80)
힌트 보기
self.hp = min(self.hp + amount, self.max_hp) 로 HP를 증가시키되 max_hp를 넘지 않게 하세요.
정답 보기
def heal(self, amount): old_hp = self.hp self.hp = min(self.hp + amount, self.max_hp) healed = self.hp - old_hp print(f"{self.name} HP {healed} 회복! ({self.hp}/{self.max_hp})")

핵심 요약

  • class 이름:으로 클래스를 정의하고 __init__(self, ...)으로 속성을 초기화합니다.
  • self는 인스턴스 자기 자신을 가리킵니다.
  • 딕셔너리 ADVANTAGE로 속성 상성을 표현하고 데미지 배율을 적용합니다.
  • while HP > 0 루프로 턴제 전투를 구현합니다.
  • 경험치 누적으로 레벨업 시 HP/공격력/방어력이 자동 상승합니다.
