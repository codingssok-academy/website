출석부

세트(set)로 출석 체크, 결석자 찾기, 집합 연산으로 출결 현황을 분석하는 프로그램을 만듭니다.

이 프로젝트에서 배우는 것

  • set()으로 중복 없는 집합 자료형을 만들 수 있습니다.
  • add()로 출석 체크, discard()로 결석 처리를 할 수 있습니다.
  • 차집합(-)으로 결석자를 자동으로 찾을 수 있습니다.
  • 교집합(&), 합집합(|)으로 데이터를 비교할 수 있습니다.
  • in 연산자로 특정 학생이 출석했는지 확인할 수 있습니다.

세트(set) 사용하기

세트는 중복이 없는 자료형입니다. 출석부에 딱 맞는 도구입니다. 같은 이름을 두 번 추가해도 한 번만 저장됩니다.

# 전체 학생 명단 (세트) all_students = {"김민준", "이서연", "박지호", "최유진", "정다은"} # 출석 세트 (처음엔 비어있음) present = set() # 출석 체크 — add()로 추가 present.add("김민준") present.add("이서연") present.add("박지호") print(f"출석: {present}") print(f"출석 인원: {len(present)}명")
# 차집합으로 결석자 자동 계산 absent = all_students - present print(f"결석자: {absent}") print(f"결석 인원: {len(absent)}명") # 특정 학생 출석 확인 if "최유진" in present: print("최유진: 출석") else: print("최유진: 결석")

집합 연산으로 출결 분석

두 날의 출석 데이터를 집합 연산으로 비교합니다. 교집합(&)은 둘 다 출석한 학생, 합집합(|)은 한 번이라도 출석한 학생을 찾습니다.

# 월요일 출석 monday = {"김민준", "이서연", "박지호"} # 화요일 출석 tuesday = {"이서연", "박지호", "최유진"} # 교집합: 월-화 모두 출석 both = monday & tuesday print(f"이틀 모두 출석: {both}") # 합집합: 한 번이라도 출석 any_day = monday | tuesday print(f"한 번이라도 출석: {any_day}") # 월요일만 출석한 사람 only_monday = monday - tuesday print(f"월요일만 출석: {only_monday}")
따라해보세요

이틀 모두 출석한 학생 집합

완성: 출석부 프로그램

입력으로 출석 체크를 하고 결석자를 자동으로 찾는 완전한 출석부 프로그램을 만듭니다.

# 전체 학생 명단 all_students = {"김민준", "이서연", "박지호", "최유진", "정다은"} present = set() print("출석 체크 시작! (끝내려면 '완료' 입력)") while True: name = input("출석 이름: ") if name == "완료": break if name in all_students: present.add(name) print(f"{name} 출석 확인!") else: print(f"{name}: 명단에 없는 학생") absent = all_students - present rate = len(present) / len(all_students) * 100 print(f"\n출석: {len(present)}명 / {len(all_students)}명") print(f"출석률: {rate:.0f}%") print(f"결석자: {absent if absent else '없음'}")

핵심 요약

이 유닛에서 배운 것

  • set()은 중복이 없는 자료형 — 같은 값을 여러 번 추가해도 한 번만 저장
  • .add(값)으로 추가, .discard(값)으로 제거
  • 값 in 세트로 포함 여부를 True/False로 확인
  • 차집합 A - B: A에는 있고 B에는 없는 것 (결석자 찾기)
  • 교집합 A & B: 둘 다 있는 것 (둘 다 출석)
  • 합집합 A | B: 어느 한쪽에라도 있는 것
