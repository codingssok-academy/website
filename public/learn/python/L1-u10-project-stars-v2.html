Chapter 10

프로젝트: 별로 그림 그리기

print()와 문자열 반복(*)을 활용하여 사각형, 삼각형, 피라미드, 다이아몬드 패턴을 만듭니다.

이 유닛에서 배우는 것

  • 문자열 반복 연산자 *로 별 패턴을 만들 수 있습니다.
  • for 반복문과 print()로 사각형을 출력할 수 있습니다.
  • 삼각형, 피라미드, 역삼각형 패턴을 코드로 구현할 수 있습니다.
  • 공백과 별을 조합하여 다이아몬드를 완성할 수 있습니다.

사각형 패턴 - 가장 기본

문자열에 * 연산자를 사용하면 같은 문자를 여러 번 반복할 수 있습니다. "*" * 5는 "*****"가 됩니다.

for 반복문으로 같은 줄을 여러 번 출력하면 사각형이 됩니다.

# 4x4 사각형 for i in range(4): print("*" * 4)
따라해보세요
1
4x4 사각형을 출력하세요.
for i in range(4): print("*" * 4)
4줄의 **** 이 출력되면 성공
2
크기를 바꿔 6x3 직사각형을 만들어보세요.
for i in range(3): print("*" * 6)
3줄의 ****** 이 출력되면 성공
3
별 대신 # 문자로 5x5 사각형을 만들어보세요.
for i in range(5): print("#" * 5)
5줄의 ##### 이 출력되면 성공

삼각형 패턴 - 점점 커지는 별

반복 변수 i를 활용하면 줄마다 별의 개수를 다르게 할 수 있습니다. range(1, 6)은 1부터 5까지 반복합니다.

# 직각삼각형 for i in range(1, 6): print("*" * i)
따라해보세요
1
높이 5인 직각삼각형을 출력하세요.
for i in range(1, 6): print("*" * i)
* 부터 ***** 까지 출력되면 성공
2
높이를 8로 바꿔보세요.
for i in range(1, 9): print("*" * i)
8줄짜리 삼각형이 출력되면 성공
3
숫자로 삼각형을 만들어보세요. str(i)로 숫자를 문자열로 바꿉니다.
for i in range(1, 6): print(str(i) * i)
1 / 22 / 333 / 4444 / 55555 가 출력되면 성공

피라미드 - 공백과 별의 조합

피라미드는 별 앞에 공백을 넣어 가운데 정렬하는 패턴입니다. 높이가 n일 때, i번째 줄의 공백은 n - i개, 별은 2 * i - 1개입니다.

# 높이 5 피라미드 n = 5 for i in range(1, n + 1): print(" " * (n - i) + "*" * (2 * i - 1))

역삼각형은 반대로, 별이 줄어들면서 공백이 늘어납니다.

# 높이 5 역삼각형 n = 5 for i in range(n, 0, -1): print(" " * (n - i) + "*" * (2 * i - 1))
따라해보세요
1
높이 5인 피라미드를 출력하세요.
n = 5 for i in range(1, n + 1): print(" " * (n - i) + "*" * (2 * i - 1))
꼭대기 * 에서 아래쪽 ********* 까지 출력되면 성공
2
높이 5인 역삼각형을 출력하세요.
n = 5 for i in range(n, 0, -1): print(" " * (n - i) + "*" * (2 * i - 1))
위에서 아래로 별이 줄어들면 성공
3
높이를 7로 바꿔서 큰 피라미드를 만들어보세요.
n = 7 for i in range(1, n + 1): print(" " * (n - i) + "*" * (2 * i - 1))
7줄짜리 피라미드가 출력되면 성공

다이아몬드 - 피라미드 + 역삼각형

다이아몬드는 피라미드(윗부분)와 역삼각형(아랫부분)을 합친 모양입니다. 윗부분은 range(1, n+1), 아랫부분은 range(n-1, 0, -1)로 만듭니다.

# 다이아몬드 (높이 n=3 기준, 총 5줄) n = 3 # 윗부분 (피라미드) for i in range(1, n + 1): print(" " * (n - i) + "*" * (2 * i - 1)) # 아랫부분 (역삼각형) for i in range(n - 1, 0, -1): print(" " * (n - i) + "*" * (2 * i - 1))
따라해보세요
1
n=3으로 다이아몬드를 출력하세요. (총 5줄)
n = 3 for i in range(1, n + 1): print(" " * (n - i) + "*" * (2 * i - 1)) for i in range(n - 1, 0, -1): print(" " * (n - i) + "*" * (2 * i - 1))
마름모 모양이 출력되면 성공
2
n=5로 큰 다이아몬드를 만들어보세요. (총 9줄)
n = 5 for i in range(1, n + 1): print(" " * (n - i) + "*" * (2 * i - 1)) for i in range(n - 1, 0, -1): print(" " * (n - i) + "*" * (2 * i - 1))
9줄짜리 큰 다이아몬드가 출력되면 성공
3
별 대신 @ 문자로 다이아몬드를 만들어보세요.
n = 4 for i in range(1, n + 1): print(" " * (n - i) + "@" * (2 * i - 1)) for i in range(n - 1, 0, -1): print(" " * (n - i) + "@" * (2 * i - 1))
@ 문자로 다이아몬드가 출력되면 성공

직접 풀어보세요

Q1
오른쪽 정렬 삼각형
쉬움
공백과 * 반복을 사용하여, 높이 5인 오른쪽 정렬 삼각형을 출력하세요.
출력 * ** *** **** *****
내 답안
힌트 보기
공백 개수는 n - i이고, 별 개수는 i입니다.
정답 확인
for i in range(1, 6): print(" " * (5 - i) + "*" * i)
Q2
속이 빈 사각형
보통
for 반복문과 조건문을 사용하여, 5x5 속이 빈 사각형을 출력하세요. 첫 줄과 마지막 줄은 별로 가득 채우고, 중간 줄은 양 끝만 별입니다.
출력***** * * * * * * *****
내 답안
힌트 보기
첫 줄(i=0)과 마지막 줄(i=4)은 "*" * 5, 나머지는 "*" + " " * 3 + "*"입니다.
정답 확인
for i in range(5): if i == 0 or i == 4: print("*" * 5) else: print("*" + " " * 3 + "*")
Q3
모래시계 패턴
어려움
역삼각형 아래에 삼각형을 붙여서 모래시계 패턴을 출력하세요. 높이 n=4로 총 7줄입니다. 공백과 * 반복을 조합하세요.
출력******* ***** *** * *** ***** *******
내 답안
힌트 보기
윗부분은 range(n, 0, -1)로 역삼각형, 아랫부분은 range(2, n+1)로 삼각형입니다.
정답 확인
n = 4 for i in range(n, 0, -1): print(" " * (n - i) + "*" * (2 * i - 1)) for i in range(2, n + 1): print(" " * (n - i) + "*" * (2 * i - 1))

핵심 요약

이 유닛에서 배운 것

  • "*" * n으로 문자열을 n번 반복할 수 있다
  • for 반복문으로 같은 줄을 여러 번 출력하면 사각형이 된다
  • 반복 변수 i를 활용하면 줄마다 별 개수를 바꿔 삼각형을 만든다
  • 공백(" " * (n-i))과 별("*" * (2*i-1))을 조합하면 피라미드가 된다
  • 피라미드 + 역삼각형 = 다이아몬드, 역삼각형 + 삼각형 = 모래시계
