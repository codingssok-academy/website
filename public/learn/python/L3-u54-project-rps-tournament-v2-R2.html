미로 찾기

2차원 리스트로 미로를 표현하고, 재귀 DFS 알고리즘으로 출구까지의 경로를 자동 탐색해 화면에 출력합니다.

이 유닛에서 만드는 것

  • 2차원 리스트로 미로 지도를 표현하고 maze[row][col]로 접근할 수 있습니다.
  • 재귀 DFS(깊이 우선 탐색)로 출구까지 경로를 자동 탐색할 수 있습니다.
  • 방문 표시(visited)로 이미 방문한 곳을 제외해 무한 루프를 방지할 수 있습니다.
  • 탐색 성공/실패 경로를 구분해 경로 리스트를 출력할 수 있습니다.

Step 1 — 2차원 리스트로 미로 표현

미로는 2차원 리스트로 표현합니다. 0은 이동 가능한 길, 1은 벽입니다. 각 칸은 maze[행][열]로 접근합니다.

MAZE = [ [1, 0, 1, 1, 1], # row 0 — S=(0,1) [0, 0, 0, 1, 0], # row 1 [1, 1, 0, 0, 0], # row 2 [0, 1, 0, 1, 0], # row 3 [0, 0, 1, 0, 0], # row 4 — E=(4,4) ] ROWS = len(MAZE) COLS = len(MAZE[0]) START = (0, 1) # (행, 열) END = (4, 4)

이동 방향은 4가지입니다. 각 방향을 리스트로 정의하면 반복문으로 처리할 수 있습니다.

DIRECTIONS = [(-1, 0), (1, 0), (0, -1), (0, 1)] # 상, 하, 좌, 우 def in_bounds(r: int, c: int) -> bool: """좌표가 미로 범위 안인지 확인""" return 0 <= r < ROWS and 0 <= c < COLS def is_passable(r: int, c: int) -> bool: """벽이 아니고 범위 안인지 확인""" return in_bounds(r, c) and MAZE[r][c] == 0

Step 2 — 재귀 DFS로 경로 탐색

DFS(깊이 우선 탐색)는 한 방향으로 갈 수 있는 데까지 깊이 파고든 다음, 막히면 돌아와서 다른 방향을 시도합니다. 재귀로 자연스럽게 표현됩니다.

DFS 재귀 탐색 함수

visited = [[False] * COLS for _ in range(ROWS)] def dfs(r: int, c: int, path: list) -> bool: """(r,c)에서 END까지 경로 탐색. 성공이면 True, path에 경로 저장""" if (r, c) == END: # 기저 사례: 목적지 도착 path.append((r, c)) return True if not is_passable(r, c): # 기저 사례: 이동 불가 return False if visited[r][c]: # 기저 사례: 이미 방문 return False visited[r][c] = True # 방문 표시 path.append((r, c)) for dr, dc in DIRECTIONS: # 4방향 탐색 if dfs(r + dr, c + dc, path): return True path.pop() # 백트래킹: 실패한 칸 제거 visited[r][c] = False return False

Step 3 — 경로 출력과 미로 시각화

탐색된 경로를 미로 위에 표시해 출력하면 결과를 직관적으로 확인할 수 있습니다. path에 담긴 좌표 집합을 활용합니다.

def print_maze(path: list): """미로를 경로와 함께 출력""" path_set = set(path) # 빠른 포함 여부 확인 for r in range(ROWS): row_str = "" for c in range(COLS): if (r, c) == START: row_str += "S" elif (r, c) == END: row_str += "E" elif (r, c) in path_set: row_str += "*" elif MAZE[r][c] == 1: row_str += "#" else: row_str += "." print(row_str)

def solve_maze(): """미로 탐색 전체 실행""" path = [] visited = [[False] * COLS for _ in range(ROWS)] sr, sc = START print("=== 미로 탐색 시작 ===") print_maze([]) print() found = dfs(sr, sc, path) if found: print(f"경로 발견! 길이: {len(path)}칸") print_maze(path) print(f"좌표 순서: {path}") else: print("경로 없음") solve_maze()

Step 4 — 확장: 이동 횟수 카운터와 다중 경로

탐색 중 방문한 칸의 총 횟수를 세거나, 여러 경로 중 가장 짧은 것을 찾는 방식으로 확장할 수 있습니다.

1
방문 횟수 카운터 추가
쉬움

dfs()에 count 매개변수(가변 컨테이너 리스트)를 추가해 탐색 중 방문한 총 칸 수를 기록하세요. 경로 찾기 성공/실패와 무관하게 방문할 때마다 count[0] += 1을 실행합니다.

예) count = [0]; dfs(..., count) → count[0]에 방문 수
힌트 보기
Python에서 int는 재귀 중 변경이 어렵습니다. count = [0] 처럼 리스트로 감싸면 재귀 깊이에 관계없이 공유됩니다.
정답 보기
def dfs(r, c, path, count): if not is_passable(r, c) or visited[r][c]: return False count[0] += 1 # 방문 카운트 visited[r][c] = True path.append((r, c)) if (r, c) == END: return True for dr, dc in DIRECTIONS: if dfs(r+dr, c+dc, path, count): return True path.pop() return False
2
경로를 방향 문자열로 출력
보통

path 좌표 리스트를 받아 각 이동이 상/하/좌/우 중 어느 방향인지 문자열로 반환하는 path_to_directions(path) 함수를 작성하세요.

예) [(0,1),(1,1)] → ["하"]
힌트 보기
연속된 두 좌표의 차이(dr=next_r - r, dc=next_c - c)를 딕셔너리에서 매핑합니다. {(-1,0):"상",(1,0):"하",(0,-1):"좌",(0,1):"우"}
정답 보기
DIR_MAP = {(-1,0):"상",(1,0):"하",(0,-1):"좌",(0,1):"우"} def path_to_directions(path): result = [] for i in range(1, len(path)): dr = path[i][0] - path[i-1][0] dc = path[i][1] - path[i-1][1] result.append(DIR_MAP[(dr, dc)]) return result
3
랜덤 미로 생성기
어려움

random.random()을 사용해 n×n 크기의 미로를 무작위로 생성하는 generate_maze(n, prob=0.3)를 작성하세요. 각 칸이 prob 확률로 벽이 됩니다. START와 END는 항상 0으로 설정합니다.

예) generate_maze(5, 0.3) → 5x5 미로 리스트
힌트 보기
2중 리스트 컴프리헨션으로 생성합니다. [[1 if random.random() < prob else 0 for _ in range(n)] for _ in range(n)] 후 [0][0]과 [n-1][n-1]을 0으로 강제 설정합니다.
정답 보기
import random def generate_maze(n, prob=0.3): maze = [[1 if random.random() < prob else 0 for _ in range(n)] for _ in range(n)] maze[0][0] = 0 maze[n-1][n-1] = 0 return maze

핵심 요약

  • 2차원 리스트: maze[r][c]로 행/열 접근 — 0 길, 1 벽으로 미로 표현
  • DFS 기저 사례 2가지: 목적지 도착(return True), 벽/방문(return False)
  • visited[r][c] = True: 방문 표시로 무한 루프 방지 — 반드시 탐색 전 설정
  • 백트래킹: path.pop() + visited[r][c] = False — 실패한 경로를 되돌림
  • set(path): 리스트를 집합으로 변환 — in 연산이 O(1)로 빨라짐
  • DFS vs BFS: DFS는 경로 존재 확인, BFS는 최단 경로 탐색에 적합
