타로 카드 뽑기

22장 메이저 아르카나 카드를 딕셔너리로 저장하고, random.sample로 3장을 뽑아 과거/현재/미래 해석을 포맷팅하여 출력하는 타로 점술 프로그램을 만듭니다.

이 프로젝트에서 만드는 것

  • 22장 메이저 아르카나 카드를 이름, 번호, 정방향/역방향 키워드가 담긴 딕셔너리로 저장합니다.
  • random.sample()로 22장 중 3장을 중복 없이 무작위 선택합니다.
  • 선택된 카드에 무작위로 정방향/역방향을 배정합니다.
  • 과거/현재/미래 포지션별로 카드 이름과 해석 키워드를 포맷팅합니다.
  • 질문 입력, 반복 뽑기, 히스토리 저장 기능을 추가합니다.

연습 문제

Q1
random.sample 결과 이해
쉬움
22장 카드에서 random.sample(리스트, 5)를 실행하면 몇 장이 선택되고, 같은 카드가 두 번 선택될 수 있나요? 이유도 설명하세요.
결과5장이 선택됨 / 중복 여부: ?
내 답안
힌트 보기
random.sample은 "비복원 추출"입니다. 한 번 선택된 항목은 다시 선택 대상에서 제외됩니다.
정답 보기
5장이 선택되고, 같은 카드는 절대 두 번 선택되지 않습니다. random.sample은 비복원 추출 방식으로, 선택된 항목을 다시 고르지 않기 때문입니다. (셔플 후 앞 k개를 가져오는 방식)

Q3
특정 카드 통계
어려움
100번 타로 리딩을 시뮬레이션하고, 가장 자주 나온 카드 Top 3를 출력하는 코드를 작성하세요. 딕셔너리로 각 카드의 등장 횟수를 카운트하세요.
출력1위: 태양 (17회), 2위: 별 (15회), ...
내 답안
힌트 보기
counts = {} 딕셔너리를 만들고 counts.get(card, 0) + 1 패턴으로 카운트. sorted(counts.items(), key=lambda x: x[1], reverse=True)[:3]으로 Top 3 추출하세요.
정답 보기
counts = {} for _ in range(100): drawn = random.sample(list(TAROT_CARDS.keys()), 3) for card in drawn: counts[card] = counts.get(card, 0) + 1 top3 = sorted(counts.items(), key=lambda x: x[1], reverse=True)[:3] for rank, (card, cnt) in enumerate(top3, 1): print(f"{rank}위: {card} ({cnt}회)")

핵심 요약

  • random.sample(seq, k) — k개를 중복 없이 선택 (비복원 추출)
  • random.choice([True, False]) — 정방향/역방향 무작위 배정
  • ', '.join(리스트) — 리스트 원소를 구분자로 연결해 문자열 생성
  • 조건부 표현식 — 조건이 참이면 A 거짓이면 B를 반환하는 한 줄 if/else
  • 딕셔너리 안에 리스트 — 카드 키워드처럼 여러 값을 가질 때 활용
  • sorted(dict.items(), key=lambda x: x[1], reverse=True) — 빈도 순 정렬
