Chapter 05

프로젝트: 자기소개 프로그램

print()로 배운 모든 기법을 활용하여 자기소개 프로그램을 완성합니다.

이 유닛에서 배우는 것

  • print()의 다양한 기능을 종합적으로 활용할 수 있습니다.
  • 출력 결과를 먼저 설계하고 코드로 구현할 수 있습니다.
  • sep, end, 이스케이프 문자, 삼중 따옴표를 적재적소에 사용할 수 있습니다.
  • ASCII 아트를 코드로 표현할 수 있습니다.
  • 완성된 프로그램을 단계적으로 개선할 수 있습니다.
왜 이걸 배울까? 지금까지 배운 print()의 다양한 기능들을 하나의 프로그램으로 합쳐봅니다. 개별 기능을 아는 것과 그것을 조합해서 완성품을 만드는 것은 완전히 다릅니다. 이 프로젝트가 "코드로 무언가를 만드는" 첫 경험이 됩니다.

프로젝트 소개

이번 유닛에서는 지금까지 배운 print() 기능을 총동원하여 자기소개 프로그램을 만듭니다. 단순히 글자를 나열하는 것이 아니라, 테두리, 정렬, ASCII 아트까지 포함된 완성도 있는 프로그램을 목표로 합니다.

프로젝트는 4단계로 진행됩니다. 각 단계를 완성한 뒤 실행해 보고, 다음 단계로 넘어갑니다.

1단계: 기본 자기소개
이름, 나이, 학교 등 기본 정보를 출력합니다.
2
2단계: 테두리 추가
출력에 테두리를 넣어 명함처럼 꾸밉니다.
3
3단계: ASCII 아트 추가
문자로 만든 그림을 프로그램에 추가합니다.
4
4단계: 종합 완성
sep, end, 이스케이프 문자를 활용하여 최종 버전을 완성합니다.

새로운 도구 — 문자열 반복(*)

프로젝트를 시작하기 전에, 테두리를 만들 때 유용한 도구를 하나 배웁니다. 문자열에 * 연산자를 사용하면 해당 문자열을 반복할 수 있습니다.

2print("-" * 20)
3print("Ha" * 5)
4print("*" * 10)

자기소개 프로그램을 만들 때 사용한 print() 기법을 모두 나열하십시오. 각 기법이 어떤 역할을 했는지 한 줄로 설명합니다.

설명하기

ASCII 아트를 코드로 작성할 때 주의해야 할 점을 2가지 적으십시오.

용어 정리

용어설명
문자열 반복(*)"문자" * 숫자 형태로 문자열을 반복. "=" * 10 → "=========="
ASCII 아트문자(글자, 기호)만으로 그림을 표현하는 기법
구분선출력에서 섹션을 시각적으로 나누는 선. "-" * 30 등으로 만듦
테두리출력을 감싸는 틀. |, +, - 등의 문자로 구성
정렬출력의 위치를 맞추는 것. 공백을 넣어 오른쪽 |를 일치시키는 것
.center()문자열을 지정한 너비의 가운데에 배치하는 메서드 (미리보기)
코드 리뷰작성된 코드를 읽고 개선할 점을 찾는 활동
리팩토링동작은 같지만 코드를 더 깔끔하고 효율적으로 고치는 것

핵심 요약

이 유닛에서 배운 것
1. "문자" * 숫자로 문자열을 반복할 수 있다 (테두리, 구분선에 활용)
2. 프로젝트를 4단계로 나누어 점진적으로 완성했다
3. 1단계: 기본 정보 → 2단계: 테두리 → 3단계: ASCII 아트 → 4단계: 종합
