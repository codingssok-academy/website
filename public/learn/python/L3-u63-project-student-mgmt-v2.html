Step 1 — Student 클래스 설계와 성적 관리

클래스를 사용하면 학생 한 명의 데이터(이름, 학번, 성적)를 하나의 객체로 묶어서 관리할 수 있습니다. 성적은 과목 이름을 키, 점수를 값으로 하는 딕셔너리로 저장합니다.

class Student: """학생 한 명의 정보를 담는 클래스""" def __init__(self, name, student_id): self.name = name self.student_id = student_id self.grades = {} # {과목명: 점수} def add_grade(self, subject, score): """성적 추가 (이미 있으면 오류 메시지)""" if subject in self.grades: print(f"{subject} 과목이 이미 있습니다. update_grade를 사용하세요.") return self.grades[subject] = score def update_grade(self, subject, score): """성적 수정 (없으면 오류 메시지)""" if subject not in self.grades: print(f"{subject} 과목이 없습니다.") return self.grades[subject] = score def delete_grade(self, subject): """성적 삭제""" if subject not in self.grades: print(f"{subject} 과목이 없습니다.") return del self.grades[subject]

사용 예시

s = Student("김민준", "2024001") s.add_grade("수학", 92) s.add_grade("영어", 85) s.add_grade("국어", 78) print(s.grades) # {'수학': 92, '영어': 85, '국어': 78} s.update_grade("영어", 90) s.delete_grade("국어") print(s.grades) # {'수학': 92, '영어': 90}

Step 2 — 과목별 평균과 석차 계산

평균은 성적 딕셔너리의 값들을 sum()과 len()으로 계산합니다. 석차는 여러 학생의 평균을 sorted()의 key 인자로 정렬해 순위를 매깁니다.

평균 계산 메서드

class Student: # ... (기존 코드 이어서) def average(self): """전 과목 평균 반환 (과목 없으면 0)""" if not self.grades: return 0 return round(sum(self.grades.values()) / len(self.grades), 2) def subject_average(self, subject): """특정 과목 점수 반환""" return self.grades.get(subject, "과목 없음")

석차 계산 함수

sorted()의 key에 lambda를 사용해 평균 기준 내림차순으로 정렬하면 석차를 자동으로 매길 수 있습니다.

def rank_students(students): """학생 리스트를 평균 기준으로 석차 매겨 반환""" ranked = sorted(students, key=lambda s: s.average(), reverse=True) for i, s in enumerate(ranked, 1): print(f"{i}등 {s.name} ({s.student_id}) 평균: {s.average()}") return ranked # 테스트 students = [ Student("김민준", "2024001"), Student("이서연", "2024002"), Student("박지호", "2024003"), ] students[0].add_grade("수학", 92); students[0].add_grade("영어", 85) students[1].add_grade("수학", 95); students[1].add_grade("영어", 90) students[2].add_grade("수학", 78); students[2].add_grade("영어", 82) rank_students(students)

Step 3 — CSV 저장과 불러오기

csv 모듈을 사용하면 학생 데이터를 스프레드시트에서 열 수 있는 형식으로 저장할 수 있습니다. 저장할 때 과목 목록을 먼저 모아 헤더를 만들고, 불러올 때 다시 Student 객체로 복원합니다.

CSV 저장 함수

import csv def save_to_csv(students, filename="students.csv"): """학생 리스트를 CSV 파일로 저장""" # 모든 학생의 과목명을 모아 헤더 생성 subjects = [] for s in students: for subj in s.grades: if subj not in subjects: subjects.append(subj) with open(filename, "w", newline="", encoding="utf-8-sig") as f: writer = csv.DictWriter(f, fieldnames=["name", "student_id"] + subjects) writer.writeheader() for s in students: row = {"name": s.name, "student_id": s.student_id} for subj in subjects: row[subj] = s.grades.get(subj, "") writer.writerow(row) print(f"{filename} 저장 완료 ({len(students)}명)")

CSV 불러오기 함수

def load_from_csv(filename="students.csv"): """CSV 파일에서 학생 리스트 복원""" students = [] with open(filename, "r", encoding="utf-8-sig") as f: reader = csv.DictReader(f) for row in reader: s = Student(row["name"], row["student_id"]) for key, val in row.items(): if key not in ("name", "student_id") and val: s.add_grade(key, int(val)) students.append(s) print(f"{filename} 불러오기 완료 ({len(students)}명)") return students
utf-8-sig란? 엑셀에서 한글 CSV를 열 때 깨지는 것을 막기 위해 BOM(Byte Order Mark)을 포함한 인코딩입니다. 일반 utf-8과 데이터는 같지만 엑셀 호환성이 높습니다.

Step 4 — 검색 기능과 시스템 완성

이름, 학번, 또는 성적 범위로 학생을 찾을 수 있는 검색 함수를 만듭니다. 리스트 컴프리헨션과 조건식을 조합하면 간결하게 구현할 수 있습니다.

def search_by_name(students, keyword): """이름에 keyword가 포함된 학생 검색""" return [s for s in students if keyword in s.name] def search_by_id(students, student_id): """학번으로 학생 검색""" result = [s for s in students if s.student_id == student_id] return result[0] if result else None def search_by_grade_range(students, min_avg, max_avg): """평균 점수가 min_avg~max_avg 사이인 학생 검색""" return [s for s in students if min_avg <= s.average() <= max_avg] # 사용 예 found = search_by_name(students, "민") print([s.name for s in found]) # ['김민준'] top = search_by_grade_range(students, 85, 100) print([s.name for s in top]) # 평균 85 이상 학생들
['김민준'] ['이서연', '김민준']

기초
Student 클래스에 best_subject() 메서드를 추가하세요. 이 메서드는 성적 딕셔너리에서 가장 높은 점수를 받은 과목 이름과 점수를 튜플로 반환합니다. 성적이 없으면 None을 반환합니다.
입력 grades = {"수학": 92, "영어": 85, "과학": 100}
출력 ('과학', 100)
내 답안
힌트 보기
max(self.grades, key=lambda k: self.grades[k])를 사용하면 가장 높은 점수의 키(과목명)를 바로 얻을 수 있습니다.
정답 보기
def best_subject(self): if not self.grades: return None best = max(self.grades, key=lambda k: self.grades[k]) return (best, self.grades[best])

def get_rank(students, target_name): ranked = sorted(students, key=lambda s: s.average(), reverse=True) for i, s in enumerate(ranked, 1): if s.name == target_name: return i return -1

핵심 요약

핵심 요약

  • 클래스 설계: __init__에서 이름·학번·빈 딕셔너리 초기화 — 데이터와 메서드를 한 곳에 묶습니다.
  • 성적 딕셔너리: {과목명: 점수} 구조 — 추가는 grades[subject] = score, 삭제는 del grades[subject].
  • 평균 계산: sum(grades.values()) / len(grades) — 과목 수에 관계없이 동작합니다.
  • 석차 계산: sorted(students, key=lambda s: s.average(), reverse=True) — 평균 기준 내림차순 정렬.
  • CSV 저장: csv.DictWriter로 헤더와 데이터를 딕셔너리 형태로 저장합니다.
  • CSV 불러오기: csv.DictReader로 각 행을 딕셔너리로 읽어 Student 객체 복원.
  • 검색: 리스트 컴프리헨션 + 조건식으로 이름 포함, 학번 일치, 평균 범위 검색 구현.
  • 인코딩: utf-8-sig로 엑셀에서 한글 깨짐 방지.
기능 메서드/함수 핵심 Python 구문
성적 추가 add_grade(subject, score) self.grades[subject] = score

평균 계산 average() sum(values) / len(values)
