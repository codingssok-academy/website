Project 02

나이 계산기 + 띠 알아보기

태어난 해를 입력받아 나이를 계산하고, 12간지 띠도 알아봅니다.

이 프로젝트에서 배우는 것

  • 현재 연도에서 태어난 해를 빼서 나이를 계산할 수 있습니다.
  • % (모듈로) 연산으로 12간지 인덱스를 구할 수 있습니다.
  • 리스트에서 인덱스로 값을 꺼내는 방법을 배웁니다.
  • 여러 조건에 따라 다른 출력을 만들 수 있습니다.
  • 실생활 날짜 계산 프로그램을 만들 수 있습니다.

나이 계산하기

나이를 계산하는 방법은 간단합니다. 현재 연도에서 태어난 해를 뺍니다.

# 나이 계산기 기본 current_year = 2026 birth_year = int(input("태어난 해를 입력하세요: ")) age = current_year - birth_year print(f"{birth_year}년생은 {age}살입니다.")

한국식 나이는 태어나자마자 1살이므로 age + 1을 더합니다. 이 프로젝트에서는 만 나이를 기준으로 합니다.

따라해보세요
1
2010년생의 만 나이를 계산해서 출력하세요.
birth = int(input("태어난 해: ")) age = 2026 - birth print(f"만 나이: {age}세")
2010 입력 시 만 나이: 16세
2
만 나이와 한국 나이를 함께 출력하세요.
birth = int(input("태어난 해: ")) age_int = 2026 - birth age_kor = age_int + 1 print(f"만 나이: {age_int}세 / 한국 나이: {age_kor}세")
두 가지 나이가 함께 출력됩니다
3
몇 년 후에 성인(만 18세)이 되는지 계산하세요.
birth = int(input("태어난 해: ")) age = 2026 - birth years_to_adult = 18 - age if years_to_adult <= 0: print("이미 성인입니다!") else: print(f"{years_to_adult}년 후 성인이 됩니다.")
성인 여부와 남은 시간을 알 수 있습니다

12간지 띠 계산하기

12간지는 쥐, 소, 호랑이 ... 총 12개의 동물이 12년 주기로 반복됩니다. % 12(나머지 연산)로 어떤 동물인지 알 수 있습니다.

# 12간지 리스트 (인덱스 0~11) zodiac = ["원숭이", "닭", "개", "돼지", "쥐", "소", "호랑이", "토끼", "용", "뱀", "말", "양"] birth_year = int(input("태어난 해: ")) index = birth_year % 12 # 나머지로 인덱스 계산 animal = zodiac[index] print(f"당신의 띠는 {animal}띠입니다!")
따라해보세요
1
12간지 리스트를 만들고 인덱스 2, 5, 10의 동물을 출력하세요.
zodiac = ["원숭이", "닭", "개", "돼지", "쥐", "소", "호랑이", "토끼", "용", "뱀", "말", "양"] print(zodiac[2], zodiac[5], zodiac[10])
개 소 말 출력
2
2010년 % 12를 직접 계산하고 그 인덱스의 동물을 출력하세요.
zodiac = ["원숭이", "닭", "개", "돼지", "쥐", "소", "호랑이", "토끼", "용", "뱀", "말", "양"] idx = 2010 % 12 print(f"2010년 인덱스: {idx}, 동물: {zodiac[idx]}")
2010년 인덱스: 2, 동물: 개
3
태어난 해를 입력받아 띠 동물을 출력하는 전체 프로그램을 만드세요.
zodiac = ["원숭이", "닭", "개", "돼지", "쥐", "소", "호랑이", "토끼", "용", "뱀", "말", "양"] birth = int(input("태어난 해: ")) print(f"당신은 {zodiac[birth % 12]}띠입니다!")
2010 입력 시 "개"띠 출력

완성: 나이 + 띠 계산기

나이 계산과 12간지를 합쳐서 완전한 프로그램을 만듭니다.

# 나이 + 띠 계산기 완성 버전 zodiac = ["원숭이", "닭", "개", "돼지", "쥐", "소", "호랑이", "토끼", "용", "뱀", "말", "양"] print("=== 나이 계산기 ===") birth_year = int(input("태어난 해를 입력하세요: ")) current_year = 2026 age = current_year - birth_year korean_age = age + 1 animal = zodiac[birth_year % 12] print(f"\n--- 결과 ---") print(f"만 나이: {age}세") print(f"한국 나이: {korean_age}세") print(f"당신의 띠: {animal}띠") if age >= 18: print("성인입니다!") else: years_left = 18 - age print(f"{years_left}년 후 성인이 됩니다.")

직접 풀어보세요

출력만 나이: 16세 / 한국 나이: 17세

birth = int(input("태어난 해: ")) age = 2026 - birth print(f"만 나이: {age}세 / 한국 나이: {age+1}세")
Q2
띠 알아보기
쉬움
태어난 해를 입력받아 12간지 띠를 출력하세요. 리스트와 % 12를 활용합니다.

출력당신은 용띠입니다!

입력2005
출력21세 / 닭띠 / 성인
내 답안
힌트 보기
나이 계산 + zodiac[birth % 12] + if age >= 18 조합
정답 확인
zodiac = ["원숭이","닭","개","돼지","쥐","소","호랑이","토끼","용","뱀","말","양"] birth = int(input("태어난 해: ")) age = 2026 - birth animal = zodiac[birth % 12] status = "성인" if age >= 18 else f"{18-age}년 후 성인" print(f"{age}세 / {animal}띠 / {status}")

핵심 요약

이 유닛에서 배운 것

  • 나이 계산: 현재연도 - 태어난해
  • 한국 나이: 만 나이 + 1
  • % 12 나머지 연산으로 12간지 인덱스를 구한다
  • 리스트 인덱싱: zodiac[index]로 원하는 값을 꺼낸다
  • if/else로 성인 여부 같은 조건 판정을 한다
  • 변수에 계산 결과를 저장하면 나중에 재사용할 수 있다
