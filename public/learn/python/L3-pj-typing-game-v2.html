타자 연습 게임

random으로 단어를 출제하고, time 모듈로 입력 시간을 측정해 정확도와 WPM(분당 단어 수)을 계산합니다. 최고 기록도 파일에 저장합니다.

이 프로젝트에서 만드는 것

  • random.choice()로 단어 목록에서 무작위 출제를 구현합니다.
  • time.time()으로 입력 시작/종료 시간을 측정해 경과 시간을 계산합니다.
  • 입력한 단어와 정답을 글자 단위로 비교해 정확도(%)를 계산합니다.
  • 최고 WPM 기록을 파일에 저장하고 불러와 비교합니다.

Step 1 — time 모듈로 입력 시간 측정

time 모듈의 time.time()은 현재 시각을 초 단위 부동소수점으로 반환합니다. 시작 시각과 종료 시각의 차이로 경과 시간을 측정합니다.

# Step 1: time 모듈 사용 import time import random WORDS = [ "apple", "banana", "python", "coding", "keyboard", "program", "function", "variable", "loop", "class", "string", "integer", "boolean", "print", "input", ] def measure_typing(): word = random.choice(WORDS) # 무작위 단어 출제 print(f"단어: {word}") start = time.time() # 시작 시각 기록 user_input = input("입력: ") end = time.time() # 종료 시각 기록 elapsed = end - start # 경과 시간(초) correct = (user_input == word) print(f"{'정답!' if correct else '틀렸어요'} — {elapsed:.2f}초") return word, user_input, elapsed

Step 2 — 정확도와 WPM 계산

입력한 텍스트를 글자 단위로 비교해 정확도를 계산합니다. WPM(Words Per Minute)은 분당 단어 수로, 타이핑 속도를 나타냅니다.

# Step 2: 정확도 + WPM 계산 def calc_accuracy(original, typed): # 글자 단위 비교 correct = sum(1 for a, b in zip(original, typed) if a == b) total = max(len(original), len(typed)) if total == 0: return 0.0 return correct / total * 100 def calc_wpm(text, elapsed): if elapsed == 0: return 0 words = len(text.split()) return words / elapsed * 60 def run_round(sentence): print(f"\n입력하세요: {sentence}") start = time.time() typed = input("> ") elapsed = time.time() - start accuracy = calc_accuracy(sentence, typed) wpm = calc_wpm(typed, elapsed) print(f"시간: {elapsed:.2f}초") print(f"정확도: {accuracy:.1f}%") print(f"WPM: {wpm:.1f}") return wpm, accuracy

Step 3 — 최고 기록 파일에 저장하기

게임 결과(WPM, 정확도)를 파일에 저장해 최고 기록을 관리합니다. 새로운 점수가 기존 최고 기록보다 높으면 갱신합니다.

# Step 3: 최고 기록 저장/불러오기 RECORD_FILE = "best_score.txt" def load_best_score(): try: with open(RECORD_FILE, "r") as f: return float(f.read().strip()) except (FileNotFoundError, ValueError): return 0.0 # 기록 없으면 0 def save_best_score(wpm): with open(RECORD_FILE, "w") as f: f.write(str(wpm)) def check_new_record(wpm): best = load_best_score() if wpm > best: save_best_score(wpm) print(f"신기록! {wpm:.1f} WPM (이전: {best:.1f})") else: print(f"최고 기록: {best:.1f} WPM (이번: {wpm:.1f})")

Q3
틀린 글자 표시
어려움

show_diff(original, typed) 함수를 만드세요. 맞은 글자는 그대로, 틀린 글자는 _로 표시합니다. 예: original="python", typed="puthon" → "p_thon"

내 답안
힌트 보기

zip(original, typed)로 글자 쌍을 만들고, 같으면 원래 글자를, 다르면 '_'를 선택해 join으로 합칩니다.

정답 보기
def show_diff(original, typed): result = [] for a, b in zip(original, typed): result.append(a if a == b else "_") # original이 더 길면 남은 글자도 추가 if len(original) > len(typed): result.extend(["_"] * (len(original) - len(typed))) return "".join(result)

핵심 요약

  • time.time(): 현재 시각(초)을 반환 — 시작/종료 차이로 경과 시간 측정.
  • random.choice(list): 리스트에서 무작위 요소 1개를 선택.
  • 정확도: sum(1 for a,b in zip(orig,typed) if a==b) / max(len...) * 100.
  • WPM: 단어수 / 경과시간(초) * 60 — 분당 단어 수.
  • 최고 기록은 파일에 저장해 다음 실행 때도 비교할 수 있습니다.
