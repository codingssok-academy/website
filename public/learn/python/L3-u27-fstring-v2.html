f-string 심화
포맷팅의 모든 것

숫자 정렬, 소수점 제어, 폭 지정, 채우기 문자까지 — f-string의 진짜 힘을 배웁니다.

이 유닛에서 배우는 것

  • f-string {} 안에서 직접 연산과 메서드 호출을 할 수 있습니다.
  • :.2f로 소수점 자리수를 정확히 지정할 수 있습니다.
  • :>10, :<10, :^10으로 정렬과 폭을 지정합니다.
  • :,로 천 단위 구분자(콤마)를 삽입할 수 있습니다.
  • 채우기 문자와 정렬 기호를 조합해 다양한 출력 형식을 만듭니다.

f-string 안에서 연산하기

f-string의 {} 안에는 변수뿐 아니라 모든 파이썬 표현식(연산, 함수 호출, 메서드)을 넣을 수 있습니다.

# {} 안에서 직접 연산 a, b = 7, 3 print(f"합: {a + b}, 곱: {a * b}, 나머지: {a % b}") # 합: 10, 곱: 21, 나머지: 1 name = "python" print(f"대문자: {name.upper()}, 길이: {len(name)}") # 대문자: PYTHON, 길이: 6 items = [10, 20, 30] print(f"평균: {sum(items) / len(items)}") # 평균: 20.0

숫자 포맷 지정자

콜론(:) 뒤에 형식 지정자를 씁니다. 숫자를 깔끔하게 출력할 때 매우 유용합니다.

# 숫자 포맷 예시 pi = 3.141592 price = 1234567 ratio = 0.8756 print(f"원주율: {pi:.3f}") # 3.142 print(f"가격: {price:,}원") # 1,234,567원 print(f"정답률: {ratio:.1%}") # 87.6% print(f"총액: {price * 1.1:,.0f}원") # 1,358,024원
따라해보세요
1
월급과 세율로 실수령액을 계산해 포맷 출력하세요.
salary = 2500000 tax_rate = 0.033 take_home = salary * (1 - tax_rate) print(f"월급: {salary:,}원") print(f"세금: {salary * tax_rate:,.0f}원 ({tax_rate:.1%})") print(f"실수령: {take_home:,.0f}원")
월급: 2,500,000원 / 세금: 82,500원 (3.3%) / 실수령: 2,417,500원
2
원주율을 소수점 1~4자리까지 차례로 출력해보세요.
pi = 3.141592653 for n in range(1, 5): print(f"소수점 {n}자리: {pi:.{n}f}")
소수점 1자리: 3.1 / 2자리: 3.14 / 3자리: 3.142 / 4자리: 3.1416

정렬과 폭 지정 — 표처럼 출력하기

폭(width)과 정렬 기호를 사용하면 데이터를 표 형태로 깔끔하게 출력할 수 있습니다.

# 정렬 예시 name = "Python" print(f"|{name:>10}|") # | Python| print(f"|{name:<10}|") # |Python | print(f"|{name:^10}|") # | Python | # 채우기 문자 지정 print(f"|{name:*>10}|") # |****Python| print(f"|{name:=^10}|") # |==Python==| # 실용 예: 성적표 출력 students = [("김민수", 95), ("이서연", 87), ("박지호", 100)] print(f"{'이름':<8} {'점수':>5}") print("-" * 14) for nm, score in students: print(f"{nm:<8} {score:>5}")
따라해보세요
1
가격 목록을 표 형식으로 출력하세요 (왼쪽 정렬 상품명, 오른쪽 정렬 가격).
menu = [("아메리카노", 3500), ("카페라떼", 4500), ("초코케이크", 5000)] print(f"{'상품명':<10} {'가격':>10}") print("-" * 22) for nm, price in menu: print(f"{nm:<10} {price:>8,}원")
상품명 / 가격 열 정렬된 표 형식 출력
2
채우기 문자 = 를 사용해 제목을 가운데 정렬로 꾸며보세요.
title = "성적 발표" print(f"{title:=^24}") print(f"{title:*^24}")
채우기 문자로 장식된 제목 출력
Q1
성적 통계 출력기 보통
5명의 점수 리스트 [78, 92, 85, 67, 95]로 최고점, 최저점, 평균을 계산하고 출력하세요. 평균은 소수점 1자리, 점수는 폭 3으로 오른쪽 정렬.
출력 최고점: 95점 / 최저점: 67점 / 평균: 83.4점
내 답안
힌트 보기 / 정답 보기
max(), min(), sum()/len() 활용. 폭 지정으로 숫자 오른쪽 정렬.
scores = [78, 92, 85, 67, 95] print(f"최고점: {max(scores):>3}점") print(f"최저점: {min(scores):>3}점") print(f"평균: {sum(scores)/len(scores):>5.1f}점")

포맷 지정자 조합 — 실전 패턴

여러 형식 지정자를 조합하면 더욱 강력한 출력이 가능합니다.

# 번호 앞에 0 채우기 for i in range(1, 6): print(f"학생 {i:02d}번") # 학생 01번 ~ 05번 # 진수 변환 출력 n = 255 print(f"10진: {n:d}, 16진: {n:x}, 2진: {n:b}") # 10진: 255, 16진: ff, 2진: 11111111
따라해보세요
1
학번 001~005를 자동으로 생성해 출력하세요 (앞을 0으로 채워 3자리).
for num in range(1, 6): student_id = f"학번: {num:03d}" print(student_id)
학번: 001 / 학번: 002 / ... / 학번: 005
Q2
상품 영수증 출력기 보통
상품 목록 [("노트북", 1250000), ("마우스", 32000), ("키보드", 75000)]을 영수증 형태로 출력하세요. 상품명은 왼쪽 10자리, 가격은 오른쪽 10자리 콤마 포함.
출력 노트북 1,250,000
합계: 1,357,000
내 답안
힌트 보기 / 정답 보기
for 루프로 각 항목 출력. 합계는 sum()으로 계산. 이름은 왼쪽정렬, 가격은 오른쪽정렬 콤마.
products = [("노트북", 1250000), ("마우스", 32000), ("키보드", 75000)] for nm, price in products: print(f"{nm:<10} {price:>10,}") total = sum(p for _, p in products) print(f"{'합계:':<10} {total:>10,}")
Q3
온도 변환 포맷터 어려움
섭씨 온도 목록 [0, 20, 37, 100]을 화씨로 변환하고 (공식: F = C * 9/5 + 32), 섭씨와 화씨를 소수점 1자리, 폭 6으로 나란히 출력하세요.
출력 섭씨 0.0 --> 화씨 32.0
내 답안
힌트 보기 / 정답 보기
변환 공식을 계산 후 f-string 폭 지정으로 출력. for 루프로 순회.
temps = [0, 20, 37, 100] for c in temps: fahr = c * 9/5 + 32 print(f"섭씨 {c:6.1f} --> 화씨 {fahr:6.1f}")
f-string vs 구식 포맷 방법

핵심 요약

  • {변수:.2f} — 소수점 2자리까지 (반올림)
  • {변수:,} — 천 단위 콤마 삽입
  • {변수:,.2f} — 콤마 + 소수점 조합
  • {변수:.1%} — 소수를 퍼센트(%)로 표기
  • {변수:>10} / {변수:<10} / {변수:^10} — 우/좌/가운데 정렬, 폭 10
  • {변수:*^10} — 채우기 문자(*)와 정렬 조합
  • {변수:03d} — 0으로 채워 3자리 정수 출력
  • {변수:x} / {변수:b} — 16진수 / 2진수 출력
  • {} 안에 연산, 함수 호출, 메서드 모두 가능
