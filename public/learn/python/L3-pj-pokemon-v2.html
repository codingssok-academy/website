프로젝트:
포켓몬 도감

딕셔너리로 포켓몬 정보(이름, 타입, HP, 기술)를 저장하고, 검색/추가/배틀 시뮬레이션 기능을 가진 나만의 포켓몬 도감을 만듭니다.

이 프로젝트에서 만드는 것

  • 중첩 딕셔너리로 포켓몬 이름, 타입, HP, 공격력, 기술 목록을 저장합니다.
  • 이름으로 포켓몬을 검색하고 상세 정보를 출력하는 함수를 만듭니다.
  • 새 포켓몬 정보를 입력받아 도감에 추가하는 함수를 만듭니다.
  • 두 포켓몬이 배틀할 때 공격력, 방어력, HP로 승패를 계산합니다.
  • 타입 상성표 딕셔너리로 공격 배율을 적용합니다.
  • 전체 메뉴 루프로 도감을 자유롭게 탐색할 수 있습니다.

Step 1 — 포켓몬 도감 데이터 구조

포켓몬 도감은 중첩 딕셔너리(nested dictionary)로 구현합니다. 바깥 딕셔너리의 키는 포켓몬 이름, 값은 포켓몬 정보가 담긴 딕셔너리입니다.

# 포켓몬 도감 — 중첩 딕셔너리 pokedex = { "피카츄": { "타입": "전기", "hp": 35, "공격": 55, "방어": 40, "기술": ["번개", "전기충격", "볼트태클"] }, "파이리": { "타입": "불꽃", "hp": 39, "공격": 52, "방어": 43, "기술": ["화염방사", "불꽃소용돌이"] }, "꼬부기": { "타입": "물", "hp": 44, "공격": 48, "방어": 65, "기술": ["물대포", "거품광선"] } } # 접근 방법 print(pokedex["피카츄"]["hp"]) # 35 print(pokedex["파이리"]["기술"][0]) # 화염방사 print(list(pokedex.keys())) # 전체 포켓몬 목록
35 화염방사 ['피카츄', '파이리', '꼬부기']

검색 함수 만들기

def search_pokemon(name): """포켓몬 이름으로 도감 검색""" if name not in pokedex: print(f"'{name}'은 도감에 없습니다.") return info = pokedex[name] print(f"===== {name} =====") print(f"타입: {info['타입']}") print(f"HP: {info['hp']} 공격: {info['공격']} 방어: {info['방어']}") print(f"기술: {', '.join(info['기술'])}") search_pokemon("피카츄")

Step 2 — 새 포켓몬 추가 & 배틀 시뮬레이션

새 포켓몬을 도감에 추가하는 함수와, 두 포켓몬이 타입 상성을 고려해 배틀하는 함수를 만듭니다.

# 타입 상성 딕셔너리: 공격타입 -> 2배 피해 받는 타입 TYPE_CHART = { "전기": ["물"], "불꽃": ["풀", "얼음"], "물": ["불꽃", "땅"], "풀": ["물", "땅"] } def add_pokemon(name, ptype, hp, attack, defense, moves): """새 포켓몬을 도감에 추가""" if name in pokedex: print(f"'{name}'은 이미 도감에 있습니다.") return pokedex[name] = { "타입": ptype, "hp": hp, "공격": attack, "방어": defense, "기술": moves } print(f"'{name}' 도감에 추가됨!") add_pokemon("이상해씨", "풀", 45, 49, 49, ["넝쿨채찍", "씨뿌리기"]) def battle(name1, name2): """두 포켓몬 배틀 시뮬레이션""" if name1 not in pokedex or name2 not in pokedex: print("존재하지 않는 포켓몬입니다.") return p1 = pokedex[name1] p2 = pokedex[name2] # 타입 상성 배율 계산 mul1 = 2.0 if p2["타입"] in TYPE_CHART.get(p1["타입"], []) else 1.0 mul2 = 2.0 if p1["타입"] in TYPE_CHART.get(p2["타입"], []) else 1.0 # 실제 데미지 = (공격력 - 상대 방어력 / 2) * 배율 dmg1 = max(1, int((p1["공격"] - p2["방어"] / 2) * mul1)) dmg2 = max(1, int((p2["공격"] - p1["방어"] / 2) * mul2)) print(f"\n[{name1}] HP:{p1['hp']} 공:{p1['공격']} 방:{p1['방어']} 타입:{p1['타입']}") print(f"[{name2}] HP:{p2['hp']} 공:{p2['공격']} 방:{p2['방어']} 타입:{p2['타입']}") print(f"\n{name1} -> {name2}: {dmg1} 데미지 (x{mul1})") print(f"{name2} -> {name1}: {dmg2} 데미지 (x{mul2})") turns1 = p2["hp"] // dmg1 + 1 turns2 = p1["hp"] // dmg2 + 1 if turns1 < turns2: print(f"\n승자: {name1}! ({turns1}턴만에 쓰러뜨림)") elif turns2 < turns1: print(f"\n승자: {name2}! ({turns2}턴만에 쓰러뜨림)") else: print("\n무승부!") battle("피카츄", "꼬부기")
'이상해씨' 도감에 추가됨! [피카츄] HP:35 공:55 방:40 타입:전기 [꼬부기] HP:44 공:48 방:65 타입:물 피카츄 -> 꼬부기: 30 데미지 (x2.0) 꼬부기 -> 피카츄: 28 데미지 (x1.0) 승자: 피카츄! (2턴만에 쓰러뜨림)

연습 문제

Q1
포켓몬 목록 출력
쉬움
pokedex에서 HP가 가장 높은 포켓몬의 이름을 출력하는 코드를 작성하세요. (힌트: max() 함수와 key 매개변수를 활용하세요.)
출력꼬부기 (HP 44로 가장 높음)
내 답안
힌트 보기
max(pokedex, key=lambda n: pokedex[n]["hp"]) — max에 key 함수를 전달하면 딕셔너리 키를 비교 기준으로 설정할 수 있습니다.
정답 보기
best = max(pokedex, key=lambda n: pokedex[n]["hp"]) print(f"HP 최고: {best} (HP {pokedex[best]['hp']})")
Q2
기술 추가 기능
보통
포켓몬 이름과 새 기술 이름을 받아서, 해당 포켓몬의 기술 목록에 추가하는 함수 learn_move(name, move)를 작성하세요. 이미 아는 기술이면 "이미 알고 있는 기술입니다."를 출력하세요.
입력learn_move("피카츄", "10만볼트")
출력피카츄가 '10만볼트'를 배웠습니다!
내 답안
힌트 보기
pokedex[name]["기술"]은 리스트입니다. move in 리스트로 중복을 확인하고, .append()로 추가하세요.
정답 보기
def learn_move(name, move): if name not in pokedex: print(f"'{name}'은 도감에 없습니다.") return if move in pokedex[name]["기술"]: print("이미 알고 있는 기술입니다.") else: pokedex[name]["기술"].append(move) print(f"{name}가 '{move}'를 배웠습니다!")
Q3
타입별 포켓몬 목록
어려움
특정 타입의 포켓몬만 출력하는 함수 filter_by_type(ptype)을 작성하세요. 해당 타입이 없으면 "해당 타입의 포켓몬이 없습니다."를 출력하세요.
입력filter_by_type("불꽃")
출력불꽃 타입 포켓몬: 파이리
내 답안
힌트 보기
리스트 컴프리헨션: [n for n, info in pokedex.items() if info["타입"] == ptype] 로 타입 필터링하세요.
정답 보기
def filter_by_type(ptype): result = [n for n, info in pokedex.items() if info["타입"] == ptype] if not result: print("해당 타입의 포켓몬이 없습니다.") else: print(f"{ptype} 타입 포켓몬: {', '.join(result)}")

핵심 요약

  • 중첩 딕셔너리 — 딕셔너리 안에 딕셔너리로 복잡한 데이터 구조 표현
  • dict[키1][키2] — 중첩 딕셔너리 접근 방법
  • name in pokedex — KeyError 없이 키 존재 여부 확인
  • dict.items() — 키와 값을 동시에 순회할 때 사용
  • 타입 상성 같은 게임 규칙도 딕셔너리로 표현 가능
  • max(dict, key=함수) — 딕셔너리에서 조건으로 최댓값 찾기
