Chapter L3-CV-3 — 컴퓨터 비전

이미지에 그리기
선, 사각형, 원, 텍스트

얼굴 인식 결과를 사각형으로 표시하거나, 경로를 선으로 그리거나, 이미지에 한국어 텍스트를 쓰는 법 — 컴퓨터 비전의 '출력' 기술을 배웁니다.

이 유닛에서 배우는 것

  • OpenCV의 색상 팔레트 — BGR 튜플로 색을 지정하는 방법을 배웁니다.
  • cv2.line(), cv2.rectangle(), cv2.circle()로 도형을 그립니다.
  • cv2.putText()로 이미지에 텍스트를 씁니다.
  • 두께(thickness)와 채우기(-1)의 차이를 이해합니다.
  • 좌표계 (x, y) 와 (pt1, pt2) 파라미터 사용법을 익힙니다.

OpenCV 좌표계

OpenCV는 왼쪽 위를 (0, 0)으로 하는 이미지 좌표계를 사용합니다. x는 오른쪽, y는 아래쪽으로 증가합니다.

색상 팔레트 (BGR)

OpenCV는 BGR 튜플로 색을 지정합니다. 예: 빨간색 = (0, 0, 255), 초록 = (0, 255, 0), 파랑 = (255, 0, 0)

선 그리기 — cv2.line()

import cv2, numpy as np canvas = np.zeros((400, 600, 3), dtype=np.uint8) # 검정 배경 # cv2.line(이미지, 시작점, 끝점, 색상BGR, 두께) cv2.line(canvas, (50, 50), (550, 50), (0, 0, 255), 3) # 빨강 선 cv2.line(canvas, (50, 100), (550, 350), (0, 255, 0), 5) # 초록 선

사각형 그리기 — cv2.rectangle()

# cv2.rectangle(이미지, 좌상단, 우하단, 색상, 두께) # 두께 -1 이면 채우기 cv2.rectangle(canvas, (100, 120), (300, 280), (255, 0, 0), 3) # 파랑 테두리 cv2.rectangle(canvas, (320, 120), (500, 280), (0, 200, 200), -1) # 채운 사각형 cv2.imwrite("shapes.jpg", canvas)

원 그리기 — cv2.circle()

원은 중심 좌표와 반지름을 지정합니다. 두께를 -1로 하면 꽉 채운 원이 됩니다.

import cv2, numpy as np canvas = np.zeros((400, 600, 3), dtype=np.uint8) # cv2.circle(이미지, 중심좌표, 반지름, 색상, 두께) cv2.circle(canvas, (150, 200), 80, (0, 255, 0), 3) # 초록 원 테두리 cv2.circle(canvas, (350, 200), 60, (0, 0, 255), -1) # 빨강 꽉찬 원

텍스트 쓰기 — cv2.putText()

이미지에 텍스트를 씁니다. OpenCV는 기본적으로 한글을 지원하지 않아 영어/숫자만 가능합니다. 한글을 쓰려면 Pillow 라이브러리를 함께 사용해야 합니다.

# cv2.putText(이미지, 텍스트, 위치(좌하단), 폰트, 크기, 색상, 두께) cv2.putText(canvas, "Hello CV!", # 텍스트 (영문/숫자) (50, 200), # 위치 (x, y) -- 텍스트 좌하단 cv2.FONT_HERSHEY_SIMPLEX, # 폰트 종류 1.5, # 폰트 크기 (0, 255, 255), # 색상 (노랑) 3 # 두께 )

실력 확인 문제

Q1
색상 코드 맞추기
쉬움
OpenCV에서 노란색(Yellow)을 나타내는 BGR 코드로 올바른 것은?
보기 (1) (255, 255, 0) (2) (0, 255, 255) (3) (255, 0, 255)
내 답안
힌트 보기
노란색(Yellow) = 빨강 + 초록. BGR 순서로는 파랑=0, 초록=255, 빨강=255 입니다.
정답 보기
(2) (0, 255, 255) # BGR 순서: B=0, G=255, R=255 # 빨강+초록 = 노란색 # (255, 255, 0) = Cyan (파랑+초록)
Q2
채운 원 그리기
보통
300x300 검정 캔버스 중앙 (150, 150)에 반지름 50의 꽉 찬 보라색 원을 그리는 코드를 완성하세요. (보라색 BGR = (255, 0, 255))
빈칸 cv2.circle(canvas, (150, 150), ___, (255, 0, 255), ___)
내 답안
힌트 보기
반지름은 50, 꽉 찬 원은 두께를 -1로 지정합니다.
정답 보기
cv2.circle(canvas, (150, 150), 50, (255, 0, 255), -1) # 두께 -1: 내부를 채운 원
Q3
인물 이름 카드 만들기
어려움
400x200 흰색 캔버스에 파란 테두리 사각형(두께 4)을 그리고, 안에 "Name: Kim" 텍스트를 초록색으로 넣는 프로그램을 작성하세요.
내 답안
힌트 보기
흰색 캔버스는 np.ones() * 255 로 만듭니다. rectangle의 파란색 BGR = (255, 0, 0), 초록색 = (0, 255, 0).
정답 보기
import cv2 import numpy as np canvas = np.ones((200, 400, 3), dtype=np.uint8) * 255 cv2.rectangle(canvas, (10, 10), (390, 190), (255, 0, 0), 4) cv2.putText(canvas, "Name: Kim", (50, 110), cv2.FONT_HERSHEY_SIMPLEX, 1.5, (0, 255, 0), 3) cv2.imwrite("card.jpg", canvas)

핵심 요약

  • OpenCV 좌표계: 왼쪽 위 (0,0), x는 오른쪽, y는 아래로 증가
  • 색상 = BGR 튜플: 빨강 (0,0,255), 초록 (0,255,0), 파랑 (255,0,0)
  • cv2.line(img, pt1, pt2, color, thickness) — 선 그리기
  • cv2.rectangle(img, pt1, pt2, color, -1) — 채운 사각형
  • cv2.circle(img, center, radius, color, thickness) — 원 그리기
  • cv2.putText(img, text, org, font, scale, color, thick) — 텍스트 (영문)
  • 두께 -1 = 도형 내부를 완전히 채움
