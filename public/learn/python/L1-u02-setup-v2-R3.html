개발 환경이란?

프로그래밍을 하려면 두 가지가 필요합니다.

쉽게 말하면, 개발 환경은 "글을 쓰기 위한 연필과 공책"과 같습니다. Python은 연필(실행기)이고, VS Code는 공책(편집기)입니다. 둘 다 있어야 프로그래밍을 시작할 수 있습니다.

1
1. 코드를 작성할 편집기
메모장으로도 코드를 작성할 수 있지만, 전문 편집기를 사용하면 자동 완성, 문법 강조, 에러 표시 등의 도움을 받을 수 있습니다. 이 교재에서는 VS Code를 사용합니다.
2
2. 코드를 실행할 인터프리터
작성한 코드를 실행하려면 Python 인터프리터가 설치되어 있어야 합니다. python.org에서 무료로 다운로드할 수 있습니다.
TIP
왜 VS Code인가?
VS Code는 Microsoft가 만든 무료 편집기로, 전 세계 개발자의 70% 이상이 사용합니다. 가볍고, 확장 기능이 풍부하며, Python뿐 아니라 거의 모든 언어를 지원합니다. IDLE(Python 기본 편집기)보다 훨씬 편리합니다.
확인해봅시다 터미널에 python --version을 입력했을 때 버전 번호가 나타납니까? 나타나지 않는다면, 설치 과정에서 무엇을 빼먹었을 가능성이 높습니까?

Step 1: Python 설치

Python 공식 사이트에서 최신 버전을 다운로드하여 설치합니다.

1
1. python.org 접속
웹 브라우저에서 python.org에 접속합니다. 상단 메뉴에서 Downloads를 클릭합니다.
2
2. 최신 버전 다운로드
노란색 Download Python 3.x.x 버튼을 클릭합니다. Windows용 설치 파일(.exe)이 다운로드됩니다.
3
3. 설치 프로그램 실행
다운로드된 파일을 실행합니다. 설치 화면이 나타납니다.
4
4. Add Python to PATH 체크
설치 화면 하단의 "Add python.exe to PATH" 체크박스를 반드시 체크합니다. 이것을 빼먹으면 터미널에서 python 명령을 인식하지 못합니다.
5
5. Install Now 클릭
Install Now를 클릭하여 설치를 진행합니다. 완료되면 Close를 클릭합니다.
WARNING
Add to PATH를 빼먹었다면
Python을 다시 설치하거나, 설치 프로그램을 다시 실행하여 Modify → Add Python to PATH를 체크하면 됩니다. PATH가 설정되지 않으면 터미널에서 'python'을 입력해도 "명령을 찾을 수 없습니다"라는 에러가 발생합니다.

Step 2: 설치 확인

Python이 정상적으로 설치되었는지 터미널에서 확인합니다.

1
1. 터미널 열기
Windows: Win키를 누르고 "cmd"를 입력한 뒤 Enter. macOS: Spotlight에서 "Terminal" 검색.
2
2. 버전 확인 명령 입력
python --version 을 입력하고 Enter를 누릅니다.
3
3. 결과 확인
Python 3.x.x 형태의 버전 번호가 출력되면 성공입니다.
Python터미널
1python --version
실행 결과
Python 3.12.4
WARNING
Windows에서 python이 안 될 때
Windows에서 python 대신 py를 입력해 보십시오. py --version도 같은 결과를 보여줍니다. 또는 python3 --version을 시도하십시오. 세 가지 모두 안 되면 PATH 설정이 누락된 것입니다.
자주 하는 실수
  • Python 설치할 때 "Add Python to PATH" 체크박스를 빼먹는 것 — 이걸 안 하면 터미널에서 python 명령이 작동하지 않습니다.
  • VS Code에서 Python 확장을 설치하지 않고 바로 코드 작성 — 확장이 없으면 자동 완성, 오류 표시 등이 작동하지 않습니다.
  • 파일 이름에 한글이나 공백을 넣는 것 — 영어, 소문자, 하이픈(-)만 사용하는 습관을 들이세요.

대화형 모드 (REPL)

Python에는 코드를 한 줄씩 입력하고 바로 결과를 확인하는 대화형 모드가 있습니다. REPL(Read-Eval-Print Loop)이라고도 합니다.

1
1. 터미널에서 python 입력
터미널(또는 VS Code 터미널)에서 python만 입력하고 Enter를 누릅니다.
2
2. >>> 프롬프트 확인
>>> 기호가 나타나면 대화형 모드에 진입한 것입니다.
3
3. 코드 입력
>>> 뒤에 Python 코드를 입력하면 바로 실행됩니다.
4
4. 종료
exit() 또는 quit()를 입력하면 대화형 모드를 종료합니다.
Python대화형 모드 (REPL)
1>>> print("Hello")
2Hello
3>>> 1 + 2
43
5>>> "Python" * 3
6'PythonPythonPython'
7>>> exit()

스크립트 모드 vs 대화형 모드

스크립트 모드 (.py 파일)
Python
1# hello.py 파일에 저장
2print("Hello")
3print(1 + 2)
4
5# 실행: python hello.py
6# 파일 전체가 한 번에 실행됨
대화형 모드 (REPL)
Python
1# 터미널에서 python 입력
2>>> print("Hello")
3Hello
4>>> 1 + 2
53
6# 한 줄씩 입력하고 즉시 결과 확인

스크립트 모드는 파일에 코드를 저장하고 한꺼번에 실행합니다. 대화형 모드는 한 줄씩 바로 결과를 확인합니다. 프로그램을 만들 때는 스크립트 모드, 간단한 테스트에는 대화형 모드를 사용합니다.

TIP
대화형 모드의 특별한 기능
대화형 모드에서는 print() 없이도 값이 출력됩니다. >>> 1 + 2 라고 입력하면 바로 3이 나옵니다. 스크립트 모드에서는 print(1 + 2)라고 써야만 결과가 화면에 나타납니다.

에러 체험 — 설치 과정에서 흔한 문제

Python 설치 후 처음 실행할 때 자주 발생하는 문제들을 미리 알아두면 당황하지 않습니다.

문제 상황
Python
1C:\> python
2'python'은(는) 내부 또는 외부 명령
3실행할 수 있는 프로그램, 또는
4배치 파일이 아닙니다.
해결 방법
Python
1# 원인: PATH 미설정
2# 해결 1: py 명령 사용
3C:\> py --version
4
5# 해결 2: Python 재설치
6# Add python.exe to PATH 체크

가장 흔한 문제입니다. Python 설치 시 "Add python.exe to PATH"를 체크하지 않으면 발생합니다.

문제 상황
Python
1# VS Code에서 실행했는데
2# 터미널에 아무것도 안 나옴
3
4# hello.py
51 + 2
해결 방법
Python
1# 원인: print() 누락
2# 스크립트 모드에서는
3# print()를 써야 출력됨
4
5# hello.py
6print(1 + 2)

대화형 모드(REPL)에서는 1 + 2만 입력해도 결과가 나오지만, .py 파일(스크립트 모드)에서는 반드시 print()로 감싸야 화면에 출력됩니다.

문제 상황
Python
1# 터미널에서 python 입력 후
2# >>> 가 나온 상태에서
3>>> python hello.py
4SyntaxError: invalid syntax
해결 방법
Python
1# 원인: 대화형 모드 안에서
2# 터미널 명령을 입력함
3
4# 해결: exit()로 먼저 나간 뒤
5>>> exit()
6C:\> python hello.py

>>> 프롬프트가 보이면 대화형 모드 안입니다. python hello.py는 터미널 명령이지 Python 코드가 아닙니다. exit()로 나간 뒤 실행하십시오.
