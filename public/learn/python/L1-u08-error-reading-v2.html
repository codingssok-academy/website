Chapter 08

에러 메시지 읽기

당황하지 않기 - SyntaxError, NameError, TypeError, IndentationError를 읽는 법을 배웁니다.

이 유닛에서 배우는 것

  • 에러 메시지의 구조(줄 번호, 화살표, 에러명)를 읽을 수 있습니다.
  • SyntaxError가 무엇인지 이해하고 고칠 수 있습니다.
  • NameError가 왜 발생하는지 설명할 수 있습니다.
  • TypeError를 만나면 자료형을 확인하고 고칠 수 있습니다.
  • IndentationError를 보고 들여쓰기를 수정할 수 있습니다.

에러는 친구다 - 에러 메시지 읽는 법

에러가 나면 당황하지 마세요. 파이썬이 "여기가 잘못됐어!"라고 친절하게 알려주는 것입니다.

따라해보세요
1
일부러 에러를 내보세요. 괄호를 안 닫아봅시다.
print("안녕"
SyntaxError가 발생합니다
2
없는 변수를 써보세요.
print(abc)
NameError: name 'abc' is not defined
3
문자열과 숫자를 더해보세요.
print("나이: " + 15)
TypeError가 발생합니다

SyntaxError - 문법이 틀렸을 때

SyntaxError는 파이썬 문법 규칙을 어겼을 때 발생합니다. 괄호, 따옴표, 콜론 등을 확인하세요.

따라해보세요
1
따옴표를 닫지 않으면 어떤 에러가 나는지 확인하세요.
print("안녕하세요)
SyntaxError: unterminated string literal
2
올바르게 고쳐서 실행하세요.
print("안녕하세요")
안녕하세요 가 정상 출력됩니다
3
print를 prnt로 잘못 쓰면 어떻게 되는지 보세요.
prnt("테스트")
NameError: name 'prnt' is not defined

NameError와 TypeError

NameError는 존재하지 않는 이름을 사용할 때 발생합니다. 오타가 가장 흔한 원인입니다.

TypeError는 자료형이 맞지 않을 때 발생합니다. 문자열과 숫자를 더하는 경우가 대표적입니다.

따라해보세요
1
변수 이름을 잘못 써보세요.
name = "민수" print(nme)
NameError: name 'nme' is not defined
2
올바른 변수 이름으로 고치세요.
name = "민수" print(name)
민수 가 출력됩니다
3
TypeError를 고쳐보세요.
# 에러 코드: print("합계: " + 100) print("합계: " + str(100))
합계: 100 이 출력됩니다

에러 고치기 연습

에러 코드를 보고 직접 고쳐보는 연습을 합시다. 에러 이름과 줄 번호를 먼저 확인하세요.

따라해보세요
1
불필요한 들여쓰기를 넣어서 IndentationError를 확인하세요.
x = 10 print(x)
IndentationError: unexpected indent
2
들여쓰기를 제거하고 다시 실행하세요.
x = 10 print(x)
10 이 정상 출력됩니다
3
여러 에러를 한 번에 고쳐보세요.
# 에러코드: prnt("점수: " + 100 # 1. prnt -> print (NameError 수정) # 2. 100 -> str(100) (TypeError 수정) # 3. 괄호 닫기 (SyntaxError 수정) print("점수: " + str(100))
점수: 100 이 출력됩니다

Q2
NameError 고치기
쉬움
아래 코드에서 NameError를 찾아 고치세요.
코드message = "Hi"
print(mesage)
출력Hi
내 답안
힌트 보기
변수 이름의 철자를 비교해보세요. message와 mesage는 다릅니다.
정답 확인
message = "Hi" print(message)
Q3
TypeError 고치기
보통
아래 코드에서 TypeError를 찾아 고치세요.
코드score = 95
print("내 점수: " + score + "점")
출력내 점수: 95점
내 답안
힌트 보기
숫자를 문자열로 변환하는 함수를 사용하세요.

score = 95 print("내 점수: " + str(score) + "점")

핵심 요약

이 유닛에서 배운 것

  • 에러 메시지는 에러 이름, 줄 번호, 설명으로 구성된다
  • SyntaxError: 괄호, 따옴표, 콜론 등 문법 실수
  • NameError: 오타이거나 정의되지 않은 이름 사용
  • TypeError: 자료형이 맞지 않을 때 (str + int 등)
  • IndentationError: 들여쓰기가 잘못되었을 때
