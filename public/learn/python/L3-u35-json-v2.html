Chapter 35 — L3c

JSON
데이터 교환의 표준

프로그램과 프로그램, 서버와 클라이언트 사이에서 데이터를 주고받는 표준 형식인 JSON을 파이썬에서 완벽하게 다루는 법을 배웁니다.

이 유닛에서 배우는 것

  • JSON이 무엇인지, 왜 데이터 교환의 표준이 되었는지 이해합니다.
  • import json으로 json 모듈을 불러오는 법을 배웁니다.
  • json.dumps()로 파이썬 객체를 JSON 문자열로 변환합니다.
  • json.loads()로 JSON 문자열을 파이썬 객체로 복원합니다.
  • json.dump() / json.load()로 파일에 JSON을 저장하고 읽습니다.
  • indent 옵션으로 JSON을 보기 좋게 정리합니다.
  • 실용 예시: 설정 파일(config.json)을 만들고 활용합니다.

JSON이란?

JSON(제이슨, JavaScript Object Notation)은 데이터를 저장하고 교환할 때 사용하는 텍스트 형식입니다. 이름에 JavaScript가 들어 있지만 어떤 프로그래밍 언어와도 함께 쓸 수 있습니다.

JSON 구조 살펴보기

JSON은 파이썬의 딕셔너리, 리스트와 매우 비슷하게 생겼습니다. 키-값 쌍으로 이루어진 구조를 사용합니다.

파이썬 vs JSON 비교

파이썬 JSON 설명
dict {"key": "val"} {"key": "val"} 거의 동일한 형태
list [1, 2, 3] [1, 2, 3] 동일
True / False true / false 소문자로 바뀜
None null 다른 이름 사용
작은따옴표 '...' 큰따옴표 "..." 만 허용 JSON은 반드시 큰따옴표

import json — 모듈 불러오기

파이썬은 JSON을 다루는 기능을 기본 모듈로 제공합니다. 별도 설치 없이 import json 한 줄로 바로 사용할 수 있습니다.

import json # 파이썬 기본 내장 모듈, 설치 불필요

json.dumps() — 파이썬 → JSON

dumps()는 파이썬 객체를 JSON 문자열로 변환합니다. dumps의 s는 string(문자열)을 뜻합니다.

import json person = {"name": "홍길동", "age": 16, "active": True} json_str = json.dumps(person) print(json_str) # {"name": "홍길동", "age": 16, "active": true} print(type(json_str)) # <class 'str'>
주목할 점

파이썬의 True가 JSON에서는 true(소문자)로, None은 null로 자동 변환됩니다.

json.loads() — JSON → 파이썬

loads()는 JSON 문자열을 파이썬 객체로 변환합니다. 네트워크나 파일에서 받아온 JSON 데이터를 파이썬에서 쓸 수 있게 만들 때 사용합니다.

import json json_str = '{"name": "이순신", "score": 98, "active": true}' data = json.loads(json_str) print(data) # {'name': '이순신', 'score': 98, 'active': True} print(type(data)) # <class 'dict'> print(data["name"]) # 이순신

실습 3 — 리스트 변환
리스트도 JSON으로 변환할 수 있습니다.
scores = [90, 85, 92, 78] print(json.dumps(scores))
[90, 85, 92, 78]

indent 옵션 — 보기 좋은 JSON

기본 dumps()는 모든 내용을 한 줄로 출력합니다. indent 옵션을 주면 들여쓰기가 적용되어 읽기 쉬운 형태로 출력됩니다.

import json person = { "name": "홍길동", "age": 16, "scores": [90, 85, 92] } # indent=2 : 들여쓰기 2칸 pretty = json.dumps(person, indent=2, ensure_ascii=False) print(pretty) # { # "name": "홍길동", # "age": 16, # "scores": [90, 85, 92] # }
ensure_ascii=False

기본값은 True라서 한글이 \uXXXX 형태로 깨져 보입니다. ensure_ascii=False를 지정하면 한글이 그대로 출력됩니다.

json.dump() / json.load() — 파일 읽기/쓰기

소문자 dump(), load()는 파일에 직접 JSON을 쓰거나 읽는 함수입니다. dumps()/loads()와 이름이 비슷하지만 s가 없으면 파일 대상입니다.

import json data = {"setting": "dark", "volume": 70} # 파일에 쓰기 with open("config.json", "w", encoding="utf-8") as f: json.dump(data, f, indent=2, ensure_ascii=False) # 파일에서 읽기 with open("config.json", "r", encoding="utf-8") as f: loaded = json.load(f) print(loaded) # {'setting': 'dark', 'volume': 70}

실용 예: 설정 파일(config.json) 만들기

JSON은 프로그램의 설정(configuration)을 저장하는 데 많이 쓰입니다. 게임 설정, 앱 환경설정 등이 모두 JSON 파일로 저장됩니다.

import json import os CONFIG_FILE = "config.json" # 기본 설정값 DEFAULT_CONFIG = { "theme": "light", "volume": 50, "language": "ko", "autosave": True } def load_config(): # 파일이 있으면 읽고, 없으면 기본값 반환 if os.path.exists(CONFIG_FILE): with open(CONFIG_FILE, "r", encoding="utf-8") as f: return json.load(f) return DEFAULT_CONFIG.copy() def save_config(config): with open(CONFIG_FILE, "w", encoding="utf-8") as f: json.dump(config, f, indent=2, ensure_ascii=False) # 사용 예 config = load_config() config["theme"] = "dark" # 설정 변경 save_config(config) # 파일에 저장 print("저장 완료:", config)

핵심 요약

  • JSON은 텍스트 기반 데이터 교환 형식. 어떤 언어와도 호환됨
  • import json — 별도 설치 없이 바로 사용 가능한 내장 모듈
  • json.dumps(obj) — 파이썬 객체 → JSON 문자열 (s = string)
  • json.loads(str) — JSON 문자열 → 파이썬 객체 (s = string)
  • json.dump(obj, f) — 파일에 JSON 쓰기 (s 없음 = file)
  • json.load(f) — 파일에서 JSON 읽기 (s 없음 = file)
  • indent=2 — 들여쓰기로 보기 좋게 출력
  • ensure_ascii=False — 한글 깨짐 방지 옵션
  • True/False → true/false, None → null 로 자동 변환됨

JSON 타입 변환 완전 정리

오류 처리 — JSONDecodeError

JSON 형식이 잘못된 문자열을 loads()에 넘기면 json.JSONDecodeError가 발생합니다. try/except로 안전하게 처리하세요.

import json bad_json = "{'name': '홍길동'}" # 작은따옴표 사용 - JSON 형식 위반 try: data = json.loads(bad_json) except json.JSONDecodeError as e: print("JSON 오류:", e) # JSON 오류: Expecting property name enclosed in double quotes

API 응답 처리 실습 예

실제로 JSON은 웹 API(인터넷 서비스 연결)에서 가장 많이 씁니다. 서버가 보내주는 JSON 문자열을 파이썬으로 받아 처리하는 패턴입니다.

import json # 서버에서 받아온 JSON 응답 (실제로는 requests.get().text) api_response = ''' { "status": "success", "data": { "students": [ {"name": "김민준", "score": 92}, {"name": "이지은", "score": 87}, {"name": "박지현", "score": 95} ] } } ''' result = json.loads(api_response) # 학생 목록 순회 students = result["data"]["students"] for s in students: print(f"{s['name']}: {s['score']}점") # 김민준: 92점 # 이지은: 87점 # 박지현: 95점
