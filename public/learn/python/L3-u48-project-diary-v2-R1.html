파일 생성, 읽기, 수정, 삭제를 직접 구현하고 메모 목록을 관리합니다. try/except로 파일 오류를 안전하게 처리합니다.

이 유닛에서 만드는 것

  • 메모를 파일에 추가(append 모드)하고 고유 ID를 부여할 수 있습니다.
  • 저장된 메모 전체 목록과 특정 메모 내용을 조회할 수 있습니다.
  • 기존 메모의 내용을 수정하여 파일을 갱신할 수 있습니다.
  • 특정 ID의 메모를 파일에서 삭제할 수 있습니다.
  • try/except로 파일 없음, 잘못된 ID 등의 오류를 안전하게 처리합니다.
  • 메뉴 루프로 사용자가 원하는 기능을 반복 선택할 수 있습니다.

Step 1 — 파일 구조 설계와 메모 저장 형식

메모는 notes.txt 한 파일에 ID, 제목, 내용을 구분자로 나눠 한 줄씩 저장합니다. 이렇게 하면 한 줄을 읽으면 한 개의 메모 정보가 완성됩니다.

split("|", 2)로 파싱하면 ID, 제목, 내용을 정확히 분리할 수 있습니다. maxsplit=2를 주면 내용 안에 |가 있어도 내용이 잘리지 않습니다.

메모 추가 함수

def add_note(title, content, filename="notes.txt"): # 기존 파일에서 최대 ID 파악 new_id = 1 try: with open(filename, "r", encoding="utf-8") as f: lines = f.readlines() if lines: last = lines[-1].split("|", 2) new_id = int(last[0]) + 1 except FileNotFoundError: pass # 파일 없으면 ID=1부터 시작 with open(filename, "a", encoding="utf-8") as f: f.write(f"{new_id}|{title}|{content}\n") print(f"[저장됨] ID {new_id}: {title}")

Step 2 — 메모 읽기와 목록 조회

저장된 모든 메모의 목록을 보거나, 특정 ID의 메모 내용을 상세 조회하는 기능을 만듭니다.

def list_notes(filename="notes.txt"): """모든 메모 목록 출력""" try: with open(filename, "r", encoding="utf-8") as f: lines = f.readlines() if not lines: print("저장된 메모가 없습니다.") return print("--- 메모 목록 ---") for line in lines: parts = line.strip().split("|", 2) if len(parts) == 3: print(f"[{parts[0]}] {parts[1]}") except FileNotFoundError: print("아직 작성된 메모가 없습니다.") def read_note(note_id, filename="notes.txt"): """ID로 특정 메모 상세 조회""" try: with open(filename, "r", encoding="utf-8") as f: for line in f: parts = line.strip().split("|", 2) if len(parts) == 3 and parts[0] == str(note_id): print(f"제목: {parts[1]}") print(f"내용: {parts[2]}") return print(f"ID {note_id}에 해당하는 메모가 없습니다.") except FileNotFoundError: print("메모 파일이 존재하지 않습니다.")

Step 3 — 메모 수정과 삭제

파일에서 특정 줄만 바꾸거나 제거하려면 전체 내용을 읽어서 가공한 뒤 다시 쓰는 방식을 사용합니다. 이것이 텍스트 파일 수정의 표준 패턴입니다.

def update_note(note_id, new_title, new_content, filename="notes.txt"): try: with open(filename, "r", encoding="utf-8") as f: lines = f.readlines() updated = False new_lines = [] for line in lines: parts = line.strip().split("|", 2) if len(parts) == 3 and parts[0] == str(note_id): new_lines.append(f"{note_id}|{new_title}|{new_content}\n") updated = True else: new_lines.append(line) if not updated: print(f"ID {note_id}를 찾을 수 없습니다.") return with open(filename, "w", encoding="utf-8") as f: f.writelines(new_lines) print(f"[수정됨] ID {note_id}") except FileNotFoundError: print("메모 파일이 없습니다.") def delete_note(note_id, filename="notes.txt"): try: with open(filename, "r", encoding="utf-8") as f: lines = f.readlines() # 해당 ID 줄만 제외 new_lines = [l for l in lines if not l.startswith(str(note_id) + "|")] if len(new_lines) == len(lines): print(f"ID {note_id}를 찾을 수 없습니다.") return with open(filename, "w", encoding="utf-8") as f: f.writelines(new_lines) print(f"[삭제됨] ID {note_id}") except FileNotFoundError: print("메모 파일이 없습니다.")

Step 4 — 메뉴 루프로 완성하기

모든 기능을 연결하는 메뉴 루프를 만들어 완성합니다. 사용자가 번호를 입력하면 해당 기능이 실행되고, 0을 입력하면 종료됩니다.

def main(): while True: print("\n=== 메모장 ===") print("1. 메모 추가 2. 목록 보기 3. 내용 조회") print("4. 메모 수정 5. 메모 삭제 0. 종료") choice = input("선택: ").strip() if choice == "1": t = input("제목: ") c = input("내용: ") add_note(t, c) elif choice == "2": list_notes() elif choice == "3": nid = input("조회할 ID: ") read_note(nid) elif choice == "4": nid = input("수정할 ID: ") t = input("새 제목: ") c = input("새 내용: ") update_note(nid, t, c) elif choice == "5": nid = input("삭제할 ID: ") delete_note(nid) elif choice == "0": print("종료합니다.") break else: print("올바른 번호를 입력하세요.") main()

핵심 요약

  • open("a") — 기존 파일 내용을 지우지 않고 끝에 추가하는 append 모드
  • readlines() — 파일 전체를 줄 단위 리스트로 반환; 수정/삭제 시 필수
  • split("|", 2) — 구분자를 최대 2번만 분리; 내용 안의 | 보호
  • writelines() — 리스트를 한 번에 파일에 쓰는 함수
  • FileNotFoundError — 파일이 없을 때 발생하는 예외; try/except로 처리
  • 수정/삭제 패턴: 전체 읽기 → 가공 → 전체 다시 쓰기("w" 모드)
