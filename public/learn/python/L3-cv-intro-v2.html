Chapter L3-CV-1 — 컴퓨터 비전

OpenCV 소개
컴퓨터 비전의 시작

사진 한 장에서 얼굴을 찾고, 색을 바꾸고, 물체를 인식하는 기술 — 컴퓨터 비전. OpenCV로 파이썬에서 이미지를 다루는 첫걸음을 시작합니다.

이 유닛에서 배우는 것

  • 컴퓨터 비전이 무엇인지, 어디에 쓰이는지 이해합니다.
  • pip install opencv-python으로 OpenCV를 설치하는 방법을 배웁니다.
  • cv2.imread()로 이미지를 읽고, cv2.imshow()로 화면에 보여주고, cv2.imwrite()로 저장합니다.
  • BGR과 RGB의 차이와 왜 중요한지 알게 됩니다.
  • 이미지의 크기(shape)와 픽셀 값을 확인하는 방법을 배웁니다.

컴퓨터 비전이란?

컴퓨터 비전(Computer Vision)은 컴퓨터가 사람의 눈처럼 이미지나 영상을 이해하는 기술입니다. 사진에서 얼굴을 찾고, 자동차를 인식하고, 손글씨를 읽는 모든 것이 컴퓨터 비전입니다.

OpenCV란?

OpenCV(Open Source Computer Vision Library)는 1999년 Intel이 개발한 오픈소스 컴퓨터 비전 라이브러리입니다. 파이썬에서 import cv2로 사용하며, 이미지 처리부터 딥러닝까지 지원합니다.

OpenCV 설치

터미널(명령 프롬프트)에서 다음 명령어를 실행하면 설치됩니다.

# 터미널에서 실행 (파이썬 패키지 설치) pip install opencv-python # 설치 확인 import cv2 print(cv2.__version__) # 예: 4.8.0
왜 import cv2인가?

패키지 이름은 opencv-python이지만, 실제 모듈 이름은 cv2입니다. OpenCV 2.x 버전 때 이름이 cv2로 고정되어 지금도 그대로 사용합니다.

이미지 읽기 — cv2.imread()

cv2.imread()는 이미지 파일을 읽어 NumPy 배열로 반환합니다. 배열의 각 원소는 픽셀(pixel) 값을 나타냅니다.

import cv2 # 이미지 읽기 img = cv2.imread("photo.jpg") # 이미지 정보 확인 print(img.shape) # (480, 640, 3) — 높이, 너비, 채널수 print(img.dtype) # uint8 — 픽셀 값은 0~255 print(img.size) # 921600 — 전체 픽셀 수 (480*640*3)

이미지 보여주기 — cv2.imshow()

# 창을 열어 이미지 표시 cv2.imshow("My Photo", img) # 창 이름, 이미지 배열 cv2.waitKey(0) # 키 입력 대기 (0 = 무한 대기) cv2.destroyAllWindows() # 모든 창 닫기

이미지 저장 — cv2.imwrite()

# 이미지를 파일로 저장 cv2.imwrite("output.jpg", img) # 파일명, 이미지 배열 cv2.imwrite("output.png", img) # PNG 형식으로도 저장 가능

실습 1 — 이미지 읽고 정보 출력
임의의 이미지 파일을 읽어 shape, dtype, size를 출력하세요.
import cv2 import numpy as np # 테스트용 이미지 만들기 (빨간색 100x100) img = np.zeros((100, 100, 3), dtype=np.uint8) img[:] = [0, 0, 255] # BGR: 빨간색 print("shape:", img.shape) # (100, 100, 3) print("dtype:", img.dtype) # uint8
shape: (100, 100, 3) / dtype: uint8
실습 2 — 이미지 저장하고 다시 읽기
이미지를 파일로 저장한 뒤 다시 읽어보세요.
cv2.imwrite("test.png", img) img2 = cv2.imread("test.png") print("저장 후 읽기:", img2.shape)
저장 후 읽기: (100, 100, 3)
실습 3 — 픽셀 값 확인
특정 위치의 픽셀 값(BGR)을 출력하세요.
# [y, x] 순서로 접근 pixel = img[50, 50] # y=50, x=50 픽셀 print("픽셀 BGR:", pixel) # [0, 0, 255]
픽셀 BGR: [0 0 255]

BGR vs RGB — 색상 순서의 비밀

사람은 보통 RGB(Red, Green, Blue) 순서로 색을 표현합니다. 그런데 OpenCV는 BGR(Blue, Green, Red) 순서를 사용합니다. 이 차이를 모르면 색이 엉뚱하게 나옵니다!

Matplotlib 같은 라이브러리는 RGB를 기대합니다. OpenCV 이미지를 그대로 Matplotlib에 넘기면 파란색과 빨간색이 뒤바뀝니다. 이때 cv2.cvtColor()로 변환해야 합니다.

import cv2 img_bgr = cv2.imread("photo.jpg") # BGR -> RGB 변환 (Matplotlib 사용 시) img_rgb = cv2.cvtColor(img_bgr, cv2.COLOR_BGR2RGB) # BGR -> GRAY 변환 (흑백) img_gray = cv2.cvtColor(img_bgr, cv2.COLOR_BGR2GRAY) print("BGR shape:", img_bgr.shape) # (h, w, 3) print("GRAY shape:", img_gray.shape) # (h, w) — 채널 없음

imread() 플래그 옵션

플래그 의미 shape 예시
cv2.IMREAD_COLOR 컬러 이미지 (기본값) (h, w, 3)
cv2.IMREAD_GRAYSCALE 흑백으로 읽기 (h, w)
cv2.IMREAD_UNCHANGED 알파 채널 포함 (h, w, 4)

Q1
OpenCV 이미지 배열 이해
쉬움
다음 코드의 출력 결과로 올바른 것을 고르세요.
코드 import cv2, numpy as np
img = np.zeros((200, 300, 3), dtype=np.uint8)

보기 (1) (3, 200, 300) (2) (200, 300, 3) (3) (300, 200, 3)
내 답안
힌트 보기
NumPy 배열 shape는 (높이, 너비, 채널) 순서입니다. zeros((200, 300, 3))은 높이 200, 너비 300, 3채널을 의미합니다.
정답 보기
(2) (200, 300, 3) # 높이 200, 너비 300, 채널 3 (BGR)
Q2
BGR to RGB 변환 코드 작성
보통
OpenCV로 읽은 이미지 img_bgr을 RGB로 변환하여 img_rgb에 저장하는 코드를 완성하세요.
빈칸 img_rgb = cv2.cvtColor(img_bgr, cv2.___________)
내 답안
힌트 보기
cvtColor의 두 번째 인자는 변환 코드입니다. BGR에서 RGB로 변환하는 상수는 COLOR_BGR2RGB 형식입니다.

img_rgb = cv2.cvtColor(img_bgr, cv2.COLOR_BGR2RGB)
