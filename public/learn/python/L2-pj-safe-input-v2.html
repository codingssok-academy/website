안전한 입력

try/except로 잘못된 입력을 처리하고, while 루프로 올바른 값이 입력될 때까지 재시도하는 프로그램을 만듭니다.

이 프로젝트에서 배우는 것

  • try/except로 오류가 발생해도 프로그램이 멈추지 않도록 할 수 있습니다.
  • ValueError를 잡아 숫자가 아닌 입력을 처리할 수 있습니다.
  • while True와 break로 올바른 입력까지 계속 재시도하는 루프를 만듭니다.
  • 범위 조건 검사로 유효한 값만 받을 수 있습니다.
  • finally 블록으로 항상 실행되는 코드를 작성할 수 있습니다.

try/except로 오류 잡기

숫자가 아닌 값을 int()로 변환하면 ValueError가 발생합니다. try/except로 이 오류를 잡아 친절한 메시지를 출력할 수 있습니다.

# try/except 기본 구조 try: num = int(input("숫자를 입력하세요: ")) print(f"입력한 숫자: {num}") except ValueError: print("숫자만 입력할 수 있습니다!")
# 여러 오류 동시에 처리 try: a = int(input("분자: ")) b = int(input("분모: ")) print(f"결과: {a / b}") except ValueError: print("숫자를 입력하세요!") except ZeroDivisionError: print("0으로 나눌 수 없습니다!")

올바른 입력까지 재시도하기

while True + try/except를 조합하면 올바른 값이 입력될 때까지 계속 물어보는 견고한 입력 함수를 만들 수 있습니다.

def get_int(prompt): """올바른 정수를 입력받을 때까지 반복""" while True: try: value = int(input(prompt)) return value # 성공 시 반환 except ValueError: print("숫자만 입력할 수 있습니다. 다시 시도하세요.") # 사용 예시 age = get_int("나이를 입력하세요: ") print(f"나이: {age}살")

완성: 안전한 계산기

안전한 입력 함수를 활용해 오류가 없는 계산기를 만듭니다.

def get_number(prompt): while True: try: return float(input(prompt)) except ValueError: print("숫자를 입력해주세요!") print("=== 안전한 계산기 ===") a = get_number("첫 번째 숫자: ") b = get_number("두 번째 숫자: ") op = input("연산 (+,-,*,/): ") try: if op == "+": result = a + b elif op == "-": result = a - b elif op == "*": result = a * b elif op == "/": result = a / b else: print("알 수 없는 연산자!") result = None if result is not None: print(f"결과: {a} {op} {b} = {result}") except ZeroDivisionError: print("0으로 나눌 수 없습니다!")

핵심 요약

이 유닛에서 배운 것

  • try: 블록에 오류가 생길 수 있는 코드를 넣는다
  • except ValueError:로 잘못된 값 변환 오류를 잡는다
  • except ZeroDivisionError:로 0으로 나누기 오류를 잡는다
  • finally:는 오류 여부와 상관없이 항상 실행된다
  • while True + try/except + break로 견고한 입력 함수를 만든다
  • 범위 검사 if low <= n <= high:로 유효한 값만 허용한다
