가위바위보 토너먼트

플레이어 클래스, 랜덤 컴퓨터 상대, 재귀 토너먼트 대진표, 승패 기록, 최종 우승자 출력까지 — 객체지향과 재귀를 결합한 완성형 게임을 만듭니다.

이 유닛에서 만드는 것

  • Player 클래스로 이름, 승/패/무 기록을 객체로 관리할 수 있습니다.
  • random.choice()로 컴퓨터가 매번 다른 선택을 하는 랜덤 상대를 만들 수 있습니다.
  • 재귀 함수로 참가자 목록을 절반씩 줄여가며 토너먼트 대진표를 구현할 수 있습니다.
  • 매 경기 결과를 Player 객체의 속성에 기록하고 통계로 출력할 수 있습니다.
  • 최종 우승자를 결정하고 전체 경기 기록을 출력할 수 있습니다.

Step 1 — Player 클래스 설계

토너먼트의 핵심은 Player 클래스입니다. 이름과 승/패/무 카운터를 속성으로 가지고, 게임 결과를 기록하는 메서드를 제공합니다.

class Player: """가위바위보 플레이어""" def __init__(self, name: str): self.name = name self.wins = 0 self.losses = 0 def record_win(self): self.wins += 1 def record_loss(self): self.losses += 1 def __repr__(self): return f"Player({self.name!r}, W={self.wins}, L={self.losses})"

컴퓨터 상대도 Player를 그대로 사용합니다. 이름만 "Bot"으로 지정하면 됩니다.

가위바위보 한 판 결과 판정 함수

CHOICES 상수와 BEATS딕셔너리로 승패를 판정합니다. random.choice()는 리스트에서 무작위 항목을 선택합니다.

import random CHOICES = ["가위", "바위", "보"] BEATS = {"가위": "보", "바위": "가위", "보": "바위"} def play_match(p1: Player, p2: Player) -> Player: """p1 vs p2 한 경기. 승자(Player)를 반환. 무승부면 재경기.""" while True: c1 = random.choice(CHOICES) c2 = random.choice(CHOICES) print(f" {p1.name}: {c1} | {p2.name}: {c2}") if c1 == c2: print(" 무승부 — 재경기") elif BEATS[c1] == c2: p1.record_win() p2.record_loss() print(f" [{p1.name}] 승리") return p1 else: p2.record_win() p1.record_loss() print(f" [{p2.name}] 승리") return p2

Step 2 — 재귀로 토너먼트 대진표 구현

토너먼트는 "참가자 목록을 두 그룹으로 나누어 각 그룹에서 승자를 뽑아 다시 경기"하는 구조입니다. 이 반복 패턴을 재귀로 자연스럽게 표현할 수 있습니다.

재귀 토너먼트 함수

def run_tournament(players: list, round_name: str = "1라운드") -> Player: """참가자 목록을 받아 재귀적으로 토너먼트를 진행하고 우승자를 반환""" if len(players) == 1: # 기저 사례 return players[0] mid = len(players) // 2 left = players[:mid] right = players[mid:] print(f"\n--- {round_name} 상단 ---") winner_left = run_tournament(left, f"{round_name}-A") print(f"\n--- {round_name} 하단 ---") winner_right = run_tournament(right, f"{round_name}-B") print(f"\n[{round_name}] {winner_left.name} vs {winner_right.name}") return play_match(winner_left, winner_right)
--- 1라운드 상단-A --- Alice: 바위 | Bob: 가위 [Alice] 승리 --- 1라운드 하단-B --- Carol: 보 | Dave: 바위 [Carol] 승리 [1라운드] Alice vs Carol Alice: 가위 | Carol: 가위 무승부 — 재경기 Alice: 바위 | Carol: 가위 [Alice] 승리

Step 3 — 승패 기록과 최종 우승자 출력

토너먼트가 끝나면 모든 플레이어의 승/패 기록을 표로 출력하고 최종 우승자를 강조합니다.

def print_results(players: list, winner: Player): """전체 경기 기록과 우승자를 출력""" print("\n" + "=" * 38) print(f" 최종 우승자: {winner.name}") print("=" * 38) print(f"{'이름':<10} {'승':>4} {'패':>4}") print("-" * 22) ranked = sorted(players, key=lambda p: p.wins, reverse=True) for p in ranked: marker = " <-- 우승" if p.name == winner.name else "" print(f" {p.name:<10} {p.wins:>3} {p.losses:>4}{marker}")

Step 4 — 확장: 컴퓨터 vs 사람 모드

토너먼트에 사람 플레이어를 추가하면 게임이 더 재미있어집니다. is_human 속성을 Player에 추가하고, play_match에서 사람이면 input()으로 선택을 받습니다.

class Player: def __init__(self, name: str, is_human: bool = False): self.name = name self.is_human = is_human self.wins = 0 self.losses = 0 # record_win, record_loss, __repr__ 동일 def get_choice(player: Player) -> str: if player.is_human: while True: c = input(f"{player.name}의 선택 (가위/바위/보): ").strip() if c in CHOICES: return c print("가위, 바위, 보 중 하나를 입력하세요.") return random.choice(CHOICES)

승률 계산 메서드 추가
쉬움

Player 클래스에 win_rate() 메서드를 추가하세요. 전체 경기 수(wins + losses)가 0이면 0.0을 반환하고, 아니면 wins / (wins + losses)를 반환합니다.

예) alice.wins=3, alice.losses=1 → win_rate() = 0.75
예) new_player.wins=0, new_player.losses=0 → win_rate() = 0.0
힌트 보기
total = self.wins + self.losses 를 먼저 계산하고, total == 0이면 0.0을 반환하세요. 아니면 self.wins / total을 반환합니다.
정답 보기
def win_rate(self) -> float: total = self.wins + self.losses if total == 0: return 0.0 return self.wins / total

토너먼트 라운드 수 계산
보통

참가자 수 n을 받아 토너먼트에서 치러지는 총 경기 수를 반환하는 total_matches(n) 함수를 작성하세요. 토너먼트에서 총 경기 수는 항상 n - 1입니다.

예) total_matches(4) → 3
예) total_matches(8) → 7
힌트 보기
매 경기마다 한 명이 탈락합니다. n명에서 1명의 우승자가 나오려면 정확히 n-1번의 경기가 필요합니다.
정답 보기
def total_matches(n: int) -> int: """참가자 n명의 토너먼트 총 경기 수""" return n - 1

핵심 요약

  • class Player: __init__에서 속성 초기화, 메서드로 상태 변경 — 객체가 자신의 데이터를 관리
  • random.choice(list): 리스트에서 무작위 항목 한 개 선택 — 컴퓨터 상대 구현에 핵심
  • BEATS 딕셔너리: 승패 판정 로직을 데이터로 분리 — if/elif 중첩 없이 깔끔하게 처리
  • 재귀 토너먼트: 기저 사례(1명) + 일반 사례(절반 분할) — 참가자 수에 관계없이 작동
  • sorted(key=lambda p: p.wins, reverse=True): 객체 리스트를 속성 기준으로 정렬
  • max(players, key=lambda p: p.wins): 객체 리스트에서 속성 최댓값 보유 객체 반환
