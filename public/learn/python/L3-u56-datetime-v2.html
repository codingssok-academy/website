Chapter 56 — L3

datetime
날짜와 시간 다루기

파이썬 표준 라이브러리 datetime 모듈을 사용하여 현재 시간 조회, 날짜 계산, D-day 구하기, 원하는 형식으로 출력하는 방법을 배웁니다.

이 챕터에서 배울 것

  • datetime.now()로 현재 날짜와 시간 가져오기
  • date, time 클래스로 날짜/시간 독립 다루기
  • timedelta로 날짜 더하기/빼기
  • strftime() / strptime()으로 형식 변환
  • D-day 계산 등 실용적인 날짜 프로그래밍

datetime 모듈 기초

datetime은 파이썬 표준 라이브러리에 포함된 모듈로, 별도 설치 없이 바로 사용할 수 있다. 날짜, 시간, 날짜+시간, 시간 간격을 모두 다룬다.

1. 모듈 임포트 방법

세 가지 방식으로 임포트할 수 있다. 보통 두 번째 방식이 가장 많이 쓰인다.

# 방법 1: 모듈 전체 임포트 import datetime now = datetime.datetime.now() # 방법 2: 클래스만 임포트 (권장) from datetime import datetime, date, time, timedelta # 방법 3: 특정 클래스만 from datetime import datetime

2. datetime.now() — 현재 날짜와 시간

datetime.now()는 현재 시스템 날짜와 시간을 datetime 객체로 반환한다. 연도, 월, 일, 시, 분, 초, 마이크로초 속성을 모두 포함한다.

from datetime import datetime now = datetime.now() print(now) # 2026-03-21 14:30:25.123456 # 각 속성 분리 접근 print(now.year) # 2026 print(now.month) # 3 print(now.day) # 21 print(now.hour) # 14 print(now.minute) # 30 print(now.second) # 25

3. date 클래스 — 날짜만 다루기

date 클래스는 날짜(연/월/일)만 저장한다. date.today()로 오늘 날짜를 가져오거나, date(년, 월, 일)로 특정 날짜를 직접 만들 수 있다.

from datetime import date today = date.today() print(today) # 2026-03-21 # 특정 날짜 만들기 birthday = date(2008, 7, 15) print(birthday) # 2008-07-15 print(birthday.year) # 2008 print(birthday.month) # 7 print(birthday.day) # 15

4. time 클래스 — 시간만 다루기

time 클래스는 시(hour), 분(minute), 초(second), 마이크로초(microsecond)를 저장한다. 날짜 정보는 없다.

from datetime import time alarm = time(7, 30, 0) print(alarm) # 07:30:00 print(alarm.hour) # 7 print(alarm.minute) # 30 meeting = time(14, 0, 0) print(meeting) # 14:00:00

날짜 형식 변환 — strftime / strptime

날짜를 사람이 읽기 좋은 문자열로 변환하거나, 문자열을 datetime 객체로 변환할 때 사용한다. 형식 코드(format code)를 외워두면 편하다.

strftime() — datetime → 문자열

strftime(format)은 datetime 객체를 원하는 형식의 문자열로 바꾼다. "strftime" = format.

from datetime import datetime now = datetime.now() # 한국어 날짜 형식 print(now.strftime("%Y년 %m월 %d일")) # 2026년 03월 21일 # 시간 포함 print(now.strftime("%Y-%m-%d %H:%M:%S")) # 2026-03-21 14:30:25 # 요일 포함 print(now.strftime("%Y/%m/%d (%A)")) # 2026/03/21 (Saturday) # 12시간 형식 print(now.strftime("%I:%M %p")) # 02:30 PM
코드의미예시
%Y4자리 연도2026
%m2자리 월 (01~12)03
%d2자리 일 (01~31)21
%H24시간 시 (00~23)14
%M분 (00~59)30
%S초 (00~59)25
%A요일 (영어 전체)Saturday
%pAM / PMPM

strptime() — 문자열 → datetime

strptime(string, format)은 문자열을 datetime 객체로 변환한다. 파일이나 사용자 입력에서 날짜 문자열을 받아 계산할 때 사용한다.

from datetime import datetime # 문자열 → datetime 변환 date_str = "2026-12-25" christmas = datetime.strptime(date_str, "%Y-%m-%d") print(christmas) # 2026-12-25 00:00:00 print(type(christmas)) # <class 'datetime.datetime'> # 다양한 입력 형식 처리 d1 = datetime.strptime("21/03/2026", "%d/%m/%Y") d2 = datetime.strptime("2026년 3월 21일", "%Y년 %m월 %d일")

timedelta — 날짜와 시간 계산

timedelta는 두 날짜 사이의 시간 간격을 나타내는 객체다. days, seconds, microseconds를 인자로 받는다. datetime 객체에 더하거나 빼면 새로운 날짜를 계산할 수 있다.

from datetime import datetime, timedelta today = datetime.now() # 날짜 더하기 next_week = today + timedelta(days=7) next_month = today + timedelta(days=30) print(next_week.strftime("%Y-%m-%d")) # 7일 후 # 날짜 빼기 yesterday = today - timedelta(days=1) last_year = today - timedelta(days=365) # 시간 단위 two_hours_later = today + timedelta(hours=2) half_hour_ago = today - timedelta(minutes=30)

두 날짜 사이의 차이 계산

두 datetime 또는 date 객체를 빼면 timedelta 객체가 나온다. .days 속성으로 일수 차이를 구할 수 있다.

from datetime import date birthday = date(2008, 7, 15) today = date.today() diff = today - birthday print(diff) # 6459 days, 0:00:00 print(diff.days) # 6459 (일수) print(diff.days // 365) # 17 (대략 나이)

D-day 계산 실전 예제

수능, 시험, 행사까지 남은 날수를 계산하는 패턴이다. 날짜가 지났으면 음수가 나오므로 abs()나 조건문으로 처리한다.

from datetime import date today = date.today() exam_day = date(2026, 11, 19) # 수능일 diff = exam_day - today if diff.days > 0: print(f"수능까지 D-{diff.days}") elif diff.days == 0: print("오늘이 수능일!") else: print(f"수능이 {abs(diff.days)}일 지났음")

실용 예제

나이 계산기

생년월일을 입력받아 정확한 나이를 계산한다. 생일이 지났는지 여부에 따라 +1 처리한다.

from datetime import date birth_str = input("생년월일 입력 (YYYY-MM-DD): ") birth_date = date.fromisoformat(birth_str) # Python 3.7+ today = date.today() age = today.year - birth_date.year # 아직 생일이 안 지났으면 1 빼기 if (today.month, today.day) < (birth_date.month, birth_date.day): age -= 1 print(f"만 {age}세 입니다.")

날짜 범위 생성기

timedelta를 반복문과 함께 써서 날짜 목록을 만들 수 있다.

from datetime import date, timedelta start = date(2026, 3, 21) end = date(2026, 3, 27) current = start while current <= end: print(current.strftime("%m/%d (%a)")) current += timedelta(days=1)

03/26 (Thu)
03/27 (Fri)

핵심 요약

  • from datetime import datetime, date, time, timedelta — 4가지 핵심 클래스
  • datetime.now() — 현재 날짜+시간 / date.today() — 오늘 날짜
  • strftime(format) — datetime → 문자열 / strptime(str, format) — 문자열 → datetime
  • timedelta(days=N) — 날짜 더하기/빼기, 두 날짜 차이 계산
  • %Y %m %d %H %M %S — 연/월/일/시/분/초 형식 코드
  • D-day = 목표날짜 - 오늘 → .days 속성으로 일수 추출
