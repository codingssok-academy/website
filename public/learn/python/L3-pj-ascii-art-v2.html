프로젝트:
ASCII 아트 생성기

문자를 반복(*, #, | 등)해서 별, 삼각형, 다이아몬드 같은 도형을 만들고, 이름을 입력하면 배너로 출력하는 프로그램을 만듭니다. for 문과 문자열 연산의 정수를 보여줍니다.

이 유닛에서 만드는 것

  • "*" * n 문자열 곱셈으로 반복 패턴을 만들 수 있습니다.
  • 중첩 for 문으로 2D 패턴(삼각형, 사각형)을 출력할 수 있습니다.
  • range()의 시작/끝/스텝을 조절해 다이아몬드를 만들 수 있습니다.
  • 이름을 입력받아 길이에 맞춘 배너를 자동으로 생성할 수 있습니다.
  • 함수로 각 도형 생성 기능을 분리해 재사용할 수 있습니다.

Step 1 — 문자열 곱셈과 패턴 반복

파이썬에서 문자열에 정수를 곱하면 해당 문자열이 그 수만큼 반복됩니다. "*" * 5는 "*****"가 됩니다. 이 기능과 for 문을 합치면 단계적으로 늘어나는 패턴을 만들 수 있습니다.

# Step 1: 직각삼각형 출력 def triangle(size, char="*"): """size 크기의 직각삼각형 출력""" for i in range(1, size + 1): print(char * i) triangle(5) print() triangle(4, "#") # 다른 문자 사용
* ** *** **** ***** # ## ### ####

역삼각형 — range의 역순 활용

range(start, stop, step)에서 step을 음수로 주면 역순으로 순회합니다. range(5, 0, -1)은 5, 4, 3, 2, 1을 생성합니다.

Step 2 — 사각형과 다이아몬드

속이 빈 사각형을 만들려면 첫 줄과 마지막 줄은 전체를 채우고, 중간 줄은 양 끝만 채웁니다. 조건문으로 현재 줄이 첫 줄인지 마지막 줄인지 판단합니다.

# Step 2a: 속빈 사각형 def rectangle(width, height=None): """width x height 속빈 사각형""" if height is None: height = width # 정사각형 for i in range(height): if i == 0 or i == height - 1: print("* " * width) else: print("* " + " " * (width - 2) + "*") rectangle(5, 4)

다이아몬드 — 공백과 별의 조합

다이아몬드는 위로 갈수록 앞 공백이 줄고 별이 늘어나다가, 중간을 기점으로 반대가 됩니다. range를 두 번 사용해 위 절반과 아래 절반을 각각 그립니다.

# Step 2b: 다이아몬드 def diamond(size): """size 크기 다이아몬드""" # 위 절반 (점점 커짐) for i in range(1, size + 1): spaces = " " * (size - i) stars = "*" * (2 * i - 1) print(spaces + stars) # 아래 절반 (점점 작아짐) for i in range(size - 1, 0, -1): spaces = " " * (size - i) stars = "*" * (2 * i - 1) print(spaces + stars) diamond(4)

Step 3 — 이름 배너 만들기

이름을 입력받아 그 길이에 맞게 자동으로 테두리를 만드는 배너 함수를 만듭니다. len(name)으로 이름 길이를 측정하고, 그에 맞춰 "#" 문자를 반복합니다.

# Step 3: 이름 배너 함수 def name_banner(name, border="#"): """이름을 받아 테두리가 있는 배너 출력""" width = len(name) + 4 # 양쪽 "# " + " #" = 4 line = border * width print(line) print(f"{border} {name} {border}") print(line) name_banner("Python") print() name_banner("나는 코딩왕", "=") # 한글 이름도 가능

Q1
계단 모양 출력
기본
아래처럼 계단 모양으로 출력하는 stairs(n) 함수를 만드세요. 각 줄은 줄 번호만큼 공백이 앞에 붙고, 별 하나가 옵니다. 문자열 곱셈 " " * i를 활용하세요.
입력 stairs(4)
출력 * / _* / _ _* / _ _ _* (각 줄)
힌트 보기
range(n) 반복에서 " " * i + "*" 를 출력하세요. i=0이면 공백 0개, i=1이면 공백 1개가 됩니다.
정답 보기
def stairs(n): for i in range(n): print(" " * i + "*")

Q2
숫자 피라미드 출력
보통
별 대신 줄 번호를 출력하는 숫자 피라미드를 만드세요. 각 줄 i에서 숫자 1부터 i까지를 공백 없이 출력합니다. str(j)로 숫자를 문자열로 변환해 연결합니다.
입력 num_pyramid(5)
출력 1 / 12 / 123 / 1234 / 12345
힌트 보기
외부 for i in range(1, n+1), 내부에서 "".join([str(j) for j in range(1, i+1)]) 로 각 줄을 만드세요.
정답 보기
def num_pyramid(n): for i in range(1, n + 1): row = "".join([str(j) for j in range(1, i + 1)]) print(row)
Q3
체스판 패턴 만들기
심화
n x n 크기의 체스판 패턴을 출력하세요. 행과 열의 합이 짝수이면 "#", 홀수이면 " "를 출력합니다. 행과 열 인덱스의 합인 i + j의 홀짝을 나머지 연산자 %로 판별하세요.
입력 chess(4)
출력 # # # # / # # # # (교대 패턴)
힌트 보기
이중 for 문에서 (i + j) % 2 == 0 이면 "#", 아니면 " " 를 row 문자열에 추가하세요.
정답 보기
def chess(n): for i in range(n): row = "" for j in range(n): row += "# " if (i + j) % 2 == 0 else " " print(row)

핵심 요약

  • "*" * n 문자열 곱셈으로 n개의 문자를 반복 생성합니다.
  • range(start, stop, step)에서 step을 음수로 주면 역순 순회입니다.
  • 중첩 for 문으로 2D 패턴(사각형, 다이아몬드)을 그릴 수 있습니다.
  • len(name)으로 문자열 길이를 측정해 동적 테두리를 만듭니다.
  • " " * i + "*" 패턴으로 들여쓰기가 있는 도형을 만듭니다.
