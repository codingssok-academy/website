프로젝트:
한줄 일기

매일 한 줄씩 일기를 입력하고 리스트에 모은 뒤 전체를 출력하는 프로그램을 만듭니다. input, 리스트, for 문의 기초를 실전에서 익힙니다.

이 프로젝트에서 배우는 것

  • input()으로 사용자에게 텍스트를 입력받을 수 있습니다.
  • list.append()로 리스트에 항목을 추가할 수 있습니다.
  • while True 루프로 반복 입력을 처리할 수 있습니다.
  • for 문으로 리스트 전체를 순서대로 출력할 수 있습니다.
  • len()으로 리스트 항목 수를 셀 수 있습니다.

Step 1 — 리스트에 항목 추가하기

리스트는 여러 개의 값을 순서대로 저장하는 자료구조입니다. append()를 쓰면 리스트 맨 뒤에 새 항목을 추가할 수 있습니다.

# 빈 리스트 만들기 diary = [] # 항목 추가 diary.append("오늘 학교 다녀왔다") diary.append("점심에 라면 먹었다") diary.append("수학 시험 봤다") print(diary) print("총", len(diary), "개의 일기")
['오늘 학교 다녀왔다', '점심에 라면 먹었다', '수학 시험 봤다'] 총 3 개의 일기

for 문으로 리스트 출력하기

for item in list 패턴을 쓰면 리스트의 모든 항목을 하나씩 꺼낼 수 있습니다. enumerate()를 쓰면 번호와 함께 출력할 수 있습니다.

# enumerate로 번호 붙여 출력 for i, entry in enumerate(diary, 1): print(f"Day {i}: {entry}")
Day 1: 오늘 학교 다녀왔다 Day 2: 점심에 라면 먹었다 Day 3: 수학 시험 봤다

Step 2 — while 루프로 반복 입력받기

while True는 무한 반복 루프입니다. 사용자가 특정 단어를 입력할 때까지 계속 일기를 받을 수 있습니다. break로 루프를 종료합니다.

# while 루프로 일기 입력받기 diary = [] print("한줄 일기 앱에 오신 걸 환영합니다!") print("종료하려면 'quit'을 입력하세요.") print() while True: entry = input(f"Day {len(diary)+1} 일기: ") if entry == "quit": break if entry == "": print("빈 내용입니다. 다시 입력해주세요.") continue diary.append(entry) print("저장되었습니다.")

전체 일기 출력 함수

저장된 일기를 보기 좋게 출력하는 함수를 만듭니다. 날짜는 1, 2, 3... 순서로 표시하고, 일기가 없으면 안내 메시지를 출력합니다.

# 전체 일기 출력 함수 def show_diary(diary): if len(diary) == 0: print("아직 일기가 없습니다.") return print("\n===== 나의 일기장 =====") for i, entry in enumerate(diary, 1): print(f"Day {i:2d}: {entry}") print(f"=====================") print(f"총 {len(diary)}일의 기록")

Step 3 — 완성 코드 & 도전 문제

지금까지 배운 내용을 합쳐 완전한 한줄 일기 앱을 만듭니다. 입력 → 저장 → 출력의 흐름을 함수로 정리합니다.

# 완성된 한줄 일기 앱 diary = [] def write_diary(): entry = input(f"Day {len(diary)+1} 일기: ") if entry: diary.append(entry) print("저장 완료!") def show_diary(): if not diary: print("일기가 없습니다.") return for i, entry in enumerate(diary, 1): print(f"Day {i}: {entry}") while True: menu = input("\n1.쓰기 2.보기 3.종료: ") if menu == "1": write_diary() elif menu == "2": show_diary() elif menu == "3": print("안녕히 가세요!") break

핵심 요약

  • list.append(x) — 리스트 끝에 항목 x를 추가
  • while True: ... break — 조건이 맞을 때까지 반복
  • for i, v in enumerate(lst, 1) — 번호와 값 동시에 순회
  • len(lst) — 리스트 항목 수 반환
  • if keyword in entry — 문자열 포함 여부 확인
