프로젝트:
보물찾기 게임

2차원 리스트로 게임 맵을 만들고, 랜덤으로 보물 위치를 배치합니다. 상하좌우 이동, 거리 기반 힌트, 함정 피하기 기능을 가진 탐험 게임을 완성합니다.

이 프로젝트에서 만드는 것

  • 2차원 리스트(리스트 컴프리헨션)로 5x5 게임 맵을 생성합니다.
  • random.randint()로 보물과 함정의 좌표를 랜덤 배치합니다.
  • 방향키(w/a/s/d)로 플레이어를 상하좌우 이동시킵니다.
  • 맨해튼 거리 계산으로 보물까지 남은 거리를 힌트로 표시합니다.
  • 맵 경계 검사로 벽을 통과하지 못하도록 처리합니다.

Step 1 — 2차원 리스트 맵 생성

게임 맵은 2차원 리스트로 만듭니다. 5x5 크기의 맵에서 map[행][열]로 각 칸에 접근합니다. 보물(T), 함정(X), 플레이어(P), 빈칸(.)을 배치합니다.

import random SIZE = 5 # 5x5 맵 def create_map(): """빈 게임 맵 생성 (모두 '.'으로 채우기)""" return [['.' for _ in range(SIZE)] for _ in range(SIZE)] def print_map(game_map, player_r, player_c): """맵 출력 — 플레이어 위치는 P로 표시""" print() for r in range(SIZE): row = [] for c in range(SIZE): if r == player_r and c == player_c: row.append('P') else: row.append('?') # 미탐색 지역은 ? print(' '.join(row)) def place_items(game_map): """보물과 함정을 랜덤 배치""" positions = set() positions.add((0, 0)) # 시작 위치 예약 # 보물 1개 배치 while True: r, c = random.randint(0, SIZE-1), random.randint(0, SIZE-1) if (r, c) not in positions: game_map[r][c] = 'T' treasure = (r, c) positions.add((r, c)) break # 함정 3개 배치 for _ in range(3): while True: r, c = random.randint(0, SIZE-1), random.randint(0, SIZE-1) if (r, c) not in positions: game_map[r][c] = 'X' positions.add((r, c)) break return treasure # 테스트 gmap = create_map() treasure_pos = place_items(gmap) print(f"보물 위치: {treasure_pos} (게임 중 숨김)") print_map(gmap, 0, 0)

Step 2 — 이동 로직과 거리 힌트

w(위)/s(아래)/a(왼쪽)/d(오른쪽) 키로 플레이어를 이동합니다. 맵 경계를 벗어나면 이동을 막고, 이동 후 보물까지의 맨해튼 거리를 힌트로 표시합니다.

def get_distance(r1, c1, r2, c2): """맨해튼 거리 계산""" return abs(r1 - r2) + abs(c1 - c2) def get_hint(distance): """거리에 따른 힌트 메시지""" if distance <= 1: return "불타오른다! 바로 근처야!" elif distance <= 3: return "따뜻해지고 있어!" elif distance <= 5: return "좀 차갑네..." else: return "완전 얼음장이야. 반대편을 찾아봐" MOVES = {'w': (-1, 0), 's': (1, 0), 'a': (0, -1), 'd': (0, 1)} def play_treasure(): gmap = create_map() treasure = place_items(gmap) pr, pc = 0, 0 # 플레이어 시작 위치 lives = 3 print("=== 보물찾기 시작! (w/s/a/d 이동, q 포기) ===") while lives > 0: print_map(gmap, pr, pc) dist = get_distance(pr, pc, treasure[0], treasure[1]) print(f"힌트: {get_hint(dist)} 목숨: {'*' * lives}") cmd = input("이동: ").strip().lower() if cmd == 'q': print(f"포기! 보물은 {treasure}에 있었어.") return if cmd not in MOVES: print("w/s/a/d 중 하나만 입력하세요") continue dr, dc = MOVES[cmd] nr, nc = pr + dr, pc + dc if not (0 <= nr < SIZE and 0 <= nc < SIZE): print("벽이야! 못 가.") continue pr, pc = nr, nc if gmap[pr][pc] == 'T': print(f"보물 발견! ({pr},{pc}) 축하!") return elif gmap[pr][pc] == 'X': lives -= 1 print(f"함정이다! 목숨 -1 (남은 목숨: {lives})") gmap[pr][pc] = '.' # 함정 제거 print(f"목숨 소진. 보물은 {treasure}에 있었어.") play_treasure()

핵심 요약

  • 2차원 리스트 — [[값] * 열 for _ in range(행)]으로 생성
  • map[r][c] — 2차원 리스트 접근: 행(r)과 열(c) 두 인덱스 필요
  • 맨해튼 거리 — abs(r1-r2) + abs(c1-c2) 격자형 거리 계산
  • 경계 검사 — 0 <= nr < SIZE and 0 <= nc < SIZE 반드시 이동 전에 검사
  • 방향 딕셔너리 — MOVES = {'w': (-1,0), ...} 이동 코드 간결화
  • set으로 이미 배치된 위치를 추적해 중복 배치 방지
