성적 등급 함수

점수를 받아 등급을 반환하는 함수를 만들고, 여러 학생의 성적을 처리하고 평균을 계산합니다.

이 프로젝트에서 배우는 것

  • 점수를 매개변수로 받아 등급 문자열을 반환하는 함수를 만들 수 있습니다.
  • 리스트와 for 루프로 여러 학생의 점수를 처리할 수 있습니다.
  • sum()과 len()으로 평균을 계산할 수 있습니다.
  • 함수를 반복적으로 호출해 여러 데이터를 처리하는 패턴을 익힙니다.
  • 결과를 깔끔하게 정리해서 출력하는 방법을 익힙니다.

점수 → 등급 함수 만들기

점수를 받아서 A, B, C, D, F 등급을 반환하는 함수 get_grade를 만듭니다. if/elif/else로 범위를 검사합니다.

def get_grade(score): """점수를 받아 등급 문자열을 반환""" if score >= 90: return "A" elif score >= 80: return "B" elif score >= 70: return "C" elif score >= 60: return "D" else: return "F" # 테스트 print(get_grade(95)) # A print(get_grade(82)) # B print(get_grade(55)) # F

여러 학생 처리하기

학생 이름과 점수를 묶은 딕셔너리 리스트를 만들고, 함수를 반복 호출해 전체 성적표를 출력합니다. sum()과 len()으로 평균도 계산합니다.

# 학생 데이터 students = [ {"name": "김민준", "score": 92}, {"name": "이서연", "score": 85}, {"name": "박지호", "score": 73}, {"name": "최유진", "score": 60}, {"name": "정다은", "score": 45}, ] print("=== 성적표 ===") for student in students: name = student["name"] score = student["score"] grade = get_grade(score) print(f"{name}: {score}점 ({grade})")
# 평균 계산 score_list = [student["score"] for student in students] total = sum(score_list) avg = total / len(score_list) print(f"\n반 평균: {avg:.1f}점") print(f"전체 등급: {get_grade(avg)}")

완성: 성적 처리 프로그램

입력 기능, 등급 함수, 평균 계산을 합친 완전한 성적 처리 프로그램을 만듭니다.

def get_grade(score): if score >= 90: return "A" elif score >= 80: return "B" elif score >= 70: return "C" elif score >= 60: return "D" else: return "F" students = [] n = int(input("학생 수: ")) for i in range(n): name = input(f"{i+1}번 이름: ") score = int(input(f"{name} 점수: ")) students.append({"name": name, "score": score}) print("\n=== 성적표 ===") score_list = [] for s in students: grade = get_grade(s["score"]) print(f"{s['name']}: {s['score']}점 ({grade})") score_list.append(s["score"]) avg = sum(score_list) / len(score_list) print(f"\n평균: {avg:.1f}점 ({get_grade(avg)})")

핵심 요약

이 유닛에서 배운 것

  • def get_grade(score):처럼 값을 받아 return으로 결과를 돌려주는 함수를 만든다
  • for student in students:로 리스트 안의 딕셔너리를 하나씩 처리한다
  • sum(리스트) / len(리스트)로 평균을 계산한다
  • 함수를 for 루프 안에서 반복 호출해 여러 데이터를 처리할 수 있다
  • max(), min()으로 최댓값, 최솟값을 찾는다
  • 딕셔너리로 카운터를 만들어 항목별 통계를 낼 수 있다
