텍스트 RPG 게임

클래스로 Player·Monster·Item을 설계하고, while 게임 루프 안에서 전투·레벨업·아이템 사용·저장/불러오기를 단계별로 구현합니다.

이 유닛에서 만드는 것

  • Player, Monster, Item 클래스를 설계하고 인스턴스를 생성할 수 있습니다.
  • while 루프로 게임이 계속 돌아가는 메인 루프를 만들 수 있습니다.

Step 1 — Player와 Monster 클래스 설계

RPG의 핵심은 캐릭터입니다. Player는 플레이어가 조종하는 영웅, Monster는 싸워야 할 적입니다. 두 클래스 모두 hp, attack 속성을 가지므로 공통 구조를 먼저 잡겠습니다.

class Player: def __init__(self, name): self.name = name self.hp = 100 self.max_hp = 100 self.attack = 15 self.level = 1 self.exp = 0 self.gold = 0 self.inventory = [] # 아이템 목록 def is_alive(self): return self.hp > 0 def take_damage(self, amount): self.hp = max(0, self.hp - amount) def status(self): print(f"[{self.name}] HP: {self.hp}/{self.max_hp} ATK: {self.attack} LV: {self.level} EXP: {self.exp}") class Monster: def __init__(self, name, hp, attack, reward_exp, reward_gold): self.name = name self.hp = hp self.attack = attack self.reward_exp = reward_exp self.reward_gold = reward_gold def is_alive(self): return self.hp > 0 def take_damage(self, amount): self.hp = max(0, self.hp - amount)

max(0, self.hp - amount) 패턴을 쓰면 HP가 음수가 되지 않아 안전합니다. 이처럼 경계값을 처리하는 것이 실전 코드의 습관입니다.

몬스터 목록 만들기

게임에 등장할 몬스터들을 리스트로 정의합니다. random.choice()로 매 전투마다 다른 몬스터를 만납니다.

import random MONSTERS = [ Monster("슬라임", 30, 5, 10, 5), Monster("고블린", 50, 10, 20, 15), Monster("오크", 80, 18, 35, 25), Monster("드래곤", 200,40, 80, 100), ] def spawn_monster(): """몬스터 목록에서 무작위로 한 마리를 반환""" template = random.choice(MONSTERS) # 원본 객체를 그대로 쓰면 HP가 줄어든 채로 재사용되므로 새 인스턴스를 만든다 return Monster(template.name, template.hp, template.attack, template.reward_exp, template.reward_gold)

Step 2 — Item 클래스와 전투 시스템

Item 클래스

아이템은 use(player) 메서드를 가집니다. 포션은 HP 회복, 파워업은 공격력 증가처럼 효과가 다양하므로 effect_type으로 종류를 구분합니다.

class Item: def __init__(self, name, effect_type, value): self.name = name # 아이템 이름 self.effect_type = effect_type # "heal" 또는 "attack_up" self.value = value # 효과 수치 def use(self, player): if self.effect_type == "heal": healed = min(self.value, player.max_hp - player.hp) player.hp += healed print(f"{self.name} 사용! HP +{healed} (현재 HP: {player.hp})") elif self.effect_type == "attack_up": player.attack += self.value print(f"{self.name} 사용! 공격력 +{self.value} (현재 공격력: {player.attack})") player.inventory.remove(self) # 사용 후 인벤토리에서 제거

전투 함수

battle(player, monster) 함수는 while 루프로 구현합니다. 플레이어와 몬스터가 번갈아 공격하고, 어느 한 쪽의 HP가 0이 될 때 루프가 끝납니다.

def battle(player, monster): print(f"\n[전투 시작] {monster.name} 등장! (HP: {monster.hp})") while player.is_alive() and monster.is_alive(): # 1. 플레이어 공격 (랜덤 변동 ±3) dmg = player.attack + random.randint(-3, 3) dmg = max(1, dmg) # 최소 1 보장 monster.take_damage(dmg) print(f" {player.name} 공격! -{dmg} (몬스터 HP: {monster.hp})") if not monster.is_alive(): break # 2. 몬스터 공격 m_dmg = monster.attack + random.randint(-2, 2) m_dmg = max(1, m_dmg) player.take_damage(m_dmg) print(f" {monster.name} 반격! -{m_dmg} (내 HP: {player.hp})") if monster.is_alive(): print("패배했습니다...") return False else: player.exp += monster.reward_exp player.gold += monster.reward_gold print(f"승리! EXP +{monster.reward_exp}, Gold +{monster.reward_gold}") return True
[전투 시작] 고블린 등장! (HP: 50) 영웅 공격! -17 (몬스터 HP: 33) 고블린 반격! -9 (내 HP: 91) 영웅 공격! -14 (몬스터 HP: 19) 고블린 반격! -11 (내 HP: 80) 영웅 공격! -19 (몬스터 HP: 0) 승리! EXP +20, Gold +15

Step 3 — 레벨업과 아이템 사용

레벨업 시스템

경험치가 level * 10 이상이 되면 레벨이 올라갑니다. 레벨이 오르면 최대 HP와 공격력이 증가하고 HP가 완전 회복됩니다.

def check_levelup(player): needed = player.level * 10 # 레벨업에 필요한 경험치 if player.exp >= needed: player.level += 1 player.max_hp += 20 player.hp = player.max_hp # 레벨업 시 HP 완전 회복 player.attack += 5 player.exp -= needed # 초과분을 다음 레벨로 이월 print(f"\n*** 레벨 업! LV {player.level} ***") print(f"최대 HP: {player.max_hp} 공격력: {player.attack}")

아이템 사용 메뉴

전투 후 메뉴에서 아이템을 선택해 사용합니다. 인벤토리가 비어 있으면 안내 메시지를 출력합니다.

def use_item_menu(player): if not player.inventory: print("인벤토리가 비어 있습니다.") return print("\n[인벤토리]") for i, item in enumerate(player.inventory, 1): print(f" {i}. {item.name} ({item.effect_type}: +{item.value})") print(" 0. 취소") choice = input("사용할 아이템 번호: ") if choice.isdigit(): idx = int(choice) - 1 if 0 <= idx < len(player.inventory): player.inventory[idx].use(player) else: print("잘못된 번호입니다.")

Step 4 — 파일 저장과 불러오기

게임을 껐다 켜도 진행 상황이 유지되도록 플레이어 상태를 파일에 저장합니다. json 모듈을 사용하면 딕셔너리를 파일에 쉽게 저장하고 읽어올 수 있습니다.

import json SAVE_FILE = "save.json" def save_game(player): """플레이어 상태를 JSON 파일에 저장""" data = { "name": player.name, "hp": player.hp, "max_hp": player.max_hp, "attack": player.attack, "level": player.level, "exp": player.exp, "gold": player.gold, } with open(SAVE_FILE, "w", encoding="utf-8") as f: json.dump(data, f, ensure_ascii=False, indent=2) print("게임을 저장했습니다.") def load_game(): """저장 파일이 있으면 불러오고, 없으면 None 반환""" try: with open(SAVE_FILE, "r", encoding="utf-8") as f: data = json.load(f) player = Player(data["name"]) player.hp = data["hp"] player.max_hp = data["max_hp"] player.attack = data["attack"] player.level = data["level"] player.exp = data["exp"] player.gold = data["gold"] print(f"저장 데이터를 불러왔습니다. [{player.name}] LV {player.level}") return player except FileNotFoundError: print("저장 파일 없음. 새 게임을 시작합니다.") return None

try / except FileNotFoundError로 파일이 없을 때를 처리합니다. 처음 실행할 때는 save.json이 없으므로 None을 반환해 새 게임을 시작하게 합니다.

저장 파일 형태 (save.json)

{ "name": "영웅", "hp": 85, "max_hp": 120, "attack": 20, "level": 2, "exp": 5, "gold": 40 }

Step 5 — while 게임 루프 완성

지금까지 만든 모든 함수와 클래스를 연결하는 메인 게임 루프입니다. 플레이어가 계속 선택을 할 수 있도록 while True로 무한 루프를 돌리고, 특정 조건에서 break로 종료합니다.

def main(): # 저장 파일 확인 → 있으면 불러오기, 없으면 새 게임 player = load_game() if player is None: name = input("캐릭터 이름을 입력하세요: ") player = Player(name) print("\n텍스트 RPG 게임에 오신 것을 환영합니다!") player.status() while True: print("\n1. 탐험 2. 아이템 사용 3. 저장 4. 종료") choice = input("선택: ").strip() if choice == "1": monster = spawn_monster() result = battle(player, monster) if result: check_levelup(player) # 낮은 확률로 포션 드롭 if random.randint(1, 10) <= 3: drop = Item("포션", "heal", 30) player.inventory.append(drop) print("포션을 획득했습니다!") else: print("게임 오버...") break elif choice == "2": use_item_menu(player) elif choice == "3": save_game(player) elif choice == "4": save_game(player) print("게임을 종료합니다.") break player.status() if __name__ == "__main__": main()

핵심 요약

핵심 요약 — 텍스트 RPG 게임

  • 클래스 설계: Player, Monster, Item은 각각 속성과 메서드를 가진 독립적인 객체입니다.
  • 전투 시스템: while player.is_alive() and monster.is_alive()로 양쪽이 살아있는 동안 루프를 반복합니다.
  • random 활용: random.randint(a, b)는 a~b 사이 정수, random.choice(list)는 리스트에서 무작위 1개를 선택합니다.
  • 레벨업: exp >= level * 10 조건으로 레벨을 올리고, 초과 경험치는 다음 레벨로 이월합니다.
  • 아이템 사용: item.use(player)는 effect_type에 따라 HP 회복 또는 공격력 증가 효과를 적용하고 인벤토리에서 제거합니다.
  • 파일 저장: json.dump(data, f)로 딕셔너리를 파일에 저장하고, json.load(f)로 다시 읽어옵니다.
  • 게임 루프: while True로 무한히 돌리고, 게임 종료 조건에서 break로 빠져나옵니다.

클래스 vs 딕셔너리 — 언제 어느 것을?

구분 클래스 딕셔너리
메서드(기능) 직접 정의 가능 (take_damage()) 별도 함수 필요
타입 구분 isinstance(obj, Player) 가능 타입 구분 어려움
파일 저장 직접 불가 → 딕셔너리로 변환 필요 json.dump() 바로 사용
적합한 상황 동작(메서드)이 많을 때 데이터 저장/전달만 할 때
