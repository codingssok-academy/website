딕셔너리로 레시피 데이터를 구성하고, 재료로 검색하고, 인분 수에 맞춰 재료를 비례 계산하며, CSV 파일로 저장합니다.

이 프로젝트에서 만드는 것

  • 중첩 딕셔너리(레시피명 → 재료/만드는법)로 레시피 데이터를 구성합니다.
  • 재료 이름으로 어떤 레시피에 들어가는지 검색하는 기능을 만듭니다.
  • 인분 수를 입력하면 재료 양을 비례식으로 자동 계산합니다.
  • csv 모듈로 레시피를 파일에 저장하고 불러옵니다.

Step 1 — 레시피 딕셔너리 구조 설계

레시피 데이터는 중첩 딕셔너리로 구성합니다. 레시피 이름을 키로, 재료(딕셔너리)와 만드는 법(리스트)을 값으로 저장합니다.

# Step 1: 레시피 딕셔너리 recipes = { "김치찌개": { "servings": 2, # 기준 인분 "ingredients": { "김치": 200, # 단위: g "돼지고기": 150, "두부": 100, "물": 500, }, "steps": [ "냄비에 물을 붓고 끓인다", "김치와 돼지고기를 넣는다", "두부를 넣고 5분 더 끓인다", ], }, "된장찌개": { "servings": 2, "ingredients": { "된장": 30, "두부": 150, "호박": 100, "물": 600, }, "steps": ["물을 끓인다", "된장을 푼다", "재료를 넣고 끓인다"], }, }

Step 2 — 재료로 검색 + 인분 비례 계산

특정 재료가 들어간 레시피를 찾고, 원하는 인분 수에 맞게 재료 양을 자동으로 비례 계산합니다.

# Step 2: 검색 + 비례 계산 def search_by_ingredient(ingredient): results = [] for name, data in recipes.items(): if ingredient in data["ingredients"]: results.append(name) return results def scale_ingredients(recipe_name, servings): recipe = recipes[recipe_name] base = recipe["servings"] # 기준 인분 scaled = {} for ing, amount in recipe["ingredients"].items(): scaled[ing] = round(amount / base * servings) return scaled def show_recipe(recipe_name, servings=None): recipe = recipes[recipe_name] base = recipe["servings"] target = servings or base print(f"=== {recipe_name} ({target}인분) ===") ings = scale_ingredients(recipe_name, target) print("[재료]") for ing, amt in ings.items(): print(f" {ing}: {amt}g") print("[만드는 법]") for i, step in enumerate(recipe["steps"], 1): print(f" {i}. {step}")

Step 3 — CSV 파일로 저장/불러오기

csv 모듈로 레시피 데이터를 CSV 파일에 저장합니다. CSV는 쉼표로 구분된 텍스트 형식으로 엑셀에서도 열 수 있습니다.

# Step 3: CSV 저장/불러오기 import csv def save_to_csv(filename="recipes.csv"): with open(filename, "w", newline="", encoding="utf-8-sig") as f: writer = csv.writer(f) writer.writerow(["이름", "기준인분", "재료(쉼표구분)", "단계수"]) for name, data in recipes.items(): ings_str = ",".join( f"{k}:{v}" for k, v in data["ingredients"].items() ) writer.writerow([name, data["servings"], ings_str, len(data["steps"])]) print(f"저장 완료: {filename}") def load_from_csv(filename="recipes.csv"): try: with open(filename, "r", encoding="utf-8-sig") as f: reader = csv.reader(f) next(reader) # 헤더 건너뜀 for row in reader: print(f"{row[0]} ({row[1]}인분) — 재료: {row[2]}") except FileNotFoundError: print("파일이 없습니다.")

Step 4 — 완성: 레시피 앱 메인 메뉴

메뉴 기반으로 레시피를 추가/검색/인분 계산/저장하는 완성 앱을 만듭니다.

# 완성 — 레시피 앱 def add_recipe(): name = input("요리 이름: ") base = int(input("기준 인분: ")) n = int(input("재료 개수: ")) ings = {} for _ in range(n): ing = input("재료명: ") amt = int(input("양(g): ")) ings[ing] = amt steps = [] while True: s = input("단계 (완료는 빈 입력): ") if not s: break steps.append(s) recipes[name] = {"servings": base, "ingredients": ings, "steps": steps} print(f"'{name}' 추가 완료!") def run_app(): while True: print("\n1.추가 2.검색(재료) 3.레시피 보기 4.저장 0.종료") c = input("선택: ") if c == "1": add_recipe() elif c == "2": ing = input("재료명: ") print(search_by_ingredient(ing)) elif c == "3": n = input("레시피명: ") s = int(input("인분 수: ")) show_recipe(n, s) elif c == "4": save_to_csv() elif c == "0": break

재료별 100g당 칼로리 딕셔너리(CALORIES = {"김치": 18, "돼지고기": 263, ...})를 만들고, 레시피의 총 예상 칼로리를 계산하는 calc_calories(recipe_name, servings) 함수를 작성하세요.

내 답안
힌트 보기

scaled = scale_ingredients(recipe_name, servings) 후 for ing, amt in scaled.items(): total += CALORIES.get(ing, 0) * amt / 100 패턴 사용.

정답 보기
CALORIES = {"김치": 18, "돼지고기": 263, "두부": 76, "물": 0, "된장": 198, "호박": 17} def calc_calories(recipe_name, servings): scaled = scale_ingredients(recipe_name, servings) total = 0 for ing, amt in scaled.items(): total += CALORIES.get(ing, 0) * amt / 100 return round(total)

핵심 요약

  • 중첩 딕셔너리로 {"레시피명": {"ingredients": {재료: 양}, "steps": [...]}} 구조를 구현합니다.
  • 재료 검색: if ingredient in data["ingredients"]로 딕셔너리 키를 확인합니다.
  • 비례 계산: amount / base_servings * wanted_servings 공식으로 자동 계산합니다.
  • csv.writer(f).writerow([...])로 리스트를 한 줄로 저장합니다.
  • all(x in dict for x in list) — 복수 조건 검색에 사용하는 패턴입니다.
