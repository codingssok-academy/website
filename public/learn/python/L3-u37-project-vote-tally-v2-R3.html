프로젝트:
편의점 재고 관리

딕셔너리로 상품 정보를 관리하고, 입고/출고 기능을 구현합니다. 재고 부족 알림과 JSON 저장으로 실무형 재고 관리 시스템을 완성합니다.

이 프로젝트에서 만드는 것

  • 딕셔너리로 상품명과 재고 수량을 관리할 수 있습니다.
  • 입고/출고 함수로 재고를 안전하게 갱신할 수 있습니다.
  • THRESHOLD 임계값으로 재고 부족 경고를 구현할 수 있습니다.
  • json.dump/json.load로 재고를 파일로 저장/복원할 수 있습니다.
  • transaction_log 리스트로 모든 거래를 시간순으로 기록할 수 있습니다.

핵심 개념 — 딕셔너리로 데이터 관리

딕셔너리는 키-값 쳐으로 데이터를 저장합니다. 상품명(키)과 수량(값)을 매핑하면 재고를 직관적으로 관리할 수 있습니다. .get(key, 0)을 사용하면 키가 없는 경우 기본값 0을 반환하여 안전합니다.

Step 1 — 재고 초기화와 입출고 함수

딕셔너리로 재고를 초기화하고, 입고(restock)와 출고(sell) 함수를 만듭니다.

# Step 1: 재고 초기화와 입출고 inventory = { "삼각김밥": 15, "콜라": 8, "컵라면": 3, "우유": 2, "과자": 20, } def restock(item, qty): inventory[item] = inventory.get(item, 0) + qty print(f"[입고] {item} +{qty} → {inventory[item]}") def sell(item, qty): stock = inventory.get(item, 0) if stock < qty: print(f"[오류] {item} 부족 (현재 {stock}개)") return False inventory[item] = stock - qty return True

Step 2 — 재고 부족 알림 + JSON 저장

THRESHOLD 임계값 이하로 떨어지면 자동으로 경고를 표시하는 check_stock() 함수와, 거래를 기록하는 transaction_log 리스트를 활용합니다.

# Step 2: 재고 부족 알림 + transaction_log THRESHOLD = 5 transaction_log = [] # 거래 내역 리스트 def restock(item, qty): inventory[item] = inventory.get(item, 0) + qty transaction_log.append({"type": "입고", "item": item, "qty": qty}) def check_stock(): warnings = [] for name, qty in inventory.items(): if qty < THRESHOLD: warnings.append(name) print(f"[주의] {name}: {qty}개") else: print(f" {name}: {qty}개") if warnings: print(f"\n부족: {', '.join(warnings)}") import json def save_inventory(filename="inventory.json"): with open(filename, "w", encoding="utf-8") as f: json.dump(inventory, f, ensure_ascii=False, indent=2) def load_inventory(filename="inventory.json"): global inventory try: with open(filename, encoding="utf-8") as f: inventory = json.load(f) except FileNotFoundError: print("저장 파일 없음")

연습 문제

Q1
상품 추가/삭제
Easy
add_item(name, qty)와 remove_item(name) 함수를 작성하세요. 이미 존재하는 상품을 추가하려 할 때는 경고를 출력합니다.
추가
add_item("아이스크림", 10)
삭제
remove_item("과자")
힌트 보기
if name in inventory:로 존재 여부 확인, del inventory[name]으로 삭제합니다.
정답 보기
def add_item(name, qty): if name in inventory: print(f"[경고] {name} 이미 존재") return inventory[name] = qty def remove_item(name): if name not in inventory: print(f"[오류] {name} 없음") return del inventory[name]
Q2
재고 검색
Medium
상품명 일부를 입력해 검색하는 search(keyword) 함수를 작성하세요. "라"를 검색하면 "컵라면"이 결과로 나와야 합니다.
호출
search("라")
출력
컵라면: 3개
힌트 보기
if keyword in name:로 부분 문자열 포함 여부를 확인합니다.
정답 보기
def search(keyword): for name, qty in inventory.items(): if keyword in name: print(f"{name}: {qty}개")
Q3
transaction_log 조회 기능
Hard
transaction_log 전체를 출력하는 show_log()와, 특정 상품의 거래만 필터링하는 filter_log(item) 함수를 작성하세요.
전체
show_log() → [입고] 콜라 10개 ...
필터
filter_log("콜라") → 콜라 거래만
힌트 보기
transaction_log를 for t in transaction_log:로 순회하고, if t["item"] == item:로 필터링합니다.
정답 보기
def show_log(): for t in transaction_log: print(f"[{t['type']}] {t['item']} {t['qty']}개") def filter_log(item): logs = [t for t in transaction_log if t["item"] == item] for t in logs: print(f"[{t['type']}] {t['item']} {t['qty']}개")

  • transaction_log — 리스트로 모든 거래를 시간순 기록
