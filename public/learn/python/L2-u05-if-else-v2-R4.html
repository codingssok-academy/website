조건문 연습문제

배운 개념을 확인하는 문제입니다. 먼저 스스로 풀고, 정답을 확인하세요.

Q1
세 수 중 최댓값
쉬움
세 개의 정수를 입력받아 가장 큰 수를 출력하세요.
입력3 7 5
출력최댓값: 7
입력9 1 9
출력최댓값: 9
힌트 보기
먼저 a가 최대라고 가정하고, b, c와 비교해 더 큰 게 있으면 최댓값을 바꿔가는 방식으로 해보세요. 또는 if-elif-else를 조합해도 됩니다.
정답 확인
a = int(input("첫째: ")) b = int(input("둘째: ")) c = int(input("셋째: ")) if a >= b and a >= c: print(f"최댓값: {a}") elif b >= a and b >= c: print(f"최댓값: {b}") else: print(f"최댓값: {c}")
Q2
택시 요금 계산기
쉬움
이동 거리(km)를 입력받아 택시 요금을 계산하세요.
기본요금(3km 이하): 4,800원 / 3km 초과: 4,800 + (거리-3) × 1,000원
입력2
출력요금: 4,800원
입력5
출력요금: 6,800원
힌트 보기
거리가 3 이하이면 4800원, 초과이면 4800 + (distance - 3) * 1000을 계산하세요.
정답 확인
distance = int(input("거리(km): ")) if distance <= 3: fee = 4800 else: fee = 4800 + (distance - 3) * 1000 print(f"요금: {fee:,}원")
Q3
혈액형 성격 분석기
쉬움
혈액형(A/B/O/AB)을 입력받아 재미있는 성격을 출력하세요. (내용은 자유롭게!)
입력B
출력B형: 자유롭고 개성 강한 당신!
힌트 보기
elif로 A, B, O, AB 각각을 처리하고, 아무것도 해당되지 않으면 "잘못된 입력"을 출력하세요.
정답 확인
blood = input("혈액형 (A/B/O/AB): ").upper() if blood == "A": print("A형: 꼼꼼하고 완벽주의자인 당신!") elif blood == "B": print("B형: 자유롭고 개성 강한 당신!") elif blood == "O": print("O형: 리더십 있고 활발한 당신!") elif blood == "AB": print("AB형: 이중적이고 미스터리한 당신!") else: print("잘못된 혈액형 입력입니다.")
Q4
윤년 판별기
보통
연도를 입력받아 윤년인지 판별하세요.
윤년 조건:
· 4로 나누어 떨어지면 윤년
· 단, 100으로 나누어 떨어지면 평년
· 단, 400으로 나누어 떨어지면 윤년
입력2024
출력2024년은 윤년입니다.
입력1900
출력1900년은 평년입니다.
힌트 보기
400 → 윤년, 100 → 평년, 4 → 윤년 순으로 검사하세요. 순서가 중요합니다! 가장 구체적인 조건을 먼저 써야 합니다.
정답 확인
year = int(input("연도: ")) if year % 400 == 0: print(f"{year}년은 윤년입니다.") elif year % 100 == 0: print(f"{year}년은 평년입니다.") elif year % 4 == 0: print(f"{year}년은 윤년입니다.") else: print(f"{year}년은 평년입니다.")
Q5
체질량지수(BMI) 상세 분석기
보통
키(cm)와 몸무게(kg)를 입력받아 BMI를 계산하고 단계별 결과를 출력하세요.
BMI = 몸무게 / (키/100)²
· 18.5 미만: 저체중 / 18.5~22.9: 정상 / 23~24.9: 과체중 / 25 이상: 비만
입력170 65
출력BMI: 22.5 — 정상
힌트 보기
bmi = weight / (height/100) ** 2로 BMI를 계산하고, round(bmi, 1)로 소수점 1자리까지 반올림하세요.
정답 확인
height = float(input("키(cm): ")) weight = float(input("몸무게(kg): ")) bmi = round(weight / (height / 100) ** 2, 1) if bmi >= 25: status = "비만" elif bmi >= 23: status = "과체중" elif bmi >= 18.5: status = "정상" else: status = "저체중" print(f"BMI: {bmi} — {status}")
Q6
온도 단위 변환기
보통
변환 방향(1=섭씨→화씨, 2=화씨→섭씨)과 온도를 입력받아 변환하세요.
· 섭씨→화씨: F = C × 9/5 + 32
· 화씨→섭씨: C = (F - 32) × 5/9
입력1, 100
출력100°C = 212.0°F
힌트 보기
먼저 변환 방향(1 또는 2)을 입력받고, if-elif-else로 각 방향의 공식을 적용하세요.
정답 확인
direction = int(input("변환 방향 (1=섭씨→화씨, 2=화씨→섭씨): ")) temp = float(input("온도: ")) if direction == 1: result = round(temp * 9/5 + 32, 1) print(f"{temp}°C = {result}°F") elif direction == 2: result = round((temp - 32) * 5/9, 1) print(f"{temp}°F = {result}°C") else: print("잘못된 선택입니다.")
