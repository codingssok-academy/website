Chapter 14

딕셔너리
이름표가 붙은 데이터

키(key)와 값(value)을 짝지어 저장하는 딕셔너리를 배웁니다.

이 유닛에서 배우는 것

  • 딕셔너리를 만들고 키로 값을 읽을 수 있습니다.
  • 값을 추가, 수정, 삭제할 수 있습니다.
  • keys(), values(), items() 메서드를 사용할 수 있습니다.
  • for문으로 딕셔너리를 반복 처리할 수 있습니다.
  • 전화번호부 프로그램을 만들 수 있습니다.

딕셔너리 만들기

딕셔너리는 {} 중괄호로 만듭니다. 각 데이터에 이름표(키)를 붙여서 저장합니다.

# 딕셔너리 만들기 student = { "이름": "민수", "나이": 15, "학교": "코딩중학교" } # 키로 값 읽기 print(student["이름"]) # 민수 print(student["나이"]) # 15
따라해보세요
1
자기 정보로 딕셔너리를 만드세요.
me = {"이름": "자현", "나이": 14, "취미": "코딩"} print(me["이름"], me["취미"])
자현 코딩
2
없는 키를 안전하게 읽어보세요.
print(me.get("혈액형", "모름"))
모름 — get()은 키가 없으면 기본값 반환
3
빈 딕셔너리를 만들어보세요.
empty = {} print(type(empty), len(empty))
<class 'dict'> 0

값 추가, 수정, 삭제

딕셔너리는 리스트처럼 자유롭게 수정할 수 있습니다.

phone = {"민수": "010-1234-5678"} # 추가 phone["서연"] = "010-9876-5432" print(phone) # {'민수': '010-1234-5678', '서연': '010-9876-5432'} # 수정 phone["민수"] = "010-1111-2222" print(phone["민수"]) # 010-1111-2222 # 삭제 del phone["서연"] print(phone) # {'민수': '010-1111-2222'}
따라해보세요
1
전화번호부에 친구를 추가하세요.
phone = {} phone["민수"] = "010-1234-5678" phone["서연"] = "010-9876-5432" phone["지호"] = "010-5555-6666" print(phone)
3명의 전화번호가 저장됩니다
2
민수의 번호를 수정하고 서연을 삭제하세요.
phone["민수"] = "010-0000-1111" del phone["서연"] print(phone)
{'민수': '010-0000-1111', '지호': '010-5555-6666'}
3
"지호" in phone으로 키 존재 여부를 확인하세요.
print("지호" in phone) # True print("하늘" in phone) # False
True / False

딕셔너리 메서드

keys(), values(), items()로 딕셔너리의 키, 값, 쌍을 꺼낼 수 있습니다.

scores = {"민수": 95, "서연": 87, "지호": 92} # 키만 print(list(scores.keys())) # ['민수', '서연', '지호'] # 값만 print(list(scores.values())) # [95, 87, 92] # 키-값 쌍 반복 for name, score in scores.items(): print(f"{name}: {score}점")
따라해보세요
1
점수의 평균을 구하세요.
scores = {"민수": 95, "서연": 87, "지호": 92} total = sum(scores.values()) avg = total / len(scores) print(f"평균: {avg:.1f}점")
평균: 91.3점
2
90점 이상인 학생만 출력하세요.
for name, score in scores.items(): if score >= 90: print(f"{name} 합격!")
민수 합격! / 지호 합격!
3
pop()으로 삭제하면서 값을 받아보세요.
removed = scores.pop("서연") print(f"삭제된 점수: {removed}") print(scores)
삭제된 점수: 87 / {'민수': 95, '지호': 92}

전화번호부 만들기

배운 내용을 활용해서 전화번호를 검색하고 추가하는 프로그램을 만들어봅시다.

# 전화번호부 프로그램 phone_book = { "민수": "010-1234-5678", "서연": "010-9876-5432", "지호": "010-5555-6666" } # 검색 name = input("이름 입력: ") if name in phone_book: print(f"{name}: {phone_book[name]}") else: print("등록되지 않은 이름입니다.") # 전체 출력 print("--- 전화번호부 ---") for name, num in phone_book.items(): print(f" {name}: {num}")

핵심 요약

이 유닛에서 배운 것

  • 딕셔너리는 {}로 만들고, "키": 값 쌍으로 저장한다
  • d["키"]로 값을 읽고, d["키"] = 값으로 추가/수정한다
  • del d["키"] 또는 d.pop("키")로 삭제한다
  • keys(), values(), items()로 반복 처리한다
  • get()을 쓰면 없는 키도 에러 없이 처리할 수 있다
