Chapter 19

예외 처리

에러가 나도 프로그램이 멈추지 않게, 에러를 우아하게 다루는 방법을 배웁니다.

이 유닛에서 배우는 것

  • 에러(예외)의 종류와 원인을 이해합니다.
  • try-except로 에러를 잡아서 처리할 수 있습니다.
  • 여러 종류의 에러를 구분하여 처리할 수 있습니다.
  • else와 finally의 역할을 이해합니다.
  • raise로 의도적으로 에러를 발생시킬 수 있습니다.

에러가 나면 어떻게 될까?

프로그램 실행 중 에러가 발생하면 파이썬은 즉시 멈추고 에러 메시지를 보여줍니다. 이것을 예외(Exception)라고 합니다.

# 에러 예시 print(10 / 0) # ZeroDivisionError int("abc") # ValueError [1, 2][10] # IndexError

try-except — 에러 잡기

try 블록 안에서 에러가 나면, 프로그램이 멈추지 않고 except 블록이 대신 실행됩니다.

try: num = int(input("숫자 입력: ")) result = 100 / num print(f"결과: {result}") except ValueError: print("숫자가 아닙니다!") except ZeroDivisionError: print("0으로 나눌 수 없습니다!")

try: data = [1, 2, 3] print(data[10]) except (IndexError, KeyError) as e: print(f"접근 에러: {e}")
접근 에러: list index out of range

else와 finally

else는 에러가 없을 때만 실행됩니다. finally는 에러 유무와 관계없이 항상 실행됩니다.

try: num = int(input("숫자: ")) result = 100 / num except ValueError: print("숫자가 아닙니다!") except ZeroDivisionError: print("0으로 나눌 수 없습니다!") else: print(f"결과: {result}") # 에러 없을 때만 finally: print("프로그램 종료") # 항상 실행

raise — 일부러 에러 발생시키기

raise를 사용하면 조건에 맞지 않을 때 의도적으로 에러를 발생시킬 수 있습니다.

def set_age(age): if age < 0: raise ValueError("나이는 0 이상이어야 합니다") if age > 150: raise ValueError("나이가 너무 큽니다") return age try: set_age(-5) except ValueError as e: print(f"에러: {e}")

실전: 안전한 입력 받기

사용자 입력은 항상 예상 밖일 수 있습니다. while + try-except 조합으로 올바른 입력을 받을 때까지 반복합니다.

while True: try: age = int(input("나이를 입력하세요: ")) if age < 0: raise ValueError("음수는 안 돼요") break # 성공하면 탈출 except ValueError as e: print(f"잘못된 입력: {e}") print(f"입력한 나이: {age}")

실전: 안전한 파일 처리

import json def load_data(filename): try: with open(filename, encoding="utf-8") as f: return json.load(f) except FileNotFoundError: print("파일이 없어서 빈 데이터로 시작합니다") return [] except json.JSONDecodeError: print("파일이 손상되어 빈 데이터로 시작합니다") return [] data = load_data("save.json") print(f"데이터: {data}")

핵심 요약

이 유닛에서 배운 것

  • try-except로 에러를 잡아서 프로그램이 멈추지 않게 한다
  • 에러 종류별로 다른 except 블록을 쓸 수 있다
  • as e로 에러 메시지를 변수에 담을 수 있다
  • else는 에러 없을 때, finally는 항상 실행된다
  • raise로 의도적으로 에러를 발생시켜 잘못된 입력을 거부한다
