함수 프로토타입 — 미리 알려주기

함수 정의와 선언을 분리합니다. 프로토타입으로 미리 알려두면 main 아래에 함수를 정의해도 됩니다. 헤더 파일의 원리도 엿봅니다.

이 유닛에서 배우는 것

  • 프로토타입(선언)이 무엇인지 설명할 수 있습니다.
  • 프로토타입을 작성하는 문법을 압니다.
  • 선언과 정의의 차이를 이해합니다.
  • main 아래에 함수를 정의하는 구조를 작성합니다.
  • 헤더 파일이 프로토타입의 확장임을 이해합니다.

프로토타입이란? — 목차와 같다

책의 목차처럼, 프로토타입은 "이런 함수가 있다"고 미리 알려주는 것입니다. 본문(정의)은 나중에 와도 됩니다. 컴파일러가 미리 함수 정보를 알 수 있습니다.

프로토타입 작성법

프로토타입은 함수 정의의 첫 줄(헤더)에 세미콜론(;)을 붙인 것입니다. 매개변수 이름은 생략해도 됩니다.

// 프로토타입 — 세미콜론으로 끝남 int add(int a, int b); // 매개변수 이름 포함 int add(int, int); // 타입만 써도 됨 void printLine(); // void 함수 프로토타입 float average(int, int); // float 반환

프로토타입 완전 예제

#include <stdio.h> // 1. 프로토타입 선언 (main 위에) int add(int a, int b); void printResult(int result); // 2. main 함수 int main() { int r = add(10, 20); printResult(r); return 0; } // 3. 함수 정의 (main 아래) int add(int a, int b) { return a + b; } void printResult(int result) { printf("결과: %d\n", result); }

이렇게 쓰면 main이 먼저 오고 함수 정의는 뒤에 올 수 있어서, 읽기 편한 코드 구조를 만들 수 있습니다.

헤더 파일의 원리 — 프로토타입 모음

#include <stdio.h>는 사실 stdio.h 파일에 있는 수많은 함수 프로토타입을 가져오는 것입니다. 그래서 printf, scanf 같은 함수를 우리가 쓸 수 있는 거예요.

O/X 문제
쉬움
맞으면 O, 틀리면 X를 쓰세요.
(1)프로토타입은 세미콜론으로 끝난다.
(2)프로토타입에서 매개변수 이름은 생략 가능하다.
(3)프로토타입이 있으면 함수 정의는 아예 안 해도 된다.
(4)stdio.h에는 printf의 프로토타입이 들어있다.
내 답안
정답 보기
(1) O (2) O (3) X (정의는 반드시 있어야 함) (4) O

Q5
헤더파일 원리
쉬움
#include <stdio.h>를 쓰는 이유를 프로토타입과 연결해 설명하세요.
내 답안
정답 보기
stdio.h 파일에는 printf, scanf 등 표준 입출력 함수의 프로토타입이 모여 있습니다. #include로 가져오면 컴파일러가 이 함수들을 미리 알 수 있어서 우리가 자유롭게 호출할 수 있습니다.

핵심 요약

  • 프로토타입: 함수 헤더 + 세미콜론. main 위에 작성.
  • 프로토타입이 있으면 함수 정의를 main 아래에 써도 됩니다.
  • 매개변수 이름은 프로토타입에서 생략 가능 (타입만 써도 됨).
  • 헤더 파일(.h)은 함수 프로토타입들의 모음입니다.
  • #include <stdio.h>는 printf 등의 프로토타입을 가져오는 것입니다.
