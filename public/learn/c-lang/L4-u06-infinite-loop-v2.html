무한루프 — 끝없이 도는 반복

의도적으로 영원히 반복하는 코드, 무한루프를 배웁니다. 서버 대기, 메뉴 시스템 등 실제 프로그램에서 어떻게 활용하는지 알아봅시다.

이 유닛에서 배우는 것

  • 무한루프가 무엇인지, 언제 필요한지 설명할 수 있습니다.
  • while(1)과 for(;;)로 무한루프를 만들 수 있습니다.
  • break로 무한루프에서 탈출할 수 있습니다.
  • 메뉴 시스템과 서버 대기 패턴을 구현할 수 있습니다.
  • 의도적 무한루프와 실수 무한루프의 차이를 알 수 있습니다.

무한루프란?

조건이 항상 참(true)이면 반복문은 절대 끝나지 않습니다. 이를 무한루프라고 합니다. 게임의 메인 루프, 서버의 요청 대기 등에서 의도적으로 사용합니다.

C언어에서 무한루프를 만드는 두 가지 대표 방법입니다. 둘 다 똑같이 동작합니다.

// 방법 1: while(1) 무한루프 while (1) { printf("계속 실행 중...\n"); // break가 없으면 영원히 반복! } // 방법 2: for(;;) 무한루프 for (;;) { printf("계속 실행 중...\n"); }
따라해보세요
1
while(1)로 "무한" 출력 후 count가 3이 되면 break로 탈출하세요.
int count = 0; while (1) { printf("무한\n"); count++; if (count == 3) break; }
무한 3번 출력 후 종료
2
for(;;)로 1부터 5까지 세고, 5에서 break하는 코드를 작성하세요.
int n = 1; for (;;) { printf("%d\n", n++); if (n > 5) break; }
1 2 3 4 5 출력 후 종료
3
while(1)로 사용자 입력을 받아 0을 입력하면 "종료" 출력 후 break하세요.
int x; while (1) { scanf("%d", &x); if (x == 0) { printf("종료\n"); break; } printf("입력: %d\n", x); }
0 입력 시 종료

메뉴 시스템 — 무한루프의 실전 활용

프로그램에서 가장 흔한 무한루프 활용은 메뉴 시스템입니다. 사용자가 종료를 선택하기 전까지 메뉴를 계속 보여주는 방식입니다.

// 메뉴 시스템 예제 int choice; while (1) { printf("\n=== 메뉴 ===\n"); printf("1. 인사하기\n"); printf("2. 합계 계산\n"); printf("0. 종료\n"); printf("선택: "); scanf("%d", &choice); if (choice == 0) { printf("프로그램 종료\n"); break; } else if (choice == 1) { printf("안녕하세요!\n"); } else if (choice == 2) { printf("1+2 = 3\n"); } else { printf("잘못된 입력입니다.\n"); } } // 0을 입력하지 않는 한 계속 반복
따라해보세요
4
while(1) 메뉴에서 1은 "학교", 2는 "집", 0은 break로 종료하는 코드를 작성하세요.
int sel; while (1) { printf("1.학교 2.집 0.종료: "); scanf("%d", &sel); if (sel == 0) break; else if (sel == 1) printf("학교\n"); else if (sel == 2) printf("집\n"); }
0 입력 전까지 메뉴 반복
5
for(;;)로 1부터 숫자를 계속 더하다가 합이 100을 넘으면 break하고 합을 출력하세요.
int sum = 0, n = 1; for (;;) { sum += n; if (sum > 100) { printf("합: %d\n", sum); break; } n++; }
1+2+...+14=105 (100 초과 시 종료)

서버 대기 패턴

실제 서버 프로그램은 요청이 올 때까지 무한히 대기합니다. C언어로 이 구조를 단순화하면 다음과 같습니다.

// 서버 대기 패턴 (단순화 예시) int running = 1; while (running) { printf("클라이언트 연결 대기 중...\n"); // 실제로는 여기서 네트워크 연결 받음 printf("요청 처리 완료\n"); // 특정 신호를 받으면 running=0으로 바꿔 종료 }

의도적 vs 실수 무한루프 비교

무한루프가 항상 나쁜 것은 아닙니다. 의도적인 무한루프는 반드시 break나 외부 종료 조건이 있어야 합니다.

따라해보세요
6
다음 실수 무한루프를 찾아 고치세요. int i=1; while(i<=5) printf("%d\n",i);
// 버그: i가 증가하지 않아 무한루프! int i = 1; while (i <= 5) { printf("%d\n", i); i++; // 이 줄이 있어야 함 }
i++ 추가로 정상 종료
7
while(1)로 짝수만 출력하다 30을 넘으면 break. 2, 4, 6...30 출력.
int n = 2; while (1) { printf("%d ", n); n += 2; if (n > 30) break; }
2 4 6 8 ... 30 출력
따라해보세요
8
for(;;)로 3, 6, 9, 12를 출력하고 12에서 break하세요.
int k = 3; for (;;) { printf("%d\n", k); if (k == 12) break; k += 3; }
3 6 9 12 출력 후 종료
9
while(1)로 입력받아 양수면 2배를 출력, 음수면 "음수" 출력, 0이면 break.
int v; while (1) { scanf("%d", &v); if (v == 0) break; else if (v > 0) printf("%d\n", v * 2); else printf("음수\n"); }
양수 → 2배, 음수 → "음수", 0 → 종료

무한루프 핵심 정리

  • while(1)과 for(;;)는 둘 다 무한루프를 만드는 방법이다.
  • 무한루프에서 탈출하려면 반드시 break가 있어야 한다.
  • 메뉴 시스템: 사용자가 0(종료)를 누를 때까지 반복.
  • 실수 무한루프는 증감식 누락이나 조건 오타가 원인이다.
  • 의도적 무한루프는 항상 탈출 조건이 명확해야 한다.
