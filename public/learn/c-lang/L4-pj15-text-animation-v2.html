텍스트 애니메이션

for + printf로 로딩바, 타이핑 효과, 프로그레스바를 만듭니다. 색상 코드(\033[)와 fflush를 활용한 터미널 애니메이션을 경험합니다.

이 프로젝트에서 배우는 것

  • for + printf("\r")로 같은 줄에 덮어쓰는 애니메이션을 만듭니다.
  • fflush(stdout)으로 버퍼를 즉시 출력하는 방법을 배웁니다.
  • usleep/Sleep으로 딜레이를 줘서 시각적 효과를 냅니다.
  • ANSI 색상 코드(\033[31m 등)로 터미널에 색을 입힙니다.
  • 카운트다운, ASCII 아트 애니메이션을 구현합니다.

로딩바 구현 원리

같은 줄을 계속 덮어쓰는 것이 핵심입니다. \r(캐리지 리턴)은 커서를 줄의 맨 앞으로 이동시킵니다. \n없이 출력하면 다음 출력이 같은 줄을 덮어씁니다.

fflush(stdout): C에서 출력은 버퍼에 쌓였다가 한꺼번에 출력됩니다. printf 후 fflush(stdout)을 호출해야 즉시 화면에 반영됩니다. \n 없이 출력할 때 반드시 필요합니다.

로딩바 + 프로그레스바 전체 코드

#include <stdio.h> #include <unistd.h> // usleep (Linux/Mac) // Windows: #include <windows.h> + Sleep(ms) void loading_bar(int total) { int i, j; printf("Loading: ["); for (i = 0; i <= total; i++) { printf("\rLoading: ["); // 커서 맨 앞으로 for (j = 0; j < i; j++) printf("#"); // 채워진 부분 for (j = i; j < total; j++) printf(" "); // 빈 부분 printf("] %3d%%", i * 100 / total); fflush(stdout); // 즉시 출력 usleep(80000); // 0.08초 대기 } printf("\n완료!\n"); } int main() { loading_bar(20); // 20칸 로딩바 return 0; }

타이핑 효과

문자열을 한 글자씩 출력해 타자기처럼 보이게 합니다. 문자열은 배열이므로 str[i]로 i번째 글자에 접근합니다. 문자열 길이는 strlen()으로 구합니다.

#include <stdio.h> #include <string.h> #include <unistd.h> void type_print(const char *str) { int len = strlen(str); for (int i = 0; i < len; i++) { printf("%c", str[i]); fflush(stdout); usleep(100000); // 0.1초 딜레이 } printf("\n"); } int main() { type_print("안녕하세요, 코딩쏙입니다!"); type_print("C언어를 배우고 있습니다."); return 0; }

ANSI 색상 코드

리눅스/Mac 터미널에서는 \033[색상코드m 형식으로 출력 색상을 바꿀 수 있습니다. \033[0m으로 반드시 원래 색으로 되돌려야 합니다.

// 색상 + 타이핑 효과 결합 printf("\033[32m"); // 초록색 시작 type_print("로딩 완료!"); printf("\033[0m"); // 색상 초기화 (필수) printf("\033[31m오류: 파일 없음\033[0m\n"); // 한 줄 적용

카운트다운 + 메시지

숫자를 내려가며 카운트하고 0이 되면 메시지를 출력합니다. \r로 같은 줄을 덮어씁니다.

#include <stdio.h> #include <unistd.h> void countdown(int n, const char *msg) { for (int i = n; i > 0; i--) { printf("\r\033[33m%d\033[0m 초 후 시작...", i); fflush(stdout); sleep(1); // 1초 대기 } printf("\r\033[32m%s\033[0m\n", msg); } int main() { countdown(5, "발사!"); return 0; }

ASCII 아트 프레임 애니메이션

여러 ASCII 아트 프레임을 빠르게 교체해 간단한 움직임을 표현합니다. 화면을 지우는 system("clear")(Linux) 또는 system("cls")(Windows)를 활용합니다.

const char *frames[] = { "( o_o)\n/| |\n /\\", "( o_o)\n/| |\\\n /\\", "( ^_^)\n | |\n /\\" }; int frame_count = 3; for (int cycle = 0; cycle < 6; cycle++) { // 6사이클 반복 system("cls"); // 화면 지우기 (Windows: cls, Linux: clear) printf("%s\n", frames[cycle % frame_count]); fflush(stdout); usleep(200000); // 0.2초 }

핵심 정리

  • \r (캐리지 리턴): 커서를 현재 줄 맨 앞으로 이동 — 같은 줄 덮어쓰기
  • fflush(stdout): 출력 버퍼를 즉시 비워 화면에 반영
  • usleep(n): n 마이크로초 대기 (1,000,000 = 1초)
  • ANSI 색상: \033[31m(빨강), \033[32m(초록), \033[0m(초기화)
  • ASCII 아트: 여러 프레임을 빠르게 교체해 움직임 표현
