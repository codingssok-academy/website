Unit 05

세미콜론과 중괄호

C 언어에서 문장을 끝내는 방법과 코드 블록을 묶는 방법을 배웁니다.

이 유닛에서 배우는 것

  • 세미콜론(;)이 왜 필요한지 설명할 수 있습니다.
  • 세미콜론 누락 에러를 직접 고칠 수 있습니다.
  • 중괄호 { }로 코드 블록을 올바르게 묶을 수 있습니다.
  • main 함수 구조 안에서 두 기호의 역할을 설명합니다.

세미콜론 — 문장의 마침표

C 언어에서 모든 실행 문장은 ;(세미콜론)으로 끝나야 합니다. 영어 글쓰기에서 문장 끝에 마침표(.)를 찍듯이, C에서는 세미콜론을 씁니다.

세미콜론이 없으면 컴파일러가 문장이 어디서 끝나는지 알 수 없습니다. 에러가 발생합니다.

// 세미콜론이 있는 올바른 코드 int main() { printf("Hello, World!\n"); return 0; }
따라해보세요
1
세미콜론을 모두 올바르게 써서 컴파일해보세요.
int main() { printf("나는 C 언어 학생!\n"); return 0; }
나는 C 언어 학생! 출력
2
일부러 세미콜론 하나를 지우고 에러 메시지를 확인해보세요.
int main() { printf("에러 체험\n") // 세미콜론 없음! return 0; }
error: expected ';' 에러 확인
3
여러 줄 출력에 세미콜론을 빠짐없이 써보세요.
int main() { printf("이름: 홍길동\n"); printf("학교: 코딩중학교\n"); printf("학년: 2학년\n"); return 0; }
3줄 정보가 순서대로 출력

중괄호 — 코드 블록 묶기

중괄호 { }는 여러 줄의 코드를 하나의 묶음(블록)으로 만듭니다. 함수, 조건문, 반복문 모두 중괄호로 시작과 끝을 표시합니다.

중괄호는 반드시 쌍으로 사용해야 합니다. 열면 반드시 닫아야 합니다.

따라해보세요
1
main 함수의 중괄호 구조를 직접 써보세요.
int main() { printf("블록 안에 있는 코드\n"); return 0; }
정상 출력 확인
2
닫는 중괄호를 지우면 어떤 에러가 나는지 확인해보세요.
int main() { printf("중괄호 실험\n"); return 0; // } 를 지워봄!
error: expected '}' 에러 확인
3
중괄호와 세미콜론을 모두 올바르게 쓴 완성 코드를 작성해보세요.
int main() { printf("--- 학생증 ---\n"); printf("이름: 김코딩\n"); printf("번호: 2025001\n"); return 0; }
학생증 형식 3줄 출력

핵심 요약

  • ;(세미콜론) — 모든 실행 문장의 끝에 반드시 붙임
  • { }(중괄호) — 코드 블록의 시작과 끝을 표시, 반드시 쌍으로 사용
  • 세미콜론 누락 에러: error: expected ';'
  • 중괄호 누락 에러: error: expected '}'
  • main 함수는 반드시 { }로 감싸야 하며, 그 안 문장마다 ;을 붙임
