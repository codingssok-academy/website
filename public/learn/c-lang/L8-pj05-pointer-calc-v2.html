결과 여러 개 반환
Return Multiple Results via Output Pointers
C 함수는 return으로 값 하나만 돌려줄 수 있다. 하지만 포인터 매개변수를 "출력 파라미터"로 쓰면
한 함수에서 여러 결과를 동시에 전달할 수 있다. 이 패턴은 실무에서 매우 자주 사용된다.
난이도 출력 파라미터 패턴 void 반환 함수 5가지 연산 동시 반환
출력 파라미터 패턴 이해
완성 코드
calc.c #include <stdio.h>

/* 출력 파라미터: 포인터로 결과 5개 동시 전달 */
void calc(int a, int b,
        int *add, int *sub, int *mul,
        int *divq, int *rem) {
    *add = a + b;
    *sub = a - b;
    *mul = a * b;
    *divq = a / b; // 정수 나눗셈
    *rem = a % b; // 나머지
    // return 없음 — 포인터로 직접 저장!
}

int main() {
    int a = 10, b = 3;
    int r_add, r_sub, r_mul, r_div, r_rem;
    
    calc(a, b, &r_add, &r_sub, &r_mul, &r_div, &r_rem);
    
    printf("%d + %d = %d\n", a, b, r_add);
    printf("%d - %d = %d\n", a, b, r_sub);
    printf("%d * %d = %d\n", a, b, r_mul);
    printf("%d / %d = %d\n", a, b, r_div);
    printf("%d %% %d = %d\n", a, b, r_rem);
    return 0;
}
$ gcc calc.c -o calc && ./calc
10 + 3 = 13
10 - 3 = 7
10 * 3 = 30
10 / 3 = 3
10 % 3 = 1
단계별 구현 가이드
STEP 1

결과 저장할 변수 선언

main에서 결과를 받을 변수들을 미리 선언한다.
int r_add, r_sub, r_mul, r_div, r_rem;

STEP 2

포인터 매개변수 선언

함수 시그니처에 출력용 포인터 추가.
void calc(int a, int b, int *add, ...)

STEP 3

역참조로 결과 저장

함수 내부에서 *로 역참조하여 저장.
*add = a + b;

STEP 4

주소 전달로 호출

&연산자로 결과 변수의 주소를 전달.
calc(10, 3, &r_add, ...)

실무 활용 예: 나눗셈 결과 (몫 + 나머지)
divmod.c /* 나눗셈: 몫과 나머지를 동시에 반환 */
void divmod(int dividend, int divisor,
            int *quotient, int *remainder) {
    *quotient = dividend / divisor;
    *remainder = dividend % divisor;
}

int main() {
    int q, r;
    divmod(17, 5, &q, &r);
    printf("17 ÷ 5 = 몫 %d, 나머지 %d\n", q, r);
    // 출력: 17 ÷ 5 = 몫 3, 나머지 2
    return 0;
}

연습문제
1 void calc(int a, int b, int *add, ...)에서 void를 쓰는 이유는?
이미 포인터로 결과를 전달하기 때문에 return으로 추가 값을 반환할 필요가 없다. void는 "반환값 없음"을 명시한다. 실무에서는 성공/실패 여부를 int로 반환하고 나머지는 출력 파라미터로 처리하기도 한다.
2 calc(10, 3, r_add, r_sub, ...)와 calc(10, 3, &r_add, &r_sub, ...)의 차이는?
r_add는 변수의 값(초기화 전이면 쓰레기값)을 전달 — 함수는 이 값을 포인터로 사용하려 해서 잘못된 메모리 주소를 건드린다 (undefined behavior). &r_add는 변수의 주소를 전달 — 함수가 올바른 메모리에 결과를 저장한다.
3 calc 함수 내에서 *add = a + b;가 실행될 때 실제로 무슨 일이 일어나는가?
add는 main의 r_add 변수 주소(예: 0x7fff2000)를 담고 있다. *add = a + b는 "주소 0x7fff2000에 13을 저장"한다. main으로 돌아오면 r_add = 13이 되어 있다.
4 출력 파라미터로 NULL을 전달하면 어떻게 되는가? 안전하게 처리하려면?
NULL을 역참조(*NULL = 값)하면 세그멘테이션 폴트가 발생한다. 안전하게 처리하려면 사용 전에 if (add != NULL) *add = a + b; 로 NULL 체크를 해야 한다. 일부 결과가 필요 없을 때 NULL을 전달하는 패턴에서 유용하다.
5 C의 출력 파라미터와 다른 언어(Python, JS)의 여러 값 반환 방식의 차이는?
Python/JS는 tuple/array로 여러 값을 묶어 return할 수 있다. C는 구조체를 반환하거나(복사 발생), 포인터로 출력 파라미터를 쓴다. C의 포인터 방식은 메모리 복사 없이 직접 저장하므로 성능상 유리하지만 코드가 복잡해진다.

이번 프로젝트 핵심

  • C 함수는 return으로 값 1개만 반환 — 포인터로 이 제한을 극복
  • 출력 파라미터: 결과를 저장할 변수의 주소를 함수에 전달
  • 함수 내부에서 역참조(*)로 호출자의 메모리에 직접 결과 저장
  • 호출 시 반드시 &로 주소를 전달해야 한다
  • scanf("%d", &n)도 같은 패턴이다 — &n으로 주소 전달
