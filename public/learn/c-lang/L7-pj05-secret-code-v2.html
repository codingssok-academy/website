ASCII Shift Cipher
ASCII 코드와 시프트 원리
알파벳의 ASCII 코드 구조

소문자 'a'는 ASCII 97, 'b'는 98, ..., 'z'는 122다. 대문자는 'A'=65 ~ 'Z'=90. 따라서 'a'+1 = 'b', 즉 정수 덧셈이 곧 알파벳 이동이다.

시프트 암호화 공식
왜 -'a'를 하나? c-'a'는 0(a)~25(z) 범위의 인덱스가 된다. 여기에 이동값을 더하고 %26으로 순환시킨 후, 다시 +'a'로 원래 문자 범위로 되돌린다.
암호화 + 복호화 구현
#include <stdio.h> #include <string.h> #include <ctype.h> void shift_cipher(char str[], int shift) { for (int i = 0; str[i] != '\0'; i++) { char c = str[i]; if (islower(c)) { str[i] = (c - 'a' + shift + 26) % 26 + 'a'; } else if (isupper(c)) { str[i] = (c - 'A' + shift + 26) % 26 + 'A'; } // 알파벳이 아니면 그대로 } } int main() { char msg[200]; printf("메시지 입력: "); fgets(msg, sizeof(msg), stdin); msg[strcspn(msg, "\n")] = '\0'; shift_cipher(msg, 1); // +1 암호화 printf("암호문: %s\n", msg); shift_cipher(msg, -1); // -1 복호화 printf("복호화: %s\n", msg); return 0; }
+26의 이유: shift가 음수(-1)일 때 (-1 + 26) % 26 = 25로 올바르게 처리된다. +26 없이 그냥 % 연산하면 음수 결과가 나올 수 있어서 안전을 위해 추가한다.
확장 — 사용자 정의 이동값(카이사르 암호)
카이사르 암호 — 이동값을 직접 입력

시프트 암호에서 이동값(key)을 사용자가 정하면 카이사르 암호(Caesar Cipher)가 된다. 고대 로마의 줄리어스 카이사르가 군사 통신에 사용한 방법이다.

#include <stdio.h> #include <string.h> #include <ctype.h> void caesar(char str[], int key) { for (int i = 0; str[i]; i++) { if (isalpha(str[i])) { char base = islower(str[i]) ? 'a' : 'A'; str[i] = (str[i] - base + key % 26 + 26) % 26 + base; } } } int main() { char plain[200], cipher[200]; int key; printf("메시지 입력: "); fgets(plain, sizeof(plain), stdin); plain[strcspn(plain, "\n")] = '\0'; printf("이동값(1~25): "); scanf("%d", &key); strcpy(cipher, plain); // 원본 복사 caesar(cipher, key); // 암호화 printf("암호문: %s\n", cipher); caesar(cipher, -key); // 복호화 (반대 방향) printf("복호문: %s\n", cipher); return 0; }
암호화 결과 시각화
비알파벳 문자 처리: 공백, 숫자, 특수문자는 isalpha() 조건으로 걸러져 그대로 유지된다. 실제 메시지에서 띄어쓰기와 문장부호를 보존하는 중요한 처리다.

Q1. 기초 계산

'a'를 shift=1로 암호화하면? 'z'를 shift=1로 암호화하면? 직접 공식을 적용하시오.

정답 보기
'a': (97-97+1)%26+97 = 1%26+97 = 98 = 'b'
'z': (122-97+1)%26+97 = 26%26+97 = 0+97 = 97 = 'a'

Q3. 코드 분석

아래 코드에서 +26을 하는 이유를 설명하시오.

str[i] = (str[i] - 'a' + shift + 26) % 26 + 'a';
정답 보기
shift가 음수(복호화 시 -1 등)일 때, C언어의 % 연산은 음수 결과를 낼 수 있다. +26을 더하면 항상 양수가 보장된다. 예: (0 + (-1) + 26) % 26 = 25 = 'z'

힌트: 소문자 처리와 동일한 패턴 (base='0', 나머지 %10)
