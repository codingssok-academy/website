Chapter 04

반복 제어 —
break와 continue

반복문을 내 뜻대로 조종하는 두 가지 무기를 배웁니다.

이 유닛에서 배우는 것

  • break가 반복문을 즉시 탈출한다는 것을 설명할 수 있습니다.
  • continue가 현재 반복만 건너뛴다는 것을 설명할 수 있습니다.
  • break와 continue의 차이를 비교할 수 있습니다.
  • 중첩 반복문에서 break의 범위를 이해할 수 있습니다.
  • 남용 시 생기는 문제를 인식하고 올바르게 사용할 수 있습니다.

break — 반복문에서 즉시 탈출

break는 반복문 안에서 실행되는 순간 반복문 전체를 즉시 끝냅니다. 남은 반복 횟수가 얼마나 남았든 상관없이 바로 빠져나옵니다.

아래 코드는 1~10 중에서 5를 찾으면 즉시 멈춥니다.

#include <stdio.h> int main() { int i; for (i = 1; i <= 10; i++) { if (i == 5) { printf("5를 찾았다! 멈춘다.\n"); break; // 반복문 즉시 탈출 } printf("%d 확인 중\n", i); } printf("반복문이 끝났다.\n"); return 0; }

출력: 1 확인 중 → 2 확인 중 → ... → 4 확인 중 → 5를 찾았다! 멈춘다. → 반복문이 끝났다.

continue — 현재 반복만 건너뛰기

continue는 break와 다릅니다. 반복문을 끝내는 게 아니라 현재 반복 회차의 나머지 코드를 건너뛰고 다음 반복으로 넘어갑니다.

아래 코드는 1~10 중 홀수는 건너뛰고 짝수만 출력합니다.

#include <stdio.h> int main() { int i; for (i = 1; i <= 10; i++) { if (i % 2 != 0) { // 홀수이면 continue; // 아래 printf 건너뜀 } printf("%d\n", i); // 짝수만 여기까지 옴 } return 0; }

출력: 2 4 6 8 10 — 홀수는 출력 없이 다음 회차로 넘어감

break vs continue 비교

두 키워드는 생김새는 비슷하지만 동작이 완전히 다릅니다. 헷갈리기 쉬우니 나란히 비교해봅니다.

break

반복문 자체를 즉시 종료. 남은 반복 횟수 무시. 반복문 바깥 코드로 이동.

continue

현재 회차의 나머지 코드만 건너뜀. 반복문은 계속 실행. 다음 회차로 이동.

중첩 루프에서 break의 범위

중첩된 반복문에서 break는 자신이 속한 가장 안쪽 반복문만 탈출합니다. 바깥 반복문은 계속 실행됩니다.

for (i = 0; i < 3; i++) { // 바깥 루프 for (j = 0; j < 5; j++) { // 안쪽 루프 if (j == 2) break; // 안쪽 루프만 탈출 printf("(%d,%d) ", i, j); } printf("\n"); // 바깥 루프는 계속 실행됨 }

출력: (0,0) (0,1) / (1,0) (1,1) / (2,0) (2,1) — 각 줄마다 j=2에서 안쪽 루프만 탈출

남용 주의

break와 continue를 너무 많이 쓰면 코드 흐름이 복잡해집니다. 특히 중첩 반복문에서 여러 개를 쓰면 어디서 나오는지 추적이 어렵습니다. 꼭 필요한 곳에만, 한 반복문 안에 1~2개 이하로 쓰는 것을 권장합니다.

응용 — 중첩 루프 + break
어려움
두 수 a와 b를 각각 1~9 범위에서 탐색하여 a * b == 24를 처음 만족하는 쌍을 찾고 출력하세요. 찾으면 두 루프 모두 멈춰야 합니다. (힌트: 바깥 루프 탈출을 위해 found 변수 활용)
출력 예 3 × 8 = 24
내 답안
힌트 / 답 보기
안쪽에서 break하면 안쪽 루프만 탈출됩니다. int found = 0;을 선언하고, 찾으면 found = 1; 후 break. 바깥 루프에서 if (found) break;로 탈출합니다.
int a, b, found = 0; for (a = 1; a <= 9; a++) { for (b = 1; b <= 9; b++) { if (a * b == 24) { printf("%d × %d = 24\n", a, b); found = 1; break; // 안쪽 루프 탈출 } } if (found) break; // 바깥 루프도 탈출 }

유닛 요약

  • break — 반복문을 즉시 완전히 종료. 남은 반복 없이 반복문 바깥으로 이동.
  • continue — 현재 회차의 나머지 코드를 건너뜀. 반복문은 계속 실행됨.
  • 중첩 루프에서 break는 자신이 속한 가장 안쪽 반복문만 탈출.
  • 두 루프 모두 탈출하려면 플래그 변수(found 등)를 활용.
  • 남용하면 코드 흐름이 복잡해지므로 필요한 곳에만 사용.
