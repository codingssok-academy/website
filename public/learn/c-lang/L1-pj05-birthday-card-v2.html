Project 05

생일 축하 카드

ASCII 아트와 printf를 조합해 화면에 생일 카드를 출력하는 프로그램을 만듭니다.

프로젝트 목표

  • ASCII 문자로 장식을 만들 수 있습니다.
  • 여러 줄로 구성된 카드 레이아웃을 완성합니다.
  • 받는 사람 이름을 바꿔서 재활용할 수 있습니다.
  • C 언어 Level 1 전체 내용을 종합 활용합니다.
PROJECT 05

ASCII 아트로 장식 만들기

ASCII 아트란 키보드 문자(*, -, |, / 등)를 조합해 그림처럼 보이게 만드는 것입니다.

별(*) 패턴을 위아래에 넣고 가운데에 메시지를 배치하면 카드처럼 보입니다.

따라해보세요
1
별(*) 구분선을 출력해 보세요.
#include <stdio.h> int main() { printf("* * * * * * * * * *\n"); return 0; }
별표 구분선이 출력됩니다
2
케이크 ASCII 아트를 출력해보세요.
printf(" | | |\n"); printf(" [=========]\n"); printf(" | CAKE! |\n"); printf(" [=========]\n");
케이크 모양이 출력됩니다
3
Happy Birthday 메시지를 추가해보세요.
printf(" Happy Birthday!\n");
생일 축하 메시지가 출력됩니다
PROJECT 05

완성 생일 카드 코드

#include <stdio.h> int main() { /* 생일 카드 프로그램 */ printf("* * * * * * * * * * * *\n"); printf("* *\n"); printf("* | | | *\n"); // 초 printf("* [===========] *\n"); // 케이크 printf("* [ BIRTHDAY ] *\n"); printf("* [===========] *\n"); printf("* *\n"); printf("* Happy Birthday! *\n"); printf("* To: 김민수 *\n"); printf("* From: 코딩쏙 친구들 *\n"); printf("* *\n"); printf("* * * * * * * * * * * *\n"); return 0; }

PROJECT 05

카드 디자인 바꾸기

테두리 문자를 바꾸거나 새로운 ASCII 아트를 추가해 개성 있는 카드를 만들어 봅시다.

Q2
별표 테두리를 # 로 바꾸기
쉬움
"* * * * * * * * * * * *\n"을 #으로 바꿔서 출력하세요.
결과# # # # # # # # # # # #
내 답안
힌트 보기
*를 #으로 바꾸기만 하면 됩니다.
정답 보기
printf("# # # # # # # # # # # #\n");
Q3
Level 1 종합 — 전체 카드 직접 만들기
보통
친구에게 보내는 생일 카드를 직접 설계하고 완성하세요. (테두리 + ASCII 아트 + 메시지 포함)
조건5줄 이상, 테두리 있음, 이름 포함
내 답안
힌트 보기
테두리 줄 → 빈 줄 → 메시지 → 빈 줄 → 테두리 줄 구조를 사용하세요.
정답 보기
printf("= = = = = = = = = =\n"); printf("= =\n"); printf("= Happy Birthday =\n"); printf("= To: [이름] =\n"); printf("= =\n"); printf("= = = = = = = = = =\n");

핵심 요약

  • ASCII 아트: *, =, |, [, ] 등 키보드 문자로 그림 표현
  • 카드 구조: 테두리 → 내용 → 테두리 패턴
  • 이름만 바꾸면 같은 카드를 다른 사람에게 재사용 가능
  • Level 1 완료: printf, 구조, 이스케이프, ASCII 아트 모두 활용
  • C언어 기초 뼈대를 완전히 익혔습니다!
