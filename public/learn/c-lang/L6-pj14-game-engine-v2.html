미니 게임 엔진
— init / update / render 구조

실제 게임 엔진처럼 초기화(init), 업데이트(update), 렌더(render) 3단계 함수 구조로 간단한 텍스트 RPG를 만드는 프로젝트입니다.

이 프로젝트에서 배우는 것

  • 실제 게임 엔진의 init/update/render 루프 구조를 이해합니다.
  • 전역 게임 상태(HP, 레벨, 점수)를 함수로 관리합니다.
  • update: 게임 로직 처리 / render: 화면 출력 분리를 실습합니다.
  • 난수로 몬스터 등장, 데미지 등 게임 이벤트를 구현합니다.
  • 게임 개발의 기초 패턴을 C 언어로 체험합니다.
PROJECT 14
미니 게임 엔진
init/update/render 게임 루프 패턴

게임 루프 3단계

1
void init()
플레이어 HP, 레벨, 점수를 초기값으로 설정. 프로그램 시작 시 한 번만 호출.
2
int update()
입력 받기 → 게임 로직 처리 → 상태 변경. 게임 오버면 0 반환.
3
void render()
현재 게임 상태를 화면에 출력. 로직 없음, 출력만.
// 전역 게임 상태 int playerHP = 100; int playerLv = 1; int score = 0; int turn = 0; void init() { playerHP = 100; playerLv = 1; score = 0; turn = 0; printf("=== 미니 RPG 시작! ===\n"); } void render() { printf("\n[턴 %d] HP:%d Lv:%d 점수:%d\n", turn, playerHP, playerLv, score); }
update vs render 분리: update는 게임 상태를 바꾸는 로직(HP 감소, 레벨 업 등)만 담당하고, render는 현재 상태를 출력만 합니다. 이렇게 분리하면 나중에 GUI로 바꿀 때 render만 수정하면 됩니다.

미니 게임 엔진 — 전체 코드

/* ====== 미니 RPG 게임 엔진 ====== */ #include <stdio.h> #include <stdlib.h> #include <time.h> int hp=100, lv=1, score=0, turn=0; void init() { srand(time(0)); hp=100; lv=1; score=0; turn=0; printf("=== 미니 RPG! HP:100 ===\n"); } void render() { printf("[턴%d] HP:%3d Lv:%d 점수:%d\n",turn,hp,lv,score); printf("1.공격 2.방어 0.도망\n선택: "); } int update() { int action; scanf("%d",&action); if(action==0) return 0; // 도망 int monsterDmg = rand()%20+5; // 5~24 데미지 if(action==1) { // 공격 int myDmg = rand()%15+lv*5; printf("공격! 내:%d 몬:%d 데미지\n",myDmg,monsterDmg); score += myDmg; hp -= monsterDmg; } else { // 방어 int reducedDmg = monsterDmg/2; printf("방어! 받는 데미지: %d\n",reducedDmg); hp -= reducedDmg; } turn++; if(score >= lv*100){ lv++; printf("레벨업! Lv%d\n",lv); } return hp > 0; // HP 0이하면 0 반환(게임오버) } int main() { init(); while(update() && (turn < 10)) { render(); } printf("게임 종료! 최종점수: %d\n",score); return 0; }

연습 문제

1
게임 루프 순서
쉬움
init/update/render의 올바른 호출 순서를 설명하세요. init는 몇 번 호출하나요?
정답 보기
init → (update → render) 반복. init는 프로그램 시작 시 단 한 번만 호출합니다.
2
update 반환값
쉬움
update()가 0을 반환하는 경우는 언제인가요?
정답 보기
플레이어가 도망치거나(action==0), HP가 0 이하가 될 때 0을 반환합니다. while 루프가 종료됩니다.
3
회복 아이템 추가
보통
메뉴에 "3. 포션 사용 (HP +30)" 을 추가하세요. 포션은 3개로 제한합니다.
힌트 보기
전역 변수 potions=3을 추가합니다. action==3이고 potions>0일 때 hp+=30, potions--. hp가 100을 초과하면 100으로 고정.
4
보스 몬스터 이벤트
어려움
10턴마다 데미지가 2배인 보스 몬스터가 등장하도록 update()를 수정하세요. 보스 등장 시 "보스 등장!" 메시지도 출력합니다.
힌트 보기
if(turn % 10 == 9) 조건으로 보스 여부 판별. 보스면 monsterDmg *= 2.
핵심 정리

핵심 정리

  • init(): 초기화(1회) / update(): 로직(반복) / render(): 출력(반복)
  • update가 0 반환 → 게임 루프 종료
  • 전역 변수로 게임 상태(hp, lv, score) 공유
  • 이 패턴은 Unity, Pygame 등 실제 게임 엔진에도 동일하게 사용됨
