Project 01

학교 소개 프로그램

printf를 활용해 학교 이름, 위치, 설립연도 등 학교 정보를 출력하는 프로그램을 만듭니다.

프로젝트 목표

  • printf로 여러 줄의 정보를 출력할 수 있습니다.
  • \t 탭으로 출력을 정렬할 수 있습니다.
  • C 프로그램 기본 뼈대를 직접 작성할 수 있습니다.
  • 자기 학교 정보로 프로그램을 수정할 수 있습니다.
PROJECT 01

프로그램 설계하기

코딩 전에 먼저 어떤 정보를 출력할지 계획합니다. 좋은 계획이 좋은 코드를 만듭니다.

항목 이름의 길이가 다를 때 \t를 활용하면 콜론(:)을 같은 위치에 맞출 수 있습니다.

따라해보세요
1
학교 이름과 위치를 탭으로 정렬해서 출력해보세요.
#include <stdio.h> int main() { printf("학교 이름:\t코딩쏙 중학교\n"); printf("위 치:\t서울시 강남구\n"); return 0; }
두 줄이 정렬되어 출력됩니다
2
설립연도도 추가해 보세요.
printf("설립연도:\t2010년\n");
설립연도: 2010년 이 추가됩니다
3
구분선 (===)을 추가해서 꾸며보세요.
printf("==================\n"); printf(" 학교 소개\n"); printf("==================\n");
구분선이 위아래에 표시됩니다
PROJECT 01

완성 코드 작성하기

설계한 내용을 바탕으로 완전한 학교 소개 프로그램을 작성합니다.

#include <stdio.h> int main() { /* 학교 소개 프로그램 */ printf("================================\n"); printf(" 우리 학교 소개\n"); printf("================================\n"); printf("학교 이름:\t코딩쏙 중학교\n"); printf("위 치:\t서울시 강남구\n"); printf("설립연도:\t2010년\n"); printf("학생 수:\t600명\n"); printf("================================\n"); return 0; }
================================
        우리 학교 소개
================================
학교 이름:    코딩쏙 중학교
위    치:    서울시 강남구
설립연도:    2010년
학생  수:    600명
================================

PROJECT 01

나만의 학교 소개로 수정하기

완성 코드를 자기 학교 정보로 바꿔봅니다. 추가 항목도 넣어서 더 완성도 있게 만들어 봅시다.

Q2
항목 추가하기 — 코드 완성
쉬움
교장 선생님 이름 "김지훈"을 출력하는 printf 한 줄을 작성하세요.
형식printf("교장 이름:\t____\n");
내 답안
힌트 보기
큰따옴표 안에 이름을 넣고 \n으로 줄바꿈합니다.
정답 보기
printf("교장 이름:\t김지훈\n");
Q3
도전: 학급 정보 출력
보통
학년이 3개, 각 학년에 반이 4개인 학교의 전체 학급 수를 계산해서 출력하는 코드를 작성하세요.
출력전체 학급 수: 12반
내 답안
힌트 보기
3 × 4 = 12. printf로 직접 숫자를 출력하면 됩니다.
정답 보기
printf("전체 학급 수:\t12반\n"); // 또는 3학년 x 4반 = 12반

핵심 요약

  • printf("항목:\t내용\n"); — 탭으로 정렬된 정보 출력
  • \t는 탭 공백, \n은 줄바꿈
  • 구분선(===)으로 출력을 보기 좋게 꾸밀 수 있다
  • printf를 여러 번 써서 여러 줄을 출력한다
  • 문자열 안의 내용만 바꾸면 다른 정보로 수정 가능
