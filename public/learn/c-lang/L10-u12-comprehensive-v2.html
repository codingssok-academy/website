L10 마인드맵 — 동적 메모리 전체 정리

종합 예제 — 동적 학생 관리

#include <stdio.h> #include <stdlib.h> #include <string.h> typedef struct { char name[20]; int score; } Student; int main() { int cap=2, cnt=0; Student *list = (Student*)calloc(cap, sizeof(Student)); char buf[20]; int sc; while(scanf("%s %d",buf,&sc)==2){ if(cnt==cap){ cap*=2; Student *tmp=(Student*)realloc(list,sizeof(Student)*cap); if(!tmp){free(list);return 1;} list=tmp; } strcpy(list[cnt].name,buf); list[cnt].score=sc; cnt++; } for(int i=0;i<cnt;i++) printf("%s: %d\n",list[i].name,list[i].score); free(list); list=NULL; return 0; }

핵심 정리

L10 핵심 정리

  • malloc — 힙에서 메모리 할당, sizeof 사용, NULL 체크 필수
  • calloc — 0 초기화 할당, realloc — 크기 변경
  • free + NULL — 메모리 누수, dangling, double free 방지
  • 동적 2D 배열 — int**, 역순 해제
  • 연결 리스트 — 노드+next 포인터, 삽입/삭제/순회
  • 스택(LIFO)/큐(FIFO) — 연결 리스트로 구현
