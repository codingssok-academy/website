문자열 배열
정렬
Sort char *arr[] String Array
char *arr[]는 문자열 포인터 배열이다. qsort와 strcmp 기반 비교 함수로 문자열 배열을 알파벳 순으로 정렬한다.
난이도 char *arr[] 구조 qsort + strcmp 이중 포인터 캐스팅
완성 코드 — qsort 버전 + 직접 정렬 버전
str_sort.c #include <stdio.h>
#include <stdlib.h>
#include <string.h>

/* qsort용 비교 함수 */
int cmp_str(const void *a, const void *b) {
    return strcmp(*(const char **)a, *(const char **)b);
}

int cmp_str_desc(const void *a, const void *b) {
    return strcmp(*(const char **)b, *(const char **)a); // 반전
}

int main() {
    const char *words[] = {
        "Cherry", "Apple", "Date", "Banana", "Elderberry"
    };
    int n = sizeof(words) / sizeof(words[0]);
    
    printf("정렬 전: ");
    for (int i = 0; i < n; i++) printf("%s ", words[i]);
    
    qsort(words, n, sizeof(char *), cmp_str);
    printf("\n오름차순: ");
    for (int i = 0; i < n; i++) printf("%s ", words[i]);
    
    qsort(words, n, sizeof(char *), cmp_str_desc);
    printf("\n내림차순: ");
    for (int i = 0; i < n; i++) printf("%s ", words[i]);
    printf("\n");
    return 0;
}
$ gcc str_sort.c -o str_sort && ./str_sort
정렬 전: Cherry Apple Date Banana Elderberry
오름차순: Apple Banana Cherry Date Elderberry
내림차순: Elderberry Date Cherry Banana Apple
cmp_str의 이중 캐스팅: qsort는 const void *를 전달. words의 원소는 const char * (문자열 주소). 따라서 a는 "const char *를 가리키는 포인터" = const char **. *(const char **)a = 실제 문자열 주소.
응용: 길이 기준 정렬 + 검색
str_utils.c /* 문자열 길이 기준 정렬 (짧은 것 먼저) */
int cmp_len(const void *a, const void *b) {
    return (int)strlen(*(const char **)a)
         - (int)strlen(*(const char **)b);
}

/* 이진 탐색으로 문자열 검색 (정렬 후) */
char **find_str(char *words[], int n, const char *target) {
    int lo = 0, hi = n - 1;
    while (lo <= hi) {
        int mid = (lo + hi) / 2;
        int cmp = strcmp(words[mid], target);
        if (cmp == 0) return &words[mid];
        if (cmp < 0) lo = mid + 1; else hi = mid - 1;
    }
    return NULL;
}

도전 과제

2 사전 정렬 + 출력: 과일 이름 10개를 입력받아 qsort로 정렬 후 번호와 함께 출력.
3 중복 제거: 정렬 후 인접한 동일 문자열을 제거하여 유일한 항목만 출력.
연습문제
1 qsort(words, n, sizeof(char *), cmp_str)에서 sizeof(char *)를 쓰는 이유는?
qsort는 각 원소의 크기를 알아야 한다. words의 원소는 char * (포인터, 8바이트). 따라서 sizeof(char *) = 8. qsort가 내부에서 8바이트 단위로 원소를 이동시킨다.
2 cmp_str에서 *(const char **)a가 필요한 이유는?
qsort는 a에 "배열의 어느 원소를 가리키는 포인터"를 전달. words의 원소가 const char *이므로 a는 const char **. 한 번 역참조(*)하면 실제 const char * (문자열 포인터)를 얻는다. 이것을 strcmp에 전달한다.
3 내림차순 비교 함수에서 a와 b를 반전하는 이유는?
strcmp(a, b) > 0이면 a가 사전 순으로 뒤 → 오름차순에서 a를 뒤로 이동. 내림차순은 반대로 해야 하므로 strcmp(b, a)를 반환. b > a이면 양수 → b를 뒤로 이동 = 오름차순 b 기준.
4 char *words[]와 char words[][]의 차이는?
char *words[]: 각 원소가 포인터. 문자열들이 다른 메모리 위치에 있을 수 있음. 정렬 시 포인터(8바이트)만 교환.
char words[N][M]: 2차원 배열. 각 원소가 M바이트짜리 고정 크기. 정렬 시 M바이트를 복사. 포인터 배열이 훨씬 유연하고 효율적.
5 bsearch로 정렬된 문자열 배열에서 검색하는 방법은?
bsearch(target, words, n, sizeof(char *), cmp_str). cmp_str과 동일한 비교 함수 사용. 반환: 찾으면 해당 원소 주소(const char **), 없으면 NULL. qsort와 bsearch는 같은 비교 함수를 공유해야 한다.

이번 프로젝트 핵심

  • char *words[] — 문자열 포인터 배열, 각 원소가 문자열 주소
  • qsort(arr, n, sizeof(char *), cmp) — 표준 정렬 함수
  • 비교 함수: const void *를 받아 *(const char **)로 역참조
  • 정렬 시 포인터만 교환 — 실제 문자열 복사 없음
  • 내림차순: strcmp(b, a) — a와 b 인자 순서 반전
