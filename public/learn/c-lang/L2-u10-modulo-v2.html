나머지 연산: %

나머지 연산자(%)로 짝/홀 판별, 자릿수 추출, 시간 변환을 배웁니다. 프로그래밍에서 가장 자주 쓰이는 연산자 중 하나입니다.

이 유닛에서 배우는 것

  • 나머지 연산자 %의 의미와 사용법을 안다
  • n % 2로 짝수/홀수를 판별할 수 있다
  • n % 10으로 일의 자리를 추출할 수 있다
  • 분을 시간과 분으로 변환할 수 있다
  • 배수 판별, 순환(사이클) 계산에 활용할 수 있다
  • /와 %의 관계를 이해한다

나머지 연산(%)이란?

% 연산자는 나눗셈의 나머지를 구합니다. 10 % 3은 10을 3으로 나눈 나머지인 1입니다. 정수끼리만 사용할 수 있습니다.

#include <stdio.h> int main(void) { printf("10 %% 3 = %d\n", 10 % 3); // 1 printf("15 %% 4 = %d\n", 15 % 4); // 3 printf("20 %% 5 = %d\n", 20 % 5); // 0 (딱 나눠짐) printf("7 %% 2 = %d\n", 7 % 2); // 1 (홀수!) return 0; }
따라해보세요
1
17 % 5의 결과를 예측하고 확인하세요.
2 (17 = 5×3 + 2)
2
숫자 456에서 일의 자리(6)를 %로 추출해보세요.
456 % 10 = 6
3
200분을 시간과 분으로 변환해보세요.
3시간 20분 (200/60=3, 200%60=20)

나머지 연산 활용

// 자릿수 추출: 357 분해 int n = 357; printf("백:%d 십:%d 일:%d\n", n/100, n/10%10, n%10); // 시간 변환: 130분 -> 2시간 10분 int total_min = 130; int hours = total_min / 60; // 2시간 int mins = total_min % 60; // 10분 printf("%d시간 %d분\n", hours, mins);

실전 활용 패턴

% 연산은 배수 판별, 순환 계산, 단위 변환에서 매우 자주 쓰입니다. 패턴을 외워두면 나중에 바로 쓸 수 있어요.

// 배수 판별 int n = 9; printf("3의 배수? %d\n", n % 3 == 0); // 1 (참) // 순환: 오늘 월요일(0), 10일 후 요일 int today = 0; // 0=월, 1=화 ... 6=일 int after = (today + 10) % 7; printf("10일 후: %d\n", after); // 3 (목요일) // 12시간제 변환 int hour24 = 15; printf("%d시\n", hour24 % 12); // 3 (오후 3시)
따라해보세요
1
n = 42 일 때 7의 배수인지 확인하세요.
42 % 7 == 0 → 1 (참, 7의 배수)
2
오늘이 수요일(2)이면, 20일 후는 무슨 요일인지 계산하세요.
(2 + 20) % 7 = 22 % 7 = 1 → 화요일
3
18시를 12시간제로 변환하세요.
18 % 12 = 6 → 오후 6시

도전 문제

Q1
나머지 연산 결과 맞추기
쉬움
다음 연산의 결과를 구하세요.
125 % 7 = ____
2100 % 10 = ____
313 % 2 = ____
내 답안
정답 보기
1) 4 (25 = 7×3 + 4) 2) 0 (딱 나눠짐) 3) 1 (홀수)
Q2
3자리 숫자 분해
보통
3자리 정수를 입력받아 백의 자리, 십의 자리, 일의 자리를 각각 출력하는 코드를 작성하세요.
입력357
출력백:3 십:5 일:7
내 답안
힌트 보기
백: n/100, 십: n/10%10, 일: n%10
정답 보기
int n; scanf("%d", &n); printf("백:%d 십:%d 일:%d\n", n/100, n/10%10, n%10);
Q3
초를 분:초로 변환
보통
초를 입력받아 분과 초로 변환하세요.
입력150
출력2분 30초
내 답안
정답 보기
int sec; scanf("%d", &sec); printf("%d분 %d초\n", sec / 60, sec % 60);
Q4
동전 개수 계산
보통
금액(원)을 입력받아 500원짜리 동전과 100원짜리 동전으로 가장 적게 사용할 때 각 동전의 개수를 출력하세요. (금액은 100의 배수로 입력)
입력1300
출력500원: 2개, 100원: 3개
내 답안
힌트 보기
500원 동전: money / 500, 나머지 금액: money % 500, 100원 동전: (money % 500) / 100
정답 보기
int money; scanf("%d", &money); int c500 = money / 500; int c100 = (money % 500) / 100; printf("500원: %d개, 100원: %d개\n", c500, c100);
Q5
n일 후 요일 계산
어려움
오늘이 월요일(0)입니다. n을 입력받아 n일 후의 요일 번호를 출력하세요. (0=월, 1=화, 2=수, 3=목, 4=금, 5=토, 6=일)
입력10
출력요일: 3 (목요일)
내 답안
힌트 보기
오늘이 0(월요일)이고 n일이 지나면 (0 + n) % 7 로 요일 번호를 구할 수 있어요.
정답 보기
int n; scanf("%d", &n); int day = (0 + n) % 7; printf("요일: %d\n", day); /* 0=월 1=화 2=수 3=목 4=금 5=토 6=일 */

핵심 요약

  • %는 나눗셈의 나머지를 구하는 연산자이다 (정수만 가능)
  • n % 2 == 0이면 짝수, 1이면 홀수이다
  • n % 10은 일의 자리, n / 10 % 10은 십의 자리를 추출한다
  • n % k == 0이면 n은 k의 배수이다
  • (today + n) % 7로 n일 후 요일을 순환 계산할 수 있다
  • /는 몫, %는 나머지 — 항상 짝으로 기억하자
  • printf에서 % 기호를 출력하려면 %%로 써야 한다
