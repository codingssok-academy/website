switch문
— 값에 따른 분기

여러 값 중 하나를 골라 실행하는 switch문을 배웁니다. if-else보다 깔끔하게 다중 분기를 처리하는 법을 익혀봅시다.

이 유닛에서 배우는 것

  • switch문의 문법을 설명하고 직접 작성할 수 있습니다.
  • break의 역할과 fall-through 현상을 이해할 수 있습니다.
  • default를 활용해 예외 상황을 처리할 수 있습니다.
  • switch를 쓸 수 있는 경우와 없는 경우를 구분할 수 있습니다.
  • if-else와 switch 중 적절한 것을 선택할 수 있습니다.

switch문 기본

여러 값을 비교할 때 if-else를 줄줄이 쓰면 코드가 길어집니다. switch문을 쓰면 같은 로직을 훨씬 깔끔하게 표현할 수 있습니다.

switch 문법 구조

실행 흐름

코드 예시 — 요일 출력

int day = 3; switch (day) { case 1: printf("월요일\n"); break; case 2: printf("화요일\n"); break; case 3: printf("수요일\n"); break; case 4: printf("목요일\n"); break; case 5: printf("금요일\n"); break; case 6: printf("토요일\n"); break; case 7: printf("일요일\n"); break; default: printf("잘못된 입력\n"); break; } // 출력: 수요일

break와 fall-through

switch문에서 break는 단순한 장식이 아닙니다. break가 없으면 C는 매칭된 case 이후의 모든 코드를 계속 실행해버립니다. 이것을 fall-through(낙하)라고 합니다.

break 없음 (오류 주의!)
int x = 2; switch (x) { case 1: printf("one\n"); case 2: printf("two\n"); case 3: printf("three\n"); default: printf("else\n"); } // 출력: two // three // else ← 전부!
break 있음 (의도한 동작)
int x = 2; switch (x) { case 1: printf("one\n"); break; case 2: printf("two\n"); break; case 3: printf("three\n"); break; default: printf("else\n"); break; } // 출력: two ← 정확히 하나만!

의도적 fall-through — 여러 case 묶기

fall-through를 일부러 활용할 수도 있습니다. 여러 case에 같은 동작을 하고 싶을 때 break 없이 case를 연속으로 씁니다.

int month = 4; switch (month) { case 3: case 4: case 5: printf("봄입니다\n"); break; // 3, 4, 5월 모두 봄 case 6: case 7: case 8: printf("여름입니다\n"); break; // 6, 7, 8월 모두 여름 default: printf("가을/겨울입니다\n"); break; } // month=4 → 출력: 봄입니다

case 3, 4, 5는 각각 break가 없으므로 모두 같은 코드("봄입니다")로 떨어집니다. 이것이 의도적 fall-through입니다.

따라해보세요
1
아래 코드에서 x = 1일 때 출력 결과를 먼저 예측한 뒤, 직접 실행해보세요.
int x = 1; switch (x) { case 1: printf("A\n"); case 2: printf("B\n"); case 3: printf("C\n"); break; }
A, B, C 모두 출력됩니다 (break가 case 3에만 있으므로)
2
위 코드에 올바른 위치에 break를 추가해서 x = 1일 때 A만 출력되게 수정하세요.
case 1: printf("A\n"); break; // break 추가! case 2: printf("B\n"); break; case 3: printf("C\n"); break;

int n = 3; switch (n) { case 1: case 3: case 5: printf("홀수\n"); break; case 2: case 4: case 6: printf("짝수\n"); break; }
홀수 가 출력됩니다

default와 switch 사용 조건

default는 어느 case에도 해당하지 않을 때 실행됩니다. 항상 맨 마지막에 씁니다. 생략할 수도 있지만, 예외 처리를 위해 습관적으로 쓰는 것이 좋습니다.

switch를 쓸 수 있는 경우 vs 못 쓰는 경우

switch는 정수·문자만! 범위 비교(크다, 작다), float, 문자열은 switch에서 사용할 수 없습니다. 이런 경우에는 if-else를 쓰세요.

코드 예시 — char로 switch

char grade = 'B'; switch (grade) { case 'A': printf("우수\n"); break; case 'B': printf("양호\n"); break; case 'C': printf("보통\n"); break; case 'D': printf("미흡\n"); break; case 'F': printf("불합격\n"); break; default: printf("잘못된 학점\n"); break; } // 출력: 양호
따라해보세요
1
grade = 'Z'로 바꿔서 실행하면 어떤 결과가 나오나요?
char grade = 'Z';
잘못된 학점 이 출력됩니다 (default 실행)
2
점수 score가 100이면 "만점", 0이면 "빵점"을 출력하는 switch문을 작성하세요.
int score = 100; switch (score) { case 100: printf("만점!\n"); break; case 0: printf("빵점...\n"); break; default: printf("%d점\n", score); break; }
만점! 이 출력됩니다
3
90점 이상을 'A', 80점 이상을 'B'로 분류하는 코드를 switch로 작성할 수 있나요? if-else와 switch 중 어떤 것이 적합한지 생각해보세요.
// switch는 범위 비교 불가! if-else가 적합 int score = 85; if (score >= 90) printf("A\n"); else if (score >= 80) printf("B\n"); else printf("C 이하\n");
B 가 출력됩니다. 범위 비교는 if-else를 씁니다!

정답 확인
char 타입이므로 case에 문자 리터럴('A', 'B' 등)을 사용합니다. GPA는 float 변수에 저장 후 출력합니다.
char grade = 'B'; float gpa; switch (grade) { case 'A': gpa = 4.0; break; case 'B': gpa = 3.0; break; case 'C': gpa = 2.0; break; case 'D': gpa = 1.0; break; case 'F': gpa = 0.0; break; default: printf("잘못된 학점\n"); return 0; } printf("GPA: %g\n", gpa);

핵심 정리

  • switch (값)은 값이 일치하는 case로 점프한다.
  • break가 없으면 아래 case로 계속 실행된다 (fall-through).
  • 여러 case에 같은 동작을 할 때는 의도적 fall-through를 활용한다.
  • default는 어느 case에도 해당하지 않을 때 실행된다.
  • switch는 정수, char만 가능. float·범위·문자열은 if-else를 쓴다.
