조건문 종합 실전

if, else if, else, switch, 삼항 연산자, 복합 조건까지 — L3 전체를 한 번에 정리합니다.

이 유닛에서 배우는 것

  • 상황에 맞는 조건문을 스스로 선택할 수 있습니다.
  • 복합 조건과 중첩 조건문을 읽고 쓸 수 있습니다.
  • 학생 관리 시스템을 조건문으로 구현할 수 있습니다.
  • 미니 ATM 프로그램을 switch + if로 만들 수 있습니다.
  • L3 전체 조건문 패턴을 복습하고 정리할 수 있습니다.

어떤 조건문을 써야 할까?

조건문은 종류가 여러 가지입니다. 상황에 맞는 것을 고르는 눈을 키워야 합니다.

상황별 빠른 선택 표

값이 딱 떨어질 때 → switch
menu == 1, 2, 3 day == 'A', 'B', 'C'
범위 비교 → if-else if
score >= 90 → A score >= 80 → B
간단한 2지선다 → 삼항
age >= 18 ? "성인" : "미성년"
복합 조건 → if + && / ||
score >= 60 && attend >= 15

코딩 스타일 가이드

좋은 코드 습관 4가지

  • 중괄호 { }는 항상 쓴다 — 한 줄짜리라도 생략하지 않는다
  • 들여쓰기는 4칸(스페이스) 또는 탭 1개로 일관되게 유지한다
  • 복합 조건은 괄호로 묶어 우선순위를 명확히 한다: (a > 0) && (b > 0)
  • switch에는 반드시 default:를 넣는다

종합 예제 1 — 학생 관리 시스템

점수와 출석일수 두 가지 조건을 모두 확인해서 합격 여부와 우수 학생을 판단하는 프로그램입니다.

합격 조건
점수 60 이상
AND 출석 15일 이상
불합격 조건
점수 미달
OR 출석 미달
우수 학생
점수 90 이상
AND 출석 18일 이상

전체 코드

// 학생 관리 시스템 #include <stdio.h> int main() { int studentId = 1001; int score = 92; int attend = 19; printf("=== 학생 %d 평가 결과 ===\n", studentId); if (score >= 60 && attend >= 15) { printf("판정: 합격\n"); if (score >= 90 && attend >= 18) { printf("특이사항: 우수 학생\n"); } } else { printf("판정: 불합격\n"); if (score < 60) { printf("사유: 점수 미달 (%d점)\n", score); } if (attend < 15) { printf("사유: 출석 미달 (%d일)\n", attend); } } return 0; }

핵심 포인트

  • && (AND): 두 조건이 모두 참일 때만 참
  • 중첩 if: 첫 번째 조건 통과 후 추가 조건 검사
  • 불합격 사유는 별도 if로 나눠서 정확히 출력

종합 예제 2 — 미니 ATM

switch로 메뉴를 선택하고, if로 잔액을 확인하는 실전 프로그램입니다.

전체 코드

// 미니 ATM 프로그램 #include <stdio.h> int main() { int balance = 50000; // 초기 잔액 int menu, amount; printf("=== 미니 ATM ===\n"); printf("1. 잔액 확인 2. 출금 3. 입금\n"); printf("메뉴 선택: "); scanf("%d", &menu); switch (menu) { case 1: printf("현재 잔액: %d원\n", balance); break; case 2: printf("출금 금액: "); scanf("%d", &amount); if (balance >= amount) { balance = balance - amount; printf("출금 완료. 잔액: %d원\n", balance); } else { printf("잔액 부족! 현재 잔액: %d원\n", balance); } break; case 3: printf("입금 금액: "); scanf("%d", &amount); balance = balance + amount; printf("입금 완료. 잔액: %d원\n", balance); break; default: printf("잘못된 메뉴입니다.\n"); } return 0; }

L3 핵심 정리

  • 비교 연산자: == != > < >= <= — 참(1) 또는 거짓(0) 반환
  • if-else if-else: 범위 조건, 여러 분기 처리에 최적
  • switch: 특정 정수·문자 값 매칭 시 가독성 높음, 반드시 break
  • 삼항 연산자: 조건 ? 참값 : 거짓값 — 간단한 2지선다에 사용
  • 복합 조건: &&(AND) · ||(OR) · !(NOT) 조합으로 복잡한 조건 표현
  • 중첩 if: if 안에 if — 계층적 조건 처리, 들여쓰기로 구조 명확히
