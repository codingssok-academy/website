로또 번호 생성기

rand() 함수로 1~45 사이 숫자를 6개 뽑습니다. 중복 제거, 오름차순 정렬, 보너스 번호까지 단계별로 만들어봅니다.

이 프로젝트에서 배우는 것

  • rand()와 srand()로 난수를 생성하는 방법을 배웁니다.
  • 배열을 사용해 여러 숫자를 저장하고 관리할 수 있습니다.
  • 중첩 for + if로 중복 번호를 검사하고 다시 뽑는 로직을 구현합니다.
  • 버블 정렬로 숫자를 오름차순으로 정렬하는 방법을 익힙니다.

rand() — 난수 생성 함수

rand()는 임의의 정수를 반환하는 함수입니다. stdlib.h를 포함해야 합니다. 나머지 연산(%)을 이용해 원하는 범위로 조절합니다.

// 기본 로또 번호 6개 생성 (중복 있음) #include <stdio.h> #include <stdlib.h> // rand(), srand() #include <time.h> // time() int main() { srand(time(NULL)); // 시드 설정 (실행마다 다른 결과) int i; printf("로또 번호: "); for (i = 0; i < 6; i++) { int num = rand() % 45 + 1; // 1~45 printf("%d ", num); } printf("\n"); return 0; }
srand(time(NULL)) 이란?

srand()는 rand()의 시작점(씨앗, seed)을 설정합니다. time(NULL)은 현재 시각을 숫자로 돌려주므로, 매 실행마다 다른 난수열이 생성됩니다. srand 없이 rand()만 쓰면 항상 같은 번호가 나옵니다.

씨앗이 고정되면 항상 같은 난수열이 나옵니다 — 디버깅에 유용

확장 1 — 중복 제거

이미 뽑은 번호가 또 나오면 다시 뽑습니다. 배열에 번호를 저장하고, 새로 뽑을 때마다 배열 전체와 비교해 중복이면 i--로 되돌려 다시 시도합니다.

// 중복 없는 로또 번호 6개 int lotto[6]; // 번호 저장 배열 int i, j, num, dup; for (i = 0; i < 6; i++) { do { num = rand() % 45 + 1; dup = 0; // 중복 플래그 초기화 for (j = 0; j < i; j++) { // 이미 뽑은 것과 비교 if (lotto[j] == num) { dup = 1; // 중복 발견! break; } } } while (dup); // 중복이면 다시 뽑기 lotto[i] = num; } printf("번호: "); for (i = 0; i < 6; i++) { printf("%d ", lotto[i]); }

확장 2 — 오름차순 정렬 (버블 정렬)

6개 번호를 작은 수부터 큰 수 순서로 정렬합니다. 버블 정렬은 옆 두 수를 비교해 순서가 틀리면 교환하는 방식입니다.

// 오름차순 정렬 (버블 정렬) int i, j, temp; for (i = 0; i < 5; i++) { for (j = 0; j < 5 - i; j++) { if (lotto[j] > lotto[j + 1]) { // 앞이 크면 temp = lotto[j]; // 교환 lotto[j] = lotto[j + 1]; lotto[j + 1] = temp; } } } printf("정렬된 번호: "); for (i = 0; i < 6; i++) { printf("%2d ", lotto[i]); }

확장 3 — 보너스 번호

6개 번호와 겹치지 않는 보너스 번호를 하나 더 뽑습니다. 중복 제거 로직을 한 번 더 적용하면 됩니다.

// 보너스 번호 뽑기 (6개와 중복 없이) int bonus, dup; do { bonus = rand() % 45 + 1; dup = 0; for (i = 0; i < 6; i++) { if (lotto[i] == bonus) { dup = 1; break; } } } while (dup); printf("번호: %2d %2d %2d %2d %2d %2d + 보너스: %2d\n", lotto[0], lotto[1], lotto[2], lotto[3], lotto[4], lotto[5], bonus);

핵심 정리

  • rand() % N + 1 → 1~N 사이 난수 생성
  • srand(time(NULL)): 매 실행마다 다른 씨앗 → 다른 난수열
  • 중복 제거: do-while + 안쪽 for로 기존 배열과 비교, dup 플래그 사용
  • 버블 정렬: 인접 두 수 비교 후 교환, 큰 수가 오른쪽으로 이동
  • 보너스 번호: 6개 뽑기와 동일한 중복 제거 로직 한 번 더 적용
  • 배열 선언: int lotto[6] → 6개 정수를 연속된 메모리에 저장
