문자 배열 기초 — 문자열의 정체

C언어에는 string 타입이 없습니다. 문자 하나하나를 char 배열에 담고, 끝에 '\0'을 붙여 문자열을 만듭니다. 이 원리를 이해하면 문자열의 모든 것이 보입니다.

이 유닛에서 배우는 것

  • char 배열과 '\0'(null terminator)의 관계를 설명할 수 있습니다.
  • 문자열을 선언하고 초기화하는 3가지 방법을 씁니다.
  • scanf로 문자열을 입력받을 수 있습니다.
  • printf로 문자열을 출력할 수 있습니다.
  • for문으로 문자 하나씩 접근하고 처리합니다.

char 배열 = 문자들의 모음

C언어에서 문자열은 char 배열에 저장됩니다. 각 칸에 문자 하나씩 들어가고, 마지막 칸에는 반드시 문자열 끝을 알리는 '\0'(null 문자)이 들어갑니다.

문자열 선언과 초기화 3가지

주의: char name[5] = "Hello";는 잘못된 선언입니다. "Hello"는 H-e-l-l-o-\0 총 6칸이 필요하므로 배열 크기를 6 이상으로 선언해야 합니다.

scanf로 문자열 입력받기

문자열을 키보드로 입력받을 때는 scanf("%s", 배열이름)을 씁니다. 배열 이름 앞에 &를 붙이지 않는다는 점에 주의하세요.

char name[20]; printf("이름 입력: "); scanf("%s", name); // & 없음! 배열 이름이 곧 주소 printf("안녕, %s!\n", name); // %s로 문자열 출력 // 공백 포함 입력은 fgets 사용 fgets(name, sizeof(name), stdin); // 한 줄 전체 읽기

printf로 문자열 출력하기

문자열은 printf("%s", 배열이름)으로 출력합니다. %s는 '\0'을 만날 때까지 문자를 순서대로 출력합니다.

char greeting[20] = "Hello World"; printf("%s\n", greeting); // Hello World printf("길이=%lu\n", strlen(greeting)); // 11 (\0 제외) // 글자 수 세기 int i = 0; while(greeting[i] != '\0') i++; printf("직접 센 길이: %d\n", i); // 11

문자 하나씩 접근하기

char 배열의 각 원소는 문자 하나입니다. 인덱스로 접근하거나 for문으로 순회하면서 각 문자를 읽거나 바꿀 수 있습니다.

char str[] = "hello"; int i; // 방법1: 인덱스로 개별 접근 printf("%c\n", str[0]); // h 출력 (%c: 문자 하나) str[0] = 'H'; // 첫 글자를 H로 변경 // 방법2: for문으로 전체 순회 (\0 만날 때까지) for(i = 0; str[i] != '\0'; i++) { if(str[i] >= 'a' && str[i] <= 'z') str[i] -= 32; // 소문자 → 대문자 (ASCII 차이 32) } printf("%s\n", str); // HELLO

핵심 정리

  • 문자열 = char 배열 + '\0': 문자열 끝에 반드시 null 문자(값 0) 필요
  • 크기: "Hello" 저장 시 최소 6칸 — 글자수 + 1('\0'용)
  • 초기화: "Hello" 리터럴 / {'H','e','\0'} 나열 / 크기 생략 3가지
  • 입력: scanf("%s", name) — & 없음, 공백 전까지만 입력
  • 출력: printf("%s", name) — '\0' 만날 때까지 자동 출력
  • 개별 접근: name[i] — %c 형식, != '\0'로 순회 종료 판별
