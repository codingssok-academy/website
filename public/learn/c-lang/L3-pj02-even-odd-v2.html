짝홀 판별기
만들기

숫자를 입력받아 짝수인지 홀수인지 자동으로 판별하는 프로그램을 만들어봅니다.
L2에서 배운 나머지 연산(%)과 조건문(if-else)을 실제 프로젝트에 적용합니다.

이 프로젝트에서 만드는 것

  • 숫자를 입력받아 짝수/홀수를 자동으로 판별하는 프로그램
  • 나머지 연산(%)과 조건문(if-else)을 실전 코드에 적용
  • 0과 음수 입력도 올바르게 처리하는 확장 버전
scanf / printf int 변수 % 나머지 연산 if-else 조건문 == 비교 연산자

단계별 구현

1
숫자 입력 받기
사용자로부터 정수 하나를 받아 변수에 저장합니다

프로그램이 시작되면 먼저 사용자에게 숫자를 입력하라고 알려줍니다. 그 다음 scanf로 입력값을 받아 변수 n에 저장합니다.

// Step 1: 숫자 입력 int n; printf("숫자를 입력하세요: "); scanf("%d", &n);

주의: scanf에서 변수 앞에 &를 반드시 붙여야 합니다. &n은 변수 n의 주소를 뜻합니다. 빠뜨리면 프로그램이 오작동합니다.

2
나머지 연산으로 판별 (핵심!)
L2-u10에서 배운 % 연산자를 드디어 실전에 씁니다

n % 2는 n을 2로 나눈 나머지를 구합니다. 짝수는 나머지가 항상 0, 홀수는 나머지가 항상 1이 됩니다.

왜 n % 2 == 0 이 짝수일까?

짝수는 2의 배수이므로 2로 나누면 나머지가 0입니다. 예: 6 ÷ 2 = 3 나머지 0. 홀수는 딱 떨어지지 않아 나머지가 1입니다. 예: 7 ÷ 2 = 3 나머지 1.

3
if-else로 결과 출력
조건에 따라 다른 메시지를 출력합니다

판별 결과에 따라 "짝수입니다" 또는 "홀수입니다"를 출력합니다. if-else 구조를 사용합니다.

// Step 3: if-else로 결과 출력 if (n % 2 == 0) { printf("%d는 짝수입니다.\n", n); } else { printf("%d는 홀수입니다.\n", n); }
실행 결과 예시
숫자를 입력하세요: 7 7는 홀수입니다. 숫자를 입력하세요: 12 12는 짝수입니다.

확장 과제

기본 판별기가 완성됐습니다. 이제 세 가지 기능을 추가해 더 똑똑한 프로그램으로 만들어봅니다.

확장 1 3의 배수도 함께 판별하기

짝홀 판별에 더해, 입력한 숫자가 3의 배수인지도 확인합니다. n % 3 == 0을 추가하면 됩니다.

if (n % 2 == 0) { printf("%d는 짝수입니다.\n", n); } else { printf("%d는 홀수입니다.\n", n); } // 추가: 3의 배수 여부도 출력 if (n % 3 == 0) { printf("%d는 3의 배수이기도 합니다.\n", n); }
실행 결과 예시
숫자를 입력하세요: 12 12는 짝수입니다. 12는 3의 배수이기도 합니다.
확장 2 0 입력 시 특별 메시지 출력

수학적으로 0은 짝수입니다 (2×0=0). 하지만 0을 입력했을 때 특별한 메시지를 따로 보여줘도 좋습니다. if-else if-else 구조를 사용합니다.

if (n == 0) { printf("0은 특별한 짝수입니다.\n"); } else if (n % 2 == 0) { printf("%d는 짝수입니다.\n", n); } else { printf("%d는 홀수입니다.\n", n); }
실행 결과 예시
숫자를 입력하세요: 0 0은 특별한 짝수입니다.
확장 3 음수도 올바르게 처리하기

C언어에서 음수에 %를 쓰면 결과가 음수(-1)로 나올 수 있습니다. 그래도 n % 2 == 0으로 짝수를 판별하는 것은 여전히 정확합니다. 홀수 조건만 != 0으로 작성하면 음수도 완벽히 처리됩니다.

// C언어: -7 % 2 는 -1 (음수 가능) // n % 2 == 0 은 짝수, != 0 은 홀수로 처리 if (n % 2 == 0) { printf("%d는 짝수입니다.\n", n); } else { // 나머지가 1이든 -1이든 모두 홀수 printf("%d는 홀수입니다.\n", n); }
음수 입력 결과
숫자를 입력하세요: -7 -7는 홀수입니다. 숫자를 입력하세요: -8 -8는 짝수입니다.
C언어 음수 나머지 규칙

C 표준에서 -7 % 2의 결과는 -1입니다. 따라서 홀수 조건을 == 1이 아닌 != 0으로 쓰거나, else로 처리해야 음수에서도 틀리지 않습니다.

완성 코드 & 도전 과제

even_odd.c — 짝홀 판별기 완성본
#include <stdio.h> int main() { int n; /* ① 입력 */ printf("숫자를 입력하세요: "); scanf("%d", &n); /* ② 0 특별 처리 → 짝수 → 홀수 순서로 판별 */ if (n == 0) { printf("0은 특별한 짝수입니다.\n"); } else if (n % 2 == 0) { printf("%d는 짝수입니다.\n", n); } else { printf("%d는 홀수입니다.\n", n); } /* ③ 3의 배수 여부 추가 출력 */ if (n % 3 == 0) { printf("%d는 3의 배수이기도 합니다.\n", n); } return 0; }
도전 과제 — FizzBuzz 맛보기
짝홀 판별기를 업그레이드해 FizzBuzz 문제를 풀어봅니다
FizzBuzz 규칙
3의 배수이면 "Fizz" 출력
5의 배수이면 "Buzz" 출력
3과 5의 공배수(15의 배수)이면 "FizzBuzz" 출력
그 외에는 숫자 그대로 출력
힌트: 조건 순서가 중요합니다
15의 배수 조건을 맨 먼저 확인해야 합니다. 그렇지 않으면 15는 3의 배수로만 잡혀 "Fizz"만 출력됩니다.
if (n % 15 == 0) → else if (n % 3 == 0) → else if (n % 5 == 0) 순서로 작성해보세요.
예상 출력 (n = 15 입력 시)
FizzBuzz — 15는 3의 배수이면서 5의 배수이므로
// 직접 채워보세요! int n; scanf("%d", &n); if (n % 15 == 0) { printf("FizzBuzz\n"); } else if (n % 3 == 0) { printf("Fizz\n"); } else if (n % 5 == 0) { printf("Buzz\n"); } else { printf("%d\n", n); }

이 프로젝트에서 배운 것

  • n % 2 == 0 이면 짝수, 아니면(else) 홀수
  • scanf로 사용자 입력을 받을 때 변수 앞에 & 필수
  • if-else if-else 체인으로 여러 조건을 순서대로 처리
  • 음수 나머지는 음수가 될 수 있으므로 else로 처리하는 것이 안전
  • 0은 수학적으로 짝수이며, 특별 분기로 따로 처리 가능
  • 나머지 연산(%)은 배수 판별에 핵심 도구 — FizzBuzz도 같은 원리
