PROJECT

합격 불합격 판정
프로그램 만들기

점수를 입력받아 합격인지 불합격인지 알려주는 프로그램을 직접 만들어봅니다.
if-else 조건문과 논리 연산자를 활용합니다.

이 프로젝트에서 만드는 것

  • 점수를 입력받아 합격 / 불합격을 판정하는 프로그램
  • 과목 3개 평균으로 합격 여부를 계산하는 확장 버전
  • 잘못된 점수 입력(음수, 100초과)을 걸러내는 입력 검증
  • 결과에 맞는 격려 메시지를 출력하는 기능

단계별 구현

프로그램을 한 번에 완성하지 않습니다. 작은 단계로 쪼개서 하나씩 확인하면서 만듭니다.

1
점수 입력받기 (0 ~ 100)
사용자가 키보드로 점수를 입력하면 변수에 저장합니다. scanf로 정수를 읽어옵니다.
#include <stdio.h> int main() { int score; // 점수를 담을 변수 printf("점수를 입력하세요 (0~100): "); scanf("%d", &score); // 키보드에서 정수 읽기 printf("입력한 점수: %d\n", score); // 확인용 출력 return 0; }
확인 포인트
int score; — 정수형 변수 선언
&score — scanf는 주소가 필요, & 는 "score의 주소"를 뜻합니다
%d — 정수를 입력/출력할 때 쓰는 서식 지정자
2
if-else로 60점 기준 합격 판별
입력받은 점수가 60점 이상이면 합격, 그 미만이면 불합격으로 나눕니다.
if (score >= 60) { printf("합격입니다!\n"); } else { printf("불합격입니다.\n"); }
3
합격 / 불합격 메시지 출력 — 완성 코드
Step 1 + Step 2를 합쳐 완성합니다. 아래 코드를 그대로 입력해 실행해보세요.
#include <stdio.h> int main() { int score; printf("점수를 입력하세요 (0~100): "); scanf("%d", &score); if (score >= 60) { printf("결과: 합격입니다!\n"); } else { printf("결과: 불합격입니다.\n"); } return 0; }
핵심 정리
if (조건) { ... } else { ... } — 조건이 참이면 if 블록, 거짓이면 else 블록 실행
>= 는 "이상(크거나 같다)"을 뜻하는 비교 연산자입니다.

확장 과제

기본 프로그램이 동작하면 세 가지 확장 과제에 도전합니다. 순서대로 코드에 추가하세요.

확장 1 과목 3개 평균으로 합격 판정
국어, 수학, 영어 세 과목 점수를 각각 입력받아 평균을 구하고, 평균이 60점 이상이면 합격으로 처리합니다.
int korean, math, english, avg; printf("국어 점수: "); scanf("%d", &korean); printf("수학 점수: "); scanf("%d", &math); printf("영어 점수: "); scanf("%d", &english); avg = (korean + math + english) / 3; // 평균 계산 printf("평균: %d점\n", avg); if (avg >= 60) { printf("결과: 합격입니다!\n"); } else { printf("결과: 불합격입니다.\n"); }
확장 2 잘못된 입력 처리 — 논리 연산자 활용
음수이거나 100을 초과하는 점수는 유효하지 않습니다. 논리 연산자 ||(또는)로 두 조건을 동시에 검사합니다.
if (score < 0 || score > 100) { printf("오류: 0~100 범위의 점수를 입력하세요.\n"); } else if (score >= 60) { printf("결과: 합격입니다!\n"); } else { printf("결과: 불합격입니다.\n"); }
논리 연산자 정리
|| (OR) — 둘 중 하나라도 참이면 참  |  -5 < 0이 참이므로 → 오류로 처리
&& (AND) — 둘 다 참이어야 참  |  score >= 0 && score <= 100 유효 범위 검사
확장 3 결과에 맞는 격려 메시지 출력
단순한 합격/불합격 외에, 합격이면 "축하합니다!", 불합격이면 "다음에 도전!" 메시지를 추가합니다.
if (avg >= 60) { printf("결과: 합격입니다!\n"); printf("축하합니다! 정말 잘했어요!\n"); } else { printf("결과: 불합격입니다.\n"); printf("다음에 도전! 분명 할 수 있어요!\n"); }

전체 코드 — 확장 3까지 완성본

세 가지 확장을 모두 합친 최종 코드입니다. 직접 입력해서 실행해보세요.

pass_fail.c — 합격 불합격 판정 프로그램 완성본
#include <stdio.h> int main() { int korean, math, english, avg; /* ── 점수 입력 ── */ printf("=== 합격 불합격 판정 프로그램 ===\n"); printf("국어 점수를 입력하세요: "); scanf("%d", &korean); printf("수학 점수를 입력하세요: "); scanf("%d", &math); printf("영어 점수를 입력하세요: "); scanf("%d", &english); /* ── 입력값 검증 ── */ if (korean < 0 || korean > 100 || math < 0 || math > 100 || english < 0 || english > 100) { printf("오류: 0~100 범위의 점수를 입력하세요.\n"); return 1; } /* ── 평균 계산 ── */ avg = (korean + math + english) / 3; printf("\n평균 점수: %d점\n", avg); /* ── 합격 판정 + 격려 메시지 ── */ if (avg >= 60) { printf("결과: 합격입니다!\n"); printf("축하합니다! 정말 잘했어요!\n"); } else { printf("결과: 불합격입니다.\n"); printf("다음에 도전! 분명 할 수 있어요!\n"); } return 0; }
도전 과제
점수를 90점 이상, 80점 이상, 70점 이상, 60점 이상, 60점 미만으로 나눠 "A / B / C / D / F" 등급도 출력해보세요. (else if 활용)
합격 과목 수를 세어 출력해보세요. 예: "60점 이상 과목: 2개"
세 과목 중 가장 높은 점수와 가장 낮은 점수를 찾아 출력해보세요.
while 반복문을 사용해 잘못된 점수를 입력하면 다시 입력받도록 바꿔보세요.

이 프로젝트에서 배운 것

  • scanf("%d", &변수) — 키보드에서 정수 입력받기
  • if (조건) { } else { } — 조건에 따라 실행 흐름 분기
  • else if — 세 가지 이상 경우를 순서대로 검사
  • || (OR), && (AND) — 두 조건을 묶는 논리 연산자
  • 평균 = (합계) / 개수 — 정수 나눗셈, 소수점 이하 버림 주의
  • 입력 검증 — 프로그램 안전성의 기본, 항상 범위를 확인
