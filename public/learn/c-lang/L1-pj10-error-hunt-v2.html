에러 사냥 챌린지

일부러 심어놓은 에러들을 찾아 고치는 디버깅 챌린지입니다.

이 프로젝트에서 하는 것

  • 에러가 심어진 코드를 보고 문제를 찾습니다.
  • 에러 메시지 없이 코드만으로 버그를 발견합니다.
  • 총 3개의 챌린지를 클리어합니다 (난이도 상승).
  • 고친 코드를 컴파일해서 정상 작동을 확인합니다.

Level 1 챌린지 에러 2개

아래 코드에는 에러가 2개 숨어 있습니다. 컴파일하기 전에 눈으로만 찾아보세요. 그런 다음 고쳐서 컴파일하세요.

#include <stdio.h> int main() { printf("Level 1 시작!\n") printf("에러를 찾아라!\n"); printf("집중 집중!\n"); return 0; // 닫는 괄호 어디 있지?
따라해보세요
1단계
위 코드를 눈으로 읽고 에러 위치를 종이에 표시해보세요.
에러 2개 위치 파악
2단계
에러가 있는 코드를 그대로 컴파일해서 에러 메시지를 읽어보세요.
에러 메시지 확인
3단계
에러를 고치고 다시 컴파일해서 성공하면 Level 1 클리어!
컴파일 성공 → Level 1 클리어

최종 보스 챌린지

Q1
나만의 에러 코드 만들기
창의
에러가 3개 이상 포함된 코드를 직접 만들어 친구에게 퀴즈로 내보세요.
조건 1printf 4줄 이상
조건 2에러 3개 이상 (세미콜론, 중괄호 혼합)
조건 3정답 코드도 별도로 작성
내 답안
예시 보기
정상 코드에서 ; 3개를 지우고 } 1개를 지우면 에러 4개짜리 챌린지가 됩니다.
Q2
에러 메시지 → 위치 찾기
심화
아래 에러 메시지 3개를 읽고 각각 어느 줄, 어떤 에러인지 찾아보세요.
main.c:3:20: error: expected ';' before '}' main.c:5:5: error: expected ';' before 'return' main.c:8:1: error: expected '}' at end of input
내 답안
정답 보기
3번째 줄: ; 누락 5번째 줄: ; 누락 8번째 줄: } 누락 (파일 끝까지 찾음)
Q3
완벽한 코드 작성
기본
에러 0개인 완벽한 코드를 처음부터 끝까지 작성하세요. printf 5줄, 주석 2개 포함.
내 답안
예시 보기
#include <stdio.h> int main() { // 자기소개 printf("이름: 홍길동\n"); printf("나이: 14\n"); printf("학교: 코딩중\n"); // 마무리 printf("취미: 코딩\n"); printf("끝!\n"); return 0; }

핵심 요약

  • 에러 메시지에서 줄 번호를 읽으면 빠르게 에러 위치 파악 가능
  • 가장 흔한 에러: 세미콜론 누락(;), 중괄호 누락(})
  • 에러를 직접 만들고 고쳐보면 실수를 줄이는 습관이 생김
  • 여러 에러가 있을 때는 첫 번째 에러부터 순서대로 해결
  • 컴파일 성공 = 에러 0 = 진짜 코더의 자격 획득!
