사칙연산: +, -, *, /

C언어의 기본 산술 연산자를 배웁니다. 정수 나눗셈의 함정(5/2=2!)과 연산 우선순위, 괄호 사용법을 익힙니다.

이 유닛에서 배우는 것

  • C언어의 사칙연산자 +, -, *, /를 사용할 수 있다
  • 정수 나눗셈에서 소수점이 사라지는 이유를 이해한다
  • 연산 우선순위(*, / 먼저, +, - 나중)를 설명할 수 있다
  • 괄호 ()로 연산 순서를 바꿀 수 있다
  • 실수 나눗셈으로 정확한 결과를 얻을 수 있다
  • 0으로 나누기, 오버플로우 같은 흔한 실수를 피할 수 있다

사칙연산의 기본

C언어의 산술 연산자는 수학과 거의 같습니다. 다만 곱하기는 x 대신 *, 나누기는 /를 사용합니다.

#include <stdio.h> int main(void) { int a = 10, b = 3; printf("더하기: %d\n", a + b); // 13 printf("빼기: %d\n", a - b); // 7 printf("곱하기: %d\n", a * b); // 30 printf("나누기: %d\n", a / b); // 3 (!) return 0; }

정수끼리 나누면 소수점이 사라집니다. 10 / 3은 수학에서 3.333...이지만, C에서는 3입니다. 이것이 C언어 초보자가 가장 많이 실수하는 부분입니다.

// 실수 나눗셈: 한 쪽이라도 실수면 OK printf("%.2f\n", 10 / 3.0); // 3.33 printf("%.2f\n", 10.0 / 3); // 3.33 printf("%.2f\n", 10.0 / 3.0); // 3.33

연산 우선순위와 괄호

수학과 마찬가지로 C언어에서도 곱셈/나눗셈이 덧셈/뺄셈보다 먼저 계산됩니다. 순서를 바꾸고 싶으면 괄호를 사용합니다.

// 우선순위 예제 int r1 = 2 + 3 * 4; // 14 (곱셈 먼저) int r2 = (2 + 3) * 4; // 20 (괄호 먼저) int r3 = 10 - 6 / 2; // 7 (나눗셈 먼저: 10-3) int r4 = (10 - 6) / 2; // 2 (괄호 먼저: 4/2) int r5 = ((2 + 3) * 4) - 1; // 19 (중첩 괄호)

흔한 실수와 주의사항

C언어 산술 연산에서 초보자가 자주 빠지는 함정 3가지를 확인해 봅시다.

실수 1 — 0으로 나누기

// 나누기 전에 반드시 0인지 확인! int a = 10, b = 0; if (b != 0) { printf("%d\n", a / b); // 안전 } else { printf("0으로 나눌 수 없습니다!\n"); }

실수 2 — 오버플로우 (너무 큰 수)

// 오버플로우 예시 #include <limits.h> // INT_MAX 사용 printf("%d\n", INT_MAX); // 2147483647 printf("%d\n", INT_MAX + 1); // -2147483648 (오버플로우!)

실수 3 — 정수 나눗셈 순서 주의

// 5/9 * 100 vs 5*100 / 9 int wrong = 5 / 9 * 100; // 0 (5/9=0이 먼저) int correct = 5 * 100 / 9; // 55 (500/9=55, 더 정확) printf("%d %d\n", wrong, correct);

보통
물건 가격과 낸 돈을 입력받아 거스름돈을 500원, 100원, 10원 단위로 출력하세요. /로 동전 개수, %로 나머지를 구합니다.
입력가격: 1300 낸 돈: 2000
출력500원: 1개, 100원: 2개, 10원: 0개
내 답안
힌트 보기
거스름돈 = 낸 돈 - 가격 = 700. 500으로 나누면 1개, 나머지 200. 100으로 나누면 2개, 나머지 0. 10으로 나누면 0개.

int price, paid; scanf("%d %d", &price, &paid); int change = paid - price; // 700 int c500 = change / 500; // 1 change = change % 500; // 200 int c100 = change / 100; // 2 change = change % 100; // 0 int c10 = change / 10; // 0 printf("500원: %d개, 100원: %d개, 10원: %d개\n", c500, c100, c10);
Q5
BMI 계산기 (실수 나눗셈)
보통
키(cm)와 몸무게(kg)를 입력받아 BMI를 소수점 둘째 자리까지 출력하세요. BMI = 몸무게(kg) / (키(m) * 키(m)). 키를 미터로 바꿀 때 실수 나눗셈을 사용해야 합니다.
입력키: 170 몸무게: 65
출력BMI: 22.49
내 답안
힌트 보기
170cm를 미터로: 170 / 100.0 = 1.70. double 타입을 사용하거나 100.0으로 나누세요. BMI = 65 / (1.70 * 1.70) = 22.49.
정답 보기
int h_cm, weight; scanf("%d %d", &h_cm, &weight); double h_m = h_cm / 100.0; // 실수 나눗셈! double bmi = weight / (h_m * h_m); printf("BMI: %.2f\n", bmi);

핵심 요약

  • 사칙연산자: +(더하기), -(빼기), *(곱하기), /(나누기)
  • 정수 / 정수 = 정수 (소수점 버림! 5/2=2)
  • 한 쪽이라도 실수면 실수 결과 (5/2.0=2.5)
  • 우선순위: 괄호 > *, / > +, -
  • 0으로 나누면 프로그램이 죽는다. 반드시 확인!
  • int 범위를 넘으면 오버플로우가 발생한다 (2147483647 + 1 = -2147483648)
  • 정수 나눗셈은 곱셈을 먼저 해야 정확도를 유지할 수 있다 (5*100/9 vs 5/9*100)
