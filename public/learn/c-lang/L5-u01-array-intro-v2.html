배열이란?
— 여러 값을 한 번에 담는 그릇

변수를 여러 개 쓰면 불편합니다. 배열 하나로 같은 종류의 데이터를 깔끔하게 관리하는 방법을 배웁니다.

이 유닛에서 배우는 것

  • 배열이 왜 필요한지 설명할 수 있습니다.
  • int arr[5]; 형태로 배열을 선언할 수 있습니다.
  • 인덱스가 0부터 시작함을 이해하고 원소에 접근할 수 있습니다.
  • 배열이 메모리에 연속으로 저장됨을 설명할 수 있습니다.
  • 인덱스 범위 초과 오류를 피하는 방법을 알 수 있습니다.

변수 여러 개 vs 배열 하나

학생 5명의 점수를 저장해야 한다고 생각해봅시다. 변수를 개별로 선언하면 어떻게 될까요?

배열(Array)을 쓰면 같은 종류의 데이터를 하나의 이름으로 묶어서 관리할 수 있습니다. 학생이 100명이어도 선언 한 줄로 해결됩니다.

배열 선언 문법

배열을 선언할 때는 자료형, 이름, 대괄호 안에 크기를 씁니다.

// 자료형 배열이름 [크기] int score [5]; // 정수 5개를 담는 배열 double height [3]; // 실수 3개를 담는 배열 char name [10]; // 문자 10개를 담는 배열
따라해보세요
1
정수 10개를 담을 수 있는 배열 data를 선언하세요.
int data[10];
정수 10칸짜리 배열이 만들어집니다
2
실수 7개를 담을 배열 temp를 선언하세요.
double temp[7];
실수 7칸짜리 배열이 만들어집니다

배열은 메모리에 연속으로 저장된다

배열의 원소들은 메모리에 빈틈없이 이어서 저장됩니다. int는 4바이트이므로 int 배열 5개는 20바이트를 연속으로 차지합니다.

인덱스는 0부터 시작한다!

배열의 각 원소에 접근할 때 쓰는 번호를 인덱스(index)라고 합니다. C언어의 인덱스는 반드시 0부터 시작합니다. 크기가 5인 배열의 인덱스는 0, 1, 2, 3, 4입니다.

int score[5]; // 크기 5짜리 배열 score[0] = 85; // 첫 번째 원소 (인덱스 0) score[1] = 92; // 두 번째 원소 (인덱스 1) score[2] = 78; // 세 번째 원소 (인덱스 2) score[3] = 95; // 네 번째 원소 (인덱스 3) score[4] = 88; // 다섯 번째 원소 (인덱스 4) printf("%d\n", score[0]); // 85 출력 printf("%d\n", score[4]); // 88 출력
인덱스는 반드시 0부터!

크기가 N인 배열의 유효한 인덱스는 0 이상 N-1 이하입니다. score[5]는 존재하지 않습니다.

인덱스 범위 초과 — 가장 위험한 실수

배열 크기를 벗어난 인덱스를 사용하면 정해지지 않은 메모리를 건드려서 프로그램이 멈추거나 이상하게 동작합니다. C언어는 이걸 자동으로 막아주지 않기 때문에 프로그래머가 직접 주의해야 합니다.

전체 코드: 배열 선언, 값 넣기, 출력

#include <stdio.h> int main() { // 크기 5짜리 정수 배열 선언 int score[5]; // 각 원소에 값 저장 score[0] = 85; score[1] = 92; score[2] = 78; score[3] = 95; score[4] = 88; // 각 원소 출력 printf("1번 학생: %d점\n", score[0]); printf("2번 학생: %d점\n", score[1]); printf("5번 학생: %d점\n", score[4]); return 0; }

핵심 정리

  • 배열은 같은 자료형의 데이터를 연속으로 저장하는 공간이다.
  • 선언: 자료형 배열이름[크기]; — 예: int score[5];
  • 인덱스는 항상 0부터 시작, 마지막 인덱스는 크기-1이다.
  • 배열 원소는 메모리에 연속으로 배치된다 (int 1개 = 4바이트).
  • 인덱스 범위 초과는 컴파일이 되어도 실행 오류를 일으킨다.
