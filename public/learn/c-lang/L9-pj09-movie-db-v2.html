영화 데이터베이스 — 검색과 정렬

Movie 구조체로 영화 정보를 저장하고, 평점순 정렬과 장르/제목 검색 기능을 구현합니다.

프로젝트 목표

  • Movie 구조체(제목/장르/연도/평점)를 정의합니다.
  • 평점 내림차순으로 정렬합니다.
  • 제목에 키워드가 포함된 영화를 검색합니다.
  • 같은 장르의 영화를 모아 출력합니다.

구현 코드

#include <stdio.h> #include <string.h> #define N 5 typedef struct { char title[40]; char genre[15]; int year; float rating; } Movie; void printMovie(const Movie *m) { printf("%-18s %-8s %d %.1f\n", m->title, m->genre, m->year, m->rating); } // 평점 내림차순 정렬 void sortByRating(Movie arr[], int n) { for (int i = 0; i < n - 1; i++) for (int j = 0; j < n - 1 - i; j++) if (arr[j].rating < arr[j+1].rating) { Movie t = arr[j]; arr[j] = arr[j+1]; arr[j+1] = t; } } // 제목 키워드 검색 void searchByTitle(const Movie arr[], int n, const char *kw) { printf("\n검색: \"%s\"\n", kw); int found = 0; for (int i = 0; i < n; i++) if (strstr(arr[i].title, kw)) { printMovie(&arr[i]); found++; } if (!found) printf("결과 없음\n"); } // 장르별 검색 void searchByGenre(const Movie arr[], int n, const char *genre) { printf("\n[%s] 장르:\n", genre); for (int i = 0; i < n; i++) if (strcmp(arr[i].genre, genre) == 0) printMovie(&arr[i]); } int main() { Movie db[N] = { {"인터스텔라", "SF", 2014, 9.2f}, {"기생충", "드라마", 2019, 8.9f}, {"아바타", "SF", 2009, 7.8f}, {"어벤져스", "액션", 2012, 8.5f}, {"라라랜드", "뮤지컬", 2016, 8.1f} }; sortByRating(db, N); printf("=== 평점순 목록 ===\n"); printf("%-18s %-8s %s %s\n", "제목", "장르", "연도", "평점"); for (int i = 0; i < N; i++) printMovie(&db[i]); searchByGenre(db, N, "SF"); searchByTitle(db, N, "라"); return 0; }

도전 과제

도전 과제

  • 특정 연도 이후의 영화만 출력하는 함수를 만들어보세요.
  • 평점 평균을 계산하고, 평균 이상인 영화만 출력해보세요.
  • 연도 오름차순으로 정렬하는 함수를 만들어보세요.

구조 분석

이 프로젝트에서 float 타입 멤버를 포함한 구조체를 비교할 때는 주의가 필요합니다. 부동소수점 비교는 ==가 아닌 대소 비교(<, >)로 해야 합니다.

확인 문제

문제 1
연도 범위 검색
시작 연도와 끝 연도를 받아 그 범위 안에 개봉된 영화를 출력하는 함수 searchByYear(arr, n, start, end)를 작성하세요.
void searchByYear(const Movie arr[], int n, int start, int end) { printf("\n%d~%d년 개봉작:\n", start, end); for (int i = 0; i < n; i++) if (arr[i].year >= start && arr[i].year <= end) printMovie(&arr[i]); }
문제 2
평점 평균 계산
전체 영화의 평점 평균을 계산하고, 평균 이상인 영화만 따로 출력하는 코드를 작성하세요.
문제 3
최고 평점 영화
배열에서 평점이 가장 높은 영화를 찾아 제목과 평점을 출력하는 함수를 작성하세요.
void findTopRated(const Movie arr[], int n) { int best = 0; for (int i = 1; i < n; i++) if (arr[i].rating > arr[best].rating) best = i; printf("최고 평점: %s (%.1f)\n", arr[best].title, arr[best].rating); }
