Project 02

동물 소리 출력기

강아지, 고양이, 소, 개구리 등 다양한 동물의 울음소리를 printf로 출력합니다.

프로젝트 목표

  • 여러 개의 printf로 목록형 출력을 만들 수 있습니다.
  • 출력 형식을 통일해 가독성을 높일 수 있습니다.
  • 5마리 이상의 동물 소리를 출력하는 프로그램을 완성합니다.
  • 자기가 좋아하는 동물을 추가해 프로그램을 확장합니다.
PROJECT 02

동물 소리 패턴 설계하기

모든 줄을 같은 형식으로 출력하면 보기 좋습니다. "동물이 말합니다: 소리" 형식을 사용합니다.

따라해보세요
1
강아지와 고양이 소리를 출력해 보세요.
#include <stdio.h> int main() { printf("강아지가 말합니다: 멍멍!\n"); printf("고양이가 말합니다: 야옹~\n"); return 0; }
두 줄의 동물 소리가 출력됩니다
2
소와 개구리도 추가해 보세요.
printf("소가 말합니다: 음메~\n"); printf("개구리가 말합니다: 개굴개굴\n");
4마리 동물 소리가 출력됩니다
3
제목과 구분선을 추가해 보세요.
printf("=== 동물 소리 모음 ===\n");
출력 위에 제목이 표시됩니다
PROJECT 02

완성 코드

#include <stdio.h> int main() { printf("===== 동물 소리 출력기 =====\n"); printf("\n"); // 빈 줄 printf("강아지가 말합니다: 멍멍!\n"); printf("고양이가 말합니다: 야옹~\n"); printf("소가 말합니다: 음메~\n"); printf("개구리가 말합니다: 개굴개굴\n"); printf("오리가 말합니다: 꽥꽥!\n"); printf("\n"); printf("총 5마리의 동물이 인사했습니다.\n"); printf("===========================\n"); return 0; }
Q1
빈 줄 출력 — 방법은?
쉬움
코드에서 printf("\n");는 어떤 역할을 하나요?
역할____
내 답안
힌트 보기
\n 하나는 줄바꿈 한 번입니다. 내용 없이 \n만 있으면 어떻게 될까요?
정답 보기
빈 줄(공백 줄)을 출력합니다. 단락 구분에 사용합니다.
PROJECT 02

나만의 동물 추가하기

5마리로 부족하다면? 좋아하는 동물을 더 추가해 봅시다.

Q2
돼지 소리 추가하기
쉬움
돼지 소리 "꿀꿀"을 출력하는 printf를 작성하세요.
형식printf("____가 말합니다: ____\n");
내 답안
힌트 보기
앞에서 만든 형식과 똑같이 작성합니다.
정답 보기
printf("돼지가 말합니다: 꿀꿀\n");
Q3
영어 버전 만들기
보통
강아지(dog), 고양이(cat)를 영어로 출력하도록 바꿔보세요.
형식Dog says: Woof!
형식Cat says: Meow~
내 답안
힌트 보기
한국어 문자열을 영어로 바꾸면 됩니다.
정답 보기
printf("Dog says: Woof!\n"); printf("Cat says: Meow~\n");

핵심 요약

  • printf를 반복해서 여러 동물의 소리를 출력한다
  • 같은 형식(패턴)을 쓰면 출력이 통일감 있게 보인다
  • printf("\n"); 로 빈 줄을 넣어 가독성을 높인다
  • 새로운 동물을 추가하려면 printf 한 줄만 추가하면 된다
  • 한국어든 영어든 큰따옴표 안에 자유롭게 쓸 수 있다
