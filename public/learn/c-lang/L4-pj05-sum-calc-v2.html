합계 계산기

0을 입력할 때까지 숫자를 반복 입력받아 합계, 평균, 최대값, 최소값을 한꺼번에 출력하는 통계 계산기를 만들어봅니다.

이 프로젝트에서 배우는 것

  • 0 입력 시 반복을 종료하는 sentinel 값 패턴을 이해합니다.
  • sum += n 으로 숫자를 누적하는 방법을 익힙니다.
  • count 변수로 입력 개수를 세어 평균을 계산합니다.
  • 최대값·최소값을 갱신하는 조건 로직을 구현합니다.
  • continue로 특정 값(음수, 홀수)을 건너뛰는 방법을 익힙니다.

합계 계산기 — 기본 구현

0이 입력될 때까지 계속 숫자를 받아서, 마지막에 합계·평균·최대값·최소값을 한꺼번에 출력합니다.

// 합계 계산기 — 기본 버전 #include <stdio.h> int main() { int n, sum = 0, count = 0; int max, min; int first = 1; // 첫 번째 입력인지 확인하는 플래그 printf("숫자를 입력하세요 (0을 입력하면 종료):\n"); while (1) { printf("입력: "); scanf("%d", &n); if (n == 0) break; // 0 입력 시 종료 sum += n; // 합계 누적 count++; // 개수 카운트 if (first) { max = min = n; // 첫 번째 값으로 초기화 first = 0; } else { if (n > max) max = n; // 최대값 갱신 if (n < min) min = n; // 최소값 갱신 } } if (count == 0) { printf("입력된 숫자가 없습니다.\n"); } else { printf("\n--- 통계 결과 ---\n"); printf("입력 개수: %d개\n", count); printf("합계: %d\n", sum); printf("평균: %.1f\n", (float)sum / count); printf("최대값: %d\n", max); printf("최소값: %d\n", min); } return 0; }

확장 1 — 양수만 합산 & continue 활용

continue는 현재 반복을 건너뛰고 다음 반복으로 넘어갑니다. 음수나 홀수를 무시하고 싶을 때 사용합니다.

// 확장 1: 양수만 합산 (continue 사용) while (1) { printf("입력 (0: 종료): "); scanf("%d", &n); if (n == 0) break; if (n < 0) { printf("음수는 건너뜁니다.\n"); continue; // 아래 코드 실행 안 하고 while 처음으로 } sum += n; count++; } // 확장 2: 짝수만 합산 (% 연산 활용) while (1) { scanf("%d", &n); if (n == 0) break; if (n % 2 != 0) { // 홀수면 건너뜀 printf("%d는 홀수, 건너뜁니다.\n", n); continue; } sum += n; count++; printf("%d 누적됨 (현재 합계: %d)\n", n, sum); }
continue 주의사항
for문에서 continue를 쓰면 for의 증감 부분(i++)은 실행됩니다. while문에서는 continue 전에 카운터를 증가시키지 않으면 무한루프가 될 수 있습니다.

핵심 정리

합계 계산기 핵심 요약

  • sum += n — 매 반복마다 n을 sum에 누적합니다.
  • if (n == 0) break — 0 입력 시 반복을 종료합니다 (sentinel 패턴).
  • if (n > max) max = n — 더 큰 값이 들어오면 최대값을 갱신합니다.
  • (float)sum / count — 정수를 실수로 변환해 소수점 평균을 구합니다.
  • continue — 현재 반복을 건너뛰고 다음으로 넘어갑니다.
