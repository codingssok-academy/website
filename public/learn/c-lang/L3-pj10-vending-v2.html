자판기 시뮬레이터

switch + if-else + 연산을 한 곳에 모아 실제 자판기 동작을 C로 구현합니다.

이 프로젝트에서 배우는 것

  • switch문으로 메뉴 번호를 선택하고 각 음료 가격을 분기할 수 있습니다.
  • if-else로 투입 금액과 가격을 비교해 거스름돈을 계산할 수 있습니다.
  • 배열로 메뉴 5개를 관리하고 재고(stock) 변수를 다룰 수 있습니다.
  • 나머지 연산(%)으로 동전 단위(500원, 100원, 50원, 10원)를 분해할 수 있습니다.
  • switch + if-else + 연산을 하나의 프로그램으로 통합할 수 있습니다.
switch if-else 나머지 연산 % 정수 나누기 / 재고 변수 배열

기본 자판기 — switch + if-else 조합

자판기의 두 가지 핵심 동작은 메뉴 선택과 금액 확인입니다. 메뉴 선택에는 switch, 금액 비교에는 if-else를 씁니다.

1
메뉴 출력 — printf 반복

자판기는 켜지면 메뉴 목록을 먼저 보여줍니다.

printf("=== 자판기 ===\n"); printf("1. 콜라 1200원\n"); printf("2. 사이다 1000원\n"); printf("3. 커피 1500원\n"); printf("번호를 선택하세요: ");
2
번호 선택 — switch문으로 가격 결정

switch는 여러 번호 중 하나를 고를 때 if-else보다 깔끔합니다. 각 case에서 해당 음료의 가격을 price 변수에 담습니다.

int choice, price = 0; scanf("%d", &choice); switch (choice) { case 1: price = 1200; printf("콜라를 선택했습니다.\n"); break; case 2: price = 1000; printf("사이다를 선택했습니다.\n"); break; case 3: price = 1500; printf("커피를 선택했습니다.\n"); break; default: printf("잘못된 번호입니다.\n"); return 0; // 프로그램 종료 }
핵심: break가 없으면 다음 case까지 실행됩니다(fall-through). 반드시 각 case 끝에 break를 씁니다.
3 + 4
금액 입력 → if-else로 거스름돈 계산

투입 금액을 받은 뒤, if로 가격과 비교합니다. 금액이 충분하면 거스름돈을 출력하고, 부족하면 안내 메시지를 냅니다.

int money; printf("금액을 투입하세요: "); scanf("%d", &money); if (money >= price) { int change = money - price; printf("구매 완료! 거스름돈: %d원\n", change); } else { int short_amount = price - money; printf("금액 부족! %d원이 더 필요합니다.\n", short_amount); }

번호를 선택하세요: 3

주의: if (money >= price) — 정확히 같은 금액(money == price)도 구매 가능하므로 >=를 씁니다. 거스름돈은 0원이 됩니다.

확장 — 메뉴 5개 · 동전 분해 · 재고 관리

실제 자판기는 메뉴가 많고, 거스름돈도 동전 단위로 돌려줍니다. 또 재고가 떨어지면 구매가 안 됩니다. 세 가지를 단계별로 확장해봅니다.

확장 1 — 메뉴 5개를 배열로

메뉴가 늘어나면 변수를 5개씩 따로 선언하면 너무 복잡합니다. 배열로 묶으면 깔끔합니다.

// 메뉴 이름 (문자열 배열) char *menu[] = {"콜라", "사이다", "커피", "녹차", "주스"}; // 메뉴 가격 배열 (인덱스 0~4) int price[] = {1200, 1000, 1500, 800, 1300}; // 메뉴 출력 (for문 활용) printf("=== 자판기 ===\n"); for (int i = 0; i < 5; i++) { printf("%d. %-6s %d원\n", i + 1, menu[i], price[i]); }
%-6s: 왼쪽 정렬로 6자리 확보. 메뉴 이름 길이가 달라도 가격 위치가 정렬됩니다.

확장 2 — 거스름돈을 동전 단위로 분해

거스름돈 1,300원을 돌려줄 때 "500원 2개, 100원 3개"처럼 단위를 나누는 방법입니다. 나누기(/)로 개수를, 나머지(%)로 남은 금액을 구합니다.

int change = money - price[choice - 1]; // 거스름돈 printf("거스름돈: %d원\n", change); int c500 = change / 500; change = change % 500; int c100 = change / 100; change = change % 100; int c50 = change / 50; change = change % 50; int c10 = change / 10; printf(" 500원 %d개, 100원 %d개, 50원 %d개, 10원 %d개\n", c500, c100, c50, c10);

확장 3 — 재고(stock) 관리

각 메뉴마다 재고 수량을 저장하는 stock 배열을 추가합니다. 구매 시 재고를 1 줄이고, 0이면 품절 처리합니다.

int stock[] = {5, 3, 4, 6, 2}; // 각 메뉴 재고 수량 int idx = choice - 1; // 배열 인덱스는 0부터 if (stock[idx] == 0) { printf("품절입니다!\n"); } else if (money >= price[idx]) { stock[idx]--; // 재고 1 감소 int change = money - price[idx]; printf("구매 완료! 재고: %d개 남음. 거스름돈: %d원\n", stock[idx], change); } else { printf("금액 부족!\n"); }
배열 인덱스 주의: 사용자가 입력하는 번호는 1~5지만, 배열 인덱스는 0~4입니다. idx = choice - 1로 변환해야 합니다.
Q
확인 문제 — 동전 분해 계산
보통

입력 change = 1750
출력 500원 3개, 100원 2개, 50원 1개, 10원 0개
내 답안
힌트 / 정답 보기
1750 / 500 = 3, 1750 % 500 = 250 → 250 / 100 = 2, 250 % 100 = 50 → 50 / 50 = 1, 50 % 50 = 0
int change = 1750; int c500 = change / 500; change = change % 500; // 3, 250 int c100 = change / 100; change = change % 100; // 2, 50 int c50 = change / 50; change = change % 50; // 1, 0 int c10 = change / 10; // 0 printf("500원 %d개, 100원 %d개, 50원 %d개, 10원 %d개\n", c500, c100, c50, c10);

전체 코드 + 도전 과제

앞에서 배운 switch + if-else + 동전 분해 + 재고 관리를 하나로 합친 완성 코드입니다.

#include <stdio.h> int main() { /* ── 메뉴 데이터 ── */ char *menu[] = {"콜라", "사이다", "커피", "녹차", "주스"}; int price[] = {1200, 1000, 1500, 800, 1300}; int stock[] = {5, 3, 4, 6, 2}; /* ── 메뉴 출력 ── */ printf("=== 자판기 ===\n"); for (int i = 0; i < 5; i++) { printf("%d. %-6s %4d원 (재고: %d)\n", i + 1, menu[i], price[i], stock[i]); } printf("번호를 선택하세요 (1~5): "); /* ── 번호 선택 ── */ int choice; scanf("%d", &choice); if (choice < 1 || choice > 5) { printf("잘못된 번호입니다.\n"); return 0; } int idx = choice - 1; printf("%s를 선택했습니다. 가격: %d원\n", menu[idx], price[idx]); /* ── 재고 확인 ── */ if (stock[idx] == 0) { printf("품절입니다!\n"); return 0; } /* ── 금액 투입 ── */ int money; printf("금액을 투입하세요: "); scanf("%d", &money); /* ── 금액 비교 ── */ if (money >= price[idx]) { stock[idx]--; // 재고 감소 int change = money - price[idx]; // 거스름돈 printf("구매 완료! 재고 %d개 남음.\n", stock[idx]); printf("거스름돈: %d원\n", change); /* ── 동전 분해 ── */ int c500 = change / 500; change %= 500; int c100 = change / 100; change %= 100; int c50 = change / 50; change %= 50; int c10 = change / 10; printf(" 500원 %d개 | 100원 %d개 | 50원 %d개 | 10원 %d개\n", c500, c100, c50, c10); } else { printf("금액 부족! %d원이 더 필요합니다.\n", price[idx] - money); } return 0; }

    전체 품절 감지 — 모든 메뉴의 재고가 0이 되면 "자판기가 비어 있습니다."를 출력하고 프로그램을 종료하는 로직을 추가해보세요.
  • 5
    함수로 분리 (심화) — 메뉴 출력, 금액 비교, 동전 분해 코드를 각각 print_menu(), check_money(), give_change() 함수로 분리해보세요.

핵심 정리

  • switch (choice) — 번호별로 가격을 결정. break 필수.
  • if (money >= price) — 금액 충분 여부 판단. else로 부족 처리.
  • change / 500, change % 500 — 나누기로 개수, 나머지로 남은 금액.
  • stock[idx]-- — 구매 시 재고 1 감소. 0이면 품절.
  • idx = choice - 1 — 사용자 번호(1~5)를 배열 인덱스(0~4)로 변환.
