Chapter L5-07

배열 뒤집기와
복사

배열을 제자리에서 뒤집는 "양끝 swap" 기법과, 원본을 보존하며 복사하는 패턴을 배웁니다. memcpy도 간단히 살펴봅니다.

이 유닛에서 배우는 것

  • 양끝에서 중앙으로 swap하며 배열을 뒤집을 수 있습니다.
  • 홀수/짝수 크기 배열 모두에서 올바르게 동작하는 이유를 이해합니다.
  • for 루프로 배열을 다른 배열에 복사할 수 있습니다.
  • 원본 배열을 보존해야 할 때 복사 패턴을 적용할 수 있습니다.
  • memcpy의 사용법을 이해합니다 (선택 심화).

배열 뒤집기 — 양끝에서 중앙으로

배열을 뒤집으려면 양쪽 끝에서 시작해 중앙을 향해 한 쌍씩 swap합니다. 왼쪽 인덱스(left)와 오른쪽 인덱스(right)가 교차할 때까지 반복합니다.

홀수 크기 배열: left == right가 되면 중앙 원소이므로 swap 불필요 — 조건 left < right가 자동으로 이를 처리합니다.

// 배열 뒤집기 — 양끝 swap int arr[] = {1, 2, 3, 4, 5}; int n = 5; int left = 0; int right = n - 1; while (left < right) { int temp = arr[left]; arr[left] = arr[right]; arr[right] = temp; left++; right--; } // 결과: {5, 4, 3, 2, 1}

배열 복사 — 원본 보존

배열을 수정하기 전에 원본을 보존하고 싶을 때는 새 배열에 복사합니다. 단순히 copy = original은 배열에서 동작하지 않습니다.

// 배열 복사 int arr[] = {7, 3, 9, 1}; int copy[4]; // 같은 크기의 빈 배열 int n = 4; for (int i = 0; i < n; i++) { copy[i] = arr[i]; // 원소 하나씩 복사 } // copy 수정해도 arr 영향 없음 copy[0] = 99; printf("원본: %d\n", arr[0]); // 7 (그대로) printf("복사본: %d\n", copy[0]); // 99

원본 보존이 필요한 상황

정렬, 뒤집기 등 배열을 수정하는 작업 전에 원본을 보존해야 하면 먼저 복사합니다.

// 원본 보존 패턴: 복사 후 수정 int original[] = {5, 2, 8, 1}; int n = 4; int work[4]; for (int i = 0; i < n; i++) work[i] = original[i]; // 복사 // work 배열을 정렬/수정 → original은 안전

memcpy — 라이브러리 복사 함수 (심화)

memcpy는 string.h에 정의된 표준 라이브러리 함수로, 메모리 블록을 바이트 단위로 빠르게 복사합니다.

#include <stdio.h> #include <string.h> // memcpy 사용 int main() { int src[] = {1, 2, 3, 4, 5}; int dest[5]; int n = 5; // for 루프 방법 for (int i = 0; i < n; i++) dest[i] = src[i]; // memcpy 방법 (같은 결과) memcpy(dest, src, n * sizeof(int)); return 0; }

memcpy 주의: 복사할 크기를 sizeof(int)를 곱해 바이트 수로 정확히 계산해야 합니다. 크기를 틀리면 메모리 오류가 발생합니다.

통합 예제 — 복사 후 뒤집기 (원본 보존)

#include <stdio.h> int main() { int original[] = {1, 2, 3, 4, 5}; int n = 5; int work[5]; // ① 복사 for (int i = 0; i < n; i++) work[i] = original[i]; // ② work 배열 뒤집기 int left = 0, right = n - 1; while (left < right) { int t = work[left]; work[left] = work[right]; work[right] = t; left++; right--; } // ③ 결과 출력 printf("원본: "); for (int i = 0; i < n; i++) printf("%d ", original[i]); // 1 2 3 4 5 printf("\n뒤집기: "); for (int i = 0; i < n; i++) printf("%d ", work[i]); // 5 4 3 2 1 return 0; }

핵심 정리

  • 뒤집기: left=0, right=n-1 → swap → left++, right-- → left<right 반복
  • 홀수 크기: left==right일 때 자동 중단 (중앙 원소 이동 불필요)
  • 복사: for로 하나씩 b[i]=a[i] — 배열 직접 대입 불가
  • memcpy: 바이트 단위 복사, 크기는 n*sizeof(타입)
  • 원본 보존 패턴: 복사 → work 수정 → original 안전

오류 찾기 — 뒤집기 경계 조건

아래 코드는 배열을 뒤집으려는 코드인데, 한 가지 오류가 있습니다. 찾아서 고치세요.
int arr[] = {1, 2, 3, 4, 5}, n = 5; int left = 0, right = n; // 오류 위치 while (left < right) { int t = arr[left]; arr[left] = arr[right]; arr[right] = t; left++; right--; }
힌트 / 정답 보기
배열의 마지막 인덱스는 n-1입니다. right = n으로 설정하면 arr[n]에 접근하여 범위 초과가 발생합니다.
int right = n - 1; // n → n-1 로 수정 // arr[n]은 존재하지 않는 인덱스 (경계 초과)
