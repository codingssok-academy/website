암호 해독기

시저 암호(Caesar Cipher)로 char 배열을 +N 이동해 암호화하고, 반대 방향으로 복호화하는 프로그램을 만듭니다.

이 프로젝트에서 배우는 것

  • ASCII 코드를 이용한 문자 변환 방법을 배웁니다.
  • 알파벳 범위를 벗어날 때 wrap-around(순환)를 처리합니다.
  • 암호화와 복호화를 같은 함수로 구현합니다.
  • 시프트 값을 변수로 받아 유연하게 처리합니다.

ASCII와 문자 연산

C언어에서 char는 사실 작은 정수입니다. 'a'는 97, 'z'는 122, 'A'는 65입니다. +3을 하면 3글자 뒤 알파벳이 됩니다.

시저 암호 구현 — wrap-around 처리

'z'에서 +3을 하면 'z'를 넘어버립니다. 나머지 연산(%)으로 알파벳 범위 내에서 순환 처리합니다.

// 시저 암호 — 소문자만 처리 void encrypt(char str[], int shift) { for (int i = 0; str[i] != '\0'; i++) { if (str[i] >= 'a' && str[i] <= 'z') { str[i] = 'a' + (str[i] - 'a' + shift) % 26; } else if (str[i] >= 'A' && str[i] <= 'Z') { str[i] = 'A' + (str[i] - 'A' + shift) % 26; } // 알파벳 아닌 문자(공백, 숫자 등)는 그대로 } } // 복호화: shift 대신 26-shift 사용 void decrypt(char str[], int shift) { encrypt(str, 26 - shift); // 반대 방향 = (26-shift) 앞으로 }

완성 코드

#include <stdio.h> #include <string.h> void caesar(char str[], int shift) { for(int i=0;str[i];i++){ if(str[i]>='a'&&str[i]<='z') str[i]='a'+(str[i]-'a'+shift)%26; else if(str[i]>='A'&&str[i]<='Z') str[i]='A'+(str[i]-'A'+shift)%26; } } int main() { char msg[100]; int shift; printf("메시지: "); scanf("%s", msg); printf("시프트: "); scanf("%d", &shift); printf("원본: %s\n", msg); caesar(msg, shift); printf("암호: %s\n", msg); caesar(msg, 26 - shift); printf("복호: %s\n", msg); return 0; }

핵심 정리

  • char 산술: 'a'=97, 'z'=122, 대문자 'A'=65
  • 암호화 공식: 'a' + (ch-'a'+shift)%26
  • 복호화: shift 대신 26-shift 사용
  • wrap-around: %26으로 z 이후 순환 처리
  • 알파벳 아닌 문자(공백, 숫자)는 변환하지 않음

심화 — ROT13 & 비열 암호

ROT13은 시프트=13인 특수 케이스로, 같은 함수로 암호화와 복호화가 모두 됩니다. shift=13이면 26-13=13으로 동일하기 때문입니다.

// ROT13 — 암호화와 복호화가 동일 void rot13(char str[]) { caesar(str, 13); // shift=13이면 암복호화 동일 }
