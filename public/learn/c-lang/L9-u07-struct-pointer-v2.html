구조체 포인터 — 화살표(->) 연산자

구조체 포인터를 선언하고, 화살표 연산자(->)로 멤버에 접근하는 법을 배웁니다. 동적 할당과의 연결도 이해해봅시다.

이 유닛에서 배우는 것

  • 구조체 포인터를 선언하고 주소를 저장할 수 있습니다.
  • 화살표 연산자(->)로 포인터를 통해 멤버에 접근할 수 있습니다.
  • (*p).멤버와 p->멤버가 동일함을 이해합니다.
  • malloc으로 구조체를 동적 할당할 수 있습니다.
  • 구조체 포인터를 함수 매개변수로 활용할 수 있습니다.

구조체 포인터 선언과 화살표 연산자

구조체 포인터는 Student *sp = &s; 형식으로 선언합니다. 포인터로 멤버에 접근할 때는 -> 연산자를 사용합니다.

typedef struct { char name[20]; int age; float score; } Student; int main() { Student s = {"김민준", 15, 88.5f}; Student *sp = &s; // 포인터에 s의 주소 저장 // 포인터로 멤버 접근: -> 연산자 사용 printf("%s\n", sp->name); // 김민준 printf("%d\n", sp->age); // 15 // (*sp).멤버 와 sp->멤버 는 완전히 동일! sp->age = 16; // 원본 s.age 도 바뀜 printf("%d\n", s.age); // 16 return 0; }

(*p).멤버 vs p->멤버

malloc으로 구조체 동적 할당

malloc을 사용하면 프로그램 실행 중에 구조체 메모리를 할당할 수 있습니다. 반드시 free로 해제해야 합니다.

#include <stdlib.h> // malloc, free int main() { // 동적 할당: 힙 메모리에 Student 공간 생성 Student *sp = (Student *)malloc(sizeof(Student)); if (sp == NULL) { printf("메모리 할당 실패\n"); return 1; } // -> 로 멤버 접근 strcpy(sp->name, "이서연"); sp->age = 16; sp->score = 92.0f; printf("%s %d %.1f\n", sp->name, sp->age, sp->score); free(sp); // 반드시 해제! return 0; }

핵심 정리

핵심 정리

  • 구조체 포인터: Student *sp = &s;
  • 화살표 연산자: sp->멤버 == (*sp).멤버
  • 동적 할당: malloc(sizeof(Student)) — 반드시 free 필요
  • 함수에서 포인터 매개변수로 받으면 원본 수정 가능
