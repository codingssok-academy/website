소수 판별

약수가 1과 자신뿐인 수, 소수를 판별하는 알고리즘을 단계적으로 최적화하며 이해합니다.

이 유닛에서 배우는 것

  • 소수의 정의를 말하고 소수와 합성수를 구분할 수 있습니다.
  • 2부터 n-1까지 나눠보는 기본 소수 판별 알고리즘을 코드로 작성할 수 있습니다.
  • sqrt(n)까지만 확인해도 되는 이유를 설명할 수 있습니다.
  • 최적화된 소수 판별 코드를 작성할 수 있습니다.
  • 에라토스테네스의 체 개념을 이해하고 원리를 설명할 수 있습니다.

소수(Prime Number)란?

소수는 1보다 큰 정수 중에서 약수가 오직 1과 자기 자신뿐인 수입니다. 2, 3, 5, 7, 11, 13 ...이 소수입니다.

기본 소수 판별 알고리즘

소수를 판별하는 가장 직관적인 방법은 2부터 n-1까지 모두 나눠보는 것입니다. 한 번이라도 나누어지면 소수가 아닙니다.

// 기본 소수 판별 — O(n) int n, is_prime = 1; // is_prime=1 이면 소수라고 가정 scanf("%d", &n); if (n < 2) { is_prime = 0; // 2 미만은 소수 아님 } else { for (int i = 2; i <= n - 1; i++) { if (n % i == 0) { // 나누어지면 is_prime = 0; // 소수 아님 break; // 더 볼 필요 없음 } } } if (is_prime) printf("%d는 소수\n", n); else printf("%d는 소수 아님\n", n);

break의 역할 — 조기 종료

break는 한 번이라도 나누어지면 루프를 바로 멈추게 합니다. 6이 소수인지 보면, i=2에서 6%2=0이 되어 즉시 종료합니다. 불필요한 반복을 줄이는 중요한 테크닉입니다.

sqrt(n) 최적화 & 에라토스테네스의 체

왜 sqrt(n)까지만 확인해도 될까?

n의 약수는 반드시 쌍으로 존재합니다. 예를 들어 36 = 6×6이므로, 한쪽이 6보다 크면 나머지 한쪽은 6보다 작습니다. sqrt(36)=6 이하에서 이미 모든 약수가 발견됩니다.

// 최적화 소수 판별 — O(sqrt(n)) #include <math.h> // sqrt() 사용 위해 int n, is_prime = 1; scanf("%d", &n); if (n < 2) { is_prime = 0; } else { for (int i = 2; i * i <= n; i++) { // i*i <= n 이 sqrt(n)과 같음 if (n % i == 0) { is_prime = 0; break; } } } printf("%d: %s\n", n, is_prime ? "소수" : "소수 아님");
i*i <= n 과 i <= sqrt(n) 은 같은 의미
sqrt() 함수를 쓰면 실수 오차가 생길 수 있습니다. i*i <= n 으로 쓰는 것이 더 안전하고 빠릅니다.

에라토스테네스의 체 개념

1부터 100까지 소수를 한꺼번에 구하려면 에라토스테네스의 체를 씁니다. 소수의 배수를 순서대로 지워나가는 방식입니다.

Unit 11 핵심 정리

  • 소수 = 약수가 1과 자신뿐인 수 (1은 소수 아님)
  • 기본 판별: 2 ~ n-1 까지 나눠보기 (O(n))
  • 최적화: 2 ~ sqrt(n) 까지만 (O(sqrt(n))) — i*i <= n 조건 사용
  • 나누어지는 순간 break; 로 조기 종료
  • 에라토스테네스의 체: 소수의 배수를 차례로 지워서 범위 내 소수 한꺼번에 구하기
