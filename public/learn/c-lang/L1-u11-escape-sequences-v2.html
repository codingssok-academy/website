Unit 11

이스케이프 시퀀스

\n \t \\ \" — 특수 문자를 출력하는 방법을 배웁니다.

이 유닛에서 배우는 것

  • 이스케이프 시퀀스가 무엇인지 설명할 수 있습니다.
  • \n으로 줄바꿈, \t로 탭 간격을 만들 수 있습니다.
  • \\로 역슬래시 자체를 출력할 수 있습니다.
  • \"로 문자열 안에 큰따옴표를 출력할 수 있습니다.
  • 이스케이프 시퀀스를 활용해 정렬된 출력을 만들 수 있습니다.

이스케이프 시퀀스란?

이스케이프 시퀀스는 \(역슬래시)로 시작하는 특수 문자 표현입니다. 일반 키보드로 입력하기 어려운 문자나 특별한 동작을 나타냅니다.

// 자주 쓰는 이스케이프 시퀀스 예시 printf("1행\n2행\n"); // \n: 줄바꿈 printf("이름\t나이\n"); // \t: 탭 간격 printf("경로: C:\\Users\n"); // \\: 역슬래시 printf("그는 \"최고\"다\n"); // \": 큰따옴표
따라해보세요
1
\n과 \t를 함께 써서 표를 만드세요.
printf("이름\t나이\t점수\n"); printf("김철수\t14\t95\n"); printf("이영희\t13\t88\n");
탭으로 정렬된 표가 출력됩니다
2
파일 경로를 출력하세요 (역슬래시 포함).
printf("경로: C:\\Program Files\\게임\n");
C:\Program Files\게임

이스케이프 시퀀스 활용

\t를 이용하면 데이터를 열 단위로 정렬해 보기 좋은 출력을 만들 수 있습니다.

// \t로 열 정렬 표 만들기 printf("이름\t나이\t점수\n"); printf("--------\n"); printf("김철수\t14\t95\n"); printf("이영희\t13\t88\n"); printf("박준호\t14\t76\n");

큰따옴표를 문자열 안에서 출력하려면 반드시 \"를 사용해야 합니다.

// \" 사용 — 인용문 출력 printf("선생님: \"잘했어!\"\n"); printf("책 제목: \"C언어의 모든 것\"\n");
따라해보세요
1
\"를 사용해 영화 제목을 인용하세요.
printf("추천 영화: \"인터스텔라\"\n");
추천 영화: "인터스텔라"
2
Windows 파일 경로를 출력하세요.
printf("저장 위치: C:\\Users\\학생\\바탕화면\n");
C:\Users\학생\바탕화면
3
게임 점수표를 탭으로 정렬해 출력하세요.
printf("플레이어\t점수\t등급\n"); printf("PLAYER1\t9800\tS\n"); printf("PLAYER2\t7500\tA\n");
탭 정렬된 게임 점수표가 출력됩니다

핵심 요약

  • 이스케이프 시퀀스는 \로 시작하는 특수 문자 표현이다
  • \n = 줄바꿈, \t = 탭(8칸 정도), \\ = 역슬래시 자체
  • \"는 문자열 안에 큰따옴표를 출력할 때 사용한다
  • \t를 이용하면 데이터를 열 단위로 깔끔하게 정렬할 수 있다
  • 이스케이프 시퀀스는 두 글자지만 실제로는 문자 하나로 처리된다
