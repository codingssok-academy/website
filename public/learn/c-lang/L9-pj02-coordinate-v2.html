좌표 구조체 — 두 점 사이의 거리 계산

Point 구조체로 2D 좌표를 표현하고, 두 점 사이의 유클리드 거리를 계산합니다. math.h의 sqrt를 활용합니다.

프로젝트 목표

  • Point 구조체로 2D 좌표를 표현합니다.
  • 두 점 사이 거리 공식(피타고라스)을 구현합니다.
  • math.h의 sqrt와 pow 함수를 활용합니다.
  • 중점(midpoint) 좌표도 계산합니다.

구현 코드

#include <stdio.h> #include <math.h> // sqrt, pow typedef struct { float x; float y; } Point; float distance(Point a, Point b) { float dx = b.x - a.x; float dy = b.y - a.y; return (float)sqrt(dx*dx + dy*dy); } Point midpoint(Point a, Point b) { Point mid; mid.x = (a.x + b.x) / 2.0f; mid.y = (a.y + b.y) / 2.0f; return mid; } int main() { Point A = {2.0f, 2.0f}; Point B = {8.0f, 4.0f}; printf("A(%.1f, %.1f)\n", A.x, A.y); printf("B(%.1f, %.1f)\n", B.x, B.y); printf("거리: %.2f\n", distance(A, B)); Point mid = midpoint(A, B); printf("중점: (%.1f, %.1f)\n", mid.x, mid.y); return 0; }
실행 결과
실행 결과
A(2.0, 2.0) B(8.0, 4.0) 거리: 6.32 중점: (5.0, 3.0)
