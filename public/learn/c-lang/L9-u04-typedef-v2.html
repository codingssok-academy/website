typedef struct — 타입 별명으로 코드 간결하게

typedef 키워드로 struct에 별명을 붙여 매번 struct를 반복하지 않아도 됩니다. 실무에서 필수로 쓰이는 패턴입니다.

이 유닛에서 배우는 것

  • typedef가 무엇인지 설명할 수 있습니다.
  • 기본 타입에 typedef로 별명을 붙일 수 있습니다.
  • typedef struct로 구조체 타입 이름을 간결하게 만들 수 있습니다.
  • struct 없이 구조체 변수를 선언할 수 있습니다.
  • typedef의 장단점을 이해합니다.

typedef란? — 타입에 별명 붙이기

typedef는 기존 타입에 새 이름(별명)을 붙이는 키워드입니다. 긴 타입명을 짧게 줄이거나, 의미 있는 이름으로 바꿀 때 사용합니다.

// 기본 타입에 별명 붙이기 typedef unsigned int uint; typedef unsigned char byte; typedef long long ll; uint age = 15; byte flag = 1; ll big = 9999999999LL;

typedef struct — struct 없이 선언

구조체에 typedef를 적용하면 매번 struct를 앞에 쓰지 않아도 됩니다. 실무에서 가장 많이 쓰는 패턴입니다.

typedef struct 문법 두 가지

typedef struct는 두 가지 방법으로 작성할 수 있습니다. 둘 다 같은 결과지만, 태그 이름(struct 뒤 이름)이 있느냐 없느냐의 차이가 있습니다.

// 방법 1: 태그 없이 (익명 구조체) typedef struct { char name[20]; int age; float score; } Student; // ← typedef 별명 // 방법 2: 태그 있음 (자기 참조 구조체에 필요) typedef struct _Node { // ← 태그 이름 int data; struct _Node *next; // 자기 자신 참조 시 태그 필요 } Node; // 사용 — struct 없이! Student s1 = {"김민준", 15, 88.5f}; Student s2; strcpy(s2.name, "이서연"); s2.age = 16; s2.score = 91.0f; printf("%s %d %.1f\n", s1.name, s1.age, s1.score); printf("%s %d %.1f\n", s2.name, s2.age, s2.score);

typedef 활용 — 완전한 예제

#include <stdio.h> #include <string.h> typedef struct { char name[20]; int grade; float avg; } Student; void printStudent(Student s) { printf("이름: %-10s | 학년: %d | 평균: %.1f\n", s.name, s.grade, s.avg); } int main() { Student arr[3] = { {"김민준", 2, 88.5f}, {"이서연", 1, 92.0f}, {"박지호", 3, 76.5f} }; for (int i = 0; i < 3; i++) { printStudent(arr[i]); } return 0; }
핵심 정리

핵심 정리

  • typedef 기존타입 새이름; — 타입에 별명을 붙입니다.
  • typedef struct { 멤버들; } 별명; — struct 없이 변수 선언 가능
  • 자기 자신을 참조하는 구조체(링크드 리스트)는 태그 이름이 필요합니다.
  • typedef는 코드 가독성을 높이고 타이핑을 줄여줍니다.

3
typedef vs struct 비교
쉬움
아래 두 코드가 동일한 결과를 내는지 O/X로 답하고 이유를 설명하세요.
Astruct Point { int x; int y; }; struct Point p = {1,2};
Btypedef struct { int x; int y; } Point; Point p = {1,2};
힌트 / 정답 보기
O — 두 코드 모두 동일하게 동작합니다. A는 struct Point라고 써야 하고, B는 Point만 써도 됩니다. 메모리 구조와 멤버 접근 방법은 완전히 동일합니다.
