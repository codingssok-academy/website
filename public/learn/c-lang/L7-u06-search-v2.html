문자열 검색
— strchr와 strstr

문자열 안에서 특정 문자나 부분 문자열을 찾는 strchr, strstr을 배웁니다.

이 유닛에서 배우는 것

  • strchr로 문자열에서 특정 문자를 찾을 수 있습니다.
  • strstr로 문자열 안에서 부분 문자열을 찾을 수 있습니다.
  • 반환값이 NULL이면 찾지 못했음을 처리할 수 있습니다.
  • 포인터 반환값을 통해 위치 정보를 활용할 수 있습니다.
  • 검색 결과로 이메일 @ 기호 위치 찾기 등을 구현합니다.

strchr — 문자 검색

strchr(str, ch)는 문자열 str에서 문자 ch를 처음 발견한 위치(포인터)를 반환합니다. 찾지 못하면 NULL을 반환합니다.

#include <stdio.h> #include <string.h> int main() { char str[] = "Hello World"; char *p; p = strchr(str, 'o'); // 첫 번째 'o' 위치 if (p != NULL) printf("발견: %s\n", p); // "o World" else printf("없음\n"); // 위치(인덱스) 계산 if (p) printf("인덱스: %ld\n", p - str); // 4 return 0; }

strstr — 부분 문자열 검색

strstr(haystack, needle)은 haystack에서 needle 문자열을 처음 발견한 위치를 반환합니다. 없으면 NULL입니다.

#include <stdio.h> #include <string.h> int main() { char text[] = "I love C language"; char *found; found = strstr(text, "C lang"); if (found) printf("찾음: '%s'\n", found); // C language found = strstr(text, "Python"); if (!found) printf("Python 없음\n"); return 0; }

검색 활용 — 이메일 @ 위치 찾기

#include <stdio.h> #include <string.h> int main() { char email[] = "student@school.com"; char *at = strchr(email, '@'); if (at) { // @ 앞부분 (아이디) int id_len = at - email; char id[30]; strncpy(id, email, id_len); id[id_len] = '\0'; printf("아이디: %s\n", id); // @ 뒷부분 (도메인) printf("도메인: %s\n", at+1); } else { printf("유효하지 않은 이메일\n"); } return 0; }

핵심 정리

핵심 요약

  • strchr(s, ch): 문자 ch를 처음 발견한 위치 포인터를 반환합니다.
  • strstr(s, sub): 부분 문자열 sub를 처음 발견한 위치를 반환합니다.
  • 찾지 못하면 NULL을 반환 — NULL 체크 필수!
  • 인덱스 = 반환 포인터 - 원래 배열 시작 주소
  • 이메일 @, 파일 확장자 . 검색 등에 활용합니다.

전체 예제 — URL 파서

#include <stdio.h> #include <string.h> int main() { char url[] = "https://www.school.com/login"; char *colon, *slash; // 프로토콜 추출 (https) colon = strchr(url, ':'); if (colon) { int len = colon - url; char proto[10]; strncpy(proto, url, len); proto[len] = '\0'; printf("프로토콜: %s\n", proto); } // /login 부분 있는지 확인 if (strstr(url, "/login")) printf("로그인 페이지\n"); return 0; }
