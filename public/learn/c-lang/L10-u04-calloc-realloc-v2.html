calloc과 realloc
0초기화와 크기 변경

calloc으로 0으로 초기화된 메모리를 할당하고, realloc으로 이미 할당된 메모리 크기를 바꾸는 방법을 배웁니다.

이 유닛에서 배우는 것

  • calloc의 문법과 malloc과의 차이를 설명합니다.
  • calloc이 0으로 초기화하는 이유를 이해합니다.
  • realloc으로 배열 크기를 늘리거나 줄입니다.
  • realloc 실패 시 원본 메모리를 보호합니다.
  • 세 함수(malloc/calloc/realloc)를 상황에 맞게 선택합니다.

calloc — 0으로 초기화된 메모리 할당

calloc은 "clear allocation"의 줄임말입니다. malloc과 달리 할당한 메모리를 모두 0으로 초기화합니다.

// calloc 문법: calloc(개수, 하나의 크기) int *arr = (int*)calloc(5, sizeof(int)); // 5개, 각 4바이트 if (arr == NULL) { return 1; } // arr[0]~arr[4]가 모두 0으로 초기화됨 for (int i = 0; i < 5; i++) printf("%d ", arr[i]); // 0 0 0 0 0 free(arr); // malloc과 비교 (같은 결과를 내려면 memset 필요) int *arr2 = (int*)malloc(sizeof(int) * 5); memset(arr2, 0, sizeof(int) * 5); // 수동으로 0 초기화 free(arr2);
calloc(n, size) = malloc(n * size) + 0으로 초기화. 문법이 약간 다릅니다: 개수와 크기를 따로 전달합니다.

realloc — 이미 할당된 메모리 크기 변경

realloc은 이미 malloc/calloc으로 할당한 메모리의 크기를 바꿉니다. 기존 데이터는 보존되면서 크기만 변경됩니다.

// realloc 사용법: 안전한 패턴 int *arr = (int*)malloc(sizeof(int) * 3); arr[0]=10; arr[1]=20; arr[2]=30; // 5개로 크기 늘리기 (안전 패턴) int *tmp = (int*)realloc(arr, sizeof(int) * 5); if (tmp == NULL) { free(arr); // 원본 해제 return 1; } arr = tmp; // 성공 시 arr 업데이트 arr[3]=40; arr[4]=50; free(arr);
realloc(arr, 새크기) 에서 arr에 직접 대입하지 말고 임시 포인터(tmp)에 받아야 합니다. 실패 시 NULL 반환 — arr이 NULL이 되면 원본도 잃어버립니다!

연습 문제

1
calloc 문법
쉬움
int 7개를 0으로 초기화하여 동적 할당하는 올바른 코드는?
① calloc(7, int)
② calloc(7, sizeof(int))
③ calloc(sizeof(int), 7, 0)
④ malloc(7, sizeof(int))
힌트 / 정답 보기
정답: ② calloc(개수, 하나의크기) 형태입니다. int *arr = (int*)calloc(7, sizeof(int));
2
malloc vs calloc 차이
쉬움
malloc과 calloc의 가장 큰 차이점은 무엇인가요?
힌트 / 정답 보기
calloc은 할당 후 모든 바이트를 0으로 초기화합니다. malloc은 초기화하지 않아 쓰레기값이 들어있습니다.
3
realloc 안전 패턴
보통
realloc 사용 시 arr = realloc(arr, ...) 처럼 직접 대입하면 안 되는 이유는?
힌트 / 정답 보기
realloc이 실패하면 NULL을 반환합니다. arr = realloc(arr, ...) 처럼 쓰면 실패 시 arr이 NULL이 되어 원본 메모리 주소를 잃어버립니다 (메모리 누수 + 해제 불가). 반드시 임시 포인터에 받아서 NULL 체크 후 교체해야 합니다.
4
realloc 코드 작성
보통
malloc으로 3개 할당 후 realloc으로 6개로 확장하는 안전한 코드를 작성하세요.
힌트 / 정답 보기
int *arr = (int*)malloc(sizeof(int)*3); if (arr == NULL) return 1; arr[0]=1; arr[1]=2; arr[2]=3; int *tmp = (int*)realloc(arr, sizeof(int)*6); if (tmp == NULL) { free(arr); return 1; } arr = tmp; arr[3]=4; arr[4]=5; arr[5]=6; free(arr);
5
calloc으로 성적 초기화
어려움
calloc으로 학생 5명의 점수 배열을 만들고, 실제 값을 입력받아 평균을 출력하세요.
힌트 / 정답 보기
int *scores = (int*)calloc(5, sizeof(int)); if (scores == NULL) return 1; int sum = 0; for (int i=0; i<5; i++) { printf("%d번 점수: ", i+1); scanf("%d", &scores[i]); sum += scores[i]; } printf("평균: %.1f\n", (double)sum/5); free(scores);
핵심 정리

핵심 정리

  • calloc(n, size) — n개×size 바이트, 모두 0으로 초기화
  • malloc vs calloc — 초기화 여부가 핵심 차이
  • realloc(ptr, 새크기) — 기존 데이터 유지하며 크기 변경
  • realloc 안전 패턴 — 임시 포인터에 받아서 NULL 체크 후 교체
