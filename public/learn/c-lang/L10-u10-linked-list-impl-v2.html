연결 리스트 구현
삽입, 삭제, 순회

연결 리스트에 노드를 앞/뒤에 삽입하고, 특정 노드를 삭제하고, 전체를 순회하는 함수를 직접 구현합니다.

이 유닛에서 배우는 것

  • 연결 리스트 앞에 노드를 삽입할 수 있습니다.
  • 연결 리스트 뒤에 노드를 추가할 수 있습니다.
  • 특정 값을 가진 노드를 삭제할 수 있습니다.
  • 리스트 전체를 순회하며 출력합니다.
  • 메모리 누수 없이 전체 리스트를 해제합니다.

앞에 삽입 (prepend)

새 노드를 만들어 기존 head 앞에 연결합니다. 새 노드의 next가 기존 head를 가리키고, head가 새 노드를 가리킵니다.

void prepend(Node **head, int data) { Node *newNode = (Node*)malloc(sizeof(Node)); if (newNode == NULL) return; newNode->data = data; newNode->next = *head; // 새 노드가 기존 head를 가리킴 *head = newNode; // head가 새 노드를 가리킴 }

뒤에 삽입 (append)

void append(Node **head, int data) { Node *newNode = (Node*)malloc(sizeof(Node)); if (newNode == NULL) return; newNode->data = data; newNode->next = NULL; if (*head == NULL) { *head = newNode; return; } Node *curr = *head; while (curr->next != NULL) curr = curr->next; // 끝까지 이동 curr->next = newNode; // 마지막 노드 뒤에 연결 }

삭제 (delete)

void deleteNode(Node **head, int data) { if (*head == NULL) return; // 첫 번째 노드가 대상인 경우 if ((*head)->data == data) { Node *tmp = *head; *head = (*head)->next; free(tmp); return; } // 중간/끝 노드 삭제 Node *curr = *head; while (curr->next != NULL && curr->next->data != data) curr = curr->next; if (curr->next != NULL) { Node *tmp = curr->next; curr->next = tmp->next; // 건너뛰기 free(tmp); } } // 전체 해제 void freeList(Node **head) { Node *curr = *head; while (curr != NULL) { Node *next = curr->next; free(curr); curr = next; } *head = NULL; }

쉬움

② [10] → [20] → [5]

힌트 / 정답 보기
정답: ① prepend는 리스트 앞에 삽입합니다. 5 → 10 → 20 순서가 됩니다.
2
Node** 파라미터
보통
prepend/append에서 Node** 를 파라미터로 받는 이유는?
힌트 / 정답 보기
함수 안에서 head를 바꾸어야 하기 때문입니다. Node* head를 전달하면 지역 복사본이 바뀌고 호출자의 head는 변경되지 않습니다. Node** head를 전달하면 *head = newNode로 실제 head 포인터를 바꿀 수 있습니다.
3
삭제 후 상태
보통
[10] → [20] → [30]에서 deleteNode(20) 후 상태는?
힌트 / 정답 보기
[10] → [30] 20을 담은 노드의 메모리를 free하고 10의 next가 30을 가리키도록 변경합니다.
4
전체 해제 순서
보통
freeList에서 다음 노드 주소를 먼저 저장하고 free하는 이유는?
힌트 / 정답 보기
free(curr) 후에는 curr->next에 접근할 수 없습니다. 따라서 free 전에 next = curr->next를 저장해두고 free(curr) 후 curr = next로 이동합니다.

핵심 정리

핵심 정리

  • prepend — 새 노드가 head를 가리키고, head를 새 노드로 교체
  • append — 끝까지 이동 후 마지막 노드 뒤에 연결
  • delete — 이전 노드의 next를 건너뛰고 free
  • freeList — next 저장 후 free, 전체 순회
  • Node** — 함수에서 head를 바꾸려면 포인터의 포인터 필요
