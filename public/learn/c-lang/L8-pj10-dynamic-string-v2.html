Dynamic String with malloc — First Taste
스택 배열은 크기를 미리 정해야 한다. malloc을 쓰면 실행 중에 필요한 만큼 힙 메모리를 할당할 수 있다.
L8의 마무리로 동적 메모리 배분의 기초를 맛본다. (L9 동적 메모리에서 완전히 다룬다)
난이도 malloc / free 기초 힙 메모리 맛보기 메모리 누수 주의
malloc 기본 원리
완성 코드
dynamic_str.c #include <stdio.h>
#include <stdlib.h> // malloc, free
#include <string.h> // strlen, strcpy

/* 동적으로 문자열 복사본 생성 */
char *my_strdup(const char *src) {
    int len = strlen(src);
    char *copy = (char *)malloc(len + 1); // +1: '\0'
    if (copy == NULL) {
        printf("메모리 할당 실패!\n");
        return NULL;
    }
    strcpy(copy, src);
    return copy;
}

int main() {
    const char *msg = "Hello, Dynamic Memory!";
    
    char *copy = my_strdup(msg);
    if (copy == NULL) return 1;
    
    printf("원본: %s\n", msg);
    printf("복사: %s\n", copy);
    printf("크기: %zu바이트 할당\n", strlen(msg) + 1);
    
    free(copy); // 반드시 해제!
    copy = NULL; // 해제 후 NULL 대입 (안전)
    return 0;
}
$ gcc dynamic_str.c -o dynamic_str && ./dynamic_str
원본: Hello, Dynamic Memory!
복사: Hello, Dynamic Memory!
크기: 23바이트 할당
메모리 누수 주의: malloc으로 할당한 메모리는 프로그램이 종료할 때까지 자동 해제되지 않는다. 반드시 free(p)를 호출해야 한다. free 후 p = NULL을 대입하는 습관을 들이자.
C 메모리 영역 지도
응용: 여러 문자열 동적 배열
multi_str.c #include <stdio.h>
#include <stdlib.h>
#include <string.h>

int main() {
    const char *words[] = {"cat", "elephant", "dog"};
    int n = 3;
    char **copies = (char **)malloc(n * sizeof(char *));
    
    for (int i = 0; i < n; i++) {
        copies[i] = (char *)malloc(strlen(words[i]) + 1);
        strcpy(copies[i], words[i]);
    }
    
    for (int i = 0; i < n; i++) printf("%s\n", copies[i]);
    
    for (int i = 0; i < n; i++) free(copies[i]);
    free(copies);
    return 0;
}

도전 과제

1 동적 정수 배열: 사용자로부터 n을 입력받아 int 배열 n개를 malloc으로 할당하고 1부터 n까지 채운 후 출력. 마지막에 free.

연습문제
1 malloc(strlen(src) + 1)에서 +1을 하는 이유는?
문자열 끝에 null 문자('\0')가 들어갈 공간이 필요하다. strlen은 '\0'을 제외한 길이를 반환하므로 실제 저장에 필요한 바이트는 strlen + 1이다. 예: "Hello"는 strlen=5, 필요 공간=6.
2 malloc이 NULL을 반환할 수 있는 경우는?
시스템 메모리가 부족할 때. 할당 크기가 너무 클 때. NULL 반환 시 역참조하면 세그폴트 발생. 항상 if (ptr == NULL) 체크 후 사용해야 한다.
3 free(p) 후 p = NULL을 대입하는 이유는?
free 후 p는 여전히 해제된 메모리 주소를 가리킨다 (댕글링 포인터). p = NULL을 대입하면 실수로 다시 역참조할 때 즉시 크래시가 발생하여 버그를 쉽게 발견할 수 있다. NULL 확인으로 이미 해제됐는지도 알 수 있다.
4 스택 배열과 힙(malloc) 배열의 생존 범위 차이는?
스택: 함수가 끝나면 자동 해제. 함수 밖으로 주소를 반환하면 안 됨.
힙: free를 호출할 때까지 살아있음. 함수 밖으로 반환 가능. 하지만 free를 직접 관리해야 한다.
5 (char *)malloc(...)에서 (char *) 캐스팅이 필요한가?
순수 C에서는 불필요 (void *가 자동으로 변환). 그러나 C++ 코드에서는 필수. 명시적 캐스팅은 의도를 분명히 하지만, 캐스팅 실수가 오류를 가리는 경우도 있다. C 코드에서는 캐스팅 없이 쓰는 것이 표준적이다.

이번 프로젝트 핵심

  • malloc(n): n바이트 힙 메모리 할당, void * 반환
  • 반드시 NULL 체크 후 사용
  • strlen + 1 = 문자열 저장에 필요한 실제 바이트
  • free(p) 로 해제 필수 — 안 하면 메모리 누수
  • free 후 p = NULL 대입 습관화
