함수 포인터
void (*fp)(int), 콜백 패턴

함수도 메모리 주소를 가집니다. 함수 포인터로 함수를 변수처럼 다루고, 콜백 패턴을 구현합니다.

이 유닛에서 배우는 것

  • 함수 포인터의 선언 형태를 이해합니다: int (*fp)(int, int)
  • 함수 포인터에 함수를 대입하고 호출합니다.
  • 함수 포인터를 매개변수로 전달하는 콜백 패턴을 배웁니다.
  • 함수 포인터 배열로 여러 연산을 선택합니다.
  • qsort의 비교 함수를 함수 포인터로 이해합니다.

함수 포인터 선언 해부

함수도 메모리에 코드로 저장되며 주소를 가집니다. 함수 포인터는 이 주소를 저장합니다.

// 함수 포인터 선언 int (*fp)(int, int); // int를 두 개 받아 int 반환하는 함수를 가리킴 // 함수 두 개 int add(int a, int b) { return a + b; } int sub(int a, int b) { return a - b; } // 대입 및 호출 fp = add; printf("%d\n", fp(3, 4)); // 7 fp = sub; printf("%d\n", fp(10, 3)); // 7

콜백 패턴 — 함수를 매개변수로

함수 포인터를 매개변수로 전달하면 호출 시점에 동작을 선택할 수 있습니다. 이것이 콜백(callback) 패턴입니다.

int add(int a, int b) { return a + b; } int mul(int a, int b) { return a * b; } // 콜백으로 연산 선택 int calc(int x, int y, int (*op)(int, int)) { return op(x, y); // 전달된 함수 호출 } printf("%d\n", calc(3, 4, add)); // 7 printf("%d\n", calc(3, 4, mul)); // 12

함수 포인터 배열

함수 포인터들을 배열로 만들면 인덱스로 함수를 선택할 수 있습니다. 메뉴 구조에 활용합니다.

int add(int a, int b) { return a+b; } int sub(int a, int b) { return a-b; } int mul(int a, int b) { return a*b; } // 함수 포인터 배열 int (*ops[3])(int, int) = {add, sub, mul}; char *names[] = {"더하기", "빼기", "곱하기"}; for (int i=0; i<3; i++) { printf("%s: %d\n", names[i], ops[i](6, 3)); } // 더하기: 9 // 빼기: 3 // 곱하기: 18

qsort — 표준 라이브러리의 함수 포인터

qsort는 비교 함수를 함수 포인터로 받아 정렬합니다. C 표준 라이브러리의 대표적인 콜백 활용입니다.

#include <stdlib.h> // 비교 함수 — 오름차순 int cmp_asc(const void *a, const void *b) { return (*(int*)a) - (*(int*)b); } int main() { int arr[] = {5, 2, 8, 1, 9}; qsort(arr, 5, sizeof(int), cmp_asc); for (int i=0; i<5; i++) printf("%d ", arr[i]); // 1 2 5 8 9 return 0; }

typedef로 함수 포인터 간결하게

함수 포인터 선언은 복잡합니다. typedef로 이름을 붙이면 코드가 훨씬 읽기 쉬워집니다.

// typedef 없이 int (*fp)(int, int); // typedef로 타입 이름 부여 typedef int (*Op)(int, int); Op fp; // 훨씬 간결! Op ops[3]; // 배열도 간결 int calc(int a, int b, Op op) { // 매개변수도 간결 return op(a, b); }
