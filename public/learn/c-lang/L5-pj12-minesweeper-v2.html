지뢰 찾기 맵

5×5 2차원 배열에 지뢰를 랜덤 배치하고, 각 칸 주변 8방향의 지뢰 개수를 계산하여 맵을 완성합니다.

이 프로젝트에서 배우는 것

  • 2차원 배열에 랜덤 지뢰를 배치합니다.
  • 8방향 탐색 배열(dr, dc)을 활용하는 패턴을 익힙니다.
  • 배열 경계 체크로 범위 초과를 방지합니다.
  • 중첩 for문으로 전체 맵을 처리합니다.

지뢰 랜덤 배치

mine 배열에 지뢰 위치를 표시합니다. 0은 일반 칸, 1은 지뢰입니다. 이미 지뢰가 있는 칸은 건너뜁니다.

#include <stdio.h> #include <stdlib.h> #include <time.h> #define N 5 #define MINES 5 int mine[N][N] = {0}; int numMap[N][N] = {0}; srand(time(NULL)); int placed = 0; while (placed < MINES) { int r = rand() % N; int c = rand() % N; if (!mine[r][c]) { mine[r][c] = 1; placed++; } }

8방향 탐색으로 숫자 계산

방향 배열 dr, dc를 사용하면 8방향을 간결하게 탐색할 수 있습니다. 경계 밖은 건너뜁니다.

int dr[] = {-1,-1,-1, 0, 0, 1, 1, 1}; int dc[] = {-1, 0, 1,-1, 1,-1, 0, 1}; for (int r=0;r<N;r++) { for (int c=0;c<N;c++) { if (mine[r][c]) { numMap[r][c]=-1; continue; } int cnt=0; for (int d=0;d<8;d++) { int nr=r+dr[d], nc=c+dc[d]; if(nr>=0&&nr<N&&nc>=0&&nc<N&&mine[nr][nc]) cnt++; } numMap[r][c] = cnt; } }

맵 출력 & 완성 코드

void printMap() { printf("\n=== 지뢰 찾기 맵 ===\n"); for(int r=0;r<N;r++){ for(int c=0;c<N;c++){ if(numMap[r][c]==-1) printf(" * "); else if(numMap[r][c]==0) printf(" . "); else printf("%2d ", numMap[r][c]); } printf("\n"); } }

가장 위험한 칸 찾기
중간
숫자 맵에서 지뢰가 아닌 칸 중 주변 지뢰 수가 가장 많은 칸(가장 위험한 칸)의 위치를 출력하세요.
출력가장 위험한 칸: (1,1) = 3개 지뢰
힌트 보기
numMap에서 -1이 아닌 값 중 최대값 탐색. 최대값을 가진 위치(r,c)를 함께 기록.

핵심 정리

  • 지뢰 배열: mine[N][N], 0=일반, 1=지뢰
  • 8방향 배열: dr[8], dc[8]로 방향 표현
  • 경계 체크: nr>=0 && nr<N && nc>=0 && nc<N
  • 지뢰 칸 숫자: numMap에 -1 저장
  • 지뢰 중복 배치 방지: while + if(!mine[r][c])

심화 — 더 큰 맵 (10×10)

N 상수를 10으로 바꾸면 10×10 맵으로 확장됩니다. #define만 수정하면 됩니다.

// 이 두 줄만 바꾸면 됩니다 #define N 10 // 5 → 10 #define MINES 15 // 5 → 15
