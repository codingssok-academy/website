구구단 출력기

for 반복문으로 원하는 단의 구구단을 깔끔하게 출력하고, 범위 지정·가로 출력·역순까지 확장해봅니다.

이 프로젝트에서 배우는 것

  • for 반복문으로 1부터 9까지 반복하며 곱셈을 출력할 수 있습니다.
  • 변수 i를 곱셈에 직접 사용하는 방법을 익힙니다.
  • 이중 for문으로 2단~9단 전체를 출력할 수 있습니다.
  • 가로 출력(\t, " ")과 역순(i--)을 적용할 수 있습니다.
  • printf 서식 문자(%d)로 깔끔한 정렬 출력을 할 수 있습니다.

구구단 출력기 — 기본 구현

사용자가 단을 입력하면 for 반복문으로 1~9를 순서대로 돌면서 "단 × i = 결과" 형식으로 출력합니다.

// 구구단 출력기 — 기본 버전 #include <stdio.h> int main() { int dan, i; printf("몇 단을 출력할까요? "); scanf("%d", &dan); for (i = 1; i <= 9; i++) { printf("%d × %d = %d\n", dan, i, dan * i); } return 0; }
따라해보세요
1
위 코드를 입력하고 3단을 출력해보세요. 3 × 1 = 3 부터 3 × 9 = 27 까지 나와야 합니다.
3 × 1 = 3, 3 × 2 = 6, ... 3 × 9 = 27
2
for (i = 1; i <= 9; i++)에서 9를 5로 바꾸면 어떻게 출력될까요?
1부터 5까지만 출력됩니다 (5 × i = ...)
3
dan * i 대신 i * dan으로 써도 결과가 같을까요? 확인해보세요.
곱셈은 교환법칙이 성립하므로 결과가 완전히 같습니다
1
5단 전체를 직접 손으로 계산해보기
쉬움
프로그램 실행 전에 5단의 결과를 직접 계산해서 적어보고, 실행 결과와 비교해보세요.
예상 5×1=5, 5×2=10, ... 5×9=45
내 답안

5단: 5, 10, 15, 20, 25, 30, 35, 40, 45 — 5씩 증가하는 패턴입니다.

확장 1 — 범위 지정 (2단~9단 전체 출력)

for문 안에 for문을 넣는 이중 for문을 사용하면 2단부터 9단까지 전체 구구단을 한 번에 출력할 수 있습니다.

// 2단~9단 전체 출력 (이중 for문) #include <stdio.h> int main() { int dan, i; for (dan = 2; dan <= 9; dan++) { printf("\n--- %d단 ---\n", dan); for (i = 1; i <= 9; i++) { printf("%d × %d = %d\n", dan, i, dan * i); } } return 0; }

확장 2 — 가로 출력 & 역순 출력

같은 줄에 탭으로 구분해 가로로 출력하거나, 9부터 1씩 줄여가며 역순 출력하는 버전입니다.

// 가로 출력 — \t(탭)으로 구분 for (i = 1; i <= 9; i++) { printf("%d×%d=%-4d", dan, i, dan * i); // %-4d: 왼쪽 정렬 4칸 if (i % 3 == 0) printf("\n"); // 3개마다 줄바꿈 } // 역순 출력 — i가 9에서 1로 감소 printf("\n--- %d단 역순 ---\n", dan); for (i = 9; i >= 1; i--) { printf("%d × %d = %d\n", dan, i, dan * i); }
%-4d 서식이란?
%-4d는 정수를 4칸 너비로 왼쪽 정렬해서 출력합니다. 숫자 길이가 달라도 항상 같은 너비를 차지해서 표처럼 정렬됩니다. %4d는 오른쪽 정렬입니다.
2

보통

출력 7 × 9 = 63, 7 × 8 = 56, ... 7 × 1 = 7
내 답안
힌트 / 정답 보기
for (i = 9; i >= 1; i--) { printf("%d × %d = %d\n", 7, i, 7 * i); }

핵심 정리

구구단 출력기 핵심 요약

  • for (i=1; i<=9; i++) — 1부터 9까지 정확히 9번 반복합니다.
  • dan * i — 반복마다 i가 바뀌면서 곱셈 결과가 달라집니다.
  • 이중 for문 — 바깥 for(단)가 1번 돌 때 안쪽 for(i)가 9번 돕니다. 총 72번 출력.
  • i--로 역순 출력, %-4d로 정렬된 가로 출력을 만듭니다.
