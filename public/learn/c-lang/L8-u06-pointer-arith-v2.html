Chapter 8 — Unit 06

포인터 산술 연산
p+1은 다음 원소, sizeof만큼 이동

포인터에 숫자를 더하거나 빼면 메모리 주소가 어떻게 이동하는지 배웁니다. *(p+i) == p[i]를 이해합니다.

이 유닛에서 배우는 것

  • 포인터 + 정수가 주소를 어떻게 이동시키는지 이해합니다.
  • sizeof(타입)만큼 주소가 이동함을 계산합니다.
  • *(p+i)와 p[i]가 동일함을 압니다.
  • p++ / p-- 로 포인터를 이동합니다.
  • 두 포인터의 차(ptrdiff)를 이해합니다.

포인터 + 정수 = 주소 이동

포인터에 정수 n을 더하면 n × sizeof(타입) 바이트만큼 주소가 이동합니다. int 포인터라면 1을 더할 때마다 4바이트씩 이동합니다.

int arr[4] = {10, 20, 30, 40}; int *p = arr; // p = 0x1000 printf("%p\n", p); // 0x1000 printf("%p\n", p+1); // 0x1004 (+4바이트) printf("%p\n", p+2); // 0x1008 (+8바이트) printf("%d\n", *(p+2)); // 30

p++ / p-- 포인터 증감

p++는 포인터를 다음 원소로 이동시킵니다. 배열을 순서대로 처리할 때 자주 사용합니다.

int arr[5] = {1, 2, 3, 4, 5}; int *p = arr; // p++로 배열 순회 for (int i = 0; i < 5; i++) { printf("%d ", *p); // 현재 위치 값 출력 p++; // 다음 원소로 이동 } // 출력: 1 2 3 4 5

*(p+i) == p[i] 증명

C언어 컴파일러는 p[i]를 *(p+i)로 변환합니다. 완전히 동일한 연산입니다.

int arr[3] = {100, 200, 300}; int *p = arr; printf("%d\n", arr[1]); // 200 printf("%d\n", *(arr+1)); // 200 printf("%d\n", p[1]); // 200 printf("%d\n", *(p+1)); // 200 printf("%d\n", 1[arr]); // 200 (신기하지만 합법적!)

신기한 C 문법: p[i]는 *(p+i)이고, 덧셈은 교환법칙이 성립하므로 i[p]도 같은 결과입니다! (실제 코드에서는 사용하지 마세요)

두 포인터의 차

같은 배열 내의 두 포인터를 빼면 원소 개수 차이를 알 수 있습니다.

int arr[5] = {1, 2, 3, 4, 5}; int *a = &arr[1]; int *b = &arr[4]; printf("%td\n", b - a); // 3 (원소 3개 차이)

포인터 연산 허용 vs 금지

int arr[5] = {1, 2, 3, 4, 5}; int *p = arr; p + 2; // O — arr[2] 주소 p++; // O — 다음 원소로 p - arr; // O — 현재 인덱스 위치 // 아래는 컴파일 오류 또는 경고 // p * 2; — 포인터 곱셈 불가 // p = 1000; — 숫자 직접 대입 불가

핵심 정리

핵심 정리

  • 포인터 + n → n × sizeof(타입) 바이트 이동
  • int 포인터 +1 → 4바이트, char 포인터 +1 → 1바이트
  • *(p+i) == p[i] — 완전히 동일한 표현
  • p++ : 다음 원소로 이동 (배열 순회에 활용)
  • 두 포인터 차: 원소 개수 차이 반환
