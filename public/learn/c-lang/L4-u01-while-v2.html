while문 —
조건이 참인 동안 반복

같은 작업을 여러 번 반복할 때, while문 하나로 해결합니다. 조건을 체크하고 참이면 계속, 거짓이면 멈춥니다.

이 유닛에서 배우는 것

  • while문이 무엇인지, 왜 필요한지 설명할 수 있습니다.
  • while문의 기본 문법 구조를 작성할 수 있습니다.
  • 카운트다운, 합계 누적 등 다양한 상황에 while을 쓸 수 있습니다.
  • 무한루프가 생기는 원인을 알고 예방할 수 있습니다.
  • 변수 갱신의 중요성을 이해하고 적용할 수 있습니다.

while문 — 조건이 참인 동안 계속 반복

배가 고프면 계속 먹습니다. 배가 부르면 멈춥니다. while문도 똑같습니다. 조건이 참인 동안 안쪽 코드를 계속 실행하고, 거짓이 되면 멈춥니다.

while문 문법 구조를 살펴봅니다. 각 부분이 어떤 역할인지 확인하세요.

1부터 5까지 숫자를 출력하는 가장 기본적인 while문입니다.

#include <stdio.h> int main() { int i = 1; // 초기값: i를 1로 시작 while (i <= 5) { // 조건: i가 5 이하인 동안 반복 printf("%d\n", i); // 실행: 현재 i 출력 i++; // 갱신: i를 1씩 증가 } return 0; }
따라해보세요
1
1부터 3까지 출력하는 while문을 작성해보세요. 조건을 i <= 3으로 바꾸면 됩니다.
int i = 1; while (i <= 3) { printf("%d\n", i); i++; }
1, 2, 3 이 각 줄에 출력됩니다
2
2, 4, 6, 8, 10을 출력하는 while문을 작성해보세요. i += 2를 사용합니다.
int i = 2; while (i <= 10) { printf("%d\n", i); i += 2; }
2, 4, 6, 8, 10 출력
3
"반복중입니다"를 정확히 4번 출력하는 while문을 작성해보세요.
int i = 1; while (i <= 4) { printf("반복중입니다\n"); i++; }
"반복중입니다" 4줄 출력

while 활용 — 카운트다운, 합계 누적, 입력 반복

카운트다운 (i--) — i를 1씩 줄여가면서 0에 도달하면 멈춥니다.

int i = 5; while (i > 0) { printf("%d!\n", i); i--; // i를 1씩 감소 (5→4→3→2→1) } printf("발사!\n");
따라해보세요
1
10부터 1까지 역순으로 출력하는 while문을 작성해보세요.
int i = 10; while (i >= 1) { printf("%d\n", i); i--; }
10, 9, 8, ... 1 역순 출력

합계 누적 (sum += i) — 반복마다 sum에 i를 더해 1+2+3+4+5를 계산합니다.

int i = 1, sum = 0; while (i <= 5) { sum += i; // sum = sum + i (누적 덧셈) i++; } printf("합계: %d\n", sum); // 합계: 15
따라해보세요
2
1부터 10까지 합계를 구해 출력해보세요. (i <= 10으로 변경)
int i = 1, sum = 0; while (i <= 10) { sum += i; i++; } printf("합계: %d\n", sum);
합계: 55 출력

사용자 입력까지 반복 (while(input != 0)) — 0을 입력할 때까지 계속 입력받습니다.

int input; scanf("%d", &input); // 첫 번째 입력 while (input != 0) { // 0이 아닌 동안 반복 printf("입력값: %d\n", input); scanf("%d", &input); // 다음 입력 } printf("종료!\n");
따라해보세요
3
-1을 입력할 때까지 숫자를 계속 입력받는 while문을 작성해보세요. 조건을 input != -1로 바꿉니다.
int input; scanf("%d", &input); while (input != -1) { printf("입력: %d\n", input); scanf("%d", &input); }
-1 전까지 계속 입력받고 출력

주의사항 — 무한루프와 초기값 설정

while문에서 가장 흔한 실수는 무한루프입니다. 조건이 절대 거짓이 되지 않으면 프로그램이 영원히 멈추지 않습니다.

무한루프 (잘못된 예)
int i = 1; while (i >= 1) { printf("%d\n", i); // i++ 빠짐! }
정상 동작 (올바른 예)
int i = 1; while (i <= 5) { printf("%d\n", i); i++; // 반드시 갱신 }
무한루프 3가지 원인

1. 변수 갱신 코드(i++, i--)를 깜빡 빠뜨린 경우
2. 조건이 절대 거짓이 될 수 없는 경우 (예: while(1))
3. 갱신 방향이 반대인 경우 (조건: i <= 5인데 갱신이 i--)

초기값 설정이 잘못되면 반복이 아예 실행되지 않거나, 의도와 다른 결과가 나옵니다.

따라해보세요
1
아래 코드에서 무한루프 원인을 찾아 고쳐보세요.
// 문제 코드 int i = 1; while (i <= 5) { printf("%d\n", i); // i++ 빠짐 } // 수정 후 int i = 1; while (i <= 5) { printf("%d\n", i); i++; // 추가! }
i++ 추가로 무한루프 해결
2
아래에서 1~5를 출력하려는 의도로 만든 코드의 문제를 찾아 고쳐보세요.
// 문제 코드 (i가 5부터 시작, while i <= 5) int i = 5; while (i <= 5) { printf("%d\n", i); i++; } // 수정: 초기값을 1로 int i = 1; while (i <= 5) { printf("%d\n", i); i++; }
초기값 1로 고치면 1~5 정상 출력
3
갱신 방향이 반대인 코드를 고쳐보세요. (while(i <= 5)인데 i--를 쓰는 경우)
// 문제: i가 줄어들면 조건 항상 참 int i = 1; while (i <= 5) { printf("%d\n", i); i--; // 잘못된 방향 → 무한루프 } // 수정 i++; // i-- 를 i++ 로 변경
i-- 를 i++ 로 바꾸면 정상

힌트 / 정답 보기
힌트: sum = 0으로 시작, sum += i로 누적
int n, i = 1, sum = 0; scanf("%d", &n); while (i <= n) { sum += i; i++; } printf("1부터 %d까지의 합: %d\n", n, sum);

보통

입력 3

내 답안
힌트 / 정답 보기
힌트: i = n으로 시작, i > 0 조건, i-- 감소
int n; scanf("%d", &n); int i = n; while (i > 0) { printf("%d!\n", i); i--; } printf("발사!\n");
5
숫자 입력 합산 (0 입력 시 종료)
보통
0을 입력할 때까지 숫자를 계속 입력받아, 입력된 숫자들의 합계를 마지막에 출력하는 프로그램을 작성하세요. 0은 합산에 포함하지 않습니다.

출력 합계: 12
내 답안
힌트 / 정답 보기

int input, sum = 0; scanf("%d", &input); while (input != 0) { sum += input; scanf("%d", &input); } printf("합계: %d\n", sum);

핵심 요약

  • while (조건) { } — 조건이 참인 동안 중괄호 안 코드를 반복 실행
  • 조건 검사 → 실행 → 갱신 → 다시 조건 검사 순서로 동작
  • i++ : 1씩 증가 카운트업 / i-- : 1씩 감소 카운트다운
  • sum += i : 반복마다 값을 누적해 합계 계산
  • while(input != 0) : 특정 값 입력 전까지 계속 입력 반복
  • 변수 갱신 코드를 빠뜨리면 무한루프 — 반드시 i++ 또는 i-- 작성
  • 초기값을 잘못 설정하면 반복이 아예 실행되지 않을 수 있음
