배열을 함수에 전달 — 원본이 바뀐다!

배열을 함수에 전달하면 일반 변수와 다르게 원본이 수정됩니다. arr[]과 size를 같이 전달하는 패턴을 익힙니다.

이 유닛에서 배우는 것

  • 배열을 매개변수로 선언하는 방법을 압니다.
  • 배열과 크기(size)를 함께 전달해야 하는 이유를 이해합니다.
  • 함수 안에서 배열을 수정하면 원본도 변함을 이해합니다.
  • 배열 합계, 최대값 구하는 함수를 작성합니다.
  • 배열 출력 함수를 만들 수 있습니다.

배열 매개변수 선언법

배열을 함수에 전달할 때는 int arr[]처럼 대괄호를 씁니다. 배열 크기는 자동으로 알 수 없어서 크기를 나타내는 변수 size도 같이 전달해야 합니다.

// 배열을 받는 함수 — arr[]과 size 같이 전달 void printArray(int arr[], int size) { for (int i = 0; i < size; i++) { printf("%d ", arr[i]); } printf("\n"); } int main() { int scores[] = {90, 85, 92, 78, 88}; int len = 5; printArray(scores, len); // 90 85 92 78 88 return 0; }

함수 안에서 배열을 수정하면 원본이 변한다

일반 변수는 복사본이 전달되지만, 배열은 주소가 전달됩니다. 그래서 함수 안에서 배열 값을 바꾸면 원본도 바뀝니다.

배열 합계와 최대값 함수

#include <stdio.h> // 배열 합계 int sumArray(int arr[], int size) { int total = 0; for (int i = 0; i < size; i++) { total += arr[i]; } return total; } // 최대값 int maxArray(int arr[], int size) { int max = arr[0]; for (int i = 1; i < size; i++) { if (arr[i] > max) max = arr[i]; } return max; } int main() { int scores[] = {80, 95, 72, 88, 91}; int n = 5; printf("합계: %d\n", sumArray(scores, n)); // 426 printf("최대: %d\n", maxArray(scores, n)); // 95 return 0; }

핵심 요약

  • 배열 매개변수: int arr[], int size 처럼 크기와 함께 전달.
  • 배열은 주소가 전달되므로 함수 안에서 수정하면 원본도 변합니다.
  • 일반 변수(call by value)와 다르게 배열은 원본이 바뀝니다.
  • 함수 안에서 배열 크기를 알 수 없으므로 size 매개변수가 필수입니다.
  • 합계, 평균, 최대/최솟값 등 배열 연산 함수를 만들 수 있습니다.
