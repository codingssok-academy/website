논리 연산자
— &&, ||, !

조건 여러 개를 연결하거나 뒤집는 논리 연산자를 배웁니다. 실생활 판단 논리를 코드로 표현해봅시다.

이 유닛에서 배우는 것

  • && (AND) 연산자로 두 조건을 동시에 검사할 수 있습니다.
  • || (OR) 연산자로 두 조건 중 하나라도 참인지 확인할 수 있습니다.
  • ! (NOT) 연산자로 조건의 참/거짓을 뒤집을 수 있습니다.
  • 논리 연산자의 우선순위를 이해하고 복합 조건을 작성할 수 있습니다.
  • 드모르간 법칙으로 논리식을 변환하는 개념을 알 수 있습니다.

&& (AND) 연산자 — 둘 다 참이어야 참

&& 연산자는 두 조건이 모두 참일 때만 전체가 참이 됩니다. 하나라도 거짓이면 결과는 거짓입니다.

&& 진리표 — 4가지 경우를 모두 확인해보세요.

가장 흔한 용도는 범위 판별입니다. 점수가 0 이상이면서 동시에 100 이하인지 확인할 때 &&를 씁니다.

int score = 85; // 점수가 유효한 범위(0~100)인지 확인 if (score >= 0 && score <= 100) { printf("유효한 점수입니다.\n"); } else { printf("잘못된 점수입니다.\n"); } // 나이가 18세 이상이고 돈이 10000원 이상인지 확인 int age = 20, money = 15000; if (age >= 18 && money >= 10000) { printf("입장 가능!\n"); }
따라해보세요
1
변수 temp가 0 이상이고 40 이하이면 "정상 체온 범위"를 출력하세요.
int temp = 36; if (temp >= 0 && temp <= 40) { printf("정상 체온 범위\n"); }
정상 체온 범위 가 출력됩니다
2
성적 grade가 90 이상이고 attendance가 80 이상이면 "장학금 대상"을 출력하세요.
int grade = 92, attendance = 85; if (grade >= 90 && attendance >= 80) { printf("장학금 대상\n"); }
장학금 대상 이 출력됩니다
3
x가 10보다 크고 20보다 작은 경우 "10과 20 사이"를 출력하세요. x = 15로 테스트하세요.
int x = 15; if (x > 10 && x < 20) { printf("10과 20 사이\n"); }
10과 20 사이 가 출력됩니다

|| (OR) 연산자 — 하나라도 참이면 참

|| 연산자는 두 조건 중 하나라도 참이면 전체가 참이 됩니다. 둘 다 거짓일 때만 결과가 거짓입니다.

|| 진리표 — 4가지 경우를 모두 확인해보세요.

&& vs || 한눈에 비교

int day = 6; // 6=토요일, 7=일요일 // 주말 판별: 토요일이거나 일요일이면 쉬는 날 if (day == 6 || day == 7) { printf("쉬는 날입니다!\n"); } else { printf("평일입니다.\n"); } // 학점이 A이거나 B이면 통과 char grade = 'A'; if (grade == 'A' || grade == 'B') { printf("통과!\n"); }
따라해보세요
1
변수 month가 6, 7, 8 중 하나이면 "여름방학"을 출력하세요. month = 7로 테스트.
int month = 7; if (month == 6 || month == 7 || month == 8) { printf("여름방학\n"); }
여름방학 이 출력됩니다
2
점수 score가 0 미만이거나 100 초과이면 "잘못된 점수"를 출력하세요.
int score = -5; if (score < 0 || score > 100) { printf("잘못된 점수\n"); }
잘못된 점수 가 출력됩니다
3
변수 color가 1(빨강)이거나 2(파랑)이면 "기본 색상"을 출력하세요.
int color = 2; if (color == 1 || color == 2) { printf("기본 색상\n"); }
기본 색상 이 출력됩니다

! (NOT) 연산자 — 참과 거짓을 뒤집기

! 연산자는 단항 연산자로, 참이면 거짓으로, 거짓이면 참으로 뒤집습니다. 조건 앞에 붙여서 사용합니다.

int isRaining = 1; // 1 = 참 (비가 온다) if (!isRaining) { // 비가 안 온다면 printf("우산 없어도 됩니다.\n"); } else { printf("우산 챙기세요!\n"); // 이 줄이 실행됨 } int isLoggedIn = 0; // 0 = 거짓 (로그인 안 됨) if (!isLoggedIn) { printf("로그인이 필요합니다.\n"); // 실행됨 }

우선순위 — ! > && > ||

세 연산자가 함께 있을 때는 !가 가장 먼저, &&가 그 다음, ||가 마지막으로 계산됩니다.

드모르간 법칙 — 논리식 변환

조건을 뒤집는 패턴에서 자주 등장합니다. 괄호 안에 !를 넣으면 연산자가 바뀝니다.

// 우선순위 예시: !A || B && C → (!A) || (B && C) int A = 0, B = 1, C = 1; int result = !A || B && C; // !0 || (1 && 1) = 1 || 1 = 1 (참) // 드모르간 법칙 활용 int x = 5, y = 10; // 아래 두 조건은 동일합니다 if (!(x == 5 && y == 10)) { } // 방법 1 if (x != 5 || y != 10) { } // 방법 2 (드모르간)
따라해보세요
1
변수 isOpen이 0(닫힘)일 때 "문이 닫혀 있습니다"를 출력하세요.
int isOpen = 0; if (!isOpen) { printf("문이 닫혀 있습니다\n"); }
문이 닫혀 있습니다 가 출력됩니다
2
다음 식의 계산 순서를 따라가 보세요: !0 && 1 || 0
// 단계별 계산: // 1단계: !0 → 1 (NOT 먼저) // 2단계: 1 && 1 → 1 (&& 다음) // 3단계: 1 || 0 → 1 (|| 마지막) int result = !0 && 1 || 0; printf("%d\n", result); // 1 출력
1 이 출력됩니다
3
!(a == 1 && b == 2)를 드모르간 법칙으로 바꿔 쓰고, a=1, b=3으로 테스트하세요.
int a = 1, b = 3; // 원본 if (!(a == 1 && b == 2)) printf("변환전: 참\n"); // 드모르간 적용 if (a != 1 || b != 2) printf("변환후: 참\n");
둘 다 "참"이 출력됩니다 — 결과가 동일합니다

보통

int age = 16; if (age ___ 14 ___ age ___ 19) { printf("중학생 또는 고등학생\n"); } else { printf("해당 없음\n"); }
내 답안
정답 보기
int age = 16; if (age >= 14 && age <= 19) { printf("중학생 또는 고등학생\n"); } else { printf("해당 없음\n"); }
14 이상이면서 동시에 19 이하 → && 사용. 범위 판별은 항상 &&

보통

int a = 5, b = 3, c = 0; if (a > b || c) { printf("A\n"); } if (a > b && c) { printf("B\n"); } if (!(a == b)) { printf("C\n"); }
출력 결과를 써보세요:
_____________________
내 답안
정답 보기
출력: A 와 C
- a > b || c: 5>3=참, c=0=거짓 → 참||거짓=참 → A 출력
- a > b && c: 참&&거짓=거짓 → B 미출력
- !(a == b): a!=b이므로 a==b는 거짓 → !거짓=참 → C 출력

놀이기구 탑승 조건 (키 AND 나이)
보통
롤러코스터를 타려면 키가 140cm 이상이고 나이가 10세 이상이어야 합니다. 아래 코드를 완성하여 탑승 가능 여부를 출력하세요.
입력 1 height = 145, age = 12 → 탑승 가능!
입력 2 height = 135, age = 13 → 키가 부족합니다.
입력 3 height = 150, age = 8 → 나이가 부족합니다.
int height = 145, age = 12; /* 여기에 if-else if-else 조건문을 작성하세요 */
내 답안
정답 보기
int height = 145, age = 12; if (height >= 140 && age >= 10) { printf("탑승 가능!\n"); } else if (height < 140) { printf("키가 부족합니다.\n"); } else { printf("나이가 부족합니다.\n"); }
두 조건을 동시에 만족해야 하므로 &&. 실패 원인을 세분화할 때 else if 활용.
5
복합 논리 수식 분석
어려움
아래 조건이 주어졌을 때, 각 변수 값을 대입하여 최종 결과를 단계별로 구하세요.
int a = 1, b = 0, c = 1, d = 0; int result = !a || b && c || !d;
계산 단계를 순서대로 채워보세요 (우선순위: ! > && > ||):
1단계: !a = ____ , !d = ____
2단계: b && c = ____
3단계: ____ || ____ || ____ = ____
내 답안
정답 보기
1단계: !a = !1 = 0,  !d = !0 = 1
2단계: b && c = 0 && 1 = 0
3단계: 0 || 0 || 1 = 1 (참)

식 전체: (!a) || (b && c) || (!d) = 0 || 0 || 1 = 1
int a=1, b=0, c=1, d=0; // !a=0, b&&c=0, !d=1 int result = !a || b && c || !d; printf("%d\n", result); // 출력: 1

핵심 정리

  • && (AND): 두 조건이 모두 참일 때만 참. 범위 판별에 주로 사용.
  • || (OR): 두 조건 중 하나라도 참이면 참. 여러 선택지 중 하나 확인에 사용.
  • ! (NOT): 참이면 거짓, 거짓이면 참으로 뒤집기. 단항 연산자.
  • 우선순위: ! (1순위) > && (2순위) > || (3순위).
  • 드모르간: !(A && B) = !A || !B,  !(A || B) = !A && !B
