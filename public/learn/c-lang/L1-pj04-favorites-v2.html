좋아하는 것 모음

좋아하는 음식, 영화, 게임 리스트를 섹션별로 분류해서 출력합니다.

프로젝트 목표

  • 섹션 제목과 번호 목록을 출력할 수 있습니다.
  • 3개 이상의 카테고리를 만들어 출력합니다.
  • 자기 취향으로 내용을 완전히 바꿀 수 있습니다.
  • 출력 형식을 자유롭게 꾸밀 수 있습니다.
PROJECT 04

섹션 구조 설계하기

목록을 섹션(카테고리)별로 나누면 훨씬 보기 좋습니다. [섹션 이름] 형식으로 제목을 만듭니다.

따라해보세요
1
음식 섹션을 만들어보세요.
#include <stdio.h> int main() { printf("[좋아하는 음식]\n"); printf("1. 떡볶이\n"); printf("2. 피자\n"); printf("3. 라면\n"); return 0; }
음식 섹션이 출력됩니다
2
빈 줄로 섹션을 구분해 보세요.
printf("\n"); // 섹션 사이 빈 줄 printf("[좋아하는 게임]\n");
섹션 사이에 빈 줄이 생깁니다
3
전체 제목을 추가해 보세요.
printf("=== 내가 좋아하는 것들 ===\n\n");
전체 제목이 맨 위에 나타납니다
PROJECT 04

완성 코드

#include <stdio.h> int main() { printf("===== 내가 좋아하는 것들 =====\n\n"); printf("[좋아하는 음식]\n"); printf("1. 떡볶이\n"); printf("2. 피자\n"); printf("3. 라면\n"); printf("\n"); printf("[좋아하는 영화]\n"); printf("1. 어벤져스\n"); printf("2. 인터스텔라\n"); printf("3. 해리포터\n"); printf("\n"); printf("[좋아하는 게임]\n"); printf("1. 마인크래프트\n"); printf("2. 리그오브레전드\n"); printf("3. 배틀그라운드\n"); return 0; }
Q1
섹션 추가하기
쉬움
"좋아하는 과목" 섹션을 만들고 3개의 과목을 추가하세요.
예시[좋아하는 과목] / 1. 수학 / 2. 체육 / 3. 미술
내 답안
힌트 보기
앞의 섹션과 완전히 같은 패턴입니다. 제목과 내용만 바꾸세요.
정답 보기
printf("[좋아하는 과목]\n"); printf("1. 수학\n"); printf("2. 체육\n"); printf("3. 미술\n");
PROJECT 04

나만의 취향으로 채우기

코드의 문자열 내용을 자기 취향으로 바꿔봅시다. 더 많은 카테고리를 추가해도 좋습니다.

Q2
나만의 섹션 제목 스타일 만들기
쉬움
"좋아하는 음악"을 세 가지 스타일로 출력하세요.
①[좋아하는 음악]
②-- 좋아하는 음악 --
③*** 좋아하는 음악 ***
내 답안
힌트 보기
printf의 문자열 안 내용만 바꾸면 됩니다.
정답 보기
printf("[좋아하는 음악]\n"); printf("-- 좋아하는 음악 --\n"); printf("*** 좋아하는 음악 ***\n");
Q3
총 개수 출력하기
보통
3개 카테고리, 각 3개 항목일 때 "총 9개의 항목"을 마지막에 출력하세요.
출력총 9개의 항목이 있습니다.
내 답안
힌트 보기
3 x 3 = 9. 직접 계산한 숫자를 문자열에 넣으면 됩니다.
정답 보기
printf("총 9개의 항목이 있습니다.\n");

핵심 요약

  • 섹션 제목은 [이름], -- 이름 -- 등 원하는 스타일로 표현
  • 번호 목록: "1. 항목\n", "2. 항목\n" 형식
  • printf("\n"); 로 섹션 사이 빈 줄 추가
  • 카테고리 추가 = 새 섹션 블록 복사 후 내용 수정
  • 문자열 내용만 바꾸면 어떤 목록이든 만들 수 있다
