메뉴 시스템

무한 루프(while(1))와 switch문을 조합해 반복적으로 메뉴를 표시하는 프로그램을 만듭니다. 실제 프로그램의 기본 뼈대입니다.

이 프로젝트에서 배우는 것

  • while(1) 무한 루프를 이용해 반복 실행하는 구조를 만들 수 있습니다.
  • switch-case 문으로 메뉴 번호에 따라 다른 동작을 구현할 수 있습니다.
  • break 문으로 루프를 빠져나가 프로그램을 종료하는 법을 배웁니다.
  • 작업 카운터, 확인 메시지, 하위 메뉴 등 확장 기법을 익힙니다.

메뉴 시스템 — 기본 구조

무한 루프로 프로그램이 계속 실행되게 하고, switch문으로 사용자 입력에 따라 다른 동작을 수행합니다. 0을 입력하면 break로 루프를 탈출해 종료합니다.

// 기본 메뉴 시스템 int choice; while (1) { // 무한 루프 printf("=== 메뉴 ===\n"); printf("1. 할 일 추가\n"); printf("2. 목록 보기\n"); printf("3. 삭제\n"); printf("0. 종료\n"); printf("선택: "); scanf("%d", &choice); switch (choice) { case 1: printf("[추가] 할 일을 입력하세요.\n"); break; case 2: printf("[목록] 저장된 항목을 표시합니다.\n"); break; case 3: printf("[삭제] 삭제할 번호를 입력하세요.\n"); break; case 0: printf("프로그램을 종료합니다.\n"); return 0; // while 탈출 default: printf("잘못된 입력입니다.\n"); } printf("\n"); }
주의: switch 안의 break vs 루프 탈출

case 안의 break는 switch만 빠져나옵니다. while 루프를 탈출하려면 return 0이나 별도 변수(flag)를 써야 합니다.

확장 1 — 작업 카운터

메뉴를 선택할 때마다 카운터 변수를 증가시켜, 총 몇 번 작업했는지 기록합니다. 변수 하나만 추가하면 됩니다.

// 작업 카운터 추가 int choice, count = 0; // count: 작업 횟수 while (1) { /* 메뉴 출력 생략 */ scanf("%d", &choice); switch (choice) { case 1: count++; // 작업할 때마다 +1 printf("[추가] 완료 (총 %d회)\n", count); break; case 0: printf("총 %d회 작업 후 종료합니다.\n", count); return 0; } }

확장 2 — 종료 확인 메시지

0을 눌렀을 때 바로 종료하지 않고, "정말 종료하시겠습니까? (1=예/0=아니오)" 를 한 번 더 물어봅니다.

case 0: { int confirm; printf("정말 종료? (1=예 / 0=아니오): "); scanf("%d", &confirm); if (confirm == 1) { printf("종료합니다.\n"); return 0; } else { printf("취소. 메뉴로 돌아갑니다.\n"); } break; }

확장 3 — 하위 메뉴

특정 메뉴(예: 1번 추가) 안에서 또 메뉴를 보여주면 계층형 메뉴가 됩니다. 두 번째 while + switch로 구현합니다.

case 1: { int sub; printf(" [추가 메뉴]\n"); printf(" 1. 텍스트 입력\n"); printf(" 2. 숫자 입력\n"); printf(" 0. 취소\n"); printf(" 선택: "); scanf("%d", &sub); switch (sub) { case 1: printf(" 텍스트를 입력하세요.\n"); break; case 2: printf(" 숫자를 입력하세요.\n"); break; case 0: printf(" 취소합니다.\n"); break; } break; // 바깥 switch의 break }

핵심 정리

  • while(1): 조건이 항상 참 → 무한 루프, break/return 으로만 탈출
  • switch(변수): 변수 값에 따라 해당 case 실행
  • case 안의 break: switch만 탈출 (while은 계속 실행됨)
  • 루프 완전 종료: return 0 또는 flag 변수 활용
  • default: 어떤 case에도 해당 안 될 때 실행 (잘못된 입력 처리)
  • 하위 메뉴: case 안에 switch 중첩으로 계층형 메뉴 구현
