매개변수와 인자 — 값 전달의 비밀

함수에 값을 전달하는 방법을 배웁니다. 매개변수와 인자의 차이, 값에 의한 전달(call by value)의 원리를 이해합니다.

이 유닛에서 배우는 것

  • 매개변수와 인자의 차이를 설명할 수 있습니다.
  • 값에 의한 전달(call by value)의 원리를 이해합니다.
  • 여러 매개변수를 가진 함수를 작성합니다.
  • 함수 안에서 매개변수를 바꿔도 원본이 안전함을 압니다.
  • 매개변수 순서와 타입이 맞아야 함을 이해합니다.

매개변수 vs 인자 — 용어 구분

같은 개념처럼 보이지만, 위치에 따라 이름이 다릅니다. 정확한 용어를 알면 설명할 때 훨씬 명확합니다.

값에 의한 전달 (Call by Value)

C언어에서 함수에 값을 전달하면, 값의 복사본이 매개변수로 들어갑니다. 그래서 함수 안에서 매개변수를 바꿔도 원본 변수에는 영향이 없습니다.

void doubleIt(int n) { n = n * 2; // 복사본 n을 바꿈 printf("함수 안: %d\n", n); // 20 } int main() { int x = 10; doubleIt(x); printf("함수 밖: %d\n", x); // 10 (원본 안변함!) return 0; }

여러 매개변수 사용하기

매개변수는 쉼표(,)로 구분해 여러 개 선언할 수 있습니다. 각 매개변수마다 타입을 따로 씁니다.

// 두 개 매개변수 int add(int a, int b) { return a + b; } // 세 개 매개변수 int addThree(int a, int b, int c) { return a + b + c; } // 다른 타입 혼합 void printInfo(int age, float height) { printf("나이: %d, 키: %.1f\n", age, height); } int main() { printf("%d\n", add(3, 7)); // 10 printf("%d\n", addThree(1, 2, 3)); // 6 printInfo(15, 165.5); return 0; }

매개변수의 순서와 타입은 호출 시 인자와 반드시 일치해야 합니다. add(3, 7)을 호출하면 a=3, b=7이 됩니다.

핵심 정리

핵심 요약

  • 매개변수: 함수 정의 쪽 괄호 안의 변수 이름.
  • 인자: 함수 호출 시 실제로 전달하는 값.
  • call by value: 인자의 복사본이 매개변수에 들어가므로 원본은 안전합니다.
  • 여러 매개변수는 쉼표로 구분하며, 각각 타입을 써야 합니다.
  • 호출 시 인자의 순서와 타입은 매개변수 선언과 반드시 일치해야 합니다.
