에디터
삽입 / 삭제 / 검색 — 3가지 편집 기능
텍스트 에디터의 핵심은 삽입(insert), 삭제(delete), 검색(search)이다.
배열 내 특정 위치에 글자를 끼워 넣거나 빼려면, 나머지 요소들을 앞뒤로 밀어야 한다.
이 프로젝트에서는 문자열을 직접 조작하며 메모리 이동 패턴을 익힌다.

학습 목표

특정 위치에 문자를 삽입하는 알고리즘 (오른쪽 이동)
특정 위치의 문자를 삭제하는 알고리즘 (왼쪽 이동)
strstr 검색 + 커서 위치 표시
메뉴 기반 인터랙티브 에디터 완성

삽입과 삭제 알고리즘
삽입 — 오른쪽으로 밀고 끼워 넣기
void insert_char(char str[], int pos, char c) { int len = strlen(str); // 뒤부터 한 칸씩 오른쪽으로 이동 for (int i = len; i >= pos; i--) str[i + 1] = str[i]; // \0 포함 이동 str[pos] = c; // 원하는 위치에 삽입 } void delete_char(char str[], int pos) { int len = strlen(str); // pos 위치부터 왼쪽으로 한 칸씩 이동 for (int i = pos; i < len; i++) str[i] = str[i + 1]; // \0도 자동으로 당겨짐 }
삽입 시 뒤부터 이동하는 이유: 앞부터 이동하면 기존 값이 덮어써진다. 예: "abc"에서 [1]을 [2]에 복사하면 'b'가 [1],[2] 모두 'b'가 돼버린다. 뒤부터 해야 기존 값을 보존한다.
미니 에디터 완전 구현
#include <stdio.h> #include <string.h> void show(char s[]) { printf("[현재]: \"%s\" (길이:%d)\n",s,(int)strlen(s)); } int main() { char text[500] = ""; int choice, pos; char c; char keyword[100]; while (1) { show(text); printf("1.입력 2.삽입 3.삭제 4.검색 5.초기화 6.종료\n선택: "); scanf("%d", &choice); if (choice == 6) break; switch (choice) { case 1: printf("텍스트: "); getchar(); fgets(text, sizeof(text), stdin); text[strcspn(text,"\n")]='\0'; break; case 2: printf("위치(0~%d): ",(int)strlen(text)); scanf("%d",&pos); printf("문자: "); scanf(" %c",&c); insert_char(text, pos, c); break; case 3: printf("위치(0~%d): ",(int)strlen(text)-1); scanf("%d",&pos); delete_char(text, pos); break; case 4: printf("검색어: "); scanf("%s",keyword); { char *f=strstr(text,keyword); if(f) printf("위치 %d에서 발견\n",(int)(f-text)); else printf("없음\n"); } break; case 5: text[0]='\0'; printf("초기화됨\n"); break; } } return 0; }
scanf(" %c") 의 공백: scanf("%c")는 이전 입력의 개행(\n)을 글자로 읽어버린다. " %c" (공백 추가)로 개행을 먼저 무시하고 실제 문자를 읽는다.
연습 문제
Q1. 추적

insert_char("abc", 1, 'X')의 결과는? 단계별로 추적하시오.

정답 보기
len=3. i=3→str[4]=str[3]='\0'. i=2→str[3]=str[2]='c'. i=1→str[2]=str[1]='b'. str[1]='X'. 결과: "aXbc"
Q2. 오류 분석

insert_char에서 루프를 i = pos부터 (앞부터) 실행하면 어떤 문제가 발생하는가?

정답 보기
"abc"에서 pos=1 삽입 시: str[2]=str[1]='b' 후 str[3]=str[2]='b' (이미 덮어쓴 값). 'c'가 사라지고 "aXbb" 같은 잘못된 결과.
Q3. 구현

문자열에서 특정 문자를 모두 삭제하는 delete_all(str, c) 함수를 작성하시오.
예) delete_all("hello world", 'l') → "heo word"

정답 보기
void delete_all(char s[], char c) { int j=0; for(int i=0;s[i];i++) if(s[i]!=c) s[j++]=s[i]; s[j]='\0'; }

문자열에서 특정 단어를 찾아 다른 단어로 교체하는 replace(str, find, rep) 함수를 작성하시오.

정답 보기

핵심 정리

삽입뒤부터 앞으로 한 칸씩 오른쪽 이동 → 원하는 위치에 문자 배치
삭제해당 위치부터 앞으로 한 칸씩 왼쪽 이동 → \0 자동 처리
방향삽입=뒤부터(덮어쓰기 방지), 삭제=앞부터(순서 유지)
scanfscanf(" %c") — 앞의 공백이 개행 문자를 먹어줌
