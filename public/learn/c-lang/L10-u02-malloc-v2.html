malloc 사용법
동적 배열 만들기

malloc으로 힙에 메모리를 할당하는 방법을 배웁니다. (int*)malloc(sizeof(int)*n) 패턴과 NULL 체크를 익힙니다.

이 유닛에서 배우는 것

  • malloc의 기본 문법을 정확히 쓸 수 있습니다.
  • sizeof를 이용해 정확한 바이트 수를 계산합니다.
  • 포인터 캐스팅 (int*) 의 의미를 이해합니다.
  • NULL 체크로 할당 실패를 처리할 수 있습니다.
  • 동적 배열을 만들고 인덱스로 접근합니다.

malloc 기본 문법

malloc은 "memory allocation"의 줄임말입니다. 힙에서 원하는 바이트 수만큼 메모리를 빌려오고, 그 시작 주소를 반환합니다.

// 정수 1개 할당 int *p = (int*)malloc(sizeof(int)); // 4바이트 // 정수 n개(배열) 할당 int n = 5; int *arr = (int*)malloc(sizeof(int) * n); // 4*5 = 20바이트 // double 3개 할당 double *d = (double*)malloc(sizeof(double) * 3); // 8*3 = 24바이트
sizeof(int)는 보통 4바이트입니다. 숫자를 직접 쓰지 말고 sizeof를 써야 이식성이 좋습니다.

NULL 체크 — 할당 실패 대비

malloc이 메모리 확보에 실패하면 NULL을 반환합니다. 반드시 NULL인지 확인해야 합니다.

int *arr = (int*)malloc(sizeof(int) * n); if (arr == NULL) { // NULL 체크 필수! printf("메모리 할당 실패\n"); return 1; // 프로그램 종료 }

동적 배열 — 만들고 사용하기

malloc으로 배열처럼 사용하는 메모리를 할당할 수 있습니다. 포인터 연산이나 인덱스([])로 접근합니다.

#include <stdio.h> #include <stdlib.h> int main() { int n = 5; int *arr = (int*)malloc(sizeof(int) * n); if (arr == NULL) { printf("실패\n"); return 1; } for (int i = 0; i < n; i++) { arr[i] = (i + 1) * 10; // 10, 20, 30, 40, 50 } for (int i = 0; i < n; i++) { printf("%d ", arr[i]); // 배열처럼 사용 } free(arr); // 반납 필수 return 0; }

sizeof — 타입별 바이트 크기

실습 구역
따라해보세요
1
사용자로부터 n을 입력받아 n개의 정수 배열을 동적 할당하세요.
int n; printf("개수 입력: "); scanf("%d", &n); int *arr = (int*)malloc(sizeof(int) * n); if (arr == NULL) { printf("실패\n"); return 1; } printf("%d개 할당 완료\n", n); free(arr);
입력한 수만큼 동적으로 할당됩니다
2
double 10개를 동적 할당하고 NULL 체크까지 하세요.
double *d = (double*)malloc(sizeof(double) * 10); if (d == NULL) { printf("실패\n"); return 1; } free(d);
80바이트(8×10) 할당 완료

전체 예제 — 성적 동적 입력

학생 수를 입력받아 동적으로 배열을 만들고, 점수를 입력받아 합계와 평균을 출력하는 완성된 예제입니다.

#include <stdio.h> #include <stdlib.h> int main() { int n; printf("학생 수 입력: "); scanf("%d", &n); int *scores = (int*)malloc(sizeof(int) * n); if (scores == NULL) { printf("메모리 할당 실패\n"); return 1; } int sum = 0; for (int i = 0; i < n; i++) { printf("%d번 점수: ", i+1); scanf("%d", &scores[i]); sum += scores[i]; } printf("합계: %d, 평균: %.1f\n", sum, (double)sum/n); free(scores); // 반납 return 0; }
malloc 바로 다음에 항상 NULL 체크를 합니다. 그리고 사용이 끝나면 free()로 반납합니다.

double 5개를 할당하는 올바른 malloc 호출은?
① malloc(5)
② malloc(sizeof(double) * 5)
③ malloc(double * 5)
④ malloc(8)
힌트 / 정답 보기
정답: ② sizeof(double)=8이므로 8*5=40바이트. 직접 숫자를 쓰면 환경마다 달라질 수 있으므로 sizeof를 씁니다.

핵심 정리

핵심 정리

  • malloc(바이트수) — 힙에서 메모리를 빌려오고 주소 반환
  • sizeof(타입)*n — 정확한 바이트 수 계산
  • (int*) 캐스팅 — void*를 원하는 포인터 타입으로 변환
  • NULL 체크 — 할당 실패 시 반드시 처리
  • arr[i] — 일반 배열처럼 인덱스로 접근 가능
