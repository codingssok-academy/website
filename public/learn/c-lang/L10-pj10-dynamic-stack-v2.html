동적 크기 스택
push/pop + 자동 확장

고정 배열 대신 realloc으로 자동 확장되는 동적 스택을 구현합니다. 용량 초과 시 2배 확장하는 capacity 패턴을 익힙니다.

이 프로젝트에서 만드는 것

  • Stack 구조체에 data 포인터, top, capacity를 저장합니다.
  • push 시 용량 초과면 realloc으로 2배 확장합니다.
  • pop 시 top--로 맨 위 값을 꺼냅니다.
  • peek으로 꺼내지 않고 맨 위 값만 확인합니다.
  • 스택을 완전히 해제하는 함수를 만듭니다.

동적 스택 구조

스택은 LIFO(Last In, First Out) 구조입니다. 접시를 쌓듯이, 마지막에 올린 것을 먼저 꺼냅니다. capacity(최대 용량)를 초과하면 realloc으로 공간을 늘립니다.

#include <stdio.h> #include <stdlib.h> typedef struct { int *data; int top; // 현재 개수 int capacity; // 최대 용량 } Stack; Stack* stack_create(int init_cap) { Stack *s = (Stack*)malloc(sizeof(Stack)); s->data = (int*)malloc(sizeof(int)*init_cap); s->top = 0; s->capacity = init_cap; return s; } void push(Stack *s, int val) { if (s->top == s->capacity) { // 꽉 찼으면 2배 확장 s->capacity *= 2; s->data = (int*)realloc(s->data, sizeof(int)*s->capacity); printf(" [확장] capacity=%d\n", s->capacity); } s->data[s->top++] = val; } int pop(Stack *s) { if (s->top == 0) { printf("스택 비어있음\n"); return -1; } return s->data[--s->top]; } int peek(Stack *s) { if (s->top == 0) return -1; return s->data[s->top-1]; } void stack_destroy(Stack *s) { free(s->data); free(s); } int main() { Stack *s = stack_create(2); // 초기 용량 2 push(s,10); push(s,20); push(s,30); // 3번째에서 확장 push(s,40); push(s,50); // 5번째에서 또 확장 printf("top=%d cap=%d\n", s->top, s->capacity); printf("peek=%d\n", peek(s)); while(s->top) printf("pop:%d\n", pop(s)); stack_destroy(s); return 0; }

실행 결과

[확장] capacity=4 [확장] capacity=8 top=5 cap=8 peek=50 pop:50 pop:40 pop:30 pop:20 pop:10
