Chapter 02

개발 환경 준비 — VS Code + GCC

C언어 코딩을 시작하기 위해 편집기와 컴파일러를 설치합니다.

이 유닛에서 배우는 것

  • VS Code를 설치하고 실행할 수 있습니다.
  • GCC 컴파일러를 설치할 수 있습니다.
  • C/C++ 확장을 VS Code에 추가할 수 있습니다.
  • 터미널에서 gcc --version 명령을 실행할 수 있습니다.
  • 첫 번째 .c 파일을 만들고 컴파일 할 수 있습니다.

VS Code 설치하기

VS Code(Visual Studio Code)는 마이크로소프트가 만든 무료 코드 편집기입니다. C언어 파일을 편리하게 작성하고 관리할 수 있습니다.

1
공식 사이트 접속
code.visualstudio.com 에 접속합니다.
2
다운로드 클릭
파란색 "Download for Windows" 버튼을 클릭합니다.
3
설치 마법사 실행
다운로드된 파일을 실행하고 "다음" 버튼을 계속 클릭합니다. "PATH에 추가" 항목은 반드시 체크합니다.
따라해보세요
1
VS Code를 설치하고 실행해 보세요.
// VS Code 실행 확인: 파란색 아이콘 더블클릭 // 처음 실행 시 한국어 언어팩 설치 권장
VS Code 시작 화면이 보이면 성공

VS Code에서 터미널을 열어보세요.
// 메뉴: 터미널 → 새 터미널 // 단축키: Ctrl + ` (백틱)
화면 아래에 터미널 창이 열립니다

Microsoft C/C++ 확장이 설치됩니다

GCC 컴파일러 설치하기

컴파일러는 우리가 쓴 C코드를 컴퓨터가 실행할 수 있는 파일로 변환합니다. Windows에서는 MinGW-w64를 통해 GCC를 설치합니다.

1
winlibs.com 접속
winlibs.com 에서 GCC for Windows를 다운로드합니다.
2
C:\mingw64 폴더에 압축 해제
다운로드한 파일을 C드라이브에 압축 해제합니다.
3
환경변수 PATH 추가
시스템 환경변수 설정에서 C:\mingw64\bin 을 PATH에 추가합니다.
Q1
컴파일러 역할 — 맞는 것 고르기
쉬움
GCC 컴파일러가 하는 일로 올바른 것은?
①코드를 예쁘게 색칠해 준다
②C 소스코드를 실행 파일로 변환한다
③코드를 자동으로 완성해 준다
④파일을 저장해 준다
내 답안
힌트 보기
컴파일러는 번역기입니다. 사람이 읽는 코드를 컴퓨터가 읽는 코드로 바꿉니다.
정답 보기
정답: ② — GCC는 .c 파일을 .exe 실행 파일로 변환합니다.

첫 컴파일 테스트

설치가 완료되었으면 직접 C파일을 만들어 컴파일해 봅시다.

/* hello.c — 내 첫 C 파일 */ #include <stdio.h> int main() { printf("컴파일 성공!\n"); return 0; }

핵심 요약

  • VS Code: 코드 편집기, code.visualstudio.com에서 무료 다운로드
  • GCC: C언어 컴파일러, winlibs.com에서 설치 (MinGW-w64)
  • 컴파일 명령: gcc 파일명.c -o 출력명
  • 실행: ./출력명 (Windows: ./출력명.exe)
  • C/C++ 확장 설치 시 VS Code에서 문법 강조와 자동완성 사용 가능
