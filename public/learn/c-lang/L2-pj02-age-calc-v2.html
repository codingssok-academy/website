LEVEL 2a PROJECT 02
나이 계산기
만들기
태어난 연도를 입력받아 나이를 계산하는 프로그램을 만들어 보자!

학습 목표

  • scanf로 키보드에서 숫자를 입력받을 수 있다
  • 뺄셈 연산으로 나이를 계산할 수 있다
  • 입력 - 처리 - 출력의 프로그램 흐름을 이해한다
  • 변수를 활용한 계산 결과를 출력할 수 있다

Step 1: 현재 연도 저장하기

나이를 계산하려면 현재 연도가 필요하다. 변수에 현재 연도를 저장하자.

#include <stdio.h> int main(void) { int current_year = 2025; // 현재 연도 return 0; }

Step 2: 태어난 연도 입력받기

scanf는 키보드에서 값을 입력받는 함수다. %d는 정수를 입력받겠다는 뜻이고, 변수 앞에 &를 붙여야 한다.

int birth_year; // 태어난 연도 (아직 값 없음) printf("태어난 연도를 입력하세요: "); scanf("%d", &birth_year); // 키보드 입력을 birth_year에 저장

Step 3: 나이 계산하기

현재 연도에서 태어난 연도를 빼면 나이가 나온다. 계산 결과를 새 변수에 저장한다.

int age = current_year - birth_year; printf("당신의 나이: %d살\n", age);
실습 1: 기본 나이 계산기
STEP 1
위의 전체 코드를 조합하여 완성하고, 자신의 태어난 연도를 입력해 보자.
태어난 연도를 입력하세요: 2011 / 당신의 나이: 14살
STEP 2
부모님의 태어난 연도를 입력해서 나이를 확인해 보자.
실습 2: 100세까지 남은 해
STEP 1
나이를 계산한 뒤, 100에서 나이를 빼서 "100세까지 남은 해"를 출력해 보자.
int remaining = 100 - age; printf("100세까지 %d년 남았습니다!\n", remaining);
100세까지 85년 남았습니다!

완성 코드

#include <stdio.h> int main(void) { int current_year = 2025; int birth_year; int age; int remaining; printf("=== 나이 계산기 ===\n"); printf("태어난 연도를 입력하세요: "); scanf("%d", &birth_year); age = current_year - birth_year; remaining = 100 - age; printf("\n--- 결과 ---\n"); printf("태어난 연도: %d년\n", birth_year); printf("현재 나이: %d살\n", age); printf("100세까지: %d년 남음\n", remaining); return 0; }

응용: 두 사람의 나이차 계산

두 사람의 태어난 연도를 입력받아 나이 차이를 계산해 보자.

int year1, year2; int age1, age2, diff; printf("첫 번째 사람의 태어난 연도: "); scanf("%d", &year1); printf("두 번째 사람의 태어난 연도: "); scanf("%d", &year2); age1 = 2025 - year1; age2 = 2025 - year2; diff = age1 - age2; printf("나이 차이: %d살\n", diff);
실습 3: 나이차 계산기
STEP 1
본인과 친구의 태어난 연도를 입력해서 나이 차이를 구해 보자.
나이 차이: 1살
STEP 2
부모님과 본인의 나이 차이도 계산해 보자. 음수가 나올 수도 있다!
나이 차이: -30살 (음수 = 상대방이 더 많음)

도전 문제

1
띠 계산기 (번호)
쉬움
태어난 연도를 입력받아 나이를 계산하고, 태어난 연도를 12로 나눈 나머지도 함께 출력하시오. (나머지가 띠 번호 역할)
입력2010
출력나이: 15살, 띠번호: 6
힌트 보기
나머지 연산자 %를 사용한다. 2010 % 12는 6이 된다.
정답 보기
#include <stdio.h> int main(void) { int birth_year, age, zodiac; printf("태어난 연도: "); scanf("%d", &birth_year); age = 2025 - birth_year; zodiac = birth_year % 12; printf("나이: %d살, 띠번호: %d\n", age, zodiac); return 0; }
2
졸업 연도 계산
쉬움
태어난 연도를 입력받아 중학교 졸업 연도(태어난 해 + 16)와 고등학교 졸업 연도(태어난 해 + 19)를 출력하시오.
입력2010
출력중학교 졸업: 2026년 / 고등학교 졸업: 2029년
힌트 보기
int grad_mid = birth_year + 16;으로 계산하면 된다.
정답 보기
#include <stdio.h> int main(void) { int birth_year, grad_mid, grad_high; printf("태어난 연도: "); scanf("%d", &birth_year); grad_mid = birth_year + 16; grad_high = birth_year + 19; printf("중학교 졸업: %d년\n", grad_mid); printf("고등학교 졸업: %d년\n", grad_high); return 0; }
3
세 사람 나이 비교
보통
세 사람의 태어난 연도를 입력받아 각각의 나이와, 세 사람 나이의 합계/평균을 출력하시오.
입력2010 2008 2012
출력나이: 15, 17, 13 / 합계: 45 / 평균: 15
힌트 보기
scanf("%d %d %d", &y1, &y2, &y3);으로 세 값을 한 번에 입력받을 수 있다. 평균은 합계를 3으로 나누면 된다.
정답 보기
#include <stdio.h> int main(void) { int y1, y2, y3; printf("세 사람의 태어난 연도: "); scanf("%d %d %d", &y1, &y2, &y3); int a1 = 2025 - y1; int a2 = 2025 - y2; int a3 = 2025 - y3; int sum = a1 + a2 + a3; printf("나이: %d, %d, %d\n", a1, a2, a3); printf("합계: %d / 평균: %d\n", sum, sum / 3); return 0; }

이번 프로젝트에서 배운 것

  • scanf("%d", &변수)로 키보드에서 정수를 입력받는 방법
  • 뺄셈 연산(-)으로 나이를 계산하는 방법
  • 입력 - 처리 - 출력의 3단계 프로그램 흐름
  • 여러 변수를 활용해 다양한 계산을 하는 방법
  • scanf에서 변수 앞에 &를 반드시 붙여야 한다는 것
