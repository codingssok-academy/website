Chapter 06

문자형: char

컴퓨터가 문자를 숫자로 저장하는 원리, ASCII 코드, 문자 연산을 배웁니다.

이 유닛에서 배우는 것

  • char 자료형이 1바이트 크기이며 문자 하나를 저장함을 안다.
  • 'A'가 내부적으로 65라는 숫자임을 이해한다.
  • printf에서 %c로 문자를 출력할 수 있다.
  • 문자에 숫자를 더하는 연산을 할 수 있다.
  • 대문자와 소문자의 ASCII 차이(32)를 활용할 수 있다.

char: 문자 하나를 저장하는 자료형

char는 문자(character) 하나를 저장하는 자료형입니다. 크기는 딱 1바이트(8비트)입니다. 문자를 저장할 때는 작은따옴표('A')로 감쌉니다.

컴퓨터는 문자를 직접 이해하지 못합니다. 대신 각 문자에 번호를 매겨서 숫자로 저장합니다. 이 번호 체계가 바로 ASCII(아스키) 코드입니다.

#include <stdio.h> int main(void) { char letter = 'A'; printf("문자: %c\n", letter); // 문자: A printf("숫자: %d\n", letter); // 숫자: 65 return 0; }

%c로 출력하면 문자가 나오고, %d로 출력하면 그 문자의 ASCII 번호가 나옵니다. 같은 변수인데 출력 방식에 따라 다르게 보이는 것입니다.

따라해보세요
1
자신의 이름 이니셜(영문)을 char 변수에 저장하고 출력해 보세요.
char initial = 'J'; printf("이니셜: %c\n", initial);
이니셜: J
2
'Z'의 ASCII 번호를 출력해 보세요.
char z = 'Z'; printf("Z의 번호: %d\n", z);
Z의 번호: 90
3
숫자 65를 char에 넣고 %c로 출력해 보세요.
char ch = 65; printf("65는 문자 %c\n", ch);
65는 문자 A

문자 연산: 숫자를 더하고 빼기

char는 내부적으로 숫자이므로, 숫자처럼 더하고 빼는 것이 가능합니다. 'A' + 1은 65 + 1 = 66이고, 66은 'B'입니다.

#include <stdio.h> int main(void) { char ch = 'A'; printf("%c의 다음 글자: %c\n", ch, ch + 1); // B printf("%c의 3번째 뒤: %c\n", ch, ch + 3); // D return 0; }

대소문자 변환: 32의 비밀

ASCII 코드에서 대문자와 소문자의 차이는 항상 32입니다. 대문자에 32를 더하면 소문자, 소문자에서 32를 빼면 대문자가 됩니다.

#include <stdio.h> int main(void) { char upper = 'H'; char lower = upper + 32; // 대문자 → 소문자 printf("대문자: %c\n", upper); // H printf("소문자: %c\n", lower); // h char small = 'k'; char big = small - 32; // 소문자 → 대문자 printf("소문자: %c\n", small); // k printf("대문자: %c\n", big); // K return 0; }
따라해보세요
1
'M'의 다음 글자를 출력해 보세요.
char ch = 'M'; printf("다음 글자: %c\n", ch + 1);
다음 글자: N
2
'd'를 대문자로 변환해서 출력해 보세요.
char small = 'd'; printf("대문자: %c\n", small - 32);
대문자: D
3
이니셜 2개를 각각 char 변수에 저장하고 나란히 출력해 보세요.
char first = 'J'; char last = 'H'; printf("이니셜: %c.%c.\n", first, last);
이니셜: J.H.

실전: 이니셜 출력 프로그램

성과 이름의 첫 글자를 char로 저장해서 이니셜을 보기 좋게 출력해 봅시다.

#include <stdio.h> int main(void) { char last_name = 'K'; // 성의 이니셜 char first_name = 'J'; // 이름의 이니셜 printf("=== 이니셜 카드 ===\n"); printf("[%c.%c.]\n", last_name, first_name); printf("ASCII: %d, %d\n", last_name, first_name); return 0; }

실전: 다음 글자 출력 프로그램

#include <stdio.h> int main(void) { char ch = 'F'; printf("현재 문자: %c (ASCII %d)\n", ch, ch); printf("다음 문자: %c (ASCII %d)\n", ch + 1, ch + 1); printf("이전 문자: %c (ASCII %d)\n", ch - 1, ch - 1); return 0; }
따라해보세요
1
'a'부터 'e'까지 5글자를 한 줄에 출력해 보세요 (반복문 없이).
char start = 'a'; printf("%c %c %c %c %c\n", start, start+1, start+2, start+3, start+4);
a b c d e

핵심 요약

  • char는 1바이트 크기로 문자 하나를 저장한다.
  • 문자는 내부적으로 ASCII 번호(숫자)로 저장된다. 'A'=65, 'a'=97, '0'=48
  • %c로 문자를 출력하고, %d로 ASCII 번호를 출력한다.
  • 문자에 숫자를 더하면 다음 문자가 된다: 'A' + 1 = 'B'
  • 대문자와 소문자의 ASCII 차이는 항상 32이다.
