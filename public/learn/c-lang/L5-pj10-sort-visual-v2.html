정렬 시각화

버블 정렬 알고리즘으로 배열을 정렬하면서, 각 단계마다 배열 상태를 출력해 정렬 과정을 눈으로 확인합니다.

이 프로젝트에서 배우는 것

  • 버블 정렬의 원리(인접 원소 비교·교환)를 이해합니다.
  • 중첩 for문으로 정렬 알고리즘을 구현합니다.
  • 각 패스마다 배열 상태를 출력하는 방법을 배웁니다.
  • 정렬 과정에서 swap 횟수를 카운트합니다.

버블 정렬 알고리즘

버블 정렬은 인접한 두 원소를 비교해서 순서가 틀리면 교환합니다. 한 번의 패스가 끝나면 가장 큰 값이 맨 끝으로 이동합니다.

int arr[] = {5, 3, 8, 1, 4}; int n = 5, swapCnt = 0; for (int i = 0; i < n - 1; i++) { // 패스 수 printf("패스 %d: ", i + 1); for (int j = 0; j < n - 1 - i; j++) { // 비교 범위 if (arr[j] > arr[j + 1]) { int tmp = arr[j]; arr[j] = arr[j + 1]; arr[j + 1] = tmp; swapCnt++; } } // 패스 후 상태 출력 for (int k = 0; k < n; k++) printf("%d ", arr[k]); printf("\n"); }

완성 코드 & 출력 예시

#include <stdio.h> void printArr(int arr[], int n) { for (int i=0;i<n;i++) printf("%3d",arr[i]); printf("\n"); } int main() { int arr[] = {5,3,8,1,4}; int n=5, swapCnt=0; printf("초기: "); printArr(arr,n); for(int i=0;i<n-1;i++){ for(int j=0;j<n-1-i;j++){ if(arr[j]>arr[j+1]){ int tmp=arr[j];arr[j]=arr[j+1];arr[j+1]=tmp; swapCnt++; } } printf("패스%d: ",i+1); printArr(arr,n); } printf("swap횟수: %d\n",swapCnt); return 0; }

조기 종료 최적화
중간
패스 중에 swap이 한 번도 없으면 이미 정렬된 것입니다. swapped 플래그를 사용해 조기 종료를 구현하세요.
효과이미 정렬된 배열: O(n)으로 처리
힌트 보기
패스 시작 전 swapped=0, swap 발생 시 swapped=1. 패스 후 if(!swapped) break;
3
선택 정렬 구현
어려움
버블 정렬 대신 선택 정렬(각 패스에서 최솟값을 찾아 맨 앞과 swap)을 구현하세요.
패스1최솟값 1을 찾아 arr[0]과 swap
패스2남은 중 최솟값 3을 찾아 arr[1]과 swap
힌트 보기
for(i=0;i<n-1;i++) { minIdx=i; for(j=i+1;j<n;j++) if(arr[j]<arr[minIdx]) minIdx=j; swap(arr[i],arr[minIdx]); }

핵심 정리

  • 버블 정렬: 인접 비교·교환, 외부 n-1 패스, 내부 n-1-i 비교
  • 한 패스 후 가장 큰(작은) 값이 맨 끝(앞)으로 이동
  • 시간복잡도: O(n²) — n이 커질수록 느려짐
  • swap 함수: tmp=a; a=b; b=tmp; 3단계
  • 조기 종료: swapped 플래그로 최적화 가능
