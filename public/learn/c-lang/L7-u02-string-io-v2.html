문자열 입출력
— scanf, fgets, puts

키보드로 문자열을 받고 화면에 출력하는 방법을 익힙니다. gets의 위험성도 배웁니다.

이 유닛에서 배우는 것

  • scanf("%s")로 공백 없는 문자열을 입력받을 수 있습니다.
  • fgets로 공백 포함 문자열을 안전하게 입력받을 수 있습니다.
  • gets의 위험성을 설명하고 fgets로 대체할 수 있습니다.
  • puts와 printf("%s")의 차이를 알 수 있습니다.
  • fgets가 자동으로 \n을 붙이는 특성을 처리할 수 있습니다.

scanf("%s") — 공백 없는 문자열 입력

scanf("%s", str)는 공백(스페이스, 탭, 엔터)을 만나기 전까지 입력받습니다. 변수 앞에 &를 붙이지 않아도 됩니다. (배열 이름이 이미 주소이기 때문)

#include <stdio.h> int main() { char name[20]; printf("이름 입력: "); scanf("%s", name); // & 불필요! 배열이라서 printf("안녕, %s!\n", name); return 0; }

주의: "김 철수"처럼 공백이 있는 이름을 입력하면 "김"만 저장됩니다. 공백 포함 입력은 fgets를 사용해야 합니다.

fgets — 공백 포함, 안전한 입력

fgets(배열, 크기, stdin)은 지정한 크기만큼만 읽어 버퍼 오버플로우를 방지합니다. 엔터(\n)도 포함해서 저장합니다.

#include <stdio.h> #include <string.h> int main() { char sentence[50]; printf("문장 입력: "); fgets(sentence, sizeof(sentence), stdin); // fgets는 \n도 저장함 → 제거 int len = strlen(sentence); if (sentence[len - 1] == '\n') sentence[len - 1] = '\0'; printf("입력한 문장: %s\n", sentence); return 0; }

gets — 사용 금지!

gets는 크기 제한 없이 입력받아 버퍼 오버플로우를 일으킵니다. 현재 C11 표준에서 제거된 함수입니다. 절대 사용하지 마세요.

puts와 printf("%s") 출력

문자열 출력에는 두 가지 방법이 있습니다. puts는 자동으로 줄바꿈을 추가하고, printf는 형식을 직접 지정합니다.

#include <stdio.h> int main() { char msg[] = "Hello, C!"; puts(msg); // Hello, C! (자동 줄바꿈) printf("%s\n", msg); // Hello, C! (같은 결과) printf("메시지: %s END\n", msg); // 형식 혼합 가능 return 0; }

char s[50]; fgets(s, sizeof(s), stdin); int len = strlen(s); if (s[len-1] == '\n') s[len-1] = '\0';

Q5
코드 작성
보통
이름(공백 없음)과 취미(공백 포함)를 각각 입력받아 출력하는 프로그램을 작성하세요.
정답 보기
#include <stdio.h> #include <string.h> int main() { char name[30], hobby[60]; printf("이름: "); scanf("%s", name); getchar(); // 버퍼 비우기 printf("취미: "); fgets(hobby, sizeof(hobby), stdin); int len = strlen(hobby); if (hobby[len-1] == '\n') hobby[len-1] = '\0'; printf("%s의 취미: %s\n", name, hobby); return 0; }
핵심 정리

핵심 요약

  • scanf("%s")는 공백 전까지만 읽습니다. 배열엔 & 불필요.
  • fgets(배열, 크기, stdin)은 공백 포함, 크기 제한 안전 입력입니다.
  • fgets는 \n을 포함하므로 직접 제거해야 합니다.
  • gets는 버퍼 오버플로우 위험 — 절대 사용 금지입니다.
  • puts는 자동 줄바꿈, printf는 형식 지정이 자유롭습니다.

전체 예제 — 입출력 함수 비교

#include <stdio.h> #include <string.h> int main() { char id[20]; // 공백 없는 아이디 char intro[100]; // 공백 포함 자기소개 printf("아이디 입력: "); scanf("%s", id); getchar(); // 버퍼에 남은 \n 제거 printf("자기소개 입력: "); fgets(intro, sizeof(intro), stdin); // \n 제거 int len = strlen(intro); if (intro[len-1] == '\n') intro[len-1] = '\0'; printf("\n=== 프로필 ===\n"); printf("ID: %s\n", id); puts(intro); // 자기소개 출력 return 0; }
