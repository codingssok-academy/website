LEVEL 2a PROJECT 01
자기소개 카드
만들기
변수에 나의 정보를 저장하고, printf로 멋진 자기소개 카드를 출력해 보자!

학습 목표

  • 정수형 변수 int를 선언하고 값을 저장할 수 있다
  • printf와 서식 지정자 %d를 사용해 변수 값을 출력할 수 있다
  • 여러 변수를 조합하여 의미 있는 문장을 출력할 수 있다
  • 자기소개 카드를 확장하여 친구/가족 소개도 만들 수 있다

프로젝트 미션

오늘의 미션은 자기소개 카드 프로그램을 만드는 것이다. 변수에 이름 번호, 나이, 학교 번호, 취미 번호를 저장하고, printf로 깔끔하게 출력하면 된다.

Step 1: 변수 선언하기

먼저 자기소개에 필요한 정보를 담을 변수를 선언한다. 아직 문자열을 배우지 않았으니, 숫자로 대체하는 방법을 쓴다. 나이는 그대로 숫자로 저장하고, 이름/학교/취미는 번호로 저장한다.

#include <stdio.h> int main(void) { // 자기소개 정보를 변수에 저장 int name_num = 1; // 1=김코딩, 2=이자바, 3=박씨언 int age = 14; // 나이 int school_num = 3; // 1=코딩초, 2=알고중, 3=코딩중 int hobby_num = 5; // 1=게임, 2=독서, 3=운동, 4=음악, 5=프로그래밍 return 0; }

Step 2: printf로 출력하기

printf에서 %d는 정수 값을 출력하는 서식 지정자다. 변수에 저장된 값이 %d 자리에 들어간다.

printf("=== 자기소개 카드 ===\n"); printf("이름 번호: %d\n", name_num); printf("나이: %d살\n", age); printf("학교 번호: %d\n", school_num); printf("취미 번호: %d\n", hobby_num); printf("==================\n");
실습 1: 기본 자기소개 카드
STEP 1
위의 전체 코드를 작성하고, 자신의 정보로 변수 값을 바꿔 보자.
STEP 2
age 값을 자기 나이로 변경하고 실행해 보자.
나이: 15살 (본인 나이가 출력됨)
STEP 3
printf 줄을 하나 더 추가해서 "좋아하는 숫자: %d" 를 출력해 보자.
좋아하는 숫자: 7

완성 코드

지금까지 배운 내용을 모아 완성된 자기소개 카드 프로그램이다.

#include <stdio.h> int main(void) { // 자기소개 정보 int name_num = 1; int age = 14; int school_num = 3; int hobby_num = 5; int fav_number = 7; // 카드 출력 printf("+-----------------------+\n"); printf("| 자 기 소 개 카 드 |\n"); printf("+-----------------------+\n"); printf("| 이름 번호 : %d |\n", name_num); printf("| 나이 : %d살 |\n", age); printf("| 학교 번호 : %d |\n", school_num); printf("| 취미 번호 : %d |\n", hobby_num); printf("| 좋아하는 수: %d |\n", fav_number); printf("+-----------------------+\n"); return 0; }

응용: 친구 소개 카드

변수 값만 바꾸면 친구 소개 카드도 만들 수 있다. 변수를 새로 선언해서 두 사람의 카드를 나란히 출력해 보자.

// 내 정보 int my_age = 14; int my_hobby = 5; // 친구 정보 int friend_age = 15; int friend_hobby = 1; printf("[나] 나이: %d, 취미번호: %d\n", my_age, my_hobby); printf("[친구] 나이: %d, 취미번호: %d\n", friend_age, friend_hobby);
실습 2: 친구 소개 카드
STEP 1
친구의 나이와 취미 번호를 변수에 저장하고 출력해 보자.
[친구] 나이: 15, 취미번호: 1
STEP 2
가족 소개도 추가해 보자. family_age 변수를 만들어 가족 한 명의 나이를 저장하고 출력하자.
[가족] 나이: 45, 취미번호: 2
실습 3: 숫자 통계 출력
STEP 1
좋아하는 숫자 3개를 변수에 저장하고, 그 합계를 계산해서 출력해 보자.
int num1 = 7; int num2 = 13; int num3 = 42; int total = num1 + num2 + num3; printf("합계: %d\n", total);
합계: 62

도전 문제

1
가족 소개 카드
쉬움
가족 한 명의 나이(family_age)와 취미 번호(family_hobby)를 변수에 저장하고, 아래처럼 출력하는 프로그램을 작성하시오.
출력[가족] 나이: 42살, 취미: 2번
힌트 보기
int family_age = 42;로 선언하고, printf에서 %d를 두 번 사용하면 된다.
정답 보기
#include <stdio.h> int main(void) { int family_age = 42; int family_hobby = 2; printf("[가족] 나이: %d살, 취미: %d번\n", family_age, family_hobby); return 0; }
2
3명의 나이 합계
쉬움
세 명의 나이를 각각 변수에 저장하고, 합계와 평균(정수)을 출력하시오.
출력합계: 42, 평균: 14
힌트 보기
평균은 total / 3으로 구한다. 정수 나누기이므로 소수점은 버려진다.
정답 보기
#include <stdio.h> int main(void) { int age1 = 13; int age2 = 14; int age3 = 15; int total = age1 + age2 + age3; int avg = total / 3; printf("합계: %d, 평균: %d\n", total, avg); return 0; }
3
좋아하는 숫자 통계
보통
좋아하는 숫자 5개를 변수에 저장하고, 합계/최댓값/최솟값을 출력하시오. (최대/최소는 직접 눈으로 확인해서 변수에 저장)
출력합계: 85, 최대: 42, 최소: 3
힌트 보기
5개 변수를 선언한 후, int max_val = 42;처럼 직접 가장 큰 값을 찾아 저장하면 된다.
정답 보기
#include <stdio.h> int main(void) { int n1 = 7, n2 = 13, n3 = 42, n4 = 20, n5 = 3; int total = n1 + n2 + n3 + n4 + n5; int max_val = 42; int min_val = 3; printf("합계: %d, 최대: %d, 최소: %d\n", total, max_val, min_val); return 0; }

이번 프로젝트에서 배운 것

  • int 변수를 선언하고 값을 저장하는 방법
  • printf에서 %d 서식 지정자로 정수를 출력하는 방법
  • 여러 변수를 하나의 printf에서 동시에 출력하는 방법
  • 변수 값을 바꾸면 출력 결과도 바뀐다는 것
  • 변수끼리 더하기, 나누기 같은 연산도 가능하다는 것
