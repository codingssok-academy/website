틱택토 게임

3×3 이차원 배열로 게임 보드를 만들고, O와 X가 번갈아 두며 가로·세로·대각선 승리를 판별하는 게임입니다.

이 프로젝트에서 배우는 것

  • 2차원 char 배열로 게임 보드를 표현합니다.
  • 가로·세로·대각선 승리 조건을 판별합니다.
  • while 반복문으로 게임 루프를 구현합니다.
  • 입력 유효성 검사(이미 채워진 칸 체크)를 합니다.

보드 초기화와 출력

3×3 char 배열을 '.'으로 초기화합니다. 행과 열을 구분하는 선을 함께 출력합니다.

char board[3][3]; // 초기화: 전체를 '.'으로 for (int r=0;r<3;r++) for (int c=0;c<3;c++) board[r][c] = '.'; // 보드 출력 함수 void printBoard(char b[3][3]) { printf("\n"); for (int r=0;r<3;r++) { printf(" %c | %c | %c\n", b[r][0],b[r][1],b[r][2]); if (r<2) printf("---+---+---\n"); } printf("\n"); }

승리 판별 함수

가로 3줄, 세로 3줄, 대각선 2줄 총 8가지 경우를 확인합니다.

int checkWin(char b[3][3], char p) { for (int i=0;i<3;i++) { if(b[i][0]==p&&b[i][1]==p&&b[i][2]==p) return 1; // 가로 if(b[0][i]==p&&b[1][i]==p&&b[2][i]==p) return 1; // 세로 } if(b[0][0]==p&&b[1][1]==p&&b[2][2]==p) return 1; // 대각선 if(b[0][2]==p&&b[1][1]==p&&b[2][0]==p) return 1; return 0; }

게임 루프 완성

#include <stdio.h> char board[3][3]; void initBoard() { for(int r=0;r<3;r++) for(int c=0;c<3;c++) board[r][c]='.'; } void printBoard() { for(int r=0;r<3;r++){ printf(" %c|%c|%c\n",board[r][0],board[r][1],board[r][2]); if(r<2) printf("-+-+-\n"); } } int checkWin(char p) { for(int i=0;i<3;i++){ if(board[i][0]==p&&board[i][1]==p&&board[i][2]==p)return 1; if(board[0][i]==p&&board[1][i]==p&&board[2][i]==p)return 1; } if(board[0][0]==p&&board[1][1]==p&&board[2][2]==p)return 1; if(board[0][2]==p&&board[1][1]==p&&board[2][0]==p)return 1; return 0; } int main() { initBoard(); char turn='O'; for(int move=0;move<9;move++){ printBoard(); int r,c; printf("%c 차례 (행 열): ",turn); scanf("%d %d",&r,&c); if(board[r][c]!='.'){move--;continue;} board[r][c]=turn; if(checkWin(turn)){printBoard();printf("%c 승리!\n",turn);return 0;} turn=(turn=='O')?'X':'O'; } printBoard(); printf("무승부!\n"); return 0; }

핵심 정리

  • 2차원 char 배열: board[3][3], '.'=빈칸, 'O'/'X'=플레이어
  • 승리 조건: 가로 3 + 세로 3 + 대각선 2 = 총 8가지
  • 턴 교체: turn = (turn=='O') ? 'X' : 'O'
  • 무승부: 9칸 모두 차고 승자가 없을 때
  • 입력 유효성: 범위 체크 + 빈칸 체크 동시에
