연결 리스트 활용
스택과 큐 구현

연결 리스트로 스택(LIFO)과 큐(FIFO)를 구현합니다. 자료구조의 핵심 두 가지를 직접 만들어봅니다.

이 유닛에서 배우는 것

  • 스택(LIFO)의 개념과 연결 리스트로 구현합니다.
  • push(앞에 삽입)와 pop(앞에서 제거)을 구현합니다.
  • 큐(FIFO)의 개념과 연결 리스트로 구현합니다.
  • enqueue(뒤에 삽입)와 dequeue(앞에서 제거)를 구현합니다.
  • 스택과 큐의 활용 예시를 설명할 수 있습니다.

스택 (Stack) — LIFO

스택은 Last In First Out — 마지막에 넣은 것이 먼저 나옵니다. 책을 쌓아놓고 위에서부터 꺼내는 것과 같습니다.

typedef struct Node { int data; struct Node *next; } Node; void push(Node **top, int data) { Node *n = (Node*)malloc(sizeof(Node)); n->data = data; n->next = *top; *top = n; } int pop(Node **top) { if (*top == NULL) { printf("비어있음\n"); return -1; } Node *tmp = *top; int val = tmp->data; *top = (*top)->next; free(tmp); return val; }

큐 (Queue) — FIFO

큐는 First In First Out — 먼저 넣은 것이 먼저 나옵니다. 줄 서기와 같습니다. tail 포인터를 별도 관리하면 O(1) 삽입이 가능합니다.

typedef struct { Node *front; // 꺼내는 쪽 Node *rear; // 넣는 쪽 } Queue; void enqueue(Queue *q, int data) { Node *n = (Node*)malloc(sizeof(Node)); n->data = data; n->next = NULL; if (q->rear) q->rear->next = n; else q->front = n; q->rear = n; } int dequeue(Queue *q) { if (!q->front) { printf("비어있음\n"); return -1; } Node *tmp = q->front; int val = tmp->data; q->front = q->front->next; if (!q->front) q->rear = NULL; free(tmp); return val; }

핵심 정리

핵심 정리

  • 스택(Stack) — LIFO, push/pop 모두 head(top)에서 처리
  • 큐(Queue) — FIFO, enqueue는 rear, dequeue는 front
  • rear 포인터 — 큐의 O(1) enqueue를 위해 필요
  • 연결 리스트 스택/큐 — 크기 제한 없음, 동적 확장 가능
