거스름돈 계산기

금액을 입력받아 500/100/50/10원 동전으로 거슬러주는 프로그램입니다. /(몫)와 %(나머지)의 핵심 활용, 그리디 알고리즘을 배웁니다.

이 프로젝트에서 배우는 것

  • /(몫)와 %(나머지)를 실전에서 활용할 수 있다
  • 그리디(Greedy) 알고리즘의 기본 개념을 이해한다
  • %= 복합 대입 연산자를 사용할 수 있다
  • 큰 단위부터 처리하는 순차적 로직을 구현할 수 있다

거스름돈 코드

1760원을 거슬러준다면? 500원 3개, 100원 2개, 50원 1개, 10원 1개입니다. 큰 동전부터 최대한 많이 사용하는 것이 그리디 알고리즘입니다.

#include <stdio.h> int main(void) { int money; printf("거스름돈 금액: "); scanf("%d", &money); printf("500원: %d개\n", money / 500); money %= 500; // 나머지를 다시 money에 저장 printf("100원: %d개\n", money / 100); money %= 100; printf(" 50원: %d개\n", money / 50); money %= 50; printf(" 10원: %d개\n", money / 10); return 0; }

도전 문제

Q1
직접 계산하기
쉬움
2340원의 동전 개수를 직접 계산하세요.
정답 보기
500원: 4개 (나머지 340) 100원: 3개 (나머지 40) 50원: 0개 (나머지 40) 10원: 4개 -- 총 11개
Q2
1000원 지폐 추가
보통
1000원 지폐도 포함해서 거스름돈을 계산하세요.
입력3760
출력1000원: 3장, 500원: 1개, ...
내 답안
정답 보기
printf("1000원: %d장\n", money / 1000); money %= 1000; // 이하 동일...
Q3
총 동전 개수 출력
보통
각 동전 개수를 변수에 저장하고, 마지막에 총 동전 개수도 출력하세요.
정답 보기
int c500 = money / 500; money %= 500; int c100 = money / 100; money %= 100; int c50 = money / 50; money %= 50; int c10 = money / 10; printf("총 %d개\n", c500+c100+c50+c10);

핵심 요약

  • 동전 개수 = 금액 / 단위, 남은 금액 = 금액 % 단위
  • 큰 단위부터 처리하는 것이 그리디(Greedy) 알고리즘이다
  • money %= 500으로 나머지를 다시 money에 저장한다
  • /와 %는 항상 짝으로 사용되는 경우가 많다
