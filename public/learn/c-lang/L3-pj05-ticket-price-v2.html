놀이공원
입장료 계산기

나이를 입력하면 입장료를 알려주는 프로그램을 만들어봅니다.
비교 연산자, if-else if-else, 논리 연산자를 종합 활용합니다.

if-else if-else 비교 연산자 논리 연산자 && || scanf / printf

이 프로젝트에서 만드는 것

  • 나이를 입력하면 입장료 등급을 판별하는 기본 계산기
  • 단체 할인(10명 이상 20% 할인) — && 활용
  • 장애인 할인(50% 할인) — || 활용
  • 여러 명의 입장료 합산 계산
  • 할인 쿠폰 시스템 도전 과제

구현 단계

1
나이 입력 받기
int age;를 선언하고 scanf로 입력 받습니다.
2
if - else if - else 로 요금 분기
4가지 조건을 순서대로 확인합니다. 어린이 → 청소년 → 성인 → 경로 순으로 작성합니다.
3
요금 출력
printf로 분기된 요금을 화면에 출력합니다.
/* 놀이공원 입장료 계산기 — 기본 버전 */ #include <stdio.h> int main() { int age; int price = 0; // 입장료 (원) printf("나이를 입력하세요: "); scanf("%d", &age); if (age <= 7) { // 어린이 price = 0; printf("어린이 — 무료입니다!\n"); } else if (age <= 17) { // 청소년 price = 15000; printf("청소년 — 입장료: %d원\n", price); } else if (age <= 64) { // 성인 price = 30000; printf("성인 — 입장료: %d원\n", price); } else { // 경로 (65세 이상) price = 0; printf("경로 우대 — 무료입니다!\n"); } return 0; }
실행 예시
나이를 입력하세요: 25
성인 — 입장료: 30000원
핵심 포인트  else if 조건은 위에서부터 차례대로 확인됩니다. age <= 17이 실행되는 시점은 이미 age > 7이 보장된 상태이므로, 8 <= age <= 17을 자동으로 의미합니다.

확장 과제 — 할인 기능 추가하기

기본 계산기에 3가지 할인 기능을 추가합니다. 각 확장마다 논리 연산자를 어떻게 쓰는지 집중해서 봅니다.

1
단체 할인 — 10명 이상이면 20% 할인
&& 활용
성인이면서 동시에 10명 이상일 때만 할인이 적용됩니다. 두 조건이 모두 참이어야 하므로 &&를 사용합니다.
int age, count; int price = 0; printf("나이: "); scanf("%d", &age); printf("인원 수: "); scanf("%d", &count); if (age <= 7) { price = 0; } else if (age <= 17) { price = 15000; } else if (age <= 64) { price = 30000; } else { price = 0; } // 단체 할인: 성인이면서(&&) 10명 이상 if (age >= 18 && age <= 64 && count >= 10) { price = price * 8 / 10; // 정수 연산으로 20% 할인 printf("단체 할인 적용! 입장료: %d원\n", price); } else { printf("입장료: %d원\n", price); }
2
장애인 할인 — 별도 입력, 50% 할인
|| 활용
단체 할인 또는 장애인 할인 중 하나라도 해당되면 할인이 적용됩니다. 둘 중 하나만 참이어도 되므로 ||를 사용합니다.
int disabled; // 1 = 장애인, 0 = 일반 printf("장애인 등록 여부 (1=예, 0=아니오): "); scanf("%d", &disabled); // 단체(10명+) 또는(||) 장애인이면 할인 if (count >= 10 || disabled == 1) { int rate = (disabled == 1) ? 5 : 8; // 장애인 50%, 단체 20% price = price * rate / 10; printf("할인 후 입장료: %d원\n", price); } else { printf("입장료: %d원\n", price); }
3
여러 명 합산 — 인원 수만큼 총 금액 계산
반복 없이 곱셈
같은 나이대의 여러 명이 입장할 때 총 금액을 계산합니다. 1인 요금을 구한 뒤 인원 수를 곱합니다.
int total = price * count; printf("\n--- 입장료 계산 결과 ---\n"); printf("인원 수 : %d명\n", count); printf("1인 요금 : %d원\n", price); printf("총 입장료: %d원\n", total);
실행 예시 (성인 12명)

인원 수 : 12명
1인 요금 : 24000원  (단체 20% 할인 적용)

전체 코드 — 통합 버전

지금까지 만든 기능을 하나의 프로그램으로 합칩니다.

/* 놀이공원 입장료 계산기 — 통합 버전 */ #include <stdio.h> int main() { int age, count, disabled; int price = 0; int total = 0; /* ── 1. 입력 ── */ printf("나이를 입력하세요: "); scanf("%d", &age); printf("인원 수를 입력하세요: "); scanf("%d", &count); printf("장애인 등록 여부 (1=예, 0=아니오): "); scanf("%d", &disabled); /* ── 2. 나이별 기본 요금 ── */ if (age <= 7) { price = 0; printf("[어린이] 기본 요금: 무료\n"); } else if (age <= 17) { price = 15000; printf("[청소년] 기본 요금: %d원\n", price); } else if (age <= 64) { price = 30000; printf("[성인] 기본 요금: %d원\n", price); } else { price = 0; printf("[경로] 기본 요금: 무료\n"); } /* ── 3. 할인 적용 ── */ if (disabled == 1) { // 장애인 50% 할인 우선 price = price / 2; printf("장애인 할인 50%% 적용 → %d원\n", price); } else if (count >= 10) { // 단체 20% 할인 price = price * 8 / 10; printf("단체 할인 20%% 적용 → %d원\n", price); } /* ── 4. 총 금액 ── */ total = price * count; printf("\n===== 최종 결제 금액 =====\n"); printf("인원 수 : %d명\n", count); printf("1인 요금 : %d원\n", price); printf("총 입장료: %d원\n", total); printf("========================\n"); return 0; }

인원 수를 입력하세요: 12
장애인 등록 여부 (1=예, 0=아니오): 0
[성인] 기본 요금: 30000원
단체 할인 20% 적용 → 24000원

도전 과제 — 할인 쿠폰 시스템 추가하기
어려움
쿠폰 번호를 정수로 입력받아, 1111이면 10% 추가 할인, 2222이면 5,000원 정액 할인을 적용하세요.
쿠폰이 적용된 뒤 금액이 0원 미만이면 0원으로 처리하세요 (음수 방지).
쿠폰 할인은 단체/장애인 할인이 모두 적용된 이후에 마지막으로 적용되어야 합니다.
유효하지 않은 쿠폰 번호(1111도 2222도 아닌 값)가 입력되면 "유효하지 않은 쿠폰입니다."를 출력하세요.

이 프로젝트에서 사용한 핵심 개념

  • if - else if - else : 여러 조건을 순서대로 검사하여 하나만 실행
  • && (AND) : 두 조건이 모두 참일 때만 실행 — 단체 할인
  • || (OR) : 조건 중 하나라도 참이면 실행 — 중복 할인 여부 판단
  • 비교 연산자 <= >= == : 나이 범위 판별에 활용
  • 정수 곱셈·나눗셈으로 % 할인 계산 (price * 8 / 10)
