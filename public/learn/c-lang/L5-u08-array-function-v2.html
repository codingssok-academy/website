Chapter L5-08

배열과 함수
미리보기

배열을 함수에 넘기면 포인터(주소)로 전달됩니다. 크기는 별도 매개변수로 함께 넘겨야 하며, 함수 안에서 배열을 수정하면 원본에 반영됩니다.

이 유닛에서 배우는 것

  • 배열을 함수에 전달하면 포인터로 전달되는 이유를 이해합니다.
  • void printArray(int arr[], int size) 패턴을 작성할 수 있습니다.
  • 크기를 함께 넘겨야 하는 이유를 설명할 수 있습니다.
  • 함수 안에서 배열을 수정하면 원본에도 반영됨을 이해합니다.
  • 배열 출력, 합계 계산, 초기화 함수를 직접 작성할 수 있습니다.

배열은 주소(포인터)로 전달된다

일반 변수를 함수에 넘기면 값의 복사본이 전달됩니다. 그러나 배열은 크기가 크므로 통째로 복사하지 않고 첫 번째 원소의 주소(포인터)를 전달합니다.

왜 크기도 같이 넘겨야 할까?

함수는 배열의 첫 번째 주소만 받습니다. 배열이 몇 개의 원소를 가지는지는 알 수 없습니다. 따라서 크기(size)를 별도 매개변수로 반드시 함께 전달해야 합니다.

sizeof 함정: 함수 안에서 sizeof(arr)는 포인터의 크기(4 또는 8바이트)를 반환합니다. 배열 전체의 크기가 아닙니다. 반드시 크기를 매개변수로 전달하세요.

배열 출력 함수 — printArray 패턴

가장 기본적이고 자주 쓰이는 패턴입니다. void printArray(int arr[], int size)로 선언하고, 안에서 for로 각 원소를 출력합니다.

#include <stdio.h> // 배열 출력 함수 void printArray(int arr[], int size) { for (int i = 0; i < size; i++) { printf("%d ", arr[i]); } printf("\n"); } // 배열 합계 함수 int sumArray(int arr[], int size) { int total = 0; for (int i = 0; i < size; i++) { total += arr[i]; } return total; } int main() { int scores[] = {85, 72, 91, 68, 95}; int n = 5; printArray(scores, n); // 85 72 91 68 95 printf("합계: %d\n", sumArray(scores, n)); // 합계: 411 return 0; }

함수 안에서 배열 수정 — 원본에 반영

배열은 주소로 전달되므로 함수 안에서 수정하면 호출한 쪽의 원본 배열이 변경됩니다. 이를 활용해 배열을 초기화하거나 변환하는 함수를 만들 수 있습니다.

// 배열 초기화 함수 (모든 원소를 0으로) void zeroArray(int arr[], int size) { for (int i = 0; i < size; i++) { arr[i] = 0; // 원본에 직접 반영됨! } } // 배열 모든 원소를 2배로 void doubleAll(int arr[], int size) { for (int i = 0; i < size; i++) { arr[i] *= 2; } } int main() { int data[] = {3, 7, 1, 5, 2}; printArray(data, 5); // 3 7 1 5 2 doubleAll(data, 5); printArray(data, 5); // 6 14 2 10 4 ← 원본 변경됨 zeroArray(data, 5); printArray(data, 5); // 0 0 0 0 0 return 0; }

핵심 정리

  • 배열은 함수에 주소(포인터)로 전달 — 복사가 아님
  • 함수 선언: void f(int arr[], int size) — size는 필수
  • 함수 안에서 arr[i]를 수정하면 원본 배열도 변경됨
  • 함수 안 sizeof(arr)는 배열 크기가 아닌 포인터 크기 반환
  • 포인터 상세 내용은 다음 챕터에서 다룹니다

출력최댓값: 12
힌트 / 정답 보기
첫 원소를 초기 최댓값으로 설정하고, 나머지와 비교하며 더 크면 갱신합니다.
int maxArray(int arr[], int size) { int max = arr[0]; for (int i = 1; i < size; i++) if (arr[i] > max) max = arr[i]; return max; } int main() { int a[] = {5, 12, 3, 9, 7}; printf("최댓값: %d\n", maxArray(a, 5)); }

sizeof 함정 분석
어려움
아래 코드의 출력을 예측하고, 함수 안에서 sizeof가 다르게 나오는 이유를 설명하세요. (int가 4바이트, 포인터가 8바이트인 환경 기준)
void checkSize(int arr[], int size) { printf("함수 안 sizeof(arr): %zu\n", sizeof(arr)); } int main() { int data[5] = {1,2,3,4,5}; printf("main sizeof(data): %zu\n", sizeof(data)); checkSize(data, 5); }
힌트 / 정답 보기
main에서는 배열 전체 크기, 함수 안에서는 포인터 크기가 출력됩니다.
main sizeof(data): 20 // 5 * 4 = 20바이트 (배열 전체) 함수 안 sizeof(arr): 8 // 포인터 크기 (64비트 환경) 이유: 함수 매개변수 int arr[]는 사실 int *arr (포인터)로 처리되므로, sizeof가 포인터 크기를 반환합니다. → 반드시 size를 별도로 전달해야 합니다.
