Unit 09 · Level 4 — 반복문 심화

별 찍기 패턴

이중 for문으로 다양한 별 패턴을 만들어 봅니다. 행과 열의 관계를 파악하면 어떤 패턴도 만들 수 있습니다.

이 유닛에서 배우는 것

  • 이중 for문의 바깥 루프(행)와 안쪽 루프(열)의 역할을 설명할 수 있습니다.
  • i행에서 별의 개수와 공백의 개수를 수식으로 나타낼 수 있습니다.
  • 직각삼각형, 역삼각형, 이등변삼각형 패턴을 코드로 작성할 수 있습니다.
  • 다이아몬드 패턴을 윗부분과 아랫부분으로 나누어 구현할 수 있습니다.
  • 새로운 패턴이 주어졌을 때 규칙을 찾아 코드로 바꿀 수 있습니다.

이중 for문 — 행과 열

별 찍기는 바깥 for문이 행(줄)을 담당하고, 안쪽 for문이 열(칸)을 담당합니다. 핵심은 몇 행에 몇 개의 별을 찍느냐를 수식으로 표현하는 것입니다.

직각삼각형 패턴

규칙 공식 (n = 전체 행 수)
i행에서 별 개수 = i개
i행에서 공백 개수 = 없음 (왼쪽 정렬)
// 직각삼각형 (왼쪽 정렬) int n = 5; for (int i = 1; i <= n; i++) { // 바깥: 행 번호 for (int j = 1; j <= i; j++) { // 안쪽: i개의 별 printf("*"); } printf("\n"); // 줄 바꿈 }

역삼각형 & 이등변삼각형

역삼각형 패턴

직각삼각형을 뒤집으면 됩니다. i행에서의 별 개수는 n - i + 1개입니다.

규칙 공식
i행 별 개수 = n - i + 1 개
예) n=5, 1행=5개, 2행=4개, 3행=3개 ...
int n = 5; for (int i = 1; i <= n; i++) { for (int j = 1; j <= n - i + 1; j++) { // 별: n-i+1개 printf("*"); } printf("\n"); }

이등변삼각형 패턴

이등변삼각형은 공백 + 별 + 공백 구조입니다. i행에서 앞쪽 공백은 n - i개, 별은 2*i - 1개입니다.

규칙 공식 (핵심!)
앞 공백 개수 = n - i 개
별 개수 = 2 * i - 1 개
예) n=5, i=3: 공백 2개 + 별 5개
int n = 5; for (int i = 1; i <= n; i++) { for (int j = 1; j <= n - i; j++) { // 앞 공백: n-i개 printf(" "); } for (int j = 1; j <= 2 * i - 1; j++) { // 별: 2i-1개 printf("*"); } printf("\n"); }

다이아몬드 패턴

다이아몬드는 윗부분(이등변삼각형)과 아랫부분(역이등변삼각형)을 합친 것입니다. 두 루프를 순서대로 작성하면 됩니다.

int n = 3; // n=3이면 높이 2n-1=5 // 위쪽 (i = 1 ~ n) for (int i = 1; i <= n; i++) { for (int j = 1; j <= n - i; j++) printf(" "); // 공백 for (int j = 1; j <= 2 * i - 1; j++) printf("*"); // 별 printf("\n"); } // 아래쪽 (i = n-1 ~ 1) for (int i = n - 1; i >= 1; i--) { for (int j = 1; j <= n - i; j++) printf(" "); // 공백 for (int j = 1; j <= 2 * i - 1; j++) printf("*"); // 별 printf("\n"); }

Unit 09 핵심 정리

  • 바깥 for = 행 / 안쪽 for = 열 (이중 루프 구조)
  • 직각삼각형 i행 별 개수: i개
  • 역삼각형 i행 별 개수: n - i + 1개
  • 이등변삼각형: 공백 (n-i)개 + 별 (2i-1)개
  • 다이아몬드 = 윗 이등변삼각형 + 아랫 역이등변삼각형
