미니 스프레드시트

2차원 배열로 행과 열을 가진 표를 만들고, 각 행과 열의 합계를 자동으로 계산하여 출력합니다.

이 프로젝트에서 배우는 것

  • 2차원 배열 선언과 초기화 방법을 배웁니다.
  • 중첩 for문으로 행과 열을 순회합니다.
  • 행 합계와 열 합계를 각각 계산합니다.
  • 표 형식으로 데이터를 정렬 출력합니다.

2차원 배열 선언과 접근

2차원 배열은 행(row)과 열(column)을 가진 표입니다. arr[행][열]로 특정 칸에 접근합니다.

// 2차원 배열 선언과 초기화 int data[3][4] = { {85, 90, 88, 92}, // 0행: 국어 {75, 80, 78, 82}, // 1행: 수학 {90, 85, 95, 88} // 2행: 영어 }; // 접근: data[행][열] printf("%d\n", data[1][2]); // 78 (수학 3분기)

행 합계와 열 합계

// 행 합계 for (int r = 0; r < 3; r++) { int rowSum = 0; for (int c = 0; c < 4; c++) rowSum += data[r][c]; printf("%d행 합계: %d\n", r, rowSum); } // 열 합계 for (int c = 0; c < 4; c++) { int colSum = 0; for (int r = 0; r < 3; r++) colSum += data[r][c]; printf("%d열 합계: %d\n", c, colSum); }

표 형식으로 출력하기

printf의 %Nd 형식을 사용해 숫자를 고정 너비로 출력하면 깔끔한 표 형식이 됩니다.

#include <stdio.h> int main() { char *label[3] = {"국어", "수학", "영어"}; int data[3][4] = { {85,90,88,92}, {75,80,78,82}, {90,85,95,88} }; printf("%-6s %5s %5s %5s %5s %6s\n", "과목","1분기","2분기","3분기","4분기","합계"); printf("------------------------------------\n"); int colSum[4] = {0}; for (int r=0;r<3;r++) { int rSum = 0; printf("%-6s", label[r]); for (int c=0;c<4;c++) { printf("%6d", data[r][c]); rSum += data[r][c]; colSum[c] += data[r][c]; } printf("%7d\n", rSum); } printf("합계 "); for(int c=0;c<4;c++) printf("%6d",colSum[c]); printf("\n"); return 0; }

출력전체 평균: 85.7

각 행의 최고점 찾기

출력국어 최고: 92 (4분기)

for(int r=0;r<3;r++){ int mx=data[r][0],mci=0; for(int c=1;c<4;c++) if(data[r][c]>mx){mx=data[r][c];mci=c;} printf("%s 최고:%d (%d분기)\n",label[r],mx,mci+1); }
3
행렬 전치 (Transpose)
어려움
3×4 행렬을 4×3으로 전치(행↔열 교환)하여 출력하세요. trans[c][r] = data[r][c]
원본3행 4열 data[3][4]
전치4행 3열 trans[4][3]
힌트 보기
int trans[4][3]; for(r) for(c) trans[c][r] = data[r][c];

핵심 정리

  • 2차원 배열: int arr[행수][열수]
  • 접근: arr[r][c] (r=행 인덱스, c=열 인덱스)
  • 행 순회: 외부 for=행, 내부 for=열
  • 열 순회: 외부 for=열, 내부 for=행
  • printf %6d: 6칸 고정 너비 출력 (표 정렬용)
