성적 등급 판정기

점수를 입력하면 A~F 등급을 자동으로 판정하는 프로그램. else if 분기를 집중 활용합니다.

이 프로젝트에서 배우는 것

  • scanf로 사용자 입력을 받을 수 있습니다.
  • if / else if / else 분기 구조를 완전히 이해합니다.
  • 범위 조건(>= 90 등)을 올바른 순서로 작성합니다.
  • 과목 3개의 평균을 구해 등급을 판정합니다.
  • +/− 세분화 등급(A+, B−…)으로 확장합니다.
  • 입력 검증(0~100 범위 체크)으로 안전한 프로그램을 만듭니다.

단계 1 — 점수 입력 받기

scanf를 사용해 사용자로부터 점수를 입력받습니다. %d 형식 지정자로 정수를 읽어옵니다.

#include <stdio.h> int main() { int score; printf("점수를 입력하세요 (0~100): "); scanf("%d", &score); // & 는 변수의 주소 printf("입력된 점수: %d\n", score); return 0; }

단계 2 — else if 분기로 등급 판정

조건이 여러 개일 때 else if를 사용합니다. 위에서 아래로 순서대로 검사하며, 처음 참이 되는 블록 하나만 실행됩니다.

#include <stdio.h> int main() { int score; printf("점수 입력 (0~100): "); scanf("%d", &score); if (score >= 90) { printf("등급: A\n"); } else if (score >= 80) { printf("등급: B\n"); } else if (score >= 70) { printf("등급: C\n"); } else if (score >= 60) { printf("등급: D\n"); } else { printf("등급: F\n"); } return 0; }

확장 1 — 과목 3개 평균 등급 판정

국어, 영어, 수학 세 과목 점수를 입력받아 평균을 구하고 등급을 판정합니다. 정수 나눗셈 주의: 평균은 float으로 처리합니다.

#include <stdio.h> int main() { int kor, eng, math; float avg; printf("국어 점수: "); scanf("%d", &kor); printf("영어 점수: "); scanf("%d", &eng); printf("수학 점수: "); scanf("%d", &math); avg = (kor + eng + math) / 3.0f; // 3이 아닌 3.0f → 실수 나눗셈 printf("평균: %.1f점\n", avg); if (avg >= 90) printf("등급: A\n"); else if (avg >= 80) printf("등급: B\n"); else if (avg >= 70) printf("등급: C\n"); else if (avg >= 60) printf("등급: D\n"); else printf("등급: F\n"); return 0; }

확장 2 — +/− 세분화 등급

등급을 A+, A, A− 형태로 세분화합니다. 구간을 5점 단위로 나누면 됩니다. 조건을 높은 점수부터 내려가는 순서로 작성해야 합니다.

if (score >= 95) printf("A+\n"); else if (score >= 90) printf("A\n"); else if (score >= 85) printf("B+\n"); else if (score >= 80) printf("B\n"); else if (score >= 75) printf("B-\n"); else if (score >= 70) printf("C+\n"); else if (score >= 65) printf("C\n"); else if (score >= 60) printf("C-\n"); else printf("F\n");

확장 3 — 입력 검증 (0~100 범위 체크)

사용자가 음수나 100 초과의 값을 입력하면 오류 메시지를 출력합니다. 점수 입력 직후 범위를 먼저 확인합니다.

scanf("%d", &score); if (score < 0 || score > 100) { printf("오류: 0~100 사이의 점수를 입력하세요.\n"); } else if (score >= 90) { printf("등급: A\n"); } else if (score >= 80) { printf("등급: B\n"); } /* ... 이하 동일 ... */

전체 완성 코드 — 성적 등급 판정기 (최종)

지금까지 배운 모든 내용을 합친 최종 버전입니다. 세 과목 평균 + 세분화 등급 + 입력 검증이 모두 포함됩니다.

#include <stdio.h> int main() { int kor, eng, math; float avg; /* ── 1. 입력 ── */ printf("국어 점수: "); scanf("%d", &kor); printf("영어 점수: "); scanf("%d", &eng); printf("수학 점수: "); scanf("%d", &math); /* ── 2. 범위 검증 ── */ if (kor < 0 || kor > 100 || eng < 0 || eng > 100 || math < 0 || math > 100) { printf("오류: 모든 점수는 0~100이어야 합니다.\n"); return 1; // 오류 종료 } /* ── 3. 평균 ── */ avg = (kor + eng + math) / 3.0f; printf("\n===== 성적 결과 =====\n"); printf("국어: %d 영어: %d 수학: %d\n", kor, eng, math); printf("평균: %.1f점\n", avg); /* ── 4. 세분화 등급 판정 ── */ printf("등급: "); if (avg >= 95) printf("A+\n"); else if (avg >= 90) printf("A\n"); else if (avg >= 85) printf("B+\n"); else if (avg >= 80) printf("B\n"); else if (avg >= 75) printf("B-\n"); else if (avg >= 70) printf("C+\n"); else if (avg >= 65) printf("C\n"); else if (avg >= 60) printf("C-\n"); else printf("F\n"); return 0; }

3
최고/최저 과목 찾기
어려움
세 과목 중 가장 높은 점수와 가장 낮은 점수를 찾아 출력하세요. if / else if로 kor, eng, math를 비교합니다.
4
장학금 기준 판정
어려움
평균 95 이상이면 "전액 장학금", 90 이상이면 "반액 장학금", 그 외면 "해당 없음"을 출력하세요. 세분화 등급 로직과 동일한 패턴입니다.

핵심 정리

  • else if 체인은 위에서부터 검사 — 처음 참인 블록 하나만 실행됩니다.
  • 점수 범위 조건은 반드시 높은 값부터 내려가는 순서로 작성합니다.
  • 정수 나눗셈 함정 — 평균은 / 3.0f로 실수 나눗셈을 해야 합니다.
  • 입력 검증은 분기 처리 전 가장 먼저 수행합니다.
  • return 1;은 오류 종료를 나타내는 관례입니다.
