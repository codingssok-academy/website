로그인 시스템
만들기

비밀번호를 맞추면 입장! — 변수, 입력, if-else를 하나로 묶는 첫 번째 실전 프로젝트입니다.

이 프로젝트에서 만드는 것

  • 변수로 비밀번호를 미리 저장하고 사용자 입력과 비교합니다.
  • if-else 조건문으로 로그인 성공/실패를 판단합니다.
  • ID + 비밀번호 동시 확인에 && 연산자를 활용합니다.
  • 실패 횟수를 변수로 추적하는 카운터를 구현합니다.
  • 관리자 계정 분리로 다중 조건 처리를 경험합니다.

단계별 구현 — 기본 로그인

4단계로 나눠서 하나씩 쌓아갑니다. 각 단계를 완성한 뒤 다음으로 넘어가세요.

1
비밀번호를 변수에 저장
변수
실제 비밀번호를 프로그램 안에 미리 저장합니다. int 타입으로 숫자 비밀번호를 사용합니다.
#include <stdio.h> int main() { int password = 1234; // 저장된 비밀번호 printf("비밀번호: %d\n", password); return 0; }
포인트: password 변수 하나만 바꾸면 전체 프로그램의 비밀번호가 바뀝니다. 값이 여러 곳에 퍼지지 않도록 변수로 관리합니다.
2
사용자 입력 받기
scanf
키보드로 숫자를 입력받아 새로운 변수 input에 저장합니다.
int password = 1234; int input; // 사용자가 입력할 변수 printf("비밀번호 입력: "); scanf("%d", &input); // & 꼭 필요!
주의: scanf에서 &input처럼 변수 앞에 &를 반드시 붙여야 합니다. 빠뜨리면 프로그램이 잘못된 곳에 값을 씁니다.
3
if-else로 비교 후 결과 출력
if-else
입력값과 저장된 비밀번호를 ==로 비교합니다. 같으면 성공, 다르면 실패 메시지를 출력합니다.
if (input == password) { printf("로그인 성공!\n"); printf("환영합니다.\n"); } else { printf("비밀번호가 틀렸습니다.\n"); }
입력이 1234일 때
비밀번호 입력: 1234 로그인 성공! 환영합니다.
입력이 0000일 때
비밀번호 입력: 0000 비밀번호가 틀렸습니다.

기본 로그인 흐름도

확장 과제 — 기능 추가하기

기본 로그인이 완성되면 아래 확장 과제를 순서대로 추가합니다. 각 확장은 앞 단계 코드 위에 쌓입니다.

확장 1
ID + 비밀번호 동시 확인 — && 활용
비밀번호만 확인하는 것에서 ID(정수)까지 함께 확인하도록 확장합니다. && 연산자로 두 조건을 동시에 검사합니다.
int correct_id = 1001; // 저장된 ID int correct_pw = 1234; // 저장된 비밀번호 int input_id, input_pw; printf("ID 입력: "); scanf("%d", &input_id); printf("비밀번호 입력: "); scanf("%d", &input_pw); if (input_id == correct_id && input_pw == correct_pw) { printf("로그인 성공!\n"); } else { printf("ID 또는 비밀번호가 틀렸습니다.\n"); }
&& 연산자: 왼쪽 조건과 오른쪽 조건이 둘 다 참일 때만 전체가 참입니다. ID가 맞아도 비밀번호가 틀리면 실패합니다.
확장 2
실패 횟수 카운터 — 변수 활용
틀릴 때마다 카운터 변수를 1씩 늘려서 "3번 중 N번 실패"를 표시합니다. 변수를 누적하는 패턴을 익힙니다.
int fail_count = 0; // 실패 횟수 카운터 if (input == password) { printf("로그인 성공!\n"); } else { fail_count = fail_count + 1; // 또는 fail_count++; printf("비밀번호 틀림! (3번 중 %d번 실패)\n", fail_count); }
fail_count++는 fail_count = fail_count + 1과 완전히 같습니다. C언어에서 자주 쓰는 단축 표현이니 두 형태 모두 익혀두세요.
확장 3
관리자 계정 분리 — 다중 조건
일반 사용자와 관리자를 ID로 구분합니다. 관리자 ID로 로그인하면 특별 메시지가 출력됩니다. else if로 3가지 경우를 처리합니다.
int admin_id = 9999; // 관리자 ID int user_id = 1001; // 일반 사용자 ID int correct_pw = 1234; if (input_id == admin_id && input_pw == correct_pw) { printf("[관리자] 로그인 성공! 모든 권한이 있습니다.\n"); } else if (input_id == user_id && input_pw == correct_pw) { printf("[일반] 로그인 성공! 환영합니다.\n"); } else { printf("로그인 실패!\n"); }

개념 코드 예시 역할

전체 코드 — 확장 3 완성본

모든 확장을 합친 최종 코드입니다. 직접 타이핑하면서 각 줄의 역할을 소리 내어 말해보세요.

#include <stdio.h> int main() { // ── 저장된 계정 정보 ────────────────────────── int admin_id = 9999; int user_id = 1001; int correct_pw = 1234; int fail_count = 0; // 실패 횟수 // ── 사용자 입력 ─────────────────────────────── int input_id, input_pw; printf("=== 로그인 ===\n"); printf("ID: "); scanf("%d", &input_id); printf("비밀번호: "); scanf("%d", &input_pw); // ── 로그인 판별 ─────────────────────────────── if (input_id == admin_id && input_pw == correct_pw) { printf("\n[관리자] 로그인 성공!\n"); printf("모든 데이터에 접근할 수 있습니다.\n"); } else if (input_id == user_id && input_pw == correct_pw) { printf("\n[일반] 로그인 성공!\n"); printf("환영합니다. (ID: %d)\n", input_id); } else { fail_count++; printf("\n로그인 실패 (3번 중 %d번 실패)\n", fail_count); printf("ID 또는 비밀번호를 확인하세요.\n"); } return 0; }
관리자 로그인 시
=== 로그인 === ID: 9999 비밀번호: 1234 [관리자] 로그인 성공! 모든 데이터에 접근할 수 있습니다.

도전 과제

1
3회 실패 시 잠금
보통
fail_count가 3이 되면 "계정이 잠겼습니다." 메시지를 추가로 출력하세요. if (fail_count >= 3) 조건을 실패 처리 블록 안에 추가합니다.
힌트 보기
else 블록 안에서 fail_count++를 한 뒤, 바로 아래에 if (fail_count >= 3) { printf("계정이 잠겼습니다.\n"); }를 추가하세요.
2
ID와 비밀번호 오류를 따로 구분
보통
로그인 실패 시 "ID가 없습니다" 또는 "비밀번호가 틀렸습니다"를 구분해서 출력하세요. ID는 맞지만 비밀번호가 다른 경우를 별도 else if로 처리합니다.
힌트 보기
먼저 if (input_id == user_id || input_id == admin_id)로 ID 존재 여부를 확인하고, 그 안에서 비밀번호를 비교합니다.
3
게스트 모드 추가
어려움
ID를 0으로 입력하면 비밀번호 없이 "게스트 모드로 입장합니다." 메시지를 출력하세요. 세 번째 계정 타입을 처리하는 else if를 추가합니다. 단, 게스트는 관리자·일반 확인보다 먼저 체크해야 합니다. 왜 그럴까요?
힌트 보기
조건문은 위에서 아래로 순서대로 검사됩니다. 게스트 조건을 가장 위에 놓아야 admin_id, user_id 검사 전에 먼저 처리됩니다.
if (input_id == 0) { printf("게스트 모드로 입장합니다.\n"); }

프로젝트 핵심 정리

  • 변수 하나로 비밀번호를 관리하면 수정이 쉬워집니다.
  • ==는 비교, =는 대입 — 절대 혼동하지 않습니다.
  • &&로 여러 조건을 동시에 체크할 수 있습니다.
  • 카운터 패턴 count++은 반복, 누적, 시도 횟수 추적에 씁니다.
  • else if 체인은 위에서 아래로 순서대로 검사됩니다.
