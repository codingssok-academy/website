Chapter 12

증감 연산: ++, --

1을 더하거나 빼는 가장 짧은 표현. 전위와 후위의 차이를 정확히 이해하면 코드가 간결해집니다.

학습 로드맵

핵심 연산자

전위 vs 후위 — 이 유닛의 핵심!

이 유닛에서 배우는 것

  • i++과 i--의 의미를 안다
  • i++과 i+=1과 i=i+1이 같다는 것을 안다
  • 전위 증감(++i)과 후위 증감(i++)의 차이를 정확히 이해한다
  • 카운터 변수에서 ++을 실전에 활용할 수 있다
  • printf 안에서 ++ 사용 시 주의사항을 안다

++ 과 -- : 1씩 증가 / 감소

i++은 i = i + 1과 완전히 같습니다. 단지 더 짧게 쓰는 방법입니다. 마찬가지로 i--는 i = i - 1입니다.

메모리 값이 변하는 과정

세 가지 표현 — 모두 같은 의미!

#include <stdio.h> int main(void) { int i = 5; i++; // i = 6 (i = i + 1 과 같음) printf("i = %d\n", i); // 6 i++; // i = 7 printf("i = %d\n", i); // 7 i--; // i = 6 (i = i - 1 과 같음) printf("i = %d\n", i); // 6 return 0; }
따라해보세요
1
위 코드를 실행해서 6, 7, 6이 순서대로 출력되는지 확인하세요.
출력: 6 → 7 → 6
2
int n = 10; n--; n--; printf("%d", n); 실행 전에 결과를 예측하고 확인하세요.
8 출력 (10에서 두 번 빼면 8)
3
int a = 3; a = a + 1;을 a++으로 바꿔 쓰고, 결과가 같은지 확인하세요.
둘 다 a = 4로 동일

전위 vs 후위: 이게 핵심!

단독으로 쓸 때는 차이가 없습니다. 하지만 다른 수식 안에서 쓸 때 결과가 달라집니다!

후위 증감 i++ — "쓰고 올리기"

전위 증감 ++i — "올리고 쓰기"

비교표 — int a = 5일 때

코드 실행 순서 b의 값 a의 값 기억법
b = a++ b=a 먼저 → a+1 5 6 쓰고 올리기
b = ++a a+1 먼저 → b=a 6 6 올리고 쓰기
b = a-- b=a 먼저 → a-1 5 4 쓰고 내리기
b = --a a-1 먼저 → b=a 4 4 내리고 쓰기
int a = 5, b; b = a++; // 후위: b=5(옛날 값), a=6(나중에 증가) printf("b=%d, a=%d\n", b, a); // b=5, a=6 a = 5; b = ++a; // 전위: a=6(먼저 증가), b=6(새 값 사용) printf("b=%d, a=%d\n", b, a); // b=6, a=6
따라해보세요
1
위 전위/후위 코드를 직접 실행해서 비교표와 같은 결과가 나오는지 확인하세요.
후위: b=5, a=6 / 전위: b=6, a=6
2
int c = 10; printf("%d\n", c--); 결과를 예측하고 확인하세요.
10 출력 (후위: 출력 후에 c가 9로 감소)
3
int c = 10; printf("%d\n", --c); 결과는?
9 출력 (전위: 먼저 9로 감소 후 출력)

실전 활용과 주의사항

카운터 변수 패턴

게임의 점수, 클릭 횟수, 반복 횟수 등을 셀 때 count++을 가장 많이 씁니다.

#include <stdio.h> int main(void) { int count = 0; // 카운터 초기화 count++; // 1번 클릭 count++; // 2번 클릭 count++; // 3번 클릭 printf("총 클릭 횟수: %d\n", count); // 3 int lives = 3; // 목숨 3개 lives--; // 목숨 1개 감소 printf("남은 목숨: %d\n", lives); // 2 return 0; }

주의사항 1 — printf 안에서 ++ 쓰기

int i = 5; // 이렇게 쓰면 명확하다 i++; printf("%d\n", i); // 6 출력 // printf 안에서 후위 증감: i 출력 후 증가 i = 5; printf("%d\n", i++); // 5 출력, 출력 후 i=6 printf("%d\n", i); // 6 출력

주의사항 2 — 같은 변수에 ++ 두 번 금지

미정의 동작 (Undefined Behavior) — 컴파일러마다 결과가 달라집니다!
i++ + i++ 또는 a[i] = i++ 처럼 같은 줄에서 같은 변수를 두 번 이상 변경하는 코드는 절대 쓰지 마세요.
// 절대 금지! — 미정의 동작 int i = 5; int x = i++ + i++; // 결과를 예측할 수 없다! // 올바른 방법 — 한 줄에 하나씩 i = 5; int a = i++; // a=5, i=6 int b = i++; // b=6, i=7
따라해보세요
1
카운터 패턴을 직접 만들어보세요. score = 0에서 시작해서 score++을 4번 실행하고 출력하세요.
score = 4
2
int i = 3; printf("%d\n", i++); printf("%d\n", i); 출력 결과 두 줄을 예측하세요.
3, 4 (후위: 출력은 3, 그 후 i가 4)
3
int i = 3; printf("%d\n", ++i); printf("%d\n", i); 출력 결과 두 줄을 예측하세요.
4, 4 (전위: 먼저 i가 4, 출력도 4)

Q5
복합 증감 추적 (도전)
어려움
아래 코드의 최종 출력 결과를 구하세요. 각 단계를 종이에 적으면서 풀어보세요.
int a = 3, b = 10, c; c = a++ + b; // c=? a=? b=? c = c + --b; // c=? a=? b=? printf("%d %d %d\n", a, b, c);
내 답안
정답 보기
1줄씩 천천히. a++는 후위(a의 현재 값 사용 후 증가), --b는 전위(먼저 감소 후 사용).
c = a++ + b; → a=3(후위라 현재 값 사용), b=10 → c = 3 + 10 = 13 → 이후 a = 4 c = c + --b; → --b(전위라 먼저 감소): b = 9 → c = 13 + 9 = 22 printf → a=4, b=9, c=22

핵심 요약

  • i++은 i = i + 1과 같다 — 1 증가하는 가장 짧은 표현
  • i--는 i = i - 1과 같다 — 1 감소하는 가장 짧은 표현
  • 후위(i++): 현재 값을 먼저 사용, 그 후 증가 — "쓰고 올리기"
  • 전위(++i): 먼저 증가, 그 후 값을 사용 — "올리고 쓰기"
  • 단독 사용 i++;은 전위/후위 차이 없다
  • 같은 줄에서 같은 변수에 ++을 두 번 쓰면 미정의 동작 — 절대 금지
