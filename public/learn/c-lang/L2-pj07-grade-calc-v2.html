성적 등급 계산기

3과목 점수를 입력받아 합계와 평균을 구합니다. 정수 합을 3.0으로 나눠 실수 평균을 구하는 형변환을 배웁니다.

이 프로젝트에서 배우는 것

  • int 변수 여러 개를 선언하고 입력받을 수 있다
  • 정수의 합계를 구할 수 있다
  • 정수 합을 3.0으로 나눠 실수 평균을 구할 수 있다
  • float와 int의 차이를 이해한다
  • printf에서 %d와 %.1f를 구분해서 사용할 수 있다

정수 합계와 실수 평균

시험 점수는 보통 정수입니다. 국어 85점, 영어 90점, 수학 78점처럼요. 하지만 평균은 소수점이 나올 수 있습니다.

핵심은 나누는 수를 3.0(실수)으로 쓰는 것입니다. 정수끼리 나누면 소수점이 사라집니다.

#include <stdio.h> int main(void) { int kor, eng, math, sum; float avg; printf("국어 점수: "); scanf("%d", &kor); printf("영어 점수: "); scanf("%d", &eng); printf("수학 점수: "); scanf("%d", &math); sum = kor + eng + math; avg = sum / 3.0; // 3.0으로 나눠야 실수 평균! printf("합계: %d\n", sum); printf("평균: %.1f\n", avg); return 0; }

핵심 요약

  • 점수(정수)는 int, 평균(실수)은 float에 저장한다
  • 정수끼리 나누면 소수점이 사라진다 (10/3 = 3)
  • 3.0으로 나누면 실수 결과가 나온다 (10/3.0 = 3.3)
  • %d는 정수 출력, %.1f는 소수점 1자리 출력이다
  • 여러 변수를 int a, b, c;처럼 한 줄에 선언할 수 있다
