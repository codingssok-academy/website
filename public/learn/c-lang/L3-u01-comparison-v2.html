비교 연산자
==, !=, <, >, <=, >=

두 값을 비교해서 참(1) 또는 거짓(0)을 얻는 방법을 배웁니다. 조건문의 핵심입니다.

이 유닛에서 배우는 것

  • 비교 연산자 6개의 의미를 설명할 수 있습니다.
  • ==과 =의 차이를 정확히 구분할 수 있습니다.
  • >=과 >의 차이(경계값 포함 여부)를 이해합니다.
  • 변수끼리 비교하고 결과를 출력할 수 있습니다.
  • 복합 수식에서 비교 연산자를 올바르게 사용합니다.

비교 연산자란?

비교 연산자는 두 값을 비교한 뒤 결과를 참(1) 또는 거짓(0) 으로 알려줍니다. 수학 시간에 배운 부등호와 비슷하지만, 컴퓨터는 반드시 1이나 0으로 답합니다.

가장 중요한 실수 — == 과 = 의 차이

수학에서 =는 "같다"이지만, C언어에서 =는 대입(값 넣기), ==는 비교(같은지 확인)입니다. 절대 헷갈리면 안 됩니다!

6개 비교 연산자 총정리

// 비교 연산자 기본 사용법 #include <stdio.h> int main() { printf("%d\n", 5 == 5); // 1 (참) printf("%d\n", 5 == 3); // 0 (거짓) printf("%d\n", 5 != 3); // 1 (참) printf("%d\n", 3 < 5); // 1 (참) printf("%d\n", 3 >= 7); // 0 (거짓) return 0; }
따라해보세요
1
10 == 10과 10 == 5의 결과를 각각 출력해보세요.
printf("%d\n", 10 == 10); // 같은가? printf("%d\n", 10 == 5); // 같은가?
1 / 0 이 출력됩니다
2
변수 a = 7로 선언하고, a != 3의 결과를 출력하세요.
int a = 7; printf("%d\n", a != 3); // 7은 3과 다른가?
1 이 출력됩니다 (7은 3과 다름)
3
아래 코드에서 틀린 부분을 찾아 고치세요. (목적: a가 5와 같은지 확인)
int a = 5; printf("%d", a = 5); // 이게 맞을까?
a = 5 를 a == 5 로 바꿔야 합니다

크기 비교 — >, <, >=, <=

수직선 위에서 범위를 생각하면 이해하기 쉽습니다. >와 >=의 차이는 경계값(같을 때)을 포함하느냐 아니냐입니다.

#include <stdio.h> int main() { int x = 5; printf("x > 5 : %d\n", x > 5); // 0 (5는 5 초과 아님) printf("x >= 5 : %d\n", x >= 5); // 1 (5는 5 이상) printf("x < 5 : %d\n", x < 5); // 0 (5는 5 미만 아님) printf("x <= 5 : %d\n", x <= 5); // 1 (5는 5 이하) printf("x < 10 : %d\n", x < 10); // 1 (5는 10 미만) return 0; }
따라해보세요
1
변수 score = 60일 때, score >= 60과 score > 60의 차이를 확인하세요.
int score = 60; printf("%d\n", score >= 60); // 이상: 1 printf("%d\n", score > 60); // 초과: 0
1 / 0 — 합격 기준이 60점이라면 >= 을 써야 합니다!
2
변수 age = 18일 때, age < 19와 age <= 18의 결과를 출력하세요.
int age = 18; printf("%d\n", age < 19); // 18은 19 미만? printf("%d\n", age <= 18); // 18은 18 이하?
1 / 1 — 둘 다 참입니다
3
변수 n = 100일 때, n >= 100, n > 100, n <= 100 세 가지를 출력하세요.
int n = 100; printf("%d %d %d\n", n >= 100, n > 100, n <= 100);
1 0 1 — 이상/이하는 경계값 포함

비교 연산자 활용

변수에 저장된 값끼리도 비교할 수 있습니다. 두 변수 a와 b를 비교하면 그 순간의 값으로 결과가 나옵니다.

// 변수끼리 비교 int a = 8, b = 3; printf("a == b : %d\n", a == b); // 0 printf("a != b : %d\n", a != b); // 1 printf("a > b : %d\n", a > b); // 1 printf("a < b : %d\n", a < b); // 0

수식과 비교 — (a + b) > 10

비교 연산자 양쪽에 계산식도 넣을 수 있습니다. 먼저 계산이 끝난 후 비교가 이루어집니다.

int a = 4, b = 7; printf("%d\n", (a + b) > 10); // 4+7=11 > 10 → 1 printf("%d\n", (a * b) == 28); // 4*7=28 == 28 → 1

문자(char) 비교 — 아스키코드 기반

문자도 숫자로 저장됩니다 (아스키코드). 'A'는 65, 'B'는 66이므로 'A' < 'B'는 참(1)입니다.

실수 비교 주의! 소수점 수(float)는 ==로 비교하면 안 됩니다. 예: 0.1 + 0.2는 컴퓨터에서 정확히 0.3이 아닐 수 있습니다. 정수 비교에서만 ==를 쓰세요.

Q5
복합 비교 수식
보통
int x = 4, y = 6; 일 때 아래 식을 계산하고 결과를 쓰세요.
(1)(x + y) == 10
(2)(x * y) > 20
(3)(x - y) >= 0
(4)(y / x) != 1
내 답안
힌트 보기
x=4, y=6. 먼저 괄호 안을 계산하세요. x*y=24, y/x=1(정수나눗셈).
정답 보기
(1) 4+6=10 → 10==10 → 1 (참) (2) 4*6=24 → 24>20 → 1 (참) (3) 4-6=-2 → -2>=0 → 0 (거짓) (4) 6/4=1 → 1!=1 → 0 (거짓, 정수 나눗셈)

핵심 요약

  • 비교 연산자의 결과는 반드시 1(참) 또는 0(거짓) 두 가지뿐입니다.
  • =는 대입(값 저장), ==는 비교(같은지 확인) — 절대 혼동 금지!
  • >=와 <=는 경계값(같은 경우)을 포함하고, >/<는 포함하지 않습니다.
  • 변수끼리 비교, 수식과 비교, 문자 비교 모두 같은 방식으로 동작합니다.
  • 6개 연산자 암기: == != < > <= >=
