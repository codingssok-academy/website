비밀번호 재시도 시스템

do-while 반복문으로 비밀번호를 반복 입력받고, 3번 틀리면 잠금되는 보안 시스템을 만들어봅니다.

이 프로젝트에서 배우는 것

  • do-while 반복문이 while과 어떻게 다른지 이해합니다.
  • 비밀번호를 3번 틀리면 잠금되는 로직을 구현할 수 있습니다.
  • 시도 횟수 카운터로 남은 기회를 실시간으로 표시할 수 있습니다.
  • 논리 연산자 &&(AND)로 두 조건을 동시에 확인하는 방법을 익힙니다.
  • ID + 비밀번호 조합 인증 구조를 만들 수 있습니다.

비밀번호 재시도 — 기본 구현

do-while은 먼저 실행하고 나서 조건을 확인합니다. 비밀번호 입력처럼 "일단 한 번은 반드시 실행해야 하는" 상황에 딱 맞습니다.

// 비밀번호 재시도 — 기본 버전 (최대 3번) #include <stdio.h> int main() { int password = 1234; // 올바른 비밀번호 int input; int tries = 0; int maxTries = 3; do { tries++; printf("비밀번호 입력 [%d/%d]: ", tries, maxTries); scanf("%d", &input); if (input == password) { printf("환영합니다!\n"); return 0; } printf("비밀번호가 틀렸습니다. 남은 기회: %d번\n", maxTries - tries); } while (tries < maxTries); // 3번 미만이면 재시도 printf("계정이 잠겼습니다. 관리자에게 문의하세요.\n"); return 0; }

확장 1 — 잠금 시간 메시지 & ID + 비밀번호 조합

실제 앱처럼 계정 잠금 시 "30초 후 다시 시도하세요" 메시지를 표시하고, ID와 비밀번호를 동시에 확인하는 버전입니다.

// 확장 버전: ID + 비밀번호 조합 인증 #include <stdio.h> int main() { int correctId = 1001; int correctPw = 1234; int inputId, inputPw; int tries = 0; do { tries++; printf("\n[%d/3] ID 입력: ", tries); scanf("%d", &inputId); printf("비밀번호 입력: "); scanf("%d", &inputPw); if (inputId == correctId && inputPw == correctPw) { printf("로그인 성공! 환영합니다.\n"); return 0; } else if (inputId != correctId) { printf("ID가 틀렸습니다.\n"); } else { printf("비밀번호가 틀렸습니다.\n"); } } while (tries < 3); printf("계정이 잠겼습니다. 30초 후 다시 시도하세요.\n"); return 0; }
실제 앱에서는 비밀번호를 숫자로 저장하지 않습니다
실제 서비스에서는 비밀번호를 암호화(해시)해서 저장합니다. 이 프로젝트는 반복문 학습을 위한 예제입니다. 나중에 문자열과 암호화를 배우면 더 안전하게 만들 수 있습니다.

핵심 정리

비밀번호 재시도 핵심 요약

  • do { ... } while(조건); — 최소 1번은 반드시 실행됩니다.
  • tries < maxTries — 시도 횟수가 한도를 넘으면 반복이 끝납니다.
  • && 연산자 — ID와 비밀번호 둘 다 맞아야 로그인이 성공합니다.
  • maxTries - tries — 남은 기회를 쉽게 계산할 수 있습니다.
  • 성공 시 return 0;으로 즉시 함수를 종료할 수 있습니다.
세미콜론 주의
while(조건); 끝에 세미콜론(;)이 있습니다. while이나 for 뒤에 바로 세미콜론을 쓰면 반복문 본체가 비어버리지만, do-while에서는 반드시 세미콜론이 필요합니다.
