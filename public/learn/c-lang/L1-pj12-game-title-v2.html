게임 타이틀 화면

텍스트로 멋진 게임 시작 화면을 만들어봅니다. 제목, 메뉴, 장식을 모두 printf로 완성합니다.

이 프로젝트에서 만들 것

  • 게임 타이틀 제목 장식을 만듭니다.
  • 메인 메뉴 선택 화면을 출력합니다.
  • 캐릭터 스탯 정보창을 만듭니다.
  • 게임 인트로 텍스트를 구성합니다.
  • 전체 게임 시작 화면을 완성합니다.

타이틀 화면 구성

게임 타이틀 화면은 제목, 장식선, 메뉴로 구성됩니다. # * = | 같은 문자로 테두리와 장식을 만듭니다.

// 게임 타이틀 화면 printf("============================\n"); printf(" SPACE SHOOTER 2099\n"); printf("============================\n\n"); printf(" 1. 새 게임 시작\n"); printf(" 2. 불러오기\n"); printf(" 3. 종료\n\n"); printf("선택하세요: \n");
따라해보세요
1
별표 테두리로 게임 제목을 꾸미세요.
printf("**********************\n"); printf("* DRAGON QUEST *\n"); printf("**********************\n");
별표 테두리 제목이 출력됩니다
2
버전 정보와 제작자를 추가하세요.
printf("버전: %d.%d\n", 1, 0); printf("제작: 코딩쏙 스튜디오\n");
버전과 제작자가 출력됩니다

캐릭터 스탯창 만들기

게임의 캐릭터 정보를 깔끔하게 정렬해서 출력해봅시다. \t로 값을 정렬합니다.

char name[] = "용사 김철수"; int level = 15; int hp = 250; int attack = 88; printf("+------ 캐릭터 정보 ------+\n"); printf("| 이름:\t%s\n", name); printf("| 레벨:\t%d\n", level); printf("| HP: \t%d / %d\n", hp, hp); printf("| 공격:\t%d\n", attack); printf("+------------------------+\n");
따라해보세요
1
아이템 인벤토리를 출력하세요.
printf("=== 인벤토리 ===\n"); printf("[1] 체력포션\tx3\n"); printf("[2] 마법의 검\tx1\n"); printf("[3] 방패\t\tx1\n");
탭으로 정렬된 인벤토리가 출력됩니다
2
전투 결과창을 만드세요.
printf("*** 전투 결과 ***\n"); printf("입힌 피해: %d\n", 145); printf("받은 피해: %d\n", 30); printf("결과: 승리!\n");
전투 결과가 출력됩니다
3
게임 오버 화면을 만드세요.
printf("\n\n"); printf(" _____ ___ __ __ ___ _____ _____ ___ ___ \n"); printf(" | __ \\ \\/ |/ __| |/ / _ \\| ___| _ \\ _ \\\n"); printf(" GAME OVER\n"); printf(" 다시 하시겠습니까? (Y/N)\n");
게임 오버 화면이 출력됩니다

도전 과제

Q1
나만의 게임 제목
쉬움
나만의 게임 제목을 === 테두리로 꾸며 출력하세요.
조건위아래 === 선 + 가운데 게임 제목
내 답안
힌트 보기
제목 위아래에 printf("====================\n");를 붙이세요.
정답 확인
printf("====================\n"); printf(" 나의 RPG 게임\n"); printf("====================\n");
Q2
점수 순위표
쉬움
3명의 점수 순위표를 탭으로 정렬해서 출력하세요.
출력1위 PLAYER1 9999점
2위 PLAYER2 8500점
내 답안
힌트 보기
순위, 이름, 점수 사이에 \t를 넣으세요.
정답 확인
printf("=== 명예의 전당 ===\n"); printf("1위\tPLAYER1\t9999점\n"); printf("2위\tPLAYER2\t8500점\n"); printf("3위\tPLAYER3\t7200점\n");
Q3
완성 타이틀 화면
보통
제목 + 메뉴 3개 + 버전 정보로 이루어진 완성된 게임 타이틀 화면을 만드세요.
조건테두리 + 제목 + 메뉴3개 + 버전정보
내 답안
힌트 보기
테두리 → 제목 → 빈줄(\n\n) → 메뉴 → 버전 순서로 작성하세요.
정답 확인
printf("########################\n"); printf("# HERO'S ADVENTURE #\n"); printf("########################\n\n"); printf(" 1. 새 게임\n"); printf(" 2. 불러오기\n"); printf(" 3. 종료\n\n"); printf("v1.0 - 코딩쏙 스튜디오\n");

핵심 요약

  • 게임 타이틀 화면은 테두리, 제목, 메뉴로 구성된다
  • # * = | + -로 테두리와 장식을 만든다
  • \t로 메뉴 항목을 깔끔하게 정렬한다
  • \n\n으로 섹션 사이에 빈 줄을 추가한다
  • 변수를 사용하면 점수, 레벨 등 동적인 값을 표시할 수 있다
