Project 15

스무고개 게임
— 중첩 if-else의 극한

예/아니오 질문으로 상대방이 생각한 동물을 맞히는 스무고개 게임을 C언어로 구현합니다. 중첩 if-else가 만드는 결정 트리를 직접 설계하고 코드로 변환하는 경험을 합니다.

이 프로젝트에서 배우는 것

  • 중첩 if-else를 사용해 결정 트리를 코드로 표현할 수 있습니다.
  • 논리적 질문 순서를 설계하고 최적화할 수 있습니다.
  • 5단계 질문으로 최대 32가지 경우를 처리할 수 있습니다.
  • 사용자 입력을 받아 동적으로 분기하는 프로그램을 작성합니다.
  • 정답률 계산 등 통계 기능을 결합할 수 있습니다.
구현

결정 트리 → 중첩 if-else 변환

스무고개의 핵심은 결정 트리(Decision Tree)입니다. 각 질문이 예/아니오로 갈라지고, 그 안에서 또 갈라집니다. 이 구조가 바로 중첩 if-else와 완벽히 일치합니다.

동물 4마리 스무고개 — 전체 코드

1// 스무고개: 동물 4마리 맞추기 (질문 2개) 2#include <stdio.h> 3 4int main() { 5 char ans1, ans2; // 답: 'y' = 예, 'n' = 아니오 6 7 printf("=== 스무고개: 동물을 맞혀볼게요! ===\n\n"); 8 9 /* ── 1번 질문 ── */ 10 printf("Q1. 다리가 4개인가요? (y/n): "); 11 scanf(" %c", &ans1); // 공백 앞에 붙여야 개행 무시 12 13 if (ans1 == 'y') { // 다리 4개 O 14 15 /* ── 2번 질문 (다리 4개일 때) ── */ 16 printf("Q2. 날 수 있나요? (y/n): "); 17 scanf(" %c", &ans2); 18 19 if (ans2 == 'y') { 20 printf("\n정답은... 박쥐!\n"); // 다리 4개 + 날 수 있음 21 } else { 22 printf("\n정답은... 고양이!\n"); // 다리 4개 + 못 날음 23 } 24 25 } else { // 다리 4개 X 26 27 /* ── 2번 질문 (다리 4개가 아닐 때) ── */ 28 printf("Q2. 날 수 있나요? (y/n): "); 29 scanf(" %c", &ans2); 30 31 if (ans2 == 'y') { 32 printf("\n정답은... 독수리!\n"); // 다리 X + 날 수 있음 33 } else { 34 printf("\n정답은... 뱀!\n"); // 다리 X + 못 날음 35 } 36 37 } 38 39 printf("\n맞았나요? 다시 실행해서 다른 동물을 시도해보세요!\n"); 40 return 0; 41}
중첩 if의 들여쓰기 규칙
if 안에 if가 들어갈 때마다 4칸씩 들여씁니다. 들여쓰기 깊이를 보면 중첩 단계를 바로 알 수 있습니다. { } 중괄호를 항상 쌍으로 적는 습관이 버그를 막습니다.

실행 예시

Q1 답Q2 답출력 결과이유
y y 박쥐 다리 4개 + 날 수 있음
y n 고양이 다리 4개 + 못 날음
n y 독수리 다리 없음 + 날 수 있음
n n 뱀 다리 없음 + 못 날음
scanf의 " %c" 주의
scanf(" %c", &ans1);에서 %c 앞의 공백 한 칸이 중요합니다. 이전 입력에서 남은 개행 문자를 무시하게 해줍니다. 공백 없으면 Enter 키가 답으로 인식됩니다.
확장

확장: 질문 5개로 32가지 동물 구분

질문 1개가 늘면 구분 가능한 동물이 2배 늘어납니다. 질문 n개 = 최대 2n가지 결과. 5개 질문이면 25 = 32마리를 구분할 수 있습니다.

5단계 확장 코드 — 정답률 포함

1#include <stdio.h> 2 3int main() { 4 char q1, q2, q3; // 3단계 → 8마리 (설명용) 5 int total = 0, correct = 0; // 정답률 추적 6 char again = 'y'; 7 8 printf("=== 스무고개 게임 (3단계, 8마리) ===\n"); 9 10 while (again == 'y') { 11 total++; 12 printf("\n동물을 생각하세요... [%d번째 도전]\n", total); 13 14 /* ── 1단계: 척추 여부 ── */ 15 printf("Q1. 등뼈가 있나요? (y/n): "); scanf(" %c", &q1); 16 17 if (q1 == 'y') { // 척추동물 18 printf("Q2. 다리가 있나요? (y/n): "); scanf(" %c", &q2); 19 20 if (q2 == 'y') { // 척추 + 다리 21 printf("Q3. 날 수 있나요? (y/n): "); scanf(" %c", &q3); 22 if (q3 == 'y') printf("\n→ 독수리!\n"); // 척추+다리+비행 23 else printf("\n→ 고양이!\n"); // 척추+다리+지상 24 } else { // 척추 + 다리 없음 25 printf("Q3. 물속에 사나요? (y/n): "); scanf(" %c", &q3); 26 if (q3 == 'y') printf("\n→ 뱀장어!\n"); // 척추+무다리+물 27 else printf("\n→ 뱀!\n"); // 척추+무다리+육지 28 } 29 } else { // 무척추동물 30 printf("Q2. 다리가 6개인가요? (y/n): "); scanf(" %c", &q2); 31 32 if (q2 == 'y') { // 무척추 + 6다리 = 곤충 33 printf("Q3. 날개가 있나요? (y/n): "); scanf(" %c", &q3); 34 if (q3 == 'y') printf("\n→ 나비!\n"); // 곤충+날개 35 else printf("\n→ 개미!\n"); // 곤충+무날개 36 } else { // 무척추 + 6다리 아님 37 printf("Q3. 껍데기가 있나요? (y/n): "); scanf(" %c", &q3); 38 if (q3 == 'y') printf("\n→ 달팽이!\n"); // 무척추+껍데기 39 else printf("\n→ 지렁이!\n"); // 무척추+무껍데기 40 } 41 } 42 43 /* ── 정답 확인 ── */ 44 char hit; 45 printf("맞았나요? (y/n): "); scanf(" %c", &hit); 46 if (hit == 'y') correct++; 47 48 /* ── 정답률 출력 ── */ 49 printf("정답률: %d/%d (%.0f%%)\n", 50 correct, total, 51 (double)correct / total * 100); 52 53 printf("한 번 더? (y/n): "); scanf(" %c", &again); 54 } 55 56 printf("\n최종 정답률: %d/%d (%.0f%%)\n", 57 correct, total, 58 (double)correct / total * 100); 59 return 0; 60}
3단계 중첩의 핵심 패턴
if (q1=='y') { if (q2=='y') { if (q3=='y') ... } } — 깊이 3의 중첩입니다. 중괄호를 잘못 닫으면 동작이 완전히 달라지므로, 작성할 때마다 들여쓰기를 확인하세요.

중첩 if의 2대 함정
1. dangling else — 중괄호 없는 if-else는 가장 가까운 if에 붙습니다. 항상 { }를 쓰세요.
2. 깊이 초과 — 실무에서 중첩 5단계 이상은 함수로 분리합니다. 가독성이 떨어집니다.

도전 과제

  • 질문 5개 / 동물 32마리 완전 트리를 직접 설계하고 구현하라. 동물 목록은 직접 정한다.
  • 결과에 동물 특징 설명 1줄을 추가하라. 예: "독수리 — 날개 너비 2m의 맹금류"
  • 역방향 게임: 컴퓨터가 동물을 고르고, 사용자가 예/아니오를 입력해 맞히는 버전을 만들어라.
  • 모든 경로를 테스트하는 자동 테스트 코드를 작성하라. (2n개 경우를 루프로 돌린다)

L3 프로젝트 15 — 핵심 정리

  • 결정 트리의 각 분기는 if(예) / else(아니오)로 1:1 대응한다.
  • 질문 n개 = 최대 2n가지 결과. 질문 하나가 경우의 수를 2배 늘린다.
  • 중첩 if는 들여쓰기와 중괄호 쌍을 정확히 맞춰야 한다.
  • scanf(" %c") 앞의 공백은 이전 개행을 흡수하는 필수 패턴이다.
  • 중첩 깊이가 5 이상이면 함수로 분리해 가독성을 유지한다.
