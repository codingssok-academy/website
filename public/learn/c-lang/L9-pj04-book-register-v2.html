도서 등록 — 제목/저자/가격 구조체

Book 구조체로 도서 정보를 관리하고, 가격 기준 정렬과 특정 저자 검색 기능을 구현합니다.

프로젝트 목표

  • Book 구조체(제목/저자/가격)를 정의합니다.
  • 도서 목록을 가격 오름차순으로 정렬합니다.
  • 특정 저자의 책을 검색해 출력합니다.
  • 전체 도서 총 가격을 계산합니다.

구현 코드

#include <stdio.h> #include <string.h> #define N 4 typedef struct { char title[40]; char author[20]; int price; int pages; } Book; void printBook(Book *b) { printf("[%s] %s저 — %d원 (%d쪽)\n", b->title, b->author, b->price, b->pages); } void sortByPrice(Book arr[], int n) { for (int i=0;i<n-1;i++) for (int j=0;j<n-1-i;j++) if (arr[j].price > arr[j+1].price) { Book t=arr[j]; arr[j]=arr[j+1]; arr[j+1]=t; } } void searchByAuthor(Book arr[], int n, const char *author) { printf("\n[%s]의 책:\n", author); int found = 0; for (int i=0;i<n;i++) if (strcmp(arr[i].author, author)==0) { printBook(&arr[i]); found++; } if (!found) printf("결과 없음\n"); } int main() { Book arr[N] = { {"C언어 기초", "홍길동", 18000, 320}, {"Python입문", "김철수", 22000, 280}, {"알고리즘", "홍길동", 35000, 450}, {"자료구조", "이영희", 28000, 380} }; sortByPrice(arr, N); printf("== 가격 순 목록 ==\n"); for (int i=0;i<N;i++) printBook(&arr[i]); searchByAuthor(arr, N, "홍길동"); int total = 0; for (int i=0;i<N;i++) total += arr[i].price; printf("총 가격: %d원\n", total); return 0; }

도전 과제

도전 과제

  • 제목에 특정 단어가 포함된 책을 검색해보세요. (strstr 활용)
  • 가장 비싼 책과 가장 싼 책을 출력해보세요.
  • 평균 가격 이상인 책만 출력해보세요.
