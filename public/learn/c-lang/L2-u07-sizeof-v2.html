Chapter 07

sizeof: 자료형의 크기

sizeof 연산자로 자료형과 변수의 메모리 크기를 확인하는 방법을 배웁니다.

이 유닛에서 배우는 것

  • sizeof 연산자의 의미와 사용법을 안다.
  • int, char, float, double의 크기를 sizeof로 확인할 수 있다.
  • sizeof에 자료형 이름과 변수 이름 모두 사용 가능함을 안다.
  • 자료형 크기가 왜 중요한지 설명할 수 있다.
  • 모든 자료형의 크기를 출력하는 프로그램을 작성할 수 있다.

sizeof 연산자란?

sizeof는 자료형이나 변수가 메모리에서 차지하는 크기(바이트 수)를 알려주는 연산자입니다. 함수가 아니라 연산자입니다.

sizeof(int)라고 쓰면 int가 차지하는 바이트 수를 돌려줍니다. 결과값은 %lu 또는 %zu로 출력합니다.

#include <stdio.h> int main(void) { printf("char: %lu바이트\n", sizeof(char)); // 1 printf("short: %lu바이트\n", sizeof(short)); // 2 printf("int: %lu바이트\n", sizeof(int)); // 4 printf("float: %lu바이트\n", sizeof(float)); // 4 printf("double: %lu바이트\n", sizeof(double)); // 8 return 0; }
따라해보세요
1
위 코드를 직접 입력하고 실행해서 각 자료형의 크기를 확인해 보세요.
char=1, short=2, int=4, float=4, double=8
2
long과 long long의 크기도 출력해 보세요.
printf("long: %lu바이트\n", sizeof(long)); printf("long long: %lu바이트\n", sizeof(long long));
long=4 (Windows) 또는 8 (Linux), long long=8
3
int와 float의 크기가 같은 이유를 생각해 보세요.
// int: 4바이트 → 정수 저장 // float: 4바이트 → 실수 저장 // 같은 4바이트지만 내부 구조가 다름!
크기는 같아도 저장 방식(정수 vs 부동소수점)이 다르다

sizeof에 변수 이름 사용하기

sizeof는 자료형 이름뿐 아니라 변수 이름에도 사용할 수 있습니다. 변수에 사용하면 그 변수의 자료형 크기를 돌려줍니다.

#include <stdio.h> int main(void) { int age = 15; double height = 165.5; char grade = 'A'; printf("age 크기: %lu바이트\n", sizeof(age)); // 4 printf("height 크기: %lu바이트\n", sizeof(height)); // 8 printf("grade 크기: %lu바이트\n", sizeof(grade)); // 1 return 0; }

sizeof(age)는 age가 int이므로 4를 돌려줍니다. 변수에 어떤 값이 들어있든 크기는 자료형에 의해 결정됩니다.

왜 크기를 알아야 할까?

자료형의 크기를 알아야 하는 이유는 메모리를 효율적으로 사용하기 위해서입니다. 작은 값에 큰 자료형을 쓰면 메모리가 낭비됩니다.

따라해보세요
1
변수를 선언하고 sizeof로 크기를 확인해 보세요.
int score = 100; printf("score: %lu바이트\n", sizeof(score)); printf("int: %lu바이트\n", sizeof(int));
둘 다 4바이트로 동일하다
2
sizeof 결과를 변수에 저장해 보세요.
int size = sizeof(double); printf("double 크기: %d\n", size);
double 크기: 8

실전: 모든 자료형 크기 출력

C언어의 주요 자료형을 모두 sizeof로 출력하는 프로그램을 만들어 봅시다.

#include <stdio.h> int main(void) { printf("=== 자료형 크기 표 ===\n\n"); printf("char: %lu바이트\n", sizeof(char)); printf("short: %lu바이트\n", sizeof(short)); printf("int: %lu바이트\n", sizeof(int)); printf("long: %lu바이트\n", sizeof(long)); printf("long long: %lu바이트\n", sizeof(long long)); printf("float: %lu바이트\n", sizeof(float)); printf("double: %lu바이트\n", sizeof(double)); return 0; }

핵심 요약

  • sizeof는 자료형/변수의 메모리 크기(바이트)를 알려주는 연산자이다.
  • char=1B, short=2B, int=4B, float=4B, double=8B (일반적인 환경)
  • sizeof(int)처럼 자료형에, sizeof(age)처럼 변수에 사용 가능하다.
  • 변수에 어떤 값이 들어있든 sizeof 결과는 자료형에 의해 결정된다.
  • 메모리를 효율적으로 사용하려면 적절한 크기의 자료형을 선택해야 한다.
