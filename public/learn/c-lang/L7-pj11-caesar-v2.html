Caesar Cipher System
카이사르 암호 시스템 구현
핵심 함수 — 단방향 통합

암호화(+key)와 복호화(-key)를 하나의 함수로 처리한다. 복호화는 단순히 key를 음수로 전달하면 된다.

#include <stdio.h> #include <string.h> #include <ctype.h> // 암호화 & 복호화 통합 함수 void caesar(char result[], char src[], int key) { strcpy(result, src); for (int i = 0; result[i]; i++) { if (isalpha(result[i])) { char base = islower(result[i]) ? 'a' : 'A'; result[i] = (result[i] - base + key % 26 + 26) % 26 + base; } } } // 브루트포스 — key 1~25 전수 시도 void brute_force(char cipher[]) { char try[500]; printf("\n=== 브루트포스 해독 ===\n"); for (int k = 1; k <= 25; k++) { caesar(try, cipher, -k); printf("key %2d: %s\n", k, try); } } int main() { char input[500], output[500]; int choice, key; while (1) { printf("\n1.암호화 2.복호화 3.자동해독 4.종료\n선택: "); scanf("%d", &choice); if (choice == 4) break; printf("메시지: "); getchar(); // 개행 제거 fgets(input, sizeof(input), stdin); input[strcspn(input, "\n")] = '\0'; switch (choice) { case 1: printf("키(1-25): "); scanf("%d", &key); caesar(output, input, key); printf("암호문: %s\n", output); break; case 2: printf("키(1-25): "); scanf("%d", &key); caesar(output, input, -key); printf("원문: %s\n", output); break; case 3: brute_force(input); break; } } printf("종료\n"); return 0; }

실행 예시
고급 — 빈도 분석으로 key 자동 추측

영어에서 가장 자주 쓰이는 글자는 'e'다. 암호문에서 가장 빈도 높은 글자가 'e'에 해당한다고 가정하면 키를 추측할 수 있다.

int guess_key(char cipher[]) { int freq[26] = {0}; // 소문자 빈도 계산 for (int i = 0; cipher[i]; i++) { if (isalpha(cipher[i])) freq[tolower(cipher[i]) - 'a']++; } // 가장 많이 나온 글자 찾기 int max_idx = 0; for (int i = 1; i < 26; i++) if (freq[i] > freq[max_idx]) max_idx = i; // 가장 빈도높은 글자가 'e'(4)라고 가정 int guessed_key = (max_idx - 4 + 26) % 26; printf("추측 key: %d (가장 빈도: '%c')\n", guessed_key, 'a' + max_idx); return guessed_key; }
빈도 분석(Frequency Analysis): 영어 텍스트에서 e, t, a, o, i, n 순서로 자주 등장한다. 짧은 텍스트에는 부정확하지만 긴 텍스트에서는 키를 높은 확률로 추측할 수 있다.
연습 문제
Q1. 설계 이해

caesar() 함수에서 복호화를 하려면 key에 어떤 값을 전달하면 되는가?

정답 보기
-key (음수). 예: 암호화 key=3이면 복호화 시 caesar(result, cipher, -3)
Q2. 코드 분석

brute_force() 함수에서 출력이 25줄인 이유는? 왜 1~25까지만 시도하는가?

정답 보기
알파벳은 26개. key=26이면 원문과 동일. key=0도 원문과 동일. 실제 의미있는 변환은 1~25뿐이다.

Q5. 도전

ROT13 인코더를 구현하시오. ROT13은 key=13인 카이사르 암호로, 같은 함수로 암호화와 복호화가 동일하게 동작한다. 이유를 설명하시오.

정답 보기
caesar(result, src, 13). ROT13을 두 번 적용하면 13+13=26이 되어 원문으로 복귀. 암호화 = 복호화가 되는 대칭 암호다.

핵심 정리

통합함수caesar(result, src, +key) = 암호화 / caesar(result, src, -key) = 복호화
브루트포스key 1~25 전수 시도. key=26은 원문과 동일
빈도분석영어에서 'e' 최다 등장 → 암호문 최빈 글자 - 4 = 추측 key
ROT13key=13, 동일 함수로 암호화/복호화 가능 (13+13=26=원위치)
