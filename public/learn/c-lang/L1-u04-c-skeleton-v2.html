Chapter 04

C 프로그램 구조 — 뼈대 이해하기

#include, main 함수, return 0 — C 프로그램의 기본 뼈대를 완전히 이해합니다.

이 유닛에서 배우는 것

  • #include <stdio.h>가 왜 필요한지 설명할 수 있습니다.
  • int main()이 프로그램의 시작점임을 압니다.
  • 중괄호 { }의 역할을 이해합니다.
  • return 0;의 의미를 설명할 수 있습니다.
  • C 프로그램의 기본 뼈대를 외워서 쓸 수 있습니다.

#include — 기능 가져오기

#include는 외부 파일의 기능을 가져오는 명령입니다. stdio.h는 "standard input output header"의 약자로, 화면 출력(printf)과 입력(scanf) 기능을 담고 있습니다.

// 헤더 파일이 없으면 에러 발생 // #include <stdio.h> 없이 printf를 쓰면: int main() { printf("안녕"); // error: printf 미정의 return 0; }
따라해보세요
1
stdio.h를 포함한 기본 뼈대를 작성해 보세요.
#include <stdio.h> int main() { printf("뼈대 완성!\n"); return 0; }
뼈대 완성! 이 출력되면 성공
2
#include를 제거하고 어떤 에러가 나는지 확인해 보세요.
// #include <stdio.h> // 주석 처리 int main() { printf("에러 확인\n"); // 에러 발생! return 0; }
implicit declaration of function 'printf' 에러
3
꺾쇠괄호와 큰따옴표의 차이를 확인해 보세요.
#include <stdio.h> // 시스템 헤더 // #include "myfile.h" // 내 파일 헤더
시스템 헤더는 <>, 직접 만든 헤더는 ""

main 함수와 return 0

int main()은 프로그램이 시작되는 곳입니다. 컴퓨터는 항상 main을 찾아서 거기서부터 실행합니다.

int main()에서 int는 이 함수가 정수를 돌려준다는 뜻입니다. 프로그램이 끝날 때 return 0;으로 운영체제에게 "정상 종료"를 알립니다.

주석 — 코드에 메모 남기기

주석은 컴파일러가 무시하는 설명입니다. 코드를 읽는 사람을 위해 설명을 남기거나, 특정 코드를 임시로 비활성화할 때 사용합니다.

/* C 프로그램 완전한 뼈대 템플릿 작성일: 2026 설명: 기본 구조 예시 */ #include <stdio.h> // 1단계: 필요한 헤더 포함 int main() { // 2단계: main 함수 시작 // 3단계: 실행할 코드 작성 printf("Hello, C!\n"); return 0; // 4단계: 정상 종료 } // 5단계: main 함수 닫기

핵심 요약

  • #include <stdio.h> — printf, scanf 기능을 프로그램에 포함
  • int main() — 프로그램의 시작점, 항상 여기서 실행 시작
  • { } — 함수의 본문을 감싸는 중괄호, 쌍이 맞아야 함
  • return 0; — 운영체제에게 정상 종료를 알리는 신호
  • // 한 줄 주석, /* */ 여러 줄 주석
