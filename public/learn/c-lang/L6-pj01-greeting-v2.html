인사말 생성기
— void 함수 첫 프로젝트

void greet(char name[]) 함수를 만들어 이름을 받아 인사말을 출력하는 첫 번째 함수 프로젝트입니다.

이 프로젝트에서 배우는 것

  • void 함수를 선언하고 호출할 수 있습니다.
  • char name[] 매개변수로 문자열을 받을 수 있습니다.
  • 함수 안에서 printf로 인사말을 출력할 수 있습니다.
  • main에서 함수를 여러 번 호출해 재사용성을 체험합니다.
  • 함수가 왜 편한지 직접 느낄 수 있습니다.
PROJECT 01
인사말 생성기
void 함수와 char[] 매개변수 활용

void 함수란?

함수에는 두 종류가 있습니다. 결과를 돌려주는 함수(return 있음)와, 그냥 작업만 하고 끝나는 함수(void)입니다. 인사말을 출력하는 것처럼 "화면에 뭔가 보여주고 끝"이면 void를 씁니다.

char name[] — 문자열 매개변수

C언어에서 문자열은 char 배열로 저장합니다. 함수에서 문자열을 받으려면 매개변수를 char name[]으로 씁니다. %s로 출력합니다.

// 함수 선언 void greet(char name[]) { printf("안녕하세요, %s님!\n", name); printf("코딩쏙에 오신 것을 환영합니다!\n"); } int main() { greet("홍길동"); // 함수 호출 1 greet("김코딩"); // 함수 호출 2 — 재사용! greet("이자바"); // 함수 호출 3 return 0; }
STEP 1
함수 선언
void greet(char name[]) { } 뼈대를 만든다
STEP 2
본체 작성
printf로 name을 포함한 인사말 출력
STEP 3
main에서 호출
greet("이름"); 으로 여러 번 호출

인사말 생성기 — 전체 코드

시간대별로 다른 인사말을 출력하는 함수를 추가해서 프로젝트를 완성합니다.

/* ====== 인사말 생성기 전체 코드 ====== */ #include <stdio.h> /* 기본 인사 함수 */ void greet(char name[]) { printf("============================\n"); printf(" 안녕하세요, %s님!\n", name); printf(" 코딩쏙에 오신 것을 환영합니다!\n"); printf("============================\n"); } /* 시간대별 인사 함수 */ void greetByTime(char name[], int hour) { printf("%s님, ", name); if (hour < 12) { printf("좋은 아침입니다!\n"); } else if (hour < 18) { printf("좋은 오후입니다!\n"); } else { printf("좋은 저녁입니다!\n"); } } /* 작별 인사 함수 */ void farewell(char name[]) { printf("수고했어요, %s님! 내일 또 봬요!\n", name); } int main() { greet("홍길동"); greet("김코딩"); greetByTime("이자바", 9); // 오전 9시 greetByTime("박파이", 15); // 오후 3시 greetByTime("최씨", 20); // 저녁 8시 farewell("홍길동"); return 0; }
핵심 포인트: 함수를 한 번 만들면 main에서 몇 번이든 호출할 수 있습니다. 이름만 바꿔 넣으면 같은 인사말 형식이 자동으로 출력됩니다.

연습 문제

1
void 함수 구조 이해
쉬움
다음 중 void 함수에 대한 설명으로 틀린 것은?
① 반환값이 없다
② return 문을 절대 쓸 수 없다
③ 매개변수는 가질 수 있다
④ printf 같은 출력 작업에 적합하다
정답 보기
정답: ② — void 함수도 return; (값 없이)을 써서 중간에 함수를 빠져나올 수 있습니다.

핵심 정리

핵심 정리

  • void 함수이름(매개변수) — 반환값 없는 함수 선언
  • char name[] — 문자열 매개변수, %s로 출력
  • 함수 한 번 만들면 main에서 몇 번이든 호출 가능
  • void 함수도 return; 으로 중간 탈출 가능
