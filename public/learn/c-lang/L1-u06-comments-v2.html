Unit 06

주석 — // 와 /* */

코드 안에 설명을 남기는 방법, 한 줄 주석과 여러 줄 주석을 배웁니다.

이 유닛에서 배우는 것

  • 주석이 무엇인지, 왜 필요한지 설명할 수 있습니다.
  • //로 한 줄 주석을 작성할 수 있습니다.
  • /* */로 여러 줄 주석을 작성할 수 있습니다.
  • 주석을 이용해 코드를 비활성화할 수 있습니다.

주석이란?

주석(Comment)은 코드 안에 쓰는 메모입니다. 컴파일러는 주석을 무시하기 때문에 실행 결과에 영향을 주지 않습니다. 코드를 설명하거나, 나중에 추가할 내용을 기록할 때 씁니다.

// 한 줄 주석

// 기호 뒤의 내용은 그 줄의 끝까지 모두 주석 처리됩니다. 코드 뒤에 바로 붙여서 설명을 달 수도 있습니다.

int main() { // 이름 출력 printf("홍길동\n"); // 코드 뒤에도 가능 // printf("이 줄은 실행 안 됨\n"); return 0; }
따라해보세요
1
코드 위에 설명 주석을 달아보세요.
int main() { // 내 정보 출력 프로그램 printf("이름: 김코딩\n"); return 0; }
주석은 출력되지 않음
2
printf 줄을 주석으로 비활성화해서 출력이 사라지는지 확인해보세요.
int main() { printf("보이는 줄\n"); // printf("안 보이는 줄\n"); return 0; }
보이는 줄만 출력

/* */ 여러 줄 주석

/*로 시작하고 */로 끝납니다. 그 사이의 모든 내용(여러 줄 포함)이 주석 처리됩니다. 길게 설명하거나 여러 줄의 코드를 한 번에 비활성화할 때 씁니다.

/* 프로그램 정보 작성자: 홍길동 날짜: 2025-03-01 */ int main() { printf("자기소개\n"); // 이름 출력 printf("코딩을 좋아함\n"); return 0; }
따라해보세요
1
프로그램 상단에 여러 줄 주석으로 정보를 기록해보세요.
/* 내 첫 번째 C 프로그램 이름: 나의 이름 날짜: 오늘 날짜 */ int main() { printf("시작!\n"); return 0; }
시작! 출력, 주석은 무시
2
/* */로 여러 printf 줄을 한꺼번에 비활성화해보세요.
int main() { printf("줄 1\n"); /* printf("줄 2\n"); printf("줄 3\n"); */ printf("줄 4\n"); return 0; }
줄 1과 줄 4만 출력
3
// 과 /* */ 를 모두 섞어 쓴 코드를 작성해보세요.
/* 취미 목록 출력 프로그램 */ int main() { // 첫 번째 취미 printf("취미1: 독서\n"); printf("취미2: 코딩\n"); // 최애 return 0; }
두 가지 취미 출력

실력 확인 문제

Q1
주석 식별하기
쉬움
아래 코드에서 실제로 출력되는 줄은 몇 번째 줄인가요?
int main() { // printf("A\n"); printf("B\n"); /* printf("C\n"); printf("D\n"); */ printf("E\n"); return 0; }
내 답안
힌트 / 정답 보기
A, C, D는 주석 안에 있습니다. 출력되는 것은 B와 E입니다.
B E
Q2
주석 추가하기
쉬움
아래 코드의 각 printf 줄에 어떤 내용인지 // 주석을 달아보세요.
int main() { printf("이름: 홍길동\n"); printf("나이: 14\n"); printf("학교: 코딩중\n"); return 0; }
내 답안
예시 정답 보기
printf("이름: 홍길동\n"); // 이름 출력 printf("나이: 14\n"); // 나이 출력 printf("학교: 코딩중\n"); // 학교 출력
Q3
주석 활용 코드 작성
보통
상단에 /* */ 정보 주석, 각 줄에 // 설명 주석을 포함하는 자기소개 프로그램을 완성하세요.
조건/* */ 주석 1개, // 주석 2개 이상
출력이름, 좋아하는 것 2개 이상
내 답안
예시 정답 보기
/* 자기소개 프로그램 - 홍길동 */ int main() { // 이름 출력 printf("이름: 홍길동\n"); // 좋아하는 것 출력 printf("게임: 마인크래프트\n"); printf("음식: 라면\n"); return 0; }

핵심 요약

  • // — 그 줄의 끝까지 주석 처리 (한 줄 주석)
  • /* */ — 시작과 끝 사이의 모든 내용이 주석 (여러 줄 주석)
  • 주석은 컴파일러가 완전히 무시, 실행 결과에 영향 없음
  • 코드 설명, 작성자 정보, 코드 비활성화 등에 활용
  • /* */ 안에 /* */를 중첩하면 에러 발생
