Chapter 02

if문 — 조건이 참이면 실행

프로그램이 "생각"하는 첫 번째 방법, if문을 배웁니다. 조건에 따라 다른 동작을 하는 코드를 작성해봅시다.

이 유닛에서 배우는 것

  • if문이 무엇인지, 왜 필요한지 설명할 수 있습니다.
  • if문의 기본 문법 구조를 쓸 수 있습니다.
  • 조건이 참일 때와 거짓일 때 실행 흐름의 차이를 알 수 있습니다.
  • 비교 연산자(>, >=, ==)를 사용해 조건식을 만들 수 있습니다.
  • = 과 == 의 차이를 구별하고, 흔한 실수를 피할 수 있습니다.

if문이란? — 조건에 따라 다르게 행동하기

우리는 매일 조건에 따라 다른 행동을 합니다. "비가 오면 우산을 쓴다", "배가 고프면 밥을 먹는다"처럼요. if문은 프로그램이 이런 판단을 할 수 있게 해주는 도구입니다.

if문 문법 구조

핵심은 이것입니다. 조건이 참(1, true)이면 `{}` 안의 코드를 실행하고, 거짓(0, false)이면 `{}` 안을 통째로 건너뜁니다.

// 나이가 18 이상이면 "성인입니다" 출력 int age = 20; if (age >= 18) { printf("성인입니다\n"); // age가 18 이상이면 실행 } // age = 20 이므로 조건 참 → "성인입니다" 출력됨
따라해보세요
1
변수 score에 90을 넣고, 90 이상이면 "잘했어요!" 출력해보세요.
int score = 90; if (score >= 90) { printf("잘했어요!\n"); }
score가 90이므로 조건 참 → 잘했어요! 출력
2
변수 temp에 35를 넣고, 30보다 크면 "더워요!" 출력해보세요.
int temp = 35; if (temp > 30) { printf("더워요!\n"); }
35 > 30 → 참 → 더워요! 출력
3
변수 age에 12를 넣고, 18 이상이면 "성인입니다" 출력해보세요. (아무것도 안 나와야 합니다)
int age = 12; if (age >= 18) { printf("성인입니다\n"); // 실행 안 됨 } // 12 >= 18 → 거짓 → {} 건너뜀 → 아무것도 출력 안 됨
12는 18보다 작으므로 조건 거짓 → 출력 없음

if문 실전 패턴

if문은 여러 상황에 쓸 수 있습니다. 가장 많이 나오는 세 가지 패턴을 익혀봅시다.

패턴 1 — 0과 비교: 양수 판별

패턴 2 — 범위 판별: 합격 기준

패턴 3 — 중괄호 생략 주의

중괄호 생략: 1줄 코드면 생략할 수 있지만, 처음에는 항상 쓰는 습관을 들이세요. 나중에 코드를 추가할 때 버그가 생기는 걸 막아줍니다.
// 양수 판별 int n = 5; if (n > 0) { printf("양수입니다\n"); } // 합격 판별 int score = 75; if (score >= 60) { printf("합격!\n"); }
따라해보세요
1
n = -3으로 바꾸면 "양수입니다"가 출력될까요? 코드를 실행해서 확인해보세요.
int n = -3; if (n > 0) { printf("양수입니다\n"); // 실행 안 됨 }
-3 > 0은 거짓 → 아무것도 출력 안 됨
2
score = 59로 바꾸면 "합격!"이 출력될까요? 확인해보세요.
int score = 59; if (score >= 60) { printf("합격!\n"); // 실행 안 됨 }
59 >= 60은 거짓 → 출력 없음
3
변수 height에 170을 넣고, 160 초과이면 "롤러코스터 탑승 가능!" 출력해보세요.
int height = 170; if (height > 160) { printf("롤러코스터 탑승 가능!\n"); }
170 > 160 → 참 → 롤러코스터 탑승 가능! 출력

흔한 실수와 주의사항

if문을 처음 배울 때 자주 하는 실수 세 가지를 알아봅시다. 이걸 미리 알면 디버깅 시간을 많이 아낄 수 있습니다.

실수 1 — = (대입) vs == (비교) 혼동

주의 — = (대입)과 == (비교)는 완전히 다릅니다

if (a = 5)는 a에 5를 넣고 그 값(5)이 0이 아니면 참으로 처리합니다. 조건을 비교하려면 반드시 == 두 개를 써야 합니다.

실수 2 — if 뒤에 세미콜론 붙이기

실수 3 — 들여쓰기만으로 범위를 착각하기

C언어는 들여쓰기가 실행 순서에 영향을 주지 않습니다

중괄호 없이 if문 아래에 두 줄을 쓰면, 두 번째 줄은 if와 관계없이 항상 실행됩니다. 범위를 정확히 하려면 반드시 { }를 써야 합니다.

따라해보세요
1
아래 코드에서 버그를 찾아 고쳐보세요. (= vs == 오류)
// 버그 있는 코드 int x = 3; if (x = 10) { // 버그! printf("x는 10입니다\n"); } // 수정된 코드 if (x == 10) { // 올바름 printf("x는 10입니다\n"); }
= 를 == 로 바꾸면 버그 수정 완료
2
아래 코드에서 세미콜론 실수를 찾아 고쳐보세요.
// 버그 있는 코드 int n = 5; if (n > 0); // 세미콜론 실수! printf("양수\n"); // 수정된 코드 if (n > 0) { printf("양수\n"); }
세미콜론 제거 + 중괄호 추가로 수정
3
n이 0보다 클 때만 "크다"와 "양수" 두 줄 모두 출력되도록 코드를 고쳐보세요.
// 버그 있는 코드 (중괄호 없음) int n = -1; if (n > 0) printf("크다\n"); printf("양수\n"); // 항상 실행됨 // 수정된 코드 if (n > 0) { printf("크다\n"); printf("양수\n"); }
중괄호로 감싸면 두 줄 모두 조건에 묶임

확인 문제

1
if문 실행 결과 예측
쉬움
아래 코드를 실행하면 어떤 결과가 출력될까요? 출력되는 내용을 쓰거나, 아무것도 출력되지 않으면 "출력 없음"이라고 쓰세요.
int a = 10; if (a > 5) { printf("10은 5보다 큽니다\n"); }
출력 ____________________________
내 답안
힌트 / 정답 보기
a = 10, 조건은 a > 5 입니다. 10 > 5는 참(true)입니다.
10은 5보다 큽니다 // a=10, 10 > 5 → 참 → {} 안 실행됨
2
양수 / 음수 / 0 판별
보통
사용자로부터 정수 n을 입력받아, n이 양수(0보다 큰 수)이면 "양수입니다"를 출력하는 코드를 완성하세요. 변수 선언과 if문을 직접 작성하세요.
int n = 7; // n에 원하는 값 대입 if ( _______________ ) { printf("___________\n"); }
내 답안
힌트 / 정답 보기
양수란 0보다 큰 수입니다. 비교 연산자 > 를 사용하세요.
int n = 7; if (n > 0) { printf("양수입니다\n"); } // 출력: 양수입니다
3
에러 찾기 — = vs ==
쉬움
아래 코드에 버그가 있습니다. 버그를 찾아 밑줄 치고, 올바르게 수정한 코드를 옆에 써보세요.
int age = 15; if (age = 18) { // 버그! printf("성인입니다\n"); }
버그 ____________________________
수정 ____________________________
내 답안
힌트 / 정답 보기
= 는 대입 연산자, == 는 비교 연산자입니다. "같은지 비교"할 때는 == 를 씁니다.
// 버그: age = 18 (대입, 항상 참) // 수정: age == 18 (비교) if (age == 18) { printf("성인입니다\n"); } // age=15, 15==18 → 거짓 → 출력 없음
4
두 수 비교 후 큰 수 출력
보통
두 정수 a = 8, b = 12가 있습니다. a가 b보다 크면 "a가 더 큽니다"를 출력하는 코드를 작성하세요.
int a = 8, b = 12; if ( _______________ ) { printf("___________\n"); }
출력 ____________________________
내 답안
힌트 / 정답 보기
a > b 조건을 사용하세요. a=8, b=12이므로 8 > 12는 거짓입니다.
int a = 8, b = 12; if (a > b) { printf("a가 더 큽니다\n"); } // 8 > 12 → 거짓 → 출력 없음 // a=15로 바꾸면 15 > 12 → 참 → 출력됨
5
합격 판정 + 메시지
보통
시험 점수 score를 받아, 점수가 70점 이상이면 "합격입니다! 점수: [점수]" 형식으로 출력하는 코드를 완성하세요. %d를 사용해서 점수도 함께 출력해야 합니다.
int score = 82; if ( _______________ ) { printf("합격입니다! 점수: %d\n", _____ ); }
출력 합격입니다! 점수: 82
내 답안
힌트 / 정답 보기
조건: score >= 70, printf의 %d 자리에 변수 score를 넣으세요.
int score = 82; if (score >= 70) { printf("합격입니다! 점수: %d\n", score); } // 출력: 합격입니다! 점수: 82

이 유닛 핵심 요약

  • if문은 조건이 참(true)일 때만 { } 안의 코드를 실행합니다.
  • 조건이 거짓(false)이면 { } 안을 통째로 건너뜁니다.
  • 비교 연산자: >(크다), >=(이상), ==(같다), <(작다), <=(이하)
  • =는 대입(값 저장), ==는 비교(같은지 확인) — 절대 헷갈리면 안 됩니다.
  • if 뒤에 세미콜론(;)을 붙이면 if문이 빈 문장이 됩니다 — 붙이지 마세요.
  • 중괄호 없이 여러 줄을 쓰면 첫 번째 줄만 if에 속합니다 — 항상 { }를 씁시다.
