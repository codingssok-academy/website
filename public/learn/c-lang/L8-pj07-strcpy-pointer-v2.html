strcpy 직접 구현
Implement strcpy() with Pointers
표준 라이브러리 strcpy는 내부적으로 포인터로 동작한다.
문자를 하나씩 복사하고 '\0'을 붙이는 과정을 직접 구현하여 문자열 포인터를 완전히 이해한다.
난이도 문자열 포인터 '\0' 종료 문자 표준 라이브러리 구현 원리
strcpy 내부 동작 단계별 추적
3가지 구현 방식
strcpy_impl.c /* 버전 1: 명시적 (이해하기 쉬움) */
void strcpy_v1(char *dst, const char *src) {
    while (*src != '\0') {
        *dst = *src; // 문자 복사
        dst++; // dst 이동
        src++; // src 이동
    }
    *dst = '\0'; // null 종료자 추가
}

/* 버전 2: *p++ 단축 표현 */
void strcpy_v2(char *dst, const char *src) {
    while (*src != '\0')
        *dst++ = *src++;
    *dst = '\0';
}

/* 버전 3: C 관용구 (가장 짧음) */
void strcpy_v3(char *dst, const char *src) {
    while ((*dst++ = *src++) != '\0'); // 대입 결과로 비교
}
버전 3의 (*dst++ = *src++): src의 문자를 dst에 복사(대입)하고, 대입 결과값이 '\0'이면 루프 종료. '\0'도 복사되므로 별도로 '\0'을 추가할 필요가 없다.
완성 코드 + strlen, strcmp 보너스
string_impl.c #include <stdio.h>

void my_strcpy(char *dst, const char *src) {
    while ((*dst++ = *src++) != '\0');
}

int my_strlen(const char *s) {
    const char *p = s;
    while (*p != '\0') p++;
    return (int)(p - s); // 포인터 차이 = 길이
}

int my_strcmp(const char *a, const char *b) {
    while (*a != '\0' && *a == *b) { a++; b++; }
    return (unsigned char)*a - (unsigned char)*b;
}

int main() {
    char src[] = "Hello, C!";
    char dst[20];
    
    my_strcpy(dst, src);
    printf("복사 결과: %s\n", dst);
    printf("길이: %d\n", my_strlen(dst));
    printf("비교 (같음): %d\n", my_strcmp(src, dst));
    printf("비교 (다름): %d\n", my_strcmp("abc", "abd"));
    return 0;
}
$ gcc string_impl.c -o string_impl && ./string_impl
복사 결과: Hello, C!
길이: 9
비교 (같음): 0
비교 (다름): -1
주의: strcpy는 dst 버퍼가 충분히 큰지 확인하지 않는다. src 길이 > dst 크기면 버퍼 오버플로우! 실무에서는 strncpy나 strlcpy를 사용한다.

연습문제
1 while ((*dst++ = *src++) != '\0');에서 '\0'도 복사되는 이유는?
*dst++ = *src++는 src의 현재 문자를 dst에 복사하고 그 값을 반환한다. '\0'이 복사될 때 대입 결과가 '\0'이므로 조건이 false가 되어 루프 종료. 이미 '\0'이 복사된 후이므로 별도 추가 불필요.
2 my_strlen에서 p - s가 문자열 길이인 이유는?
s는 문자열 시작 주소, p는 '\0'에서 멈춘 주소. char 포인터 차이는 바이트 수 = 문자 수. "Hello"이면 p = s+5, p-s = 5. 표준 strlen의 정확한 구현이다.
3 src를 const char *로 받는 이유는?
strcpy는 src를 읽기만 하고 수정하지 않는다. const를 붙이면 함수 내부에서 *src = ... 같은 실수를 컴파일러가 잡아준다. 또한 문자열 리터럴("Hello")을 전달할 수 있다.
4 char src[] = "Hello"와 const char *src = "Hello"의 차이는?
char src[] = "Hello": 스택에 6바이트 복사본 생성. 내용 수정 가능.
const char *src = "Hello": 읽기 전용 메모리의 문자열 리터럴을 가리킴. 내용 수정 시 undefined behavior.
5 my_strcmp가 0, 양수, 음수를 반환하는 기준은?
첫 번째 다른 문자의 아스키코드 차이를 반환. 0 = 같음, 양수 = a가 b보다 큼(사전 순 뒤), 음수 = a가 b보다 작음(사전 순 앞). "abc"와 "abd"는 마지막 글자 c(99) - d(100) = -1.

이번 프로젝트 핵심

  • 문자열은 null 문자('\0')로 끝나는 char 배열이다
  • strcpy = while (*dst++ = *src++) != '\0'; 단 한 줄로 가능
  • strlen = '\0'까지 포인터 이동 후 p - start로 길이 계산
  • const char *src로 읽기 전용 보호를 명시해야 한다
  • dst 버퍼 크기를 반드시 충분하게 확보해야 한다
