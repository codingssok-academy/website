배열과 반복문
— for로 배열 전체를 처리하기

배열이 진짜 강력해지는 순간, 반복문과 만날 때입니다. for 루프 하나로 원소 100개를 입력받고, 합산하고, 출력합니다.

이 유닛에서 배우는 것

  • for(i=0; i<5; i++)로 배열 전체를 순회할 수 있습니다.
  • 반복문으로 배열에 값을 입력받을 수 있습니다.
  • 배열 원소의 합계와 평균을 계산하는 패턴을 익힙니다.
  • 역순으로 배열을 출력하는 방법을 알 수 있습니다.
  • 배열과 반복문을 결합하면 코드가 얼마나 짧아지는지 이해합니다.

for 루프로 배열 전체 출력

배열 크기가 5이면 인덱스는 0~4입니다. for(i=0; i<5; i++)를 쓰면 i가 0, 1, 2, 3, 4로 바뀌면서 모든 원소를 순서대로 접근합니다.

#include <stdio.h> int main() { int arr[5] = {10, 20, 30, 40, 50}; // for 루프로 배열 전체 출력 for (int i = 0; i < 5; i++) { printf("arr[%d] = %d\n", i, arr[i]); } return 0; }

크기 3인 배열 {5, 10, 15}를 for 루프로 출력하세요.
int a[3] = {5, 10, 15}; for (int i = 0; i < 3; i++) { printf("%d\n", a[i]); }
5, 10, 15 차례로 출력됩니다

반복문으로 배열에 값 입력받기

scanf와 for 루프를 함께 쓰면 사용자로부터 여러 값을 배열에 순서대로 저장할 수 있습니다.

#include <stdio.h> int main() { int score[5]; // 5개 값 입력받기 printf("점수 5개를 입력하세요:\n"); for (int i = 0; i < 5; i++) { scanf("%d", &score[i]); } // 입력받은 값 출력 printf("입력된 점수:\n"); for (int i = 0; i < 5; i++) { printf("%d번: %d점\n", i + 1, score[i]); } return 0; }

합계와 평균 계산 패턴

배열의 합계와 평균은 매우 자주 쓰는 패턴입니다. sum += arr[i]로 누적하고, 마지막에 개수로 나눕니다.

int arr[5] = {10, 20, 30, 40, 50}; int sum = 0; for (int i = 0; i < 5; i++) { sum += arr[i]; // sum = sum + arr[i] } printf("합계: %d\n", sum); printf("평균: %.1f\n", (double)sum / 5);

int a[] = {4, 8, 12}; int sum = 0; for (int i = 0; i < 3; i++) sum += a[i]; printf("합계: %d\n", sum);
합계: 24 가 출력됩니다

역순 출력 — i를 끝에서 시작

역순 출력은 for의 시작값을 마지막 인덱스(N-1)로, 조건을 i>=0으로, 증감을 i--로 바꿉니다.

int arr[5] = {10, 20, 30, 40, 50}; // 정순 출력 printf("정순: "); for (int i = 0; i < 5; i++) { printf("%d ", arr[i]); } printf("\n"); // 역순 출력 printf("역순: "); for (int i = 4; i >= 0; i--) { printf("%d ", arr[i]); } printf("\n");

전체 패턴 종합 — 입력, 합계, 평균, 최대값

#include <stdio.h> int main() { int score[5]; int sum = 0, max; // 입력 for (int i = 0; i < 5; i++) { scanf("%d", &score[i]); } max = score[0]; // 최대값 초기화 for (int i = 0; i < 5; i++) { sum += score[i]; if (score[i] > max) max = score[i]; } printf("합계: %d\n", sum); printf("평균: %.1f\n", (double)sum / 5); printf("최대: %d\n", max); return 0; }

int a[] = {3, 1, 4, 1, 5}; for (int i = 4; i >= 0; i--) printf("%d ", a[i]);

쉬움
아래 코드의 빈칸을 채워 합계를 구하세요.
int arr[3] = {10, 20, 30}; int sum = 0; for (int i = 0; i < ____; i++) { ____ += arr[i]; } printf("합계: %d\n", sum);
내 답안
힌트 보기
배열 크기는 3, 누적은 sum += arr[i]입니다.

Q3
오류 찾기
보통
아래 코드에서 잘못된 부분을 찾아 설명하세요.
int arr[5] = {1, 2, 3, 4, 5}; for (int i = 0; i <= 5; i++) { printf("%d\n", arr[i]); }
내 답안
힌트 보기
크기 5인 배열의 마지막 인덱스는 4입니다. i<=5이면 i=5일 때도 실행됩니다.
정답 보기
i <= 5 → i=5일 때 arr[5] 접근 = 인덱스 범위 초과 올바른 조건: i < 5
Q4
코드 작성 — 평균
보통
사용자로부터 정수 4개를 입력받아 배열에 저장하고, 평균을 소수점 한 자리로 출력하는 프로그램을 작성하세요.
내 답안
힌트 보기
입력 루프와 합계 루프를 별도로 쓰거나 한 루프에서 같이 처리해도 됩니다. 평균은 (double)sum / 4입니다.
정답 보기
#include <stdio.h> int main() { int a[4], sum = 0; for (int i = 0; i < 4; i++) scanf("%d", &a[i]); for (int i = 0; i < 4; i++) sum += a[i]; printf("평균: %.1f\n", (double)sum / 4); return 0; }
Q5
최소값 찾기
보통
배열 {42, 7, 99, 13, 55}에서 가장 작은 값을 찾아 출력하는 프로그램을 작성하세요.
내 답안
힌트 보기
min을 arr[0]으로 초기화하고, 루프를 돌며 arr[i] < min이면 min을 갱신합니다.
정답 보기
#include <stdio.h> int main() { int arr[] = {42, 7, 99, 13, 55}; int min = arr[0]; for (int i = 1; i < 5; i++) { if (arr[i] < min) min = arr[i]; } printf("최솟값: %d\n", min); // 7 return 0; }

핵심 정리

  • 정순 순회: for(i=0; i<N; i++) — i가 0부터 N-1까지
  • 역순 순회: for(i=N-1; i>=0; i--) — i가 N-1부터 0까지
  • 입력: scanf("%d", &arr[i]); — 반복문 안에서 사용
  • 합계 누적: sum = 0; sum += arr[i];
  • 평균: (double)sum / N — 정수 나눗셈 방지를 위해 형변환
