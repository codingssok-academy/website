동적 구조체 배열
크기 조절 패턴

구조체 포인터를 malloc으로 할당하고 realloc으로 크기를 조절하는 방법을 배웁니다. 실제 데이터 관리 프로그램의 핵심 패턴입니다.

이 유닛에서 배우는 것

  • 구조체 포인터를 malloc으로 할당합니다.
  • 화살표 연산자(->)로 동적 구조체 멤버에 접근합니다.
  • 구조체 배열을 동적으로 할당합니다.
  • realloc으로 구조체 배열 크기를 늘립니다.
  • 실제 데이터 관리 패턴을 구현합니다.

구조체 포인터 동적 할당

구조체도 malloc으로 동적 할당할 수 있습니다. 포인터로 멤버에 접근할 때는 -> 연산자를 사용합니다.

typedef struct { char name[30]; int age; int score; } Student; // 구조체 1개 동적 할당 Student *s = (Student*)malloc(sizeof(Student)); if (s == NULL) { return 1; } strcpy(s->name, "홍길동"); s->age = 15; s->score = 95; printf("%s %d점\n", s->name, s->score); free(s); s = NULL;

구조체 배열 동적 할당

// n명의 학생 배열 동적 할당 int n = 3; Student *students = (Student*)malloc(sizeof(Student) * n); if (students == NULL) { return 1; } students[0].age = 15; // 배열 인덱스로 접근 시 . 사용 (students+1)->age = 16; // 포인터로 접근 시 -> 사용 free(students);

realloc으로 크기 조절

#include <stdio.h> #include <stdlib.h> #include <string.h> typedef struct { char name[30]; int score; } Student; int main() { int capacity = 2, count = 0; Student *list = (Student*)malloc(sizeof(Student) * capacity); char name[30]; int score; while (scanf("%s %d", name, &score) == 2) { if (count == capacity) { capacity *= 2; Student *tmp = (Student*)realloc(list, sizeof(Student)*capacity); if (tmp == NULL) { free(list); return 1; } list = tmp; } strcpy(list[count].name, name); list[count].score = score; count++; } for (int i=0; i<count; i++) printf("%s: %d\n", list[i].name, list[i].score); free(list); return 0; }
capacity를 2배씩 늘리는 방식은 벡터(Vector) 자료구조의 핵심 아이디어입니다. 매번 realloc하면 느리므로 미리 여유를 두고 늘립니다.

4
capacity 패턴
보통
capacity를 2배씩 늘리는 방식의 장점은 무엇인가요?
힌트 / 정답 보기
데이터가 추가될 때마다 realloc을 호출하면 느립니다. 2배씩 늘리면 realloc 호출 횟수가 log2(n)회로 줄어들어 전체적으로 효율적입니다 (분할상환 분석 O(1) amortized).

void printBest(Student *arr, int n) { int maxIdx = 0; for (int i=1; i<n; i++) if (arr[i].score > arr[maxIdx].score) maxIdx = i; printf("최고: %s %d점\n", arr[maxIdx].name, arr[maxIdx].score); }
핵심 정리

핵심 정리

  • 구조체 동적 할당 — malloc(sizeof(구조체))
  • 포인터 멤버 접근 — s->멤버 ((*s).멤버와 동일)
  • 구조체 배열 — malloc(sizeof(구조체) * n)
  • 크기 조절 — realloc + 임시 포인터 + NULL 체크
  • capacity 2배 패턴 — realloc 호출 횟수 최소화
