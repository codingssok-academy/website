배열 선언과 초기화
— 처음부터 값을 채우는 방법

배열을 선언하는 동시에 값을 넣는 초기화 방법들을 배웁니다. 부분 초기화, 전체 0 초기화, 크기 자동 결정까지 익힙니다.

이 유닛에서 배우는 것

  • 중괄호 { }를 이용한 배열 초기화를 할 수 있습니다.
  • 부분 초기화 시 나머지 원소가 0이 됨을 이해합니다.
  • = {0}으로 전체를 0으로 초기화할 수 있습니다.
  • 크기를 생략해 초기화 개수로 크기를 자동 결정할 수 있습니다.
  • 선언만 한 배열(쓰레기값)과 초기화한 배열의 차이를 설명할 수 있습니다.

선언만 한 배열 vs 초기화한 배열

배열도 일반 변수와 마찬가지로 선언만 하면 쓰레기값이 들어있습니다. 사용 전에 반드시 초기화해야 합니다.

중괄호로 초기화: {값1, 값2, ...}

배열 선언과 동시에 중괄호 안에 값을 넣으면 초기화됩니다. 값의 개수는 배열 크기와 같아야 합니다.

// 전체 초기화: 크기와 값 개수가 일치 int score[5] = {85, 92, 78, 95, 88}; printf("%d %d %d %d %d\n", score[0], score[1], score[2], score[3], score[4]); // 출력: 85 92 78 95 88
따라해보세요
1
크기 4인 배열 num을 선언하면서 1, 3, 5, 7로 초기화하세요.
int num[4] = {1, 3, 5, 7}; printf("%d %d %d %d\n", num[0], num[1], num[2], num[3]);
1 3 5 7 이 출력됩니다

부분 초기화 — 나머지는 자동으로 0

초기화 값의 개수가 배열 크기보다 적으면, 나머지 원소는 자동으로 0으로 채워집니다.

전체를 0으로 초기화 — {0} 패턴

배열 전체를 0으로 초기화할 때는 = {0}을 사용합니다. 첫 원소에 0을 주면 나머지도 모두 0이 됩니다.

// 부분 초기화: 나머지는 0 int a[5] = {10, 20, 30}; // a[0]=10, a[1]=20, a[2]=30, a[3]=0, a[4]=0 // 전체 0으로 초기화 int b[5] = {0}; // b[0]=0, b[1]=0, b[2]=0, b[3]=0, b[4]=0 // 첫 원소만 지정, 나머지 0 int c[5] = {99}; // c[0]=99, c[1]=0, c[2]=0, c[3]=0, c[4]=0
부분 초기화 활용 팁

= {0} 패턴은 배열을 초기화할 때 가장 많이 쓰는 관용구입니다. 반복문으로 합산하기 전에 배열을 0으로 준비할 때 특히 유용합니다.

따라해보세요
1
크기 5인 배열 val을 {1, 2}로 초기화하고 모든 원소를 출력하세요.
int val[5] = {1, 2}; printf("%d %d %d %d %d\n", val[0], val[1], val[2], val[3], val[4]);
1 2 0 0 0 이 출력됩니다
2
크기 4인 배열 zero를 전체 0으로 초기화하세요.
int zero[4] = {0}; // zero[0]=0, zero[1]=0, zero[2]=0, zero[3]=0
네 원소 모두 0입니다

크기 생략 — 컴파일러가 자동으로 결정

초기화 목록을 주면 배열 크기를 생략할 수 있습니다. 컴파일러가 값 개수를 세어서 크기를 자동으로 정합니다.

// 크기 명시 (일반) int a[4] = {10, 20, 30, 40}; // 크기 생략 (동일한 결과) int b[] = {10, 20, 30, 40}; // 크기 = 4 자동 결정 // 월별 이름처럼 고정 데이터에 유용 int days[] = {31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31}; // 크기 = 12 자동 결정

초기화 패턴 4가지 비교

핵심 정리

  • 전체 초기화: int arr[3] = {1, 2, 3}; — 크기만큼 값을 모두 나열
  • 부분 초기화: int arr[5] = {1, 2}; — 나머지 원소는 자동으로 0
  • 전체 0 초기화: int arr[5] = {0}; — 전체 원소가 0이 됨
  • 크기 생략: int arr[] = {1, 2, 3}; — 컴파일러가 3으로 자동 결정
  • 선언만 한 배열에는 쓰레기값이 들어있으므로 반드시 초기화 후 사용
