Chapter 11

복합 대입 연산자

+=, -=, *=, /=, %= — 변수에 연산과 대입을 동시에 처리하는 5가지 단축 문법을 모두 익힙니다.

이 유닛에서 배우는 것

  • +=, -=, *=, /=, %= 5가지를 모두 읽고 쓸 수 있다
  • a = a + 5와 a += 5가 완전히 같다는 것을 이해한다
  • 복합 대입이 코드를 간결하게 만드는 이유를 설명할 수 있다
  • =+와 +=를 혼동하지 않는다
  • 점수 누적, 할인 적용 등 실전 상황에 적용할 수 있다

기본 개념 — 왜 복합 대입을 쓰나?

프로그래밍에서는 "변수의 값을 바꿔서 다시 그 변수에 저장"하는 일이 매우 많습니다. 예를 들어 점수를 10점 올리려면 이렇게 씁니다.

a += 5는 a = a + 5와 완전히 동일합니다. 컴퓨터가 실행하는 방식도 같습니다. 단지 타이핑을 줄이고, 코드를 읽기 쉽게 만들어 줍니다.

#include <stdio.h> int main(void) { int a = 10; printf("초기값: %d\n", a); // 10 a += 5; // a = a + 5 = 15 printf("+=5 후: %d\n", a); // 15 a *= 2; // a = a * 2 = 30 printf("*=2 후: %d\n", a); // 30 a -= 6; // a = a - 6 = 24 printf("-=6 후: %d\n", a); // 24 return 0; }

활용 예시 — 실전에서 이렇게 쓴다

예시 1 — 점수 누적 계산 (total += score)

#include <stdio.h> int main(void) { int total = 0; int score; printf("3과목 점수를 입력하세요: "); scanf("%d", &score); total += score; // 1과목 scanf("%d", &score); total += score; // 2과목 scanf("%d", &score); total += score; // 3과목 printf("합계: %d, 평균: %.1f\n", total, total / 3.0); return 0; }

예시 2 — 할인 적용 (price -= discount)

#include <stdio.h> int main(void) { int price = 50000; // 정가 50,000원 int discount = 5000; // 할인 5,000원 price -= discount; // 50000 - 5000 = 45000 price *= 2; // 2개 구매: 45000 * 2 = 90000 price /= 10; // 10% 추가 할인: 90000 / 10 = 9000 printf("최종 결제 금액: %d원\n", price); return 0; }

흔한 실수 — 이것만 주의하면 된다

실수 1 — =+ 오타 주의

a =+ 5는 복합 대입이 아닙니다. a = (+5)로 해석되어 a에 그냥 5가 저장됩니다. 기존 a의 값은 완전히 사라집니다.

항상 +=처럼 연산자를 먼저, 등호를 나중에 씁니다.

실수 2 — 초기화 없이 += 사용

초기화하지 않은 변수에 +=를 사용하면 쓰레기 값에 더해집니다. 예상치 못한 큰 숫자가 나올 수 있습니다.

누적용 변수는 반드시 int sum = 0;처럼 0으로 초기화한 뒤 사용하세요.

실수 3 — a *= 2 + 3의 계산 순서

a *= 2 + 3은 a = a * (2 + 3)과 같습니다. 우변 전체인 2 + 3 = 5를 먼저 계산한 뒤 a에 곱합니다.

a = a * 2 + 3과는 다른 결과가 나옵니다. 복잡한 식은 괄호로 의도를 명확히 표현하는 것이 좋습니다.

Q5
복합 수식 결과 예측
어려움
다음 코드를 실행하면 a, b, c의 최종 값은 각각 무엇인가요? 각 줄마다 추적하세요.
int a = 10, b = 6, c = 3; a += b * c; // a = ? b -= a / c; // b = ? c *= a % b + 1; // c = ?
내 답안
힌트 보기
1줄: a = 10 + (6*3) = 28 | 2줄: b = 6 - (28/3) = 6 - 9 → -3 | 3줄: c = 3 * (28 % (-3) + 1)
정답 보기
1줄: a += b*c = 10 + (6*3) = 10 + 18 = 28 2줄: b -= a/c = 6 - (28/3) = 6 - 9 = -3 3줄: c *= a%b + 1 = 3 * (28 % (-3) + 1) = 3 * (1 + 1) ← C에서 28%(-3)=1 = 3 * 2 = 6 최종: a=28, b=-3, c=6

핵심 요약

  • 복합 대입 연산자는 a = a + n을 a += n으로 줄인 것이다
  • 5가지: += 더하기, -= 빼기, *= 곱하기, /= 나누기, %= 나머지
  • 누적 합계에는 sum = 0;으로 초기화 후 sum += score; 패턴을 쓴다
  • =+는 복합 대입이 아니다 — 항상 += 순서로 써야 한다
  • a *= 2 + 3은 a = a * (2 + 3) — 우변 전체를 먼저 계산한다
  • 실행 순서대로 한 줄씩 추적하면 어떤 복잡한 연산도 따라갈 수 있다
