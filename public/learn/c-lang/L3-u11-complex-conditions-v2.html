복합 조건
— &&, || 조합 실전

두 가지 이상의 조건을 하나로 묶어 정교한 분기를 만드는 법을 배웁니다. 드모르간 법칙까지 익히면 복잡한 조건도 명쾌하게 다룰 수 있습니다.

이 유닛에서 배우는 것

  • 복합 조건을 단계별로 분해해서 읽을 수 있습니다.
  • 괄호로 우선순위를 명확히 표현할 수 있습니다.
  • 로그인 / 영업시간 / 입력 검증 등 실전 패턴을 사용할 수 있습니다.
  • 드모르간 법칙으로 부정 조건을 단순화할 수 있습니다.

복합 조건 읽는 법

조건식이 길고 복잡할수록 괄호 단위로 쪼개서 읽어야 합니다. 한 번에 전체를 이해하려 하지 말고, 안쪽 괄호부터 평가하세요.

괄호 위치가 결과를 바꾼다

같은 변수, 같은 연산자라도 괄호 위치가 다르면 결과가 다릅니다. 의도가 정확히 드러나도록 항상 괄호를 사용하세요.
따라해보세요
1
age가 18 이상이고 65 이하인지 확인하는 조건을 작성해보세요.
int age = 30; if (age >= 18 && age <= 65) { printf("근로 가능 연령\n"); }
age = 30 이면 "근로 가능 연령" 출력
2
(age >= 18 && age <= 65) || isVIP를 직접 입력하고, isVIP = 1로 테스트해보세요.
int age = 10; int isVIP = 1; if ((age >= 18 && age <= 65) || isVIP) { printf("입장 가능\n"); }
age=10이어도 isVIP=1이므로 "입장 가능" 출력
3
점수가 60점 이상이고 출석이 80% 이상일 때 합격 처리하는 조건을 작성해보세요.
int score = 75; int attendance = 85; if (score >= 60 && attendance >= 80) { printf("합격\n"); } else { printf("불합격\n"); }
score=75, attendance=85 이면 "합격" 출력

실전 복합 조건 패턴

현업 코드에서 자주 등장하는 세 가지 패턴입니다. 패턴을 외우면 복잡한 조건도 빠르게 작성할 수 있습니다.

패턴 1 — 로그인 + 권한 체크

// id가 admin이고 pw가 맞거나, 슈퍼유저이면 로그인 if ((id == 'A' && pw == 1234) || isSuperUser) { printf("로그인 성공\n"); }

패턴 2 — 영업시간 판별

// 평일(1~5) + 9시~18시 사이면 영업 중 if ((hour >= 9 && hour < 18) && dayOfWeek <= 5) { printf("영업 중\n"); } else { printf("영업 종료\n"); }

패턴 3 — 입력 검증 (부정 조합)

// 0~100 범위 밖이면 무효 — 부정 전체를 감싸기 if (!(score < 0 || score > 100)) { printf("유효한 점수: %d\n", score); } else { printf("잘못된 입력\n"); }
따라해보세요
1
id가 'A'(65)이고 pw가 9999이거나, isSuperUser가 1이면 "접근 허용"을 출력해보세요.
int id = 65, pw = 9999, isSuperUser = 0; if ((id == 65 && pw == 9999) || isSuperUser) { printf("접근 허용\n"); }
id=65, pw=9999 이므로 "접근 허용" 출력
2
hour = 14, dayOfWeek = 3 으로 영업시간 조건을 테스트해보세요.
int hour = 14, dayOfWeek = 3; if ((hour >= 9 && hour < 18) && dayOfWeek <= 5) { printf("영업 중\n"); }
수요일 오후 2시 — "영업 중" 출력
3
score = -5로 입력 검증을 테스트하고, "잘못된 입력"이 나오는지 확인해보세요.
int score = -5; if (!(score < 0 || score > 100)) { printf("유효\n"); } else { printf("잘못된 입력\n"); }
score=-5 이므로 "잘못된 입력" 출력

드모르간 법칙 실전

드모르간 법칙은 복잡한 부정 조건을 단순화하는 규칙입니다. 부정 기호 !를 괄호 안으로 분배할 때 &&와 ||가 바뀝니다.

법칙 1 — !(A && B) = !A || !B

법칙 2 — !(A || B) = !A && !B

부정 조건 단순화 — 실전 예시

핵심: !를 괄호 안으로 밀어 넣으면 && ↔ || 가 반전됩니다. 반대로, 괄호 밖으로 꺼낼 때도 동일하게 반전됩니다.
따라해보세요
1
!(x > 0 && y > 0)를 드모르간 법칙으로 변환하고, x=1, y=-1로 두 식이 같은 결과인지 확인해보세요.
int x = 1, y = -1; // 원래 표현 printf("%d\n", !(x > 0 && y > 0)); // 드모르간 변환 printf("%d\n", (x <= 0) || (y <= 0));
둘 다 1(참) 출력 — 동일한 조건
2
!(score < 0 || score > 100)를 드모르간으로 변환해 더 읽기 쉽게 만들어보세요.
int score = 75; // 변환 전 if (!(score < 0 || score > 100)) { ... } // 변환 후 (더 직관적) if (score >= 0 && score <= 100) { printf("유효 점수\n"); }
score=75 이므로 "유효 점수" 출력
3
!(isAdmin || isModerator)를 드모르간으로 변환해보세요.
int isAdmin = 0, isModerator = 0; // 변환 전: 관리자도 아니고 모더레이터도 아니면 if (!(isAdmin || isModerator)) { printf("일반 사용자\n"); } // 변환 후: 동일한 의미, 더 명확 if (!isAdmin && !isModerator) { printf("일반 사용자\n"); }
둘 다 "일반 사용자" 출력 — 동일한 조건

확인 문제

1
복합 AND 조건 — 청소년 요금 판별
쉬움
나이가 13세 이상이고 18세 이하이면 "청소년 요금"을 출력하는 프로그램을 작성하세요.
age = 15로 테스트하세요.
입력 age = 15
출력 청소년 요금
내 답안
힌트 / 정답 보기
age >= 13 과 age <= 18 두 조건을 && 로 묶으세요.
int age = 15; if (age >= 13 && age <= 18) { printf("청소년 요금\n"); } else { printf("일반 요금\n"); }
2
복합 OR 조건 — 할인 대상 판별
쉬움
나이가 65세 이상이거나, 장애인(isDisabled == 1)이거나, 군인(isSoldier == 1)이면 "할인 대상"을 출력하세요.
age=30, isDisabled=0, isSoldier=1로 테스트하세요.
입력 age=30, isDisabled=0, isSoldier=1
출력 할인 대상
내 답안
힌트 / 정답 보기
세 조건을 || 로 연결하세요. 셋 중 하나라도 참이면 됩니다.
int age = 30, isDisabled = 0, isSoldier = 1; if (age >= 65 || isDisabled || isSoldier) { printf("할인 대상\n"); } else { printf("일반 요금\n"); }
3
중첩 복합 조건 — 심야 할증 판별
보통
택시 심야 할증 조건: 시간이 22시 이상이거나 6시 미만이고, 거리가 10km 초과일 때 "심야 할증"을 출력하세요.
hour=23, distance=15로 테스트하세요.
입력 hour=23, distance=15
출력 심야 할증
내 답안
힌트 / 정답 보기
시간 조건을 괄호로 묶어 OR 처리하고, 거리 조건과 AND 로 연결하세요: (hour >= 22 || hour < 6) && distance > 10
int hour = 23, distance = 15; if ((hour >= 22 || hour < 6) && distance > 10) { printf("심야 할증\n"); } else { printf("기본 요금\n"); }
4
드모르간 변환 — 버그 찾기
보통
아래 두 조건이 동일한지 확인하고, 틀렸다면 올바르게 고쳐 드모르간 법칙을 적용하세요.
원본 !(a > 5 && b < 10)
변환 a <= 5 && b >= 10 (맞나요?)
내 답안
힌트 / 정답 보기
!(A && B) = !A || !B — && 는 || 로 바뀌어야 합니다!
// 틀린 변환 (&&가 그대로) !(a > 5 && b < 10) ≠ a <= 5 && b >= 10 // 올바른 변환 (&&→||) !(a > 5 && b < 10) == a <= 5 || b >= 10 // 검증 int a = 3, b = 7; printf("%d\n", !(a>5&&b<10)); // 1 (참) printf("%d\n", a<=5||b>=10); // 1 (참) — 동일
5
종합 — 회원 등급 판별
어려움
쇼핑몰 등급 조건을 구현하세요.
VIP: 구매액 100만원 이상이고, 가입일이 1년 이상이거나 리뷰 수가 10개 이상
GOLD: 구매액 50만원 이상이고 VIP가 아닐 때
그 외: NORMAL
purchase=120, years=0, reviews=15 로 테스트하세요.
입력 purchase=120, years=0, reviews=15
출력 VIP 등급
내 답안
힌트 / 정답 보기
VIP 조건: purchase >= 100 && (years >= 1 || reviews >= 10). if-else if 체인으로 연결하세요.
int purchase = 120, years = 0, reviews = 15; int isVIP = (purchase >= 100) && (years >= 1 || reviews >= 10); int isGold = (purchase >= 50) && !isVIP; if (isVIP) printf("VIP 등급\n"); else if (isGold) printf("GOLD 등급\n"); else printf("NORMAL 등급\n");

Unit 11 핵심 요약

  • && (AND): 모든 조건이 참이어야 전체가 참
  • || (OR): 하나라도 참이면 전체가 참
  • 우선순위: 괄호 > ! > 비교 > && > || — 괄호로 의도를 명확히
  • 드모르간 법칙 1: !(A && B) = !A || !B — && 가 || 로
  • 드모르간 법칙 2: !(A || B) = !A && !B — || 가 && 로
  • 실전 팁: 복잡한 조건은 bool 변수에 먼저 담아두면 가독성이 좋아집니다
