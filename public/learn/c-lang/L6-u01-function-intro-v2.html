함수란? — 코드 묶음에 이름 붙이기

같은 코드를 반복 작성하지 않아도 되는 마법, 함수를 배웁니다. 입력을 받고, 처리하고, 결과를 돌려주는 구조를 이해해봅시다.

이 유닛에서 배우는 것

  • 함수가 무엇인지 설명할 수 있습니다.
  • 함수가 왜 필요한지 반복 코드 예시로 이해합니다.
  • 함수의 세 요소(입력, 처리, 출력)를 구분합니다.
  • main 함수가 함수임을 이해합니다.
  • 간단한 함수를 직접 정의하고 호출할 수 있습니다.

함수 = 코드 묶음에 이름 붙이기

함수(Function)란 특정 작업을 수행하는 코드 묶음에 이름을 붙인 것입니다. 요리 레시피처럼, 한 번 만들어두면 언제든 이름만 불러서 사용할 수 있습니다.

우리가 지금까지 계속 사용해온 main()도 함수입니다. 그리고 printf(), scanf()도 모두 미리 만들어진 함수입니다. 우리가 직접 만들 수도 있습니다.

함수가 왜 필요할까? — 반복 코드 제거

같은 작업을 여러 번 해야 할 때, 함수가 없으면 같은 코드를 계속 써야 합니다.

함수를 사용하면 코드가 짧아지고, 수정도 한 곳만 하면 됩니다. 이것이 함수의 가장 큰 장점입니다.

main도 함수다

우리가 항상 작성하는 int main()도 사실 함수입니다. 프로그램이 시작되면 운영체제가 main 함수를 호출합니다.

// main도 함수 — 운영체제가 호출함 int main() { printf("안녕하세요!\n"); return 0; // 운영체제에 0 반환 (정상 종료) }

printf()도 함수입니다. stdio.h 파일 안에 이미 정의되어 있어서, 우리가 이름만 불러 사용할 수 있습니다. 우리도 이런 함수를 직접 만들 수 있습니다.

나만의 함수 만들기 — 첫 번째 예제

함수를 만들고(정의), 이름을 불러 사용하는(호출) 과정을 따라해봅니다.

#include <stdio.h> // 함수 정의: sayHello라는 함수를 만든다 void sayHello() { printf("안녕하세요!\n"); printf("반갑습니다!\n"); } int main() { sayHello(); // 함수 호출 1번 printf("---\n"); sayHello(); // 함수 호출 2번 return 0; }

Q3

보통
아래 코드에서 잘못된 부분을 찾아 고치세요.
void greet() { printf("Hello!\n"); } int main() { greet; /* 오류 */ return 0; }
내 답안
힌트 보기

greet; → greet(); 괄호 없이 함수 이름만 쓰면 호출이 아닌 함수 주소 참조가 됩니다.

핵심 요약

  • 함수는 특정 작업을 수행하는 코드 묶음에 이름을 붙인 것입니다.
  • 함수의 3요소: 입력(매개변수), 처리(함수 본문), 출력(반환값).
  • 함수를 쓰면 반복 코드를 없애고, 수정도 한 곳만 하면 됩니다.
  • main(), printf(), scanf() 모두 함수입니다.
  • 함수 정의 후 이름과 괄호()로 호출합니다.
