Chapter 06

중첩 if —
조건 안의 조건

if 안에 또 다른 if를 넣어 더 세밀한 판단을 하는 법을 배웁니다.

이 유닛에서 배우는 것

  • 중첩 if가 왜 필요한지 이해할 수 있습니다.
  • if 안에 또 다른 if를 작성할 수 있습니다.
  • 중첩 if와 &&(논리연산자)의 차이를 설명할 수 있습니다.
  • 깊은 중첩이 왜 나쁜지 알고, 피하는 방법을 압니다.
  • dangling else 문제를 이해하고 중괄호로 해결할 수 있습니다.

중첩 if 기본

단일 조건으로 충분하지 않을 때가 있습니다. "점수가 80점 이상이면서, 출석도 80% 이상이어야 합격"처럼 두 조건을 단계적으로 확인해야 할 때 중첩 if를 씁니다.

문법 구조 — 들여쓰기가 핵심

실행 흐름도

아래 코드는 점수와 출석을 모두 확인해서 합격 여부를 알려줍니다.

int score = 85; int attend = 90; // 출석률 (%) if (score >= 80) { // 1차 조건 통과 — 이제 2차 조건 확인 if (attend >= 80) { printf("합격입니다!\n"); } else { printf("출석이 부족합니다.\n"); } } else { printf("점수가 부족합니다.\n"); }
따라해보세요
1
age가 18 이상이고, height가 160 이상일 때 "탑승 가능"을 출력하는 중첩 if를 작성하세요.
int age = 18, height = 165; if (age >= 18) { if (height >= 160) { printf("탑승 가능\n"); } }
탑승 가능 이 출력됩니다
2
money가 1000 이상이면서 item이 재고(stock)가 있을 때(stock > 0) "구매 완료"를 출력하세요.
int money = 2000, stock = 3; if (money >= 1000) { if (stock > 0) { printf("구매 완료\n"); } else { printf("품절입니다\n"); } }
구매 완료 가 출력됩니다
3
score가 60 이상이면 "통과"를 출력하고, 그 안에서 score가 90 이상이면 추가로 "우수상"을 출력하세요.
int score = 92; if (score >= 60) { printf("통과\n"); if (score >= 90) { printf("우수상\n"); } }
통과 와 우수상 이 모두 출력됩니다

중첩 if vs 논리연산자(&&)

두 조건을 모두 만족할 때 실행하는 코드를 작성하는 방법은 두 가지입니다. 결과는 같지만 용도가 다릅니다.

언제 중첩을 쓰고, 언제 &&를 쓸까?

상황 추천 방식 이유
조건이 2개, 둘 다 참이어야 실행 && 코드가 짧고 읽기 쉬움
각 조건마다 다른 오류 메시지 필요 중첩 if 어느 조건이 실패했는지 else로 알 수 있음
1차 통과 후 추가 정보 처리 필요 중첩 if 1차 통과 내부에서 여러 작업 가능
조건이 3개 이상 &&로 연결됨 중첩 if &&가 너무 길어지면 중첩으로 쪼개는 게 명확
따라해보세요
1
temp가 0보다 크고 40보다 작을 때 "정상 체온 범위"를 출력하는 코드를 중첩 if로 작성하세요.
int temp = 36; if (temp > 0) { if (temp < 40) { printf("정상 체온 범위\n"); } }
정상 체온 범위 가 출력됩니다
2
위 코드를 &&를 사용해서 한 줄짜리 if로 바꿔보세요.
int temp = 36; if (temp > 0 && temp < 40) { printf("정상 체온 범위\n"); }
결과는 똑같이 정상 체온 범위 가 출력됩니다
3
로그인 확인: id_ok가 1(참)이고 pw_ok도 1일 때 "로그인 성공", id가 틀리면 "아이디 오류", id는 맞는데 pw가 틀리면 "비밀번호 오류"를 각각 출력하도록 중첩 if로 작성하세요.
int id_ok = 1, pw_ok = 0; if (id_ok) { if (pw_ok) { printf("로그인 성공\n"); } else { printf("비밀번호 오류\n"); } } else { printf("아이디 오류\n"); }
비밀번호 오류 가 출력됩니다

주의사항 & 심화

깊은 중첩은 피하자

코드 냄새 기준: 중첩이 3단 이상이면 읽기 어렵습니다. 중첩 3단 이상은 &&로 합치거나, 조건을 함수로 만들어 분리하세요.

들여쓰기로 구조 파악하기

dangling else — 어느 if에 붙는 else일까?

규칙: 중첩 if에서는 반드시 중괄호 { }를 붙이세요. else가 어느 if에 붙는지 헷갈리는 dangling else 문제를 방지합니다.

따라해보세요
1
아래 3단 중첩 if를 &&를 사용해서 1단 if 하나로 바꾸세요.
if (a > 0) { if (b > 0) { if (c > 0) { printf("모두 양수"); } } }
if (a > 0 && b > 0 && c > 0) { printf("모두 양수\n"); }
중첩 없이 동일한 결과를 냅니다
2
dangling else를 고치세요. x가 10보다 크면서 y가 5보다 클 때 "OK", x가 10 이하일 때 "x 작음"을 출력하도록 중괄호를 추가하세요.
if (x > 10) { if (y > 5) { printf("OK\n"); } } else { printf("x 작음\n"); }
중괄호로 else의 소속을 명확하게 했습니다
3
아래 조건을 중첩 if로 구현하세요: num이 양수(0보다 큼)이면 짝수(num % 2 == 0)인지 홀수인지 출력하고, 음수이면 "음수입니다"를 출력하세요.
int num = 6; if (num > 0) { if (num % 2 == 0) { printf("양수이고 짝수\n"); } else { printf("양수이고 홀수\n"); } } else { printf("음수입니다\n"); }
양수이고 짝수 가 출력됩니다

int x = 10, y = 3; if (x > 5) { if (y > 5) { printf("A\n"); } else { printf("B\n"); } } else { printf("C\n"); }

코드를 작성하세요
보통
학원 입장 프로그램입니다. fee가 10000 이상이면서, reservation이 1(예약 완료)일 때 "입장 가능"을, 수강료는 냈는데 예약이 안 됐으면 "예약 먼저 하세요"를, 수강료 자체가 부족하면 "수강료 부족"을 출력하는 중첩 if를 작성하세요.
입력
fee=15000, reservation=1
출력
입장 가능
내 답안
힌트 & 정답 보기
바깥 if: fee >= 10000 / 안쪽 if: reservation == 1
int fee = 15000, reservation = 1; if (fee >= 10000) { if (reservation == 1) { printf("입장 가능\n"); } else { printf("예약 먼저 하세요\n"); } } else { printf("수강료 부족\n"); }
4
버그를 찾아 고치세요
보통
아래 코드는 a가 0보다 클 때 "a는 양수"를, a가 0 이하일 때 "a는 0이하"를 출력하려는 코드입니다. dangling else 버그가 있습니다. 어디를 수정해야 할까요?
int a = -3, b = 1; if (a > 0) if (b > 0) printf("a는 양수\n"); else printf("a는 0이하\n"); // 이 else가 어느 if에 붙을까?
내 답안
힌트 & 정답 보기
else는 들여쓰기에 관계없이 가장 가까운 if에 붙습니다. 바깥 if에 else를 붙이려면 중괄호로 구역을 나눠야 합니다.
int a = -3, b = 1; if (a > 0) { if (b > 0) { printf("a는 양수\n"); } } else { printf("a는 0이하\n"); // 이제 바깥 if에 붙음 }
5
심화 — 중첩 if로 등급 분류
어려움
점수(score)와 태도 점수(attitude)로 최종 등급을 정합니다. score가 90 이상이면서 attitude가 80 이상이면 "A등급", score가 90 이상인데 attitude가 80 미만이면 "B등급", score가 90 미만이면 "C등급 이하"를 출력하세요.
입력
score=95, attitude=75
출력
B등급
내 답안
힌트 & 정답 보기
바깥 if: score >= 90 확인. 바깥 if가 참일 때 안쪽 if로 attitude 확인. 바깥 if가 거짓이면 바깥 else에서 C등급.
int score = 95, attitude = 75; if (score >= 90) { if (attitude >= 80) { printf("A등급\n"); } else { printf("B등급\n"); } } else { printf("C등급 이하\n"); } // 출력: B등급

유닛 06 핵심 정리

  • 중첩 if는 if 안에 또 다른 if를 넣어 2단계 이상의 조건을 판단한다.
  • 바깥 if가 거짓이면 안쪽 if 전체를 건너뛴다 — 순서가 중요하다.
  • 두 조건 모두 참이어야 할 때, 단순한 경우엔 &&가 더 깔끔하다.
  • 각 조건마다 다른 에러 메시지가 필요하면 중첩 if + else를 쓴다.
  • 중첩 3단 이상은 읽기 어렵다 — &&나 함수 분리로 해결한다.
  • dangling else: else는 가장 가까운 if에 붙는다. 중괄호로 명확히 하자.
