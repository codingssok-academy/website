시간 변환기

총 초를 입력받아 시:분:초로 변환합니다. /3600, %3600, /60, %60 패턴을 마스터합니다.

이 프로젝트에서 배우는 것

  • 총 초를 시, 분, 초로 변환할 수 있다
  • /와 %의 연쇄 사용 패턴을 익힌다
  • 3600(1시간)과 60(1분)의 관계를 이해한다
  • 거스름돈 계산기와 같은 패턴임을 인식한다

시간 변환 코드

1시간 = 3600초, 1분 = 60초입니다. 총 초를 3600으로 나누면 시간, 나머지를 60으로 나누면 분, 또 나머지가 초입니다.

#include <stdio.h> int main(void) { int total, hours, mins, secs; printf("총 초를 입력하세요: "); scanf("%d", &total); hours = total / 3600; // 시간 mins = total % 3600 / 60; // 분 secs = total % 60; // 초 printf("%d시간 %d분 %d초\n", hours, mins, secs); return 0; }

도전 문제

Q1
직접 계산하기
쉬움
10000초는 몇 시간 몇 분 몇 초인지 직접 계산하세요.
정답 보기
10000 / 3600 = 2 (시간) 10000 % 3600 = 2800 2800 / 60 = 46 (분) 2800 % 60 = 40 (초) 답: 2시간 46분 40초
Q2
일(day) 추가
보통
총 초가 86400(1일) 이상일 수 있도록, 일:시:분:초로 변환하세요.
입력90061
출력1일 1시간 1분 1초
내 답안
힌트 보기
1일 = 86400초. 먼저 86400으로 나누고, 나머지로 시간 계산을 합니다.
정답 보기
int days = total / 86400; total %= 86400; int hours = total / 3600; total %= 3600; int mins = total / 60; int secs = total % 60;
Q3
역변환: 시분초 -> 초
보통
시, 분, 초를 입력받아 총 초로 변환하세요.
입력2 30 15
출력9015초
내 답안
정답 보기
int h, m, s; scanf("%d %d %d", &h, &m, &s); printf("%d초\n", h*3600 + m*60 + s);

핵심 요약

  • 시간 = 총초 / 3600, 분 = 나머지 / 60, 초 = 나머지 % 60
  • total % 3600 / 60처럼 연산을 연결할 수 있다
  • 거스름돈 계산과 시간 변환은 같은 패턴이다 (큰 단위부터)
  • 역변환: 총초 = 시*3600 + 분*60 + 초
