Chapter 01

변수란? — 데이터를 담는 상자

프로그래밍의 가장 기본, 변수를 배웁니다. 데이터를 저장하고, 바꾸고, 출력하는 법을 익혀봅시다.

이 유닛에서 배우는 것

  • 변수가 무엇인지 설명할 수 있습니다.
  • 변수를 선언하고 초기화할 수 있습니다.
  • 올바른 변수 이름 규칙을 알 수 있습니다.
  • 변수에 새 값을 대입하고 출력할 수 있습니다.
  • 왜 변수가 필요한지 설명할 수 있습니다.

변수 = 이름표 붙은 상자

변수(Variable)란 데이터를 저장하는 메모리 공간에 이름을 붙인 것입니다. 마치 이름표가 붙은 상자에 물건을 넣고 꺼내는 것과 같습니다.

변수가 없다면 어떨까요? 같은 값을 쓸 때마다 직접 숫자를 입력해야 합니다. 값이 바뀌면 모든 곳을 수정해야 합니다. 변수를 쓰면 한 번만 바꾸면 됩니다.

변수 선언과 초기화

변수를 사용하려면 먼저 상자를 만들겠다고 컴퓨터에 알려야 합니다. 이것을 선언이라고 합니다.

int age;는 정수를 담을 상자 age를 만들어라 라는 뜻입니다. int age = 15;는 선언과 동시에 값 15를 넣는 것이며, 이를 초기화라고 합니다.

// 1단계: 선언 (상자만 만들기) int age; // 2단계: 값 대입 (상자에 값 넣기) age = 15; // 한 줄로 선언 + 초기화 int score = 95; // 여러 변수를 한 줄에 선언 int a = 10, b = 20, c = 30;
따라해보세요
1
정수형 변수 grade를 선언하고, 값 2를 넣어보세요.
int grade = 2;
grade라는 상자에 2가 들어갑니다
2
변수 height를 선언하고 값 165를 넣은 뒤 출력해보세요.
int height = 165; printf("키: %d cm", height);
키: 165 cm 이 출력됩니다
3
변수 year를 선언하고 2025를 넣어보세요.
int year = 2025; printf("올해: %d년", year);
올해: 2025년 이 출력됩니다

변수 이름 규칙

변수 이름은 아무렇게나 지을 수 없습니다. C언어에는 반드시 지켜야 할 규칙이 있습니다.

변수에 새 값 대입 (재대입)

변수에 새 값을 넣으면 이전 값은 사라지고, 새 값으로 바뀝니다. 상자의 내용물을 교체하는 것과 같습니다.

// 전체 흐름: 선언 - 초기화 - 재대입 - 출력 #include <stdio.h> int main() { int age = 15; printf("현재 나이: %d\n", age); age = 16; printf("생일 후: %d\n", age); int score = 85; score = 92; printf("최종 점수: %d\n", score); return 0; }
따라해보세요
1
변수 score를 80으로 초기화한 뒤, 95로 바꿔 출력하세요.
int score = 80; score = 95; printf("점수: %d", score);
점수: 95 가 출력됩니다 (80은 사라짐)
2
나이와 학년 변수 2개를 선언하고 출력해보세요.
int age = 14; int grade = 2; printf("나이: %d, 학년: %d", age, grade);
나이: 14, 학년: 2
3
변수 temp를 30, 25, 35로 순서대로 바꿔 출력하세요.
int temp = 30; temp = 25; temp = 35; printf("온도: %d", temp);
온도: 35 (마지막 값만 남음)

핵심 요약

  • 변수는 데이터를 저장하는 이름 붙은 메모리 공간입니다.
  • 변수를 만드는 것을 선언, 값을 넣는 것을 초기화라고 합니다.
  • 변수 이름: 영문/숫자/밑줄만 허용, 숫자 시작 불가, 예약어 사용 불가.
  • 새 값을 대입하면 이전 값은 사라지고 새 값만 남습니다.
  • 변수를 쓰면 값이 바뀌어도 한 곳만 수정하면 됩니다.
