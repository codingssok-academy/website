동적 2차원 배열
malloc 이중 포인터

포인터 배열(int**)로 2차원 배열을 동적으로 할당하는 방법을 배웁니다. 행과 열을 따로 할당하고 해제하는 패턴을 익힙니다.

이 유닛에서 배우는 것

  • int** 이중 포인터의 의미를 이해합니다.
  • 행 배열과 각 열 배열을 따로 할당합니다.
  • arr[i][j]로 2D 배열처럼 접근합니다.
  • 해제 시 열 먼저, 행 나중에 역순 해제합니다.
  • 동적 2D 배열로 행렬을 다룹니다.

동적 2차원 배열 — 구조 이해

2차원 배열을 동적으로 만들려면 int**(포인터의 포인터)를 사용합니다. 먼저 행(row) 포인터 배열을 만들고, 각 행마다 열(column)을 할당합니다.

// 3행 3열 동적 2차원 배열 int rows = 3, cols = 3; // 1단계: 행 포인터 배열 할당 int **arr = (int**)malloc(sizeof(int*) * rows); // 2단계: 각 행에 열 할당 for (int i = 0; i < rows; i++) { arr[i] = (int*)malloc(sizeof(int) * cols); }

동적 2D 배열 — 사용과 해제

#include <stdio.h> #include <stdlib.h> int main() { int rows = 3, cols = 3; // 할당 int **arr = (int**)malloc(sizeof(int*) * rows); for (int i = 0; i < rows; i++) arr[i] = (int*)malloc(sizeof(int) * cols); // 값 채우기 int val = 1; for (int i = 0; i < rows; i++) for (int j = 0; j < cols; j++) arr[i][j] = val++; // 출력 for (int i = 0; i < rows; i++) { for (int j = 0; j < cols; j++) printf("%3d", arr[i][j]); printf("\n"); } // 해제 — 열 먼저, 행 나중에! for (int i = 0; i < rows; i++) { free(arr[i]); // 각 행의 열 해제 arr[i] = NULL; } free(arr); // 행 포인터 배열 해제 arr = NULL; return 0; }
해제 순서: 열(arr[i]) 먼저 free → 행(arr) 나중에 free. 반대로 하면 행 포인터를 잃어버려 열을 해제할 수 없습니다!

해제 순서
보통
동적 2D 배열(int** arr, rows행)을 해제하는 올바른 순서는?
① free(arr) 먼저, 그 다음 for문으로 free(arr[i])
② for문으로 free(arr[i]) 먼저, 그 다음 free(arr)
③ 한 번에 free(arr) 만 호출
④ 순서 상관없음
힌트 / 정답 보기
정답: ② 열(arr[i]) 먼저 해제 → 행(arr) 나중에 해제. 행을 먼저 해제하면 arr[i]에 접근할 수 없습니다.

핵심 정리

핵심 정리

  • int** — 행 포인터들의 배열을 가리키는 포인터
  • 할당 순서 — 행 포인터 배열 먼저, 각 행의 열 나중
  • 접근 — arr[i][j] 로 일반 2D 배열과 동일
  • 해제 순서 — 열(arr[i]) 먼저, 행(arr) 나중 (역순)
