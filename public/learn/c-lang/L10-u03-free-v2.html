free로 메모리 해제
해제 후 NULL 패턴

malloc으로 빌린 메모리를 free로 반납하는 방법을 배웁니다. 해제 후 NULL 대입 패턴으로 안전한 코드를 작성합니다.

이 유닛에서 배우는 것

  • free() 함수로 동적 메모리를 반납할 수 있습니다.
  • 해제 후 NULL 대입 패턴을 이해하고 사용합니다.
  • double free 문제를 예방하는 방법을 배웁니다.
  • 메모리 해제를 빠뜨리지 않는 습관을 만듭니다.
  • 안전한 메모리 관리 패턴을 익힙니다.

free() — 메모리 반납

malloc으로 빌린 메모리는 반드시 free()로 돌려줘야 합니다. 돌려주지 않으면 힙 메모리가 계속 줄어드는 메모리 누수(leak)가 발생합니다.

// 기본 패턴 int *p = (int*)malloc(sizeof(int) * 10); if (p == NULL) { return 1; } // ... p 사용 ... p[0] = 100; free(p); // 메모리 반납

free 후 NULL 대입 패턴

free() 후에도 포인터는 이전 주소를 기억합니다. 이 상태에서 포인터를 사용하면 오류가 발생합니다. 따라서 p = NULL을 대입하는 습관을 들여야 합니다.

// 안전한 해제 패턴 free(p); p = NULL; // 해제 후 반드시 NULL 대입! // 이후에 실수로 사용해도 NULL 체크로 방어 가능 if (p != NULL) { // 여기만 실행됨 (안전) }

함수에서 동적 메모리 사용하기

함수에서 malloc으로 할당한 메모리는 함수가 끝나도 자동 해제되지 않습니다. 호출자가 직접 free해야 합니다.

#include <stdio.h> #include <stdlib.h> // 동적 배열을 만들어 반환하는 함수 int* createArray(int n) { int *arr = (int*)malloc(sizeof(int) * n); if (arr == NULL) return NULL; for (int i = 0; i < n; i++) arr[i] = i * 2; return arr; // 주소 반환 (힙에 남아있음) } int main() { int *data = createArray(5); if (data == NULL) return 1; for (int i = 0; i < 5; i++) printf("%d ", data[i]); free(data); // 호출자가 해제 data = NULL; // NULL 대입 return 0; }
함수 안에서 malloc하고 반환한 경우, 호출자가 반드시 free() 해야 합니다. 안 하면 메모리 누수!

free의 주의사항

free(NULL)은 아무 일도 하지 않습니다. 해제 후 NULL 대입하면 실수로 두 번 free해도 안전합니다.

1
free의 역할
쉬움
free() 함수가 하는 일은 무엇인가요?
① 변수를 0으로 초기화한다
② 힙에서 빌린 메모리를 반납한다
③ 포인터를 삭제한다
④ 스택 메모리를 해제한다
힌트 / 정답 보기
정답: ② free()는 malloc으로 힙에서 빌린 메모리를 운영체제에 반납합니다.
2
NULL 대입 이유
쉬움
free() 후에 포인터에 NULL을 대입하는 이유는 무엇인가요?
힌트 / 정답 보기
free() 후에도 포인터는 이전 주소를 기억합니다. 실수로 해제된 메모리에 접근(use-after-free)하거나 두 번 해제(double free)하는 것을 방지하기 위해 NULL을 대입합니다. free(NULL)은 안전하게 무시됩니다.
3
잘못된 free 찾기
보통
다음 코드에서 잘못된 부분을 찾아 수정하세요.
코드int x = 10; free(&x);
힌트 / 정답 보기
free()는 malloc으로 할당한 메모리에만 사용해야 합니다.
잘못된 점: x는 스택 변수입니다. free(&x)는 오류! 스택 변수는 함수 종료 시 자동 해제됩니다. free()는 malloc/calloc/realloc 으로 할당한 것만 사용.

p[0]=1; p[1]=2; p[2]=3;

5
함수에서 동적 메모리
어려움
함수에서 malloc으로 배열을 만들어 반환하고, main에서 사용 후 해제하는 코드를 작성하세요.
힌트 / 정답 보기
int* makeArr(int n) { int *a = (int*)malloc(sizeof(int)*n); if (a == NULL) return NULL; for (int i=0; i<n; i++) a[i] = i+1; return a; } int main() { int *arr = makeArr(3); if (arr == NULL) return 1; for (int i=0; i<3; i++) printf("%d ", arr[i]); free(arr); arr = NULL; return 0; }
핵심 정리

핵심 정리

  • free(p) — malloc으로 빌린 메모리를 반납
  • free 후 p = NULL — 안전한 패턴, 이중 해제 방지
  • free(NULL) — 아무 일도 안 함 (안전)
  • 스택 변수에 free 금지 — malloc 메모리에만 사용
  • 함수에서 반환한 동적 메모리 — 호출자가 free 해야 함
