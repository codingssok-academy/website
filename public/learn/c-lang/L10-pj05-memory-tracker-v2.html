메모리 추적기
malloc/free 횟수 추적

전역 카운터로 malloc과 free 호출 횟수를 추적하여 메모리 누수를 감지하는 간단한 메모리 추적기를 만듭니다.

이 프로젝트에서 만드는 것

  • malloc/free 래퍼 함수를 만듭니다.
  • 전역 카운터로 할당/해제 횟수를 추적합니다.
  • 할당된 총 바이트 수를 계산합니다.
  • 프로그램 종료 시 메모리 누수 여부를 보고합니다.

메모리 추적기 구현

#include <stdio.h> #include <stdlib.h> int g_malloc_count = 0; int g_free_count = 0; int g_total_bytes = 0; void* tracked_malloc(int size) { void *p = malloc(size); if(p) { g_malloc_count++; g_total_bytes += size; printf("[MALLOC] %d바이트 할당 (총 %d회)\n", size, g_malloc_count); } return p; } void tracked_free(void *p) { if(p){ g_free_count++; free(p); printf("[FREE] 해제 (총 %d회)\n", g_free_count); } } void report() { printf("\n=== 메모리 리포트 ===\n"); printf("malloc: %d회\nfree: %d회\n", g_malloc_count, g_free_count); printf("총 할당: %d바이트\n", g_total_bytes); if(g_malloc_count != g_free_count) printf("[경고] 메모리 누수 의심! %d개 미해제\n", g_malloc_count-g_free_count); else printf("[OK] 모든 메모리 해제됨\n"); } int main() { int *a = (int*)tracked_malloc(20); int *b = (int*)tracked_malloc(40); int *c = (int*)tracked_malloc(80); tracked_free(a); tracked_free(b); // c는 해제 안 함 → 누수! report(); return 0; }

실행 결과

[MALLOC] 20바이트 할당 (총 1회) [MALLOC] 40바이트 할당 (총 2회) [MALLOC] 80바이트 할당 (총 3회) [FREE] 해제 (총 1회) [FREE] 해제 (총 2회) === 메모리 리포트 === malloc: 3회 free: 2회 총 할당: 140바이트 [경고] 메모리 누수 의심! 1개 미해제
도전 과제

도전 과제

1. tracked_free(c)를 추가하면 "[OK]" 메시지로 바뀌는지 확인하세요.
2. 할당된 포인터 주소도 함께 출력해보세요.
3. 미해제된 바이트 수도 계산하여 출력해보세요.
