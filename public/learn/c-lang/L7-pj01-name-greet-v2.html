Chapter 07 — Project 01

이름 입력
→ 인사말 출력

이름을 입력받아 다양한 형식의 인사말을 출력합니다. scanf와 printf 기본 활용 프로젝트입니다.

사용 함수: scanf, printf, strlen, strcat, strcpy

핵심 개념: 문자열 입출력, 문자열 연결, 길이 활용

프로젝트 설명

이름을 입력받아 여러 가지 형식의 인사말을 출력합니다. 문자열 입출력의 기본을 연습합니다.

단계별 구현

STEP 1 — 기본 입출력
이름을 입력받아 간단한 인사말을 출력합니다.
#include <stdio.h> #include <string.h> int main() { char name[30]; printf("이름을 입력하세요: "); scanf("%s", name); printf("안녕하세요, %s 님!\n", name); printf("이름 글자 수: %lu자\n", strlen(name)); return 0; }
STEP 2 — 인사말 조합
strcat으로 인사말 문자열을 조립합니다.
char greeting[60] = "안녕하세요, "; strcat(greeting, name); strcat(greeting, " 님! 반갑습니다."); printf("%s\n", greeting);

완성 코드

#include <stdio.h> #include <string.h> #include <ctype.h> int main() { char name[30]; char greeting[80]; printf("이름을 입력하세요: "); scanf("%s", name); // 기본 인사 printf("안녕하세요, %s 님!\n", name); // 이름 길이 int len = strlen(name); printf("이름 글자 수: %d자\n", len); // 영어 이름이라면 대문자 변환 char upper_name[30]; strcpy(upper_name, name); for (int i = 0; i < len; i++) upper_name[i] = toupper(upper_name[i]); // 인사말 조합 strcpy(greeting, "[ "); strcat(greeting, name); strcat(greeting, " 님 환영합니다! ]"); printf("%s\n", greeting); return 0; }
도전! 확장 과제

성과 이름을 따로 입력받아 "성이름 님, 안녕하세요!" 형식으로 출력해보세요. strcat을 두 번 사용합니다.

심화 확장 버전

#include <stdio.h> #include <string.h> int main() { char family[15], given[15]; char full[35]; printf("성 입력: "); scanf("%s", family); printf("이름 입력: "); scanf("%s", given); strcpy(full, family); strcat(full, given); printf("\n=== 인사말 ===\n"); printf("안녕하세요, %s 님!\n", full); printf("성: %s, 이름: %s\n", family, given); printf("전체 이름 길이: %lu자\n", strlen(full)); printf("첫 글자: %c\n", full[0]); return 0; }
