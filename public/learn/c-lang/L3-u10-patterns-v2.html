조건문 패턴
— 범위, 윤년, 최대값

if/else를 실전에서 쓰는 3가지 핵심 패턴을 익힙니다. 실제 프로그램에서 가장 자주 나오는 구조입니다.

범위 판별

&&로 상한·하한 동시 검사

윤년 판별

복합 논리식 ( && + || )

최대값/최소값

변수 갱신 패턴

이 유닛에서 배우는 것

  • &&를 사용해 범위를 올바르게 표현할 수 있습니다.
  • 윤년 조건식을 논리 연산자로 완성할 수 있습니다.
  • 두 수, 세 수 중 최대·최소값을 구하는 패턴을 쓸 수 있습니다.
  • 변수 갱신 패턴이 왜 유용한지 설명할 수 있습니다.
  • 실전 문제에서 세 패턴을 올바르게 선택해 적용할 수 있습니다.

범위 판별 패턴 — &&로 범위 묶기

점수가 60점 이상 70점 미만인지 검사할 때 수학에서는 60 ≤ n < 70 이라고 씁니다. C언어에서는 이 표현을 두 조건을 &&로 연결해서 나타냅니다.

핵심 규칙: C언어에서 60 <= n < 70 처럼 쓰면 작동하지 않습니다. 반드시 n >= 60 && n < 70 형태로 써야 합니다.

int score = 75; if (score >= 90) // 90 이상 printf("A\n"); else if (score >= 80) // 80 이상 90 미만 printf("B\n"); else if (score >= 70) // 70 이상 80 미만 printf("C\n"); else if (score >= 60) // 60 이상 70 미만 printf("D\n"); else // 60 미만 printf("F\n");

범위 표현의 두 가지 방법 비교

주의: 방법 2는 else if 순서가 틀리면 버그가 납니다. 처음에는 방법 1(&&)을 쓰는 게 안전합니다.

따라해보세요
1
temp가 36 이상 37.5 미만이면 "정상", 37.5 이상이면 "발열"을 출력해보세요.
float temp = 37.2f; if (temp >= 36.0f && temp < 37.5f) printf("정상\n"); else if (temp >= 37.5f) printf("발열\n");
정상 이 출력됩니다
2
age가 13 이상 18 이하면 "청소년"을 출력해보세요. (<= 18으로 끝 범위 포함)
int age = 16; if (age >= 13 && age <= 18) printf("청소년\n");
청소년 이 출력됩니다
3
점수에 따라 S/A/B/C/F 등급을 모두 출력하는 else-if 체인을 && 없이, 순서만으로 작성해보세요.
int score = 83; if (score >= 95) printf("S\n"); else if (score >= 80) printf("A\n"); else if (score >= 70) printf("B\n"); else if (score >= 60) printf("C\n"); else printf("F\n");
A 가 출력됩니다

윤년 판별 패턴 — 복합 논리식

윤년은 달력에서 2월이 29일이 되는 해입니다. 4년에 한 번이지만, 100의 배수인 해는 건너뛰고, 400의 배수인 해는 다시 윤년이 됩니다.

조건식 단계별 분해

int y = 2024; if ((y % 4 == 0 && y % 100 != 0) || (y % 400 == 0)) printf("%d년은 윤년\n", y); else printf("%d년은 평년\n", y);
따라해보세요
1
2000년이 윤년인지 확인해보세요. (400의 배수 → 윤년)
int y = 2000; if ((y % 4 == 0 && y % 100 != 0) || (y % 400 == 0)) printf("윤년\n"); else printf("평년\n");
윤년 — 400의 배수라 세 번째 조건에서 통과
2
1900년이 평년인지 확인해보세요. (100의 배수, 400의 배수 아님 → 평년)
int y = 1900; // y%4==0 → 참, y%100!=0 → 거짓 → 첫 조건 거짓 // y%400==0 → 거짓 → 전체 거짓 → 평년 if ((y % 4 == 0 && y % 100 != 0) || (y % 400 == 0)) printf("윤년\n"); else printf("평년\n");
평년 이 출력됩니다
3
scanf로 연도를 입력받아 윤년/평년을 판단하는 완성 코드를 작성해보세요.
int y; scanf("%d", &y); if ((y % 4 == 0 && y % 100 != 0) || (y % 400 == 0)) printf("%d년: 윤년\n", y); else printf("%d년: 평년\n", y);
입력값에 따라 윤년 또는 평년 출력

최대값/최소값 패턴 — 변수 갱신

두 수 또는 세 수 중 가장 큰 값을 찾는 패턴입니다. 변수 갱신 패턴은 초기값을 먼저 대입하고, 더 큰 값이 나오면 그 값으로 교체하는 방식입니다.

2개 중 최대값 — if-else

int a = 42, b = 57; int max; if (a > b) max = a; else max = b; printf("최대값: %d\n", max); // 최대값: 57

3개 중 최대값 — 변수 갱신 패턴

int a = 20, b = 35, c = 28; int max = a; // 1단계: 첫 번째 값으로 초기화 if (b > max) max = b; // 2단계: b가 더 크면 갱신 if (c > max) max = c; // 3단계: c가 더 크면 갱신 printf("최대값: %d\n", max); // 최대값: 35

변수 갱신 패턴의 장점: 값이 4개, 5개로 늘어도 if (n > max) max = n; 한 줄씩 추가하면 됩니다. 배열과 반복문을 쓰면 100개도 같은 패턴으로 처리됩니다.

따라해보세요
1
x = 8, y = 3 중 최소값을 구해보세요. (부등호 방향만 반대)
int x = 8, y = 3; int min; if (x < y) min = x; else min = y; printf("최소값: %d\n", min);
최소값: 3 이 출력됩니다
2
a=50, b=30, c=70 세 수의 최대값을 변수 갱신 패턴으로 구해보세요.
int a = 50, b = 30, c = 70; int max = a; if (b > max) max = b; if (c > max) max = c; printf("최대값: %d\n", max);
최대값: 70 이 출력됩니다
3
세 과목 점수 kor=88, eng=72, math=95 중 가장 높은 점수를 출력해보세요.
int kor = 88, eng = 72, math = 95; int best = kor; if (eng > best) best = eng; if (math > best) best = math; printf("최고점: %d\n", best);
최고점: 95 이 출력됩니다

내 답안

힌트: 먼저 최대값을 구한 뒤, 같은 변수로 등급 판별 else-if를 이어서 쓰세요.

int kor, eng, math; scanf("%d %d %d", &kor, &eng, &math); int best = kor; if (eng > best) best = eng; if (math > best) best = math; // 등급 판별 char grade; if (best >= 90) grade = 'A'; else if (best >= 80) grade = 'B'; else if (best >= 70) grade = 'C'; else if (best >= 60) grade = 'D'; else grade = 'F'; printf("최고점: %d점 (%c등급)\n", best, grade);

Unit 10 핵심 정리

  • 범위 판별: n >= 60 && n < 70 — 하한과 상한을 &&로 연결. 수학 표기 60 ≤ n < 70 과 동일한 의미.
  • else-if 순서 활용: 높은 쪽부터 내려오면 위 조건에서 이미 걸러지므로 && 없이도 범위 분리 가능. 순서 실수 주의.
  • 윤년 공식: (y%4==0 && y%100!=0) || y%400==0 — 괄호 위치 주의.
  • 최대값 패턴: max = a;로 초기화 후 if (b > max) max = b; 반복. 값이 늘어도 같은 패턴으로 확장.
  • 최소값 패턴: 부등호만 반대(<)로 바꾸면 동일하게 적용.
