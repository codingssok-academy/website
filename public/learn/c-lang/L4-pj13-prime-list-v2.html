소수 목록 출력기

2부터 N까지 소수를 전부 출력합니다. 브루트포스 검사와 에라토스테네스의 체를 비교하며 알고리즘 효율을 배웁니다.

이 프로젝트에서 배우는 것

  • 소수(Prime)의 정의와 판별 조건을 이해합니다.
  • 중첩 for문으로 소수를 브루트포스 검사합니다.
  • 에라토스테네스의 체 알고리즘으로 효율을 높입니다.
  • 소수 개수를 카운트하고 n번째 소수를 찾습니다.
  • 차이가 2인 소수 쌍(쌍둥이 소수)을 출력합니다.

소수(Prime Number)란?

소수는 1과 자기 자신으로만 나누어지는 2 이상의 정수입니다. 2, 3, 5, 7, 11, 13... 이 해당합니다. 1은 소수가 아닙니다.

브루트포스 소수 판별

2부터 n-1까지 나누어보는 방법입니다. 하나라도 나누어지면 소수가 아닙니다. 간단하지만 느립니다. 최적화: 2부터 sqrt(n)까지만 검사해도 충분합니다.

#include <stdio.h> #include <math.h> // sqrt() 사용 (컴파일: -lm 옵션) int is_prime(int n) { if (n < 2) return 0; // 2 미만: 소수 아님 for (int i = 2; i <= (int)sqrt(n); i++) { if (n % i == 0) return 0; // 나누어지면 소수 아님 } return 1; // 나누어지지 않으면 소수 } int main() { int n, count = 0; printf("N 입력: "); scanf("%d", &n); printf("2~%d 소수: ", n); for (int i = 2; i <= n; i++) { if (is_prime(i)) { printf("%d ", i); count++; } } printf("\n총 %d개\n", count); return 0; }

에라토스테네스의 체 알고리즘

배열을 이용해 소수가 아닌 수를 한꺼번에 지워나가는 고대 그리스의 알고리즘입니다. 브루트포스보다 훨씬 빠릅니다.

#include <stdio.h> #define MAX 1000 int main() { int sieve[MAX + 1]; int n, i, j; printf("N 입력: "); scanf("%d", &n); // 1단계: 모두 1(소수 가정)로 초기화 for (i = 2; i <= n; i++) sieve[i] = 1; sieve[0] = sieve[1] = 0; // 0, 1은 소수 아님 // 2단계: i의 배수를 0(소수 아님)으로 표시 for (i = 2; i * i <= n; i++) { if (sieve[i]) { for (j = i * i; j <= n; j += i) sieve[j] = 0; } } // 3단계: sieve[i]==1인 수 출력 int count = 0; for (i = 2; i <= n; i++) { if (sieve[i]) { printf("%d ", i); count++; } } printf("\n총 %d개\n", count); return 0; }

n번째 소수 찾기

소수를 찾을 때마다 카운트를 늘려서, 카운트가 원하는 순서(k번째)에 도달하면 멈춥니다. 무한루프 + break 패턴을 활용합니다.

// k번째 소수 찾기 int k, count = 0, num = 1; printf("몇 번째 소수? "); scanf("%d", &k); while (count < k) { num++; if (is_prime(num)) count++; } printf("%d번째 소수 = %d\n", k, num); // 입력: 10 → 출력: 10번째 소수 = 29

쌍둥이 소수 (Twin Prime)

차이가 2인 소수 쌍을 쌍둥이 소수라고 합니다. (3,5), (5,7), (11,13), (17,19), (29,31)... 두 소수를 모두 찾아 쌍으로 출력합니다.

for (int i = 2; i <= n; i++) { if (is_prime(i) && is_prime(i + 2)) { printf("(%d, %d)\n", i, i + 2); } }

for (int i = 2; i <= n; i++) while (n % i == 0) { printf("%d ", i); n /= i; }

핵심 정리

  • 소수: 1과 자기자신으로만 나누어지는 2 이상의 수
  • 브루트포스: 2부터 sqrt(n)까지 나눠보기 — O(sqrt(n))
  • 에라토스테네스의 체: 배열로 배수를 일괄 제거 — O(n log log n)
  • n번째 소수: 카운트 변수로 k번째 소수 위치 추적
  • 쌍둥이 소수: is_prime(i) && is_prime(i+2) 동시 검사
