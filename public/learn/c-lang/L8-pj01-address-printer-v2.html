주소 출력기
변수의 메모리 주소 탐험

다양한 타입의 변수를 선언하고, 각각의 메모리 주소를 %p로 출력해봅니다. 메모리 레이아웃을 직접 확인합니다.

프로젝트 목표

  • 다양한 타입 변수의 주소를 %p로 출력합니다.
  • 배열 원소들의 주소가 연속적임을 확인합니다.
  • int, float, char의 주소 간격을 비교합니다.
  • 포인터 변수도 주소를 가짐을 확인합니다.

단계별 구현

1
기본 변수들의 주소 출력
#include <stdio.h> int main() { int a = 42; float f = 3.14f; char c = 'A'; printf("int a = %d, 주소: %p\n", a, &a); printf("float f = %.2f, 주소: %p\n", f, &f); printf("char c = %c, 주소: %p\n", c, &c); return 0; }
예상 출력
int a = 42, 주소: 0x7fff1000 float f = 3.14, 주소: 0x7fff0ffc char c = A, 주소: 0x7fff0ffb
2
배열 원소의 주소 간격 확인
int arr[5] = {10, 20, 30, 40, 50}; printf("배열 원소 주소:\n"); for (int i=0; i<5; i++) { printf("arr[%d] = %2d, 주소: %p\n", i, arr[i], &arr[i]); } printf("\n주소 간격: %td bytes\n", &arr[1] - &arr[0]);
예상 출력 (주소는 다를 수 있음)
arr[0] = 10, 주소: 0x7fff1000 arr[1] = 20, 주소: 0x7fff1004 arr[2] = 30, 주소: 0x7fff1008 arr[3] = 40, 주소: 0x7fff100C arr[4] = 50, 주소: 0x7fff1010 주소 간격: 1 (원소 단위, 실제 4바이트)

최종 완성 코드

#include <stdio.h> int main() { /* 기본 변수 */ int a = 42; float f = 3.14f; char c = 'Z'; int arr[3] = {1, 2, 3}; printf("=== 기본 변수 주소 ===\n"); printf("int a : 값=%-5d 주소=%p 크기=%zu\n", a, &a, sizeof(a)); printf("float f : 값=%-5.2f 주소=%p 크기=%zu\n", f, &f, sizeof(f)); printf("char c : 값=%-5c 주소=%p 크기=%zu\n", c, &c, sizeof(c)); printf("\n=== 배열 원소 주소 ===\n"); for (int i=0; i<3; i++) printf("arr[%d]=%d 주소=%p\n", i, arr[i], arr+i); printf("\n=== 포인터 변수 주소 ===\n"); int *p = &a; printf("p 가 가리키는 주소: %p\n", p); printf("p 자신의 주소: %p\n", &p); printf("p 의 크기: %zu bytes\n", sizeof(p)); return 0; }

포인터 p 자신도 메모리에 존재하며 주소(&p)를 가집니다. 64비트 시스템에서 sizeof(p)는 항상 8입니다.

도전 과제

도전 과제

  • double 변수를 추가하고 주소를 출력해보세요.
  • char 배열과 int 배열의 주소 간격을 비교해보세요.
  • 포인터 변수 p와 변수 a 중 어느 주소가 더 큰지 확인해보세요.
  • 함수 안에서 선언한 변수의 주소를 main과 비교해보세요.

실행 결과 분석

스택 메모리는 보통 높은 주소에서 낮은 주소 방향으로 변수가 배치됩니다. 배열 원소는 낮은 주소에서 높은 주소 방향으로 연속 배치됩니다.

int는 4바이트, float는 4바이트, char는 1바이트, 포인터는 8바이트(64비트)입니다.
