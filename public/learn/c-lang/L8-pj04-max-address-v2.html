CHAPTER 8 PROJECT 04
배열 최대값의
주소 반환
Return the Address of Maximum Value
함수가 단 하나의 값만 반환할 수 있다 — 하지만 포인터를 반환하면 그 주소로 값도 읽고 수정도 할 수 있다.
배열에서 최대값을 찾아 그 원소의 주소를 반환하는 함수를 구현한다.
난이도 포인터 반환 배열 탐색 주소 활용법
포인터를 반환하는 이유
find_max 함수 작동 원리
단계별 구현
STEP 1

함수 반환 타입: int *

포인터를 반환하는 함수는 반환 타입에 *를 붙인다.
int *find_max(int *arr, int n)

STEP 2

max_ptr 초기화

첫 원소를 임시 최대값으로 시작.
int *max_ptr = arr;

STEP 3

순회하며 비교

더 큰 값 발견 시 max_ptr 업데이트.
max_ptr = &arr[i];

STEP 4

주소 반환 + 활용

반환받은 주소로 값 읽기/쓰기 가능.
int idx = ptr - arr;

주의: 지역 변수의 주소를 반환하면 절대 안 된다. 함수가 종료되면 지역 변수는 사라진다. 배열의 원소처럼 함수 밖에서 살아있는 메모리 주소만 반환해야 한다.
완성 코드
max_addr.c #include <stdio.h>

/* 배열에서 최대값의 주소를 반환 */
int *find_max(int *arr, int n) {
    int *max_ptr = arr; // 첫 원소 주소로 초기화
    for (int i = 1; i < n; i++) {
        if (arr[i] > *max_ptr) {
            max_ptr = &arr[i]; // 더 크면 주소 갱신
        }
    }
    return max_ptr;
}

/* 배열에서 최솟값의 주소를 반환 */
int *find_min(int *arr, int n) {
    int *min_ptr = arr;
    for (int i = 1; i < n; i++)
        if (arr[i] < *min_ptr) min_ptr = &arr[i];
    return min_ptr;
}

int main() {
    int arr[] = {15, 42, 8, 97, 33};
    int n = sizeof(arr) / sizeof(arr[0]);
    
    int *max_p = find_max(arr, n);
    int *min_p = find_min(arr, n);
    
    printf("최대값: %d (인덱스 %d)\n", *max_p, (int)(max_p - arr));
    printf("최솟값: %d (인덱스 %d)\n", *min_p, (int)(min_p - arr));
    
    /* 주소로 값 수정도 가능 */
    *max_p = 0; // 최대값을 0으로 초기화
    printf("최대값 초기화 후: arr[3] = %d\n", arr[3]);
    
    return 0;
}
$ gcc max_addr.c -o max_addr && ./max_addr
최대값: 97 (인덱스 3)
최솟값: 8 (인덱스 2)
최대값 초기화 후: arr[3] = 0
포인터 빼기로 인덱스 계산: max_p - arr은 두 포인터 사이의 원소 개수를 반환한다. max_p = &arr[3], arr = &arr[0]이면 3 - 0 = 3.
도전 과제

도전 과제

1 두 번째 최대값 찾기: find_max로 최대값을 찾고, 그 위치를 제외하고 다시 find_max를 호출하여 두 번째 최대값을 찾아라.
2 범위 내 최대값: 배열과 시작/끝 인덱스를 받아 해당 범위 내의 최대값 주소를 반환하는 함수를 작성하라.
3 절댓값 기준 최대: 음수 포함 배열에서 절댓값이 가장 큰 원소의 주소를 반환하라. (-99 vs 50이면 -99가 답)
연습문제
1 int *find_max(int *arr, int n)의 반환 타입이 int *인 이유는?
주소(포인터)를 반환하기 때문이다. int를 반환하면 값만 알 수 있고, int *를 반환하면 해당 메모리 주소를 돌려줘서 호출자가 값을 읽거나 수정할 수 있다.
2 max_p - arr의 결과가 3인 이유를 설명하라.
max_p = &arr[3] (0x100c), arr = &arr[0] (0x1000). 포인터 빼기는 바이트 차이를 sizeof(int)로 나눈 원소 개수를 반환. (0x100c - 0x1000) / 4 = 12 / 4 = 3.
3 *max_p = 0;이 arr[3]을 바꾸는 이유는?
max_p는 arr[3]의 주소를 담고 있다. *max_p = 0은 "max_p가 가리키는 메모리에 0을 저장"하는 것이므로 arr[3] = 0이 된다. 포인터로 원본 배열을 직접 수정하는 패턴이다.
4 함수 안에서 지역 변수의 주소를 반환하면 안 되는 이유는?
지역 변수는 함수 스택 프레임에 존재한다. 함수가 return하면 스택 프레임이 해제되어 그 메모리는 다른 용도로 사용될 수 있다. 반환된 주소를 역참조하면 쓰레기 값이나 프로그램 충돌이 발생한다.
5 find_max에서 max_ptr 초기값을 arr[0]의 값(15)이 아닌 arr 주소로 초기화하는 이유는?
포인터를 반환해야 하기 때문이다. int max_val = arr[0]으로 초기화하면 나중에 그 인덱스를 알 수 없다. max_ptr = arr로 시작하면 최대값의 위치(주소)를 계속 추적하면서 마지막에 그 주소를 반환할 수 있다.

이번 프로젝트 핵심

  • 함수가 포인터를 반환하면 값뿐 아니라 위치 정보도 제공한다
  • 반환 타입 int *는 "int를 가리키는 포인터를 반환"을 의미한다
  • ptr - arr로 포인터 위치를 인덱스로 변환할 수 있다
  • 절대 지역 변수의 주소를 반환하면 안 된다
