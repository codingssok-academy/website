나만의 명함

테두리와 정렬을 이용해 텍스트 명함을 만들고, 변수로 정보를 관리합니다.

이 프로젝트에서 만들 것

  • 테두리로 명함 카드 틀을 만듭니다.
  • 이름, 학교, 반, 연락처를 정렬해 출력합니다.
  • 변수로 명함 정보를 관리합니다.
  • 앞면과 뒷면이 있는 두 장짜리 명함을 만듭니다.
  • 사용자 입력으로 동적 명함을 생성합니다.

명함 틀 만들기

명함은 테두리, 이름, 정보 줄로 구성됩니다. + = | 기호로 깔끔한 테두리를 만듭니다.

// 기본 명함 printf("+==============================+\n"); printf("| |\n"); printf("| 이름: 김철수 |\n"); printf("| 학교: 코딩쏙 중학교 |\n"); printf("| 학년: 1학년 2반 |\n"); printf("| |\n"); printf("+==============================+\n");
따라해보세요
1
위 명함 코드를 입력하고 실행해보세요.
printf("+==============================+\n"); printf("| 이름: 나의 이름 |\n"); printf("+==============================+\n");
간단한 명함 틀이 출력됩니다
2
별표 테두리 명함도 만들어보세요.
printf("********************************\n"); printf("* 이름: 박지현 *\n"); printf("* 특기: 코딩, 축구 *\n"); printf("********************************\n");
별표 테두리 명함이 출력됩니다

변수로 명함 만들기

정보를 변수에 저장하면 쉽게 수정할 수 있는 명함 프로그램을 만들 수 있습니다.

char name[] = "김철수"; char school[] = "코딩쏙 중학교"; int grade = 1; int cls = 2; char hobby[] = "코딩, 게임"; printf("+================================+\n"); printf("| 이름: %-20s|\n", name); printf("| 학교: %-20s|\n", school); printf("| 학년/반: %d학년 %d반 |\n", grade, cls); printf("| 특기: %-20s|\n", hobby); printf("+================================+\n");
따라해보세요
1
변수를 사용해 내 정보로 명함을 만드세요.
char myname[] = "이지은"; int mygrade = 2; printf("+------ 명함 ------+\n"); printf("| 이름: %s\n", myname); printf("| 학년: %d학년\n", mygrade); printf("+------------------+\n");
변수로 만든 명함이 출력됩니다
2
앞면+뒷면으로 이루어진 두 장짜리 명함을 만드세요.
printf("[앞면]\n"); printf("+------------------+\n"); printf("| 이름: 최준혁 |\n"); printf("+------------------+\n\n"); printf("[뒷면]\n"); printf("+------------------+\n"); printf("| 특기: 축구 |\n"); printf("+------------------+\n");
앞면과 뒷면 명함이 출력됩니다
3
scanf로 직접 입력해서 명함을 만드세요.
char name[50]; printf("이름 입력: "); scanf("%s", name); printf("+---- %s님의 명함 ----+\n", name); printf("| 반갑습니다! |\n"); printf("+----------------------+\n");
입력한 이름으로 명함이 만들어집니다

도전 과제

Q1
3줄 명함
쉬움
테두리 포함 이름, 학교, 연락처가 있는 기본 명함을 출력하세요.
조건테두리 + 이름 + 학교 + 연락처 3줄
내 답안
힌트 보기
위아래 테두리 줄과 사이에 정보 3줄을 넣으세요.
정답 확인
printf("+============================+\n"); printf("| 이름: 홍길동 |\n"); printf("| 학교: 서울 중학교 |\n"); printf("| 연락: 010-1234-5678 |\n"); printf("+============================+\n");
Q2
변수 명함
쉬움
이름, 학년, 반을 변수에 저장하고 명함을 출력하세요.
조건char, int 변수 사용 + 테두리 명함
내 답안
힌트 보기
char name[] = "..."; int grade = ..., cls = ...; 후 printf에서 %s, %d로 사용하세요.
정답 확인
char name[] = "김민준"; int grade = 1, cls = 3; printf("+------ 명함 ------+\n"); printf("| 이름: %s\n", name); printf("| %d학년 %d반\n", grade, cls); printf("+------------------+\n");
Q3
동적 명함 생성기
보통
이름, 학교, 특기를 scanf로 입력받아 완성된 명함을 출력하는 프로그램을 만드세요.
조건scanf 3번 + 테두리 명함 출력
내 답안
힌트 보기
char 배열 3개를 선언하고 scanf로 차례대로 입력받은 뒤 printf로 명함을 출력하세요.
정답 확인
char name[50], school[100], hobby[100]; printf("이름: "); scanf("%s", name); printf("학교: "); scanf("%s", school); printf("특기: "); scanf("%s", hobby); printf("+================================+\n"); printf("| 이름: %s\n", name); printf("| 학교: %s\n", school); printf("| 특기: %s\n", hobby); printf("+================================+\n");

핵심 요약

  • 명함은 테두리 줄 + 정보 줄 + 테두리 줄 구조로 만든다
  • + = | * # -로 다양한 테두리를 만든다
  • 변수에 정보를 저장하면 한 곳에서 수정할 수 있어 편리하다
  • scanf로 입력받으면 실행할 때마다 다른 명함을 만들 수 있다
  • %s는 문자열, %d는 정수를 출력할 때 사용한다
