비밀 암호 메시지

특수문자와 printf를 이용해 나만의 비밀 암호 메시지를 출력합니다.

이 프로젝트에서 만드는 것

  • 특수문자(*, =, -, [, ])로 테두리를 만듭니다.
  • 여러 줄 printf로 비밀 메시지 카드를 출력합니다.
  • 주석으로 각 섹션을 설명합니다.
  • 세미콜론, 중괄호, 들여쓰기를 완벽히 지킵니다.

암호 메시지 구조 설계

암호 메시지는 테두리, 제목, 내용, 서명 4개의 섹션으로 구성합니다. 각 섹션을 주석으로 구분하면 코드가 훨씬 읽기 쉬워집니다.

#include <stdio.h> int main() { /* 비밀 암호 메시지 프로그램 */ // 테두리 위 printf("========================\n"); // 제목 printf(" SECRET CODE: PJ06\n"); // 구분선 printf(" ----------------------\n"); // 메시지 내용 printf(" ** 코딩을 사랑하는 자 **\n"); printf(" ** 이 메시지를 읽어라 **\n"); // 서명 printf(" -- [ 홍 길 동 ] --\n"); // 테두리 아래 printf("========================\n"); return 0; }
따라해보세요
1
위 코드를 그대로 입력하고 컴파일해서 결과를 확인해보세요.
암호 메시지 틀이 출력
2
메시지 내용을 나만의 문장으로 바꿔보세요.
나만의 암호 메시지 완성

암호 패턴 확장하기

다양한 특수문자를 조합하면 더 멋진 암호 패턴을 만들 수 있습니다.

#include <stdio.h> int main() { /* 별표 패턴 암호 */ printf("* * * * * * * * *\n"); printf("* *\n"); printf("* TOP SECRET! *\n"); printf("* 코딩쏙 비밀 *\n"); printf("* *\n"); printf("* * * * * * * * *\n"); return 0; }
따라해보세요
1
이퀄(=)과 별표(*)를 번갈아 쓴 테두리 패턴을 만들어보세요.
printf("=*=*=*=*=*=*=*=*\n");
고유한 테두리 패턴 완성
2
공백을 이용해 텍스트를 가운데 정렬처럼 보이게 해보세요.
printf("* 안녕! *\n");
가운데 정렬 효과
3
친구에게 보내는 나만의 암호 메시지를 완성해보세요.
창의적인 암호 메시지 완성

도전 과제

Q1
암호 메시지 완성
기본
아래 조건으로 나만의 암호 메시지를 완성하세요.
조건 1특수문자 테두리 포함 (=, *, - 중 선택)
조건 2제목 + 메시지 2줄 + 서명 포함
조건 3주석으로 각 섹션 설명
내 답안
예시 정답 보기
#include <stdio.h> int main() { // 테두리 printf("######################\n"); // 제목 printf(" [ MISSION ACCEPTED ]\n"); // 내용 printf(" 코딩을 포기하지 마라\n"); printf(" 너는 할 수 있다!\n"); // 서명 printf(" -- 코딩쏙 --\n"); printf("######################\n"); return 0; }
Q2
멀티 메시지 카드
심화
암호 메시지 카드를 2개 만들어 연속으로 출력하세요. 두 카드 사이에 빈 줄을 1줄 넣으세요.
힌트printf("\n"); 으로 빈 줄 출력 가능
내 답안
힌트 보기
두 번째 카드 시작 전에 printf("\n");을 추가하면 빈 줄이 생깁니다.
Q3
창의적 암호 패턴
창의
특수문자만으로 간단한 그림(집, 나무, 로봇 등)을 아스키 아트로 표현해보세요.
예시 /\ , / \ , | | 로 집 모양
내 답안
예시 보기
printf(" /\\ \n"); printf(" / \\ \n"); printf(" /____\\ \n"); printf(" | | \n"); printf(" |____| \n");

핵심 요약

  • 특수문자(*, =, -, [ ])로 텍스트 테두리 표현 가능
  • \n으로 줄 바꿈, 공백으로 들여쓰기 효과
  • 주석으로 섹션을 구분하면 코드 관리가 쉬워짐
  • printf 여러 줄을 조합해 복잡한 텍스트 디자인 가능
