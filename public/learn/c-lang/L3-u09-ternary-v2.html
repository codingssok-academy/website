Level 3 · Unit 09

삼항 연산자
— ? :

if-else를 한 줄로 압축하는 강력한 표현식. 조건에 따라 두 값 중 하나를 선택합니다.

이 유닛에서 배우는 것

  • 삼항 연산자의 구조(조건 ? 참값 : 거짓값)를 설명할 수 있습니다.
  • if-else와 삼항 연산자를 서로 변환할 수 있습니다.
  • printf 안에서 삼항 연산자를 직접 사용할 수 있습니다.
  • 절대값, 최댓값, 짝홀 판별을 한 줄로 작성할 수 있습니다.
  • 중첩 삼항의 위험성을 알고 언제 if-else를 써야 할지 판단할 수 있습니다.

삼항 연산자 기본

삼항 연산자(ternary operator)는 피연산자가 세 개인 유일한 연산자입니다. 조건 ? 참값 : 거짓값 형태로, if-else 4줄을 한 줄로 표현합니다.

// 최댓값 구하기 — 삼항 연산자 int a = 7, b = 3; int max; // if-else 방식 if (a > b) { max = a; } else { max = b; } // 삼항 연산자로 압축 (완전히 동일) max = (a > b) ? a : b; printf("최댓값: %d\n", max); // 최댓값: 7
따라해보세요
1
x = 10, y = 20일 때, 더 작은 값을 min에 저장하는 삼항 연산자를 작성해보세요.
min = (x < y) ? x : y;
min에 10이 저장됩니다
2
score = 75일 때, 60 이상이면 pass = 1, 아니면 pass = 0으로 설정해보세요.
pass = (score >= 60) ? 1 : 0;
pass에 1이 저장됩니다
3
나이가 19 이상이면 adult = 1, 아니면 adult = 0으로 설정해보세요. (age = 17)
adult = (age >= 19) ? 1 : 0;
adult에 0이 저장됩니다

삼항 연산자 활용

삼항 연산자는 변수에 저장할 때만 쓰는 게 아닙니다. printf 안에서 직접 쓰면 코드를 더욱 간결하게 만들 수 있습니다.

예제 1 — 절대값 구하기

수학에서 절대값은 음수면 부호를 바꾸고, 양수면 그대로입니다. 삼항 연산자로 한 줄에 표현합니다.

int n = -5; int abs_n = (n < 0) ? -n : n; printf("|%d| = %d\n", n, abs_n); // |-5| = 5

예제 2 — 짝홀 판별 한 줄

나머지 연산자 %와 삼항 연산자를 결합하면 짝수/홀수 판별도 한 줄입니다.

int n = 4; // 방법 1: 변수에 저장 char *result = (n % 2 == 0) ? "짝수" : "홀수"; printf("%d는 %s입니다.\n", n, result); // 방법 2: printf 안에서 바로 printf("%d는 %s입니다.\n", n, (n % 2 == 0) ? "짝수" : "홀수");
따라해보세요
1
temp = -3일 때, 절대값을 삼항 연산자로 구해보세요.
abs_temp = (temp < 0) ? -temp : temp;
abs_temp에 3이 저장됩니다
2
score = 85를 받아, 70 이상이면 "합격", 미만이면 "불합격"을 printf로 출력해보세요.
printf("%s\n", (score >= 70) ? "합격" : "불합격");
합격 이 출력됩니다
3
num = 9일 때 3의 배수이면 "배수", 아니면 "아님"을 출력해보세요.
printf("%s\n", (num % 3 == 0) ? "배수" : "아님");
배수 가 출력됩니다

주의사항 — 이럴 때 if-else를 쓰세요

삼항 연산자는 강력하지만 잘못 쓰면 오히려 코드를 읽기 어렵게 만듭니다. 세 가지 주의사항을 반드시 기억하세요.

주의 1 — 중첩 삼항은 읽기 어렵다

삼항 연산자 안에 또 삼항 연산자를 넣으면 코드가 복잡해집니다. 이런 경우엔 if-else를 쓰세요.

주의 2 — 삼항 vs if-else 선택 가이드

주의 3 — 삼항은 값을 반환한다 (표현식)

삼항 연산자는 문장(statement)이 아니라 표현식(expression)입니다. 즉, 결과가 값이 되어서 변수에 저장하거나 함수 인자로 바로 넘길 수 있습니다. 반면 if-else는 단독으로 실행되는 문장입니다.

이런 코드는 컴파일 오류 또는 경고가 납니다

삼항 연산자 양쪽의 타입이 달라야 하는 경우 (int vs char*)엔 암묵적 변환 문제가 생깁니다. 양쪽 값의 타입을 항상 맞춰주세요.

언제 삼항을 쓰고 언제 if-else를 쓸까?

값 하나를 선택하는 짧은 조건 → 삼항. 실행 문장이 여러 줄이거나 분기가 3개 이상 → if-else. 코드는 나중에 읽는 사람을 위해 쓰는 것입니다.

따라해보세요
1
다음 중첩 삼항을 if-else 로 바꿔 써보세요: r = (x>0)?1:(x<0)?-1:0;
if (x > 0) r = 1; else if (x < 0) r = -1; else r = 0;
훨씬 읽기 쉬워집니다
2
삼항 연산자를 써도 좋은 경우를 골라 삼항으로 작성해보세요: a와 b 중 큰 값을 big에 저장.
big = (a > b) ? a : b;
단순한 값 선택이므로 삼항이 적합합니다
3
다음을 삼항으로 바꿔보세요: if(n==0) printf("영"); else printf("비영");
printf("%s", (n == 0) ? "영" : "비영");
printf 안에서 삼항 사용 연습입니다

연습 문제

1
빈칸 채우기 — 삼항 연산자 문법
쉬움
아래 코드의 빈칸을 채워 a와 b 중 큰 값을 출력하는 삼항 연산자를 완성하세요.
int a = 8, b = 5; printf("%d\n", (a __ b) __ a __ b);
출력
8
내 답안
힌트 / 정답 보기
a가 b보다 크면 a, 아니면 b. 조건은 a > b, 참값은 a, 거짓값은 b.
printf("%d\n", (a > b) ? a : b);
2
코드 읽기 — 출력 결과 예측
쉬움
아래 코드를 실행하면 어떤 값이 출력될까요? 단계별로 계산해보세요.
int x = 10, y = 20; int result = (x + y > 25) ? x * 2 : y / 2; printf("%d\n", result);
x+y
30 (25보다 크므로 참)
참값
x * 2 = ?
내 답안
힌트 / 정답 보기
x+y = 30 > 25 이므로 조건은 참. 참값인 x*2 = 10*2 = 20을 선택.
출력: 20
3
직접 작성 — 점수에 따른 등급 출력
보통
정수형 변수 score를 선언하고 값 78을 넣으세요. 삼항 연산자를 사용해 60 이상이면 "Pass", 미만이면 "Fail"을 printf로 출력하는 코드를 작성하세요.
출력
Pass
내 답안
힌트 / 정답 보기
문자열 비교 형식은 %s. 삼항 결과가 문자열이니 char* 타입으로 저장하거나 printf 안에서 바로 사용.
int score = 78; printf("%s\n", (score >= 60) ? "Pass" : "Fail");
4
변환 — if-else를 삼항으로
보통
아래 if-else 코드를 삼항 연산자 한 줄로 바꿔 쓰세요.
int n = -9; int abs_n; if (n < 0) { abs_n = -n; } else { abs_n = n; } printf("%d\n", abs_n);
출력
9
내 답안
힌트 / 정답 보기
조건: n < 0, 참이면 -n, 거짓이면 n. 삼항으로 합치면 한 줄!
int n = -9; int abs_n = (n < 0) ? -n : n; printf("%d\n", abs_n);
5
응용 — 세 수 중 최댓값
어려움
변수 a=5, b=12, c=8이 주어졌을 때, 삼항 연산자만 사용해 세 수 중 최댓값을 구하고 출력하세요. if-else는 사용하지 않습니다.
출력
최댓값: 12
내 답안
힌트 / 정답 보기
먼저 a와 b 중 큰 값을 tmp에 저장. 그 다음 tmp와 c 중 큰 값이 최댓값. 2단계 삼항을 사용하거나, 삼항 안에 삼항 1번만 허용.
int a=5, b=12, c=8; int tmp = (a > b) ? a : b; int max = (tmp > c) ? tmp : c; printf("최댓값: %d\n", max);

Unit 09 핵심 정리

  • 삼항 연산자 형식: 조건식 ? 참값 : 거짓값 — 피연산자 3개
  • if-else 압축: 값 하나를 선택하는 단순한 조건은 삼항이 더 깔끔합니다
  • printf 안 사용: printf("%s", (조건) ? "참" : "거짓");
  • 절대값: (n < 0) ? -n : n
  • 짝홀: (n % 2 == 0) ? "짝수" : "홀수"
  • 삼항은 표현식: 값을 반환하므로 변수에 저장하거나 함수 인자로 바로 전달 가능
  • 중첩 삼항은 금물: 3개 이상 분기, 실행 문장 여러 개일 때는 if-else를 씁니다
