비밀번호 생성기

이니셜과 생년을 입력받아 나만의 비밀번호를 생성합니다. char와 int를 조합하고 문자 연산을 활용합니다.

이 프로젝트에서 배우는 것

  • char와 int를 함께 사용할 수 있다
  • 대문자를 소문자로 바꾸는 문자 연산을 할 수 있다
  • printf에서 %c와 %d를 섞어 출력할 수 있다
  • 입력받은 데이터를 조합해서 새로운 결과를 만들 수 있다
  • ASCII 코드를 활용한 실용적인 프로그램을 만들 수 있다

비밀번호 생성 코드

이니셜 2글자(대문자)와 생년(4자리)을 입력받아 비밀번호를 만듭니다. 비밀번호 규칙: 첫 글자(대문자) + 둘째 글자(소문자) + 생년 + 첫 글자(소문자)

#include <stdio.h> int main(void) { char first, second; // 이니셜 2글자 int year; // 생년 printf("이니셜 첫 글자 (대문자): "); scanf("%c", &first); printf("이니셜 둘째 글자 (대문자): "); scanf(" %c", &second); // 앞에 공백! (Enter 버림) printf("생년 (4자리): "); scanf("%d", &year); printf("=== 비밀번호 ===\n"); printf("%c%c%d%c\n", first, // 대문자 그대로 second + 32, // 소문자로 변환 year, // 생년 first + 32); // 첫글자 소문자 return 0; }

도전 문제

Q1
비밀번호 예측하기
쉬움
이니셜 L, M, 생년 2012를 입력하면 비밀번호는?
내 답안
정답 보기
Lm2012l (L + m + 2012 + l)
Q2
비밀번호 패턴 변경
보통
비밀번호 패턴을 바꿔보세요: 첫글자(소) + 생년 뒤 2자리 + 둘째글자(대) + 첫글자 다음 알파벳
입력K, J, 2010
출력k10JL
내 답안
힌트 보기
year % 100으로 뒤 2자리, first + 32로 소문자, first + 1로 다음 알파벳
정답 보기
printf("%c%d%c%c\n", first + 32, // 소문자 year % 100, // 뒤 2자리 second, // 대문자 그대로 first + 1); // 다음 알파벳
Q3
특수문자 추가 비밀번호
보통
비밀번호 앞뒤에 *를 붙여서 출력하세요.
출력*Kj2010k*
내 답안
정답 보기
printf("*%c%c%d%c*\n", first, second + 32, year, first + 32);

핵심 요약

  • char에 +32하면 대문자가 소문자가 된다
  • scanf(" %c")에서 앞 공백은 Enter를 무시하는 트릭이다
  • %c와 %d를 한 printf에서 섞어 쓸 수 있다
  • 문자와 숫자를 조합하면 다양한 패턴을 만들 수 있다
  • Level 2b에서 배운 자료형: char, int, float, double
