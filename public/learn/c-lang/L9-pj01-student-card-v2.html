학생 카드 — 이름/나이/점수 구조체

struct로 학생 정보를 담고, 3명의 데이터를 출력하는 카드 형식 프로그램을 만듭니다.

프로젝트 목표

  • typedef struct로 Student 타입을 정의합니다.
  • 3명의 학생 데이터를 배열로 저장합니다.
  • for 반복문으로 카드 형식 출력을 구현합니다.
  • 최고 점수 학생을 자동으로 찾아 표시합니다.

단계별 구현

STEP 1
Student 구조체 정의
이름, 나이, 점수를 멤버로 갖는 구조체를 typedef로 만듭니다.
#include <stdio.h> #include <string.h> #define N 3 typedef struct { char name[20]; int age; float score; } Student;
STEP 2
데이터 배열 초기화
3명의 학생 정보를 배열로 선언하고 초기화합니다.
int main() { Student arr[N] = { {"김민준", 15, 88.5f}, {"이서연", 16, 92.0f}, {"박지호", 14, 76.5f} };
STEP 3
카드 형식 출력
for 반복문으로 각 학생의 카드를 출력합니다.
for (int i = 0; i < N; i++) { printf("┌─────────────────┐\n"); printf("│ 학생 카드 #%d │\n", i+1); printf("├─────────────────┤\n"); printf("│ 이름: %-10s │\n", arr[i].name); printf("│ 나이: %2d세 │\n", arr[i].age); printf("│ 점수: %5.1f점 │\n", arr[i].score); printf("└─────────────────┘\n\n"); }

완성 코드

// 최고 점수 학생 찾기 int best = 0; for (int i = 1; i < N; i++) { if (arr[i].score > arr[best].score) best = i; } printf("최고 점수: %s (%.1f점)\n", arr[best].name, arr[best].score); return 0; }
실행 결과
실행 결과
┌─────────────────┐ │ 학생 카드 #1 │ ├─────────────────┤ │ 이름: 김민준 │ │ 나이: 15세 │ │ 점수: 88.5점 │ └─────────────────┘ ┌─────────────────┐ │ 학생 카드 #2 │ ... 최고 점수: 이서연 (92.0점)
도전 과제

도전 과제

  • 학생 수를 5명으로 늘려보세요.
  • 점수 평균도 카드 아래에 출력해보세요.
  • 나이가 가장 어린 학생도 찾아보세요.
  • scanf로 직접 학생 정보를 입력받아보세요.

확인 문제

문제 1
구조체 정의 확인
Student 구조체에 반(class, int) 멤버를 추가하고, 2반 학생들만 카드로 출력하는 코드를 작성하세요.
typedef struct { char name[20]; int age; float score; int cls; // 반 추가 } Student; // for 문 안에서 if (arr[i].cls == 2) 조건 추가
문제 2
정렬 후 출력
학생 배열을 점수 내림차순으로 정렬한 뒤 카드를 출력하는 전체 코드를 작성하세요.
문제 3
합격/불합격 표시
70점 이상은 "합격", 미만은 "불합격"을 카드에 추가로 출력하는 코드를 완성하세요.
printf("│ 결과: %-7s │\n", arr[i].score >= 70 ? "합격" : "불합격");
