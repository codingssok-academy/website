출석부 시스템

학생 번호 배열과 출석 배열을 만들어 출석 체크를 하고 출석/결석 목록을 출력하는 시스템을 구현합니다.

이 프로젝트에서 배우는 것

  • 두 배열을 같은 인덱스로 연결(병렬 배열)하는 방법을 익힙니다.
  • 0/1 플래그 배열로 상태를 관리하는 기법을 배웁니다.
  • 배열을 순회하며 조건별 목록을 출력합니다.
  • 출석률을 계산해 백분율로 출력합니다.

출석 배열 설계

출석 여부는 0(결석) 또는 1(출석)로 표현합니다. 학생 번호 배열과 출석 배열을 같은 인덱스로 연결합니다.

int n = 5; int stuNum[5] = {1, 2, 3, 4, 5}; // 학생 번호 int attend[5] = {0}; // 출석 상태 (0=결석) // 출석 체크 — 출석한 학생 번호 입력 int num; printf("출석한 학생 번호 입력 (0=종료): "); while (scanf("%d", &num) == 1 && num != 0) { if (num >= 1 && num <= n) attend[num - 1] = 1; // 번호→인덱스 변환 printf("번호 입력: "); }

출석/결석 목록 출력

printf("\n=== 출석부 결과 ===\n"); int presentCount = 0; printf("[출석] "); for (int i = 0; i < n; i++) { if (attend[i] == 1) { printf("%d번 ", stuNum[i]); presentCount++; } } printf("\n[결석] "); for (int i = 0; i < n; i++) { if (attend[i] == 0) printf("%d번 ", stuNum[i]); } printf("\n출석률: %.1f%%\n", (float)presentCount / n * 100);

완성 코드

#include <stdio.h> int main() { int n = 5; int attend[5] = {0}; printf("=== 출석 체크 ===\n"); for (int i = 0; i < n; i++) { printf("%d번 학생 (1=출석, 0=결석): ", i + 1); scanf("%d", &attend[i]); } int cnt = 0; printf("\n[출석] "); for (int i = 0; i < n; i++) if (attend[i]) { printf("%d번 ", i+1); cnt++; } printf("\n[결석] "); for (int i = 0; i < n; i++) if (!attend[i]) printf("%d번 ", i+1); printf("\n출석: %d명 / 결석: %d명\n", cnt, n-cnt); printf("출석률: %.1f%%\n", (float)cnt/n*100); return 0; }

주간 출석 체크 (5일)
어려움
5명 × 5일 출석 데이터를 1차원 배열로 표현하세요. attend[학생인덱스 * 5 + 요일인덱스]로 접근합니다.
크기int attend[25]
접근attend[i*5+j] = 학생i의 j번째 날
힌트 보기
2차원 개념을 1차원으로 표현하는 방법입니다. 다음 프로젝트에서 진짜 2차원 배열을 배웁니다.

핵심 정리

  • 0/1 플래그 배열로 상태 관리 (0=결석, 1=출석)
  • 병렬 배열: 같은 인덱스 두 배열을 연결하여 사용
  • if(attend[i]) = if(attend[i]==1) (0이 아니면 참)
  • !attend[i] = attend[i]==0 (부정 연산자)
  • 출석률 = (출석수 / 전체) × 100.0 (float 형변환 필요)
