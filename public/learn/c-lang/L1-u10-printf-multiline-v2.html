Unit 10

printf — 여러 줄 출력

하나의 printf 또는 여러 printf를 이용해 여러 줄을 출력하는 방법을 배웁니다.

이 유닛에서 배우는 것

  • \n을 사용해 여러 줄을 출력할 수 있습니다.
  • 하나의 printf로 여러 줄을 출력할 수 있습니다.
  • 여러 개의 printf를 연속으로 사용할 수 있습니다.
  • %d, %f, %s 서식 지정자를 이해합니다.
  • 정렬된 출력을 만들 수 있습니다.

printf와 줄바꿈

printf는 화면에 텍스트를 출력하는 함수입니다. \n은 줄바꿈 문자로, 이 위치에서 다음 줄로 넘어갑니다.

// 방법 1: 하나의 printf에 \n 여러 개 printf("이름: 김철수\n나이: 14\n학교: 중학교\n");

\n 없이 printf를 쓰면 모든 출력이 한 줄에 붙어서 나옵니다.

// 방법 2: printf 여러 개 — \n 있어야 줄바꿈 printf("첫째 줄\n"); printf("둘째 줄\n"); printf("셋째 줄\n");
따라해보세요
1
하나의 printf로 이름, 나이, 반을 세 줄로 출력하세요.
printf("이름: 박민준\n나이: 13\n반: 2반\n");
이름/나이/반이 각각 한 줄씩 출력됩니다
2
printf 세 개를 써서 같은 결과를 만드세요.
printf("이름: 박민준\n"); printf("나이: 13\n"); printf("반: 2반\n");
위와 동일한 결과가 나옵니다
3
빈 줄을 포함해서 출력하세요 (이름 출력 후 빈 줄, 그다음 나이 출력).
printf("이름: 이지은\n\n나이: 15\n");
이름 출력 후 빈 줄이 생기고 나이가 출력됩니다

서식 지정자로 여러 줄 출력

서식 지정자(%d, %f, %s)를 사용하면 변수 값을 여러 줄에 걸쳐 출력할 수 있습니다.

int age = 14; float height = 162.5; char name[] = "김지훈"; printf("이름: %s\n", name); printf("나이: %d살\n", age); printf("키: %.1f cm\n", height);

하나의 printf로 여러 변수를 여러 줄에 출력할 수도 있습니다.

// 하나의 printf로 여러 변수 출력 printf("이름: %s\n나이: %d살\n키: %.1f cm\n", name, age, height);
따라해보세요
1
정수와 실수를 각각 다른 줄에 출력하세요.
int score = 95; float avg = 87.5; printf("점수: %d\n평균: %.1f\n", score, avg);
점수: 95 / 평균: 87.5
2
성적표 형태로 세 과목을 출력하세요.
printf("=== 성적표 ===\n"); printf("국어: %d\n", 88); printf("영어: %d\n", 92); printf("수학: %d\n", 79);
제목과 세 과목이 각 줄에 출력됩니다
3
빈 줄로 섹션을 구분해 출력하세요.
printf("[ 개인 정보 ]\n"); printf("이름: 최유나\n\n"); printf("[ 학교 정보 ]\n"); printf("학교: 서울중학교\n");
두 섹션이 빈 줄로 구분되어 출력됩니다

핵심 요약

  • \n은 줄바꿈 문자로 printf 안에서 다음 줄로 이동한다
  • 하나의 printf에 \n을 여러 개 넣어 여러 줄을 출력할 수 있다
  • 여러 printf를 연속으로 사용해도 같은 결과를 만들 수 있다
  • %d=정수, %f=실수, %s=문자열, %c=문자
  • %.2f는 소수점 아래 2자리까지만 출력한다
