점(.) 연산자 — 멤버 읽기/쓰기

점(.) 연산자로 구조체 멤버에 접근하는 방법을 깊이 익힙니다. 멤버 값을 읽고, 수정하고, 연산에 활용해봅시다.

이 유닛에서 배우는 것

  • 점(.) 연산자의 의미와 사용법을 설명할 수 있습니다.
  • 구조체 멤버의 값을 읽어 출력할 수 있습니다.
  • 구조체 멤버의 값을 수정할 수 있습니다.
  • 멤버 값을 사용해 계산(연산)을 수행할 수 있습니다.
  • scanf로 구조체 멤버에 직접 입력받을 수 있습니다.

점(.) 연산자란?

점 연산자 .는 구조체 변수와 멤버 이름 사이에 써서 특정 멤버에 접근합니다. 변수.멤버이름 형식으로 사용합니다.

struct Student { char name[20]; int age; float score; }; struct Student s = {"김민준", 15, 88.5f}; // 멤버 읽기 printf("%s\n", s.name); // 김민준 printf("%d\n", s.age); // 15 printf("%.1f\n", s.score); // 88.5 // 멤버 쓰기(수정) s.age = 16; s.score = 92.0f; strcpy(s.name, "김민준(수정)");

멤버 값으로 연산하기

멤버에 접근한 값은 일반 변수처럼 사칙연산, 비교, 출력 등 모든 연산에 사용할 수 있습니다.

struct Rectangle { int width; int height; }; struct Rectangle r = {10, 5}; int area = r.width * r.height; // 50 int perimeter = (r.width + r.height) * 2; // 30 printf("넓이: %d\n", area); printf("둘레: %d\n", perimeter); // 멤버 자체에 연산 적용 r.width += 5; // r.width = 15 r.height *= 2; // r.height = 10

scanf로 멤버에 입력받기

scanf로 구조체 멤버에 직접 입력받을 수 있습니다. 정수/실수 멤버는 &s.멤버를 사용합니다.

#include <stdio.h> struct Student { char name[20]; int age; float score; }; int main() { struct Student s; printf("이름 입력: "); scanf("%s", s.name); // 문자 배열: & 없이 사용 printf("나이 입력: "); scanf("%d", &s.age); // 정수: & 필요 printf("점수 입력: "); scanf("%f", &s.score); // 실수: & 필요 printf("\n이름: %s, 나이: %d, 점수: %.1f\n", s.name, s.age, s.score); return 0; }

멤버를 함수 인수로 전달

구조체 멤버는 일반 변수처럼 함수에 인수로 전달할 수 있습니다. 단, 구조체 전체를 넘기는 것과 멤버 하나만 넘기는 것은 다릅니다.

#include <stdio.h> void printAge(int age) { printf("나이: %d세\n", age); } void addScore(float *score, float bonus) { *score += bonus; } int main() { struct Student s = {"김민준", 15, 88.5f}; printAge(s.age); // 멤버 값 전달 addScore(&s.score, 5.0f); // 멤버 주소 전달 → 수정 가능 printf("수정된 점수: %.1f\n", s.score); // 93.5 return 0; }
핵심 정리

핵심 정리

  • 변수.멤버 형식으로 구조체 멤버에 접근합니다.
  • 멤버 읽기: printf("%d", s.age)
  • 멤버 쓰기: s.age = 16; (문자열은 strcpy)
  • 멤버는 일반 변수처럼 연산, 함수 인수, 조건 비교에 사용 가능합니다.
  • scanf 입력: 숫자 멤버는 &s.멤버, 문자 배열은 s.name
