  • 복합 조건식을 단계적으로 분해해서 이해할 수 있습니다.

  • 연산자 우선순위 && > ||를 실전에서 체감합니다.
Project 11 · 윤년 판별기

윤년 규칙을 코드로 분해하기

윤년(leap year) 규칙은 세 가지 조건이 조합됩니다. 한 번에 쓰기 전에, 각 조건을 따로 이해하고 합쳐봅시다.

규칙 1 연도가 4로 나누어 떨어진다 — y % 4 == 0
규칙 2 단, 100으로도 나누어 떨어지면 평년이다 — y % 100 != 0
규칙 3 예외: 400으로 나누어 떨어지면 다시 윤년 — y % 400 == 0

기본 구현 코드

연도를 입력받아 윤년인지 판별하는 완전한 프로그램입니다.

/* 윤년 판별기 v1 */ #include <stdio.h> int main(void) { int year; printf("연도를 입력하세요: "); scanf("%d", &year); /* 복합 조건: (4의 배수 AND 100의 배수 아님) OR 400의 배수 */ if ((year % 4 == 0 && year % 100 != 0) || year % 400 == 0) { printf("%d년은 윤년입니다.\n", year); } else { printf("%d년은 평년입니다.\n", year); } return 0; }

대표 연도 검증

연도 %4==0 %100!=0 %400==0 결과
2024 참 참 - 윤년
1900 참 거짓 거짓 평년
2000 참 거짓 참 윤년
2023 거짓 - 거짓 평년
Project 11 · 확장 기능

확장 기능 구현하기

기본 판별에서 한 발 더 나아가 세 가지 실용적인 기능을 추가합니다. 각각 독립적으로 구현해 보세요.

확장 1 해당 연도 2월 일수 출력

윤년이면 29일, 평년이면 28일을 출력합니다. 삼항 연산자를 활용하면 한 줄로 처리할 수 있습니다.

#include <stdio.h> int main(void) { int year, feb_days; printf("연도 입력: "); scanf("%d", &year); /* 윤년 판별 후 2월 일수 결정 */ int is_leap = (year % 4 == 0 && year % 100 != 0) || year % 400 == 0; feb_days = is_leap ? 29 : 28; printf("%d년 2월은 %d일까지 있습니다.\n", year, feb_days); return 0; }
실행 예시
연도 입력: 2024 2024년 2월은 29일까지 있습니다.
확장 2 연도 범위 입력 → 윤년 목록 출력

시작 연도와 끝 연도를 입력받아 그 사이의 모든 윤년을 나열합니다. for 반복문과 판별식을 조합합니다.

#include <stdio.h> int main(void) { int start, end, y, count = 0; printf("시작 연도: "); scanf("%d", &start); printf("끝 연도: "); scanf("%d", &end); printf("\n%d ~ %d 사이의 윤년:\n", start, end); for (y = start; y <= end; y++) { if ((y % 4 == 0 && y % 100 != 0) || y % 400 == 0) { printf(" %d\n", y); count++; } } printf("총 %d개\n", count); return 0; }
실행 예시 (2000 ~ 2024)
2000 ~ 2024 사이의 윤년: 2000 2004 2008 2012 2016 2020 2024 총 7개
확장 3 다음 윤년까지 몇 년 남았는지 출력

입력한 연도가 윤년이면 0을 출력하고, 아니라면 다음 윤년까지 남은 해를 계산합니다.

#include <stdio.h> int main(void) { int year, next, diff; printf("연도 입력: "); scanf("%d", &year); /* 현재 연도부터 위로 올라가며 첫 윤년 탐색 */ next = year; while (!((next % 4 == 0 && next % 100 != 0) || next % 400 == 0)) { next++; } diff = next - year; if (diff == 0) printf("%d년은 윤년입니다!\n", year); else printf("다음 윤년은 %d년, %d년 남았습니다.\n", next, diff); return 0; }
실행 예시
연도 입력: 2026 다음 윤년은 2028년, 2년 남았습니다.
Project 11 · 전체 코드 + 도전

통합 버전 — 메뉴 선택형 윤년 판별기

세 가지 기능을 하나의 프로그램에 합쳐, 사용자가 원하는 기능을 선택할 수 있게 만듭니다.

#include <stdio.h> /* 윤년 판별 함수 (반환값: 1=윤년, 0=평년) */ int is_leap_year(int y) { return (y % 4 == 0 && y % 100 != 0) || y % 400 == 0; } int main(void) { int menu, year, start, end, y, count, next, diff; printf("=== 윤년 판별기 ===\n"); printf("1. 특정 연도 판별\n"); printf("2. 2월 일수 확인\n"); printf("3. 윤년 목록 출력\n"); printf("4. 다음 윤년까지 남은 해\n"); printf("선택: "); scanf("%d", &menu); if (menu == 1) { printf("연도: "); scanf("%d", &year); printf("%d년 → %s\n", year, is_leap_year(year) ? "윤년" : "평년"); } else if (menu == 2) { printf("연도: "); scanf("%d", &year); printf("%d년 2월: %d일\n", year, is_leap_year(year) ? 29 : 28); } else if (menu == 3) { printf("시작: "); scanf("%d", &start); printf("끝: "); scanf("%d", &end); count = 0; for (y = start; y <= end; y++) if (is_leap_year(y)) { printf(" %d\n", y); count++; } printf("총 %d개\n", count); } else if (menu == 4) { printf("연도: "); scanf("%d", &year); next = year; while (!is_leap_year(next)) next++; diff = next - year; if (diff == 0) printf("%d년은 윤년!\n", year); else printf("다음 윤년 %d년, %d년 남음\n", next, diff); } return 0; }

핵심 정리

  • 윤년 조건: (y%4==0 && y%100!=0) || y%400==0
  • && 우선순위 > || — 괄호 없이 써도 되지만, 괄호로 명시하면 더 읽기 좋음
  • 반환값 활용: 판별식 자체가 0 또는 1이라 삼항 연산자와 잘 어울림
  • 함수 분리: is_leap_year()로 뽑으면 네 곳에서 동일 로직 재사용
  • while 탐색: 다음 윤년처럼 "조건 만족할 때까지"는 while이 자연스러운 선택

도전 문제

기본: 2001 ~ 2100 범위에서 윤년이 몇 개인지 세고, 4년마다 정확히 한 번 오지 않는 해를 출력해 보세요. (힌트: 1900, 2100 같은 예외에 주목)
심화: 연도를 입력받아 그 해의 1월 1일이 무슨 요일인지 계산하는 프로그램을 만들어 보세요. (힌트: 1970년 1월 1일은 목요일, 윤년마다 하루씩 더 추가)
고급: 연도와 월, 일을 입력받아 "그 날짜가 해당 연도의 몇 번째 날인지" 출력하는 프로그램을 작성하세요. 각 달의 일수 배열과 윤년 조건을 함께 활용합니다.
