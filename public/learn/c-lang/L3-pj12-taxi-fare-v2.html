택시 요금 계산기

거리와 시간을 입력받아 기본요금 + 추가요금 + 야간 할증을 else if로 계산합니다.

서울 택시 요금 기준 (2024)
구분기준요금
기본요금2km 이하4,800원
추가요금131m마다+100원
야간 할증22시 ~ 04시+20%
단거리1km 미만4,800원
중거리2km ~ 5km4,800 + 추가
장거리5km 초과4,800 + 추가
계산 공식
추가거리 = 총거리(m) - 2000
추가요금 = (추가거리 / 131) × 100
총요금 = 4800 + 추가요금

이 프로젝트에서 배우는 것

  • 거리 구간을 else if로 나눠 요금을 계산할 수 있습니다.
  • 정수 나눗셈(/)으로 추가 요금을 구할 수 있습니다.
  • 야간 시간 조건을 시간 변수와 || 연산으로 판별할 수 있습니다.
  • 할인율을 float으로 적용해 최종 요금을 계산할 수 있습니다.
  • 합승 인원으로 1인당 요금을 나눌 수 있습니다.

1단계 — 기본 요금 계산기 구현

택시 요금은 구간별로 다른 규칙이 적용됩니다. 2km 이하는 기본요금만, 2km를 넘으면 추가요금이 붙습니다. 이것을 else if로 표현합니다.

1
변수 준비 — 거리(m)를 입력받는다

거리 단위는 미터(m)로 입력받습니다. 2km = 2000m 이므로 비교가 쉽습니다.

int distance; // 이동 거리 (m 단위) int fare; // 최종 요금 int extra; // 추가 거리 (2km 초과분) printf("이동 거리를 입력하세요 (m): "); scanf("%d", &distance);
2
else if로 구간별 요금 계산

거리가 2000m(2km) 이하면 기본요금만, 초과하면 추가요금을 계산합니다.

if (distance <= 2000) { // 구간 1: 기본요금만 (2km 이하) fare = 4800; } else if (distance <= 5000) { // 구간 2: 2km 초과 ~ 5km extra = distance - 2000; // 추가 거리 fare = 4800 + (extra / 131) * 100; // 131m마다 100원 } else { // 구간 3: 5km 초과 extra = distance - 2000; fare = 4800 + (extra / 131) * 100; } printf("요금: %d원\n", fare);
정수 나눗셈 주의! C에서 extra / 131은 소수점을 버립니다. 131m씩 딱 떨어지지 않는 거리는 내림 처리됩니다. 이것이 실제 택시 미터기 방식입니다.
실행 예시 1 — 단거리 (1500m)
이동 거리를 입력하세요 (m): 1500
요금: 4800원
실행 예시 2 — 중거리 (3500m)
이동 거리를 입력하세요 (m): 3500
요금: 6100원
따라해보세요
1
거리 4200m를 직접 계산해보세요. 추가거리는 몇 m? 추가요금은?
추가거리 = 4200-2000 = 2200m, 2200/131 = 16칸, 추가요금 = 1600원, 총요금 = 6400원
2
구간 2와 구간 3의 공식이 같습니다. else if를 지우고 하나의 else로 합칠 수 있을까요?
가능합니다. distance <= 2000이 아닌 모든 경우에 같은 공식을 적용하면 됩니다.

2단계 — 야간 할증 + 할인 + 합승 확장

기본 요금 계산에 야간 할증, 장애인·경로 할인, 합승 분담 기능을 추가합니다. 각각 독립적인 조건문으로 구현합니다.

야간 할증 (22시 ~ 04시, 20% 추가)

시간을 정수로 입력받아 야간 범위인지 판단합니다. 22시 이후 또는 4시 미만이면 야간입니다.

int hour; // 탑승 시각 (0~23) printf("탑승 시각을 입력하세요 (0~23): "); scanf("%d", &hour); // 야간 판별: 22시 이상 OR 4시 미만 if (hour >= 22 || hour < 4) { fare = fare + fare / 5; // 20% 추가 (fare * 1.2 = fare + fare/5) printf("야간 할증 적용\n"); }
fare / 5 = 20% 이유: 20%는 1/5입니다. fare * 0.2는 float이 필요하지만, fare / 5는 정수 연산으로 같은 결과를 냅니다 (소수점 이하 버림).

할인 적용 (장애인 / 경로우대 20%)

A
할인 코드 방식
int discount_code; // 1: 장애인, 2: 경로, 0: 없음 printf("할인 코드: "); scanf("%d", &discount_code); if (discount_code == 1 || discount_code == 2) { fare = fare - fare / 5; printf("20%% 할인\n"); }
B
할인율 변수 방식 (float)
float rate = 1.0f; // 할인율 배수 저장 if (discount_code == 1 || discount_code == 2) { rate = 0.8f; // 80%만 냄 } fare = (int)(fare * rate);

합승 인원 나누기

2인 이상 합승 시 1인당 요금을 계산합니다. 단, 최소 1인임을 확인해야 합니다.

int passengers; // 탑승 인원 printf("탑승 인원 (1~4): "); scanf("%d", &passengers); if (passengers >= 2) { int per_person = fare / passengers; printf("1인당 요금: %d원\n", per_person); } else { printf("총요금: %d원\n", fare); }
실행 예시 — 야간 3500m, 2인 합승
이동 거리를 입력하세요 (m): 3500
탑승 시각을 입력하세요 (0~23): 23
할인 코드 (0/1/2): 0
탑승 인원 (1~4): 2
야간 할증 적용
총요금: 7080원 | 1인당: 3540원

전체 코드

else if || scanf int 나눗셈 할증 할인율 합승
/* 택시 요금 계산기 — 야간할증 + 할인 + 합승 */ #include <stdio.h> int main() { int distance; // 이동 거리 (m) int hour; // 탑승 시각 (0~23) int discount_code; // 할인 코드: 0=없음, 1=장애인, 2=경로 int passengers; // 탑승 인원 int fare; // 요금 int extra; // 추가 거리 /* 1. 입력 */ printf("=== 택시 요금 계산기 ===\n"); printf("이동 거리 (m): "); scanf("%d", &distance); printf("탑승 시각 (0~23): "); scanf("%d", &hour); printf("할인 코드 (0=없음/1=장애인/2=경로): "); scanf("%d", &discount_code); printf("탑승 인원 (1~4): "); scanf("%d", &passengers); /* 2. 기본요금 + 추가요금 (else if 구간 계산) */ if (distance <= 2000) { fare = 4800; // 기본요금만 } else { extra = distance - 2000; fare = 4800 + (extra / 131) * 100; // 131m마다 100원 } /* 3. 야간 할증 (22시 이후 또는 04시 이전) */ if (hour >= 22 || hour < 4) { fare = fare + fare / 5; // 20% 추가 printf("[야간 할증 20%% 적용]\n"); } /* 4. 할인 (장애인/경로 20% 감면) */ if (discount_code == 1 || discount_code == 2) { fare = fare - fare / 5; // 20% 차감 printf("[할인 20%% 적용]\n"); } /* 5. 합승 분담 */ printf("------------------------\n"); printf("총요금: %d원\n", fare); if (passengers >= 2) { printf("1인당: %d원 (%d명)\n", fare / passengers, passengers); } return 0; }

입력 distance=3000, hour=23, discount_code=2

이 프로젝트에서 배운 것

  • else if로 구간별 요금 로직을 명확하게 분리할 수 있습니다.
  • 정수 나눗셈(/)은 소수점을 버립니다 — 요금 계산에서 이것이 내림 처리가 됩니다.
  • 야간 시간처럼 불연속 조건은 ||(또는)로 표현합니다.
  • 할증과 할인을 순서대로 쌓아 적용하면 복잡한 요금 체계도 구현할 수 있습니다.
  • 인원으로 나누면 1인당 요금을 계산할 수 있습니다.
