Project 09

가위바위보 게임

조건문(if-else, switch)을 총동원해서 완성하는 첫 번째 종합 프로젝트

이 프로젝트에서 배우는 것

  • if-else와 switch를 상황에 맞게 선택해서 쓸 수 있습니다.
  • 중첩 조건문으로 9가지 경우의 수를 처리할 수 있습니다.
  • rand() / srand()로 컴퓨터 랜덤 선택을 구현할 수 있습니다.
  • 전적(승/패/무)을 변수로 누적 관리할 수 있습니다.
  • 숫자를 문자열로 변환하는 매핑 패턴을 익힙니다.

Step 1 — 기본 뼈대: 입력과 고정 컴퓨터

일단 랜덤 없이 만든다. 컴퓨터는 항상 바위(2)를 냅니다. 사용자 입력을 받아 승패를 판정하는 최소 버전으로 시작.

설계 원칙 — 복잡한 프로그램은 작은 버전부터 만들고, 하나씩 기능을 추가한다. 한 번에 다 만들려다 막히는 것보다 단계별로 완성하는 게 빠르다.

9가지 경우의 수 표

가위(1), 바위(2), 보(3) 각각 3가지 × 3가지 = 9가지 경우. 모든 경우를 코드로 처리해야 한다.

방법 A — 중첩 if-else

#include <stdio.h> int main() { int user, com = 2; // 컴퓨터는 항상 바위 printf("가위(1) 바위(2) 보(3): "); scanf("%d", &user); if (user == com) { printf("비겼습니다!\n"); } else if (user == 1 && com == 3) { printf("이겼습니다!\n"); // 가위 > 보 } else if (user == 2 && com == 1) { printf("이겼습니다!\n"); // 바위 > 가위 } else if (user == 3 && com == 2) { printf("이겼습니다!\n"); // 보 > 바위 } else { printf("졌습니다!\n"); } return 0; }

방법 B — switch로 사용자 값 분기

switch(user) 안에서 각 경우마다 컴퓨터 값을 비교하는 방식. case가 명확해서 읽기 쉽다.

switch (user) { case 1: // 사용자: 가위 if (com == 1) printf("비겼습니다!\n"); else if (com == 2) printf("졌습니다!\n"); else printf("이겼습니다!\n"); break; case 2: // 사용자: 바위 if (com == 2) printf("비겼습니다!\n"); else if (com == 3) printf("졌습니다!\n"); else printf("이겼습니다!\n"); break; case 3: // 사용자: 보 if (com == 3) printf("비겼습니다!\n"); else if (com == 1) printf("졌습니다!\n"); else printf("이겼습니다!\n"); break; default: printf("잘못된 입력입니다.\n"); }
if vs switch 선택 기준
- 값이 딱 떨어지는 정수 비교 → switch가 깔끔
- 범위 조건 (score >= 90) 또는 복합 조건 (a && b) → if-else 사용

출력

if (user == com) printf("비겼습니다!\n"); else if (__________ == com) printf("이겼습니다!\n"); else printf("졌습니다!\n");

정답 보기

Step 2 — 확장: 랜덤 · 전적 · 한글 출력

컴퓨터 랜덤 선택 — rand() & srand()

#include <stdio.h> #include <stdlib.h> // rand(), srand() #include <time.h> // time() int main() { srand(time(0)); // 씨앗값: 실행마다 달라짐 int com = rand() % 3 + 1; // 1, 2, 3 중 하나 // ... 이하 동일 }
srand를 main 맨 위에 딱 한 번 호출해야 한다. 루프 안에서 매번 호출하면 시간이 같아서 같은 값만 나온다.

전적 기록 — 승/패/무 카운트

int win = 0, lose = 0, draw = 0; // 판정 후 카운트 증가 if (user == com) { draw++; printf("비겼습니다!\n"); } else if (user % 3 + 1 == com) { win++; printf("이겼습니다!\n"); } else { lose++; printf("졌습니다!\n"); } // 전적 출력 printf("전적: %d승 %d패 %d무\n", win, lose, draw);

숫자 → 한글 변환 (포인터 배열 미리보기)

1→"가위", 2→"바위", 3→"보" 로 출력하면 훨씬 알아보기 쉽다. 가장 간단한 방법은 if-else 또는 삼항 연산자 체인이다.

// 방법 1: if-else 변환 char *getName(int n) { if (n == 1) return "가위"; else if (n == 2) return "바위"; else return "보"; } // 방법 2: 문자열 배열 (배열 배운 후 사용) char *names[] = {"가위", "바위", "보"}; printf("사용자: %s | 컴퓨터: %s\n", names[user-1], names[com-1]);

완성 코드 — 랜덤 + 전적 + 한글 출력 통합 버전

#include <stdio.h> #include <stdlib.h> #include <time.h> /* 숫자를 한글 이름으로 변환 */ char *getName(int n) { if (n == 1) return "가위"; else if (n == 2) return "바위"; else return "보"; } int main() { srand(time(0)); // 랜덤 씨앗 — 맨 위에서 한 번 int win = 0, lose = 0, draw = 0; int rounds = 3; for (int i = 1; i <= rounds; i++) { printf("\n--- %d라운드 ---\n", i); printf("가위(1) 바위(2) 보(3): "); int user; scanf("%d", &user); // 유효성 검사 if (user < 1 || user > 3) { printf("잘못된 입력! 프로그램을 종료합니다.\n"); return 1; } int com = rand() % 3 + 1; // 1, 2, 3 랜덤 printf("사용자: %s | 컴퓨터: %s\n", getName(user), getName(com)); if (user == com) { draw++; printf("결과: 비겼습니다!\n"); } else if (user % 3 + 1 == com) { win++; printf("결과: 이겼습니다!\n"); } else { lose++; printf("결과: 졌습니다!\n"); } } /* 최종 전적 */ printf("\n===== 최종 전적 =====\n"); printf("%d승 %d패 %d무 (승률: %d%%)\n", win, lose, draw, win * 100 / rounds); return 0; }

핵심 정리

  • if-else vs switch: 정수 일치 비교는 switch, 범위·복합 조건은 if-else
  • rand()%3+1 → 1~3 균등 난수 / srand(time(0)) 는 main 맨 위 한 번만
  • user%3+1==com 조건 하나로 이기는 경우 9개를 3줄로 처리
  • 전적은 int win/lose/draw 변수로 누적 후 마지막에 한 번에 출력
  • 숫자→문자열 매핑은 함수 또는 배열로 처리하면 중복 제거
