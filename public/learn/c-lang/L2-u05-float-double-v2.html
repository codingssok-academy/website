실수형: float와 double

소수점이 있는 숫자를 다루는 float와 double의 차이, 정밀도, 출력 방법을 배웁니다.

이 유닛에서 배우는 것

  • float와 double의 크기와 정밀도 차이를 설명할 수 있다.
  • 실수 리터럴(3.14, 3.14f)의 차이를 구분할 수 있다.
  • printf에서 %f, %.2f 포맷을 사용할 수 있다.
  • float와 double의 정밀도 차이를 직접 확인할 수 있다.
  • 원의 넓이, 할인 가격 등 실수 계산 프로그램을 작성할 수 있다.

실수형이란?

정수형(int)은 1, 2, -5처럼 소수점이 없는 숫자만 저장합니다. 하지만 3.14, 0.5, -2.7 같은 소수점이 있는 숫자를 저장하려면 실수형이 필요합니다.

C언어에서 실수형은 두 가지가 있습니다: float와 double입니다.

float는 4바이트, double은 8바이트를 사용합니다. double은 float보다 2배 더 큰 공간을 쓰는 대신, 소수점 아래 더 많은 자릿수를 정확하게 저장합니다.

실수 리터럴

코드에 소수점 숫자를 직접 쓰는 것을 실수 리터럴이라고 합니다. C에서 3.14라고 쓰면 기본적으로 double입니다. float로 만들려면 뒤에 f를 붙여야 합니다.

#include <stdio.h> int main(void) { float pi_f = 3.14f; // float: 뒤에 f 필수 double pi_d = 3.14; // double: 기본값 printf("float: %f\n", pi_f); printf("double: %f\n", pi_d); return 0; }
따라해보세요
1
float 변수에 자신의 키(예: 165.5)를 저장하고 출력해 보세요.
float height = 165.5f; printf("키: %f\n", height);
키: 165.500000
2
double 변수에 원주율 3.141592653589793을 저장하고 출력해 보세요.
double pi = 3.141592653589793; printf("원주율: %f\n", pi);
원주율: 3.141593
3
3.14와 3.14f의 타입 차이를 말해보세요.
// 3.14 → double (8바이트) // 3.14f → float (4바이트)
f가 없으면 double, f가 있으면 float

실수 출력: %f와 소수점 자릿수

실수를 출력할 때는 %f를 사용합니다. 기본적으로 소수점 아래 6자리까지 출력됩니다. 자릿수를 조절하려면 %.2f처럼 점 뒤에 원하는 자릿수를 씁니다.

#include <stdio.h> int main(void) { double price = 12500.7; printf("기본: %f\n", price); // 12500.700000 printf("2자리: %.2f\n", price); // 12500.70 printf("1자리: %.1f\n", price); // 12500.7 printf("정수: %.0f\n", price); // 12501 return 0; }

float와 double의 정밀도 차이

float은 소수점 약 6~7자리까지만 정확합니다. double은 15~16자리까지 정확합니다. 같은 값을 저장해도 float은 뒤쪽 숫자가 달라질 수 있습니다.

이런 오차는 컴퓨터가 소수를 2진수로 저장하기 때문에 생깁니다. 정밀한 계산이 필요하면 double을 쓰는 것이 좋습니다.

따라해보세요
1
가격 9900.5를 소수점 2자리까지 출력해 보세요.
double price = 9900.5; printf("가격: %.2f원\n", price);
가격: 9900.50원
2
float와 double에 같은 값을 넣고 소수점 10자리까지 출력해서 비교해 보세요.
float a = 1.0f / 3.0f; double b = 1.0 / 3.0; printf("float: %.10f\n", a); printf("double: %.10f\n", b);
float은 7자리쯤부터, double은 15자리쯤부터 오차 발생

실전: 원의 넓이 계산

원의 넓이 공식은 pi x r x r입니다. 반지름을 입력받아 원의 넓이를 계산해 봅시다.

#include <stdio.h> int main(void) { double pi = 3.141592653589793; double radius = 5.0; double area = pi * radius * radius; printf("반지름: %.1f\n", radius); printf("넓이: %.2f\n", area); return 0; }

실전: 할인 가격 계산

원래 가격에 할인율을 곱해서 할인 가격을 구해봅시다. 할인율은 0.0~1.0 사이의 실수입니다.

#include <stdio.h> int main(void) { double original = 25000.0; // 원래 가격 double rate = 0.2; // 20% 할인 double discount = original * rate; double final_price = original - discount; printf("원래 가격: %.0f원\n", original); printf("할인액: %.0f원\n", discount); printf("최종 가격: %.0f원\n", final_price); return 0; }
따라해보세요
1
반지름 7.5인 원의 넓이를 소수점 2자리까지 출력해 보세요.
double r = 7.5; double area = 3.141592653589793 * r * r; printf("넓이: %.2f\n", area);
넓이: 176.71

핵심 요약

  • float는 4바이트(소수점 6~7자리), double은 8바이트(소수점 15~16자리)이다.
  • 실수 리터럴은 기본이 double이고, f를 붙이면 float이 된다.
  • %f는 소수점 6자리 기본 출력, %.2f는 2자리까지 출력한다.
  • float보다 double이 더 정밀하다. 정확한 계산이 필요하면 double을 쓴다.
  • 컴퓨터는 소수를 2진수로 저장하므로 미세한 오차가 생길 수 있다.
