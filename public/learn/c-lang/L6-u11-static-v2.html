static과 함수 고급 — 값이 기억되는 변수

static 지역 변수는 함수가 끝나도 값이 사라지지 않습니다. 호출 카운터 패턴과 함수 포인터의 개념을 맛봅니다.

이 유닛에서 배우는 것

  • static 지역 변수가 일반 지역 변수와 어떻게 다른지 이해합니다.
  • static 변수로 호출 카운터를 구현합니다.
  • static 변수가 프로그램 전체 생애를 유지함을 압니다.
  • 함수 포인터의 개념을 처음 맛봅니다.
  • static을 사용하는 상황을 판단할 수 있습니다.

static 지역 변수 — 값이 기억된다

일반 지역 변수는 함수가 끝나면 사라집니다. 하지만 static을 붙이면 함수가 끝나도 값이 유지됩니다. 다음에 다시 호출하면 이전 값이 그대로 있습니다.

void counter() { static int count = 0; // 처음 한 번만 0으로 초기화 count++; printf("호출 횟수: %d\n", count); } int main() { counter(); // 호출 횟수: 1 counter(); // 호출 횟수: 2 counter(); // 호출 횟수: 3 return 0; }

static int count = 0은 프로그램 시작 시 딱 한 번만 0으로 초기화됩니다. 이후 호출에서는 이전 값을 그대로 유지합니다.

호출 카운터 패턴

static 변수는 함수가 몇 번 호출되었는지 세는 데 유용합니다. 전역 변수를 쓰지 않고도 상태를 유지할 수 있습니다.

#include <stdio.h> int getNextId() { static int id = 0; id++; return id; // 1, 2, 3, 4... 순서대로 반환 } void registerUser() { int myId = getNextId(); printf("회원 ID: %d\n", myId); } int main() { registerUser(); // 회원 ID: 1 registerUser(); // 회원 ID: 2 registerUser(); // 회원 ID: 3 return 0; }

함수 포인터 맛보기

함수도 메모리에 저장되므로, 함수의 주소를 변수에 담을 수 있습니다. 이것을 함수 포인터라고 합니다. 지금은 이런 것이 있다는 것만 알면 됩니다.

int add(int a, int b) { return a + b; } int mul(int a, int b) { return a * b; } int main() { // 함수 포인터 선언: 반환타입 (*이름)(매개변수타입) int (*op)(int, int); op = add; printf("%d\n", op(3, 4)); // 7 (add 호출) op = mul; printf("%d\n", op(3, 4)); // 12 (mul 호출) return 0; }

핵심 정리

핵심 요약

  • static 지역 변수: 함수가 끝나도 값이 유지됩니다.
  • static 초기화는 처음 한 번만 실행됩니다.
  • static 변수는 선언된 함수 안에서만 접근 가능합니다 (전역 변수와 다름).
  • 호출 카운터, 누적 합산 등에 유용한 패턴입니다.
  • 함수 포인터: 함수의 주소를 저장하는 변수 (고급 개념, 나중에 자세히).
