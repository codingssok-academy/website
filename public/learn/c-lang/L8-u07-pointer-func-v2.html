포인터 매개변수로
원본 수정 — swap 구현

포인터를 함수 매개변수로 전달해 원본 데이터를 수정하는 다양한 패턴을 익힙니다. swap 함수를 완전히 이해합니다.

이 유닛에서 배우는 것

  • 포인터 매개변수 함수의 선언, 호출, 구현을 완전히 이해합니다.
  • swap 함수를 직접 구현하고 이해합니다.
  • 여러 값을 "반환"하는 함수 패턴을 익힙니다.
  • 배열 포인터 매개변수를 사용하는 함수를 작성합니다.
  • 포인터 매개변수 패턴의 실전 응용을 배웁니다.

포인터 매개변수 3단계 패턴

포인터 매개변수를 사용하는 함수는 항상 이 3단계 패턴을 따릅니다.

// 1단계: 함수 정의 — *p 매개변수 void set_value(int *p, int val) { *p = val; // 원본 변경 } // 2단계: 호출 — &a 주소 전달 int a = 10; set_value(&a, 99); // 3단계: 결과 확인 printf("%d\n", a); // 99

swap 함수 단계별 실행 추적

완전한 swap 구현

#include <stdio.h> void swap(int *a, int *b) { int tmp = *a; *a = *b; *b = tmp; } int main() { int x = 10, y = 20; printf("Before: x=%d y=%d\n", x, y); // 10 20 swap(&x, &y); printf("After: x=%d y=%d\n", x, y); // 20 10 return 0; }

여러 값 동시 반환 패턴

C언어에서 함수는 return으로 하나의 값만 반환할 수 있습니다. 하지만 포인터 매개변수를 이용하면 여러 값을 동시에 전달할 수 있습니다.

// 배열에서 최솟값, 최댓값, 합계를 동시에 구하기 void stats(int *arr, int n, int *mn, int *mx, int *sum) { *mn = *mx = arr[0]; *sum = 0; for (int i = 0; i < n; i++) { if (arr[i] < *mn) *mn = arr[i]; if (arr[i] > *mx) *mx = arr[i]; *sum += arr[i]; } } int main() { int data[] = {3, 1, 4, 1, 5, 9, 2}; int mn, mx, s; stats(data, 7, &mn, &mx, &s); printf("min=%d max=%d sum=%d\n", mn, mx, s); // min=1 max=9 sum=25 return 0; }

배열 뒤집기 함수

#include <stdio.h> void reverse(int *arr, int n) { int *left = arr; // 맨 앞 포인터 int *right = arr + n - 1; // 맨 뒤 포인터 while (left < right) { int tmp = *left; *left = *right; *right = tmp; left++; // 앞에서 전진 right--; // 뒤에서 후진 } } int main() { int arr[] = {1, 2, 3, 4, 5}; reverse(arr, 5); for (int i=0; i<5; i++) printf("%d ", arr[i]); // 5 4 3 2 1 return 0; }
