구조체를 함수에 전달/반환하기

구조체를 함수의 매개변수로 넘기고, 함수가 구조체를 반환하는 방법을 배웁니다. 값 전달과 포인터 전달의 차이도 이해해봅시다.

이 유닛에서 배우는 것

  • 구조체를 함수에 값으로 전달할 수 있습니다.
  • 구조체를 포인터로 전달해 원본을 수정할 수 있습니다.
  • 함수가 구조체를 반환하는 코드를 작성할 수 있습니다.
  • 값 전달과 포인터 전달의 차이점을 설명할 수 있습니다.
  • 함수로 구조체를 만들어 반환하는 패턴을 사용할 수 있습니다.

값 전달(pass by value)

구조체를 함수에 일반 변수처럼 전달하면 복사본이 전달됩니다. 함수 안에서 수정해도 원본은 바뀌지 않습니다.

typedef struct { char name[20]; int age; float score; } Student; void printStudent(Student s) { // 복사본 전달 printf("%s: %d세, %.1f점\n", s.name, s.age, s.score); s.age = 99; // 복사본만 수정 — 원본에 영향 없음 } int main() { Student s = {"김민준", 15, 88.5f}; printStudent(s); printf("원본 age: %d\n", s.age); // 여전히 15 return 0; }

포인터 전달(pass by pointer)

포인터로 전달하면 원본을 직접 수정할 수 있고, 큰 구조체도 메모리를 복사하지 않아 효율적입니다.

void levelUp(Student *sp) { // 포인터 전달 sp->score += 5.0f; // 원본 수정! sp->age += 1; } Student s = {"김민준", 15, 88.5f}; levelUp(&s); printf("%.1f %d\n", s.score, s.age); // 93.5 16

구조체를 반환하는 함수

함수가 구조체를 반환 타입으로 가질 수 있습니다. 이를 이용해 구조체를 만들어 돌려주는 팩토리 함수를 작성할 수 있습니다.

Student makeStudent(const char *name, int age, float score) { Student s; strcpy(s.name, name); s.age = age; s.score = score; return s; // 구조체 반환 } int main() { Student a = makeStudent("김민준", 15, 88.5f); Student b = makeStudent("이서연", 16, 92.0f); printf("%s %.1f\n", a.name, a.score); printf("%s %.1f\n", b.name, b.score); return 0; }

핵심 정리

핵심 정리

  • 값 전달: 복사본이 함수에 전달 → 원본 불변, 큰 구조체는 비효율
  • 포인터 전달: 주소 전달 → 원본 수정 가능, 메모리 효율적
  • 구조체 반환: Student makeStudent(...) { return s; }
  • 함수 안에서 포인터로 멤버 접근: sp->멤버 (화살표 연산자)

전체 활용 예제

구조체 생성, 출력, 수정 함수를 모두 사용하는 종합 예제입니다.

#include <stdio.h> #include <string.h> typedef struct { char name[20]; int age; float score; } Student; Student make(const char *n, int a, float sc) { Student s; strcpy(s.name, n); s.age=a; s.score=sc; return s; } void print(Student s) { printf("%-8s %2d세 %.1f점\n", s.name, s.age, s.score); } void bonus(Student *sp, float b) { sp->score += b; } int main() { Student s1 = make("김민준", 15, 88.5f); Student s2 = make("이서연", 16, 92.0f); bonus(&s1, 5.0f); print(s1); print(s2); return 0; }
