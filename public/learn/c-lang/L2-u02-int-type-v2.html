Chapter 02

정수형 변수 — int

소수점 없는 숫자를 저장하는 int 자료형과, 다른 정수형 자료형들의 차이를 배웁니다.

이 유닛에서 배우는 것

  • int가 정수를 저장하는 자료형임을 알 수 있습니다.
  • int의 크기(4바이트)와 범위를 알 수 있습니다.
  • short, long, unsigned의 차이를 구분할 수 있습니다.
  • 상황에 맞는 정수 자료형을 선택할 수 있습니다.
  • 정수 변수를 선언하고 활용할 수 있습니다.

int = 정수를 담는 자료형

int는 integer(정수)의 줄임말입니다. 소수점이 없는 수, 즉 ..., -2, -1, 0, 1, 2, ... 같은 숫자를 저장합니다.

int는 메모리에서 4바이트(32비트)를 차지합니다. 1바이트는 8비트이므로, 총 32개의 0과 1로 숫자를 표현합니다.

int의 범위

32비트로 표현할 수 있는 정수의 범위는 -2,147,483,648부터 2,147,483,647까지입니다. 약 21억입니다.

다른 정수형: short와 long

int보다 작은 범위가 필요하면 short(2바이트), 큰 범위가 필요하면 long(8바이트)을 씁니다.

// 각 자료형으로 변수 선언 short age = 15; // 2바이트, 작은 수에 적합 int score = 95; // 4바이트, 가장 많이 사용 long population = 8000000000L; // 8바이트, 큰 수

unsigned: 음수 없이 두 배

unsigned int는 음수를 포기하고 양수 범위를 두 배로 늘립니다. 나이나 점수처럼 음수가 필요 없을 때 유용합니다.

unsigned int count = 4000000000; // 42억까지 가능 printf("count: %u\n", count); // %u = unsigned 출력
따라해보세요
1
int로 점수 변수를 만들고 95를 저장하세요.
int score = 95; printf("점수: %d", score);
점수: 95
2
short로 나이를 저장하세요.
short age = 15; printf("나이: %d", age);
나이: 15
3
long으로 세계 인구를 저장하세요.
long pop = 8000000000L; printf("인구: %ld", pop);
인구: 8000000000

왜 int가 기본일까?

대부분의 숫자는 int 범위(-21억~+21억) 안에 충분히 들어갑니다. 나이, 점수, 개수 등 일상적인 숫자는 int로 충분합니다.

// 적절한 자료형 선택 예시 #include <stdio.h> int main() { int score = 95; // 점수: int 충분 int year = 2025; // 연도: int 충분 short month = 12; // 월: short도 가능 long distance = 384400000L; // 달까지 거리(m) printf("점수: %d\n", score); printf("연도: %d\n", year); printf("월: %d\n", month); printf("거리: %ld m\n", distance); return 0; }
따라해보세요
1
적절한 자료형을 골라 학교 학생 수(800명)를 저장하세요.
int students = 800; printf("학생 수: %d명", students);
int가 적절합니다 (short도 가능)
2
지구 둘레(40,075km)를 미터로 저장하세요.
long earth = 40075000L; printf("둘레: %ld m", earth);
int로도 가능하지만 long이 안전합니다
3
unsigned int로 조회수(30억)를 저장하세요.
unsigned int views = 3000000000; printf("조회수: %u", views);
int(-21억~+21억)로는 부족! unsigned가 필요

확인 문제

Q1
범위 초과 문제
보통
short 변수에 50000을 저장하면 어떻게 될까요?
코드short x = 50000;
내 답안
힌트 보기
short의 최대값은 32,767입니다. 50,000은 이 범위를 넘습니다.
정답 보기
오버플로우(overflow)가 발생합니다. short 범위(-32,768~32,767)를 초과하므로 예상과 다른 엉뚱한 값이 저장됩니다. int를 사용해야 합니다.
Q2
자료형 선택
쉬움
다음 데이터에 가장 적절한 자료형을 고르세요.
(1)시험 점수 (0~100)
(2)세계 인구 (80억)
(3)유튜브 조회수 (최대 40억)
내 답안
힌트 보기
int 범위는 약 21억, long은 약 922경, unsigned int는 약 42억입니다.
정답 보기
(1) int (100은 int 범위 안) (2) long (80억은 int 범위 초과) (3) unsigned int (40억은 int 초과, unsigned int로 가능)

쉬움

핵심 요약

  • int는 4바이트 정수형으로, 약 -21억~+21억 범위입니다.
  • short(2B), int(4B), long(8B) 순으로 크기가 커집니다.
  • unsigned를 붙이면 음수를 포기하고 양수 범위가 2배가 됩니다.
  • 대부분의 경우 int를 사용하면 충분합니다.
  • 범위를 넘으면 오버플로우가 발생하여 엉뚱한 값이 됩니다.
