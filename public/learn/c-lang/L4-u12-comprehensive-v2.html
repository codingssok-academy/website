반복문 종합 실전

L4에서 배운 모든 반복문 기술을 통합하여 성적 처리 시스템과 숫자 야구 게임을 직접 만들어 봅니다.

이 유닛에서 배우는 것

  • L4 전체 개념(for/while/do-while/중첩/break/continue)을 하나의 마인드맵으로 정리합니다.
  • 여러 학생의 점수를 입력받아 합계, 평균, 최고점을 계산하는 프로그램을 작성합니다.
  • 평균 점수에 따라 등급(A~F)을 자동으로 출력합니다.
  • 숫자 야구 게임에서 strike와 ball을 판정하는 로직을 구현합니다.
  • L4를 마무리하고 L5(배열)에서 무엇을 배울지 미리 파악합니다.

Level 4 반복문 — 전체 마인드맵

L4에서 배운 반복문 개념을 한 눈에 정리합니다. 연결 관계를 보면서 어떤 상황에 무엇을 쓸지 확인하세요.

언제 어떤 반복문을 쓸까?

  • for문 — 반복 횟수가 미리 정해진 경우 (별 찍기, 1~n 합계)
  • while문 — 조건이 만족되는 동안 반복 (사용자 입력 반복, 게임 루프)
  • do-while문 — 최소 1번은 반드시 실행해야 하는 경우 (메뉴 선택)
  • 이중 for — 행과 열이 있는 2차원 구조 (표, 패턴)
  • break — 조건 만족 시 즉시 루프 종료 / continue — 현재 반복 건너뛰기

종합 예제 1 — 성적 처리 시스템

여러 명의 점수를 입력받아 합계, 평균, 최고점을 계산하고, 평균 점수에 따른 등급을 출력합니다.

#include <stdio.h> int main() { int n, score, sum = 0, max_score; printf("학생 수: "); scanf("%d", &n); printf("첫 번째 점수: "); scanf("%d", &score); sum = max_score = score; // 첫 점수로 초기화 for (int i = 2; i <= n; i++) { printf("%d번째 점수: ", i); scanf("%d", &score); sum += score; if (score > max_score) max_score = score; } double avg = (double)sum / n; printf("\n합계: %d점\n", sum); printf("평균: %.1f점\n", avg); printf("최고점: %d점\n", max_score); // 등급 결정 char grade; if (avg >= 90) grade = 'A'; else if (avg >= 80) grade = 'B'; else if (avg >= 70) grade = 'C'; else if (avg >= 60) grade = 'D'; else grade = 'F'; printf("등급: %c\n", grade); return 0; }

종합 예제 2 — 숫자 야구 게임

컴퓨터가 1~9 중 서로 다른 3자리 숫자를 정하면, 사용자가 맞출 때까지 strike/ball을 판정합니다.

strike / ball 규칙
Strike: 숫자와 위치가 모두 일치
Ball: 숫자는 맞지만 위치가 다름
Out: 숫자 자체가 없음
예) 정답: 4 2 5 / 입력: 4 5 2 → 1Strike 2Ball
#include <stdio.h> int main() { int ans[3] = {4, 2, 5}; // 실제로는 rand()로 생성 int guess[3], strike, ball, tries = 0; while (1) { // 3 Strike 될 때까지 반복 strike = ball = 0; tries++; printf("%d번째 시도 (3자리 입력): ", tries); scanf("%d %d %d", &guess[0], &guess[1], &guess[2]); // Strike 판정: 숫자도 같고 위치도 같음 for (int i = 0; i < 3; i++) { if (guess[i] == ans[i]) strike++; } // Ball 판정: 숫자는 있지만 위치가 다름 for (int i = 0; i < 3; i++) { for (int j = 0; j < 3; j++) { if (i != j && guess[i] == ans[j]) ball++; } } printf("%dS %dB\n", strike, ball); if (strike == 3) { // 3 Strike = 정답! printf("정답! %d번 만에 맞혔습니다.\n", tries); break; } } return 0; }

Level 4 반복문 — 핵심 정리

  • for: 횟수 고정 / while: 조건 반복 / do-while: 최소 1회 보장
  • 이중 for: 행(바깥)×열(안쪽), 별 찍기·패턴의 핵심
  • 누적 변수: sum=0(합), fact=1(곱), max/min=첫 값
  • 소수 판별: i*i <= n 조건으로 O(sqrt(n)) 최적화
  • break: 루프 즉시 탈출 / continue: 현재 반복 건너뛰기
