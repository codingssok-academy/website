Chapter 08

switch 활용 — break와 default 심화

break의 정확한 동작을 이해하고, fall-through 패턴을 의도적으로 활용합니다. default 위치 규칙과 char 타입 switch도 함께 배웁니다.

이 유닛에서 배우는 것

  • break가 없을 때 fall-through가 발생하는 이유를 설명할 수 있습니다.
  • 의도적 fall-through로 여러 case가 같은 코드를 공유할 수 있습니다.
  • default의 위치 규칙과 관례를 구분할 수 있습니다.
  • char 변수를 switch에 사용하고 대소문자를 동시에 처리할 수 있습니다.
  • switch와 if-else 중 상황에 맞는 것을 선택할 수 있습니다.

break 심화 — fall-through란?

break는 switch 블록 전체를 즉시 빠져나가는 명령입니다. break가 없으면 해당 case 코드를 실행한 뒤 다음 case로 계속 흘러내립니다. 이것을 fall-through(폴스루)라고 합니다.

의도적 fall-through — case 묶기

반대로, 여러 case가 같은 동작을 해야 할 때 의도적으로 fall-through를 활용합니다. break 없이 case를 쌓으면 됩니다.

실전 예시로 월별 날 수를 출력하는 프로그램을 만들어봅시다. 31일인 달(1,3,5,7,8,10,12)을 한꺼번에 묶는 데 fall-through가 딱 맞습니다.

int month = 7; int days; switch (month) { case 1: case 3: case 5: case 7: case 8: case 10: case 12: days = 31; break; case 4: case 6: case 9: case 11: days = 30; break; case 2: days = 28; break; default: days = -1; // 잘못된 입력 } printf("%d월은 %d일입니다.\n", month, days);
따라해보세요
1
int n = 2; 로 설정하고, case 1: case 2: case 3: 을 묶어 "1~3 사이"를 출력해보세요. break를 제거하면 어떤 결과가 나오는지 확인하세요.
switch (n) { case 1: case 2: case 3: printf("1~3 사이\n"); break; }
1~3 사이 출력, break 제거하면 다음 case도 실행됩니다
2
위 월→일수 코드를 직접 입력하고, month 값을 2, 4, 9로 바꿔가며 결과를 확인하세요.
2→28일, 4→30일, 9→30일이 출력됩니다
3
case 3 다음 break를 일부러 빼서 fall-through가 발생하는 것을 눈으로 확인해보세요.
int x = 1; switch (x) { case 1: printf("A\n"); // break 없음! case 2: printf("B\n"); break; case 3: printf("C\n"); break; }
A와 B 모두 출력됩니다 (fall-through 발생)

default 심화 + char switch

default 위치는 어디든 OK — 하지만 관례는 맨 마지막

default는 switch 블록 안 어느 위치에도 올 수 있습니다. 단, 관례상 마지막에 씁니다. default 앞에도 break가 있는 경우 default는 건너뜁니다.

char 변수로 switch 사용하기

switch는 정수 계열 자료형만 사용 가능합니다. char는 내부적으로 정수(ASCII 코드)이므로 switch에 사용할 수 있습니다.

대소문자를 동시에 처리하려면 case 'a': case 'A': 처럼 두 case를 fall-through로 묶으면 됩니다.

char cmd = 'a'; switch (cmd) { case 'a': case 'A': printf("항목 추가\n"); break; case 'd': case 'D': printf("항목 삭제\n"); break; case 'q': case 'Q': printf("프로그램 종료\n"); break; default: printf("알 수 없는 명령: %c\n", cmd); }
따라해보세요
1
위 메뉴 코드를 직접 입력하고 cmd를 'D', 'q', 'x' 로 바꿔가며 결과를 확인해보세요.
각각 "항목 삭제", "프로그램 종료", "알 수 없는 명령: x" 출력
2
메뉴에 'l'/'L' — "목록 출력"을 추가해보세요.
case 'l': case 'L': printf("목록 출력\n"); break;
l 또는 L 입력 시 "목록 출력" 출력
3
default를 switch 맨 처음 위치로 옮겨도 동작하는지 확인해보세요. 결과가 같은지 비교하세요.
동작은 같습니다. 하지만 가독성이 떨어지므로 마지막 위치를 권장합니다.

switch vs if-else — 언제 뭘 써야 할까?

두 구조는 비슷해 보이지만 적합한 상황이 다릅니다. 아래 비교표를 보고 판단 기준을 잡아봅시다.

switch에서 범위 비교하는 꼼수 — 점수 나누기

switch는 원래 범위 비교가 안 됩니다. 하지만 점수를 10으로 나눠 정수로 만들면 등급 판정 같은 범위 처리도 할 수 있습니다.

꼼수: score / 10을 switch에 넘기면 90점대→9, 80점대→8... 로 변환됩니다.
int score = 85; switch (score / 10) { // 85/10 = 8 case 10: case 9: printf("A등급\n"); break; case 8: printf("B등급\n"); break; // 여기 해당! case 7: printf("C등급\n"); break; default: printf("D등급\n"); }

int season = 2, temp = 37; switch (season) { case 1: printf("봄\n"); break; case 2: printf("여름\n"); if (temp >= 35) printf("폭염 주의!\n"); break; case 3: printf("가을\n"); break; case 4: printf("겨울\n"); break; default: printf("알 수 없는 계절\n"); } // 출력: 여름 // 폭염 주의!

이 유닛 핵심 요약

  • fall-through: break 없으면 다음 case로 코드 실행이 흘러내림
  • 의도적 fall-through: case를 여러 개 쌓아 같은 코드를 공유
  • default 위치: 어디든 OK, 관례상 맨 마지막에 (마지막 default는 break 생략 가능)
  • char switch: 'A', 'a' 처럼 char 리터럴을 case에 사용 가능
  • switch 선택 조건: 정확한 값 비교 + int/char 변수 + 케이스 4개 이상
  • 범위 꼼수: score / 10으로 점수 범위를 정수 값으로 변환해 switch 적용
