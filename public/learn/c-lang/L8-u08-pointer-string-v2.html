char *s = "Hello"
문자열 리터럴과 const

문자열을 포인터로 다루는 방법을 배웁니다. 문자 배열과 문자열 포인터의 차이, const의 중요성을 이해합니다.

이 유닛에서 배우는 것

  • char *s = "Hello"; 의 메모리 구조를 이해합니다.
  • 문자 배열과 문자열 포인터의 차이를 압니다.
  • 문자열이 항상 '\0'으로 끝나는 이유를 설명합니다.
  • const char *를 사용해야 하는 이유를 압니다.
  • 포인터로 문자열을 순회합니다.

문자열 리터럴과 char * 포인터

"Hello"같은 문자열 리터럴은 프로그램의 읽기 전용 영역에 저장됩니다. char *s는 이 영역의 첫 문자('H')를 가리킵니다.

const char *s = "Hello"; // 문자열 리터럴 포인터 char arr[] = "Hello"; // 스택에 복사 // s[0] = 'h'; — 오류! 읽기 전용 arr[0] = 'h'; // OK — 스택 복사본 수정 printf("%s\n", arr); // hello

'\0' — 문자열 끝 표시

C언어의 문자열은 항상 null 문자 '\0'(값 0)으로 끝납니다. 문자열 함수들은 이 '\0'을 만날 때까지 처리합니다.

// 포인터로 문자열 순회 — \0까지 const char *s = "Hello"; while (*s != '\0') { printf("%c ", *s); // H e l l o s++; } // 문자열 길이 구하기 (strlen 직접 구현) int my_strlen(const char *s) { int cnt = 0; while (*s++) cnt++; return cnt; } printf("%d\n", my_strlen("Hello")); // 5

const char * — 읽기 전용 보장

문자열 리터럴을 가리킬 때는 반드시 const char *를 사용해야 합니다. 함수가 문자열을 수정하지 않을 때도 const를 붙이는 습관을 기릅시다.

// 좋은 습관: 수정 안 하면 const int count_char(const char *s, char target) { int cnt = 0; while (*s) { if (*s == target) cnt++; s++; } return cnt; } printf("%d\n", count_char("banana", 'a')); // 3

문자열 포인터 배열

문자열 포인터를 배열로 만들면 여러 문자열을 효율적으로 관리할 수 있습니다.

const char *fruits[] = { "apple", "banana", "cherry" }; int n = 3; for (int i = 0; i < n; i++) { printf("%s\n", fruits[i]); } // apple // banana // cherry

핵심 정리

  • const char *s = "Hello": 읽기 전용 영역의 문자열 리터럴 가리킴
  • char arr[] = "Hello": 스택에 복사 — 수정 가능
  • 모든 C 문자열은 '\0'으로 끝남
  • 문자열 포인터로 while(*s) 패턴으로 순회
  • 수정 안 하는 문자열 매개변수는 항상 const char * 사용
