은행 계좌 — 입출금/이체 시스템

Account 구조체로 계좌를 관리하고, 입금/출금/이체 기능을 구현합니다. 잔액 부족 시 오류 처리도 포함합니다.

프로젝트 목표

  • Account 구조체(계좌번호/이름/잔액/계좌종류)를 정의합니다.
  • 입금(deposit)과 출금(withdraw) 함수를 구현합니다.
  • 잔액 부족 시 출금 불가 처리를 합니다.
  • 두 계좌 간 이체(transfer) 함수를 구현합니다.

구현 코드

#include <stdio.h> #include <string.h> typedef struct { int id; char owner[20]; int balance; char type[10]; // "보통" 또는 "적금" } Account; void printAccount(const Account *a) { printf("[%d] %s (%s) — %d원\n", a->id, a->owner, a->type, a->balance); } void deposit(Account *a, int amount) { if (amount <= 0) { printf("입금액은 양수여야 합니다.\n"); return; } a->balance += amount; printf("%s 입금: +%d원 (잔액: %d원)\n", a->owner, amount, a->balance); } int withdraw(Account *a, int amount) { if (amount <= 0) { printf("출금액은 양수여야 합니다.\n"); return 0; } if (a->balance < amount) { printf("%s 잔액 부족! (잔액: %d원, 출금 요청: %d원)\n", a->owner, a->balance, amount); return 0; } a->balance -= amount; printf("%s 출금: -%d원 (잔액: %d원)\n", a->owner, amount, a->balance); return 1; } int transfer(Account *from, Account *to, int amount) { printf("%s → %s 이체: %d원\n", from->owner, to->owner, amount); if (!withdraw(from, amount)) return 0; deposit(to, amount); return 1; } int main() { Account a = {1, "김민준", 120000, "보통"}; Account b = {2, "이서연", 85000, "보통"}; printAccount(&a); printAccount(&b); printf("\n--- 거래 내역 ---\n"); deposit(&a, 50000); withdraw(&b, 200000); // 잔액 부족 transfer(&a, &b, 30000); printf("\n--- 최종 잔액 ---\n"); printAccount(&a); printAccount(&b); return 0; }

도전 과제

도전 과제

  • 거래 내역(history)을 배열로 저장하는 기능을 추가해보세요.
  • 이자율을 적용해 적금 만기 금액을 계산해보세요.
  • 여러 계좌 중 잔액이 가장 많은 계좌를 찾아 출력해보세요.

구조 분석

withdraw 함수가 int를 반환하는 이유는 성공/실패를 호출자에게 알리기 위해서입니다. transfer는 이 반환값을 이용해 출금이 실패하면 입금 단계로 넘어가지 않습니다.

확인 문제

문제 1
전체 계좌 잔액 합산
Account 배열을 받아 전체 잔액 합계를 반환하는 함수 totalBalance를 작성하세요.
int totalBalance(const Account arr[], int n) { int total = 0; for (int i = 0; i < n; i++) total += arr[i].balance; return total; }
문제 2
잔액 부자 찾기
Account 배열에서 잔액이 가장 많은 계좌를 찾아 출력하는 함수를 작성하세요.
문제 3
이자 계산
연이율(%)을 입력받아 1년 후 잔액(원금 + 이자)을 계산하는 함수를 작성하세요. 이자 = 잔액 × 이율 / 100
void applyInterest(Account *a, float rate) { int interest = (int)(a->balance * rate / 100.0f); a->balance += interest; printf("%s 이자 +%d원 (%.1f%%)\n", a->owner, interest, rate); }
