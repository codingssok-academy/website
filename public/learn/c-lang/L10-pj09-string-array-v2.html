동적 문자열 배열
char** 포인터 배열

여러 이름을 동적으로 저장하는 char** 포인터 배열을 만듭니다. 각 문자열마다 딱 필요한 만큼만 malloc으로 할당하는 효율적인 패턴을 익힙니다.

이 프로젝트에서 만드는 것

  • char** 포인터 배열을 동적 할당합니다.
  • 각 이름을 strlen+1 크기로 개별 할당합니다.
  • 이름 목록을 출력하고 알파벳 순으로 정렬합니다.
  • 특정 이름을 검색합니다.
  • 2단계(개별 문자열 → 배열 자체)로 안전하게 해제합니다.

char** 구조 이해

char **names는 포인터의 배열입니다. 각 포인터가 독립적인 문자열을 가리키므로, 문자열마다 길이가 달라도 됩니다.

#include <stdio.h> #include <stdlib.h> #include <string.h> void sortNames(char **names, int n) { for(int i=0;i<n-1;i++) for(int j=0;j<n-1-i;j++) if(strcmp(names[j],names[j+1])>0) { char *tmp=names[j]; names[j]=names[j+1]; names[j+1]=tmp; } } void printNames(char **names, int n) { for(int i=0;i<n;i++) printf("%d. %s\n", i+1, names[i]); } int searchName(char **names, int n, char *target) { for(int i=0;i<n;i++) if(strcmp(names[i],target)==0) return i; return -1; } int main() { int n = 5; char *raw[] = {"Charlie","Alice","Eve","Bob","David"}; /* 1단계: 포인터 배열 할당 */ char **names = (char**)malloc(sizeof(char*)*n); if(!names) return 1; /* 2단계: 각 문자열 개별 할당 */ for(int i=0;i<n;i++) { names[i] = (char*)malloc(strlen(raw[i])+1); strcpy(names[i], raw[i]); } printf("-- 원본 --\n"); printNames(names,n); sortNames(names,n); printf("-- 정렬 후 --\n"); printNames(names,n); int idx = searchName(names,n,"Eve"); if(idx>=0) printf("Eve는 %d번 위치\n", idx+1); /* 해제: 개별 문자열 먼저 → 포인터 배열 */ for(int i=0;i<n;i++) { free(names[i]); names[i]=NULL; } free(names); names=NULL; return 0; }

실행 결과

-- 원본 -- 1. Charlie 2. Alice 3. Eve 4. Bob 5. David -- 정렬 후 -- 1. Alice 2. Bob 3. Charlie 4. David 5. Eve Eve는 5번 위치
