Unit 07

들여쓰기 스타일

읽기 쉬운 코드를 위한 들여쓰기 규칙과 코드 정렬 방법을 배웁니다.

이 유닛에서 배우는 것

  • 들여쓰기가 왜 필요한지 이해합니다.
  • 4칸(스페이스) 들여쓰기를 올바르게 사용합니다.
  • 중괄호 블록 단위로 들여쓰기를 일관되게 맞춥니다.
  • 들여쓰기가 없는 코드와 있는 코드의 가독성을 비교합니다.

들여쓰기란?

들여쓰기(Indentation)는 코드 줄 앞에 공백을 넣어 계층 구조를 시각적으로 표현하는 방법입니다. C 언어에서 들여쓰기는 문법적으로 필수는 아니지만, 읽기 쉬운 코드를 위해 반드시 지켜야 하는 규칙입니다.

블록({ }) 안의 코드는 4칸 스페이스로 들여씁니다. 탭 키를 쓰면 자동으로 들여써 주는 편집기도 있습니다.

따라해보세요
1
4칸 들여쓰기를 정확하게 맞춰 코드를 작성해보세요.
int main() { printf("줄 1\n"); printf("줄 2\n"); printf("줄 3\n"); return 0; }
4칸 들여쓰기로 정렬된 코드
2
일부러 들여쓰기를 제각각으로 해서 얼마나 읽기 힘든지 확인해보세요.
int main() { printf("0칸\n"); printf("3칸\n"); printf("6칸\n"); return 0; }
읽기 어려운 코드 체험

중첩 블록의 들여쓰기

블록 안에 또 블록이 있을 때(중첩), 각 단계마다 4칸씩 더 들여씁니다. 단계가 깊어질수록 4, 8, 12칸으로 늘어납니다.

int main() { // 0칸 if (점수 > 60) { // 4칸 printf("합격\n"); // 8칸 } // 4칸 return 0; // 4칸 } // 0칸
따라해보세요
1
2단계 중첩 들여쓰기를 연습해보세요.
int main() { if (1) { printf("8칸 들여쓰기\n"); } return 0; }
8칸 들여쓰기 블록 확인
2
편집기의 자동 들여쓰기 기능을 활용해보세요.
int main() { // 탭 키 한 번 = 4칸 들여쓰기 printf("탭 키 활용\n"); return 0; }
탭 키로 자동 들여쓰기 확인
3
아래 코드의 들여쓰기를 4칸으로 맞춰서 다시 써보세요.
int main(){ printf("이름\n"); printf("나이\n"); return 0; }
4칸 들여쓰기로 깔끔하게 정돈

실력 확인 문제

Q1
들여쓰기 단계 파악
쉬움
아래 코드에서 각 줄의 들여쓰기 단계(0/1/2단계)를 맞혀보세요.
int main() { if (1) { printf("안녕\n"); } return 0; }
내 답안
정답 보기
int main() { → 0단계 (0칸) if (1) { → 1단계 (4칸) printf → 2단계 (8칸) } → 1단계 (4칸) return 0; → 1단계 (4칸) } → 0단계 (0칸)
Q2
들여쓰기 고치기
쉬움
아래 코드의 들여쓰기를 올바른 4칸 스타일로 고치세요.
int main() { printf("A\n"); printf("B\n"); return 0; }
내 답안
정답 보기
int main() { printf("A\n"); printf("B\n"); return 0; }
Q3
올바른 스타일로 코드 작성
보통
4칸 들여쓰기, 일관된 중괄호 위치, 주석 포함 코드를 작성하세요.
조건printf 3줄, if 블록 1개, 4칸 들여쓰기 엄수
내 답안
예시 정답 보기
/* 성적 출력 */ int main() { // 점수 출력 printf("점수: 85\n"); if (1) { printf("합격입니다\n"); } return 0; }

핵심 요약

  • 들여쓰기는 문법 필수는 아니지만 가독성을 위해 반드시 지킴
  • 블록({ }) 안 코드는 4칸 스페이스로 들여씀
  • 중첩 블록: 단계마다 4칸씩 추가 — 1단계 4칸, 2단계 8칸
  • 들여쓰기가 일관되지 않으면 팀 작업 시 큰 문제가 됨
  • 편집기의 탭 키나 자동 정렬 기능을 적극 활용
