영화 리뷰 카드

좋아하는 영화의 별점과 리뷰를 C 언어로 예쁘게 출력합니다.

이 프로젝트에서 만드는 것

  • 영화 제목, 장르, 별점, 한 줄 평을 포함한 리뷰 카드 출력.
  • 별점을 * 문자로 시각적으로 표현합니다.
  • 여러 영화 리뷰를 연속 출력하는 리뷰 모음 완성.
  • 정렬된 정보 배치로 깔끔한 카드 레이아웃 구현.

영화 리뷰 카드 만들기

영화 리뷰 카드는 제목, 장르, 감독, 별점, 한 줄 평, 추천 여부 6개 정보로 구성합니다. 정보 레이블을 같은 폭으로 맞추면 정렬이 예쁩니다.

#include <stdio.h> int main() { /* 영화 리뷰 카드 */ // 카드 헤더 printf("==============================\n"); printf(" [ 영화 리뷰 카드 ]\n"); printf("==============================\n"); // 영화 정보 printf(" 제목 : 인터스텔라\n"); printf(" 장르 : SF / 드라마\n"); printf(" 감독 : 크리스토퍼 놀란\n"); printf("------------------------------\n"); // 별점과 리뷰 printf(" 별점 : ***** (5/5)\n"); printf(" 한 줄 평 : 우주 여행의 감동!\n"); printf(" 추천 : 강력 추천!\n"); printf("==============================\n"); return 0; }
따라해보세요

위 코드를 입력하고 리뷰 카드를 출력해보세요.
정렬된 영화 리뷰 카드 출력
2
좋아하는 영화로 내용을 바꿔보세요.
나만의 리뷰 카드 완성

영화 리뷰 모음 만들기

여러 영화를 한 프로그램에서 연속 출력하면 나만의 영화 리뷰 모음이 완성됩니다.

#include <stdio.h> int main() { /* 영화 리뷰 모음 - 3편 */ // 영화 1 printf("[ 인터스텔라 ]\n"); printf(" 별점 : *****\n"); printf(" 한 줄 평 : 감동적인 SF 걸작\n"); printf("\n"); // 영화 2 printf("[ 라라랜드 ]\n"); printf(" 별점 : ****\n"); printf(" 한 줄 평 : 꿈을 향한 아름다운 이야기\n"); printf("\n"); // 영화 3 printf("[ 어벤져스 ]\n"); printf(" 별점 : ****\n"); printf(" 한 줄 평 : 히어로 액션의 정점!\n"); return 0; }

나만의 리뷰 모음 완성
3

도전 과제

Q1
완전한 리뷰 카드 작성
기본
좋아하는 영화 1편의 완전한 리뷰 카드를 작성하세요.
조건 1제목, 장르, 감독, 별점, 한 줄 평 포함
조건 2별점을 * 기호로 표현
조건 3테두리로 감싸기
내 답안
예시 보기
printf("=========================\n"); printf(" 제목 : 해리포터\n"); printf(" 장르 : 판타지\n"); printf(" 별점 : *****\n"); printf(" 한 줄 평 : 마법 세계의 모험!\n"); printf("=========================\n");

창의

힌트필드 이름만 바꾸면 됩니다 (저자, 개발사 등)
내 답안
예시 보기
printf("[ 게임 리뷰 카드 ]\n"); printf(" 게임명 : 마인크래프트\n"); printf(" 장르 : 샌드박스\n"); printf(" 별점 : *****\n"); printf(" 한 줄 평 : 무한한 창의력!\n");

핵심 요약

  • * 기호 반복으로 별점을 시각적으로 표현 가능
  • 레이블 폭을 일정하게 맞추면 정렬된 카드 레이아웃 완성
  • printf("\n")으로 카드 사이 여백 삽입
  • 여러 카드를 연속 출력해 리뷰 모음집 구성 가능
  • 주석으로 각 영화 섹션 구분 → 코드 읽기 쉬움
