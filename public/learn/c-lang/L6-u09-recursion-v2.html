재귀 함수 — 자기 자신을 부르는 마법

함수가 자기 자신을 호출하는 재귀를 배웁니다. 거울 안의 거울처럼 끝없이 반복될 수 있는 위험, 그래서 기저 조건이 꼭 필요합니다.

이 유닛에서 배우는 것

  • 재귀 함수가 무엇인지 설명할 수 있습니다.
  • 기저 조건(Base Case)이 왜 반드시 필요한지 이해합니다.
  • 팩토리얼 재귀 함수를 작성합니다.
  • 재귀 호출의 실행 순서를 추적할 수 있습니다.
  • 재귀와 반복문의 공통점을 이해합니다.

재귀 = 자기 자신을 호출하는 함수

재귀(Recursion)란 함수 안에서 자기 자신을 다시 호출하는 것입니다. 거울 두 개를 마주보게 하면 끝없이 반사되는 것과 비슷합니다.

기저 조건 — 재귀의 멈춤 버튼

재귀에는 반드시 기저 조건(Base Case)이 있어야 합니다. 기저 조건이 없으면 함수가 무한히 자기 자신을 호출해 프로그램이 멈추지 않습니다.

// 기저 조건 없음 → 무한 호출! (나쁜 예) void bad(int n) { bad(n - 1); // 끝없이 호출됨 → 스택 오버플로우! } // 기저 조건 있음 → 올바른 재귀 (좋은 예) void countdown(int n) { if (n == 0) { printf("발사!\n"); return; } // 기저 조건 printf("%d...\n", n); countdown(n - 1); // 자기 자신 호출 (n이 줄어듦) }

팩토리얼 재귀 — n! = n × (n-1)!

팩토리얼은 재귀로 표현하기 가장 쉬운 예입니다. 5! = 5 × 4!, 4! = 4 × 3!, ... 처럼 자기 자신으로 정의됩니다.

int factorial(int n) { if (n <= 1) return 1; // 기저 조건 return n * factorial(n - 1); // 재귀 호출 } // factorial(4) = 4 × 3 × 2 × 1 = 24

핵심 요약

  • 재귀: 함수가 자기 자신을 호출하는 것.
  • 기저 조건(Base Case): 재귀를 멈추는 조건. 없으면 무한 호출.
  • 각 재귀 호출은 문제를 조금씩 작게 만들어야 합니다.
  • 팩토리얼: n! = n × (n-1)! — 재귀의 대표 예시.
  • 재귀는 반복문으로 바꿀 수 있습니다 (U10에서 비교).
