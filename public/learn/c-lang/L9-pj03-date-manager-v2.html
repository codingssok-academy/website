날짜 관리자 — 날짜 구조체와 요일 계산

Date 구조체로 날짜를 표현하고, 두 날짜의 차이와 요일을 계산합니다. Zeller 공식으로 요일을 구합니다.

프로젝트 목표

  • Date 구조체(year, month, day)를 정의합니다.
  • 날짜를 연도 내 일수(Day of Year)로 변환합니다.
  • 두 날짜 사이의 차이를 일 수로 계산합니다.
  • Zeller 공식으로 요일을 계산합니다.

구현 코드

#include <stdio.h> typedef struct { int year, month, day; } Date; int isLeapYear(int y) { return (y%4==0 && y%100!=0) || (y%400==0); } int daysInMonth(int y, int m) { int days[] = {0,31,28,31,30,31,30, 31,31,30,31,30,31}; if (m==2 && isLeapYear(y)) return 29; return days[m]; } int dayOfYear(Date d) { int total = d.day; for (int m = 1; m < d.month; m++) total += daysInMonth(d.year, m); return total; } const char *weekday(Date d) { // Zeller 공식 (간략화) int y = d.year, m = d.month, day = d.day; if (m < 3) { m += 12; y--; } int k = y % 100, j = y / 100; int h = (day + (13*(m+1)/5) + k + k/4 + j/4 - 2*j) % 7; const char *days[] = {"토","일","월","화","수","목","금"}; return days[((h+6)%7)]; } int main() { Date d1 = {2026, 3, 27}; Date d2 = {2026, 1, 1}; printf("%d/%d/%d (%s)\n", d1.year, d1.month, d1.day, weekday(d1)); printf("연내 %d번째 날\n", dayOfYear(d1)); printf("두 날짜 차이: %d일\n", dayOfYear(d1) - dayOfYear(d2)); return 0; }

날짜 유효성 검사
입력받은 Date가 유효한지 확인하는 함수 isValidDate를 작성하세요. (month 1~12, day 1~해당월 일수)
int isValidDate(Date d) { if (d.month < 1 || d.month > 12) return 0; if (d.day < 1 || d.day > daysInMonth(d.year, d.month)) return 0; return 1; }
