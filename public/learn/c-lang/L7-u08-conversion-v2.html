문자열 변환
— atoi와 sprintf

문자열을 정수로, 정수를 문자열로 변환하는 atoi, atof, sprintf를 배웁니다.

이 유닛에서 배우는 것

  • atoi로 문자열 "123"을 정수 123으로 변환할 수 있습니다.
  • atof로 문자열 "3.14"를 실수로 변환할 수 있습니다.
  • sprintf로 정수나 실수를 문자열로 만들 수 있습니다.
  • 숫자 문자와 숫자의 차이('3' vs 3)를 이해합니다.
  • scanf로 숫자를 입력받을 때와 문자열로 받는 차이를 압니다.

atoi — 문자열을 정수로

사용자가 키보드로 입력한 숫자는 문자열입니다. "123"은 문자 '1','2','3'으로 이루어진 배열이지, 정수 123이 아닙니다. atoi로 변환해야 계산에 쓸 수 있습니다.

#include <stdio.h> #include <stdlib.h> // atoi, atof 포함 int main() { char numStr[] = "123"; int n = atoi(numStr); printf("%d + 1 = %d\n", n, n + 1); // 124 // atof — 실수 변환 char fStr[] = "3.14"; double f = atof(fStr); printf("%.2f\n", f); // 3.14 // 숫자가 아닌 문자열 → 0 반환 printf("%d\n", atoi("abc")); // 0 printf("%d\n", atoi("12abc")); // 12 (앞부분까지) return 0; }

sprintf — 정수를 문자열로

sprintf(str, 형식, 값)은 printf처럼 형식에 따라 값을 조합하되, 화면이 아닌 문자열 배열에 저장합니다.

#include <stdio.h> int main() { char buf[50]; int score = 95; // 정수 → 문자열 sprintf(buf, "%d", score); printf("문자열: '%s'\n", buf); // '95' // 복합 문자열 조합 sprintf(buf, "점수: %d점 (%s)", score, score >= 90 ? "우수" : "보통"); printf("%s\n", buf); // 점수: 95점 (우수) return 0; }

문자 vs 숫자 차이 — '3' vs 3

문자 '3'의 ASCII 값은 51입니다. 정수 3과 다릅니다. 이 차이를 이해해야 문자열에서 숫자를 올바르게 변환할 수 있습니다.

#include <stdio.h> int main() { char c = '3'; int n = 3; printf("'3' + 1 = %d\n", c + 1); // 52 (ASCII 51+1) printf("3 + 1 = %d\n", n + 1); // 4 // 문자 숫자를 정수로: '3' - '0' = 3 int digit = c - '0'; // 51 - 48 = 3 printf("변환: %d\n", digit); // 3 return 0; }

핵심 정리

핵심 요약

  • atoi(str): 문자열을 정수로 변환. 숫자가 아니면 0 반환.
  • atof(str): 문자열을 실수(double)로 변환합니다.
  • sprintf(buf, fmt, ...): printf처럼 형식화해 문자열에 저장.
  • '3' - '0' = 3 — 한 자리 문자 숫자를 정수로 변환하는 트릭.
  • atoi, atof는 stdlib.h에, sprintf는 stdio.h에 있습니다.

전체 예제 — 성적 처리 시스템

#include <stdio.h> #include <stdlib.h> #include <string.h> int main() { char score_str[10]; char result[50]; char name[20]; printf("이름: "); scanf("%s", name); printf("점수: "); scanf("%s", score_str); int score = atoi(score_str); char *grade; if (score >= 90) grade = "A"; else if (score >= 80) grade = "B"; else if (score >= 70) grade = "C"; else grade = "F"; sprintf(result, "%s: %d점 (%s등급)", name, score, grade); printf("\n%s\n", result); return 0; }
