Project 03

시간표 출력기

요일별 수업을 printf와 탭으로 정렬된 시간표로 출력합니다.

프로젝트 목표

  • \t로 표 형태의 출력을 만들 수 있습니다.
  • 헤더 행(제목 줄)과 데이터 행을 구분해 출력합니다.
  • 5일치 시간표를 완성합니다.
  • 자기 실제 시간표로 수정할 수 있습니다.
PROJECT 03

표 형식으로 출력하기

C언어로 표를 출력하려면 각 칸을 \t로 구분합니다. 제목 줄과 데이터 줄을 나눠서 작성합니다.

따라해보세요
1
시간표 헤더(제목 줄)를 출력해 보세요.
#include <stdio.h> int main() { printf("요일\t1교시\t2교시\t3교시\n"); printf("-----\t-----\t-----\t-----\n"); return 0; }
정렬된 표 헤더가 출력됩니다
2
월요일 수업을 추가해 보세요.
printf("월요일\t국어\t수학\t영어\n");
월요일 행이 추가됩니다
3
화요일도 추가해 보세요.
printf("화요일\t영어\t과학\t체육\n");
화요일 행이 추가됩니다
PROJECT 03

완성 코드 — 5일치 시간표

#include <stdio.h> int main() { printf("===== 1학년 1반 시간표 =====\n"); printf("요일\t1교시\t2교시\t3교시\n"); printf("-----\t-----\t-----\t-----\n"); printf("월요일\t국어\t수학\t영어\n"); printf("화요일\t영어\t과학\t체육\n"); printf("수요일\t수학\t국어\t음악\n"); printf("목요일\t과학\t미술\t수학\n"); printf("금요일\t체육\t영어\t국어\n"); printf("===========================\n"); return 0; }
Q1
시간표 행 완성하기
쉬움
목요일의 수업이 "사회, 음악, 수학" 일 때 printf를 완성하세요.
형식printf("목요일\t____\t____\t____\n");
내 답안
힌트 보기
앞에서 쓴 패턴과 동일합니다. \t로 과목을 구분합니다.
정답 보기
printf("목요일\t사회\t음악\t수학\n");
PROJECT 03

4교시까지 확장하기

3교시에서 4교시로 확장하려면 각 줄에 탭(\t)과 과목 하나만 추가하면 됩니다.

Q2
4교시 헤더 완성하기
쉬움
4교시까지 있는 시간표 헤더를 완성하세요.
형식printf("요일\t1교시\t2교시\t3교시\t____\n");
내 답안
힌트 보기
3교시 다음은 4교시입니다.
정답 보기
printf("요일\t1교시\t2교시\t3교시\t4교시\n");
Q3
도전: 실제 시간표 입력
보통
자기 학교의 실제 월요일 시간표를 printf로 출력하세요. (3교시 이상)
예시월요일 실제 수업 3개 이상 출력
내 답안
힌트 보기
수업 이름만 실제 것으로 바꾸면 됩니다.
정답 보기
// 예시 (학교마다 다름) printf("월요일\t국어\t수학\t영어\t과학\n");

핵심 요약

  • \t 탭으로 표의 각 칸을 구분한다
  • 헤더(제목) 행을 먼저 출력하고, 구분선 후 데이터를 출력한다
  • 열을 추가하려면 헤더와 모든 데이터 줄에 \t항목을 추가한다
  • 문자열 내용만 바꾸면 어떤 시간표든 만들 수 있다
  • 형식 통일이 표의 가독성을 결정한다
