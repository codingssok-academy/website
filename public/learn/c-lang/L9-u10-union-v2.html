공용체 union — 메모리 공유하기

union은 여러 멤버가 같은 메모리 공간을 공유합니다. 구조체와 비교하며 언제 union이 유용한지 이해해봅시다.

이 유닛에서 배우는 것

  • union이 struct와 어떻게 다른지 설명할 수 있습니다.
  • union 선언과 멤버 접근을 할 수 있습니다.
  • union의 크기가 가장 큰 멤버 크기임을 이해합니다.
  • 한 번에 하나의 멤버만 유효하다는 규칙을 알 수 있습니다.
  • union의 실용적 사용 사례를 이해합니다.

union(공용체) 기본 문법

union은 struct와 문법이 비슷하지만, 모든 멤버가 같은 메모리 주소를 공유합니다. 크기는 가장 큰 멤버의 크기와 같습니다.

union Data { int i; // 4 bytes float f; // 4 bytes char c; // 1 byte }; // sizeof(union Data) = 4 (가장 큰 멤버) union Data d; d.i = 65; printf("i = %d\n", d.i); // 65 printf("c = %c\n", d.c); // A (같은 메모리이므로 65=ASCII 'A') d.f = 3.14f; // 이제 f를 쓰면 i는 쓰레기값이 됨! printf("f = %.2f\n", d.f); // 3.14 printf("i = %d\n", d.i); // 쓰레기값 (부동소수점 비트 해석)

struct vs union 크기 비교

struct S { int i; float f; char c; }; union U { int i; float f; char c; }; printf("struct 크기: %zu\n", sizeof(struct S)); // 12 (패딩 포함) printf("union 크기: %zu\n", sizeof(union U)); // 4

실용적 사용: 다양한 타입을 하나의 공간에

통신 프로토콜, 하드웨어 레지스터, 다형적 데이터 구조에서 union이 자주 사용됩니다.

#include <stdio.h> typedef union { unsigned int raw; // 4 bytes 전체 unsigned char bytes[4]; // 바이트 단위 접근 } IpAddress; int main() { IpAddress ip; ip.raw = 0xC0A80001; // 192.168.0.1 (빅엔디안 기준) printf("IP: %d.%d.%d.%d\n", ip.bytes[3], ip.bytes[2], ip.bytes[1], ip.bytes[0]); // 시스템에 따라 다름 return 0; }

핵심 정리

핵심 정리

  • union은 모든 멤버가 같은 메모리 주소를 공유합니다.
  • 크기 = 가장 큰 멤버의 크기
  • 한 번에 하나의 멤버만 의미 있는 값을 가집니다.
  • struct는 멤버별 독립 공간, union은 공유 공간
  • 주로 메모리 절약, 타입 재해석, 프로토콜 처리에 사용합니다.
