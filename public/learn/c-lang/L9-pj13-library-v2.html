도서관 시스템 — 대출/반납/검색

LibBook 구조체로 도서와 대출 상태를 관리합니다. 대출/반납 시 상태가 변경되고, 대출 중인 책만 따로 조회할 수 있습니다.

프로젝트 목표

  • LibBook 구조체(제목/저자/isLoaned/대출자/반납기한)를 정의합니다.
  • 책을 대출하는 함수(loanBook)를 구현합니다.
  • 책을 반납하는 함수(returnBook)를 구현합니다.
  • 대출 중인 책 목록을 출력하는 함수를 구현합니다.

구현 코드

#include <stdio.h> #include <string.h> #define N 4 typedef struct { char title[40]; char author[20]; int isLoaned; // 0=대출가능, 1=대출중 char borrower[20]; // 대출자 이름 char dueDate[12]; // 반납기한 "YYYY-MM-DD" } LibBook; void printBook(const LibBook *b) { if (b->isLoaned) printf("[대출중] %-15s | %s | 반납: %s\n", b->title, b->borrower, b->dueDate); else printf("[가 능] %-15s | %s\n", b->title, b->author); } int loanBook(LibBook *b, const char *borrower, const char *due) { if (b->isLoaned) { printf("\"%s\" 이미 대출 중입니다.\n", b->title); return 0; } b->isLoaned = 1; strcpy(b->borrower, borrower); strcpy(b->dueDate, due); printf("\"%s\" 대출 완료 → %s (반납: %s)\n", b->title, borrower, due); return 1; } int returnBook(LibBook *b) { if (!b->isLoaned) { printf("\"%s\" 대출된 책이 아닙니다.\n", b->title); return 0; } printf("\"%s\" 반납 완료 (%s)\n", b->title, b->borrower); b->isLoaned = 0; b->borrower[0] = '\0'; b->dueDate[0] = '\0'; return 1; } void listLoaned(const LibBook arr[], int n) { printf("\n=== 대출 중인 책 ===\n"); int count = 0; for (int i = 0; i < n; i++) if (arr[i].isLoaned) { printBook(&arr[i]); count++; } if (!count) printf("없음\n"); } int main() { LibBook shelf[N] = { {"C언어 기초", "홍길동", 0, "", ""}, {"Python입문", "김철수", 0, "", ""}, {"알고리즘", "이영희", 0, "", ""}, {"자료구조", "박민수", 0, "", ""} }; loanBook(&shelf[0], "김민준", "2026-04-10"); loanBook(&shelf[2], "이서연", "2026-04-05"); loanBook(&shelf[0], "박지호", "2026-04-15"); // 중복 대출 listLoaned(shelf, N); returnBook(&shelf[0]); listLoaned(shelf, N); return 0; }

도전 과제

도전 과제

  • 대출자 이름으로 해당 사람이 빌린 책 목록을 출력해보세요.
  • 반납기한이 지난 책을 찾아 연체 안내를 출력해보세요.
  • 제목으로 책을 검색하는 함수를 만들어보세요.

구조 분석

이 프로젝트에서 isLoaned 플래그(0/1)와 빈 문자열("")을 사용해 상태를 관리합니다. 반납 시 borrower[0] = '\0'으로 문자열을 비우는 방법을 사용합니다.
