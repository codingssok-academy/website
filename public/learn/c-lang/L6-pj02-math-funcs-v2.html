int를 반환하는 함수

사칙연산 결과는 숫자이므로 int를 반환합니다. return 키워드로 계산 결과를 돌려줍니다.

int add(int a, int b)
a + b 결과를 반환
int sub(int a, int b)
a - b 결과를 반환
int mul(int a, int b)
a * b 결과를 반환
int div(int a, int b)
a / b 결과를 반환 (b≠0 확인 필요)
// 덧셈 함수 int add(int a, int b) { return a + b; } // 뺄셈 함수 int sub(int a, int b) { return a - b; } // 곱셈 함수 int mul(int a, int b) { return a * b; } // 나눗셈 함수 — 0으로 나누기 체크! int divFunc(int a, int b) { if (b == 0) { printf("오류: 0으로 나눌 수 없습니다!\n"); return 0; } return a / b; }

switch로 연산 선택

switch 문은 여러 경우 중 하나를 선택할 때 씁니다. 사용자가 입력한 연산자(+,-,*,/)에 따라 다른 함수를 호출합니다.

실습 구역
따라해보세요
1
함수 4개를 작성하고 int result = add(10, 3); 후 출력해 보세요.
13이 출력됩니다

사칙연산 함수 — 전체 코드

/* ====== 사칙연산 함수 계산기 ====== */ #include <stdio.h> int add(int a, int b) { return a + b; } int sub(int a, int b) { return a - b; } int mul(int a, int b) { return a * b; } int divFunc(int a, int b) { if (b == 0) { printf("오류: 0으로 나눌 수 없습니다!\n"); return 0; } return a / b; } int main() { int a, b, result; char op; printf("첫 번째 수: "); scanf("%d", &a); printf("연산자(+,-,*,/): "); scanf(" %c", &op); printf("두 번째 수: "); scanf("%d", &b); switch (op) { case '+': result = add(a, b); printf("%d + %d = %d\n", a, b, result); break; case '-': result = sub(a, b); printf("%d - %d = %d\n", a, b, result); break; case '*': result = mul(a, b); printf("%d * %d = %d\n", a, b, result); break; case '/': result = divFunc(a, b); printf("%d / %d = %d\n", a, b, result); break; default: printf("알 수 없는 연산자입니다.\n"); } return 0; }
주의: C의 표준 라이브러리에는 div라는 함수가 이미 있습니다. 그래서 함수 이름을 divFunc로 짓는 것이 안전합니다.

연습 문제

1
switch 빈칸 채우기
쉬움
아래 코드에서 빈칸 ___를 채우세요.
case ___: result = sub(a, b); break;
(뺄셈을 선택하는 case)
정답 보기
정답: case '-': — 문자는 작은따옴표로 감쌉니다.
2
나머지 연산 함수 추가
쉬움
int modFunc(int a, int b) 함수를 작성하고, switch에 case '%':를 추가하세요.
정답 보기
int modFunc(int a, int b) { if (b == 0) { printf("오류!\n"); return 0; } return a % b; }
3
break 없을 때
보통
switch에서 break를 빼면 어떻게 될까요? case '+'에서 break를 지우면?
정답 보기
fall-through 현상 — case '+'가 실행된 후 case '-' 코드도 이어서 실행됩니다. break는 switch를 탈출하는 역할을 합니다.
4
double 버전으로 업그레이드
어려움
int 대신 double을 사용하는 사칙연산 함수 4개를 다시 작성하세요. double add(double a, double b) 형식으로.
힌트 보기
int를 double로만 바꾸면 됩니다. printf에서는 %f 또는 %.2f를 사용하세요.
핵심 정리

핵심 정리

  • int 함수명(int a, int b) { return a + b; } — 반환값 있는 함수
  • switch(op) { case '+': ... break; } — 문자로 연산 선택
  • 나눗셈 전 반드시 if(b == 0) 체크
  • break 빠지면 다음 case로 fall-through 발생
