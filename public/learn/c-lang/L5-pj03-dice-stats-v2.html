주사위 통계 프로그램

주사위를 100번 굴려 1~6이 각각 몇 번 나왔는지 배열로 카운트하고 막대 그래프로 출력합니다.

이 프로젝트에서 배우는 것

  • rand()와 srand()로 난수를 생성하는 방법을 배웁니다.
  • 배열 인덱스를 활용한 빈도 카운트 기법을 익힙니다.
  • for문으로 텍스트 막대 그래프를 출력합니다.
  • 배열 값과 인덱스의 관계를 활용합니다.

난수(Random Number) 생성하기

C언어에서 난수를 만들려면 rand() 함수를 씁니다. 1~6 사이의 주사위 값은 rand() % 6 + 1로 구합니다.

#include <stdlib.h> // rand(), srand() #include <time.h> // time() srand(time(NULL)); // 프로그램 시작 시 한 번만 호출 int dice = rand() % 6 + 1; // 1~6 사이 랜덤 printf("주사위: %d\n", dice);

빈도 카운트 — 배열 인덱스 활용

주사위 값 1~6을 배열 인덱스로 바로 사용합니다. count[dice]++ 한 줄로 해당 눈의 카운트를 증가시킵니다.

int count[7] = {0}; // [0]은 사용 안 함, 전부 0으로 초기화 for (int i = 0; i < 100; i++) { int dice = rand() % 6 + 1; count[dice]++; // 해당 눈의 카운트 +1 }

각 눈의 카운트가 배열에 저장됩니다

텍스트 막대 그래프 출력

각 눈의 빈도만큼 별표(*)를 출력해 텍스트 막대 그래프를 만듭니다. for문 안에 for문을 중첩합니다.

printf("\n=== 주사위 통계 (100회) ===\n"); for (int i = 1; i <= 6; i++) { printf("%d눈: ", i); for (int j = 0; j < count[i]; j++) { printf("*"); } printf(" (%d회)\n", count[i]); }

완성 코드

#include <stdio.h> #include <stdlib.h> #include <time.h> int main() { srand(time(NULL)); int count[7] = {0}; for (int i = 0; i < 100; i++) count[rand() % 6 + 1]++; printf("=== 주사위 통계 ===\n"); for (int i = 1; i <= 6; i++) { printf("%d눈: ", i); for (int j = 0; j < count[i]; j++) printf("*"); printf(" (%d회)\n", count[i]); } return 0; }

쉬움
100번 굴린 결과에서 가장 많이 나온 눈(1~6)과 그 횟수를 출력하세요.

int maxCnt=count[1], maxEye=1; for(int i=2;i<=6;i++) if(count[i]>maxCnt){maxCnt=count[i];maxEye=i;} printf("최다: %d (%d회)\n",maxEye,maxCnt);

3
1000번 시뮬레이션
쉬움
100번 대신 1000번으로 늘려서 실행해보세요. 각 눈의 비율이 약 16.7%에 가까워지는지 확인하세요.
이론값각 눈 1000/6 ≈ 167회
힌트 보기
for문의 반복 횟수만 100에서 1000으로 바꾸면 됩니다. 큰수의 법칙(Law of Large Numbers)을 직접 확인하는 실험입니다.

핵심 정리

  • rand() % 6 + 1 → 1~6 범위 난수 생성
  • srand(time(NULL)) → 매 실행마다 다른 난수
  • count[dice]++ → 인덱스=값 으로 직접 카운트
  • 배열 크기 7 (인덱스 0~6, 0은 미사용)
  • 중첩 for문으로 텍스트 막대 그래프 출력
