학생 성적표

5명 × 3과목 2차원 배열로 성적을 관리하고, 각 학생의 평균, 등급, 석차를 계산해 성적표를 출력합니다.

이 프로젝트에서 배우는 것

  • 5×3 2차원 배열로 여러 학생의 다과목 성적을 관리합니다.
  • 평균 계산 후 등급을 부여하는 로직을 구현합니다.
  • 전체 평균을 비교해 석차를 계산합니다.
  • 표 형식으로 성적표를 출력합니다.

성적 데이터 설계

학생 이름 배열과 점수 2차원 배열을 같은 행 인덱스로 연결합니다. score[학생][과목] 구조입니다.

char *names[5] = {"김민준","이서연","박도현","최유나","정하은"}; char *subjects[3] = {"국어", "수학", "영어"}; int score[5][3] = { {85, 92, 88}, // 김민준 {95, 90, 96}, // 이서연 {72, 68, 75}, // 박도현 {88, 85, 82}, // 최유나 {78, 80, 76} // 정하은 };

평균 계산 & 등급 부여

float avg[5]; // 각 학생 평균 char grade[5]; // 각 학생 등급 for (int i=0;i<5;i++) { int sum=0; for (int j=0;j<3;j++) sum += score[i][j]; avg[i] = (float)sum / 3; if (avg[i]>=90) grade[i]='A'; else if(avg[i]>=80) grade[i]='B'; else if(avg[i]>=70) grade[i]='C'; else if(avg[i]>=60) grade[i]='D'; else grade[i]='F'; }

석차 계산 & 완성 출력

석차는 "나보다 평균이 높은 학생 수 + 1"입니다. 각 학생에 대해 모든 학생과 비교합니다.

int rank[5]; for (int i=0;i<5;i++) { rank[i] = 1; for (int j=0;j<5;j++) if (avg[j] > avg[i]) rank[i]++; } // 성적표 출력 printf("%-8s %4s %4s %4s %6s %4s %4s\n", "이름","국어","수학","영어","평균","등급","석차"); printf("----------------------------------\n"); for (int i=0;i<5;i++) { printf("%-8s %4d %4d %4d %6.1f %4c %4d\n", names[i],score[i][0],score[i][1],score[i][2], avg[i],grade[i],rank[i]); }

핵심 정리

  • score[학생][과목] — 행=학생, 열=과목
  • 행 합계: 내부 for로 열(j) 순회 → 학생 합계
  • 열 합계: 내부 for로 행(i) 순회 → 과목 합계
  • 석차: "나보다 큰 수 개수 + 1"
  • 등급: if-else if 체인, 내림차순 조건 순서 중요

심화 — 정렬된 석차표 출력

평균 기준 내림차순으로 정렬해 석차 순서대로 출력하는 코드를 작성합니다. 인덱스 배열을 정렬합니다.

// 인덱스 배열: order[0]=1(이서연=1등), order[1]=0(김민준=2등)... int order[5] = {0, 1, 2, 3, 4}; // 버블 정렬로 avg 기준 내림차순 정렬 for (int i=0;i<4;i++) for (int j=0;j<4-i;j++) if (avg[order[j]] < avg[order[j+1]]) { int tmp=order[j]; order[j]=order[j+1]; order[j+1]=tmp; } printf("=== 석차 순 성적표 ===\n"); for (int i=0;i<5;i++) { int idx=order[i]; printf("%d위: %-8s %.1f점 %c\n",i+1,names[idx],avg[idx],grade[idx]); }
