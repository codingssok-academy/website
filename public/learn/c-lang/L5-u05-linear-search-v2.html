Chapter L5-05

배열 검색 —
선형 탐색

배열에서 원하는 값을 앞에서부터 하나씩 비교하며 찾는 선형 탐색을 배웁니다. for + if + break 패턴과 -1 반환 관례를 익힙니다.

이 유닛에서 배우는 것

  • 선형 탐색의 개념과 동작 방식을 설명할 수 있습니다.
  • for + if 패턴으로 배열에서 값을 찾을 수 있습니다.
  • break로 불필요한 반복을 줄이는 이유를 이해합니다.
  • 찾은 경우는 인덱스, 못 찾은 경우는 -1을 반환하는 패턴을 익힙니다.
  • 선형 탐색을 다양한 상황에 응용할 수 있습니다.

선형 탐색이란?

선형 탐색(Linear Search)은 배열의 첫 번째 원소부터 마지막 원소까지 순서대로 하나씩 비교하며 원하는 값을 찾는 방법입니다. 구조가 단순해 처음 배우기에 좋습니다.

못 찾았을 때: -1 반환 패턴

배열에 원하는 값이 없으면 끝까지 다 돌고 -1을 반환합니다. -1은 유효한 인덱스가 아니므로 "없음"을 뜻하는 관례입니다.

왜 -1인가: 배열 인덱스는 항상 0 이상입니다. 따라서 -1은 절대 유효한 인덱스가 될 수 없으므로, "못 찾음" 신호로 쓰기에 딱 좋습니다.

선형 탐색 코드 구조

핵심 패턴: result = -1로 시작 → for로 순회 → if로 비교 → 찾으면 break

// ① 선형 탐색 — 기본 구조 int arr[] = {3, 7, 1, 9, 4, 2}; int size = 6; int target = 9; int result = -1; // 못 찾으면 -1 유지 for (int i = 0; i < size; i++) { if (arr[i] == target) { result = i; // 인덱스 저장 break; // 더 볼 필요 없음 } } if (result != -1) printf("찾음! 인덱스: %d\n", result); else printf("없음\n");

완성 코드 — 전체 실행 예제

#include <stdio.h> int main() { int scores[] = {72, 85, 91, 60, 78}; int size = 5; int target = 91; int result = -1; for (int i = 0; i < size; i++) { printf("비교: scores[%d] = %d\n", i, scores[i]); if (scores[i] == target) { result = i; break; } } if (result != -1) printf("91점은 인덱스 %d에 있습니다.\n", result); else printf("91점 없음\n"); return 0; }

선형 탐색 응용 — 중복값, 최솟값

선형 탐색 패턴을 확장하면 중복 검색, 최솟값 찾기 등 다양한 문제를 풀 수 있습니다.

첫 번째 vs 모든 위치 찾기

첫 번째 위치만
// break 사용 → 첫 번째만 int result = -1; for (int i = 0; i < n; i++) { if (arr[i] == target) { result = i; break; } }
모든 위치 출력
// break 없음 → 전부 찾기 for (int i = 0; i < n; i++) { if (arr[i] == target) { printf("%d ", i); } }

최솟값 찾기 (선형 탐색 응용)

int arr[] = {8, 3, 6, 1, 5}; int size = 5; int minVal = arr[0]; // 첫 원소를 초기 최솟값으로 int minIdx = 0; for (int i = 1; i < size; i++) { if (arr[i] < minVal) { minVal = arr[i]; minIdx = i; } } printf("최솟값: %d (인덱스 %d)\n", minVal, minIdx);

패턴 공통점: 모든 경우가 배열을 앞에서 뒤로 한 번 훑습니다. 이 "한 번 훑기" 패턴이 선형 탐색의 핵심입니다.

핵심 정리

  • 선형 탐색: 배열을 앞에서 뒤로 하나씩 비교
  • result = -1로 초기화 → 찾으면 인덱스 저장 → break
  • break 없으면 모든 위치 검색 가능
  • -1은 "유효하지 않은 인덱스" = 못 찾음 신호
  • 응용: 최솟값/최댓값, 중복 검색, 조건 검색
