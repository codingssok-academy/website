단어 뒤집기

char 배열로 문자열을 저장하고, 앞뒤를 swap하는 방식으로 단어를 뒤집는 프로그램을 만듭니다.

이 프로젝트에서 배우는 것

  • char 배열로 문자열을 저장하는 방법을 배웁니다.
  • strlen()로 문자열 길이를 구합니다.
  • 두 값을 교환하는 swap 알고리즘을 익힙니다.
  • 배열 양 끝에서 중앙으로 좁혀오는 패턴을 이해합니다.

char 배열과 문자열

C언어에서 문자열은 char 배열로 저장합니다. 문자열 끝에는 자동으로 null 문자('\0')가 붙습니다.

#include <string.h> // strlen 사용 char str[100]; printf("단어 입력: "); scanf("%s", str); // 공백 없는 단어 입력 int len = strlen(str); // 문자열 길이 (null 제외) printf("길이: %d\n", len); // "hello" → 5

swap으로 뒤집기

앞 인덱스(left)와 뒤 인덱스(right)를 가운데로 좁혀가며 두 문자를 교환합니다. left < right인 동안 반복합니다.

int left = 0, right = len - 1; while (left < right) { char tmp = str[left]; // 임시 저장 str[left] = str[right]; str[right] = tmp; left++; right--; }

완성 코드

#include <stdio.h> #include <string.h> int main() { char str[100]; printf("단어 입력: "); scanf("%s", str); int len = strlen(str); int left = 0, right = len - 1; while (left < right) { char tmp = str[left]; str[left++] = str[right]; str[right--] = tmp; } printf("뒤집기 결과: %s\n", str); return 0; }

핵심 정리

  • char 배열 선언: char str[100], 입력: scanf("%s", str)
  • strlen(str) — 문자열 길이 반환 (null 제외)
  • swap 패턴: tmp = a; a = b; b = tmp;
  • 양끝 좁히기: left=0, right=len-1, while(left<right)
  • ASCII: 대문자 A=65, 소문자 a=97, 차이는 32
