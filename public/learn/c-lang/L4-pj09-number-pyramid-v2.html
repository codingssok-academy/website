숫자 피라미드

중첩 for문으로 숫자를 쌓아 피라미드 모양을 만듭니다. 별 찍기에서 한 단계 더 나아가 숫자 패턴을 다룹니다.

이 프로젝트에서 배우는 것

  • 중첩 for문으로 숫자 피라미드(1, 12, 123...)를 출력할 수 있습니다.
  • 역 피라미드(12345, 1234...)와 다이아몬드 패턴도 구현할 수 있습니다.
  • 홀수만 출력하는 조건 패턴을 활용할 수 있습니다.
  • 안쪽 루프 변수(j)를 직접 출력하는 방법을 익힙니다.

숫자 피라미드 — 기본 코드

별 찍기 패턴과 구조는 같습니다. 다른 점은 printf("*") 대신 printf("%d", j)로 안쪽 루프 변수 j를 출력한다는 것입니다. j는 1부터 증가하므로 자연스럽게 1, 2, 3... 이 찍힙니다.

// 숫자 피라미드 (5줄) int i, j; for (i = 1; i <= 5; i++) { for (j = 1; j <= i; j++) { printf("%d", j); // j를 출력 (1, 2, 3...) } printf("\n"); }

확장 1 — 역 피라미드

바깥 루프를 n에서 1로 감소시키면 역 피라미드가 됩니다. 별 역삼각형과 완전히 같은 원리입니다.

// 역 피라미드 (5줄) int i, j, n = 5; for (i = n; i >= 1; i--) { // 5→1 감소 for (j = 1; j <= i; j++) { printf("%d", j); } printf("\n"); }

확장 2 — 다이아몬드 숫자 패턴

피라미드(위쪽)와 역 피라미드(아래쪽)를 합치면 다이아몬드가 됩니다. 두 for문을 이어서 작성합니다. 겹치는 중간 행이 생기지 않도록 아래쪽은 n-1 부터 시작합니다.

// 다이아몬드 숫자 (n=5) int i, j, n = 5; // 위쪽 반: 1 → n for (i = 1; i <= n; i++) { for (j = 1; j <= i; j++) printf("%d", j); printf("\n"); } // 아래쪽 반: n-1 → 1 for (i = n - 1; i >= 1; i--) { for (j = 1; j <= i; j++) printf("%d", j); printf("\n"); }

확장 3 — 홀수만 피라미드

안쪽 루프에서 if (j % 2 != 0) 조건을 추가하면, 홀수 번호(1, 3, 5, 7, 9)만 출력할 수 있습니다. 또는 j += 2로 홀수만 순회하는 방법도 있습니다.

// 홀수만 피라미드 (방법 1: if 조건) for (i = 1; i <= 5; i++) { for (j = 1; j <= i; j++) { if (j % 2 != 0) { // 홀수만 출력 printf("%d", j); } } printf("\n"); } // 홀수만 피라미드 (방법 2: j+=2) for (i = 1; i <= 5; i++) { for (j = 1; j <= i; j += 2) { // 1, 3, 5... printf("%d", j); } printf("\n"); }

핵심 정리

  • 숫자 피라미드 = 별 찍기 구조 + printf("%d", j) 로 j 출력
  • 역 피라미드: 바깥 루프 i=n~1 감소 (안쪽 동일)
  • 다이아몬드: 피라미드(i=1~n) + 역피라미드(i=n-1~1) 연결
  • 홀수 피라미드: j % 2 != 0 조건 또는 j+=2 증가
  • 짝수 피라미드: j % 2 == 0 조건 또는 j=2, j+=2
  • 안쪽 루프 변수 j를 출력하면 자동으로 1, 2, 3... 순서
