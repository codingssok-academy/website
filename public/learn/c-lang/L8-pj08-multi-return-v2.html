CHAPTER 8 PROJECT 08
min, max, avg
동시 반환
Return min, max, avg Simultaneously
배열 한 번 순회로 최솟값, 최댓값, 평균을 동시에 계산한다.
세 결과를 포인터 매개변수로 호출자에게 전달 — 이것이 C의 다중 반환 패턴이다.
난이도 배열 1회 순회 3가지 동시 계산 double 평균 처리
완성 코드
stats.c #include <stdio.h>

/* 배열 한 번 순회로 min, max, avg 동시 계산 */
void stats(int *arr, int n,
         int *mn, int *mx, double *avg) {
    *mn = arr[0]; // 첫 원소로 초기화
    *mx = arr[0];
    int sum = 0;
    
    for (int i = 0; i < n; i++) {
        if (arr[i] < *mn) *mn = arr[i]; // 최솟값 갱신
        if (arr[i] > *mx) *mx = arr[i]; // 최댓값 갱신
        sum += arr[i];
    }
    
    *avg = (double)sum / n; // 형변환 후 나눗셈
}

int main() {
    int arr[] = {3, 1, 4, 1, 5, 9, 2, 6};
    int n = sizeof(arr) / sizeof(arr[0]);
    int min_val, max_val;
    double avg_val;
    
    stats(arr, n, &min_val, &max_val, &avg_val);
    
    printf("최솟값: %d\n", min_val);
    printf("최댓값: %d\n", max_val);
    printf("평균: %.2f\n", avg_val);
    return 0;
}
$ gcc stats.c -o stats && ./stats
최솟값: 1
최댓값: 9
평균: 3.88
평균 계산 주의: 정수 나눗셈 vs 실수 나눗셈
avg_warning.c /* 잘못된 평균 계산 */
int sum = 31;
int n = 8;
double avg1 = sum / n; // → 3.000000 (정수 나눗셈 후 대입!)
double avg2 = (double)sum / n; // → 3.875000 (올바른 방법)
double avg3 = sum / (double)n; // → 3.875000 (이것도 가능)
double avg4 = (double)(sum / n); // → 3.000000 (이미 정수 나눗셈 후 캐스팅)
핵심: (double)sum / n 에서 먼저 sum을 double로 변환 → sum/n 나눗셈이 실수 나눗셈이 된다. 괄호 위치가 결과를 완전히 바꾼다.
활용: 성적 통계 프로그램
grade_stats.c #include <stdio.h>

void grade_stats(int *scores, int n,
                 int *pass, int *fail, double *avg) {
    *pass = *fail = 0;
    int sum = 0;
    for (int i = 0; i < n; i++) {
        sum += *scores;
        if (*scores >= 60) (*pass)++; else (*fail)++;
        scores++;
    }
    *avg = (double)sum / n;
}

int main() {
    int scores[] = {85, 42, 73, 91, 55, 68};
    int pass, fail; double avg;
    grade_stats(scores, 6, &pass, &fail, &avg);
    printf("합격: %d명, 불합격: %d명, 평균: %.1f\n", pass, fail, avg);
    return 0;
}
$ ./grade_stats
합격: 4명, 불합격: 2명, 평균: 69.0
도전 과제

도전 과제

1 중앙값 추가: stats 함수에 중앙값을 반환하는 *median 파라미터를 추가하라. 배열 정렬 후 중간 인덱스 값.
2 표준편차: avg를 먼저 구한 뒤, 다시 순회하여 분산(variance)과 표준편차(stddev)를 계산하는 함수를 작성하라.
3 성적 분포: A(90+), B(80~89), C(70~79), D(60~69), F(60 미만) 각 개수를 포인터로 반환하는 함수를 작성하라.
연습문제
1 *avg = (double)sum / n에서 (double) 캐스팅 없이 쓰면 어떤 결과가 나오는가?
sum과 n이 모두 int이면 sum/n은 정수 나눗셈. 결과도 int (소수점 버림). 이후 *avg에 대입할 때 정수 → double 변환이 되지만 이미 소수점이 사라졌다. 예: 31/8 = 3 (정수), *avg = 3.0.
2 *mn = arr[0] 초기화가 필요한 이유는? *mn = 0으로 하면 안 되는가?
*mn = 0으로 초기화하면 배열의 모든 값이 양수일 때 최솟값이 항상 0이 된다 (arr의 실제 최솟값보다 작음). 첫 원소로 초기화해야 실제 최솟값을 찾을 수 있다. 음수 배열에서는 특히 중요하다.
3 stats 함수에서 n=0을 전달하면 어떤 문제가 발생하는가?
*avg = (double)sum / n에서 0으로 나누기 = 정의되지 않은 동작(UB). 실행 시 프로그램 충돌. 방어적으로 if (n == 0) { *mn = *mx = 0; *avg = 0.0; return; } 처리가 필요하다.
4 포인터 매개변수 방식과 구조체 반환 방식 중 어느 것이 더 좋은가?
구조체 반환: 코드가 더 깔끔하고 실수 줄어듦. 단, 구조체 복사 오버헤드.
포인터 매개변수: 복사 없이 직접 저장. NULL 전달로 일부 결과 무시 가능. C 표준 라이브러리에서 널리 사용.
최신 C/C++ 실무에서는 구조체 반환이 선호되지만, 순수 C 교육에서는 포인터 방식이 중요하다.
5 grade_stats에서 (*pass)++ 대신 *pass++를 쓰면 어떻게 되는가?
*pass++는 *(pass++)로 해석 — pass 포인터 자체가 다음 주소로 이동하고, 역참조는 이전 주소에서 읽은 값. pass 카운터가 증가하는 게 아니라 포인터가 엉뚱한 메모리를 가리키게 된다. (*pass)++로 괄호를 써야 한다.

이번 프로젝트 핵심

  • 배열 한 번 순회로 여러 통계 값 동시 계산 — O(n) 효율
  • min, max는 첫 원소로 초기화 (0이나 큰 값으로 하면 안 됨)
  • (double)sum / n — 형변환 위치가 결과를 결정한다
  • (*count)++ — 역참조 값 증가는 반드시 괄호 필요
