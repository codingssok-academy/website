온도 변환 공식

섭씨(Celsius)와 화씨(Fahrenheit)는 서로 변환할 수 있습니다. 공식을 그대로 코드로 옮기면 됩니다.

F = C × 9.0/5.0 + 32
섭씨 → 화씨
C = (F - 32) × 5.0/9.0
화씨 → 섭씨
주의: 정수 나눗셈 함정! 9/5는 1.8이 아니라 정수 1입니다! 반드시 9.0/5.0으로 써야 실수 계산이 됩니다.
// 섭씨 → 화씨 변환 함수 double toFahrenheit(double celsius) { return celsius * 9.0 / 5.0 + 32; } // 화씨 → 섭씨 변환 함수 double toCelsius(double fahrenheit) { return (fahrenheit - 32) * 5.0 / 9.0; }

소수점 출력 — %.1f

%f는 소수점 6자리까지 출력합니다. 온도는 소수점 1자리만 보여주면 깔끔합니다.

온도 변환기 — 전체 코드

/* ====== 온도 변환 함수 프로그램 ====== */ #include <stdio.h> double toFahrenheit(double celsius) { return celsius * 9.0 / 5.0 + 32; } double toCelsius(double fahrenheit) { return (fahrenheit - 32) * 5.0 / 9.0; } void printTempTable() { printf("=== 온도 변환표 ===\n"); printf("섭씨(C)\t화씨(F)\n"); printf("-----------------\n"); int c; for (c = 0; c <= 100; c += 10) { printf("%6.1f\t%6.1f\n", (double)c, toFahrenheit(c)); } } int main() { double input; int choice; printf("온도 변환기\n"); printf("1. 섭씨→화씨 2. 화씨→섭씨 3. 변환표 출력\n"); printf("선택: "); scanf("%d", &choice); if (choice == 1) { printf("섭씨 입력: "); scanf("%lf", &input); printf("%.1f°C = %.1f°F\n", input, toFahrenheit(input)); } else if (choice == 2) { printf("화씨 입력: "); scanf("%lf", &input); printf("%.1f°F = %.1f°C\n", input, toCelsius(input)); } else if (choice == 3) { printTempTable(); } else { printf("잘못된 선택입니다.\n"); } return 0; }
