*p = 10; 원본 변경
Call by Value vs Reference

포인터의 핵심 활용 — 함수에서 원본 값을 수정하는 방법을 배웁니다. 값 전달과 주소 전달의 차이를 이해합니다.

이 유닛에서 배우는 것

  • *p = 값; 으로 포인터를 통해 원본을 변경합니다.
  • Call by Value — 값을 복사해서 전달하는 방식을 이해합니다.
  • Call by Reference — 주소를 전달해 원본을 수정합니다.
  • 포인터 매개변수를 사용하는 함수를 작성합니다.
  • swap 함수를 포인터로 구현합니다.

Call by Value — 복사본만 바뀐다

함수에 변수를 그냥 넘기면 값의 복사본이 전달됩니다. 함수 안에서 값을 바꿔도 원본은 그대로입니다.

void double_val(int x) { // x는 a의 복사본 x = x * 2; // 복사본만 변경 printf("함수 안 x=%d\n", x); // 20 } int main() { int a = 10; double_val(a); // a를 복사해서 전달 printf("main의 a=%d\n", a); // 10 — 원본 그대로! return 0; }

Call by Reference — 주소로 원본을 바꾼다

함수에 변수의 주소를 넘기면, 함수 안에서 포인터로 원본에 직접 접근해 값을 변경할 수 있습니다.

void double_ref(int *p) { // p는 주소를 받음 *p = *p * 2; // 원본 직접 변경! printf("함수 안 *p=%d\n", *p); // 20 } int main() { int a = 10; double_ref(&a); // a의 주소 전달 printf("main의 a=%d\n", a); // 20 — 원본 바뀜! return 0; }

Call by Value vs Reference 비교

swap 함수 — 포인터의 대표 예제

두 변수의 값을 교환하는 swap 함수는 포인터 없이는 불가능합니다.

void swap(int *a, int *b) { int tmp = *a; // a가 가리키는 값 임시 저장 *a = *b; // b의 값을 a에 저장 *b = tmp; // tmp를 b에 저장 } int main() { int x = 10, y = 20; printf("전: x=%d, y=%d\n", x, y); // 10 20 swap(&x, &y); printf("후: x=%d, y=%d\n", x, y); // 20 10 return 0; }

*p로 연산 결과 저장

포인터 매개변수를 활용하면 함수가 여러 값을 "반환"할 수 있습니다.

// 포인터로 여러 결과 반환 void calc(int a, int b, int *sum, int *diff) { *sum = a + b; // sum이 가리키는 곳에 합 저장 *diff = a - b; // diff가 가리키는 곳에 차 저장 } int main() { int s, d; calc(10, 3, &s, &d); printf("합=%d, 차=%d\n", s, d); // 합=13, 차=7 return 0; }

핵심 정리

  • Call by Value: 값 복사 전달 → 원본 변경 불가
  • Call by Reference: 주소 전달 → *p로 원본 직접 변경 가능
  • 호출: f(&a), 매개변수: int *p, 사용: *p = 새값
  • swap 함수는 포인터의 가장 대표적인 활용 예제
  • 포인터 매개변수로 여러 결과를 함수에서 반환할 수 있음
