아스키 코드 탐험

문자를 입력하면 숫자 코드를 보여주고, 숫자를 입력하면 문자를 보여주는 변환기를 만듭니다. char와 int의 관계를 탐험합니다.

이 프로젝트에서 배우는 것

  • char 변수에 문자를 저장하고 %c로 출력할 수 있다
  • 같은 char 값을 %d로 출력하면 숫자(ASCII 코드)가 나온다
  • 숫자를 %c로 출력하면 해당 문자가 나온다
  • 대문자/소문자 간 ASCII 코드 차이(32)를 이해한다
  • 문자에 숫자를 더하는 연산을 할 수 있다

ASCII 코드란?

컴퓨터는 숫자만 이해합니다. 그래서 문자마다 고유한 숫자 번호를 매겨 놓았는데, 이것이 바로 ASCII(아스키) 코드입니다. 'A'는 65번, 'a'는 97번입니다.

C언어에서 char 변수는 문자를 저장하지만, 실제로는 숫자(ASCII 코드)가 저장됩니다. 같은 값을 %c로 출력하면 문자, %d로 출력하면 숫자가 나옵니다.

#include <stdio.h> int main(void) { char ch; int num; // 1. 문자 -> 숫자 printf("문자를 입력하세요: "); scanf("%c", &ch); printf("'%c'의 ASCII 코드: %d\n", ch, ch); // 버퍼 비우기 (Enter 키 제거) getchar(); // 2. 숫자 -> 문자 printf("숫자를 입력하세요 (65~122): "); scanf("%d", &num); printf("%d번 문자: %c\n", num, num); return 0; }

문자 연산의 비밀

char 변수에 숫자를 더하거나 빼면, ASCII 코드가 바뀌면서 다른 문자가 됩니다.

// 대문자를 소문자로 바꾸기 char upper = 'A'; char lower = upper + 32; printf("%c -> %c\n", upper, lower); // A -> a // 다음 알파벳 구하기 char ch = 'C'; printf("다음 문자: %c\n", ch + 1); // D

핵심 요약

  • char는 문자를 저장하지만, 실제로는 ASCII 숫자가 저장된다
  • %c는 문자로 출력, %d는 숫자(코드)로 출력한다
  • 대문자 + 32 = 소문자, 소문자 - 32 = 대문자
  • 'A'=65, 'a'=97, '0'=48이 기본 외울 숫자이다
  • 문자에 숫자를 더하면 다음 문자로 이동한다 ('A'+1 = 'B')
