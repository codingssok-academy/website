배열 크기와 sizeof
— 숫자를 직접 쓰지 않는 법

배열 크기를 코드에 직접 숫자로 쓰면(매직넘버) 나중에 바꿀 때 여러 곳을 수정해야 합니다. sizeof와 #define으로 한 곳만 바꾸면 전체가 바뀌게 만드는 법을 배웁니다.

이 유닛에서 배우는 것

  • sizeof(arr)가 배열 전체 바이트 크기임을 이해합니다.
  • sizeof(arr) / sizeof(arr[0])로 원소 개수를 구할 수 있습니다.
  • 매직넘버가 왜 나쁜지 설명할 수 있습니다.
  • #define SIZE 5 패턴으로 한 곳에서 크기를 관리할 수 있습니다.
  • 배열 크기 자동 계산 패턴을 실전에 적용할 수 있습니다.

sizeof — 바이트 크기를 알려주는 연산자

sizeof는 변수나 자료형이 메모리에서 몇 바이트를 차지하는지 알려줍니다. 배열 전체에 사용하면 전체 바이트 수를 반환합니다.

int arr[5] = {1, 2, 3, 4, 5}; printf("배열 전체 크기: %zu바이트\n", sizeof(arr)); // 출력: 20 (= 5 × 4바이트) printf("원소 하나 크기: %zu바이트\n", sizeof(arr[0])); // 출력: 4 (int 1개) int n = sizeof(arr) / sizeof(arr[0]); printf("원소 개수: %d\n", n); // 출력: 5
%zu 형식 지정자

sizeof의 반환형은 size_t라는 부호 없는 정수형입니다. 엄밀히는 %zu로 출력해야 합니다. 실무에서는 int로 캐스팅해서 %d를 쓰는 경우도 많습니다.

따라해보세요
1
크기 8인 int 배열의 sizeof 결과를 예측하고, 원소 개수를 구해보세요.
int a[8] = {0}; printf("전체: %zu바이트\n", sizeof(a)); // 32 printf("개수: %d\n", (int)(sizeof(a) / sizeof(a[0]))); // 8
전체: 32바이트, 개수: 8 이 출력됩니다

매직넘버 — 코드에 숫자를 직접 쓰지 말자

배열 크기 5를 코드 여러 곳에 직접 쓰면, 크기를 10으로 바꿀 때 모든 5를 찾아서 수정해야 합니다. 하나라도 놓치면 버그가 됩니다.

#define으로 상수 이름 만들기

#define은 코드 전처리 단계에서 이름을 값으로 대체합니다. 배열 크기를 하나의 이름으로 관리할 수 있습니다.

#define SIZE 5 // 위에 한 번만 정의 int arr[SIZE]; // = int arr[5] for (int i = 0; i < SIZE; i++) { // = i < 5 scanf("%d", &arr[i]); } int sum = 0; for (int i = 0; i < SIZE; i++) { sum += arr[i]; } printf("평균: %.1f\n", (double)sum / SIZE); // 이제 크기를 10으로 바꾸려면 #define SIZE 10 한 줄만 수정!
#define은 = 없이, 세미콜론도 없이!

#define SIZE = 5;라고 쓰면 SIZE가 = 5;로 치환돼 오류가 납니다. 반드시 #define SIZE 5 형태로 씁니다.

따라해보세요
1
#define으로 SIZE를 정의하고 배열을 선언한 뒤 for로 출력하세요.
#define SIZE 4 int a[SIZE] = {10, 20, 30, 40}; for (int i = 0; i < SIZE; i++) printf("%d\n", a[i]);
10, 20, 30, 40 차례로 출력됩니다

sizeof로 배열 크기 자동 계산

배열을 선언한 범위 안에서 sizeof를 쓰면 크기를 하드코딩하지 않아도 됩니다. 원소를 추가해도 코드가 자동으로 맞춰집니다.

종합 코드 — sizeof와 #define 함께 사용

#include <stdio.h> #define SIZE 5 int main() { int score[SIZE] = {85, 92, 78, 95, 88}; // sizeof로 원소 개수 계산 (선언 직후만 유효) int n = sizeof(score) / sizeof(score[0]); printf("원소 개수: %d\n", n); // 5 int sum = 0; for (int i = 0; i < SIZE; i++) { sum += score[i]; } printf("합계: %d\n", sum); printf("평균: %.1f\n", (double)sum / SIZE); return 0; }
따라해보세요
1
sizeof로 배열 원소 개수를 자동 계산하고 for 루프 조건에 사용하세요.
int a[] = {2, 4, 6, 8, 10}; int n = sizeof(a) / sizeof(a[0]); for (int i = 0; i < n; i++) printf("%d\n", a[i]);
2, 4, 6, 8, 10 차례로 출력됩니다
2
#define을 이용해 크기 3인 배열의 합계를 구하세요.
#define N 3 int b[N] = {1, 2, 3}; int s = 0; for (int i = 0; i < N; i++) s += b[i]; printf("합: %d\n", s);
합: 6 이 출력됩니다

Q5
종합 코드 작성
보통
#define SIZE 6을 선언하고, 크기 6인 배열에 1~6을 초기화한 뒤 sizeof로 원소 개수를 확인하고 합계를 출력하는 프로그램을 작성하세요.
내 답안
힌트 보기
#define SIZE 6 → int arr[SIZE] = {1,2,3,4,5,6} → sizeof로 n 계산 → for 루프로 sum
정답 보기
#include <stdio.h> #define SIZE 6 int main() { int arr[SIZE] = {1, 2, 3, 4, 5, 6}; int n = sizeof(arr) / sizeof(arr[0]); int sum = 0; printf("원소 개수: %d\n", n); for (int i = 0; i < SIZE; i++) sum += arr[i]; printf("합계: %d\n", sum); return 0; }

핵심 정리

  • sizeof(arr) — 배열 전체 바이트 크기 (int 5개 = 20)
  • sizeof(arr[0]) — 원소 하나의 바이트 크기 (int = 4)
  • 원소 개수: sizeof(arr) / sizeof(arr[0]) — 선언 범위 안에서만 유효
  • 매직넘버 금지: 크기를 코드 여러 곳에 직접 쓰지 않는다.
  • #define SIZE 5 — 한 줄 수정으로 전체 코드 반영, = 과 ; 없이 씀
