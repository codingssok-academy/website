회문(回文)
판별기
앞뒤가 같은 단어 — Palindrome Checker
"racecar"를 뒤집어도 "racecar" — 이런 단어가 회문(Palindrome)이다.
PJ03에서 배운 양방향 포인터 패턴으로 구현하되, 이번엔 swap 대신 비교를 한다.
공백과 대소문자를 무시하는 "진짜 회문 판별"까지 단계적으로 업그레이드한다.

학습 목표

양방향 포인터로 회문 판별하는 알고리즘 구현
대소문자 무시 (tolower 전처리)
공백/특수문자 무시한 문장 회문 판별
숫자 회문 판별 응용 (ex: 12321)
코딩쏙 C언어 · L7 문자열 · PJ-07
Two Pointer Comparison
회문 판별 알고리즘
단계별 비교 추적 — "level"
기본 구현
#include <stdio.h> #include <string.h> #include <ctype.h> int is_palindrome(char str[]) { int i = 0, j = strlen(str) - 1; while (i < j) { if (tolower(str[i]) != tolower(str[j])) { return 0; // 불일치 → 회문 아님 } i++; j--; } return 1; // 모두 일치 → 회문 } int main() { char word[100]; printf("단어 입력: "); scanf("%s", word); if (is_palindrome(word)) printf("\"%s\"는 회문입니다.\n", word); else printf("\"%s\"는 회문이 아닙니다.\n", word); return 0; }
tolower 비교: "Racecar"는 'R'≠'r'이라 회문 판별에 실패한다. tolower()로 소문자 변환 후 비교하면 대소문자 무시가 가능하다.
응용 — 문장 회문 + 숫자 회문
공백/특수문자 무시한 문장 회문 판별

"A man a plan a canal Panama"는 공백을 제거하면 "amanaplanacanalpanama" — 회문이다. isalpha()로 알파벳만 걸러서 비교한다.

int is_sentence_palindrome(char str[]) { char clean[200]; int k = 0; // 알파벳만 추출, 소문자로 for (int i = 0; str[i]; i++) { if (isalpha(str[i])) clean[k++] = tolower(str[i]); } clean[k] = '\0'; // 정리된 문자열로 회문 판별 int i = 0, j = k - 1; while (i < j) { if (clean[i] != clean[j]) return 0; i++; j--; } return 1; }
숫자 회문 판별

정수 → 문자열 변환 후 판별

int is_num_palindrome(int n) { char s[20]; sprintf(s, "%d", n); return is_palindrome(s); } // 12321 → "12321" → 회문

회문 숫자 예시

1, 2, ... 9 (한 자리 전부)
11, 22, ... 99
101, 121, 131, ...
12321, 99999
→ "팰린드롬 수"라고도 함

알고리즘 관점: is_palindrome은 O(n/2) — 길이의 절반만 비교하면 된다. 실제 인터뷰에서 자주 나오는 기초 알고리즘 문제다.

Q5. 도전

문장을 입력받아 공백, 쉼표, 느낌표를 무시하고 회문인지 판별하는 프로그램을 작성하시오.
예) "A man, a plan, a canal: Panama!" → 회문

is_sentence_palindrome() 함수 사용. isalpha로 알파벳만 추출, tolower 소문자 변환 후 is_palindrome 호출.
