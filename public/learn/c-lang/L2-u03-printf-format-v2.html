printf 서식지정자 — %d

printf에서 변수 값을 출력하는 핵심 도구, 서식지정자를 배웁니다. %d, %f, %c, %s의 차이를 익혀봅시다.

이 유닛에서 배우는 것

  • printf에서 %d가 하는 역할을 설명할 수 있습니다.
  • 여러 변수를 한 번에 출력할 수 있습니다.
  • %d, %f, %c, %s의 차이를 구분할 수 있습니다.
  • 필드 너비를 지정하여 정렬된 출력을 만들 수 있습니다.
  • 서식 문자열과 변수의 매칭 원리를 이해합니다.

printf와 %d의 관계

printf("나이: %d살", age);에서 %d는 "여기에 정수 값을 넣어라"라는 뜻입니다. printf가 실행되면 %d 자리에 age의 값이 들어갑니다.

int age = 15; printf("나이: %d살\n", age); // 출력: 나이: 15살

여러 변수 출력하기

%d를 여러 개 쓰면 변수도 순서대로 여러 개 넣을 수 있습니다. 순서가 중요합니다!

int a = 3, b = 5; printf("%d + %d = %d\n", a, b, a + b); // 출력: 3 + 5 = 8

서식지정자 종류 미리보기

%d는 정수용이고, 소수점, 문자, 문자열에는 각각 다른 서식지정자를 씁니다.

따라해보세요
1
변수 두 개를 만들어 덧셈 결과를 출력하세요.
int x = 10, y = 20; printf("%d + %d = %d", x, y, x + y);
10 + 20 = 30
2
이름(문자열), 나이(정수)를 함께 출력하세요.
int age = 15; printf("이름: 철수, 나이: %d살", age);
이름: 철수, 나이: 15살
3
세 과목 점수를 한 줄에 출력하세요.
int kor = 90, eng = 85, math = 95; printf("국어:%d 영어:%d 수학:%d", kor, eng, math);
국어:90 영어:85 수학:95

필드 너비로 정렬하기

%5d는 최소 5칸을 차지하며 오른쪽 정렬합니다. %-5d는 왼쪽 정렬합니다.

// 점수표 정렬 출력 #include <stdio.h> int main() { printf("%-8s %5s\n", "과목", "점수"); printf("%-8s %5d\n", "국어", 95); printf("%-8s %5d\n", "영어", 88); printf("%-8s %5d\n", "수학", 100); return 0; }
따라해보세요
1
%5d를 사용해 숫자를 오른쪽 정렬하세요.
printf("[%5d]\n", 42); printf("[%5d]\n", 7); printf("[%5d]\n", 1234);
[ 42] [ 7] [ 1234] 처럼 정렬됩니다
2
%-5d로 왼쪽 정렬도 해보세요.
printf("[%-5d]\n", 42); printf("[%-5d]\n", 7);
[42 ] [7 ] 처럼 왼쪽 정렬됩니다
3
점수 3개를 정렬된 표로 출력하세요.
printf("국어: %3d점\n", 95); printf("영어: %3d점\n", 88); printf("수학: %3d점\n", 100);
숫자가 깔끔하게 정렬됩니다

확인 문제

Q1
출력 결과 예측
쉬움
다음 코드의 출력 결과를 쓰세요.
int a = 7, b = 3; printf("%d - %d = %d", a, b, a - b);
내 답안
힌트 보기
%d가 3개이므로 변수도 3개 순서대로 매칭됩니다. a=7, b=3, a-b=4
정답 보기
7 - 3 = 4
Q2
서식 문자열 완성
쉬움
출력이 "점수: 95점, 등급: 1등급"이 되도록 빈칸을 채우세요.
int score = 95, rank = 1; printf("점수: ____점, 등급: ____등급", score, rank);
내 답안
힌트 보기
정수를 출력하는 서식지정자는 %d입니다.
정답 보기
printf("점수: %d점, 등급: %d등급", score, rank);
Q3
정렬 출력
보통
다음 코드의 출력 결과에서 대괄호 안의 내용을 쓰세요.
printf("[%5d]\n", 42); printf("[%-5d]\n", 42);
내 답안
힌트 보기
%5d는 5칸 오른쪽 정렬, %-5d는 5칸 왼쪽 정렬입니다.
정답 보기
[ 42] (앞에 빈칸 3개, 오른쪽 정렬) [42 ] (뒤에 빈칸 3개, 왼쪽 정렬)

핵심 요약

  • %d는 printf에서 정수 값을 출력하는 서식지정자입니다.
  • %d 개수와 변수 개수는 반드시 일치해야 합니다.
  • %d(정수), %f(실수), %c(문자), %s(문자열) 등이 있습니다.
  • %5d(5칸 오른쪽 정렬), %-5d(5칸 왼쪽 정렬)로 너비 지정 가능합니다.
  • 서식지정자와 변수는 순서대로 1:1 매칭됩니다.
