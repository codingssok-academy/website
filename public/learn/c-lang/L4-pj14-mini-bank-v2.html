미니 은행 시스템

무한루프 메뉴로 입금·출금·잔액조회를 구현합니다. 잔액 부족 처리, 거래 카운트, 이자 계산까지 실제 프로그램 구조를 경험합니다.

이 프로젝트에서 배우는 것

  • while(1) 무한루프와 break로 메뉴 시스템을 구현합니다.
  • switch-case로 여러 선택지를 깔끔하게 처리합니다.
  • 잔액 부족 시 오류 메시지를 출력하는 예외 처리를 배웁니다.
  • 거래 횟수를 카운트 변수로 추적합니다.
  • 이자 계산(0.5%)과 비밀번호 보호를 추가합니다.

무한루프 메뉴 시스템 구조

while(1)로 무한루프를 만들고, 0을 입력하면 break로 탈출합니다. 이 패턴이 대부분의 메뉴 프로그램의 기본 구조입니다.

#include <stdio.h> int main() { int choice; int balance = 0; // 잔액 int amount; // 입출금 금액 printf("=== 미니 은행 ===\n"); while (1) { // 무한루프 printf("\n1.입금 2.출금 3.잔액 0.종료\n"); printf("선택: "); scanf("%d", &choice); switch (choice) { case 1: printf("입금액: "); scanf("%d", &amount); if (amount <= 0) { printf("양수를 입력하세요\n"); break; } balance += amount; printf("%d원 입금. 잔액: %d원\n", amount, balance); break; case 2: printf("출금액: "); scanf("%d", &amount); if (amount > balance) { printf("잔액 부족! 현재 잔액: %d원\n", balance); } else { balance -= amount; printf("%d원 출금. 잔액: %d원\n", amount, balance); } break; case 3: printf("현재 잔액: %d원\n", balance); break; case 0: printf("이용해 주셔서 감사합니다.\n"); return 0; // 루프 탈출 + 종료 default: printf("잘못된 선택입니다.\n"); } } }

실행 예시

확장 1 — 거래 횟수 카운트

입금과 출금이 성공할 때마다 카운터를 늘립니다. 종료 시 총 거래 횟수와 함께 요약을 출력합니다.

int tx_count = 0; // 거래 횟수 (transaction count) // 입금 성공 시 balance += amount; tx_count++; printf("%d원 입금 [거래 %d회]\n", amount, tx_count); // 종료 시 요약 case 0: printf("총 거래 %d회 | 최종 잔액: %d원\n", tx_count, balance); return 0;

확장 2 — 이자 계산 (0.5%)

메뉴에 4번(이자 적립)을 추가합니다. 이자율 0.5%를 잔액에 곱해 소수점 이하는 버리고 잔액에 더합니다.

case 4: // 이자 적립 { int interest = balance * 0.005; // 0.5% 이자 (int로 절사) balance += interest; printf("이자 %d원 적립. 잔액: %d원\n", interest, balance); } break;

확장 3 — 비밀번호 보호

프로그램 시작 시 비밀번호를 입력받아 검사합니다. 3회 오류 시 강제 종료되는 잠금 기능을 추가합니다.

#define PASSWORD 1234 #define MAX_TRIES 3 // main 시작 부분에 삽입 int tries = 0, input_pw; printf("비밀번호 입력: "); while (tries < MAX_TRIES) { scanf("%d", &input_pw); if (input_pw == PASSWORD) { printf("인증 성공!\n"); break; } tries++; printf("틀렸습니다. 남은 시도: %d회\n", MAX_TRIES - tries); if (tries == MAX_TRIES) { printf("3회 오류. 프로그램을 종료합니다.\n"); return 1; } printf("비밀번호 재입력: "); }

핵심 정리

  • while(1) + break: 무한루프 메뉴의 핵심 패턴
  • switch-case: 여러 분기를 깔끔하게 처리, break 빠뜨리지 않기
  • 잔액 부족 체크: 출금 전 amount > balance 조건 필수
  • 거래 카운트: 성공한 거래마다 tx_count++ 누적
  • 이자 = (int)(balance * 0.005) — float 결과를 int로 절사
