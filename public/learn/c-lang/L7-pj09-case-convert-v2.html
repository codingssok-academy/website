"Hello World"를 모두 대문자로, 또는 모두 소문자로 바꾸는 것은 기본 중의 기본이다.
toupper(), tolower()와 isupper/islower 조건을 조합하면
대소문자 토글(toggle), 타이틀 케이스(Title Case) 등 다양한 변환이 가능하다.

학습 목표

isupper/islower 조건으로 선택적 변환

toupper / tolower
대소문자 변환 원리
ASCII 차이 = 32

대문자 'A'=65, 소문자 'a'=97. 차이는 딱 32. 따라서 대문자에 32를 더하면 소문자, 소문자에서 32를 빼면 대문자가 된다. toupper/tolower 함수가 이 원리로 동작한다.

전체 변환 구현
#include <stdio.h> #include <string.h> #include <ctype.h> void to_upper_all(char str[]) { for (int i = 0; str[i]; i++) str[i] = toupper(str[i]); } void to_lower_all(char str[]) { for (int i = 0; str[i]; i++) str[i] = tolower(str[i]); } void toggle_case(char str[]) { for (int i = 0; str[i]; i++) { if (isupper(str[i])) str[i] = tolower(str[i]); else if (islower(str[i])) str[i] = toupper(str[i]); } } int main() { char s1[] = "Hello World"; char s2[] = "Hello World"; char s3[] = "hElLo WoRlD"; to_upper_all(s1); printf("대문자: %s\n", s1); // HELLO WORLD to_lower_all(s2); printf("소문자: %s\n", s2); // hello world toggle_case(s3); printf("토글: %s\n", s3); // HeLlO wOrLd return 0; }
응용 — Title Case + 케이스 통계
Title Case — 각 단어의 첫 글자를 대문자로

"hello world" → "Hello World" 변환이다. 공백 다음 글자와 맨 첫 글자를 toupper로 변환한다.

void title_case(char str[]) { int new_word = 1; // 처음은 새 단어로 취급 for (int i = 0; str[i]; i++) { if (str[i] == ' ') { new_word = 1; // 공백 다음은 새 단어 } else if (new_word) { str[i] = toupper(str[i]); // 첫 글자 대문자 new_word = 0; } else { str[i] = tolower(str[i]); // 나머지 소문자 } } }
케이스 통계 분석
void case_stats(char str[]) { int upper=0, lower=0, other=0; for (int i=0; str[i]; i++) { if (isupper(str[i])) upper++; else if (islower(str[i])) lower++; else other++; } printf("대문자: %d, 소문자: %d, 기타: %d\n", upper, lower, other); }
new_word 플래그 패턴: 이전 문자가 공백이었는지 추적하는 변수. 문자열 처리에서 "경계 감지"에 자주 쓰이는 패턴이다. 단어 시작, 문장 시작 등에 응용 가능.

Q1. ASCII 계산

정답 보기
72 + 32 = 104. tolower('H') = 104 = 'h'
