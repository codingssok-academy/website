시간 계산기 — 덧셈/뺄셈/비교

Time 구조체로 시:분:초를 표현하고, 두 시간을 더하거나 빼는 함수를 구현합니다. 올림(carry)과 내림(borrow) 처리가 핵심입니다.

프로젝트 목표

  • Time 구조체(hour, min, sec)를 정의합니다.
  • 두 시간을 더하는 함수(초 올림 처리)를 구현합니다.
  • 두 시간의 차이를 구하는 함수를 구현합니다.
  • 두 시간을 비교하는 함수를 구현합니다.

구현 코드

#include <stdio.h> typedef struct { int hour, min, sec; } Time; // 총 초로 변환 int toSeconds(Time t) { return t.hour * 3600 + t.min * 60 + t.sec; } // 초를 Time 구조체로 변환 Time fromSeconds(int s) { Time t; t.hour = s / 3600; t.min = (s % 3600) / 60; t.sec = s % 60; return t; } Time addTime(Time a, Time b) { return fromSeconds(toSeconds(a) + toSeconds(b)); } // a - b (a >= b 전제) Time subTime(Time a, Time b) { int diff = toSeconds(a) - toSeconds(b); if (diff < 0) diff = 0; return fromSeconds(diff); } // -1: a < b, 0: 같음, 1: a > b int compareTime(Time a, Time b) { int sa = toSeconds(a), sb = toSeconds(b); if (sa < sb) return -1; if (sa > sb) return 1; return 0; } void printTime(Time t, const char *label) { printf("%s: %02d:%02d:%02d\n", label, t.hour, t.min, t.sec); } int main() { Time a = {2, 45, 30}; Time b = {1, 30, 45}; printTime(a, "A"); printTime(b, "B"); printTime(addTime(a, b), "A + B"); printTime(subTime(a, b), "A - B"); int cmp = compareTime(a, b); printf("비교: A %s B\n", cmp > 0 ? ">" : (cmp < 0 ? "<" : "==")); return 0; }

도전 과제

  • 시간 배열에서 가장 긴 시간과 가장 짧은 시간을 찾아보세요.
  • 현재 시각(예: 14:30:00)에서 n초 후의 시각을 계산해보세요.
  • 두 시간의 비율(A가 B의 몇 배인지)을 소수점으로 출력해보세요.

구조 분석 — 초 변환의 장점

시간 계산에서 시:분:초를 직접 더하면 올림(carry) 처리가 복잡합니다. 이 프로젝트는 총 초로 변환 후 계산하는 방법을 사용해 코드를 단순화했습니다.

핵심 포인트
%02d 서식 지정자
%02d는 최소 2자리로 출력하되, 자릿수가 부족하면 앞을 0으로 채웁니다.
예: 시각이 08:05:03일 때 %d는 "8:5:3", %02d는 "08:05:03"으로 출력합니다.
