Chapter 8 — Unit 01

포인터란?
주소를 저장하는 변수

C언어의 꽃, 포인터를 배웁니다. 메모리 주소가 무엇인지, 포인터가 왜 필요한지 이해합니다.

이 유닛에서 배우는 것

  • 메모리 주소가 무엇인지 설명할 수 있습니다.
  • 포인터 변수가 일반 변수와 다른 점을 알 수 있습니다.
  • 포인터가 왜 필요한지 이해할 수 있습니다.
  • 포인터 변수를 선언하는 기본 형태를 알 수 있습니다.
  • 메모리 주소와 값의 차이를 구분할 수 있습니다.

메모리란? 컴퓨터 안의 주소 공간

컴퓨터의 메모리(RAM)는 수많은 작은 칸으로 나뉘어 있습니다. 각 칸은 고유한 주소(address)를 가집니다. 변수를 만들면 이 칸 중 하나에 값이 저장됩니다.

핵심: int 변수 하나는 메모리에서 4바이트(4칸)를 차지합니다. 주소는 보통 0x로 시작하는 16진수로 표현됩니다.

포인터 = 주소를 저장하는 변수

일반 변수는 정수, 실수 같은 값을 저장합니다. 포인터 변수는 다른 변수의 메모리 주소를 저장합니다. 주소를 저장함으로써 그 변수를 간접적으로 접근할 수 있습니다.

int a = 10; // 일반 변수: 값 10을 저장 int *p = &a; // 포인터 변수: a의 주소를 저장 printf("%d\n", a); // 10 출력 (값 직접 접근) printf("%p\n", p); // 0x1000 출력 (주소 출력)

왜 포인터가 필요한가?

포인터는 세 가지 중요한 이유로 필요합니다. 각 상황을 그림으로 이해해봅시다.

포인터 변수 선언 기본형

포인터 변수를 선언할 때는 타입 뒤에 *(별표)를 붙입니다. 이 *는 "포인터입니다"라는 표시입니다.

int *p; // int형 변수의 주소를 저장하는 포인터 float *fp; // float형 변수의 주소를 저장하는 포인터 char *cp; // char형 변수의 주소를 저장하는 포인터

중요: 포인터 변수도 선언만 하면 쓰레기 주소가 들어 있습니다. 반드시 유효한 변수의 주소를 대입한 뒤 사용하세요!

메모리 주소 시각화

실제 코드를 실행하면 변수들이 메모리에 어떻게 배치되는지 살펴봅시다.

포인터의 크기

흥미로운 사실! 포인터 변수는 어떤 타입을 가리키든 크기가 같습니다. 64비트 시스템에서는 모든 포인터가 8바이트입니다.

printf("int 크기: %zu\n", sizeof(int)); // 4 printf("float 크기: %zu\n", sizeof(float)); // 4 printf("int* 크기: %zu\n", sizeof(int*)); // 8 (64비트) printf("float* 크기: %zu\n", sizeof(float*)); // 8 (64비트)

핵심 정리

  • 메모리는 주소로 구분되는 수많은 칸으로 이루어져 있다.
  • 포인터 변수는 다른 변수의 메모리 주소를 저장한다.
  • 포인터를 선언할 때는 타입 뒤에 *를 붙인다: int *p;
  • 포인터 변수는 크기가 항상 동일하다 (64비트: 8바이트).
  • 선언만 하면 쓰레기 주소 — 반드시 초기화 후 사용!
