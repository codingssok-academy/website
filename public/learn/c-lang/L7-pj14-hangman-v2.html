마스킹 배열 — '_' 로 숨기기

단어 "hello"를 처음엔 "_ _ _ _ _"로 표시한다. 'l'을 맞추면 "_ _ l l _"로 업데이트된다. 마스킹 배열 display[]를 별도로 관리한다.

#include <stdio.h> #include <string.h> #include <ctype.h> #define MAX_WRONG 6 void draw_hangman(int wrong) { char *stages[] = { " +---+\n | |\n |\n |\n |\n |", " +---+\n | |\n O |\n |\n |\n |", " +---+\n | |\n O |\n | |\n |\n |", " +---+\n | |\n O |\n /| |\n |\n |", " +---+\n | |\n O |\n /|\\ |\n |\n |", " +---+\n | |\n O |\n /|\\ |\n / |\n |", " +---+\n | |\n O |\n /|\\ |\n / \\ |\n |" }; printf("%s\n", stages[wrong]); } int main() { char words[5][20] = {"hello","world","apple","banana","orange"}; char *secret = words[2]; // "apple" 선택 int len = strlen(secret); char display[20]; // 마스킹 배열 for (int i=0; i<len; i++) display[i] = '_'; display[len] = '\0'; char wrong_letters[30] = ""; int wrong_cnt = 0, correct_cnt = 0; while (wrong_cnt < MAX_WRONG && correct_cnt < len) { draw_hangman(wrong_cnt); printf("단어: %s 틀린횟수: %d/%d\n",display,wrong_cnt,MAX_WRONG); printf("틀린 글자: %s\n", wrong_letters); char guess; printf("글자 입력: "); scanf(" %c", &guess); guess = tolower(guess); // 이미 시도한 글자 체크 if (strchr(wrong_letters, guess) != NULL || strchr(display, guess) != NULL) { printf("이미 시도한 글자!\n"); continue; } // 글자 포함 여부 확인 if (strchr(secret, guess) != NULL) { printf("정답! '%c' 포함됨\n", guess); for (int i=0; i<len; i++) if (secret[i] == guess) { display[i]=guess; correct_cnt++; } } else { printf("틀렸습니다!\n"); wrong_letters[wrong_cnt++] = guess; wrong_letters[wrong_cnt] = '\0'; } } draw_hangman(wrong_cnt); if (correct_cnt == len) printf("축하합니다! \"%s\" 완성!\n", secret); else printf("게임 오버! 정답: \"%s\"\n", secret); return 0; }
동작 원리 + 개선 포인트
correct_cnt 계산 방법

display 배열에서 '_'가 아닌 글자 수를 세어도 되고, 맞출 때마다 개수를 누적해도 된다. 단, 같은 글자가 단어에 여러 개 있으면 한 번 맞출 때 여러 개 공개된다는 점을 주의한다.

게임 개선 아이디어
힌트 기능: 남은 글자 중 하나를 랜덤으로 공개 (한 번만 사용 가능)
단어 선택: rand() % N 으로 words 배열에서 랜덤 선택
카테고리: 과일/동물/나라 별로 단어 분류 후 메뉴에서 선택
점수 시스템: (MAX_WRONG - wrong_cnt) × 10점 보너스
간단한 랜덤 단어 선택 추가
#include <stdlib.h> #include <time.h> srand(time(NULL)); // 시드 초기화 char *secret = words[rand() % 5]; // 0~4 중 랜덤
연습 문제
Q1. 로직 이해

secret = "apple", 현재 display = "_ppl_"일 때 남은 글자 개수는?
correct_cnt는 얼마인가?

정답 보기
display "_ppl_"에서 '_'가 2개 → 맞춰야 할 글자 2개 남음. correct_cnt = 3 (p, p, l)이 공개됨.
Q2. 중복 방지

이미 시도한 글자를 중복 입력하면 어떻게 처리하는가? 코드에서 관련 부분을 찾아 설명하시오.

정답 보기
strchr(wrong_letters, guess) != NULL 이거나 strchr(display, guess) != NULL이면 "이미 시도" 메시지 출력 후 continue로 다시 입력.
Q3. 구현

단어 개수를 10개로 늘리고, 프로그램 시작 시 rand()로 무작위 단어를 선택하도록 수정하시오.

정답 보기
words[10][20]에 10개 단어. #include <time.h>, srand(time(NULL)) 후 secret = words[rand()%10].
Q4. 응용

맞춘 글자와 틀린 글자를 함께 표시하는 알파벳 26개 상태 표시줄을 구현하시오.
(미시도: 빈칸, 정답: O, 오답: X)

정답 보기
char alpha_state[26]; memset(alpha_state, ' ', 26). 정답이면 alpha_state[guess-'a']='O', 오답이면 'X'. 매 턴 출력.
Q5. 도전

2인용 행맨을 구현하시오: 플레이어 1이 단어를 입력하면(화면 가림 처리), 플레이어 2가 맞추는 방식.

정답 보기
P1 입력 시 system("cls") 또는 여러 번 printf("\n")로 이전 화면을 밀어낸다. P1 입력 단어를 secret에 저장 후 display 초기화. 나머지 동일.
