성인 판별기 — 나이로 어른인지 확인!

scanf로 나이를 입력받고, if문으로 성인 여부를 판단하는 프로그램을 만들어봅시다. 지금까지 배운 변수, 입출력, 조건문을 한 번에 활용합니다.

완성 모습 미리보기

프로그램 흐름도

이 프로젝트에서 배우는 것

  • scanf로 사용자 입력을 받을 수 있습니다.
  • if / else 문으로 조건에 따라 다른 메시지를 출력할 수 있습니다.
  • else if로 3단계 이상의 분류를 만들 수 있습니다.
  • 연산식(현재년도 - 출생연도)을 활용한 응용 판별을 만들 수 있습니다.

단계별 구현 가이드

성인 판별기를 3단계로 나눠서 차근차근 만들어봅시다. 각 단계가 끝날 때마다 실행해서 확인하세요.

1
나이 입력받기 — scanf 사용

먼저 사용자에게 나이를 입력받습니다. scanf는 키보드로 값을 입력받는 함수입니다.

#include <stdio.h> int main() { int age; // 나이를 저장할 변수 printf("나이를 입력하세요: "); scanf("%d", &age); // &age : age 변수의 주소 printf("입력한 나이: %d\n", age); // 일단 확인용 출력 return 0; }
scanf에서 변수 앞에 &를 빠뜨리면 프로그램이 오동작합니다. 절대 잊지 마세요.
2
if문으로 18 이상인지 판별

나이가 18 이상이면 성인, 그렇지 않으면 미성년자입니다. if와 else를 사용합니다.

if (age >= 18) { // 나이가 18 이상이면 이 부분 실행 printf("성인입니다! 투표권이 있어요.\n"); } else { // 18 미만이면 이 부분 실행 printf("미성년자입니다.\n"); }
3
완성 코드 — 합치기

Step 1과 Step 2를 합치면 완성입니다. 직접 실행하고 여러 나이를 입력해보세요.

#include <stdio.h> int main() { int age; printf("나이를 입력하세요: "); scanf("%d", &age); if (age >= 18) { printf("성인입니다! 투표권이 있어요.\n"); } else { printf("미성년자입니다.\n"); } return 0; }

입력: 19

나이를 입력하세요: 19 성인입니다! 투표권이 있어요.

입력: 15

나이를 입력하세요: 15 미성년자입니다.

확장 과제 — 한 단계 더!

기본 성인 판별기를 완성했다면, 아래 3가지 확장 과제에 도전해봅시다. 더 똑똑한 프로그램으로 만들 수 있습니다.

확장 1 else if 활용 어린이 / 청소년 / 성인 3단계 분류

단순히 성인/미성년자가 아닌, 나이에 따라 3가지로 분류해봅시다.

if (age < 13) { printf("어린이입니다.\n"); } else if (age < 18) { printf("청소년입니다.\n"); } else { printf("성인입니다.\n"); }
확장 2 연산 활용 출생연도로 나이 계산 후 판별

나이 대신 태어난 연도를 입력받아 현재 연도에서 빼서 나이를 계산해봅시다.

int birth_year; int age; printf("태어난 연도를 입력하세요: "); scanf("%d", &birth_year); age = 2026 - birth_year; // 나이 계산 printf("계산된 나이: %d세\n", age); if (age >= 18) { printf("성인입니다!\n"); } else { printf("미성년자입니다.\n"); }
확장 3 추가 출력 몇 년 남았는지 알려주기

미성년자라면 성인이 되기까지 몇 년이 남았는지 함께 출력해봅시다.

if (age >= 18) { printf("성인입니다!\n"); } else { int years_left = 18 - age; // 몇 년 남았는지 계산 printf("미성년자입니다. %d년 후에 성인이 돼요!\n", years_left); }
나이를 입력하세요: 15 미성년자입니다. 3년 후에 성인이 돼요!

최종 완성 코드 — 모두 합치기

앞에서 배운 기본 + 확장 3을 합친 최종 버전입니다. 직접 입력해보고 다양한 나이로 테스트하세요.

#include <stdio.h> int main() { int age; printf("=== 성인 판별기 ===\n"); printf("나이를 입력하세요: "); scanf("%d", &age); if (age < 13) { printf("%d세 — 어린이입니다.\n", age); printf("성인까지 %d년 남았어요!\n", 18 - age); } else if (age < 18) { printf("%d세 — 청소년입니다.\n", age); printf("성인까지 %d년 남았어요!\n", 18 - age); } else { printf("%d세 — 성인입니다! 투표권이 있어요.\n", age); } return 0; }

실행 결과 예시

입력: 9 (어린이)

나이를 입력하세요: 9 9세 — 어린이입니다. 성인까지 9년 남았어요!

입력: 15 (청소년)

나이를 입력하세요: 15 15세 — 청소년입니다. 성인까지 3년 남았어요!

입력: 20 (성인)

나이를 입력하세요: 20 20세 — 성인입니다! 투표권이 있어요.

프로젝트 핵심 정리

  • scanf("%d", &변수명) — 정수 입력받기, & 필수
  • if (조건) { } else { } — 조건에 따라 다른 코드 실행
  • else if — 조건을 3개 이상으로 나눌 때 사용
  • 나이 계산: 현재연도 - 출생연도
  • 남은 해 계산: 18 - age
