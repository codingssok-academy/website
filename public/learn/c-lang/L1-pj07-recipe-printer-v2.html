요리 레시피 출력기

좋아하는 요리의 재료와 조리 순서를 C 언어로 예쁘게 출력합니다.

이 프로젝트에서 만드는 것

  • 레시피 카드 형식의 텍스트 레이아웃을 설계합니다.
  • 재료 목록, 조리 순서를 번호와 함께 출력합니다.
  • 섹션별 구분선을 특수문자로 표현합니다.
  • 4페이지 분량의 완성도 높은 레시피 카드를 완성합니다.

레시피 카드 설계하기

레시피 카드는 제목 → 재료 → 조리 순서 3단계 구조로 만듭니다. 각 섹션을 -----로 구분하면 읽기 쉬운 카드가 됩니다.

#include <stdio.h> int main() { /* 라면 레시피 출력기 */ // 제목 printf("======== 라면 레시피 ========\n"); // 재료 섹션 printf("------- [재료] -------\n"); printf(" - 라면 1봉지\n"); printf(" - 계란 1개\n"); printf(" - 대파 조금\n"); printf(" - 물 500ml\n"); // 조리 순서 섹션 printf("------- [순서] -------\n"); printf(" 1. 냄비에 물 500ml 붓기\n"); printf(" 2. 물이 끓으면 면과 수프 넣기\n"); printf(" 3. 3분 더 끓이기\n"); printf(" 4. 계란과 대파 올리기\n"); // 마무리 printf("============================\n"); printf(" 완성! 맛있게 드세요!\n"); return 0; }

나만의 레시피 만들기

좋아하는 요리를 선택해서 완전한 레시피 카드를 작성합니다. 재료, 조리 시간, 난이도까지 포함하면 더욱 완성도 높은 카드가 됩니다.

#include <stdio.h> int main() { /* 나만의 레시피 카드 */ // 헤더 printf("################################\n"); printf("## 나만의 특제 볶음밥 레시피 ##\n"); printf("################################\n"); // 기본 정보 printf(" [조리 시간] 약 15분\n"); printf(" [난이도 ] 쉬움\n"); printf(" [인분 ] 1인분\n"); printf("--------------------------------\n"); // 재료 printf(" [재료]\n"); printf(" - 밥 1공기\n"); printf(" - 계란 2개\n"); printf(" - 당근 1/4개\n"); printf(" - 간장 1스푼\n"); printf("--------------------------------\n"); // 조리 순서 printf(" [만드는 법]\n"); printf(" 1. 당근 작게 썰기\n"); printf(" 2. 프라이팬에 기름 두르기\n"); printf(" 3. 계란 스크램블 만들기\n"); printf(" 4. 밥 넣고 볶기\n"); printf(" 5. 간장으로 간하기\n"); printf("################################\n"); return 0; }
따라해보세요
1
위 코드를 참고해서 좋아하는 요리 레시피로 바꿔보세요.
나만의 레시피 카드 완성
2
재료 개수를 다르게 해서 테두리 길이를 맞춰보세요.
정렬된 레시피 카드
3
각 섹션 앞에 // 주석으로 설명을 달아보세요.

도전 과제

Q1
간식 레시피 만들기
기본
좋아하는 간식(떡볶이, 샌드위치, 과일 화채 등)의 레시피 카드를 만드세요.
조건 1제목 헤더 포함 (특수문자 테두리)
조건 2재료 3가지 이상
조건 3조리 순서 3단계 이상
내 답안
예시 정답 보기
printf("==== 떡볶이 레시피 ====\n"); printf("[재료]\n"); printf(" - 떡볶이 떡 200g\n"); printf(" - 고추장 2스푼\n"); printf(" - 물 1컵\n"); printf("[순서]\n"); printf(" 1. 물에 고추장 풀기\n"); printf(" 2. 떡 넣고 5분 끓이기\n"); printf(" 3. 완성!\n");

심화
두 가지 요리 레시피를 하나의 프로그램에서 연속으로 출력하세요. 사이에 빈 줄 2줄을 넣으세요.
힌트printf("\n\n"); 으로 빈 줄 2개
내 답안
힌트 보기
첫 번째 레시피 마지막 줄 다음에 printf("\n\n");을 추가하면 됩니다.
Q3
주석 완전 정복
기본
레시피 코드 전체에 /* */ 헤더 주석과 // 섹션 주석을 모두 달아보세요.
내 답안
예시 보기
/* 나만의 레시피 출력기 작성자: 내 이름 요리: 라면 */ int main() { // 헤더 출력 printf("제목\n"); // 재료 출력 printf("재료\n"); return 0; }

핵심 요약

  • 여러 줄 printf를 조합해 구조화된 텍스트 레이아웃 가능
  • 특수문자 테두리로 섹션을 시각적으로 구분
  • - 항목, 1. 단계 형식으로 목록 표현
  • 주석으로 섹션 설명 → 유지보수 편리
  • 실제 사용 가능한 완성된 프로그램 경험
