Hello, World! — 첫 C 프로그램

C언어로 첫 번째 프로그램을 작성하고, 화면에 글자를 출력합니다.

이 유닛에서 배우는 것

  • C언어로 "Hello, World!"를 출력할 수 있습니다.
  • printf 함수로 문자열을 출력할 수 있습니다.
  • \n이 줄바꿈을 의미한다는 것을 압니다.
  • 코드를 컴파일하고 실행하는 과정을 알 수 있습니다.
  • 다양한 메시지를 출력하도록 코드를 수정할 수 있습니다.

Hello, World! 작성하기

모든 프로그래밍 언어를 배울 때 첫 번째로 만드는 프로그램이 "Hello, World!" 출력입니다. C언어로 한번 만들어 봅시다.

#include <stdio.h> int main() { printf("Hello, World!\n"); return 0; }

printf로 다양하게 출력하기

printf는 C언어에서 화면 출력의 기본입니다. 문자열뿐만 아니라 다양한 내용을 출력할 수 있습니다.

#include <stdio.h> int main() { printf("이름:\t김민수\n"); // 탭으로 정렬 printf("나이:\t14살\n"); printf("인사: \"안녕하세요!\"\n"); // 따옴표 출력 return 0; }

핵심 요약

  • printf("내용\n"); — 화면에 글자를 출력한다
  • \n은 줄바꿈, \t는 탭 들여쓰기
  • 모든 문장 끝에는 세미콜론 ; 필수
  • 오류 메시지는 파일명:줄번호: 오류내용 형식으로 출력된다
  • 컴파일이 성공하면 실행 파일(.exe)이 생성된다
