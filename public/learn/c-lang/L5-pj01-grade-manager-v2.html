성적 관리 프로그램

배열에 5명의 점수를 저장하고, 평균과 최고점을 계산하는 프로그램을 만들어봅니다.

이 프로젝트에서 배우는 것

  • 배열에 여러 값을 저장할 수 있습니다.
  • for 반복문으로 배열 전체를 순회할 수 있습니다.
  • 배열 원소를 더해 합계와 평균을 계산할 수 있습니다.
  • 최고점을 찾는 알고리즘을 구현할 수 있습니다.
  • 프로그램을 단계별로 설계하는 방법을 익힙니다.

프로젝트 설계 — 무엇을 만들까?

5명 학생의 수학 점수를 배열에 저장하고, 전체 평균과 최고점, 최고점을 받은 학생 번호를 출력하는 성적 관리 프로그램을 만듭니다.

배열 기초 복습

배열은 같은 자료형의 값을 여러 개 저장하는 상자입니다. int scores[5];는 정수 5개를 담는 배열을 선언합니다.

// 방법 1: 선언과 동시에 초기화 int scores[5] = {85, 92, 78, 97, 88}; // 방법 2: for문으로 입력받기 int scores[5]; for (int i = 0; i < 5; i++) { scanf("%d", &scores[i]); // i번째 칸에 입력 }
따라해보세요
1
정수 배열 scores[5]를 선언하고 값을 직접 초기화해보세요.
int scores[5] = {85, 92, 78, 97, 88};
5개의 점수가 배열에 저장됩니다
2
for문으로 배열의 모든 점수를 출력해보세요.
for (int i = 0; i < 5; i++) { printf("%d번 학생: %d점\n", i+1, scores[i]); }
1번 학생: 85점 ... 5번 학생: 88점

합계와 평균 계산하기

for문으로 배열을 순회하면서 모든 점수를 더해 합계를 구하고, 합계를 학생 수로 나눠 평균을 계산합니다.

int sum = 0; for (int i = 0; i < 5; i++) { sum += scores[i]; // sum = sum + scores[i] } float avg = (float)sum / 5; // 정수÷정수=정수 → 형변환 필요! printf("합계: %d\n", sum); printf("평균: %.1f점\n", avg);

최고점 찾기

배열에서 최고점을 찾을 때는 처음 값을 최고점으로 가정하고, 더 큰 값이 나오면 교체하는 방식을 씁니다.

int max = scores[0]; int maxIdx = 0; for (int i = 1; i < 5; i++) { if (scores[i] > max) { max = scores[i]; maxIdx = i; } } printf("최고점: %d점 (%d번 학생)\n", max, maxIdx + 1);

합계를 구하는 for문을 작성하고 sum을 출력해보세요.
int sum = 0; for (int i = 0; i < 5; i++) sum += scores[i]; printf("합계: %d\n", sum);
합계: 440

완성 코드 & 연습 문제

지금까지 배운 내용을 합쳐 성적 관리 프로그램을 완성합니다. 입력→합계→평균→최고점 순서로 구현합니다.

// 성적 관리 프로그램 — 완성 코드 #include <stdio.h> int main() { int scores[5]; int sum = 0; int max, maxIdx; printf("=== 성적 관리 프로그램 ===\n"); for (int i = 0; i < 5; i++) { printf("%d번 학생 점수: ", i + 1); scanf("%d", &scores[i]); } max = scores[0]; maxIdx = 0; for (int i = 0; i < 5; i++) { sum += scores[i]; if (scores[i] > max) { max = scores[i]; maxIdx = i; } } printf("\n--- 결과 ---\n"); printf("평균: %.1f점\n", (float)sum / 5); printf("최고점: %d점 (%d번 학생)\n", max, maxIdx + 1); return 0; }

핵심 정리

  • int arr[N] — N개짜리 정수 배열 선언
  • 인덱스는 0부터 시작, 마지막은 N-1
  • for문으로 배열 전체 순회: for(i=0; i<N; i++)
  • 합계: sum += arr[i], 평균: (float)sum / N
  • 최고점: 처음 값을 max로 두고 더 크면 교체
