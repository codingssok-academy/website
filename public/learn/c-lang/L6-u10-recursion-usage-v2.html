재귀 활용 — 피보나치, 거듭제곱, 반복 비교

재귀의 실용적인 활용 예시를 배웁니다. 피보나치 수열, 거듭제곱 계산, 반복문과 재귀의 비교를 통해 언제 무엇을 쓸지 판단합니다.

이 유닛에서 배우는 것

  • 피보나치 수열을 재귀로 구현합니다.
  • 거듭제곱(power)을 재귀로 구현합니다.
  • 재귀와 반복문을 비교해 장단점을 이해합니다.
  • 재귀가 유리한 상황과 반복이 유리한 상황을 구분합니다.
  • 재귀 트리 구조를 시각화하여 이해합니다.

피보나치 수열 재귀

피보나치 수열: 1, 1, 2, 3, 5, 8, 13, ... — 앞의 두 수를 더한 값이 다음 수입니다. fib(n) = fib(n-1) + fib(n-2)로 재귀 표현이 딱 맞습니다.

int fib(int n) { if (n <= 1) return n; // 기저: fib(0)=0, fib(1)=1 return fib(n - 1) + fib(n - 2); // 두 가지 재귀 호출 } // fib(6) = 8 (0,1,1,2,3,5,8)

거듭제곱 재귀

2^8 = 2 × 2^7 처럼 거듭제곱도 재귀로 표현됩니다.

int power(int base, int exp) { if (exp == 0) return 1; // 기저: 어떤 수의 0제곱 = 1 return base * power(base, exp - 1); } // power(2, 4) = 2×2×2×2 = 16

재귀 vs 반복문 비교

같은 문제를 재귀와 반복문으로 모두 풀 수 있습니다. 팩토리얼로 비교해봅니다.

// 재귀 팩토리얼 int factRec(int n) { if (n <= 1) return 1; return n * factRec(n - 1); } // 반복문 팩토리얼 int factLoop(int n) { int result = 1; for (int i = 2; i <= n; i++) { result *= i; } return result; }

재귀 활용 패턴 정리

핵심 정리

핵심 요약

  • 피보나치: fib(n) = fib(n-1) + fib(n-2), 기저: n <= 1 → n.
  • 거듭제곱: power(base, exp) = base × power(base, exp-1), 기저: exp==0 → 1.
  • 재귀는 트리 구조, 분할 정복 문제에 특히 적합합니다.
  • 단순 반복(합계, 최대값)은 반복문이 더 빠르고 안전합니다.
  • 재귀는 코드가 수학 정의와 유사해 읽기 쉽지만, 깊이가 크면 느립니다.
