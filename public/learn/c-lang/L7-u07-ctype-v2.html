ctype.h 함수들
— 문자 분류와 변환

isalpha, isdigit, isspace, toupper, tolower로 문자를 분류하고 변환합니다.

이 유닛에서 배우는 것

  • isalpha, isdigit, isspace로 문자를 분류할 수 있습니다.
  • isupper, islower로 대소문자를 판별할 수 있습니다.
  • toupper, tolower로 대소문자를 변환할 수 있습니다.
  • ctype.h 함수가 0(거짓)과 0이 아닌 값(참)을 반환함을 압니다.
  • 문자열의 모든 문자를 검사하는 반복문을 작성합니다.

ctype.h 문자 분류 함수

ctype.h를 include하면 문자를 분류하는 함수들을 사용할 수 있습니다. 이 함수들은 조건이 참이면 0이 아닌 값, 거짓이면 0을 반환합니다.

#include <stdio.h> #include <ctype.h> int main() { char c = 'A'; printf("isalpha: %d\n", isalpha(c)); // 0이 아닌 값 printf("isdigit: %d\n", isdigit(c)); // 0 (알파벳) printf("isupper: %d\n", isupper(c)); // 0이 아닌 값 printf("islower: %d\n", islower(c)); // 0 char d = '5'; printf("isdigit('5'): %d\n", isdigit(d)); // 0이 아닌 값 char sp = ' '; printf("isspace(' '): %d\n", isspace(sp)); // 0이 아닌 값 return 0; }

toupper / tolower — 대소문자 변환

toupper(c)는 소문자를 대문자로, tolower(c)는 대문자를 소문자로 변환합니다. 이미 해당 케이스거나 알파벳이 아니면 그대로 반환합니다.

#include <stdio.h> #include <ctype.h> #include <string.h> int main() { char str[] = "Hello World 123"; // 모두 대문자로 for (int i = 0; i < (int)strlen(str); i++) str[i] = toupper(str[i]); printf("%s\n", str); // HELLO WORLD 123 // 모두 소문자로 for (int i = 0; i < (int)strlen(str); i++) str[i] = tolower(str[i]); printf("%s\n", str); // hello world 123 return 0; }

문자열 분류 종합 예제

문자열의 각 문자를 순회하며 알파벳, 숫자, 공백, 기타를 세는 예제입니다.

#include <stdio.h> #include <ctype.h> #include <string.h> int main() { char s[] = "Hello 123!"; int alpha = 0, digit = 0, space = 0, other = 0; for (int i = 0; i < (int)strlen(s); i++) { if (isalpha(s[i])) alpha++; else if (isdigit(s[i])) digit++; else if (isspace(s[i])) space++; else other++; } printf("알파벳: %d, 숫자: %d, 공백: %d, 기타: %d\n", alpha, digit, space, other); return 0; }

핵심 정리

핵심 요약

  • ctype.h: isalpha(알파벳), isdigit(숫자), isspace(공백) 분류
  • isupper/islower로 대소문자 판별합니다.
  • 반환값: 참이면 0이 아닌 값, 거짓이면 0
  • toupper/tolower로 대소문자를 변환합니다. 알파벳 아니면 그대로.
  • for문과 조합해 문자열 전체를 분류하고 변환할 수 있습니다.

전체 예제 — 문자열 통계 분석기

#include <stdio.h> #include <ctype.h> #include <string.h> int main() { char line[100]; int upper=0, lower=0, digit=0, space=0, other=0; printf("문장 입력: "); fgets(line, sizeof(line), stdin); for (int i = 0; i < (int)strlen(line); i++) { char c = line[i]; if (isupper(c)) upper++; else if (islower(c)) lower++; else if (isdigit(c)) digit++; else if (isspace(c)) space++; else other++; } printf("대문자: %d\n", upper); printf("소문자: %d\n", lower); printf("숫자: %d\n", digit); printf("공백: %d\n", space); printf("기타: %d\n", other); return 0; }
