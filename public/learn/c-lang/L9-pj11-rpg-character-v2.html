RPG 캐릭터 — 전투 시뮬레이터

Character 구조체로 이름/HP/MP/ATK를 관리하고, 공격/힐/스킬 시전 등의 전투 함수를 구현합니다.

프로젝트 목표

  • Character 구조체(이름/HP/MP/ATK/레벨)를 정의합니다.
  • 일반 공격 함수를 구현합니다.
  • MP를 소모해 강력한 스킬을 사용하는 함수를 구현합니다.
  • HP를 회복하는 힐 함수를 구현합니다.

구현 코드

#include <stdio.h> #include <string.h> typedef struct { char name[20]; int hp, maxHp; int mp, maxMp; int atk; int level; } Character; void printStatus(const Character *c) { printf("[%s] HP:%d/%d MP:%d/%d ATK:%d LV:%d\n", c->name, c->hp, c->maxHp, c->mp, c->maxMp, c->atk, c->level); } void attack(Character *attacker, Character *target) { int dmg = attacker->atk; target->hp -= dmg; if (target->hp < 0) target->hp = 0; printf("%s가 %s에게 %d 데미지!\n", attacker->name, target->name, dmg); } void skill(Character *attacker, Character *target, int mpCost) { if (attacker->mp < mpCost) { printf("%s: MP 부족! (%d/%d)\n", attacker->name, attacker->mp, mpCost); return; } attacker->mp -= mpCost; int dmg = attacker->atk * 2; // 스킬 = ATK x2 target->hp -= dmg; if (target->hp < 0) target->hp = 0; printf("%s 스킬 사용! %s에게 %d 대미지! (MP: %d)\n", attacker->name, target->name, dmg, attacker->mp); } void heal(Character *c, int amount) { c->hp += amount; if (c->hp > c->maxHp) c->hp = c->maxHp; printf("%s HP +%d 회복! (%d/%d)\n", c->name, amount, c->hp, c->maxHp); } int main() { Character hero = {"용사", 100, 130, 80, 100, 35, 5}; Character boss = {"드래곤", 200, 200, 0, 0, 50, 10}; printf("=== 전투 시작 ===\n"); printStatus(&hero); printStatus(&boss); printf("\n--- 1라운드 ---\n"); skill(&hero, &boss, 30); attack(&boss, &hero); heal(&hero, 20); printf("\n--- 2라운드 ---\n"); attack(&hero, &boss); attack(&boss, &hero); printf("\n=== 현재 상태 ===\n"); printStatus(&hero); printStatus(&boss); return 0; }

도전 과제

도전 과제

  • HP가 0이 되면 "사망"을 출력하고 공격/스킬을 할 수 없도록 수정해보세요.
  • 경험치(exp)를 멤버로 추가하고, 적을 처치하면 레벨업하는 로직을 구현해보세요.
  • 랜덤 크리티컬(50% 확률로 ATK×2) 기능을 추가해보세요. (rand() 활용)

구조 분석

전투 함수에서 캐릭터를 포인터로 전달하는 것이 핵심입니다. 값으로 전달하면 HP가 줄어도 원본 구조체에 반영되지 않습니다.

확인 문제

문제 1
생존 여부 확인
캐릭터가 살아있는지(hp > 0) 확인하는 함수 isAlive를 작성하고, 사망 시 공격 함수에서 "이미 쓰러짐" 메시지를 출력하도록 수정하세요.
int isAlive(const Character *c) { return c->hp > 0; } void attackSafe(Character *att, Character *tgt) { if (!isAlive(att)) { printf("%s: 쓰러짐\n", att->name); return; } if (!isAlive(tgt)) { printf("%s: 이미 쓰러짐\n", tgt->name); return; } attack(att, tgt); }
문제 2
MP 회복
MP를 amount만큼 회복시키는 함수 recoverMp(c, amount)를 작성하세요. maxMp를 초과할 수 없습니다.
문제 3
레벨업
레벨을 1 올리고, ATK를 5 증가, maxHp를 20 증가시키는 함수 levelUp을 구현하세요.
