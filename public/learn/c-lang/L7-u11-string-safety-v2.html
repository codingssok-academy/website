문자열 안전성
— 버퍼 오버플로우

버퍼 오버플로우가 왜 위험한지, fgets와 strncpy로 어떻게 예방하는지 배웁니다.

이 유닛에서 배우는 것

  • 버퍼 오버플로우가 무엇인지 설명할 수 있습니다.
  • gets가 위험한 이유를 설명하고 fgets로 대체합니다.
  • 배열 크기보다 큰 문자열을 넣으면 일어나는 일을 압니다.
  • 안전한 입력 패턴(fgets + \n 제거)을 익숙하게 작성합니다.
  • strncpy 사용 시 \0을 수동으로 추가해야 함을 압니다.

버퍼 오버플로우란?

배열(버퍼)의 크기를 초과해서 데이터를 쓰는 것을 버퍼 오버플로우라고 합니다. 인접한 메모리가 덮어씌워져 프로그램이 비정상 종료되거나 해킹에 악용됩니다.

#include <stdio.h> int main() { char buf[5]; // 위험! 크기 초과 입력 시 버퍼 오버플로우 // gets(buf); ← 절대 사용 금지! // 안전: 크기를 명시 fgets(buf, sizeof(buf), stdin); printf("%s\n", buf); return 0; }

안전한 입력 패턴

#include <stdio.h> #include <string.h> // 안전한 문자열 입력 함수 void safe_input(char buf[], int size) { fgets(buf, size, stdin); int len = strlen(buf); if (len > 0 && buf[len-1] == '\n') buf[len-1] = '\0'; } int main() { char name[20]; printf("이름: "); safe_input(name, sizeof(name)); printf("안녕, %s!\n", name); return 0; }

핵심 정리

핵심 요약

  • 버퍼 오버플로우: 배열 크기 초과 쓰기 → 메모리 파괴
  • gets 사용 금지 — fgets(buf, sizeof(buf), stdin) 사용
  • fgets는 \n을 포함 → 후처리로 제거 필요
  • strncpy/strncat: n 제한으로 안전, 단 \0 수동 추가 필요
  • 안전한 코드 습관: 항상 크기를 명시하고 경계를 확인

전체 예제 — 안전한 회원가입

#include <stdio.h> #include <string.h> #include <ctype.h> void safe_input(char *buf, int size) { fgets(buf, size, stdin); int len = strlen(buf); if (len > 0 && buf[len-1] == '\n') buf[len-1] = '\0'; } int main() { char id[20], pw[20], name[30]; printf("아이디(20자 이하): "); safe_input(id, sizeof(id)); printf("비밀번호(20자 이하): "); safe_input(pw, sizeof(pw)); printf("이름: "); safe_input(name, sizeof(name)); printf("\n=== 가입 완료 ===\n"); printf("ID: %s 이름: %s\n", id, name); printf("PW 길이: %lu자리\n", strlen(pw)); return 0; }
