strcat 연결 패턴
strcat이 내부에서 하는 일

strcat(dest, src)은 dest의 '\0' 위치부터 src를 복사해 이어 붙인다. 마치 건물에 층을 추가하는 것처럼 뒤에 쌓인다.

버퍼 크기 주의: dest 배열이 최종 문자열 길이 + 1('\0') 이상이어야 한다. 작으면 버퍼 오버플로우 발생!
단어 배열로 문장 자동 조립
#include <stdio.h> #include <string.h> int main() { char words[5][20] = {"I", "love", "C", "language", "!"}; char sentence[200] = ""; // 빈 문자열로 초기화 (필수!) for (int i = 0; i < 5; i++) { if (i > 0 && words[i][0] != '!') { strcat(sentence, " "); // 단어 사이에 공백 추가 } strcat(sentence, words[i]); } printf("%s\n", sentence); // I love C language! return 0; }
초기화 필수: char sentence[200] = ""; 처럼 빈 문자열로 초기화하면 sentence[0] = '\0'이 된다. 이 '\0' 위치에 strcat이 첫 단어를 붙인다.
직접 입력받아 문장 만들기
int main() { int n; printf("단어 개수: "); scanf("%d", &n); char sentence[500] = ""; char word[50]; for (int i = 0; i < n; i++) { scanf("%s", word); if (i > 0) strcat(sentence, " "); strcat(sentence, word); } printf("완성된 문장: %s\n", sentence); return 0; }
응용 — 문장 양식 만들기
이름 + 나이 + 직업으로 자기소개 문장 생성

여러 필드를 조합해서 하나의 자기소개 문장을 만든다. 숫자는 sprintf로 문자열로 변환한 후 strcat으로 연결한다.

#include <stdio.h> #include <string.h> int main() { char name[30], job[30]; int age; printf("이름: "); scanf("%s", name); printf("나이: "); scanf("%d", &age); printf("직업: "); scanf("%s", job); char age_str[10]; sprintf(age_str, "%d", age); // 정수 → 문자열 char result[200] = "안녕! "; strcat(result, name); strcat(result, ", "); strcat(result, age_str); strcat(result, "세, "); strcat(result, job); printf("%s\n", result); return 0; }
sprintf 활용: 정수 age는 strcat에 바로 사용할 수 없다. sprintf(buf, "%d", age)로 먼저 문자열로 바꿔야 한다. 이것이 정수 → 문자열 변환의 표준 패턴이다.

연습 문제
Q1. 결과 예측

아래 코드의 출력 결과는?

char s[50] = "Good"; strcat(s, " "); strcat(s, "Morning"); printf("%s\n", s);
정답 보기
Good Morning
Q2. 버퍼 계산

"Hello", " ", "World", "!" 네 문자열을 모두 붙일 때, 필요한 최소 버퍼 크기는 몇 바이트인가?

정답 보기
5 + 1 + 5 + 1 + 1(\0) = 13바이트. 실용적으로 char s[50]; 처럼 여유 있게 잡는다.
Q3. 코드 완성

이름(name)과 학교(school)를 입력받아 "나는 [name], [school]에 다닙니다." 형태로 출력하는 코드를 완성하시오.

char result[200] = "나는 "; // name, school 입력 후... ___(result, ___); ___(result, ", "); ___(result, ___); ___(result, "에 다닙니다.");
정답 보기
strcat(result, name); strcat(result, ", "); strcat(result, school); strcat(result, "에 다닙니다.");
Q4. 오류 찾기

아래 코드에서 문제가 되는 부분을 찾고 이유를 설명하시오.

char s[10] = "Hello"; strcat(s, " World!!!");
정답 보기
"Hello"(5) + " World!!!"(9) + '\0'(1) = 15바이트가 필요하지만 배열은 10바이트뿐. 버퍼 오버플로우 발생!
Q5. 도전 과제

사용자에게 단어를 5개 입력받고, 쉼표(,)로 구분하여 연결하는 프로그램을 작성하시오.
예) "apple", "banana", "cherry" → "apple,banana,cherry"

정답 보기
char result[300] = "", w[50]; for(int i=0; i<5; i++) { scanf("%s",w); if(i>0) strcat(result,","); strcat(result,w); }
