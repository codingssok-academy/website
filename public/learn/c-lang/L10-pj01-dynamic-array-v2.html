동적 배열 생성
malloc으로 배열 만들기

사용자로부터 크기를 입력받아 동적으로 배열을 할당하고, 값을 채운 뒤 통계(합계/평균/최댓값)를 출력합니다.

이 프로젝트에서 만드는 것

  • 사용자 입력으로 배열 크기를 동적 결정합니다.
  • malloc으로 힙에 배열을 할당합니다.
  • 배열에 값을 입력받아 채웁니다.
  • 합계, 평균, 최댓값을 계산합니다.
  • 사용 후 반드시 free로 메모리를 해제합니다.

프로젝트 설계

STEP 1
크기 입력 및 malloc
사용자로부터 배열 크기 n을 입력받아 malloc으로 n개의 정수 배열을 할당합니다.
STEP 2
값 입력
for 반복문으로 n개의 값을 입력받아 배열에 저장합니다.
STEP 3
통계 계산 및 출력
합계, 평균, 최댓값을 구해서 출력합니다.
STEP 4
메모리 해제
free(arr); arr = NULL; 로 메모리를 반납합니다.

완성 코드

#include <stdio.h> #include <stdlib.h> int main() { int n; printf("배열 크기 입력: "); scanf("%d", &n); int *arr = (int*)malloc(sizeof(int) * n); if (arr == NULL) { printf("메모리 할당 실패\n"); return 1; } printf("%d개의 정수를 입력하세요:\n", n); for (int i = 0; i < n; i++) { printf("%d번째: ", i+1); scanf("%d", &arr[i]); } int sum = 0, maxVal = arr[0]; for (int i = 0; i < n; i++) { sum += arr[i]; if (arr[i] > maxVal) maxVal = arr[i]; } printf("합계: %d\n", sum); printf("평균: %.2f\n", (double)sum / n); printf("최댓값: %d\n", maxVal); free(arr); arr = NULL; return 0; }

실행 결과 예시

배열 크기 입력: 5 5개의 정수를 입력하세요: 1번째: 10 2번째: 20 3번째: 30 4번째: 40 5번째: 50 합계: 150 평균: 30.00 최댓값: 50
