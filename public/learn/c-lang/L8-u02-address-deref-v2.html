Chapter 8 — Unit 02

& 주소 연산자
* 역참조 연산자

포인터의 핵심 연산자 두 개를 배웁니다. &는 주소를 알아내고, *는 주소를 따라가 값을 가져옵니다.

이 유닛에서 배우는 것

  • & 연산자로 변수의 주소를 구할 수 있습니다.
  • * 연산자로 포인터가 가리키는 값을 읽을 수 있습니다.
  • * 연산자로 포인터가 가리키는 값을 변경할 수 있습니다.
  • &와 *를 함께 사용하는 패턴을 이해합니다.
  • 포인터의 화살표 관계를 그림으로 표현할 수 있습니다.

& 연산자 — 변수의 주소를 알아낸다

&(앰퍼샌드)를 변수 앞에 붙이면 그 변수가 저장된 메모리 주소를 알 수 있습니다. 집 주소를 알아내는 것과 같습니다.

int a = 42; printf("%d\n", a); // 42 — 값 출력 printf("%p\n", &a); // 0x7fff1234 — 주소 출력 (%p 사용!)

%p: 포인터(주소) 출력 형식 지정자. 주소는 %p로 출력합니다!

* 연산자 — 주소를 따라가 값을 가져온다

포인터 변수 앞에 *를 붙이면 그 포인터가 가리키는 주소의 값을 가져옵니다. 이를 역참조(dereference)라고 합니다.

&와 *의 관계 — 서로 반대

&와 *는 서로 반대 동작을 합니다. &는 값 → 주소, *는 주소 → 값입니다.

int a = 42; int *p = &a; // p에 a의 주소 저장 printf("%d\n", a); // 42 (변수 직접) printf("%p\n", &a); // 0x.. (a의 주소) printf("%p\n", p); // 0x.. (p에 저장된 주소 = a의 주소) printf("%d\n", *p); // 42 (p가 가리키는 값 = a) printf("%d\n", *&a); // 42 (*과 &는 상쇄)

* 연산자로 값 변경하기

*p = 새값;을 쓰면 포인터가 가리키는 변수의 값을 바꿀 수 있습니다. 포인터를 통해 원본을 수정하는 핵심입니다!

int a = 42; int *p = &a; printf("변경 전: %d\n", a); // 42 *p = 99; // p가 가리키는 곳(=a)에 99 저장 printf("변경 후: %d\n", a); // 99 — a가 바뀜!

완전한 포인터 활용 예제

// 포인터 연산자 종합 예제 #include <stdio.h> int main() { int a = 10; int *p = &a; // p에 a의 주소 저장 printf("a = %d\n", a); // 10 (값) printf("&a = %p\n", &a); // 주소 printf("p = %p\n", p); // 주소 (같음) printf("*p = %d\n", *p); // 10 (값) printf("&a==p : %d\n", &a==p); // 1 (같은 주소) *p = 999; // p 통해 a 변경 printf("a 변경 후 = %d\n", a); // 999 return 0; }

정리 + 연습문제

핵심 정리

핵심 정리

  • &변수: 변수의 메모리 주소를 반환 (주소 연산자)
  • *포인터: 포인터가 가리키는 주소의 값을 반환 (역참조 연산자)
  • *p = 새값: 포인터를 통해 원본 변수 값을 변경
  • 주소는 %p로 출력, 값은 %d로 출력
  • &와 *는 서로 반대 — *(&a) == a
