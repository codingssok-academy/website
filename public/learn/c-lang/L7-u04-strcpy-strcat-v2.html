strcpy와 strcat
— 복사와 연결

문자열을 복사하는 strcpy와 이어 붙이는 strcat, 그리고 버퍼 크기 주의사항을 배웁니다.

이 유닛에서 배우는 것

  • strcpy로 문자열을 다른 배열에 복사할 수 있습니다.
  • strcat으로 두 문자열을 이어 붙일 수 있습니다.
  • 대상 배열의 크기가 충분해야 함을 이해합니다.
  • strncpy, strncat으로 안전하게 복사/연결할 수 있습니다.
  • = 연산자로 문자열을 복사할 수 없는 이유를 설명합니다.

strcpy — 문자열 복사

C언어에서 str1 = str2;처럼 = 연산자로 문자열을 복사할 수 없습니다. 반드시 strcpy를 사용해야 합니다.

#include <stdio.h> #include <string.h> int main() { char src[] = "Hello"; char dst[20]; // 충분한 크기! strcpy(dst, src); printf("%s\n", dst); // Hello // 문자열 리터럴도 복사 가능 strcpy(dst, "World"); printf("%s\n", dst); // World return 0; }

strcat — 문자열 연결

strcat(dst, src)은 dst의 끝(기존 \0 위치)에 src를 이어 붙입니다. dst는 두 문자열을 합친 것보다 충분히 커야 합니다.

#include <stdio.h> #include <string.h> int main() { char full[50] = "안녕"; // 충분한 공간 strcat(full, ", "); strcat(full, "C언어!"); printf("%s\n", full); // 안녕, C언어! return 0; }

버퍼 크기 주의 — strncpy / strncat

strcpy/strcat는 크기를 확인하지 않아 위험합니다. strncpy, strncat은 복사할 최대 글자 수를 지정해 안전합니다.

#include <stdio.h> #include <string.h> int main() { char dst[10]; char src[] = "Hello World"; // strncpy: 최대 9글자만 복사 (마지막 \0 자리 확보) strncpy(dst, src, 9); dst[9] = '\0'; // 반드시 수동으로 \0 추가! printf("%s\n", dst); // Hello Wor // strncat: 최대 5글자 이어붙이기 char s[20] = "Hi"; strncat(s, " World!!!", 6); printf("%s\n", s); // Hi World return 0; }

핵심 정리

핵심 요약

  • strcpy(dst, src): src를 dst에 복사. dst 크기 충분해야 합니다.
  • strcat(dst, src): src를 dst 끝에 연결. dst 크기 = 합계+1.
  • = 연산자로 문자열 배열 복사 불가 — strcpy 사용!
  • strncpy/strncat: 최대 n글자 제한으로 안전하게 처리합니다.
  • strncpy 후 \0을 반드시 수동으로 추가해야 합니다.

전체 예제 — 이름표 만들기

#include <stdio.h> #include <string.h> int main() { char first[20], last[20]; char fullname[50]; char badge[80]; printf("성: "); scanf("%s", last); printf("이름: "); scanf("%s", first); // 전체 이름 조립 strcpy(fullname, last); strcat(fullname, first); // 이름표 만들기 strcpy(badge, "[ "); strcat(badge, fullname); strcat(badge, " 님 ]"); printf("\n%s\n", badge); printf("이름 길이: %lu글자\n", strlen(fullname)); return 0; }
