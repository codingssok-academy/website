열거형 enum — 가독성 높이기

이름 있는 정수 상수 목록을 만드는 enum을 배웁니다. 숫자 대신 의미 있는 이름으로 코드를 읽기 쉽게 만들 수 있습니다.

이 유닛에서 배우는 것

  • enum이 무엇인지 설명할 수 있습니다.
  • enum을 선언하고 변수를 만들 수 있습니다.
  • 기본 값(0부터 시작)과 직접 지정 방법을 알 수 있습니다.
  • switch문과 enum을 함께 사용할 수 있습니다.
  • 구조체 멤버로 enum을 활용할 수 있습니다.

enum이란?

enum(열거형)은 이름 있는 정수 상수의 집합입니다. if (direction == 2)보다 if (direction == RIGHT)가 훨씬 읽기 쉽습니다.

// enum 선언: 첫 번째 = 0, 자동으로 1씩 증가 enum Direction { NORTH, // 0 EAST, // 1 SOUTH, // 2 WEST // 3 }; enum Direction d = EAST; printf("방향 번호: %d\n", d); // 1 if (d == EAST) { printf("동쪽으로 이동\n"); }

값 직접 지정

enum Month { JAN = 1, // 1월부터 시작 FEB, // 2 MAR, // 3 APR, MAY, JUN, JUL, AUG, SEP, OCT, NOV, DEC }; enum Month m = MAR; printf("%d월\n", m); // 3월

switch + enum

enum은 switch 문과 함께 사용할 때 가장 빛납니다. 각 상태에 대한 처리를 명확하게 표현할 수 있습니다.

enum Season { SPRING, SUMMER, AUTUMN, WINTER }; void printSeason(enum Season s) { switch (s) { case SPRING: printf("봄 — 꽃이 핍니다\n"); break; case SUMMER: printf("여름 — 더워요\n"); break; case AUTUMN: printf("가을 — 단풍이 들어요\n"); break; case WINTER: printf("겨울 — 눈이 와요\n"); break; } } int main() { printSeason(AUTUMN); // 가을 — 단풍이 들어요 return 0; }

구조체 멤버로 enum 활용

enum Grade { GRADE_A, GRADE_B, GRADE_C, GRADE_F }; typedef struct { char name[20]; float score; enum Grade grade; // enum 멤버 } Student; Student s = {"김민준", 92.5f, GRADE_A}; printf("%s: %.1f점 (%d등급)\n", s.name, s.score, s.grade);

출발 출력
핵심 정리

핵심 정리

  • enum은 이름 있는 정수 상수의 집합입니다.
  • 기본값은 0부터 시작해 1씩 증가합니다.
  • 직접 지정: enum E { A=1, B, C };
  • switch문과 함께 쓰면 코드 가독성이 크게 향상됩니다.
  • 구조체 멤버, 함수 매개변수로도 활용 가능합니다.
