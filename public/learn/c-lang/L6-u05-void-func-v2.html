void 함수 — 결과 없이 일만 한다

반환값 없는 void 함수를 배웁니다. 출력, 메뉴 표시 등 결과를 돌려줄 필요 없이 특정 작업만 수행하는 함수의 패턴을 익힙니다.

이 유닛에서 배우는 것

  • void가 무엇을 의미하는지 설명할 수 있습니다.
  • 출력만 하는 void 함수를 직접 작성합니다.
  • void 함수에서 return을 쓰는 방법(조기 종료)을 이해합니다.
  • void vs int 함수 중 어떤 상황에 무엇을 쓸지 판단합니다.
  • printLine() 같은 유틸 함수 패턴을 익힙니다.

void란? — 아무것도 없다

void는 영어로 "빈 공간, 없음"이라는 뜻입니다. 함수의 반환 타입 자리에 void를 쓰면 "이 함수는 결과값을 돌려주지 않는다"는 의미입니다.

void 함수 기본 패턴

void 함수는 주로 화면 출력, 메뉴 표시, 여러 작업을 묶는 용도로 사용합니다.

#include <stdio.h> // 구분선 출력 함수 void printLine() { printf("====================\n"); } // 인사 출력 함수 void printWelcome() { printLine(); printf("코딩쏙에 오신 것을 환영합니다!\n"); printLine(); } int main() { printWelcome(); printf("수업을 시작합니다.\n"); printLine(); return 0; }

void 함수에서 return 사용 — 조기 종료

void 함수도 return을 사용할 수 있습니다. 값 없이 return만 쓰면 함수를 즉시 종료합니다. 조건에 따라 함수를 일찍 끝낼 때 유용합니다.

// 음수이면 출력하지 않고 종료 void printPositive(int n) { if (n < 0) { printf("양수만 출력합니다.\n"); return; // 값 없이 return → 함수 종료 } printf("값: %d\n", n); } int main() { printPositive(10); // 값: 10 printPositive(-5); // 양수만 출력합니다. printPositive(3); // 값: 3 return 0; }

void 함수 실전 활용 — printLine 패턴

실제 프로그램에서 void 함수는 반복 출력 작업을 묶어 코드를 깔끔하게 만드는 데 많이 쓰입니다.

#include <stdio.h> void printLine() { printf("--------------------\n"); } void printTitle(int num, int total) { printf("문제 %d / %d\n", num, total); } void printMenu() { printLine(); printf("1. 새 게임\n"); printf("2. 점수 보기\n"); printf("3. 종료\n"); printLine(); } int main() { printMenu(); printTitle(1, 5); return 0; }
핵심 정리

핵심 요약

  • void: 반환값이 없는 함수의 반환 타입.
  • void 함수는 출력, 작업 묶기, 메뉴 표시 등에 사용.
  • void 함수에서 return; (값 없이)은 함수를 즉시 종료합니다.
  • void 함수의 반환값을 변수에 저장하려 하면 오류입니다.
  • printLine() 같은 유틸 함수는 반복 출력을 줄여줍니다.
