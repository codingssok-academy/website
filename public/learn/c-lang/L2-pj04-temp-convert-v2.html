Level 2a - Project 04

온도 변환기

섭씨 온도를 입력받아 화씨 온도로 변환하는 프로그램을 만듭니다. 수학 공식을 코드로 옮기는 방법을 배웁니다.

프로젝트 목표

  • 수학 공식을 C 코드로 변환할 수 있습니다.
  • 곱셈, 나눗셈, 덧셈을 조합한 수식을 작성합니다.
  • 정수 나눗셈의 순서가 결과에 영향을 주는 것을 이해합니다.
  • 역변환(화씨->섭씨)도 응용할 수 있습니다.
PROJECT 04

Step 1. 공식을 코드로 옮기기

섭씨를 화씨로 바꾸는 공식은 F = C x 9 / 5 + 32입니다. 이 공식을 C 코드로 작성합니다.

정수 나눗셈은 소수점을 버립니다. 27 / 5 = 5 (5.4가 아님). 그래서 9를 먼저 곱한 후 5로 나누는 순서가 더 정확합니다.

따라해보세요
1
섭씨 0도를 화씨로 변환해보세요.
#include <stdio.h> int main() { int celsius = 0; int fahr = celsius * 9 / 5 + 32; printf("섭씨 %d도 = 화씨 %d도\n", celsius, fahr); return 0; }
섭씨 0도 = 화씨 32도
2
scanf로 섭씨를 입력받도록 바꿔보세요.
int celsius; printf("섭씨 온도: "); scanf("%d", &celsius); int fahr = celsius * 9 / 5 + 32; printf("화씨: %d도\n", fahr);
100 입력 시 "화씨: 212도"
3
체온 36도를 변환해서 확인해보세요.
// 36 * 9 / 5 + 32 = 324 / 5 + 32 = 64 + 32 = 96 // 실제 체온 화씨는 96.8이지만 int라 96 (소수점 버림)
섭씨 36도 = 화씨 96도 (정수 한계)
PROJECT 04

Step 2. 완성 코드

섭씨를 입력받아 화씨로 변환하고, 간단한 날씨 설명도 출력하는 프로그램입니다.

#include <stdio.h> int main() { /* 온도 변환기 */ int celsius; int fahr; printf("========================\n"); printf(" 온도 변환기\n"); printf("========================\n"); printf("섭씨 온도를 입력하세요: "); scanf("%d", &celsius); fahr = celsius * 9 / 5 + 32; printf("------------------------\n"); printf("섭씨:\t%d도\n", celsius); printf("화씨:\t%d도\n", fahr); printf("========================\n"); return 0; }

Q1
손계산 vs 코드 비교
쉬움
섭씨 30도를 공식에 대입하세요. 30 * 9 / 5 + 32의 결과는?
계산30 * 9 = ____ / 5 = ____ + 32 = ____
내 답안
힌트 보기
30 * 9 = 270, 270 / 5 = 54, 54 + 32 = ?
정답 보기
30 * 9 = 270 270 / 5 = 54 54 + 32 = 86 화씨 86도
Q2
역변환: 화씨 -> 섭씨
보통
화씨를 섭씨로 바꾸는 공식은 C = (F - 32) * 5 / 9입니다. 화씨 212도를 섭씨로 변환하는 코드를 작성하세요.
입력212
출력섭씨: 100도
내 답안
힌트 보기
괄호를 사용해서 F - 32를 먼저 계산합니다. (fahr - 32) * 5 / 9
정답 보기
int fahr = 212; int celsius = (fahr - 32) * 5 / 9; printf("섭씨: %d도\n", celsius); // (212 - 32) * 5 / 9 = 180 * 5 / 9 = 900 / 9 = 100

Step 3. 응용하기

섭씨-화씨 외에 켈빈(Kelvin) 변환도 추가하고, 양방향 변환기를 만들어봅니다.

응용 따라해보세요
4
켈빈 변환도 추가해보세요. 켈빈 = 섭씨 + 273
int kelvin = celsius + 273; printf("켈빈:\t%d K\n", kelvin);
섭씨 25도 -> 켈빈 298 K
Q3
도전: 3단위 동시 변환
보통
섭씨를 입력받아 화씨와 켈빈을 동시에 출력하는 코드를 작성하세요.
입력섭씨: 100
출력화씨: 212도 / 켈빈: 373 K
내 답안
힌트 보기
화씨: celsius * 9 / 5 + 32, 켈빈: celsius + 273
정답 보기
int celsius, fahr, kelvin; printf("섭씨: "); scanf("%d", &celsius); fahr = celsius * 9 / 5 + 32; kelvin = celsius + 273; printf("화씨: %d도\n", fahr); printf("켈빈: %d K\n", kelvin);

핵심 요약

  • 섭씨 -> 화씨: fahr = celsius * 9 / 5 + 32;
  • 화씨 -> 섭씨: celsius = (fahr - 32) * 5 / 9;
  • 켈빈 = 섭씨 + 273
  • 정수 나눗셈은 소수점을 버리므로 곱셈을 먼저 하는 것이 정확하다
  • 괄호 ()를 사용해 계산 순서를 명확하게 지정한다
