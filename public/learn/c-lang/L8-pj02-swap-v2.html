Swap Two Numbers with Pointers
두 변수의 값을 바꾸는 swap 함수 — C에서 포인터가 필요한 가장 대표적인 상황이다.
포인터 없이는 원본을 건드릴 수 없다. 이 프로젝트로 call by reference를 완전히 익힌다.
난이도 핵심: call by reference 포인터 매개변수 tmp 변수 패턴
왜 포인터가 필요한가? — 스택 프레임 이해
swap 함수 작동 원리 — tmp 변수 3단계
tmp 없이 바로 *pa = *pb; *pb = *pa; 하면? — 두 번째 줄 실행 시 *pa가 이미 *pb 값이라서 원래 a 값이 사라진다. tmp가 보관소 역할을 한다.
완성 코드
swap.c /* 포인터로 두 수 교환 */
#include <stdio.h>

/* swap 함수: 포인터로 원본 직접 수정 */
void swap(int *pa, int *pb) {
    int tmp = *pa; // 1단계: tmp에 a 값 보관
    *pa = *pb; // 2단계: a 자리에 b 값 저장
    *pb = tmp; // 3단계: b 자리에 보관된 값 저장
}

int main() {
    int a = 10, b = 20;
    
    printf("교환 전: a=%d, b=%d\n", a, b);
    swap(&a, &b); // 주소를 전달!
    printf("교환 후: a=%d, b=%d\n", a, b);
    
    /* 여러 번 swap */
    int x = 100, y = 200, z = 300;
    printf("\n3개 변수: x=%d, y=%d, z=%d\n", x, y, z);
    swap(&x, &y);
    swap(&y, &z);
    printf("x↔y 후 y↔z: x=%d, y=%d, z=%d\n", x, y, z);
    
    return 0;
}

교환 후: a=20, b=10

3개 변수: x=100, y=200, z=300

단계별 구현 가이드
STEP 1

함수 시그니처 작성

void swap(int *pa, int *pb)
반환값 없음. 포인터 두 개를 매개변수로 받음.

STEP 2

tmp 변수로 값 보관

int tmp = *pa;
역참조(*pa)로 a의 값을 tmp에 저장.

STEP 3

교환 수행

*pa = *pb; *pb = tmp;
포인터로 원본 메모리에 직접 씀.

STEP 4

주소 전달로 호출

swap(&a, &b);
&연산자로 주소를 전달해야 한다.

잘못된 방법
void bad(int x, int y) {
  int t = x;
  x = y; y = t;
} // 복사본만 바꿈
올바른 방법
void good(int *pa, int *pb) {
  int t = *pa;
  *pa = *pb; *pb = t;
} // 원본 수정!
도전 과제

도전 과제

1 3개 변수 회전 (rotate): a→b, b→c, c→a 순서로 값을 이동하는 rotate(int *a, int *b, int *c) 함수를 작성하라. swap 2번으로 구현할 수 있다.
2 float 버전 swap: int 대신 float를 교환하는 swap_float(float *pa, float *pb)를 작성하라. 구조는 동일하지만 타입만 바뀐다.
3 배열 최솟값/최댓값 위치 교환: int 배열에서 최솟값과 최댓값을 찾아 swap으로 위치를 바꾸는 함수를 작성하라.
연습문제
1 swap 함수에서 매개변수를 int *pa, int *pb로 받는 이유는?
C는 함수에 값을 전달할 때 기본적으로 복사(call by value)를 한다. 복사본을 수정해도 원본에 영향이 없다. 포인터(주소)를 전달하면 함수 안에서 역참조(*)로 원본 메모리에 직접 쓸 수 있기 때문에 포인터 매개변수를 사용한다.
2 swap(a, b)와 swap(&a, &b)의 차이는?
swap(a, b): a와 b의 값(10, 20)이 복사되어 전달 → 함수 안에서 복사본만 수정됨, 원본 불변.
swap(&a, &b): a와 b의 주소가 전달 → 함수 안에서 역참조로 원본을 직접 수정 가능.
3 tmp 없이 *pa = *pb; *pb = *pa;를 하면 결과가 어떻게 되는가?
a=10, b=20일 때: *pa = *pb 실행 후 a=20이 됨. 이후 *pb = *pa는 이미 20이 된 a를 b에 복사 → b=20. 결국 a=20, b=20이 되어 원래 a 값(10)이 사라진다. tmp가 반드시 필요하다.
4 swap(&a, &b) 호출 시 pa에 저장되는 값은 무엇인가?
pa에는 변수 a의 메모리 주소가 저장된다. 예를 들어 a가 0x7fff1000 주소에 있다면 pa = 0x7fff1000. *pa는 "그 주소에 있는 값", 즉 a의 값이다.
5 swap 함수를 이용해 배열을 오름차순으로 정렬하는 버블 정렬의 핵심 코드를 완성하라.
if (arr[j] > arr[j+1]) swap(&arr[j], &arr[j+1]);
이웃한 두 원소를 비교해서 순서가 잘못되면 swap으로 교환. 이 과정을 반복하면 가장 큰 값이 뒤로 밀려 정렬된다.

이번 프로젝트 핵심

  • swap은 포인터가 필요한 가장 대표적인 함수다
  • 포인터 없이는 함수 안에서 원본 변수를 바꿀 수 없다
  • 3단계: tmp = *pa → *pa = *pb → *pb = tmp
  • 호출할 때 &연산자로 주소를 전달해야 함 (swap(&a, &b))
  • 같은 패턴으로 float, char, 구조체도 교환 가능하다
