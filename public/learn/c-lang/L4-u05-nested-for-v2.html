Chapter 04 — Unit 05

중첩 for문 — 반복 속의 반복

for문 안에 또 다른 for문을 넣어 2차원 구조를 처리하는 방법을 배웁니다. 구구단과 격자 패턴이 어떻게 만들어지는지 직접 확인해 봅시다.

이 유닛에서 배우는 것

  • 중첩 for문의 구조와 실행 순서를 설명할 수 있습니다.
  • 바깥 for와 안쪽 for가 각각 몇 번 실행되는지 계산할 수 있습니다.
  • 중첩 for문으로 구구단 테이블을 만들 수 있습니다.
  • i, j 좌표를 이용해 격자 패턴을 출력할 수 있습니다.
  • 중첩 깊이가 깊어질수록 주의해야 할 점을 알 수 있습니다.

중첩 for문이란?

for문 안에 또 다른 for문을 넣은 것을 중첩 for문이라고 합니다. 바깥 for가 1번 돌 때마다 안쪽 for가 처음부터 끝까지 전부 돕니다. 시계를 생각해보세요. 분침(바깥)이 한 바퀴 돌면 초침(안쪽)은 60바퀴를 돕니다.

실행 순서를 단계별로 살펴봅시다. i=1일 때 j가 1, 2, 3, 4를 모두 돈 다음, i=2로 넘어갑니다.

// 중첩 for문 기본 구조 for (int i = 1; i <= 3; i++) { // 바깥 for for (int j = 1; j <= 4; j++) { // 안쪽 for printf("i=%d, j=%d\n", i, j); } }
따라해보세요
1
i=1~2, j=1~3 중첩 for문을 작성해 총 6쌍을 출력하세요.
for (int i = 1; i <= 2; i++) for (int j = 1; j <= 3; j++) printf("(%d,%d) ", i, j);
(1,1) (1,2) (1,3) (2,1) (2,2) (2,3)
2
i=1~3, j=1~3으로 총 9번 실행되는 중첩 for를 만들어 실행 횟수를 세어보세요.
int count = 0; for (int i = 1; i <= 3; i++) for (int j = 1; j <= 3; j++) count++; printf("총: %d번\n", count);
총: 9번
3
i=0~1, j=0~1으로 (0,0) (0,1) (1,0) (1,1) 좌표를 출력하세요.
for (int i = 0; i <= 1; i++) for (int j = 0; j <= 1; j++) printf("(%d,%d)\n", i, j);
(0,0) / (0,1) / (1,0) / (1,1) 출력

구구단 전체 출력

중첩 for문의 대표 예제는 구구단입니다. 바깥 for는 단(2~9), 안쪽 for는 곱하는 수(1~9)를 담당합니다.

// 구구단 전체 출력 (2단 ~ 9단) for (int i = 2; i <= 9; i++) { printf("\n--- %d단 ---\n", i); for (int j = 1; j <= 9; j++) { printf("%d x %d = %d\n", i, j, i * j); } }

구구단을 가로로 나란히 출력하면 격자 테이블이 됩니다. 탭(\t)을 활용합니다.

따라해보세요

for (int i = 3; i <= 3; i++) for (int j = 1; j <= 9; j++) printf("%d x %d = %d\n", i, j, i*j);

for (int j = 1; j <= 9; j++) { for (int i = 2; i <= 5; i++) printf("%d*%d=%2d\t", i, j, i*j); printf("\n"); }
각 줄에 2단~5단이 나란히 출력됩니다

좌표(i, j) 격자와 별 패턴

중첩 for문은 2차원 격자 위치를 나타낼 때 매우 유용합니다. i를 행(row), j를 열(col)로 생각하면 화면의 모든 위치를 표현할 수 있습니다.

// 직각삼각형 별 패턴 for (int i = 1; i <= 5; i++) { for (int j = 1; j <= i; j++) { // j <= i 가 핵심! printf("*"); } printf("\n"); } // 결과: // * // ** // *** // **** // *****
따라해보세요
7
i=1~4, j=1~4로 (i,j) 좌표를 격자 형태로 출력하세요. 각 행 출력 후 줄바꿈.
for (int i = 1; i <= 4; i++) { for (int j = 1; j <= 4; j++) printf("(%d,%d) ", i, j); printf("\n"); }
4행 4열의 좌표 격자가 출력됩니다
8
5x5 별(*)로 채운 정사각형을 출력하세요.
for (int i = 1; i <= 5; i++) { for (int j = 1; j <= 5; j++) printf("* "); printf("\n"); }
5행 5열의 별 정사각형 출력
9
숫자로 된 직각삼각형을 출력하세요. i=5까지, j는 j 값 자체를 출력.
for (int i = 1; i <= 5; i++) { for (int j = 1; j <= i; j++) printf("%d", j); printf("\n"); }
1 / 12 / 123 / 1234 / 12345

중첩 깊이 주의사항

중첩이 깊어질수록 실행 횟수가 폭발적으로 늘어납니다. 3중 중첩이면 n³번, 4중이면 n⁴번입니다. 가능하면 2중 이하로 유지하세요.

중첩 for문 핵심 정리

  • 바깥 for가 1번 돌 때 안쪽 for는 처음부터 끝까지 전부 돈다.
  • 총 실행 횟수 = 바깥 범위 × 안쪽 범위 (2중 기준)
  • 구구단: 바깥=단(2~9), 안쪽=수(1~9) → 8×9=72번
  • 별 패턴: j <= i 조건으로 삼각형, j <= 상수로 직사각형
  • 중첩이 깊을수록 실행 횟수 폭발 → 2중 이하 권장
