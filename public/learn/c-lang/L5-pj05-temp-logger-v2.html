온도 기록기

7일 동안의 온도를 float 배열에 저장하고, 평균 온도와 최고·최저 온도가 있는 요일을 출력합니다.

이 프로젝트에서 배우는 것

  • float 배열로 실수 데이터를 저장하는 방법을 익힙니다.
  • 문자열 배열로 요일 이름을 저장하고 출력합니다.
  • float 비교 연산으로 최고/최저를 찾습니다.
  • 평균 이상/이하 요일을 필터링합니다.

float 배열과 문자열 배열

온도는 소수점이 있으므로 float 배열을 씁니다. 요일 이름은 문자열 포인터 배열로 저장합니다.

float temp[7]; char *days[7] = {"월", "화", "수", "목", "금", "토", "일"}; printf("7일 온도 입력 (소수 가능):\n"); for (int i = 0; i < 7; i++) { printf("%s요일: ", days[i]); scanf("%f", &temp[i]); // float 입력은 %f }

평균, 최고, 최저 계산

float sum = 0; float maxT = temp[0], minT = temp[0]; int maxD = 0, minD = 0; for (int i = 0; i < 7; i++) { sum += temp[i]; if (temp[i] > maxT) { maxT = temp[i]; maxD = i; } if (temp[i] < minT) { minT = temp[i]; minD = i; } } float avg = sum / 7; // float/int = float (형변환 불필요) printf("평균: %.1f°C\n", avg); printf("최고: %.1f°C (%s요일)\n", maxT, days[maxD]); printf("최저: %.1f°C (%s요일)\n", minT, days[minD]);
따라해보세요
1
float sum에서 float/7은 자동으로 float입니다. int sum이라면 어떻게 해야 할까요?
(float)sum / 7 또는 sum / 7.0f 로 강제 변환

완성 코드 & 평균 이상 요일 출력

#include <stdio.h> int main() { float temp[7] = {22.5, 25.0, 23.3, 30.1, 24.8, 20.2, 26.7}; char *days[7] = {"월","화","수","목","금","토","일"}; float sum=0, maxT=temp[0], minT=temp[0]; int maxD=0, minD=0; for (int i=0;i<7;i++) { sum += temp[i]; if(temp[i]>maxT){maxT=temp[i];maxD=i;} if(temp[i]<minT){minT=temp[i];minD=i;} } float avg = sum / 7; printf("평균: %.1f°C\n", avg); printf("최고: %.1f°C (%s요일)\n", maxT, days[maxD]); printf("최저: %.1f°C (%s요일)\n", minT, days[minD]); printf("평균 이상인 요일: "); for (int i=0;i<7;i++) if (temp[i] >= avg) printf("%s요일 ", days[i]); printf("\n"); return 0; }

핵심 정리

  • float 배열: float temp[7], scanf는 %f, printf는 %.1f
  • 문자열 포인터 배열: char *days[7] = {"월",...}
  • float/int = float (int끼리 나눌 때만 형변환 필요)
  • 이전값 참조: temp[i] - temp[i-1] (i=1부터 시작)
  • %+.1f 형식: 양수면 +, 음수면 - 자동 출력
