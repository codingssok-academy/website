struct 선언, 초기화, 멤버 접근

구조체 변수를 선언하고 초기화하는 세 가지 방법을 배웁니다. 멤버에 접근하고 값을 읽고 쓰는 방법도 익혀봅시다.

이 유닛에서 배우는 것

  • 구조체 변수를 선언하고 초기화하는 방법 3가지를 알 수 있습니다.
  • 중괄호 초기화({})로 한 번에 값을 넣을 수 있습니다.
  • 멤버별 개별 대입 방법을 사용할 수 있습니다.
  • 구조체 변수를 다른 변수에 복사할 수 있습니다.
  • 문자열 멤버는 strcpy를 사용해야 함을 이해합니다.

초기화 방법 1: 중괄호 초기화

구조체 변수를 선언할 때 중괄호 {}를 사용하면 선언과 동시에 모든 멤버를 초기화할 수 있습니다. 멤버 순서대로 값을 나열합니다.

struct Student { char name[20]; int age; float score; }; // 방법 1: 중괄호 초기화 (선언 순서대로) struct Student s1 = {"김민준", 15, 88.5f}; // C99 이후: 지정 초기화 (순서 상관없이 멤버 이름 지정) struct Student s2 = { .age = 16, .score = 92.0f, .name = "이서연" };

초기화 방법 2: 개별 멤버 대입

선언 후 각 멤버에 따로 값을 넣을 수 있습니다. 문자열 멤버는 =로 직접 대입할 수 없으므로 반드시 strcpy()를 사용합니다.

#include <string.h> // strcpy 사용하려면 필요 struct Student s3; // 먼저 선언 strcpy(s3.name, "박지호"); // 문자열: strcpy 필수 s3.age = 14; // 정수: 직접 대입 s3.score = 75.0f; // 실수: 직접 대입 // 절대 이렇게 하면 안 됨! // s3.name = "박지호"; ← 컴파일 오류

초기화 방법 3: 구조체 복사 대입

구조체 변수끼리는 =로 직접 복사할 수 있습니다. 모든 멤버가 한 번에 복사됩니다.

struct Student s1 = {"김민준", 15, 88.5f}; struct Student s2; s2 = s1; // s1의 모든 멤버가 s2로 복사됨 printf("%s %d %.1f\n", s2.name, s2.age, s2.score); // 출력: 김민준 15 88.5 s2.age = 16; // s2를 수정해도 s1은 그대로 printf("s1.age=%d, s2.age=%d\n", s1.age, s2.age); // 출력: s1.age=15, s2.age=16

전체 예제: 세 가지 방법 비교

#include <stdio.h> #include <string.h> struct Student { char name[20]; int age; float score; }; int main() { // 방법 1: 중괄호 struct Student a = {"김민준", 15, 88.5f}; // 방법 2: 개별 대입 struct Student b; strcpy(b.name, "이서연"); b.age = 16; b.score = 91.0f; // 방법 3: 복사 struct Student c = a; printf("%s %d %.1f\n", a.name, a.age, a.score); printf("%s %d %.1f\n", b.name, b.age, b.score); printf("%s %d %.1f\n", c.name, c.age, c.score); return 0; }

0으로 초기화 (memset)

구조체의 모든 멤버를 0으로 초기화하고 싶을 때 memset() 함수나 = {0}을 사용합니다.

#include <string.h> struct Student s; // 방법 1: = {0} (C99, 가장 간단) struct Student s1 = {0}; // 모든 멤버 0/'\0'으로 초기화 // 방법 2: memset memset(&s, 0, sizeof(s)); // 모든 바이트를 0으로 설정 printf("name: [%s]\n", s.name); // 빈 문자열 printf("age: %d\n", s.age); // 0 printf("score: %.1f\n", s.score); // 0.0
핵심 정리

핵심 정리

  • 중괄호 초기화: struct S v = {"값", 숫자, 실수}; — 선언 시 순서대로
  • 지정 초기화(C99): .멤버명 = 값 — 순서 상관없이 지정
  • 개별 대입: 선언 후 v.멤버 = 값으로 하나씩
  • 문자열 멤버는 반드시 strcpy(v.name, "값") 사용
  • 구조체끼리 =으로 복사 가능 (모든 멤버 복사됨)
