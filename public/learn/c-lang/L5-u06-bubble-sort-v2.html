배열 정렬 —
버블 정렬

인접한 두 원소를 비교해 교환하며 정렬하는 버블 정렬을 배웁니다. 이중 for, swap 패턴, temp 변수 사용법을 익힙니다.

이 유닛에서 배우는 것

  • 버블 정렬의 개념과 동작 방식을 설명할 수 있습니다.
  • temp 변수를 이용한 swap 패턴을 작성할 수 있습니다.
  • 이중 for 구조로 버블 정렬을 구현할 수 있습니다.
  • 패스(pass)마다 최댓값이 뒤로 확정되는 원리를 이해합니다.
  • 오름차순/내림차순 정렬 방향을 바꿀 수 있습니다.

버블 정렬이란?

버블 정렬(Bubble Sort)은 인접한 두 원소를 비교해 순서가 잘못됐으면 교환(swap)하는 과정을 반복합니다. 큰 값이 거품처럼 오른쪽으로 떠오르는 모양이라 버블 정렬이라고 합니다.

swap: 두 변수 값 교환

두 변수의 값을 교환하려면 임시 변수 temp가 필요합니다. temp 없이 바로 바꾸면 한 값이 덮어써집니다.

// swap 패턴 — 반드시 이 순서로! int temp = arr[i]; // ① 임시 저장 arr[i] = arr[i+1]; // ② 덮어쓰기 arr[i+1] = temp; // ③ 임시값 복원

버블 정렬 — 이중 for 구조

바깥 루프는 패스(pass) 횟수, 안쪽 루프는 인접 비교를 담당합니다. 패스마다 끝에서 한 칸씩 범위가 줄어듭니다.

int arr[] = {5, 3, 8, 1, 4}; int n = 5; for (int i = 0; i < n - 1; i++) { // 패스 횟수: n-1 for (int j = 0; j < n - 1 - i; j++) { // 범위: 뒤에서 i칸 제외 if (arr[j] > arr[j+1]) { // 앞이 더 크면 교환 int temp = arr[j]; arr[j] = arr[j+1]; arr[j+1] = temp; } } }

패스별 정렬 과정 — 단계 시각화

왜 n-1-i인가: 패스 i가 끝나면 뒤에서 i+1개는 이미 확정되었으므로, 그 칸들은 다시 비교할 필요가 없습니다. 안쪽 루프 범위를 줄여 효율을 높입니다.

완성 코드 — 오름차순 정렬

#include <stdio.h> int main() { int arr[] = {64, 34, 25, 12, 22}; int n = 5; // 버블 정렬 for (int i = 0; i < n - 1; i++) { for (int j = 0; j < n - 1 - i; j++) { if (arr[j] > arr[j+1]) { int temp = arr[j]; arr[j] = arr[j+1]; arr[j+1] = temp; } } } // 출력 for (int i = 0; i < n; i++) printf("%d ", arr[i]); // 출력: 12 22 25 34 64 return 0; }

내림차순으로 바꾸기

조건을 >에서 <로 바꾸면 큰 값이 앞으로 이동합니다.

핵심 정리

  • 버블 정렬: 인접 두 원소 비교 → 잘못된 순서면 swap
  • swap은 반드시 temp 변수를 사용 (순서: temp=a, a=b, b=temp)
  • 이중 for: 바깥(패스 횟수), 안쪽(인접 비교, 범위 축소)
  • 안쪽 루프 범위: j < n-1-i — 뒤쪽 확정 칸 제외
  • > → 오름차순, < → 내림차순
