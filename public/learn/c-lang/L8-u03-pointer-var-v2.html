int *p = &a;
포인터 변수와 타입 일치

포인터 선언의 전체 형태를 이해하고, 타입이 왜 반드시 일치해야 하는지 배웁니다.

이 유닛에서 배우는 것

  • int *p = &a;의 각 부분이 무엇을 의미하는지 설명합니다.
  • 포인터와 변수의 타입이 일치해야 하는 이유를 이해합니다.
  • 다양한 타입의 포인터를 선언하고 사용합니다.
  • 타입 불일치 시 발생하는 문제를 파악합니다.
  • NULL 포인터의 의미와 사용법을 배웁니다.

int *p = &a; 완전 해부

포인터 선언의 완전한 형태를 부분별로 이해합시다.

타입이 일치해야 하는 이유

포인터의 타입은 역참조 시 몇 바이트를 읽을지를 결정합니다. int 포인터는 4바이트, char 포인터는 1바이트를 읽습니다.

int a = 65; int *ip = &a; // O — int 변수에 int* char *cp = &a; // X — 타입 불일치 (경고/오류) // 올바른 사용 int n = 10; int *p1 = &n; // int* → int 변수 float f = 3.14; float *p2 = &f; // float* → float 변수 char c = 'A'; char *p3 = &c; // char* → char 변수

* 위치 스타일

C언어에서 *의 위치는 세 가지 스타일이 있습니다. 모두 같은 의미이지만 관습적으로 변수명 쪽에 붙이는 스타일이 많습니다.

주의: int* p, q;는 p만 포인터이고 q는 일반 int! 헷갈리면 한 줄에 하나씩 선언하세요.

// 헷갈리는 예시 int* p, q; // p는 int*, q는 int (주의!) // 명확하게 int *p; // p는 포인터 int q; // q는 일반 int

NULL 포인터

포인터에 아직 가리킬 대상이 없을 때는 NULL을 대입합니다. NULL은 주소 0을 의미하며, "아무것도 가리키지 않음"을 나타냅니다.

int *p = NULL; // 아직 가리킬 곳 없음 // NULL 체크 후 사용 (안전) if (p != NULL) { *p = 10; // 안전하게 역참조 } // NULL 체크 없이 역참조 → 크래시! // *p = 10; — segmentation fault 발생

정리 + 연습문제

핵심 정리

핵심 정리

  • int *p = &a;: 포인터 p를 선언하고 a의 주소로 초기화
  • 포인터 타입 = 가리키는 변수의 타입과 반드시 일치
  • * 위치: int *p / int* p 모두 동일 — 혼합 사용 주의
  • NULL 포인터: 가리킬 대상 없음, 역참조 전 반드시 NULL 체크
  • 타입이 다르면 읽는 바이트 수가 달라져 잘못된 값 반환
