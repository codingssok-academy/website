L7 문자열 PROJECT 03 중급
문자열
뒤집기
String Reverse — 양 끝에서 중앙으로
"hello"를 "olleh"로 바꾸려면?
배열의 첫 글자와 마지막 글자를 맞바꾸고, 안쪽으로 한 칸씩 이동하면 된다.
포인터 i(왼쪽)와 j(오른쪽)가 서로 만날 때까지 반복 — 이것이 양방향 포인터(Two Pointer) 패턴이다.

학습 목표

양방향 포인터(i, j)로 문자 교환하는 원리 이해
strlen()로 끝 인덱스 계산 (len-1)
임시 변수(temp)를 이용한 swap 패턴 습득
단어 뒤집기 → 문장 전체 뒤집기 응용
코딩쏙 C언어 · L7 문자열 · PJ-03
Two Pointer Pattern
핵심 알고리즘 — 양방향 포인터 Swap
swap의 원리 — 임시 변수(temp)

두 값을 맞바꾸려면 임시 저장소(temp)가 반드시 필요하다. 예를 들어 컵 A와 B의 음료를 바꾸려면 빈 컵 C가 있어야 하는 것과 같다.

// swap 기본 패턴 char temp = str[i]; // ① str[i]를 temp에 저장 str[i] = str[j]; // ② str[j] 값을 str[i]에 덮어쓰기 str[j] = temp; // ③ temp(원래 str[i])를 str[j]에 넣기
단계별 뒤집기 추적 — "hello"
핵심 조건: i < j 일 때만 swap. i와 j가 같거나 교차하면 이미 뒤집기 완료!
완성 코드
#include <stdio.h> #include <string.h> void reverse_str(char str[]) { int i = 0; int j = strlen(str) - 1; // 마지막 인덱스 while (i < j) { char temp = str[i]; str[i] = str[j]; str[j] = temp; i++; // 왼쪽 → 오른쪽 j--; // 오른쪽 → 왼쪽 } } int main() { char word[100]; printf("단어 입력: "); scanf("%s", word); reverse_str(word); printf("뒤집은 결과: %s\n", word); return 0; }
전체 프로그램 구현
문자열 길이별 동작 확인
응용 — 단어별 뒤집기 (문장 내 각 단어 처리)

문장 전체가 아니라 공백으로 구분된 각 단어를 독립적으로 뒤집는 패턴이다.

#include <stdio.h> #include <string.h> void reverse_str(char s[], int start, int end) { while (start < end) { char t = s[start]; s[start] = s[end]; s[end] = t; start++; end--; } } void reverse_words(char str[]) { int start = 0, len = strlen(str); for (int i = 0; i <= len; i++) { if (str[i] == ' ' || str[i] == '\0') { reverse_str(str, start, i - 1); // 단어 뒤집기 start = i + 1; // 다음 단어 시작점 } } } int main() { char sentence[200]; printf("문장 입력: "); fgets(sentence, sizeof(sentence), stdin); // fgets가 \n 포함 — 제거 sentence[strcspn(sentence, "\n")] = '\0'; reverse_words(sentence); printf("결과: %s\n", sentence); return 0; }
strcspn(s, "\n"): s에서 '\n'이 처음 나타나는 인덱스 반환. fgets로 받은 줄바꿈을 '\0'으로 교체하는 깔끔한 패턴이다.
회문(Palindrome) 확인으로 응용

회문은 앞으로 읽어도 뒤로 읽어도 같은 단어다 (예: "level", "racecar"). 뒤집기 알고리즘을 그대로 활용할 수 있다.

int is_palindrome(char str[]) { int i = 0, j = strlen(str) - 1; while (i < j) { if (str[i] != str[j]) return 0; // 불일치 → 회문 아님 i++; j--; } return 1; // 모두 일치 → 회문 }
연습 문제
Q1. 기초 확인

"cat"을 reverse_str() 함수로 뒤집을 때, swap이 몇 번 실행되는가? 그리고 최종 결과는?

힌트 보기
len = 3, i=0/j=2 일 때 한 번 swap. i=1/j=1이면 i<j 조건 불만족.
정답 보기
swap 1번 → "tac"
Q2. 코드 완성

아래 코드에서 빈칸을 채워 reverse_str 함수를 완성하시오.

void reverse_str(char str[]) { int i = 0, j = ___________; // 마지막 인덱스 while (___________) { // 반복 조건 char temp = str[i]; str[i] = ___________; str[j] = temp; i++; j--; } }
정답 보기
j = strlen(str) - 1; // 조건: i < j // str[j];
Q3. 오류 찾기

아래 코드에는 버그가 있다. 찾아서 고치시오.

void reverse_str(char str[]) { int i = 0, j = strlen(str); // 버그! while (i < j) { char t = str[i]; str[i] = str[j]; str[j] = t; i++; j--; } }
힌트 보기
strlen("hello") = 5. str[5]은 '\0'(null terminator)이다. 이걸 str[0]과 swap하면?
정답 보기
j = strlen(str) 이면 j가 '\0' 위치를 가리킴. 반드시 j = strlen(str) - 1 로 수정해야 한다.
