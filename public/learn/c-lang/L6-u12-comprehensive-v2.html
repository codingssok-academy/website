L6 함수 마인드맵

종합 예제 — 함수로 계산기 리팩토링

함수 없이 만든 계산기를 각 연산을 함수로 분리해 개선합니다. 코드가 훨씬 읽기 쉽고 수정이 쉬워집니다.

#include <stdio.h> // 프로토타입 int add(int a, int b); int sub(int a, int b); int mul(int a, int b); float divF(int a, int b); void printResult(char op, int a, int b, float result); int main() { int x = 10, y = 3; printResult('+', x, y, add(x, y)); printResult('-', x, y, sub(x, y)); printResult('*', x, y, mul(x, y)); printResult('/', x, y, divF(x, y)); return 0; } int add(int a, int b) { return a + b; } int sub(int a, int b) { return a - b; } int mul(int a, int b) { return a * b; } float divF(int a, int b) { return (float)a / b; } void printResult(char op, int a, int b, float result) { printf("%d %c %d = %.2f\n", a, op, b, result); }

Q4
재귀 작성
보통
자연수 n이 주어질 때 각 자릿수를 더하는 재귀 함수 digitSum(int n)을 작성하세요. (예: digitSum(123) = 6)
내 답안
힌트 보기
n % 10이 마지막 자릿수, n / 10은 나머지 숫자입니다. 기저: n이 0이면 0.
정답 보기
int digitSum(int n) { if (n == 0) return 0; return (n % 10) + digitSum(n / 10); } // digitSum(123) = 3 + digitSum(12) = 3 + 2 + digitSum(1) = 3+2+1 = 6

핵심 정리

L6 함수 챕터 최종 요약

  • 함수: 코드 묶음에 이름. 정의(반환타입 이름(매개변수){본문}) + 호출(이름()).
  • 매개변수/인자: 정의 쪽이 매개변수, 호출 쪽이 인자. call by value.
  • return: 함수 즉시 종료 + 값 반환. 반환타입 일치 필수.
  • void: 반환값 없음. 출력/작업 전용 함수.
  • 스코프: 지역 변수는 블록 안에서만, 전역은 어디서든.
  • 프로토타입: 함수 선언을 미리 알려줌 → main 아래 정의 가능.
  • 배열 전달: 주소 전달 → 원본 수정됨. size도 같이 전달.
  • 재귀: 자기 호출. 기저 조건 필수. 팩토리얼/피보나치.
  • static 지역 변수: 함수가 끝나도 값 유지. 카운터 패턴.
