숫자 퀴즈 게임

연산 퀴즈를 출제하고, 사용자 답과 정답을 모두 출력합니다. if문 없이 만드는 퀴즈 게임으로, Level 2c의 모든 내용을 종합합니다.

이 프로젝트에서 배우는 것

  • 고정된 값으로 연산 문제를 출제할 수 있다
  • scanf로 사용자 답을 입력받을 수 있다
  • 프로그램이 정답을 계산해서 출력할 수 있다
  • Level 2c의 모든 연산자(+, -, *, /, %, ++, +=)를 종합 활용한다

숫자 퀴즈 게임 코드

프로그램이 문제를 출제하고, 사용자가 답을 입력하면, 사용자의 답과 정답을 모두 출력합니다. if문이 없으므로 맞았는지 자동 판별은 하지 않고, 눈으로 비교합니다.

#include <stdio.h> int main(void) { int answer; int score = 0; // 퀴즈 1: 더하기 printf("[Q1] 17 + 25 = ? "); scanf("%d", &answer); printf(" 내 답: %d, 정답: %d\n\n", answer, 17 + 25); // 퀴즈 2: 곱하기 printf("[Q2] 8 * 7 = ? "); scanf("%d", &answer); printf(" 내 답: %d, 정답: %d\n\n", answer, 8 * 7); // 퀴즈 3: 나머지 printf("[Q3] 100 %% 7 = ? "); scanf("%d", &answer); printf(" 내 답: %d, 정답: %d\n\n", answer, 100 % 7); // 퀴즈 4: 정수 나눗셈 printf("[Q4] 29 / 5 = ? (정수) "); scanf("%d", &answer); printf(" 내 답: %d, 정답: %d\n\n", answer, 29 / 5); // 퀴즈 5: 복합 연산 printf("[Q5] 3 + 4 * 5 = ? "); scanf("%d", &answer); printf(" 내 답: %d, 정답: %d\n\n", answer, 3 + 4 * 5); printf("퀴즈 끝! 위 결과를 눈으로 비교해보세요.\n"); return 0; }

핵심 요약

  • 프로그램이 계산한 정답과 사용자 답을 비교 출력할 수 있다
  • %%로 printf에서 퍼센트 기호를 출력한다
  • if문 없이도 "답 보여주기" 방식의 퀴즈 게임을 만들 수 있다
  • Level 2c 종합: +, -, *, /, %, +=, -=, *=, /=, %=, ++, --, 우선순위, 괄호
