간단 계산기 v2

switch문과 char 타입으로 연산자를 선택하고, 0으로 나누기 오류까지 완벽하게 처리하는 계산기를 만들어봅니다.

이 프로젝트에서 배우는 것

  • char 타입으로 연산자 문자를 입력받고 저장할 수 있습니다.
  • switch문으로 연산자에 따라 다른 계산을 실행할 수 있습니다.
  • 0으로 나누는 오류를 if로 사전에 막을 수 있습니다.
  • 나머지(%) 연산과 실수 결과(double)를 다룰 수 있습니다.
  • do-while로 반복 실행 여부를 사용자에게 물어볼 수 있습니다.

두 수와 연산자 입력받기

계산기는 세 가지 정보가 필요합니다. 첫 번째 수, 연산자(+, -, *, /), 두 번째 수. 수는 int, 연산자는 문자이므로 char에 저장합니다.

주의: scanf(" %c", &op)에서 %c 앞에 공백을 반드시 씁니다. 앞서 입력한 줄바꿈(\n)이 남아 있으면 공백 없이 쓰면 그 줄바꿈이 op에 잡힙니다.

switch문으로 연산자 분기

switch(op)는 op 값이 무엇인지 확인해서 해당 case로 점프합니다. if-else if를 여러 개 쓰는 것보다 훨씬 읽기 쉽습니다.

0으로 나누기 오류 처리

수학에서 0으로 나누는 것은 정의되지 않습니다. C언어에서 정수를 0으로 나누면 프로그램이 강제 종료됩니다. 반드시 if(b == 0)으로 먼저 확인해야 합니다.

0으로 나누기 = 프로그램 충돌! case '/'에서 계산 전에 b가 0인지 반드시 확인하세요. 확인 없이 a / b를 쓰면 런타임 에러가 발생합니다.
#include <stdio.h> int main() { int a, b; char op; printf("첫 번째 수: "); scanf("%d", &a); printf("연산자 (+,-,*,/): "); scanf(" %c", &op); // 공백 필수! printf("두 번째 수: "); scanf("%d", &b); switch (op) { case '+': printf("%d + %d = %d\n", a, b, a + b); break; case '-': printf("%d - %d = %d\n", a, b, a - b); break; case '*': printf("%d * %d = %d\n", a, b, a * b); break; case '/': if (b == 0) { // 0 나누기 체크! printf("오류: 0으로 나눌 수 없습니다.\n"); } else { printf("%d / %d = %d\n", a, b, a / b); } break; default: printf("잘못된 연산자입니다.\n"); } return 0; }
실행 결과 확인
케이스 1 — 정상 나누기
입력: 10 / 3
첫 번째 수: 10 연산자 (+,-,*,/): / 두 번째 수: 3 10 / 3 = 3
정수 나누기이므로 소수점은 버려집니다
케이스 2 — 0으로 나누기
입력: 5 / 0
첫 번째 수: 5 연산자 (+,-,*,/): / 두 번째 수: 0 오류: 0으로 나눌 수 없습니다.
프로그램이 안전하게 오류를 알려주고 종료합니다

확장 1 — 나머지(%) 연산 추가

나머지 연산자 %는 정수를 나눈 나머지를 구합니다. 예를 들어 10 % 3 = 1이 됩니다. switch에 case '%'를 추가하면 됩니다.

단, %도 0으로 나누는 것은 불가능합니다. 나누기와 동일하게 b == 0 체크가 필요합니다.

확장 2 — 실수 결과 출력

정수 나누기 10 / 3은 3이 됩니다. 소수점까지 표시하려면 피연산자를 double로 변환해야 합니다. (double)a / b 처럼 캐스팅합니다.

확장 3 — 연속 계산 (다시 하시겠습니까?)

한 번 계산하고 끝나면 불편합니다. do-while로 계산 후 계속할지 물어봅니다. y를 누르면 반복, 그 외엔 종료합니다.

#include <stdio.h> int main() { int a, b; char op, again; do { printf("첫 번째 수: "); scanf("%d", &a); printf("연산자 (+,-,*,/,%%): "); scanf(" %c", &op); printf("두 번째 수: "); scanf("%d", &b); switch (op) { case '+': printf("= %d\n", a + b); break; case '-': printf("= %d\n", a - b); break; case '*': printf("= %d\n", a * b); break; case '/': if (b == 0) printf("오류: 0으로 나눌 수 없습니다.\n"); else printf("= %.2f\n", (double)a / b); // 실수 결과 break; case '%': if (b == 0) printf("오류: 0으로 나눌 수 없습니다.\n"); else printf("= %d\n", a % b); // 나머지 break; default: printf("잘못된 연산자입니다.\n"); } printf("다시 하시겠습니까? (y/n): "); scanf(" %c", &again); } while (again == 'y'); printf("계산기를 종료합니다.\n"); return 0; }
확장 기능 실행 예시
첫 번째 수: 7 연산자 (+,-,*,/,%): % 두 번째 수: 3 = 1 다시 하시겠습니까? (y/n): y 첫 번째 수: 10 연산자 (+,-,*,/,%): / 두 번째 수: 3 = 3.33 다시 하시겠습니까? (y/n): n 계산기를 종료합니다.

전체 코드 (완성본)

지금까지 만든 계산기 v2 전체 코드입니다. 주석을 읽으며 각 부분의 역할을 확인하세요.

#include <stdio.h> int main() { int a, b; /* 두 정수 피연산자 */ char op, again; /* 연산자, 반복 여부 문자 */ do { /* ① 입력 */ printf("\n첫 번째 수: "); scanf("%d", &a); printf("연산자 (+ - * / %%): "); scanf(" %c", &op); /* 공백으로 앞 줄바꿈 무시 */ printf("두 번째 수: "); scanf("%d", &b); /* ② 계산 */ switch (op) { case '+': printf("%d + %d = %d\n", a, b, a + b); break; case '-': printf("%d - %d = %d\n", a, b, a - b); break; case '*': printf("%d * %d = %d\n", a, b, a * b); break; case '/': if (b == 0) { printf("오류: 0으로 나눌 수 없습니다.\n"); } else { printf("%d / %d = %.2f\n", a, b, (double)a / b); } break; case '%': if (b == 0) { printf("오류: 0으로 나눌 수 없습니다.\n"); } else { printf("%d %% %d = %d\n", a, b, a % b); } break; default: printf("알 수 없는 연산자 '%c'입니다.\n", op); } /* ③ 반복 여부 */ printf("다시 하시겠습니까? (y/n): "); scanf(" %c", &again); } while (again == 'y'); printf("계산기를 종료합니다.\n"); return 0; }

이 프로젝트에서 배운 것

  • char 타입에 scanf(" %c", &op)로 문자 한 글자를 입력받는다.
  • switch문은 값이 딱 정해진 분기에 if-else if보다 읽기 쉽다.
  • 각 case 마지막에 break;가 없으면 아래 case까지 실행된다. 반드시 쓸 것.
  • /와 % 연산 전에 b == 0 체크는 필수다.
  • (double)a / b로 형 변환하면 소수점 결과를 얻을 수 있다.
  • do-while은 먼저 실행하고 나중에 조건을 확인한다. 최소 1회 실행이 보장된다.
