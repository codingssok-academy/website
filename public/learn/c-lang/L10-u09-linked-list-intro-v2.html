연결 리스트 개념
노드와 next 포인터

배열과 다른 방식으로 데이터를 연결하는 연결 리스트를 배웁니다. 노드 구조체와 next 포인터의 역할을 이해합니다.

이 유닛에서 배우는 것

  • 배열과 연결 리스트의 차이를 설명할 수 있습니다.
  • 노드 구조체(data + next 포인터)를 정의합니다.
  • head 포인터의 역할을 이해합니다.
  • NULL로 리스트 끝을 표시하는 방법을 압니다.
  • 연결 리스트의 장단점을 설명할 수 있습니다.

배열 vs 연결 리스트

배열은 메모리가 연속으로 배치되어 인덱스로 빠르게 접근할 수 있지만 크기를 바꾸기 어렵습니다. 연결 리스트는 각 데이터가 흩어져 있고 포인터로 연결되어 삽입/삭제가 쉽습니다.

노드 구조체 정의

// 연결 리스트 노드 구조체 typedef struct Node { int data; // 데이터 struct Node *next; // 다음 노드를 가리키는 포인터 } Node; // 노드 생성 함수 Node* createNode(int data) { Node *n = (Node*)malloc(sizeof(Node)); if (n == NULL) return NULL; n->data = data; n->next = NULL; // 처음엔 다음 노드 없음 return n; }
struct 안에서 자기 자신의 타입을 가리킬 때는 struct Node *next 처럼 struct 키워드를 앞에 붙여야 합니다.

연결 리스트 만들기

#include <stdio.h> #include <stdlib.h> typedef struct Node { int data; struct Node *next; } Node; int main() { // 노드 3개 생성 Node *n1 = (Node*)malloc(sizeof(Node)); Node *n2 = (Node*)malloc(sizeof(Node)); Node *n3 = (Node*)malloc(sizeof(Node)); n1->data = 10; n1->next = n2; // n1 → n2 n2->data = 20; n2->next = n3; // n2 → n3 n3->data = 30; n3->next = NULL; // n3 → 끝 Node *head = n1; // 첫 번째 노드 // 순회 (traverse) Node *curr = head; while (curr != NULL) { printf("%d ", curr->data); curr = curr->next; // 다음 노드로 이동 } printf("\n"); // 출력: 10 20 30 free(n1); free(n2); free(n3); return 0; }

2
리스트 끝 표시
쉬움
연결 리스트의 마지막 노드의 next에는 무엇을 넣나요?
힌트 / 정답 보기
NULL을 넣습니다. next == NULL이면 더 이상 다음 노드가 없다는 표시입니다. 순회 시 curr != NULL 조건으로 끝을 감지합니다.
3
배열 vs 연결 리스트
보통
연결 리스트가 배열보다 유리한 경우는?
① 임의 인덱스로 빠른 접근이 필요할 때
② 중간에 자주 삽입/삭제가 필요할 때
③ 메모리를 적게 쓸 때
④ 캐시 효율이 중요할 때
힌트 / 정답 보기
정답: ② 연결 리스트는 포인터만 변경하면 O(1)로 삽입/삭제가 됩니다. 배열은 중간 삽입 시 뒤로 밀어야 해서 O(n)이 걸립니다.

리스트 길이 세기
어려움

int length(Node *head) { int count = 0; Node *curr = head; while (curr != NULL) { count++; curr = curr->next; } return count; }
핵심 정리

핵심 정리

  • 연결 리스트 — 노드들이 포인터로 연결된 자료구조
  • 노드 구성 — data(값) + next(다음 노드 주소)
  • head — 첫 번째 노드를 가리키는 포인터
  • NULL — 리스트 끝을 나타냄
  • 순회 — curr = head; while(curr != NULL) { curr = curr->next; }
