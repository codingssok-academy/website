문자열이란?
— char 배열과 \0

"Hello"는 글자 5개인데 왜 6바이트일까요? 문자열의 진짜 구조를 배웁니다.

이 유닛에서 배우는 것

  • 문자열이 char 배열로 저장된다는 것을 설명할 수 있습니다.
  • 널 종료 문자 \0이 왜 필요한지 이해할 수 있습니다.
  • "Hello"가 6바이트인 이유를 말할 수 있습니다.
  • char 배열을 선언하고 초기화할 수 있습니다.
  • 문자와 문자열의 차이를 구분할 수 있습니다.

문자열 = char 배열 + \0

C언어에는 문자열 전용 자료형이 없습니다. 대신 char(문자) 배열을 연속으로 나열하고, 마지막에 널 종료 문자 \0을 붙여 문자열을 표현합니다.

\0은 숫자 0과 같은 값(ASCII 0)으로, 문자열이 여기서 끝난다는 신호입니다. printf 같은 함수들은 \0을 만날 때까지 출력합니다.

char 배열 선언 방법

문자열을 저장하려면 char 배열을 선언합니다. 크기는 저장할 문자 수 + 1(\\0 자리)로 잡아야 합니다.

// 방법 1: 크기 지정 + 문자열 초기화 char name[6] = "Hello"; // 5글자 + \0 = 6칸 // 방법 2: 크기 자동 결정 (컴파일러가 계산) char name[] = "Hello"; // 자동으로 6칸 // 방법 3: 문자 하나씩 초기화 (직접 \0 추가 필요) char name[6] = {'H','e','l','l','o','\0'}; // 주의: 크기가 부족하면 \0이 안 들어감! char bad[5] = "Hello"; // 위험! \0 공간 없음

ABC 가 출력됩니다

"Hello"가 6바이트인 이유

글자는 H, e, l, l, o — 5개인데 왜 6바이트일까요? 마지막에 \0이 자동으로 붙기 때문입니다.

#include <stdio.h> #include <string.h> int main() { char str[] = "Hello"; printf("sizeof: %lu\n", sizeof(str)); // 6 (\0 포함) printf("strlen: %lu\n", strlen(str)); // 5 (\0 제외) // 각 문자 확인 for (int i = 0; i <= 5; i++) { printf("str[%d] = %c (ASCII %d)\n", i, str[i] ? str[i] : '?', str[i]); } return 0; }

문자열 입출력 기초

문자열을 출력할 때는 %s 형식 지정자를 사용합니다. printf는 \0을 만날 때까지 출력합니다.

#include <stdio.h> int main() { char greeting[] = "안녕하세요"; char subject[] = "C언어"; printf("%s, %s!\n", greeting, subject); printf("인사말 길이: %lu\n", strlen(greeting)); return 0; }

핵심 정리

핵심 요약

  • C언어 문자열은 char 배열 + 끝의 \0(널 종료 문자)입니다.
  • "Hello"는 글자 5개 + \0 1개 = 6바이트입니다.
  • sizeof는 \0 포함 전체 크기, strlen은 \0 제외 글자 수입니다.
  • 문자는 작은 따옴표('A'), 문자열은 큰 따옴표("AB")를 씁니다.
  • string.h를 include해야 strlen 등 문자열 함수를 쓸 수 있습니다.

전체 예제 — 문자열 기초 종합

#include <stdio.h> #include <string.h> int main() { // 문자열 선언 char name[] = "김나바"; char school[20] = "코딩중학교"; // 출력 printf("이름: %s\n", name); printf("학교: %s\n", school); // 크기 비교 printf("name sizeof=%lu strlen=%lu\n", sizeof(name), strlen(name)); // 개별 문자 접근 printf("첫 글자: %c\n", name[0]); // \0 확인 printf("끝 문자 ASCII: %d\n", name[strlen(name)]); // 0이 출력됨 = \0 return 0; }
