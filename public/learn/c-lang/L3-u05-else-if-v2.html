else if —
여러 조건 분기

두 가지가 아닌 세 가지, 네 가지 상황을 구분할 때 쓰는 else if를 배웁니다.

이 유닛에서 배우는 것

  • else if 문법 구조를 읽고 쓸 수 있습니다.
  • if / if-else / if-else if-else 세 가지 형태를 구분할 수 있습니다.
  • 조건이 위에서 아래로 순서대로 검사됨을 이해할 수 있습니다.
  • 조건 순서가 잘못되어 생기는 버그를 찾을 수 있습니다.
  • BMI, 성적, 온도 같은 실전 예제를 스스로 작성할 수 있습니다.

if만 vs if-else vs if-else if-else

조건에 따라 다른 코드를 실행하는 방법은 세 가지 형태로 발전합니다. 경우의 수가 늘어날수록 더 복잡한 형태가 필요합니다.

else if 문법 구조

else if는 "앞 조건이 거짓일 때, 또 다른 조건을 검사"합니다. 개수 제한 없이 붙일 수 있습니다.

score가 85이면 첫 번째 조건 score >= 90은 거짓, 두 번째 score >= 80은 참이므로 "B등급"이 출력됩니다.

score가 95일 때 실행 결과를 예측해보세요.
score >= 90 이 참이므로 "A등급"이 출력됩니다
2
score가 72일 때 실행 결과는?
첫 두 조건 거짓, 세 번째 score >= 70 참 → "C등급" 출력
3
score가 55일 때 출력은?
모든 else if 거짓 → else 실행 → "F등급" 출력

else if 실행 순서 — 위에서 아래로

else if는 위에서 아래로 순서대로 조건을 검사합니다. 한 조건이 참이 되면 나머지는 건너뜁니다.

조건 순서가 중요한 이유

else if는 순서대로 검사하므로, 범위가 넓은 조건을 먼저 쓰면 뒤 조건이 절대 실행되지 않습니다.

핵심 규칙: 범위 조건(>=, <=)을 쓸 때는 범위가 좁은 것(큰 숫자)을 먼저, 범위가 넓은 것(작은 숫자)을 나중에 씁니다.
따라해보세요
1
아래 코드에서 score가 88일 때 출력 결과는?
if (score >= 60) printf("합격\n"); else if (score >= 80) printf("우수\n"); else printf("불합격\n");
"합격" — 첫 조건 참이라 "우수"는 실행 안 됨 (순서 버그!)
2
위 코드의 순서를 올바르게 수정해보세요.
if (score >= 80) printf("우수\n"); else if (score >= 60) printf("합격\n"); else printf("불합격\n");
score=88이면 "우수", score=70이면 "합격", score=45이면 "불합격"
3
온도(temp)가 25일 때, 아래 결과는? 단, <0 → 영하 / <15 → 쌀쌀 / else → 따뜻
if (temp < 0) printf("영하\n"); else if (temp < 15) printf("쌀쌀\n"); else printf("따뜻\n");
temp=25는 0 이상, 15 이상 → else 실행 → "따뜻" 출력

실전 패턴 — BMI 판정

BMI(체질량지수)는 체중(kg)을 키(m)의 제곱으로 나눈 값입니다. else if로 구간을 나눠 판정합니다.

// BMI 판정 프로그램 float bmi = 22.5; // 직접 값을 넣었습니다 if (bmi < 18.5) { printf("저체중입니다.\n"); } else if (bmi < 25.0) { printf("정상 체중입니다.\n"); } else if (bmi < 30.0) { printf("과체중입니다.\n"); } else { printf("비만입니다.\n"); }

실전 패턴 — 온도 판정 (5단계)

else if는 몇 개든 붙일 수 있습니다. 다섯 구간으로 온도를 판정하는 예제입니다.

int temp = 28; if (temp < 0) { printf("매우 추워요!\n"); } else if (temp < 15) { printf("추워요.\n"); } else if (temp < 25) { printf("딱 좋아요!\n"); } else if (temp < 35) { printf("더워요.\n"); } else { printf("매우 더워요!\n"); }
팁: else if 개수가 5개를 넘어가면 switch-case 문을 고려하세요. 정수 값이 딱 떨어지는 경우 switch가 더 읽기 쉽습니다. (switch는 다음 유닛에서 배웁니다)
따라해보세요

bmi = 16.0일 때 출력 결과는?
16.0 < 18.5 → 첫 if 참 → "저체중입니다." 출력
2
temp = -5일 때 출력 결과는?
-5 < 0 → 첫 if 참 → "매우 추워요!" 출력
3
월(month)이 주어질 때 계절 구분 코드를 만들어보세요. (3~5월=봄, 6~8월=여름, 9~11월=가을, else=겨울)
int month = 7; if (month >= 3 && month <= 5) printf("봄\n"); else if (month >= 6 && month <= 8) printf("여름\n"); else if (month >= 9 && month <= 11) printf("가을\n"); else printf("겨울\n");
month=7이면 "여름" 출력

핵심 정리

  • else if는 if의 조건이 거짓일 때 또 다른 조건을 검사합니다.
  • 조건은 위에서 아래로 순서대로 검사되며, 참이 되면 나머지는 건너뜁니다.
  • 범위 조건(>=, <=)을 쓸 때는 좁은 범위(큰 값)를 먼저 써야 합니다.
  • else는 모든 조건이 거짓일 때 실행되며, 생략 가능합니다.
  • else if가 너무 많아지면 switch-case 문을 고려하세요.
