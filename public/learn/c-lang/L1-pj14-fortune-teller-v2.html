오늘의 운세

사용자 이름을 입력받아 맞춤형 운세 메시지를 출력하는 프로그램을 만듭니다.

이 프로젝트에서 만들 것

  • scanf로 사용자 이름을 입력받습니다.
  • 이름을 포함한 맞춤형 운세 메시지를 출력합니다.
  • 여러 가지 운세 카테고리를 만들어봅니다.
  • 장식 테두리로 운세 카드를 꾸밉니다.
  • 행운의 숫자와 색깔도 추가합니다.

이름 입력받고 운세 출력

scanf로 사용자 이름을 입력받고, printf로 맞춤형 메시지를 출력합니다.

char name[50]; printf("이름을 입력하세요: "); scanf("%s", name); printf("\n*** 오늘의 운세 ***\n\n"); printf("안녕하세요, %s님!\n", name); printf("오늘은 행운이 가득한 날입니다.\n");
따라해보세요
1
이름을 입력받아 인사 메시지를 출력하세요.
char name[50]; printf("이름: "); scanf("%s", name); printf("%s님, 환영합니다!\n", name);
입력한 이름으로 환영 메시지가 출력됩니다
2
나이도 함께 입력받아 출력하세요.
char name[50]; int age; printf("이름: "); scanf("%s", name); printf("나이: "); scanf("%d", &age); printf("%s님(%d세)의 오늘 운세\n", name, age);
이름과 나이가 포함된 운세 제목이 출력됩니다

운세 카드 완성하기

애정운, 학업운, 금전운 등 카테고리별 운세와 행운의 숫자를 추가해 완성된 운세 카드를 만듭니다.

char name[50]; printf("이름: "); scanf("%s", name); printf("\n+------ %s님의 운세 ------+\n", name); printf("학업운: 오늘 집중력이 최고입니다.\n"); printf("금전운: 작은 행운이 찾아옵니다.\n"); printf("애정운: 좋은 인연을 만납니다.\n"); printf("행운의 숫자: %d\n", 7); printf("+-------------------------+\n");
따라해보세요
1
오늘의 날씨 운세를 추가하세요.
printf("날씨운: 맑은 하늘처럼 기분 좋은 하루!\n");
날씨운 항목이 추가됩니다
2
행운의 점수(1~100)도 변수로 추가하세요.
int luck = 88; printf("오늘 행운 지수: %d점\n", luck);
행운 지수 88점이 출력됩니다
3
생년을 입력받아 나이도 출력하세요.
int birth, age; printf("태어난 해: "); scanf("%d", &birth); age = 2026 - birth + 1; printf("한국 나이: %d세\n", age);
한국 나이를 계산해 출력합니다

도전 과제

Q1
나이 입력 운세
쉬움
이름과 나이를 입력받아 "%s님(%d세)의 오늘 운세: 좋은 일이 생깁니다!" 형식으로 출력하세요.
입력김민수 14
출력김민수님(14세)의 오늘 운세: 좋은 일이 생깁니다!
내 답안
힌트 보기
scanf("%s", name); scanf("%d", &age);로 순서대로 입력받으세요.
정답 확인
char name[50]; int age; printf("이름: "); scanf("%s", name); printf("나이: "); scanf("%d", &age); printf("%s님(%d세)의 오늘 운세: 좋은 일이 생깁니다!\n", name, age);
Q2
행운 점수 계산
쉬움
태어난 해를 입력받아 한국 나이와 행운 숫자(나이 % 10 + 1)를 출력하세요.
입력2012
출력나이: 15세 행운 숫자: 6
내 답안
힌트 보기
age = 2026 - birth + 1; lucky = age % 10 + 1;
정답 확인
int birth, age, lucky; printf("태어난 해: "); scanf("%d", &birth); age = 2026 - birth + 1; lucky = age % 10 + 1; printf("나이: %d세 행운 숫자: %d\n", age, lucky);
Q3
완성 운세 카드
보통
이름, 나이를 입력받아 학업운 + 애정운 + 금전운 + 행운숫자가 포함된 완성 운세 카드를 출력하세요.
조건테두리 + 이름/나이 + 3가지 운세 + 행운숫자
내 답안
힌트 보기
입력 → 테두리 출력 → 이름/나이 출력 → 운세3개 → 행운숫자 순서로 작성하세요.
정답 확인
char name[50]; int age; printf("이름: "); scanf("%s", name); printf("나이: "); scanf("%d", &age); printf("+---- %s(%d세) 오늘의 운세 ----+\n", name, age); printf("학업운: 집중력 최고의 날입니다.\n"); printf("애정운: 좋은 인연이 찾아옵니다.\n"); printf("금전운: 작은 행운이 있습니다.\n"); printf("행운 숫자: %d\n", age % 9 + 1); printf("+------------------------------+\n");

핵심 요약

  • scanf("%s", name)으로 문자열을 입력받는다 (공백 없는 단어)
  • scanf("%d", &age)에서 &를 빠뜨리면 오류가 난다
  • 입력받은 값은 printf의 %s, %d로 다시 출력할 수 있다
  • % 연산자(나머지)를 사용하면 범위 내 숫자를 생성할 수 있다
  • 테두리 안에 변수를 넣으면 맞춤형 카드 출력이 가능하다
