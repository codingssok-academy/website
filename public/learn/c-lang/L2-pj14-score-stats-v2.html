점수 통계

5과목 점수를 입력받아 합계(+=), 평균(형변환), 최고점, 최저점을 구합니다. 복합 대입과 산술 연산의 종합 프로젝트입니다.

이 프로젝트에서 배우는 것

  • sum += score로 누적 합계를 구할 수 있다
  • sum / 5.0으로 실수 평균을 구할 수 있다
  • 여러 변수 중 최고값과 최저값을 찾을 수 있다
  • 지금까지 배운 연산자를 종합 활용할 수 있다

점수 통계 코드

5과목 점수를 입력받아 합계, 평균, 최고점, 최저점을 출력합니다. 아직 if문을 배우지 않았으므로, 최고/최저는 직접 눈으로 확인하거나 수동 비교 방식을 사용합니다.

#include <stdio.h> int main(void) { int s1, s2, s3, s4, s5; int sum = 0; printf("5과목 점수를 입력하세요:\n"); printf("국어: "); scanf("%d", &s1); sum += s1; printf("영어: "); scanf("%d", &s2); sum += s2; printf("수학: "); scanf("%d", &s3); sum += s3; printf("과학: "); scanf("%d", &s4); sum += s4; printf("사회: "); scanf("%d", &s5); sum += s5; printf("\n=== 점수 통계 ===\n"); printf("합계: %d\n", sum); printf("평균: %.1f\n", sum / 5.0); printf("각 과목: %d %d %d %d %d\n", s1, s2, s3, s4, s5); return 0; }

2

합계: 500, 평균: 100.0
3
5.0을 5로 바꾸면 평균이 어떻게 달라지나요?
정수 나눗셈이 되어 86.0 대신 86이 됩니다

도전 문제

Q1
평균 직접 계산
쉬움
90, 80, 70, 60, 100의 합계와 평균을 구하세요.
정답 보기
합계: 400, 평균: 80.0
Q2
편차 계산 추가
보통
각 과목의 평균과의 차이(편차)를 출력하는 코드를 추가하세요. 편차 = 과목점수 - 평균
예시국어 85, 평균 86.0 -> 편차 -1.0
내 답안
정답 보기
double avg = sum / 5.0; printf("국어 편차: %.1f\n", s1 - avg); printf("영어 편차: %.1f\n", s2 - avg); // ... 나머지 과목도 동일
Q3
과목 수 변수화
보통
5.0 대신 count 변수를 만들어 과목 수를 저장하고, 나중에 과목 수가 바뀌어도 한 곳만 수정하면 되도록 하세요.
정답 보기
int count = 5; // ... printf("평균: %.1f\n", sum / (double)count);

핵심 요약

  • sum += score 패턴으로 여러 값을 누적 합산한다
  • 평균 = 합계 / 과목수 (5.0으로 나눠야 실수 평균)
  • 변수 이름을 의미 있게 짓자 (sum, avg, count 등)
  • 매직 넘버(5.0) 대신 변수를 쓰면 유지보수가 쉽다
