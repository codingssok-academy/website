Chapter 04

scanf -- 키보드로 입력받기

사용자가 직접 값을 입력하는 프로그램을 만들어봅니다. scanf 함수와 주소 연산자 &를 배우고, 입력-처리-출력(IPO) 패턴을 익힙니다.

이 유닛에서 배우는 것

  • scanf 함수로 키보드 입력을 받을 수 있습니다.
  • 주소 연산자 &의 역할을 이해합니다.
  • 여러 값을 한 번에 입력받을 수 있습니다.
  • scanf 사용 시 흔한 실수를 피할 수 있습니다.
  • 입력-처리-출력(IPO) 패턴으로 프로그램을 설계합니다.

scanf 함수의 구조

지금까지는 printf로 출력만 했습니다. 이제 scanf를 써서 사용자로부터 값을 입력받아 봅시다. scanf는 "scan formatted"의 줄임말입니다.

& = 주소 연산자

&는 "이 변수의 주소를 알려줘"라는 뜻입니다. scanf는 값을 변수에 직접 넣어야 하기 때문에, 변수가 어디에 있는지 주소를 알아야 합니다.

scanf 작동 과정

사용자가 키보드로 값을 입력하면, 3단계를 거쳐 변수에 저장됩니다.

// 나이 입력받기 #include <stdio.h> int main() { int age; printf("나이를 입력하세요: "); scanf("%d", &age); printf("당신의 나이: %d살\n", age); return 0; }
따라해보세요
1
정수형 변수 score를 선언하고, scanf로 값을 입력받아 출력하세요.
int score; printf("점수: "); scanf("%d", &score); printf("입력한 점수: %d\n", score);
점수: 95 입력 시 "입력한 점수: 95" 출력
2
변수 height를 선언하고, 키를 입력받아 "키: OOO cm" 형태로 출력하세요.
int height; printf("키(cm): "); scanf("%d", &height); printf("키: %d cm\n", height);
키(cm): 165 입력 시 "키: 165 cm" 출력
3
변수 year를 선언하고, 태어난 해를 입력받아 출력하세요.
int year; printf("태어난 해: "); scanf("%d", &year); printf("%d년생입니다\n", year);
태어난 해: 2011 입력 시 "2011년생입니다" 출력

여러 값 한 번에 입력받기

scanf 하나로 여러 변수에 값을 동시에 입력받을 수 있습니다. 서식 문자열에 여러 개의 %d를 쓰고, 변수도 여러 개 나열하면 됩니다.

// 두 수의 합 계산 #include <stdio.h> int main() { int a, b; printf("두 정수를 입력하세요: "); scanf("%d %d", &a, &b); printf("%d + %d = %d\n", a, b, a + b); return 0; }

흔한 실수 1: & 빼먹기

scanf에서 &를 빼먹으면 프로그램이 비정상 종료(크래시)됩니다. 값을 보낼 주소를 모르기 때문입니다.

흔한 실수 2: 서식 문자열 불일치

%d는 정수만 읽습니다. 사용자가 문자를 입력하면 scanf는 값을 읽지 못하고, 변수에 엉뚱한 값이 들어갑니다.

// 세 과목 점수 입력 + 합계 #include <stdio.h> int main() { int kor, eng, math; printf("국어 영어 수학 점수: "); scanf("%d %d %d", &kor, &eng, &math); printf("합계: %d\n", kor + eng + math); return 0; }
따라해보세요
1
두 정수를 입력받아 곱을 출력하세요.
int x, y; scanf("%d %d", &x, &y); printf("%d * %d = %d\n", x, y, x * y);
3 7 입력 시 "3 * 7 = 21" 출력
2
세 정수를 입력받아 평균을 출력하세요.
int a, b, c; scanf("%d %d %d", &a, &b, &c); printf("평균: %d\n", (a + b + c) / 3);
80 90 70 입력 시 "평균: 80" 출력
3
이름 대신 번호와 점수를 입력받아 "N번: OO점" 형태로 출력하세요.
int num, score; printf("번호와 점수: "); scanf("%d %d", &num, &score); printf("%d번: %d점\n", num, score);
3 95 입력 시 "3번: 95점" 출력

IPO 패턴: 입력 - 처리 - 출력

대부분의 프로그램은 Input(입력) - Process(처리) - Output(출력) 3단계로 구성됩니다. scanf로 입력받고, 계산하고, printf로 출력하는 것이 바로 IPO 패턴입니다.

// IPO 패턴: 태어난 해로 나이 계산 #include <stdio.h> int main() { int birthYear, age; // [Input] 입력 printf("태어난 해를 입력하세요: "); scanf("%d", &birthYear); // [Process] 처리 age = 2026 - birthYear; // [Output] 출력 printf("당신의 나이: %d살\n", age); return 0; }

확인 문제

Q1
scanf 빈칸 채우기
쉬움
빈칸을 채워 정수를 입력받아 출력하는 코드를 완성하세요.
int num; printf("숫자: "); ____("____", ____num); printf("입력: %d\n", num);
내 답안
힌트 보기
입력 함수는 scanf, 정수 서식은 %d, 변수 앞에 &를 붙입니다.
정답 보기
scanf("%d", &num); scanf / %d / & 세 가지를 채우면 됩니다.
Q2
& 빼먹은 코드 에러 찾기
쉬움
다음 코드에서 잘못된 부분을 찾고, 올바르게 고치세요.
int age; printf("나이: "); scanf("%d", age); // 이 줄에 문제가 있습니다 printf("입력: %d\n", age);
내 답안
힌트 보기
scanf는 변수의 주소가 필요합니다. 주소를 알려주는 연산자는 무엇인가요?
정답 보기
scanf("%d", &age); age 앞에 &를 붙여야 합니다. &가 없으면 변수의 주소를 알 수 없어 프로그램이 비정상 종료됩니다.
Q3
두 수 교환 프로그램 완성
보통
두 정수를 입력받아 순서를 바꿔 출력하는 프로그램을 완성하세요. 임시 변수 temp를 활용합니다.
입력10 20
출력a=20, b=10
int a, b, temp; scanf("%d %d", &a, &b); temp = ____; a = ____; b = ____; printf("a=%d, b=%d\n", a, b);
내 답안
힌트 보기
컵 2개의 음료를 바꾸려면 빈 컵(temp)이 필요합니다. a를 temp에 옮기고, b를 a에 넣고, temp를 b에 넣으세요.
정답 보기
temp = a; // a값을 임시 저장 a = b; // b값을 a에 넣기 b = temp; // 임시 저장한 원래 a값을 b에 넣기 교환 순서: temp=a → a=b → b=temp

핵심 요약

  • scanf("%d", &변수)로 키보드에서 정수를 입력받습니다.
  • &는 주소 연산자입니다. scanf에는 반드시 &를 붙여야 합니다.
  • 여러 값 입력: scanf("%d %d", &a, &b) -- 공백이나 Enter로 구분합니다.
  • & 빼먹기, 서식 불일치(%d에 문자 입력)는 가장 흔한 실수입니다.
  • 프로그램 설계: Input(입력) - Process(처리) - Output(출력) 패턴을 기억하세요.
