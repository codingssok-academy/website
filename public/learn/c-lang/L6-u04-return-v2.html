반환값과 return — 결과를 돌려주기

함수가 계산한 결과를 호출한 곳으로 돌려주는 return을 배웁니다. 반환 타입 일치, 여러 return 사용법까지 완벽히 익힙니다.

이 유닛에서 배우는 것

  • return 문이 하는 일을 설명할 수 있습니다.
  • 반환 타입과 return 값이 일치해야 함을 압니다.
  • 조건에 따라 다른 값을 반환하는 함수를 작성합니다.
  • return이 함수를 즉시 종료함을 이해합니다.
  • 반환값을 변수에 저장하거나 바로 사용할 수 있습니다.

return이 하는 두 가지 일

return은 두 가지 역할을 합니다. 첫째, 함수를 즉시 종료합니다. 둘째, 호출한 곳으로 값을 돌려줍니다.

return 뒤의 값이 함수의 결과가 됩니다. 이 결과는 호출한 곳에서 변수에 저장하거나, 바로 printf에 넣을 수 있습니다.

반환값 사용 방법

int add(int a, int b) { return a + b; } int main() { // 방법 1: 변수에 저장 int result = add(3, 5); printf("저장 후 출력: %d\n", result); // 8 // 방법 2: 바로 printf에 사용 printf("바로 출력: %d\n", add(10, 20)); // 30 // 방법 3: 다른 계산에 사용 int total = add(1, 2) + add(3, 4); printf("합산: %d\n", total); // 10 return 0; }

반환 타입 일치 — 중요!

함수의 반환 타입과 실제 return하는 값의 타입이 일치해야 합니다. 일치하지 않으면 경고나 오류가 발생할 수 있습니다.

여러 return — 조건에 따른 반환

함수 안에 return을 여러 개 쓸 수 있습니다. 조건에 따라 다른 값을 반환할 때 유용합니다. return을 만나면 함수가 즉시 끝납니다.

// 절댓값 반환 함수 int absVal(int n) { if (n >= 0) { return n; // 양수면 그대로 반환 } return -n; // 음수면 부호 바꿔서 반환 } // 더 큰 수 반환 함수 int maxOf(int a, int b) { if (a > b) return a; // a가 크면 a 반환하고 종료 return b; // 그렇지 않으면 b 반환 } int main() { printf("%d\n", absVal(-7)); // 7 printf("%d\n", maxOf(3, 9)); // 9 return 0; }

핵심 정리

핵심 요약

  • return은 함수를 즉시 종료하고 값을 호출 위치로 돌려줍니다.
  • 반환 타입과 return하는 값의 타입이 반드시 일치해야 합니다.
  • return 여러 개: 조건에 따라 다른 값 반환 가능.
  • return을 만나면 그 아래 코드는 실행되지 않습니다.
  • 반환값은 변수 저장, printf 직접 사용, 다른 계산에 사용 가능.
