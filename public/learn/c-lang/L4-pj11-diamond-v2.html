다이아몬드 별 찍기

중첩 for문으로 위쪽 삼각형과 아래쪽 삼각형을 합쳐 완벽한 다이아몬드 패턴을 만듭니다.

이 프로젝트에서 배우는 것

  • 중첩 for문으로 2차원 패턴을 만드는 원리를 이해합니다.
  • 공백 개수와 별 개수를 수식으로 계산할 수 있습니다.
  • 두 개의 반복문 블록을 합쳐 하나의 도형을 만듭니다.
  • 속이 빈 다이아몬드, 숫자 다이아몬드로 응용합니다.
  • 사용자 입력으로 크기를 동적으로 변경할 수 있습니다.

다이아몬드 패턴의 원리

다이아몬드는 위쪽 삼각형과 아래쪽 삼각형을 이어 붙인 모양입니다. 크기 n=5일 때, 각 행에서 공백과 별의 개수를 먼저 파악해야 합니다.

공식 정리: 행 번호 i일 때 공백 = n - i개, 별 = 2*i - 1개. 위쪽은 i가 1에서 n까지 증가, 아래쪽은 n-1에서 1까지 감소합니다.

전체 코드 — 크기 5 다이아몬드

#include <stdio.h> int main() { int n = 5; // 다이아몬드 크기 (홀수 권장) int i, j; // 위쪽 삼각형 (i: 1 ~ n) for (i = 1; i <= n; i++) { for (j = 0; j < n - i; j++) // 공백 printf(" "); for (j = 0; j < 2 * i - 1; j++) // 별 printf("*"); printf("\n"); } // 아래쪽 삼각형 (i: n-1 ~ 1) for (i = n - 1; i >= 1; i--) { for (j = 0; j < n - i; j++) // 공백 printf(" "); for (j = 0; j < 2 * i - 1; j++) // 별 printf("*"); printf("\n"); } return 0; }

속이 빈 다이아몬드

가장자리만 별을 찍는 속이 빈 다이아몬드입니다. 첫 번째 열 또는 마지막 열에만 별을 찍고, 나머지는 공백으로 채웁니다.

// 속이 빈 다이아몬드 핵심 조건 for (j = 0; j < 2 * i - 1; j++) { // 첫 번째(j==0) 또는 마지막(j==2*i-2) 위치만 별 if (j == 0 || j == 2 * i - 2) printf("*"); else printf(" "); } // 단, i==1(꼭짓점)은 별 하나만 출력되므로 조건 자동 처리됨

사용자 입력으로 크기 조절

scanf로 크기 n을 입력받아 동적으로 다이아몬드 크기를 바꿉니다. 입력값이 1보다 작으면 경고를 출력하도록 유효성 검사를 추가합니다.

#include <stdio.h> int main() { int n, i, j; printf("다이아몬드 크기 입력 (1~10): "); scanf("%d", &n); if (n < 1 || n > 10) { printf("1~10 사이 값을 입력하세요.\n"); return 1; } // 위쪽 삼각형 for (i = 1; i <= n; i++) { for (j = 0; j < n - i; j++) printf(" "); for (j = 0; j < 2 * i - 1; j++) printf("*"); printf("\n"); } // 아래쪽 삼각형 for (i = n - 1; i >= 1; i--) { for (j = 0; j < n - i; j++) printf(" "); for (j = 0; j < 2 * i - 1; j++) printf("*"); printf("\n"); } return 0; }

핵심 정리

  • 다이아몬드 = 위쪽 삼각형(i: 1→n) + 아래쪽 삼각형(i: n-1→1)
  • 각 행의 공백 = n-i, 별 = 2*i-1 (공식 암기)
  • 속이 빈 다이아몬드: j==0 또는 j==2*i-2 조건으로 가장자리만 출력
  • 숫자/문자 다이아몬드: printf 안의 출력 내용만 바꾸면 됨
  • 사용자 입력 + 유효성 검사로 프로그램 견고성을 높임
