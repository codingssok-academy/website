구구단 전체 출력

중첩 for문으로 2단부터 9단까지 구구단 전체를 출력합니다. 가로 정렬과 특정 단 강조도 함께 배웁니다.

이 프로젝트에서 배우는 것

  • 중첩 for문으로 2단~9단 전체 구구단을 출력할 수 있습니다.
  • 구구단을 가로로 나란히 정렬(여러 단 동시 출력) 할 수 있습니다.
  • 특정 단의 결과만 강조해 출력하는 조건문 활용법을 배웁니다.
  • printf의 서식 문자(%2d)로 출력을 정렬하는 방법을 익힙니다.

구구단 전체 출력 — 기본 코드

바깥 루프가 단(i: 2~9)을 담당하고, 안쪽 루프가 곱하는 수(j: 1~9)를 담당합니다. 총 8 × 9 = 72번 곱셈식을 출력합니다.

// 구구단 전체 출력 (2단~9단) int i, j; for (i = 2; i <= 9; i++) { // 바깥: 단 (2~9) printf("=== %d단 ===\n", i); for (j = 1; j <= 9; j++) { // 안쪽: 곱할 수 (1~9) printf("%d x %d = %2d\n", i, j, i * j); } printf("\n"); // 단 사이 빈 줄 }

확장 1 — 가로 정렬 (2단 | 3단 | 4단 나란히)

단을 세로로 나열하는 대신 가로로 배치하면 종이를 아낄 수 있습니다. 바깥 루프가 행(j: 1~9)을, 안쪽 루프가 단(i: 2~4)을 담당하도록 순서를 바꿉니다.

// 가로 정렬: 2단, 3단, 4단 나란히 int i, j; for (j = 1; j <= 9; j++) { // 바깥: 행 (1~9) for (i = 2; i <= 4; i++) { // 안쪽: 단 (2~4) printf("%d x %d = %2d ", i, j, i * j); } printf("\n"); }

확장 2 — 특정 단 강조 (if 조건)

구구단 출력 중에 특정 단(예: 5단)의 결과에만 표시를 추가하면, 일반 단과 구분할 수 있습니다. if문과 중첩 for문을 함께 사용합니다.

// 5단 결과만 "[]" 표시 추가 int i, j; for (i = 2; i <= 9; i++) { for (j = 1; j <= 9; j++) { if (i == 5) { printf("%d x %d = %2d []\n", i, j, i * j); } else { printf("%d x %d = %2d\n", i, j, i * j); } } printf("\n"); }

핵심 정리

  • 구구단 전체: 바깥 for i=2~9(단), 안쪽 for j=1~9(곱할 수)
  • 가로 정렬: 루프 순서를 뒤집어서 바깥=행(j), 안=단(i)
  • 특정 단 강조: 안쪽에 if (i == 특정단) 조건 추가
  • 짝수 단만: i += 2 또는 if (i % 2 == 0) 활용
  • %2d 서식: 결과가 한 자리여도 두 칸 차지 → 세로 정렬
  • 총 출력 횟수: 8단 × 9개 = 72개 결과
