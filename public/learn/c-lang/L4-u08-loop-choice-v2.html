반복문 선택 가이드 — 언제 무엇을?

for, while, do-while 중 어떤 반복문을 써야 할까요? 상황별로 최적의 반복문을 선택하는 판단 기준과, 세 가지로 같은 기능을 구현하는 방법을 익혀봅시다.

이 유닛에서 배우는 것

  • for, while, do-while의 구조 차이를 설명할 수 있습니다.
  • 언제 for를, 언제 while을, 언제 do-while을 써야 하는지 판단할 수 있습니다.
  • do-while이 반드시 1번은 실행된다는 특성을 이해할 수 있습니다.
  • 같은 기능을 세 가지 반복문으로 변환할 수 있습니다.
  • 상황에 맞는 반복문을 선택해 코드를 작성할 수 있습니다.

세 가지 반복문 비교

C언어의 반복문은 for, while, do-while 세 가지입니다. 모두 같은 일을 할 수 있지만 상황에 따라 어떤 것이 더 자연스러운지 다릅니다.

while과 do-while의 결정적 차이는 조건이 처음부터 거짓일 때입니다. while은 0번, do-while은 최소 1번 실행합니다.

같은 기능 — 세 가지 방법으로

1부터 N까지 합을 구하는 기능을 for, while, do-while 세 가지로 구현해봅니다. 어느 것을 써도 결과는 같습니다.

// 1~10 합 구하기 — for 버전 int sum = 0; for (int i = 1; i <= 10; i++) { sum += i; } printf("합: %d\n", sum); // 55 // 1~10 합 구하기 — while 버전 sum = 0; int i = 1; while (i <= 10) { sum += i; i++; } printf("합: %d\n", sum); // 55 // 1~10 합 구하기 — do-while 버전 sum = 0; i = 1; do { sum += i; i++; } while (i <= 10); printf("합: %d\n", sum); // 55

do-while이 특히 유용한 경우는 입력 검증입니다. 올바른 값이 들어올 때까지 반복 입력받는 패턴입니다.

// 입력 검증 패턴 (do-while이 딱 맞는 경우) int score; do { printf("점수 입력 (0~100): "); scanf("%d", &score); if (score < 0 || score > 100) printf("범위를 벗어났습니다. 다시 입력하세요.\n"); } while (score < 0 || score > 100); printf("입력된 점수: %d\n", score);

반복문 선택 핵심 정리

  • for: 반복 횟수를 미리 알 때 — 가장 자주 쓰임
  • while: 조건이 참인 동안 — 횟수 모를 때, 0번 실행 가능
  • do-while: 최소 1번 실행 보장 — 메뉴, 입력 검증
  • 세 가지 모두 서로 변환 가능하지만, 상황에 맞는 것이 읽기 좋다.
  • 무한루프는 while(1) 또는 for(;;) + break 탈출 조건.
