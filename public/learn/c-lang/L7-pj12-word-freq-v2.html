strtok 동작 복습

strtok(str, " ")은 공백을 기준으로 문자열을 분리하고, 각 호출에서 다음 토큰을 반환한다. 두 번째 호출부터는 첫 번째 인자를 NULL로 전달한다.

#include <stdio.h> #include <string.h> #include <ctype.h> #define MAX_WORDS 100 #define MAX_LEN 50 int main() { char text[500]; printf("문장 입력: "); fgets(text, sizeof(text), stdin); text[strcspn(text, "\n")] = '\0'; char words[MAX_WORDS][MAX_LEN]; // 단어 저장 int counts[MAX_WORDS] = {0}; // 빈도 저장 int word_cnt = 0; char *token = strtok(text, " ,.!?"); // 구분자 여러 개 while (token != NULL) { // 소문자로 정규화 for (int i = 0; token[i]; i++) token[i] = tolower(token[i]); // 이미 있는 단어인지 확인 int found = 0; for (int i = 0; i < word_cnt; i++) { if (strcmp(words[i], token) == 0) { counts[i]++; found = 1; break; } } // 새 단어면 추가 if (!found) { strcpy(words[word_cnt], token); counts[word_cnt++] = 1; } token = strtok(NULL, " ,.!?"); } // 결과 출력 printf("\n=== 단어 빈도 ===\n"); for (int i = 0; i < word_cnt; i++) printf("%-15s: %d\n", words[i], counts[i]); return 0; }
응용 — 최빈 단어 + 막대 그래프
가장 많이 나온 단어 찾기
// 최대 빈도 찾기 int max_i = 0; for (int i = 1; i < word_cnt; i++) if (counts[i] > counts[max_i]) max_i = i; printf("최빈 단어: \"%s\" (%d회)\n", words[max_i], counts[max_i]);
텍스트 막대 그래프 출력
// ■ 기호로 빈도 막대 그래프 printf("\n=== 빈도 그래프 ===\n"); for (int i = 0; i < word_cnt; i++) { printf("%-12s |", words[i]); for (int j = 0; j < counts[i]; j++) printf("#"); // #으로 막대 표현 printf(" %d\n", counts[i]); }
실행 예시
%-15s 포맷: printf에서 %-15s는 왼쪽 정렬로 15칸 확보. 단어 길이가 달라도 표가 정렬되어 보인다. 음수 넓이가 왼쪽 정렬을 의미한다.
연습 문제
Q1. strtok 결과

strtok("hello,world,test", ",")를 반복 호출하면 몇 번 호출할 때 NULL이 반환되는가?

정답 보기
4번째 호출 시 NULL. 1번="hello", 2번="world", 3번="test", 4번=NULL
Q2. 구조 이해

words[MAX_WORDS][MAX_LEN] 배열에서 MAX_WORDS=100, MAX_LEN=50이면 총 몇 바이트를 차지하는가?

정답 보기
100 × 50 = 5000바이트 (약 5KB)
Q3. 오류 분석

tolower로 소문자 정규화를 하지 않으면 어떤 문제가 생기는가? "The"와 "the"를 예로 설명하시오.

정답 보기
strcmp("The", "the") != 0 이므로 서로 다른 단어로 처리됨. 결과에 "The"와 "the"가 따로 카운트되어 빈도가 분산된다.
Q4. 구현

빈도 결과를 내림차순 정렬하여 출력하는 코드를 작성하시오. (가장 많이 나온 단어가 먼저)

정답 보기
버블 정렬로 counts 배열을 내림차순 정렬. 교환 시 counts와 words 배열 모두 동시에 교환해야 한다. strcpy 임시 버퍼 사용.
Q5. 도전

텍스트에서 딱 한 번만 나온 단어(유일 단어)와, 가장 많이 나온 단어 상위 3개를 각각 출력하는 프로그램을 작성하시오.

정답 보기
counts[i]==1인 항목은 "유일 단어". 상위 3개는 정렬 후 첫 3개 출력 또는 최대값 3회 반복 탐색.

핵심 정리

strtok첫 호출: strtok(str, " ") / 이후: strtok(NULL, " ") — NULL 반환 시 종료

중복strcmp로 기존 단어 탐색 → found 플래그로 신규/기존 분기
정규화tolower로 대소문자 통일 후 비교 → "The"와 "the" 동일 처리
