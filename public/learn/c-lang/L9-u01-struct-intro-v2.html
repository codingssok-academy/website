구조체란? — 다른 타입 데이터 묶기

여러 종류의 데이터를 하나의 이름으로 묶어 관리하는 구조체(struct)를 배웁니다. 배열과 무엇이 다른지도 비교해봅시다.

이 유닛에서 배우는 것

  • 구조체가 무엇인지 설명할 수 있습니다.
  • 배열과 구조체의 차이를 비교할 수 있습니다.
  • struct 키워드로 구조체를 선언할 수 있습니다.
  • 구조체 변수를 만들고 멤버에 값을 넣을 수 있습니다.
  • 구조체가 왜 필요한지 실생활 예를 들어 설명할 수 있습니다.

구조체가 왜 필요할까?

학생 한 명의 정보를 저장한다고 생각해봅시다. 이름(문자열), 나이(정수), 점수(실수)처럼 서로 다른 타입의 데이터를 함께 관리해야 합니다. 배열은 같은 타입만 묶을 수 있으므로, 이럴 때 구조체(struct)가 필요합니다.

배열 vs 구조체 비교

배열은 int score[5]처럼 같은 타입의 값 여러 개를 연속으로 저장합니다. 구조체는 이름, 나이, 점수처럼 서로 다른 타입의 데이터를 하나의 이름으로 묶습니다.

struct 기본 문법

구조체를 만들려면 먼저 struct 키워드로 새 타입을 정의합니다. 그 안에 필요한 변수(멤버)들을 선언합니다.

// 구조체 정의 (타입을 만드는 것 — 상자의 설계도) struct Student { char name[20]; // 이름 (문자열) int age; // 나이 (정수) float score; // 점수 (실수) }; // ← 세미콜론 절대 빠뜨리지 않기! int main() { // 구조체 변수 선언 (상자를 실제로 만드는 것) struct Student s1; // 멤버에 값 대입 (점 연산자 .) s1.age = 15; s1.score = 88.5f; printf("나이: %d, 점수: %.1f\n", s1.age, s1.score); return 0; }

구조체 멤버 출력 예제

구조체 변수를 만든 후 각 멤버를 점(.) 연산자로 읽고 printf로 출력해봅시다.

#include <stdio.h> #include <string.h> struct Student { char name[20]; int age; float score; }; int main() { struct Student s1; strcpy(s1.name, "김철수"); // 문자열은 strcpy 사용 s1.age = 15; s1.score = 92.5f; printf("이름: %s\n", s1.name); printf("나이: %d세\n", s1.age); printf("점수: %.1f\n", s1.score); return 0; }

메모리 구조 이해

구조체는 멤버들이 메모리에 연속으로 배치됩니다. 각 멤버는 자신의 타입 크기만큼 공간을 차지합니다.

핵심 정리

핵심 정리

  • 구조체는 서로 다른 타입의 데이터를 하나의 이름으로 묶는 도구입니다.
  • 배열은 같은 타입만 묶지만, 구조체는 다른 타입도 함께 묶을 수 있습니다.
  • struct 이름 { 멤버들; }; 형식으로 선언하고, 끝에 세미콜론이 필수입니다.
  • 멤버 접근은 점(.) 연산자를 사용합니다: 변수.멤버
