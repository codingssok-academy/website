반복+조건 조합 — for 안의 if

for문 안에 if문을 넣어 조건에 맞는 값만 출력하거나, 최대값을 찾거나, 개수를 세는 실용적인 패턴을 익혀봅시다.

이 유닛에서 배우는 것

  • for문 안에 if문을 넣어 조건에 맞는 값만 처리할 수 있습니다.
  • % 연산자를 이용해 짝수/홀수를 판별할 수 있습니다.
  • continue로 특정 값을 건너뛸 수 있습니다.
  • 최대값 찾기 패턴을 이해하고 구현할 수 있습니다.
  • 조건을 만족하는 개수를 카운트할 수 있습니다.

for 안에 if — 조건 필터링

for문이 모든 수를 훑을 때, if문으로 원하는 수만 골라 처리합니다. %(나머지 연산자)를 이용하면 짝수와 홀수를 쉽게 판별할 수 있습니다.

// 1~10에서 짝수만 출력 for (int i = 1; i <= 10; i++) { if (i % 2 == 0) { // 나머지가 0이면 짝수 printf("%d ", i); } } // 출력: 2 4 6 8 10 // 1~10에서 홀수만 출력 for (int i = 1; i <= 10; i++) { if (i % 2 != 0) { // 나머지가 0이 아니면 홀수 printf("%d ", i); } } // 출력: 1 3 5 7 9

continue는 이번 반복만 건너뛰고 다음 반복으로 바로 갑니다. break는 반복문 전체를 종료하지만, continue는 이번 차례만 스킵합니다.

// 5를 건너뛰고 1~10 출력 (continue 사용) for (int i = 1; i <= 10; i++) { if (i == 5) { continue; // i=5일 때 printf 건너뜀 } printf("%d ", i); } // 출력: 1 2 3 4 6 7 8 9 10

최대값 찾기 패턴

배열 없이 입력값들 중에서 가장 큰 수를 찾을 수 있습니다. 핵심은 현재까지의 최대값을 저장하는 변수 max입니다.

// N개 입력에서 최대값 찾기 int n, x, max; printf("개수 입력: "); scanf("%d", &n); scanf("%d", &x); max = x; // 첫 값을 최대값으로 초기화 for (int i = 1; i < n; i++) { scanf("%d", &x); if (x > max) { max = x; // 더 큰 값이 나오면 갱신 } } printf("최대값: %d\n", max);

카운트 패턴 — 조건 만족 개수 세기

반복문을 돌면서 조건을 만족하는 경우의 수를 세는 패턴입니다. count 변수를 0으로 시작해서 조건 만족 시 1씩 증가시킵니다.

// 1~100에서 5의 배수 개수 세기 int count = 0; // 반드시 0으로 초기화 for (int i = 1; i <= 100; i++) { if (i % 5 == 0) { count++; // 조건 만족하면 카운트 증가 } } printf("5의 배수 개수: %d개\n", count); // 출력: 5의 배수 개수: 20개 // 합계와 개수 동시에 구하기 (평균 계산) int sum = 0, cnt = 0; for (int i = 1; i <= 100; i++) { if (i % 3 == 0) { sum += i; cnt++; } } printf("합: %d, 개수: %d, 평균: %.1f\n", sum, cnt, (float)sum/cnt);

반복+조건 조합 핵심 정리

  • 필터 패턴: for로 범위를 훑고 if로 원하는 것만 처리한다.
  • 짝수: i%2==0, 홀수: i%2!=0, N의 배수: i%N==0
  • continue: 이번 반복만 건너뜀 / break: 반복문 전체 종료
  • 최대값: max를 첫 값으로 초기화 후 if(x>max) max=x
  • 카운트: count=0으로 시작, 조건 만족 시 count++
