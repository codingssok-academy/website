O/X 퀴즈

printf로 퀴즈 문제와 정답을 출력하는 O/X 퀴즈 게임을 만듭니다.

이 프로젝트에서 만드는 것

  • C 언어 관련 O/X 퀴즈 5문제를 printf로 출력합니다.
  • 문제 번호, 질문, 정답을 세트로 구성합니다.
  • 정답 섹션을 별도로 구분해 출력합니다.
  • 주석과 섹션 구분선을 활용합니다.

O/X 퀴즈 구조 만들기

퀴즈는 문제 번호 + 질문 + 정답으로 구성합니다. 정답을 들여쓰기로 구분하면 문제와 정답이 시각적으로 분리되어 읽기 좋습니다.

#include <stdio.h> int main() { /* C언어 O/X 퀴즈 게임 */ // 제목 printf("===== C언어 O/X 퀴즈 =====\n"); printf("\n"); // 문제 1 printf("Q1. C 언어는 세미콜론으로 문장을 끝낸다.\n"); printf(" 정답: O\n"); printf("\n"); // 문제 2 printf("Q2. 주석은 프로그램 실행에 영향을 준다.\n"); printf(" 정답: X\n"); printf("\n"); printf("==========================\n"); return 0; }
따라해보세요
1
위 코드를 입력하고 퀴즈 2문제가 출력되는 것을 확인하세요.
퀴즈 형식 출력 확인
2
정답 O 줄에 해설을 추가해보세요.
printf(" 정답: O (세미콜론은 문장의 끝!)\n");
해설 포함 퀴즈

O/X 퀴즈 5문제 완성

C 언어에서 배운 내용으로 5문제짜리 퀴즈를 완성합니다. 문제가 끝난 뒤에는 점수 안내도 출력합니다.

#include <stdio.h> int main() { /* C언어 O/X 퀴즈 - 5문제 */ printf("===== C언어 O/X 퀴즈 =====\n\n"); // Q1 printf("Q1. printf 는 화면에 출력하는 함수다.\n"); printf(" 정답: O\n\n"); // Q2 printf("Q2. 주석은 컴파일러가 실행한다.\n"); printf(" 정답: X (무시됨)\n\n"); // Q3 printf("Q3. // 는 한 줄 주석 기호다.\n"); printf(" 정답: O\n\n"); // Q4 printf("Q4. 들여쓰기가 없으면 에러가 난다.\n"); printf(" 정답: X (에러 없음, 가독성 문제)\n\n"); // Q5 printf("Q5. 중괄호는 반드시 쌍으로 써야 한다.\n"); printf(" 정답: O\n\n"); // 점수 안내 printf("==========================\n"); printf("5/5 맞으면 C언어 마스터!\n"); return 0; }
따라해보세요
1
5문제 퀴즈를 모두 입력하고 출력해보세요.
5문제 + 점수 안내 출력
2
나만의 퀴즈 문제를 1개 추가해보세요.
6문제 퀴즈로 확장
3
정답 줄에 해설 설명을 추가해보세요.
해설 포함 완성 퀴즈

도전 과제

Q1
나만의 퀴즈 3문제
기본
C 언어 또는 학교에서 배운 내용으로 나만의 O/X 퀴즈 3문제를 만드세요.
조건 1문제 번호 포함 (Q1, Q2, Q3)
조건 2정답 들여쓰기 (4칸)
조건 3O와 X 각각 1개 이상 포함
내 답안
예시 보기
printf("Q1. 2+2는 5이다.\n"); printf(" 정답: X (2+2=4)\n\n"); printf("Q2. 서울은 대한민국 수도다.\n"); printf(" 정답: O\n");
Q2
정답 섹션 분리
심화
문제만 먼저 출력하고, 구분선 아래에 정답을 모아서 출력하는 형식으로 바꿔보세요.
형식Q1~Q3 문제 → ----- → [정답] 섹션
내 답안
힌트 보기
문제를 모두 출력한 뒤 printf("--- 정답 ---\n");을 출력하고 정답만 모아서 출력하면 됩니다.
Q3
다른 과목 퀴즈 만들기
창의
수학, 과학, 역사 등 다른 과목의 O/X 퀴즈를 5문제 만들어보세요.
내 답안
예시 보기
printf("===== 수학 O/X 퀴즈 =====\n\n"); printf("Q1. 원주율 파이는 약 3.14이다.\n"); printf(" 정답: O\n\n");

핵심 요약

  • 여러 줄 printf로 퀴즈 형식의 인터랙티브 텍스트 구성 가능
  • 들여쓰기(공백)로 문제와 정답을 시각적으로 구분
  • "\n\n"으로 문제 사이 여백 출력
  • 주석으로 각 문제 섹션 구분 → 코드 관리 편리
  • printf만으로 실제 게임 같은 텍스트 인터페이스 표현 가능
