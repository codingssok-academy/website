Unit 12 · L5 배열 종합

배열 종합 실전 — 성적처리·연락처

L5에서 배운 1차원·2차원 배열과 문자 배열을 모두 활용하는 실전 시스템을 만듭니다. 성적 처리 시스템과 미니 연락처 관리 프로그램을 완성합니다.

이 유닛에서 배우는 것

  • 배열 + 정렬 + 검색을 하나의 시스템으로 통합합니다.
  • 1차원 배열로 성적을 처리하고 최고/최저/평균을 구합니다.
  • 2차원 배열로 복수 과목 성적을 관리합니다.
  • char 배열로 이름을 저장하고 검색합니다.
  • L6 함수의 필요성을 실전에서 체감합니다.

종합 예제 1 — 학생 성적 처리 시스템

5명 학생의 점수 배열을 받아 평균·최고점·최저점·등수를 출력하는 시스템입니다. L5의 핵심 패턴을 모두 사용합니다.

int score[5] = {85, 92, 78, 96, 88}; int i, j, tmp, max, min, sum=0, cnt=0; /* ① 평균 */ for(i=0; i<5; i++) sum += score[i]; printf("평균: %.1f\n", (float)sum/5); /* ② 최고·최저 */ max = min = score[0]; for(i=1; i<5; i++) { if(score[i] > max) max = score[i]; if(score[i] < min) min = score[i]; } printf("최고: %d, 최저: %d\n", max, min); /* ③ 90점 이상 인원 */ for(i=0; i<5; i++) if(score[i]>= 90) cnt++; printf("90 이상: %d명\n", cnt); /* ④ 버블 정렬 (오름차순) */ for(i=0; i<4; i++) for(j=0; j<4-i; j++) if(score[j] > score[j+1]) { tmp = score[j]; score[j] = score[j+1]; score[j+1] = tmp; } printf("정렬: "); for(i=0; i<5; i++) printf("%d ", score[i]);

종합 예제 2 — 다과목 성적 관리 시스템

3명 학생의 3과목 점수를 2차원 배열에 저장하고, 학생별 합계와 과목별 1등을 찾습니다.

char name[3][10] = {"Kim", "Lee", "Park"}; int score[3][3] = { {85, 90, 78}, {92, 88, 95}, {75, 82, 70} }; int total[3] = {0}; int i, j, best; // 학생별 합계 for(i=0; i<3; i++) { for(j=0; j<3; j++) total[i] += score[i][j]; printf("%s 합계: %d\n", name[i], total[i]); } // 1등 찾기 (합계 기준) best = 0; for(i=1; i<3; i++) if(total[i] > total[best]) best = i; printf("1등: %s (%d점)\n", name[best], total[best]);

미니 연락처 관리 시스템

이름과 전화번호를 char 배열 배열에 저장하고 이름으로 검색합니다.

char cname[5][20] = {"Alice","Bob","Carol","Dave","Eve"}; char phone[5][15] = {"010-1111","010-2222","010-3333", "010-4444","010-5555"}; char query[20]; int i, found = -1; printf("검색할 이름: "); scanf("%s", query); // 선형 검색 for(i=0; i<5; i++) { int j=0, match=1; while(query[j] != '\0' || cname[i][j] != '\0') { if(query[j] != cname[i][j]) { match=0; break; } j++; } if(match) { found = i; break; } } if(found >= 0) printf("%s: %s\n", cname[found], phone[found]); else printf("없음\n");

지금까지의 코드, 왜 불편할까?

앞의 예제들을 보면 비슷한 패턴의 코드가 반복됩니다. "평균 구하기", "최댓값 찾기" 같은 작업을 쓸 때마다 다시 작성해야 합니다. 이것이 함수가 필요한 이유입니다.

L6 함수 — 미리 보기

  • 함수: 이름 붙인 코드 묶음 — 한 번 정의, 여러 번 호출
  • int max(int a[], int n) — 배열의 최댓값 반환
  • void print_array(int a[], int n) — 출력 함수
  • 매개변수(parameter)로 배열 전달하기 — 포인터의 첫 만남
  • return 값으로 계산 결과 전달하기

L5 배열 전체 핵심 정리

  • u07 1차원: int a[n] — 인덱스 0~n-1, for문 순회
  • u08 정렬/검색: 버블정렬 O(n²), 선형검색 O(n), 이진검색 O(log n)
  • u09 2차원: int a[r][c] — 이중 for, 행 우선 메모리
  • u10 2차원 활용: 구구단·좌석·행렬덧셈·행/열합계·대각선
  • u11 char 배열: 문자열 = char[] + '\0', scanf %s, printf %s
  • u12 종합: 배열 + 정렬 + 검색 + 2D + char 통합 시스템
  • L6 예고: 함수로 반복 코드 묶기 — 재사용·가독성·유지보수
