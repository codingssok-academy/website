Unit 08

컴파일 에러 읽기

에러 메시지를 이해하고 원인을 찾아 코드를 고치는 방법을 배웁니다.

이 유닛에서 배우는 것

  • 컴파일 에러 메시지의 구조(파일명, 줄번호, 내용)를 파악합니다.
  • 가장 흔한 에러 3가지를 인식하고 고칠 수 있습니다.
  • 에러 메시지를 보고 문제 줄을 찾아가는 습관을 만듭니다.
  • 경고(warning)와 에러(error)의 차이를 이해합니다.

에러 메시지 구조 읽기

컴파일러가 출력하는 에러 메시지는 일정한 형식을 따릅니다. 이 형식을 알면 에러를 빠르게 찾아 고칠 수 있습니다.

흔한 에러 3가지

// 에러 1: 세미콜론 누락 printf("안녕\n") // ← ; 없음! // 에러 2: 중괄호 누락 int main() { printf("Hi\n"); // ← 닫는 } 없음! // 에러 3: 헤더 미포함 // #include <stdio.h> 없으면 printf 에러!
따라해보세요
1
세미콜론 누락 에러를 직접 만들고 메시지를 읽어보세요.
#include <stdio.h> int main() { printf("에러 실험\n") // ; 일부러 뺌 return 0; }
main.c:3:XX: error: expected ';' 확인
2
에러 줄 번호를 보고 해당 줄을 고쳐보세요.
#include <stdio.h> int main() { printf("에러 실험\n"); // 고침! return 0; }
컴파일 성공

에러 해결 전략

에러가 났을 때 당황하지 않고 차분히 접근하면 대부분 빠르게 해결할 수 있습니다.

// 에러 코드 #include <stdio.h> int main() { printf("이름: 홍길동\n") // ← 4번째 줄, ; 없음 } // 고친 코드 #include <stdio.h> int main() { printf("이름: 홍길동\n"); // ; 추가! return 0; }
따라해보세요
1
에러 메시지의 줄 번호를 읽고 해당 줄을 찾아 고쳐보세요.
// 에러: main.c:4:10: error: expected ';' #include <stdio.h> int main() { printf("4번째 줄\n") return 0; }
4번째 줄 printf 끝에 ; 추가
2
여러 에러가 있을 때 첫 번째 에러부터 고쳐보세요.
#include <stdio.h> int main() { printf("A\n") printf("B\n") return 0; }
두 곳 모두 ; 추가 후 컴파일
3
#include 없이 printf를 써서 어떤 에러가 나는지 확인해보세요.
// #include <stdio.h> 일부러 뺌 int main() { printf("헤더 없음\n"); return 0; }

핵심 요약

  • 에러 메시지 형식: 파일명:줄번호:칸수: error: 내용
  • 가장 흔한 에러: 세미콜론 누락, 중괄호 누락, 헤더 미포함
  • 에러 해결 순서: 메시지 확인 → 줄 번호 이동 → 원인 파악 → 수정
  • error는 반드시 수정, warning은 가능하면 수정
  • 여러 에러가 있을 때는 첫 번째 에러부터 하나씩 고침
