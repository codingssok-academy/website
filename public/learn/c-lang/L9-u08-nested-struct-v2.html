중첩 구조체 — 구조체 안의 구조체

구조체 멤버로 다른 구조체를 포함시킬 수 있습니다. 주소(시/구/동)처럼 계층적으로 데이터를 표현하는 방법을 배웁니다.

이 유닛에서 배우는 것

  • 중첩 구조체(구조체 안에 구조체)를 정의할 수 있습니다.
  • 중첩 멤버에 점 연산자를 이어서 접근할 수 있습니다.
  • 중첩 구조체를 초기화하는 방법을 알 수 있습니다.
  • 실생활 예(주소 계층)를 구조체로 표현할 수 있습니다.
  • 3단계 이상의 중첩 접근 표현을 작성할 수 있습니다.

중첩 구조체란?

구조체의 멤버로 다른 구조체 변수를 포함시킬 수 있습니다. 이를 중첩 구조체(Nested Struct)라고 합니다. 현실의 계층적 데이터를 자연스럽게 표현합니다.

typedef struct { char city[20]; char gu[20]; char dong[20]; } Address; typedef struct { char name[20]; int age; Address addr; // 멤버로 Address 구조체 포함 } Person; Person p; strcpy(p.name, "홍길동"); p.age = 20; strcpy(p.addr.city, "서울"); // 중첩 접근: p.addr.city strcpy(p.addr.gu, "강남구"); strcpy(p.addr.dong, "역삼1동"); printf("%s: %s %s %s\n", p.name, p.addr.city, p.addr.gu, p.addr.dong);

중첩 구조체 초기화

중첩 구조체도 중괄호를 중첩하여 한 번에 초기화할 수 있습니다.

Person p = { "홍길동", // name 20, // age { // addr (Address 구조체) "서울", "강남구", "역삼1동" } }; printf("%s — %s %s %s\n", p.name, p.addr.city, p.addr.gu, p.addr.dong);

3단계 이상 중첩

typedef struct { int year, month, day; } Date; typedef struct { char name[20]; Date birthday; // Date 구조체 포함 } Student; Student s = {"김민준", {2010, 5, 20}}; printf("%s 생일: %d년 %d월 %d일\n", s.name, s.birthday.year, s.birthday.month, s.birthday.day);
