if-else문 — 둘 중 하나 실행

조건이 참이면 A를, 거짓이면 B를 실행합니다. 프로그램이 상황에 따라 다르게 행동하는 핵심 구조입니다.

이 유닛에서 배우는 것

  • if-else문의 구조와 실행 흐름을 설명할 수 있습니다.
  • 조건이 참/거짓일 때 서로 다른 코드를 실행할 수 있습니다.
  • 짝수/홀수, 합격/불합격, 최대값 등 실전 패턴을 작성할 수 있습니다.
  • dangling else 문제와 중괄호의 역할을 이해합니다.
  • if-else문으로 절대값, 정렬, 윤년 판별 문제를 풀 수 있습니다.

if만 있을 때 vs if-else 있을 때

if만 쓰면 조건이 거짓일 때 아무것도 안 합니다. if-else를 쓰면 참일 때와 거짓일 때 각각 다른 코드를 실행합니다.

if-else 문법 구조

if-else의 각 부분이 하는 역할을 그림으로 확인합니다.

조건식이 참(1, true)이면 if 블록이, 거짓(0, false)이면 else 블록이 실행됩니다. 둘 중 하나만 실행됩니다.

코드: 짝수/홀수 판별

// 짝수/홀수 판별 int n = 7; if (n % 2 == 0) { printf("%d은 짝수입니다.\n", n); } else { printf("%d은 홀수입니다.\n", n); }

n이 7이므로 7 % 2는 1, 조건 1 == 0은 거짓이므로 else 블록이 실행됩니다. 출력: 7은 홀수입니다.

if-else 활용 패턴

if-else는 다양한 판별 문제에 사용됩니다. 자주 나오는 3가지 패턴을 익혀봅니다.

패턴 1 — 합격/불합격 판별

int score = 75; if (score >= 60) { printf("합격입니다!\n"); } else { printf("불합격입니다.\n"); }

패턴 2 — 양수/음수 판별

int num = -5; if (num > 0) { printf("양수입니다.\n"); } else { printf("음수(또는 0)입니다.\n"); }

패턴 3 — 두 수 중 최대값 구하기

두 변수를 비교해 더 큰 값을 출력합니다. if-else로 명확하게 작성합니다.

int a = 13, b = 27; int max; if (a > b) { max = a; } else { max = b; } printf("최대값: %d\n", max);

a(13) > b(27)가 거짓이므로 else 블록에서 max = b = 27이 됩니다. 출력: 최대값: 27

주의사항 — dangling else

else는 항상 가장 가까운 if에 붙습니다. 중괄호를 생략하면 의도와 다르게 동작할 수 있습니다.

규칙: else는 항상 가장 가까운(안쪽) if에 붙습니다. 의도한 if에 붙이려면 반드시 중괄호 { } 를 사용하세요.

if-else vs 삼항연산자 미리보기

삼항연산자(? :)는 if-else를 한 줄로 줄인 것입니다. 나중에 배우지만 미리 눈에 익혀둡니다.

지금은 if-else로 충분합니다. 삼항연산자는 간단한 경우에만 쓰고, 복잡하면 if-else가 더 읽기 쉽습니다.

핵심 정리

  • if (조건) { ... } else { ... } — 조건이 참이면 if 블록, 거짓이면 else 블록 실행
  • 조건식은 참(1) 또는 거짓(0)을 반환 — ==, !=, >, <, >=, <= 연산자 사용
  • else는 항상 가장 가까운 if에 붙음 (dangling else) — 중괄호로 명확히 표현
  • 한 줄이어도 중괄호를 쓰는 것이 안전하고 권장되는 습관
  • if-else의 두 블록 중 정확히 하나만 실행됨 — 둘 다 실행되거나 둘 다 안 되는 경우는 없음
