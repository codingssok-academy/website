간단 계산기 v1

두 수를 입력받아 사칙연산과 나머지 연산 결과를 한 번에 모두 출력하는 계산기를 만듭니다.

이 프로젝트에서 배우는 것

  • 5가지 산술 연산자를 한 프로그램에서 모두 사용할 수 있다
  • 정수 나눗셈의 몫과 나머지를 구분할 수 있다
  • (double) 캐스팅으로 실수 나눗셈을 할 수 있다
  • printf에서 %%로 퍼센트 기호를 출력할 수 있다

간단 계산기 코드

두 정수를 입력받고, 5가지 연산 결과를 모두 출력합니다. 실수 나눗셈 결과도 추가합니다.

#include <stdio.h> int main(void) { int a, b; printf("첫 번째 수: "); scanf("%d", &a); printf("두 번째 수: "); scanf("%d", &b); printf("=== 계산 결과 ===\n"); printf("%d + %d = %d\n", a, b, a + b); printf("%d - %d = %d\n", a, b, a - b); printf("%d * %d = %d\n", a, b, a * b); printf("%d / %d = %d (몫)\n", a, b, a / b); printf("%d %% %d = %d (나머지)\n", a, b, a % b); printf("실수 나눗셈: %.2f\n", (double)a / b); return 0; }

Q1
결과 예측하기
쉬움
a=20, b=7일 때 a+b, a/b, a%b의 결과는?
내 답안
정답 보기
a+b = 27, a/b = 2 (정수), a%b = 6
Q2
세 수 계산기
보통
세 수를 입력받아 합계, 곱, 평균을 출력하세요.
입력3 7 5
출력합: 15, 곱: 105, 평균: 5.0
내 답안
정답 보기
int a, b, c; scanf("%d %d %d", &a, &b, &c); printf("합: %d, 곱: %d, 평균: %.1f\n", a+b+c, a*b*c, (a+b+c)/3.0);
Q3
몫과 나머지 검증
보통
a == (a/b)*b + (a%b)가 항상 성립하는지 확인하는 코드를 작성하세요.
내 답안
정답 보기
printf("검증: %d == %d\n", a, (a/b)*b + (a%b)); // 17 == (17/5)*5 + (17%5) == 3*5+2 == 17

핵심 요약

  • 5가지 산술 연산: +, -, *, /(몫), %(나머지)
  • printf에서 %를 출력하려면 %%로 써야 한다
  • (double)b는 b를 일시적으로 실수로 변환하는 캐스팅이다
  • a == (a/b)*b + (a%b) 관계가 항상 성립한다
