Array Traversal with p++ Pattern
배열을 순회하는 데 인덱스(arr[i]) 대신 포인터(p++)를 쓸 수 있다.
p++는 포인터를 다음 원소로 이동시킨다. 문자열 처리, 메모리 복사 등 C의 핵심 패턴이다.
난이도 p++ 순회 패턴 배열과 포인터 동등성 종료 조건 이해
p++ 이 실제로 하는 일
다양한 순회 패턴 코드
traverse.c #include <stdio.h>

int main() {
    int arr[] = {10, 20, 30, 40, 50};
    int n = sizeof(arr) / sizeof(arr[0]);
    int *p;
    
    /* 방법 1: 기본 p++ 순회 */
    printf("방법1: ");
    for (p = arr; p < arr + n; p++)
        printf("%d ", *p);
    printf("\n");
    
    /* 방법 2: while + p++ */
    printf("방법2: ");
    p = arr;
    while (p < arr + n)
        printf("%d ", *p++); // 출력 후 이동
    printf("\n");
    
    /* 방법 3: 역순 순회 (p--) */
    printf("역순: ");
    for (p = arr + n - 1; p >= arr; p--)
        printf("%d ", *p);
    printf("\n");
    
    /* 방법 4: 포인터로 합산 */
    int sum = 0;
    for (p = arr; p < arr + n; p++)
        sum += *p;
    printf("합계: %d\n", sum);
    
    return 0;
}

p++ 패턴을 함수로 분리
ptr_func.c #include <stdio.h>

/* 포인터 순회로 합계 계산 */
int sum_array(int *p, int n) {
    int total = 0;
    int *end = p + n; // 끝 주소 미리 계산
    while (p < end)
        total += *p++; // 값 더하고 이동
    return total;
}

/* 포인터로 배열 출력 */
void print_array(int *p, int n) {
    printf("[ ");
    for (int *end = p + n; p < end; p++)
        printf("%d ", *p);
    printf("]");
}

/* 포인터로 배열 값 2배로 */
void double_array(int *p, int n) {
    for (int i = 0; i < n; i++, p++)
        *p *= 2;
}
주의: 배열 이름 arr은 상수 포인터이므로 arr++ 불가! 반드시 int *p = arr;처럼 별도 포인터 변수를 만들어야 한다.
도전 과제

도전 과제

1 포인터로 배열 복사: void copy_array(int *src, int *dst, int n) — p++ 패턴으로 src → dst 복사.
2 짝수만 출력: void print_even(int *p, int n) — 배열을 순회하며 짝수만 출력.
3 두 배열 합산: void add_arrays(int *a, int *b, int *result, int n) — a[i]+b[i]를 result[i]에 저장.
연습문제
1 p++과 (*p)++의 차이는?
p++: 포인터 p가 다음 원소 주소로 이동. *p의 값은 변하지 않음.
(*p)++: p가 가리키는 값을 1 증가. 포인터 p의 위치는 변하지 않음.
*p++ = *(p++): 현재 *p를 읽고, p를 다음으로 이동.
2 for (p = arr; p < arr + n; p++)에서 종료 조건 p < arr + n이 의미하는 것은?
arr + n은 배열의 마지막 원소 다음 주소(경계 밖). p가 이 주소에 도달하면 순회 종료. 예: n=5이면 arr+5 = &arr[5]로, 이 주소에는 접근하지 않는다.
3 while (*p != '\0') p++;는 무엇을 하는가?
문자열의 끝(null 문자 '\0')을 찾는 코드. 문자열 길이 계산 함수(strlen)의 핵심 원리. p는 문자열 끝에 위치하게 되므로 p - start가 문자열 길이다.
4 역순 순회에서 p = arr + n - 1로 초기화하는 이유는?
n=5이면 arr+n = arr[5](경계 밖). 마지막 원소는 arr[4] = arr + 4 = arr + n - 1. 역순 시작점이므로 -1을 빼야 한다.
5 int *p = arr; 대신 arr++를 직접 쓰면 왜 오류가 나는가?
배열 이름 arr은 첫 원소의 주소를 나타내는 상수 포인터다. 상수이므로 값(주소)을 변경할 수 없다. arr++는 arr의 값을 바꾸려는 시도이므로 컴파일 오류가 발생한다. 별도 포인터 변수 p에 복사해야 한다.

이번 프로젝트 핵심

  • p++는 다음 원소 주소로 이동 (int면 +4바이트)
  • for (p=arr; p<arr+n; p++) 패턴이 기본형
  • 배열 이름은 상수라 arr++ 불가 — int *p = arr; 로 복사
  • *p++는 값을 읽고 나서 이동하는 단축 표현
  • 문자열 순회는 *p != '\0' 조건 사용
