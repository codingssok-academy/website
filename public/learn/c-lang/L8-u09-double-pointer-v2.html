Chapter 8 — Unit 09

이중 포인터 int **pp
포인터의 포인터

포인터를 가리키는 포인터, 이중 포인터를 배웁니다. 세 단계의 화살표 연결을 그림으로 이해합니다.

이 유닛에서 배우는 것

  • 이중 포인터 int **pp가 무엇인지 이해합니다.
  • 세 단계(pp → p → a)의 화살표 연결을 그릴 수 있습니다.
  • *pp, **pp의 결과를 계산합니다.
  • 이중 포인터로 포인터 변수를 함수에서 수정합니다.
  • 문자열 배열에서 이중 포인터를 활용합니다.

이중 포인터 = 포인터를 가리키는 포인터

단일 포인터는 일반 변수를 가리킵니다. 이중 포인터(int **pp)는 포인터 변수를 가리킵니다. 화살표가 두 번 연결됩니다.

int a = 42; int *p = &a; // p는 a를 가리킴 int **pp = &p; // pp는 p를 가리킴 printf("%d\n", a); // 42 printf("%d\n", *p); // 42 printf("%d\n", **pp); // 42 printf("%p\n", *pp); // p의 값 = a의 주소

이중 포인터로 포인터 변수 수정

함수에서 포인터 변수 자체를 수정하려면 이중 포인터가 필요합니다.

void change_ptr(int **pp, int *new_target) { *pp = new_target; // 포인터 변수 자체 변경 } int main() { int x = 10, y = 20; int *p = &x; printf("*p=%d\n", *p); // 10 change_ptr(&p, &y); // p를 y로 재지정 printf("*p=%d\n", *p); // 20 return 0; }

문자열 배열과 이중 포인터

main 함수의 char **argv는 이중 포인터입니다. 명령줄 인수 배열을 나타냅니다.

// char **는 문자열 배열을 받는 표준 방법 void print_strings(char **strs, int n) { for (int i = 0; i < n; i++) { printf("%s\n", strs[i]); // strs[i] = *(strs+i) } } int main(int argc, char **argv) { printf("프로그램: %s\n", argv[0]); return 0; }

이중 포인터 값 수정 종합 예제

#include <stdio.h> int main() { int a = 100; int *p = &a; int **pp = &p; printf("a = %d\n", a); // 100 printf("*p = %d\n", *p); // 100 printf("**pp = %d\n", **pp); // 100 printf("&a = %p\n", &a); // 0x1000 printf("p = %p\n", p); // 0x1000 printf("*pp = %p\n", *pp); // 0x1000 printf("&p = %p\n", &p); // 0x2000 printf("pp = %p\n", pp); // 0x2000 **pp = 999; // a를 999로 변경 printf("a(변경후) = %d\n", a); // 999 return 0; }

정리 + 연습문제

핵심 정리

핵심 정리

  • int **pp = &p: pp는 포인터 p의 주소 저장
  • *pp: p의 값 (= a의 주소), **pp: a의 값
  • 이중 포인터로 함수에서 포인터 변수 자체를 수정 가능
  • 문자열 배열 char **argv = char *argv[]
  • * 하나 당 역참조 한 단계씩 올라감
