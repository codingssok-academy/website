양방향 연결 리스트

이전/다음 곡 이동이 가능한 플레이리스트를 양방향(doubly linked list) 연결 리스트로 구현합니다. prev 포인터를 추가하면 뒤로 탐색이 가능해집니다.

이 프로젝트에서 만드는 것

  • Song 노드에 title, artist, prev, next를 저장합니다.
  • 플레이리스트 끝에 곡을 추가합니다.
  • 현재 곡을 재생(출력)하고 다음 곡으로 이동합니다.
  • 이전 곡으로 돌아가는 prevSong() 기능을 구현합니다.
  • 전체 리스트를 앞뒤로 순회합니다.

양방향 연결 리스트 구조

단방향은 next만 있어서 앞으로만 이동합니다. 양방향은 prev도 있어서 뒤로 돌아갈 수 있습니다.

#include <stdio.h> #include <stdlib.h> #include <string.h> typedef struct Song { char title[50]; char artist[30]; struct Song *prev, *next; } Song; Song *head=NULL, *tail=NULL, *current=NULL; void addSong(const char*title, const char*artist) { Song *s=(Song*)malloc(sizeof(Song)); strcpy(s->title,title); strcpy(s->artist,artist); s->prev=tail; s->next=NULL; if(tail) tail->next=s; else head=s; tail=s; if(!current) current=s; } void playCurrent() { if(!current){ printf("없음\n"); return; } printf("재생: %s - %s\n", current->title, current->artist); } void nextSong() { if(current && current->next) { current=current->next; playCurrent(); } else printf("마지막 곡\n"); } void prevSong() { if(current && current->prev) { current=current->prev; playCurrent(); } else printf("첫 번째 곡\n"); } void printList() { printf("== 플레이리스트 ==\n"); for(Song*c=head;c;c=c->next) printf("%s %s - %s\n", c==current?">":" ", c->title, c->artist); } void freeAll() { Song*c=head,*nx; while(c){nx=c->next;free(c);c=nx;} head=tail=current=NULL; } int main() { addSong("Dynamite","BTS"); addSong("Blinding Lights","The Weeknd"); addSong("Shape of You","Ed Sheeran"); addSong("Stay","Kid LAROI"); printList(); playCurrent(); nextSong(); nextSong(); prevSong(); freeAll(); return 0; }

실행 결과

== 플레이리스트 == > Dynamite - BTS Blinding Lights - The Weeknd Shape of You - Ed Sheeran Stay - Kid LAROI 재생: Dynamite - BTS 재생: Blinding Lights - The Weeknd 재생: Shape of You - Ed Sheeran 재생: Blinding Lights - The Weeknd
