문자열 비교 — 인증의 핵심
로그인은 "사용자가 입력한 문자열"과 "저장된 문자열"이 완전히 같은지 확인하는 과정이다.
C에서는 == 대신 strcmp()를 사용한다. strcmp가 0을 반환하면 일치 — 이것이 로그인 성공 조건이다.
3회 시도 제한, 대소문자 구분 등 실제 로그인 요소도 함께 구현한다.

왜 == 를 사용하면 안 되나?

C에서 문자열 변수는 배열의 주소(포인터)다. id == "admin"은 주소를 비교하는 것이라 항상 거짓이 된다. 반드시 strcmp()로 내용을 비교해야 한다.

기본 로그인 구현
#include <stdio.h> #include <string.h> int main() { char saved_id[20] = "admin"; // 저장된 아이디 char saved_pw[20] = "1234"; // 저장된 비밀번호 char input_id[20], input_pw[20]; printf("ID: "); scanf("%s", input_id); printf("PW: "); scanf("%s", input_pw); if (strcmp(input_id, saved_id) == 0 && strcmp(input_pw, saved_pw) == 0) { printf("로그인 성공! 환영합니다.\n"); } else if (strcmp(input_id, saved_id) == 0) { printf("비밀번호가 틀렸습니다.\n"); } else { printf("아이디를 찾을 수 없습니다.\n"); } return 0; }
3회 시도 제한 추가
int main() { char saved_id[] = "admin", saved_pw[] = "1234"; char id[20], pw[20]; int attempts = 0; while (attempts < 3) { printf("시도 %d/3\n", attempts + 1); printf("ID: "); scanf("%s", id); printf("PW: "); scanf("%s", pw); if (strcmp(id, saved_id) == 0 && strcmp(pw, saved_pw) == 0) { printf("로그인 성공!\n"); return 0; } printf("실패. 남은 시도: %d\n", 2 - attempts); attempts++; } printf("계정이 잠겼습니다.\n"); return 0; }
응용 — 다중 계정 로그인
2차원 배열로 여러 계정 관리

여러 계정을 2차원 char 배열로 저장하고, for 루프로 순서대로 비교하는 패턴이다.

#include <stdio.h> #include <string.h> #define MAX_USERS 3 int main() { char users[MAX_USERS][20] = {"admin", "alice", "bob"}; char pwds[MAX_USERS][20] = {"1234", "abcd", "5678"}; char id[20], pw[20]; printf("ID: "); scanf("%s", id); printf("PW: "); scanf("%s", pw); int found = 0; for (int i = 0; i < MAX_USERS; i++) { if (strcmp(id, users[i]) == 0) { if (strcmp(pw, pwds[i]) == 0) { printf("로그인 성공! 환영합니다, %s\n", users[i]); } else { printf("비밀번호 불일치\n"); } found = 1; break; } } if (!found) printf("존재하지 않는 아이디\n"); return 0; }
found 플래그 패턴: 루프에서 일치 항목을 찾으면 found=1로 표시하고 break. 루프 후 found가 0이면 "찾지 못함" 처리. 이것은 검색 알고리즘의 기본 패턴이다.

Q1. 개념 확인

strcmp("apple", "apple")의 반환값은 무엇인가? strcmp("apple", "banana")의 반환값은?

정답 보기
strcmp("apple","apple") = 0 (같음)
strcmp("apple","banana") = 음수 ('a' < 'b' 이므로)
Q2. 오류 찾기

아래 코드에서 버그를 찾으시오.

if (strcmp(input_pw, saved_pw)) { printf("로그인 성공\n"); }
정답 보기
strcmp 반환값이 0일 때 성공인데, if (strcmp(...))는 0이 아닐 때 true. 조건이 반대다. if (strcmp(...) == 0)으로 수정해야 한다.

핵심 정리

strcmp반환 0 = 같음, 음수 = 앞이 작음, 양수 = 앞이 큼
주의if(strcmp(a,b))는 불일치 시 true — 조건 반대. 반드시 == 0 명시
다중계정2차원 배열 + for 루프 + found 플래그 패턴
보안실제 서비스에서는 비밀번호를 평문으로 저장하지 않음 (해시 사용)
