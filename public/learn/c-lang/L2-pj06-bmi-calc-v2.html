BMI 계산기

키(cm)와 몸무게(kg)를 입력받아 BMI를 계산하는 프로그램을 만듭니다. float/double, scanf, printf의 소수점 서식을 배웁니다.

이 프로젝트에서 배우는 것

  • double 자료형으로 소수점 있는 값을 저장할 수 있다
  • scanf("%lf", &변수)로 실수를 입력받을 수 있다
  • printf("%.1f")로 소수점 자릿수를 지정할 수 있다
  • cm를 m으로 변환하는 단위 변환을 할 수 있다
  • BMI 공식을 코드로 구현할 수 있다

BMI란 무엇인가?

BMI(Body Mass Index, 체질량지수)는 키와 몸무게로 계산하는 건강 지표입니다. 병원, 학교 건강검진에서 널리 사용됩니다.

핵심은 단위 변환입니다. 키를 cm로 입력받지만, 공식에는 m(미터)가 필요합니다. 170cm는 1.70m으로 바꿔야 합니다.

이제 코드를 작성해 봅시다. double 자료형은 소수점이 있는 숫자를 저장합니다.

#include <stdio.h> int main(void) { double height_cm, weight, height_m, bmi; printf("키(cm)를 입력하세요: "); scanf("%lf", &height_cm); printf("몸무게(kg)를 입력하세요: "); scanf("%lf", &weight); height_m = height_cm / 100.0; // cm -> m 변환 bmi = weight / (height_m * height_m); // BMI 공식 printf("BMI: %.1f\n", bmi); return 0; }

코드 분석: 핵심 포인트

scanf에서 %lf는 double용 서식 지정자입니다. %f는 float용이고, %lf는 double용입니다. 출력할 때 printf에서는 둘 다 %f로 출력합니다.

심화: 다양한 입력 처리

100.0으로 나누는 이유가 중요합니다. 만약 100(정수)으로 나누면 어떻게 될까요?

double 변수에 담겨 있으므로 height_cm / 100.0은 정상적으로 1.70이 됩니다. 하지만 만약 int끼리 나누면 소수점이 사라집니다. 이것이 형변환의 핵심입니다.

// 주의! int끼리 나누면 소수점이 사라진다 int a = 170; int b = 100; printf("%d\n", a / b); // 1 (소수점 버림) printf("%f\n", a / 100.0); // 1.700000 (정확)

핵심 요약

  • double은 소수점이 있는 숫자를 저장하는 자료형이다 (8바이트)
  • scanf에서 double은 %lf, printf에서는 %f를 사용한다
  • printf("%.1f")는 소수점 1자리까지만 출력한다
  • BMI = 몸무게(kg) / (키(m) x 키(m))
  • cm에서 m으로 바꾸려면 100.0으로 나눈다 (정수 100이 아님!)
