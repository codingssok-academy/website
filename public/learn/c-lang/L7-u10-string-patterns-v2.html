문자열 패턴
— strtok와 문자 치환

strtok으로 문자열을 분리하고, 특정 문자를 치환하는 패턴을 배웁니다.

이 유닛에서 배우는 것

  • strtok으로 문자열을 구분자 기준으로 분리할 수 있습니다.
  • strtok이 원본 문자열을 수정함을 이해합니다.
  • 반복 호출 시 NULL을 첫 인자로 넘기는 방법을 압니다.
  • for/while로 문자열을 순회하며 특정 문자를 교체합니다.
  • CSV(쉼표 구분) 데이터를 파싱하는 패턴을 구현합니다.

strtok — 문자열 토큰 분리

strtok(str, delim)은 문자열을 구분자(delimiter)로 나눠 각 조각(토큰)을 순서대로 반환합니다. 원본 문자열을 수정하므로 주의가 필요합니다.

#include <stdio.h> #include <string.h> int main() { char str[] = "apple,banana,cherry"; char *token; // 첫 번째 토큰 token = strtok(str, ","); // 이후 토큰: 첫 인자에 NULL while (token != NULL) { printf("토큰: %s\n", token); token = strtok(NULL, ","); } return 0; }

주의: strtok은 원본 문자열을 수정합니다. 원본을 보존해야 한다면 strcpy로 복사 후 사용하세요.

문자 치환 패턴

문자열을 순회하며 특정 문자를 다른 문자로 바꾸는 패턴입니다.

#include <stdio.h> #include <string.h> // 특정 문자를 다른 문자로 치환 void replace_char(char str[], char from, char to) { for (int i = 0; i < (int)strlen(str); i++) { if (str[i] == from) str[i] = to; } } int main() { char s[50] = "Hello World from C"; replace_char(s, ' ', '_'); printf("%s\n", s); // Hello_World_from_C return 0; }

핵심 정리

핵심 요약

  • strtok(str, delim): 구분자로 문자열을 분리합니다.
  • 두 번째 이후 호출은 첫 인자에 NULL을 넘깁니다.
  • 토큰이 없으면 NULL을 반환 — while 루프 종료 조건.
  • strtok은 원본을 수정! 원본 보존 필요 시 strcpy로 복사.
  • 문자 치환: for문으로 순회 중 if(s[i]==from) s[i]=to;

전체 예제 — 문장 파서

#include <stdio.h> #include <string.h> int main() { char sentence[100]; char backup[100]; char words[20][20]; int count = 0; printf("문장 입력: "); fgets(sentence, sizeof(sentence), stdin); sentence[strlen(sentence)-1] = '\0'; // \n 제거 strcpy(backup, sentence); // 원본 보존 char *token = strtok(sentence, " "); while (token && count < 20) { strcpy(words[count++], token); token = strtok(NULL, " "); } printf("\n원본: %s\n", backup); printf("단어 수: %d\n", count); for (int i = 0; i < count; i++) printf(" [%d] %s\n", i, words[i]); return 0; }
