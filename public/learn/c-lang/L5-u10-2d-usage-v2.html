2차원 배열 활용 — 구구단·좌석·행렬

2차원 배열로 구구단 표를 저장하고, 좌석 배치도를 관리하고, 행렬 연산을 구현합니다. 행 합계·열 합계·대각선 패턴까지 실전 활용법을 익힙니다.

이 유닛에서 배우는 것

  • 2차원 배열로 구구단 표를 저장하고 출력할 수 있습니다.
  • 좌석 배치도(0/1 표현)를 구현할 수 있습니다.
  • 행렬 덧셈 알고리즘을 구현할 수 있습니다.
  • 행 합계·열 합계·대각선 합을 구할 수 있습니다.
  • 2차원 배열의 패턴 접근법을 이해합니다.

실전 예제 1 — 구구단 표 저장

구구단을 2차원 배열 gugu[10][10]에 저장하면, gugu[단][수]로 즉시 접근할 수 있습니다. 인덱스 0은 사용하지 않아 직관적입니다.

int gugu[10][10] = {0}; int i, j; // 구구단 채우기 for(i = 2; i <= 9; i++) for(j = 1; j <= 9; j++) gugu[i][j] = i * j; // 원하는 단 즉시 출력 printf("3단: "); for(j = 1; j <= 9; j++) printf("%d ", gugu[3][j]); // 3 6 9 12 15 18 21 24 27

실전 예제 2 — 좌석 배치도

영화관이나 교실의 좌석을 0(빈 자리)과 1(예약됨)로 2차원 배열에 저장합니다.

int seat[4][5] = { {0,1,0,1,0}, // A행 {1,0,0,0,1}, // B행 {0,0,1,0,0}, // C행 {1,1,0,0,1} // D행 }; // 빈 자리 찾기 for(i=0; i<4; i++) for(j=0; j<5; j++) if(seat[i][j] == 0) printf("빈좌석: %d행%d열\n", i, j);

실전 예제 3 — 행렬 덧셈

두 행렬 A, B를 더해 결과 C를 구합니다. 같은 위치(i, j)의 원소끼리 더하면 됩니다. 행렬 크기가 같아야 합니다.

int a[2][2] = {{1,2},{3,4}}; int b[2][2] = {{5,6},{7,8}}; int c[2][2], i, j; for(i=0; i<2; i++) for(j=0; j<2; j++) c[i][j] = a[i][j] + b[i][j]; // 같은 위치끼리 덧셈

행 합계·열 합계·대각선 패턴

2차원 배열에서 행별 합계, 열별 합계, 대각선 원소의 합을 구하는 패턴은 자주 출제됩니다.

따라해보세요
1
3×3 배열의 각 열 합계를 출력해보세요.
for(j=0; j<3; j++) { csum = 0; for(i=0; i<3; i++) csum += a[i][j]; printf("%d열 합: %d\n", j, csum); }
열 인덱스 j를 바깥, 행 인덱스 i를 안쪽에 씁니다

종합 예제 — 학급 점수 분석

학생 4명의 과목별(국어·수학·영어) 점수를 2차원 배열에 저장하고, 학생별 평균과 과목별 평균을 구합니다.

int score[3][3] = { {80, 75, 90}, {95, 88, 72}, {70, 92, 85} }; int i, j, sum; // 학생별 평균 (행 합계) for(i=0; i<3; i++) { sum = 0; for(j=0; j<3; j++) sum += score[i][j]; printf("학생%d 평균: %.1f\n", i, (float)sum/3); } // 과목별 평균 (열 합계) char *subj[] = {"국어","수학","영어"}; for(j=0; j<3; j++) { sum = 0; for(i=0; i<3; i++) sum += score[i][j]; printf("%s 평균: %.1f\n", subj[j], (float)sum/3); }

핵심 정리

  • 구구단 저장: gugu[i][j] = i*j — O(n²) 채우기, 즉시 조회
  • 좌석 배치: 0/1 비트맵 — seat[i][j]=1 예약, ==0 빈 자리 확인
  • 행렬 덧셈: c[i][j] = a[i][j] + b[i][j] — 같은 위치끼리
  • 행 합계: 바깥 for=행, 안쪽 for=열 → sum 누적
  • 열 합계: 바깥 for=열, 안쪽 for=행 → 인덱스 순서 바꾸기
  • 대각선 합: for(i=0;i<n;i++) diag+=a[i][i]
