문자열 배열
— char names[5][20]

2차원 char 배열로 여러 문자열을 저장하고 관리하는 방법을 배웁니다.

이 유닛에서 배우는 것

  • 2차원 char 배열로 여러 문자열을 저장할 수 있습니다.
  • char names[5][20]의 의미를 설명할 수 있습니다.
  • for문으로 문자열 배열을 입출력할 수 있습니다.
  • 문자열 배열에 strcpy로 문자열을 복사합니다.
  • strcmp로 여러 문자열을 정렬할 수 있습니다.

char names[5][20] — 이름 5개 저장

문자열을 여러 개 저장하려면 2차원 char 배열을 사용합니다. char names[5][20]은 최대 20글자짜리 이름을 5개 저장할 수 있습니다.

#include <stdio.h> #include <string.h> int main() { // 초기화와 함께 선언 char names[5][20] = { "김나바", "이코딩", "박쏙쏙", "최프로", "정클론" }; // 모든 이름 출력 for (int i = 0; i < 5; i++) printf("%d번: %s\n", i+1, names[i]); // 특정 이름 변경 strcpy(names[2], "박새학기"); printf("3번: %s\n", names[2]); return 0; }

입력받아 저장하기

#include <stdio.h> int main() { char names[3][30]; for (int i = 0; i < 3; i++) { printf("%d번째 이름: ", i+1); scanf("%s", names[i]); // & 불필요! } printf("\n=== 명단 ===\n"); for (int i = 0; i < 3; i++) printf("%d. %s\n", i+1, names[i]); return 0; }

문자열 배열 정렬

strcmp를 이용해 문자열 배열을 사전순으로 정렬할 수 있습니다.

#include <stdio.h> #include <string.h> int main() { char arr[4][20] = {"cherry", "apple", "date", "banana"}; char tmp[20]; int n = 4; for (int i = 0; i < n-1; i++) { for (int j = 0; j < n-1-i; j++) { if (strcmp(arr[j], arr[j+1]) > 0) { strcpy(tmp, arr[j]); strcpy(arr[j], arr[j+1]); strcpy(arr[j+1], tmp); } } } for (int i = 0; i < n; i++) printf("%s\n", arr[i]); return 0; }

핵심 정리

핵심 요약

  • char names[n][m]: n개의 문자열, 각 최대 m-1글자 저장
  • names[i]로 i번째 문자열에 접근합니다.
  • scanf("%s", names[i])로 입력, & 불필요합니다.
  • strcpy(names[i], str)로 복사, strcmp로 비교합니다.
  • for문으로 배열 전체를 순회해 처리합니다.

전체 예제 — 반 명단 관리

#include <stdio.h> #include <string.h> int main() { char names[5][20]; int scores[5]; for (int i = 0; i < 5; i++) { printf("%d번 이름: ", i+1); scanf("%s", names[i]); printf("%d번 점수: ", i+1); scanf("%d", &scores[i]); } printf("\n=== 성적표 ===\n"); int total = 0; for (int i = 0; i < 5; i++) { printf("%-10s: %d점\n", names[i], scores[i]); total += scores[i]; } printf("평균: %.1f점\n", (double)total / 5); return 0; }
