Level 2a - Project 03

용돈 계산기

주간 용돈을 입력받아 월간, 연간 용돈을 계산하는 프로그램을 만듭니다. 곱셈 연산을 활용합니다.

프로젝트 목표

  • 곱셈 연산자(*)를 사용해 계산할 수 있습니다.
  • scanf로 입력받은 값으로 여러 계산을 수행합니다.
  • 하나의 입력에서 여러 결과를 출력하는 프로그램을 만듭니다.
  • 저축 목표 계산으로 응용할 수 있습니다.
PROJECT 03

Step 1. 곱셈으로 계산하기

C언어에서 곱셈은 * 기호를 사용합니다. 주간 용돈에 4를 곱하면 월간, 52를 곱하면 연간 용돈이 됩니다.

한 달은 약 4주, 1년은 52주입니다. 주급에 4를 곱하면 월급, 52를 곱하면 연봉을 계산할 수 있습니다.

따라해보세요
1
주급을 입력받아 변수에 저장해보세요.
#include <stdio.h> int main() { int weekly; printf("주간 용돈(원): "); scanf("%d", &weekly); printf("입력한 주급: %d원\n", weekly); return 0; }
5000 입력 시 "입력한 주급: 5000원"
2
월급과 연봉을 계산해보세요.
int monthly = weekly * 4; int yearly = weekly * 52; printf("월간 용돈: %d원\n", monthly); printf("연간 용돈: %d원\n", yearly);
5000원 입력 시 월간 20000원, 연간 260000원
3
하루 용돈도 계산해보세요. (주급 / 7)
int daily = weekly / 7; printf("하루 용돈: %d원\n", daily);
5000 / 7 = 714원 (정수 나눗셈, 소수점 버림)
PROJECT 03

Step 2. 완성 코드

입력받은 주급으로 하루, 월간, 연간 용돈을 모두 계산하는 프로그램입니다.

#include <stdio.h> int main() { /* 용돈 계산기 */ int weekly; int daily, monthly, yearly; printf("========================\n"); printf(" 용돈 계산기\n"); printf("========================\n"); printf("주간 용돈(원): "); scanf("%d", &weekly); daily = weekly / 7; monthly = weekly * 4; yearly = weekly * 52; printf("------------------------\n"); printf("하루 용돈:\t%d원\n", daily); printf("월간 용돈:\t%d원\n", monthly); printf("연간 용돈:\t%d원\n", yearly); printf("========================\n"); return 0; }

주간 용돈(원): 5000
------------------------
하루 용돈:    714원
월간 용돈:    20000원
연간 용돈:    260000원

Step 3. 응용하기

저축 목표를 설정하고, 몇 주가 걸리는지 계산하는 프로그램으로 확장합니다.

응용 따라해보세요
4
저축 목표와 주급을 입력받아 필요한 주 수를 계산해보세요.
int goal, weekly, weeks; printf("저축 목표(원): "); scanf("%d", &goal); printf("주간 용돈(원): "); scanf("%d", &weekly); weeks = goal / weekly; printf("필요한 기간: %d주\n", weeks);
목표 100000, 주급 5000 시 "20주"
Q3
도전: 용돈 인상 비교
보통
현재 주급과 인상된 주급을 입력받아, 연간 차이를 계산하세요.
입력현재: 5000, 인상: 7000
출력연간 차이: 104000원
내 답안
힌트 보기
각각 52를 곱해서 연간 금액을 구하고, 빼면 됩니다. (7000-5000)*52 = 104000
정답 보기
int now, raised, diff; printf("현재 주급: "); scanf("%d", &now); printf("인상 주급: "); scanf("%d", &raised); diff = (raised - now) * 52; printf("연간 차이: %d원\n", diff);

핵심 요약

  • *는 곱셈, /는 나눗셈 연산자이다
  • int끼리 나누면 소수점 아래는 버려진다 (정수 나눗셈)
  • 하나의 입력으로 여러 계산 결과를 만들 수 있다
  • 변수에 계산 결과를 저장하면 나중에 다시 쓸 수 있다
  • 괄호 ()로 계산 순서를 지정할 수 있다
