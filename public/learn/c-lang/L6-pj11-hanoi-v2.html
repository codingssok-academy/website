이 프로젝트에서 배우는 것

  • 재귀 함수가 무엇인지 이해합니다.
  • 하노이 탑 규칙(큰 원반이 작은 원반 위에 오면 안 됨)을 압니다.
  • hanoi(n, from, to, via) 재귀 함수를 작성합니다.
  • 재귀의 기저 조건(base case)이 왜 중요한지 배웁니다.

PROJECT 11
하노이 탑
재귀 함수 + 기저 조건 + 분할 정복

재귀란?

재귀(Recursion)는 함수가 자기 자신을 호출하는 것입니다. 반드시 멈추는 조건(기저 조건)이 있어야 합니다. 없으면 무한 루프처럼 계속 실행됩니다.

하노이 탑 재귀 아이디어 (n개 원반 A → C)
1단계: 위의 n-1개를 A에서 B로 이동 (C를 보조로)
2단계: 가장 큰 원반 하나를 A에서 C로 이동
3단계: B에 있는 n-1개를 B에서 C로 이동 (A를 보조로)
// 하노이 탑 재귀 함수 void hanoi(int n, char from, char to, char via) { // 기저 조건: 원반이 1개면 바로 이동 if (n == 1) { printf("원반 1: %c → %c\n", from, to); return; } // 1단계: n-1개를 via로 hanoi(n-1, from, via, to); // 2단계: 가장 큰 원반 이동 printf("원반 %d: %c → %c\n", n, from, to); // 3단계: n-1개를 목표로 hanoi(n-1, via, to, from); }
기저 조건(Base Case): n == 1 일 때 그냥 이동하고 return합니다. 이것이 없으면 재귀가 멈추지 않아 스택 오버플로우가 발생합니다!

하노이 탑 — 전체 코드 + 실행 결과

/* ====== 하노이 탑 재귀 ====== */ #include <stdio.h> int moveCount = 0; // 이동 횟수 카운터 void hanoi(int n, char from, char to, char via) { if (n == 1) { printf("원반 1: %c → %c\n", from, to); moveCount++; return; } hanoi(n-1, from, via, to); printf("원반 %d: %c → %c\n", n, from, to); moveCount++; hanoi(n-1, via, to, from); } int main() { int n; printf("원반 개수: "); scanf("%d", &n); printf("=== 하노이 탑 (원반 %d개) ===\n", n); hanoi(n, 'A', 'C', 'B'); printf("총 이동 횟수: %d (= 2^%d - 1)\n", moveCount, n); return 0; }

핵심 정리

핵심 정리

  • 재귀: 함수가 자기 자신을 호출
  • 기저 조건(base case): 재귀를 멈추는 조건 — 반드시 필요!
  • 하노이 n개: hanoi(n-1) → 이동 → hanoi(n-1) 패턴
  • n개 원반 최소 이동 횟수 = 2^n - 1
