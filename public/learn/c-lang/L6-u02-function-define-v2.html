함수 선언과 정의 — 구조 완벽 분석

반환타입 함수이름(매개변수) {본문} 구조를 해부합니다. main 위에 정의하는 규칙과 각 부분의 역할을 배웁니다.

이 유닛에서 배우는 것

  • 함수 정의의 4가지 구성 요소를 말할 수 있습니다.
  • 반환타입, 함수이름, 매개변수, 본문을 구분합니다.
  • 함수는 main 위에 정의해야 하는 이유를 이해합니다.
  • 함수를 직접 정의하고 호출하는 코드를 작성합니다.
  • 반환타입 void와 int의 차이를 압니다.

함수 구조 해부하기

함수를 만들 때는 4가지를 반드시 써야 합니다. 각 부분의 역할을 정확히 알아봅시다.

위 함수를 분석하면: int는 정수를 반환한다는 뜻, add는 함수 이름, int a, int b는 입력받을 두 정수, 중괄호 안이 실제 실행할 코드입니다.

각 구성 요소 설명

main 위에 정의해야 하는 이유

C언어는 코드를 위에서 아래로 읽습니다. main에서 함수를 호출할 때, 그 함수가 이미 정의되어 있어야 합니다. 그래서 함수는 main보다 위에 써야 합니다.

#include <stdio.h> // 1. 함수 정의 (main 위에!) int add(int a, int b) { return a + b; } int main() { // 2. 함수 호출 int result = add(3, 5); printf("결과: %d\n", result); // 결과: 8 return 0; }

핵심 정리

핵심 요약

  • 함수 구조: 반환타입 이름(매개변수) { 본문 }.
  • 반환타입: void(없음), int(정수), float(실수) 등.
  • 함수는 반드시 main보다 위에 정의합니다 (또는 프로토타입 사용, L6-u07).
  • 함수 이름은 변수 이름 규칙과 동일 (영문/밑줄/숫자, 숫자 시작 불가).
  • 매개변수가 없으면 빈 괄호 ()를 씁니다.
