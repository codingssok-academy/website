— getGrade(score) → char

점수를 받아 A~F 등급 문자를 반환하는 함수를 만들고, char 반환 타입과 if-else 사슬을 연습합니다.

이 프로젝트에서 배우는 것

  • char를 반환하는 함수를 만들 수 있습니다.
  • if-else if 사슬로 범위 조건을 처리할 수 있습니다.
  • %c 서식으로 char 값을 출력할 수 있습니다.
  • 함수 반환값을 char 변수에 저장할 수 있습니다.
  • 성적 시스템의 기본 구조를 이해합니다.
PROJECT 04
성적 판정 함수
char 반환 타입 + if-else if 사슬

성적 기준표

점수 범위등급의미
90 ~ 100A우수
80 ~ 89B양호
70 ~ 79C보통
60 ~ 69D미흡
0 ~ 59F낙제

char를 반환하는 함수

정수나 실수뿐 아니라 문자(char)도 반환할 수 있습니다. 등급처럼 한 글자로 된 결과를 돌려줄 때 씁니다.

// char를 반환하는 성적 판정 함수 char getGrade(int score) { if (score >= 90) { return 'A'; } else if (score >= 80) { return 'B'; } else if (score >= 70) { return 'C'; } else if (score >= 60) { return 'D'; } else { return 'F'; } } int main() { int score = 85; char grade = getGrade(score); // 'B' 반환 printf("점수: %d, 등급: %c\n", score, grade); return 0; }
핵심: if-else if 사슬에서 조건은 큰 수부터 씁니다. 90 이상 → 80 이상 → 70 이상 순서로 내려갑니다. 조건 순서가 바뀌면 결과가 틀립니다!

성적 판정 — 전체 프로그램

/* ====== 성적 판정 함수 프로그램 ====== */ #include <stdio.h> char getGrade(int score) { if (score >= 90) return 'A'; else if (score >= 80) return 'B'; else if (score >= 70) return 'C'; else if (score >= 60) return 'D'; else return 'F'; } void printResult(char name[], int score) { char grade = getGrade(score); printf("이름: %-8s 점수: %3d점 등급: %c\n", name, score, grade); } int main() { printf("===== 성적 판정표 =====\n"); printResult("홍길동", 95); printResult("김코딩", 82); printResult("이자바", 74); printResult("박파이", 61); printResult("최씨", 45); /* 사용자 입력 버전 */ int s; printf(\n"점수를 입력하세요: "); scanf("%d", &s); printf("등급: %c\n", getGrade(s)); return 0; }

연습 문제

1
조건 순서 이해
쉬움
조건을 반대 순서(60이상 먼저, 90이상 나중)로 쓰면 어떤 문제가 생길까요?

보통
등급에 따라 다른 메시지를 출력하는 void printMsg(char grade) 함수를 만드세요.
A: "최우수!", B: "잘했어요!", C: "보통이에요", D: "조금 더", F: "분발하세요"

void printMsg(char grade) { switch(grade) { case 'A': printf("최우수!\n"); break; case 'B': printf("잘했어요!\n"); break; case 'C': printf("보통이에요\n"); break; case 'D': printf("조금 더\n"); break; default: printf("분발하세요\n"); } }

핵심 정리

핵심 정리

  • char 함수명(int x) — 문자를 반환하는 함수
  • if-else if 사슬: 큰 숫자(높은 등급) 조건부터 작성
  • char 출력: printf("%c", grade)
  • char 값 비교: grade == 'A' (작은따옴표)
