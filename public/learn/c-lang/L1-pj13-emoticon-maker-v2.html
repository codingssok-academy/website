이모티콘 만들기

텍스트 문자로 다양한 표정의 이모티콘을 만들어봅니다. 기쁨, 슬픔, 분노, 졸음 등 감정을 표현합니다.

이 프로젝트에서 만들 것

  • 텍스트로 다양한 표정의 이모티콘을 만듭니다.
  • 한 줄 이모티콘과 여러 줄 이모티콘을 구분합니다.
  • 감정 이모티콘 모음집을 출력합니다.
  • 이름과 감정을 변수로 관리합니다.
  • 나만의 창작 이모티콘을 만들어봅니다.

한 줄 이모티콘

이모티콘은 특수문자 조합으로 만듭니다. 한 줄로 표현하는 간단한 이모티콘부터 시작합니다.

// 감정 이모티콘 모음 printf("기쁨: (^_^)\n"); printf("슬픔: (T_T)\n"); printf("놀람: (O_O)\n"); printf("졸림: (-_-)zzz\n"); printf("분노: (>_<)\n");
따라해보세요
1
위 이모티콘 5개를 모두 출력하세요.
printf("기쁨: (^_^)\n"); printf("슬픔: (T_T)\n"); printf("놀람: (O_O)\n"); printf("졸림: (-_-)zzz\n"); printf("분노: (>_<)\n");
5가지 감정 이모티콘이 출력됩니다
2
큰따옴표 안에 이모티콘을 넣어 출력하세요.
printf("친구가 말했다: \"(^_^) 안녕!\"\n");
친구가 말했다: "(^_^) 안녕!" 이 출력됩니다

여러 줄 이모티콘

여러 줄을 사용하면 더 표현력 있는 이모티콘을 만들 수 있습니다.

// 만세 이모티콘 (여러 줄) printf(" \\(^_^)/\n"); printf(" /| |\\\n"); printf(" / \\\n"); printf(" [만세!]\n\n");
// 이모티콘 메시지 카드 printf("+---------------------+\n"); printf("| |\n"); printf("| \\(^_^)/ |\n"); printf("| 생일 축하해! |\n"); printf("| |\n"); printf("+---------------------+\n");
따라해보세요
1
박수치는 이모티콘을 만드세요.
printf(" (^_^)\n"); printf(" 0/ \0\n"); printf(" [짝짝!]\n");
박수치는 이모티콘이 출력됩니다
2
메시지 카드 형식으로 응원 메시지를 만드세요.
printf("+-----------------+\n"); printf("| (^_^)v |\n"); printf("| 시험 잘 봐! |\n"); printf("+-----------------+\n");
응원 메시지 카드가 출력됩니다
3
나의 기분을 변수로 설정해 출력하세요.
char mood[] = "(^_^)"; char msg[] = "오늘 기분 최고!"; printf("%s %s\n", mood, msg);
(^_^) 오늘 기분 최고! 가 출력됩니다

도전 과제

Q1
감정 선택 출력
쉬움
이름과 감정 이모티콘을 변수에 저장하고, 상태 메시지를 출력하세요.
출력김철수: (^_^) 오늘 기분 좋아!
내 답안
힌트 보기
char name[] = "김철수"; char face[] = "(^_^)"; 후 printf로 조합하세요.
정답 확인
char name[] = "김철수"; char face[] = "(^_^)"; printf("%s: %s 오늘 기분 좋아!\n", name, face);
Q2
이모티콘 일기
쉬움
오늘의 일과를 이모티콘과 함께 3줄 일기로 출력하세요.
조건각 줄에 이모티콘 + 문장
내 답안
힌트 보기
아침/점심/저녁 상황에 맞는 이모티콘을 골라 붙이세요.
정답 확인
printf("(-.-)zzz 아침에 일어나기 힘들었다.\n"); printf("(^_^) 점심에 친구랑 맛있게 먹었다.\n"); printf("(-_-) 저녁에 공부하느라 피곤하다.\n");
Q3
이모티콘 카드
보통
친구에게 보내는 이모티콘 카드를 만드세요. 테두리, 이모티콘, 메시지, 이름이 모두 있어야 합니다.
조건테두리 + 이모티콘 + 메시지 + 보내는사람
내 답안
힌트 보기
+---+ 테두리 안에 이모티콘과 메시지, 마지막에 이름을 넣으세요.
정답 확인
printf("+--------------------+\n"); printf("| \\ (^_^) / |\n"); printf("| 친구야 힘내! |\n"); printf("| -철수 |\n"); printf("+--------------------+\n");

핵심 요약

  • 이모티콘은 ^ _ - O T > < / \ ( ) | 등의 문자 조합으로 만든다
  • 한 줄 이모티콘: (^_^) (T_T) (-_-)zzz 등
  • 여러 줄 이모티콘은 여러 개의 printf를 연속으로 써서 만든다
  • 역슬래시는 \\로 써야 화면에 \가 출력된다
  • 변수에 이모티콘 문자열을 저장하면 재사용이 편리하다
