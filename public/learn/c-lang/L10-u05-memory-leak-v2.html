메모리 누수란?
감지와 해결 패턴

malloc으로 할당했지만 free하지 않으면 메모리 누수가 발생합니다. 누수를 찾아내고 예방하는 패턴을 익힙니다.

이 유닛에서 배우는 것

  • 메모리 누수가 무엇인지 설명할 수 있습니다.
  • 누수가 발생하는 대표적인 상황을 인식합니다.
  • 누수를 예방하는 코드 패턴을 적용합니다.
  • Valgrind 등 감지 도구의 역할을 이해합니다.
  • goto 패턴으로 에러 발생 시 안전하게 해제합니다.

메모리 누수 — 물 새는 양동이

메모리 누수(memory leak)란 malloc으로 할당한 메모리를 free 하지 않아 힙 메모리가 계속 줄어드는 현상입니다.

누수가 발생하는 대표 패턴

// 패턴 1: 단순 free 누락 void leak1() { int *p = (int*)malloc(100); // free(p) 빠뜨림! → 100바이트 누수 } // 패턴 2: 조기 return 시 free 누락 void leak2(int x) { int *p = (int*)malloc(100); if (x < 0) { return; // free 없이 return! → 누수 } free(p); // 이 줄에 도달 못 함 } // 패턴 3: 포인터 덮어쓰기 void leak3() { int *p = (int*)malloc(100); p = (int*)malloc(200); // 첫 번째 주소 잃어버림! → 100바이트 누수 free(p); // 200바이트만 해제 }

누수 예방 패턴

// 예방 패턴 1: goto 사용 (에러 처리 일원화) int process() { int *a = (int*)malloc(100); if (a == NULL) goto cleanup; int *b = (int*)malloc(200); if (b == NULL) goto cleanup; // 작업... free(b); cleanup: free(a); // 항상 실행됨 return 0; } // 예방 패턴 2: 함수 단위로 할당/해제 int* allocData(int n) { return (int*)malloc(sizeof(int) * n); } void freeData(int **p) { free(*p); *p = NULL; } // 사용: int *d = allocData(10); freeData(&d);

Valgrind — 메모리 누수 감지 도구

Valgrind는 리눅스에서 메모리 누수를 감지하는 도구입니다. 학교나 회사에서 많이 사용합니다.

연습 문제

1
메모리 누수 정의
쉬움
메모리 누수(memory leak)란 무엇인가요?
① 메모리의 값이 바뀌는 현상
② malloc으로 할당했지만 free 하지 않아 힙 메모리가 줄어드는 현상
③ 배열 범위를 벗어나 접근하는 현상
④ 포인터가 NULL인 현상
힌트 / 정답 보기
정답: ② 메모리 누수는 할당된 메모리가 해제되지 않아 사용 가능한 힙 메모리가 점점 줄어드는 현상입니다.
2
누수 코드 찾기
보통
다음 코드에서 메모리 누수가 발생하는 이유를 설명하세요.
코드int *p = malloc(40);
p = malloc(80); free(p);
힌트 / 정답 보기
첫 번째 malloc(40)의 주소를 p가 기억하고 있었는데 두 번째 malloc(80)으로 p를 덮어쓰면서 첫 번째 40바이트의 주소를 잃어버렸습니다. free(p)는 80바이트만 해제하고 40바이트는 누수됩니다.
3
조기 return 수정
보통
다음 코드의 누수를 수정하세요.
코드int *p = malloc(100);
if (error) return -1; // 누수!
free(p); return 0;
힌트 / 정답 보기
int *p = malloc(100); if (error) { free(p); return -1; } // free 추가! free(p); return 0;
4
Valgrind 출력 해석
쉬움
"definitely lost: 0 bytes" 메시지의 의미는?
① 메모리 할당이 0번 됨
② 누수 없음 (모든 메모리 해제됨)
③ 프로그램이 실패함
④ free를 0번 호출함
힌트 / 정답 보기
정답: ② "definitely lost: 0 bytes"는 메모리 누수가 없다는 뜻입니다. 모든 malloc된 메모리가 free되었습니다.
5
누수 없는 코드 작성
어려움
두 배열 a, b를 malloc으로 할당하고, b 할당 실패 시 a도 해제하는 안전한 코드를 작성하세요.
힌트 / 정답 보기
int *a = (int*)malloc(sizeof(int)*5); if (a == NULL) return 1; int *b = (int*)malloc(sizeof(int)*5); if (b == NULL) { free(a); return 1; } // a도 해제! // 작업... free(b); free(a);
핵심 정리

핵심 정리

  • 메모리 누수 — malloc 후 free 안 하면 힙 메모리 고갈
  • 대표 원인 — free 누락, 조기 return, 포인터 덮어쓰기
  • 예방 — 모든 return 경로에서 free 확인, free 후 NULL 대입
  • Valgrind — 누수 감지 도구 (리눅스)
