쇼핑 카트 — 상품 담기/총액 계산

Product 구조체로 상품을 관리하고, 장바구니에 담긴 상품의 수량과 총액을 계산합니다.

프로젝트 목표

  • Product 구조체(이름/단가/수량)를 정의합니다.
  • 장바구니에 상품을 추가/제거하는 함수를 구현합니다.
  • 상품별 소계와 총액을 계산합니다.
  • 가격 기준으로 상품을 정렬합니다.

구현 코드

#include <stdio.h> #include <string.h> #define MAX 10 typedef struct { char name[30]; int price; // 단가 int qty; // 수량 } Product; int cartSize = 0; Product cart[MAX]; void addItem(const char *name, int price, int qty) { if (cartSize >= MAX) { printf("카트가 가득 찼습니다.\n"); return; } strcpy(cart[cartSize].name, name); cart[cartSize].price = price; cart[cartSize].qty = qty; cartSize++; printf("%s 추가됨 (%d개)\n", name, qty); } int removeItem(const char *name) { for (int i = 0; i < cartSize; i++) { if (strcmp(cart[i].name, name) == 0) { // 마지막 항목으로 덮어쓰기 cart[i] = cart[cartSize - 1]; cartSize--; printf("%s 제거됨\n", name); return 1; } } printf("%s 찾을 수 없음\n", name); return 0; } void printCart() { printf("\n=== 장바구니 ===\n"); printf("%-12s %8s %4s %10s\n", "상품명", "단가", "수량", "소계"); int total = 0; for (int i = 0; i < cartSize; i++) { int sub = cart[i].price * cart[i].qty; total += sub; printf("%-12s %7d원 %4d %9d원\n", cart[i].name, cart[i].price, cart[i].qty, sub); } printf("------------------------\n"); printf("합계: %d원\n", total); } void sortByPrice() { for (int i = 0; i < cartSize - 1; i++) for (int j = 0; j < cartSize - 1 - i; j++) if (cart[j].price > cart[j+1].price) { Product t = cart[j]; cart[j] = cart[j+1]; cart[j+1] = t; } } int main() { addItem("사과", 1500, 3); addItem("우유", 2200, 2); addItem("과자", 800, 5); addItem("음료수", 1200, 4); printCart(); removeItem("우유"); sortByPrice(); printCart(); return 0; }

도전 과제

도전 과제

  • 수량을 변경하는 함수 updateQty(name, newQty)를 구현해보세요.
  • 할인율을 적용해 최종 금액을 계산해보세요. (예: 10% 할인)
  • 가장 비싼 상품과 가장 저렴한 상품을 찾아 출력해보세요.

구조 분석

이번 프로젝트의 핵심은 removeItem 함수에 있습니다. 배열에서 중간 원소를 제거할 때, 뒤의 원소를 앞으로 당기는 대신 마지막 원소로 덮어쓰는 방법을 사용했습니다.

이 방법은 O(1) 시간에 삭제가 가능합니다. 단, 원소의 순서가 바뀝니다. 순서를 유지해야 한다면 뒤의 원소를 한 칸씩 앞으로 당겨야 합니다(O(n)).

핵심 포인트
배열 원소 삭제의 두 가지 방법
방법 1 (순서 유지): 삭제 위치 뒤의 원소를 앞으로 한 칸씩 이동. O(n) 시간 복잡도.
방법 2 (순서 무관): 마지막 원소로 덮어쓰고 size를 줄임. O(1) 시간 복잡도.
이번 프로젝트는 방법 2를 사용했습니다.

확인 문제

문제 1
수량 업데이트
이름을 받아 해당 상품의 수량을 새 값으로 변경하는 함수 updateQty를 작성하세요. 상품이 없으면 "찾을 수 없음"을 출력합니다.
void updateQty(const char *name, int newQty) { for (int i = 0; i < cartSize; i++) { if (strcmp(cart[i].name, name) == 0) { cart[i].qty = newQty; printf("%s 수량: %d → %d\n", name, cart[i].qty, newQty); return; } } printf("찾을 수 없음\n"); }
문제 2
최고가/최저가 상품 찾기
카트에서 단가가 가장 비싼 상품과 가장 저렴한 상품의 이름을 각각 출력하는 함수를 작성하세요.
문제 3
할인 적용
전체 상품에 특정 할인율(%)을 적용한 최종 금액을 계산하는 함수 calcDiscount(float rate)를 작성하세요.
void calcDiscount(float rate) { int total = 0; for (int i = 0; i < cartSize; i++) total += cart[i].price * cart[i].qty; int discounted = (int)(total * (1.0f - rate / 100.0f)); printf("%.0f%% 할인 적용: %d원 → %d원\n", rate, total, discounted); }
