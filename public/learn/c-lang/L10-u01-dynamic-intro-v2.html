동적 메모리란?
스택 vs 힙

프로그램이 실행되는 동안 메모리를 요청하고 반납하는 방법을 배웁니다. 왜 동적 메모리가 필요한지 이해합니다.

이 유닛에서 배우는 것

  • 메모리의 스택과 힙 영역 차이를 설명할 수 있습니다.
  • 정적 메모리와 동적 메모리의 차이를 이해합니다.
  • 동적 메모리가 왜 필요한지 설명할 수 있습니다.
  • malloc과 free의 역할을 알 수 있습니다.
  • 실행 중 크기를 결정하는 프로그램을 이해합니다.

메모리 영역 — 스택 vs 힙

프로그램이 실행될 때 메모리는 여러 영역으로 나뉩니다. 그 중 우리가 집중해서 볼 영역은 스택(Stack)과 힙(Heap)입니다.

스택은 함수 안에서 쓰는 지역변수가 저장되는 곳으로, 함수가 끝나면 자동으로 사라집니다. 힙은 프로그래머가 직접 요청하고 직접 반납하는 곳입니다.

정적 메모리 vs 동적 메모리

정적 메모리는 코드를 작성할 때 크기가 정해집니다. 동적 메모리는 프로그램이 실행되는 중에 크기를 결정합니다.

실습 구역
따라해보세요
1
정적 배열은 크기가 고정됩니다 — 학생 수를 10명으로 고정하면?
int scores[10]; // 반드시 10명, 더 늘릴 수 없음
학생이 11명이면 배열이 부족해서 문제 발생
2
동적 메모리는 실행 중 크기를 결정합니다 — 학생 수를 입력받아 할당하면?
int n; scanf("%d", &n); // 실행 중 학생 수 입력 int *scores = (int*)malloc(n * sizeof(int)); // n명에 맞게 할당
50명이든 1000명이든 딱 맞게 할당됨

왜 동적 메모리가 필요한가?

실제 프로그램에서는 크기를 미리 알 수 없는 상황이 많습니다. 동적 메모리가 필요한 대표적인 상황을 살펴봅니다.

malloc과 free — 기본 개념

malloc은 힙에서 메모리를 빌려오는 함수이고, free는 빌린 메모리를 반납하는 함수입니다.

// 동적 메모리 기본 패턴 #include <stdlib.h> // malloc, free 사용하려면 필요 int *p = (int*)malloc(sizeof(int)); // 정수 1개 크기 할당 *p = 42; printf("%d\n", *p); free(p); // 반드시 반납!
malloc은 <stdlib.h> 헤더에 있습니다. 항상 #include <stdlib.h>를 포함하세요.

스택 vs 힙 — 직접 비교

스택과 힙의 차이를 코드와 그림으로 함께 비교해봅니다.

// 스택 — 크기 고정 int a = 10; // 스택에 4바이트 자동 할당 int arr[5]; // 스택에 20바이트 자동 할당 // 함수 끝나면 자동 해제, 크기 못 바꿈 // 힙 — 크기 자유 int n = 100; int *arr2 = (int*)malloc(n * sizeof(int)); // 힙에 할당 // ... 사용 ... free(arr2); // 직접 반납
힙에서 빌린 메모리는 반드시 free()로 반납해야 합니다. 반납 안 하면 메모리 누수(memory leak)가 발생합니다!
따라해보세요
1
정수 1개를 동적으로 할당하고 값을 저장한 뒤 출력하세요.

값: 77 이 출력됩니다

핵심 정리

핵심 정리

  • 스택: 자동 관리, 크기 고정, 지역변수
  • 힙: 수동 관리, 크기 자유, malloc/free 사용
  • 동적 메모리: 실행 중 크기 결정, 유연한 프로그램 작성
  • malloc은 <stdlib.h> 필요, 사용 후 반드시 free()
