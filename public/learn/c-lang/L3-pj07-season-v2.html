계절 판별기
— switch 실전 활용

월(month)을 입력받아 해당 계절을 출력하는 프로그램을 만들어봅니다.
switch fall-through 패턴으로 코드를 더 간결하게 작성합니다.

봄
3월 · 4월 · 5월
여름
6월 · 7월 · 8월
가을
9월 · 10월 · 11월
겨울
12월 · 1월 · 2월

이 프로젝트에서 배우는 것

  • switch 문의 fall-through(연속 실행) 패턴을 이해하고 활용합니다.
  • 여러 case를 하나의 블록으로 묶는 방법을 익힙니다.
  • if-else와 switch의 차이를 비교하고 언제 무엇을 쓸지 판단합니다.
  • 잘못된 입력(범위 초과)을 default로 처리하는 방법을 배웁니다.
  • 계절별 다른 메시지를 출력하는 실용적 프로그램을 완성합니다.

switch fall-through — 핵심 개념

fall-through란 break 없이 다음 case로 실행이 흘러 내려가는 것입니다. 계절처럼 "3월이든 4월이든 5월이든 봄"일 때 아주 유용합니다.

계절 판별기 — switch 버전 코드

// 계절 판별기 v1 — switch fall-through 활용 #include <stdio.h> int main() { int month; printf("월을 입력하세요 (1~12): "); scanf("%d", &month); switch (month) { case 3: case 4: case 5: // 3, 4, 5월 모두 이 블록으로 fall-through printf("봄입니다.\n"); break; case 6: case 7: case 8: // 6, 7, 8월 printf("여름입니다.\n"); break; case 9: case 10: case 11: // 9, 10, 11월 printf("가을입니다.\n"); break; case 12: case 1: case 2: // 12, 1, 2월 (12월이 위에 오는 점 주의!) printf("겨울입니다.\n"); break; default: // 1~12 범위 외 printf("잘못된 월입니다.\n"); } return 0; }

switch vs if-else — 비교

두 방식 모두 같은 결과를 냅니다. 어떤 것이 더 읽기 쉬울지 비교해봅니다.

switch 버전 (권장)
switch (month) { case 3: case 4: case 5: printf("봄"); break; case 6: case 7: case 8: printf("여름"); break; case 9: case 10: case 11: printf("가을"); break; default: printf("겨울"); }
if-else 버전
if (month >= 3 && month <= 5) { printf("봄"); } else if (month >= 6 && month <= 8) { printf("여름"); } else if (month >= 9 && month <= 11) { printf("가을"); } else { printf("겨울"); }
언제 switch를 쓸까?

같은 변수를 여러 정수 값과 비교할 때 switch가 더 읽기 좋습니다. if-else는 범위(>=, <=) 비교나 복잡한 조건에 유리합니다. 이 프로젝트에서는 switch가 더 깔끔합니다.

계절별 추천 활동 메시지 추가

계절 이름뿐 아니라 추천 활동 메시지도 함께 출력하도록 확장합니다.

switch (month) { case 3: case 4: case 5: printf("봄입니다.\n"); printf("추천 활동: 꽃구경, 소풍\n"); break; case 6: case 7: case 8: printf("여름입니다.\n"); printf("추천 활동: 수영, 바다 여행\n"); break; case 9: case 10: case 11: printf("가을입니다.\n"); printf("추천 활동: 단풍놀이, 독서\n"); break; case 12: case 1: case 2: printf("겨울입니다.\n"); printf("추천 활동: 스키, 따뜻한 음식\n"); break; default: printf("잘못된 월입니다. (1~12 범위만 입력하세요)\n"); }

잘못된 월 처리 — default의 역할

주의: default 없으면 무슨 일이 생길까?

default가 없으면 1~12 범위 밖 값이 들어와도 아무것도 출력하지 않습니다. 사용자는 프로그램이 멈춘 것처럼 느낍니다. 항상 default를 넣어 예외를 처리하세요.

Q
month = 13을 입력하면 어떤 문장이 출력되나요?

입력 13
출력 ?
정답 보기
잘못된 월입니다. (1~12 범위만 입력하세요)

case 1~12 중 어느 것도 13과 일치하지 않으므로 default 블록이 실행됩니다.

전체 완성 코드

// ====================================== // 계절 판별기 — 완성 버전 // 기술: switch fall-through, default 처리 // ====================================== #include <stdio.h> int main() { int month; printf("=== 계절 판별기 ===\n"); printf("월을 입력하세요 (1~12): "); scanf("%d", &month); printf("\n%d월은 ", month); switch (month) { case 3: case 4: case 5: printf("봄입니다.\n"); printf("추천 활동: 꽃구경, 소풍\n"); break; case 6: case 7: case 8: printf("여름입니다.\n"); printf("추천 활동: 수영, 바다 여행\n"); break; case 9: case 10: case 11: printf("가을입니다.\n"); printf("추천 활동: 단풍놀이, 독서\n"); break; case 12: case 1: case 2: printf("겨울입니다.\n"); printf("추천 활동: 스키, 따뜻한 음식\n"); break; default: printf("잘못된 월입니다.\n"); printf("1~12 사이의 숫자를 입력하세요.\n"); } return 0; }

이 프로젝트 핵심 정리

  • fall-through: case 사이에 break 없으면 다음 case로 흘러 내려감
  • case 묶기: 같은 결과를 내는 값들을 case 연속 나열로 처리
  • 12월 순서: 겨울 case는 12→1→2 순서로 — 12가 제일 먼저
  • default: 모든 case에 해당 없으면 실행 — 항상 넣는 습관
  • switch vs if-else: 정수 값 비교는 switch, 범위 비교는 if-else
