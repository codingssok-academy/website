strstr — 하이라이트 검색 엔진
"I love C programming" 문장에서 "C"를 찾으면 어디 있을까?
strstr(haystack, needle)은 큰 문자열(건초더미)에서 작은 문자열(바늘)을 찾아 해당 위치의 포인터를 반환한다.
NULL이 아니면 발견, NULL이면 없음 — 간단하면서 강력한 검색 함수다.

학습 목표

strstr() 반환값(포인터)을 활용한 검색
포인터 뺄셈으로 검색 위치(인덱스) 계산
반복 검색으로 모든 위치 찾기 (strstr 연속 호출)

strstr Search Engine
strstr 동작 원리
반환값: 포인터(주소)

strstr은 찾은 위치의 주소(포인터)를 반환한다. 찾지 못하면 NULL. 포인터에서 원본 배열 시작 주소를 빼면 인덱스를 알 수 있다.

#include <stdio.h> #include <string.h> int main() { char text[] = "I love C programming and C is great"; char keyword[50]; printf("검색어: "); scanf("%s", keyword); char *found = strstr(text, keyword); if (found != NULL) { int pos = found - text; // 인덱스 계산 printf("\"%s\" 발견! 위치: %d번째\n", keyword, pos); } else { printf("\"%s\"를 찾을 수 없음\n", keyword); } return 0; }
포인터 뺄셈: found - text = 두 주소의 차이 = 인덱스 위치. found는 text 배열 내부를 가리키는 포인터이므로 이 뺄셈이 가능하다.
모든 위치 찾기 (반복 검색)
// "C"가 문장에서 나타나는 모든 위치 찾기 char *ptr = text; // 검색 시작 위치 int count = 0; while ((ptr = strstr(ptr, keyword)) != NULL) { printf("위치 %d에서 발견\n", (int)(ptr - text)); ptr++; // 다음 문자부터 다시 검색 count++; } printf("총 %d회 발견\n", count);
응용 — 단어 교체(Replace)
검색 후 교체 패턴

strstr로 위치를 찾고, 그 자리에 새 단어를 삽입하는 "문자열 교체" 기능을 구현한다. 버퍼 조작이 필요하다.

void str_replace(char result[], char src[], char find[], char rep[]) { char *pos = strstr(src, find); if (pos == NULL) { strcpy(result, src); // 못 찾으면 원본 복사 return; } int prefix_len = pos - src; // find 앞부분 길이 strncpy(result, src, prefix_len); // 앞부분 복사 result[prefix_len] = '\0'; strcat(result, rep); // 새 단어 붙이기 strcat(result, pos + strlen(find)); // 나머지 붙이기 } int main() { char src[] = "I love cat"; char result[200]; str_replace(result, src, "cat", "dog"); printf("%s\n", result); // "I love dog" return 0; }
strchr vs strstr 비교
strchr(s, c): 문자 c 하나를 검색. 반환: 해당 문자가 있는 포인터
strstr(s, t): 문자열 t 전체를 검색. 반환: 해당 부분문자열 시작 포인터
예: strchr("hello", 'l') → &s[2] / strstr("hello world", "world") → &s[6]
연습 문제
Q1. 결과 예측

strstr("programming", "gram")의 반환값은 NULL인가, 아닌가? 인덱스는 몇 번인가?

정답 보기
NULL 아님 (찾음). "programming"에서 "gram"은 인덱스 3부터 시작. 반환값 - "programming"의 주소 = 3.
Q2. 코드 분석

아래 코드에서 ptr++를 하지 않으면 어떤 문제가 발생하는가?

while ((ptr = strstr(ptr, "C")) != NULL) { printf("%d\n", (int)(ptr - text)); // ptr++; 없으면? }
정답 보기
ptr이 이동하지 않으므로 strstr이 항상 같은 위치를 반환 → 무한 루프 발생.
Q3. 구현

문장에서 특정 단어가 몇 번 등장하는지 세는 count_word() 함수를 작성하시오.

정답 보기
int count_word(char text[], char word[]) { char *p=text; int cnt=0; while((p=strstr(p,word))!=NULL){cnt++;p+=strlen(word);} return cnt; }

정답 보기
