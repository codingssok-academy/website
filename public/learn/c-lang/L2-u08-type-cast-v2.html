Chapter 08

형변환: 자동 vs 강제

서로 다른 자료형 사이의 변환 규칙, 데이터 손실, 캐스팅 문법을 배웁니다.

이 유닛에서 배우는 것

  • 자동 형변환(묵시적 변환)이 언제 일어나는지 안다.
  • 큰 자료형에서 작은 자료형으로 변환할 때 데이터 손실을 이해한다.
  • (int)3.14처럼 강제 형변환(캐스팅)을 사용할 수 있다.
  • 정수 나눗셈의 함정(5/2=2)과 해결 방법을 안다.
  • 자료형 승격 규칙(char->int->float->double)을 설명할 수 있다.

자동 형변환(묵시적 변환)

서로 다른 자료형을 섞어서 사용하면, C 컴파일러가 자동으로 작은 자료형을 큰 자료형으로 변환합니다. 이것을 자동 형변환 또는 묵시적 변환이라고 합니다.

#include <stdio.h> int main(void) { int a = 10; double b = 3.5; double result = a + b; // a가 자동으로 10.0으로 변환 printf("결과: %f\n", result); // 13.500000 return 0; }

int 10과 double 3.5를 더하면, int가 자동으로 double(10.0)로 변환된 뒤 계산됩니다. 결과도 double입니다.

데이터 손실: 큰 것을 작은 곳에 넣으면

반대로, 큰 자료형의 값을 작은 자료형 변수에 넣으면 데이터가 잘립니다. 이것을 데이터 손실이라고 합니다.

#include <stdio.h> int main(void) { double pi = 3.14159; int n = pi; // 소수점 아래 버려짐! n = 3 printf("pi = %f\n", pi); // 3.141590 printf("n = %d\n", n); // 3 return 0; }
따라해보세요
1
int 변수에 double 값 9.99를 넣고 출력해서 손실을 확인해 보세요.
int x = 9.99; printf("x = %d\n", x);
x = 9 (소수점 아래 .99가 사라짐)
2
int 5와 double 2.0을 더한 결과를 출력해 보세요.
int a = 5; double b = 2.0; printf("결과: %f\n", a + b);
결과: 7.000000 (int가 자동으로 double로 변환)
3
char에 300을 넣어보세요. 어떤 일이 생기나요?
char ch = 300; // char 범위: -128~127 printf("ch = %d\n", ch);
오버플로우 발생! 예상과 다른 값이 나온다

강제 형변환 (캐스팅)

프로그래머가 직접 자료형을 변환하는 것을 강제 형변환 또는 캐스팅(casting)이라고 합니다. 변수 앞에 (자료형)을 붙입니다.

#include <stdio.h> int main(void) { double score = 95.7; int rounded = (int)score; // 강제로 int로 변환 printf("원래: %f\n", score); // 95.700000 printf("변환: %d\n", rounded); // 95 return 0; }

정수 나눗셈의 함정

정수끼리 나누면 결과도 정수입니다. 5 / 2는 2.5가 아니라 2입니다! 이것은 초보자가 가장 많이 실수하는 부분입니다.

해결 방법은 둘 중 하나를 실수로 만드는 것입니다. 5.0 / 2, (double)5 / 2, 5 / 2.0 모두 2.5가 됩니다.

승격 규칙

서로 다른 자료형이 만나면, 항상 더 큰 자료형 쪽으로 변환됩니다. 이 순서를 승격(promotion) 규칙이라고 합니다.

따라해보세요
1
7 / 2와 7.0 / 2의 결과를 비교해 보세요.
printf("7/2 = %d\n", 7 / 2); printf("7.0/2 = %f\n", 7.0 / 2);
7/2 = 3, 7.0/2 = 3.500000
2
(double)7 / 2의 결과를 출력해 보세요.
printf("결과: %f\n", (double)7 / 2);
결과: 3.500000
3
(int)8.9의 결과를 출력해 보세요.
printf("결과: %d\n", (int)8.9);
결과: 8 (반올림이 아니라 버림!)

실전: 평균 계산 시 형변환

시험 3과목의 점수 합계를 과목 수로 나눠 평균을 구합니다. 정수끼리 나누면 소수점이 사라지므로, 형변환이 필수입니다.

#include <stdio.h> int main(void) { int kor = 85, math = 92, eng = 78; int total = kor + math + eng; // 잘못된 방법: 정수 / 정수 = 정수 int wrong = total / 3; printf("잘못된 평균: %d\n", wrong); // 85 // 올바른 방법: 형변환 사용 double avg = (double)total / 3; printf("올바른 평균: %.2f\n", avg); // 85.00 return 0; }

실전: BMI 계산

BMI(체질량지수) = 몸무게(kg) / (키(m) x 키(m)). 키를 cm로 입력받아 m로 변환하는 과정에서 형변환이 필요합니다.

#include <stdio.h> int main(void) { int weight = 55; // kg int height_cm = 165; // cm // cm를 m로 변환: 165 / 100 = 1 (정수 나눗셈!) // 올바른 방법: 형변환 사용 double height_m = (double)height_cm / 100; double bmi = (double)weight / (height_m * height_m); printf("키: %d cm (%.2f m)\n", height_cm, height_m); printf("BMI: %.1f\n", bmi); return 0; }
따라해보세요
1
국어 90, 수학 87, 영어 93의 평균을 소수점 1자리까지 출력해 보세요.
int sum = 90 + 87 + 93; double avg = (double)sum / 3; printf("평균: %.1f\n", avg);
평균: 90.0

핵심 요약

  • 자동 형변환: 작은 자료형이 큰 자료형으로 자동 변환된다 (int + double = double).
  • 데이터 손실: double을 int에 넣으면 소수점 아래가 사라진다.
  • 강제 형변환: (int)3.14처럼 괄호 안에 자료형을 써서 직접 변환한다.
  • 정수 나눗셈 함정: 5/2=2이다. 5.0/2 또는 (double)5/2로 해결한다.
  • 승격 규칙: char -> int -> float -> double 순서로 큰 쪽으로 승격된다.
