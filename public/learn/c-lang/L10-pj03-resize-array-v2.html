realloc으로
배열 크기 조절

처음에 작은 배열을 할당하고, 필요할 때마다 realloc으로 크기를 늘리는 동적 확장 배열을 구현합니다.

이 프로젝트에서 만드는 것

  • 처음에 작은 크기(3)로 malloc 합니다.
  • 배열이 꽉 차면 realloc으로 2배 확장합니다.
  • 기존 데이터가 보존됨을 확인합니다.
  • realloc 실패 시 원본을 안전하게 해제합니다.
  • 최종 배열 내용을 출력합니다.

동적 확장 배열 설계

STEP 1
초기 malloc
capacity=3으로 시작. count(실제 개수)와 capacity(최대 크기)를 별도 관리합니다.
STEP 2
꽉 찼을 때 realloc
count == capacity 가 되면 capacity를 2배로 늘려 realloc합니다.
STEP 3
데이터 추가
arr[count++] = value 로 추가합니다.
#include <stdio.h> #include <stdlib.h> int main() { int capacity = 3, count = 0; int *arr = (int*)malloc(sizeof(int) * capacity); if (!arr) return 1; printf("숫자를 입력하세요 (0: 종료):\n"); int val; while (scanf("%d", &val) == 1 && val != 0) { if (count == capacity) { capacity *= 2; int *tmp = (int*)realloc(arr, sizeof(int) * capacity); if (!tmp) { free(arr); return 1; } arr = tmp; printf("배열 확장: %d칸\n", capacity); } arr[count++] = val; } printf("저장된 %d개:\n", count); for (int i=0; i<count; i++) printf("%d ", arr[i]); printf("\n용량 사용: %d/%d\n", count, capacity); free(arr); arr=NULL; return 0; }

실행 결과 및 동작 분석

숫자를 입력하세요 (0: 종료): 10 20 30 40 50 60 70 0 배열 확장: 6칸 배열 확장: 12칸 저장된 7개: 10 20 30 40 50 60 70 용량 사용: 7/12

도전 과제

1. 배열이 비어있을 때 realloc으로 크기를 줄이는(shrink) 기능을 추가하세요.
2. 중복된 숫자가 있으면 추가하지 않는 기능을 만들어보세요.
3. 입력받은 숫자들을 정렬하여 출력해보세요.
