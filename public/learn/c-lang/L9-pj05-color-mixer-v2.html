RGB 색상 혼합기

RGB 구조체로 색상을 표현하고, 두 색상을 혼합하거나 밝기를 조정하는 함수를 구현합니다. 16진수 변환도 연습합니다.

프로젝트 목표

  • RGB 구조체(r, g, b: unsigned char)를 정의합니다.
  • 두 색상을 혼합(평균값)하는 함수를 구현합니다.
  • 밝기를 조정(배율 곱)하는 함수를 구현합니다.
  • RGB를 16진수 문자열(#RRGGBB)로 변환합니다.

구현 코드

#include <stdio.h> typedef struct { unsigned char r, g, b; } Color; Color mix(Color a, Color b) { Color result; result.r = (a.r + b.r) / 2; result.g = (a.g + b.g) / 2; result.b = (a.b + b.b) / 2; return result; } Color brighten(Color c, float factor) { Color result; int r = (int)(c.r * factor); int g = (int)(c.g * factor); int bv= (int)(c.b * factor); result.r = (r > 255) ? 255 : (unsigned char)r; result.g = (g > 255) ? 255 : (unsigned char)g; result.b = (bv> 255) ? 255 : (unsigned char)bv; return result; } void printColor(Color c, const char *label) { printf("%s: rgb(%3d,%3d,%3d) = #%02X%02X%02X\n", label, c.r, c.g, c.b, c.r, c.g, c.b); } int main() { Color red = {255, 0, 0}; Color green = {0, 255, 0}; Color blue = {0, 0, 255}; printColor(red, "빨강"); printColor(green, "초록"); printColor(mix(red, green), "혼합"); printColor(brighten(blue, 1.5f), "밝은파랑"); return 0; }
실행 결과
실행 결과
빨강: rgb(255, 0, 0) = #FF0000 초록: rgb( 0,255, 0) = #00FF00 혼합: rgb(127,127, 0) = #7F7F00 밝은파랑: rgb( 0, 0,255) = #0000FF
도전 과제

도전 과제

  • 세 가지 색상을 혼합하는 함수를 만들어보세요.
  • 색상을 반전(255-r, 255-g, 255-b)하는 함수를 구현해보세요.
  • 그레이스케일 변환: (r+g+b)/3 을 r, g, b에 모두 적용해보세요.

확인 문제

문제 1
색상 비교 함수
두 색상이 같은지 비교하는 함수 colorEqual을 작성하세요. (r, g, b 모두 같아야 true)
int colorEqual(Color a, Color b) { return a.r==b.r && a.g==b.g && a.b==b.b; }
문제 2
밝기 계산
색상의 밝기(luminance)를 계산하는 함수를 작성하세요. 공식: 0.299*r + 0.587*g + 0.114*b
문제 3
팔레트 배열
Color 배열 5개로 팔레트를 만들고, 가장 밝은 색을 찾아 출력하세요.
