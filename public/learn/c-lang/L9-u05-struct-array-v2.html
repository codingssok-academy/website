구조체 배열 — 여러 데이터 한꺼번에 관리

구조체 배열을 사용하면 같은 형식의 데이터 여러 개를 깔끔하게 관리할 수 있습니다. for 반복문과 함께 쓰는 방법을 익혀봅시다.

이 유닛에서 배우는 것

  • 구조체 배열을 선언하고 초기화할 수 있습니다.
  • 인덱스로 배열 원소의 멤버에 접근할 수 있습니다.
  • for 반복문으로 구조체 배열을 순회할 수 있습니다.
  • 구조체 배열에서 최댓값/최솟값을 찾을 수 있습니다.
  • 간단한 정렬(버블 정렬)을 구조체 배열에 적용할 수 있습니다.

구조체 배열 선언과 초기화

구조체 배열은 Student arr[5];처럼 선언합니다. 각 원소는 구조체 하나이며, arr[0].name 형식으로 멤버에 접근합니다.

typedef struct { char name[20]; int age; float score; } Student; // 구조체 배열 선언 + 초기화 Student arr[3] = { {"김민준", 15, 88.5f}, {"이서연", 16, 92.0f}, {"박지호", 14, 76.5f} }; // 개별 원소 멤버 접근: arr[인덱스].멤버 printf("%s: %.1f\n", arr[0].name, arr[0].score);

for 반복문으로 구조체 배열 순회

for 반복문으로 배열의 모든 원소를 순회하면서 멤버를 처리할 수 있습니다.

#include <stdio.h> #define N 3 int main() { Student arr[N] = { {"김민준", 15, 88.5f}, {"이서연", 16, 92.0f}, {"박지호", 14, 76.5f} }; // 전체 출력 for (int i = 0; i < N; i++) { printf("%d. %s — %.1f점\n", i+1, arr[i].name, arr[i].score); } // 합계와 평균 float sum = 0; for (int i = 0; i < N; i++) sum += arr[i].score; printf("평균: %.1f\n", sum / N); // 최고 점수 학생 찾기 int best = 0; for (int i = 1; i < N; i++) { if (arr[i].score > arr[best].score) best = i; } printf("최고: %s\n", arr[best].name); return 0; }

구조체 배열 — 버블 정렬

구조체 배열을 특정 멤버 기준으로 정렬할 수 있습니다. 구조체끼리 =으로 교환(swap)합니다.

// 점수 내림차순 버블 정렬 for (int i = 0; i < N-1; i++) { for (int j = 0; j < N-1-i; j++) { if (arr[j].score < arr[j+1].score) { Student tmp = arr[j]; // 구조체 통째로 swap arr[j] = arr[j+1]; arr[j+1] = tmp; } } } printf("-- 점수 순위 --\n"); for (int i = 0; i < N; i++) { printf("%d위: %s (%.1f)\n", i+1, arr[i].name, arr[i].score); }
핵심 정리

핵심 정리

  • 구조체 배열: Student arr[N]; — N개의 Student가 연속 배치
  • 멤버 접근: arr[i].멤버
  • for 반복문으로 전체 순회, 합계/평균/최솟값/최댓값 계산 가능
  • 구조체끼리 =으로 통째로 swap 가능
