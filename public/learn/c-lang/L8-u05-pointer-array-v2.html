Chapter 8 — Unit 05

배열 이름은 포인터
arr == &arr[0]

배열 이름이 사실은 첫 원소의 주소라는 사실을 배웁니다. 포인터와 배열의 깊은 연결을 이해합니다.

이 유닛에서 배우는 것

  • 배열 이름이 첫 원소의 주소임을 이해합니다.
  • arr == &arr[0]가 왜 참인지 설명합니다.
  • 포인터로 배열 원소에 접근합니다.
  • 배열을 함수에 포인터로 전달합니다.
  • 배열과 포인터의 차이점(대입 불가 등)을 압니다.

배열 이름 = 첫 원소의 주소

C언어에서 배열 이름은 특별합니다. arr라고 쓰면 자동으로 첫 번째 원소 arr[0]의 주소가 됩니다. 배열 전체를 가리키는 상수 포인터라고 볼 수 있습니다.

int arr[4] = {10, 20, 30, 40}; printf("%p\n", arr); // 0x1000 (배열명 = 첫 원소 주소) printf("%p\n", &arr[0]); // 0x1000 (첫 원소 주소 직접) printf("%d\n", arr == &arr[0]); // 1 (같다!)

포인터로 배열 원소 접근

포인터 변수에 배열 이름을 대입하면 포인터로 배열 원소에 접근할 수 있습니다.

int arr[4] = {10, 20, 30, 40}; int *p = arr; // p = &arr[0] printf("%d\n", *p); // 10 (arr[0]) printf("%d\n", *(p+1)); // 20 (arr[1]) printf("%d\n", *(p+2)); // 30 (arr[2]) printf("%d\n", p[3]); // 40 (arr[3] — 인덱스 표기 가능)

배열과 포인터 접근 방법 비교

// 네 가지 표기 — 모두 같은 원소! int arr[3] = {1, 2, 3}; int *p = arr; arr[1] // 인덱스 (배열) *(arr+1) // 포인터 연산 (배열명) p[1] // 인덱스 (포인터 변수) *(p+1) // 포인터 연산 (포인터 변수) // 네 개 모두 2를 반환

배열을 함수에 전달하기

배열을 함수에 넘기면 배열의 첫 주소(포인터)가 전달됩니다. 함수 안에서 원본 배열을 수정할 수 있습니다.

void print_arr(int *p, int n) { // int p[] 도 동일 for (int i = 0; i < n; i++) { printf("%d ", p[i]); } printf("\n"); } int main() { int arr[5] = {1, 2, 3, 4, 5}; print_arr(arr, 5); // arr = 첫 원소 주소 전달 return 0; }

주의: 배열 이름(arr)은 상수 포인터입니다. arr = p;처럼 대입은 불가능합니다. 포인터 변수 p는 재대입 가능합니다.

배열 수정 함수 예제

#include <stdio.h> // 배열 모든 원소를 2배로 void double_all(int *p, int n) { for (int i = 0; i < n; i++) { p[i] = p[i] * 2; // 원본 수정 } } // 배열 합계 int sum_arr(int *p, int n) { int s = 0; for (int i = 0; i < n; i++) s += p[i]; return s; } int main() { int arr[4] = {1, 2, 3, 4}; double_all(arr, 4); // arr = {2, 4, 6, 8} printf("합=%d\n", sum_arr(arr, 4)); // 20 return 0; }

핵심 정리

핵심 정리

  • 배열 이름 arr는 첫 원소 arr[0]의 주소 (상수 포인터)
  • arr == &arr[0] 은 항상 참
  • arr[i] == *(arr+i) == *(p+i) == p[i] (모두 동일)
  • 배열을 함수에 전달 시 포인터(주소)가 전달됨 → 원본 수정 가능
  • 배열 이름은 상수 — 대입(arr = p) 불가
