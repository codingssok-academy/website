지역 변수와 전역 변수 — 스코프의 세계

변수가 살 수 있는 범위(스코프)를 배웁니다. 함수 안에서만 사는 지역 변수와 모든 곳에서 접근 가능한 전역 변수의 차이를 이해합니다.

이 유닛에서 배우는 것

  • 스코프(범위)가 무엇인지 설명할 수 있습니다.
  • 지역 변수의 특징과 생존 범위를 이해합니다.
  • 전역 변수를 선언하고 어디서든 사용할 수 있음을 압니다.
  • 전역 변수를 남용하면 안 되는 이유를 설명합니다.
  • 같은 이름의 지역/전역 변수가 있을 때 어떻게 되는지 압니다.

스코프 (Scope) — 변수의 생존 범위

스코프(Scope)란 변수를 사용할 수 있는 범위입니다. 중괄호 { } 안에서 선언된 변수는 그 중괄호 안에서만 살 수 있습니다.

지역 변수는 선언된 블록이 끝나면 사라집니다. 전역 변수는 함수 밖, 파일 맨 위에 선언되어 어느 함수에서든 사용할 수 있습니다.

지역 변수와 전역 변수 코드 비교

#include <stdio.h> int count = 0; // 전역 변수: 어디서든 접근 가능 void addOne() { count++; // 전역 변수 count 접근 OK int temp = 10; // 지역 변수: addOne 안에서만 } int main() { addOne(); addOne(); printf("count: %d\n", count); // 2 // printf("%d", temp); // 오류! temp는 addOne 안에만 있음 return 0; }

같은 이름: 지역 vs 전역

전역 변수와 지역 변수의 이름이 같으면, 함수 안에서는 지역 변수가 우선입니다. 이것을 "변수 가리기(shadowing)"라고 합니다.

int x = 100; // 전역 x void test() { int x = 5; // 지역 x — 전역 x를 가림 printf("%d\n", x); // 5 (지역 x 사용) } int main() { test(); printf("%d\n", x); // 100 (전역 x 사용) return 0; }

보통

핵심 정리

핵심 요약

  • 스코프: 변수가 유효한 범위. 중괄호 안에서 선언된 변수는 그 안에서만 사용 가능.
  • 지역 변수: 함수/블록 안에 선언, 블록이 끝나면 사라짐.
  • 전역 변수: 함수 밖 파일 상단에 선언, 모든 함수에서 사용 가능.
  • 이름이 같아도 지역/전역은 서로 다른 변수. 지역이 전역을 가림(shadowing).
  • 전역 변수는 필요할 때만 최소로 사용. 남용하면 버그 추적이 어려워짐.
