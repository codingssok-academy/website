숫자 맞추기 게임

while 반복문과 if/else 조건문을 결합해 "더 크게" / "더 작게" 힌트를 주는 업다운 게임을 만들어봅니다.

이 프로젝트에서 배우는 것

  • while 반복문과 if/else를 결합해 게임 루프를 만들 수 있습니다.
  • 입력값을 정답과 비교해 "더 크게" / "더 작게" 힌트를 줄 수 있습니다.
  • 시도 횟수를 카운트하는 변수를 관리할 수 있습니다.
  • rand()로 랜덤 정답을 만드는 방법을 익힙니다.
  • break로 특정 조건에서 반복을 즉시 종료할 수 있습니다.

숫자 맞추기 게임 — 기본 구현

정답을 42로 고정해두고, 사용자가 맞출 때까지 힌트를 주며 반복 입력받는 프로그램입니다.

// 숫자 맞추기 게임 — 기본 버전 (정답 고정: 42) #include <stdio.h> int main() { int answer = 42; // 고정 정답 int guess; int count = 0; // 시도 횟수 printf("1~100 사이의 숫자를 맞춰보세요!\n"); while (1) { // 무한 반복 (break로 탈출) printf("추측: "); scanf("%d", &guess); count++; if (guess == answer) { printf("정답! %d번 만에 맞혔습니다.\n", count); break; // 반복 탈출 } else if (guess < answer) { printf("더 크게!\n"); } else { printf("더 작게!\n"); } } return 0; }

확장 1 — rand()로 랜덤 정답 & 시도 제한

rand()를 사용하면 매번 다른 정답으로 게임을 즐길 수 있습니다. 시도 횟수를 10번으로 제한하면 긴장감이 올라갑니다.

// 확장 버전: 랜덤 정답 + 10번 시도 제한 #include <stdio.h> #include <stdlib.h> // rand(), srand() #include <time.h> // time() int main() { srand(time(NULL)); // 랜덤 시드 설정 (매 실행마다 다른 숫자) int answer = rand() % 100 + 1; // 1~100 랜덤 int guess, count = 0; int maxTry = 10; printf("1~100 숫자를 %d번 안에 맞춰보세요!\n", maxTry); while (count < maxTry) { printf("[%d/%d] 추측: ", count + 1, maxTry); scanf("%d", &guess); count++; if (guess == answer) { printf("정답! %d번 만에 맞혔습니다!\n", count); return 0; } int diff = answer - guess; if (diff < 0) diff = -diff; // 절댓값 계산 if (guess < answer) { if (diff <= 5) printf("매우 가까워요! 더 크게!\n"); else printf("더 크게!\n"); } else { if (diff <= 5) printf("매우 가까워요! 더 작게!\n"); else printf("더 작게!\n"); } } printf("실패! 정답은 %d였습니다.\n", answer); return 0; }

핵심 정리

숫자 맞추기 게임 핵심 요약

  • while(1) + break — 무한 반복하다가 정답이면 탈출합니다.
  • count++ — 시도할 때마다 카운터를 1 증가시킵니다.
  • rand() % 100 + 1 — 1~100 범위의 랜덤 정수를 얻습니다.
  • srand(time(NULL)) — 매 실행마다 다른 랜덤 시드를 설정합니다.
  • 차이(diff)의 절댓값으로 "매우 가까움" 힌트를 줄 수 있습니다.
