strcmp — 문자열 비교
0이면 같다!

두 문자열이 같은지 비교하는 strcmp, 사전순 비교 원리, strcasecmp까지 배웁니다.

이 유닛에서 배우는 것

  • == 연산자로 문자열을 비교할 수 없는 이유를 설명합니다.
  • strcmp의 반환값(0, 양수, 음수)의 의미를 알 수 있습니다.
  • strcmp로 두 문자열의 같음을 확인할 수 있습니다.
  • 사전순 비교 원리(ASCII 값 차이)를 이해합니다.
  • strcmp를 활용해 로그인 로직을 구현할 수 있습니다.

== 연산자로 문자열 비교 불가!

정수나 실수는 ==로 비교할 수 있지만, 문자열(char 배열)은 절대 ==로 비교하면 안 됩니다. 배열 이름은 주소이기 때문에 주소끼리 비교됩니다.

strcmp 반환값 이해

strcmp(s1, s2)는 두 문자열을 처음부터 비교해 첫 번째로 다른 문자의 ASCII 차이를 반환합니다.

#include <stdio.h> #include <string.h> int main() { printf("%d\n", strcmp("abc", "abc")); // 0 (같음) printf("%d\n", strcmp("abc", "abd")); // 음수 (c < d) printf("%d\n", strcmp("abd", "abc")); // 양수 (d > c) // 실용적 사용: 같은지만 확인 char pw[] = "1234"; char input[20]; scanf("%s", input); if (strcmp(input, pw) == 0) printf("로그인 성공!\n"); else printf("비밀번호 틀림\n"); return 0; }

사전순 비교 원리

strcmp는 문자의 ASCII 값을 비교합니다. 'A'=65, 'B'=66, 'a'=97, 'b'=98 순서로 배열됩니다.

#include <stdio.h> #include <string.h> int main() { char words[4][10] = {"banana", "apple", "cherry", "date"}; char temp[10]; // 버블 정렬 (사전순) for (int i = 0; i < 3; i++) { for (int j = 0; j < 3 - i; j++) { if (strcmp(words[j], words[j+1]) > 0) { strcpy(temp, words[j]); strcpy(words[j], words[j+1]); strcpy(words[j+1], temp); } } } for (int i = 0; i < 4; i++) printf("%s\n", words[i]); return 0; }

핵심 정리

핵심 요약

  • 문자열 비교는 == 금지 — strcmp를 사용해야 합니다.
  • strcmp 반환값: 0=같음, 음수=s1이 앞, 양수=s1이 뒤.
  • 사전순 비교는 ASCII 값 차이를 기준으로 합니다.
  • strcmp(a,b)==0 패턴을 로그인, 메뉴 선택에 활용합니다.
  • strncmp(s1,s2,n)으로 앞 n글자만 비교할 수 있습니다.

전체 예제 — 퀴즈 정답 확인

#include <stdio.h> #include <string.h> int main() { char answers[3][20] = {"apple", "banana", "cherry"}; char questions[3][50] = { "사과를 영어로?", "바나나를 영어로?", "체리를 영어로?" }; int score = 0; for (int i = 0; i < 3; i++) { char input[20]; printf("Q%d: %s ", i+1, questions[i]); scanf("%s", input); if (strcmp(input, answers[i]) == 0) { printf("정답!\n"); score++; } else { printf("오답! 정답: %s\n", answers[i]); } } printf("\n점수: %d/3\n", score); return 0; }
