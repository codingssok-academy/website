환율 계산기

원화 금액을 입력받아 달러, 엔, 유로로 변환하는 프로그램을 만듭니다. double 자료형과 printf %.2f 서식을 연습합니다.

이 프로젝트에서 배우는 것

  • double 변수에 실수를 저장할 수 있다
  • 나눗셈으로 단위 변환(원화 -> 외화)을 할 수 있다
  • printf("%.2f")로 소수점 2자리까지 출력할 수 있다
  • 여러 가지 환율을 한 번에 계산할 수 있다
  • 상수를 사용하는 이유를 이해한다

환율 변환 프로그램

환율 변환은 간단합니다. 원화 금액을 환율로 나누면 외화 금액이 나옵니다. 예를 들어 10,000원을 달러로 바꾸려면 10000 / 1350.0 = 7.41달러입니다.

#include <stdio.h> int main(void) { double krw; // 원화 금액 double usd, jpy, eur; // 외화 결과 // 환율 상수 double rate_usd = 1350.0; // 1달러 = 1350원 double rate_jpy = 13.37; // 1엔 = 13.37원 double rate_eur = 1460.0; // 1유로 = 1460원 printf("원화 금액을 입력하세요: "); scanf("%lf", &krw); usd = krw / rate_usd; jpy = krw / rate_jpy; eur = krw / rate_eur; printf("=== 환율 변환 결과 ===\n"); printf("달러: $%.2f\n", usd); printf("엔화: %.1f엔\n", jpy); printf("유로: %.2f유로\n", eur); return 0; }

핵심 요약

  • 환율 변환: 외화 = 원화 / 환율
  • double은 정밀한 실수를 저장하는 자료형이다
  • printf("%.2f")는 소수점 2자리까지 출력한다 (돈 계산에 적합)
  • 환율을 변수에 저장하면 나중에 환율이 바뀌어도 한 곳만 수정하면 된다
  • scanf("%lf")로 double 값을 입력받는다
