팩토리얼 계산기

n! = 1 × 2 × 3 × ... × n. for문으로 누적 곱셈을 구현하고, 오버플로우와 조합(nCr)까지 다룹니다.

이 프로젝트에서 배우는 것

  • 누적 곱셈(result *= i) 패턴을 이해하고 구현합니다.
  • 팩토리얼 값이 얼마나 빠르게 커지는지 체감합니다.
  • int 오버플로우를 감지하고 long long으로 대응합니다.
  • 팩토리얼을 이용한 조합(nCr) 계산을 구현합니다.
  • 재귀 함수를 활용한 팩토리얼 계산 방식을 미리 봅니다.

팩토리얼(!) 이란?

팩토리얼은 1부터 n까지 모든 정수를 곱한 값입니다. n! = 1 × 2 × 3 × ... × n이며, 특별히 0! = 1로 정의합니다.

기본 팩토리얼 코드

#include <stdio.h> int main() { int n; long long result = 1; // long long: 최대 약 922경 int i; printf("n 입력 (0~20): "); scanf("%d", &n); if (n < 0) { printf("팩토리얼은 음수 불가\n"); return 1; } printf("%d! 계산 과정:\n", n); printf("result = 1"); for (i = 1; i <= n; i++) { result *= i; // 누적 곱셈 printf(" x %d = %lld", i, result); } printf("\n%d! = %lld\n", n, result); return 0; }

오버플로우 감지

int 타입은 약 21억(2,147,483,647)까지만 저장할 수 있습니다. 13! = 6,227,020,800으로 이 범위를 초과합니다. 곱하기 전에 미리 검사해야 합니다.

// 오버플로우 감지 — long long 한계(20!) 체크 #include <stdio.h> #define LLONG_MAX 9223372036854775807LL int main() { int n; printf("n 입력: "); scanf("%d", &n); if (n > 20) { printf("경고: 20! 초과 — long long 범위 넘음\n"); return 1; } long long result = 1; for (int i = 1; i <= n; i++) result *= i; printf("%d! = %lld\n", n, result); return 0; }

조합(nCr) 계산

조합은 n개 중 r개를 순서 없이 고르는 경우의 수입니다. 공식: nCr = n! / (r! * (n-r)!). 팩토리얼 함수를 재사용합니다.

long long factorial(int n) { long long result = 1; for (int i = 1; i <= n; i++) result *= i; return result; } int main() { int n, r; printf("n r 입력: "); scanf("%d %d", &n, &r); if (r > n) { printf("r은 n보다 클 수 없습니다\n"); return 1; } long long result = factorial(n) / (factorial(r) * factorial(n - r)); printf("%dC%d = %lld\n", n, r, result); return 0; }

재귀(Recursion) 미리보기

재귀란 함수가 자기 자신을 호출하는 기법입니다. 팩토리얼은 n! = n × (n-1)!이므로 재귀로 우아하게 표현할 수 있습니다.

// 재귀 팩토리얼 — for 없이 함수 호출만으로 long long factorial(int n) { if (n <= 1) return 1; // 기저 조건 (Base Case) return n * factorial(n - 1); // 재귀 호출 } /* for문 버전과 결과 동일 n=5: factorial(5) = 5 × factorial(4) = 5 × 4 × factorial(3) = 5 × 4 × 3 × 2 × 1 = 120 */

long long r = 1; for (int i = n; i >= 1; i -= 2) r *= i;

힌트 / 정답 보기
매번 factorial 함수를 호출하면 낭비입니다. fac *= i;로 이전 값을 누적 유지하면 O(n)에 해결됩니다.
long long fac = 1, sum = 0; for (int i = 1; i <= n; i++) { fac *= i; sum += fac; }

핵심 정리

  • 팩토리얼: result = 1에서 시작, result *= i로 누적 곱셈
  • int 한계 = 12!, long long 한계 = 20! — 큰 수는 long long 사용
  • 조합 nCr = n! / (r! × (n-r)!) — 팩토리얼 함수 재사용
  • 재귀 버전: n <= 1이면 1 반환, 아니면 n × factorial(n-1)
  • 기저 조건(Base Case) 없으면 무한 재귀 → 스택 오버플로우
