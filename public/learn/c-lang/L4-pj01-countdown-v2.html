카운트다운 타이머

while 반복문으로 숫자를 세면서 "발사!"까지 출력하는 카운트다운 프로그램을 만들어봅니다.

이 프로젝트에서 배우는 것

  • while 반복문으로 숫자를 줄여가며 출력할 수 있습니다.
  • n-- 연산으로 변수를 1씩 감소시키는 방법을 익힙니다.
  • 조건이 거짓이 될 때 반복이 끝나는 원리를 이해합니다.
  • 2씩 감소, 조건 강조 등 다양한 변형을 만들 수 있습니다.
  • 완성된 프로그램을 보며 반복문 흐름 전체를 그릴 수 있습니다.

카운트다운 타이머 — 기본 구현

사용자가 시작 숫자를 입력하면, while 반복문으로 숫자를 하나씩 줄여가며 출력하다가 0이 되면 "발사!"를 출력하는 프로그램입니다.

// 카운트다운 타이머 — 기본 버전 #include <stdio.h> int main() { int n; printf("시작 숫자를 입력하세요: "); scanf("%d", &n); while (n > 0) { // n이 0보다 큰 동안 반복 printf("%d\n", n); // 현재 n 출력 n--; // n을 1 줄임 } printf("발사!\n"); // 반복 끝나면 발사 출력 return 0; }

확장 1 — 2씩 감소 & 3초 전 강조

기본 카운트다운을 더 실감나게 바꿔봅니다. 숫자를 2씩 줄이거나, 3 이하일 때 다른 메시지를 출력해 긴장감을 높입니다.

// 확장 버전: 2씩 감소 + 3 이하 강조 #include <stdio.h> int main() { int n; printf("시작 숫자 입력 (짝수 추천): "); scanf("%d", &n); while (n > 0) { if (n <= 3) { printf("*** %d *** 곧 발사!\n", n); // 3 이하면 강조 } else { printf("%d\n", n); } n -= 2; // 2씩 감소 } printf("발사!\n"); return 0; }

확장 2 — sleep()으로 딜레이 추가

sleep(1)을 사용하면 1초씩 기다리며 카운트다운을 출력할 수 있습니다. 실제 타이머처럼 동작합니다.

// sleep() 딜레이 추가 버전 #include <stdio.h> #include <unistd.h> // sleep() 함수 포함 (Linux/Mac) // Windows: #include <windows.h> Sleep(1000); 으로 사용 int main() { int n = 5; while (n > 0) { printf("%d\n", n); sleep(1); // 1초 대기 n--; } printf("발사!\n"); return 0; }
sleep() 참고

핵심 정리

카운트다운 타이머 핵심 요약

  • while (n > 0) — n이 0보다 크면 계속 반복합니다.
  • n-- — n을 1씩 줄입니다. n = n - 1과 완전히 같습니다.
  • n -= 2 — n을 2씩 줄입니다. 홀수/짝수 중 하나만 거칩니다.
  • 조건이 처음부터 거짓(n=0)이면 반복문 본체는 한 번도 실행되지 않습니다.
  • sleep(1)로 1초 딜레이를 추가할 수 있습니다.
무한루프 주의
n--을 잊으면 n이 영원히 줄지 않아서 프로그램이 끝나지 않습니다. 반복문 안에서 반드시 종료 조건이 변하도록 코드를 작성하세요.
