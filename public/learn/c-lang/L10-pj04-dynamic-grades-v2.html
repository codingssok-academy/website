동적 학생 수
성적 관리 프로그램

학생 수를 실행 중에 입력받아 동적으로 배열을 할당하고, 이름과 점수를 관리하며 통계를 출력합니다.

이 프로젝트에서 만드는 것

  • Student 구조체 포인터 배열을 동적 할당합니다.
  • 이름과 점수를 입력받아 저장합니다.
  • 평균, 최고점, 최저점을 계산합니다.
  • 석차(등수)를 계산하여 출력합니다.
  • 구조체 배열을 안전하게 해제합니다.

완성 코드

#include <stdio.h> #include <stdlib.h> #include <string.h> typedef struct { char name[30]; int score; } Student; int main() { int n; printf("학생 수: "); scanf("%d", &n); Student *st = (Student*)malloc(sizeof(Student)*n); if(!st){ printf("할당 실패\n"); return 1; } for(int i=0;i<n;i++){ printf("%d번 이름 점수: ",i+1); scanf("%s %d", st[i].name, &st[i].score); } int sum=0, maxS=st[0].score, minS=st[0].score; for(int i=0;i<n;i++){ sum+=st[i].score; if(st[i].score>maxS) maxS=st[i].score; if(st[i].score<minS) minS=st[i].score; } printf("\n== 성적 결과 ==\n"); printf("평균: %.1f 최고: %d 최저: %d\n", (double)sum/n, maxS, minS); printf("\n이름\t점수\t등수\n"); for(int i=0;i<n;i++){ int rank=1; for(int j=0;j<n;j++) if(st[j].score>st[i].score) rank++; printf("%s\t%d\t%d등\n", st[i].name, st[i].score, rank); } free(st); st=NULL; return 0; }

실행 결과

학생 수: 4 1번 이름 점수: 홍길동 85 2번 이름 점수: 김철수 92 3번 이름 점수: 박영희 78 4번 이름 점수: 이민준 95 == 성적 결과 == 평균: 87.5 최고: 95 최저: 78 이름 점수 등수 홍길동 85 3등 김철수 92 2등 박영희 78 4등 이민준 95 1등

도전 과제

1. 점수 순으로 정렬하여 출력해보세요 (버블 정렬).
2. 90점 이상은 "우수", 60점 미만은 "미달"로 표시하세요.
3. 과목을 여러 개(국어, 영어, 수학) 받아 총점과 평균을 계산하세요.
