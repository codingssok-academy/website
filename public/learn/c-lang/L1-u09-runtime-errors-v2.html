Unit 09

런타임 에러 — 실행 중 오류

컴파일은 성공했지만 실행 중에 발생하는 오류를 이해하고 고치는 방법을 배웁니다.

이 유닛에서 배우는 것

  • 컴파일 에러와 런타임 에러의 차이를 설명할 수 있습니다.
  • 0으로 나누기 오류가 왜 발생하는지 이해합니다.
  • 배열 범위 초과 오류를 인식하고 수정할 수 있습니다.
  • 에러 메시지를 읽고 원인을 찾을 수 있습니다.
  • 방어적 코딩으로 런타임 에러를 예방할 수 있습니다.

에러의 세 가지 종류

C 프로그램에서 발생하는 오류는 크게 세 가지로 나뉩니다. 런타임 에러는 컴파일은 통과했지만 실행 중에 발생하는 오류입니다.

런타임 에러가 발생하면 프로그램이 갑자기 종료됩니다. 가장 흔한 원인은 0으로 나누기와 배열 범위 초과입니다.

// 런타임 에러 예시 — 0으로 나누기 int a = 10; int b = 0; printf("%d\n", a / b); // 실행 중 오류 발생!
따라해보세요
1
0으로 나누기 오류를 직접 확인하세요. (컴파일은 성공합니다)
int x = 5, y = 0; printf("%d\n", x / y);
컴파일 성공 → 실행 시 프로그램 종료됨

주요 런타임 에러와 수정법

런타임 에러의 종류별로 원인과 해결 방법을 알아봅니다.

가장 안전한 방법은 if문으로 미리 검사하는 것입니다. 이를 방어적 코딩이라고 합니다.

// 방어적 코딩 — 나누기 전에 검사 int a = 10; int b = 0; if (b != 0) { printf("결과: %d\n", a / b); } else { printf("오류: 0으로 나눌 수 없습니다\n"); }
따라해보세요
1
방어적 코딩으로 0 나누기를 막으세요.
int a = 20, b = 0; if (b != 0) printf("%d\n", a / b); else printf("나눌 수 없음\n");
나눌 수 없음 이 출력됩니다
2
배열 크기와 인덱스를 확인하세요.
int arr[3] = {10, 20, 30}; printf("%d %d %d\n", arr[0], arr[1], arr[2]);
10 20 30
3
입력값이 0인지 검사하는 나눗셈 프로그램을 만드세요.
int num; scanf("%d", &num); if (num == 0) { printf("입력이 0입니다\n"); } else { printf("100 / %d = %d\n", num, 100 / num); }
0 입력 시 경고, 5 입력 시 20 출력

정답 확인

핵심 요약

  • 런타임 에러는 컴파일은 성공하지만 실행 중에 발생하는 오류다
  • 가장 흔한 원인: 0으로 나누기, 배열 범위 초과
  • 나누기 전에 if (b != 0)으로 검사하는 것이 방어적 코딩이다
  • 배열 크기가 N이면 인덱스는 0 ~ N-1까지만 사용한다
  • 에러 메시지 "Segmentation fault"는 메모리 접근 오류를 의미한다
