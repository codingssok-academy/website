ASCII 아트 동물원

텍스트 문자로 귀여운 동물 그림을 만들어 동물원을 완성합니다.

이 프로젝트에서 만들 것

  • 텍스트 문자로 고양이 ASCII 아트를 완성합니다.
  • 강아지, 물고기 등 3가지 동물을 그립니다.
  • 동물원 입장 안내판도 만들어봅니다.
  • 특수문자와 이스케이프 시퀀스를 활용합니다.
  • 여러 동물을 한 화면에 이어서 출력합니다.

ASCII 아트란?

ASCII 아트는 키보드 문자만으로 그림을 표현하는 기술입니다. printf와 특수문자를 조합하면 귀여운 동물 그림을 만들 수 있습니다.

줄바꿈 \n을 이용해 여러 행에 걸쳐 그림을 완성합니다. 역슬래시는 반드시 \\로 써야 합니다.

// 고양이 ASCII 아트 printf(" /\\_/\\\n"); printf("( o.o )\n"); printf(" > ^ <\n"); printf(" 고양이\n");
따라해보세요
1
위의 고양이 코드를 직접 입력하고 실행하세요.
printf(" /\\_/\\\n"); printf("( o.o )\n"); printf(" > ^ <\n");
고양이 그림이 출력됩니다
2
눈을 바꿔서 자고 있는 고양이를 만드세요 (o.o → -.-)
printf(" /\\_/\\\n"); printf("( -.- )\n"); printf(" > ^ <\n");
자고 있는 고양이가 출력됩니다

동물원 완성하기

강아지와 물고기 그림을 추가하여 동물원을 완성해봅시다.

// 강아지 printf(" __\n"); printf("(oo)\n"); printf(/)( )\n"); printf(" 강아지\n\n");
// 물고기 printf(" ><(((o>\n"); printf(" 물고기\n\n");
// 동물원 완성 — 입장 안내판 + 세 동물 printf("===================\n"); printf(" ASCII 동물원\n"); printf("===================\n\n"); printf(" /\\_/\\\n"); printf("( o.o )\n"); printf(" > ^ <\n"); printf(" [고양이]\n\n"); printf(" /\\ /\\\n"); printf((U U)\n"); printf(" [강아지]\n\n"); printf(" ><(((o>\n"); printf(" [물고기]\n");
따라해보세요
1
동물원 안내판을 만들어 출력하세요.
printf("*******************\n"); printf("* 동물원에 오신 *\n"); printf("* 것을 환영합니다 *\n"); printf("*******************\n");
별표 테두리 안내판이 출력됩니다
2
나만의 동물(토끼)을 만들어보세요.
printf("(\\ /)\n"); printf("( . .)\n"); printf(" c(\")(\") \n"); printf(" [토끼]\n");
토끼 그림이 출력됩니다
3
입장료 안내를 추가하세요.
printf("입장료: 어른 %d원 / 어린이 %d원\n", 5000, 2000);
입장료: 어른 5000원 / 어린이 2000원

Q2

쉬움

출력이름: 냥이
나이: 3살
내 답안

char name[] = "냥이"; int age = 3; printf("이름: %s\n", name); printf("나이: %d살\n", age);

핵심 요약

  • ASCII 아트는 키보드 문자만으로 그림을 표현하는 방법이다
  • 역슬래시 \는 \\로 써야 출력된다
  • \n으로 줄을 구분해 여러 행의 그림을 완성한다
  • 특수문자 / \ | _ - = ( ) ^ * # 등을 조합해 다양한 모양을 만든다
  • printf 여러 개를 연속으로 써서 하나의 그림을 완성한다
