Project 06

별 찍기 삼각형

중첩 for문으로 별(*)을 이어 붙여 삼각형 모양을 만들어 봅니다. 패턴 프로그래밍의 첫걸음입니다.

이 프로젝트에서 배우는 것

  • 중첩 for문의 구조(바깥 루프 + 안쪽 루프)를 설명할 수 있습니다.
  • 직각삼각형, 역삼각형, 이등변삼각형 패턴을 코드로 구현할 수 있습니다.
  • 행 번호와 출력 개수의 관계를 이해하고 응용할 수 있습니다.
  • 공백 문자를 활용해 모양을 정렬하는 방법을 익힐 수 있습니다.

중첩 for문이란?

for문 안에 또 다른 for문을 넣는 것을 중첩 for문이라고 합니다. 바깥 루프가 한 번 돌 때마다 안쪽 루프 전체가 실행됩니다. 별 찍기 패턴에서는 바깥 루프 = 행(줄), 안쪽 루프 = 열(별 개수)를 담당합니다.

직각삼각형 — 코드와 출력

가장 기본적인 패턴입니다. i행에서 별을 i개 찍고, 줄을 바꿉니다. 안쪽 루프 조건을 j <= i로 설정하는 게 핵심입니다.

// 직각삼각형 별 찍기 (5줄) int i, j; for (i = 1; i <= 5; i++) { // 바깥: 1~5행 for (j = 1; j <= i; j++) { // 안쪽: i개만큼 printf("*"); } printf("\n"); // 줄 바꿈 }

확장 1 — 역삼각형

직각삼각형을 뒤집으면 역삼각형입니다. 바깥 루프를 큰 수에서 작은 수로 내려오면(i = n부터 시작해 1까지), 안쪽 루프 조건은 동일하게 j <= i를 쓰면 됩니다.

// 역삼각형 (5줄) int i, j; for (i = 5; i >= 1; i--) { // 바깥: 5→1 감소 for (j = 1; j <= i; j++) { // 안쪽: i개만큼 printf("*"); } printf("\n"); }

확장 2 — 이등변삼각형 (공백 + 별)

이등변삼각형은 별 앞에 공백을 넣어 가운데로 정렬합니다. n줄짜리라면 i행의 공백은 n - i개, 별은 2*i - 1개입니다.

// 이등변삼각형 (5줄) int i, j, n = 5; for (i = 1; i <= n; i++) { // 1. 공백 출력: n-i 개 for (j = 1; j <= n - i; j++) { printf(" "); } // 2. 별 출력: 2*i-1 개 for (j = 1; j <= 2 * i - 1; j++) { printf("*"); } printf("\n"); }
공식 정리

n줄짜리 이등변삼각형 → i행: 공백 = n - i개, 별 = 2×i - 1개
1행: 공백 4, 별 1 / 2행: 공백 3, 별 3 / 5행: 공백 0, 별 9

힌트: n=4, 안쪽 루프 2개 — 첫 번째는 공백(j<=n-i), 두 번째는 별(j<=2*i-1)

int i, j, n = 4; for (i = 1; i <= n; i++) { for (j = 1; j <= n - i; j++) printf(" "); for (j = 1; j <= 2 * i - 1; j++) printf("*"); printf("\n"); }

핵심 정리

  • 중첩 for문: 바깥 루프(행) 한 번 → 안쪽 루프(열) 전체 실행
  • 직각삼각형: 바깥 i=1~n 증가, 안쪽 j=1~i
  • 역삼각형: 바깥 i=n~1 감소, 안쪽 j=1~i (안쪽 동일)
  • 이등변삼각형: 공백 루프(j <= n-i) + 별 루프(j <= 2*i-1)
  • 각 행이 끝날 때 printf("\n") 필수 — 빠뜨리면 한 줄로 붙어버림
