# 코딩쏙 Growth 2.0 운영 정책 RC1 기본안

이 문서는 최종 운영 확정안이 아닙니다. 원장님이 통합 데모를 확인하기 위한 RC1 기본안입니다.

## 학생에게 보여주는 내용

- 학생은 잘한 점과 다음 수업 목표를 중심으로 확인합니다.
- 보완할 점은 학생에게 직접 표시하지 않습니다.
- 공개된 최신 평가와 공개 학습 개념만 보여줍니다.

## 학부모에게 보여주는 내용

- 학부모는 잘한 점, 보완할 점, 다음 수업 목표를 함께 확인합니다.
- 한 학부모가 여러 자녀를 연결하고 선택할 수 있습니다.
- 공개되지 않은 초안과 이전 보관 평가는 보여주지 않습니다.

## 선생님의 평가 절차

- 선생님은 먼저 평가 초안을 저장합니다.
- 저장과 공개는 서로 다른 행동으로 구분합니다.
- 공개 전 확인 화면에서 학생과 학부모에게 보이는 범위를 다시 확인합니다.
- 이전 공개 평가는 삭제하지 않고 기록으로 보관합니다.
- 직접 입력한 학습 개념은 해당 평가에만 저장합니다.

## 경험치와 알림

- 경험치는 학습 활동별로 정해진 고정 점수를 사용합니다.
- 같은 활동으로 경험치가 중복 지급되지 않도록 합니다.
- 알림톡과 자동 알림은 아직 발송하지 않습니다.

## 실제 서비스 적용 원칙

- 실제 서비스 적용 전 충분한 시범 운영을 진행합니다.
- 실제 개인정보는 온라인 시험 환경과 보호 절차가 준비된 뒤 사용합니다.
- RC1에서는 가상 학생과 로컬 데이터베이스만 사용합니다.
