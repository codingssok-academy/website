# Growth 2.0 통합 데모 RC1 안내서

## 통합 데모란?

Growth 2.0 통합 데모는 학생, 학부모, 선생님 화면이 하나의 연습용 데이터베이스에서 어떻게 이어지는지 확인하는 시험 환경입니다.

실제 운영 홈페이지와 운영 데이터베이스에서 완전히 분리되어 있습니다. 테스트 학생 A와 B 등 가상 자료만 사용하며 실제 학생 개인정보는 들어 있지 않습니다.

## 한 번에 시작하기

PowerShell에서 다음 한 줄을 실행합니다.

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "C:\dev\codingssok-growth-v2-demo-rc1\scripts\start-growth2-integrated-demo.ps1"
```

정상적으로 시작되면 학생, 학부모, 선생님 화면이 각각 열립니다.

## 한 번에 종료하기

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "C:\dev\codingssok-growth-v2-demo-rc1\scripts\stop-growth2-integrated-demo.ps1"
```

종료하면 가상 사용자와 평가 자료를 정리하고 이 데모용 로컬 데이터베이스만 종료합니다.

## 확인 주소

- 학생: http://127.0.0.1:3018/growth-preview/student-local
- 학부모: http://127.0.0.1:3018/growth-preview/parent-local
- 선생님: http://127.0.0.1:3018/growth-preview/teacher-local
- 기존 가상 학생 화면: http://127.0.0.1:3018/growth-preview

## 권장 확인 순서

1. 학생 A로 들어가 공개 평가 v1과 학습 기록을 확인합니다.
2. 학생 B로 들어가 공개 평가가 없는 정상 상태를 확인합니다.
3. 학부모 화면에서 학생 A v1과 학생 B 빈 상태를 확인합니다.
4. 선생님 화면에서 학생 A의 작성 중 v2를 확인하고 공개합니다.
5. 학생 A 화면에서 `최신 내용 다시 불러오기`를 누르고 v2를 확인합니다.
6. 학생에게 보완할 점이 보이지 않는지 확인합니다.
7. 학부모 화면에서 학생 A v2와 보완할 점을 확인합니다.
8. 선생님 화면에서 학생 B의 첫 v1을 공개합니다.
9. 학생과 학부모 화면에서 학생 B v1과 직접 입력 개념을 확인합니다.
10. 화면을 새로고침한 뒤 다시 로그인해 공개 결과가 유지되는지 확인합니다.

## 화면별로 볼 내용

### 학생 화면

잘한 점, 다음 수업 목표, 이번 주 학습 개념과 실제 읽기 기능이 제공하는 XP, 미션, 프로젝트, 성장 기록, 배지를 확인합니다. 보완할 점은 학생에게 표시하지 않습니다.

### 학부모 화면

연결된 자녀를 선택해 잘한 점, 보완할 점, 다음 수업 목표, 학습 개념과 공개 기록을 확인합니다.

### 선생님 화면

담당 학생의 평가 초안을 확인하고 저장과 공개를 구분해 체험합니다. 공개 버튼을 누른 뒤 한 번 더 확인해야 실제로 공개됩니다.

## 공개 전과 공개 후

공개 전에는 작성 중인 평가가 선생님 화면에만 보입니다. 공개 후에는 학생과 학부모가 최신 평가를 읽을 수 있습니다. 학생에게는 잘한 점과 다음 목표가, 학부모에게는 보완할 점까지 표시됩니다.

## 새로고침하면 로그인이 풀리는 이유

이 데모는 로그인 정보를 브라우저에 저장하지 않습니다. 개인정보와 로그인 정보가 남지 않도록 화면을 새로고침하면 가상 로그인이 해제됩니다. 공개된 평가는 로컬 데이터베이스에 유지되므로 다시 로그인하면 최신 상태가 나타납니다.

## 꼭 알아둘 점

- 실제 개인정보가 없는 로컬 시험 환경입니다.
- 실제 운영 배포가 아닙니다.
- 운영 사이트와 운영 데이터베이스에 연결되지 않습니다.
- 데모를 마치면 종료 명령으로 안전하게 정리합니다.
