# 공개 파일 다운로드 진단

검사일: 2026-09-05 (한국 시간)

## 사용자 보고와 범위

사용자는 Chrome 다운로드 목록에 `가짜연결작품.txt`가 보이지 않는다고 보고했다. 이번에는 이전 시험 요청의 Vercel/Supabase 로그와 로컬 코드를 읽어 원인을 조사했다. 새 계정·파일·DB 자료를 생성하지 않았고 운영 DB에 연결하지 않았다. 소스, 환경변수, DB 구조·권한, 배포를 변경하지 않았다.

## 확인한 증거

1. 기존 Preview의 12:47:38 요청 `/api/student/files/d2a80165-d1dd-4fce-9b18-75e882472135`는 Vercel 함수까지 도착했고 HTTP **307**을 반환했다. 방화벽은 Allowed였다.
2. 시험 저장소는 같은 가짜 파일의 서명 주소 생성 POST에 **200**, 이어진 Chrome의 실제 파일 GET에도 **200**을 반환했다.
3. 저장소 응답은 `text/plain`, `Content-Length: 78`, `Content-Disposition: attachment`였다. 준비했던 가짜 파일의 크기와 일치한다. 서버 응답 성공이지 사용자의 디스크 저장 완료 증거는 아니다.
4. 다운로드 이름은 한글 원문이 아니라 중복 인코딩된 문자열이었다. 응답의 `filename*` 값이 `UTF-8''%25EA%25B0...txt`로 시작했다. 한 번 해석하면 `%EA%B0...txt`가 남는다.
5. 현재 설치된 `@supabase/storage-js` 2.110.0의 `createSignedUrl`은 `URLSearchParams`로 download 값을 인코딩한 뒤 완성된 URL 전체에 `encodeURI`를 다시 적용한다. 홈페이지 파일 API는 `createSignedUrl(path, 60, { download: file.original_name })`를 사용한다.

## 외부 요청 없는 재현

설치된 SDK에 가짜 fetch 응답을 주어 확인했다. 실제 네트워크 요청과 비밀키 사용 없이 네 번 모두 재현했다.

| 원본 파일명 | download 값이 원본과 같은가 |
| --- | --- |
| `report.txt` | 예 |
| `가짜연결작품.txt` | 아니요: `%EA%B0...txt` 형태가 남음 |
| `my work.txt` | 예 |
| `100%.txt` | 아니요: `100%25.txt`가 됨 |

따라서 **한글·퍼센트 문자가 들어간 다운로드 파일명 처리 오류는 확인했다.** 그러나 이름이 깨진 후보 파일도 확인한 두 다운로드 위치에서는 발견되지 않았으므로, 이것이 다운로드 목록에 아무 항목도 없는 현상의 유일한 원인이라고 확정하지 않는다. 브라우저 내부 다운로드 페이지에 대한 도구의 접근 제한을 우회하지 않았다.

## 이전 검사 결론의 정정

해당 파일 요청 시각에 시험 저장소 로그는 Auth user 확인, `codingssok_can_read_student_file` RPC, 가짜 학생의 프로필 조회를 기록했다. 코드상 이는 파일 API의 학생/교사 로그인 권한 경로다. UI에서 학생 로그아웃 뒤 학부모 화면에 들어갔다는 사실만으로 학생 서버 세션이 종료됐다고 볼 수 없다.

따라서 **학부모 단독 세션으로 파일 다운로드가 허용되는지에 대한 검사는 아직 완료되지 않았다.** 관리자→학생→학부모 성장 내용 표시 확인과 내부 메모 비표시 확인을 취소하는 것은 아니며, 파일 다운로드 권한의 시험 조건을 바로잡는 것이다. 로그아웃 원인은 이번 진단에서 별도 수정하지 않았다.

## 제안하는 다음 작업

- 기존 권한 검사와 60초짜리 파일 링크는 유지한다.
- download 파일명을 URL에 한 번만 인코딩하도록 처리한다. 전체 서명 주소를 통째로 디코딩하거나 버킷을 공개하지 않는다.
- 한글·공백·퍼센트 문자가 포함된 파일명 회귀 검사를 추가한다.
- 학생 서버 로그인 상태가 없는 학부모 세션에서 실제 다운로드를 다시 확인한다. 사용자 컴퓨터에 파일이 저장된 증거까지 확인한 뒤에만 완료로 판정한다.
- 이번 사용자 답변은 진단 범위로 처리했으며 위 수정은 아직 적용하지 않았다.
