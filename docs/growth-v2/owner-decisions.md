# Growth 2.0 원장님 결정 사항

> 기술 질문이 아니라 실제 학원 운영 방법을 정하는 질문입니다. 최대 5개만 먼저 결정하면 됩니다.

## 1. 선생님 평가를 언제 학부모에게 공개할까요?

선택 예시:

- 선생님이 저장 후 직접 공개
- 선생님이 작성하고 원장님 확인 후 공개

**추천 기본안: 초기 테스트는 선생님 직접 공개**

이유: 먼저 실제 수업 뒤 작성 시간이 얼마나 걸리는지 확인할 수 있습니다. 원장 확인이 꼭 필요한 평가 유형이 발견되면 그때 승인 단계를 추가하는 편이 단순합니다.

예시: 선생님이 금요일 수업 후 평가를 작성하고 `학부모에게 공개`를 누르면 바로 주간 리포트에 표시됩니다.

## 2. 학생에게 보완할 점도 보여 줄까요?

선택 예시:

- 학생: 잘한 점 + 다음 목표만 표시
- 학생: 잘한 점 + 보완할 점 + 다음 목표 모두 표시

**추천 기본안: 학생에게는 잘한 점과 다음 목표만 표시**

이유: 어린 학생이 부족하다는 느낌보다 다음에 무엇을 하면 되는지 쉽게 이해하는 데 도움이 됩니다. 보완할 점의 자세한 문장은 학부모에게 제공합니다.

예시: 학생 화면에는 “질문하는 습관이 좋아졌어요”와 “다음에는 점수 기능을 만들어요”가 보입니다.

## 3. 공개된 평가를 언제까지 수정할 수 있게 할까요?

선택 예시:

- 공개 당일까지만 수정
- 다음 주 리포트가 나오기 전까지 수정
- 기간 제한 없이 수정

**추천 기본안: 다음 주 평가 작성 전까지 수정 가능**

단, 기존 문장을 지우지 않고 수정 버전을 새로 남깁니다. 학부모에게는 최신 공개 버전만 보입니다.

예시: 월요일에 오타를 발견하면 버전 2로 고쳐 다시 공개하고, 버전 1은 기록으로 보관합니다.

## 4. 학부모가 여러 자녀를 한 계정에서 볼 수 있게 할까요?

**추천 기본안: 가능하게 설계**

형제·자매가 함께 다니는 경우가 있으므로 학부모 계정 하나에서 자녀를 선택하는 편이 편리합니다. 각 자녀는 관리자가 정확히 연결한 경우에만 보입니다.

예시: 학부모 화면 위에서 `민준`, `서연` 중 한 명을 선택합니다. 다른 학부모의 자녀는 절대 보이지 않습니다.

## 5. 경험치 규칙을 고정할까요, 원장님이 바꿀 수 있게 할까요?

선택 예시:

- 초기에는 미션별 경험치 고정
- 관리자 화면에서 언제든 변경

**추천 기본안: 초기 MVP는 고정**

이유: 경험치 기준이 자주 바뀌면 같은 활동인데 시기마다 보상이 달라져 설명하기 어려울 수 있습니다. 실제 운영 자료가 쌓인 뒤 관리자 변경 기능을 추가하는 편이 안전합니다.

예시: “프로젝트 기록 완료 +25 XP”를 한 학기 동안 고정하고, 학기 종료 후 조정 여부를 검토합니다.

## 결정 기록란

| 항목 | 추천안 사용 여부 | 원장님 결정 |
|---|---|---|
| 평가 공개 주체 | 선생님 직접 공개 | 미정 |
| 학생에게 보완할 점 표시 | 표시하지 않음 | 미정 |
| 공개 평가 수정 기간 | 다음 주 평가 전까지 | 미정 |
| 여러 자녀 보기 | 허용 | 미정 |
| 경험치 규칙 | 초기 고정 | 미정 |

결정 전에는 이 문서의 추천안을 테스트 기본값으로만 사용하며 운영에 적용하지 않습니다.
