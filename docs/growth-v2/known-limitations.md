# Growth 2.0 통합 데모 RC1 알려진 제한사항

RC1은 학생·학부모·선생님 평가 공개 흐름을 확인하는 로컬 통합 데모입니다. 다음 기능은 아직 연결하지 않았습니다.

- 실제 사용자 로그인
- 비밀번호 재설정
- 온라인 Supabase
- 실제 학생 정보
- 학부모 상담과 댓글
- 알림톡
- PDF 리포트
- 공동 환경의 실제 미션 완료
- 프로젝트 기록 저장
- 관리자 화면
- 운영 모니터링
- 백업과 복구
- 운영 배포

## 개발 환경 안내

전체 홈페이지 코드 정리 검사에는 Growth 2.0과 관계없는 기존 오류가 남아 있습니다. 이번 RC1 변경 파일은 별도로 검사하며 통과 여부를 구분해 기록합니다.

개발 화면에서는 기본 주소 설정 안내와 존재하지 않는 `manifest.json` 요청 안내가 나타날 수 있습니다. 이는 Growth 2.0 평가, 로그인, 공개, 읽기 기능의 오류가 아닙니다.

## 화면 캡처

자동 캡처가 가능한 환경에서는 `docs/growth-v2/screenshots/`에 PC와 휴대폰 화면을 보관합니다. 캡처에는 실제 개인정보나 비밀값을 포함하지 않습니다.
